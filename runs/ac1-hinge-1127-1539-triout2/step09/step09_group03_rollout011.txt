1. **Problem size** – Choose a length `n` depending on the time budget.
   Larger `n` gives more freedom; we stay ≤ 15 000 to keep FFT cheap.

2. **Warm‑start / candidate generation**  
   * If a previous best sequence (`height_sequence_1`) exists – resize it.  
   * Otherwise create a portfolio of simple parametric families  
     (power‑law, exponential, half‑sine, linear‑decrease, mixtures) and a few
     random Dirichlet draws.  All candidates are projected onto the simplex
     `Σa = √(2n)`.  The best candidate (lowest max‑convolution) becomes the
     starting point.

3. **Soft‑max Adam descent** – Optimise the smooth surrogate  
   `ℓ_β(a)=log Σ_k exp(β·(a*a)_k)`.  
   β is increased geometrically (1 → 10⁶) while an Adam optimiser with
   projection onto the simplex drives the objective down.

4. **Exact‑max Adam descent** – Switch to the true sub‑gradient of
   `max(a*a)` (indicator of the maximal convolution entries).  Another Adam
   phase refines the shape further.

5. **Mass‑transfer local refinement** – Repeatedly move a chunk of mass from
   an index that contributes most to the current maximal entry (largest
   gradient component) to an index that contributes least.  Each move is
   accepted if it improves the true max‑convolution, otherwise with a
   simulated‑annealing probability.  Convolution is recomputed with an FFT
   after every move; the loop runs until the time budget is exhausted.

6. **Clean‑up** – Trim trailing zeros, evaluate with the provided
   `evaluate_sequence`, store the result for future warm‑starts and return
   the list of floats.

All steps respect non‑negativity and the ℓ¹‑norm constraint, and the whole
search finishes well within the allotted 1000 s.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic convolution utilities
# ----------------------------------------------------------------------


def _conv_fft(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a (length 2·n‑1) using a power‑of‑two FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return conv


def _max_convolution_fft(a: np.ndarray) -> float:
    """Maximum entry of the convolution a*a."""
    return float(_conv_fft(a).max())


def _score(a: np.ndarray) -> float:
    """Objective 2·n·max(a*a) / (sum(a)²).  For Σa=√(2n) this equals max(a*a)."""
    n = a.shape[0]
    max_b = _max_convolution_fft(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Simple helpers
# ----------------------------------------------------------------------


def _project_to_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Euclidean projection onto the simplex {x ≥ 0, Σx = s}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    theta = 0.0 if rho.size == 0 else cssv[rho[-1]] / (rho[-1] + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _resize_sequence(seq: np.ndarray, new_len: int) -> np.ndarray:
    """Linear interpolation of `seq` to `new_len` entries."""
    old_len = seq.shape[0]
    if new_len == old_len:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, old_len)
    new_x = np.linspace(0.0, 1.0, new_len)
    return np.interp(new_x, old_x, seq).astype(np.float64)


# ----------------------------------------------------------------------
# Gradient of the soft‑max surrogate (used in phase 3)
# ----------------------------------------------------------------------


def _gradient_softmax(a: np.ndarray, beta: float):
    """
    Gradient of the soft‑max approximation of max(convolution).
    Returns (grad, conv) where conv is the full convolution a*a.
    """
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    a_fft = np.fft.rfft(a, n=size)
    b = np.fft.irfft(a_fft * a_fft, n=size)[: 2 * n - 1]

    max_b = b.max()
    exps = np.exp(beta * (b - max_b))
    p = exps / exps.sum()

    # grad = 2 * (reverse(a) convolve p)
    a_rev = a[::-1]
    grad_full = np.fft.irfft(np.fft.rfft(a_rev, n=size) *
                             np.fft.rfft(p, n=size), n=size)[:2 * n - 1]
    grad = 2.0 * grad_full[n - 1:n - 1 + n]
    return grad, b


# ----------------------------------------------------------------------
# Gradient of the true max (used in phase 4)
# ----------------------------------------------------------------------


def _gradient_of_max(a: np.ndarray):
    """
    Sub‑gradient of max(a*a).  Returns (grad, max_val) where grad has the same
    size as `a`.  The gradient corresponds to an indicator of the currently
    maximal convolution entries.
    """
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    a_fft = np.fft.rfft(a, n=size)
    b = np.fft.irfft(a_fft * a_fft, n=size)[:2 * n - 1]

    max_b = b.max()
    # tolerance to catch all ties (numerical)
    tol = max_b * 1e-12 + 1e-14
    mask = (b >= max_b - tol).astype(np.float64)

    a_rev = a[::-1]
    grad_full = np.fft.irfft(np.fft.rfft(a_rev, n=size) *
                             np.fft.rfft(mask, n=size), n=size)[:2 * n - 1]
    grad = 2.0 * grad_full[n - 1:n - 1 + n]
    return grad, max_b


# ----------------------------------------------------------------------
# Phase 3 – Adam on the soft‑max surrogate
# ----------------------------------------------------------------------


def _adam_softmax_phase(a0: np.ndarray,
                        target_sum: float,
                        deadline: float) -> tuple[np.ndarray, float]:
    """Adam optimiser on the soft‑max surrogate (β increased geometrically)."""
    a = _project_to_simplex(a0.copy(), target_sum)
    best_a = a.copy()
    best_val = _score(a)

    beta = 1.0
    max_beta = 1e7
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1, beta2 = 0.9, 0.999
    eps = 1e-12
    t = 0
    rng = np.random.default_rng()

    while time.time() < deadline:
        t += 1
        grad, _ = _gradient_softmax(a, beta)

        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        step = (target_sum * 0.2) * m_hat / (np.sqrt(v_hat) + eps)
        a -= step
        a = _project_to_simplex(a, target_sum)

        # occasional jitter to escape tiny plateaus
        if t % 800 == 0:
            jitter = rng.normal(scale=target_sum * 0.0007, size=a.shape)
            a = np.maximum(a + jitter, 0.0)
            a = _project_to_simplex(a, target_sum)

        val = _score(a)
        if val < best_val:
            best_val = val
            best_a = a.copy()
            print(f"[{time.time():.2f}] SoftmaxAdam it={t} β={beta:.1e} score={best_val:.6f}")

        # increase β periodically
        if t % 300 == 0 and beta < max_beta:
            beta = min(beta * 2.0, max_beta)

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 4 – Adam on the exact max (sub‑gradient)
# ----------------------------------------------------------------------


def _adam_max_phase(a0: np.ndarray,
                    target_sum: float,
                    deadline: float) -> tuple[np.ndarray, float]:
    """Adam optimiser on the true max (sub‑gradient)."""
    a = _project_to_simplex(a0.copy(), target_sum)
    best_a = a.copy()
    best_val = _score(a)

    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1, beta2 = 0.9, 0.999
    eps = 1e-12
    t = 0
    rng = np.random.default_rng()

    while time.time() < deadline:
        t += 1
        grad, max_b = _gradient_of_max(a)

        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        step = (target_sum * 0.2) * m_hat / (np.sqrt(v_hat) + eps)
        a -= step
        a = _project_to_simplex(a, target_sum)

        # jitter every few hundred steps
        if t % 600 == 0:
            jitter = rng.normal(scale=target_sum * 0.001, size=a.shape)
            a = np.maximum(a + jitter, 0.0)
            a = _project_to_simplex(a, target_sum)

        val = _score(a)
        if val < best_val:
            best_val = val
            best_a = a.copy()
            print(f"[{time.time():.2f}] MaxAdam it={t} score={best_val:.6f}")

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 5 – aggressive mass‑transfer local refinement
# ----------------------------------------------------------------------


def _mass_transfer_refine(a0: np.ndarray,
                         target_sum: float,
                         deadline: float) -> tuple[np.ndarray, float]:
    """
    Hill‑climbing / simulated‑annealing on the true max‑convolution.
    Moves a chunk of mass from a “bad’’ index (large gradient) to a
    “good’’ index (small gradient).  Convolution is recomputed with FFT
    after each move.
    """
    a = a0.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_val = _score(a)

    rng = np.random.default_rng()
    start = time.time()
    size = 1 << ((2 * n - 1).bit_length())

    # temperature schedule (linear decay)
    T0 = best_val * 0.03

    while time.time() < deadline:
        # 1. current convolution and gradient of the max entry
        a_fft = np.fft.rfft(a, n=size)
        b = np.fft.irfft(a_fft * a_fft, n=size)[:2 * n - 1]
        max_b = b.max()
        tol = max_b * 1e-12 + 1e-14
        mask = (b >= max_b - tol).astype(np.float64)

        a_rev = a[::-1]
        grad_full = np.fft.irfft(np.fft.rfft(a_rev, n=size) *
                                 np.fft.rfft(mask, n=size), n=size)[:2 * n - 1]
        grad = 2.0 * grad_full[n - 1:n - 1 + n]

        # 2. pick donor (largest gradient where there is mass)
        donor_candidates = np.where(a > target_sum * 1e-8)[0]
        if donor_candidates.size == 0:
            break
        donor = donor_candidates[np.argmax(grad[donor_candidates])]

        # 3. pick receiver (smallest gradient – could be zero)
        receiver = np.argmin(grad)
        if receiver == donor:
            # fall back to a random opposite index
            receiver = rng.integers(n)
            if receiver == donor:
                continue

        # 4. propose a transfer
        max_delta = min(a[donor] * 0.25, target_sum * 0.001)
        if max_delta <= 0:
            continue
        delta = rng.random() * max_delta

        a_new = a.copy()
        a_new[donor] -= delta
        a_new[receiver] += delta

        # 5. evaluate new max (exact)
        a_new_fft = np.fft.rfft(a_new, n=size)
        b_new = np.fft.irfft(a_new_fft * a_new_fft, n=size)[:2 * n - 1]
        new_val = float(2.0 * n * b_new.max() / (target_sum * target_sum))

        # 6. acceptance (simulated annealing)
        elapsed = time.time() - start
        temperature = max(0.0, T0 * (1.0 - elapsed / (deadline - start)))
        accept = False
        if new_val < best_val:
            accept = True
        elif temperature > 0.0:
            prob = np.exp(-(new_val - best_val) / temperature)
            if rng.random() < prob:
                accept = True

        if accept:
            a = a_new
            if new_val < best_val:
                best_val = new_val
                best_a = a.copy()
                print(f"[{time.time():.2f}] Transfer improved score={best_val:.6f}")

        # occasional re‑normalisation (drift)
        if time.time() - start > 20.0:
            a = _project_to_simplex(a, target_sum)
            start = time.time()  # reset for temperature computation

    return best_a, best_val


# ----------------------------------------------------------------------
# Candidate generation utilities
# ----------------------------------------------------------------------


def _make_candidate(arr: np.ndarray, target_sum: float) -> np.ndarray:
    """Clamp to non‑negative, project onto the simplex and return a copy."""
    arr = np.maximum(arr, 0.0)
    return _project_to_simplex(arr, target_sum)


def _generate_parameteric_candidates(n: int, target_sum: float):
    """Yield a series of simple parametric families (power‑law, exp, sine …)."""
    x = np.arange(n, dtype=np.float64)

    # power‑law descending
    for p in np.linspace(0.3, 2.0, 12):
        a = (n - x) ** (-p)
        yield _make_candidate(a, target_sum)

    # exponential decay
    for lam in np.linspace(0.0005, 0.010, 10):
        a = np.exp(-lam * x)
        yield _make_candidate(a, target_sum)

    # half‑sine (positive on (0,π))
    a = np.sin(np.pi * (x + 0.5) / n)
    yield _make_candidate(a, target_sum)

    # linear decreasing
    a = 1.0 - x / (n - 1)
    yield _make_candidate(a, target_sum)

    # mixtures: α·power‑law + (1‑α)·uniform
    uniform = np.ones_like(x)
    for p in [0.8, 1.2, 1.6]:
        base = (n - x) ** (-p)
        for alpha in np.linspace(0.2, 0.8, 5):
            a = alpha * base + (1.0 - alpha) * uniform
            yield _make_candidate(a, target_sum)

    # random Dirichlet draws
    rng = np.random.default_rng()
    for _ in range(30):
        a = rng.gamma(shape=0.5, scale=1.0, size=n)
        yield _make_candidate(a, target_sum)


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a non‑negative step sequence with a low benchmark score.
    The routine respects the time budget (seconds) and returns the best
    sequence found as a plain list of floats.
    """
    start = time.time()
    deadline = start + budget_s - 0.5          # small safety margin

    # ------------------------------------------------------------------
    # Choose length n (larger n → more degrees of freedom)
    # ------------------------------------------------------------------
    if budget_s >= 850:
        n = 15000
    elif budget_s >= 550:
        n = 12000
    else:
        n = 8000

    target_sum = np.sqrt(2.0 * n)

    # ------------------------------------------------------------------
    # Warm‑start / candidate generation
    # ------------------------------------------------------------------
    candidates = []

    # use previous best if present
    if "height_sequence_1" in globals():
        prev = np.array(globals()["height_sequence_1"], dtype=np.float64)
        candidates.append(_resize_sequence(prev, n))
    else:
        # simple fallback (power‑law)
        candidates.append(_make_candidate((n - np.arange(n)) ** -0.7, target_sum))

    # parametric families
    candidates.extend(_generate_parameteric_candidates(n, target_sum))

    # evaluate all candidates (fast FFT‑based score)
    best_a = None
    best_val = np.inf
    for idx, cand in enumerate(candidates):
        val = _score(cand)
        if val < best_val:
            best_val = val
            best_a = cand.copy()
        if idx % 20 == 0:
            print(f"[{time.time():.2f}] Candidate {idx}/{len(candidates)} best={best_val:.6f}")

    print(f"[{time.time():.2f}] After candidate sweep best score={best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – soft‑max Adam descent (≈15 % of remaining budget)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        phase3_dead = time.time() + 0.15 * (deadline - time.time())
        best_a, best_val = _adam_softmax_phase(best_a, target_sum, phase3_dead)
        print(f"[{time.time():.2f}] End softmax‑Adam best={best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 4 – exact‑max Adam descent (≈30 % of remaining budget)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        phase4_dead = time.time() + 0.30 * (deadline - time.time())
        best_a, best_val = _adam_max_phase(best_a, target_sum, phase4_dead)
        print(f"[{time.time():.2f}] End max‑Adam best={best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 5 – aggressive mass‑transfer refinement (remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = _mass_transfer_refine(best_a, target_sum, deadline)
        print(f"[{time.time():.2f}] End local refinement best={best_val:.6f}")

    # ------------------------------------------------------------------
    # Final clean‑up
    # ------------------------------------------------------------------
    arr = np.array(best_a, dtype=np.float64)
    nz = np.where(arr > 1e-12)[0]
    if nz.size:
        arr = arr[: nz[-1] + 1]

    final_seq = arr.tolist()

    try:
        final_val = evaluate_sequence(final_seq)   # type: ignore[name-defined]
        print(f"[{time.time():.2f}] Final evaluated score = {final_val:.6f}")
    except Exception as exc:
        print(f"[{time.time():.2f}] Evaluation error: {exc}")

    # store for warm‑starts in a later call
    globals()["height_sequence_1"] = final_seq

    return final_seq
