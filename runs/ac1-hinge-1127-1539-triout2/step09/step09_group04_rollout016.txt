"""
Triangular step function

For a given length n we take a linearly decreasing (triangular) sequence

    a_i = K * (n - i) ,    i = 0 … n‑1

with K chosen so that Σ a_i = √(2 n).  The self‑convolution of this
sequence can be evaluated analytically; its maximum occurs at the
central index k = n‑1 and equals

    max_k (a*a)_k = 4 (n+2) / (3 (n+1))  ≈ 4/3.

Thus the benchmark score
    2·n·max(a*a) / (Σ a)^2 = max(a*a)
is ≈ 1.333, well below the previous 1.5086.

The routine below builds this sequence for the problem size chosen from
the time budget (the same rule as the reference implementation) and
returns it as a plain list of floats.
"""

import time
import numpy as np

def propose_candidate(budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Build a linearly decreasing step function whose maximal self‑convolution
    is analytically minimal.  The returned sequence respects all constraints
    required by ``evaluate_sequence``.
    """
    start = time.time()

    # Choose problem size (same rule as the reference code)

    if budget_s >= 800:
