The evaluation metric is  

    score = 2 * n * max(conv(a, a)) / (sum(a)**2)

For a uniform vector the score is exactly 2.

size n, the discrete convolution peak is roughly (2/3)/n, giving

    score ≈ 2 * n * (2/3) / n = 4/3 ≈ 1.33 .

Thus a simple linearly increasing non‑negative sequence already
