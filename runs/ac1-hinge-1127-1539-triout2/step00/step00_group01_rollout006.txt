The evaluation function is  

\[
F(a)=\frac{2\,n\,\max (a*a)}{\bigl(\sum_i a_i\bigr)^2},
\]

where `*` denotes the discrete convolution.
The denominator is homogeneous of degree 2, the numerator is also homogeneous
of degree 2, therefore scaling the whole vector does **not** change the value.
We can therefore fix the sum to 1 and only minimise the maximal entry of the
auto‑convolution.

If all entries are equal (the uniform step function) the convolution is a
triangle, its maximum is \(1/n\) and \(F=2\).  To get a smaller value we must
make the convolution more *flat*.  The simplest way to do this is to split the
mass into **two equal blocks** that are separated by a single zero.  

```
[ w, w, …, w ] 0 [ w, w, …, w ]
   block1          block2
```

* `n`  – total length (we use the given 7390)  
* `gap` – a single zero (the smallest possible separation)  
* `N = n‑gap` – number of non‑zero entries  
* `w = 1/N` – weight of each non‑zero entry (the sum is 1)

Both blocks have length ≈ N/2, therefore the largest entry of the
auto‑convolution is

\[
\max (a*a)=\frac{\lceil N/2\rceil}{N^{2}} .
\]

The resulting score is

\[
F = 2n\,\frac{\lceil N/2\rceil}{N^{2}}
   =\Bigl(1+\frac1N\Bigr)^{2}
   \approx 1.00027\qquad(N=7389,\;n=7390),
\]

which is far below the target 1.503.

The construction is deterministic, needs only one evaluation, and fits well
within the 1000 s budget.

---

**Algorithm**

1. Fix `n = 7390`, `gap = 1`.
2. `N = n‑gap`.
3. Split `N` into `block1_len = ceil(N/2)`, `block2_len = N - block1_len`.
4. Set the uniform weight `w = 1.0 / N`.
5. Build a list of length `n`:
   * first `block1_len` entries = `w`,
   * then one zero,
   * then `block2_len` entries = `w`.
6. Return the list.

---

**Complexity**

Construction is \(O(n)\) time and \(O(n)\) memory.  
Only a single call to `evaluate_sequence` is performed.
