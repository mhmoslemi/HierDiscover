Thus local search: identify the index k where convolution is max. Then try to redistribute a mass from positions that contribute heavily to that max to positions that are less represented.

Approach:

- Compute convolution b = np.convolve(a, a).
- Determine max index(s) k_max = np.argmax(b).
- Compute gradient g_i = a_{k_max - i} + a_i (with zeros outside).
- To reduce M, we should decrease a_i for those i where gradient large (i.e., those that contribute strongly to peak), and increase other positions (perhaps where contributions to other peaks not max). But we must keep sum constant.

Thus we could propose to "flatten" a by moving mass from indices with high gradient to those with lower gradient (for example to the ends or middle). However to ensure nonnegativity.

def compute_objective(seq):
    n = len(seq)
    S = np.sum(seq)
    if S < 0.01:
        return np.inf
    m = 1 << ((2*n-1).bit_length())
    fft_seq = np.fft.rfft(seq, n=m)
    conv = np.fft.irfft(fft_seq * fft_seq, n=m)[:2*n-1]
    M = np.max(conv)
    return float(2 * n * M / (S ** 2))

"""
Propose a low‑score step‑function.

The evaluation score is  2·n·max(conv(a,a)) / (sum(a)²).  For a uniform
sequence the score is 2.  A classical construction uses the discrete analogue
of the kernel 1/√x, whose auto‑convolution is (almost) constant:
    a_i = 1 / sqrt(i + c)               (i = 0,…,n‑1)

For large n this gives a score ≈ π/2 ≈ 1.57, which is a substantial
improvement over the uniform bound 2.  The routine first scans a small
grid of the exponent β (around the optimal 0.5) and an additive offset c,
keeps the best candidate, and then performs a few cheap gradient‑descent
steps that try to lower the current maximal convolution value.
All work is stopped well before the provided time budget so that a valid
sequence is always returned.

The function returns a plain ``list[float]`` that respects the
non‑negative and clipping rules checked inside ``evaluate_sequence``.
"""

import time
import numpy as np


def _objective(seq: np.ndarray) -> float:
    """
    Fast version of the objective used during the search.
    It computes 2·n·max(conv(seq,seq)) / (sum(seq)²) using an FFT
    based full linear convolution.
    """
    n = len(seq)
    s = np.sum(seq)
    if s < 0.01:
        return np.inf

    # length of the FFT (next power of two for speed)
    m = 1 << ((2 * n - 1).bit_length())
    fft = np.fft.rfft(seq, n=m)
    conv = np.fft.irfft(fft * fft, n=m)[: 2 * n - 1]
    max_conv = np.max(conv)

    return float(2.0 * n * max_conv / (s * s))


def propose_candidate(seed: int = 42, budget_s: float = 1000, **kwargs):
    """
    Search for a sequence with a low evaluation score.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.  The function returns well before the
        budget expires.

    Returns
    -------
    list[float]
        The best sequence found.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 2.0   # keep a tiny safety margin

    # ------------------------------------------------------------------
    # 1. Choose a length.  5000 gives a good trade‑off between quality
    #    and speed (the final score does not depend strongly on n).
    # ------------------------------------------------------------------
    n = 5000
    print(f"[+] Starting search, length = {n}")

    # ------------------------------------------------------------------
    # 2. Grid search over exponent β (≈0.5) and additive offset c.
    #    a_i = 1 / (i + 1 + c)^β  ; i = 0,…,n‑1
    # ------------------------------------------------------------------
    best_seq = None
    best_score = np.inf

    betas = np.linspace(0.45, 0.55, 21)          # around the theoretical optimum 0.5
    offsets = np.linspace(0.0, 5.0, 11)          # a small shift improves the discrete case

    for beta in betas:
        for c in offsets:
            # build the candidate
            idx = np.arange(n, dtype=np.float64) + 1.0 + c
            cand = 1.0 / (idx ** beta)

            # fast objective
            score = _objective(cand)

            if score < best_score:
                best_score = score
                best_seq = cand.copy()
                print(
                    f"[grid] beta={beta:.3f}, offset={c:.2f} → score={score:.6f}"
                )

            if time.time() > deadline:
                break
        if time.time() > deadline:
            break

    # In the unlikely event that the grid failed (should never happen)
    if best_seq is None:
        best_seq = np.ones(n, dtype=np.float64)
        best_score = _objective(best_seq)

    # ------------------------------------------------------------------
    # 3. Simple gradient‑descent refinement.
    #    For the current maximal convolution index k_max we use the
    #    sub‑gradient g_i = a_i + a_{k_max-i} (zero when the second index
    #    is out of range).  A tiny step in the negative gradient direction
    #    reduces the maximal entry.
    # ------------------------------------------------------------------
    a = best_seq.copy()

    no_improve = 0

    while time.time() < deadline:

        grad = a + shift                     # g_i = a_i + a_{k_max-i}

        if s > 1e-12:

        else:
            # all zeros – abort this refinement loop
            break

        new_score = _objective(new_a)

            break

    return [float(x) for x in best_global_seq]
