assistantfinal**Solution Overview**

The aim is to minimise  

\[
F(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a*a` is the (linear) convolution of a non‑negative vector `a` with itself.  
Because the objective is *scale‑invariant* we may restrict ourselves to probability
vectors (`∑ a_i = 1`).  The problem then becomes

```
 minimise   max_k (a*a)_k
 subject to a_i ≥ 0 ,   Σ a_i = 1 .
```

A convenient way to obtain a descent direction is the linear programme  

```
 maximise   Σ g_i
 subject to (a * g)_k ≤ M          for all k               (1)
            g_i ≥ 0
```

where `M = max_k (a*a)_k`.  Any feasible `g` cannot increase the current
maximum convolution value, while a larger total mass `Σ g_i` gives a useful
direction.  After solving (1) we mix the new vector `g` with the current one
`a` :

\[
a(t) = (1-t)a + t\,g , \qquad 0\le t\le 1 .
\]

For a fixed `t` the convolution of `a(t)` with itself is a quadratic function
of `t`, therefore the new maximal value can be evaluated quickly for a few
candidate `t` and the best one is kept.

The algorithm repeatedly

1. evaluates the current maximum `M`,
2. solves the LP (1) with a *slightly tighter* bound `M·(1‑ε)`,
3. performs a line‑search in `t` and updates `a`,
4. records the best sequence seen so far,
5. occasionally perturbs the current vector or restarts from a fresh random
   point to avoid stagnation.

The whole search runs for the allotted time (≈ 1000 s) and finally returns the
best sequence it discovered.

The implementation uses only `numpy` and `scipy.optimize.linprog`.  
All helper functions are top‑level as required.

```python
"""
Proposes a step‑function (list of non‑negative heights) that tries to
minimise the evaluation function `evaluate_sequence`.

The method is a simple bound‑tightening loop:

* keep a probability vector `a` (its sum is 1 – scaling does not affect the score);
* compute M = max(conv(a, a));
* solve a linear programme that finds a non‑negative vector `g` with largest
  total mass while satisfying conv(a, g) ≤ M·(1‑ε);
* mix `a` and `g` with an optimal step length `t ∈ [0,1]` (grid search);
* repeat until the time budget expires, occasionally perturbing or restarting
  to escape local minima.

The best sequence found during the whole run is returned.
"""

import time
import random
import numpy as np
from scipy.optimize import linprog

# ----------------------------------------------------------------------
# Helper functions (no closures, no lambdas – top level as required)
# ----------------------------------------------------------------------


def convolution(vec1: np.ndarray, vec2: np.ndarray) -> np.ndarray:
    """Linear convolution of two 1‑D arrays."""
    return np.convolve(vec1, vec2)


def max_convolution(vec: np.ndarray) -> float:
    """Maximum value of the self‑convolution of `vec`."""
    return convolution(vec, vec).max()


def build_lp_matrix(f: np.ndarray) -> np.ndarray:
    """
    Build the matrix A for the constraints (f * g)_k ≤ bound.
    Row `k` contains the coefficients of the linear expression
        Σ_i f_i * g_{k‑i}
    (out‑of‑range indices are treated as zero).
    """
    n = f.shape[0]
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)

    # For each column i (i.e. variable g_i) the non‑zero rows are
    #   k = i, i+1, … , i+n‑1   with coefficient f[0…n‑1].
    for i in range(n):
        A[i : i + n, i] = f  # slice length is n
    return A


def solve_direction_lp(f: np.ndarray, bound: float, time_limit: float = 5.0):
    """
    Solve the LP that maximises Σ g_i under the constraints
        (f * g)_k ≤ bound   for all k,
        g_i ≥ 0.
    Returns a feasible vector g on success, otherwise None.
    """
    n = f.shape[0]
    A = build_lp_matrix(f)           # shape (2n‑1, n)
    rows = A.shape[0]

    # Inequalities:   A @ g ≤ bound
    # Add the non‑negativity constraints g_i ≥ 0  →  -I @ g ≤ 0
    A_ub = np.vstack([A, -np.eye(n)])
    b_ub = np.concatenate([np.full(rows, bound, dtype=np.float64),
                           np.zeros(n, dtype=np.float64)])

    # Objective: maximise Σ g_i  → minimise -Σ g_i
    c = -np.ones(n, dtype=np.float64)

    # Use HiGHS (default) – give a modest time limit to keep the outer loop fast.
    res = linprog(c, A_ub=A_ub, b_ub=b_ub,
                  method='highs',
                  options={'time_limit': time_limit, 'disp': False})

    if res.success:
        return np.maximum(res.x, 0.0)   # safety, numerical noise may produce tiny negatives
    return None


def optimal_mix_step(a: np.ndarray, g: np.ndarray,
                    conv_a: np.ndarray, conv_g: np.ndarray,
                    conv_ag: np.ndarray,
                    grid: np.ndarray) -> (float, np.ndarray):
    """
    For a fixed pair (a, g) evaluate the convex combination
        a(t) = (1‑t) a + t g
    on a small grid of t values and return the t that yields the smallest
    maximum convolution together with the corresponding mixed vector.
    """
    best_t = 0.0
    best_max = conv_a.max()   # at t = 0 we are at the current sequence
    best_vec = a.copy()

    # pre‑compute coefficients that appear in the quadratic expansion
    # B_k(t) = (1‑t)² A_k + 2t(1‑t) C_k + t² D_k
    A = conv_a
    C = conv_ag
    D = conv_g

    for t in grid:
        # quadratic combination (vectorised)
        combo = (1.0 - t) ** 2 * A + 2.0 * t * (1.0 - t) * C + t ** 2 * D
        m = combo.max()
        if m < best_max:
            best_max = m
            best_t = t
            best_vec = (1.0 - t) * a + t * g

    return best_t, best_vec


def perturb_vector(v: np.ndarray, scale: float = 1e-3) -> np.ndarray:
    """Add a small zero‑mean Gaussian perturbation and renormalise."""
    pert = v + np.random.randn(v.size) * scale
    pert = np.clip(pert, 0.0, None)
    s = pert.sum()
    if s <= 0.0:
        pert = np.abs(np.random.randn(v.size))
        s = pert.sum()
    return pert / s


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a good step‑function within the given time budget.
    Returns the best sequence (list of floats) found.
    """
    np.random.seed(seed)
    random.seed(seed)

    deadline = time.time() + budget_s - 0.5   # a little safety margin
    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Parameters (chosen experimentally for the time budget)
    # ------------------------------------------------------------------
    lengths = [800, 1200, 1800]          # modest sizes – LP stays cheap
    epsilon_start = 0.12                # initial tightening factor
    epsilon_decay = 0.94                # slowly relax the tightening
    grid_t = np.linspace(0.0, 1.0, 21)   # line‑search grid for mixing step
    max_no_improve = 250                # restart after this many idle iterations

    # ------------------------------------------------------------------
    # Main outer loop – try a few different lengths
    # ------------------------------------------------------------------
    for n in lengths:
        # random initial probability vector (Dirichlet‑like)
        a = np.random.rand(n)
        a = a / a.sum()

        # evaluate current sequence (scaling does not matter)
        try:
            cur_score = evaluate_sequence(a.tolist())
        except Exception:
            cur_score = float("inf")
        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[Init] n={n}, score={cur_score:.6f}")

        iter_no_improve = 0
        eps = epsilon_start
        iteration = 0

        while time.time() < deadline:
            iteration += 1

            # --------------------------------------------------------------
            # 1. current maximum of the self‑convolution
            # --------------------------------------------------------------
            conv_a = convolution(a, a)
            M = conv_a.max()
            idx_max = np.argmax(conv_a)   # not needed directly but handy for debugging

            # --------------------------------------------------------------
            # 2. solve LP for a promising direction (tighten the bound a little)
            # --------------------------------------------------------------
            bound = M * (1.0 - eps)
            g = solve_direction_lp(a, bound, time_limit=4.0)

            # If the LP fails (often because the bound is too tight) fall back
            # to a weaker bound; if it still fails we perform a random perturbation.
            if g is None:
                # try again with the original bound (no tightening)
                g = solve_direction_lp(a, M, time_limit=4.0)

            if g is None:
                # random perturbation – keep the search alive
                a = perturb_vector(a, scale=1e-2)
                iter_no_improve += 1
                continue

            # --------------------------------------------------------------
            # 3. normalise g (only a scaling, the convex combination will fix the
            #    actual bound later)
            # --------------------------------------------------------------
            g_sum = g.sum()
            if g_sum == 0.0:
                # degenerate solution – perturb and continue
                a = perturb_vector(a, scale=1e-2)
                continue
            g = g / g_sum

            # --------------------------------------------------------------
            # 4. compute the three convolutions needed for the line‑search
            # --------------------------------------------------------------
            conv_g = convolution(g, g)
            conv_ag = convolution(a, g)

            # --------------------------------------------------------------
            # 5. choose the mixing coefficient t that minimises the new max
            # --------------------------------------------------------------
            t_opt, a_new = optimal_mix_step(a, g,
                                            conv_a, conv_g, conv_ag,
                                            grid_t)

            # --------------------------------------------------------------
            # 6. evaluate and possibly accept the new vector
            # --------------------------------------------------------------
            try:
                new_score = evaluate_sequence(a_new.tolist())
            except Exception:
                # safety – reject this step
                new_score = float("inf")

            if new_score < best_score:
                best_score = new_score
                best_seq = a_new.copy()
                print(f"[Iter {iteration:04d}] n={n}, eps={eps:.4f}, t={t_opt:.3f}, "
                      f"score={new_score:.6f}")

            # accept the step if it does not increase the max‑convolution
            if new_score <= cur_score or new_score < cur_score * 1.001:
                a = a_new
                cur_score = new_score
                iter_no_improve = 0
            else:
                # no improvement – keep old vector but count stagnation
                iter_no_improve += 1

            # --------------------------------------------------------------
            # 7. adapt epsilon (tighten a bit more as we progress)
            # --------------------------------------------------------------
            eps = max(eps * epsilon_decay, 1e-4)

            # --------------------------------------------------------------
            # 8. occasional random perturbation to escape flats
            # --------------------------------------------------------------
            if iteration % 70 == 0:
                a = perturb_vector(a, scale=5e-3)

            # --------------------------------------------------------------
            # 9. restart if we are stuck for a long time
            # --------------------------------------------------------------
            if iter_no_improve >= max_no_improve:
                a = np.random.rand(n)
                a = a / a.sum()
                iter_no_improve = 0
                eps = epsilon_start
                print(f"[Restart] n={n} after {iteration} iterations")

            # --------------------------------------------------------------
            # safety check for the global deadline
            # --------------------------------------------------------------
            if time.time() >= deadline:
                break

    # ------------------------------------------------------------------
    # Return the best final sequence (as a list of plain floats)
    # ------------------------------------------------------------------
    if best_seq is None:
        # fallback – uniform sequence (guaranteed finite score)
        n_fallback = 800
        best_seq = np.full(n_fallback, 1.0 / n_fallback)

    return best_seq.tolist()
```

**Explanation of key ideas**

* **Scale invariance** – fixing the sum to one turns the problem into a pure
  minimisation of the maximal convolution value.
* **Linear programme for a descent direction** – constraints (1) are linear in the
  unknown vector `g`; maximizing its total mass provides a powerful direction that
  never raises the current maximum.
* **Convex combination & line‑search** – mixing the current vector with the LP
  solution reduces the maximal entry of the convolution; a cheap grid search in
  `t` is sufficient.
* **Adaptive tightening (`ε`)** – the bound used in the LP is gradually made
  tighter, forcing the algorithm to push the maximum down.
* **Random perturbations & restarts** – keep the search from getting stuck in
  plateaus.

The routine respects all competition constraints (single‑CPU, no file I/O,
no closures, print‑based progress) and will return a concrete height sequence
well within the allocated time.
