"""
propose_candidate – gradient‑based flattening of the autocorrelation.

The evaluation metric is 2·n·max(conv(a,a)) / (sum(a)**2).  Because the
objective is scale‑invariant we keep the ℓ₁‑norm of the candidate equal to
1.  For a uniform vector the value equals 2.  The aim is to make the
convolution a≈constant, i.e. to reduce the peak.  The algorithm performs a
projected gradient descent on a smooth approximation of the L∞‑norm:
    L(a) = log( Σ_k exp(β·(b_k – max(b))) )
with b = a∗a.  Its gradient can be written via a correlation,
    ∇L = 2·corr(w, a)   where   w_k ∝ exp(β·(b_k – max(b))).

We start from a shuffled version of the previous best sequence (if
available) or from a random Dirichlet vector, then repeatedly:
  * compute the convolution,
  * build the soft‑max weights w,
  * take a gradient step, project onto the non‑negative orthant and
    renormalise,
  * keep the best seen vector.

β is gradually increased (sharper focus on the true maximum) while the
step size η decays.  A small amount of random jitter is added now and
then to escape possible plateaus.  The routine stops after the allotted
time and returns the best sequence found.

def propose_candidate(seed: int = 0, budget_s: float = 1000, **kwargs):

    Returns
