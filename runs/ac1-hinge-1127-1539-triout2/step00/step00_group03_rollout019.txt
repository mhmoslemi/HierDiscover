The goal is to minimise  

\[
F(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2},
\]

where `a` is a non‑negative sequence, `n=len(a)` and `*` is the discrete convolution
(`np.convolve`).  
The value of `F` does **not** change if the whole sequence is multiplied by a
positive constant, therefore we can keep the `ℓ¹`‑norm of the sequence fixed.
A convenient normalisation is  

\[
\sum a_i = \sqrt{2n},
\]

because for the uniform sequence this gives `F = 2`.

--------------------------------------------------------------------

### 1.  Improving the bound with a linear program  

For a fixed sequence `f` (the current candidate) let  

```
M = max( f * f )
```

be its current peak.  
If we can find another non‑negative sequence `g` with a **larger** `ℓ¹`‑norm
but still satisfying  

```
f * g  ≤  M      (component‑wise)
```

then the denominator of `F` grows while the numerator does not, i.e. the
value of `F` strictly decreases.

The condition `f * g ≤ M` is linear in the unknown entries of `g`.  
Hence the following linear programme finds the best possible `g`:

```
maximise   sum(g_i)
subject to f * g ≤ M      (2n‑1 inequalities)
            g_i ≥ 0
```

The optimiser returns an extreme point – a sparse vector that puts a lot of
mass on indices where the convolution with `f` is small (usually the ends of
the array).  

After solving the LP we **renormalise** `g` so that it again has sum
`sqrt(2n)` and then move a fraction `t` towards it:

```
f ← (1‑t)·f + t·g            (0 < t ≤ 1)
```

The new sequence still has the same normalisation and its peak never grows.
Repeating the step reduces `F` monotonically.

--------------------------------------------------------------------

### 2.  Algorithmic details

* **Length** – the LP size grows with `n`.  Using `n ≈ 500` keeps the
  optimisation cheap while still allowing the value of `F` to drop far
  below the uniform bound `2.0`.  (The problem statement does **not**
  require a particular length.)

* **LP implementation** – `scipy.optimize.linprog` with the `highs`
  method works well.  The constraint matrix is sparse (`scipy.sparse.csr_matrix`)
  because each row contains at most `n` non‑zero entries.

* **Step size schedule** – a large step (`t = 0.4`) gives fast initial
  progress, then it is gradually reduced to `0.02` to fine‑tune the
  sequence.

* **Restarts** – the algorithm is started from both the uniform sequence
  (the known state‑of‑the‑art) and from a random sequence; the best result
  of the two runs is kept.

* **Time handling** – the total running time is limited to the supplied
  `budget_s` (default 1000 s).  The loop stops a few seconds before the
  deadline so that the function can return the best sequence found.

--------------------------------------------------------------------

```python
import time
import numpy as np
from scipy import optimize
from scipy.sparse import csr_matrix, vstack

linprog = optimize.linprog


def _build_convolution_matrix(f):
    """
    Build a sparse matrix A such that   A @ g = f * g   (full convolution).
    The matrix has (2*n-1) rows and n columns.
    """
    n = len(f)
    rows = []
    cols = []
    data = []
    for k in range(2 * n - 1):
        # i runs over all positions where f[i] participates in (f*g)[k]
        low = max(0, k - (n - 1))
        high = min(n - 1, k)
        for i in range(low, high + 1):
            j = k - i
            rows.append(k)
            cols.append(j)
            data.append(f[i])
    return csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))


def solve_convolution_lp(f, M, time_limit=5.0):
    """
    Solve  maximise sum(g)  s.t.  f * g ≤ M (component‑wise) , g ≥ 0 .
    Returns the optimiser g as a 1‑D NumPy array or None on failure.
    """
    n = len(f)
    # objective: maximise sum(g)  → minimise -sum(g)
    c = -np.ones(n)

    # inequality matrix  (sparse)
    A_ub = _build_convolution_matrix(f)

    # right‑hand side of the inequalities
    b_ub = np.full(2 * n - 1, M, dtype=float)

    # bounds for the variables: g_i ≥ 0
    bounds = [(0, None)] * n

    # use the HiGHS interior‑point method – fast and accepts sparse matrices
    res = linprog(
        c,
        A_ub=A_ub,
        b_ub=b_ub,
        bounds=bounds,
        method="highs",
        options={"time_limit": time_limit, "presolve": True},
    )
    if res.success:
        return np.maximum(res.x, 0.0)   # safety: clip tiny negatives
    return None


def lp_improvement_step(f, t):
    """
    One improvement step:
    * compute the current peak M,
    * solve the LP to obtain a better direction g,
    * renormalise g to the same ℓ¹‑norm as f,
    * move a fraction t towards g.
    Returns the new sequence (or the original f if the LP fails).
    """
    n = len(f)
    # current peak of the convolution
    conv = np.convolve(f, f)
    M = np.max(conv)

    g = solve_convolution_lp(f, M)
    if g is None:
        return f  # LP failed – keep the old sequence

    # renormalise g so that it has the same ℓ¹‑norm as f
    sum_f = np.sum(f)
    sum_g = np.sum(g)
    if sum_g == 0:
        return f
    g = g * (sum_f / sum_g)

    # convex combination
    new_f = (1.0 - t) * f + t * g
    # protect against numerical negativity
    new_f = np.maximum(new_f, 0.0)
    return new_f


def _initial_uniform(n):
    """Uniform sequence with ℓ¹‑norm = sqrt(2n)."""
    total = np.sqrt(2.0 * n)
    return np.full(n, total / n, dtype=float)


def propose_candidate(seed=42, budget_s=1000, **_):
    """
    Search for a step‑function (a non‑negative sequence) that minimises the
    supplied `evaluate_sequence` function.

    The routine performs a number of LP‑based improvement steps starting
    either from the known SOTA construction (`height_sequence_1`) or from a
    random initialisation.  The best sequence encountered before the time
    budget expires is returned.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 5.0   # a few seconds safety margin

    # ------------------------------------------------------------------
    # choose a manageable problem size
    # if a previous construction exists we keep its length,
    # otherwise we fall back to n = 500 (fast LPs)
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 500

    # ------------------------------------------------------------------
    # two starting points: uniform (SOTA) and a random one
    # ------------------------------------------------------------------
    starts = []

    uniform_seq = _initial_uniform(n)
    starts.append(uniform_seq)

    # random start: generate a random non‑negative vector and renormalise it
    rnd = np.random.rand(n)
    rnd = np.maximum(rnd, 0.0)
    rnd_sum = np.sum(rnd)
    if rnd_sum > 0:
        rnd = rnd * (np.sqrt(2.0 * n) / rnd_sum)
    else:
        rnd = uniform_seq.copy()
    starts.append(rnd)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # optimisation loop, shared for both starting points
    # ------------------------------------------------------------------
    for start in starts:
        f = start.copy()
        # small initial step size – will be adapted later
        step = 0.4
        # step‑size reduction schedule (geometric)
        step_decay = 0.97

        # evaluate the starting point
        try:
            cur_score = evaluate_sequence(f.tolist())
            if cur_score < best_score:
                best_score, best_seq = cur_score, f.copy()
        except Exception:
            cur_score = float("inf")

        while time.time() < deadline:
            # perform one LP based improvement
            f_new = lp_improvement_step(f, step)

            # evaluate the new candidate
            try:
                new_score = evaluate_sequence(f_new.tolist())
                if new_score < best_score:
                    best_score, best_seq = new_score, f_new.copy()
                # keep the improvement if it at least does not worsen the value
                if new_score <= cur_score:
                    f, cur_score = f_new, new_score
                else:
                    # occasional acceptance of a worse move (simulated annealing)
                    # temperature slowly decays with the step size
                    prob = np.exp(-(new_score - cur_score) / (step + 1e-12))
                    if np.random.rand() < prob:
                        f, cur_score = f_new, new_score
            except Exception:
                # if evaluation failed we simply keep the old sequence
                pass

            # gradually shrink the step size – this gives fine control later
            step = max(0.02, step * step_decay)

            # safety break if the step became tiny and no improvement occurs
            if step <= 0.02 and time.time() > deadline - 20:
                break

    # ------------------------------------------------------------------
    # final sanity check – guarantee that a sequence is returned
    # ------------------------------------------------------------------
    if best_seq is None:
        # fallback – the uniform construction (guarantees a finite score)
        best_seq = _initial_uniform(n)

    # Convert to plain Python list before returning
    return best_seq.tolist()
```
