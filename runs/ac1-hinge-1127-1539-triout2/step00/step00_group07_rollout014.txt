"""
Linear decreasing step function.

The convolution of a strictly decreasing sequence a_i = (n-i) (or any
positive multiple of it) has a maximal self‑convolution value

    max_k (a*a)_k = n (n+1)(n+2) / 6

while the ℓ1 norm is  S = n (n+1) / 2.
Plugging these expressions into the evaluation formula

    2·n·max_b / S² = 4·(n+2) / (3·(n+1))

yields a value that converges to 4/3 ≃ 1.333… for large n, i.e.
significantly better than the uniform construction (value 2.0) and below
the target 1.503.

The function below builds exactly this decreasing shape, scaled so that
all entries lie in the allowed interval [0, 1000] (the scale does not
affect the evaluation because the objective is homogeneous).  The
sequence length is taken from the provided `height_sequence_1` if
available; otherwise a default length of 2000 is used.
"""
