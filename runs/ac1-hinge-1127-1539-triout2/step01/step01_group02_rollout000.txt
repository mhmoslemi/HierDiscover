```
score = 2·n·max(conv(a,a)) / ( sum(a)² )
```

where `a = (a₀,…,aₙ₋₁)` is a non‑negative step‑function, `conv` is the full
convolution and `n` is the length of the list.
The score is *scale‑invariant* – multiplying all entries by a constant does
not change it – therefore we can freely normalise the vector to a probability
distribution (∑aᵢ = 1) during the optimisation.  
The remaining difficulty is the product of the length `n` with the maximal
convolution coefficient.
A good shape spreads the mass so that each offset receives roughly the same
amount of overlap; a slowly decaying tail is useful, but a very long tail only
increases `n` without helping the maximal overlap.

The algorithm consists of three parts

1. **Broad parametric sweep** – generate families of sequences
   (power‑law, exponential, stretched exponential), truncate them at several
   lengths and keep the best candidate.
2. **Refinement** – mirror‑descent updates (identical to the previous
   submission) that directly reduce the maximal convolution coefficient.
   After each update very small entries are *pruned* and the vector is
   renormalised, thus lowering `n` as the optimisation proceeds.
3. **Post‑processing** – after the time limit has been reached the tail of the
   best sequence is trimmed greedily while the score improves.

All steps respect the 1000 s wall‑clock budget and print progress information.
The code contains no closures, no lambda‑expressions and only uses the
standard library together with **NumPy**.

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-

"""
propose_candidate – search for a non‑negative step‑function that minimises
evaluate_sequence.

The algorithm consists of:
  1) a fast parametric sweep over three families (power‑law, exponential,
     stretched exponential) and several truncation lengths;
  2) a mirror‑descent style refinement that repeatedly decreases the maximal
     convolution coefficient, together with aggressive pruning of tiny
     entries (which reduces the length factor n);
  3) a final greedy tail‑pruning phase.

The function respects the 1000 s budget and returns the best sequence found.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions – all top‑level, no closures
# ----------------------------------------------------------------------


def evaluate(seq):
    """Safe wrapper around the provided evaluate_sequence."""
    try:
        score = evaluate_sequence(seq)   # noqa: F821 – provided by the environment
        if not np.isfinite(score):
            return float('inf')
        return float(score)
    except Exception:
        return float('inf')


def generate_powerlaw(p, sigma, max_len=3000, eps=1e-8):
    """a_i = (i + sigma)^(-p)  (i = 0,…). Truncated when below eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = (i + sigma) ** (-p)
    mask = a > eps
    return a[mask]


def generate_exponential(lam, max_len=3000, eps=1e-8):
    """a_i = exp(-lam * i). Truncated when below eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = np.exp(-lam * i)
    mask = a > eps
    return a[mask]


def generate_stretched_exp(lam, q, max_len=3000, eps=1e-8):
    """a_i = exp(-lam * i**q). Truncated when below eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = np.exp(-lam * (i ** q))
    mask = a > eps
    return a[mask]


def mirror_descent_step(x, eta):
    """
    One mirror‑descent step.
    x – probability vector (sum = 1, non‑negative)
    Returns the updated probability vector.
    """
    n = x.shape[0]
    conv = np.convolve(x, x)               # length 2n‑1
    k = int(conv.argmax())                  # index of maximal entry
    # Build sub‑gradient g_i = x_{k-i} on the overlapping interval
    g = np.zeros_like(x)
    i_min = max(0, k - (n - 1))
    i_max = min(k, n - 1)
    idx = np.arange(i_min, i_max + 1)
    jdx = k - idx
    g[idx] = x[jdx]                         # factor 2 omitted (absorbed in η)
    # Multiplicative update + projection onto simplex
    y = x * np.exp(-eta * g)
    if y.sum() == 0.0:                      # pathological case – re‑randomise
        y = np.abs(np.random.randn(n))
    y = y / y.sum()
    return y


def prune_small_entries(x, thresh=1e-4):
    """
    Remove entries smaller than thresh, renormalise to sum‑1.
    Returns the pruned vector (may be unchanged).
    """
    mask = x >= thresh
    if mask.all():
        return x
    if mask.sum() == 0:
        # All entries tiny – keep the largest one to avoid empty vector
        idx = np.argmax(x)
        x = np.zeros_like(x)
        x[idx] = 1.0
        return x
    x = x[mask]
    x = x / x.sum()
    return x


def greedy_tail_prune(seq, current_best):
    """
    Remove trailing elements while the score improves.
    Returns the possibly shortened list and its score.
    """
    arr = np.array(seq, dtype=np.float64)
    best_seq = arr.copy()
    best_score = current_best
    # Try to drop the last element repeatedly
    while arr.shape[0] > 2:
        candidate = arr[:-1]                     # drop tail
        cand_score = evaluate(candidate.tolist())
        if cand_score < best_score:
            best_score = cand_score
            best_seq = candidate
            arr = candidate
            # print progress inside the post‑processing loop
            print(f'greedy prune: new length {len(arr)} score {best_score:.6f}')
        else:
            break
    # Also try to drop leading elements (symmetrically)
    arr = best_seq
    while arr.shape[0] > 2:
        candidate = arr[1:]                      # drop head
        cand_score = evaluate(candidate.tolist())
        if cand_score < best_score:
            best_score = cand_score
            best_seq = candidate
            arr = candidate
            print(f'greedy prune head: new length {len(arr)} score {best_score:.6f}')
        else:
            break
    return best_seq.tolist(), best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Search for a step‑function (list of heights) with minimal
    evaluate_sequence score.  The routine respects the 1000 s time limit and
    returns the best sequence found.
    """
    rng = np.random.default_rng(seed)
    deadline = time.time() + budget_s - 5.0   # safety margin

    best_score = float('inf')
    best_seq = None

    # ------------------------------------------------------------------
    # Phase 1 – broad parametric sweep
    # ------------------------------------------------------------------
    max_len_global = 2500          # upper bound for generated sequences
    length_grid = [200, 400, 800, 1200, 1800, 2500]

    print('=== Phase 1 : parametric sweep ===')

    # --------- Power‑law family ----------
    p_vals = np.linspace(0.30, 0.80, 11)          # 0.30 … 0.80
    sigma_vals = np.logspace(-4, 0, 20)          # 1e‑4 … 1
    for p in p_vals:
        for sigma in sigma_vals:
            if time.time() >= deadline:
                break
            raw = generate_powerlaw(p, sigma, max_len=max_len_global)
            if raw.size == 0:
                continue
            for L in length_grid:
                if L > raw.size:
                    continue
                seq = raw[:L]
                score = evaluate(seq.tolist())
                if score < best_score:
                    best_score = score
                    best_seq = seq.tolist()
                    print(f'new best PL p={p:.3f} sigma={sigma:.5g} len={L} '
                          f'score={best_score:.6f}')
                if best_score < 1.503:
                    break
            if best_score < 1.503:
                break
        if best_score < 1.503:
            break

    # --------- Exponential family ----------
    if best_score > 1.503 and time.time() < deadline:
        lam_vals = np.logspace(-4, -0.1, 15)      # λ from 1e‑4 to ~0.8
        for lam in lam_vals:
            if time.time() >= deadline:
                break
            raw = generate_exponential(lam, max_len=max_len_global)
            if raw.size == 0:
                continue
            for L in length_grid:
                if L > raw.size:
                    continue
                seq = raw[:L]
                score = evaluate(seq.tolist())
                if score < best_score:
                    best_score = score
                    best_seq = seq.tolist()
                    print(f'new best EXP lambda={lam:.5g} len={L} '
                          f'score={best_score:.6f}')
                if best_score < 1.503:
                    break
            if best_score < 1.503:
                break

    # --------- Stretched exponential family ----------
    if best_score > 1.503 and time.time() < deadline:
        lam_vals = np.logspace(-4, -0.1, 10)      # λ
        q_vals = np.linspace(0.5, 2.0, 7)         # stretch exponent
        for lam in lam_vals:
            for q in q_vals:
                if time.time() >= deadline:
                    break
                raw = generate_stretched_exp(lam, q,
                                             max_len=max_len_global)
                if raw.size == 0:
                    continue
                for L in length_grid:
                    if L > raw.size:
                        continue
                    seq = raw[:L]
                    score = evaluate(seq.tolist())
                    if score < best_score:
                        best_score = score
                        best_seq = seq.tolist()
                        print(f'new best STEXP λ={lam:.5g} q={q:.2f} len={L} '
                              f'score={best_score:.6f}')
                    if best_score < 1.503:
                        break
                if best_score < 1.503:
                    break
            if best_score < 1.503:
                break

    # If nothing was found (unlikely) fall back to a uniform vector
    if best_seq is None:
        n_fallback = 500
        best_seq = [1.0] * n_fallback
        best_score = evaluate(best_seq)
        print('fallback uniform, score =', best_score)

    # ------------------------------------------------------------------
    # Phase 2 – mirror‑descent refinement with pruning
    # ------------------------------------------------------------------
    print('=== Phase 2 : mirror‑descent refinement ===')
    x = np.array(best_seq, dtype=np.float64)
    # Normalise to probability simplex – scale does not matter for the score
    if x.sum() == 0.0:
        x = np.abs(np.random.randn(x.shape[0]))
    x = x / x.sum()

    iteration = 0
    while time.time() < deadline:
        iteration += 1
        eta = 0.18 / np.sqrt(iteration)          # decreasing step size
        x = mirror_descent_step(x, eta)

        # Aggressive pruning of tiny entries (helps lower n)
        if iteration % 30 == 0:                  # prune every few iterations
            x = prune_small_entries(x, thresh=1e-4)

        # Small random jitter to escape plateaus
        if rng.random() < 0.02:
            i, j = rng.integers(0, x.shape[0], size=2)
            delta = (rng.random() - 0.5) * 0.02 * x[i]
            x[i] = max(0.0, x[i] + delta)
            x[j] = max(0.0, x[j] - delta)
            # re‑normalise
            if x.sum() == 0.0:
                x = np.abs(np.random.randn(x.shape[0]))
            x = x / x.sum()

        cur_score = evaluate(x.tolist())
        if cur_score < best_score:
            best_score = cur_score
            best_seq = x.tolist()
            print(f'iteration {iteration:5d} -> improved score = {best_score:.6f} '
                  f'len={len(best_seq)}')
            if best_score < 1.503:
                print('Target reached – stopping early.')
                break

    # ------------------------------------------------------------------
    # Phase 3 – final greedy tail pruning (optional, cheap)
    # ------------------------------------------------------------------
    print('=== Phase 3 : greedy tail pruning ===')
    if time.time() < deadline and best_seq is not None:
        pruned_seq, pruned_score = greedy_tail_prune(best_seq, best_score)
        if pruned_score < best_score:
            best_score = pruned_score
            best_seq = pruned_seq
            print('post‑processing improved score to', best_score)

    print('final best score:', best_score, 'length:', len(best_seq))
    return best_seq
```
