the normalising constant C = 1000 keeps a₀ = 1000.
An elementary continuous‑approximation shows that

    max(a∗a) ≈  (p+1)²·B(p+1,p+1) / n   · (sum(a)²)

where B is the Beta‑function.
Hence the external score tends to

    score(p) = 2·(p+1)²·B(p+1,p+1)

which rapidly decreases with the exponent p.
Choosing p = 5 already yields a score ≈ 0.026, well below the target
1.503, while remaining numerically stable for n of a few thousand.

The implementation below builds such a power‑law decreasing sequence,
prints the achieved score and returns the list of heights.
No optimisation loop is required, therefore the whole routine finishes
far within the 1000 s limit.
"""

# ----------------------------------------------------------------------
# Helper – power‑law decreasing sequence
# ----------------------------------------------------------------------


def _power_sequence(n: int, exponent: int) -> list[float]:
    """
    Return a sequence a_i = 1000 * ((n-i)/n)**exponent,
    i = 0 … n-1.
    All entries are non‑negative and the first entry equals 1000.
    """
    # values (n‑i)/n go from 1 down to 1/n
    ratios = np.arange(n, 0, -1, dtype=np.float64) / n
    seq = 1000.0 * np.power(ratios, exponent)
    # Convert to plain Python floats (evaluate_sequence expects a list)
    return seq.tolist()
