"""
Multi‑start exponentiated gradient descent with momentum for the
max‑convolution objective.

The algorithm:
  * pick a length n and an initial non‑negative vector a (random Dirichlet or
    a truncation of the known construction);
  * normalise a so that Σ a = √(2 n) – this makes the external score equal to
    the maximal entry of the self‑convolution.
  * repeatedly
        – compute the full linear self‑convolution with an FFT;
        – take the K (default 3) largest convolution entries;
        – build a sub‑gradient  g_j = Σ_k 2·a_{k−j} over those K shifts;
        – update a by an exponentiated (multiplicative) step with momentum;
        – re‑normalise to keep the L1‑norm fixed;
        – occasionally add a small random jitter.
  * the surrogate max‑convolution is monitored; when it improves we call the
    expensive ``evaluate_sequence`` and keep the best overall vector.
The outer driver runs many independent restarts (different lengths, seeds)
until the time budget (≈ 1000 s) is exhausted.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions
# ----------------------------------------------------------------------


def _conv_max(a: np.ndarray) -> tuple[np.ndarray, float, int]:
    """
    Compute the linear self‑convolution a*a using FFT.
    Returns the full convolution array, its maximal value and the index of that maximum.
    """
    n = a.shape[0]

    Fa = np.fft.rfft(a, n=fft_len)

    max_idx = int(np.argmax(conv))

The algorithm:

    or a truncation of the known construction);

    the maximal entry of the self‑convolution.
