propose_candidate

Search for a low‑evaluation step‑function using a simple power‑law family.

The algorithm works in three phases:
1. **Coarse grid search** on a short sequence (n≈5 000).  For each pair
   (p, γ) we build the vector
        a_i = ((i+γ+1)^p - (i+γ)^p) / ((n+γ)^p - γ^p)
   (which is the normalised difference of a power law) and evaluate it.
   The best (p, γ) are kept.

2. **Local random refinement** of the parameters on the same short sequence.
   Small Gaussian steps are tried; improvements are accepted immediately.

3. **Construction of a large sequence** (by default n=200 000) with the
   discovered parameters.  One final call to `evaluate_sequence` is made
   to report the score.  If the large sequence would be slower than the
   remaining time budget, its length is reduced accordingly.

All numbers are non‑negative, the L¹‑norm is normalised to 1 (scaling
does not affect the evaluation), and the returned object is a plain
Python list of floats as required by the competition harness.
"""

import time
import numpy as np

def _generate_sequence(n: int, p: float, gamma: float) -> np.ndarray:
    """
    Produce a normalised non‑negative sequence of length `n`
    from the power‑law difference formula.
    """
    i = np.arange(n, dtype=np.float64)
    # power‑law differences
    a = np.power(i + gamma + 1.0, p) - np.power(i + gamma, p)
    denom = np.power(n + gamma, p) - np.power(gamma, p)
    # safety division (denom > 0 for p>0)
    if denom == 0:
        return np.zeros_like(a)
    a /= denom
    return a
