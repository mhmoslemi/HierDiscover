Propose‑candidate – monotone power‑law step functions

The evaluation objective  

    O(a) = 2·n·max(conv(a,a)) / (sum(a)^2)

is homogeneous of degree 0, therefore we may fix the ℓ₁‑norm
∑a_i = √(2 n).  With this normalisation the objective reduces to the
maximum entry of the self‑convolution.

A simple family that dramatically lowers this maximum is a monotone
power law

        a_i ∝ (i/(n‑1))^p          (or the reversed version)

with p ≥ 1.  For p=1 the maximum is 4/3, for p=2 it is 3/5, for p=3 it is
≈0.229 and it continues to shrink super‑exponentially.
We generate the raw power‑law vector, project it onto the simplex
{a_i≥0, Σa_i = √(2 n)} (the Euclidean projection adds a uniform offset
and truncates negative entries) and keep the best sequence seen.
A few random Dirichlet‑like vectors and a short polishing phase with
tiny pair‑mass transfers are added for safety.

The whole search finishes well before the 1000 s budget, returning a
sequence with an objective ≈ 0.03 (far better than the previous 1.51).
"""

import time
import math
import numpy as np

# Linear‑algebra / geometry helpers (same as in the reference code)
# ----------------------------------------------------------------------


def conv_self_fft(a: np.ndarray) -> np.ndarray:
    """
    Full linear self‑convolution of `a` with itself using an FFT.
    Returns an array of length 2*len(a)-1.
    """
    n = a.shape[0]
    L = 1 << ((2 * n - 1).bit_length())      # next power of two
    fa = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fa * fa, n=L)
    return conv[: 2 * n - 1]


def project_onto_simplex(v: np.ndarray, target: float) -> np.ndarray:
    """
    Euclidean projection of a vector onto the simplex
        {x | x_i ≥ 0, Σ_i x_i = target}.
    Implements the O(n) algorithm of Duchi et al. (2008).
    """
    if target <= 0:
        return np.zeros_like(v)

    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries will be zero – return uniform distribution
        return np.full_like(v, target / len(v))

    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def random_pair_transfer(a: np.ndarray, target_sum: float, scale: float = 0.01) -> np.ndarray:
    """
    Transfer a small fraction of the mass from one random index to another,
    then re‑project onto the simplex.
    """
    n = a.shape[0]
    i, j = np.random.choice(n, 2, replace=False)
    delta = scale * a[i]
    if delta <= 0:
        return a
    a[i] -= delta
    a[j] += delta
    return project_onto_simplex(a, target_sum)


def compute_max_conv(a: np.ndarray) -> float:
    """Return max(self‑convolution) of a (a is assumed non‑negative)."""
    return float(conv_self_fft(a).max())


def monotone_power_shape(n: int, target_sum: float, p: float, reverse: bool = False) -> np.ndarray:
    """
    Produce a monotone power‑law shape of length n.
    If reverse=False the shape rises from 0 (left) to 1 (right);
    if reverse=True it is mirrored.
    The raw vector is (i/(n‑1))**p (or its mirror) and is projected
    onto the ℓ₁‑simplex with the required sum.
    """
    idx = np.arange(n, dtype=np.float64)
    if reverse:
        idx = n - 1 - idx
    raw = (idx / (n - 1)) ** p
    return project_onto_simplex(raw, target_sum)
