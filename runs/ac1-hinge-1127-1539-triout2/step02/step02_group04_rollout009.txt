Smoothed‑max (soft‑max) gradient descent for the step‑function problem.

The objective `evaluate_sequence` equals `2·n·max(conv)` once the
sequence is normalised to unit ℓ¹‑norm.  We minimise an
smooth approximation of `max(conv)` (a soft‑max) whose gradient can be
computed analytically:

    d/da_i  L = Σ_k w_k ∂conv_k/∂a_i,
    where w_k ∝ exp(β(conv_k/max(conv)−1)).

Because ∂conv_k/∂a_i = 2·a_{k−i} when the index is inside the support,
the gradient reduces to a cross‑correlation of the weight vector with
the current sequence.  All convolutions and correlations are evaluated
with FFTs for O(n log n) cost.

The optimisation proceeds as follows:

1. A fast parametric sweep (power‑law / exponential families) produces a
   good starting vector.
2. From the best candidate we run an Adam‑type optimiser on the smooth
   objective, projecting onto the probability simplex after each step.
   β is slowly increased so that the optimisation first sees a smooth
   landscape and later concentrates on the true maximum.
3. Occasionally a tiny random jitter or a full restart is performed to
   escape plateaus.

During the run the exact `evaluate_sequence` value is computed only when
the cheap surrogate (`2·n·max(conv)`) improves; this keeps the wall‑clock
well within the 1000 s budget.  The best sequence found is returned.
"""

def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("simplex projection only works on 1‑D arrays")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if len(rho) == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _evaluate(seq: np.ndarray) -> float:
    """Thin wrapper around the provided evaluate_sequence (list‑oriented)."""
    try:
        return evaluate_sequence(seq.tolist())
    except Exception:
        return float('inf')


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_fft(x: np.ndarray) -> np.ndarray:
    """Autoconvolution of x using FFT (real‑valued, length 2·n‑1)."""
    n = x.shape[0]
    L = _next_pow2(2 * n - 1)
    X = np.fft.rfft(x, L)
    conv = np.fft.irfft(X * X, L)[: 2 * n - 1]
    return conv


def _cross_corr_from_weights(w: np.ndarray, x: np.ndarray) -> np.ndarray:
    """
    Compute   g_i = 2 * Σ_j w_{i+j} * x_j   for i=0,…,n‑1.

    This is a valid cross‑correlation; it is evaluated with FFTs.
    """
    n = x.shape[0]
    L = _next_pow2(len(w) + n - 1)
    # reverse x to turn correlation into a convolution
    xr = x[::-1]
    W = np.fft.rfft(w, L)
    Xr = np.fft.rfft(xr, L)
    full = np.fft.irfft(W * Xr, L)[: len(w) + n - 1]
    start = n - 1
    grad = 2.0 * full[start : start + n]
    return grad


def _smooth_max_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """
    Produce a soft‑max weight vector concentrating on the maximal entries
    of `conv`.  The maximal entry receives weight 1 (after normalisation)
    and all others receive exp(beta*(conv/M−1)).
    """
    M = conv.max()
    if M <= 0.0:
        return np.ones_like(conv) / conv.size
    # scale by the current maximum to keep the exponent numerically stable
    w = np.exp(beta * (conv / M - 1.0))
    w /= w.sum()
    return w


def _gradient_softmax_max(x: np.ndarray, beta: float) -> np.ndarray:
    """Gradient of the smooth max (soft‑max) of the auto‑convolution."""
    conv = _conv_fft(x)
    w = _smooth_max_weights(conv, beta)
    grad = _cross_corr_from_weights(w, x)
    return grad, conv.max()


def _generate_powerlaw(p: float, sigma: float,
                       max_len: int = 5000, eps: float = 1e-10) -> np.ndarray:
    """a_i = (i + sigma) ** (-p)   truncated when a_i < eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = (i + sigma) ** (-p)
    return a[a > eps]


def _generate_exponential(lam: float,
                          max_len: int = 5000, eps: float = 1e-10) -> np.ndarray:
    """a_i = exp(-lam * i)   truncated when a_i < eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = np.exp(-lam * i)
    return a[a > eps]


def _generate_mixed(p: float, sigma: float, lam: float,
                    max_len: int = 5000, eps: float = 1e-10) -> np.ndarray:
    """a_i = (i+sigma)^(-p) * exp(-lam*i)   truncated when a_i < eps."""
    i = np.arange(max_len, dtype=np.float64)
    a = (i + sigma) ** (-p) * np.exp(-lam * i)
    return a[a > eps]

            no_improve_cnt = 0
            print(f'iteration {t_iter:6d} – restart triggered')

    print('final best score:', best_score, 'length:', len(best_seq))

"""
Smoothed‑max (soft‑max) gradient descent for the step‑function problem.

The objective `evaluate_sequence` simplifies, after normalising the
sequence to ℓ¹‑norm = 1, to

    F(x) = 2·n·max_k (x * x)_k ,

where `*` denotes discrete convolution and `n` is the length of `x`.
We therefore minimise a smooth approximation of the inner maximum:

    Lβ(x) = (1/β)·log Σ_k exp(β·(conv_k / max(conv) – 1))

which concentrates all weight on the current maximal entries.
The gradient of `Lβ` can be written in closed form because

    ∂conv_k/∂x_i = 2·x_{k‑i}      (indices outside the support give 0).

Hence

    ∇Lβ(x) = 2·corr( w , x ) ,

with `w` the soft‑max weight vector and `corr` a valid cross‑correlation.
All convolutions and correlations are evaluated with FFTs (O(n·log n)).

Algorithm
---------
1. **Light parametric sweep** – a few power‑law, exponential and mixed
   families are sampled, each candidate is normalised and evaluated.
   The best candidate is kept as a start point.
2. **Adam optimisation on the smooth objective** – starting from the best

   onto the probability simplex.  The concentration parameter `β` is

                best_seq = cand.tolist()
                print(f'new best EXP λ={lam:.5e} len={len(cand)} score={best_score:.6f}')

    # mixed family (a few hand‑picked triples)
    for p, sigma, lam in [(0.48, 1e-2, 5e-3),
                          (0.52, 5e-2, 1e-3),
                          (0.50, 1e-1, 2e-3)]:
        if time.time() >= deadline:
            break
        seq = _generate_mixed(p, sigma, lam, max_len, eps)
        if seq.size < 2:
            continue
        cand = seq / seq.sum()
        approx = 2 * cand.size * _conv_fft(cand).max()
        if approx < best_score:
            exact = _evaluate(cand)
            if exact < best_score:
                best_score = exact
                best_seq = cand.tolist()
                print(f'new best MIX p={p:.2f} σ={sigma:.5g} λ={lam:.5g} len={len(cand)} score={best_score:.6f}')

    # ------------------------------------------------------------------
    # 2.  Fallback to a uniform vector if nothing was found.
    # ------------------------------------------------------------------
    if best_seq is None:
        n0 = 3000
        best_seq = np.full(n0, 1.0 / n0)
        best_score = _evaluate(best_seq)
        print('fallback to uniform sequence, score =', best_score)

    # ------------------------------------------------------------------
    # 3.  Smoothed‑max Adam optimisation.
    # ------------------------------------------------------------------
    x = np.array(best_seq, dtype=np.float64)
    x = x / x.sum()                       # enforce simplex

    # Adam hyper‑parameters
    lr = 0.2
    beta1 = 0.9
    beta2 = 0.999
    eps_opt = 1e-8

    m = np.zeros_like(x)
    v = np.zeros_like(x)
    t_iter = 0

    # schedule for the soft‑max concentration β
    beta_start = 5.0
    beta_end = 30.0
    beta_ramp_iters = 3000

    # early‑stop monitoring
    best_approx = 2 * len(x) * _conv_fft(x).max()
    no_improve_cnt = 0
    max_no_improve = 2000

    print('=== Phase 2 – smoothed‑max Adam optimisation ===')
    while time.time() < deadline:
        t_iter += 1
        beta_cur = beta_start + (beta_end - beta_start) * min(1.0,
                                                             t_iter / beta_ramp_iters)

        # gradient of the smooth approximation
        grad, cur_max = _gradient_softmax_max(x, beta_cur)

        # Adam step
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * (grad ** 2)
        m_hat = m / (1 - beta1 ** t_iter)
        v_hat = v / (1 - beta2 ** t_iter)
        y = x - lr * m_hat / (np.sqrt(v_hat) + eps_opt)

        # projection back onto the simplex
        x = _simplex_projection(y)

        # occasional random jitter to help escape tiny plateaus
        if np.random.rand() < 0.01:
            idx = np.random.randint(x.shape[0])
            delta = (np.random.rand() - 0.5) * 0.2 * x[idx]
            x[idx] = max(0.0, x[idx] + delta)
            x = x / x.sum()

        # cheap surrogate objective (exact up to rounding)
        approx_score = 2 * len(x) * cur_max

        # evaluate with the true function only when the surrogate improves
        if approx_score + 1e-6 < best_approx:
            exact = _evaluate(x)
            if exact < best_score:
                best_score = exact
                best_seq = x.tolist()
                print(f'iteration {t_iter:6d} → new best exact = {best_score:.6f}')
                if best_score < 1.503:
                    print('Target bound reached – terminating early.')
                    break
            best_approx = approx_score
            no_improve_cnt = 0
        else:
            no_improve_cnt += 1

        # restart if we have stagnated for a while
        if no_improve_cnt >= max_no_improve:
            n = x.shape[0]
            rand_vec = np.random.rand(n)
            rand_vec /= rand_vec.sum()
            x = 0.6 * x + 0.4 * rand_vec
            x = _simplex_projection(x)
            m.fill(0.0)
            v.fill(0.0)
            no_improve_cnt = 0
            print(f'iteration {t_iter:6d} – restart triggered')

    print('final best score:', best_score, 'length:', len(best_seq))
    return best_seq
