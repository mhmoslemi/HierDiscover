   supplied `height_sequence_1` if it exists, otherwise a default of 6000.

   and (when available) the previous best construction are tried and the
   best one is kept as a start point.

3. **Adam optimisation on a smooth‑max surrogate** – the true `max`
   is approximated by a temperature‑controlled soft‑max (`γ`).  The gradient
   of this surrogate is computed via FFTs and an Adam update is applied.
   After each step the vector is projected onto the probability simplex
   (non‑negative, fixed L1).

4. **Plateau shaking** – if no improvement is seen for many iterations the
   current iterate is perturbed with a small random jitter to escape flat
   regions.

5. **Fine‑tuning** – a short phase with a very large temperature (almost the
   true `max`) and a tiny constant step size further polishes the solution.

6. **Simple hill‑climbing** – a final short stochastic local‑search that moves
   a small amount of mass between two random positions and accepts the move
   iff it improves the score.

All heavy work (convolutions, gradients) is done with NumPy FFTs for speed.
The routine respects the 1000 s budget and returns the best sequence found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level – no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _compute_score(a: np.ndarray, target_sum: float) -> float:
    """
    Fast evaluation of the metric when `sum(a) == target_sum`.
    The score then equals the maximal entry of the linear convolution.
    """
    n = a.shape[0]
    nfft = _next_pow2(2 * n - 1)
    af = np.fft.rfft(a, n=nfft)
    conv = np.fft.irfft(af * af, n=nfft)[: 2 * n - 1]
    return float(conv.max())


def project_onto_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of *v* onto the simplex
        { x : x_i ≥ 0 , sum_i x_i = target_sum }.
    """
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w

# ----------------------------------------------------------------------

        conv_new = np.fft.irfft(af_new * af_new, n=nfft_conv)[: 2 * n - 1]
        score_new = float(conv_new.max())
        if score_new < best_score:
            best_score = score_new
            best_a = a.copy()
            elapsed = time.time() - start_time
            print(f"Fine‑tune: new best {best_score:.6f} (elapsed {elapsed:.1f}s)")

    # ------------------------------------------------------------------
    # 8. Simple stochastic hill‑climbing (local search)
    # ------------------------------------------------------------------
    hill_iters = 5000
    for _ in range(hill_iters):
        if time.time() >= deadline:
            break
        i, j = np.random.randint(0, n, size=2)
        if i == j:
            continue
        delta = 0.01 * a[i]                     # move 1 % of source mass
        if delta <= 0.0:
            continue
        a_candidate = a.copy()
        a_candidate[i] -= delta
        a_candidate[j] += delta                # sum unchanged, non‑negativity kept
        # evaluate
        af_cand = np.fft.rfft(a_candidate, n=nfft_conv)
        conv_cand = np.fft.irfft(af_cand * af_cand, n=nfft_conv)[: 2 * n - 1]
        score_cand = float(conv_cand.max())
        if score_cand < best_score:
            best_score = score_cand
            best_a = a_candidate.copy()
            a = a_candidate
            elapsed = time.time() - start_time
            print(f"Hill‑climb: new best {best_score:.6f} (elapsed {elapsed:.1f}s)")

    elapsed = time.time() - start_time
    print(f"Finished in {elapsed:.1f}s – best score {best_score:.6f}")

    # ------------------------------------------------------------------
    # 9. Return the best sequence discovered
    # ------------------------------------------------------------------
    return best_a.tolist()
