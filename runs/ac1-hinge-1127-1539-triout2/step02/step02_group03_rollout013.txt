The evaluation function  

```
score = 2·n·max(conv(a,a)) / (∑a)²
```  

is *scale invariant*.  If we keep the ℓ₁–norm fixed to  

```
∑ a_i = √(2·n)          (1)
```  

the factor `2·n/(∑a)²` becomes 1 and the score is exactly the maximal
convolution entry `max_b`.  Consequently the optimisation problem is

```
minimise   max_k (a * a)_k
subject to a_i ≥ 0 ,  ∑ a_i = √(2·n)                (2)
```

The algorithm below works directly on (2).  It uses a **smooth
approximation of the max‑operator** (soft‑max) and performs **projected
gradient descent** on the resulting loss.  The projection is the Euclidean
projection onto the simplex (1).  A small amount of simulated‑annealing
mass‑swaps and occasional Gaussian jitter are added to escape local
minima.

Key ideas
---------

* **Soft‑max loss**  
  `L_τ(a) = τ·log Σ_k exp( (a*a)_k / τ )`.  
  `∇_a L_τ` can be written as a cross‑correlation of the current vector
  with the soft‑max weights.  The gradient is cheap to obtain with a pair
  of FFTs.

* **Projected additive update**  
  `a ← Π_S( a – η·∇L_τ )` where `Π_S` is the projection onto (1).  The
  additive step (instead of the multiplicative update used before) is
  able to move mass more precisely and often yields a lower peak.

* **Continuation on τ** – start with a large temperature (the current
  maximal convolution entry) and decrease it slowly; the optimisation
  initially sees a smooth landscape and later focusses on the true max.

* **Random mass swaps** (probability `move_prob`) with a simulated‑annealing
  acceptance rule provide additional exploration.

* **Jitter** – occasional tiny Gaussian perturbations help to avoid
  stagnation.

The search runs many independent short restarts (different random seeds,
different sequence lengths).  The best sequence found over all restarts is
returned.  The whole routine respects the 1000 s time budget.

```python
"""
Fast projected gradient descent on a soft‑max approximation of the
∞‑norm of the self‑convolution.

The algorithm minimises the maximal entry of a*a while keeping
the vector non‑negative and ℓ₁‑norm equal to √(2·n).  It mixes:
 • additive projected gradient steps on the smooth loss τ·log Σ exp(b/τ)
 • occasional simulated‑annealing mass‑swaps
 • rare Gaussian jitter.
All operations are performed with FFTs (O(n log n)) and the code
returns the best sequence discovered before the time budget expires.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Projection onto the simplex {x ≥ 0, sum(x)=S}
# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, S: float) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, sum(x)=S}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]                     # descending order
    cssv = np.cumsum(u) - S
    rho_arr = np.arange(1, n + 1)
    cond = u - cssv / rho_arr > 0
    if not np.any(cond):
        # all entries will be zero – fallback to uniform distribution
        return np.full_like(v, S / n)
    rho = np.where(cond)[0][-1]               # last true index
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Full self‑convolution via FFT (real inputs)
# ----------------------------------------------------------------------
def _full_convolution_fft(a: np.ndarray) -> np.ndarray:
    """Return the full convolution a*a using a real FFT."""
    n = a.shape[0]
    conv_len = 2 * n - 1
    fft_len = 1 << ((conv_len - 1).bit_length())   # next power of two
    Fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Fa * Fa, n=fft_len)[:conv_len]
    return conv


# ----------------------------------------------------------------------
# Initialise a feasible vector of length n (ℓ₁‑norm = √(2·n))
# ----------------------------------------------------------------------
def _initial_sequence(base_seq: np.ndarray | None,
                      n: int,
                      rng: np.random.Generator) -> np.ndarray:
    """Create a non‑negative vector of length n with sum √(2·n)."""
    S = np.sqrt(2.0 * n)
    if base_seq is not None and base_seq.size >= n:
        a = base_seq[:n].astype(float).copy()
        a += rng.normal(scale=a.mean() * 0.001, size=n)   # tiny jitter
        a = np.clip(a, 0.0, None)
    else:
        a = rng.random(n)                                 # Uniform Dirichlet(1)
    a = _project_to_simplex(a, S)
    return a


# ----------------------------------------------------------------------
# One soft‑max (or hard‑max) gradient step followed by projection
# ----------------------------------------------------------------------
def _softmax_update(a: np.ndarray, tau: float, eta: float) -> tuple[np.ndarray,
                                                                  np.ndarray,
                                                                  float]:
    """
    Perform a single update:
      – compute b = a*a,
      – compute soft‑max weights w_k ∝ exp(b_k / τ),
      – evaluate the gradient g_i = 2 Σ_j w_{i+j} a_j,
      – take an additive step a ← a – η·g,
      – project onto the ℓ₁‑simplex.
    Returns the new vector, the new convolution b, and max(b).
    """
    n = a.shape[0]
    S = np.sqrt(2.0 * n)

    # convolution and its current maximum
    b = _full_convolution_fft(a)
    max_b = np.max(b)

    if tau <= 1e-12:                      # treat as hard max (standard sub‑gradient)
        k = np.argmax(b)                 # index of the maximal entry
        idx = np.arange(n)
        partner = k - idx
        valid = (partner >= 0) & (partner < n)
        g = np.zeros_like(a)
        g[valid] = 2.0 * a[partner[valid]]
        if k % 2 == 0:                    # diagonal contribution appears only once
            d = k // 2
            if 0 <= d < n:
                g[d] = a[d]
    else:                                 # smooth soft‑max gradient
        # soft‑max weights (stable)
        diff = b - max_b
        exps = np.exp(diff / tau)
        w = exps / np.sum(exps)

        # cross‑correlation a ⋆ w = Σ_j a_j w_{i+j}
        a_rev = a[::-1]                   # reverse a for cross‑correlation via convolution
        m = 1 << ((len(w) + n - 1).bit_length())
        Fw = np.fft.rfft(w, n=m)
        Fa_rev = np.fft.rfft(a_rev, n=m)
        conv = np.fft.irfft(Fw * Fa_rev, n=m)[:len(w) + n - 1]
        g = 2.0 * conv[n - 1:n - 1 + n]   # slice gives length n

    # additive update and projection
    a_new = a - eta * g
    a_proj = _project_to_simplex(a_new, S)

    # recompute convolution after projection
    b_new = _full_convolution_fft(a_proj)
    max_new = np.max(b_new)

    return a_proj, b_new, max_new


# ----------------------------------------------------------------------
# Local optimiser (one restart)
# ----------------------------------------------------------------------
def _optimize_local(a0: np.ndarray,
                    deadline: float,
                    rng: np.random.Generator) -> tuple[np.ndarray, float]:
    """
    Mixed optimisation:
      – projected soft‑max gradient descent,
      – occasional simulated‑annealing mass‑swaps,
      – rare jitter.
    Returns the best vector seen and its maximal convolution entry.
    """
    a = a0.copy()
    n = a.shape[0]
    S = np.sqrt(2.0 * n)

    # initialise best record
    b = _full_convolution_fft(a)
    cur_max = np.max(b)
    best_a = a.copy()
    best_max = cur_max

    # hyper‑parameters
    eta = 0.6               # initial additive step size
    eta_decay = 0.9997
    move_prob = 0.12        # probability of attempting a random mass move
    epsilon_move = 0.04     # fraction of mass moved when a move is tried
    temp = cur_max * 0.1    # temperature for simulated‑annealing moves
    temp_decay = 0.9998
    jitter_prob = 0.01
    jitter_scale = 0.02
    tau = cur_max           # start temperature for soft‑max
    tau_decay = 0.9995

    while time.time() < deadline:
        # ------------------------------------------------------------------
        # 1) random mass swap (simulated annealing)
        # ------------------------------------------------------------------
        if rng.random() < move_prob:
            i = rng.integers(n)
            if a[i] <= 0.0:
                # nothing to move from this index
                continue
            j = rng.integers(n)
            if i == j:
                continue

            delta = epsilon_move * a[i]
            a_candidate = a.copy()
            a_candidate[i] -= delta
            a_candidate[j] += delta

            b_candidate = _full_convolution_fft(a_candidate)
            cand_max = np.max(b_candidate)

            accept = False
            if cand_max <= cur_max:
                accept = True
            else:
                prob = np.exp(-(cand_max - cur_max) / max(temp, 1e-12))
                if rng.random() < prob:
                    accept = True

            if accept:
                a = a_candidate
                cur_max = cand_max
                if cur_max < best_max:
                    best_max = cur_max
                    best_a = a.copy()
            temp *= temp_decay

        # ------------------------------------------------------------------
        # 2) projected soft‑max gradient step
        # ------------------------------------------------------------------
        else:
            a, b, cur_max = _softmax_update(a, max(tau, 1e-12), eta)
            if cur_max < best_max:
                best_max = cur_max
                best_a = a.copy()

        # ------------------------------------------------------------------
        # 3) occasional jitter
        # ------------------------------------------------------------------
        if rng.random() < jitter_prob:
            noise = rng.normal(scale=a.mean() * jitter_scale, size=n)
            a = np.clip(a + noise, 0.0, None)
            a = _project_to_simplex(a, S)
            b = _full_convolution_fft(a)
            cur_max = np.max(b)
            if cur_max < best_max:
                best_max = cur_max
                best_a = a.copy()

        # decay schedules
        eta *= eta_decay
        tau *= tau_decay

    return best_a, best_max


# ----------------------------------------------------------------------
# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs):
    """
    Run many short optimisation restarts within the given time budget
    and return the sequence with the smallest maximal self‑convolution
    entry (i.e. the smallest score returned by `evaluate_sequence`).
    """
    rng = np.random.default_rng(seed)
    deadline = time.time() + budget_s - 5.0          # small safety margin

    # ------------------------------------------------------------------
    # try to reuse a previously discovered construction, if any
    # ------------------------------------------------------------------
    base_seq = None
    if 'height_sequence_1' in globals():
        try:
            base_seq = np.asarray(globals()['height_sequence_1'], dtype=float)
        except Exception:
            base_seq = None

    best_overall_seq = None
    best_overall_score = np.inf
    attempt = 0

    # ------------------------------------------------------------------
    # main loop: many independent restarts
    # ------------------------------------------------------------------
    while time.time() < deadline:
        attempt += 1

        # choose a length – we explore a fairly wide interval
        if base_seq is not None:
            max_len = max(800, min(8000, int(base_seq.size * 1.5)))
        else:
            max_len = 8000
        n = rng.integers(800, max_len + 1)

        # initialise a feasible vector
        a0 = _initial_sequence(base_seq, n, rng)

        # allocate a slice of the remaining time to this restart
        slice_deadline = min(time.time() + 35.0, deadline)

        # run the optimiser
        a_opt, score = _optimize_local(a0, slice_deadline, rng)

        # keep the best overall result
        if score < best_overall_score:
            best_overall_score = score
            best_overall_seq = a_opt.copy()
            print(f"[global] attempt={attempt} n={n} "
                  f"new best max={best_overall_score:.6f}")

    # ------------------------------------------------------------------
    # final sanity check – evaluate through the black‑box function
    # ------------------------------------------------------------------
    if best_overall_seq is not None:
        final_seq = best_overall_seq.tolist()
        external_score = evaluate_sequence(final_seq)
        print(f"[final] best external score = {external_score:.6f} "
              f"(internal max = {best_overall_score:.6f}) "
              f"length = {len(final_seq)}")
        # store the result for possible reuse by a later run
        globals()['height_sequence_1'] = final_seq
        return final_seq
    else:
        # fallback – should never happen
        return [1.0]
```
