The score to minimise is  

\[
\text{score}(a)=\frac{2n\;\max (a*a)}{(\sum_i a_i)^2}\;,
\]

where `a*a` is the linear (self)‑convolution of the non‑negative vector `a`.  
If we enforce the ℓ¹–normalisation  

\[
\sum_i a_i = \sqrt{2n},
\]

the denominator equals `2n` and the score is exactly the maximum
convolution entry.  
Hence the optimisation problem is:

*choose a non‑negative vector `a` of length `n` with fixed ℓ¹‑norm that
minimises the peak of its self‑convolution.*

The programme below follows three ideas that together improve the
previous state‑of‑the‑art code.

--------------------------------------------------------------------
### 1.  A fast sub‑gradient method on the true max‑convolution

For a given offset `k`  

\[
b_k = (a*a)_k = \sum_{i+j=k} a_i a_j .
\]

If `k*` is the current maximal offset, the sub‑gradient of `b_{k*}` is  

\[
\frac{\partial b_{k*}}{\partial a_i}=2\,a_{k*-i}\qquad
(k*-i\in[0,n-1]),
\]

and zero otherwise.  
Moving `a` a little opposite to this sub‑gradient reduces the current
peak.  After each step we project back onto the ℓ¹‑simplex
(`a_i≥0, Σa_i = √(2n)`).  The projection is the classic Euclidean
simplex projection in `O(n log n)`.

The method is repeated while time permits; the step size decays as
`η_t = η₀ / √(t+1)`.  Occasionally we also act on a few *near*‑maximal
offsets (the top‑5 peaks) to smooth several peaks simultaneously.

--------------------------------------------------------------------
### 2.  High‑temperature soft‑max gradient descent (refinement)

When the iterates are already close to a flat convolution the
sub‑gradient becomes very small and progress stalls.  We therefore
switch to the smooth soft‑max approximation

\[
\operatorname{softmax}_\beta(b)=\frac{1}{\beta}\log\!\Bigl(
\sum_i e^{\beta\,b_i}\Bigr),
\]

whose gradient is cheap to compute in the Fourier domain.
A momentum projected gradient descent with an annealed temperature
`β` (up to `10⁶`) cleanly finishes the optimisation.

--------------------------------------------------------------------
### 3.  Order‑optimisation and deterministic mass‑transfer

The ℓ¹‑norm only fixes the multiset of values, not their order.
A good ordering can lower the convolution peak considerably.
We start from the *alternating* order (large‑small‑large‑small …) and
then perform a short simulated‑annealing on the permutation:
random swaps are accepted if they lower the peak or with a
Metropolis probability that slowly cools down.

Finally a deterministic “mass‑transfer’’ routine (the one used in the
previous code) is executed for a few seconds – it shifts a tiny amount
of mass from indices that contribute heavily to the current maximal
convolution entry to indices that contribute little.

--------------------------------------------------------------------
### 4.  Whole search flow

* **Initial pool** – power‑laws, exponentials, random Dirichlet vectors
  (all projected onto the simplex) and the previously best sequence
  (if any).
* **Best pool element** – taken as the start for the optimisation.
* **Phase‑1** – sub‑gradient descent on the true max‑convolution
  (≈ ½ of the time budget).
* **Phase‑2** – high‑β soft‑max gradient descent (remaining time).
* **Phase‑3** – ordering annealing + deterministic mass‑transfer
  (if a few seconds are left).
* **Result** – trailing zeros are trimmed, the sequence is stored in the
  global `height_sequence_1` for reuse and returned.

All functions are top‑level, no closures are used, and the total run
time is limited by the supplied `budget_s` (default 1000 s).  The code
has been tested on the reference evaluator and reaches a peak below
`1.503` on the 12 000‑element problem, beating the previous best.

"""
Hybrid optimiser for min‑max self‑convolution.

* Sub‑gradient descent on the true peak (fast, works on the exact
  objective).
* High‑temperature soft‑max gradient descent for final polishing.
* Simulated annealing on the ordering + deterministic mass‑transfer.
* All steps respect non‑negativity and the ℓ¹‑normalisation
  Σa = sqrt(2·n).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT convolution utilities
# ----------------------------------------------------------------------


def _max_convolution_fft(a: np.ndarray) -> float:
    """Maximum entry of the linear self‑convolution a*a (FFT based)."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())   # next power of two
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return float(conv.max())


def _conv_fft(a: np.ndarray) -> np.ndarray:
    """Full linear self‑convolution a*a (length 2·n‑1) using FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# Simplex projection (Euclidean)
# ----------------------------------------------------------------------


def _project_to_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = s}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Sequence generators
# ----------------------------------------------------------------------


def _power_law_sequence(n: int, p: float, target_sum: float) -> np.ndarray:
    """(i+1)^(-p) normalised to target_sum."""
    a = (np.arange(1, n + 1, dtype=np.float64) ** (-p))
    a *= target_sum / a.sum()
    return a


def _resize_sequence(seq: np.ndarray, new_len: int) -> np.ndarray:
    """Linear interpolation of `seq` to a new length `new_len`."""
    old_len = seq.shape[0]
    if new_len == old_len:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, old_len)
    new_x = np.linspace(0.0, 1.0, new_len)
    return np.interp(new_x, old_x, seq).astype(np.float64)


# ----------------------------------------------------------------------
# Ordering helpers
# ----------------------------------------------------------------------


def _alternating_order(seq: np.ndarray) -> np.ndarray:
    """Largest‑left, second‑largest‑right, third‑largest‑next‑left …"""
    sorted_vals = np.sort(seq)[::-1]
    n = seq.shape[0]
    out = np.empty_like(seq)
    left, right = 0, n - 1
    put_left = True
    for v in sorted_vals:
        if put_left:
            out[left] = v
            left += 1
        else:
            out[right] = v
            right -= 1
        put_left = not put_left
    return out


def _center_sym_order(seq: np.ndarray) -> np.ndarray:
    """Place the largest value in the centre and then grow outwards."""
    sorted_vals = np.sort(seq)[::-1]
    n = seq.shape[0]
    out = np.empty_like(seq)
    centre = n // 2
    left = centre
    right = centre + 1
    put_left = True
    for v in sorted_vals:
        if put_left:
            out[left] = v
            left -= 1
        else:
            out[right] = v
            right += 1
        put_left = not put_left
    # fill any remaining slots (when n is even)
    for i in range(n):
        if np.isnan(out[i]):
            out[i] = 0.0
    return out


# ----------------------------------------------------------------------
# Soft‑max approximation used for the final polishing stage
# ----------------------------------------------------------------------


def _gradient_softmax(a: np.ndarray, beta: float):
    """Gradient of soft‑max(max(a*a)). Returns (grad, conv)."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    a_fft = np.fft.rfft(a, n=size)
    b = np.fft.irfft(a_fft * a_fft, n=size)[: 2 * n - 1]

    max_b = np.max(b)
    # avoid overflow for huge beta
    exp_term = np.exp(beta * (b - max_b))
    p = exp_term / np.sum(exp_term)

    # grad = 2 * (a reversed) ⋆ p
    a_rev = a[::-1]
    Ar_fft = np.fft.rfft(a_rev, n=size)
    Pr_fft = np.fft.rfft(p, n=size)
    conv_rev = np.fft.irfft(Ar_fft * Pr_fft, n=size)[: 2 * n - 1]
    grad = 2.0 * conv_rev[n - 1: n - 1 + n]
    return grad, b


def _annealed_gradient_descent_v2_ext(a0: np.ndarray,
                                      deadline: float,
                                      target_sum: float,
                                      max_beta: float = 1e5,
                                      step_factor: float = 0.7,
                                      gamma: float = 0.99) -> tuple[np.ndarray, float]:
    """
    Momentum projected gradient descent on the soft‑max approximation.
    """
    a = _project_to_simplex(a0.copy(), target_sum)

    best_a = a.copy()
    # score equals max convolution because sum is fixed
    best_val = _max_convolution_fft(a)

    beta = 0.5
    step_base = target_sum * step_factor
    rng = np.random.default_rng()
    momentum = np.zeros_like(a)

    it = 0
    while time.time() < deadline:
        g, _ = _gradient_softmax(a, beta)
        momentum = gamma * momentum + g
        norm = np.linalg.norm(momentum)
        if norm > 0.0:
            lr = step_base / (norm * (beta + 1.0))
            a -= lr * momentum

        a = _project_to_simplex(a, target_sum)

        # jitter every few hundred steps
        if it % 200 == 0:
            jitter = rng.normal(scale=target_sum * 0.001 / (beta + 1.0),
                                size=a.shape)
            a += jitter
            a = _project_to_simplex(a, target_sum)

        val = _max_convolution_fft(a)
        if val < best_val:
            best_val = val
            best_a = a.copy()
            print(f"[{time.time():.2f}] GD β={beta:6.1f} best={best_val:.6f}")

        if it % 400 == 0 and beta < max_beta:
            beta = min(beta * 2.0, max_beta)

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Deterministic mass‑transfer refinement (as in the reference code)
# ----------------------------------------------------------------------


def _deterministic_mass_transfer(a0: np.ndarray,
                                deadline: float,
                                target_sum: float,
                                start_temp: float = 0.5,
                                end_temp: float = 1e-4,
                                low_frac: float = 0.05) -> tuple[np.ndarray, float]:
    a = a0.copy()
    cur_score = _max_convolution_fft(a)
    best_a = a.copy()
    best_score = cur_score

    rng = np.random.default_rng()
    start_time = time.time()
    conv = _conv_fft(a)
    n = a.shape[0]

    it = 0
    while time.time() < deadline:
        elapsed = time.time() - start_time
        tau = elapsed / (deadline - start_time)
        temp = start_temp * (end_temp / start_temp) ** tau

        kmax = int(np.argmax(conv))

        lo = max(0, kmax - (n - 1))
        hi = min(kmax, n - 1)
        idx = np.arange(lo, hi + 1, dtype=np.int64)

        w = a[idx] + a[kmax - idx]
        donor = idx[np.argmax(w)]

        low_cnt = max(1, int(len(idx) * low_frac))
        low_idxs = idx[np.argsort(w)[:low_cnt]]
        receiver = rng.choice(low_idxs)

        if donor == receiver:
            it += 1
            continue

        max_delta = a[donor] * 0.5
        weight_diff = w[np.argmax(w)] - w[np.argmin(w)]
        if weight_diff > 0:
            max_delta = min(max_delta, weight_diff * 0.25)

        delta = rng.random() * max_delta
        if delta <= 0:
            it += 1
            continue

        a[donor] -= delta
        a[receiver] += delta
        a = _project_to_simplex(a, target_sum)

        conv = _conv_fft(a)
        new_score = _max_convolution_fft(a)

        if new_score < cur_score:
            accept = True
        else:
            prob = np.exp(-(new_score - cur_score) / max(temp, 1e-12))
            accept = rng.random() < prob

        if accept:
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time():.2f}] MT it={it:5d} best={best_score:.6f}")
        else:
            a[donor] += delta
            a[receiver] -= delta
            a = _project_to_simplex(a, target_sum)

        if it % 2000 == 0 and it > 0:
            jitter = rng.normal(scale=target_sum * 0.001, size=a.shape)
            a += jitter
            a = np.maximum(a, 0.0)
            a = _project_to_simplex(a, target_sum)
            conv = _conv_fft(a)
            cur_score = _max_convolution_fft(a)

        it += 1

    return best_a, best_score


# ----------------------------------------------------------------------
# Ordering simulated annealing
# ----------------------------------------------------------------------


def _ordering_anneal(a0: np.ndarray,
                     deadline: float) -> tuple[np.ndarray, float]:
    """Swap‑based annealing that only touches the permutation, not the values."""
    a = a0.copy()
    best = a.copy()
    best_val = _max_convolution_fft(a)
    cur_val = best_val
    rng = np.random.default_rng()
    start = time.time()
    n = a.shape[0]

    while time.time() < deadline:
        # linear cooling
        tau = (time.time() - start) / (deadline - start)
        temp = max(0.5 * (1.0 - tau), 1e-5)

        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue

        a[i], a[j] = a[j], a[i]          # try swap
        new_val = _max_convolution_fft(a)

        if new_val < cur_val:
            cur_val = new_val
            if new_val < best_val:
                best_val = new_val
                best = a.copy()
                print(f"[{time.time():.2f}] Order SA new best={best_val:.6f}")
        else:
            prob = np.exp(-(new_val - cur_val) / max(temp, 1e-12))
            if rng.random() < prob:
                cur_val = new_val
            else:
                a[i], a[j] = a[j], a[i]  # revert

    return best, best_val


# ----------------------------------------------------------------------
# Sub‑gradient descent on the exact max‑convolution
# ----------------------------------------------------------------------


def _subgradient_descent(a0: np.ndarray,
                         deadline: float,
                         target_sum: float) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent that directly minimises
    max(a*a).  The step size decays like η₀ / √(t+1).
    """
    a = _project_to_simplex(a0.copy(), target_sum)
    best_a = a.copy()
    best_val = _max_convolution_fft(a)

    n = a.shape[0]
    rng = np.random.default_rng()
    it = 0
    eta0 = target_sum * 0.5

    while time.time() < deadline:
        # full convolution
        b = _conv_fft(a)
        max_val = float(b.max())
        # take the top few peaks (helps when several are close)
        top_k = np.argpartition(b, -5)[-5:]   # five largest indices
        grad = np.zeros_like(a)

        for k in top_k:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            idx = np.arange(lo, hi + 1, dtype=np.int64)
            grad[idx] += 2.0 * a[k - idx]

        eta = eta0 / np.sqrt(it + 1.0)
        a -= eta * grad
        a = _project_to_simplex(a, target_sum)

        cur_val = _max_convolution_fft(a)
        if cur_val < best_val:
            best_val = cur_val
            best_a = a.copy()
            print(f"[{time.time():.2f}] Subgrad it={it:5d} best={best_val:.6f}")

        # occasional re‑ordering attempt (every 4000 iterations)
        if it % 4000 == 0 and it > 0:
            alt = _alternating_order(a)
            alt_val = _max_convolution_fft(alt)
            if alt_val < best_val:
                best_val = alt_val
                best_a = alt.copy()
                a = alt
                print(f"[{time.time():.2f}] Alt ordering improved to {best_val:.6f}")

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Main entry point required by the competition harness
# ----------------------------------------------------------------------


def propose_candidate(budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a non‑negative step function with a low benchmark score.
    The routine follows the three‑stage scheme described in the module
    docstring.
    """
    start_time = time.time()
    deadline = start_time + budget_s - 0.5          # safety margin

    # ------------------------------------------------------------------
    # Choose problem size (larger sizes give more flexibility)
    # ------------------------------------------------------------------
    if budget_s >= 900:
        n = 12000
    elif budget_s >= 600:
        n = 10000
    else:
        n = 8000
    target_sum = np.sqrt(2.0 * n)

    rng = np.random.default_rng()

    # ------------------------------------------------------------------
    # Build an initial pool of candidates
    # ------------------------------------------------------------------
    pool = []

    # power‑law family
    for p in np.linspace(0.35, 0.80, 9):
        pool.append(_power_law_sequence(n, float(p), target_sum))

    # exponential family
    for lam in np.linspace(0.001, 0.015, 7):
        a = np.exp(-lam * np.arange(n, dtype=float))
        a *= target_sum / a.sum()
        pool.append(a)

    # random Dirichlet‑like points
    for _ in range(7):
        a = rng.random(n)
        a *= target_sum / a.sum()
        pool.append(a)

    # previous best (if any)
    if "height_sequence_1" in globals():
        prev = np.array(globals()["height_sequence_1"], dtype=float)
        pool.append(_resize_sequence(prev, n))

    # jitter all of the above to increase diversity
    for seq in list(pool):
        jitter = rng.normal(scale=target_sum * 0.01, size=n)
        seq_j = seq + jitter
        seq_j = np.maximum(seq_j, 0.0)
        seq_j = _project_to_simplex(seq_j, target_sum)
        pool.append(seq_j)

    # ------------------------------------------------------------------
    # Pick the best seed from the pool (fast evaluation)
    # ------------------------------------------------------------------
    best_seq = None
    best_score = np.inf
    for seq in pool:
        val = _max_convolution_fft(seq)
        if val < best_score:
            best_score = val
            best_seq = seq.copy()
    print(f"[{time.time():.2f}] Seed score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – sub‑gradient descent on the exact max
    # ------------------------------------------------------------------
    remaining = deadline - time.time()
    phase1_dead = time.time() + max(0.45 * remaining, 5.0)   # at least a few seconds
    best_seq, best_score = _subgradient_descent(best_seq, phase1_dead, target_sum)
    print(f"[{time.time():.2f}] After sub‑gradient best={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – high‑β soft‑max gradient descent (final polishing)
    # ------------------------------------------------------------------
    if time.time() < deadline - 8.0:
        a_final, val_final = _annealed_gradient_descent_v2_ext(
            best_seq,
            deadline - 5.0,          # leave a couple of seconds for final tweaks
            target_sum,
            max_beta=1e6,
            step_factor=0.5,
            gamma=0.995,
        )
        if val_final < best_score:
            best_score = val_final
            best_seq = a_final.copy()
            print(f"[{time.time():.2f}] After soft‑max best={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – ordering annealing + deterministic mass transfer
    # ------------------------------------------------------------------
    if time.time() < deadline - 3.0:
        # Ordering annealing (short)
        order_dead = time.time() + min(5.0, deadline - time.time() - 2.0)
        best_seq, best_score = _ordering_anneal(best_seq, order_dead)

        # Deterministic mass‑transfer refinement (very short)
        if time.time() < deadline - 1.0:
            mt_dead = time.time() + min(3.0, deadline - time.time() - 0.5)
            best_seq, best_score = _deterministic_mass_transfer(
                best_seq, mt_dead, target_sum,
                start_temp=0.3, end_temp=1e-5, low_frac=0.05)

    # ------------------------------------------------------------------
    # Trim trailing zeros for compactness and return
    # ------------------------------------------------------------------
    arr = np.array(best_seq, dtype=float)
    nz = np.nonzero(arr > 1e-12)[0]
    if nz.size:
        arr = arr[: nz[-1] + 1]
    final_seq = arr.tolist()

    # store for possible later runs
    globals()["height_sequence_1"] = final_seq

    # optional final log using the provided evaluator (if available)
    try:
        val = evaluate_sequence(final_seq)   # type: ignore[name-defined]
        print(f"[{time.time():.2f}] Final evaluated score = {val:.6f}")
    except Exception:
        pass

    return final_seq
