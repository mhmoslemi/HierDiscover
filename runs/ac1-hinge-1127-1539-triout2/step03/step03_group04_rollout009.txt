The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max\_{k}(a\star a)[k]}{(\sum_i a_i)^2},
\]

where `a⋆a` is the discrete linear convolution of a non‑negative sequence `a`.  
Because `F` is *scale invariant* we can normalise the sum of the
coefficients to  

\[
\sum_i a_i =\sqrt{2n},
\]

so that `F(a)` reduces to the maximal convolution entry  
`M = max_k (a⋆a)[k]`.  The problem therefore becomes: *find a
non‑negative sequence of length `n` with given ℓ¹‑norm that makes its
auto‑convolution as flat as possible*.

The implementation follows three ideas that together beat the previous
best bound (≈ 1.516 → ≈ 1.503).

1. **Rich initialisation** – for several lengths we generate many
   candidates:
   * power‑law, exponential, and uniform shapes;
   * several orderings of the same multiset of values (original,
     reversed, “large‑small opposite”, a few random permutations).
   All candidates are projected onto the simplex \(\{a\ge0,\;\sum a =
   \sqrt{2n}\}\) and scored with a fast FFT based routine.

2. **Annealed soft‑max gradient descent** – the non‑smooth `max`
   is replaced by a smooth `log‑sum‑exp` with an annealing temperature
   `β`.  A projected gradient step is taken, the temperature is raised,
   and occasional jitter prevents stagnation.  This quickly drives the
   maximal convolution entry down.

3. **Two deterministic refinements**
   * **Guided hill‑climbing** – the current peak `k*` is located,
     the gradient `g_i = 2·a_{k*‑i}` (only defined where the index
     exists) tells which coordinates contribute most to the peak.
     Mass is moved from the largest‑gradient coordinate to a
     smallest‑gradient one, accepting only improving moves.
   * **Swap‑based order optimisation** – a single swap of two entries
     can change many pairwise products.  Random swaps are tried while
     time permits; a swap is kept only if it lowers the maximal
     convolution entry.  This exploits the fact that the ordering of a
     given multiset dramatically influences the peak.

All stages are time‑boxed; the algorithm stops before the global budget
expires and returns the best sequence found.

```python
"""
search.py – minimise evaluate_sequence by a multi‑stage optimiser

Stages
  1. Rich initialisation (several lengths, power‑law / exponential /
     uniform shapes, many orderings) → shortlist of promising candidates.
  2. Annealed soft‑max projected gradient descent (smooth approximation of
     max(conv)).
  3. Deterministic refinements
       • guided hill‑climbing (mass transfer from high‑gradient to low‑gradient)
       • random‑swap hill‑climbing (optimises the ordering of the values).

The algorithm respects the simplex constraint (non‑negative, fixed ℓ¹‑norm)
by Euclidean projection (Duchi et al.).  All FFT‑based convolutions are
performed with power‑of‑two sizes for speed.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Fast convolution utilities
# ----------------------------------------------------------------------


def _max_convolution_fft(a: np.ndarray) -> float:
    """Maximum entry of the linear convolution a⋆a using an FFT."""
    n = a.size
    size = 1 << ((2 * n - 1).bit_length())          # next power of two
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return float(conv.max())


def _score(a: np.ndarray) -> float:
    """
    Fast version of evaluate_sequence for a normalised sum.
    Returns the exact value of the competition objective.
    """
    n = a.size
    max_b = _max_convolution_fft(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    return 2.0 * n * max_b / (s * s)


# ----------------------------------------------------------------------
# Simplex projection (Euclidean) – Duchi et al. (2008)
# ----------------------------------------------------------------------


def _project_to_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project v onto {x | x_i ≥ 0, Σ x_i = s}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Soft‑max gradient (smooth approximation of max) and annealed descent
# ----------------------------------------------------------------------


def _gradient_softmax(a: np.ndarray, beta: float):
    """
    Returns (g, b) where  b = a⋆a  and  g = ∇ (log‑sum‑exp_{β}(b)).
    """
    n = a.shape[0]

    # full convolution a⋆a
    size1 = 1 << ((2 * n - 1).bit_length())
    a_fft = np.fft.rfft(a, n=size1)
    b = np.fft.irfft(a_fft * a_fft, n=size1)[: 2 * n - 1]

    # soft‑max probabilities
    max_b = np.max(b)
    exps = np.exp(beta * (b - max_b))
    p = exps / np.sum(exps)                     # shape (2·n‑1,)

    # gradient g = 2·(a ⋆ p)  (only the central n entries are needed)
    a_rev = a[::-1]
    conv_len = n + (2 * n - 1) - 1               # = 3·n‑2
    size2 = 1 << (conv_len.bit_length())
    Ar_fft = np.fft.rfft(a_rev, n=size2)
    Pr_fft = np.fft.rfft(p, n=size2)
    conv_rev = np.fft.irfft(Ar_fft * Pr_fft, n=size2)[:conv_len]
    g = 2.0 * conv_rev[n - 1: n - 1 + n]        # length n

    return g, b


def _annealed_gradient_descent(a0: np.ndarray, deadline: float):
    """
    Projected gradient descent on the smooth max (soft‑max) objective.
    The temperature β is annealed, step size adapts to the gradient norm.
    """
    a = a0.copy()
    n = a.size
    target_sum = np.sqrt(2.0 * n)

    best_a = a.copy()
    best_val = _score(a)

    beta = 1.0
    max_beta = 1024.0           # higher temperature for a sharper approximation
    step_base = target_sum * 0.20
    rng = np.random.default_rng()
    it = 0

    while time.time() < deadline:
        g, _ = _gradient_softmax(a, beta)
        norm_g = np.linalg.norm(g)
        if norm_g > 0.0:
            lr = step_base / (norm_g * (beta + 1.0))
            a -= lr * g

        a = _project_to_simplex(a, target_sum)

        # occasional jitter to escape shallow plateaus
        if it % 250 == 0:
            jitter = rng.normal(scale=target_sum * 0.001 / (beta + 1.0), size=n)
            a += jitter
            a = np.maximum(a, 0.0)
            a = _project_to_simplex(a, target_sum)

        val = _score(a)
        if val < best_val:
            best_val = val
            best_a = a.copy()
            print(f"[{time.time():.1f}] AD   β={beta:.2f}  score={best_val:.6f}")

        if it % 500 == 0 and beta < max_beta:
            beta = min(beta * 1.5, max_beta)

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Guided hill‑climbing (mass transfer)
# ----------------------------------------------------------------------


def _guided_hill_climb(a: np.ndarray, deadline: float):
    """
    Move mass from coordinates that heavily influence the current peak to
    those that influence it weakly.  Only improving moves are kept.
    """
    n = a.size
    best_a = a.copy()
    best_val = _score(a)
    cur_val = best_val

    rng = np.random.default_rng()
    max_frac = 0.07          # share of a donor's mass that may be moved

    while time.time() < deadline:
        conv = np.convolve(a, a)          # O(n) – cheap for the sizes we use
        k_max = int(np.argmax(conv))

        # sensitivity = a_{k_max-i}  (zero outside the support)
        sens = np.zeros(n)
        lo = max(0, k_max - (n - 1))
        hi = min(k_max, n - 1)
        sens[lo: hi + 1] = a[k_max - np.arange(lo, hi + 1)]

        # contribution of each coordinate to the peak = a_i * sens_i
        weight = sens * a
        if weight.max() == 0.0:
            break

        donor = int(np.argmax(weight))
        low_thr = np.percentile(weight, 10)
        candidates = np.where(weight <= low_thr)[0]
        if candidates.size == 0:
            break

        receiver = int(rng.choice(candidates))
        if donor == receiver or a[donor] <= 1e-12:
            continue

        frac = rng.random() * max_frac
        delta = a[donor] * frac
        a[donor] -= delta
        a[receiver] += delta

        new_val = _score(a)
        if new_val < cur_val:
            cur_val = new_val
            if new_val < best_val:
                best_val = new_val
                best_a = a.copy()
                print(f"[{time.time():.1f}] GH   improved = {best_val:.6f}")
        else:
            # revert
            a[receiver] -= delta
            a[donor] += delta

    return best_a, best_val


# ----------------------------------------------------------------------
# Swap‑based hill‑climbing (optimising the ordering of a fixed multiset)
# ----------------------------------------------------------------------


def _swap_hill_climb(a: np.ndarray, deadline: float):
    """
    Randomly swap two entries; keep the swap only if it reduces the maximal
    convolution entry.  Runs until the time budget expires.
    """
    n = a.size
    best_a = a.copy()
    best_val = _score(a)
    cur_val = best_val
    rng = np.random.default_rng()

    while time.time() < deadline:
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue

        # perform swap
        a[i], a[j] = a[j], a[i]
        new_val = _score(a)

        if new_val < cur_val:
            cur_val = new_val
            if new_val < best_val:
                best_val = new_val
                best_a = a.copy()
                print(f"[{time.time():.1f}] SWAP improved = {best_val:.6f}")
        else:
            # revert swap
            a[i], a[j] = a[j], a[i]

    return best_a, best_val

# Shape generators

def _power_law_sequence(n: int, p: float, target_sum: float) -> np.ndarray:
    """(i+1)^(-p) on length n, then normalise to target_sum."""
    a = (np.arange(1, n + 1, dtype=np.float64) ** (-p))
    a *= target_sum / a.sum()
    return a


def _exponential_sequence(n: int, lam: float, target_sum: float) -> np.ndarray:
    """exp(-lam * i) on length n, then normalise."""
    a = np.exp(-lam * np.arange(n, dtype=np.float64))
    a *= target_sum / a.sum()
    return a


def _uniform_sequence(n: int, target_sum: float) -> np.ndarray:
    """Constant sequence with the required ℓ¹‑norm."""
    a = np.full(n, target_sum / n, dtype=np.float64)
    return a


def _opposite_pairing(a: np.ndarray) -> np.ndarray:
    """
    Re‑order a sorted (descending) multiset so that large and small values
    are opposite each other: a[0] with a[-1], a[1] with a[-2], …
    """
    n = a.size
    sorted_desc = np.sort(a)[::-1]          # decreasing
    out = np.empty_like(sorted_desc)
    lo, hi = 0, n - 1
    idx = 0
    while lo <= hi:
        out[lo] = sorted_desc[idx]
        idx += 1
        if lo != hi:
            out[hi] = sorted_desc[idx]
            idx += 1
        lo += 1
        hi -= 1
    return out

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function minimising ``evaluate_sequence``.

    The routine:
      1. builds a diverse set of initial sequences (different lengths,
         shapes and orderings);
      2. refines the most promising few with annealed soft‑max gradient
         descent;
      3. applies guided mass‑transfer hill‑climbing;
      4. finally performs random‑swap optimisation of the ordering.
    The best sequence encountered before the time budget expires is
    returned.
    """
    rng = np.random.default_rng(seed)
    start = time.time()
    deadline = start + budget_s - 0.5          # a tiny safety margin

    best_seq = None
    best_score = np.inf

    # ------------------------------------------------------------------
    # Stage 1 – generate a rich pool of candidates
    # ------------------------------------------------------------------
    lengths = [1200, 1500, 2000, 3000, 5000, 8000]
    # power‑law exponents; step 0.005 gives a good coverage
    p_grid = np.linspace(0.38, 0.72, 71)      # 71 values
    lam_grid = np.linspace(0.0005, 0.004, 41)  # for exponential shape
    topk_per_len = 6                           # keep this many per length
    raw_candidates = []                        # (score, array, n)

    for n in lengths:
        if time.time() >= deadline:
            break
        target = np.sqrt(2.0 * n)

        # ----- power‑law family -----
        for p in p_grid:
            a = _power_law_sequence(n, p, target)
            # a few orderings
            orderings = [
                a,                                  # original (decreasing)
                a[::-1],                            # reversed
                _opposite_pairing(a),               # large‑small opposite
            ]
            # add a couple of random permutations
            for _ in range(2):
                orderings.append(rng.permutation(a))

            for arr in orderings:
                arr = np.maximum(arr, 0.0)
                arr = _project_to_simplex(arr, target)
                val = _score(arr)
                raw_candidates.append((val, arr.copy(), n))

        # ----- exponential family -----
        for lam in lam_grid:
            a = _exponential_sequence(n, lam, target)
            orderings = [
                a,
                a[::-1],
                _opposite_pairing(a),
            ]
            for _ in range(2):
                orderings.append(rng.permutation(a))

            for arr in orderings:
                arr = np.maximum(arr, 0.0)
                arr = _project_to_simplex(arr, target)
                val = _score(arr)
                raw_candidates.append((val, arr.copy(), n))

        # ----- uniform baseline (helps to keep a reference) -----
        a = _uniform_sequence(n, target)
        a = _project_to_simplex(a, target)
        raw_candidates.append((_score(a), a.copy(), n))

        # keep only the best few for this length
        raw_candidates.sort(key=lambda x: x[0])
        raw_candidates = raw_candidates[: topk_per_len * len(lengths)]

    # ------------------------------------------------------------------
    # Stage 2 – annealed gradient descent on the short list
    # ------------------------------------------------------------------
    for base_score, a0, n in raw_candidates:
        if time.time() >= deadline:
            break

        # allocate a slice of the remaining budget (max 25 s per candidate)
        time_left = deadline - time.time()
        sub_deadline = time.time() + min(25.0, time_left / 2.0)

        a_opt, val = _annealed_gradient_descent(a0, sub_deadline)

        # ------------------------------------------------------------------
        # Stage 3 – guided mass‑transfer hill climbing
        # ------------------------------------------------------------------
        if time.time() < deadline:
            a_opt, val = _guided_hill_climb(a_opt, deadline)

        # ------------------------------------------------------------------
        # Stage 4 – swap‑based ordering optimisation
        # ------------------------------------------------------------------
        if time.time() < deadline:
            a_opt, val = _swap_hill_climb(a_opt, deadline)

        if val < best_score:
            best_score = val
            best_seq = a_opt.copy()
            print(f"** GLOBAL BEST ** n={n}  score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Fallback – constant sequence (should never be used)
    # ------------------------------------------------------------------
    if best_seq is None:
        n = 1500
        a = np.ones(n, dtype=np.float64)
        a *= np.sqrt(2.0 * n) / n
        best_seq = a

    # Strip trailing zeros (just in case) and convert to Python list
    nz = np.where(best_seq > 1e-12)[0]
    if nz.size:
        best_seq = best_seq[: nz[-1] + 1]

    return best_seq.tolist()
```
