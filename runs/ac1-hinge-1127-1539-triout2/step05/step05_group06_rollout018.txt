The idea is simple:
1. Start with a short uniform block.  For a uniform block of length n
   the self‑convolution peak is exactly 2 (after the usual L¹‑normalisation),
   and the objective value is just that peak.
2. Add many *isolated* heights of size w≈√2.  If the positions of those
   isolated heights form a Sidon (B₂) set, every pairwise sum of indices is
   unique.  Consequently each new convolution entry contributed by the
   isolated heights is exactly w², never larger than the original peak.
3. The isolated heights increase the total L¹‑mass linearly while the peak
   stays (essentially) constant, so the factor
        2·n·max_b / (sum_a)²
   shrinks roughly like 2 / (#isolated points).  With a few hundred isolated
   points the score drops to the order of 10⁻², far below the target 1.503.

The Sidon set is built greedily (Mian‑Chowla construction).  The scale
factor K>n₀ guarantees that sums involving the original block cannot clash

import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Helper: greedy construction of a Sidon (B2) set (Mian‑Chowla sequence)
# ----------------------------------------------------------------------


def _generate_sidon(size: int) -> List[int]:
    """
    Return a list of `size` non‑negative integers forming a Sidon set,
    i.e. all pairwise sums a_i + a_j (i≤j) are distinct.
    The standard greedy algorithm is used.
    """
    sidon: List[int] = []
    sums = set()          # set of already seen sums a_i + a_j
    cand = 0
    while len(sidon) < size:
        conflict = False
        # test whether any existing sum would clash with cand
        for x in sidon:
            if cand + x in sums:
                conflict = True
                break
        # also test the self‑sum
        if not conflict and (cand + cand) in sums:

            for x in sidon:
                sums.add(cand + x)
                sums.add(x + cand)   # same value, but cheap and safe
        cand += 1
