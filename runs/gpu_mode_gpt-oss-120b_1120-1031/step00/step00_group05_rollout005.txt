The TriMul forward does:

1. x = norm(x) using LayerNorm: x_norm = (x - mean) / sqrt(var + eps) * weight + bias. This can be done in PyTorch; it's not the main bottleneck.

2. left = left_proj(x): linear projection, weight shape (hidden_dim, dim). right = right_proj(x). So left = x @ W_left^T, similarly for right. This is a linear matmul at each (i,j) position; shape: [B,N,N,hidden_dim].

3. mask application: mask shape [B,N,N] broadcasted to last dim: mask[..., None] * left/right.

4. Left Gate: left_gate = sigmoid(left_gate(x)) where left_gate = linear(x) (dim->hidden_dim). So left_gate = sigmoid(x @ W_left_gate^T). Similarly right_gate, out_gate.

5. Multiply left by left_gate, right by right_gate.

6. out = einsum('... i k d, ... j k d -> ... i j d', left, right). That is for each batch and dim (d), for each i,j we sum over k: left[b,i,k,d] * right[b,j,k,d]. So it's a batched "pairwise inner product" across dimension k. Equivalent to, for each d: left[:,:, :, d] are BxNxN; right similarly. The output is BxNxNxhidden_dim? Actually hidden_dim, not dim. But code expects out of shape [B,N,N,dim]. Wait out after einsum: left shape: [..., i, k, d], right shape: [..., j, k, d]. The einsum reduces over k, leaving [B, i, j, d] where d = hidden_dim. So out shape [B,N,N,hidden_dim]. Then they apply to_out_norm (LayerNorm hidden_dim) and multiply by out_gate (with shape [B,N,N,hidden_dim]) and then linear to_out: hidden_dim -> dim, producing output shape [B,N,N,dim].

Thus major computational cost: the tri-multiplication (reduction over k). That's a triple sum: each i, j, sum over k of vector element wise multiplication per hidden_dim dimension. Equivalent to a batched matrix multiplication: left[..., i, k, d] and right[..., j, k, d] where d is hidden_dim. Observations: for each d, left and right are 3D tensors BxNxN. The reduction can be expressed as a batch of matrix-matrix multiplications: left_d = left[..., :, :, d] (shape BxNxN). Meanwhile right_d = right[..., :, :, d]. But for the sum we need left[i,k,d] * right[j,k,d] across k => left_d @ right_d^T? Let's examine: left[i,k] * right[j,k] sum over k => sum_k left[i,k] * right[j,k] = (left @ right^T)[i,j] because right[j] is row j, but we have right indexed as [j,k]; typical matrix multiplication left (size N x N) times right^T (size N x N) yields entry (i,j) = sum_k left[i, k] * right[j, k]. That's exactly the required per batch and per d. So out[:,:, :, d] = left_d @ right_d^T. So we need to compute a batch of matrix multiplications for each hidden_dim d: B * hidden_dim matrix multiplications of shape (N,N) * (N,N). That's an N^3 operation. For hidden_dim small (128), B up to 2, this is manageable.

def custom_kernel(data):
    input_tensor, mask, weights, config = data
    dim = config['dim']
    hidden_dim = config['hidden_dim']
    # extract weight tensors (already torch.nn.parameter) for layernorm etc.

    # Compute layernorm over dim.
    # x_norm = torch.nn.functional.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias, eps=1e-6)
    # Equivalent: x_norm = ((input - mean) / sqrt(var + eps)) * weight + bias

    # Compute linear projections using torch.nn.functional.linear:
    left = torch.nn.functional.linear(x_norm, left_proj_weight) # shape B,N,N,hidden_dim
    right = torch.nn.functional.linear(x_norm, right_proj_weight)
    # compute gates
    left_gate = torch.sigmoid(torch.nn.functional.linear(x_norm, left_gate_weight))
    right_gate = torch.sigmoid(torch.nn.functional.linear(x_norm, right_gate_weight))
    out_gate = torch.sigmoid(torch.nn.functional.linear(x_norm, out_gate_weight))

    # Apply mask if not nominal; mask shape B,N,N.
    if mask is not None:
        mask = mask.unsqueeze(-1)  # B,N,N,1
        left = left * mask
        right = right * mask

    left = left * left_gate
    right = right * right_gate

"""
custom_kernel
==============

Implements the **outgoing** TriMul operation from AlphaFold‑3.  
The forward pass consists of

1. LayerNorm over the last channel dimension (dim).
2. Two linear projections (`left_proj`, `right_proj`) + two linear gates.
3. Optional pair‑wise mask.
4. A batch of matrix‑multiplications
   `out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]`
   (equivalent to `left[...,d] @ right[...,d].T`).  
   This N³ reduction is performed by a fused Triton kernel that processes a
   tile of size (BLOCK_M, BLOCK_N) for each head ``d`` and each batch.
5. LayerNorm over the hidden dimension, multiplication by an output gate,
   and a final linear projection back to ``dim``.

Only the heavy tri‑multiplication is off‑loaded to Triton; all other
operations stay in PyTorch (highly‑optimised cuBLAS / cudnn kernels).
The Triton kernel works on FP16 inputs (to halve memory bandwidth) while
accumulating in FP32 to retain numeric stability.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# -----------------------------------------------------------------------------#
# Triton kernel: a batched matmul over the hidden dimension (D).
# -----------------------------------------------------------------------------#
@triton.jit
def trimul_kernel(
    left_ptr,          # *fp16   [B,N,N,D]
    right_ptr,         # *fp16   [B,N,N,D]
    out_ptr,           # *fp32   [B,N,N,D]
    B, N, D,           # runtime ints
    # left strides
    stride_left_batch, stride_left_i, stride_left_j, stride_left_d,
    # right strides
    stride_right_batch, stride_right_i, stride_right_j, stride_right_d,
    # output strides
    stride_out_batch, stride_out_i, stride_out_j, stride_out_d,
    # compile‑time tile sizes
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """Batched GEMM: for every (batch, head) compute
       out[...,i,j] = left[...,i,:] @ right[...,j,:]^T
       using tiling (BLOCK_M, BLOCK_N, BLOCK_K)."""
    pid_i = tl.program_id(0)                # tile row   (i)
    pid_j = tl.program_id(1)                # tile col   (j)
    pid_hd = tl.program_id(2)               # combined batch * hidden_head

    batch_id = pid_hd // D                  # which batch
    head_id  = pid_hd % D                   # which hidden dimension (d)

    # ----- base pointers for this (batch, head) -----------------------------
    left_base  = left_ptr  + batch_id * stride_left_batch  + head_id * stride_left_d
    right_base = right_ptr + batch_id * stride_right_batch + head_id * stride_right_d
    out_base   = out_ptr   + batch_id * stride_out_batch   + head_id * stride_out_d

    # ----- offsets for the output tile --------------------------------------
    offs_i = pid_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ----- loop over K dimension -------------------------------------------
    for start_k in range(0, N, BLOCK_K):
        offs_k = start_k + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left block: shape (BLOCK_M, BLOCK_K)
        left_ptrs = (left_base
                     + offs_i[:, None] * stride_left_i
                     + offs_k[None, :] * stride_left_j)
        a = tl.load(left_ptrs,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0,
                    dtype=tl.float16).to(tl.float32)

        # right block (transposed): shape (BLOCK_K, BLOCK_N)
        # we need right[j, k] -> original row=j, col=k
        right_ptrs = (right_base
                      + offs_k[:, None] * stride_right_j   # row = k  (original col)
                      + offs_j[None, :] * stride_right_i)  # col = j  (original row)
        b = tl.load(right_ptrs,
                    mask=mask_k[:, None] & mask_j[None, :],
                    other=0.0,
                    dtype=tl.float16).to(tl.float32)

        acc += tl.dot(a, b)   # (BLOCK_M, BLOCK_N)

    # ----- write back --------------------------------------------------------
    out_ptrs = out_base + offs_i[:, None] * stride_out_i + offs_j[None, :] * stride_out_j
    tl.store(out_ptrs,
             acc,
             mask=mask_i[:, None] & mask_j[None, :])


# -----------------------------------------------------------------------------#
# Python entry point
# -----------------------------------------------------------------------------#
def custom_kernel(data):
    """
    Runs the TriMul forward pass.  ``data`` is a 4‑tuple:
        (input_tensor, mask_tensor, weights_dict, config_dict)

    Returns:
        Tensor of shape [B, N, N, dim] (float32) on the same CUDA device.
    """
    # -------------------------------------------------------------
    # unpack inputs
    # -------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # -------------------------------------------------------------
    # layer‑norm over the channel dim
    # -------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=1e-6,
    )  # [B,N,N,dim] float32

    # -------------------------------------------------------------
    # linear projections (no bias)
    # -------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])          # [B,N,N,hidden_dim]
    right = F.linear(x, weights["right_proj.weight"])

    # -------------------------------------------------------------
    # gate computations (sigmoid)
    # -------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    # -------------------------------------------------------------
    # optional mask (broadcast to channel dim)
    # -------------------------------------------------------------
    if not nomask and mask is not None:
        # mask shape [B,N,N]; expand to [B,N,N,1] and cast to the tensor dtype
        mask_exp = mask.to(x.dtype).unsqueeze(-1)
        left = left * mask_exp
        right = right * mask_exp

    # -------------------------------------------------------------
    # apply element‑wise gates
    # -------------------------------------------------------------
    left = left * left_gate
    right = right * right_gate

    # -------------------------------------------------------------
    # prepare for Triton (cast to FP16, make contiguous)
    # -------------------------------------------------------------
    left_f16 = left.to(torch.float16).contiguous()
    right_f16 = right.to(torch.float16).contiguous()
    B, N, _, _ = left_f16.shape

    # output buffer for the hidden‑dim result (FP32)
    out_hidden = torch.empty(B, N, N, hidden_dim, dtype=torch.float32, device=device)

    # -------------------------------------------------------------
    # strides (in elements, not bytes) – same layout for left/right/out
    # -------------------------------------------------------------
    stride_lb, stride_li, stride_lj, stride_ld = left_f16.stride()
    stride_rb, stride_ri, stride_rj, stride_rd = right_f16.stride()
    stride_ob, stride_oi, stride_oj, stride_od = out_hidden.stride()

    # -------------------------------------------------------------
    # launch Triton kernel
    # -------------------------------------------------------------
    BLOCK_M = 32   # tile rows  (must satisfy BLOCK_M*BLOCK_N <= 1024)
    BLOCK_N = 32   # tile cols
    BLOCK_K = 32   # reduction tile

    num_blocks_i = (N + BLOCK_M - 1) // BLOCK_M
    num_blocks_j = (N + BLOCK_N - 1) // BLOCK_N
    # third grid dimension = batch * hidden_dim
    grid = (num_blocks_i, num_blocks_j, B * hidden_dim)

    trimul_kernel[grid](
        left_f16,
        right_f16,
        out_hidden,
        B, N, hidden_dim,
        # left strides
        stride_lb, stride_li, stride_lj, stride_ld,
        # right strides
        stride_rb, stride_ri, stride_rj, stride_rd,
        # output strides
        stride_ob, stride_oi, stride_oj, stride_od,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # -------------------------------------------------------------
    # post‑processing: layer‑norm, out‑gate, final linear
    # -------------------------------------------------------------
    out_norm = F.layer_norm(
        out_hidden,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=1e-6,
    )
    out_norm = out_norm * out_gate  # broadcast over hidden dim

    output = F.linear(out_norm, weights["to_out.weight"])   # back to [B,N,N,dim]

    return output
