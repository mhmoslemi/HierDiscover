"""
Projected gradient descent for the step‑function optimisation problem.

The evaluation that we want to minimise is

        2·n·max_k (a*a)_k / (∑a_i)² ,

which is scale‑invariant.  We therefore keep the ℓ₁‑norm fixed to
√(2 n) and only move the mass among the coordinates.

The algorithm works with a smooth approximation of the max:
    softmax_β(conv) = exp(β·(conv‑max(conv))) / Σ exp(·).

Its gradient with respect to a is
    ∇ = 2·∑_i a_i·w_{i+·},
i.e. for each index j   g_j = 2·∑_i a_i·w_{i+j},
where w are the soft‑max weights.  After a gradient step we
project back onto the feasible set (non‑negative entries and the
prescribed ℓ₁‑norm).  The temperature β is slowly increased so that
the smooth objective approaches the true maximum, while the step size
is gradually decreased.  The best sequence encountered during the
run is returned.

The routine runs for ≤ budget_s seconds (default 1000 s) and,
if a previous construction `height_sequence_1` is available, starts
from it; otherwise it uses a random initialisation.

import time
import numpy as np

# ----------------------------------------------------------------------
def _softmax_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """
    Return the soft‑max weights of a convolution vector.
    The maximum is subtracted first for numerical stability.
    """
    max_c = conv.max()
    shifted = conv - max_c                     # ≤ 0
    w = np.exp(beta * shifted)
    s = w.sum()
    if s == 0.0:
        # should not happen, but fall back to uniform weights
        w = np.full_like(conv, 1.0 / conv.size)
    else:
        w /= s
    return w


def _gradient(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the smooth max of (a*a) with respect to a.
    For each i we add 2·a_i·w_{i+·} to the whole gradient vector.
    """
    n = a.shape[0]
    # w has length 2·n‑1, and w[i:i+n] is always a valid slice
    g = np.zeros_like(a)
    for i in range(n):
        g += 2.0 * a[i] * w[i:i + n]
    return g

    s = a.sum()
    if s < 0.01:
