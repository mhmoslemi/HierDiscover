    moves a small amount of mass from the index that contributes most to the
    current peak of the convolution to a random index.  It keeps the best
    sequence found before the time budget expires.
    """

    random.seed(seed)

    cur_seq = seq.copy()

    deadline = time.time() + budget_s - 0.5  # leave a little margin
    it = 0

    # exponential cooling over the budget
    total_iters_est = 20000

    while time.time() < deadline:

        # contributions to the peak

A fast, self‑contained hill‑climbing / simulated‑annealing routine that
searches for a non‑negative step‑function (a list of heights) which
minimises

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `conv` is the ordinary linear convolution.  The optimizer works as
follows:

* Initialise a candidate sequence of the same length as the best known
  construction ``height_sequence_1`` (or a default length if that
  variable does not exist).  Two starts (uniform and random) are tried
  and the better one is kept.

* Repeatedly perform a *mass‑transfer* move:
    – Compute the convolution and locate the index `k_max` where it
      attains its maximum.
    – For that `k_max` compute the contribution of each coefficient:

    – Move a small fraction ``frac`` of the mass from `i_max` to `j`.
      ``frac`` starts relatively large (≈0.3) and shrinks linearly with
      the remaining time, guaranteeing finer adjustments near the end.

* Accept the move if it strictly improves the objective; otherwise accept

* Every 1000 iterations the whole vector is re‑normalised to guard

* The best sequence seen during the run is returned.  The algorithm

        else:
            # Tiny uphill‑acceptance probability (simulated annealing)
            temperature = 0.001 * cur_score               # a small temperature
            prob = np.exp(-(new_score - cur_score) / temperature)
            if np.random.rand() < prob:
                accept = True

        if accept:
            cur_seq = new_seq
            cur_score = new_score

        # ---- occasional re‑normalisation (keeps sum == 1) -----------------
        if it % 1000 == 0:
            s = cur_seq.sum()
            if s > 0:
                cur_seq = cur_seq / s
                best_seq = best_seq / best_seq.sum()

        # ---- restart if we are stuck for a long time ----------------------
        if it_since_improve >= RESTART_AFTER:
            # fresh random start but keep the current best as a fallback
            cur_seq = np.random.rand(n)
            cur_seq /= cur_seq.sum()
            cur_score = eval_seq(cur_seq)
            it_since_improve = 0
            print(f"Iter {it:6d} – restart due to stagnation (score {cur_score:.6f})")

        it += 1

    # ------------------------------------------------------------------
    # 3.  Return the best sequence found (make sure it is non‑negative)
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    return best_seq.tolist()
