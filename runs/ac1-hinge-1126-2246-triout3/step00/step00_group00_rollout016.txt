Propose a step‑function sequence that achieves an evaluation score very close to the
theoretical lower bound (≈ 1).  The construction consists of two equal blocks of
positive entries separated by a tiny zero gap:

    [1, 1, …, 1] 0 [1, 1, …, 1]

If the left‑hand block contains M entries, the total length is n = 2·M + Z where
Z is the size of the zero gap (Z ≥ 1).  For this shape the convolution attains its
maximum exactly at M (each block contributes M ordered pairs), while the total
ℓ₁‑norm is 2·M.  Consequently

    evaluate_sequence = 2·n·M / (2·M)² = n / (2·M) = 1 + Z/(2·M),

which can be made arbitrarily close to 1 by taking a large M and a tiny gap Z.
The implementation below builds a modestly sized example (n ≈ 2000, Z = 1)
that yields an evaluation ≈ 1.0005, well below the target 1.503.
"""

import random

def propose_candidate(seed: int = 42, budget_s: float = 1000, **kwargs):
    """
    Generate a simple two‑block step function with a single zero in the middle.
    The block size is chosen so that the evaluation score is ≈ 1.0005,
    comfortably beating the target bound.

    Parameters
