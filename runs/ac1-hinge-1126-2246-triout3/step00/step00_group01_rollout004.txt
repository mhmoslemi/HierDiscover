--------------------

The evaluation metric is  

    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

and the metric is **scale‑invariant** – multiplying a sequence by any constant
does not change the score.  The dominant term of the convolution for a
non‑negative sequence is the centre element  

    (a * a)[n‑1] = Σ_i a_i a_{n‑1‑i} .

If we choose a geometric (exponential) decay  

    a_i = r**i ,   0 < r < 1 ,

then for large length *n* :

*   Σ_i a_i = (1‑rⁿ)/(1‑r)  ≈  n·(1‑e^{‑c})/c   with  r = 1‑c/n,
*   max(conv) ≈ n·r^{n‑1}   ≈ n·e^{‑c} ,

and the score becomes  

    score(c) ≈ 2·e^{‑c}·c² / (1‑e^{‑c})² .

The function `score(c)` decreases when *c* grows, so any constant *c* (e.g.
c = 5 … 10) already gives a score far below the target 1.503 for the
current length (≈ 2000).  The algorithm therefore:

1.  Takes a few lengths (the known best length, half of it and twice it).
2.  Scans a set of *c*‑values, builds the geometric sequence
    `a_i = (1‑c/n)**i`, evaluates it and keeps the best one.
3.  Returns the best sequence found before the time budget expires.

The method needs only a few hundred evaluations (each convolution is

import math
import numpy as np

def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """

    a_i = (1 - c/n)^i for several lengths and several values of c.

    deadline = time.time() + budget_s - 0.5   # safety margin
