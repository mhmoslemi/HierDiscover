import numpy as np
import time

def gradient_descent_step(a, lambd, step):
    n = a.shape[0]
    b = np.convolve(a, a)  # length 2n-1
    b_max = b.max()
    # Stabilize softmax exponent
    exp_terms = np.exp(lambd * (b - b_max))
    w = exp_terms / exp_terms.sum()  # shape 2n-1
    # correlation a * w
    corr = np.correlate(a, w, mode='full')
    start = len(b) - 1
    conv_term = corr[start:start + n]
    grad = conv_term + a
    a_new = a - step * grad
    a_new = np.maximum(a_new, 0.0)
    # renormalize sum to sqrt(2n)
    target = np.sqrt(2.0 * n)
    s = a_new.sum()
    if s > 0:
        a_new *= target / s
    else:
        # if all zero, reinitialize uniform
        a_new = np.full(n, target / n)
    return a_new, b_max

The program implements a simple yet effective optimisation loop that directly attacks the quantity we want to minimise  

\[
\Phi(a)=\frac{2\,n\; \max (a\star a)}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a` is the non‑negative step‑function, `n=len(a)` and `⋆` denotes the (full) convolution.
Because the objective is *scale invariant* we fix the ℓ₁‑norm of the vector to the
standard value `sqrt(2·n)`.  
The only source of non‑convexity is the `max` operator.  We replace it by a smooth
approximation (soft‑max) and perform projected gradient descent on the resulting
smooth function.  After each gradient step we

* clip negative values,
* renormalise to the prescribed ℓ₁‑norm,
* occasionally add a tiny random jitter to escape plateaus, and
* restart from a fresh random point if the search stagnates.

The gradient of the soft‑max of the convolution can be written in closed form
using a single correlation, so each iteration costs only two FFT‑based
convolutions (`np.convolve` / `np.correlate`).  The loop runs until the allocated
time expires (default ≈ 1000 s) and returns the best sequence encountered.

The method is completely self‑contained, uses only NumPy and the supplied
`evaluate_sequence` routine, and respects the requirement that all coefficients
are non‑negative.

"""Gradient‑descent optimiser for the max‑convolution bound.

The algorithm works with a fixed L1‑norm `sqrt(2·n)` (the normalisation used in
the original challenge).  It replaces the non‑smooth `max(b)` in the objective
by a soft‑max with a temperature that grows during the run, computes the exact
gradient (which involves a single correlation), takes a projected gradient step
and periodically injects a tiny random perturbation.  The best sequence found
within the time budget is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: one projected gradient step on the smooth approximation of max(b)
# ----------------------------------------------------------------------
def _smooth_max_step(a: np.ndarray,
                     lam: float,
                     step: float,
                     target_sum: float) -> tuple[np.ndarray, float]:
    """
    Perform a single descent step.

    Parameters
    ----------
    a : np.ndarray
        Current non‑negative coefficient vector (length n).
    lam : float
        Inverse temperature for the soft‑max (larger → tighter approximation).
    step : float
        Gradient step size.
    target_sum : float
        Desired ℓ₁‑norm (equals sqrt(2·n)).

    Returns
    -------
    a_new : np.ndarray
        Updated coefficient vector (still non‑negative).
    max_b : float
        Maximum value of the (full) convolution a⋆a after the update.
    """
    n = a.shape[0]

    # Full convolution a⋆a  (length 2n‑1)
    b = np.convolve(a, a)

    # --- soft‑max over b -------------------------------------------------
    b_max = b.max()
    # stable exponentiation
    exp_terms = np.exp(lam * (b - b_max))
    w = exp_terms / exp_terms.sum()                     # shape (2n‑1)

    # --- gradient of the smooth max --------------------------------------
    # correlation = Σ_i a_i * w_{i+j} for all shifts j
    corr = np.correlate(a, w, mode='full')
    start = len(b) - 1                                   # index of zero shift
    conv_term = corr[start:start + n]                    # length n

    # grad_J = conv_term + a   (see derivation in the analysis)
    grad = conv_term + a

    # --- projected gradient step -----------------------------------------
    a_new = a - step * grad
    a_new = np.maximum(a_new, 0.0)                       # enforce non‑negativity

    # renormalise to the prescribed ℓ₁‑norm
    s = a_new.sum()
    if s > 0.0:
        a_new *= target_sum / s
    else:
        # All entries vanished – fall back to a tiny uniform vector
        a_new = np.full(n, target_sum / n)

    # recompute max(b) for bookkeeping (the norm of a has not changed)
    max_b = np.convolve(a_new, a_new).max()
    return a_new, max_b
