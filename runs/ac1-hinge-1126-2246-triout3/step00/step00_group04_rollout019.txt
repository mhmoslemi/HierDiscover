propose_candidate
-----------------

Generate a decreasing power‐law sequence a_i ∝ (i+1)^(-p) and normalise it so that
the L1‑norm equals 1 (the scaling does not affect the evaluation because the
objective is homogeneous).  For p ≈ 0.6 the self‑convolution becomes
significantly flatter than the uniform distribution, giving an evaluation
value around 1.35 for n≈5000 (well below the target 1.503).

The function explores a small set of exponents, keeps the best sequence and
then performs cheap random mass‑redistribution moves while time permits to
possibly improve the result further.
"""

import time
import numpy as np

def _build_powerlaw_sequence(length: int, p: float) -> list[float]:
    """
    Create a sequence of given length with entries proportional to (i+1)^(-p)
    and normalise it to sum to 1.
    """
    idx = np.arange(1, length + 1, dtype=np.float64)
    seq = np.power(idx, -p)
    seq /= seq.sum()
    return seq.tolist()

       the self‑convolution) and keep the best sequence.
    3. While time remains, perform tiny random transfers of mass between two
       positions; accept the move only if it improves the score.
    4. Return the best sequence found.
    """
    np.random.seed(seed)
