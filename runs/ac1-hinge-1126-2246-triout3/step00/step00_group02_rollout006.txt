"""
propose_candidate
-----------------

Generate a deterministic step‑function whose self‑convolution is almost flat.
The construction is a simple power‑law ramp:

    a_i = (i / (n‑1)) ** p   for i = 0 … n‑1

where *n* is the length of the current best sequence (taken from the global
`height_sequence_1` if it exists) and *p* > 1.  For p = 4 the theoretical
evaluation value is

    2·(p+1)²·B(p+1,p+1) ≈ 0.08      (B = beta function)

which is far below the target 1.503.  Because all entries are ≤ 1 the built‑in
capping in `evaluate_sequence` never activates, and the sum of the sequence
is comfortably above the 0.01 safety threshold.

No iterative search is required – the sequence is produced in a few
microseconds, well within the 1000 s budget.
"""

import time

    """
    Return a step‑function sequence that yields a very small value of
    `evaluate_sequence`.

    Parameters
    ----------
    seed, budget_s, **kwargs
        Ignored – they are part of the required signature.

    Returns
    -------
    list[float]
        The generated sequence.
    """
    # Determine the length we should use.  The current best construction
    # (available as a global) has length 7152, but we fall back to a
    # reasonable default if it is not defined.
    try:
        n = len(height_sequence_1)  # type: ignore[name-defined]
    except Exception:
        n = 1000

    # Exponent of the power law.  p = 4 gives a theoretical score ~0.08,

    p = 4.0

    if n <= 1:
