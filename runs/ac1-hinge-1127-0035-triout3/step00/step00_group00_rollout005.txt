def compute_max_conv(arr):
    n = len(arr)
    size = 1 << (int(np.ceil(np.log2(2*n-1))))
    ft = np.fft.rfft(arr, size)
    conv = np.fft.irfft(ft * ft, size)
    conv = conv[:2*n-1]
    return conv.max()

def project_simplex(v):
    # Using algorithm from Duchi et al.
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.nonzero(u - cssv / np.arange(1, n+1) > 0)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w
```

def compute_conv_max(a):
    n = len(a)
    size = 1 << ((2*n-1).bit_length())
    # pad a to size
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A*A, n=size)
    conv = conv[:2*n-1]
    max_val = conv.max()
    k_max = conv.argmax()
    return max_val, k_max, conv

Linear‑growth step function.

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

which is invariant under a global scaling of the sequence.
For a sequence a_i that grows linearly,
    a_i = (i + 1)          (i = 0 … n‑1)

the convolution at the centre (k = n‑1) can be computed in closed form:
    max(conv) = n (n + 1) (n + 2) / 6

and the score becomes
    score = (4/3) * (n + 2) / (n + 1)  →  4/3  (≈ 1.333)

as n → ∞.  This is well below the target 1.503, so a simple linear
sequence already beats the current best bound.

The implementation below builds a linear sequence of length N,
scaled so that the largest entry is exactly 1000 (the limit enforced
