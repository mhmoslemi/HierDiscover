Uniform step sequence generator.

The evaluation function
    E(a) = 2 * n * max(conv(a, a)) / (sum(a))**2
satisfies a simple inequality for any non‑negative list `a` of length `n`:

    max(conv(a, a)) ≥ sum_i a_i**2 ≥ (sum_i a_i)**2 / n

Hence  E(a) ≥ 2, with equality iff all entries are equal
(i.e. a uniform step function).  This is a provable optimum, so the
best possible score is exactly 2.  The algorithm therefore returns a
uniform sequence of the same length as the previously discovered
