The idea:
- Build a first block of length L with height v (e.g., 1.0). Its autocorrelation
  provides the maximal convolution value M = L*v^2.
- Add a second block of height e (< v) with length m such that e^2*m <= M.
  This guarantees that the addition does not increase the maximal
  convolution value.
- The second block increases the sum of the sequence while keeping the
  maximum convolution unchanged, thereby decreasing the evaluation
  metric 2*n*max_b/(sum^2).

We try several values of e and keep the sequence with the smallest
evaluation score observed within the time budget.
"""

import time
import numpy as np

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    # Use a deterministic random generator for possible random variations.
    np.random.seed(seed)
    deadline = time.time() + budget_s - 5.0  # keep a small margin

    # Base block parameters
    L = 1000                     # length of the first block
    v = 1.0                      # height of the first block

    best_seq = None

"""Two‑block construction that lowers the evaluation metric.

We create a first block of length L with height v (here v = 1).  
Its autocorrelation gives the maximal convolution value  

    M = L * v**2 .

A second block of height e (< v) and length m is appended.  
If we enforce  

    e**2 * m ≤ M   (i.e.  m ≤ L / e**2)

then the second block cannot increase the maximum of the convolution:
* its own autocorrelation never exceeds M,
* the cross‑terms with the first block are at most v·e·min(L,m) ≤ M.

Thus the denominator (the sum of the sequence) grows while the numerator
remains unchanged, lowering  

    2 * n * max_b / (sum_a**2).

The evaluation value depends only on the ratio r = v/e :

    score = 2 * (1 + r**2) / (1 + r)**2 ,

which varies from 2 (r → 0 or ∞) down to 1 (r = 1).  By picking e close to
v we obtain scores just above 1, comfortably beating the target 1.503.

The function tries a handful of e‑values, keeps the best sequence observed
within the time budget, and returns it.
"""

import time
import numpy as np

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """Return a non‑negative height sequence with a low evaluation score.

    The algorithm builds a two‑block step function as described above.
    Several candidate heights for the second block are examined; the one
    yielding the smallest score is returned.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 5.0   # spare a few seconds for clean‑up

    # Parameters of the first (high) block.
    L = 1000          # length
    v = 1.0           # height

    best_seq = None
    best_score = float('inf')

    # scores near the theoretical optimum 1, while smaller values give
    # scores a bit larger – we try a range and keep the best.
