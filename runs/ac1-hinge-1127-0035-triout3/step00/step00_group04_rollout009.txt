"""
Propose a sequence of non‑negative heights that improves the current
upper bound (≈2.0) by using a simple analytically‑motivated construction.

The evaluation function can be rewritten as

    evaluate_sequence(a) = max_k (a * a)[k]

when the sequence a is normalised so that sum(a) = √(2 n) (n = len(a)).
Writing p_i = a_i / sum(a) gives a probability distribution (p_i ≥ 0,
∑p_i = 1) and

    evaluate_sequence(a) = 2 n·max_k (p * p)[k].

Hence we need to minimise the largest entry of the self‑convolution of a
probability vector.  For a discrete distribution on {0,…,n‑1} the linear
profile

        p_i ∝ i+1      (or any monotone affine transform)

has a closed‑form convolution whose peak equals

        max(p * p) = (2/3)·(n+2) / (n·(n+1))

and therefore

        evaluate_sequence = (4/3)·(n+2)/(n+1)  < 1.5   for all n ≥ 10.

Thus a simple linear‑increasing sequence already beats the target bound.
The function below builds that sequence (using the length of the
available `height_sequence_1` when possible), reports its score and
returns it.  No external files, network access or heavyweight optimisation
loops are required, keeping the runtime well within the 1000 s budget.
"""

import math
import time
import numpy as np


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Generate a sequence of heights whose self‑convolution peak is provably

    Parameters

    """
    start_time = time.time()
    # ------------------------------------------------------------------

    try:
        n = len(height_sequence_1)  # type: ignore[name-defined]

    total = n * (n + 1) / 2.0               # denominator of the linear profile
