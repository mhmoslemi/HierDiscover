"""
propose_candidate
-----------------

Generate a simple deterministic step‑function that is provably better than the
baseline constant (uniform) sequence.

Idea
----
For a sequence a = (1, 2, …, n) the convolution a∗a has its largest entry at
the centre (shift n‑1) and its value is

    M = Σ_{i=1}^n i·(n+1-i) = n·(n+1)·(n+2) / 6 .

The L¹‑norm is S = Σ_{i=1}^n i = n·(n+1)/2.
Hence the evaluation function (with the security checks applied) becomes

    f = 2·n·M / S² = 4·(n+2) / (3·(n+1)) → 4/3  ≈ 1.333…   as n → ∞.

Choosing n = 1000 respects the imposed cap of 1000 on individual
coefficients, yields f ≈ 1.334 which is well below the required 1.503
threshold.

The algorithm simply returns this “linear ramp” sequence.
"""

import numpy as np

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Return a linear ramp sequence a_i = i+1 (i = 0 … 999).

    The sequence length is 1000 (the maximum allowed without triggering the
    value‑capping security check).  Its expected evaluation score is about
    1.334, comfortably beating the target bound.
    """
    # Length limited to 1000 so that the maximum value (1000) does not get clipped.
    n = 1000
    sequence = list(range(1, n + 1))   # [1, 2, ..., 1000]

    expected_score = 4.0 * (n + 2) / (3.0 * (n + 1))

    return sequence
