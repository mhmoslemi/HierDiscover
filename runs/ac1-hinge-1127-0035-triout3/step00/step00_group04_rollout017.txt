For a fixed length `n` the value of the evaluation function depends only on

candidate, then refine around that exponent with a finer grid.  All work is
performed inside the time budget, and the best sequence found is returned.

The method is deterministic (apart from the optional random seed) and does
not use any closures, lambdas or file/network I/O, satisfying the contest
rules.

        if score < best_score:
            best_score, best_seq, best_p = score, seq, p
            print(f"[coarse] p = {p:.5f}  score = {score:.6f}")

    # --------------------------------------------------------------------
    # Fine search around the best exponent found so far
    # --------------------------------------------------------------------
    if best_p is not None:
        # explore a window of ±0.05 around the current best value
        p_low = max(0.5, best_p - 0.05)
        p_high = min(0.9, best_p + 0.05)
        fine_ps = np.linspace(p_low, p_high, 41)   # step ≈ 0.0025
        for p in fine_ps:
            if time.time() > deadline:
                break
            score, seq = evaluate_power_law(p)
            if score < best_score:
                best_score, best_seq, best_p = score, seq, p
                print(f"[fine]   p = {p:.5f}  score = {score:.6f}")

    # --------------------------------------------------------------------
    # Fallback – uniform sequence (guaranteed to be a valid answer)
    # --------------------------------------------------------------------
    if best_seq is None:
        best_seq = [1.0] * n
        best_score = evaluate_sequence(best_seq)
        print(f"[fallback] uniform sequence score = {best_score:.6f}")

    print(f"Best exponent p = {best_p:.6f} with final score = {best_score:.6f}")
    return best_seq
