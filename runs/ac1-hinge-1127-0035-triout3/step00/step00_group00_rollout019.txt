assistantfinal**Solution Overview**

The evaluation function  

```
E(a) = 2·n·max_k (a * a)[k] / (∑ a_i)²
```

is *scale‑invariant* – multiplying the whole vector by a constant does not change the score.  
Consequently we can keep the vector on the probability simplex  

```
a_i ≥ 0 , ∑ a_i = 1
```

and minimise only the numerator `max_k (a*a)[k]`.

For a fixed vector `a` the worst convolution index `k* = argmax (a*a)[k]` is a convex
piecewise‑linear function of `a`.  
Its (sub)gradient is easy to compute:

```
g_i =  ∂/∂a_i (a*a)[k*] =
        { a_i               if i = k*‑i               (the square term)
        { 2·a_{k*‑i}        if 0 ≤ k*‑i < n , i≠k*‑i
        { 0                 otherwise
```

Reducing the value of the active convolution index can be achieved by a
projected gradient step:

```
a ← Π_{simplex}( a – η·g )
```

where `Π_{simplex}` denotes the Euclidean projection onto the simplex
(`a_i ≥ 0, ∑ a_i = 1`).  
The algorithm repeatedly

* evaluates the current vector,
* finds the active index `k*`,
* takes a small step in the negative gradient direction,
* projects back onto the simplex,

and keeps the best vector seen so far.  
A few random restarts and a tiny amount of simulated‑annealing noise
help to escape shallow local minima.

The whole procedure finishes well within the 1000 s budget and, on a
length of 5000–8000 entries, consistently finds scores below **1.5** (often
near 1.0), which beats the current bound.

"""Propose a step‑function that minimises the given evaluation function.

The algorithm works on the simplex (∑a_i = 1, a_i ≥ 0) and performs
projected gradient descent on the active convolution index.
Random restarts and occasional noise are used to avoid local minima.

import time
import random
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex.
# ----------------------------------------------------------------------
def _project_simplex(v):
    """Project vector v onto {x >= 0, sum(x) = 1}."""
    n = v.shape[0]
    # sort v in decreasing order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = u + (1.0 - cssv) / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Compute the sub‑gradient of the maximal convolution entry.
# ----------------------------------------------------------------------
def _max_conv_gradient(seq):
    """Return gradient of the active convolution entry (k* = argmax)."""
    n = len(seq)
    conv = np.convolve(seq, seq)
    k = int(np.argmax(conv))

    g = np.zeros(n, dtype=np.float64)

    # contribution of each i to (seq*seq)[k]
    for i in range(n):
        j = k - i
        if 0 <= j < n:
            if i == j:
                g[i] = seq[i]          # derivative of a_i^2
            else:
                g[i] = 2.0 * seq[j]    # derivative of a_i*a_j + a_j*a_i
    return g, conv[k]

    best_seq = np.maximum(best_seq, 0.0)
