The arcsine density f(x)=1/√(x(1‑x)) on (0,1) satisfies

The resulting evaluation score 2·n·max(b)/(sum(a)²) is therefore very close to
the theoretical lower bound of 1 (the optimum for large n).

The routine builds such a sequence for a moderate length n (default 3000),
evaluates its score, and then performs a tiny stochastic hill‑climbing
refinement while time permits.  The final sequence is returned.
"""

import numpy as np
import time

    The function returns a list of floats ready for ``evaluate_sequence``.
    A small local search is performed inside the given time budget.
    """

    # 1.  Setup & parameters
    # ----------------------------------------------------------------------
    np.random.seed(seed)

    # safety margin before the hard timeout
    deadline = time.time() + budget_s - 0.5

    # length of the step function – large enough for a near‑optimal bound,
    # still cheap to convolve many times.
    n = 3000

    # ----------------------------------------------------------------------
    # 2.  Build the arcsine‑shaped base sequence

    # 3.  Initial evaluation
