The evaluation function is scale‑invariant:
    eval = 2·n·max(conv(a,a)) / (sum(a))² .

    eval(p) = 2·(p+1)²·(p!)² / (2p+1)! .

The algorithm:
  1. Try a few lengths (500–4000) and exponents (1‑5) and keep the best
     candidate according to `evaluate_sequence`.
  2. Optionally improve the best candidate with a tiny hill‑climbing
     routine that transfers a small amount of weight between two

  3. Return the best sequence found before the time budget expires.

All numbers are non‑negative and never exceed the 0‑1000 clamp of

        if delta <= 0:
            continue
        if curr_seq[i] - delta < 0:
            continue

        new_seq = curr_seq.copy()
        new_seq[i] -= delta
        new_seq[j] = min(1000.0, new_seq[j] + delta)  # keep within bound

        # keep the other entry non‑negative (it already is)
        try:
            new_score = evaluate_sequence(new_seq)
        except Exception:
            continue

        if new_score < curr_score:
            curr_seq, curr_score = new_seq, new_score
            if new_score < best_score:
                best_seq, best_score = new_seq, new_score
                print(f"Hill‑climb improved score to {best_score:.6f}")

    print(f"Returning best score {best_score:.6f} (length {len(best_seq)})")
    return best_seq
