"""
Simple analytic construction for the step‑function optimization problem.

The idea is to start from a uniform “core” of length n₀ with height

    c = sqrt(2/n₀)               # makes the core sum = sqrt(2·n₀)

Its self‑convolution attains the maximal value B₀ = n₀·c² = 2.
If we append an auxiliary block of the same length, but with a
height ε = c/2, then

    • the auxiliary self‑convolution gives M·ε² = n₀·c² = 2,
    • the cross‑terms give 2·n₀·c·ε = 2,
    • therefore the overall maximum of the convolution stays B = 2.

Choosing M = 4·n₀ (i.e. the auxiliary block is four times as long as the core)
makes the total sum three times larger while the maximum stays unchanged.
The evaluation function becomes

    2·n·B / S² = 20/18 ≈ 1.111…

which is well below the target bound 1.503.

The implementation builds exactly this construction (using the length of the
provided `height_sequence_1` if available) and returns the candidate list.
No iterative optimisation is required, so the function finishes instantly.
"""

import math
import time

def propose_candidate(seed: int = 42, budget_s: float = 900.0, **kwargs):
    """
    Build a step‑function sequence that provably yields a low score.

    Parameters
    ----------
    seed : int, optional
        Random seed (not used – kept for compatibility with the framework).
    budget_s : float, optional
        Time budget in seconds.  The algorithm is O(1) and finishes far before

    kwargs : dict
        Ignored – present for API compatibility.

    Returns
    -------
    list[float]
        The constructed sequence of non‑negative heights.
    """

    # If the benchmark sequence ``height_sequence_1`` exists we reuse its
    # length; otherwise we fall back to a modest default (2000).
    # ------------------------------------------------------------------
    try:
