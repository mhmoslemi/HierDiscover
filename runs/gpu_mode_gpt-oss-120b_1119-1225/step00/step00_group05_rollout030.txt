The provided pytorch code does a certain multiplication: out = einsum('... i k d, ... j k d -> ... i j d', left, right). The semantics: For each pair (i,j), sum over k: left[..., i, k, d] * right[..., j, k, d] (here left and right have shape (B,N,N,C_hidden)). Actually left = left_proj(x) of shape (B,N,N, hidden_dim). So left[b,i,k,d] and right[b,j,k,d] multiplied elementwise across d, then summed over k (i.e., for each d) produce output with shape (B,N,N, hidden_dim). Actually the einsum as given yields shape (B,N,N, hidden_dim) because broadcasting for ... and d. Indeed we sum over k but maintain d.

Thus the operation is per batch: for each i and j, the output for each hidden dimension d = sum_{k} left[b,i,k,d] * right[b,j,k,d].

Thus the kernel performs a batched matrix multiplication over the K dimension (N) but with each output channel d having independent sum: basically it's a batched subspace (N,N, hidden_dim) where each hidden dimension is a separate matrix multiplication of left[b,:, :, d] (N x N) and right[b,:, :, d]^T? Let's see: left shape is (N,N,hidden), right shape is (N,N,hidden). But the contraction uses left[b,i,k,d] * right[b,j,k,d] sum over k; that can be seen as left[:,:,d] (N,N) times right[:,:,d]^T (N,N). Actually if you denote L_d = left[:,:,d] and R_d = right[:,:,d]. Then out[i,j,d] = sum_k L_d[i,k] * (R_d)[j,k] = L_d[i,:] dot R_d[j,:] (notice second index of R_d is k but j is first index). Usually matrix multiplication is L_d (i,k) times R_d^T (k,j) = sum_k L_d[i,k] * R_d^T[k,j] = sum_k L_d[i,k] * R_d[j,k]. Yes that's exactly out = L_d @ (R_d).T (or L_d @ R_d.T). So for each hidden dimension d, we need to compute a matrix product: (N,N) @ (N,N)^T => (N,N). So we have hidden_dim separate matrix multiplications.

Alternatively treat as: left and right are (B,N,N, hidden) and we compute out = sum_{k} left[...,i,k,:] * right[...,j,k,:] along k. Equivalent to matrix multiplication across N for each hidden dimension.

@triton.jit
def tri_mul_outgoing_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr, BLOCK_H: tl.constexpr
):
    """
    Triton kernel for TriMul outgoing contraction:
    Computes out[b,i,j,d] = sum_k left[b,i,k,d] * right[b,j,k,d]
    for each batch b, sequence indices i,j and hidden dim d.
    """

    pid_b = tl.program_id(0)
    pid_i = tl.program_id(1)
    pid_j = tl.program_id(2)

    # Compute offsets for i and j blocks
    i_offset = pid_i * BLOCK_M
    j_offset = pid_j * BLOCK_N

    # Range vectors
    i_range = i_offset + tl.arange(0, BLOCK_M)
    j_range = j_offset + tl.arange(0, BLOCK_N)

    # Masks for out-of-bounds i/j
    mask_i = i_range < N
    mask_j = j_range < N

    # Loop over hidden dimension groups
    d_start = 0
    while d_start < H:
        # Hidden indices for this block
        d_range = d_start + tl.arange(0, BLOCK_H)
        mask_d = d_range < H

        # Initialize accumulator for all (i,j) in the block and hidden in block
        acc = tl.zeros((BLOCK_M, BLOCK_N, BLOCK_H), dtype=tl.float32)

        # Loop over K dimension
        k_start = 0
        while k_start < N:
            k_range = k_start + tl.arange(0, BLOCK_K)

            mask_k = k_range < N

            # Compute masks for left and right loads
            mask_left = mask_i[:, None, None] & mask_k[None, :, None] & mask_d[None, None, :]
            mask_right = mask_j[None, :, None] & mask_k[:, None, None] & mask_d[None, None, :]

            # Pointers
            left_ptrs = left_ptr +\
                pid_b * stride_left_b +\
                i_range[:, None, None] * stride_left_i +\
                k_range[None, :, None] * stride_left_k +\
                d_range[None, None, :] * stride_left_h

            right_ptrs = right_ptr +\
                pid_b * stride_right_b +\
                j_range[None, :, None] * stride_right_i +\
                k_range[:, None, None] * stride_right_k +\
                d_range[None, None, :] * stride_right_h

            # Load (fp16)
            left_tile = tl.load(left_ptrs, mask=mask_left, other=0.0)   # shape (BLOCK_M, BLOCK_K, BLOCK_H), dtype fp16
            right_tile = tl.load(right_ptrs, mask=mask_right, other=0.0) # shape (BLOCK_K, BLOCK_N, BLOCK_H), dtype fp16

            # Compute dot product per hidden channel
            for d_idx in range(BLOCK_H):
                # Only compute if d_idx is valid; early exit
                # The dot will be zero for masked lanes anyway
                acc[:, :, d_idx] += tl.dot(left_tile[:, :, d_idx], right_tile[:, :, d_idx])

            # Increment k
            k_start += BLOCK_K

        # Store results for this hidden block
        # We need mask for i,j when storing
        mask_ij = mask_i[:, None] & mask_j[None, :]

        for d_idx in range(BLOCK_H):
            # Break if hidden dim out of range
            if (d_start + d_idx) >= H:
                break
            out_ptrs = out_ptr +\
                pid_b * stride_out_b +\
                i_range[:, None] * stride_out_i +\
                j_range[None, :] * stride_out_j +\
                (d_start + d_idx) * stride_out_h

            tl.store(out_ptrs, acc[:, :, d_idx], mask=mask_ij)

        d_start += BLOCK_H

"""
TriMul “outgoing” implementation.

The kernel computes the core contraction
    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
for each batch b, sequence indices i,j and hidden dimension d.
The surrounding operations (LayerNorms, Linear projections and gates)
are performed with PyTorch, while the O(N³·Cₕ) contraction is
executed in a custom Triton kernel that processes 32×32 tiles of the
(i,j) plane and 8 hidden channels at a time (BLOCK_H = 8).  All
computations inside the kernel use FP16 loads with FP32 accumulation
to keep the final result in float32 precision.
"""

import torch
import triton
import triton.language as tl


@triton.jit
def tri_mul_outgoing_kernel(
    left_ptr,                     # *FP16    [B, N, N, H]
    right_ptr,                    # *FP16    [B, N, N, H]
    out_ptr,                      # *FP32    [B, N, N, H]
    B, N, H,                      # runtime sizes
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr,        # tile size for i
    BLOCK_N: tl.constexpr,        # tile size for j
    BLOCK_K: tl.constexpr,        # tile size for k
    BLOCK_H: tl.constexpr,        # hidden‑channel tile size
):
    """ Compute out = Σ_k left[...,i,k,:] * right[...,j,k,:] """
    pid_b = tl.program_id(0)          # batch dimension
    pid_i = tl.program_id(1)          # i‑tile
    pid_j = tl.program_id(2)          # j‑tile

    # -------------------- tile offsets --------------------
    i_offset = pid_i * BLOCK_M
    j_offset = pid_j * BLOCK_N

    i = i_offset + tl.arange(0, BLOCK_M)    # (M)
    j = j_offset + tl.arange(0, BLOCK_N)    # (N)

    mask_i = i < N
    mask_j = j < N
    mask_ij = mask_i[:, None] & mask_j[None, :]

    # -------------------- loop over hidden dimension --------------------
    d_start = 0
    while d_start < H:
        d = d_start + tl.arange(0, BLOCK_H)        # (Hblk)
        mask_d = d < H

        # Accumulator for this hidden block: (M,N,Hblk) in fp32
        acc = tl.zeros((BLOCK_M, BLOCK_N, BLOCK_H), dtype=tl.float32)

        # -------------------- loop over K --------------------
        k_start = 0
        while k_start < N:
            k = k_start + tl.arange(0, BLOCK_K)    # (K)
            mask_k = k < N

            # masks for loads
            mask_left  = mask_i[:, None, None] & mask_k[None, :, None] & mask_d[None, None, :]
            mask_right = mask_j[None, :, None] & mask_k[:, None, None] & mask_d[None, None, :]

            # pointers for left tile  (i,k,d)
            left_ptrs = (
                left_ptr
                + pid_b * stride_left_b
                + i[:, None, None] * stride_left_i
                + k[None, :, None] * stride_left_k
                + d[None, None, :] * stride_left_h
            )
            # pointers for right tile (k,j,d) – note the transposed layout
            right_ptrs = (
                right_ptr
                + pid_b * stride_right_b
                + j[None, :, None] * stride_right_i      # j controls the second dimension
                + k[:, None, None] * stride_right_k
                + d[None, None, :] * stride_right_h
            )

            # Load tiles (FP16). Out‑of‑bounds entries are zeroed.
            left_tile  = tl.load(left_ptrs,  mask=mask_left,  other=0.0)   # (M,K,Hblk)
            right_tile = tl.load(right_ptrs, mask=mask_right, other=0.0)   # (K,N,Hblk)

            # Perform a dot‑product for each hidden channel in the block
            for d_idx in range(BLOCK_H):
                # The mask guarantees that invalid ``d`` rows are zero,
                # so the dot for those channels is a no‑op.
                acc[:, :, d_idx] += tl.dot(left_tile[:, :, d_idx],
                                           right_tile[:, :, d_idx])
            k_start += BLOCK_K

        # -------------------- store the result for this hidden block --------------------
        for d_idx in range(BLOCK_H):
            # Guard against writing past the hidden dimension
            if (d_start + d_idx) >= H:
                break
            out_ptrs = (
                out_ptr
                + pid_b * stride_out_b
                + i[:, None] * stride_out_i
                + j[None, :] * stride_out_j
                + (d_start + d_idx) * stride_out_h
            )
            tl.store(out_ptrs, acc[:, :, d_idx], mask=mask_ij)

        d_start += BLOCK_H


def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul module.
    Args:
        data = (input_tensor, mask_tensor, weights_dict, config_dict)
            input_tensor : torch.Tensor (B, N, N, C)
            mask_tensor  : torch.Tensor (B, N, N) or None
            weights_dict : dict of model weights
            config_dict  : dict with keys "dim" and "hidden_dim"
    Returns:
        torch.Tensor of shape (B, N, N, C)  (float32)
    """
    input_tensor, mask_tensor, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    B, N, _, _ = input_tensor.shape

    # ------------------------------------------------------------------
    # 1) Input LayerNorm
    # ------------------------------------------------------------------
    x = torch.nn.functional.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ------------------------------------------------------------------
    # 2) Linear projections (no bias)
    # ------------------------------------------------------------------
    left  = torch.nn.functional.linear(x, weights["left_proj.weight"])
    right = torch.nn.functional.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3) Optional mask
    # ------------------------------------------------------------------
    if mask_tensor is not None:
        mask = mask_tensor.to(dtype).unsqueeze(-1)          # (B,N,N,1)
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4) Gates (sigmoid)
    # ------------------------------------------------------------------
    left_gate  = torch.nn.functional.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate   = torch.nn.functional.linear(x, weights["out_gate.weight"]).sigmoid()

    # ------------------------------------------------------------------
    # 5) Apply gates
    # ------------------------------------------------------------------
    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 6) Cast to fp16 for the heavy contraction
    # ------------------------------------------------------------------
    left_fp16  = left.to(torch.float16).contiguous()
    right_fp16 = right.to(torch.float16).contiguous()

    # Output buffer (float32, same layout as left/right)
    out = torch.empty_like(left_fp16, dtype=torch.float32, device=device)

    # ------------------------------------------------------------------
    # 7) Triton kernel launch (contraction)
    # ------------------------------------------------------------------
    # Strides are expressed in *elements* (not bytes)
    stride_l_b, stride_l_i, stride_l_k, stride_l_h = left_fp16.stride()
    stride_r_b, stride_r_i, stride_r_k, stride_r_h = right_fp16.stride()
    stride_o_b, stride_o_i, stride_o_j, stride_o_h = out.stride()

    # Tile sizes – chosen to fit comfortably in registers on an H100
    BLOCK_M = 32
    BLOCK_N = 32
    BLOCK_K = 32
    BLOCK_H = 8   # number of hidden channels processed together

    grid = (B,
            (N + BLOCK_M - 1) // BLOCK_M,
            (N + BLOCK_N - 1) // BLOCK_N)

    tri_mul_outgoing_kernel[grid](
        left_fp16,
        right_fp16,
        out,
        B, N, hidden_dim,
        stride_l_b, stride_l_i, stride_l_k, stride_l_h,
        stride_r_b, stride_r_i, stride_r_k, stride_r_h,
        stride_o_b, stride_o_i, stride_o_j, stride_o_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        BLOCK_H=BLOCK_H,
    )

    # ------------------------------------------------------------------
    # 8) Output LayerNorm over the hidden dimension
    # ------------------------------------------------------------------
    out_norm = torch.nn.functional.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )

    # ------------------------------------------------------------------
    # 9) Apply the final gate and project back to the original dim
    # ------------------------------------------------------------------
    out_norm = out_norm * out_gate.unsqueeze(-1)          # (B,N,N,H)
    output = torch.nn.functional.linear(out_norm, weights["to_out.weight"])

    return output
