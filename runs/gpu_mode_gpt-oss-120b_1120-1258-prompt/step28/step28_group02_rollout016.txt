Implementation details of fused projection+gate kernel:

- Input: x_norm (R, dim) half.
- Weight matrices: left_proj, right_proj, left_gate, right_gate, out_gate: each (H, dim) half.
- mask (optional) shape (R) half.

- Output: left, right, out_gate with shape [B, H, N, N] half.

Algorithm:

For each row r in [0,R):
    load x_norm vector (dim) as half.
    For each hidden block of size BLOCK_H:
        compute left_proj dot x_norm -> left_acc (FP32)
        compute right_proj dot x_norm -> right_acc (FP32)
        compute left_gate dot x_norm -> left_gate_acc (FP32)
        compute right_gate dot x_norm -> right_gate_acc (FP32)
        compute out_gate dot x_norm -> out_gate_acc (FP32)
    After processing whole dim:
        left_gate_sig = sigmoid(left_gate_acc)
        right_gate_sig = sigmoid(right_gate_acc)
        out_gate_sig = sigmoid(out_gate_acc)
        left = left_acc * left_gate_sig
        right = right_acc * right_gate_sig
        if mask: left *= mask, right *= mask.
        store left and right (FP16) and out_gate (FP16) to appropriate tensors.

Implementation: we use loops over dim in blocks of BLOCK_D (e.g., 32 or 64). For each block we load x_norm tile and weight tiles for each projection/gate.

We need to be careful about aligning memory loads for weight. We store weight matrices in row-major: shape (H, dim). So weight offset: h*dim + d. For hidden block index `h_off` we have hidden offsets `offs_h = h_off + tl.arange(0, BLOCK_H)`. For each block we compute `w_ptr_proj = left_proj_weight + offs_h[:, None] * dim + offs_d[None, :]`. Since X is floats of shape [R, dim].

Thus we can compute per-row dot: partial = tl.sum(w_ptr_proj * x_tile[None, :], axis=1); accumulate.

Alternatively to use tl.dot to get more efficient code, we could compute `tl.dot(w_tile, x_tile[None, :].t())`, but sum may be okay.

Now we need to compute left, right, out_gate into output buffers.

We'll also output left_gate and right_gate after sigmoid? We are applying them already.

Thus after final loop for H-block, we have left_acc and right_acc per hidden block.

But we need to store left and right as half.

Thus after final computation, we call out: left_fp16 = left_acc.to(tl.float16) * mask * left_gate_sig (converted to half). Similarly for right.

Thus we need the left_gate_sig and right_gate_sig at per hidden element.

Implementation details: The mask is per row (R) (0/1). We'll load mask per row: mask_val = tl.load(mask_ptr + offs_r) if HAS_MASK else 1.0.

Since we will multiply left and right by mask after computing them and gating, we can apply mask as factor in store.

Potential concerns:

- The weight matrices for left_proj, right_proj, left_gate, right_gate, out_gate each must be loaded many times for each row. Since R may be huge (up to 1M), and H =128, we could think of computing per tile of hidden dimension to use registers for weights.

- For each hidden block, we load weight tile per each row and compute dot product with same x_norm tile. This can be computationally heavy but we have limited memory.

- Possibly the kernel can be vectorized across rows: each program processes multiple rows (BLOCK_R) to amortize weight loading across rows. Then we can load weight tile once per block and reuse across rows within a program.

Thus we design kernel with a block of ROWS (BLOCK_R) and a block of hidden dimension (BLOCK_H). This matches split_fuse_gate earlier.

Thus we can reuse pattern from split_fuse_gate: previously, they loaded proj (R,5*H) for each row, meaning weight accumulation for all hidden dims already pre computed; they just read into TE. Our fused kernel needs to compute these projections.

"""
Outgoing TriMul (AlphaFold‑3) – fast forward‑only implementation.

The forward pass is expressed with three highly‑fused Triton kernels:

1️⃣ Row‑wise LayerNorm (FP32 → FP16).  Reduces the input tensor
    from [B,N,N,dim] → [R,dim] where R = B·N·N.

2️⃣ `proj_gate_fused_kernel`:
   * Computes the five linear projections (left, right,
     left_gate, right_gate, out_gate) in a single pass over the
     normalized input.
   * Applies the optional pair‑wise mask and the three sigmoid‑gates.
   * Writes the three tensors `left`, `right`, `out_gate` in the
     layout required for the subsequent batched GEMM
     ([B, H, N, N]).

3️⃣ `final_fused_kernel`:
   * First computes per‑pair (b,i,j) mean/variance of the contracted
     tensor `out = left @ rightᵀ`.
   * Applies the second LayerNorm (`to_out_norm`), multiplies by the
     `out_gate`, and projects to the output dimension with the final
     linear weight (`to_out.weight`).
   * Writes the result directly in float32 shape [B,N,N,dim].

All kernels are written for Triton 3.3.1 and target an NVIDIA H100.
Only the forward pass is implemented (no gradients)."""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

# ----------------------------------------------------------------------
# 1️⃣ Row‑wise LayerNorm (FP32 → FP16)
# ----------------------------------------------------------------------
@triton.jit
def layernorm_kernel(
    x_ptr,  # [R, dim] FP32
    y_ptr,  # [R, dim] FP16
    w_ptr,  # [dim]   FP32 (γ)
    b_ptr,  # [dim]   FP32 (β)
    rows,   # total number of rows R (scalar)
    dim,    # channel dimension (scalar)
    eps,    # epsilon (scalar)
    BLOCK_M: tl.constexpr,   # rows per program
    BLOCK_D: tl.constexpr,   # tile along dim
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)           # [BLOCK_M]
    mask_m = offs_m < rows

    # ---------- mean / variance (pass 1) ----------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    for d_off in range(0, dim, BLOCK_D):
        offs_d = d_off + tl.arange(0, BLOCK_D)           # [BLOCK_D]
        mask_d = offs_d < dim

        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)        # [BLOCK_M, BLOCK_D]

        sum_val += tl.sum(vals, axis=1)                  # [BLOCK_M]
        sum_sq  += tl.sum(vals * vals, axis=1)           # [BLOCK_M]

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)

    # ---------- normalization (pass 2) ----------
    for d_off in range(0, dim, BLOCK_D):
        offs_d = d_off + tl.arange(0, BLOCK_D)           # [BLOCK_D]
        mask_d = offs_d < dim

        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)        # [BLOCK_M, BLOCK_D]

        norm = (vals - mean[:, None]) * rstd[:, None]

        gamma = tl.load(w_ptr + offs_d, mask=mask_d, other=0.0)   # FP32
        beta  = tl.load(b_ptr + offs_d, mask=mask_d, other=0.0)   # FP32

        out = norm * gamma[None, :] + beta[None, :]                # FP32
        tl.store(y_ptr + offs_m[:, None] * dim + offs_d[None, :],
                 out.to(tl.float16),
                 mask=mask_m[:, None] & mask_d[None, :])

# ----------------------------------------------------------------------
# 2️⃣ Fused projection + gating (produces left, right, out_gate)
# ----------------------------------------------------------------------
@triton.jit
def proj_gate_fused_kernel(
    x_ptr,            # [R, dim]               FP16 (normed input)
    left_w_ptr,       # [H, dim]               FP16
    right_w_ptr,      # [H, dim]               FP16
    left_gate_w_ptr,  # [H, dim]               FP16
    right_gate_w_ptr, # [H, dim]               FP16
    out_gate_w_ptr,   # [H, dim]               FP16
    mask_ptr,         # [R]                    FP16 (optional)
    left_out_ptr,     # [B, H, N, N]           FP16
    right_out_ptr,    # [B, H, N, N]           FP16
    out_gate_out_ptr, # [B, H, N, N]           FP16
    R, H, N, dim,
    HAS_MASK: tl.constexpr,
    BLOCK_R: tl.constexpr,
    BLOCK_H: tl.constexpr,
    BLOCK_D: tl.constexpr,
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)          # [BLOCK_R]
    mask_r = offs_r < R

    # decode (b,i,k) from flat row index
    nn = N * N
    b = offs_r // nn
    rem = offs_r - b * nn
    i = rem // N
    k = rem - i * N

    # optional mask (scalar per row)
    if HAS_MASK:
        m_val = tl.load(mask_ptr + offs_r, mask=mask_r, other=1.0)   # [BLOCK_R]
        m_val = m_val[:, None]                                        # [BLOCK_R, 1]
    else:
        m_val = tl.full([BLOCK_R, 1], 1.0, dtype=tl.float16)

    hidden_stride = nn  # stride between hidden planes
    base = b * (H * hidden_stride) + i * N + k   # start offset for hidden plane 0

    # ------------------------------------------------------------------
    # Loop over hidden tiles
    # ------------------------------------------------------------------
    for h_off in range(0, H, BLOCK_H):
        offs_h = h_off + tl.arange(0, BLOCK_H)            # [BLOCK_H]
        mask_h = offs_h < H

        # accumulators for this hidden tile (FP32 for accuracy)
        left_acc      = tl.zeros([BLOCK_R, BLOCK_H], dtype=tl.float32)
        right_acc     = tl.zeros([BLOCK_R, BLOCK_H], dtype=tl.float32)
        left_gate_acc = tl.zeros([BLOCK_R, BLOCK_H], dtype=tl.float32)
        right_gate_acc= tl.zeros([BLOCK_R, BLOCK_H], dtype=tl.float32)
        out_gate_acc  = tl.zeros([BLOCK_R, BLOCK_H], dtype=tl.float32)

        # ------------------------------------------------------------------
        # Loop over input channel tiles
        # ------------------------------------------------------------------
        for d_off in range(0, dim, BLOCK_D):
            offs_d = d_off + tl.arange(0, BLOCK_D)        # [BLOCK_D]
            mask_d = offs_d < dim

            # load a tile of the normalized input (R x dim)
            x_tile = tl.load(
                x_ptr + offs_r[:, None] * dim + offs_d[None, :],
                mask=mask_r[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)                # [BLOCK_R, BLOCK_D]

            # load weight tiles (H x dim) – broadcast over rows
            w_left = tl.load(
                left_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                mask=mask_h[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)                # [BLOCK_H, BLOCK_D]
            w_right = tl.load(
                right_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                mask=mask_h[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)
            w_lgate = tl.load(
                left_gate_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                mask=mask_h[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)
            w_rgate = tl.load(
                right_gate_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                mask=mask_h[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)
            w_outgate = tl.load(
                out_gate_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                mask=mask_h[:, None] & mask_d[None, :],
                other=0.0).to(tl.float32)

            # contribution = Σ_d x[d] * w[h,d]
            # Broadcast to (BLOCK_R, BLOCK_H, BLOCK_D) and reduce over d
            left_acc      += tl.sum(x_tile[:, None, :] * w_left[None, :, :],    axis=2)
            right_acc     += tl.sum(x_tile[:, None, :] * w_right[None, :, :],   axis=2)
            left_gate_acc += tl.sum(x_tile[:, None, :] * w_lgate[None, :, :],   axis=2)
            right_gate_acc+= tl.sum(x_tile[:, None, :] * w_rgate[None, :, :],   axis=2)
            out_gate_acc  += tl.sum(x_tile[:, None, :] * w_outgate[None, :, :], axis=2)

        # --------------------------------------------------------------
        # Apply sigmoids and optional mask, then write outputs
        # --------------------------------------------------------------
        left_gate  = (1.0 / (1.0 + tl.exp(-left_gate_acc))).to(tl.float16)
        right_gate = (1.0 / (1.0 + tl.exp(-right_gate_acc))).to(tl.float16)
        out_gate   = (1.0 / (1.0 + tl.exp(-out_gate_acc))).to(tl.float16)

        left  = left_acc.to(tl.float16)  * left_gate  * m_val
        right = right_acc.to(tl.float16) * right_gate * m_val
        og    = out_gate                                            # already FP16

        dst = base[:, None] + offs_h[None, :] * hidden_stride      # [BLOCK_R, BLOCK_H]

        tl.store(left_out_ptr + dst,
                 left,
                 mask=mask_r[:, None] & mask_h[None, :])
        tl.store(right_out_ptr + dst,
                 right,
                 mask=mask_r[:, None] & mask_h[None, :])
        tl.store(out_gate_out_ptr + dst,
                 og,
                 mask=mask_r[:, None] & mask_h[None, :])

# ----------------------------------------------------------------------
# 3️⃣ Final kernel – Row‑wise stats, LayerNorm, out_gate and projection
# ----------------------------------------------------------------------
@triton.jit
def final_fused_kernel(
    out_ptr,          # [B, H, N, N]  FP16 (contracted tensor)
    gate_ptr,         # [B, H, N, N]  FP16 (out_gate)
    ln_w_ptr,         # [H]           FP32 (to_out_norm.gamma)
    ln_b_ptr,         # [H]           FP32 (to_out_norm.beta)
    w_out_T_ptr,      # [H, dim]      FP16 (to_out.weightᵀ)
    out_final_ptr,    # [B, N, N, dim] FP32
    total_rows, H, N, dim,
    eps,
    BLOCK_M: tl.constexpr,   # rows per program
    BLOCK_K: tl.constexpr,   # hidden‑dim tile
    BLOCK_N: tl.constexpr,   # output‑dim tile
):
    pid_m = tl.program_id(0)   # row tile
    pid_n = tl.program_id(1)   # output‑dim tile

    row_start = pid_m * BLOCK_M
    col_start = pid_n * BLOCK_N

    offs_m = row_start + tl.arange(0, BLOCK_M)   # [BLOCK_M]
    offs_n = col_start + tl.arange(0, BLOCK_N)   # [BLOCK_N]

    mask_m = offs_m < total_rows
    mask_n = offs_n < dim

    nn = N * N
    b = offs_m // nn
    rem = offs_m - b * nn
    i = rem // N
    j = rem - i * N

    hidden_stride = nn
    base = b * (H * hidden_stride) + i * N + j   # start of hidden plane 0

    # ------------------------------------------------------------------
    # Pass 1 – compute mean / rsqrt‑variance over the hidden dim
    # ------------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    for h_off in range(0, H, BLOCK_K):
        offs_h = h_off + tl.arange(0, BLOCK_K)           # [BLOCK_K]
        mask_h = offs_h < H

        ptr = out_ptr + base[:, None] + offs_h[None, :] * hidden_stride
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_h[None, :],
                       other=0.0).to(tl.float32)          # [BLOCK_M, BLOCK_K]

        sum_val += tl.sum(vals, axis=1)                  # [BLOCK_M]
        sum_sq  += tl.sum(vals * vals, axis=1)           # [BLOCK_M]

    mu   = sum_val / H
    var  = sum_sq / H - mu * mu
    rstd = tl.rsqrt(var + eps)

    # ------------------------------------------------------------------
    # Pass 2 – LayerNorm, out_gate, final projection
    # ------------------------------------------------------------------
    acc = tl.zeros([BLOCK_M, BLOCK_N], dtype=tl.float32)

    for h_off in range(0, H, BLOCK_K):
        offs_h = h_off + tl.arange(0, BLOCK_K)           # [BLOCK_K]
        mask_h = offs_h < H

        # contracted tensor slice
        ptr_out = out_ptr + base[:, None] + offs_h[None, :] * hidden_stride
        vals_out = tl.load(ptr_out,
                           mask=mask_m[:, None] & mask_h[None, :],
                           other=0.0).to(tl.float32)        # [M, K]

        # LayerNorm parameters (γ,β) for this hidden slice
        gamma = tl.load(ln_w_ptr + offs_h, mask=mask_h, other=0.0)   # FP32
        beta  = tl.load(ln_b_ptr + offs_h, mask=mask_h, other=0.0)   # FP32

        # (out - μ) * rstd → γ· + β
        diff = (vals_out - mu[:, None]) * rstd[:, None]             # [M, K]
        norm = diff * gamma[None, :] + beta[None, :]                # [M, K]

        # gate
        ptr_gate = gate_ptr + base[:, None] + offs_h[None, :] * hidden_stride
        vals_gate = tl.load(ptr_gate,
                            mask=mask_m[:, None] & mask_h[None, :],
                            other=0.0).to(tl.float32)               # [M, K]

        gated = norm * vals_gate                                    # [M, K]
        gated_fp16 = gated.to(tl.float16)                           # fp16 for the dot

        # final projection slice (H × dim)
        w_ptr = w_out_T_ptr + offs_h[:, None] * dim + offs_n[None, :]   # [K, TILE_N]
        w_tile = tl.load(w_ptr,
                         mask=mask_h[:, None] & mask_n[None, :],
                         other=0.0)                                      # FP16

        acc += tl.dot(gated_fp16, w_tile).to(tl.float32)            # [M, N]

    # store result (flattened row index → [B,N,N,dim])
    dst_ptr = out_final_ptr + offs_m[:, None] * dim + offs_n[None, :]
    tl.store(dst_ptr,
             acc,
             mask=mask_m[:, None] & mask_n[None, :])

def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator (no gradients).

    Args:
        data (tuple): (input_tensor, mask_tensor, weights_dict, config_dict)
            - input_tensor : torch.Tensor [B, N, N, dim] (float32)
            - mask_tensor  : torch.Tensor [B, N, N] (bool/float) or None
            - weights_dict : mapping with keys
                "norm.weight", "norm.bias",
                "left_proj.weight", "right_proj.weight",
                "left_gate.weight", "right_gate.weight", "out_gate.weight",
                "to_out_norm.weight", "to_out_norm.bias",
                "to_out.weight"
              (all float32)
            - config_dict must contain
                "dim" (int), "hidden_dim" (int), "nomask" (bool, optional)

    Returns:
        torch.Tensor: [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    x, mask, w, cfg = data
    dim = cfg["dim"]
    hidden_dim = cfg["hidden_dim"]
    nomask = bool(cfg.get("nomask", True))
    eps = 1e-5
    device = x.device

    B, N, _, _ = x.shape
    R = B * N * N
    H = hidden_dim

    # ------------------------------------------------------------------
    # 1️⃣ Row‑wise LayerNorm (FP32 → FP16)
    # ------------------------------------------------------------------
    x_flat = x.reshape(R, dim).contiguous()                     # [R, dim] FP32
    x_norm = torch.empty(R, dim, dtype=torch.float16, device=device)

    BLOCK_M = 128
    BLOCK_D = 64
    grid_ln = (triton.cdiv(R, BLOCK_M),)
    layernorm_kernel[grid_ln](
        x_flat,
        x_norm,
        w["norm.weight"],
        w["norm.bias"],
        R,
        dim,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
        num_warps=8,
    )
    del x_flat

    # ------------------------------------------------------------------
    # 2️⃣ Fused projection + gating → left / right / out_gate
    # ------------------------------------------------------------------
    left      = torch.empty(B, H, N, N, dtype=torch.float16, device=device)
    right     = torch.empty(B, H, N, N, dtype=torch.float16, device=device)
    out_gate  = torch.empty(B, H, N, N, dtype=torch.float16, device=device)

    # cast all linear weights to FP16 once
    left_proj_w      = w["left_proj.weight"].to(torch.float16)
    right_proj_w     = w["right_proj.weight"].to(torch.float16)
    left_gate_w      = w["left_gate.weight"].to(torch.float16)
    right_gate_w     = w["right_gate.weight"].to(torch.float16)
    out_gate_w       = w["out_gate.weight"].to(torch.float16)

    if not nomask and mask is not None:
        mask_flat = mask.to(torch.float16).reshape(R).contiguous()
        HAS_MASK = 1
        mask_ptr = mask_flat
    else:
        HAS_MASK = 0
        mask_ptr = torch.empty(0, dtype=torch.float16, device=device)   # dummy

    BLOCK_R = 64
    BLOCK_H = 64
    BLOCK_D = 32
    grid_proj = (triton.cdiv(R, BLOCK_R),)
    proj_gate_fused_kernel[grid_proj](
        x_norm,
        left_proj_w,
        right_proj_w,
        left_gate_w,
        right_gate_w,
        out_gate_w,
        mask_ptr,
        left,
        right,
        out_gate,
        R,
        H,
        N,
        dim,
        HAS_MASK=HAS_MASK,
        BLOCK_R=BLOCK_R,
        BLOCK_H=BLOCK_H,
        BLOCK_D=BLOCK_D,
        num_warps=8,
    )
    del x_norm, left_proj_w, right_proj_w, left_gate_w, right_gate_w, out_gate_w, mask_ptr

    # ------------------------------------------------------------------
    # 3️⃣ Batched GEMM over the hidden dimension (cuBLAS)
    # ------------------------------------------------------------------
    left_mat  = left.view(B * H, N, N)                      # FP16
    right_mat = right.view(B * H, N, N)                     # FP16
    out = torch.bmm(left_mat, right_mat.transpose(1, 2))   # [B*H, N, N] FP16
    out = out.view(B, H, N, N)                             # [B, H, N, N] FP16

    # ------------------------------------------------------------------
    # 4️⃣ Fuse second LayerNorm, out_gate and final projection
    # ------------------------------------------------------------------
    w_out_T = w["to_out.weight"].to(torch.float16).t().contiguous()   # [H, dim]

    final = torch.empty(B, N, N, dim, dtype=torch.float32, device=device)

    BLOCK_M_OUT = 128   # rows per program
    BLOCK_K_OUT = 32    # hidden‑dim chunk
    BLOCK_N_OUT = 128   # output‑dim chunk

    grid_out = (
        triton.cdiv(R, BLOCK_M_OUT),
        triton.cdiv(dim, BLOCK_N_OUT),
    )
    final_fused_kernel[grid_out](
        out,
        out_gate,
        w["to_out_norm.weight"],   # γ  FP32
        w["to_out_norm.bias"],     # β  FP32
        w_out_T,
        final,
        R,
        H,
        N,
        dim,
        eps,
        BLOCK_M=BLOCK_M_OUT,
        BLOCK_K=BLOCK_K_OUT,
        BLOCK_N=BLOCK_N_OUT,
        num_warps=8,
    )
    return final
```
