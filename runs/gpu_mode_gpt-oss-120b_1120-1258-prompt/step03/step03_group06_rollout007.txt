    out_gate (all FP16).

3️⃣  Optional binary mask is applied to left/right **before** the sigmoid gates.

4️⃣  Sigmoid gates are applied element‑wise (still in FP16).

5️⃣  Triangular multiplicative update:
        out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    This is a batched matrix‑multiply per hidden channel, performed with
    torch.bmm on tensors of shape (B·H, N, N).
    To avoid an extra large permute‑reshape copy we compute the batch
    directly via a *torch.einsum* which internally tiles the reduction
    without materialising the transposed view.

6️⃣  Second LayerNorm + output‑gate are fused in a Triton kernel
    (`fused_layernorm_gate_kernel`).  The kernel:
        • computes mean/variance in FP32,
        • normalises, applies γ/β,
        • multiplies by the already‑sigmoid’ed out_gate,
        • stores the result in FP16.

7️⃣  Final linear projection (hidden → C) is a standard FP16 GEMM
    (torch.nn.functional.linear).  The result is cast back to FP32.

Only the fused LayerNorm+gate step is written in Triton – satisfying the
requirement that “part of the operations” be a custom kernel while letting
cuBLAS/Fused‑CUDA handle the heavy matrix multiplies.

The implementation avoids any explicit `torch.cuda.synchronize()` calls,
leveraging the default CUDA stream for asynchronous execution, which
reduces kernel launch overhead and improves overall latency.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ---------------------------------------------------------------
# Triton kernel: fused LayerNorm + output gate (both FP16 I/O)
# ---------------------------------------------------------------
@triton.jit
def fused_layernorm_gate_kernel(
    x_ptr,            # const   half* [rows, dim]   – input to normalize
    y_ptr,            #   mut   half* [rows, dim]   – output (norm·gate)
    weight_ptr,       # const float* [dim]          – γ
    bias_ptr,         # const float* [dim]          – β
    gate_ptr,         # const half*  [rows, dim]   – pre‑sigmoid’ed out_gate
    rows: tl.constexpr,
    dim: tl.constexpr,
    eps: tl.constexpr,
    BLOCK_M: tl.constexpr,   # rows per program
    BLOCK_D: tl.constexpr,   # dim‑wise tile size
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)        # [BLOCK_M]
    mask_m = offs_m < rows

    # ---------- first pass: per‑row mean / variance (FP32) ----------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)  # [BLOCK_D]
        mask_d = offs_d < dim
        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)      # [BLOCK_M, BLOCK_D]

        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)                        # 1/√(var+eps)

    # ---------- second pass: normalise, γ/β, gate ----------
    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim
        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)

        # normalisation
        norm = (vals - mean[:, None]) * rstd[:, None]          # (x-µ)/σ

        # γ and β (stored as FP32)
        w = tl.load(weight_ptr + offs_d, mask=mask_d, other=0.0)   # γ
        b = tl.load(bias_ptr   + offs_d, mask=mask_d, other=0.0)   # β
        out = norm * w[None, :] + b[None, :]                     # FP32

        # multiply by already‑sigmoid’ed out_gate (FP16 → FP32)
        gate = tl.load(gate_ptr + offs_m[:, None] * dim + offs_d[None, :],
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)
        out = out * gate

        # store FP16 result
        tl.store(y_ptr + offs_m[:, None] * dim + offs_d[None, :],
                 out.to(tl.float16),
                 mask=mask_m[:, None] & mask_d[None, :])


# ---------------------------------------------------------------
# Entry point – Triton‑accelerated forward pass of outgoing TriMul
# ---------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args
    ----
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, C]  (float32)
        - mask_tensor  : torch.Tensor [B, N, N]    (bool/float)
        - weights_dict : dict of model parameters (float32)
        - config_dict  : dict with keys:
            * dim          – input channel dimension C
            * hidden_dim   – projection dimension H
            * nomask       – True → ignore ``mask_tensor``
            * eps          – LayerNorm epsilon (optional)

    Returns
    -------
    torch.Tensor
        Output tensor [B, N, N, C] (float32) on the same CUDA device.
    """
    # ------------------------------------------------------------------
    # 0. unpack
    # ------------------------------------------------------------------
    inp, mask, weights, cfg = data
    device = inp.device
    dim = cfg["dim"]
    hidden = cfg["hidden_dim"]
    eps = cfg.get("eps", 1e-5)
    nomask = cfg.get("nomask", True)

    B, N, _, _ = inp.shape
    total_rows = B * N * N                                     # rows for flattening

    # ------------------------------------------------------------------
    # 1. Input LayerNorm (cuDNN) → FP16
    # ------------------------------------------------------------------
    # Normalise over the last dimension (=dim)
    x_norm = F.layer_norm(
        inp,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=eps,
    ).to(torch.half)                                            # (B,N,N,dim) FP16

    # ------------------------------------------------------------------
    # 2. Fused linear projections (+ gates) – single GEMM
    # ------------------------------------------------------------------
    # concatenate the five projection/gate weight matrices
    concat_w = torch.cat(
        [
            weights["left_proj.weight"],
            weights["right_proj.weight"],
            weights["left_gate.weight"],
            weights["right_gate.weight"],
            weights["out_gate.weight"],
        ],
        dim=0,
    ).half().contiguous()                                        # (5*H, C)

    # ------------------- linear -------------------
    proj = F.linear(x_norm, concat_w)                             # (B,N,N,5*H) FP16
    # split into the five tensors
    left_proj, right_proj, left_gate, right_gate, out_gate = torch.split(
        proj, hidden, dim=3
    )                                                            # each (B,N,N,H) FP16

    # ------------------- optional mask -------------------
    if not nomask:
        mask_fp16 = mask.unsqueeze(-1).to(inp.dtype).half()      # (B,N,N,1)
        left_proj = left_proj * mask_fp16
        right_proj = right_proj * mask_fp16

    # ------------------- sigmoid gates -------------------
    left_gate = torch.sigmoid(left_gate)                         # (B,N,N,H) FP16
    right_gate = torch.sigmoid(right_gate)                       # (B,N,N,H) FP16
    out_gate = torch.sigmoid(out_gate)                           # (B,N,N,H) FP16

    # ------------------- apply gates -------------------
    left = left_proj * left_gate                                 # (B,N,N,H) FP16
    right = right_proj * right_gate                              # (B,N,N,H) FP16

    # ------------------------------------------------------------------
    # 3. Triangular multiplicative update (batched matmul)
    # ------------------------------------------------------------------
    # Compute out[i,j,h] = Σ_k left[i,k,h] * right[j,k,h]
    # Using einsum avoids the extra permute‑reshape copy required for
    # a manual reshape → torch.bmm approach.
    out = torch.einsum('b i k h, b j k h -> b i j h', left, right)  # (B,N,N,H)

    # ------------------------------------------------------------------
    # 4. Second LayerNorm + output‑gate (fused Triton kernel)
    # ------------------------------------------------------------------
    # Flatten: (B·N·N, H)  –  each row will be normalised independently
    out_flat = out.view(-1, hidden).contiguous()                 # FP16
    out_gate_flat = out_gate.view(-1, hidden).contiguous()       # FP16 (already sigmoid)

    out_norm_gate = torch.empty_like(out_flat)                    # FP16 for result

    # Triton launch – tuning constants chosen for H100
    BLOCK_M = 128      # rows per program (tuned for large row counts)
    BLOCK_D = 32       # channel‑wise tile
    grid = (triton.cdiv(out_flat.shape[0], BLOCK_M),)

    fused_layernorm_gate_kernel[grid](
        out_flat,
        out_norm_gate,
        weights["to_out_norm.weight"],
        weights["to_out_norm.bias"],
        out_gate_flat,
        out_flat.shape[0],
        hidden,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
    )
    # No explicit torch.cuda.synchronize(); subsequent ops synchronize automatically.

    # ------------------------------------------------------------------
    # 5. Final projection back to `dim`
    # ------------------------------------------------------------------
    final_fp16 = F.linear(out_norm_gate,
                          weights["to_out.weight"].half())          # (R, dim) FP16
    final = final_fp16.view(B, N, N, dim).to(torch.float32)        # cast to FP32

    return final
```
