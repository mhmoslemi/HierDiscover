"""custom_kernel – highly‑optimized “outgoing” TriMul (AlphaFold‑3).

Algorithm
---------
1️⃣ Fast LayerNorm (torch‑C++ implementation) on the input tensor.
2️⃣ Fuse the five linear layers (left/right project, three gates) into a
   single half‑precision GEMM:  X_norm @ W_fused.T  →  [left_proj, left_gate,
   right_proj, right_gate, out_gate].
3️⃣ Apply the optional pair‑wise mask only to the two projection tensors,
   then fuse each projection with its sigmoid gate.
4️⃣ Triangular multiplicative update (the core of TriMul) using a single
   einsum `out = left · right` which internally maps to a batched GEMM.
5️⃣ Second LayerNorm + output‑gate are fused in a custom Triton kernel
   (`layernorm_gate_kernel`).  The kernel computes mean/variance in fp32,
   applies the affine transform, multiplies the pre‑computed output gate and
   writes the result in fp16.
6️⃣ Final linear projection back to the model dimension (half‑precision GEMM).

Only the second LayerNorm + gate is written in Triton; the rest uses
highly‑optimized PyTorch/CUDA kernels.  Memory traffic is minimized by
keeping the intermediate tensors in FP16 whenever possible and by avoiding
expensive `permute/contiguous` copies (the contraction is performed directly
with `einsum`)."""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton fused LayerNorm + element‑wise output gate (FP16 I/O, FP32 math)
# ----------------------------------------------------------------------
@triton.jit
def layernorm_gate_kernel(
    x_ptr,          # const half*   [total_rows, dim]   (input)
    gate_ptr,       # const half*   [total_rows, dim]   (sigmoid‑gate)
    y_ptr,          #       half*   [total_rows, dim]   (output)
    w_ptr,          # const float*  [dim]               (γ)
    b_ptr,          # const float*  [dim]               (β)
    total_rows,     # int
    dim: tl.constexpr,          # static (hidden_dim)
    eps: tl.constexpr,          # static
    BLOCK_M: tl.constexpr,      # rows per program
    BLOCK_D: tl.constexpr,      # columns per inner loop
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)
    mask_m = offs_m < total_rows

    # --------------------------------------------------------------
    # Pass 1 – compute mean and variance (FP32)
    # --------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim
        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)          # [BLOCK_M, BLOCK_D]

        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)                         # 1/√(var+eps)

    # --------------------------------------------------------------
    # Pass 2 – normalize, affine transform and multiply gate
    # --------------------------------------------------------------
    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim

        # load normalized input
        x = tl.load(x_ptr + offs_m[:, None] * dim + offs_d[None, :],
                    mask=mask_m[:, None] & mask_d[None, :],
                    other=0.0).to(tl.float32)

        # load gate (already sigmoid‑ed)
        g = tl.load(gate_ptr + offs_m[:, None] * dim + offs_d[None, :],
                    mask=mask_m[:, None] & mask_d[None, :],
                    other=0.0).to(tl.float32)

        norm = (x - mean[:, None]) * rstd[:, None]          # LayerNorm

        w = tl.load(w_ptr + offs_d, mask=mask_d, other=0.0) # γ
        b = tl.load(b_ptr + offs_d, mask=mask_d, other=0.0) # β

        out = norm * w[None, :] + b[None, :]                # affine
        out = out * g                                        # apply output‑gate

        tl.store(y_ptr + offs_m[:, None] * dim + offs_d[None, :],
                 out.to(tl.float16),
                 mask=mask_m[:, None] & mask_d[None, :])

        torch.split(proj, hidden, dim=1)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask (applied only to the two projection tensors)
    # ------------------------------------------------------------------
    if not nomask:
        mask_h = mask_tensor.view(-1, 1).to(dtype=torch.float16, device=device)  # [R,1]
        left_proj_raw  = left_proj_raw * mask_h
        right_proj_raw = right_proj_raw * mask_h

    # ------------------------------------------------------------------
    # 4️⃣ Fuse projection with its sigmoid gate
    # ------------------------------------------------------------------
    left  = left_proj_raw  * torch.sigmoid(left_gate_raw)   # [R, H] FP16
    right = right_proj_raw * torch.sigmoid(right_gate_raw) # [R, H] FP16
    out_gate = torch.sigmoid(out_gate_raw)                 # [R, H] FP16

    # ------------------------------------------------------------------
    # 5️⃣ Reshape for the triangular multiplicative update
    # ------------------------------------------------------------------
    left  = left.view(B, N, N, hidden)                     # [B,N,N,H]
    right = right.view(B, N, N, hidden)                    # [B,N,N,H]

    # ------------------------------------------------------------------
    # 6️⃣ Core TriMul:   out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    # ------------------------------------------------------------------
    # Using einsum avoids the costly permute+contiguous copies.
    out = torch.einsum('b i k d, b j k d -> b i j d', left, right)   # FP16

    # ------------------------------------------------------------------
    # 7️⃣ Second LayerNorm + output‑gate (fused Triton kernel)
    # ------------------------------------------------------------------
    out_flat      = out.view(-1, hidden)                     # [R, H] FP16
    out_gate_flat = out_gate.view(-1, hidden)                # [R, H] FP16
    out_norm_gated = torch.empty_like(out_flat)              # FP16 destination

    BLOCK_M = 256                # rows per program (tune for H100)
    BLOCK_D = 64                 # columns per inner loop (covers hidden dim)
    grid = (triton.cdiv(out_flat.shape[0], BLOCK_M),)

    layernorm_gate_kernel[grid](
        out_flat,
        out_gate_flat,
        out_norm_gated,
        weights["to_out_norm.weight"],
        weights["to_out_norm.bias"],
        out_flat.shape[0],
        hidden,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
    )
    torch.cuda.synchronize()

    # ------------------------------------------------------------------
    # 8️⃣ Final linear projection back to `dim`
    # ------------------------------------------------------------------
    final_fp16 = F.linear(out_norm_gated,
                          weights["to_out.weight"].to(dtype=torch.float16,
                                                      device=device))   # [R, dim] FP16

    final = final_fp16.view(B, N, N, dim).to(torch.float32)   # desired float32 output
    return final
```

**Explanation of key optimizations**

* **First LayerNorm** – delegated to PyTorch’s native CUDA implementation (highly tuned) while still obeying the “at least one Triton kernel” rule.
* **Fused linear‑gate** – a single half‑precision GEMM replaces five separate matmuls, cutting memory reads of the normalized tensor from five to one.
* **Mask handling** – applied only to the two projection tensors, avoiding unnecessary work on the gate tensors.
* **Triangular update** – performed with a single `einsum`, which maps internally to a batched GEMM (`bmm`) and completely eliminates the expensive `permute → contiguous → bmm → permute` sequence used in the reference implementation.
* **Second LayerNorm + gate** – combined in a custom Triton kernel that computes mean/variance in FP32, normalizes, applies the affine transform, multiplies by the pre‑computed output gate, and writes the result in FP16, thereby reducing an extra memory round‑trip.
* **Half‑precision throughout** – all heavy linear algebra is carried out in FP16, only the final result is cast back to FP32 as required by the API.
* **Block sizes** – `BLOCK_M=256` and `BLOCK_D=64` were chosen to maximise occupancy on H100 while keeping register pressure modest.

The final pipeline therefore minimizes memory traffic, kernel launch overhead, and makes full use of H100’s Tensor‑Core capabilities, comfortably targeting sub‑millisecond latency for the provided configurations.
