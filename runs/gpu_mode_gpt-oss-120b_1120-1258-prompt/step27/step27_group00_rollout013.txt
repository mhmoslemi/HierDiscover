First we must understand the operation. The code described is the forward pass from the reference PyTorch implementation: given input tensor [B, N, N, dim], do:

- x_norm = layernorm(x) with weight and bias.

- left, right = linear projections (dim->hidden_dim) for each, same as left_proj, right_proj.

- mask: [B,N,N] maybe None. left = left * mask, right = right * mask.

- left_gate = sigmoid(linear(x, left_gate_weight)), right_gate similar, out_gate similarly.

- left = left * left_gate, right = right * right_gate.

- einsum: out[b,i,j,:] = sum_k left[b,i,k,:] * right[b,j,k,:] (note i and j are both second dimension; left uses k dimension from i dimension of left, right uses k dimension from j dimension). This yields shape [B,N,N,hidden_dim] -> actually shape [B,N,N,hidden_dim] after sum over k dimension (size N). This is a batched N^3 operation.

- out = layernorm(out) (to_out_norm: per hidden_dim)

- out = out * out_gate

- out = linear(out, to_out.weight) shape [B,N,N,dim]

"""
Outgoing TriMul (AlphaFold‑3 style) – compact Triton + cuDNN/cuBLAS implementation
================================================================================

Algorithm
---------
1️⃣  Layer‑Norm over the last feature dimension of the pairwise tensor
    `x ∈ ℝ^{B×N×N×C}` using the cuDNN kernel (torch.nn.functional.layer_norm).

2️⃣  Fuse the five linear projections (left‑proj, right‑proj, left‑gate,
    right‑gate, out‑gate) into a single GEMM `R×C  ×  C×5H → R×5H`
    (R = B·N·N).  The weight matrix is built on‑the‑fly from the supplied
    model weights and is used in FP16.

3️⃣  Split the fused projection and apply the optional mask and sigmoid gates
    in one Triton kernel.  The kernel writes the three tensors
    `left, right, out_gate ∈ ℝ^{B×H×N×N}` (FP16) directly in the layout
    required by the next batched GEMM.

4️⃣  Core “einsum’’ `out[b,i,j,h] = Σₖ left[b,i,k,h]·right[b,j,k,h]`
    is carried out with a single batched GEMM (`torch.bmm`).

5️⃣  Second LayerNorm over the hidden dimension `H` (cuDNN),
    multiplication by `out_gate`, and the final linear projection
    (`H → C`) are performed with the highly‑optimised cuBLAS linear
    routine.  The result is reshaped to `[B, N, N, C]` and cast to
    `float32`.

Only the split+gate kernel is written in Triton – all heavy linear algebra
uses the vendor‑provided kernels, giving a fast, memory‑bandwidth‑aware
forward pass while keeping the implementation straightforward and fully
correct.

"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: split fused projection, apply mask and sigmoid gates
# ----------------------------------------------------------------------
@triton.jit
def split_fuse_gate_kernel(
    proj_ptr,       # [R, 5·H]  FP16 fused projection
    left_ptr,       # [B, H, N, N] FP16
    right_ptr,      # [B, H, N, N] FP16
    out_gate_ptr,   # [B, H, N, N] FP16
    mask_ptr,       # [R] FP16 (optional, broadcast over H)
    R, H, N,
    HAS_MASK: tl.constexpr,
    BLOCK_R: tl.constexpr,  # rows per program (e.g. 64)
    BLOCK_H: tl.constexpr,  # hidden dim per program (e.g. 128)
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)          # [BLOCK_R]
    mask_r = offs_r < R

    # decode flat index r = b·N·N + i·N + k
    nn = N * N
    b = offs_r // nn
    rem = offs_r - b * nn
    i = rem // N
    k = rem - i * N

    # optional mask (broadcast over H)
    if HAS_MASK:
        m = tl.load(mask_ptr + offs_r, mask=mask_r, other=1.0)   # [BLOCK_R]
        mask_val = m[:, None]                                    # broadcast over H
    else:
        mask_val = tl.full([BLOCK_R, 1], 1.0, dtype=tl.float16)

    # stride for each hidden plane inside the destination tensors
    hidden_stride = N * N
    # base offset for h = 0  (flattened view of [B, H, N, N])
    base_off = b * (H * hidden_stride) + i * N + k

    # iterate over hidden dimension
    for h_off in range(0, tl.cdiv(H, BLOCK_H)):
        offs_h = h_off * BLOCK_H + tl.arange(0, BLOCK_H)   # [BLOCK_H]
        mask_h = offs_h < H

        # view of the fused projection: [left | right | left_gate | right_gate | out_gate]
        proj_base = offs_r[:, None] * (5 * H) + offs_h[None, :]         # [BLOCK_R, BLOCK_H]

        left_raw = tl.load(proj_ptr + proj_base,
                           mask=mask_r[:, None] & mask_h[None, :],
                           other=0.0)
        right_raw = tl.load(proj_ptr + proj_base + H,
                            mask=mask_r[:, None] & mask_h[None, :],
                            other=0.0)
        left_gate_raw = tl.load(proj_ptr + proj_base + 2 * H,
                                mask=mask_r[:, None] & mask_h[None, :],
                                other=0.0)
        right_gate_raw = tl.load(proj_ptr + proj_base + 3 * H,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0)
        out_gate_raw = tl.load(proj_ptr + proj_base + 4 * H,
                               mask=mask_r[:, None] & mask_h[None, :],
                               other=0.0)

        # sigmoid in FP32 → cast back to FP16
        left_gate  = (1.0 / (1.0 + tl.exp(-left_gate_raw.to(tl.float32)))).to(tl.float16)
        right_gate = (1.0 / (1.0 + tl.exp(-right_gate_raw.to(tl.float32)))).to(tl.float16)
        out_gate   = (1.0 / (1.0 + tl.exp(-out_gate_raw.to(tl.float32)))).to(tl.float16)

        # apply mask and gates
        left  = left_raw  * mask_val * left_gate
        right = right_raw * mask_val * right_gate
        outg  = out_gate   # no mask on out_gate

        dst_off = base_off[:, None] + offs_h[None, :] * hidden_stride   # [BLOCK_R, BLOCK_H]

        tl.store(left_ptr + dst_off, left,
                 mask=mask_r[:, None] & mask_h[None, :])
        tl.store(right_ptr + dst_off, right,
                 mask=mask_r[:, None] & mask_h[None, :])
        tl.store(out_gate_ptr + dst_off, outg,
                 mask=mask_r[:, None] & mask_h[None, :])

    # ------------------------------------------------------------------

    out = torch.bmm(left_mat, right_mat.transpose(1, 2))   # [B·H, N, N] FP16
