The evaluation metric  

\[
\text{score}= \frac{2\;n\;\max (a*a)}{(\sum a)^2}
\]

has a simple analytic lower bound.  
For any non‑negative vector `a`

* \(\displaystyle \max (a*a)\ge b_0=\sum_i a_i^2\) (the centre of the self‑convolution)  
* By Cauchy‑Schwarz, \(\displaystyle \bigl(\sum_i a_i\bigr)^2\le n\sum_i a_i^2\).

Combining the two inequalities gives  

\[
\text{score}\;\ge\;2.
\]

Equality holds **iff** every entry of `a` is identical (a uniform step function).  
Therefore the optimal construction is a constant vector; any other shape cannot beat the score = 2.

The code below:

1. Builds a uniform sequence of the same length as the supplied `height_sequence_1`
   (or a safe default length if that variable is not present).  
2. Evaluates its score (should be exactly 2).  
3. Performs a very cheap random‑block perturbation loop inside the time budget,
   looking only for *numerical* improvements caused by floating‑point rounding.
   In practice the uniform sequence already attains the theoretical optimum, so
   the loop merely serves as safety‑net and progress reporting.
4. Returns the best sequence found.

This algorithm is O(n) in memory and runs instantly, guaranteeing a finite,
optimal result well within the 1000 s limit.

        factor = float(np.exp(rng.normal(0.0, 0.01)))
        candidate = best.copy()
        candidate[start:start + width] *= factor
        # enforce the problem’s hard bounds
        np.clip(candidate, 0.0, 1000.0, out=candidate)

        # exact evaluation (authoritative)
        score = float(evaluate_sequence(candidate.tolist()))
        if np.isfinite(score) and score < best_score - 1e-12:
            best = candidate
            best_score = score
            print(f"[improve] new best score={best_score:.12f}")

    print(f"[final] best score={best_score:.12f}")
    # Return a plain Python list of floats as required by the harness
    return [float(x) for x in best]
