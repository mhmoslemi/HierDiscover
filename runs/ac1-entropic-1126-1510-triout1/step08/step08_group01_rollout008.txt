assistantfinal**Solution Overview**

The optimiser searches for a non‑negative step function `a = (a₀,…,a_{n‑1})`
that minimises  

\[
\operatorname{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}\;,
\]

where `a*a` is the discrete self‑convolution.
The evaluation routine `evaluate_sequence` will finally be called on the
returned vector; we therefore normalise every candidate to
\(\sum a = \sqrt{2n}\) (the scale used in `evaluate_sequence`).

The programme consists of three stages:

1. **Broad sampling** – a diverse collection of analytic families
   (arcsine, triangular, exponential, Gaussian, Cauchy, symmetric / 
   asymmetric Beta) and random Dirichlet draws are generated for several
   lengths `n`.  Each vector is normalised to \(\sum a = 1\) and scored
   with the cheap surrogate  

   \[
   \hat s(a) = 2\,n\;\max (a*a)\;,
   \]

   which equals the true score after the final scaling.

2. **Multi‑phase smoothed optimisation** – the best few candidates are
   refined by *Adam* on a **smooth approximation** of the `max`
   functional.  
   For a fixed exponent `p ≥ 2`

   \[
   L_p(a)=\bigl(\sum_i (a*a)_i^{\,p}\bigr)^{1/p}
   \]

   satisfies \(L_p\!\downarrow\max_i (a*a)_i\) as \(p\!\to\!\infty\).
   Its gradient can be written in closed form using FFTs:

   \[
   \nabla L_p(a)=
   \frac{2}{(\sum_i b_i^{p})^{(p-1)/p}}
   \bigl(a\;\text{rev} * b^{\,p-1}\bigr)_{n-1\ldots n-1+n},
   \qquad b = a*a .
   \]

   We start with a gentle smoothing (`p=2`) and progressively tighten
   (`p=8`, `p=32`).  After each phase the best point is kept.
   The optimisation respects the simplex constraint via Euclidean projection.

3. **Fine‑grained local search** – a Frank‑Wolfe style pairwise mass‑transfer
   loop is applied to the globally best vector, using the *exact*
   sub‑gradient of the `max` functional (no diagonal correction bug).
   An optional linear‑programming boost (via `scipy.optimize.linprog`) is
   performed when the dimension is modest.

All steps stop as soon as the global time budget (≈ 1000 s) is exhausted.
The final vector is scaled to \(\sum a = \sqrt{2n}\) and returned as a plain
Python list.

```python
"""
Robust optimiser for the step‑function score.

The algorithm works in three stages:

1. Broad sampling of analytic families (arcsine, triangular, exponential,
   Gaussian, Cauchy, symmetric/unsymmetric Beta) and random Dirichlet draws
   for several lengths.  Every candidate is ℓ₁‑normalised (sum = 1) and
   scored with the cheap surrogate 2·n·max(conv(a,a)).

2. Multi‑phase smoothed optimisation of the best seeds.  We minimise the
   p‑norm of the self‑convolution (p = 2 → 8 → 32) using Adam on the exact
   gradient (computed via FFT).  The simplex constraint is enforced by Euclidean
   projection.

3. Frank‑Wolfe pairwise mass transfer on the global best, followed by a
   tiny linear‑programming boost for moderate dimensions.

The final vector is scaled to sum = √(2 n) before being returned.
"""

import time
import numpy as np
from numpy.fft import rfft, irfft
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, sum(x)=s}."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a (length 2·n‑1) via a real FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()
    A = rfft(a, n=size)
    conv = irfft(A * A, n=size)
    return conv[: 2 * n - 1]


def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using a real FFT."""
    size = 1 << ((a.size + b.size - 1) - 1).bit_length()
    A = rfft(a, n=size)
    B = rfft(b, n=size)
    conv = irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]


# ----------------------------------------------------------------------
def _max_convolution_score(a: np.ndarray) -> float:
    """
    Exact surrogate for evaluate_sequence when sum(a)=1:
    2·n·max(a*a).
    """
    n = a.shape[0]
    b = _fft_self_convolve(a)
    return 2.0 * n * b.max()


# ----------------------------------------------------------------------
# ----------  families for the broad‑sampling stage --------------------
def _arcsine_distribution(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals


def _triangular_distribution(n: int) -> np.ndarray:
    half = n // 2
    left = np.arange(1, half + 1, dtype=np.float64)
    if n % 2 == 1:
        right = left[:-1][::-1]
    else:
        right = left[::-1]
    vals = np.concatenate([left, right])
    if vals.size != n:
        vals = np.pad(vals, (0, n - vals.size), constant_values=0)
    vals /= vals.sum()
    return vals


def _exponential_distribution(n: int, lam: float = 0.005) -> np.ndarray:
    idx = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    vals = np.exp(-lam * np.abs(idx - centre))
    vals /= vals.sum()
    return vals


def _gaussian_distribution(n: int, sigma_factor: float = 0.2) -> np.ndarray:
    idx = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    sigma = sigma_factor * n
    vals = np.exp(-0.5 * ((idx - centre) / sigma) ** 2)
    vals /= vals.sum()
    return vals


def _cauchy_distribution(n: int, scale_factor: float = 0.2) -> np.ndarray:
    idx = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    scale = scale_factor * n
    vals = 1.0 / (1.0 + ((idx - centre) / scale) ** 2)
    vals /= vals.sum()
    return vals


def _beta_symmetric_distribution(n: int, p: float) -> np.ndarray:
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    w = np.exp((p - 1) * np.log(x) + (p - 1) * np.log(1.0 - x))
    if w.sum() == 0:
        w = np.full_like(w, 1.0 / n)
    else:
        w /= w.sum()
    return w


def _beta_distribution(n: int, alpha: float, beta: float) -> np.ndarray:
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    with np.errstate(divide='ignore', invalid='ignore'):
        w = np.exp((alpha - 1) * np.log(x) + (beta - 1) * np.log(1 - x))
    if np.isnan(w).any() or np.isinf(w).any() or w.sum() == 0:
        w = np.full_like(w, 1.0 / n)
    else:
        w /= w.sum()
    return w


def _random_dirichlet_alpha(n: int, alpha: float) -> np.ndarray:
    """Draw a random point on the simplex from Dirichlet(α,…,α)."""
    if alpha <= 0:
        raise ValueError("alpha must be positive")
    x = np.random.gamma(alpha, 1.0, size=n)
    return x / x.sum()


# ----------------------------------------------------------------------
# ----------  gradients for smoothed objectives -----------------------
def _lp_gradient(a: np.ndarray, p: float) -> np.ndarray:
    """
    Gradient of the p‑norm of the self‑convolution L_p(a) =
    ( Σ_i (a*a)_i^p )^{1/p}  with respect to a, under the simplex constraint.
    """
    n = a.shape[0]
    b = _fft_self_convolve(a)                  # length 2n‑1
    # power terms
    b_pow = np.power(b, p)
    sum_pow = np.sum(b_pow)
    if sum_pow == 0.0:
        return np.zeros_like(a)

    # weight = b^{p-1} / ( Σ b^p )^{(p-1)/p}
    denom = sum_pow ** ((p - 1.0) / p)
    w = np.power(b, p - 1.0) / denom           # same length 2n‑1

    # convolution of reversed a with the weight vector
    conv_rev = _fft_convolve(a[::-1], w)
    grad = 2.0 * conv_rev[n - 1 : n - 1 + n]    # shape (n,)
    return grad


def _subgrad_exact(a: np.ndarray):
    """
    Exact sub‑gradient of max(a*a) on the simplex (sum = 1).  No diagonal
    correction is applied – this fixes the bug present in the reference
    implementation.
    Returns (gradient, current_max, active_indices).
    """
    n = a.shape[0]
    b = _fft_self_convolve(a)
    cur_max = b.max()
    eps = 1e-12 * (abs(cur_max) + 1.0)
    active = np.flatnonzero(b >= cur_max - eps)
    w = np.zeros_like(b)
    w[active] = 1.0
    conv_rev = _fft_convolve(a[::-1], w)
    grad = 2.0 * conv_rev[n - 1 : n - 1 + n]
    return grad, cur_max, active


# ----------------------------------------------------------------------
# ----------  Adam optimiser for a given smoothing exponent ----------
def _adam_lp_descent(a0: np.ndarray, p: float, deadline: float,
                     max_iters: int = 15_000,
                     step0: float = 0.5,
                     beta1: float = 0.9,
                     beta2: float = 0.999) -> tuple[np.ndarray, float]:
    """
    Adam optimisation of L_p (p‑norm of the self‑convolution) on the simplex.
    Returns the best vector seen and its surrogate score 2·n·max(conv).
    """
    a = a0.copy()
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    best_a = a.copy()
    best_score = _max_convolution_score(a)
    t = 0
    while time.time() < deadline and t < max_iters:
        t += 1
        grad = _lp_gradient(a, p)
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        eta = step0 / (np.sqrt(v_hat) + 1e-8)
        a = a - eta * m_hat
        a = _project_onto_simplex(a, s=1.0)
        cur_score = _max_convolution_score(a)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# ----------  Linear‑programming refinement (optional) ---------------
def _lp_refine(a: np.ndarray, deadline: float) -> tuple[np.ndarray, float]:
    """
    One‑shot LP improvement: maximise Σ g_j subject to (a*g)_k ≤ M,
    where M = max(a*a).  Works comfortably for n ≤ 2000.
    """
    n = a.shape[0]
    if n > 2000:
        return a, _max_convolution_score(a)

    cur_max = _subgrad_exact(a)[1]

    rows, cols, data = [], [], []
    for k in range(2 * n - 1):
        j_start = max(0, k - (n - 1))
        j_end = min(k, n - 1)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            data.append(a[k - j])          # coefficient a_{k-j}
    A = csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))
    b = np.full(2 * n - 1, cur_max, dtype=np.float64)

    c = -np.ones(n, dtype=np.float64)      # maximise Σ g_j  → minimise −Σ g_j
    bounds = [(0, None)] * n

    remaining = max(0.0, deadline - time.time())
    res = linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                  method='highs',
                  options={'time_limit': remaining, 'presolve': True})
    if not res.success:
        return a, _max_convolution_score(a)

    g = res.x
    if g.sum() > 0:
        g = g / g.sum()
    else:
        g = a.copy()

    # blend a small amount of g into a and finish with a cheap SGD polish
    t = 0.2
    a_new = (1 - t) * a + t * g
    a_new = _project_onto_simplex(a_new, s=1.0)
    a_ref, sc_ref = _adam_lp_descent(a_new, p=2.0, deadline=deadline,
                                     max_iters=4_000, step0=0.3)
    return a_ref, sc_ref
```
