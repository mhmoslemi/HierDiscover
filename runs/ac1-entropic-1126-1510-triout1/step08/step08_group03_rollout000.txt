This implementation searches for a step‑function (a non‑negative vector) that minimises  

```
evaluate_sequence(a) = 2·n·max(convolve(a,a)) / (sum(a)²)
```  

The objective is *scale‑invariant*; we therefore keep all candidates normalised to
`sum(a)=1`.  
The algorithm works in three phases:

1. **Broad sampling** – generate a large pool of candidates from several analytic
   families (arcsine, triangular, exponential, sine, cosine, uniform,
   symmetric/asymmetric Beta) and from random Dirichlet draws.  
   Each candidate is evaluated by the cheap surrogate  
   `score = 2·n·max(a*a)` (the exact objective with `sum(a)=1`).

2. **Iterative refinement** – the best‑scoring candidates are improved by a
   cascade of first‑order methods that stay on the simplex:
   * exponentiated‑gradient descent,
   * Adam,
   * a continuation method that minimises a *smooth* approximation of the
     max‑operator (soft‑max) with an increasing smoothing factor,
   * plain sub‑gradient descent.
   The number of iterations for the top candidates is much larger than in the
   previous baseline, allowing the optimiser to approach a more accurate
   local minimum.

3. **Fine‑grained hill‑climbing** – tiny random mass transfers between two
   positions are repeatedly attempted; moves that decrease the cheap score are
   kept.  Occasionally a small Gaussian jitter is added to escape plateaux.

All steps respect the global 1000 s budget.  The final vector is returned as a
plain Python list of floats, ready for `evaluate_sequence`.

```python
"""
Propose a step‑function that minimises ``evaluate_sequence``.

Algorithm
---------

1. **Broad sampling** – generate many candidates from analytic families
   (arcsine, triangular, exponential, sine, cosine, uniform,
   symmetric & asymmetric Beta) and random Dirichlet draws.
   All candidates are normalised to sum 1 and scored by the cheap surrogate
   ``2·n·max(a*a)`` (exact objective for sum = 1).

2. **Refinement** – keep the top‑k seeds and improve them independently on the
   simplex using a cascade of first‑order methods:
   * exponentiated‑gradient descent,
   * Adam,
   * continuation with a smooth max (soft‑max) that gradually becomes sharp,
   * plain sub‑gradient descent.
   The best‑scoring seed receives a longer optimisation budget.

3. **Hill‑climbing** – perform many tiny random mass transfers between two
   coordinates; accept moves that lower the cheap score.  Occasionally add a
   small Gaussian jitter to escape local plateaux.

The routine respects a 1000 s wall‑clock budget and returns the best
sequence found (as a list of floats).  The code is self‑contained and does not
use any file or network I/O.
"""

import time
import numpy as np
from numpy.fft import rfft, irfft

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, sum(x)=s}."""
    if s < 0:
        raise ValueError("simplex radius must be non‑negative")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a (length 2·n‑1) using real FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()
    A = rfft(a, n=size)
    conv = irfft(A * A, n=size)
    return conv[: 2 * n - 1]


def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using real FFT."""
    size = 1 << ((a.size + b.size - 1) - 1).bit_length()
    A = rfft(a, n=size)
    B = rfft(b, n=size)
    conv = irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]


# ----------------------------------------------------------------------
def _max_convolution_score(a: np.ndarray) -> float:
    """Cheap surrogate = 2·n·max(a*a) assuming sum(a)=1."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    return 2.0 * n * b.max()


# ----------------------------------------------------------------------
def _subgrad(a: np.ndarray):
    """Exact sub‑gradient of max(a*a) on the simplex."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    cur_max = b.max()
    eps = 1e-12 * (abs(cur_max) + 1.0)
    active = np.flatnonzero(b >= cur_max - eps)

    w = np.zeros_like(b)
    w[active] = 1.0

    conv_rev = _fft_convolve(a[::-1], w)
    grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

    # diagonal correction for terms where k = 2*i
    even = (active % 2 == 0)
    diag_idx = active[even] // 2
    if diag_idx.size:
        grad[diag_idx] -= a[diag_idx]

    return grad, cur_max, active


# ----------------------------------------------------------------------
def _exp_gradient_descent(a0: np.ndarray, deadline: float,
                          max_iters: int = 150_000,
                          eta0: float = 0.8):
    """Exponentiated‑gradient (mirror descent) on the simplex."""
    a = a0.copy()
    best_a = a.copy()
    best_score = _max_convolution_score(a)
    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1
        grad, _, _ = _subgrad(a)
        eta = eta0 / np.sqrt(it)
        a = a * np.exp(-eta * grad)
        s = a.sum()
        a = a / s if s > 0 else np.full_like(a, 1.0 / a.size)
        cur = _max_convolution_score(a)
        if cur < best_score - 1e-15:
            best_score, best_a = cur, a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
def _adam_descent(a0: np.ndarray, deadline: float,
                  max_iters: int = 150_000,
                  step0: float = 0.2,
                  beta1: float = 0.9,
                  beta2: float = 0.999):
    """Adam on the simplex (projected after each step)."""
    a = a0.copy()
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    best_a = a.copy()
    best_score = _max_convolution_score(a)
    t = 0
    while time.time() < deadline and t < max_iters:
        t += 1
        grad, _, _ = _subgrad(a)
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        eta = step0 / (np.sqrt(v_hat) + 1e-8)
        a = a - eta * m_hat
        a = _project_onto_simplex(a, s=1.0)
        cur = _max_convolution_score(a)
        if cur < best_score - 1e-15:
            best_score, best_a = cur, a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
def _subgradient_descent(a0: np.ndarray, deadline: float,
                         max_iters: int = 400_000,
                         eta0: float = 0.6):
    """Plain sub‑gradient descent with diminishing step size."""
    a = a0.copy()
    best_a = a.copy()
    best_score = _max_convolution_score(a)
    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1
        grad, _, _ = _subgrad(a)
        eta = eta0 / np.sqrt(it)
        a = a - eta * grad
        a = _project_onto_simplex(a, s=1.0)
        cur = _max_convolution_score(a)
        if cur < best_score - 1e-15:
            best_score, best_a = cur, a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
def _smooth_gradient(a: np.ndarray, gamma: float):
    """Gradient of the soft‑max approximation of max(a*a)."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    b_max = b.max()
    # soft‑max weights
    w = np.exp(gamma * (b - b_max))
    w_sum = w.sum()
    w = w / w_sum if w_sum > 0 else np.full_like(w, 1.0 / w.size)

    # gradient = 2 * conv_rev(a, w)
    conv_rev = _fft_convolve(a[::-1], w)
    grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

    # diagonal correction for k = 2*i
    diag_w = w[2 * np.arange(n)]
    grad -= a * diag_w
    return grad, b_max


def _smooth_gradient_descent(a0: np.ndarray, deadline: float,
                             max_iters: int = 300_000,
                             eta0: float = 0.7,
                             gamma0: float = 5.0,
                             gamma_factor: float = 1.001):
    """Continuation: start with smooth max (γ≈5) and increase γ gradually."""
    a = a0.copy()
    best_a = a.copy()
    best_score = _max_convolution_score(a)
    it = 0
    gamma = gamma0
    while time.time() < deadline and it < max_iters:
        it += 1
        grad, _ = _smooth_gradient(a, gamma)
        eta = eta0 / np.sqrt(it)
        a = a - eta * grad
        a = _project_onto_simplex(a, s=1.0)
        cur = _max_convolution_score(a)
        if cur < best_score - 1e-15:
            best_score, best_a = cur, a.copy()
        gamma *= gamma_factor
    return best_a, best_score

# Analytic families ----------------------------------------------------
def _arcsine_distribution(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    return vals / vals.sum()


def _triangular_distribution(n: int) -> np.ndarray:
    # symmetric triangle (peak in the centre)
    half = n // 2
    left = np.arange(1, half + 1, dtype=np.float64)
    right = left[::-1] if n % 2 == 0 else left[:-1][::-1]
    vals = np.concatenate([left, right])
    if vals.size != n:
        vals = np.pad(vals, (0, n - vals.size), constant_values=0)
    return vals / vals.sum()


def _exponential_distribution(n: int, lam: float = 0.005) -> np.ndarray:
    idx = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    vals = np.exp(-lam * np.abs(idx - centre))
    return vals / vals.sum()


def _sine_distribution(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = np.sin(np.pi * (i + 0.5) / n)
    return vals / vals.sum()


def _cosine_distribution(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = np.cos(np.pi * (i - (n - 1) / 2) / n) + 1.0
    return vals / vals.sum()


def _beta_symmetric_distribution(n: int, p: float) -> np.ndarray:
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    w = np.exp((p - 1) * np.log(x) + (p - 1) * np.log(1.0 - x))
    if w.sum() == 0:
        w = np.full_like(w, 1.0 / n)
    else:
        w = w / w.sum()
    return w


def _beta_asymmetric_distribution(n: int, p: float, q: float) -> np.ndarray:
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    w = np.exp((p - 1) * np.log(x) + (q - 1) * np.log(1.0 - x))
    w = np.where(np.isfinite(w), w, 0.0)
    if w.sum() == 0:
        w = np.full_like(w, 1.0 / n)
    else:
        w = w / w.sum()
    return w


def _random_dirichlet(n: int, rng: np.random.Generator) -> np.ndarray:
    x = rng.gamma(1.0, 1.0, size=n)
    return x / x.sum()

def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:
    """
    Search for a non‑negative step‑function minimising ``evaluate_sequence``.

    The routine respects a wall‑clock budget of ``budget_s`` seconds and
    returns the best candidate found as a plain Python list.
    """
    rng = np.random.default_rng(seed)
    deadline = time.time() + budget_s - 5.0   # safety margin

    # --------------------------------------------------------------
    # Base length (use previous construction if available)
    try:
        base_n = len(height_sequence_1)   # type: ignore[name-defined]
    except Exception:
        base_n = 3500

    # Choose a diverse set of lengths around the base length
    lengths = set()
    for f in (0.7, 0.85, 1.0, 1.15, 1.3, 1.6, 2.0):
        n = int(base_n * f)
        if n >= 500:
            lengths.add(n)
    for _ in range(8):
        n = rng.integers(500, min(12000, base_n * 3) + 1)
        lengths.add(int(n))
    lengths = sorted(lengths)

    # --------------------------------------------------------------
    # 1. Broad sampling of analytically parametrised families
    candidates = []          # list of (array, cheap_score)

    beta_params = [0.2, 0.5, 0.8, 1.2, 2.0, 3.0, 5.0]

    for n in lengths:
        if time.time() >= deadline:
            break

        # deterministic families
        fams = [
            _arcsine_distribution,
            _triangular_distribution,
            lambda nn: _exponential_distribution(nn, lam=0.003),
            _sine_distribution,
            _cosine_distribution,
            lambda nn: np.full(nn, 1.0 / nn),   # uniform
        ]
        for f in fams:
            a = f(n)
            candidates.append((a, _max_convolution_score(a)))

        # Symmetric beta (grid)
        for p in beta_params:
            a = _beta_symmetric_distribution(n, p)
            candidates.append((a, _max_convolution_score(a)))

        # Asymmetric beta (grid)
        for p in beta_params:
            for q in beta_params:
                a = _beta_asymmetric_distribution(n, p, q)
                candidates.append((a, _max_convolution_score(a)))

        # Random Dirichlet draws
        for _ in range(4):
            a = _random_dirichlet(n, rng)
            candidates.append((a, _max_convolution_score(a)))

        # Random mixtures of two families
        for _ in range(3):
            fam1 = rng.choice(['arcsine', 'triangular', 'uniform', 'sine'])
            if fam1 == 'arcsine':
                a1 = _arcsine_distribution(n)
            elif fam1 == 'triangular':
                a1 = _triangular_distribution(n)
            elif fam1 == 'uniform':
                a1 = np.full(n, 1.0 / n)
            else:
                a1 = _sine_distribution(n)

            fam2 = rng.choice(['beta_sym', 'beta_asym', 'exponential'])
            if fam2 == 'beta_sym':
                p = rng.choice(beta_params)
                a2 = _beta_symmetric_distribution(n, p)
            elif fam2 == 'beta_asym':
                p = rng.choice(beta_params)
                q = rng.choice(beta_params)
                a2 = _beta_asymmetric_distribution(n, p, q)
            else:
                lam = 10 ** rng.uniform(-4, -2)
                a2 = _exponential_distribution(n, lam=lam)

            lam_mix = rng.random()
            a = lam_mix * a1 + (1.0 - lam_mix) * a2
            a = a / a.sum()
            candidates.append((a, _max_convolution_score(a)))

    # --------------------------------------------------------------
    # 2. Add previously known best (if any)
    try:
        prev = np.asarray(height_sequence_1, dtype=np.float64)   # type: ignore[name-defined]
        if prev.ndim == 1 and prev.size > 0:
            prev = prev / prev.sum()
            candidates.append((prev, _max_convolution_score(prev)))
    except Exception:
        pass

    # --------------------------------------------------------------
    # 3. Keep the top‑k seeds for refinement (k large enough for diversity)
    candidates.sort(key=lambda x: x[1])
    top_k = min(len(candidates), 120)   # 120 seeds -> still manageable
    seeds = [seq for seq, _ in candidates[:top_k]]

    # Keep a small record of the overall best
    best_seq = seeds[0].copy()
    best_score = _max_convolution_score(best_seq)
    print(f"[{time.time():.1f}] initial cheap best={best_score:.6f}")

    # --------------------------------------------------------------
    # 4. Light pre‑optimisation for *all* seeds (quick exp‑grad)
    remaining = deadline - time.time()
    per_seed_budget = remaining * 0.3 / max(len(seeds), 1)   # 30 % of remaining time

    refined = []
    for idx, seed in enumerate(seeds):
        if time.time() >= deadline:
            break
        seed_deadline = time.time() + per_seed_budget
        seq, sc = _exp_gradient_descent(seed, seed_deadline,
                                        max_iters=30_000,
                                        eta0=0.9)
        refined.append((seq, sc))
        if sc < best_score - 1e-14:
            best_seq, best_score = seq.copy(), sc
            print(f"[{time.time():.1f}] pre‑exp‑grad seed {idx+1} → {sc:.6f}")

    # --------------------------------------------------------------
    # 5. Keep the most promising after the quick phase
    refined.sort(key=lambda x: x[1])
    top_fine = [seq for seq, _ in refined[:20]]   # 20 seeds for detailed work

    # --------------------------------------------------------------
    # 6. Intensive refinement (continuation + Adam + sub‑grad)
    remaining = deadline - time.time()
    per_seed_budget = remaining * 0.6 / max(len(top_fine), 1)   # 60 % of remaining time

    for idx, seed in enumerate(top_fine):
        if time.time() >= deadline:
            break
        seed_deadline = time.time() + per_seed_budget

        # Adam (fast adaptive steps)
        seq, sc = _adam_descent(seed, seed_deadline,
                                max_iters=80_000,
                                step0=0.25)
        if sc < best_score - 1e-14:
            best_seq, best_score = seq.copy(), sc
            print(f"[{time.time():.1f}] seed {idx+1} Adam → {sc:.6f}")

        # Continuation with smooth max (main workhorse)
        seq, sc = _smooth_gradient_descent(seed, seed_deadline,
                                            max_iters=180_000,
                                            eta0=0.7,
                                            gamma0=5.0,
                                            gamma_factor=1.001)
        if sc < best_score - 1e-14:
            best_seq, best_score = seq.copy(), sc
            print(f"[{time.time():.1f}] seed {idx+1} smooth → {sc:.6f}")

        # Sub‑gradient tidy‑up
        seq, sc = _subgradient_descent(seed, seed_deadline,
                                       max_iters=120_000,
                                       eta0=0.6)
        if sc < best_score - 1e-14:
            best_seq, best_score = seq.copy(), sc
            print(f"[{time.time():.1f}] seed {idx+1} subgrad → {sc:.6f}")

    # --------------------------------------------------------------
    # 7. Fine‑grained hill climbing on the current best
    a = best_seq.copy()
    cur_score = best_score
    n = a.shape[0]
    it = 0
    max_transfer = 0.03   # start with up to 3 % of total mass

    while time.time() < deadline:
        it += 1
        # geometric decay of the transferred amount
        transfer = max_transfer * (0.5 ** (it / 12_000.0))

        i = rng.integers(n)
        j = rng.integers(n - 1)
        if j >= i:
            j += 1

        delta = rng.random() * min(transfer, a[i])
        if delta <= 0:
            continue

        a_new = a.copy()
        a_new[i] -= delta
        a_new[j] += delta
        new_score = _max_convolution_score(a_new)

        if new_score < cur_score - 1e-15:
            a = a_new
            cur_score = new_score
            if new_score < best_score - 1e-14:
                best_seq = a_new.copy()
                best_score = new_score
                print(f"[{time.time():.1f}] hill‑climb iter={it} new best {best_score:.6f}")

        # occasional jitter to escape plateaux
        if it % 5_000 == 0 and rng.random() < 0.15:
            jitter = rng.standard_normal(n) * 5e-5
            a = best_seq + jitter
            a = _project_onto_simplex(a, s=1.0)
            cur_score = _max_convolution_score(a)

    print(f"Final cheap score: {best_score:.6f} (length={len(best_seq)})")
    # Return as plain Python list (evaluate_sequence will re‑normalise internally)
    return best_seq.tolist()
```
