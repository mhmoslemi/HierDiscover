The evaluation function  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2}
\]

is homogeneous – scaling the vector does not change the score – so we may
choose the normalisation `∑a = 1`.  
The task is therefore to minimise the maximal entry of the auto‑convolution
`c = a*a` under the simplex constraints `a_i ≥ 0 , ∑a_i = 1`.

The programme below follows three ideas

1. **Broad initialisation** – many analytical families (arcsine,
   Beta (α,α) with very small α, uniform, random) are tried and the
   one with the smallest *fast* score `2·n·max(c)` is kept.

2. **Smooth‑max optimisation** – Adam is used on the smooth approximation  

   \[
   L_\alpha(a)=\frac{1}{\alpha}\log\!\Bigl(\sum_k e^{\alpha(c_k-c_{\max})}\Bigr)
   \]

   with a slowly increasing temperature `α`.  Afterwards a short exact
   sub‑gradient descent (the same machinery as the reference solution)
   polishing the result.

3. **Heavy custom simulated‑annealing** – after the gradient phase we
   already have a good starting point.  A *linear‑time* update of the
   convolution is possible when a tiny amount `δ` of mass is moved from
   position `src` to `dst`:

   ```
   c ← c - 2·δ·shift(src,a) + 2·δ·shift(dst,a) + kernel(δ,src,dst)
   ```

   (`shift(p,a)` is the vector `a` placed at indices `p … p+n‑1`,
   `kernel` contains the three self‑terms).  This makes one
   SA‑iteration cheap (O(n) work, no FFT) and we can afford many
   thousands of iterations in the remaining time budget.

All steps respect the simplex – after a move we keep the sum exactly
`1` and never create negative entries.  The final sequence is projected
onto the simplex once more before the black‑box `evaluate_sequence` is
called.

The whole search runs inside the given 1000 s budget, prints progress
information and finally returns the best sequence it found.

```python
#!/usr/bin/env python
"""
search for a low‑score non‑negative step function.

Algorithm:
  1) generate many candidate vectors (arcsine, beta(α,α) with α∈[0.05,0.9],
     uniform, random, simple mixtures) and keep the one with the smallest
     fast proxy 2·n·max(conv).
  2) smooth‑max Adam optimisation (α grows up to 2000) and a short exact
     sub‑gradient polishing.
  3) intensive simulated‑annealing where each move updates the
     convolution incrementally (O(n) work, no FFT).  This phase uses the
     majority of the time budget.
  4) final call to evaluate_sequence and return the best vector.

All helpers are defined at top level, no closures or file I/O are used.
"""

import math
import time
import numpy as np

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, Σx = s}."""
    if s < 0:
        raise ValueError("Simplex size must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using a real FFT (length 2·len(a)-1)."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()   # next power of two
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]


# ----------------------------------------------------------------------
def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution of two real vectors using a real FFT."""
    size = 1 << ((a.size + b.size - 1) - 1).bit_length()
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]


# ----------------------------------------------------------------------
def _arcsine_distribution(n: int) -> np.ndarray:
    """Discrete arcsine distribution (probability vector) of length n."""
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals


# ----------------------------------------------------------------------
def _beta_distribution(n: int, alpha: float, beta: float) -> np.ndarray:
    """Discrete Beta(α,β) on a uniform grid, normalised to sum 1."""
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    log_vals = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    vals = np.exp(log_vals)
    vals[~np.isfinite(vals)] = 0.0
    total = vals.sum()
    if total == 0.0:
        vals = np.full(n, 1.0 / n, dtype=np.float64)
    else:
        vals /= total
    return vals


# ----------------------------------------------------------------------
def _smooth_max_gradient(a: np.ndarray, alpha: float):
    """Gradient of the smooth‑max surrogate
          Lα(a) = (1/α)·log Σ_k exp(α·(a*a)_k - α·c_max)
    Returns (grad, current max) where grad has the same shape as a.
    """
    b = _fft_self_convolve(a)
    cur_max = b.max()
    # soft‑max weights (stable)
    exp_term = np.exp(alpha * (b - cur_max))
    w = exp_term / exp_term.sum()
    a_rev = a[::-1]
    conv_rev = _fft_convolve(a_rev, w)          # length = 3n‑2
    grad = 2.0 * conv_rev[len(a) - 1 : len(a) - 1 + len(a)]
    return grad, cur_max


# ----------------------------------------------------------------------
def _adam_optimize(a0: np.ndarray,
                   deadline: float,
                   init_alpha: float = 1.0,
                   alpha_factor: float = 1.005,
                   alpha_max: float = 2000.0,
                   lr0: float = 0.2,
                   beta1: float = 0.9,
                   beta2: float = 0.999,
                   eps: float = 1e-8):
    """
    Adam optimisation of the smooth‑max surrogate.
    Returns the best vector (probability) encountered and its peak convolution.
    """
    a = a0.copy()
    n = a.shape[0]
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    t = 0
    alpha = init_alpha

    best_a = a.copy()
    best_peak = _fft_self_convolve(a).max()

    while time.time() < deadline:
        t += 1
        grad, cur_max = _smooth_max_gradient(a, alpha)

        # Adam moments
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        lr = lr0 / np.sqrt(t)

        a = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        a = _project_onto_simplex(a, s=1.0)

        if cur_max < best_peak - 1e-14:
            best_peak = cur_max
            best_a = a.copy()

        if alpha < alpha_max:
            alpha = min(alpha_max, alpha * alpha_factor)

        # occasional tiny jitter
        if t % 500 == 0 and np.random.rand() < 0.1:
            a += np.random.randn(n) * 1e-6
            a = _project_onto_simplex(a, s=1.0)

    return best_a, best_peak


# ----------------------------------------------------------------------
def _max_subgradient_step(a: np.ndarray):
    """One sub‑gradient step for the exact ℓ∞ objective."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    cur_max = b.max()
    tol = max(1e-12, cur_max * 1e-12)
    active = np.where(b >= cur_max - tol)[0]
    w = np.zeros_like(b)
    if active.size > 0:
        w[active] = 1.0 / active.size
    a_rev = a[::-1]
    grad = 2.0 * _fft_convolve(a_rev, w)[n - 1 : n - 1 + n]
    return grad, cur_max


# ----------------------------------------------------------------------
def _refine_max(a0: np.ndarray, deadline: float) -> np.ndarray:
    """Short exact‑max refinement using sub‑gradient descent."""
    a = a0.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_peak = _fft_self_convolve(a).max()
    it = 0
    while time.time() < deadline:
        it += 1
        grad, cur_max = _max_subgradient_step(a)
        step = 0.02 / np.sqrt(it)          # diminishing step
        a = a - step * grad
        a = _project_onto_simplex(a, s=1.0)
        if cur_max < best_peak - 1e-14:
            best_peak = cur_max
            best_a = a.copy()
        if it % 400 == 0 and np.random.rand() < 0.07:
            a += np.random.randn(n) * 5e-7
            a = _project_onto_simplex(a, s=1.0)
    return best_a


# ----------------------------------------------------------------------
def _incremental_annealing(a0: np.ndarray, deadline: float) -> np.ndarray:
    """
    Fast simulated‑annealing that updates the self‑convolution incrementally
    (O(n) per move).  Returns the best vector encountered.
    """
    a = a0.copy()
    n = a.shape[0]
    conv_len = 2 * n - 1
    c = _fft_self_convolve(a)                 # current convolution
    cur_max = c.max()
    best_a = a.copy()
    best_max = cur_max

    start = time.time()
    total = max(deadline - start, 1e-6)

    start_temp = max(cur_max, 1e-3) * 0.5
    final_temp = start_temp * 1e-5
    if final_temp <= 0.0:
        final_temp = 1e-9
    cooling_rate = -math.log(final_temp / start_temp) / total

    # main SA loop
    while time.time() < deadline:
        # pick source (must have some mass)
        src = np.random.randint(n)
        if a[src] <= 1e-14:
            continue
        # pick destination different from src
        dst = np.random.randint(n - 1)
        if dst >= src:
            dst += 1

        # move a fraction (up to 5 %) of the source mass
        max_delta = min(a[src], 0.05)
        if max_delta <= 0:
            continue
        delta = np.random.rand() * max_delta
        delta2 = delta * delta

        # --- compute tentative new convolution (copy, then update) ---
        c_new = c.copy()
        # linear part: -2·δ·shift(src,a) + 2·δ·shift(dst,a)
        c_new[src:src + n] -= 2.0 * delta * a
        c_new[dst:dst + n] += 2.0 * delta * a

        # kernel part (self‑terms of the moved mass)
        c_new[2 * src] += delta2
        c_new[2 * dst] += delta2
        idx = src + dst
        c_new[idx] -= 2.0 * delta2

        new_max = c_new.max()
        elapsed = time.time() - start
        temperature = start_temp * math.exp(-cooling_rate * elapsed)
        delta_obj = new_max - cur_max

        accept = False
        if delta_obj < 0.0:
            accept = True
        else:
            prob = math.exp(-delta_obj / max(temperature, 1e-12))
            if np.random.rand() < prob:
                accept = True

        if accept:
            # commit the move
            a[src] -= delta
            a[dst] += delta
            c = c_new
            cur_max = new_max
            if cur_max < best_max:
                best_max = cur_max
                best_a = a.copy()
        # occasional small jitter to keep the walk ergodic
        if np.random.rand() < 0.001:
            jitter = np.random.randn(n) * 1e-6
            a += jitter
            a = _project_onto_simplex(a, 1.0)
            c = _fft_self_convolve(a)
            cur_max = c.max()
            if cur_max < best_max:
                best_max = cur_max
                best_a = a.copy()

    # final safety projection
    best_a = _project_onto_simplex(best_a, 1.0)
    return best_a
