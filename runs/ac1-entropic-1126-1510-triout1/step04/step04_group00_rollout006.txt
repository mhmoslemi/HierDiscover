Propose a low‑score step‑function.

Algorithm
---------
* Work on the simplex Σ a_i = 1 (the objective is scale‑invariant).
* Represent the vector by logits u (softmax(u) = a).  This guarantees
  non‑negativity and the simplex constraint without an explicit projection.
* Optimise a smoothed version of   max_i (a*a)_i   using the
  log‑sum‑exp surrogate:
        φ_α(a) = (1/α)·log Σ_i exp(α·b_i)  ,  b = a∗a .
  For α→∞   φ_α → max_i b_i .
* Gradient of φ_α w.r.t. a is
        ∇_a φ_α = 2·conv_rev(a_rev , w) ,
  where w_i = softmax(α·b_i) and conv_rev is the (full) convolution of
  a reversed with w.  The gradient w.r.t. the logits u is
        ∇_u φ_α = a ⊙ (∇_a φ_α – (∇_a φ_α·a)) .
* Use the Adam optimiser on the logits, with a slowly increasing temperature

def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full a*a convolution via a real FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()   # next power of two
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]


def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:

    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)

    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals
