def _project_to_simplex(v, z):
    """Project onto nonnegative simplex."""
    n = v.shape[0]
    if z < 0:
        raise ValueError
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n+1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

Linear‑programming driven search for a low‑score step function.

The algorithm works in three stages:

1. **Initialisation** – use the supplied reference sequence (if any) or a
   uniform distribution, projected onto the simplex Σa = √(2·n).

2. **LP improvement loop** – for the current sequence `f` compute its
   peak `M = max(f*f)`.  Solve the linear programme
        maximise   Σ b_i
        subject to  f * b ≤ M   (component‑wise)
                    b_i ≥ 0
   The solution `b` tells how much total ℓ¹‑mass can be packed under the same
   peak.  After scaling `b` to the required total mass `S = √(2·n)` we obtain
   a new sequence with a strictly smaller peak (`M·S/Σb`).  The process is
   repeated until no further improvement is possible or time runs out.

3. **Final polishing** – a short projected sub‑gradient descent on the true
