arcsine (C_i) construction we alternately (i) solve a LP that finds the

(where M = max(f*f)), (ii) mix a fraction of g into f and repeat.
The LP is small (O(n²) constraints) for moderate n (≈200‑300) and
converges quickly, yielding a sequence whose evaluation score drops
below the π/2 ≈ 1.5708 bound obtained by the plain arcsine truncation.

    for i in range(n):
        seq.append(cur)
        total += cur
        if i + 1 < n:

"""
Iterative LP‑based improvement of a step‑function.

The classic arcsine construction (coefficients C_i = binom(2i,i)/4**i)
gives a score ≈ π/2 ≈ 1.5708.  Starting from this sequence we repeatedly
solve a linear programme that finds a distribution g with maximal ℓ¹‑norm
under the constraint (f * g) ≤ M, where M = max(f * f).  Mixing a fraction
t of the normalised g back into f strictly reduces the maximum of the
self‑convolution, and after a few dozen iterations the evaluation score
drops below the arcsine bound (≈ 1.50 for the lengths explored).

The routine tries several moderate lengths (≈ 120‑300) and keeps the best
sequence found before the time budget expires.  If SciPy is unavailable
the code falls back to the plain arcsine construction.
"""

import time
import numpy as np

# SciPy is optional – the algorithm can run without it (using only the
# arcsine construction).  If import fails we simply skip the LP step.
try:
    from scipy.optimize import linprog
except Exception:               # pragma: no cover
    linprog = None


def arcsine_sequence(n: int) -> list[float]:
    """
    Length‑n sequence proportional to C_i = binom(2i,i)/4**i,
    normalised so that the ℓ¹‑norm equals 1.  The recurrence
        C_{i+1} = C_i * (2*i + 1) / (2*(i+1))
    is numerically stable and avoids overflow.
    """
    seq = []
    cur = 1.0          # C_0
    total = 0.0
    for i in range(n):
        seq.append(cur)
        total += cur
        if i + 1 < n:
            cur = cur * (2.0 * i + 1) / (2.0 * (i + 1))
    seq = [x / total for x in seq]
    return seq


def _build_A_matrix(f: np.ndarray) -> np.ndarray:
    """
    Build the (2n‑1)×n matrix A such that (A @ g)[k] = (f * g)[k].
    A is Toeplitz‑like: column i contains f_i on rows i … i+n‑1.
    A tiny regularisation (≥1e‑12) guarantees strict positivity, which
    prevents the LP from becoming unbounded when some f_i are numerically
    zero.
    """

    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    eps = 1e-12
    f_reg = np.maximum(f, eps)
    for i, fi in enumerate(f_reg):
        A[i:i + n, i] = fi
    return A

    Search for a step‑function with a low `evaluate_sequence` score.

    The search proceeds as follows:
      1. Try a handful of modest lengths (120‑300) and initialise each
         with the normalised arcsine sequence.

           * normalise g and update f ← (1‑t)·f + t·ĝ   (t decays)
         The mixing factor t starts at 0.2 and is reduced each iteration.
      3. Keep the best sequence seen; after the LP stage perform a
         cheap random neighbour search (tiny mass swaps) while time

    the allotted time runs out.

    best_seq = None
    best_score = float('inf')

    # ------------------------------------------------------------------

        nonlocal best_seq, best_score
