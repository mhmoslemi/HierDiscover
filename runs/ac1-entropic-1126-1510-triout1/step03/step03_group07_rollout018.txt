and the evaluation is *scale‑invariant*.  
We therefore keep the ℓ₁‑norm fixed to  

\[
S=\sqrt{2n}
\]

and minimise the peak of the linear convolution `a*a`.  
The code below uses three complementary ideas

1. **Projected gradient descent on a smooth approximation of the max** –  
   a soft‑max weighting concentrates the gradient on the current largest
   convolution entry.  After each step we Euclidean‑project onto the
   non‑negative simplex of sum = S.

2. **Heavy simulated‑annealing polishing** –  
   a massive number of random “mass‑swap’’ moves (`i←i+δ , j←j‑δ`) are
   performed while a temperature schedule accepts occasional worsening
   moves.  This explores the non‑convex landscape far beyond the simple
   deterministic polishing used previously.

3. **Multiple starts & time‑aware loops** –  
   the overall run respects the 1000 s budget, automatically shrinking
   the number of iterations when the deadline approaches.  The best

"""
Advanced optimisation for the step‑function “max‑convolution’’ problem.

The algorithm consists of:
  1. A long projected gradient descent on a soft‑max approximation of the
     max‑convolution (non‑negative simplex projection keeps the ℓ₁‑norm
     fixed to √(2·n)).
  2. A massive simulated‑annealing polishing phase that repeatedly swaps
     tiny amounts of mass between two positions while accepting moves
     according to a decreasing temperature schedule.
  3. Time‑aware loops and continuous best‑solution tracking.

Both phases use FFT‑based convolution / correlation for O(n log n) speed.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the non‑negative simplex Σx = target_sum
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """Project v onto {x ≥ 0, sum(x) = target_sum}."""
    if target_sum <= 0:
        return np.zeros_like(v)

    # Duchi et al. (2008) – O(n) algorithm
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, v.size + 1)
    rho = np.where(u - cssv / ind > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Random pairwise mass transfer (keeps ℓ₁‑norm exactly target_sum)
# ----------------------------------------------------------------------
def _random_pair_move(seq: np.ndarray, sigma: float) -> np.ndarray:
    """Move a small amount of mass from one index to another (preserves the sum)."""
    n = seq.shape[0]
    i, j = np.random.choice(n, size=2, replace=False)

    # draw delta uniformly from (‑σ/2, σ/2)
    delta = (np.random.rand() - 0.5) * sigma
    # keep both entries non‑negative
    if delta > 0:
        delta = min(delta, seq[j])
    else:
        delta = -min(-delta, seq[i])

    new_seq = seq.copy()
    new_seq[i] += delta
    new_seq[j] -= delta
    return new_seq


# ----------------------------------------------------------------------
# FFT‑based full convolution a*a  (length 2n‑1)
# ----------------------------------------------------------------------
def _fft_convolve(a: np.ndarray) -> np.ndarray:
    n = a.shape[0]
    nfft = 1 << ((2 * n - 1).bit_length())
    A = np.fft.rfft(a, nfft)
    conv = np.fft.irfft(A * A, nfft)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# FFT‑based correlation  w⋆a  (valid part, length n)
# ----------------------------------------------------------------------
def _fft_correlate(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """valid correlation of w (length 2n‑1) with a (length n)."""
    n = a.shape[0]
    L = w.shape[0]                     # = 2n‑1
    a_rev = a[::-1]
    nfft = 1 << ((L + n - 1).bit_length())
    W = np.fft.rfft(w, nfft)
    A_rev = np.fft.rfft(a_rev, nfft)
    full = np.fft.irfft(W * A_rev, nfft)[: L + n - 1]
    start = n - 1
    return full[start : start + n]    # length n (valid correlation)


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness.
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: float = 1000, **kwargs):
    """
    Optimise a non‑negative step function (list of heights) under the
    given time budget.  Returns the best sequence found.

    The optimisation consists of a long projected gradient descent on a
    soft‑max surrogate of max(conv) followed by an extensive simulated‑
    annealing polishing phase that swaps tiny amounts of mass between
    pairs of indices while respecting the ℓ₁‑norm.
    """
    np.random.seed(seed)

    start_time = time.time()
    # keep a small safety margin for the harness
    deadline = start_time + max(0.0, budget_s - 2.0)

    # --------------------------------------------------------------
    # Determine the problem size.
    # --------------------------------------------------------------
    try:
        base = np.array(height_sequence_1, dtype=float)   # type: ignore
        N = base.size
    except Exception:
        N = 12000            # fallback length

    S = math.sqrt(2.0 * N)   # ℓ₁‑norm we keep fixed (score = max(conv))

    # --------------------------------------------------------------
    # Initialise a feasible point.
    # --------------------------------------------------------------
    if 'base' in locals():
        a = np.clip(base, 0.0, 1000.0)
        a = _project_onto_simplex(a, S)
    else:
        a = np.full(N, S / N, dtype=float)
        a += 0.001 * S * np.random.rand(N) / N
        a = _project_onto_simplex(a, S)

    # current best
    best_seq = a.copy()
    best_score = _fft_convolve(a).max()
    print(f"[Init] n={N}, initial score={best_score:.6f}")

    # --------------------------------------------------------------
    # Phase 1 – projected gradient descent on a soft‑max surrogate.
    # --------------------------------------------------------------
    max_gd_iters = 80000                     # may be stopped early by time
    beta_start = 0.5
    beta_end = 200.0
    lr_start = 0.6
    lr_end = 0.02

    it = 0
    while time.time() < deadline and it < max_gd_iters:
        it += 1

        conv = _fft_convolve(a)
        max_conv = conv.max()

        # linear schedules
        frac = it / max_gd_iters
        beta = beta_start + (beta_end - beta_start) * frac
        lr = lr_start + (lr_end - lr_start) * (1.0 - frac)

        # soft‑max weights – stable implementation
        exp_vals = np.exp(beta * (conv - max_conv))
        w = exp_vals / exp_vals.sum()

        # gradient of the smooth surrogate
        grad = 2.0 * _fft_correlate(w, a)

        # gradient step + projection
        a_new = a - lr * grad
        a_new = np.maximum(a_new, 0.0)
        a_new = _project_onto_simplex(a_new, S)

        a = a_new

        # occasional reporting
        if it % 200 == 0:
            cur_score = _fft_convolve(a).max()
            if cur_score < best_score:
                best_score = cur_score
                best_seq = a.copy()
                print(f"[GD {it:05d}] new best score: {best_score:.6f}")

    # --------------------------------------------------------------
    # Phase 2 – simulated‑annealing polishing with random pair moves.
    # --------------------------------------------------------------
    total_sa_iters = 200000
    # start from the best sequence found so far
    cur_seq = best_seq.copy()
    cur_score = best_score

    # temperature and move‑size schedules
    T0 = best_score * 0.2                # start temperature ≈ 20 % of score
    mean_val = S / N                     # typical entry size

    sa_it = 0
    while time.time() < deadline and sa_it < total_sa_iters:
        sa_it += 1

        # linear cooling
        T = T0 * (1.0 - sa_it / total_sa_iters)

        # sigma shrinks from a few *mean* to a tiny value
        sigma = (0.5 * mean_val) * (1.0 - sa_it / total_sa_iters) + 1e-8

        cand = _random_pair_move(cur_seq, sigma)
        cand_score = _fft_convolve(cand).max()
        delta = cand_score - cur_score

        # Metropolis acceptance
        accept = False
        if delta < 0:
            accept = True
        elif T > 0 and np.random.rand() < math.exp(-delta / T):
            accept = True

        if accept:
            cur_seq = cand
            cur_score = cand_score
            if cur_score < best_score:
                best_score = cur_score
                best_seq = cur_seq.copy()
                print(f"[SA {sa_it:06d}] new best score: {best_score:.6f}")

    # --------------------------------------------------------------
    # Return the best sequence (as a plain Python list).
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    # final projection guarantees the exact ℓ₁‑norm (tiny numerical drift)
    best_seq = _project_onto_simplex(best_seq, S)

    print(f"[Done] final best score = {best_score:.6f}")
    return best_seq.tolist()
