Simulated‑annealing optimiser for the step‑function bound.

The algorithm works on the ℓ¹‑normalised simplex (Σa = √(2 n)),
the objective being the maximum entry of the self‑convolution
(= the score returned by ``evaluate_sequence`` after normalisation).
A simple Metropolis scheme is employed:

* start from the best known construction if it exists, otherwise from a
  uniform vector;
* repeatedly propose a tiny “mass transfer’’ (move a random fraction of
  weight from one index to another) together with a few occasional
  “block‑redistribute’’ moves;
* accept the move if it improves the max‑convolution, otherwise accept
  with probability exp(−Δ/temperature);
* temperature decays exponentially; after the annealing phase a short
  deterministic hill‑climb (only improving moves) is performed.

All moves keep the ℓ¹‑norm exactly (or are re‑scaled) and respect the
non‑negativity constraints, so the returned sequence is always valid
for ``evaluate_sequence``.  The routine respects the 1000 s wall‑clock
limit and prints intermediate best scores.
"""

import time
import math
import numpy as np


def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """Euclidean projection of v onto {x≥0, Σx = z}."""
    if z < 0:
        raise ValueError("Target sum must be non‑negative.")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _max_convolution(a: np.ndarray, fft_len: int) -> float:
    """Maximum entry of a*a (linear convolution) using an FFT."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    return float(conv[: 2 * a.size - 1].max())


def _full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Full linear convolution a*a (real values)."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    return conv[: 2 * a.size - 1]

    Search for a non‑negative step function with a low evaluation score.

    Parameters
    ----------
    seed : int
        Random seed (reproducible runs).
    budget_s : int
        Time budget in seconds (the function will stop a fraction early).

    Returns
    -------
    list[float]
        The best sequence discovered (plain Python list).
    """

    deadline = time.time() + budget_s - 0.1      # safety margin

    ref_seq = globals().get("height_sequence_1")
