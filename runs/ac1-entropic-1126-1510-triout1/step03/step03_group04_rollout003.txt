def propose_candidate(seed=42, budget_s=1000):
    import time, numpy as np, math
    rng = np.random.default_rng(seed)
    deadline = time.time() + budget_s - 0.1

    # choose length
    n = 8000
    target_sum = math.sqrt(2.0 * n)
    best_score = float('inf')
    best_a = None

    # Precompute FFT size
    n2 = 1 << ((2 * n - 1).bit_length())

    def max_conv(arr):
        # arr is float numpy of length n
        f = np.fft.rfft(arr, n2)
        conv = np.fft.irfft(f * f, n2)
        return float(conv[:2 * n - 1].max())

We use a large length n and repeatedly generate random sparse
vectors (binary mask + Dirichlet weights) and keep the one with the
smallest maximum convolution value.  A cheap local hill‑climb
further reduces the peak.  The algorithm runs for the whole
time budget and returns the best sequence found.

import math
import numpy as np

    """Return max entry of the linear convolution of arr with itself."""

    conv = np.fft.irfft(f * f, size)

Propose a low‑score step function via random sparse masks.

The evaluation objective is
    score = 2·n·max(a∗a) / (∑a)² .
Because the objective is scale‑invariant we fix the ℓ¹‑norm to
    ∑a = √(2 n) .
With a sparse random mask (≈30‑70 % non‑zero entries) the number of
ordered pairs that contribute to each convolution entry is close to
the average `k²/(2n)`.  By choosing a sufficiently large length `n` and
a fairly dense mask the maximum of the auto‑convolution is pushed very
close to its theoretical lower bound 1.  The algorithm therefore
repeatedly draws random masks, rescales the non‑zero weights to the
required ℓ¹‑norm, keeps the best candidate and finally performs a cheap
local hill‑climb that swaps tiny amounts of mass between positions.

The whole routine respects a wall‑clock budget (default 1000 s) and
returns the best sequence found.

import time
import math
import numpy as np

def max_convolution(arr: np.ndarray) -> float:
    """
    Compute max entry of the linear convolution of ``arr`` with itself
    using a real FFT.  The function works for any length ``n``.
    """
    n = arr.shape[0]
    size = 1 << ((2 * n - 1).bit_length())   # next power of two ≥ 2n‑1
    f = np.fft.rfft(arr, size)
    conv = np.fft.irfft(f * f, size)
