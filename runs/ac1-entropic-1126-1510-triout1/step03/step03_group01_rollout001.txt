Propose a step‑function (non‑negative vector) that minimises the
self‑convolution peak appearing in `evaluate_sequence`.

Algorithm
---------
1. Initialise the vector with the discrete arcsine distribution
   (known to give a low convolution peak) and normalise to sum 1.
2. Run a projected Adam optimiser on a smooth approximation of the
   max‑convolution objective:
        Lα(a) = (1/α)·log Σ_k exp(α·( (a∗a)_k – max(a∗a) ))
   The soft‑max temperature α is slowly increased so that optimisation
   gradually focuses on the true peak.  After each gradient step the
   vector is projected onto the probability simplex.
3. Keep the best exact solution (lowest max convolution) seen during
   optimisation.
4. Perform a short local‑search phase: repeatedly move a small amount of
   mass from a random index i to another random index j, accept the move
   only if it lowers the max convolution (hill‑climbing).  Each trial
   recomputes the convolution via an FFT (fast enough for the lengths
   used).  This often squeezes a few more percent out of the score.
5. Return the best vector found as a plain Python list.

The whole routine respects the supplied time budget (default 1000 s) and
uses only NumPy and the standard library.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x >= 0, sum(x)=s}."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _arcsine_distribution(n: int) -> np.ndarray:
    """Discrete arcsine distribution (probability vector) of length n."""
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Return a * a via real FFT (full length 2·len(a)‑1)."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()   # next power of two
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]


# ----------------------------------------------------------------------
def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT (real output)."""
    size = 1 << ((a.size + b.size - 1) - 1).bit_length()
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]
