Now produce final answer with code block.assistantfinal**Solution Overview**

The program searches for a non‑negative step function (a probability vector) that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}
\]

where `a*a` is the linear convolution of the vector with itself.  
The search consists of the following stages (all operations respect the time budget):

1. **Diverse seeds** – a handful of analytically known families (uniform,
   arcsine, mixtures with uniform, random Dirichlet, sparse Dirichlet).  
   The best seed is kept.

2. **Soft‑max mirror descent** – an entropy‑mirror (exponentiated‑gradient)
   optimiser that smoothes the ‑∞‑norm with a temperature‑controlled soft‑max.
   For a temperature `τ` the weight of each convolution entry `k` is  

   \[
   w_k = \frac{e^{(c_k-\max c)/\tau}}{\sum_j e^{(c_j-\max c)/\tau}},
   \qquad c = a*a .
   \]

   The gradient of the smoothed objective is obtained analytically by a
   single FFT‑based convolution, then the update is  

   \[
   a \leftarrow a\;\odot\;
   \exp\!\bigl(-\eta_t\,m_t\bigr) ,
   \qquad
   m_t = \beta m_{t-1}+(1-\beta)g_t ,
   \]

   followed by projection onto the probability simplex.

   The temperature is exponentially cooled, the step size `η_t` decays as
   `1/√t`, and occasional jitter steps escape plateaus.

3. **Hierarchical up‑sampling** – after a few seconds of refinement the
   current best distribution is linearly interpolated to a larger size
   (doubling each round, up to about 25 000 entries).  The soft‑max descent
   is run again on the larger vector, allowing the shape to adapt at higher
   resolution.

4. **Deterministic pairwise cleanup** – a fast greedy sweep that moves a
   random fraction of mass between two coordinates whenever the objective
   improves.

5. **Final simulated‑annealing cleanup** – a cheap Metropolis search with a
   slowly decreasing temperature to polish any remaining spikes.

All heavy work is performed with NumPy’s real FFT (`rfft/irfft`) which
provides O(n log n) convolutions and keeps the whole search comfortably
inside the 1000 s budget.

The entry point required by the evaluation harness is the function
`propose_candidate`.  It returns a plain Python list of `float`s; the
provided `evaluate_sequence` function will clip and scale the list as
necessary.

```python
"""
Non‑negative step‑function optimiser.

It builds a few analytic seeds, refines them with a temperature‑controlled
soft‑max mirror‑descent (exponentiated‑gradient on the smoothed ∞‑norm of the
self‑convolution), repeatedly upsamples the current best vector, and finishes
with deterministic pairwise moves followed by a short simulated‑annealing
clean‑up.  All operations respect a global 1000 s time budget.
"""

from __future__ import annotations

import time
import math
import numpy as np
from numpy.fft import rfft, irfft

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, sum(x)=s}."""
    if s < 0:
        raise ValueError("simplex radius must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho_arr.size == 0:
        theta = 0.0
    else:
        rho = rho_arr[-1]
        theta = cssv[rho] / (rho + 1)
    return np.maximum(v - theta, 0.0)

# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using real FFT (length 2·n‑1)."""
    n = a.shape[0]
    need = 2 * n - 1
    size = 1 << ((need - 1).bit_length())
    A = rfft(a, n=size)
    conv = irfft(A * A, n=size)
    return conv[:need]

# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a with sum(a)=1."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    return 2.0 * n * b.max()

# ----------------------------------------------------------------------
# Analytic families ----------------------------------------------------
def _distribution_uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)


def _distribution_arcsine(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals


def _distribution_beta_sym(n: int, p: float) -> np.ndarray:
    """Symmetric Beta(p,p) on the regular grid."""
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    w = np.exp((p - 1) * np.log(x) + (p - 1) * np.log(1.0 - x))
    if w.sum() == 0.0:
        w = np.full_like(w, 1.0 / n)
    else:
        w /= w.sum()
    return w


def _distribution_dirichlet(n: int, rng: np.random.Generator) -> np.ndarray:
    alpha = rng.uniform(0.01, 2.0)
    a = rng.dirichlet(np.full(n, alpha))
    return a.astype(np.float64)


def _distribution_random_sparse(
    n: int, rng: np.random.Generator, density: float = 0.006
) -> np.ndarray:
    k = max(2, int(n * density))
    idx = rng.choice(n, size=k, replace=False)
    vals = np.zeros(n, dtype=np.float64)
    vals[idx] = rng.random(k)
    if vals.sum() == 0.0:
        vals[0] = 1.0
    vals /= vals.sum()
    return vals


def _mix_with_uniform(base: np.ndarray, lam: float) -> np.ndarray:
    """lam·U + (1‑lam)·base, where U is the uniform distribution."""
    n = base.shape[0]
    uniform = np.full(n, 1.0 / n, dtype=np.float64)
    return lam * uniform + (1.0 - lam) * base

# ----------------------------------------------------------------------
def _softmax_descent(
    a: np.ndarray,
    deadline: float,
    best_seq: np.ndarray,
    best_score: float,
    lr0: float = 0.6,
    beta: float = 0.9,
    temp0: float = 0.3,
    temp_decay: float = 0.9997,
    min_temp: float = 1e-4,
    eval_interval: int = 150,
    patience: int = 1500,
) -> tuple[np.ndarray, float]:
    """
    Entropy‑mirror descent on the exact objective using a soft‑max
    approximation of the ℓ∞‑norm.

    Parameters
    ----------
    a          – initial probability vector (sum = 1)
    deadline   – absolute time after which the optimisation must stop
    best_seq   – current globally best sequence (for early replacement)
    best_score – its objective value
    lr0        – initial learning rate (η_t = lr0 / sqrt(t))
    beta       – momentum coefficient
    temp0      – initial temperature for the soft‑max
    temp_decay – multiplicative cooling factor per iteration
    min_temp   – lower bound for the temperature
    eval_interval – how often (iterations) the exact objective is evaluated
    patience   – number of evaluations without improvement before a jitter

    Returns
    -------
    (best_seq, best_score) – possibly improved global best.
    """
    n = a.shape[0]
    rng = np.random.default_rng()
    t = 0
    no_improve = 0
    momentum = np.zeros_like(a)
    temp = temp0

    # pre‑allocate the FFT size (it never changes for a given n)
    need = 3 * n - 2                      # length of a * w_rev
    size = 1 << ((need - 1).bit_length())

    while time.time() < deadline and t < 800_000:
        t += 1

        # ---- convolution and soft‑max weights ----
        conv = _fft_self_convolve(a)                 # length 2n‑1
        max_c = conv.max()
        # soft‑max centred at the maximum
        w = np.exp((conv - max_c) / temp)
        w_sum = w.sum()
        w /= w_sum

        # ---- gradient of the smoothed max ----
        w_rev = w[::-1]                              # length 2n‑1
        A = rfft(a, n=size)
        W = rfft(w_rev, n=size)
        full = irfft(A * W, n=size)[:need]           # length 3n‑2
        grad = 2.0 * full[2 * n - 2 : 2 * n - 2 + n]  # slice for i=0..n‑1

        # ---- momentum update ----
        momentum = beta * momentum + (1.0 - beta) * grad

        # ---- step size and exponentiated update ----
        eta = lr0 / math.sqrt(t)
        a = a * np.exp(-eta * momentum)

        # ---- projection onto the simplex ----
        a_sum = a.sum()
        if a_sum == 0.0:
            a = np.full(n, 1.0 / n, dtype=np.float64)
        else:
            a /= a_sum

        # ---- temperature cooling ----
        temp = max(min_temp, temp * temp_decay)

        # ---- occasional evaluation & bookkeeping ----
        if t % eval_interval == 0:
            cur = _objective(a)
            if cur + 1e-14 < best_score:
                best_score, best_seq = cur, a.copy()
                no_improve = 0
                print(f"[{time.time():.1f}] it={t:,} new global best {best_score:.6f}")
                # early stop if target already reached
                if best_score < 1.503:
                    return best_seq, best_score
            else:
                no_improve += 1

        # ---- jitter if stuck ----
        if no_improve >= patience:
            jitter = rng.exponential(scale=0.003, size=n)
            a = a + jitter
            a = np.maximum(a, 0.0)
            a /= a.sum()
            no_improve = 0

    return best_seq, best_score


# ----------------------------------------------------------------------
def _pairwise_swap_local(
    a: np.ndarray,
    deadline: float,
    best_seq: np.ndarray,
    best_score: float,
    max_trials: int | None = None,
) -> tuple[np.ndarray, float]:
    """
    Greedy deterministic sweep: pick a source index i with positive mass,
    move a random fraction to a random destination j and keep the move only
    if it improves the exact objective.
    """
    n = a.shape[0]
    trials = 0
    rng = np.random.default_rng()
    while time.time() < deadline:
        if max_trials is not None and trials >= max_trials:
            break
        trials += 1

        src = np.where(a > 1e-12)[0]
        if src.size == 0:
            break
        i = rng.choice(src)
        j = rng.integers(n - 1)
        if j >= i:
            j += 1

        delta = a[i] * rng.random() * 0.33
        if delta < 1e-14:
            continue

        new_a = a.copy()
        new_a[i] -= delta
        new_a[j] += delta

        cur = _objective(new_a)
        if cur + 1e-14 < best_score:
            a = new_a
            best_score = cur
            best_seq = a.copy()
            print(
                f"[{time.time():.1f}] swap {i}->{j} δ={delta:.3e} new best {best_score:.6f}"
            )

    return best_seq, best_score


# ----------------------------------------------------------------------
def _random_local_search(
    a: np.ndarray,
    deadline: float,
    best_seq: np.ndarray,
    best_score: float,
    init_temp: float = 0.008,
    decay: float = 0.9995,
) -> tuple[np.ndarray, float]:
    """
    Cheap simulated‑annealing style search.  Mass is transferred between two
    random positions; a worsening move is accepted with Metropolis probability.
    """
    n = a.shape[0]
    rng = np.random.default_rng()
    T = init_temp
    while time.time() < deadline:
        i = rng.integers(n)
        j = rng.integers(n - 1)
        if j >= i:
            j += 1
        delta = a[i] * rng.random() * 0.28
        if delta < 1e-14:
            continue
        new_a = a.copy()
        new_a[i] -= delta
        new_a[j] += delta
        cur = _objective(new_a)
        if cur + 1e-14 < best_score:
            a = new_a
            best_score = cur
            best_seq = a.copy()
            print(
                f"[{time.time():.1f}] SA improve {i}->{j} Δ={delta:.3e} best {best_score:.6f}"
            )
        else:
            if rng.random() < math.exp(-(cur - best_score) / max(T, 1e-12)):
                a = new_a
        T *= decay
    return best_seq, best_score


# ----------------------------------------------------------------------
def _upsample(seq: np.ndarray, new_len: int) -> np.ndarray:
    """Linear interpolation of a simplex‑vector to a larger length."""
    old_len = seq.shape[0]
    if new_len == old_len:
        return seq.copy()
    x_old = np.linspace(0.0, 1.0, old_len)
    x_new = np.linspace(0.0, 1.0, new_len)
    new_seq = np.interp(x_new, x_old, seq)
    new_seq = np.maximum(new_seq, 0.0)
    new_seq /= new_seq.sum()
    return new_seq


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:

    Search for a non‑negative step function that minimises ``evaluate_sequence``.
    The whole search respects the given time budget (default 1000 s).

    Returns a plain Python list of heights.
    """
    rng = np.random.default_rng(seed)
    start = time.time()
    deadline = start + budget_s - 4.0  # safety margin

    # ------------------------------------------------------------------
    # 1️⃣  Seed generation (moderate size)
    n0 = 5000
    seeds: list[np.ndarray] = []

    # a) deterministic families
    seeds.append(_distribution_uniform(n0))
    seeds.append(_distribution_arcsine(n0))

    # b) arcsine mixed with uniform (different lambdas)
    for lam in (0.0, 0.15, 0.30, 0.45):
        seeds.append(_mix_with_uniform(_distribution_arcsine(n0), lam))

    # c) symmetric beta (fine grid around 0.5)
    for p in (0.35, 0.45, 0.55, 0.65, 0.75):
        seeds.append(_distribution_beta_sym(n0, p))

    # d) a few random Dirichlet vectors
    for _ in range(3):
        seeds.append(_distribution_dirichlet(n0, rng))

    # e) sparse random vectors
    for _ in range(2):
        seeds.append(_distribution_random_sparse(n0, rng, density=0.008))

    except Exception:
        pass

    # pick the best seed according to the exact objective
    best_seq: np.ndarray | None = None
    best_score = float("inf")
    for s in seeds:
        sc = _objective(s)
        if sc < best_score:

    if best_seq is None:  # very unlikely, fallback
        best_seq = _distribution_uniform(n0)

    # 2️⃣  First refinement on the moderate size vector

        best_seq, best_score = _softmax_descent(
            best_seq.copy(),
            sub_deadline,
            best_seq=best_seq,
            best_score=best_score,
            lr0=0.6,
            beta=0.9,
            temp0=0.35,
            temp_decay=0.9998,
            min_temp=5e-5,
            eval_interval=120,
            patience=1200,
        )
        print(f"[{time.time():.1f}] after first descent best {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3️⃣  Hierarchical up‑sampling + refinement
    while True:
        remaining = deadline - time.time()
        if remaining < 70.0:
            break
        cur_n = len(best_seq)
        new_n = min(cur_n * 2, 25000)
        if new_n == cur_n:
            break
        print(f"[{time.time():.1f}] up‑sampling {cur_n} → {new_n}")
        up_seq = _upsample(best_seq, new_n)

        # allocate a reasonable share of the remaining budget to this level

        up_seq, up_score = _softmax_descent(
            up_seq,
            sub_deadline,
            best_seq=best_seq,
            best_score=best_score,
            lr0=0.55,
            beta=0.92,
            temp0=0.25,
            temp_decay=0.9997,
            min_temp=1e-4,
            eval_interval=150,
            patience=1500,
        )
        if up_score < best_score:
            best_score, best_seq = up_score, up_seq.copy()
            print(f"[{time.time():.1f}] new global best after up‑sample {best_score:.6f}")
        # continue the loop – another up‑sample if time permits

    # ------------------------------------------------------------------
    # 4️⃣  Deterministic pairwise refinement (greedy mass transfers)

        best_seq, best_score = _pairwise_swap_local(

            deadline,

        best_seq, best_score = _random_local_search(
            best_seq.copy(),
            deadline,
            best_seq=best_seq,
            best_score=best_score,
            init_temp=0.008,
            decay=0.9995,
        )

    print(
        f"Final best score: {best_score:.6f} (length={len(best_seq)})"
    )
    # return a plain Python list; ``evaluate_sequence`` will perform its own clipping
    return best_seq.tolist()
```
