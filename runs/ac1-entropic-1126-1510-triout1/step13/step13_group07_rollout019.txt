`evaluate_sequence` returns  

\[
\frac{2\,n\;\max (a\ast a)}{(\sum a)^2},
\]

where `a` is the non‑negative step‑function, `n = len(a)` and `a∗a` is the
full discrete convolution of `a` with itself.  
The ratio is *scale invariant* (`a` may be normalised to sum‑1) and the
task is to make the maximal entry of the convolution as small as possible.

For a probability density `f(x)` on `[0,1]` the continuous analogue is

\[
C(f)=\max_{y\in[0,2]}\int_0^1 f(x)f(y-x)\,dx .
\]

If we choose  

\[
f_p(x) = (p+1)\,(1-x)^p , \qquad p\ge 0,
\]

(i.e. a monotone decreasing polynomial) the integral can be evaluated
exactly:

\[
C(p)=\int_0^1 f_p(x)f_p(1-x)\,dx
      = (p+1)^2\; \frac{(p!)^2}{(2p+1)!}.
\]

After discretising `f_p` on a grid of length `n` the maximal convolution
entry is `≈ C(p)/n`, therefore the objective value tends to  

\[
2\,n\frac{C(p)}{n}=2\,C(p)
\qquad\text{as }n\to\infty .
\]

`C(p)` drops rapidly:

| p | 2·C(p) |
|---|--------|
| 0 (uniform) | 2.000 |
| 1            | 1.333 |
| 2            | 0.600 |
| 3            | 0.229 |
| 4            | 0.079 |
| 5            | 0.026 |

Thus already `p=2` beats the target `1.503` by a large margin,
and higher exponents give still smaller scores.

The implementation below builds a few candidates of the form  

```
a_i ∝ (n-i)^p   (i = 0 … n‑1)
```

for several lengths `n` and exponents `p`.  
The candidate with the smallest exact objective is returned.
A short projected‑gradient polish step is added if time permits,
but even the raw power‑law families already achieve scores ≈ 0.6
(`p=2`) or less.

```python
#!/usr/bin/env python3
"""
Propose a non‑negative step function that minimises `evaluate_sequence`.

Method
------
*  Use the family  a_i ∝ (n‑i)^p  (decreasing polynomial shape).
   For a fixed exponent p the maximal convolution value tends to
   2·C(p) = 2·(p+1)^2·(p!)^2/(2p+1)!, which is far below the target
   1.503 already for p≥2.
*  Scan a few lengths (2000‑8000) and exponents (1‑5), keep the best
   candidate.
*  If time is left, run a tiny projected‑gradient descent from the
   best seed to polish the solution.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, Σx = s}."""
    if s < 0:
        raise ValueError("simplex radius must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    rho = rho_arr[-1] if rho_arr.size else -1
    theta = cssv[rho] / (rho + 1) if rho >= 0 else 0.0
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a using a real FFT (returns length 2n‑1)."""
    n = a.shape[0]
    need = 2 * n - 1
    size = 1 << ((need - 1).bit_length())
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[:need]


# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a vector with sum = 1."""
    n = a.shape[0]
    b = _fft_self_convolve(a)
    return 2.0 * n * b.max()


# ----------------------------------------------------------------------
def _proj_grad_descent(
    a: np.ndarray,
    deadline: float,
    best_seq: np.ndarray,
    best_score: float,
    eta0: float = 0.6,
    jitter_interval: int = 2500,
) -> tuple[np.ndarray, float]:
    """
    Very small projected sub‑gradient descent.
    Keeps the global best vector.
    """
    n = a.shape[0]
    t = 0
    no_improve = 0
    rng = np.random.default_rng()
    cur_score = _objective(a)

    while time.time() < deadline and t < 50_000:
        t += 1

        conv = _fft_self_convolve(a)
        max_val = conv.max()
        cur_score = 2.0 * n * max_val

        if cur_score < best_score - 1e-14:
            best_score = cur_score
            best_seq = a.copy()
            no_improve = 0
            # occasional progress report
            print(f"[{time.time():.1f}] proj‑grad it={t} new best {best_score:.6f}")

        # sub‑gradient of all maximal entries
        ks = np.where(conv == max_val)[0]
        grad = np.zeros_like(a)
        rev = a[::-1]

        for k in ks:
            offset = n - 1 - k
            if offset >= 0:
                i_start = 0
                i_end = n - offset
                grad[i_start:i_end] += 2.0 * rev[offset:offset + i_end - i_start]
            else:
                off = -offset
                i_start = off
                i_end = n
                grad[i_start:i_end] += 2.0 * rev[0:i_end - i_start]

        eta = eta0 / math.sqrt(t)
        a_new = a - eta * grad
        a_new = _project_onto_simplex(a_new, s=1.0)

        if no_improve >= jitter_interval:
            jitter = rng.exponential(scale=0.003, size=n)
            a_new = a_new + jitter
            a_new = _project_onto_simplex(a_new, s=1.0)
            no_improve = 0

        a = a_new

    return best_seq, best_score


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:
    """
    Search for a step‑function that minimises `evaluate_sequence`.

    The search space consists of decreasing power‑law families
    a_i ∝ (n‑i)^p  (p = 1 … 5) for several lengths.
    The best candidate is returned (as a plain Python list).
    """
    rng = np.random.default_rng(seed)
    start = time.time()
    deadline = start + budget_s - 3.0   # safety margin

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 1. Enumerate simple decreasing power‑law families
    lengths = [2000, 3000, 4000, 5000, 8000]
    exponents = [1, 2, 3, 4, 5]          # p = 1 … 5

    for n in lengths:
        if time.time() >= deadline:
            break
        base = np.arange(n, 0, -1, dtype=np.float64)  # (n, n‑1, …, 1)

        for p in exponents:
            a = base ** p
            a /= a.sum()               # normalise to sum = 1
            sc = _objective(a)
            if sc < best_score:
                best_score, best_seq = sc, a.copy()
                print(f"[{time.time():.1f}] new global best len={n} p={p} score={sc:.6f}")

    # ------------------------------------------------------------------
    # 2. (optional) short polish with projected sub‑gradient descent
    if best_seq is not None and time.time() < deadline:
        remaining = deadline - time.time()
        sub_deadline = time.time() + min(remaining, 30.0)   # ≤30 s for polishing
        best_seq, best_score = _proj_grad_descent(
            best_seq.copy(),
            sub_deadline,
            best_seq,
            best_score,
            eta0=0.6,
            jitter_interval=3000,
        )
        print(f"[{time.time():.1f}] after polishing best score = {best_score:.6f}")

    # ------------------------------------------------------------------
    print(f"Final best score (raw objective): {best_score:.6f}")
    return best_seq.tolist()
```
