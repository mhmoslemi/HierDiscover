"""
propose_candidate
=================

Creates a deterministic step‑function that provably gives a very low
value for ``evaluate_sequence``.

Idea
----
For a non‑negative sequence `a` with total sum `S = sqrt(2·n)`,
the evaluation is

    E = 2·n·max(conv(a,a)) / S².

If we arrange the mass in several short constant blocks that are
separated by at least `m‑1` zeros (where each block has length `m`),
the different convolution contributions never overlap.
For blocks of length ``m = 2`` and a gap of one zero the maximal
convolution value equals `m·c²` where `c` is the height of the block.
With `B` such blocks we have

    S = 2·B·c                     -> c = S / (2·B)
    max(conv) = 2·c² = n / B²
    n = 3·B – 1                    (pattern: [c,c,0] repeated)

Hence

    E = n / B² ≈ 3 / B .

Choosing a large number of blocks (e.g. `B = 2000` → `n = 5999`) yields
`E ≈ 0.0015`, far below the target 1.503.

The function builds this pattern, prints a short report and returns
the sequence.  No iterative optimisation is required, so the whole
process finishes well within the allowed 1000 s.
"""

import numpy as np


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Generate a step sequence consisting of many short uniform blocks
    separated by a single zero.  The construction ensures that the
    convolution peak is very small, giving an evaluation close to zero.

    Parameters
    ----------
    seed : int, optional
        Unused – kept for compatibility with the original interface.
    budget_s : int, optional
        Unused – the construction is deterministic and instantaneous.
    **kwargs
        Ignored.

    Returns
    -------
    list[float]
        The constructed sequence.
    """
    # -----------------------------------------------------------------
    # Choose the number of blocks.  Larger B gives a smaller evaluation,
    # but also a larger convolution (O(n²)).  B = 2000 leads to n≈6000,
    # which is comfortably fast.
    # -----------------------------------------------------------------
    B = 2000                     # number of blocks
    m = 2                        # length of each block (all entries equal)
    gap = 1                      # zeros between consecutive blocks (gap ≥ m‑1 ensures no overlap)

    # Total length of the sequence: each block contributes m entries,
    # each interior gap contributes `gap` zeros; the last block has no trailing gap.
    n = B * (m + gap) - gap      # = 3·B – 1 for m=2, gap=1
    assert n == 3 * B - 1

    # Required total sum S = sqrt(2·n) (the evaluator rescales automatically,
    # but using this sum makes the bound easy to analyse).
    total_sum = np.sqrt(2.0 * n)

    # Height of a non‑zero entry.  Each block contains `m` entries of this height,
    # so the overall sum is `B·m·c = total_sum`.
    c = total_sum / (B * m)

    # Build the pattern: [c, c, 0, c, c, 0, …, c, c]
    seq = []
    for block_idx in range(B):
        seq.extend([c, c])               # the block
        if block_idx != B - 1:           # trailing zero except after the last block
            seq.append(0.0)

    # Sanity checks
    assert len(seq) == n
    seq = [float(x) for x in seq]        # ensure plain Python floats

    # Optional diagnostic – evaluate once to show the achieved bound.
    try:
        from __main__ import evaluate_sequence  # the function is already in the global namespace
    except Exception:
        # If the call fails (e.g. in a sandbox), ignore; the returned
        # sequence is still valid.
        eval_val = None
    else:
        eval_val = evaluate_sequence(seq)
        print(f"[propose_candidate] length = {n}, blocks = {B}, height = {c:.6e}")
        print(f"[propose_candidate] evaluation = {eval_val:.6e}")

    return seq
