"""
Propose a high‑performance step function.

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `n` is the length of the list.
For a monotone power law   a_i = (i+1)^p   (i = 0 .. n‑1)   the
asymptotic value of the score is

    C(p) = 2·(p+1)^2·Beta(p+1, p+1)
         = 2·(p+1)^2·(p!·p!)/(2p+1)!

which rapidly decreases when p grows (C(1)=4/3, C(2)=0.6,
C(3)≈0.23, C(4)≈0.08, …).  By scaling the whole vector so that the
largest entry equals the allowed maximum 1000 we keep the shape
while staying inside the evaluator’s clipping limits.  The score is
independent of the scaling factor, so any such rescaling yields the
same constant C(p).

The algorithm simply tries a few integer exponents, builds the
corresponding sequences, evaluates them and returns the best one.
All work fits easily into the 1000 s budget.

"""

import math
import numpy as np

def _make_power_sequence(n: int, p: int, vmax: float = 1000.0) -> list[float]:
    """
    Return a length‑n list a_i = ((i+1)^p) * (vmax / n^p).
    The maximum entry (i = n‑1) is exactly `vmax`.
    """
    # scaling factor so that (n)^p * factor = vmax
    factor = vmax / (n ** p)
    # build the list using a list‑comprehension (fast, no loops in C)
    return [((i + 1) ** p) * factor for i in range(n)]
