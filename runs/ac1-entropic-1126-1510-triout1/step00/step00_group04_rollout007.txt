* The true objective is  max_k (a*a)_k  (because the normalisation makes
  evaluate_sequence return exactly this value).
* We replace the hard max by a softmax with a temperature parameter β:
      f_β(a) = (1/β)·log ∑_k exp(β·(a*a)_k)
  whose gradient can be written in closed form using a correlation
  (cross‑correlation) between the current coefficients and the softmax
  weights.
* A simple projected gradient step is taken (non‑negativity + simplex
  projection).  Learning rate, β and a small amount of random noise are
  adapted during the run.
* The best sequence seen so far is stored and finally returned.

The method is completely self‑contained, uses only NumPy and the supplied

import time
import math
import numpy as np

def _softmax_weights(b, beta):
    """Return softmax weights w_k = exp(beta*b_k) / sum(exp(beta*b))."""
    # shift for numerical stability
    b_max = np.max(b)
    exp_term = np.exp(beta * (b - b_max))
    w = exp_term / exp_term.sum()
    return w

    """
    Gradient of the soft‑max approximated objective with respect to `a`.

    Parameters

    a : ndarray (n,)

    w : ndarray (2*n-1,)

    grad : ndarray (n,)
