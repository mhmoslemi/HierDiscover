Gradient‐based smoothing search for a step‑function that minimizes
evaluate_sequence.  The algorithm treats the problem as
minimise max_k (a*a)[k] under a_i ≥ 0, ∑a_i = 1.
It uses a smooth approximation of the max (log‑sum‑exp) and a
multiplicative (mirror) update that stays on the probability simplex.
Random restarts of moderate length (200‑600) are performed until the
time budget expires; the best sequence found is returned.
"""
import time
import numpy as np

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Search for a non‑negative sequence that yields a low value of
    evaluate_sequence().  The routine runs for at most ``budget_s`` seconds
    and returns the best sequence discovered.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 2.0   # keep a small margin

    best_seq = None
    best_score = float('inf')
    iteration = 0

    # main outer loop – random restarts until time runs out
    while time.time() < deadline:
        # --------------------------------------------------------------
        # Choose a problem size (length of the step function).
        # Lengths between 200 and 600 give a good trade‑off between
        # quality of the bound (≈2n/(2n‑1)) and per‑iteration cost.
        # --------------------------------------------------------------
        n = np.random.randint(200, 601)

        # Random start on the simplex (Dirichlet(1,…,1))
        a = np.random.rand(n)
        a /= a.sum()                       # sum(a) = 1

        # Hyper‑parameters for the smoothed max optimisation.
        alpha = 1.0                         # smoothness of the log‑sum‑exp
        lr = 0.5                            # step size for the mirror update
        max_inner = 3000                    # safety cap on inner iterations

        for it in range(max_inner):
            # -----------------------------------------------------------------
            # Time check – abort inner loop if we are close to the global deadline.
            # -----------------------------------------------------------------

                break

            # --------------------------------------------------------------

            max_conv = conv.max()

            # --------------------------------------------------------------

                best_score = score
                best_seq = a.copy()
                print(f"[{time.time()-start:.1f}s] new best: {best_score:.6f} (n={n}, it={it})")

            # --------------------------------------------------------------

            w = np.exp(exp_arg)

"""
Gradient‑based search for a step‑function minimizing `evaluate_sequence`.

The objective for a non‑negative vector a (length n) is
    J(a) = 2 n·max_k (a*a)[k] / (sum_i a_i)^2 .
Because the ratio is scale‑invariant we fix sum_i a_i = 1, so
    J = 2 n·max_k C_k   where C = a convolve a .

We minimise the maximum convolution value over the simplex.
A smooth approximation of the max is used:
    L_α(a) = (1/α)·log Σ_k exp(α·C_k)      (α → ∞ gives the true max).

Mirror descent with an exponentiated‑gradient update stays on the
probability simplex:
    a ← a ∘ exp(−η·∇L_α) ,   then renormalise.

The gradient of L_α is a weighted sum of shifted copies of a;
it can be computed with a single convolution:
    ∇L_α[i] = 2·Σ_j a_j·w_{i+j},
where w is the soft‑max weight vector on the convolution indices.
The algorithm performs several random restarts with moderate lengths
(200‑600) until the time budget expires, keeping the best sequence
found.  Simple jitter is added occasionally to escape flat regions.
"""
import time
import numpy as np

def _softmax_weights(conv, alpha):
    """
    Returns a probability vector w_k ∝ exp(alpha * conv_k) in a numerically
    stable way (shifted by the maximum of conv).
    """
    max_c = conv.max()
    # shift to avoid overflow, all exponents ≤ 0
    exp_arg = alpha * (conv - max_c)
    w = np.exp(exp_arg)
    w_sum = w.sum()
    if w_sum == 0.0:
        # fallback to uniform weights (should not happen)
        w = np.full_like(w, 1.0 / w.size)
    else:
        w /= w_sum
    return w


def _gradient(a, w):
    """
    Compute the gradient of the smoothed max objective with respect to a.
    The formula is   g_i = 2 * Σ_j a_j * w_{i+j},
    which is obtained by a single convolution of the reversed a with w.
    """
    a_rev = a[::-1]                 # reverse a
    conv_full = np.convolve(a_rev, w)   # length 3n‑2
    n = a.shape[0]
    # slice that corresponds to Σ_j a_j w_{i+j}
    grad = 2.0 * conv_full[n - 1 : n - 1 + n]
    return grad

    Search for a sequence of non‑negative heights that yields a low value
    of `evaluate_sequence`.  Runs for at most `budget_s` seconds and
    returns the best sequence found (as a plain Python list of floats).
    """
    np.random.seed(seed)
    start_time = time.time()
    # leave a small safety margin for the caller
    deadline = start_time + budget_s - 2.0

    best_seq = None
    best_score = float("inf")
    outer_runs = 0

    # -----------------------------------------------------------------
    # Outer loop: random restarts of moderate size until we run out of time
    # -----------------------------------------------------------------
    while time.time() < deadline:
        n = np.random.randint(200, 601)          # length of the step function

        # random start on the probability simplex
        a = np.random.rand(n)
        a /= a.sum()                              # enforce sum = 1

        # hyper‑parameters for the smooth‑max optimisation
        alpha = 1.0                               # temperature of log‑sum‑exp
        lr = 0.5                                   # step size for mirror update
        max_inner = 800                           # safeguard on inner iterations
        patience = 200                            # stop if no improvement for this many steps
        no_improve = 0
        best_inner_score = float("inf")

        # -----------------------------------------------------------------
        # Inner optimisation loop (mirror descent on the smoothed max)
        # -----------------------------------------------------------------
        for it in range(max_inner):
            # time check
            if time.time() >= deadline:
                break

            # 1) convolution and current (exact) score
            conv = np.convolve(a, a)                # length 2n‑1
            max_conv = conv.max()
            score = 2.0 * n * max_conv               # exact J because sum(a)=1

            # 2) update global best if this is an improvement
            if score < best_score:
                best_score = score
                best_seq = a.copy()
                print(f"[{time.time() - start_time:.1f}s] New best: {best_score:.6f} "

                # if we already beat a reasonable target we could stop early,

            # 3) check inner‑loop progress (early stop if stuck)
            if score + 1e-12 < best_inner_score:
                best_inner_score = score
                no_improve = 0
            else:
                no_improve += 1
                if no_improve >= patience:
                    break

            # 4) soft‑max weights for the smooth max
            w = _softmax_weights(conv, alpha)

            # 5) gradient of the smooth objective
            grad = _gradient(a, w)

            # 6) mirror (exponentiated) update that stays on the simplex
            a = a * np.exp(-lr * grad)
            eps = 1e-16
            a = np.maximum(a, eps)                 # avoid exact zeros
