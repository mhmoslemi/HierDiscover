"""
Propose a step‑function that gives a very small value of the
evaluation function.

The evaluation is
    2 * n * max(conv(a, a)) / (sum(a) ** 2)

For non‑negative sequences the maximum of the convolution is achieved
either at the centre (where many terms overlap) or at the far edge
where the square of the largest entry appears.  By making the sequence
strictly increasing the centre term is minimized (rearrangement
inequality).  Using a power‑law shape

        a_i = 1000 * (i/(n-1))**p ,  i = 0 … n‑1

keeps the entries in the allowed range [0,1000] and lets us control the
ratio analytically:

    A = ∫_0^1 t^p dt = 1/(p+1)
    C = ∫_0^1 t^p (1-t)^p dt = Beta(p+1, p+1)

If the centre term C·n·10⁶ is ≤ 10⁶ (the edge square), the edge term
dominates and the evaluation becomes

        R = 2 * (p+1)² / n .

Choosing the smallest integer p for which C·n ≤ 1 guarantees the edge
term dominates.  For the usual construction length (≈ 4000) this is
p = 6, giving R ≈ 0.025, far better than the target 1.503.

The function below builds this sequence (using the length of the
available `height_sequence_1` when possible) and returns it.  A single
call to `evaluate_sequence` is performed only for logging.
"""

import time
import math

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    # Determine a convenient length.
    try:
        n = len(height_sequence_1)          # use the existing construction length
    except Exception:
        n = 4000                            # fallback length

    # Exponent chosen to keep the centre convolution ≤ edge square.
    # For n ≈ 4000 the smallest such integer is p = 6.
    p = 6

    # Build the monotone power‑law sequence.
    # a_i = 1000 * (i / (n-1))**p ,   i = 0,…,n-1
    # This respects all security checks in evaluate_sequence.
    if n == 1:
        seq = [1000.0]          # trivial single‑element case
    else:
        inv = 1.0 / (n - 1)
        seq = [1000.0 * ((i * inv) ** p) for i in range(n)]

    # Optional: compute the actual score for reporting.
    try:
        score = evaluate_sequence(seq)
        print(f"Constructed candidate: n={n}, p={p}, eval={score:.6f}")
    except Exception as e:
        # In the unlikely event of an error, just report INF.
        score = float('inf')
        print(f"Error during evaluation: {e}")

    # Return the sequence – it will be used by the outer harness.
    return seq
