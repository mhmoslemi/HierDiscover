assistantfinal**Solution Overview**

The evaluation function  

\[
\text{score}(a)=\frac{2n\;\max (a*a)}{(\sum a)^2}
\]

is *scale‑invariant*: multiplying the whole vector by any positive constant does not change the score.
Let  

\[
S=\sum a_i,\qquad n=\text{len}(a).
\]

Because all entries are non‑negative,
\[
\max (a*a)\;\ge\;(a*a)_{0}= \sum a_i^{2}
          \;\ge\; \frac{S^{2}}{n}\qquad\text{(Cauchy–Schwarz)} .
\]

Hence  

\[
\text{score}(a) \ge
\frac{2n\;S^{2}/n}{S^{2}} = 2 .
\]

The lower bound **2** is attained by the *uniform* sequence  

\[
a_i = \frac{\sqrt{2n}}{n}\quad (i=0,\dots,n-1),
\]

so the optimal value of the objective is known analytically.
The algorithm below therefore

1. builds the optimal uniform sequence (using the length of the
   provided `height_sequence_1` when it exists, otherwise a default length);
2. performs a very cheap stochastic search (Gaussian perturbations) that
   **only accepts a candidate if it strictly improves the score**.
   Because the theoretical optimum is already reached, the search never
   finds a better point, but it guarantees that the function always returns a
   valid sequence (the uniform one) well before the 1000 s deadline.

The implementation follows the required interface and prints intermediate
information for debugging.

```python
"""
Uniform‑optimal step function search.

The evaluation function is lower‑bounded by 2 (Cauchy–Schwarz).  
A flat sequence a_i = sqrt(2·n)/n reaches this bound, therefore it is
globally optimal.  The algorithm builds this uniform sequence,
then tries a tiny random perturbation loop that only keeps a new
candidate when the score improves – which never happens, but guarantees
that a valid answer is returned quickly.
"""

import time
import math
import random
import numpy as np

# The evaluation function is available in the execution environment
# as evaluate_sequence.  Do **not** import or redefine it.


def uniform_sequence(length: int) -> list[float]:
    """
    Return the optimal uniform sequence of given length:
    a_i = sqrt(2·length) / length  (all entries identical and non‑negative).
    """
    if length <= 0:
        raise ValueError("length must be positive")
    value = math.sqrt(2.0 * length) / length
    return [value] * length


def perturb_sequence(seq: list[float], sigma: float) -> list[float]:
    """
    Add Gaussian noise with standard deviation sigma to each element,
    then apply the same clipping that evaluate_sequence does
    (non‑negative, capped at 1000).

    The function returns a *new* list; the original sequence is untouched.
    """
    perturbed = []
    for x in seq:
        y = x + random.gauss(0.0, sigma)
        # Clip exactly as evaluate_sequence does
        if y < 0.0:
            y = 0.0
        elif y > 1000.0:
            y = 1000.0
        perturbed.append(y)
    return perturbed


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Return a sequence of non‑negative heights that (almost certainly) attains
    the optimal score 2.0.

    The routine:
    * builds the uniform sequence of the same length as the global
      variable ``height_sequence_1`` when it exists,
      otherwise a default length of 2000,
    * evaluates it,
    * runs a very short stochastic improvement loop (Gaussian perturbations)
      that only accepts strictly better scores,
    * finally returns the best sequence found.

    The total run time is far below the 1000 s budget, guaranteeing
    a valid answer.
    """
    # ------------------------------------------------------------------
    # 1. initialise random seed and timing
    # ------------------------------------------------------------------
    random.seed(seed)
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0   # keep a small safety margin

    # ------------------------------------------------------------------
    # 2. Choose a starting length and build the uniform sequence
    # ------------------------------------------------------------------
    try:
        # ``height_sequence_1`` is provided by the surrounding framework.
        # If it exists we reuse its length (the problem statement
        # suggests that length ≈ 2153 is a good start).
        length = len(height_sequence_1)
        print(f"Using length from height_sequence_1: {length}")
    except NameError:
        length = 2153          # a reasonable default when the variable is missing
        print(f"height_sequence_1 not found – using default length {length}")

    best_seq = uniform_sequence(length)
    best_score = evaluate_sequence(best_seq)
    print(f"Initial uniform sequence score: {best_score:.12f}")

    # If for some unforeseen reason the uniform sequence is not optimal,
    # we will try a tiny stochastic search.
    # The parameters are deliberately very modest: we only need to stay
    # under the time limit.
    sigma = 0.02 * max(best_seq)   # step size proportional to the typical entry
    iteration = 0

    while time.time() < deadline:
        iteration += 1
        # Generate a candidate by perturbation
        cand = perturb_sequence(best_seq, sigma)

        # Evaluate the candidate
        try:
            cand_score = evaluate_sequence(cand)
        except Exception as e:
            # Any unexpected error (should not happen) is ignored.
            print(f"Evaluation exception at iteration {iteration}: {e}")
            continue

        # Accept only if we have a *strict* improvement (lower score).
        # Because the theoretical optimum is 2, this never occurs,
        # but the check keeps the algorithm safe.
        if cand_score < best_score:
            print(f"Iteration {iteration}: improved score {cand_score:.12f}")
            best_score = cand_score
            best_seq = cand
            # Optionally tighten the perturbation size after a success
            sigma *= 0.9
        else:
            # Occasionally shrink sigma to explore finer neighbourhoods
            if iteration % 200 == 0:
                sigma *= 0.99

        # Very cheap early‑exit: if we ever hit the theoretical lower bound
        # (within floating‑point tolerance) we stop searching.
        if best_score <= 2.0000001:
            break

    elapsed = time.time() - start_time
    print(f"Search finished after {iteration} iterations, elapsed {elapsed:.2f}s")
    print(f"Best score returned: {best_score:.12f}")

    # ------------------------------------------------------------------
    # 3. Return the best sequence found.
    # ------------------------------------------------------------------
    return best_seq
```
