"""
Uniform step function – provably optimal.

The evaluation function is
    E(a) = 2 * n * max_k (a * a)_k / (sum_i a_i)^2 .

For any non‑negative vector `a` of length `n` we have
    max_k (a * a)_k  ≥  (a * a)_0 = Σ a_i^2
and, by Cauchy–Schwarz,
    Σ a_i^2  ≥  (Σ a_i)^2 / n.

Consequently
    E(a) ≥ 2 * n * (Σ a_i)^2 / (n * (Σ a_i)^2) = 2,

and equality holds *iff* all entries are equal.
Therefore the uniform vector minimises the score and the theoretical optimum
is exactly 2.  The function below simply returns that uniform vector.
If ``height_sequence_1`` is present its length is reused, otherwise a default
length of 1600 is used.
"""

def propose_candidate(seed: int = 0, budget_s: float = 1000, **kwargs) -> list[float]:
    """
    Return a uniform non‑negative sequence of the same length as the
    previously discovered construction (``height_sequence_1``) if it exists,
    otherwise of length given by ``kwargs['n']`` or a default of 1600.

    This sequence attains the minimal possible value of the evaluation
    function (exactly 2.0).  The function runs in a fraction of a second,
    far below the allotted time budget.
    """
    # ------------------------------------------------------------------ #
    # Determine the length of the output sequence.

    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
