The code below implements a *pair‑wise simulated‑annealing* optimizer for the
step‑function problem.  
The idea is simple:

1. **Feasibility** – the vector `a` is always projected onto the simplex  

   \[
   \{x\ge 0,\;\sum_i x_i = \sqrt{2n}\}
   \]

   so the normalisation required by `evaluate_sequence` is guaranteed.

2. **Local move** – pick two indices `i ≠ j`.  
   Remove a small amount `δ` from `a[i]` and add it to `a[j]`.  
   The convolution `c = a∗a` can be updated *exactly* in **O(n)** by the
   identities derived from  

   \[
   (a+d)\ast(a+d)=a\ast a+2\;(a\ast d)+d\ast d .
   \]

   No full recomputation of the convolution is needed.

3. **Annealing** – a temperature `T` controls the probability of accepting a
   move that increases the current objective  

   \[
   \operatorname{score}= \max_k (a\ast a)[k].
   \]

   `T` and the step size are multiplied by a factor < 1 each iteration,
   turning the algorithm from a high‑temperature exploratory phase into a
   fine‑grained descent.

4. **Restarts & block post‑processing** – after a long period without
   improvement the algorithm is restarted from a fresh random point.  In the
   final seconds a cheap “block‑search’’ is performed: the best solution found
   is turned into a piece‑wise constant function (2‑6 blocks) – a pattern that
   often reduces the max‑convolution further.

The whole routine stays well inside the 1000 s wall‑clock budget, uses only a
single CPU and complies with the required function signature.

```python
pairwise_annealing.py

Simulated annealing with exact O(n) convolution updates.
The algorithm moves mass between two positions, updates the auto‑correlation
exactly, and accepts moves according to a decreasing temperature schedule.
A final cheap block‑search refines the best solution.

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """
    Euclidean projection of a vector onto the simplex
        {x ≥ 0, Σ x = z}.
    """
    if z < 0:
        raise ValueError("Target sum z must be non‑negative.")
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

    # --------------------------------------------------------------
    # Annealing parameters
    T          = cur_max * 0.5               # initial temperature
    T_min      = 1e-6
    cooling    = 0.9998                      # per iteration
    step_frac  = 0.5                         # initial fraction of mass moved
    step_decay = 0.9999

    conv_len = 2 * n - 1
    # reusable buffers (avoid per‑iteration allocation)
    mask      = np.zeros(conv_len, dtype=bool)
    delta_arr = np.zeros(conv_len, dtype=float)

    idx_array = np.arange(n)
    it = 0
    no_improve = 0

    # --------------------------------------------------------------
    while time.time() < deadline:
        # ---- choose a source index weighted by its current mass ----
        total = a.sum()
        if total == 0.0:
            break
        probs = a / total
        i = np.random.choice(idx_array, p=probs)

        # source must have some mass
        if a[i] < 1e-12:
            continue

        # ---- choose a distinct destination index -----------------
        j = np.random.randint(0, n - 1)
        if j >= i:
            j += 1

        # ---- size of the transfer --------------------------------
        max_delta = a[i]
        delta = max_delta * step_frac * np.random.rand()
        if delta < 1e-12:
            continue

        # ---- build mask of affected convolution entries ----------
        mask.fill(False)
        start_i = i
        end_i   = i + n
        start_j = j
        end_j   = j + n
        mask[start_i:end_i] = True
        mask[start_j:end_j] = True
        mask[2 * i] = True
        mask[2 * j] = True
        mask[i + j] = True

        # ---- delta contributions (exact) -------------------------
        delta_arr.fill(0.0)
        delta_arr[start_i:end_i] -= 2.0 * delta * a
        delta_arr[start_j:end_j] += 2.0 * delta * a
        delta_arr[2 * i] += delta * delta
        delta_arr[2 * j] += delta * delta
        delta_arr[i + j] -= 2.0 * delta * delta

        # ---- prospective new maximum -----------------------------
        # unaffected part
        if mask.all():
            max_unaffected = -np.inf
        else:
            max_unaffected = conv[~mask].max()
        # affected part
        affected_vals = conv[mask] + delta_arr[mask]
        max_affected = affected_vals.max()
        new_max = max(max_unaffected, max_affected)

        # ---- Metropolis acceptance --------------------------------
        accept = False
        if new_max < cur_max:
            accept = True
        else:
            if T > 0.0:
                prob = math.exp(-(new_max - cur_max) / T)
                if np.random.rand() < prob:
                    accept = True

        # ---- apply accepted move ---------------------------------
        if accept:
            # update convolution in place
            conv[start_i:end_i] -= 2.0 * delta * a
            conv[start_j:end_j] += 2.0 * delta * a
            conv[2 * i] += delta * delta
            conv[2 * j] += delta * delta
            conv[i + j] -= 2.0 * delta * delta

            # update the vector a
            a[i] -= delta
            a[j] += delta

            cur_max = new_max

            if cur_max < best_max - 1e-12:
                best_max = cur_max
                best_a = a.copy()
                best_conv = conv.copy()
                no_improve = 0
                print(f"[{it:08d}] new best = {best_max:.6f}")
            else:
                no_improve += 1
        else:
            no_improve += 1

        # ---- schedule update --------------------------------------
        T = max(T * cooling, T_min)
        step_frac = max(step_frac * step_decay, 0.01)

        # ---- occasional restart if stuck -------------------------
        if no_improve > 25000:
            a = np.random.rand(n)
            a = _project_to_simplex(a, target_sum)
            conv = np.convolve(a, a)
            cur_max = conv.max()
            T = cur_max * 0.5
            step_frac = 0.5
            no_improve = 0
            print(f"[{it:08d}] restart (stagnation)")
        it += 1

    # --------------------------------------------------------------
    # Final cheap block‑search (2‑6 constant blocks) – often gives a
    # small extra improvement.
    block_trials = 500
    for _ in range(block_trials):
        nb = np.random.randint(2, 7)                     # number of blocks
        cuts = np.sort(np.random.choice(n - 1, nb - 1, replace=False) + 1)
        blocks = np.split(np.arange(n), cuts)

        # preserve the total mass inside each block
        cand = np.empty_like(best_a)
        for blk in blocks:
            block_sum = best_a[blk].sum()
            if blk.size > 0:
                cand[blk] = block_sum / blk.size

        cand = _project_to_simplex(cand, target_sum)
        cand_conv = np.convolve(cand, cand)
        cand_max = cand_conv.max()
        if cand_max < best_max:
            best_max = cand_max
            best_a = cand.copy()
            best_conv = cand_conv
            print(f"[block] improved to {best_max:.6f}")

    print(f"[final] best score = {best_max:.6f} after {it} iterations")
    return best_a.tolist()
```
