Propose a step‑function (list of non‑negative heights) that minimises
`evaluate_sequence`.  

The algorithm uses a two‑phase projected Adam optimiser:

1. **Smoothed objective** –  Instead of the non‑smooth max,
   we minimise the log‑sum‑exp (LSE) of the self‑convolution,
   which is an upper bound on the max and has a convenient gradient.
   The smoothing parameter β is increased gradually, turning the
   objective into the true max.

2. **Refinement** –  After a preset number of iterations the optimisation
   switches to a standard sub‑gradient step that only looks at the
   currently maximal convolution entry.

All iterates are projected onto the probability simplex
(Σ a_i = 1, a_i ≥ 0) so the objective is scale‑invariant.
FFT‑based convolutions make each iteration O(n log n) and allow
hundreds of thousands of updates within the 1000 s budget.
Multiple lengths and random restarts are tried; the best sequence found
is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, Σx = s}."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho_arr.size == 0:
        theta = 0.0
    else:
        rho = rho_arr[-1]
        theta = cssv[rho] / (rho + 1)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
def _arcsine_distribution(n: int) -> np.ndarray:
    """Discrete arcsine distribution (probability vector) of length n."""
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray, size: int) -> np.ndarray:
    """Full self‑convolution a*a using FFT, result length = 2·len(a)‑1."""
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * a.shape[0] - 1]


# ----------------------------------------------------------------------
def _fft_cross_convolve(a: np.ndarray, b: np.ndarray, size: int) -> np.ndarray:
    """Full convolution a*b using FFT (real inputs)."""
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv
