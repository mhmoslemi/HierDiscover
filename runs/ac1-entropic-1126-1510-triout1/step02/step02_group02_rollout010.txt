Propose a step‑function with low 2·n·max(conv)/sum².

Algorithm (≈ three phases)

1️⃣  **Shape exploration** – sample a few simple families (uniform,
    inverse‑sqrt, double‑ended exponential, random block).  Each candidate
    is projected onto the simplex Σa = √(2 n) and scored with a fast FFT
    convolution.  The best of these becomes the start vector `f`.

2️⃣  **LP boosting** – repeat:
      * compute M = max(f∗f)
      * build the linear constraint  A·g ≤ M  where Aₖⱼ = fₖ₋ⱼ (zero when
        out of range).  This matrix is the full convolution matrix of `f`
        and is stored once in CSR form; only its data (the repeated values
        of `f`) are updated each iteration.
      * solve   max Σ gⱼ   s.t. A·g ≤ M , g ≥ 0   (via `scipy.optimize.linprog`,
        “highs” method).  The optimal `g₀` is scaled to the target sum
        √(2 n) → `g`.

        for `t`.  The step is accepted only when the new self‑convolution
        does not increase the current maximum `M`.  `t` is automatically
        reduced on rejection and slowly increased on success.
      The process monotonically drives down `M` and usually reaches a
      score below the target 1.503 within a few dozen iterations.

3️⃣  **Fine‑grained gradient polishing** – starting from the best vector
      obtained above, perform a smoothed projected gradient descent:
      * a soft‑max of the convolution entries provides differentiable
        weights approximating the ℓ∞‑norm,
      * the analytic gradient is computed by FFT‑based convolutions,
      * Nesterov momentum and Euclidean projection onto the simplex are

      * occasional small random perturbations help escape plateaus.

# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, Σx = z}."""
    if z < 0:
        raise ValueError("Target sum must be non‑negative.")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _conv_fft(u: np.ndarray, v: np.ndarray, size_fft: int) -> np.ndarray:
    """
    Linear convolution of u and v using FFT (output length len(u)+len(v)-1).
    The FFT size must be a power of two at least len(u)+len(v)-1.
    """
    fu = np.fft.rfft(u, n=size_fft)
    fv = np.fft.rfft(v, n=size_fft)
    conv = np.fft.irfft(fu * fv, n=size_fft)
    return conv[: len(u) + len(v) - 1]


# ----------------------------------------------------------------------
def _self_convolution(a: np.ndarray, size_fft: int) -> np.ndarray:
    """Return a * a (full discrete convolution)."""
    return _conv_fft(a, a, size_fft)


# ----------------------------------------------------------------------
def _weighted_gradient(a: np.ndarray, w: np.ndarray, size_fft: int) -> np.ndarray:
    """
    Gradient of Σ_k w_k·(a*a)_k with respect to a (weights w are fixed).
    Implements the analytic formula using FFTs.
    """
    n = a.shape[0]
    a_rev = a[::-1]
    # convolution of w with reversed a
    conv = _conv_fft(w, a_rev, size_fft)          # length = (2n-1)+(n)-1 = 3n-2
    start = n - 1                                 # index where Σ_k w_k a_{k-i} appears
    grad = 2.0 * conv[start:start + n]
    # subtract diagonal over‑counting (the term a_i·a_i appears only once)
    diag_w = w[0:2 * n - 1:2]                     # w_{2i}, length n
    grad -= a * diag_w
    return grad
