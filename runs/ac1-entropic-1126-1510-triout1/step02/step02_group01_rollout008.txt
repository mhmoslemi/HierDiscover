def lp_refine(a_initial, target_sum, max_iter, time_deadline):

    a = a_initial.copy()
    best_a = a.copy()
    best_score = np.max(np.convolve(a,a))
    # iterate
    while time.time() < time_deadline and iter < max_iter:
        conv_a = np.convolve(a,a)
        M = conv_a.max()
        # build constraints
        # Build sparse matrix for conv(f,b) <= M
        row = []
        col = []
        data = []
        # For each k in range(2*n-1)
        for k in range(2*n-1):
            start = max(0, k - (n-1))
            end = min(k, n-1)
            # j runs start..end
            # coefficient = a[k-j]
            # loop j = start..end
            for j in range(start, end+1):
                row.append(k)
                col.append(j)
                data.append(a[k-j])
        A_ub = sparse.csr_matrix((data, (row, col)), shape=(2*n-1, n))
        # objective
        c = -np.ones(n)
        # bounds per variable (0, 1000)
        bounds = [(0, 1000) for _ in range(n)]
        res = scipy.optimize.linprog(c, A_ub=A_ub, b_ub=np.full(2*n-1, M), bounds=bounds, method='highs')
        if not res.success:
            # fallback to break
            print("LP failed", res.message)
            break
        b = res.x
        sum_b = b.sum()
        if sum_b == 0:
            break
        alpha = target_sum / sum_b
        g = alpha * b
        # combine with mixing factor t (maybe 0.5)
        t = 0.5
        a = (1 - t) * a + t * g
        # ensure nonnegative and sum remains target via projection
        a = _project_to_simplex(a, target_sum)
        # evaluate score
        cur_score = np.max(np.convolve(a,a))
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[LP iter {iter}] new best = {best_score:.6f}")
        iter += 1

    return best_a, best_score

The score to minimise is  

\[
\text{score}= \frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2}\; .
\]

For a fixed length `n` the denominator is constant if we enforce  

\[
\sum_i a_i = \sqrt{2n},
\]

therefore minimising the score is exactly the problem  

\[
\min_{a\ge 0}\; \max_k (a*a)_k .
\]

The previous runner used a smooth‑max gradient descent with random restarts.
The new method adds a *linear‑programming refinement* that is provably
non‑increasing for the objective, followed by a short annealed projected‑gradient
phase and a cheap block‑search.

* **LP refinement** – given the current vector `f`, let `M = max(f*f)`.
  Solve  

  \[
  \max\;\sum_j b_j\quad\text{s.t.}\; (f*b)_k \le M \;(k=0\ldots 2n-2),\; b_j\ge0,\;b_j\le1000 .
  \]

  The feasible region is a polyhedron, the optimum is an extreme point with
  many active constraints.  After the LP we scale the solution to the required
  ℓ¹‑norm and move a small step towards it:
  `f ← (1‑t)·f + t·g` with `t≈0.4`.  
  Repeating this step quickly drives the maximum convolution down.

* **Annealed gradient phase** – once the LP has stalled we fall back to the
  soft‑max / hard‑max projected gradient scheme from the reference code,
  but with Adam‑style momentum and a slightly cooler temperature schedule.

* **Block search** – a final inexpensive search over piece‑wise‑constant
  vectors (2‑6 blocks) catches occasional improvements.

All steps respect the simplex constraint (`a_i ≥ 0`, `∑a_i = √(2n)`) using the
standard Euclidean projection.

The whole routine stays well below the 1000 s wall‑clock limit, uses at most
two CPUs, and returns the best sequence found.

propose_candidate
-----------------

Multi‑phase optimizer for the step‑function problem.

Phase 1  – Linear‑programming refinement (convex LP that maximises the ℓ¹‑norm
           under the current convolution bound).  This step provably reduces
           the maximum convolution.

Phase 2  – Annealed projected gradient descent with a soft‑max surrogate and
           Adam‑style momentum (the method from the reference code, but with
           a tighter schedule).

Phase 3  – Cheap block‑wise random search (2‑6 constant blocks) to polish the
           solution.

The routine respects the simplex {a≥0, Σa = √(2 n)} at every step and returns
the best vector found as a plain Python list.
"""

import time
import math
import numpy as np
import scipy.sparse as sp
import scipy.optimize

# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = z}."""
    if z < 0:
        raise ValueError("Target sum must be non‑negative")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _gradient_topk(a: np.ndarray, conv: np.ndarray, top_k: int = 5) -> np.ndarray:
    """Sub‑gradient of the hard max using the `top_k` largest convolution entries."""
    n = a.shape[0]
    idxs = np.argpartition(-conv, top_k - 1)[:top_k]
    grad = np.zeros_like(a)
    i = np.arange(n)
    for k in idxs:
        j = k - i
        mask = (j >= 0) & (j < n)
        grad[mask] += 2.0 * a[j[mask]]
        diag = mask & (i == j)
        grad[diag] -= a[i[diag]]
    return grad
