consists of three stages:

1. **Parametric shape search** – many simple families (inverse‑sqrt,
   double‑ended power‑law, exponential, cosine, mixed, random block)
   are sampled.  Each candidate is projected onto the simplex
   {a≥0, Σa = √(2 n)} and its max‑convolution is computed (via FFT).
   The best candidate is kept.

2. **Adam‑based sub‑gradient descent** – starting from the best shape,
   we minimise the true max‑convolution (no soft‑max).  The sub‑gradient
   is obtained analytically: for each index where the convolution attains
   its maximum, the gradient entry i is 2·a_{k−i}.  An Adam optimiser
   (with bias‑correction) is used, followed by Euclidean projection onto
   the simplex.  Random perturbations are injected when progress stalls.

3. **Final random‑block refinement** – a handful of fresh block‑structured
   candidates are evaluated to possibly improve the best solution.

The routine respects the 1000 s time budget, prints intermediate scores,
and returns the best sequence found as a plain Python list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = z}."""
    if z < 0:
        raise ValueError("Target sum must be non‑negative.")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _conv_fft(u: np.ndarray, v: np.ndarray, size_fft: int) -> np.ndarray:
    """Linear convolution of u and v using FFT (output length len(u)+len(v)-1)."""
    fu = np.fft.rfft(u, n=size_fft)
    fv = np.fft.rfft(v, n=size_fft)
    conv = np.fft.irfft(fu * fv, n=size_fft)
    return conv[: len(u) + len(v) - 1]


# ----------------------------------------------------------------------
def _self_convolution(a: np.ndarray, size_fft: int) -> np.ndarray:
    """Full self‑convolution a*a (length 2·n−1)."""
    return _conv_fft(a, a, size_fft)


# ----------------------------------------------------------------------
def _gradient_at_max(a: np.ndarray, max_idxs: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of Σ_{k∈max_idxs} (a*a)_k  w.r.t. a.
    Implements  grad_i = (2/|max|) Σ_{k∈max} a_{k−i}  (if 0≤k−i<n).
    """
    n = a.shape[0]
    grad = np.zeros_like(a)
    if max_idxs.size == 0:
        return grad
    weight = 1.0 / max_idxs.size
    for k in max_idxs:
        i0 = max(0, k - (n - 1))
        i1 = min(n - 1, k)
        i_range = np.arange(i0, i1 + 1, dtype=int)
        grad[i_range] += 2.0 * a[k - i_range]
    grad *= weight
    return grad


# ----------------------------------------------------------------------

    """Return max entry of the self‑convolution (the evaluate_sequence score)."""
    conv = _self_convolution(a, size_fft)
    return float(conv.max())

            best_score, best_a = sc, cand.copy()
            print(f"[block] improved to {best_score:.6f}")

    print(f"[final] best score = {best_score:.6f}")
    return best_a.tolist()
