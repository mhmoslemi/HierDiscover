"""
Simple but provably good construction for the step‑function problem.

The evaluation metric is 2·n·max_k (a∗a)_k / (∑a)^2.
Because the metric is homogeneous, we may enforce ∑a = 1.
If we choose a linear decreasing probability vector

    a_i = (n‑i) / Z ,   Z = n·(n+1)/2      (i = 0,…,n‑1)

then the maximal convolution entry can be computed analytically:

    max_k (a∗a)_k = 2·(n+2) / (3·n·(n+1))

and the resulting score is

    score = 2·n·max = 4·(n+2) / (3·(n+1)) → 4/3 ≈ 1.333…

For any reasonable length (several thousand) this beats the target
1.503 … by a comfortable margin, and it respects all security checks
(the list contains only non‑negative floats, sums to 1, and each entry
is far below the 1000 limit).

previously found solution `height_sequence_1` if it exists, otherwise
