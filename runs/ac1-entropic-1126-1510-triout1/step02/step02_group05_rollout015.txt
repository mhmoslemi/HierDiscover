Implementation details of projection onto simplex:

def proj_simplex(v):
    """Projects v onto the probability simplex (sum=1, v>=0)."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    # Find rho
    rho_arr = u - cssv / np.arange(1, n+1)
    rho = np.where(rho_arr > 0)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w

assistantfinal**Solution Overview**

The objective is  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0
\]

where `*` is the ordinary (full) convolution.  
Because the score is *scale‑invariant* we may restrict ourselves to the
probability simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

For a fixed vector `a` the convolution `c = a*a` is a quadratic map.
The quantity we have to minimise is the *maximum* entry of `c`.
A smooth approximation of the maximum is the **log‑sum‑exp**  

\[
m_\alpha(a)=\frac{1}{\alpha}\log\!\Bigl(\sum_k e^{\alpha\,c_k}\Bigr)
\qquad(\alpha>0),
\]

which converges to `max(c)` when `α→∞`.  
`mα` is differentiable; its gradient can be written
compactly using a convolution, which makes the whole iteration
\(O(n\log n)\) (here we use the direct `np.convolve`, fast enough for
the chosen sizes).

The optimisation proceeds in three phases

1. **Initialisation** – use the best known construction (`height_sequence_1`)
   if it exists, otherwise a uniform distribution.  
   The vector is normalised to sum to 1.

2. **Smoothed‑max gradient descent** –  
   * compute `c = a*a`,  
   * form the soft‑max weights  
     \(w_k\propto e^{\alpha(c_k-\max c)}\),  
   * gradient of `mα` is  
     \(\nabla m_\alpha(a)=2\;(a\star w)\)  
     (cross‑correlation, implemented by a single convolution),  
   * a step is taken with the Adam‑style adaptive learning rate,  
   * the result is projected back onto the probability simplex.  
   The smoothing parameter `α` is increased gradually, so we first move
   towards a flat convolution and later focus on the true maximum.

3. **Fine polishing** – a cheap random‑pair “mass‑swap’’ move
   (the same move used in the reference code) is applied many times
   with an annealing schedule; the best sequence seen is kept.

All operations respect the time budget (the loop stops a few seconds
before the harness timeout).  The algorithm repeatedly evaluates the
exact score (via `evaluate_sequence`) only when an improvement is
found, so the overhead is negligible.

The whole code is self‑contained, uses only `numpy` and the standard
library, and respects the required function signature.

```python
"""
Gradient‑descent on a smoothed max‐convolution, followed by a short
random‑pair polishing phase.

* work on the probability simplex (∑a_i = 1, a_i ≥ 0) – removes the
  scale invariance of evaluate_sequence;
* minimise the log‑sum‑exp of the autocorrelation (a * a);
* gradient of the smooth objective is 2·(a ⋆ w) where w are soft‑max
  weights of the convolution;
* Adam‑style adaptive step together with projection onto the simplex;
* finally a few thousand random pairwise mass‑swaps (the same move as
  the reference LP‑based code) are used to polish the best candidate.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: projection onto the probability simplex (Duchi et al. 2008)
# ----------------------------------------------------------------------
def proj_simplex(v: np.ndarray) -> np.ndarray:
    """Project vector *v* onto the simplex {x | x_i ≥ 0, Σ x_i = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.where(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Helper: tiny random pairwise mass‑swap (keeps the L1‑norm exactly 1)
# ----------------------------------------------------------------------
def _random_pair_move(seq: np.ndarray, sigma: float) -> np.ndarray:
    """Move a small amount of mass between two distinct indices."""
    n = seq.shape[0]
    i, j = np.random.choice(n, size=2, replace=False)

    # symmetric zero‑mean proposal, uniform in [-σ/2, σ/2]
    delta = (np.random.rand() - 0.5) * sigma

    # clip so that we never go negative
    if delta > 0.0:
        delta = min(delta, seq[j])
    else:
        delta = -min(-delta, seq[i])

    new_seq = seq.copy()
    new_seq[i] += delta
    new_seq[j] -= delta
    return new_seq


# ----------------------------------------------------------------------
# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: float = 1000, **kwargs):
    """
    Return a list of non‑negative heights that (hopefully) gives a low
    evaluate_sequence score.  The routine runs for at most *budget_s*
    seconds and may use any amount of CPU time within that limit.
    """
    np.random.seed(seed)
    start = time.time()
    # keep a small safety margin – the harness will kill the process if
    # we run over the budget.
    deadline = start + max(0.0, budget_s - 2.0)

    # --------------------------------------------------------------
    # 1. initialise a feasible sequence (probability simplex)
    # --------------------------------------------------------------
    try:
        base = np.array(height_sequence_1, dtype=float)  # type: ignore
        # limit the dimension to keep each iteration cheap
        MAXLEN = 2500
        if base.size > MAXLEN:
            base = base[:MAXLEN]
        base = np.maximum(base, 0.0)
        if base.sum() < 1e-12:
            raise ValueError
        base /= base.sum()
    except Exception:
        # fallback: a uniform vector of moderate length
        MAXLEN = 2500
        base = np.full(MAXLEN, 1.0 / MAXLEN, dtype=float)

    # add a tiny random jitter to break perfect symmetry
    base += 1e-6 * np.random.rand(base.shape[0])
    base /= base.sum()

    a = base.copy()
    n = a.shape[0]

    # keep the best sequence seen so far
    best_seq = a.copy()
    try:
        best_score = evaluate_sequence(best_seq.tolist())
    except Exception:
        best_score = float("inf")
    print(f"[Init] length={n}, score={best_score:.6f}")

    # --------------------------------------------------------------
    # 2. Smoothed‑max gradient descent (Adam + simplex projection)
    # --------------------------------------------------------------
    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr = 0.2                # initial learning rate
    min_lr = 1e-4

    # smoothing parameter for the log‑sum‑exp
    alpha = 2.0
    alpha_mult = 1.02
    max_alpha = 500.0

    it = 0
    while time.time() < deadline:
        it += 1

        # --- convolution and smooth‑max weights ---------------------------------
        conv = np.convolve(a, a)               # length 2n‑1
        max_conv = conv.max()

        # soft‑max over the convolution entries (shifted by the max for stability)
        tmp = alpha * (conv - max_conv)
        # clip to avoid overflow/underflow in np.exp
        tmp = np.clip(tmp, -700.0, 700.0)
        w = np.exp(tmp)
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.ones_like(w) / w.size
        else:
            w /= w_sum

        # --- gradient of the smoothed max (2·(a ⋆ w)) ---------------------------
        # cross‑correlation a ⋆ w can be obtained with a single convolution
        # of a with the reversed weight vector.
        conv_res = np.convolve(a, w[::-1])          # length 3n‑2
        # gradient component j = 2 * conv_res[2n‑2‑j]
        idx = (2 * n - 2) - np.arange(n)
        grad = 2.0 * conv_res[idx]

        # --- Adam update -------------------------------------------------------
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        # bias‑corrected moments
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        a_new = a - step                     # move opposite to the gradient
        a = proj_simplex(a_new)               # enforce feasibility

        # decay learning rate and increase smoothing
        lr = max(min_lr, lr * 0.9999)
        alpha = min(max_alpha, alpha * alpha_mult)

        # --- evaluate the exact score (fast, because we already have conv) ---
        current_score = 2.0 * n * np.max(np.convolve(a, a))
        if current_score < best_score:
            best_score = current_score
            best_seq = a.copy()
            print(f"[Iter {it:05d}] new best (smooth‑max) score: {best_score:.6f}")

        # occasional full evaluation for safety
        if it % 100 == 0:
            try:
                exact = evaluate_sequence(a.tolist())
                if exact < best_score:
                    best_score = exact
                    best_seq = a.copy()
                    print(f"[Iter {it:05d}] new best (exact) score: {best_score:.6f}")
            except Exception:
                pass

    # --------------------------------------------------------------
    # 3. Final polishing – cheap random pair swaps (annealed)
    # --------------------------------------------------------------
    polish_iters = 4000
    it = 0
    while time.time() < deadline and it < polish_iters:
        it += 1
        # linear cooling of the proposal width
        frac = it / polish_iters
        sigma = 0.3 * (1.0 - frac) + 0.02 * frac
        cand = _random_pair_move(best_seq, sigma)

        try:
            cand_score = evaluate_sequence(cand.tolist())
        except Exception:
            continue

        if cand_score < best_score:
            best_score = cand_score
            best_seq = cand
            print(f"[Polish {it:04d}] new best score: {best_score:.6f}")

    # final safety: ensure non‑negative entries
    best_seq = np.maximum(best_seq, 0.0)
    return best_seq.tolist()
```
