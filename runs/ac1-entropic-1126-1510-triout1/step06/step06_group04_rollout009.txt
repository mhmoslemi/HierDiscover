assistantfinal**Solution Overview**

The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\]

where `*` denotes the (linear) self‑convolution.  
Because the score is invariant under a global scaling of the vector we may
always enforce  

\[
\sum_i a_i = 1\qquad\Longrightarrow\qquad
\text{score}(a)=2\,n\;\max (a*a).
\]

Hence the problem reduces to *reducing the maximal entry of the
self‑convolution*.

The previous implementation used a plain projected sub‑gradient method.
Below we employ a **smoothed Adam optimisation**:

* a differentiable approximation of the `max` operator is used  
  \[
  \operatorname{softmax}_\beta(b)=\frac{\log\!\bigl(\sum_k e^{\beta b_k}\bigr)}{\beta},
  \]
  whose gradient is a weighted sum of the individual convolution
  gradients,
  \[
  \nabla_a \operatorname{softmax}_\beta(b)=2\;a_{rev}*w,
  \qquad
  w_k=\frac{e^{\beta b_k}}{\sum_j e^{\beta b_j}} .
  \]

* Adam (adaptive moment estimation) provides an efficient
  first‑order optimisation with automatic step‑size adaptation.

* After each update the vector is projected back onto the probability
  simplex (`a ≥ 0 , Σa = 1`) – this guarantees that the evaluator receives a
  valid step function.

* The smoothing parameter `β` starts small (the objective is very smooth)
  and is increased geometrically so that the optimisation finally focuses
  on the true maximum.

* A short **exploratory phase** generates many candidates from several
  parametric families (uniform, arcsine, symmetric Beta, Dirichlet,
  mixtures).  The best candidate is then refined with the Adam optimiser.
  The whole routine respects the 1000 s time limit.

The implementation contains only top‑level functions, no lambdas or
closures, and prints occasional progress information.

```python
#!/usr/bin/env python3
"""
Propose a low‑score step function.

The algorithm works in two phases.

1. **Exploratory random search** – several families of distributions
   (uniform, arcsine, symmetric Beta, Dirichlet, mixtures) are sampled
   for a few different lengths.  All candidates are projected onto the
   simplex (Σa=1) and evaluated with the fast proxy
   `2·n·max(a*a)`.  The best candidate across the whole exploration is
   kept.

2. **Smoothed Adam refinement** – starting from the best candidate we
   minimise a smooth approximation of the max‑convolution using Adam
   with a projection onto the simplex after each step.  The smoothing
   parameter `β` grows from a small value to a large one so that the
   optimiser first moves in a well‑behaved landscape and finally focuses
   on the true supremum.  Small random jitter is injected from time to
   time to escape plateaus.

The routine respects the 1000 s budget (the argument `budget_s`).  The
final sequence is returned as a plain Python list; `evaluate_sequence`
is called once at the end to obtain the true score.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, Σx = s}."""
    if s < 0:
        raise ValueError("Simplex size must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _beta_distribution(n: int, alpha: float, beta: float) -> np.ndarray:
    """Discrete (mid‑point) Beta(α,β) distribution of length n, normalised to Σ=1."""
    x = (np.arange(n, dtype=np.float64) + 0.5) / n          # mid‑points
    # log‑pdf for numerical stability
    logC = math.lgamma(alpha + beta) - math.lgamma(alpha) - math.lgamma(beta)
    logpdf = logC + (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    logpdf = np.minimum(logpdf, 700.0)                     # avoid overflow
    pdf = np.exp(logpdf)
    pdf = np.maximum(pdf, 0.0)
    total = pdf.sum()
    if total == 0.0:
        pdf[:] = 1.0 / n
    else:
        pdf /= total
    return pdf


# ----------------------------------------------------------------------
def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution of two real vectors using real FFT."""
    size = 1 << ((a.size + b.size - 1 - 1).bit_length())
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]


# ----------------------------------------------------------------------
def _self_convolution_full(a: np.ndarray) -> np.ndarray:
    """Linear self‑convolution a*a (length 2·n‑1) via FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1 - 1).bit_length())
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]


# ----------------------------------------------------------------------
def _raw_score(a: np.ndarray) -> float:
    """
    Proxy score for a vector which already satisfies Σa = 1.
    Returns 2·n·max(a*a).
    """
    n = a.shape[0]
    b = _self_convolution_full(a)
    return float(2.0 * n * b.max())


# ----------------------------------------------------------------------
def _adam_refine(
    a0: np.ndarray,
    deadline: float,
    beta_start: float = 5.0,
    beta_target: float = 150.0,
    lr0: float = 0.25,
) -> np.ndarray:
    """
    Adam optimisation of the smoothed max‑convolution objective.
    The vector is kept on the simplex by projection after every step.
    """
    a = a0.copy()
    n = a.shape[0]
    # Adam hyper‑parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12

    m = np.zeros_like(a)
    v = np.zeros_like(a)

    it = 0
    beta = beta_start
    # increase β multiplicatively every `inc_every` iterations
    inc_every = 2000

    rng = np.random.default_rng(12345)

    while time.time() < deadline:
        it += 1

        # ----- compute self‑convolution -----
        b = _self_convolution_full(a)
        max_b = b.max()

        # ----- smoothed max (log‑sum‑exp) -----
        # w_k = exp(beta * (b_k - max_b))  /  Σ exp(...)
        w = np.exp(beta * (b - max_b))
        w_sum = w.sum()
        if w_sum == 0.0:                     # numerical safety
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # ----- gradient of the smoothed objective -----
        grad = 2.0 * _fft_convolve(a[::-1], w)[n - 1 : n - 1 + n]

        # ----- Adam update -----
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = lr0 / math.sqrt(it)
        a = a - step * m_hat / (np.sqrt(v_hat) + eps)

        # ----- keep a on the simplex -----
        a = _project_onto_simplex(a)

        # ----- slowly increase the smoothing parameter -----
        if it % inc_every == 0:
            beta = min(beta_target, beta * 1.5)

        # ----- occasional tiny random jitter -----
        if it % 1000 == 0 and rng.random() < 0.07:
            a += rng.normal(scale=5e-7, size=n)
            a = _project_onto_simplex(a)

        # ----- periodic logging -----
        if it % 5000 == 0:
            cur_raw = _raw_score(a)
            print(f"[{time.time():.1f}] Adam it={it:>6} β={beta:.1f} raw={cur_raw:.6f}")

    return a


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list:
    """
    Search for a non‑negative step function with a low evaluate_sequence score.
    The function respects the given time budget and returns the best sequence
    it found (as a plain Python list).
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5      # a small safety margin

    # ------------------------------------------------------------------
    # Optional warm‑start from a previously discovered sequence
    base_seq = None
    try:
        base_seq = np.asarray(height_sequence_1, dtype=np.float64)  # type: ignore[name-defined]
        if base_seq.size > 0:
            base_seq = base_seq / base_seq.sum()
    except Exception:
        base_seq = None

    best_seq = None
    best_score = float("inf")
    best_len = None

    # ------------------------------------------------------------------
    # Lengths to explore – we try a few values; larger n gives a finer
    # discretisation of the continuous problem.
    lengths = [8000, 12000, 16000]

    for n in lengths:
        if time.time() >= deadline:
            break
        print(f"[{time.time():.1f}] Exploring length {n}")

        # ---- deterministic baselines -------------------------------------------------
        uniform = np.full(n, 1.0 / n, dtype=np.float64)
        sc = _raw_score(uniform)
        if sc < best_score:
            best_score, best_seq, best_len = sc, uniform.copy(), n
            print(f"   uniform    score={best_score:.6f}")

        arcsine = _beta_distribution(n, 0.5, 0.5)
        sc = _raw_score(arcsine)
        if sc < best_score:
            best_score, best_seq, best_len = sc, arcsine.copy(), n
            print(f"   arcsine    score={best_score:.6f}")

        if base_seq is not None:
            # interpolate the warm‑start to the current length
            x_old = np.linspace(0.0, 1.0, base_seq.size)
            x_new = np.linspace(0.0, 1.0, n)
            cand = np.interp(x_new, x_old, base_seq)
            cand = _project_onto_simplex(cand)
            sc = _raw_score(cand)
            if sc < best_score:
                best_score, best_seq, best_len = sc, cand.copy(), n
                print(f"   warm‑start score={best_score:.6f}")

        # ---- symmetric Beta grid -------------------------------------------------
        alphas = np.concatenate((
            np.linspace(0.12, 0.6, 12, endpoint=False),
            np.linspace(0.6, 2.0, 15),
            np.linspace(2.0, 5.0, 8)
        ))
        for a in alphas:
            if time.time() >= deadline:
                break
            vec = _beta_distribution(n, a, a)
            sc = _raw_score(vec)
            if sc < best_score:
                best_score, best_seq, best_len = sc, vec.copy(), n
                print(f"   symBeta a={a:.3f} score={best_score:.6f}")

        # ---- random Beta draws -------------------------------------------------------
        for _ in range(400):
            if time.time() >= deadline:
                break
            alpha = 10 ** rng.uniform(-2, 1)   # 0.01 … 10
            beta = 10 ** rng.uniform(-2, 1)
            vec = _beta_distribution(n, alpha, beta)
            sc = _raw_score(vec)
            if sc < best_score:
                best_score, best_seq, best_len = sc, vec.copy(), n
                print(f"   randBeta a={alpha:.3f} b={beta:.3f} score={best_score:.6f}")

        # ---- Dirichlet draws ---------------------------------------------------------
        for _ in range(300):
            if time.time() >= deadline:
                break
            conc = 10 ** rng.uniform(-2, 1)   # 0.01 … 10
            vec = rng.gamma(conc, 1.0, size=n)
            vec /= vec.sum()
            sc = _raw_score(vec)
            if sc < best_score:
                best_score, best_seq, best_len = sc, vec.copy(), n
                print(f"   dirichlet conc={conc:.3f} score={best_score:.6f}")

        # ---- mixture of two Betas ----------------------------------------------------
        for _ in range(250):
            if time.time() >= deadline:
                break
            a1, b1 = 10 ** rng.uniform(-2, 1), 10 ** rng.uniform(-2, 1)
            a2, b2 = 10 ** rng.uniform(-2, 1), 10 ** rng.uniform(-2, 1)
            lam = rng.random()
            p1 = _beta_distribution(n, a1, b1)
            p2 = _beta_distribution(n, a2, b2)
            vec = lam * p1 + (1.0 - lam) * p2
            vec = _project_onto_simplex(vec)
            sc = _raw_score(vec)
            if sc < best_score:
                best_score, best_seq, best_len = sc, vec.copy(), n
                print(f"   mix2 λ={lam:.3f} score={best_score:.6f}")

    # ------------------------------------------------------------------
    if best_seq is None:
        # Fallback – should never happen
        n = 8000
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)
        best_len = n
        best_score = _raw_score(best_seq)
        print("Fallback uniform used.")

    print(f"Best raw score after exploration: {best_score:.6f} (length={best_len})")

    # ------------------------------------------------------------------
    # 2) Smoothed Adam refinement (majority of the remaining budget)
    remaining_deadline = deadline
    refined = _adam_refine(best_seq, remaining_deadline)

    # Choose the better of the raw‑score of the refined vector and the
    # raw‑score of the best candidate from the random phase.
    refined_score = _raw_score(refined)
    if refined_score < best_score:
        final_seq = refined
        final_raw = refined_score
    else:
        final_seq = best_seq
        final_raw = best_score

    # ------------------------------------------------------------------
    # Final evaluation with the official evaluator (it rescales automatically)
    final_score = evaluate_sequence(final_seq.tolist())
    print(f"Final evaluated score: {final_score:.6f} (raw={final_raw:.6f}, length={len(final_seq)})")

    return final_seq.tolist()
```
