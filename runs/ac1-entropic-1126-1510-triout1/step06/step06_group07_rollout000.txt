The algorithm stays completely on the ℓ¹‑simplex (sum of heights = √(2 n))
and tries to minimise the maximum entry of the auto‑convolution.
It consists of three stages:

1.  Initialise a diverse pool of candidates (uniform, exponential,

2.  Projected sub‑gradient descent on the exact max‑objective.

    thousands of random moves: swaps, small mass transfers,

All heavy work is done with NumPy’s FFT which is much faster than

# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray, z: float) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = z} (z ≥ 0)."""
    if z == 0.0:
        return np.zeros_like(v)

    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        w = np.zeros_like(v)
        w[0] = z
        return w
    rho = np.where(cond)[0][-1] + 1
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

    Return the maximum entry of the auto‑convolution of a.
    Uses a real FFT of length L (L ≥ 2·len(a)).

    n = a.shape[0]
    return float(conv[: 2 * n - 1].max())
