assistantfinal**Solution Overview**

The problem is to minimise  

\[
\text{score}(a)=\frac{2\,n\,\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

All vectors are normalised to `∑a = 1`; then the score reduces to  

\[
\text{score}=2\,n\;\max_k (a*a)_k .
\]

The code below implements a *four‑stage* optimiser

1. **Broad family sampling** – many parametric families (arcsine, beta,
   power‑law, exponential, Dirichlet, two‑level etc.) are generated for a
   set of lengths.  The best vector (according to the cheap fast‑score
   `2·n·max(conv)`) is kept.

2. **Smooth‑max Adam optimisation** – the ℓ∞‑objective is replaced by the
   smooth surrogate  

   \[
   L_\alpha(a)=\frac1\alpha\log\!\sum_k
       \exp\bigl(\alpha\,(a*a)_k\bigr)
   \]

   and optimised with Adam.  The smoothing parameter `α` is increased
   continuously (continuation).

3. **Linear‑programming improvement** – for the current vector `f`
   compute `M = max(f*f)`.  
   The linear programme  

   \[
   \max_{g\ge 0}\;\sum_i g_i \quad\text{s.t.}\quad (f*g)_k\le M\;\forall k
   \]

   gives a direction `g` that can carry more total mass without breaking
   the current bound.  A convex combination `f←(1‑t)f + t·g/∑g`
   (projected back onto the simplex) strictly reduces `M`.  Only a few
   LP solves are needed; the convolution matrix is built once per LP
   with a *sparse* Toeplitz structure, so the step is cheap for
   `n≈4000`.

4. **Exact‑max sub‑gradient + greedy mass‑transfer** – the remaining time
   is spent performing (i) sub‑gradient descent on the true ℓ∞‑objective
   and (ii) a greedy local search that moves a small fraction of mass from
   a source that contributes strongly to the current peak towards a random
   destination.  Both steps keep the vector on the simplex.

Finally the best candidate is evaluated with the provided
`evaluate_sequence` black‑box and returned.

The whole routine respects the 1000 s budget, works on a single machine
(and can use up to two CPUs via NumPy/SciPy) and never produces
negative or non‑finite entries.

```python
"""Advanced step‑function optimiser.

The algorithm consists of four stages:
0 – broad family sampling (including arcsine, beta, power‑law, Dirichlet,
    two‑level);
1 – smooth‑max Adam optimisation with continuation;
2 – a linear‑programming improvement step that increases the total mass
    while respecting the current ℓ∞‑bound;
3 – exact ℓ∞ sub‑gradient descent + a greedy mass‑transfer local search.
The best vector is finally evaluated with ``evaluate_sequence``.
"""

import time
import math
import numpy as np
from scipy import sparse, optimize

# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, Σx=s}."""
    if s < 0:
        raise ValueError("Simplex size must be non‑negative")
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.where(u - cssv / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using a real FFT (length 2·len(a)‑1)."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1) - 1).bit_length()   # next power of two
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]


# ----------------------------------------------------------------------
def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution of two real vectors using a real FFT."""
    size = 1 << ((a.size + b.size - 1) - 1).bit_length()
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]


# ----------------------------------------------------------------------
def _smooth_max_gradient(a: np.ndarray, alpha: float):
    """Gradient of L_α(a) = (1/α)·log Σ exp(α·(a*a)_k)."""
    b = _fft_self_convolve(a)
    cur_max = b.max()
    # soft‑max weights (stable)
    exp_term = np.exp(alpha * (b - cur_max))
    w = exp_term / exp_term.sum()
    # convolution of reversed a with weight vector
    a_rev = a[::-1]
    conv_rev = _fft_convolve(a_rev, w)          # length = 3n‑2
    grad = 2.0 * conv_rev[len(a) - 1 : len(a) - 1 + len(a)]
    return grad, cur_max


# ----------------------------------------------------------------------
def _adam_optimize(a0: np.ndarray,
                   deadline: float,
                   init_alpha: float = 1.0,
                   alpha_factor: float = 1.01,
                   alpha_max: float = 10000.0,
                   lr0: float = 0.5,
                   beta1: float = 0.9,
                   beta2: float = 0.999,
                   eps: float = 1e-8):
    """
    Adam optimisation of the smooth‑max surrogate.
    Returns the best probability vector (∑=1) seen and its exact peak.
    """
    a = a0.copy()
    n = a.shape[0]
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    t = 0
    alpha = init_alpha

    best_a = a.copy()
    best_peak = _fft_self_convolve(a).max()

    while time.time() < deadline:
        t += 1
        grad, cur_max = _smooth_max_gradient(a, alpha)

        # Adam moments
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        lr = lr0 / np.sqrt(t)
        a = a - lr * m_hat / (np.sqrt(v_hat) + eps)
        a = _project_onto_simplex(a, s=1.0)

        if cur_max < best_peak - 1e-15:
            best_peak = cur_max
            best_a = a.copy()

        if alpha < alpha_max:
            alpha = min(alpha_max, alpha * alpha_factor)

        # occasional tiny jitter
        if t % 400 == 0 and np.random.rand() < 0.1:
            a += np.random.randn(n) * 5e-7
            a = _project_onto_simplex(a, s=1.0)

    return best_a, best_peak


# ----------------------------------------------------------------------
def _max_subgradient_step(a: np.ndarray):
    """
    One exact sub‑gradient step for the ℓ∞‑objective.
    Uses equal weight on all active maximal entries.
    """
    n = a.shape[0]
    b = _fft_self_convolve(a)
    cur_max = b.max()
    tol = max(1e-12, cur_max * 1e-12)
    active = np.where(b >= cur_max - tol)[0]

    w = np.zeros_like(b)
    if active.size > 0:
        w[active] = 1.0 / active.size

    a_rev = a[::-1]
    grad = 2.0 * _fft_convolve(a_rev, w)[n - 1 : n - 1 + n]
    return grad, cur_max


# ----------------------------------------------------------------------
def _refine_max(a0: np.ndarray, deadline: float) -> np.ndarray:
    """Exact ℓ∞ sub‑gradient descent (diminishing step)."""
    a = a0.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_peak = _fft_self_convolve(a).max()
    it = 0
    while time.time() < deadline:
        it += 1
        grad, cur_max = _max_subgradient_step(a)
        step = 0.02 / np.sqrt(it)
        a = a - step * grad
        a = _project_onto_simplex(a, s=1.0)

        if cur_max < best_peak - 1e-14:
            best_peak = cur_max
            best_a = a.copy()

        if it % 500 == 0 and np.random.rand() < 0.07:
            a += np.random.randn(n) * 5e-7
            a = _project_onto_simplex(a, s=1.0)

    return best_a


# ----------------------------------------------------------------------
def _directed_local_search(a0: np.ndarray, deadline: float):
    """Greedy mass‑transfer search that attacks the current peak."""
    a = a0.copy()
    n = a.shape[0]
    b = _fft_self_convolve(a)
    cur_max = b.max()
    best_a = a.copy()
    best_max = cur_max

    while time.time() < deadline:
        # pick an index that belongs to a maximal term
        max_idx = np.random.choice(np.where(b >= cur_max - 1e-12)[0])

        # indices i that contribute to (a*a)[max_idx]
        i_low = max(0, max_idx - (n - 1))
        i_high = min(max_idx, n - 1)
        i_vals = np.arange(i_low, i_high + 1, dtype=int)
        prod = a[i_vals] * a[max_idx - i_vals]

        if prod.sum() == 0.0:
            src = np.random.randint(n)
        else:
            prob = prod / prod.sum()
            src = np.random.choice(i_vals, p=prob)

        dst = np.random.randint(n)
        if dst == src:
            continue

        max_delta = min(a[src], 0.1)           # move up to 10 % of source mass
        delta = np.random.rand() * max_delta

        a_new = a.copy()
        a_new[src] -= delta
        a_new[dst] += delta

        b_new = _fft_self_convolve(a_new)
        new_max = b_new.max()

        if new_max < cur_max - 1e-15:
            a = a_new
            b = b_new
            cur_max = new_max
            if new_max < best_max:
                best_max = new_max
                best_a = a.copy()

        if np.random.rand() < 0.005:          # tiny random jitter
            a += np.random.randn(n) * 1e-7
            a = _project_onto_simplex(a, s=1.0)
            b = _fft_self_convolve(a)
            cur_max = b.max()

    return best_a


# ----------------------------------------------------------------------
def _lp_max_sum(f: np.ndarray, M: float):
    """
    Solve
        maximise   ∑ g_i
        subject to g_i ≥ 0,
                    (f * g)_k ≤ M   for all k,
    and return the optimal g (or None if the LP fails).
    """
    n = f.shape[0]

    # Build the (2n‑1)×n convolution matrix T with entries
    # T[k, j] = f_{k‑j}  (zero when the index is out of range).
    # Every diagonal d (>=0) contains the constant value f[d].
    diags = [np.full(n, f[d]) for d in range(n)]
    offsets = np.arange(n)          # 0 … n‑1
    T = sparse.diags(diags, offsets, shape=(2 * n - 1, n), format='csr')

    c = -np.ones(n)                 # minimise –∑g ⇔ maximise ∑g
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n

    # ``highs`` is fast and accepts sparse matrices
    res = optimize.linprog(c, A_ub=T, b_ub=b_ub,
                          bounds=bounds,
                          method='highs',
                          options={'presolve': True, 'time_limit': 30})

    if res.success:
        return res.x
    return None


# ----------------------------------------------------------------------
def _lp_improvement(a: np.ndarray, deadline: float):
    """Perform a few LP‑based improvements (mixing with the LP direction)."""
    n = a.shape[0]
    cur_max = _fft_self_convolve(a).max()
    it = 0
    while time.time() < deadline and it < 4:
        g = _lp_max_sum(a, cur_max)
        if g is None:
            break
        sum_g = g.sum()
        if sum_g <= 1.0 + 1e-12:
            break
        g_norm = g / sum_g

        improved = False
        # try a couple of mixing ratios, keep the best improvement
        for t in (0.5, 0.2, 0.1):
            cand = (1 - t) * a + t * g_norm
            cand = _project_onto_simplex(cand, s=1.0)
            new_max = _fft_self_convolve(cand).max()
            if new_max < cur_max - 1e-12:
                a = cand
                cur_max = new_max
                improved = True
                print(f"[LP] iter {it+1}, mix {t:.2f}, fast_score={2*n*new_max:.6f}")
                break
        if not improved:
            break
        it += 1
    return a


# ----------------------------------------------------------------------
def _two_level_family(n: int, deadline: float):
    """
    Simple two‑level parametric family:
        a_i = p   for i < L
        a_i = q   otherwise,   p = r·q , r≥1 .
    Returns the best vector and its fast_score.
    """
    best_seq = None
    best_score = float('inf')
    step_L = max(1, n // 100)          # ≈1 % of length
    r_grid = np.logspace(0.0, 2.3, num=30)   # from 1 to ≈200

    for L in range(step_L, n, step_L):
        if time.time() > deadline:
            break
        denom_base = n - L
        for r in r_grid:
            denom = L * r + denom_base
            q = 1.0 / denom
            p = r * q
            seq = np.empty(n, dtype=np.float64)
            seq[:L] = p
            seq[L:] = q
            peak = _fft_self_convolve(seq).max()
            score = 2.0 * n * peak
            if score < best_score:
                best_score = score
                best_seq = seq.copy()
    return best_seq, best_score


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list:
    """
    Main entry point.  Returns a plain Python list of non‑negative numbers.
    The routine follows the four‑stage scheme described in the module
    docstring and never exceeds the given time budget.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 1.0   # safety margin

    # --------------------------------------------------------------
    # try to use a previously discovered construction if available
    try:
        base_seq = np.asarray(height_sequence_1, dtype=np.float64)  # type: ignore[name-defined]
        base_seq = _project_onto_simplex(base_seq, s=1.0)
        base_n = len(base_seq)
    except Exception:
        base_seq = None
        base_n = 4000

    # --------------------------------------------------------------
    # lengths we will explore – a small spread around the previous best
    lengths = [max(500, int(base_n * f))
               for f in (0.6, 0.8, 1.0, 1.2, 1.4)
               if int(base_n * f) >= 500]
    if not lengths:
        lengths = [max(500, base_n)]

    overall_best_seq = None
    overall_best_score = float('inf')

    # --------------------------------------------------------------
    # Phase 0 – broad family sampling (including extra power‑law & Dirichlet)
    print("[phase 0] broad family sampling")
    for n in lengths:
        if time.time() >= deadline:
            break

        starters = {}

        # classic families
        starters["arcsine"] = (1.0 / np.sqrt((np.arange(n) + 0.5) *
                               (n - np.arange(n) - 0.5)))
        starters["arcsine"] /= starters["arcsine"].sum()

        starters["uniform"] = np.full(n, 1.0 / n, dtype=np.float64)

        starters["random1"] = np.random.rand(n)
        starters["random1"] /= starters["random1"].sum()

        starters["random2"] = np.random.rand(n)
        starters["random2"] /= starters["random2"].sum()

        # symmetric Beta densities (α = β)
        for a in (0.25, 0.35, 0.45, 0.55, 0.65, 0.75):
            x = (np.arange(n, dtype=np.float64) + 0.5) / n
            log_vals = (a - 1.0) * np.log(x) + (a - 1.0) * np.log(1.0 - x)
            vals = np.exp(log_vals)
            vals[~np.isfinite(vals)] = 0.0
            if vals.sum() == 0.0:
                vals = np.full(n, 1.0 / n)
            else:
                vals /= vals.sum()
            starters[f"beta_{a:.2f}"] = vals

        # exponential decay families
        for lam in (0.0005, 0.001, 0.002):
            vec = np.exp(-lam * np.arange(n))
            vec /= vec.sum()
            starters[f"exp_{lam:.4f}"] = vec

        # power‑law / arcsine‑like families (p negative)
        for p in (-2.0, -1.5, -1.2, -1.0, -0.8, -0.6, -0.4, -0.2, -0.1):
            x = (np.arange(n, dtype=np.float64) + 0.5)
            y = (n - np.arange(n, dtype=np.float64) - 0.5)
            vals = (x * y) ** p
            vals[~np.isfinite(vals)] = 0.0
            if vals.sum() == 0.0:
                vals = np.full(n, 1.0 / n)
            else:
                vals /= vals.sum()
            starters[f"pow_{p:.1f}"] = vals

        # Dirichlet‑like draws (small concentration → sparse vectors)
        for alpha in (0.5, 0.3, 0.2):
            vec = np.random.gamma(shape=alpha, size=n)
            if vec.sum() == 0.0:
                vec = np.full(n, 1.0 / n)
            else:
                vec /= vec.sum()
            starters[f"dirich_{alpha:.1f}"] = vec

        # mixture of arcsine & uniform
        for w in (0.2, 0.4, 0.6):
            mix = (1.0 - w) * starters["arcsine"] + w * starters["uniform"]
            starters[f"mix_{w:.1f}"] = mix

        # interpolated previous best (if any)
        if base_seq is not None:
            old_n = len(base_seq)
            x_old = np.linspace(0.0, 1.0, old_n)
            x_new = np.linspace(0.0, 1.0, n)
            interp = np.interp(x_new, x_old, base_seq)
            interp = np.maximum(0.0, interp)
            if interp.sum() == 0.0:
                interp = np.full(n, 1.0 / n)
            else:
                interp /= interp.sum()
            starters["prev"] = interp

        # evaluate all starters
        for tag, vec in starters.items():
            vec = _project_onto_simplex(vec, s=1.0)
            peak = _fft_self_convolve(vec).max()
            fast_score = 2.0 * n * peak
            if fast_score < overall_best_score:
                overall_best_score = fast_score
                overall_best_seq = vec.copy()
                print(f"[init] n={n:4d} {tag:<12s} fast_score={fast_score:.6f}")

    # --------------------------------------------------------------
    # Phase 1 – cheap two‑level parametric search
    print("[phase 1] two‑level family search")
    for n in lengths:
        if time.time() >= deadline:
            break
        seq, score = _two_level_family(n, deadline)
        if seq is not None and score < overall_best_score:
            overall_best_score = score
            overall_best_seq = seq.copy()
            print(f"[two‑level] n={n:4d} fast_score={score:.6f}")

    # fallback: uniform if nothing has been found
    if overall_best_seq is None:
        n = max(500, base_n)
        overall_best_seq = np.full(n, 1.0 / n, dtype=np.float64)
        overall_best_score = 2.0 * n * _fft_self_convolve(overall_best_seq).max()
        print("[fallback] using uniform distribution")

    # --------------------------------------------------------------
    # Phase 2 – Adam optimisation of smooth‑max surrogate
    time_left = deadline - time.time()
    if time_left > 10.0:
        n = len(overall_best_seq)
        print(f"[phase 2] Adam optimisation (n={n}) – time left {time_left:.1f}s")
        phase_end = time.time() + 0.55 * time_left
        a_opt, _ = _adam_optimize(overall_best_seq, phase_end)
        overall_best_seq = a_opt.copy()
        overall_best_score = 2.0 * n * _fft_self_convolve(overall_best_seq).max()
        print(f"[phase 2] after Adam fast_score={overall_best_score:.6f}")

    # --------------------------------------------------------------
    # Phase 3 – linear‑programming improvement
    time_left = deadline - time.time()
    if time_left > 5.0 and len(overall_best_seq) <= 4000:
        n = len(overall_best_seq)
        print(f"[phase 3] LP improvement (n={n}) – time left {time_left:.1f}s")
        lp_deadline = time.time() + 0.20 * time_left
        improved = _lp_improvement(overall_best_seq, lp_deadline)
        overall_best_seq = improved
        overall_best_score = 2.0 * n * _fft_self_convolve(overall_best_seq).max()
        print(f"[phase 3] after LP fast_score={overall_best_score:.6f}")

    # --------------------------------------------------------------
    # Phase 4 – exact max sub‑gradient descent + directed local search
    time_left = deadline - time.time()
    if time_left > 5.0:
        n = len(overall_best_seq)
        print(f"[phase 4] sub‑gradient + local search (n={n}) – time left {time_left:.1f}s")
        sub_end = time.time() + 0.55 * time_left
        a_ref = _refine_max(overall_best_seq, sub_end)

        local_end = deadline
        a_final = _directed_local_search(a_ref, local_end)

        overall_best_seq = a_final.copy()
        overall_best_score = 2.0 * n * _fft_self_convolve(overall_best_seq).max()
        print(f"[phase 4] after local search fast_score={overall_best_score:.6f}")

    # --------------------------------------------------------------
    # Final evaluation with the true black‑box
    try:
        true_score = evaluate_sequence(overall_best_seq.tolist())
        print(f"[final] evaluate_sequence score={true_score:.6f}")
        if true_score < overall_best_score:
            overall_best_score = true_score
    except Exception as exc:
        print("[final] evaluate_sequence raised:", exc)

    print(f"Best approx. score {overall_best_score:.6f} (length={len(overall_best_seq)})")
    return overall_best_seq.tolist()
```
