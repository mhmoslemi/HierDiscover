assistantfinal**Solution Overview**

The task is to output a non‑negative vector `a` (a step‑function) that minimizes  

```
score(a) = 2·n·max(conv(a,a)) / (sum(a)²)
```

`evaluate_sequence` first clips the vector to `[0,1000]` and then computes this exact formula, therefore we may safely **normalise `a` to have sum = 1** – the score is invariant under scaling.

The previous implementation already obtains a score ≈ 1.50998.  
To push the bound below the target 1.503 we combine a few ideas that were not used before:

1. **Richer initial families** – in addition to the Beta(·,·) families we also try  
   * very flat Beta (p ≫ 1)  
   * very spiky Beta (p ≪ 1)  
   * mixtures of two Beta‑densities (3‑parameter family)  
   * Dirichlet draws with a *controllable* edge‑bias exponent ranging from 0.05 to 2.0.  
   The enlarged grid is explored for several lengths (up to 120 k).  
   Because the score depends only on the *shape*, a moderate length (≈ 20 k) is usually enough; longer lengths are only sampled when time permits.

2. **Two‑phase continuous optimisation**  
   * **Smooth‑max mirror descent** – an exponentiated‑gradient step on a soft‑max approximation of the max‑convolution, with a temperature that grows exponentially and a learning‑rate that decays exponentially.  
   * **Projected Adam sub‑gradient** – a true sub‑gradient step on the exact max‑convolution, with back‑tracking line‑search and Adam‑style momentum.

3. **Escaping local minima – Simulated‑Annealing‑style hill‑climber**  
   After the deterministic refinement we run a cheap stochastic search: repeatedly move a tiny amount of probability mass from the index that contributes most to the current peak to a random low‑mass index.  
   The move is accepted if it strictly improves the score, otherwise it is accepted with probability `exp(-(Δ/τ))` where the temperature τ decays geometrically.  
   This simple scheme is able to “jump” out of shallow basins that the gradient methods may miss.

4. **Multiple restarts** – the whole optimisation (mirror‑descent + Adam + SA) is launched from the three best initial candidates (the best uniform‑like, the best edge‑biased and the best mixture). The best result overall is returned.

All heavy work (convolutions) is performed by a real‑FFT implementation that runs in *O(n log n)*.  The algorithm checks the remaining wall‑clock time after each major block and stops well before the 1000 s limit.

The code below follows the required interface (`propose_candidate`) and contains only top‑level helper functions (no closures, no lambdas).

```python
"""
Propose a non‑negative step function (list of floats) that minimises
`evaluate_sequence`.  The algorithm consists of:

1.  A broad, heavily parameterised random search over many analytic families
    (Beta, mixtures of Betas, edge‑biased Dirichlet).  The best few vectors are
    kept.

2.  For each kept vector we run
      * smooth‑max mirror descent (exponentiated‑gradient)
      * projected Adam sub‑gradient descent on the true max‑convolution.
   The result with the lowest score is retained.

3.  A cheap simulated‑annealing hill‑climber is applied to the retained vector
    to escape possible local minima.

All convolutions use a real FFT.  The routine is time‑budget aware and will stop
well before the 1000 s limit.  The returned list is a plain Python list of
non‑negative floats (already normalised – the evaluator will re‑scale if needed).
"""

import time
import math
import random
import numpy as np

# ----------------------------------------------------------------------
# FFT helpers (real transforms)

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())

def _fft_self_convolve(a: np.ndarray) -> np.ndarray:
    """Full linear self‑convolution a*a using a real FFT."""
    n = a.shape[0]
    size = _next_pow2(2 * n - 1)
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)
    return conv[: 2 * n - 1]

def _fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution of a and b using a real FFT."""
    size = _next_pow2(a.size + b.size - 1)
    A = np.fft.rfft(a, n=size)
    B = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(A * B, n=size)
    return conv[: a.size + b.size - 1]

# ----------------------------------------------------------------------
# Simplex projection

def _project_onto_simplex(v: np.ndarray, s: float = 1.0) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x ≥ 0, sum(x)=s}."""
    v = np.asarray(v, dtype=np.float64)
    if np.all(v >= 0) and np.isclose(v.sum(), s):
        return v.copy()
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho = np.where(u - cssv / (np.arange(1, n + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w

# ----------------------------------------------------------------------
# Scoring

def _max_convolution_score(a: np.ndarray) -> float:
    """
    a must be normalised to sum = 1.
    Returns the quantity 2·n·max(a*a) exactly as `evaluate_sequence` would.
    """
    n = a.shape[0]
    conv = _fft_self_convolve(a)
    return 2.0 * n * conv.max()

# ----------------------------------------------------------------------
# Analytic families (all return a vector with sum = 1)

def _distribution_uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)

def _distribution_arcsine(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    vals = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    vals /= vals.sum()
    return vals

def _distribution_beta(n: int, p: float, q: float) -> np.ndarray:
    """Beta(p,q) on a regular grid."""
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    logw = (p - 1) * np.log(x) + (q - 1) * np.log(1 - x)
    logw -= np.max(logw)
    w = np.exp(logw)
    if w.sum() == 0 or not np.isfinite(w).all():
        return _distribution_uniform(n)
    w /= w.sum()
    return w

def _distribution_beta_sym(n: int, p: float) -> np.ndarray:
    """Symmetric Beta(p,p)."""
    return _distribution_beta(n, p, p)

def _distribution_edge_dirichlet(n: int, exp: float) -> np.ndarray:
    """
    Dirichlet draw with concentration concentrated at the edges.
    The concentration parameters are ((i+0.5)*(n-i-0.5))^{-exp}+0.1.
    """
    idx = np.arange(n, dtype=np.float64)
    conc = ((idx + 0.5) * (n - idx - 0.5)) ** (-exp) + 0.1
    vec = np.random.dirichlet(conc)
    return vec

def _distribution_beta_mixture(n: int, p1: float, p2: float, w: float) -> np.ndarray:
    """
    Mixture w·Beta(p1,p1) + (1-w)·Beta(p2,p2).  Result is normalised to sum 1.
    """
    a = _distribution_beta_sym(n, p1)
    b = _distribution_beta_sym(n, p2)
    mix = w * a + (1.0 - w) * b
    mix = np.maximum(mix, 1e-15)
    mix /= mix.sum()
    return mix

# Stochastic local search (simulated annealing)

def _annealing_refine(a: np.ndarray, deadline: float, seed: int = 0) -> np.ndarray:
    """
    Perform a cheap simulated‑annealing style hill‑climber.
    The algorithm repeatedly moves a small amount of mass from the index that
    contributes most to the current peak towards a random low‑mass index.
    It accepts worsening moves with a temperature that decays geometrically.
    """
    rng = np.random.default_rng(seed)
    n = a.shape[0]
    eps = 1e-15
    best = a.copy()
    best_score = _max_convolution_score(best)
    cur = a.copy()
    cur_score = best_score

    # Temperature schedule
    T0 = 0.01
    T_end = 1e-5
    total_steps_est = 5000  # rough upper bound; we respect deadline anyway
    step = 0

    while time.time() < deadline and step < total_steps_est:
        step += 1
        # Identify the peak index k and a pair (i,j) that realises it.
        conv = _fft_self_convolve(cur)
        k = int(conv.argmax())
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        # Find the pair (i,j) with maximal product among those that produce k
        best_pair_i = i_start
        best_pair_j = k - i_start
        max_prod = cur[best_pair_i] * cur[best_pair_j]
        for i in range(i_start, i_end + 1):
            j = k - i
            prod = cur[i] * cur[j]
            if prod > max_prod:
                max_prod = prod
                best_pair_i, best_pair_j = i, j

        source = best_pair_i if cur[best_pair_i] >= cur[best_pair_j] else best_pair_j

        # Choose a destination index with low mass (random among bottom 10%)
        sorted_idx = np.argsort(cur)
        low_candidates = sorted_idx[: max(1, n // 10)]
        dest = int(rng.choice(low_candidates))

        if dest == source:
            # avoid no‑op
            continue

        # Amount to transfer – small fraction of source mass
        max_delta = min(cur[source] * 0.5, 0.02)
        delta = max_delta * rng.random()
        if delta < eps:
            continue

        cand = cur.copy()
        cand[source] -= delta
        cand[dest] += delta
        cand = np.maximum(cand, eps)
        cand /= cand.sum()
        cand_score = _max_convolution_score(cand)

        # Acceptance rule
        if cand_score < cur_score - 1e-14:
            cur = cand
            cur_score = cand_score
            if cand_score < best_score - 1e-14:
                best = cand
                best_score = cand_score
        else:
            # temperature decreasing linearly in log‑space
            tau = T0 * (T_end / T0) ** (step / total_steps_est)
            accept_prob = math.exp(-(cand_score - cur_score) / max(tau, 1e-12))
            if rng.random() < accept_prob:
                cur = cand
                cur_score = cand_score

    return best

def _mirror_descent(a: np.ndarray, deadline: float) -> np.ndarray:
    """
    Exponentiated‑gradient (mirror) descent on a smooth‑max approximation
    of the max‑convolution.
    """
    n = a.shape[0]
    eps = 1e-15
    # Schedule parameters – tuned for quick convergence
    total_iters = 8000
    start_temp, end_temp = 1.0, 15000.0
    start_lr, end_lr = 0.25, 0.0005

    for it in range(total_iters):
        if time.time() >= deadline:
            break
        t = it / total_iters
        alpha = start_temp * (end_temp / start_temp) ** t
        lr = start_lr * (end_lr / start_lr) ** t

        conv = _fft_self_convolve(a)
        maxc = conv.max()
        # Soft‑max weights
        w = np.exp(alpha * (conv - maxc))
        w_sum = w.sum()
        if w_sum == 0:
            w.fill(1.0 / w.size)
        else:
            w /= w_sum

        # Gradient of the smooth max (see analysis)
        conv_rev = _fft_convolve(a[::-1], w)
        grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

        # Mirror‑descent update (exponentiated gradient)
        a = a * np.exp(-lr * grad)
        a = _project_onto_simplex(a, 1.0)
        a = np.maximum(a, eps)
        a /= a.sum()
    return a

def _adam_subgrad(a: np.ndarray, deadline: float) -> np.ndarray:
    """
    Projected Adam on the true max‑convolution (active‑set sub‑gradient).
    """
    n = a.shape[0]
    eps = 1e-15
    v = np.zeros_like(a)
    beta1, beta2 = 0.9, 0.999
    it = 0
    step0 = 0.5

    while time.time() < deadline:
        it += 1
        conv = _fft_self_convolve(a)
        cur_max = conv.max()
        tol = 1e-12 * (abs(cur_max) + 1.0)
        active = np.flatnonzero(conv >= cur_max - tol)

        # Sub‑gradient w.r.t. the true max (indicator on active set)
        w = np.zeros_like(conv)
        w[active] = 1.0
        grad = 2.0 * _fft_convolve(a[::-1], w)[n - 1 : n - 1 + n]

        # Adam update
        v = beta1 * v + (1.0 - beta1) * grad
        v_hat = v / (1.0 - beta1 ** it)

        # Simple back‑tracking line search
        step = step0
        while True:
            cand = a - step * v_hat
            cand = _project_onto_simplex(cand, 1.0)
            cand = np.maximum(cand, eps)
            cand /= cand.sum()
            cand_score = _max_convolution_score(cand)
            cur_score = _max_convolution_score(a)
            if cand_score <= cur_score or step < 1e-8:
                break
            step *= 0.5

        a = cand
        # optional jitter every 1000 iterations
        if it % 1000 == 0:
            jitter = np.random.randn(n) * 1e-5
            a = np.maximum(a + jitter, eps)
            a /= a.sum()
    return a

def _refine_candidate(init_vec: np.ndarray, deadline: float, seed: int) -> np.ndarray:
    """
    Apply mirror‑descent → Adam → annealing to a single starting vector.
    Returns the best vector found before the deadline.
    """
    a = init_vec.copy()
    # 1) Mirror descent
    md_deadline = deadline - 0.1 * (deadline - time.time())
    a = _mirror_descent(a, md_deadline)

    # 2) Adam sub‑gradient
    adam_deadline = deadline - 0.05 * (deadline - time.time())
    a = _adam_subgrad(a, adam_deadline)

    # 3) Simulated‑annealing hill‑climber
    anneal_deadline = deadline
    a = _annealing_refine(a, anneal_deadline, seed=seed)

    return a

# Main entry point

def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:
    """
    Search for a step‑function minimising ``evaluate_sequence``.
    The function respects a wall‑clock budget (default 1000 s) and returns
    the best sequence found as a plain Python list.
    """
    rng = np.random.default_rng(seed)
    random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 2.0   # safety margin
    eps = 1e-15

    # --------------------------------------------------------------
    # 1️⃣  Broad exploration – keep the top three candidates.
    best_cands = []   # list of (score, vector, length)

    lengths = [2000, 5000, 10000, 20000, 50000, 120000]
    # Parameter grids (expanded compared to the previous solution)
    sym_p_grid = np.concatenate((
        np.logspace(np.log10(0.02), np.log10(0.5), 15),   # very edge‑biased
        np.linspace(0.5, 5.0, 15)                       # flat‑to‑central shapes
    ))
    asym_q = 0.5
    edge_exp_grid = np.linspace(0.05, 2.0, 12)
    mix_params_grid = [
        (rng.uniform(0.05, 0.5), rng.uniform(0.5, 5.0), rng.random())
        for _ in range(12)
    ]

    for n in lengths:
        if time.time() >= deadline:
            break

        # ---- deterministic families ----------------------------------
        families = []

        families.append((_distribution_uniform(n), "uniform"))
        families.append((_distribution_arcsine(n), "arcsine"))

        # symmetric Beta
        for p in sym_p_grid:
            families.append((_distribution_beta_sym(n, p), f"beta_sym(p={p:.3f})"))

        # asymmetric Beta (left‑heavy and right‑heavy)
        for p in sym_p_grid:
            families.append((_distribution_beta(n, p, asym_q),
                             f"beta(p={p:.3f},q={asym_q})"))
            families.append((_distribution_beta(n, asym_q, p),
                             f"beta(p={asym_q},q={p:.3f})"))

        # edge‑biased Dirichlet draws
        for bex in edge_exp_grid:
            families.append((_distribution_edge_dirichlet(n, bex),
                             f"edge_dir(bex={bex:.2f})"))

        # random Dirichlet draws (concentration = 1)
        for _ in range(5):
            families.append((np.random.dirichlet(np.ones(n)), "dirichlet(1)"))

        # mixtures of two Betas
        for (p1, p2, w) in mix_params_grid:
            families.append((_distribution_beta_mixture(n, p1, p2, w),
                             f"mix(p1={p1:.3f},p2={p2:.3f},w={w:.3f})"))

        # Evaluate all candidates for this length (vectorised loops are avoided
        # to keep memory consumption low)
        for vec, name in families:
            if time.time() >= deadline:
                break
            vec = np.maximum(vec, eps)
            vec /= vec.sum()
            sc = _max_convolution_score(vec)
            if len(best_cands) < 3:
                best_cands.append((sc, vec.copy(), n, name))
                best_cands.sort(key=lambda x: x[0])
            else:
                if sc < best_cands[-1][0]:
                    best_cands[-1] = (sc, vec.copy(), n, name)
                    best_cands.sort(key=lambda x: x[0])

    # ------------------------------------------------------------------
    # 2️⃣  If a previously discovered sequence exists, consider it as a start.
    try:
        prev = np.asarray(height_sequence_1, dtype=np.float64)  # type: ignore[name-defined]
        if prev.ndim == 1 and prev.size:
            prev = np.maximum(prev, eps)
            prev /= prev.sum()
            sc = _max_convolution_score(prev)
            best_cands.append((sc, prev.copy(), len(prev), "prev"))
            best_cands.sort(key=lambda x: x[0])
            best_cands = best_cands[:3]
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 3️⃣  Refine each of the top candidates independently.
    refined = []
    for idx, (score0, vec0, n0, label) in enumerate(best_cands):
        if time.time() >= deadline:
            break
        print(f"[{time.time():.1f}] start refinement {idx+1}/3"
              f" (len={n0}, {label}, score={score0:.6f})")
        # Allocate a fraction of the remaining budget for each refinement
        remaining = deadline - time.time()
        # give at most 0.3·remaining to each, but never less than 1 s
        sub_deadline = time.time() + max(1.0, 0.3 * remaining)
        refined_vec = _refine_candidate(vec0, sub_deadline, seed + idx * 999)
        refined_score = _max_convolution_score(refined_vec)
        refined.append((refined_score, refined_vec, n0, label))
        print(f"[{time.time():.1f}] finished refinement {idx+1} "
              f"score={refined_score:.6f}")

    # ------------------------------------------------------------------
    # 4️⃣  Choose the best among refined solutions
    refined.sort(key=lambda x: x[0])
    best_score, best_seq, best_n, best_label = refined[0]

    # ------------------------------------------------------------------
    # 5️⃣  Final sanity check – make sure the vector respects the evaluator
    best_seq = np.maximum(best_seq, 0.0)
    # Clip values to the range allowed by evaluate_sequence (0 .. 1000)
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    # Normalise to avoid the sum‑check edge case in the evaluator
    s = best_seq.sum()
    if s < 0.01:
        # if for some reason sum is too tiny, fall back to uniform
        best_seq = _distribution_uniform(best_n)
    else:
        best_seq /= s

    final_score = _max_convolution_score(best_seq)
    print(f"[{time.time():.1f}] final best score ≈ {final_score:.6f}"
          f" (length={best_n}, label={best_label})")

    return best_seq.tolist()
```
