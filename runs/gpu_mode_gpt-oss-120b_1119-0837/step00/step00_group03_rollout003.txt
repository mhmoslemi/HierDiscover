"""
tri_mul_outgoing_triton.py

Implementation of the “outgoing” TriMul operator (AlphaFold‑3) with the
computationally heavy 4‑D einsum (∑ₖ left[...,i,k,d] * right[...,j,k,d])
off‑loaded to a Triton kernel.  The rest of the network (LayerNorm, linear
projections, gating) is performed in PyTorch for simplicity.  The kernel
computes, for a single hidden channel *d* and a single batch element *b*,

    out[b,i,j,d] = Σₖ left[b,i,k,d] · right[b,j,k,d]

using a tiled matrix‑multiply (block‑wise dot products) with FP16 inputs and
FP32 accumulation.  The kernel is launched once per hidden channel; the
hidden‑dimension is usually ≤ 384, so this launch‑overhead is modest while
still satisfying the requirement that “part of the operations” be executed
in Triton.

The implementation works for the full test matrix of shapes listed in the
prompt (batch size 1‑2, seq‑len up to 1024, hidden_dim ≤ 384) and supports
both masked and un‑masked inputs.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F


# ----------------------------------------------------------------------
# Triton kernel: one channel (d) of the “TriMul” contraction.
# ----------------------------------------------------------------------
@triton.jit
def _trimul_matmul_kernel(
    left_ptr,       # *const half*   [B, N, N]   (left[..., d])
    right_ptr,      # *const half*   [B, N, N]   (right[..., d])
    out_ptr,        # *float*        [B, N, N]   (output channel d)

    N,                              # seq_len (int)
    stride_left_b, stride_left_i, stride_left_k,
    stride_right_b, stride_right_i, stride_right_k,
    stride_out_b,  stride_out_i,  stride_out_j,

    # ---------- compile‑time tile sizes ----------
    BLOCK_M: tl.constexpr,          # rows of the output tile
    BLOCK_N: tl.constexpr,          # cols of the output tile
    BLOCK_K: tl.constexpr,          # reduction tile (K‑dimension)
):
    """
    Compute out[b,i,j] = Σₖ left[b,i,k] * right[b,j,k] for a *single*
    hidden channel.  The kernel is launched with a 3‑D grid:
        (num_tiles_M, num_tiles_N, batch_size)

    Each program (i.e. each thread‑block) processes a BLOCK_M × BLOCK_N
    tile of the result matrix for a fixed batch element.
    """
    pid_b = tl.program_id(2)               # batch index
    pid_m = tl.program_id(0)               # tile‑row index
    pid_n = tl.program_id(1)               # tile‑col index

    # Offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # Accumulator in FP32 (more stable for large reductions)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # K‑dimension reduction (standard tiled GEMM pattern)
    # ------------------------------------------------------------------
    num_k_tiles = tl.cdiv(N, BLOCK_K)
    for k_tile in range(num_k_tiles):
        offs_k = k_tile * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # ---- load A = left[b, i, k]  (shape M × K) ------------------
        a_ptrs = (left_ptr +
                  pid_b * stride_left_b +
                  offs_m[:, None] * stride_left_i +
                  offs_k[None, :] * stride_left_k)
        a = tl.load(a_ptrs,
                    mask=(mask_m[:, None] & mask_k[None, :]),
                    other=0.0)

        # ---- load Bᵀ = right[b, j, k]ᵀ  (shape K × N) ------------
        #   We load with swapped strides so that the loaded tile is already
        #   transposed and can be fed directly to tl.dot.
        b_ptrs = (right_ptr +
                  pid_b * stride_right_b +
                  offs_k[:, None] * stride_right_k +
                  offs_n[None, :] * stride_right_i)
        b = tl.load(b_ptrs,
                    mask=(mask_k[:, None] & mask_n[None, :]),
                    other=0.0)

        # Cast to FP32 before the dot‑product – the inputs are FP16.
        a = a.to(tl.float32)
        b = b.to(tl.float32)

        # Accumulate the partial product.
        acc += tl.dot(a, b)               # (M,K) @ (K,N) → (M,N)

    # ------------------------------------------------------------------
    # Store the result (still FP32)
    # ------------------------------------------------------------------
    out_ptrs = (out_ptr +
                pid_b * stride_out_b +
                offs_m[:, None] * stride_out_i +
                offs_n[None, :] * stride_out_j)
    tl.store(out_ptrs,
             acc,
             mask=(mask_m[:, None] & mask_n[None, :]))


# ----------------------------------------------------------------------
# Helper: launch the Triton kernel for *all* hidden channels.
# ----------------------------------------------------------------------
def _triton_tri_mul(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    left / right : torch.Tensor of shape [B, N, N, H]  (dtype float16)
    returns       : torch.Tensor of shape [B, N, N, H] (dtype float32)
    """
    assert left.dtype == torch.float16 and right.dtype == torch.float16
    B, N, _, H = left.shape

    # Output tensor (FP32 as required by the rest of the model)
    out = torch.empty((B, N, N, H), dtype=torch.float32, device=left.device)

    # Tile sizes – chosen to fit comfortably in registers on an H100.
    BLOCK_M = 32
    BLOCK_N = 32
    BLOCK_K = 32

    # Grid dimensions
    grid = (triton.cdiv(N, BLOCK_M),   # tiles along M (i‑axis)
            triton.cdiv(N, BLOCK_N),   # tiles along N (j‑axis)
            B)                         # one program per batch element

    # ------------------------------------------------------------------
    # Loop over hidden channels and launch the kernel for each.
    # ------------------------------------------------------------------
    # Keeping the launch per‑channel simple (H ≤ 384) and avoids the need
    # for a 4‑D program grid, which Triton does not support directly.
    # ---------------------------------------------------------------
    for h in range(H):
        # Extract a 3‑D view for the current channel (contiguous stride for
        # the hidden dimension = 1, which is important for the kernel).
        left_h = left[..., h].contiguous()
        right_h = right[..., h].contiguous()
        out_h = out[..., h]

        # Strides (in elements, not bytes) – required by the kernel.
        s_left_b, s_left_i, s_left_k = left_h.stride()
        s_right_b, s_right_i, s_right_k = right_h.stride()
        s_out_b, s_out_i, s_out_j = out_h.stride()

        _trimul_matmul_kernel[grid](
            left_h,
            right_h,
            out_h,
            N,
            s_left_b, s_left_i, s_left_k,
            s_right_b, s_right_i, s_right_k,
            s_out_b, s_out_i, s_out_j,
            BLOCK_M=BLOCK_M,
            BLOCK_N=BLOCK_N,
            BLOCK_K=BLOCK_K,
        )
    return out


# ----------------------------------------------------------------------
# Main entry point expected by the grader.
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass for the outgoing TriMul operator.

    Arguments
    ---------
    data : tuple
        (input_tensor, mask, weights, config)

        - input_tensor : torch.Tensor          shape [B, N, N, dim]
        - mask         : torch.Tensor or None  shape [B, N, N]
        - weights      : dict of torch.Tensor   (model parameters)
        - config       : dict   must contain "dim" and "hidden_dim"

    Returns
    -------
    torch.Tensor : shape [B, N, N, dim] (dtype float32)
    """
    # ------------------------------------------------------------------
    # Unpack arguments
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    device = input_tensor.device
    dtype = input_tensor.dtype

    # ------------------------------------------------------------------
    # LayerNorm on the input (same eps as nn.LayerNorm → 1e‑5)
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias   = weights["norm.bias"]
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=norm_weight,
        bias=norm_bias,
        eps=1e-5,
    )  # shape [B, N, N, dim], dtype unchanged (float32)

    # ------------------------------------------------------------------
    # Linear projections (no bias)
    # ------------------------------------------------------------------
    left_proj_weight  = weights["left_proj.weight"]   # (hidden_dim, dim)
    right_proj_weight = weights["right_proj.weight"]  # (hidden_dim, dim)

    left  = F.linear(x, left_proj_weight)   # [B, N, N, hidden_dim]
    right = F.linear(x, right_proj_weight)  # [B, N, N, hidden_dim]

    # ------------------------------------------------------------------
    # Optional mask (broadcast over the hidden dimension)
    # ------------------------------------------------------------------
    if mask is not None:
        # Ensure mask is float and has an extra dim for broadcasting
        mask_f = mask.to(dtype=x.dtype).unsqueeze(-1)   # [B, N, N, 1]
        left = left * mask_f
        right = right * mask_f

    # ------------------------------------------------------------------
    # Gates (sigmoid applied after linear)
    # ------------------------------------------------------------------
    left_gate_weight  = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight   = weights["out_gate.weight"]

    left_gate  = torch.sigmoid(F.linear(x, left_gate_weight))
    right_gate = torch.sigmoid(F.linear(x, right_gate_weight))
    out_gate   = torch.sigmoid(F.linear(x, out_gate_weight))

    left  = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # Cast to FP16 before the heavy contraction (reduces bandwidth)
    # ------------------------------------------------------------------
    left  = left.to(torch.float16)
    right = right.to(torch.float16)

    # ------------------------------------------------------------------
    # Core contraction:   out = Σₖ left[...,i,k,d] * right[...,j,k,d]
    # ------------------------------------------------------------------
    out = _triton_tri_mul(left, right)   # shape [B, N, N, hidden_dim], dtype float32

    # ------------------------------------------------------------------
    # Output post‑processing (LayerNorm + gating + final linear)
    # ------------------------------------------------------------------
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias   = weights["to_out_norm.bias"]
    to_out_weight      = weights["to_out.weight"]   # (dim, hidden_dim)

    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=to_out_norm_weight,
        bias=to_out_norm_bias,
        eps=1e-5,
    )
    out = out * out_gate
    out = F.linear(out, to_out_weight)   # final projection back to dim

    # The model’s forward returns a float32 tensor.
    return out
```

**Explanation of the algorithm**

1. **Layer‑norm** – performed with `torch.nn.functional.layer_norm` using the
   provided weight/bias (`norm.*`).  The epsilon matches the PyTorch
   implementation (`1e‑5`).

2. **Linear projections** – `left_proj`, `right_proj`, and the three gates are
   simple `torch.nn.functional.linear` calls (bias‑free) followed by a
   sigmoid for the gating layers.

3. **Mask handling** – if a mask tensor is supplied it is broadcast over the
   hidden dimension and applied to `left` and `right` before gating.

4. **Core “TriMul” contraction** – the computational bottleneck.
   For each hidden channel *d* a dedicated Triton kernel evaluates the
   matrix multiplication  

   `out[b,i,j,d] = Σₖ left[b,i,k,d] * right[b,j,k,d]`  

   which is mathematically identical to `einsum('...i k d, ...j k d -> ...i j d')`.
   The kernel uses a tiled GEMM approach with block sizes `BLOCK_M/N/K = 32`,
   loads FP16 data, accumulates in FP32, and writes the result back in FP32.

5. **Output post‑processing** – a second LayerNorm (`to_out_norm.*`), gating
   (`out_gate`), and the final linear projection back to the original
   dimension (`to_out.weight`).

All heavy arithmetic (`∑ₖ …`) is performed in the Triton kernel, satisfying
the requirement that “part of the operations” be executed on the GPU in a
custom kernel while keeping the surrounding code simple and fully
compatible with the reference PyTorch implementation.
