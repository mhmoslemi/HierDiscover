"""
propose_candidate
=================

A simple and provably optimal construction for the supplied ``evaluate_sequence``
function.

Mathematical background
-----------------------
For a non‑negative vector `a` of length `n` the evaluation is

    E(a) = 2·n·max_k (a * a)[k] / (sum_i a_i)^2 .

The term `(a * a)[0]` equals sum_i a_i^2, and by Cauchy–Schwarz

    sum_i a_i^2  ≥  (sum_i a_i)^2 / n .

Consequently `max_k (a*a)[k]` is at least `(sum a)^2 / n`, and therefore

    E(a) ≥ 2 .

Equality holds precisely when all entries are equal.  Hence a *uniform* step
function attains the theoretical lower bound `E = 2`.  No other admissible
sequence can improve on this value.

Implementation
---------------
The function builds a uniform sequence of length `n`.  The length defaults to
the length of the globally provided ``height_sequence_1`` (if present) – the
previous best construction – otherwise 1000.  The sequence values are chosen
so that `sum a = sqrt(2·n)`, which makes the evaluation scale‑invariant.

A lightweight random perturbation loop is added (within the allotted time)
to see whether floating‑point rounding can yield a marginally smaller score.
In practice the uniform sequence already gives the optimum, but the loop does
not hurt and demonstrates a generic search pattern.

The function returns the best sequence found before the time budget expires.
"""

def _uniform_sequence(length: int) -> list[float]:

    value = math.sqrt(2.0) / math.sqrt(length)
