Nevertheless, we may try an approach based on "coordinate descent on M".

Observation: Since the objective depends only on max conv (peak value) times n, we can aim at reducing the peak value gradually.

We can find index kmax where conv is maximal. Then we can try to reduce contributions to conv_kmax by adjusting a_i and a_j that produce that peak. The contributions to conv at kmax are from pairs (i, j) where i+j=kmax. So each pair contributes a_i a_j (twice if i≠j). To reduce total conv at kmax, we can try to reduce some a_i and a_j while increasing other a's to keep sum constant. For example, pick a pair (i, j) with large a_i and a_j, reduce both slightly and increase some other entries that do not affect the same sum.

Thus algorithm:

- Identify kmax = np.argmax(conv)
- Compute contributions for each i: if i in [0..n-1], j=kmax - i (if j in same range). For each i contributes a_i*a_j (or 2 if i!=j). We can compute contributions per index: effect_i = a_i * a_j (if j valid) else 0. The total conv(kmax) = sum_i a_i * a_{kmax-i}. For each i.

- Choose i with high effect (maybe top few) and choose some index l far away such that moving mass from i to l reduces contributions at kmax while not increasing elsewhere too much.

- Perform small transfer delta from i to l; evaluate new conv max (maybe recompute). Accept if improved.

We can repeat many iterations.

Probably simple random move will also discover such improvements over time.

```
def proj_simplex(v):
    # Ensure v as numpy array
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n+1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        rho = 0
    else:
        rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w
```

```
def conv_fft(x, y):
    n = len(x) + len(y) - 1
    size = 1 << (n - 1).bit_length()  # next power of two
    X = np.fft.rfft(x, size)
    Y = np.fft.rfft(y, size)
    Z = X * Y
    res = np.fft.irfft(Z, size)
    return res[:n]
```

```python
def proj_simplex(v):
    # Projection onto probability simplex {w >= 0, sum w = 1}
    # Based on algorithm from Duchi et al. (2008)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n+1)
    # find rho = max i where u_i > cssv_i / i
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0]
    if rho.size == 0:
        theta = 0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w
```

"""
Propose a step‑function (list of non‑negative heights) that minimizes
the provided `evaluate_sequence` score.

Algorithm
---------
* Work on a probability vector `a` (non‑negative, sum = 1).  Since the
  evaluation is scale‑invariant this normalisation does not affect the
  final score.
* Approximate the non‑smooth term `max(conv(a,a))` by a smooth
  soft‑max:
        Lβ(a) = log( Σ_k exp(β·(a∗a)_k) ) / β .
  For β→∞ the soft‑max converges to the true maximum.
* The gradient of `Lβ` w.r.t. `a` can be written in closed form:
        ∇Lβ(a)_j = a_j + Σ_i a_i·p_{i+j},
  where `p` are the soft‑max weights on the convolution entries.
  The term Σ_i a_i·p_{i+j} is obtained by a single convolution of the
  reversed vector `a[::-1]` with `p`.
* Perform projected gradient descent on the simplex:
  – compute the convolution with FFT (O(n log n));
  – compute soft‑max weights;
  – form the gradient using another FFT;
  – take a small step opposite to the gradient;
  – project the result back onto the probability simplex
    (Euclidean projection, Duchi et al. 2008).
* β is started small (smooth objective) and slowly increased, while the
  learning rate is slowly decayed.  This “entropy‑annealing” helps the
  optimizer escape plateaus and eventually focus on the true maximum.
* Multiple sequence lengths and several random starts (including the
  supplied `height_sequence_1`) are explored until the time budget is

import time
import numpy as np

def _proj_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex { w >= 0, sum w = 1 }."""
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]

    if not np.any(cond):

    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w
