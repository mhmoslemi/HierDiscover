The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

For a monotone linear sequence a_i = i (or any positive multiple of i) one can
compute analytically:

    sum(a) = n (n‑1) / 2
    max(conv) = n (n‑1) (n‑2) / 6

Consequently

    score = (2 n) * [n (n‑1) (n‑2) / 6] / [n² (n‑1)² / 4] = (4/3) * (n‑2)/(n‑1)

which tends to 4/3 ≈ 1.333 for large n – well below the target 1.503.

value is 1000, because the evaluator clips values to that limit).  The length
