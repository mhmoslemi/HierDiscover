def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Search for a sequence of non‑negative heights that minimizes
    `evaluate_sequence`.  The theoretical minimum of the objective is 2,
    achieved by any constant (uniform) sequence.  The algorithm therefore
    starts from a uniform sequence of length L and performs a simple
    stochastic hill‑climbing; the best sequence found (normally the uniform
    one) is returned.
    """
    import time, numpy as np
    np.random.seed(seed)

    deadline = time.time() + budget_s - 0.5

    # Choose a reasonable length.  If a previous construction is available
    # we reuse its length, otherwise we pick a default of 2000.
    try:
        base = list(height_sequence_1)
        L = len(base)
        # Normalise to a constant height (1.0) while keeping length.
        curr = [1.0] * L
    except Exception:
        L = 1805   # the length of the previous best solution
        curr = [1.0] * L

    # Clip to the limits used inside `evaluate_sequence`
    curr = [max(0.0, min(1000.0, float(x))) for x in curr]

    best_seq = curr[:]
    best_score = evaluate_sequence(best_seq)

    # If the current score is already the theoretical optimum (2.0) we can
    # stop early – any perturbation can only increase the objective.
    if abs(best_score - 2.0) < 1e-12:

Simple uniform‑height step function search.

The objective to minimise is
    E(a) = 2 * n * max(conv(a, a)) / (sum(a)^2)

For any non‑negative vector a the inequality
    max(conv(a, a)) ≥ sum(a)^2 / n

sum_i a_i^2 ≥ sum(a)^2 / n).  Hence
    E(a) ≥ 2,
with equality attained by any constant (uniform) sequence.
Therefore the global optimum is 2, reached by the uniform sequence.

* builds a constant sequence of length taken from the previously known
