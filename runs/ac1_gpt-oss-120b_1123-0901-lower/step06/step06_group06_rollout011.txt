assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the linear convolution of the non‑negative sequence `a`.  
Because the ratio is scale‑invariant we can fix `∑a = 1` and simply minimise
`max (a*a)`.

A *flat* self‑convolution (all entries equal to the average `1/(2n‑1)`) would give the
theoretical lower bound `F≈1`.  Exact flatness is impossible under the
non‑negativity constraint, but we can approach it by **alternating projections**
between

* the **simplex** – non‑negative entries that sum to one, and  
* the **spectral‑flatness set** – vectors whose discrete Fourier transform (DFT)
  has constant magnitude (|𝐀ₖ| = 1 for every frequency).  

If a sequence has a flat spectrum its circular auto‑convolution is (almost) uniform,
hence its linear auto‑convolution is also almost uniform on the interval
`[0,2n‑2]`.  By repeatedly projecting onto these two sets we obtain a sequence
with a very low `max(a*a)`.  The algorithm is cheap (FFT‑based, O(n log n) per
iteration) and works well for the sizes that give the best bounds.

The code below

1. explores several lengths (`1024 … 16384`) – larger `n` gives a lower
   theoretical bound,
2. performs a number of *restarts* (different random seeds) of the alternating‑projection
   scheme,
3. keeps the best sequence found,
4. finally runs a short Adam optimisation (smooth‑max surrogate) to polish the
   result.

All work respects the supplied time budget; if the budget expires the best
sequence obtained so far is returned.

```python
"""
Propose a non‑negative step‑function that minimises

        F(a) = 2·n·max(a*a) / (sum(a)²)

The algorithm is:

1.  Alternating projection between
        • the simplex (a_i ≥ 0, Σ a_i = 1) and
        • the set of vectors whose DFT has constant magnitude (|Âₖ| = 1).
    The projection onto the spectral set is performed by keeping the phase of
    the current DFT and forcing the magnitude to 1.  After the inverse FFT the
    tail (indices ≥ n) is forced to zero, the first n entries are clipped to
    non‑negative values and renormalised.

2.  Several random restarts are executed for a range of lengths (up to 16384).
    The best sequence over all runs is kept.

3.  The best candidate is fine‑tuned with a few Adam steps on a smooth‑max
    surrogate of the true maximum.  This polishing phase often yields a
    small additional improvement.

The whole search respects a 1000 s budget and returns a plain Python list.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper FFT utilities -------------------------------------------------
def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a using an FFT of length ``fft_len``."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    return conv[: 2 * a.shape[0] - 1]


def _corr_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for the Adam surrogate.
    Returns a vector of length len(a) equal to

        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]

    where n = len(a).
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: float = 1000) -> list:
    """
    Search for a non‑negative sequence with a low evaluation score.
    The function respects the given time budget and returns the best
    sequence discovered as a plain Python list.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # safety margin

    best_seq = None
    best_val = float("inf")

    # Lengths to try – larger n gives a lower theoretical bound.
    lengths = [1024, 2048, 4096, 8192, 16384]

    for n in lengths:
        if time.time() > deadline:
            break
        print(f"\n=== Optimising length n={n} ===")
        # FFT length – next power of two (fast and convenient for both
        # convolution and the alternating‑projection step).
        fft_len = 1 << int(np.ceil(np.log2(2 * n - 1)))

        # ------------------------------------------------------------------
        # 1) Alternating‑projection stage
        # ------------------------------------------------------------------
        # Number of independent random restarts (more for smaller n).
        restarts = 12 if n <= 4096 else 6
        for restart in range(restarts):
            if time.time() > deadline:
                break

            # ----- initialise a -----   (arcsine shape + tiny jitter)
            i = np.arange(n, dtype=np.float64)
            a = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i))
            a += 0.001 * np.random.rand(n)               # random jitter
            a = np.maximum(a, 0.0)
            a /= a.sum()                                 # simplex normalisation

            # Full vector (length = fft_len); the tail must stay zero.
            v = np.zeros(fft_len, dtype=np.float64)
            v[:n] = a

            # Iteration budget – grows for smaller problems.
            max_iters = 3000 if n <= 4096 else 1500
            last_improve = time.time()

            for it in range(max_iters):
                # ----- projection onto the spectral‑flatness set -----
                V = np.fft.fft(v)                # full complex FFT (length fft_len)
                phi = np.angle(V)
                # force magnitude to 1, keep the phase; enforce real DC = 1
                V_new = np.empty_like(V)
                V_new[0] = 1.0                    # DC component (sum = 1)
                V_new[1:] = np.exp(1j * phi[1:]) # magnitude = 1, phase preserved

                # ----- back to time domain -----
                v_new = np.real(np.fft.ifft(V_new))

                # ----- projection onto the simplex (first n entries) -----
                v_new[n:] = 0.0                   # enforce zero tail
                a = np.maximum(v_new[:n], 0.0)   # non‑negative
                s = a.sum()
                if s < 1e-12:                    # avoid collapse – reinitialise if needed
                    a = np.random.dirichlet(np.ones(n))
                    s = a.sum()
                a /= s
                v[:n] = a                         # update full vector

                # ----- evaluate current objective -----
                conv = _conv_fft(a, fft_len)
                max_c = conv.max()
                val = 2.0 * n * max_c

                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    last_improve = time.time()
                    print(f"[n={n} restart={restart} it={it:04d}] new best {val:.6f}")

                # ----- stagnation handling – tiny random shake -----
                if time.time() - last_improve > 5.0:
                    a += (np.random.rand(n) - 0.5) * 5e-4
                    a = np.maximum(a, 0.0)
                    a /= a.sum()
                    v[:n] = a
                    last_improve = time.time()

                if time.time() > deadline:
                    break

        # ------------------------------------------------------------------
        # 2) Optional fine‑tuning with Adam on a smooth‑max surrogate.
        #    This step is cheap (few thousand iterations) and sometimes
        #    squeezes a small extra improvement.
        # ------------------------------------------------------------------
        if best_seq is not None and len(best_seq) == n:
            print(f"[n={n}] fine‑tuning the current best with Adam")
            a = best_seq.copy()
            # Work in the log‑softmax (logits) domain – this guarantees non‑negativity.
            logits = np.log(a + 1e-15)

            m = np.zeros_like(logits)
            v_adam = np.zeros_like(logits)
            beta1, beta2, eps = 0.9, 0.999, 1e-8

            # Learning‑rate that scales mildly with the problem size.
            lr = 0.07 * np.sqrt(2048.0 / n)

            # Temperature for the smooth‑max – starts small and grows quickly.
            lam = 0.3
            lam_factor = 1.015

            max_adam_iters = int(20000 * 1024.0 / n) + 2000
            last_imp = time.time()

            for t in range(1, max_adam_iters + 1):
                # ----- soft‑max mapping (simplex) -----
                mx = logits.max()
                exp_x = np.exp(logits - mx)
                a = exp_x / exp_x.sum()

                # ----- convolution and smooth‑max weights -----
                fa = np.fft.rfft(a, fft_len)
                conv = np.fft.irfft(fa * fa, fft_len)[: 2 * n - 1]
                max_c = conv.max()
                w = np.exp(lam * (conv - max_c))
                w_sum = w.sum()
                if w_sum == 0.0:
                    w = np.full_like(w, 1.0 / w.size)
                else:
                    w /= w_sum

                # ----- gradient of the surrogate (linear in w) -----
                grad_a = 2.0 * _corr_fft(w, a, fft_len)

                # ----- back‑prop through the soft‑max -----
                avg = np.dot(a, grad_a)
                grad_log = a * (grad_a - avg)

                # ----- Adam update -----
                m = beta1 * m + (1.0 - beta1) * grad_log
                v_adam = beta2 * v_adam + (1.0 - beta2) * (grad_log ** 2)
                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v_adam / (1.0 - beta2 ** t)
                logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

                # ----- temperature schedule -----
                lam = min(lam * lam_factor, 1e6)

                # ----- objective check -----
                val = 2.0 * n * max_c
                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    last_imp = time.time()
                    print(f"[n={n} Adam it={t}] new best {val:.6f}")

                # ----- early stop on stagnation -----
                if time.time() - last_imp > 8.0:
                    break
                if time.time() > deadline:
                    break

    # ----------------------------------------------------------------------
    # Fallback – uniform vector (should never be needed).
    # ----------------------------------------------------------------------
    if best_seq is None:
        fallback_n = 1024
        best_seq = np.full(fallback_n, 1.0 / fallback_n, dtype=np.float64)

    # Return a plain Python list as required by the external evaluator.
    return best_seq.tolist()
```
