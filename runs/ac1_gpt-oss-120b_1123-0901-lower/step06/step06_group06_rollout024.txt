assistantfinal**Solution Overview**

The task is to return a non‑negative list `a` that minimises  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\]

where `a*a` is the (full) linear convolution of `a` with itself.
`evaluate_sequence` implements exactly this formula (together with a few
safety clamps).  
The function is scale‑invariant, therefore we can always keep the
sequence on the probability simplex (`∑a_i = 1`).  The problem is a
non‑smooth optimisation on the simplex.

The code below builds on the previous “Adam + sub‑gradient” approach but
adds a few extra ingredients that empirically push the bound lower:

* **Richer set of start‑points** – in addition to the Dirichlet draws
  already used we also generate (i) random + Gaussian blobs,
  (ii) piecewise‑linear “double‑tent”, (iii) low‑frequency cosine series,
  (iv) a few hand‑crafted low‑autocorrelation patterns.
* **Two‑phase optimiser**
  1. **Smooth‑max Adam** – a smooth approximation of the max (`log‑sum‑exp`)
     is minimised with Adam.  The temperature is increased geometrically
     from `0.1` up to `1e6` so that the surrogate converges to the true
     `max`.
  2. **Exact sub‑gradient (exponentiated‑gradient)** – after the smooth
     phase we switch to the exact non‑smooth objective.  This phase is
     very cheap because the gradient is a simple cross‑correlation.
* **Local hill‑climbing** – a cheap coordinate‑wise move (`δ` mass shifted
  from one index to another) is attempted repeatedly; moves that lower
  the objective are kept.  This often removes tiny plateaus that Adam
  cannot escape.
* **Length schedule** – we start with moderate lengths (`1024`, `2048`,
  `4096`) and, when time permits, try a larger size (`8192`).  Longer
  vectors give a larger search space, but the algorithm automatically
  stops when the time budget expires.
* **Fine‑tuning of the current global best** – after every length the
  best sequence found so far is re‑optimised with a long Adam run.

All expensive operations (convolution & cross‑correlation) are performed
with an FFT of size a power of two, yielding an \(O(n\log n)\) cost.
The whole search respects the given time budget (`budget_s`, default
`1000 s`).  The function finally returns the best sequence it discovered
as a plain Python list – exactly the format that the external judge
expects.

```python
"""
Propose a non‑negative step‑function (list of heights) that minimises

        F(a) = 2·n·max(a*a) / (sum(a)²)

The optimiser works in three stages:

1.  A rich pool of random / deterministic start‑vectors (Dirichlet,
    power‑law, Gaussian‑blob, double‑tent, cosine‑series, sparse spikes)
    – all normalised to sum = 1.

2.  Smooth‑max Adam optimisation (log‑sum‑exp surrogate) with a
    geometrically increasing temperature, followed by an exact
    exponentiated‑gradient (sub‑gradient) phase.

3.  A cheap coordinate‑wise hill‑climbing pass that moves a tiny amount
    of mass between two random positions and keeps the move if it lowers
    the objective.

After each length the current best is fine‑tuned with a long Adam run.
The whole search stops after the allocated budget (default 1000 s) and
returns the best sequence found.
"""

import time
import numpy as np
from numpy.fft import rfft, irfft

# ----------------------------------------------------------------------
# Helper FFT‑based convolution / cross‑correlation
def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a using an FFT of length ``fft_len``."""
    fa = rfft(a, fft_len)
    conv = irfft(fa * fa, fft_len)
    return conv[: 2 * a.shape[0] - 1]


def _corr_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for the sub‑gradient.
    Returns a vector of length len(a) equal to

        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]

    where n = len(a).
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = rfft(w, fft_len)
    fr = rfft(rev_a, fft_len)
    corr = irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]


# ----------------------------------------------------------------------
# Exact objective (no clamping – the same as evaluate_sequence for sum=1)
def _objective(a: np.ndarray, n: int, conv_len: int) -> float:
    """Exact evaluation of 2·n·max(conv) (sum(a) is assumed to be 1)."""
    conv = _conv_fft(a, conv_len)
    return 2.0 * n * conv.max()


# ----------------------------------------------------------------------
# Construction of a diversified pool of initial candidates
def _initial_pool(n: int) -> list[np.ndarray]:
    """Create many different starting vectors, all normalised to sum‑= 1."""
    pool = []
    rng = np.random.default_rng()

    # 1) Warm start from the previous global solution (if any)
    if "height_sequence_1" in globals():
        old = np.asarray(height_sequence_1, dtype=np.float64)
        if old.shape[0] > n:
            old = old[:n]
        else:
            old = np.pad(old, (0, n - old.shape[0]))
        old = np.maximum(old, 0.0)
        s = old.sum()
        old = old / s if s > 0 else np.full_like(old, 1.0 / n)
        pool.append(old)

    # 2) Pure Dirichlet (uniform)
    pool.append(np.random.dirichlet(np.ones(n)))

    # 3) Over‑ and under‑dispersed Dirichlet
    for conc in (0.2, 0.4, 0.6, 0.8, 1.5, 2.0, 3.0):
        pool.append(np.random.dirichlet(np.full(n, conc)))

    # 4) Power‑law edge‑concentrated shapes
    idx = np.arange(1, n + 1, dtype=np.float64)
    prod = idx * (n - idx + 1.0)
    for alpha in np.linspace(-2.0, -0.2, 7):
        shape = np.power(prod, alpha, where=prod > 0, out=np.zeros_like(prod))
        if shape.sum() > 0:
            pool.append(shape / shape.sum())

    # 5) Gaussian blobs with random centre & width
    for _ in range(4):
        centre = rng.integers(0, n)
        sigma = rng.uniform(0.02, 0.15) * n
        i = np.arange(n, dtype=np.float64)
        gauss = np.exp(-0.5 * ((i - centre) / sigma) ** 2)
        pool.append(gauss / gauss.sum())

    # 6) Double‑tent (two linear ramps meeting in the centre)
    left = np.linspace(0, 1, n // 2, endpoint=False)
    right = left[::-1]
    double_tent = np.concatenate([left, right])
    if double_tent.shape[0] < n:
        double_tent = np.concatenate([double_tent, [0.0]])
    pool.append(double_tent / double_tent.sum())

    # 7) Low‑frequency cosine series (smooth bump)
    i = np.arange(n, dtype=np.float64)
    coeffs = rng.uniform(-1, 1, size=3)
    cos_series = coeffs[0] * np.cos(2 * np.pi * i / (n - 1))
    cos_series += coeffs[1] * np.cos(4 * np.pi * i / (n - 1))
    cos_series += coeffs[2] * np.cos(6 * np.pi * i / (n - 1))
    cos_series = np.maximum(cos_series, 0.0)
    if cos_series.sum() == 0:
        cos_series = np.ones_like(cos_series)
    pool.append(cos_series / cos_series.sum())

    # 8) Sparse pattern (≈ sqrt(n) spikes)
    m_spikes = max(2, int(np.sqrt(2 * n)))
    sparse = np.zeros(n, dtype=np.float64)
    spikes = rng.choice(n, size=m_spikes, replace=False)
    sparse[spikes] = rng.uniform(0.5, 1.0, size=m_spikes)
    pool.append(sparse / sparse.sum())

    return pool

def propose_candidate(seed: int = 0, budget_s: float = 1000) -> list:

    function.  The routine runs for at most ``budget_s`` seconds and
    returns the best sequence found as a plain Python list.
    """

    deadline = time.time() + budget_s - 0.5     # leave a tiny safety margin

    best_seq = None
    best_val = float("inf")

    # Lengths we will try – start small, increase if time allows.
    lengths = [1024, 2048, 4096, 8192]

    fft_len_conv = {}
    fft_len_corr = {}
    for n in lengths:
        conv_len = 2 * n - 1
        fft_len_conv[n] = 1 << int(np.ceil(np.log2(conv_len)))
        fft_len_corr[n] = 1 << int(np.ceil(np.log2(conv_len + n - 1)))

    # ------------------------------------------------------------------
    for n in lengths:
        if time.time() > deadline:
            break

        print(f"\n=== Optimising length n={n} ===")
        conv_len = fft_len_conv[n]
        corr_len = fft_len_corr[n]

        # ----- build a diversified pool of start points -----------------
        candidates = _initial_pool(n)

        # ----- optimise every candidate ---------------------------------
        for cid, a0 in enumerate(candidates):
            if time.time() > deadline:
                break

            # Work in the log‑softmax (logits) domain – this guarantees
            # the simplex constraint without an explicit projection.
            a = np.asarray(a0, dtype=np.float64)
            a = np.maximum(a, 0.0)
            a = a / a.sum()
            logits = np.log(a + 1e-15)

            # ---- Adam on a smooth‑max surrogate ------------------------
            m = np.zeros_like(logits)
            v = np.zeros_like(logits)
            beta1, beta2, eps = 0.9, 0.999, 1e-8

            # Learning‑rate roughly scales with sqrt(2048/n)
            lr = 0.07 * np.sqrt(2048.0 / n)

            # Temperature schedule (smooth‑max)
            temperature = 0.15
            temp_factor = 1.025   # aggressive growth

            last_improve = time.time()
            # Give more iterations to smaller n
            max_iters = int(60000 * 1024 / n) + 5000

            for t in range(1, max_iters + 1):
                # ---- soft‑max (simplex) mapping ------------------------
                mx = logits.max()
                exp_x = np.exp(logits - mx)
                a = exp_x / exp_x.sum()

                # ---- smooth‑max of the convolution ---------------------
                conv = _conv_fft(a, conv_len)
                max_c = conv.max()
                # log‑sum‑exp weights
                w = np.exp(temperature * (conv - max_c))
                w_sum = w.sum()
                if w_sum == 0.0:
                    w = np.full_like(w, 1.0 / w.size)
                else:
                    w /= w_sum

                # ---- gradient of the surrogate (linear in w) ----------
                grad_a = 2.0 * _corr_fft(w, a, corr_len)

                # ---- back‑prop through the soft‑max --------------------
                avg = np.dot(a, grad_a)
                grad_logits = a * (grad_a - avg)

                # ---- Adam update ---------------------------------------
                m = beta1 * m + (1.0 - beta1) * grad_logits
                v = beta2 * v + (1.0 - beta2) * (grad_logits ** 2)
                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v / (1.0 - beta2 ** t)
                logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

                # ---- temperature increase -------------------------------
                temperature = min(temperature * temp_factor, 1e6)

                # ---- exact objective (sum(a) == 1) ---------------------
                val = 2.0 * n * max_c   # identical to evaluate_sequence

                    best_val = val
                    best_seq = a.copy()
                    last_improve = time.time()
                    print(f"[n={n} cand={cid} Adam it={t:05d}] new best {val:.6f}")

                # ---- stagnation handling – mild random shake -----------
                if time.time() - last_improve > 6.0:
                    logits += (np.random.rand(n) - 0.5) * 1e-2
                    last_improve = time.time()

                if time.time() > deadline:
                    break

            # ---- Exact max: exponentiated‑gradient (sub‑gradient) -------
            a = a / a.sum()
            eta = 0.55                  # step size for EG
            sub_last_improve = time.time()
            for sub_it in range(5000):
                conv = _conv_fft(a, conv_len)
                max_c = conv.max()
                active = np.isclose(conv, max_c, atol=1e-12, rtol=0.0)

                if active.any():
                    w = np.zeros_like(conv)
                    w[active] = 1.0 / active.sum()
                else:
                    w = np.zeros_like(conv)

                grad_a = 2.0 * _corr_fft(w, a, corr_len)

                a = a * np.exp(-eta * grad_a)
                s = a.sum()
                if s < 1e-12:
                    a = np.random.dirichlet(np.ones(n))
                    s = a.sum()
                a = a / s

                conv = _conv_fft(a, conv_len)
                max_c = conv.max()
                val = 2.0 * n * max_c

                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    sub_last_improve = time.time()
                    print(f"[n={n} cand={cid} Subgrad it={sub_it}] new best {val:.6f}")

                if time.time() - sub_last_improve > 7.0:
                    break
                if time.time() > deadline:
                    break

            # ---- Light‑weight hill‑climbing on the current candidate ----
            a = a.copy()
            hill_last_improve = time.time()
            for hc in range(2000):
                i, j = np.random.choice(n, 2, replace=False)
                # move a tiny amount δ from i to j (keep non‑negative)
                delta = np.random.uniform(0, 0.001) * a[i]
                a[i] -= delta
                a[j] += delta
                # renormalise (sum is unchanged, but protect against drift)
                a = np.maximum(a, 0.0)
                a_sum = a.sum()
                if a_sum == 0:
                    continue
                a /= a_sum

                val = _objective(a, n, conv_len)

                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    hill_last_improve = time.time()
                    print(f"[n={n} cand={cid} Hill it={hc}] new best {val:.6f}")

                # stop early if we see no progress for a while
                if time.time() - hill_last_improve > 5.0:
                    break
                if time.time() > deadline:
                    break

        # ---------- fine‑tune the global best for the current length ----
        if best_seq is not None and len(best_seq) == n:
            print(f"[n={n}] fine‑tuning global best (val={best_val:.6f})")
            a = best_seq.copy()
            logits = np.log(a + 1e-15)

            m = np.zeros_like(logits)
            v = np.zeros_like(logits)
            beta1, beta2, eps = 0.9, 0.999, 1e-8
            lr = 0.045 * np.sqrt(2048.0 / n)
            temperature = 0.35
            temp_factor = 1.012
            fine_last_improve = time.time()
            fine_iters = int(80000 * 1024 / n) + 5000

            for t in range(1, fine_iters + 1):
                mx = logits.max()
                exp_x = np.exp(logits - mx)
                a = exp_x / exp_x.sum()

                conv = _conv_fft(a, conv_len)
                max_c = conv.max()
                w = np.exp(temperature * (conv - max_c))
                w_sum = w.sum()
                w = w / w_sum if w_sum != 0 else np.full_like(w, 1.0 / w.size)

                grad_a = 2.0 * _corr_fft(w, a, corr_len)
                avg = np.dot(a, grad_a)
                grad_logits = a * (grad_a - avg)

                m = beta1 * m + (1.0 - beta1) * grad_logits
                v = beta2 * v + (1.0 - beta2) * (grad_logits ** 2)
                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v / (1.0 - beta2 ** t)
                logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

                temperature = min(temperature * temp_factor, 1e6)

                val = 2.0 * n * max_c
                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    fine_last_improve = time.time()
                    print(f"[n={n} fine it={t:05d}] new best {val:.6f}")

                if time.time() - fine_last_improve > 9.0:
                    logits += (np.random.rand(n) - 0.5) * 5e-3
                    fine_last_improve = time.time()

                if time.time() > deadline:
                    break

    # ------------------------------------------------------------------
    # Fallback – should never be needed, but keep a safe guard.
    if best_seq is None:
        fallback_n = 1024
        best_seq = np.full(fallback_n, 1.0 / fallback_n, dtype=np.float64)

    # Return as a plain Python list (the external evaluator expects a list)
    return best_seq.tolist()
```
