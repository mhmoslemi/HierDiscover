assistantfinal**Solution Overview**

The function below implements a **smoothed‑max gradient descent** on the self‑convolution peak.
The idea is:

1. **Normalization** – keep the vector on the probability simplex (sum = 1, non‑negative).  
2. **Smooth objective** – replace the nonsmooth max by a log‑sum‑exp
   \[
   F_\beta(a)=\frac1\beta\log\!\Bigl(\sum_k e^{\beta\,\mathrm{conv}(a,a)_k}\Bigr)
   \]
   whose gradient is a weighted sum of the gradients of the single
   convolution entries.  The weights are
   \[
   w_k=\frac{e^{\beta(\mathrm{conv}_k-\max\mathrm{conv})}}{\sum_j e^{\beta(\mathrm{conv}_j-\max\mathrm{conv})}} .
   \]

3. **Fast gradient** – the weighted gradient can be written as a
   cross‑correlation and is computed by a single FFT‑based convolution.  
4. **Projected (additive) update** – `a ←  a − η·grad`, followed by a
   projection onto the simplex.  A short back‑tracking line‑search
   guarantees a non‑increasing peak.  
5. **Exploration** – if several attempts do not improve the peak a tiny
   random perturbation is added; after a long streak without improvement
   we restart from a fresh random Dirichlet vector.  
6. **Annealing of β** – β is slowly increased (default 1 → 30) so that the
   algorithm first smooths the landscape and later focuses on the true
   maximum.

The routine works for any length; if a previously found sequence
`height_sequence_1` exists its length is reused, otherwise a default of
≈ 6000 entries is used.  The best vector encountered during the run is
returned as a plain Python list.

```python
#!/usr/bin/env python
"""
Smoothed‑max gradient descent for the self‑convolution peak problem.

The algorithm keeps the coefficient vector on the probability simplex,
optimises a log‑sum‑exp relaxation of the peak, computes the weighted
gradient efficiently with FFTs, uses a back‑tracking line‑search and
occasionally randomises to escape plateaus.  The best vector found
within the time budget is returned as a list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: projection onto the simplex {x >= 0, sum(x) = 1}
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("simplex projection expects a 1‑D array")
    n = v.shape[0]
    # sort in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    # find the rho where u_i > (cssv_i / i)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # numerical safety – fall back to uniform
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

# ----------------------------------------------------------------------
# Helper: full linear convolution a*a (length 2·n‑1) via FFT
# ----------------------------------------------------------------------
def _full_convolution(a: np.ndarray) -> np.ndarray:
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())  # next power of two
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[: 2 * n - 1]
    return conv

# ----------------------------------------------------------------------
# Helper: weighted gradient of the smoothed max (see docstring)
# ----------------------------------------------------------------------
def _weighted_gradient(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute 2 * sum_k w_k * a_{k-i}   for i = 0..n‑1.
    This is the cross‑correlation of w with a (reversed) and can be
    obtained by a single convolution in the Fourier domain.
    """
    n = a.shape[0]
    a_rev = a[::-1]                       # reversed a
    # length of the convolution we need: len(w) + n - 1
    size = 1 << ((len(w) + n - 1).bit_length())
    fw = np.fft.rfft(w, size)
    fa = np.fft.rfft(a_rev, size)
    conv = np.fft.irfft(fw * fa, size)    # length = len(w)+n-1
    start = n - 1
    grad = 2.0 * conv[start:start + n]    # pick the n relevant entries
    return grad

    """

        # (f) Previous best if it exists
        try:
            prev = np.array(height_sequence_1, dtype=np.float64)  # type: ignore[name-defined]
            if prev.sum() > 0:
                prev = np.maximum(prev, 0.0)
                prev = prev / prev.sum()
                vecs.append(prev)
        except Exception:
            pass

        return vecs

    # --------------------------------------------------------------
    # 3. Simple score evaluator (identical to evaluate_sequence for sum=1)
    # --------------------------------------------------------------
    def _score(a: np.ndarray) -> float:
        conv = _full_convolution(a)
        return float(2 * n * conv.max())

    # --------------------------------------------------------------
    # 4. Initialise best solution from the pool
    # --------------------------------------------------------------
    init_vecs = _initial_vectors()
    best_a = None
    best_score = float("inf")
    for v in init_vecs:
        sc = _score(v)
        if sc < best_score:
            best_score = sc
            best_a = v.copy()
    if best_a is None:      # should never happen
        best_a = np.full(n, 1.0 / n)

    print(f"Initial best score from pool: {best_score:.6f}")

    # --------------------------------------------------------------
    # 5. Main optimisation loop (smoothed‑max gradient descent)
    # --------------------------------------------------------------
    a = best_a.copy()        # current iterate
    iteration = 0
    beta = 1.0               # start with a gentle smoothing
    beta_max = 30.0
    eta0 = 0.5               # initial step‑size factor
    no_improve = 0
    RESTART_THRESHOLD = 15000
    LINESEARCH_MAX = 5

    while time.time() < deadline:
        # ----------------------------------------------------------
        # compute convolution and the maximal entry
        # ----------------------------------------------------------
        conv = _full_convolution(a)
        max_val = conv.max()

        # ----------------------------------------------------------
        # compute the smoothed‑max weights
        # ----------------------------------------------------------
        # w_k = exp(beta * (conv_k - max_val))  (≤ 1)
        w = np.exp(beta * (conv - max_val))
        w_sum = w.sum()
        if w_sum == 0.0:  # numeric safety
            w = np.full_like(w, 1.0 / w.size)
        else:
            w = w / w_sum

        # ----------------------------------------------------------
        # weighted gradient (efficient FFT implementation)
        # ----------------------------------------------------------
        grad = _weighted_gradient(a, w)

        # ----------------------------------------------------------
        # back‑tracking line‑search (ensure the peak does not increase)
        # ----------------------------------------------------------
        eta = eta0 / math.sqrt(iteration + 1.0)
        improved = False
        for _ in range(LINESEARCH_MAX):
            a_candidate = _project_onto_simplex(a - eta * grad)
            conv_cand = _full_convolution(a_candidate)
            if conv_cand.max() <= max_val + 1e-14:   # non‑worsening
                a = a_candidate
                max_val = conv_cand.max()
                improved = True
                break
            eta *= 0.5

        if not improved:
            # small random kick to get out of a plateau
            noise = np.random.randn(n) * 5e-4
            a = _project_onto_simplex(a + noise)

        # ----------------------------------------------------------
        # keep the best solution seen so far
        # ----------------------------------------------------------
        cur_score = float(2 * n * max_val)
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
            no_improve = 0
            print(f"Iter {iteration:7d}: new best score {best_score:.6f}")
        else:
            no_improve += 1

        # ----------------------------------------------------------
        # anneal beta slowly (focus more on the true max)
        # ----------------------------------------------------------
        if iteration % 2000 == 0 and iteration > 0:
            beta = min(beta * 1.2, beta_max)

        # ----------------------------------------------------------
        # occasional full restart if we have been stuck too long
        # ----------------------------------------------------------
        if no_improve >= RESTART_THRESHOLD:
            rng = np.random.default_rng(seed + iteration)
            a = rng.dirichlet(np.ones(n))
            no_improve = 0
            print(f"Iter {iteration:7d}: restart with fresh Dirichlet")

        iteration += 1

    # --------------------------------------------------------------
    # 6. Return the best vector discovered (as a plain list)
    # --------------------------------------------------------------
    final_score = _score(best_a)
    print(f"Finished after {iteration} iterations. Best score = {final_score:.6f}")
    return best_a.tolist()
```
