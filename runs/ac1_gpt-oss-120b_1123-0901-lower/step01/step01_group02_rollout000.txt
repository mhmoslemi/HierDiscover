"""
Propose a step‑function height sequence that minimises the evaluation
function (i.e. the maximal autocorrelation).

Algorithm
---------
* Work with a fixed length `n` and keep the total sum `S = sqrt(2·n)`.
  After each update the vector is projected onto the simplex
  `{a ≥ 0, sum(a)=S}` – this preserves the scale‑invariance of the
  objective.

* Instead of the non‑smooth maximum we minimise a smooth
  approximation:
        f(a) = (1/α)·log( Σ_k exp(α·(a∗a)[k]) )
  whose gradient is
        ∇f_i = 2· Σ_k w_k·a_{k‑i},
  where `w_k = exp(α·(a∗a)[k]) / Σ_j exp(α·(a∗a)[j])`.
  For α→∞ the smoothed objective converges to the true maximum.

* The gradient is computed efficiently with two convolutions:
      conv  = a ∗ a                         (length 2n‑1)
      w    = softmax(α·conv)                (same length)
      grad = 2· (w ∗ rev(a))[n‑1 : n‑1+n]   (rev = a reversed)

* An Adam optimiser (first‑/second‑moment adaptation) supplies
  adaptive step sizes.  The learning‑rate decays slowly, and a small
  random jitter is added periodically to escape shallow plateaus.

* The algorithm runs until the time budget (≈1000 s) is exhausted,
  keeping the best sequence ever seen.

The method is deliberately different from the previous plain projected
gradient descent and usually finds lower maximal autocorrelations,
approaching the target bound ≈1.503.
"""

import time
import math
import numpy as np

# ---------------------------------------------------------------
# Helper: smoothed gradient of the max‑convolution objective
def _smoothed_gradient(a: np.ndarray, alpha: float) -> np.ndarray:
    """
    Return the gradient of the smoothed max‑convolution objective.

    Parameters
    ----------
    a : np.ndarray
        Current non‑negative sequence (shape (n,)).
    alpha : float
        Smoothing parameter (α ≥ 0).  Larger values make the objective
        closer to the true maximum.

    Returns
    -------
    grad : np.ndarray
        Gradient vector of shape (n,).
    """
    n = a.shape[0]

    # a ∗ a
    conv = np.convolve(a, a)                 # length 2n‑1

    # Softmax weights (shifted by the max to avoid overflow)
    maxc = conv.max()
    # exponent is ≤ 0, so exp never overflows
    exp_term = np.exp(alpha * (conv - maxc))
    w = exp_term / exp_term.sum()            # length 2n‑1, sums to 1

    # Compute via convolution of w with reversed a
    rev_a = a[::-1]
    t = np.convolve(w, rev_a)                # length 3n‑2
    grad = 2.0 * t[n - 1 : n - 1 + n]        # slice length n
    return grad
