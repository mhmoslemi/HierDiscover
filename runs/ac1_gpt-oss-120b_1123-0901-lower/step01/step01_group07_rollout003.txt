Search for a low‑score step‑function using a parameterised power‑law (optionally
with a small exponential tail).  The search explores several sequence lengths,
exponents p, additive shifts γ and exponential decay λ.  First a coarse grid
is evaluated, then a simple CMA‑ES‑style random walk refines the parameters
under the remaining time budget.  The best sequence found is returned as a
plain Python list.
"""

import time
import numpy as np

def _make_sequence(n: int, p: float, gamma: float, lam: float = 0.0) -> np.ndarray:
    """Return a sequence a_i = (i+γ)^{-p} * exp(-λ i) for i = 0 … n‑1."""
    i = np.arange(n, dtype=float)
    seq = (i + gamma) ** (-p)
    if lam != 0.0:
        seq = seq * np.exp(-lam * i)
    return seq
