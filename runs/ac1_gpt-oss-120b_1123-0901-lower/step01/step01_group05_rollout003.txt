Propose a candidate step‑function sequence that improves the bound < 1.503.

Algorithm
---------
1. **Initial shape** – use the classic “inverse‑square‑root’’ sequence
   a_i = C(2i,i)/4ⁱ (≈ 1/√i).  Scale it so that ∑a_i = √(2 n) to keep all
   numbers in a comfortable range.

2. **Iterative LP refinement** – given the current sequence `a`,
   compute M = max(a * a).  Solve the linear program

        maximise   ∑ g_i
        subject to (a * g)[k] ≤ M   for all k
                    g_i ≥ 0

   constraint matrix is a Toeplitz matrix that can be built efficiently

                        shape=(2 * n - 1, n), format='csc')
        b_ub = np.full(2 * n - 1, M, dtype=np.float64)

        # --- Linear programme: maximise sum(g)  (i.e. minimise –sum)
        c = -np.ones(n, dtype=np.float64)      # minimise –∑g_i  → maximise ∑g_i
        try:
            res = opt.linprog(c, A_ub=A_ub, b_ub=b_ub,
                              bounds=(0, None), method='highs')
        except Exception as exc:
            print(f"[iter {iteration}] linprog error: {exc}")
            break

        if not res.success:
            print(f"[iter {iteration}] LP failed: {res.message}")
            break

        g = res.x
        sum_g = g.sum()
        if sum_g == 0.0:
            print(f"[iter {iteration}] LP returned zero sum, aborting.")
            break

        # --- Rescale g to the target l1‑norm and mix -----------------
        g_scaled = g * (target_sum / sum_g)
        a_new = (1.0 - t) * a + t * g_scaled

        # --- Evaluate the candidate ---------------------------------
        cand_seq = a_new.tolist()
        try:
            cand_score = evaluate_sequence(cand_seq)
        except Exception:
            cand_score = float('inf')

        if cand_score < best_score:
            best_score = cand_score
            best_seq = a_new.copy()
            print(f"[iter {iteration}] improved score = {best_score:.6f}")
        else:
            # even if not better, keep the new sequence as a fresh start
            # because it may yield a lower M for the next LP round.
            best_seq = a_new.copy()

        # --- Dynamically adapt the mixing parameter -----------------
        if cand_score < best_score * 0.995:
            t = min(0.5, t * 1.05)   # become more aggressive when improving
        else:
            t = max(0.05, t * 0.95)  # be more conservative otherwise

        # ------------------------------------------------------------------
        # 4. Light stochastic polishing (every few LP steps)
        # ------------------------------------------------------------------
        if iteration % 3 == 0:
            for _ in range(12):
                i = rng.integers(n)
                factor = math.exp(rng.normal(0.0, 0.04))   # log‑normal step
                pert = best_seq.copy()
                pert[i] = max(0.0, pert[i] * factor)
                try:
                    score_pert = evaluate_sequence(pert.tolist())
                except Exception:
                    continue
                if score_pert < best_score:
                    best_score = score_pert
                    best_seq = pert
                    print(f"[local] improved to {best_score:.6f} at idx {i}")

    # ------------------------------------------------------------------
    # 5. Return the best sequence found.
    # ------------------------------------------------------------------
    print(f"[final] best score {best_score:.6f} after {iteration} iterations")
    return best_seq.tolist()
```
