        scale = np.sum(f) / sum_g
        g = g * scale

The idea follows the iterative construction described in the statement.
Starting from a power‑law shape we repeatedly:

1. Solve a linear program

       s.t.  (f * g)_k ≤ M   for every k,
             g_j ≥ 0,

   combination of the unknown g_j.

2. Scale the LP solution to have the same ℓ₁‑norm as f,
   mix it with the current f using a small step size t,
   and recompute the new maximum M.

early entries (which dominate the peak of the autocorrelation) to later,
smaller entries.  After a few iterations the peak max b drops and the
evaluation score improves.  When the time budget allows we finish with a

            # perturb a few indices randomly
            idx = np.random.randint(0, n, size=3)
            delta = np.random.randn(3) * 0.03
            cand = best_seq.copy()
            cand[idx] += delta
            cand = np.clip(cand, 0.0, None)   # keep non‑negative
            sc = evaluate_sequence(cand.tolist())
            if sc < best_score:
                best_score = sc
                best_seq = cand
                print(f"[rand] improved score={sc:.6f}")

    result = best_seq.tolist()
    print(f"Finished – best score {best_score:.6f}  length={len(result)}")
    return result
