"""
propose_candidate
=================

A two‑phase optimizer for the step‑function minimisation problem.

Phase 1 – *LP alternation*  
    Start from the discrete arcsine distribution (the classical √‑optimal
    continuous construction).  Repeatedly solve a linear programme

        maximise   Σ b_j
        subject to (a * b)_k ≤ M   (k = 0 … 2n‑2) ,   b ≥ 0

    where ``a`` is the current sequence and ``M = max(a * a)``.
    The solution `b` contains as much total mass as possible while keeping
    the convolution bound unchanged.  After scaling `b` to the original
    total mass we mix it back into `a` (``a ← (1‑t)·a + t·b``).  Each
    iteration can only reduce the bound `M`, consequently the evaluation
    score ``2·n·M/(Σa)^2`` never gets larger.

Phase 2 – *stochastic hill climbing*  
    With the sequence already close to a local optimum we perform many tiny
    mass‑transfer moves (move a small fraction from a larger entry to a
    smaller one) and keep any improvement.  This polishing step is cheap
    and often yields a few extra points.

Both phases respect the hard limits enforced by ``evaluate_sequence``:
all entries stay non‑negative and below 1000, and the sum never approaches
zero (the optimiser maintains a unit sum, which makes the objective
scale‑invariant).  The algorithm stops when the allotted time (``budget_s``)
is exhausted and returns the best sequence seen.

The implementation falls back to the pure hill‑climbing used in the
previous baseline if SciPy is unavailable.
"""

import numpy as np

# Optional SciPy import – required only for the LP phase.
# ----------------------------------------------------------------------

    from scipy.linalg import toeplitz
    _SCIPY_AVAILABLE = True

    _SCIPY_AVAILABLE = False


def _build_conv_matrix(a: np.ndarray) -> np.ndarray:
    """
    Build the (2n‑1) × n matrix C such that C @ b = a * b (full convolution).
    The matrix is Toeplitz with first column [a0,…,a_{n‑1},0,…,0]ᵀ and first
    row [a0,0,…,0].
    """
    n = a.shape[0]
    first_col = np.concatenate([a, np.zeros(n - 1, dtype=a.dtype)])
    first_row = np.concatenate([np.array([a[0]], dtype=a.dtype),
                                np.zeros(n - 1, dtype=a.dtype)])
    C = toeplitz(first_col, first_row)[: 2 * n - 1, :]
    return C

            src, dst = j, i

        # delta is a small fraction of the *smaller* value – guarantees non‑negativity
        delta = 0.01 * min(a[src], a[dst])
        if delta <= 0.0:
            it += 1
            continue

        a_new = a.copy()
        a_new[src] -= delta
        a_new[dst] += delta

        new_score = eval_score(a_new)
        if new_score < best_score:
            a = a_new
            best_seq = a_new.copy()
            best_score = new_score
            print(f"[HC] it {it:05d} improved score to {best_score:.6f}")
        it += 1

    print(f"[final] best score={best_score:.6f}, total HC iterations={it}")

    # ------------------------------------------------------------------
    # 6.  Return the best sequence (clipped to the evaluator's limits).
    # ------------------------------------------------------------------
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    return best_seq.tolist()
