assistantfinal**Solution Overview**

The evaluation metric  

```
score = 2·n·max(conv(a,a)) / (sum(a)²)
```

is scale‑invariant, i.e. multiplying the whole vector by a constant does **not**
change the score.  Consequently we only have to optimise the *shape* of the
non‑negative vector `a`.

For a monotone “inverse‑square‑root’’ sequence the convolution is almost flat
and the score is `π/2 ≈ 1.5709`.  To beat the target `1.503` we must lower the
maximum of the self‑convolution while keeping the total mass `sum(a)` unchanged.
The largest contribution to the maximal convolution entry comes from pairs
`(i , k‑i)` with large product `a[i]·a[k‑i]`.  Reducing one of the two
components and moving that mass to a position that contributes **little**
to the maximal entry reduces the score.

The algorithm therefore performs a **simulated‑annealing / hill‑climbing**
search that repeatedly

1. finds the index `k*` of the current maximal convolution,
2. computes the contribution `c[i] = a[i]·a[k*‑i]` (zero where the partner
   index is out of range),
3. selects a *high‑contribution* position `i_hi` and a *low‑contribution*
   position `i_lo`,
4. transfers a small fraction of the mass from `i_hi` to `i_lo`,
5. accepts the move if it improves the score (or probabilistically accepts
   a worsening move while the temperature is still high).

The temperature (and the transferred fraction) are gradually decreased,
allowing large exploratory steps early on and fine adjustments later.
After the main annealing phase a cheap random‑perturbation phase (identical
to the baseline code) is run for any remaining time.

All operations are vectorised with NumPy; a full convolution is recomputed
only when a candidate vector is built, which is fast enough for the allowed
budget (≈ 1000 s).  The routine works for any length `n`; we reuse the length
of the previously discovered best sequence when possible, otherwise a
default of `3000` elements is used.

"""
simulated‑annealing optimisation of a step‑function height vector.

- start from the classic inverse‑square‑root shape (a_i = C_i/4**i)
- repeatedly move a small amount of mass from an index that contributes a lot
  to the current maximal convolution entry to an index that contributes little
- accept moves that improve the score, otherwise accept with a temperature‑
  dependent probability (simulated annealing)
- finish with a cheap random multiplicative refinement (as in the reference)
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------
def generate_inverse_sqrt_sequence(n: int) -> np.ndarray:
    """Return a NumPy array a_0,…,a_{n‑1} with a_i = C_i/4**i.
    The recurrence a_{i+1}=a_i·(2·i+1)/(2·i+2) is used to avoid overflow."""
    a = np.empty(n, dtype=float)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    return a


def score_of(seq: np.ndarray) -> float:
    """Return the value of the evaluation function for `seq`."""
    n = seq.size
    conv = np.convolve(seq, seq)
    return float(2.0 * n * conv.max() / (seq.sum() ** 2))


def contributions_at(seq: np.ndarray, k: int) -> tuple[np.ndarray, np.ndarray]:
    """For a given k, return the index array and the corresponding contributions
    a[i]·a[k‑i] (zero where the partner index is out of range)."""
    n = seq.size
    i_start = max(0, k - (n - 1))
    i_end = min(n, k + 1)          # exclusive
    idx = np.arange(i_start, i_end, dtype=int)
    partner = k - idx
    contrib = seq[idx] * seq[partner]
    return idx, contrib

# Main entry point required by the runner
# ----------------------------------------------------------------------

    Return a list of non‑negative floats that (hopefully) beats the
    reference bound 2.0 and improves on the inverse‑square‑root construction.
    The optimisation proceeds in two stages:
      1. simulated‑annealing / pairwise mass transfer,
      2. cheap random multiplicative local search (fallback).
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 1. Choose the length of the sequence.
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 3000

    # ------------------------------------------------------------------
    # 2. Initialise the vector.
    #    Use the inverse‑sqrt shape (scale is irrelevant – we normalise to sum=1).
    # ------------------------------------------------------------------
    base = generate_inverse_sqrt_sequence(n)
    a = base / base.sum()   # normalise to total mass 1 (score unchanged)

    # initialise best‑found solution
    cur_seq = a.copy()
    cur_score = score_of(cur_seq)
    best_seq = cur_seq.copy()
    best_score = cur_score

    print(f"[init] length={n}, initial score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Simulated‑annealing loop (pairwise mass transfer)
    # ------------------------------------------------------------------
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # tiny safety margin
    # temperature schedule – starts at 0.02 and linearly goes to 0
    T0 = 0.02

    # counters for adapting step size
    no_improve = 0
    move_frac = 0.08   # fraction of the source entry that is moved

    while time.time() < deadline:
        # recompute convolution for the current sequence
        conv = np.convolve(cur_seq, cur_seq)
        k_max = int(conv.argmax())
        # contributions for the maximal index
        idx, contrib = contributions_at(cur_seq, k_max)

        # pick source (high contribution) and target (low contribution)
        i_hi = idx[int(np.argmax(contrib))]
        i_lo = idx[int(np.argmin(contrib))]

        if i_hi == i_lo:      # degenerate – pick random distinct pair
            i_hi = rng.integers(n)
            i_lo = rng.integers(n)
            while i_lo == i_hi:
                i_lo = rng.integers(n)

        # amount of mass to move – never larger than the source entry
        delta = cur_seq[i_hi] * move_frac
        if delta <= 0.0:
            break

        # build the candidate
        cand = cur_seq.copy()
        cand[i_hi] -= delta
        cand[i_lo] += delta

        cand_score = score_of(cand)

        # temperature based on elapsed fraction
        elapsed = (time.time() - start_time) / (budget_s - 0.5)
        T = max(0.0, T0 * (1.0 - elapsed))

        # acceptance rule
        accept = False
        if cand_score < cur_score:
            accept = True
        else:
            # occasional uphill moves while the temperature is still high
            if T > 0.0 and rng.random() < np.exp(-(cand_score - cur_score) / T):
                accept = True

        if accept:

            cur_score = cand_score
            no_improve = 0
            # keep the best ever seen
            if cand_score < best_score:
                best_score = cand_score
                best_seq = cand.copy()
                print(f"[improve] new best score={best_score:.6f}")
        else:
            no_improve += 1

        # if we have been stagnant for a while, shrink the move fraction
        if no_improve >= 200:
            move_frac = max(0.001, move_frac * 0.5)
            no_improve = 0

    # ------------------------------------------------------------------
    # 4. Final cheap random local search (like the reference implementation)
    # ------------------------------------------------------------------
    # restore the best sequence found so far for the local search phase
    cur_seq = best_seq.copy()
    cur_score = best_score

        old = cur_seq[i]
        factor = np.exp(rng.normal(0.0, 0.02))
        new_val = max(0.0, old * factor)

        cand[i] = new_val
        cand_score = score_of(cand)

            if cand_score < best_score:

                best_seq = cand.copy()

    # ------------------------------------------------------------------
    print(f"[final] best score={best_score:.6f}")
    return best_seq.tolist()
