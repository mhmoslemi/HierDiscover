assistantfinal**Solution Overview**

The goal is to return a non‑negative vector `a` (a step‑function) that minimises  

\[
F(a)=\frac{2\,n\;\max (a\star a)}{(\sum a)^2},
\]

where `a⋆a` is the linear convolution of `a` with itself.  
The problem is scale‑invariant, therefore we keep the vector on the simplex
(`sum(a)=1`).  

The code below implements a *two‑stage* optimisation:

1. **Smooth‑max Adam optimisation** – a continuation method that replaces the
   non‑smooth `max` by a log‑sum‑exp (smooth‑max) with a temperature `λ`.
   Adam with a KL‑mirror map (soft‑max parametrisation) drives the distribution
   towards a low‑max convolution.  
   *Improvements over the reference implementation*  
   * a tighter temperature cap (`λ≤30`) to avoid numerical overflow,  
   * an adaptive learning‑rate schedule,  
   * more sub‑gradient iterations (default 20 000) and a decreasing step‑size,
   * the ability to work on a larger grid (`n=8192` or `16384`) when time permits.

2. **Greedy mass‑transfer refinement** – after the Adam stage we are already
   close to a local minimum.  We then repeatedly move a tiny amount of mass
   from the index that most harms the maximal convolution (largest sub‑gradient)
   to the index that helps the most (smallest sub‑gradient).  The move is
   performed on the simplex and the convolution is recomputed via FFT.
   If no improvement is seen for a while a small random perturbation is added
   to escape possible plateaus.

Both stages respect the global time budget (`budget_s`, default 1000 s) and keep
track of the best sequence ever seen.  If a previous solution exists in the
global variable `height_sequence_1` it is used as a warm‑start (interpolated to
the current grid size).

The function `propose_candidate` returns the best sequence found (as a plain
Python list) and prints the final evaluated bound.

```python
"""
propose_candidate
-----------------

Search for a non‑negative step‑function that minimises

        F(a) = 2·n·max(a∗a) / (sum(a)²)

The algorithm consists of two phases:

1.  A smooth‑max Adam optimiser on the simplex (log‑sum‑exp surrogate of the
    max).  Temperature λ starts at 0.5 and is increased geometrically, but is
    capped at 30 to avoid overflow.  Adam uses the KL‑mirror map (soft‑max
    parametrisation) and stops when the global deadline is reached.

2.  A greedy mass‑transfer refinement.  At each iteration the sub‑gradient of
    the exact max (active‑set weights) is computed; mass is moved from the
    index with the highest gradient (most responsible for the peak) to the
    index with the lowest gradient.  The step size decays over time and a
    random shake is added when progress stalls.

Both stages are applied to a (possibly up‑sampled) warm‑start derived from the
global variable ``height_sequence_1``; otherwise a random Dirichlet start is
used.  The routine respects the given time budget (default 1000 s) and returns
the best sequence found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a (length 2·len(a)-1) using FFT."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    return conv[: 2 * a.shape[0] - 1]


def _cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for gradients.
    Returns a vector of length len(a) equal to
        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]   for i=0…n‑1.
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr_full = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr_full[start:start + n]


# ----------------------------------------------------------------------
def _adam_smooth_max(
    a0: np.ndarray,
    n: int,
    conv_fft_len: int,
    corr_fft_len: int,
    deadline: float,
    global_best_seq: np.ndarray | None,
    global_best_val: float,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser on a log‑sum‑exp surrogate of max(conv).
    Returns the best sequence/value encountered (global across all calls).
    """
    eps = 1e-15
    logits = np.log(a0 + eps)          # soft‑max parametrisation
    m = np.zeros_like(logits)
    v = np.zeros_like(logits)

    beta1, beta2, eps_adam = 0.9, 0.999, 1e-8
    lr = 0.05

    lam = 0.5          # temperature for smooth‑max
    lam_factor = 1.02
    lam_cap = 30.0     # avoid overflow in exp

    last_improve = time.time()
    it = 0

    while time.time() < deadline:
        # ----- soft‑max → simplex -----
        mx = logits.max()
        exp_log = np.exp(logits - mx)
        a = exp_log / exp_log.sum()

        # ----- exact objective (just for bookkeeping) -----
        conv = _full_convolution(a, conv_fft_len)
        max_c = conv.max()
        val = 2.0 * n * max_c / (a.sum() ** 2)
        if val < global_best_val:
            global_best_val = val
            global_best_seq = a.copy()
            last_improve = time.time()
            print(f"[Adam n={n} iter={it:06d}] new best {val:.6f}")

        # ----- smooth‑max weights (log‑sum‑exp) -----
        w = np.exp(lam * (conv - max_c))
        w_sum = w.sum()
        if w_sum == 0 or np.isnan(w_sum):
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # ----- gradient of surrogate (chain rule through soft‑max) -----
        grad_a = 2.0 * _cross_correlation(w, a, corr_fft_len)
        avg = np.dot(a, grad_a)
        grad_log = a * (grad_a - avg)

        # ----- Adam update on logits -----
        m = beta1 * m + (1.0 - beta1) * grad_log
        v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)
        m_hat = m / (1.0 - beta1 ** (it + 1))
        v_hat = v / (1.0 - beta2 ** (it + 1))
        logits -= lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        # ----- temperature schedule -----
        lam = min(lam * lam_factor, lam_cap)

        # ----- occasional shaking to escape stagnation -----
        if time.time() - last_improve > 4.0:
            logits += (np.random.rand(n) - 0.5) * 1e-2
            last_improve = time.time()

        it += 1
        # safety break
        if it >= 250_000:          # extremely generous upper bound
            break

    return global_best_seq, global_best_val

def _subgradient_refine(
    a0: np.ndarray,
    n: int,
    conv_fft_len: int,
    corr_fft_len: int,
    deadline: float,
    global_best_seq: np.ndarray | None,
    global_best_val: float,
    max_iter: int = 20000,
) -> tuple[np.ndarray, float]:
    """
    Exponentiated‑gradient sub‑gradient phase on the *exact* max.
    The step size η decays slowly; a random shake is added if
    progress stalls for >5 s.
    """
    a = np.maximum(a0, 0.0)
    a /= a.sum()

    eta = 0.6
    last_improve = time.time()

    for it in range(max_iter):
        if time.time() >= deadline:
            break

        conv = _full_convolution(a, conv_fft_len)
        max_c = conv.max()
        val = 2.0 * n * max_c / (a.sum() ** 2)

        if val < global_best_val:
            global_best_val = val
            global_best_seq = a.copy()
            last_improve = time.time()
            print(f"[Subgrad n={n} iter={it:05d}] new best {val:.6f}")

        # ---- active‑set weights (uniform on the ties) ----
        active = np.isclose(conv, max_c, atol=1e-12, rtol=0.0)
        if active.any():
            w = np.zeros_like(conv)
            w[active] = 1.0 / active.sum()
        else:
            w = np.zeros_like(conv)

        grad_a = 2.0 * _cross_correlation(w, a, corr_fft_len)

        # ---- exponentiated‑gradient update (keeps a≥0) ----
        a = a * np.exp(-eta * grad_a)

        s = a.sum()
        if s < 1e-12:                     # guard against collapse
            a = np.random.dirichlet(np.ones(n))
            s = a.sum()
        a /= s

        # ---- step‑size decay & stagnation handling ----
        if it % 500 == 0 and it > 0:
            eta *= 0.95          # slowly shrink step size

        if time.time() - last_improve > 5.0:
            # random shake to leave a possible flat region
            a = a + (np.random.rand(n) - 0.5) * 1e-3
            a = np.clip(a, 0.0, None)
            a /= a.sum()
            last_improve = time.time()

    return global_best_seq, global_best_val


# ----------------------------------------------------------------------
def _mass_transfer_refine(
    a0: np.ndarray,
    n: int,
    conv_fft_len: int,
    corr_fft_len: int,
    deadline: float,
    global_best_seq: np.ndarray | None,
    global_best_val: float,
) -> tuple[np.ndarray, float]:
    """
    Simple greedy refinement: at each step move a small amount of probability
    from the index that contributes most to the maximal convolution (largest
    sub‑gradient) to the index that contributes the least.  The convolution is
    recomputed each iteration with FFT.  The step size decays and random
    perturbations are added when progress stalls.
    """
    a = a0.copy()
    best_seq = global_best_seq
    best_val = global_best_val

    last_improve = time.time()
    it = 0
    epsilon_factor = 0.04   # initial fraction of the source mass to move

    while time.time() < deadline:
        conv = _full_convolution(a, conv_fft_len)
        max_c = conv.max()
        val = 2.0 * n * max_c   # denominator is 1 (sum(a)=1)

        if val < best_val:
            best_val = val
            best_seq = a.copy()
            last_improve = time.time()
            print(f"[Mass‑transfer iter={it:06d}] new best {val/(a.sum()**2):.6f}")

        # active set for the exact max
        active = np.isclose(conv, max_c, atol=1e-12, rtol=0.0)
        if not active.any():
            break
        w = np.where(active, 1.0 / active.sum(), 0.0)

        grad = 2.0 * _cross_correlation(w, a, corr_fft_len)

        i_high = int(np.argmax(grad))
        i_low = int(np.argmin(grad))

        if a[i_high] < 1e-12:
            # nothing to move – pick a random source
            candidates = np.where(a > 1e-12)[0]
            if candidates.size == 0:
                break
            i_high = int(np.random.choice(candidates))

        # step size – a decreasing schedule
        eps_move = min(epsilon_factor * a[i_high], 0.002)
        eps_move = max(eps_move, 1e-7)          # avoid stagnation at zero

        a[i_high] -= eps_move
        a[i_low] += eps_move

        # maintain the simplex (numerical drift)
        a = np.clip(a, 0.0, None)
        a_sum = a.sum()
        if a_sum == 0:
            a = np.random.dirichlet(np.ones(n))
        else:
            a /= a_sum

        it += 1

        # decay epsilon_factor very slowly
        if it % 2000 == 0:
            epsilon_factor = max(0.001, epsilon_factor * 0.9)

        # shake if no progress for a while
        if time.time() - last_improve > 6.0:
            a = a + (np.random.rand(n) - 0.5) * 1e-3
            a = np.clip(a, 0.0, None)
            a /= a.sum()
            last_improve = time.time()

    # convert back to the true objective (divide by sum²)
    if best_seq is not None:
        best_val = 2.0 * n * np.max(_full_convolution(best_seq, conv_fft_len)) / (best_seq.sum() ** 2)

    return best_seq, best_val

def propose_candidate(seed: int = 0, budget_s: float = 1000) -> list:
    """
    Search for a non‑negative step‑function with a low evaluation score.
    The function respects the given time budget and returns the best sequence.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # small safety margin

    # --------------------------------------------------------------
    # Choose a grid size: use a larger grid if the budget is generous.
    total_budget = budget_s
    if total_budget >= 800:
        n = 16384
    elif total_budget >= 500:
        n = 8192
    else:
        n = 4096

    conv_fft_len = _next_pow2(2 * n - 1)
    corr_fft_len = _next_pow2(3 * n - 2)

    # --------------------------------------------------------------
    # Build a warm start from the global variable if available.
    warm = globals().get("height_sequence_1")
    warm_arr = None
    if isinstance(warm, (list, tuple, np.ndarray)):
        warm_arr = np.asarray(warm, dtype=np.float64)
        if warm_arr.ndim == 1 and warm_arr.size > 0:
            # Linear interpolation to the target length
            if warm_arr.size != n:
                x_old = np.linspace(0.0, 1.0, warm_arr.size, endpoint=False)
                x_new = np.linspace(0.0, 1.0, n, endpoint=False)
                warm_arr = np.interp(x_new, x_old, warm_arr)
            warm_arr = np.maximum(warm_arr, 0.0)
            if warm_arr.sum() >= 0.01:
                warm_arr = warm_arr / warm_arr.sum()
            else:
                warm_arr = None

    # --------------------------------------------------------------
    # Assemble a modest pool of diverse initial vectors.
    candidates = []

    if warm_arr is not None:
        candidates.append(warm_arr.copy())
        for shift in (n // 4, n // 2, 3 * n // 4):
            candidates.append(np.roll(warm_arr, shift))

    # pure random Dirichlet
    candidates.append(np.random.dirichlet(np.ones(n)))

    # power‑law edge‑concentrated shapes
    idx = np.arange(n, dtype=np.float64) + 1.0
    prod = idx * (n - idx + 1.0)
    for alpha in np.linspace(-2.0, -0.5, 4):
        shape = np.where(prod > 0, prod ** alpha, 0.0)
        if shape.sum() > 0:
            shape /= shape.sum()
            candidates.append(shape)

    # two‑Gaussian edge shapes
    i = np.arange(n, dtype=np.float64)
    for gamma in (0.2, 0.5, 1.0, 2.0):
        shape = np.exp(-gamma * (i ** 2)) + np.exp(-gamma * ((n - 1 - i) ** 2))
        shape /= shape.sum()
        candidates.append(shape)

    # sinusoidal half‑wave
    shape = np.sin(np.pi * (np.arange(n) + 0.5) / n)
    shape = np.maximum(shape, 0.0)
    shape /= shape.sum()
    candidates.append(shape)

    # uniform baseline
    candidates.append(np.full(n, 1.0 / n))

    best_seq: np.ndarray | None = None
    best_val = float("inf")

    # --------------------------------------------------------------
    # Optimise each candidate – the heavy lifting.
    for cid, cand in enumerate(candidates):
        if time.time() >= deadline:
            break

        a0 = np.maximum(cand, 0.0)
        s = a0.sum()
        if s < 0.01:
            a0 = np.random.dirichlet(np.ones(n))
        else:
            a0 = a0 / s

        # Phase 1 – Adam on smooth‑max
        best_seq, best_val = _adam_smooth_max(
            a0, n, conv_fft_len, corr_fft_len, deadline, best_seq, best_val
        )
        # Phase 2 – exact sub‑gradient (exponentiated‑gradient)
        best_seq, best_val = _subgradient_refine(
            best_seq, n, conv_fft_len, corr_fft_len, deadline, best_seq, best_val
        )

    # --------------------------------------------------------------
    # Final greedy mass‑transfer refinement (if time permits)
    if time.time() + 5.0 < deadline and best_seq is not None:
        best_seq, best_val = _mass_transfer_refine(
            best_seq, n, conv_fft_len, corr_fft_len, deadline, best_seq, best_val
        )

    # --------------------------------------------------------------
    # Fallback – should never happen but keep a safe default.
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)

    # Clip to the evaluator’s allowed range (non‑negative, ≤ 1000)
    best_seq = np.clip(best_seq, 0.0, 1000.0)

    # Final reporting (optional – harmless if evaluate_sequence is not present)
    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"Final evaluated bound: {final_score:.6f}")
    except Exception as e:
        print("Could not evaluate final sequence:", e)

    return best_seq.tolist()
```
