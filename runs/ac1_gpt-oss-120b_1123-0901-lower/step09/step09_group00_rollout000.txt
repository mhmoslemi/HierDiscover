The algorithm proceeds in three stages:

1. **Broad parametric sweep** – generate a diverse pool of candidates

   piecewise‑constant blocks and equally‑spaced spikes).  All candidates are
   normalized to sum = 1 and the best one is kept.

2. **Fine‑grained exponentiated‑gradient refinement** – starting from the
   best candidate, repeatedly compute the exact sub‑gradient of the max‑convex
   function (active‑set of maximal convolution entries) and perform an
   exponentiated‑gradient step with a simple back‑tracking line‑search.  The
   step size follows a 1/√t schedule; the current best ever‑seen vector is
   stored.

3. **Short simulated‑annealing polish** – a stochastic local search that moves
   a random fraction of mass between two coordinates, accepting downhill moves

All phases respect the global time budget (≈ 1000 s).  The returned sequence
is non‑negative, normalized (sum = 1) and clipped to the evaluator’s limits.

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a * a (length 2·len(a)‑1) using FFT."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    return conv[: 2 * a.shape[0] - 1]


def _cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear cross‑correlation (w ★ a) needed for sub‑gradient."""
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = a.shape[0] - 1
    return corr[start: start + a.shape[0]]
