## In depth algorithm analysis

### Problem restated

We need to minimize evaluate_sequence(seq) where seq nonnegative, length n variable.

Given evaluate_sequence returns (2*n*max(conv(seq, seq))) / (sum(seq)^2). Under scaling equivalence, we can fix sum of seq to sqrt(2*n) to make evaluate = max(conv). Indeed, with sum = sqrt(2n), we have evaluate = max(conv). So we keep sum fixed.

Thus the objective is minimize L∞ norm of autocorrelation (convolution with itself). It is convex.

Goal: find sequence achieving low max autocorrelation. Standard approach: subgradient descent on max. We propose using smoothed objective (log-sum-exp) and mirror descent.

### Mirror descent with exponential updates

Given f(a) = max_i (c_i(a)), where c_i(a) = (a*a)[i] = Σ_j a_j a_{i-j}. This is convex, but non-smooth at ties. Replace with f_α(a) = (1/α) log Σ_i exp(α c_i(a)), which approximates max as α → ∞. Its gradient w.r.t a is 2 * (a * w) (convolution of a with weighting vector w, where w_i = exp(α c_i) / Σ_j exp(α c_j)).

We can perform mirror descent on simplex using KL divergence:

a_{new} = a ∘ exp(-η ∇ f_α(a))  (∘ denotes elementwise product), then project onto simplex (i.e., renormalize to sum target). This ensures a stays nonnegative and sum constraint.

By gradually increasing α, we refine approximation of max.

We also add occasional random perturbations to escape local minima.

### Complexity and hyperparameters

- FFT convolution for c = a*a: O(n log n). For gradient we need convolution a with w_rev also O(n log n). Manageable for n up to 3000, many iterations.

- Hyperparameters: initial α=0.2, increase by factor 1.02 each iteration up to α_max=8. Gradient step size η set adaptively: η = lr / (max(grad) + eps). Choose lr≈0.5, decaying slowly maybe η scale.

These choices are heuristic and can be tuned on the fly.

### Multi‑restart outer loop

Given limited time, we run many independent restarts with random lengths n in [1200, 3000]. Each run gets a time slice (~10‑12 sec). The best overall sequence is stored globally.

We also warm‑start runs with the best known sequence (truncated/padded) with probability 0.5 to spread promising patterns.

### Termination

The loop stops when time budget is exhausted; the current best sequence is returned as a plain list.

"""
Mirror‑descent with log‑sum‑exp smoothing for the autocorrelation L∞ problem.

The evaluation function is scale‑invariant, so we fix Σ a_i = √(2 n).  With
this normalization the objective equals max_k (a*a)[k].  To minimise the
maximum we replace it by the smooth surrogate

    f_α(a) = (1/α)·log ∑_k exp(α·c_k(a)),   c_k(a) = (a*a)[k] ,

and perform exponentiated (KL‑mirror) updates on the simplex:

    a ← a ∘ exp(−η·∇f_α(a)),   a ← Π_{simplex}(a).

The gradient of f_α is
    ∇f_α(a) = 2·a * w with w_k ∝ exp(α·c_k(a)),
where “*” is the full convolution and w is a probability vector.
α is increased gradually (continuation) so the algorithm first follows a
smooth landscape and later concentrates on the true max.  Multiple random
restarts with varying lengths (1200‒3000) are performed within the given
time budget; the best sequence found is returned.
"""

import time
import numpy as np

# --------------------------------------------------------------------------- #
# Helper: projection onto the simplex {x_i ≥ 0, Σ x_i = s}.
# --------------------------------------------------------------------------- #
def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Euclidean projection of v onto the simplex of radius s (s ≥ 0)."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# --------------------------------------------------------------------------- #
# Full convolution via FFT (real inputs, result is real).
# --------------------------------------------------------------------------- #
def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Return the full convolution of real vectors x and y using FFT."""
    n = x.shape[0] + y.shape[0] - 1
    n_fft = 1 << ((n - 1).bit_length())  # next power of two
    X = np.fft.rfft(x, n=n_fft)
    Y = np.fft.rfft(y, n=n_fft)
    conv = np.fft.irfft(X * Y, n=n_fft)[:n]
    return conv


# --------------------------------------------------------------------------- #
# Core optimisation of a single instance (fixed length n).
# --------------------------------------------------------------------------- #
def _optimise_instance(
    n: int,
    init_vec: np.ndarray,
    deadline: float,
    best_global_seq: np.ndarray | None,
    best_global_score: float,
) -> tuple[np.ndarray, float]:
    """
    Run a mirror‑descent optimisation on a sequence of length n.
    Returns the best local sequence and its score.
    """
    target_sum = np.sqrt(2.0 * n)

    # initialise on the simplex
    a = _project_onto_simplex(init_vec.astype(float), target_sum)

    # hyper‑parameters (can be tuned)
    alpha = 0.2                # smoothing parameter
    alpha_max = 8.0
    alpha_factor = 1.018       # increase per iteration
    base_lr = 0.5              # base learning‑rate for mirror step
    max_iters = 5000           # safety cap

    best_local_seq = a.copy()
    # current objective = max convolution entry (since Σa = √(2n))
    conv = _conv_fft(a, a)
    best_local_score = float(conv.max())

    it = 0
    while time.time() < deadline and it < max_iters:
        # ----- current convolution and score -----
        conv = _conv_fft(a, a)               # length 2n‑1
        cur_max = conv.max()
        cur_score = float(cur_max)           # equals evaluate_sequence() here

        # keep global best
        if cur_score < best_global_score:
            best_global_score = cur_score
            best_global_seq = a.copy()
            print(f"[{time.time():.2f}] NEW GLOBAL BEST = {best_global_score:.6f} (n={n})")

        # keep local best (useful for early exit)
        if cur_score < best_local_score:
            best_local_score = cur_score
            best_local_seq = a.copy()

        # ----- smoothed weights (log‑sum‑exp) -----
        # shift by max to avoid overflow
        shifted = conv - cur_max
        exp_vals = np.exp(alpha * shifted)
        w = exp_vals / np.sum(exp_vals)           # length 2n‑1, sums to 1

        # ----- gradient of the smoothed objective -----
        # ∇f = 2 * a * w   (full convolution)
        w_rev = w[::-1]                           # reverse for the correct orientation
        grad_full = _conv_fft(a, w_rev)           # length 3n‑2
        idx = 2 * n - 2 - np.arange(n)            # pick the needed n entries
        grad = 2.0 * grad_full[idx]               # shape (n,)

        # ----- mirror‑descent (exponentiated) step -----
        gmax = grad.max()
        if gmax <= 0:
            break                                   # nothing to improve
        eta = base_lr / (gmax + 1e-12)               # scale step size
        a = a * np.exp(-eta * grad)                 # element‑wise
        a = _project_onto_simplex(a, target_sum)    # re‑project onto simplex

        # ----- occasional random perturbation (simulated annealing) -----
        if np.random.rand() < 0.012:
            noise = np.random.randn(n) * (target_sum * 0.001)
            a = _project_onto_simplex(np.maximum(a + noise, 0.0), target_sum)
            # optionally shrink learning rate after a shake
            base_lr *= 0.95

        # ----- continuation on the smoothing parameter -----
        alpha = min(alpha_max, alpha * alpha_factor)

        # ----- tiny decay of the base learning rate (helps fine‑tuning) -----
        base_lr *= 0.99994

        it += 1

    return best_local_seq, best_local_score

                pad = np.random.rand(n - src.size) * 1e-3
                init = np.concatenate([src, pad])
        else:
            init = np.random.rand(n)

        # Allocate a slice of the remaining budget for this run.
        run_deadline = min(deadline, time.time() + 12.0)   # ≈12 s per restart
        best_seq, _ = _optimise_instance(
            n=n,
            init_vec=init,
            deadline=run_deadline,
            best_global_seq=best_seq,
            best_global_score=best_score,
        )
        # Re‑evaluate after the run (the optimiser already updates the global best).
        # To keep the global best up‑to‑date, compute the official score.
        if best_seq is not None:
            # guarantee the sum constraint (tiny numerical drift may appear)
            target_sum = np.sqrt(2.0 * len(best_seq))
            best_seq = _project_onto_simplex(np.array(best_seq, dtype=float), target_sum)
            # final official evaluation (might be a tiny bit different due to rounding)
            try:
                official_score = evaluate_sequence(best_seq.tolist())
            except Exception:
                official_score = float("inf")
            if official_score < best_score:
                best_score = official_score
                print(f"[{time.time():.2f}] GLOBAL BEST UPDATED TO {best_score:.6f} (n={len(best_seq)})")

        # early exit if we already beat the target bound
        if best_score < 1.503:
            break

    # ------------------------------------------------------------------- #
    # Fallback – in the extremely unlikely case no sequence was found.
    # ------------------------------------------------------------------- #
    if best_seq is None:
        n = 1500
        target_sum = np.sqrt(2.0 * n)
        best_seq = np.full(n, target_sum / n, dtype=float)

    # Return a plain Python list as required by the grader.
    return best_seq.tolist()
