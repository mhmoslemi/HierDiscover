assistantfinal**Solution Overview**

The score to minimise is  

```
score(a) = 2·n·max(conv(a,a)) / (sum(a))²
```

`conv` is the *full* convolution (`np.convolve`).  
Because the score is homogeneous (`a → c·a` leaves it unchanged) we can
*fix* the ℓ₁‑norm of the vector to  

```
S = √(2·n)
```

and simply minimise  

```
F(a) = max(conv(a,a))        with   a ≥ 0 ,   Σa = S                (1)
```

The optimisation problem is non‑convex and the objective is non‑smooth
(the maximum).  
We use a **smoothed approximation** of the maximum

```
Mε(a) = ε·log Σk exp(conv_k(a)/ε)        (soft‑max)                (2)
```

`Mε → max(conv)` when `ε → 0`.  
`Mε` is differentiable; the gradient w.r.t. a can be written as a
convolution, which we evaluate with an FFT – `O(n log n)` per iteration.

The algorithm consists of three phases

* **Phase 1 – cheap parametric families** – exponential, linear,
  quadratic and triangular shapes, all projected onto the simplex.
* **Phase 2 – smoothed gradient descent** – Adam‑style updates on the
  smooth objective (2) with a decreasing temperature `ε`.  Every few
  iterations the true objective (1) is evaluated and the global best
  sequence is stored.
* **Phase 3 – optional LP refinement** – a single linear programme,
  exactly as in the reference implementation, is executed if SciPy is
  available and time permits.

All heavy work (convolutions, FFT) is performed with NumPy; the whole
search runs for at most the supplied time budget (default 1000 s) and
returns the best sequence discovered.

```python
"""Step‑function optimiser.

The routine searches for a non‑negative sequence a with Σa = √(2 n) that
minimises max(conv(a,a)).  It combines cheap parametric sweeps,
smoothed soft‑max gradient descent (Adam + simplex projection) and an
optional LP refinement.  The whole search respects the given time
budget and returns the best sequence found.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Simplex projection (Euclidean)
# ----------------------------------------------------------------------
def project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project v onto the simplex {x≥0, Σx = s}."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Full convolution by real FFT (fast for moderate n)
# ----------------------------------------------------------------------
def conv_full_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution x*y using real FFT (output size = len(x)+len(y)-1)."""
    n = len(x) + len(y) - 1
    size = 1 << ((n).bit_length())          # next power of two
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)
    return conv[:n]


def conv_self(a: np.ndarray) -> np.ndarray:
    """Full convolution a*a (real FFT)."""
    return conv_full_fft(a, a)


# ----------------------------------------------------------------------
# Helper to call the external evaluator safely
# ----------------------------------------------------------------------
def safe_evaluate(seq):
    """Return the external score or +inf on error."""
    try:
        return evaluate_sequence(seq)
    except Exception:
        return float("inf")


# ----------------------------------------------------------------------
# Parametric families (non‑normalised)
# ----------------------------------------------------------------------
def shape_exp(n, alpha):
    return np.exp(-alpha * np.arange(n, dtype=float))


def shape_exp_rev(n, alpha):
    return np.exp(-alpha * np.arange(n - 1, -1, -1, dtype=float))


def shape_linear_desc(n, beta):
    i = np.arange(n, dtype=float)
    return np.maximum(0.0, 1.0 - beta * i)


def shape_quad_desc(n, beta):
    i = np.arange(n, dtype=float)
    return np.maximum(0.0, 1.0 - beta * i * i)


def shape_triangular(n):
    i = np.arange(n, dtype=float)
    return np.minimum(i + 1.0, n - i)


# ----------------------------------------------------------------------
# Update the global best (top‑level, no closure)
# ----------------------------------------------------------------------
def maybe_update(best_score_dict, best_seq_dict, cand):
    """Replace the global best if cand improves."""
    score = safe_evaluate(cand.tolist())
    if score < best_score_dict["value"]:
        best_score_dict["value"] = score
        best_seq_dict["seq"] = cand.copy()
        print(f"[{time.time():.2f}] New best = {score:.6f} (len={len(cand)})")
    return score


# ----------------------------------------------------------------------
# Smoothed gradient of the soft‑max of the convolution
# ----------------------------------------------------------------------
def softmax_gradient(a: np.ndarray, epsilon: float) -> np.ndarray:
    """
    Compute ∇a  ε·log Σ_k exp(conv_k(a)/ε) .
    Returns a vector of length n (same as a).
    """
    n = a.shape[0]
    # full convolution a*a
    conv = conv_self(a)                 # length 2n-1
    # soft‑max weights (stable version)
    conv_shift = conv - np.max(conv)    # avoid overflow
    w = np.exp(conv_shift / epsilon)
    w /= w.sum()                        # soft‑max probabilities, size 2n-1

    # gradient = 2 * (w * a_rev) sliced
    a_rev = a[::-1]
    tmp = conv_full_fft(w, a_rev)       # length (2n-1)+n-1 = 3n-2
    grad = 2.0 * tmp[n - 1 : n - 1 + n]  # take the central n entries
    return grad


# ----------------------------------------------------------------------
# Adam optimiser for a single start vector
# ----------------------------------------------------------------------
def adam_optimize(start: np.ndarray, budget_s: float,
                  best_score_dict, best_seq_dict):
    """Run Adam on the smooth objective for the supplied time budget."""
    n = start.shape[0]
    target = math.sqrt(2.0 * n)

    a = start.astype(float)                     # already on the simplex
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0

    epsilon = 0.5               # initial temperature for the soft‑max
    epsilon_min = 0.005
    decay = 0.9995

    deadline = time.time() + budget_s
    while time.time() < deadline:
        # soft‑max gradient
        grad = softmax_gradient(a, epsilon)

        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = 0.5                                     # base step size
        update = -step * m_hat / (np.sqrt(v_hat) + eps)

        a = a + update
        a = np.maximum(a, 0.0)                        # non‑negativity
        a = project_onto_simplex(a, target)           # ℓ₁‑norm = √(2n)

        # reduce temperature slowly
        epsilon = max(epsilon * decay, epsilon_min)

        # occasional exact evaluation (cheap because a is already normalised)
        if t % 12 == 0:
            # true objective = max(conv(a,a))
            cur_score = np.max(conv_self(a))
            if cur_score < best_score_dict["value"]:
                # store as real sequence
                maybe_update(best_score_dict, best_seq_dict, a)

            # early stop if we have already beaten the target
            if best_score_dict["value"] < 1.503:
                break


# ----------------------------------------------------------------------
# Optional LP refinement (identical to the reference implementation)
# ----------------------------------------------------------------------
def lp_refine(a: np.ndarray, best_score_dict, best_seq_dict, remaining_time):
    """Single LP‑step that (if successful) improves the current best."""
    try:
        from scipy.optimize import linprog
    except Exception:
        return

    n = a.shape[0]
    target = math.sqrt(2.0 * n)
    deadline = time.time() + remaining_time
    while time.time() < deadline:
        conv = conv_self(a)
        M = conv.max()
        rows = 2 * n - 1

        # Build constraint matrix for (a * g)_k ≤ M
        A = np.zeros((rows, n), dtype=float)
        for k in range(rows):
            low = max(0, k - (n - 1))
            high = min(n - 1, k)
            cols = np.arange(low, high + 1, dtype=int)
            A[k, cols] = a[k - cols]

        res = linprog(c=-np.ones(n),
                      A_ub=A,
                      b_ub=np.full(rows, M),
                      bounds=(0, None),
                      method="highs",
                      options={"presolve": True})
        if not res.success:
            break

        g = res.x
        s = g.sum()
        if s <= 0:
            break
        g = g * (target / s)                # re‑scale to the simplex

        # convex blend (t = 0.2)
        t = 0.2
        a = (1.0 - t) * a + t * g
        maybe_update(best_score_dict, best_seq_dict, a)

        # stop if progress stalls
        if best_score_dict["value"] < 1.503:
            break
        if time.time() + 0.5 > deadline:
            break


# ----------------------------------------------------------------------
# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: float = 1000.0,
                     **kwargs) -> list:
    """
    Search for a non‑negative step function that minimises the evaluation
    metric.  The routine respects the supplied time budget and returns the
    best sequence found (as a plain Python list).
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5      # safety margin

    best_score = {"value": float("inf")}
    best_seq = {"seq": None}

    # ------------------------------------------------------------------
    # Phase 1 – cheap parametric families
    # ------------------------------------------------------------------
    lengths = list(range(200, 1601, 200)) + [1326, 1500]
    for n in lengths:
        target = math.sqrt(2.0 * n)

        # exponential decay
        for alpha in np.logspace(-4, -0.3, num=12):
            a = shape_exp(n, alpha)
            if a.sum() == 0:
                continue
            a = a / a.sum() * target
            maybe_update(best_score, best_seq, a)

        # reversed exponential
        for alpha in np.logspace(-4, -0.3, num=12):
            a = shape_exp_rev(n, alpha)
            if a.sum() == 0:
                continue
            a = a / a.sum() * target
            maybe_update(best_score, best_seq, a)

        # linear descending
        for beta in np.linspace(0.0, 2.0 / max(1, n - 1), num=10):
            a = shape_linear_desc(n, beta)
            if a.sum() == 0:
                continue
            a = a / a.sum() * target
            maybe_update(best_score, best_seq, a)

        # quadratic descending
        for beta in np.linspace(0.0, 1.0 / max(1, n ** 2), num=10):
            a = shape_quad_desc(n, beta)
            if a.sum() == 0:
                continue
            a = a / a.sum() * target
            maybe_update(best_score, best_seq, a)

        # symmetric triangular shape
        a = shape_triangular(n)
        a = a / a.sum() * target
        maybe_update(best_score, best_seq, a)

        if time.time() >= deadline:
            break

    # ------------------------------------------------------------------
    # Phase 2 – smoothed gradient descent (Adam) with random restarts
    # ------------------------------------------------------------------
    while time.time() < deadline:
        # choose a length (moderate – ensures a few thousand FFTs are cheap)
        n = np.random.randint(300, 2501)          # 300 … 2500
        target = math.sqrt(2.0 * n)

        # random initial vector – Dirichlet‑like sparsity
        raw = np.random.gamma(shape=0.3, scale=1.0, size=n)
        if raw.sum() == 0:
            continue
        init = raw / raw.sum() * target

        # keep a tiny fraction of the current best as a warm start
        if best_seq["seq"] is not None and np.random.rand() < 0.1:
            # resample a sub‑vector of the best and pad with zeros
            old = np.array(best_seq["seq"], copy=False)
            if old.shape[0] == n:
                init = old.copy()
            else:
                idx = np.random.choice(old.shape[0], size=min(n, old.shape[0]), replace=False)
                init_vec = np.zeros(n, dtype=float)
                init_vec[:len(idx)] = old[idx]
                if init_vec.sum() > 0:
                    init = init_vec / init_vec.sum() * target

        # give this start a few seconds of Adam optimisation
        remaining = deadline - time.time()
        if remaining < 2.0:
            break
        adam_optimize(init, min(8.0, remaining), best_score, best_seq)

        # early exit if target already reached
        if best_score["value"] < 1.503:
            break

    # ------------------------------------------------------------------
    # Phase 3 – optional LP refinement (if time permits)
    # ------------------------------------------------------------------
    if best_seq["seq"] is not None:
        remaining = deadline - time.time()
        if remaining > 5.0:
            lp_refine(np.array(best_seq["seq"], copy=False),
                      best_score, best_seq, remaining)

    # ------------------------------------------------------------------
    # Fallback – uniform sequence if nothing succeeded
    # ------------------------------------------------------------------
    if best_seq["seq"] is None:
        n = 1000
        target = math.sqrt(2.0 * n)
        best_seq["seq"] = np.full(n, target / n, dtype=float)

    return best_seq["seq"].tolist()
```

The program follows the three‑phase strategy described above, stays within the
time limit, avoids closures, and returns the best step‑function heights it
found.
