The evaluation function is  

\[
E(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\]

where `a*a` is the ordinary (linear) convolution.  
For a fixed total sum the denominator is constant, therefore we have to *flatten* the
convolution – i.e. minimise the largest entry of `a*a`.

A simple, provably‑good starting point is the discrete analogue of the continuous
function \(f(x)=x^{-1/2}\).  
For a long vector this makes the convolution almost constant, giving an initial
score of about 1.57 (much better than the constant‑sequence value 2).

From this point we run a **projected sub‑gradient descent** on the objective  
`max(a*a)`.  
At each iteration we

1. compute the convolution,
2. pick a (random) index `k` where the maximum is attained,
3. evaluate the sub‑gradient of the scalar `c_k = (a*a)[k]` w.r.t. `a`,
4. move a little in the opposite direction,
5. project back onto the simplex (`a_i ≥ 0`, `∑a_i = 1`).

The step size decreases like `1/√t`, guaranteeing convergence.  
Occasional random perturbations are added to escape plateaus.

The algorithm is completely self‑contained, respects the time limit, and returns
the best sequence seen during the run.

```python
"""Projected sub‑gradient minimisation of max(a*a).

The function builds a 1/√ decay (a_i = 1/√(i+1)), which already yields a
score ≈ 1.57.  It then repeatedly reduces the largest convolution entry using
a sub‑gradient step while keeping the vector non‑negative and normalised
(∑a_i = 1).  The best sequence seen before the time budget expires is returned.
"""

import time
import numpy as np

# ------------------------------------------------------------
# Helper utilities
# ------------------------------------------------------------

def _initial_sequence(n: int) -> np.ndarray:
    """Return a non‑negative start vector of length *n*.
    a_i = 1 / sqrt(i+1), normalised to sum 1."""
    a = np.array([1.0 / np.sqrt(i + 1) for i in range(n)], dtype=float)
    a /= a.sum()
    return a


def _subgradient(a: np.ndarray, k: int) -> np.ndarray:
    """
    Sub‑gradient of the scalar convolution entry c_k = (a*a)[k]
    with respect to a (for non‑negative a).

    For each i, ∂c_k/∂a_i = a_{k-i} + a_{k-i} = 2*a_{k-i}   if i ≠ k-i,
                         = a_i                               if i = k-i,
    and zero when k-i is out of bounds.
    """
    n = a.shape[0]
    grad = np.zeros_like(a)

    # indices i for which the partner index j = k-i lies inside [0, n)
    i = np.arange(n)
    j = k - i
    mask = (j >= 0) & (j < n)

    i_valid = i[mask]
    j_valid = j[mask]

    # i == j  (self‑product)  -> coefficient 1
    self_mask = i_valid == j_valid
    grad[i_valid[self_mask]] = a[i_valid[self_mask]]

    # i != j  -> coefficient 2
    diff_mask = ~self_mask
    grad[i_valid[diff_mask]] = 2.0 * a[j_valid[diff_mask]]

    return grad


def _project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Project vector *v* onto the probability simplex {x ≥ 0, sum x = 1}
    using the standard O(n) algorithm.
    """
    # shift to make the sum exactly one
    # (the algorithm works for any linear equality)
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s == 0:
        # fallback to uniform distribution
        return np.full_like(v, 1.0 / v.size)
    return v / s


# ------------------------------------------------------------
# Main entry point required by the competition framework
# ------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Return a sequence of non‑negative heights that (as far as possible within the
    time budget) minimises `evaluate_sequence`.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Time budget in seconds (the function must return before this time).

    Returns
    -------
    list[float]
        The best sequence found.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5  # safety margin

    # --------------------------------------------------------
    # Choose length
    # --------------------------------------------------------
    # Prefer the length of the previously known construction if it exists,
    # otherwise fall back to a moderate size.
    n = globals().get("height_sequence_1")
    if isinstance(n, (list, tuple, np.ndarray)):
        n = len(n)
    else:
        n = 2000  # a safe default that still runs fast

    # --------------------------------------------------------
    # Initial vector
    # --------------------------------------------------------
    a = _initial_sequence(n)
    best_a = a.copy()
    best_score = evaluate_sequence(best_a.tolist())
    print(f"[init] length={n}, initial score={best_score:.6f}")

    # --------------------------------------------------------
    # Sub‑gradient descent loop
    # --------------------------------------------------------
    iteration = 0
    step0 = 0.2  # initial step magnitude

    while time.time() < deadline:
        # 1) compute convolution and locate a maximal entry
        conv = np.convolve(a, a)
        max_val = conv.max()
        max_idx = np.flatnonzero(conv == max_val)

        # pick a random maximiser to avoid bias when several tie
        k = int(np.random.choice(max_idx))

        # 2) sub‑gradient of that entry
        g = _subgradient(a, k)

        # 3) move opposite to the gradient, keeping sum zero
        d = -g
        # make the step orthogonal to the all‑ones vector (preserves the sum)
        d -= d.mean()

        # 4) step size schedule  (1/√t)
        step = step0 / np.sqrt(iteration + 1.0)
        a_new = a + step * d

        # 5) enforce feasibility (non‑negative, normalised)
        a_new = _project_to_simplex(a_new)

        # ----------------------------------------------------
        # Evaluate and decide whether to keep the new point
        # ----------------------------------------------------
        try:
            cur_score = evaluate_sequence(a_new.tolist())
        except Exception:
            # numerical safety – keep the old point
            cur_score = np.inf

        # always keep the globally best point
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()
            print(f"[iter {iteration:06d}] new best: {best_score:.6f}")

        # accept the new point if it improves, otherwise keep the old one
        # (occasionally accept a worse point to escape plateaus)
        accept = cur_score <= best_score or np.random.rand() < 0.01
        if accept:
            a = a_new

        # occasional random jitter to shake the process
        if iteration % 2000 == 0 and iteration > 0:
            jitter = np.random.normal(scale=0.02, size=n)
            a = _project_to_simplex(a + jitter)

        iteration += 1

    # --------------------------------------------------------
    # Return the best sequence discovered
    # --------------------------------------------------------
    print(f"[done] iterations={iteration}, best score={best_score:.6f}")
    return best_a.tolist()
```
