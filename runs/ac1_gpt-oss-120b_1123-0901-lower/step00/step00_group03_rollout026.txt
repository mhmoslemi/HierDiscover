Propose a step‑function sequence by using a simple polynomial growth shape.
For a_i = (i+1)^p (p ≥ 2) the self‑convolution at the centre can be computed in
closed form and the evaluation score 2·n·max(conv)/sum(a)^2 becomes

    R(p) = 2·(p+1)^2·Beta(p+1,p+1),

which rapidly drops below the target 1.503 already for p = 2.
We generate a few candidates (p = 1…5), scale them so that the largest entry
stays safely below the 1000‑clamp used in ``evaluate_sequence`` and return the
best one found.  The algorithm is deterministic, runs instantly and needs no
external optimisation loop.
"""

import numpy as np

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Return the best polynomial‑growth sequence discovered within the budget.
    The function respects all validation steps inside `evaluate_sequence`.
    """
    # Use the length of the best known construction if available,
    # otherwise fall back to a reasonable default.
    n = len(height_sequence_1) if 'height_sequence_1' in globals() else 1108

    # Upper bound for the values before the built‑in clipping (keep safely below 1000)
    target_max = 900.0

    best_seq = None
    best_score = float('inf')

    # Try a small set of exponents – p = 1 (uniform) is the baseline,
    # higher p give increasingly better scores.
    for p in range(1, 6):

        # Scale uniformly so that the largest entry is `target_max`.
