propose_candidate
=================

Search for a non‑negative step sequence whose evaluation value

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

is as small as possible.

The algorithm is deliberately simple but works well for the
quadratic objective:

1.  Initialise the vector with the classic “inverse‑square‑root’’ shape  
    a_i ∝ 1 / sqrt(i+1).  This distribution is known to give a very
    low value (≈ π/2 for large n) – far below the uniform sequence which
    scores 2.0.

2.  Repeatedly improve the sequence by a projected sub‑gradient step.
    For the current maximum convolution index `k*` the sub‑gradient of
    `max(conv(a,a))` is `g_i = 2 * a_{k*-i}` (zero where the index is
    out of range).  A small step `α * g` is taken, the result is
    projected onto the probability simplex (non‑negative, sum = 1) and
    accepted if the evaluation improves.

3.  Occasionally perform a tiny random perturbation to escape possible
    plateaus.

The loop runs until the allocated time budget (default 1000 s) is nearly
exhausted.  The best sequence found is returned.

No external files are accessed and only `numpy` and `scipy.optimize.linprog`
are required (the LP from the reference solution is kept as a possible
fallback but is not needed for the core search).

"""

import time
import numpy as np
from scipy import optimize

# ----------------------------------------------------------------------
# Helper: projection of a vector onto the probability simplex
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, sum x = 1}."""
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    # rho = max { j | u_j - cssv_j / j > 0 }
    rho = np.where(u - cssv / ind > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w

        conv = np.convolve(a, a)
        k_max = int(np.argmax(conv))

        g = np.zeros_like(a)
