"""
Propose a candidate sequence using a simple power-law shape.
For length n we set a_i = (i+1)^p with p >= 2. This shape makes the central
convolution sum ∑ a_i*a_{n-1-i} proportional to n^{2p+1}Beta(p+1,p+1) while
the ℓ1 norm grows as n^{p+1}/(p+1). The resulting evaluation
 2 n * max(conv) / (sum^2) = 2 (p+1)^2 * Beta(p+1,p+1)
which for p=2 already yields ≈0.60, well below the target 1.503.
We generate a few exponents, scale the whole vector to respect the
1000‑value ceiling, evaluate each candidate and return the best.
"""

import numpy as np
import time

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    # Length: try to copy length of existing best if available
    try:
        n = len(height_sequence_1)
    except NameError:
        n = 3000   # fallback length
    best_seq = None
    best_score = float('inf')
    # Exponents to try – higher exponents give lower score, but too large may lead to underflow.
    exponents = [2, 3, 4, 5, 6]
    for p in exponents:
        # Build raw power‑law vector
        raw = np.arange(1, n + 1, dtype=np.float64) ** p
        # Scale so that the maximum entry is exactly 1000 (stays below the cap)
        scale = 1000.0 / raw[-1]
        seq = list(raw * scale)
        # Evaluate
        score = evaluate_sequence(seq)
        if score < best_score:
            best_score = score
            best_seq = seq
    # In the unlikely case everything failed, fall back to uniform sequence
    if best_seq is None:
        best_seq = [1.0] * n
        best_score = evaluate_sequence(best_seq)
    # Print final score for debugging
    print(f"Best exponent score: {best_score:.6f} using length {n}")
    return best_seq

The evaluation metric is 
    2·n·max(conv(a,a)) / (sum(a)**2)

For a sequence a_i = (i+1)^p (i = 0 … n‑1) the convolution at the centre is
    ∑_{i=1}^n i^p (n+1-i)^p = n^{2p+1}·Beta(p+1,p+1) + o(n^{2p+1})

and  sum(a) = n^{p+1}/(p+1) + o(n^{p+1}).  
Consequently

    score = 2·n·max(conv) / (sum^2) → 2·(p+1)^2·Beta(p+1,p+1)

which for p=2 already gives ≈0.6 and decreases rapidly for larger p.
The score is invariant under uniform scaling, therefore we simply scale the
vector so that its largest entry is exactly 1000 (the built‑in cap in the
