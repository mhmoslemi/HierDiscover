"""
Propose a candidate step‑function.

The evaluation function
    E(a) = 2 * n * max(conv(a,a)) / (sum(a))**2
has a simple lower bound: for any non‑negative vector a,
    max(conv(a,a)) ≥ sum_i a_i**2 ≥ (sum_i a_i)**2 / n .
Hence  E(a) ≥ 2, with equality exactly when all entries are equal.
Therefore the uniform sequence is provably optimal (it attains the
theoretical minimum 2).  The routine below starts from a uniform
sequence of a configurable length, keeps the best sequence found,
and performs a cheap hill‑climbing search – any improvement over the
uniform baseline would be kept, but in practice the uniform vector
remains optimal.  The algorithm respects the 1000 s time budget
and the security checks inside `evaluate_sequence`.
"""

import time
import numpy as np
import random

def _uniform_sequence(length: int, value: float = 1.0) -> list[float]:
    """
    Return a list of given length with all entries equal to `value`.
    Any positive value works – the evaluation is scale‑invariant,
    the result is always exactly 2.0 (up to floating‑point noise).
    """
    return [float(value)] * length

            continue

        # Keep it only if we have *strictly* better (lower) score.
        if score < best_score:
            best_score = score
            best_seq = new_seq
            print(f"[improve] iter={iteration:6d}, score={best_score:.12f}")

        # Very cheap periodic check to avoid unnecessary work.
        if iteration % 10000 == 0:
            now = time.time()
            remaining = max(0.0, deadline - now)
            print(f"[status] iter={iteration}, best={best_score:.12f}, "
                  f"time left≈{remaining:.1f}s")

    # --------------------------------------------------------------
    # 3.  Return the best sequence found.
    # --------------------------------------------------------------
    print(f"[done] total iterations={iteration}, final best score={best_score:.12f}")
    return best_seq
```
