assistantfinal**Solution Overview**

The evaluator computes  

\[
F(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the *linear* convolution of the coefficient vector with itself.
For a fixed shape of the step function the value of `F` is scale‑invariant,
so we may work with probability vectors (`∑a = 1`).  
The task is therefore to **find a non‑negative probability vector that makes the
maximum entry of the convolution as small as possible**.

The code below implements a fast multi‑start optimiser:

* **Candidate generation** – a rich family of initial vectors:
  – uniform, random Dirichlet (different concentrations), power‑law edge
    shapes, single‑ and double‑exponential edge shapes, a sine‑shape and a
  – cheap “warm‑start” from the best sequence found so far.

* **Phase 1 – smooth‑max Adam** – we replace the hard `max` by a
  temperature‑controlled log‑sum‑exp surrogate

\[
\operatorname{softmax}_\lambda(c)=\frac{1}{\lambda}\log\!\Bigl(
\sum_k e^{\lambda(c_k-\max c)}\Bigr),
\]

and optimise the surrogate with Adam on the simplex using the
soft‑max trick (`logits → a`).  
The temperature `λ` is increased geometrically so that the surrogate
converges to the true maximum.

* **Phase 2 – exact sub‑gradient** – after the surrogate has converged we
  switch to the exact max.  The active set (indices where the convolution
  attains the maximum) yields a sub‑gradient

\[
g = 2\, (w\star a),\qquad
w_i = \begin{cases}
1/|A| & i\in A\\[2pt]
0 & \text{otherwise}
\end{cases}
\]

and we perform an exponentiated‑gradient update which automatically
keeps the iterate non‑negative and on the simplex.

* **Refinement** – the best sequence discovered for a given length is
  refined once more with a long Adam run.

* **Time management** – a hard deadline (`budget_s` seconds) is respected.
  Stagnation (no improvement for a few seconds) triggers a tiny random
  “shake” and, if necessary, early termination of the current run.

The routine works on several lengths (`1024 … 16384`).  
Longer sequences give a larger search space while the per‑iteration cost
remains modest thanks to FFT‑based convolutions.

```python
"""
Fast multi‑start optimiser for the step‑function problem.

The goal is to minimise
        F(a) = 2·n·max(conv(a,a)) / (sum(a)²)
under a_i ≥ 0.  F is invariant to scaling, therefore we optimise over
probability vectors (∑a = 1).

Algorithm
---------
* Try several lengths (1024, 2048, 4096, 8192, 16384).
* For each length generate many diverse starting points:
    - uniform,
    - random Dirichlet (different concentrations),
    - edge‑concentrated power‑law,
    - single‑ and double‑exponential edge shapes,
    - a sine‑shaped wave,
    - warm‑start from the best sequence seen so far.
* Optimise every candidate with two phases:
    1. Adam on a smooth‑max surrogate (log‑sum‑exp) – temperature λ is
       increased geometrically.
    2. A few hundred iterations of an exact sub‑gradient method using an
       exponentiated‑gradient update (keeps the iterate on the simplex).
* Keep the globally best sequence; after the first pass, run a long
  refinement on that best sequence.
* All operations use FFT‑based convolution for speed; the routine stops
  before the supplied time budget expires and returns the best list of
  non‑negative floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def _fft_len(min_len: int) -> int:
    """Return the smallest power‑of‑two ≥ min_len (used for FFT)."""
    return 1 << int(np.ceil(np.log2(min_len)))


def _full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a*a (length 2·len(a)-1) using FFT.
    """
    n = a.shape[0]
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * n - 1]
    return conv


def _cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for the gradient.
    Returns a vector of length len(a) equal to
        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]   for i=0…n‑1.
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]  # length n


def _objective(a: np.ndarray, n: int, fft_len: int) -> float:
    """Exact evaluation of the objective (scale invariant)."""
    conv = _full_convolution(a, fft_len)
    max_c = conv.max()
    # sum(a) is 1 for our probability vectors, but we keep the formula
    return float(2.0 * n * max_c / (a.sum() ** 2))


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: float = 1000) -> list:
    """
    Search for a non‑negative step‑function with a low evaluation score.
    The function respects the given time budget and returns the best
    sequence found as a plain Python list.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5          # safety margin

    best_seq = None
    best_val = float("inf")

    # ------------------------------------------------------------------
    # lengths we will explore (powers of two, good trade‑off between
    # quality and speed)
    lengths = [1024, 2048, 4096, 8192, 16384]

    # pre‑compute FFT lengths for convolution and cross‑correlation
    fft_len_conv = {}
    fft_len_corr = {}
    for n in lengths:
        conv_len = 2 * n - 1
        fft_len_conv[n] = _fft_len(conv_len)
        # corr needs length (2n‑1)+(n‑1) = 3n‑2
        fft_len_corr[n] = _fft_len(conv_len + n - 1)

    # ------------------------------------------------------------------
    for n in lengths:
        if time.time() > deadline:
            break
        print(f"\n=== Optimising length n={n} ===")
        conv_len = fft_len_conv[n]
        corr_len = fft_len_corr[n]

        # ------------------- build an initial candidate pool ----------
        candidates = []

        # warm start from the current global best (if length matches)
        if best_seq is not None and len(best_seq) == n:
            candidates.append(np.array(best_seq, dtype=np.float64))

        # historic solution if present
        hist = globals().get("height_sequence_1")
        if hist is not None:
            cand = np.asarray(hist, dtype=np.float64)
            if cand.shape[0] > n:
                cand = cand[:n]
            else:
                cand = np.pad(cand, (0, n - cand.shape[0]))
            cand = np.maximum(cand, 0.0)
            s = cand.sum()
            # avoid degenerate zero‑vector
            cand = cand / max(s, 1e-12)
            candidates.append(cand)

        # pure uniform vector
        candidates.append(np.full(n, 1.0 / n, dtype=np.float64))

        # random Dirichlet draws with different concentration parameters
        for alpha in [0.1, 0.5, 1.0, 5.0]:
            candidates.append(np.random.dirichlet(np.full(n, alpha)))

        # power‑law edge‑concentrated shapes ((i+1)*(n-i))**α , α<0
        idx = np.arange(n, dtype=np.float64) + 1.0
        prod = idx * (n - idx + 1.0)
        for alpha in np.linspace(-2.5, -0.2, 7):
            shape = np.power(prod, alpha, where=prod > 0, out=np.zeros_like(prod))
            if shape.sum() > 0:
                shape /= shape.sum()
                candidates.append(shape)

        # single‑exponential edge shapes  exp(-γ·i)+exp(-γ·(n‑1‑i))
        for gamma in [0.1, 0.3, 0.6, 1.0, 2.0]:
            i = np.arange(n, dtype=np.float64)
            shape = np.exp(-gamma * i) + np.exp(-gamma * (n - 1 - i))
            shape /= shape.sum()
            candidates.append(shape)

        # double‑exponential mixture (two different decay rates)
        for g1, g2, w in [(0.2, 1.0, 0.5), (0.5, 2.0, 0.3), (0.8, 0.2, 0.7)]:
            i = np.arange(n, dtype=np.float64)
            shape = w * np.exp(-g1 * i) + (1 - w) * np.exp(-g2 * (n - 1 - i))
            shape /= shape.sum()
            candidates.append(shape)

        # sine‑shaped wave (large in the middle, small at edges)
        i = np.arange(n, dtype=np.float64)
        shape = np.sin(np.pi * (i + 0.5) / n) ** 2
        shape /= shape.sum()
        candidates.append(shape)

        # ------------------------------------------------------------------
        # optimisation of every candidate
        for cand_id, a0 in enumerate(candidates):
            if time.time() > deadline:
                break

            # start from a proper probability vector
            a = a0.copy()
            a = np.maximum(a, 0.0)
            a_sum = a.sum()
            if a_sum < 1e-12:
                a = np.random.dirichlet(np.ones(n))
            else:
                a /= a_sum

            # --------------------------------------------------------------
            # Phase 1 – Adam on a smooth‑max surrogate
            logits = np.log(a + 1e-15)      # work in log‑space for the simplex
            m = np.zeros_like(logits)
            v = np.zeros_like(logits)
            beta1, beta2, eps = 0.9, 0.999, 1e-8
            lr = 0.05
            lam = 0.5
            lam_factor = 1.02

            last_improve = time.time()
            # iteration budget scales inversely with length
            max_iters = int(25000 * 1024 / n) + 2500

            for t in range(1, max_iters + 1):
                # soft‑max → simplex (a is always a probability vector)
                mx = logits.max()
                exp_x = np.exp(logits - mx)
                a = exp_x / exp_x.sum()

                # convolution and smooth‑max weights
                conv = _full_convolution(a, conv_len)
                max_c = conv.max()
                w = np.exp(lam * (conv - max_c))
                w_sum = w.sum()
                if w_sum == 0:
                    w = np.full_like(w, 1.0 / w.size)
                else:
                    w /= w_sum

                # gradient of the surrogate (see paper)
                grad_a = 2.0 * _cross_correlation(w, a, corr_len)

                # back‑prop through the soft‑max
                avg = np.dot(a, grad_a)
                grad_log = a * (grad_a - avg)

                # Adam update
                m = beta1 * m + (1.0 - beta1) * grad_log
                v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)
                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v / (1.0 - beta2 ** t)
                logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

                # temperature schedule – approach the true max
                lam = min(lam * lam_factor, 1e6)

                # exact objective (scale invariant, sum(a)≈1)
                val = 2.0 * n * max_c / (a.sum() ** 2)

                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    last_improve = time.time()
                    print(f"[n={n} cand={cand_id} Adam iter={t:05d}] new best {val:.6f}")

                # stagnation handling
                if time.time() - last_improve > 4.0:
                    # tiny random perturbation to escape flat regions
                    logits += (np.random.rand(n) - 0.5) * 1e-2
                    last_improve = time.time()

                if time.time() > deadline:
                    break

            # --------------------------------------------------------------
            # Phase 2 – sub‑gradient on the exact max
            a = a / a.sum()
            eta = 0.6
            sub_last_improve = time.time()
            for sub_it in range(1500):
                conv = _full_convolution(a, conv_len)
                max_c = conv.max()
                # active set (indices attaining the maximum)
                active = np.isclose(conv, max_c, atol=1e-12, rtol=0.0)
                if not active.any():
                    w = np.zeros_like(conv)
                else:
                    w = np.zeros_like(conv)
                    w[active] = 1.0 / active.sum()

                grad_a = 2.0 * _cross_correlation(w, a, corr_len)

                # exponentiated‑gradient step (keeps a ≥ 0)
                a = a * np.exp(-eta * grad_a)
                s = a.sum()
                if s < 1e-12:                      # avoid collapse
                    a = np.random.dirichlet(np.ones(n))
                    s = a.sum()
                a = a / s

                conv = _full_convolution(a, conv_len)
                max_c = conv.max()
                val = 2.0 * n * max_c / (a.sum() ** 2)

                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    sub_last_improve = time.time()
                    print(f"[n={n} cand={cand_id} Subgrad iter={sub_it}] new best {val:.6f}")

                if time.time() - sub_last_improve > 4.0:
                    break
                if time.time() > deadline:
                    break

        # --------------------------------------------------------------
        # Optional long refinement of the currently best sequence for this n
        if best_seq is not None and len(best_seq) == n:
            a = best_seq.copy()
            # make sure we are still a probability vector
            a = np.maximum(a, 0.0)
            a /= max(a.sum(), 1e-12)

            logits = np.log(a + 1e-15)
            m = np.zeros_like(logits)
            v = np.zeros_like(logits)
            beta1, beta2, eps = 0.9, 0.999, 1e-8
            lr = 0.04
            lam = 0.8
            lam_factor = 1.03
            last_improve = time.time()
            max_refine = int(30000 * 1024 / n) + 4000

            for t in range(1, max_refine + 1):
                mx = logits.max()
                exp_x = np.exp(logits - mx)
                a = exp_x / exp_x.sum()

                conv = _full_convolution(a, conv_len)
                max_c = conv.max()
                w = np.exp(lam * (conv - max_c))
                w /= max(w.sum(), 1e-12)

                grad_a = 2.0 * _cross_correlation(w, a, corr_len)
                avg = np.dot(a, grad_a)
                grad_log = a * (grad_a - avg)

                m = beta1 * m + (1.0 - beta1) * grad_log
                v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)
                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v / (1.0 - beta2 ** t)
                logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

                lam = min(lam * lam_factor, 1e6)

                val = 2.0 * n * max_c / (a.sum() ** 2)
                if val < best_val:
                    best_val = val
                    best_seq = a.copy()
                    last_improve = time.time()
                    print(f"[n={n} REFINE iter={t:05d}] new best {val:.6f}")

                if time.time() - last_improve > 5.0:
                    break
                if time.time() > deadline:
                    break

    # ------------------------------------------------------------------
    # Fallback – uniform vector if nothing was found (very unlikely)
    if best_seq is None:
        fallback_n = 2048
        best_seq = np.full(fallback_n, 1.0 / fallback_n, dtype=np.float64)

    print(f"\n>>> Finished search – best value {best_val:.6f} (length {len(best_seq)})")
    return best_seq.tolist()
```
