assistantfinal**Solution Explanation**

The score to minimise is  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

Because the denominator is homogeneous we may **normalise** the vector to the
probability simplex  

\[
\sum_i a_i = 1 .
\]

Then  

\[
F(a)=2\,n\;\max (a*a) .
\]

For a given length `n` the problem is non‑convex (the product `a_i a_j` is not
convex), therefore we use a **multi‑start stochastic optimisation** that
combines three ideas.

--------------------------------------------------------------------
### 1.  Smooth‑max surrogate (log‑sum‑exp) + Adam  

\[
\operatorname{S}_\lambda(a)=\lambda\log\Bigl(\sum_k e^{\operatorname{conv}_k(a)/\lambda}\Bigr)
\]

converges to the true maximum when the temperature `λ` grows.
`∇_a S_λ` is a weighted sum of the gradients of the individual convolution
entries; the weights are a soft‑max of the convolution values.
We keep the iterate on the simplex by the **soft‑max re‑parameterisation**

\[
a_i = \frac{e^{\,z_i}}{\sum_j e^{\,z_j}} .
\]

Adam is applied to the logits `z`.  
The temperature is increased geometrically (`λ←λ·λ_factor`) so that the
optimiser first sees a smooth landscape and finally refines the true max.

--------------------------------------------------------------------
### 2.  Exact sub‑gradient phase  

After the surrogate phase we switch to the real objective.
If `k*` is a maximising index of the convolution,
the sub‑gradient of `max(conv)` is  

\[
g = 2\, (w ★ a) , \qquad
w_i = \begin{cases}
1/|I| & i\in I\\
0     & \text{otherwise}
\end{cases}
\]

where `I` is the (tiny) set of active indices.
An **exponentiated‑gradient** update (`a ← a·e^{-ηg}`) keeps all components
non‑negative and stays on the simplex after re‑normalisation.

--------------------------------------------------------------------
### 3.  Diverse initial candidates  

A rich pool of start points is crucial.  For every length we create

* the current global best (interpolated if lengths differ),
* the historic `height_sequence_1`,
* uniform vector,
* Dirichlet draws with several concentration parameters (including very
  sparse draws),
* sorted Dirichlet vectors (monotone shapes),
* symmetric power‑law and two‑Gaussian edge shapes (as in the reference),
* monotone exponential and asymmetric power‑law shapes.

All candidates are normalised to sum = 1 before optimisation.

--------------------------------------------------------------------
### 4.  Global schedule  

Lengths `[1024, 2048, 4096, 8192]` are processed in that order.
For each length all candidates are optimised, the best sequence is stored,
and a final polishing Adam run is performed on the overall best.

The whole routine respects the external time budget (`budget_s`) with a
small safety margin.

--------------------------------------------------------------------
### 5.  Result  

The function returns the best sequence found as a plain Python list.
It works with any `evaluate_sequence` that follows the specification
provided in the task description.

```python
"""
Multi‑start optimisation for the step‑function bound.

- Generates many diverse start vectors for several lengths.
- Phase 1: Adam on a smooth‑max (log‑sum‑exp) surrogate, temperature λ
  grows geometrically.
- Phase 2: Exact sub‑gradient descent with exponentiated‑gradient updates.
- Periodic random “shakes” avoid stagnation.
- Returns the best vector (list of non‑negative floats) found before the
  time budget expires.
"""

import time
import numpy as np

# -------------------------------------------------------------
# FFT helpers -------------------------------------------------
def full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a * a (length 2*len(a)-1) via real FFT."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * a.shape[0] - 1]
    return conv


def cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for a gradient.
    Result length = len(a).  Implements the formula used in the reference.
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]


# -------------------------------------------------------------
# Objective helpers -------------------------------------------
def exact_objective(a: np.ndarray, n: int, fft_len: int) -> float:
    """
    Return 2 * n * max(conv) / (sum(a)**2)  (sum is assumed ≈ 1).
    """
    conv = full_convolution(a, fft_len)
    return 2.0 * n * conv.max() / (a.sum() ** 2)


# -------------------------------------------------------------
# Optimisation of a single candidate ---------------------------
def optimise_candidate(
    a0: np.ndarray,
    n: int,
    fft_len_conv: int,
    fft_len_corr: int,
    best_val: float,
    best_seq: np.ndarray,
    deadline: float,
) -> tuple[float, np.ndarray]:
    """
    Perform the two optimization phases on a single start vector.
    Returns possibly improved (best_val, best_seq).
    """
    # ---------- initialise ----------
    a = a0 / a0.sum()
    logits = np.log(a + 1e-15)                     # soft‑max parameters

    # ---------- Adam on smooth‑max ----------
    m = np.zeros_like(logits)
    v = np.zeros_like(logits)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    lr = 0.05
    lam = 0.5
    lam_factor = 1.05

    last_improve = time.time()
    max_iters = int(20000 * 1024 / n) + 3000     # more iterations than before

    for t in range(1, max_iters + 1):
        # soft‑max → simplex
        mx = logits.max()
        exp_x = np.exp(logits - mx)
        a = exp_x / exp_x.sum()

        # convolution and smooth‑max weights
        conv = full_convolution(a, fft_len_conv)
        max_c = conv.max()
        w = np.exp(lam * (conv - max_c))
        w_sum = w.sum()
        if w_sum == 0.0:
            w[:] = 1.0 / w.size
        else:
            w /= w_sum

        # gradient of smooth‑max (via cross‑correlation)
        grad_a = 2.0 * cross_correlation(w, a, fft_len_corr)

        # back‑prop through soft‑max
        avg = np.dot(a, grad_a)
        grad_log = a * (grad_a - avg)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_log
        v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        logits -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # temperature schedule
        lam = min(lam * lam_factor, 1e6)

        # exact objective (sum≈1)
        val = 2.0 * n * max_c / (a.sum() ** 2)

        if val < best_val:
            best_val = val
            best_seq = a.copy()
            last_improve = time.time()
            print(f"[n={n} Adam iter={t:05d}] new best {val:.6f}")

        # stagnation handling – occasional small random shake
        if time.time() - last_improve > 4.0:
            logits += (np.random.rand(n) - 0.5) * 1e-2
            last_improve = time.time()

        if time.time() > deadline:
            return best_val, best_seq

    # ---------- Sub‑gradient on true max ----------
    a = a / a.sum()
    eta = 0.6                     # step size for exponentiated update
    sub_last_improve = time.time()
    for sub_it in range(5000):
        conv = full_convolution(a, fft_len_conv)
        max_c = conv.max()
        active = np.isclose(conv, max_c, atol=1e-12, rtol=0.0)
        if not active.any():
            w = np.zeros_like(conv)
        else:
            w = np.zeros_like(conv)
            w[active] = 1.0 / active.sum()

        grad_a = 2.0 * cross_correlation(w, a, fft_len_corr)

        a = a * np.exp(-eta * grad_a)          # exponentiated‑gradient step
        s = a.sum()
        if s < 1e-12:                          # avoid collapse to zero
            a = np.random.dirichlet(np.ones(n))
            s = a.sum()
        a = a / s

        conv = full_convolution(a, fft_len_conv)
        max_c = conv.max()
        val = 2.0 * n * max_c / (a.sum() ** 2)

        if val < best_val:
            best_val = val
            best_seq = a.copy()
            sub_last_improve = time.time()
            print(f"[n={n} Subgrad iter={sub_it}] new best {val:.6f}")

        if time.time() - sub_last_improve > 4.0:
            break
        if time.time() > deadline:
            break

    return best_val, best_seq

def make_powerlaw_edge(n: int, alpha: float) -> np.ndarray:
    idx = np.arange(n, dtype=np.float64) + 1.0
    prod = idx * (n - idx + 1.0)
    shape = np.power(prod, alpha, where=prod > 0, out=np.zeros_like(prod))
    if shape.sum() == 0.0:
        shape = np.ones_like(shape)
    return shape / shape.sum()


def make_two_gaussian(n: int, gamma: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    shape = np.exp(-gamma * (i ** 2)) + np.exp(-gamma * ((n - 1 - i) ** 2))
    return shape / shape.sum()


def make_exponential_decay(n: int, k: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    shape = np.exp(-k * i)
    return shape / shape.sum()


def interpolated(best: np.ndarray, new_len: int) -> np.ndarray:
    """Resize a probability vector by linear interpolation."""
    old_len = best.shape[0]
    if old_len == new_len:
        return best.copy()
    x_old = np.linspace(0.0, 1.0, old_len)
    x_new = np.linspace(0.0, 1.0, new_len)
    return np.interp(x_new, x_old, best)

        if time.time() > deadline:
            break
        print(f"\n=== Optimising length n={n} ===")
        conv_len_fft = fft_len_conv[n]
        corr_len_fft = fft_len_corr[n]

        # ---- build candidates ------------------------------------
        candidates = []

        # warm start from current global best (interpolated if length differs)
        if best_seq is not None:
            cand = interpolated(best_seq, n)
            candidates.append(cand)

        # historic sequence if present
        hseq = globals().get("height_sequence_1")
        if hseq is not None:
            cand = np.asarray(hseq, dtype=np.float64)
            if cand.shape[0] > n:
                cand = cand[:n]
            else:
                cand = np.pad(cand, (0, n - cand.shape[0]))
            cand = np.maximum(cand, 0.0)
            if cand.sum() < 0.01:
                cand = np.random.dirichlet(np.ones(n))
            else:
                cand = cand / cand.sum()
            candidates.append(cand)

        # uniform
        candidates.append(np.full(n, 1.0 / n, dtype=np.float64))

        # Dirichlet draws with various concentration parameters
        for alpha in [0.1, 0.3, 0.5, 1.0, 2.0, 5.0]:
            candidates.append(np.random.dirichlet(np.full(n, alpha)))

        # sorted Dirichlet (monotone decreasing)
        for alpha in [0.2, 0.5, 1.0]:
            v = np.random.dirichlet(np.full(n, alpha))
            candidates.append(np.sort(v)[::-1])

        # power‑law edge shapes
        for alpha in np.linspace(-2.0, -0.2, 7):
            candidates.append(make_powerlaw_edge(n, alpha))

        # two‑Gaussian edge shapes
        for gamma in [0.2, 0.5, 1.0, 2.0, 5.0]:
            candidates.append(make_two_gaussian(n, gamma))

        # monotone exponential decay
        for k in [0.0005, 0.001, 0.002, 0.005]:
            candidates.append(make_exponential_decay(n, k))

        # asymmetric power‑law shape (different exponents on each side)
        idx = np.arange(n, dtype=np.float64)
        left = (idx + 1) ** -1.0
        right = (n - idx) ** -0.5
        candidates.append((left * right) / (left * right).sum())

        # ---------------------------------------------------------
        # Optimise each candidate
        for cand_id, a0 in enumerate(candidates):
            if time.time() > deadline:
                break
            # ensure a proper probability vector
            a0 = np.array(a0, dtype=np.float64)
            if a0.sum() < 1e-12:
                a0 = np.random.dirichlet(np.ones(n))
            a0 = np.maximum(a0, 0.0)
            a0 = a0 / a0.sum()

            best_val, best_seq = optimise_candidate(
                a0,
                n,
                conv_len_fft,
                corr_len_fft,
                best_val,
                best_seq,
                deadline,
            )

    # -------------------------------------------------------------
    # Final polishing on the globally best sequence (if any)
    if best_seq is not None:
        n = best_seq.shape[0]
        conv_len_fft = fft_len_conv.get(n, 1 << int(np.ceil(np.log2(2 * n - 1))))
        corr_len_fft = fft_len_corr.get(n, 1 << int(np.ceil(np.log2(3 * n - 1))))
        # a short extra Adam run with lower learning rate to fine‑tune
        logits = np.log(best_seq + 1e-15)
        m = np.zeros_like(logits)
        v = np.zeros_like(logits)
        beta1, beta2, eps = 0.9, 0.999, 1e-8
        lr = 0.02
        lam = 1.0
        lam_factor = 1.05
        last_improve = time.time()
        for t in range(1, 5000 + 1):
            mx = logits.max()
            exp_x = np.exp(logits - mx)
            a = exp_x / exp_x.sum()
            conv = full_convolution(a, conv_len_fft)
            max_c = conv.max()
            w = np.exp(lam * (conv - max_c))
            w_sum = w.sum()
            if w_sum == 0.0:
                w[:] = 1.0 / w.size
            else:
                w /= w_sum
            grad_a = 2.0 * cross_correlation(w, a, corr_len_fft)
            avg = np.dot(a, grad_a)
            grad_log = a * (grad_a - avg)
            m = beta1 * m + (1.0 - beta1) * grad_log
            v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            logits -= lr * m_hat / (np.sqrt(v_hat) + eps)
            lam = min(lam * lam_factor, 1e6)

            val = 2.0 * n * max_c / (a.sum() ** 2)
            if val < best_val:
                best_val = val
                best_seq = a.copy()
                last_improve = time.time()
                print(f"[Polish Adam iter={t}] new best {val:.6f}")

            if time.time() - last_improve > 3.0:
                logits += (np.random.rand(n) - 0.5) * 1e-3
                last_improve = time.time()
            if time.time() > deadline:
                break

    # -------------------------------------------------------------
    # Fallback – uniform vector if nothing was found (very unlikely)
    if best_seq is None:
        fallback_n = 2048
        best_seq = np.full(fallback_n, 1.0 / fallback_n, dtype=np.float64)

    return best_seq.tolist()
```
