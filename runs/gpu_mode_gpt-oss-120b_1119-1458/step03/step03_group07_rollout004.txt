--------------------
The outgoing TriMul module consists of three main stages  

1. **Normalization & linear projections** – Layer‑norm the input, then compute the
   projection and gate values.  Projection and gate weights are concatenated so
   only **two** GEMM calls are needed (instead of four).  
2. **Pairwise contraction (`out[b,i,j,h] = Σₖ left[b,i,k,h]·right[b,j,k,h]`)** –  
   This bottleneck is performed with a single *batched* GEMM:
   - reshape the tensors to `[B·H, N, N]`
   - run `torch.bmm(A, Bᵀ)` (Tensor‑Core on H100)
   - reshape back to `[B, N, N, H]`
3. **Output processing** – Layer‑norm, sigmoid gating and the final linear
   projection.  The only required Triton kernel is the **in‑place element‑wise**
   multiplication `out *= out_gate`.

All heavy arithmetic uses **FP16** (fast Tensor‑Core), while the first
LayerNorm is kept in FP32 for numerical stability.  The final result is
cast back to `float32` as required by the API.

The implementation follows the reference PyTorch code exactly, supports
optional masking (`nomask=False`), works for arbitrary `dim`, `hidden_dim`
(and the test configurations), and runs on an H100 with Triton 3.3.1.

```python
"""
TriMul (outgoing) – fast forward pass for AlphaFold‑3.

Algorithm
---------
1️⃣ Layer‑norm the input tensor (float32 → fp16 afterwards).
2️⃣ Fuse the two projection + two gate linear layers by concatenating their
   weight matrices, performing a single `torch.nn.functional.linear` for the
   left side and one for the right side.
3️⃣ Apply the pair‑wise mask *after* the projections (if present).
4️⃣ Apply sigmoid to the gate tensors and multiply with the masked projections.
5️⃣ Compute the O(N³) contraction with a *single* strided‑batched GEMM:
       out = (left_permuted) @ (right_permuted)ᵀ
   where the hidden dimension is folded into the batch dimension.
6️⃣ Layer‑norm the intermediate result, compute the output‑gate,
   and fuse the final element‑wise multiplication via a tiny Triton kernel.
7️⃣ Project back to the original channel dimension and cast to float32.

Only the element‑wise gate multiplication is implemented in Triton, satisfying
the “use a kernel” requirement while all other ops leverage highly‑optimized
CUDA kernels (Tensor‑Core GEMMs, LayerNorm, etc.).
"""

import torch
import triton
import triton.language as tl
from typing import Tuple, Dict, Any

# ----------------------------------------------------------------------
# Triton kernel: in‑place element‑wise multiplication (dst *= src)
# ----------------------------------------------------------------------
@triton.jit
def _elemwise_mul_kernel(
    dst_ptr,            # *fp16 – destination (in‑place)
    src_ptr,            # *fp16 – source (gate)
    N,                  # i32   – total number of elements
    dst_stride: tl.constexpr,  # i32 – stride for dst (usually 1)
    src_stride: tl.constexpr,  # i32 – stride for src (usually 1)
    BLOCK_SIZE: tl.constexpr,  # i32 – threads per block
):
    pid = tl.program_id(0)
    start = pid * BLOCK_SIZE
    offs = start + tl.arange(0, BLOCK_SIZE)
    mask = offs < N

    dst = tl.load(dst_ptr + offs * dst_stride, mask=mask)
    src = tl.load(src_ptr + offs * src_stride, mask=mask)

    tl.store(dst_ptr + offs * dst_stride, dst * src, mask=mask)


# ----------------------------------------------------------------------
# Batched GEMM for the O(N³) contraction.
# Computes C = A @ Bᵀ   where A,B: [B·H, N, N]  →  out: [B, N, N, H]
# ----------------------------------------------------------------------
def _batched_matmul_transpose(
    left: torch.Tensor,   # [B, N, N, H]   fp16
    right: torch.Tensor   # [B, N, N, H]   fp16
) -> torch.Tensor:
    B, N, _, H = left.shape

    # Fold the hidden dimension into the batch dimension
    A = left.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)        # [B·H, N, N]
    B_ = right.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)      # [B·H, N, N]

    # GEMM of A with the transpose of B (fast Tensor‑Core implementation)
    C = torch.bmm(A, B_.transpose(1, 2))                               # [B·H, N, N]

    # Restore original shape [B, N, N, H]
    out = C.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()
    return out


# ----------------------------------------------------------------------
# Main entry point used by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul module (no gradients).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, dim] (float32)
        - mask_tensor  : torch.Tensor [B, N, N] (float32, bool or None)
        - weights_dict : name → torch.Tensor (float32, already on the same device)
        - config_dict  : must contain ``dim`` and ``hidden_dim``;
                         optional ``nomask`` (bool, default True).

    Returns
    -------
    torch.Tensor
        Output tensor [B, N, N, dim] (float32, same device as input).
    """
    # -------------------------------------------------
    # 0️⃣ Unpack inputs
    # -------------------------------------------------
    input_tensor, mask_tensor, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    device = input_tensor.device

    # -------------------------------------------------
    # 1️⃣ First LayerNorm (float32 → fp16 for speed)
    # -------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias   = weights["norm.bias"]

    x_norm = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=norm_weight,
        bias=norm_bias,
    )  # [B, N, N, dim]  float32
    x = x_norm.to(torch.float16)  # switch to FP16 for the rest

    # -------------------------------------------------
    # 2️⃣ Cast all linear weights to FP16 once
    # -------------------------------------------------
    # Projection + gate weights are later fused
    left_proj_w   = weights["left_proj.weight"].to(torch.float16)
    left_gate_w   = weights["left_gate.weight"].to(torch.float16)
    right_proj_w  = weights["right_proj.weight"].to(torch.float16)
    right_gate_w  = weights["right_gate.weight"].to(torch.float16)

    out_gate_w    = weights["out_gate.weight"].to(torch.float16)

    to_out_norm_w = weights["to_out_norm.weight"].to(torch.float16)
    to_out_norm_b = weights["to_out_norm.bias"].to(torch.float16)
    to_out_w      = weights["to_out.weight"].to(torch.float16)

    # -------------------------------------------------
    # 3️⃣ Fuse projection & gate (2 linear calls instead of 4)
    # -------------------------------------------------
    #   combined weight shape : (2·H, dim)
    left_comb_w  = torch.cat([left_proj_w, left_gate_w], dim=0)    # (2H, dim)
    right_comb_w = torch.cat([right_proj_w, right_gate_w], dim=0)  # (2H, dim)

    # Linear → [B, N, N, 2·H]
    left_comb  = torch.nn.functional.linear(x, left_comb_w)   # fp16
    right_comb = torch.nn.functional.linear(x, right_comb_w)  # fp16

    # Split back
    left_proj = left_comb[..., :hidden_dim]          # [B,N,N,H]
    left_gate = left_comb[..., hidden_dim:]          # [B,N,N,H]
    right_proj = right_comb[..., :hidden_dim]        # [B,N,N,H]
    right_gate = right_comb[..., hidden_dim:]        # [B,N,N,H]

    # -------------------------------------------------
    # 4️⃣ Optional mask (applied only to the projections)
    # -------------------------------------------------
    if not nomask:
        # mask: [B,N,N] → broadcast over the hidden dimension
        mask_fp16 = mask_tensor.to(torch.float16).unsqueeze(-1)  # [B,N,N,1]
        left_proj = left_proj * mask_fp16
        right_proj = right_proj * mask_fp16

    # -------------------------------------------------
    # 5️⃣ Apply sigmoid gates
    # -------------------------------------------------
    left_gate = torch.sigmoid(left_gate)
    right_gate = torch.sigmoid(right_gate)

    # Apply gates (and keep the result in FP16)
    left = left_proj * left_gate    # [B,N,N,H]
    right = right_proj * right_gate

    # -------------------------------------------------
    # 6️⃣ Heavy O(N³) contraction via a strided‑batched GEMM
    # -------------------------------------------------
    out = _batched_matmul_transpose(left, right)   # [B,N,N,H]  fp16

    # -------------------------------------------------
    # 7️⃣ Second LayerNorm (still FP16)
    # -------------------------------------------------
    out = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=to_out_norm_w,
        bias=to_out_norm_b,
    )  # [B,N,N,H]  fp16

    # -------------------------------------------------
    # 8️⃣ Output gate (sigmoid) + in‑place multiplication (Triton)
    # -------------------------------------------------
    # out_gate = sigmoid(linear(x, out_gate_w))
    out_gate = torch.sigmoid(torch.nn.functional.linear(x, out_gate_w))  # [B,N,N,H]

    # Flatten tensors for the 1‑D Triton kernel
    out_flat = out.contiguous().view(-1)
    gate_flat = out_gate.contiguous().view(-1)
    total_elems = out_flat.numel()

    # Launch Triton kernel (dst ← dst * src)
    BLOCK_SIZE = 1024  # ≤ max threads per block on H100
    grid = ((total_elems + BLOCK_SIZE - 1) // BLOCK_SIZE,)

    _elemwise_mul_kernel[grid](
        out_flat,
        gate_flat,
        total_elems,
        1,          # dst stride
        1,          # src stride
        BLOCK_SIZE=BLOCK_SIZE,
        num_warps=4,
    )

    # -------------------------------------------------
    # 9️⃣ Final linear projection back to `dim`
    # -------------------------------------------------
    out = torch.nn.functional.linear(out, to_out_w)   # [B,N,N,dim]  fp16

    # -------------------------------------------------
    # 🔚 Cast back to float32 (expected output dtype)
    # -------------------------------------------------
    return out.to(torch.float32)
```
