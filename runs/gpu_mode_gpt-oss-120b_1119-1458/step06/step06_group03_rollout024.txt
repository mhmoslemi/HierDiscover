Before coding, understand the problem: TriMul (outgoing) operation consists of:

- Input shape [B, N, N, D], where D = dim.

- Step 1: LayerNorm.

- Step 2: Linear projections to hidden_dim H: left_proj = Linear(D->H, bias=False): shape [B,N,N,H]

- Right_proj similarly.

- Compute left_gate = sigmoid(Linear(D->H)): shape [B,N,N,H], similar for right_gate and out_gate.

- Multiply left * left_gate * mask (if mask present). Right * right_gate * mask.

- Contraction: out[b,i,j,h] = sum_k left[b,i,k,h] * right[b,j,k,h]. This is basically a matrix multiplication per channel: for each hidden channel h (and batch B) we compute left_slice = left[b,:, :, h] shaped [N,N], where dimension axes: i and k; right_slice shaped [N,N] with axes j and k. Out takes i,j axes. But we can think of left as L_i_k, right as R_j_k. Then out_i_j = sum_k L_i_k * R_j_k.

Another way: left: [B,N,N,H], right: [B,N,N,H]; we can compute out via einsum.

Implementation uses torch.bmm on (B*H) batch dimension: left_reshape = left.permute(0,3,1,2) -> shape [B,H,N,N] then view as [B*H,N,N] and right similarly, then compute matmul: left @ right.transpose(-2,-1) yields shape [B*H,N,N], then reshape back.

"""
TriMul (outgoing) – fully fused forward pass.

Algorithm Overview
------------------
1️⃣  First LayerNorm (FP32 for numeric stability) → cast to FP16.
2️⃣  Flatten the tensor and perform **one** large matmul that produces the
    four required linear projections (left_proj, left_gate, right_proj,
    right_gate) in a single operation.  This eliminates three extra matmul
    launches and reduces memory traffic for the input.
3️⃣  Apply sigmoid to the two gate tensors, element‑wise multiply the gates
    with their respective projections and (optionally) broadcast the mask.
    This is done with pure broadcasting – no separate Triton kernel is needed.
4️⃣  Heavy O(N³) contraction:
        out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    is evaluated by a custom Triton batched‑GEMM kernel that works directly
    on the (B,N,N,H) layout, thus avoiding the costly ``permute() + .contiguous()``
    copies required by ``torch.bmm``.  Each hidden channel is treated as a
    separate batch element.
5️⃣  Second LayerNorm (FP16) over the hidden dimension.
6️⃣  Compute the output gate from the normalised input (same as the reference)
    → sigmoid(linear(x)).
7️⃣  Apply the output gate and a final linear projection back to ``dim``.
8️⃣  Cast the result back to FP32 for the harness.

All heavy arithmetic is performed in FP16 (with float32 accumulators inside
the Triton GEMM).  The implementation is self‑contained, supports the
presence/absence of a mask, and runs on NVIDIA H100 (triton 3.3.1).
"""

import torch
import triton
import triton.language as tl
from typing import Tuple, Dict, Any

# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for the Triple‑Mul contraction.
# Input tensors left/right have shape [B, N, N, H] where H is the hidden dim.
# The kernel treats each (batch, hidden) pair as an independent batch
# element and computes:   C[i,j] = Σ_k A[i,k] * B[j,k]   (i,j,k ∈ [0,N)).
# ----------------------------------------------------------------------
@triton.jit
def _batched_gemm_kernel(
    left_ptr,   # *fp16 : left tensor
    right_ptr,  # *fp16 : right tensor
    out_ptr,    # *fp16 : output tensor
    # stride arguments for left, right and output (B, i, k, h)
    stride_left_batch, stride_left_i, stride_left_k, stride_left_h,
    stride_right_batch, stride_right_i, stride_right_k, stride_right_h,
    stride_out_batch, stride_out_i, stride_out_j, stride_out_h,
    N: tl.int32, H: tl.int32,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid_i = tl.program_id(0)      # row‑tile
    pid_j = tl.program_id(1)      # col‑tile
    pid_bh = tl.program_id(2)     # (batch, hidden) tile

    # ------------------------------------------------------------------
    # Derive batch and hidden indices from the flattened batch dimension.
    # ------------------------------------------------------------------
    b = pid_bh // H
    h = pid_bh % H

    # ------------------------------------------------------------------
    # Starting coordinates of the tile.
    # ------------------------------------------------------------------
    i0 = pid_i * BLOCK_M
    j0 = pid_j * BLOCK_N

    # --------------------------------------------------------------
    # Compute 1‑D offsets for this (batch, hidden) pair.
    # --------------------------------------------------------------
    base_left  = b * stride_left_batch  + h * stride_left_h
    base_right = b * stride_right_batch + h * stride_right_h
    base_out   = b * stride_out_batch   + h * stride_out_h

    # ------------------------------------------------------------------
    # Thread‑local ranges (vectorised within the block).
    # ------------------------------------------------------------------
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32 (high‑precision reduction)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # ------------------------------------------------------------------
    # Loop over K dimension in tiles of size BLOCK_K.
    # ------------------------------------------------------------------
    num_k = tl.cdiv(N, BLOCK_K)
    for kk in range(num_k):
        k0 = kk * BLOCK_K
        offs_k = k0 + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # --------------------------------------------------------------
        # Load a tile of left: shape (BLOCK_M, BLOCK_K)
        # --------------------------------------------------------------
        a_ptrs = left_ptr + base_left \
                 + (offs_i[:, None] * stride_left_i) \
                 + (offs_k[None, :] * stride_left_k)
        a = tl.load(a_ptrs, mask=mask_i[:, None] & mask_k[None, :], other=0.0).to(tl.float32)

        # --------------------------------------------------------------
        # Load a tile of right transposed: shape (BLOCK_K, BLOCK_N)
        #   right[b, j, k, h] -> we need B_T[k, j]
        # --------------------------------------------------------------
        b_ptrs = right_ptr + base_right \
                 + (offs_j[None, :] * stride_right_i) \
                 + (offs_k[:, None] * stride_right_k)
        b = tl.load(b_ptrs, mask=mask_j[None, :] & mask_k[:, None], other=0.0).to(tl.float32)

        # --------------------------------------------------------------
        # Block‐wise matrix multiply.
        # --------------------------------------------------------------
        acc += tl.dot(a, b)

    # ------------------------------------------------------------------
    # Write the result back (cast to FP16).
    # ------------------------------------------------------------------
    c = acc.to(tl.float16)
    c_ptrs = out_ptr + base_out \
             + (offs_i[:, None] * stride_out_i) \
             + (offs_j[None, :] * stride_out_j)
    tl.store(c_ptrs, c, mask=mask_i[:, None] & mask_j[None, :])

# ----------------------------------------------------------------------
# Triton wrapper – computes out = Σ_k left[..., i,k,h] * right[..., j,k,h].
# ----------------------------------------------------------------------
def _batched_gemm_triton(left: torch.Tensor, right: torch.Tensor) -> torch.Tensor:
    """
    Arguments
    ---------
    left, right : torch.Tensor
        Shape [B, N, N, H], dtype torch.float16, contiguous.

    Returns
    -------
    out : torch.Tensor
        Shape [B, N, N, H], dtype torch.float16, same layout as inputs.
    """
    B, N, _, H = left.shape
    device = left.device

    # Allocate output tensor (same layout as inputs)
    out = torch.empty_like(left, device=device)

    # Strides (convert to 32‑bit integers for Triton)
    s_left = left.stride()
    s_right = right.stride()
    s_out = out.stride()
    # Cast strides to int32 (required by Triton)
    s_left = [int(x) for x in s_left]
    s_right = [int(x) for x in s_right]
    s_out = [int(x) for x in s_out]

    # Tile sizes – empirically good for H100 (adjustable if needed)
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        (N + BLOCK_M - 1) // BLOCK_M,
        (N + BLOCK_N - 1) // BLOCK_N,
        B * H,
    )
    _batched_gemm_kernel[grid](
        left.data_ptr(),
        right.data_ptr(),
        out.data_ptr(),
        # left strides
        s_left[0], s_left[1], s_left[2], s_left[3],
        # right strides
        s_right[0], s_right[1], s_right[2], s_right[3],
        # out strides
        s_out[0], s_out[1], s_out[2], s_out[3],
        N, H,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
        num_warps=8,  # H100 prefers many warps per block
    )
    return out

# ----------------------------------------------------------------------
# Entry point used by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass of the outgoing TriMul module (no autograd).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor [B, N, N, dim]   (float32)
        - mask_tensor  : torch.Tensor [B, N, N]       (float32/bool)
        - weights_dict : dict name → torch.Tensor (float32)
        - config_dict  : contains ``dim`` and ``hidden_dim``; optional ``nomask``

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, dim] (float32, same device as input).
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask_tensor, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    device = input_tensor.device

    # ------------------------------------------------------------------
    # Load weights (convert to FP16 once)
    # ------------------------------------------------------------------
    # LayerNorm (first)
    norm_weight = weights["norm.weight"].to(device=device, dtype=torch.float32)
    norm_bias   = weights["norm.bias"].to(device=device, dtype=torch.float32)

    # Collect the four linear weights for left/right & gates
    left_proj_w   = weights["left_proj.weight"]   # (hidden, dim)
    right_proj_w  = weights["right_proj.weight"]
    left_gate_w   = weights["left_gate.weight"]
    right_gate_w  = weights["right_gate.weight"]
    # Concatenate for a single matmul: shape (4*hidden, dim)
    combined_w = torch.cat([left_proj_w, left_gate_w,
                            right_proj_w, right_gate_w], dim=0).to(
        device=device, dtype=torch.float16
    )

    # Output gate weight
    out_gate_w = weights["out_gate.weight"].to(device=device, dtype=torch.float16)

    # Second LayerNorm (hidden dim)
    to_out_norm_w = weights["to_out_norm.weight"].to(device=device, dtype=torch.float16)
    to_out_norm_b = weights["to_out_norm.bias"].to(device=device, dtype=torch.float16)

    # Final projection back to dim
    to_out_w = weights["to_out.weight"].to(device=device, dtype=torch.float16)

    # ------------------------------------------------------------------
    # 1️⃣ First LayerNorm (FP32) → cast to FP16
    # ------------------------------------------------------------------
    x_norm = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=norm_weight,
        bias=norm_bias,
    )
    x_fp16 = x_norm.to(torch.float16).contiguous()   # [B, N, N, dim]  FP16

    # ------------------------------------------------------------------
    # 2️⃣ Flatten and single linear projection producing all four tensors.
    # ------------------------------------------------------------------
    B, N, _, _ = x_fp16.shape
    M = B * N * N
    x_flat = x_fp16.view(M, dim)                     # (B·N·N, dim)
    proj_all = torch.nn.functional.linear(x_flat, combined_w)   # (M, 4*H)

    # Split the result
    proj_all = proj_all.view(B, N, N, 4 * hidden_dim)  # (B,N,N,4*H)
    left_proj   = proj_all[..., 0:hidden_dim]
    left_gate_l = proj_all[..., hidden_dim:2*hidden_dim]
    right_proj  = proj_all[..., 2*hidden_dim:3*hidden_dim]
    right_gate_l= proj_all[..., 3*hidden_dim:4*hidden_dim]

    # --------------------------------------------------------------
    # 3️⃣ Gating (sigmoid) and optional mask
    # --------------------------------------------------------------
    left_gate = torch.sigmoid(left_gate_l)
    right_gate = torch.sigmoid(right_gate_l)

    left = left_proj * left_gate
    right = right_proj * right_gate

    if not nomask:
        # mask shape [B, N, N] → broadcast over hidden dimension
        mask_fp16 = mask_tensor.to(torch.float16).unsqueeze(-1).contiguous()
        left = left * mask_fp16
        right = right * mask_fp16

    # ------------------------------------------------------------------
    # 4️⃣ Heavy O(N³) contraction using custom Triton batched GEMM.
    #    This computes out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    # ------------------------------------------------------------------
    out_hidden = _batched_gemm_triton(left, right)    # [B, N, N, hidden]  FP16

    # ------------------------------------------------------------------
    # 5️⃣ Second LayerNorm (FP16) over the hidden dimension.
    # ------------------------------------------------------------------
    out_hidden = torch.nn.functional.layer_norm(
        out_hidden,
        (hidden_dim,),
        weight=to_out_norm_w,
        bias=to_out_norm_b,
    )

    # ------------------------------------------------------------------
    # 6️⃣ Output gate (sigmoid) computed from the normalised input.
    # ------------------------------------------------------------------
    out_gate = torch.sigmoid(torch.nn.functional.linear(x_fp16, out_gate_w))

    # ------------------------------------------------------------------
    # 7️⃣ Apply output gate and final linear projection back to ``dim``.
    # ------------------------------------------------------------------
    out_hidden = out_hidden * out_gate
    out = torch.nn.functional.linear(out_hidden, to_out_w)   # [B, N, N, dim]  FP16

    # ------------------------------------------------------------------
    # 8️⃣ Return FP32 for the harness.
    # ------------------------------------------------------------------
    return out.to(torch.float32)
