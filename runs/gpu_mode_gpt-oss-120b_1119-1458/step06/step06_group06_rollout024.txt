Let's think about an efficient Triton kernel for batched GEMM.

We need to compute out = A @ B^T for each batch element (B*H). Each A, B are square matrices of size N,N.

We can treat each batch element as an independent matrix multiplication. We can parallelize across B*H * N * N.

Triton provides facilities for batched GEMM: Using program_id axis for block indices across M (rows) and N (columns), and then also using program_id_z for batch dimension.

In Triton, program_id axes can be up to 3 axes. So we can define:

- pid0 = tl.program_id(0) -> row tile index

- pid1 = tl.program_id(1) -> column tile index

- pid2 = tl.program_id(2) -> batch index (combined B*H). Then we compute m = pid0*BLOCK_M, n = pid1*BLOCK_N, batch = pid2.

Thus grid = (ceil(N/BLOCK_M), ceil(N/BLOCK_N), B*H).

We then load sub-blocks of A and B conditionally.

"""
TriMul (outgoing) – high‑performance forward implementation.

Algorithm
---------
1. Layer‑norm the input (FP32) → cast to FP16.
2. Fuse the four linear projections (left‑proj, left‑gate, right‑proj,
   right‑gate) into **two** matmuls by concatenating their weight matrices.
   This halves the number of passes over the large (B·N·N) input tensor.
3. Apply sigmoid to the gating branches and fuse the mask, projection and
   gate in a tiny Triton kernel (`mask_gate_fuse_kernel`).  The mask is
   broadcast over the hidden dimension, therefore a single launch per stream.
4. Heavy contraction
   ```
   out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   ```
   is implemented as a batched GEMM (A @ Bᵀ) with a custom Triton kernel.
   The kernel reads the original strided layout `[B,N,N,H]` directly,
   avoiding the costly `permute(...).contiguous()` copies required by
   `torch.bmm`.
5. Second Layer‑norm (FP16) → out‑gate (sigmoid) → final linear projection
   back to the original channel dimension.
6. Cast result to FP32 (the harness expects FP32).

All computations after the first layer‑norm are performed in FP16 while
accumulations are carried out in FP32 for numerical stability.  The code
runs on an H100 with Triton 3.3.1 and satisfies the required signature.
"""

import torch
import triton
import triton.language as tl
from typing import Tuple, Dict, Any

# ----------------------------------------------------------------------
# Triton kernel: fuse (proj * gate * mask) – mask is broadcast over the
# hidden dimension.  Operates on a flat view of a contiguous tensor
# of shape [B, N, N, H] (size = B·N·N·H).
# ----------------------------------------------------------------------
@triton.jit
def mask_gate_fuse_kernel(
    proj_ptr,          # *fp16 : projection tensor to be updated
    gate_ptr,          # *fp16 : gate tensor (already sigmoid-ed)
    mask_ptr,          # *fp16 : mask tensor of shape (B·N·N,)
    total_elements,    # i32   : total number of elements in proj_ptr
    hidden_dim,        # i32   : width of the hidden dimension (H)
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(0)                     # block index
    offs = pid * BLOCK + tl.arange(0, BLOCK)   # linear offsets handled by this block
    mask_bounds = offs < total_elements        # guard for the tail of the tensor

    # Load the tensors
    proj = tl.load(proj_ptr + offs, mask=mask_bounds, other=0.0)
    gate = tl.load(gate_ptr + offs, mask=mask_bounds, other=0.0)

    # Mask is broadcast over the hidden dimension: every `hidden_dim` elements
    # belong to the same (b,i,k) location.
    mask_idx = offs // hidden_dim
    mask = tl.load(mask_ptr + mask_idx, mask=mask_bounds, other=1.0)

    # Fused multiplication
    out = proj * gate * mask

    # Store the result back in‑place
    tl.store(proj_ptr + offs, out, mask=mask_bounds)


# ----------------------------------------------------------------------
# Triton kernel: batched GEMM for the O(N³) contraction.
# Computes out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d].
# Operates directly on the strided 4‑D tensors without any reshapes.
# ----------------------------------------------------------------------
@triton.jit
def batched_gemm_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,                                 # tensor sizes
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # Program IDs
    pid_m = tl.program_id(0)                  # tile row (i)
    pid_n = tl.program_id(1)                  # tile col (j)
    pid_bh = tl.program_id(2)                 # combined batch * hidden index

    # Decode batch index `b` and hidden channel index `h`
    b = pid_bh // H
    h = pid_bh % H

    # Tile offsets
    i0 = pid_m * BLOCK_M
    j0 = pid_n * BLOCK_N
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)

    # Masks for the i/j edges
    mask_i = offs_i < N
    mask_j = offs_j < N

    # Accumulator (FP32)
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Iterate over the reduction dimension k
    num_k = tl.cdiv(N, BLOCK_K)
    for kk in range(num_k):
        k0 = kk * BLOCK_K
        offs_k = k0 + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # ---------- left tile (M × K) ----------
        # left[b, i, k, h]  -> offsets: i * stride_i + k * stride_k + h
        a_ptrs = (
            left_ptr
            + b * stride_left_b
            + h * stride_left_h
            + offs_i[:, None] * stride_left_i
            + offs_k[None, :] * stride_left_k
        )
        a = tl.load(
            a_ptrs,
            mask=mask_i[:, None] & mask_k[None, :],
            other=0.0,
        ).to(tl.float16)

        # ---------- right tile transposed (K × N) ----------
        # right[b, j, k, h] accessed as Bᵀ: rows = k, cols = j
        b_ptrs = (
            right_ptr
            + b * stride_right_b
            + h * stride_right_h
            + offs_k[:, None] * stride_right_k
            + offs_j[None, :] * stride_right_i
        )
        b = tl.load(
            b_ptrs,
            mask=mask_k[:, None] & mask_j[None, :],
            other=0.0,
        ).to(tl.float16)

        # Matrix multiply for this K‑block
        acc += tl.dot(a, b)                     # (M,K) @ (K,N) → (M,N)

    # Write the result back (FP16)
    out_ptrs = (
        out_ptr
        + b * stride_out_b
        + h * stride_out_h
        + offs_i[:, None] * stride_out_i
        + offs_j[None, :] * stride_out_j
    )
    out_val = acc.to(tl.float16)
    tl.store(
        out_ptrs,
        out_val,
        mask=mask_i[:, None] & mask_j[None, :],
    )

# Entry point called by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(
    data: Tuple[torch.Tensor, torch.Tensor, Dict[str, torch.Tensor], Dict[str, Any]]
) -> torch.Tensor:
    """
    Forward pass for the outgoing TriMul operator.
    """
    # --------------------------- unpack inputs ---------------------------
    input_tensor, mask_tensor, weights, config = data
    dim        = config["dim"]               # input channel dimension (c_z)
    hidden_dim = config["hidden_dim"]        # projection width (c)
    nomask     = config.get("nomask", True)  # True → ignore the mask

    device = input_tensor.device

    # ----------------- 1️⃣ First LayerNorm (FP32) → FP16 -----------------
    x = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    ).half()                                 # [B, N, N, dim]  fp16

    # -------------------- 2️⃣ Cast model weights to FP16 -----------------
    # Concatenate left/right projection + gate weights into two big matrices
    left_proj_w   = weights["left_proj.weight"].half()
    left_gate_w   = weights["left_gate.weight"].half()
    right_proj_w  = weights["right_proj.weight"].half()
    right_gate_w  = weights["right_gate.weight"].half()
    combined_lr_weight = torch.cat(
        [left_proj_w, left_gate_w, right_proj_w, right_gate_w], dim=0
    )                                          # shape [4*H, dim]

    out_gate_w    = weights["out_gate.weight"].half()
    to_out_norm_w = weights["to_out_norm.weight"].half()
    to_out_norm_b = weights["to_out_norm.bias"].half()
    to_out_w      = weights["to_out.weight"].half()

    # ---------------------- 3️⃣ Combined linear ----------------------
    # Produce projection & gate tensors for both sides in a single matmul
    # Shape after linear: [B, N, N, 4*H]
    combined = torch.nn.functional.linear(x, combined_lr_weight)

    # Slice the combined tensor
    hs = hidden_dim
    left_proj  = combined[..., 0:hs]                     # proj   (L)
    left_gate_raw = combined[..., hs:2*hs]               # gate   (L)
    right_proj = combined[..., 2*hs:3*hs]                # proj   (R)
    right_gate_raw = combined[..., 3*hs:4*hs]            # gate   (R)

    left_gate  = torch.sigmoid(left_gate_raw)
    right_gate = torch.sigmoid(right_gate_raw)

    # ------------------- 4️⃣ Out‑gate (sigmoid) -------------------
    out_gate = torch.sigmoid(torch.nn.functional.linear(x, out_gate_w))

    # ------------------- 5️⃣ Mask‑gate fusion (Triton) -----------------
    if nomask:
        left  = left_proj * left_gate
        right = right_proj * right_gate
    else:
        # ensure contiguous tensors for the Triton kernel
        left_proj   = left_proj.contiguous()
        left_gate   = left_gate.contiguous()
        right_proj  = right_proj.contiguous()
        right_gate  = right_gate.contiguous()
        mask_fp16   = mask_tensor.to(torch.float16).contiguous().view(-1)  # (B·N·N,)

        total_elems = left_proj.numel()                     # B·N·N·H
        BLOCK = 1024
        grid = ((total_elems + BLOCK - 1) // BLOCK,)

        # Fuse proj * gate * mask for the left stream (in‑place)
        mask_gate_fuse_kernel[grid](
            left_proj,
            left_gate,
            mask_fp16,
            total_elems,
            hidden_dim,
            BLOCK=BLOCK,
            num_warps=4,
        )
        # Fuse proj * gate * mask for the right stream (in‑place)
        mask_gate_fuse_kernel[grid](
            right_proj,
            right_gate,
            mask_fp16,
            total_elems,
            hidden_dim,
            BLOCK=BLOCK,
            num_warps=4,
        )
        left, right = left_proj, right_proj

    # ------------------- 6️⃣ Heavy contraction (Triton GEMM) -------------------
    batch, seq_len, _, _ = left.shape
    out = torch.empty_like(left)  # allocate [B, N, N, H] fp16

    # Strides – note they are integer values (in elements, not bytes)
    sL_b, sL_i, sL_k, sL_h = left.stride()
    sR_b, sR_i, sR_k, sR_h = right.stride()
    sO_b, sO_i, sO_j, sO_h = out.stride()

    # Tile sizes – tuned for H100 (you may adjust if needed)
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    grid = (
        (seq_len + BLOCK_M - 1) // BLOCK_M,
        (seq_len + BLOCK_N - 1) // BLOCK_N,
        batch * hidden_dim,
    )
    batched_gemm_kernel[grid](
        left_ptr=left,
        right_ptr=right,
        out_ptr=out,
        B=batch,
        N=seq_len,
        H=hidden_dim,
        stride_left_b=sL_b,
        stride_left_i=sL_i,
        stride_left_k=sL_k,
        stride_left_h=sL_h,
        stride_right_b=sR_b,
        stride_right_i=sR_i,
        stride_right_k=sR_k,
        stride_right_h=sR_h,
        stride_out_b=sO_b,
        stride_out_i=sO_i,
        stride_out_j=sO_j,
        stride_out_h=sO_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,
    )
    # ------------------------------------------------------------------
    # 7️⃣ Second LayerNorm (FP16)
    # ------------------------------------------------------------------
    out = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=to_out_norm_w,
        bias=to_out_norm_b,
    )
    # 8️⃣ Out‑gate multiplication + final projection back to `dim`
    out = out * out_gate
    out = torch.nn.functional.linear(out, to_out_w)

    # 9️⃣ Cast back to FP32 for the harness
    return out.float()
