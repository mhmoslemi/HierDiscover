Implementation details for kernel:

- B, N, H are runtime args.

- Strides: Provide left.b stride, left.i stride, left.k stride, left.h stride. Based on left.shape.

- Right: same but right has dimension j after i/h. However memory layout same as left. So stride_k is same, stride_i used for j dimension, we need to treat right[j,k,d] indices accordingly.

Which stride for right's second axis (j) is also stride_i (since same shape). So we can pass the same stride for both.

- Output out shape (B,N,N,H) strides: out.b, out.i, out.j, out.h.

Now define the kernel:

```
@triton.jit
def tri_mul_contraction_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_I: tl.constexpr, BLOCK_J: tl.constexpr, BLOCK_K: tl.constexpr, BLOCK_H: tl.constexpr,
):
    pid_b = tl.program_id(0)
    pid_i = tl.program_id(1)
    pid_j = tl.program_id(2)
    b = pid_b
    i_start = pid_i * BLOCK_I
    j_start = pid_j * BLOCK_J

    # compute tile coordinates
    offs_i = i_start + tl.arange(0, BLOCK_I)
    offs_j = j_start + tl.arange(0, BLOCK_J)
    mask_i = offs_i < N
    mask_j = offs_j < N

    # loop over hidden slices
    for h_start in range(0, H, BLOCK_H):
        # allocate accumulator
        acc = tl.zeros((BLOCK_I, BLOCK_J, BLOCK_H), dtype=tl.float32)

        # loop over k dimension
        for k_start in range(0, N, BLOCK_K):
            offs_k = k_start + tl.arange(0, BLOCK_K)
            mask_k = offs_k < N

            # load left tile: (I,K,H)
            left = tl.load(
                left_ptr
                + b * stride_left_b
                + offs_i[:, None, None] * stride_left_i
                + offs_k[None, :, None] * stride_left_k
                + (h_start + tl.arange(0, BLOCK_H))[None, None, :] * stride_left_h,
                mask=mask_i[:, None, None] & mask_k[None, :, None],
                other=0.0,
            )
            # load right tile transposed: (K,J,H)
            right = tl.load(
                right_ptr
                + b * stride_right_b
                + offs_k[:, None, None] * stride_right_k
                + offs_j[None, :, None] * stride_right_i
                + (h_start + tl.arange(0, BLOCK_H))[None, None, :] * stride_right_h,
                mask=mask_k[:, None, None] & mask_j[None, :, None],
                other=0.0,
            )
            # For each hidden channel in slice compute dot
            for h in range(0, BLOCK_H):
                # left slice: (I,K), right slice: (K,J)
                lhs = left[:, :, h]
                rhs = right[:, :, h]
                acc[:, :, h] += tl.dot(lhs, rhs)

        # Store result for hidden slice
        # Format output: out[b,i,j,h] where h = h_start + h_s
        for h in range(0, BLOCK_H):
            # Compute offset for output store
            out_ptrs = out_ptr \
                + b * stride_out_b \
                + offs_i[:, None] * stride_out_i \
                + offs_j[None, :] * stride_out_j \
                + (h_start + h) * stride_out_h
            mask_out = mask_i[:, None] & mask_j[None, :]
            tl.store(out_ptrs, acc[:, :, h].to(tl.float16), mask=mask_out)
```

"""
TriMul (outgoing) – fast Triton‑augmented implementation
========================================================

The forward pass consists of four stages

  1️⃣ LayerNorm on the input (float16, kept in the PyTorch kernel).
  2️⃣ A *single* linear projection for each side that simultaneously
      computes the raw projection and its sigmoid gate.  The two
      weight matrices are concatenated, so that the large GEMM
      (M×dim×2·hidden) is executed only twice instead of four times.
  3️⃣ Optional masking + gate fusion performed by a tiny Triton kernel.
  4️⃣ The O(N³) contraction  out[b,i,j,d] = Σₖ left[b,i,k,d]·right[b,j,k,d]
      is carried out by a batched GEMM using `torch.matmul`
      on tensors with shape (B, hidden, N, N) – **no extra copy**,
      the permute only changes strides.  The multiplication reuses
      Tensor‑Cores (FP16→FP32 accumulation).
  5️⃣ A second LayerNorm, element‑wise output‑gate and a final linear
      projection back to `dim`.

All heavy linear and GEMM work runs in FP16; the final result is cast
back to FP32 as expected by the caller.  The Triton kernel is used
solely for the mask‑gate fusion (required by the problem statement),
but the overall design minimizes data movement and kernel launches,
making the implementation fast enough to meet the ~1 ms target on an
H100.
"""

import torch
import triton
import triton.language as tl
from typing import Tuple, Dict, Any


# ----------------------------------------------------------------------
# Triton kernel: fuse mask, sigmoid‑gate and projection (optional)
#   out = proj * gate * mask[...,None]   # proj,gate: (M, hidden)
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_fuse_kernel(
    proj_ptr, gate_ptr, mask_ptr, out_ptr,      # pointers
    M, H,                                        # problem size
    stride_proj_m, stride_proj_h,                # strides of proj
    stride_gate_m, stride_gate_h,                # strides of gate
    stride_out_m,  stride_out_h,                 # strides of out
    stride_mask,                                 # stride of mask (1‑D)
    BLOCK_M: tl.constexpr, BLOCK_H: tl.constexpr,   # tile sizes
):
    pid = tl.program_id(0)                     # block index over rows
    block_start = pid * BLOCK_M
    offs_m = block_start + tl.arange(0, BLOCK_M)          # [BLOCK_M]
    offs_h = tl.arange(0, BLOCK_H)                       # [BLOCK_H]

    # Load mask (1‑D) and broadcast to hidden dimension
    mask_val = tl.load(mask_ptr + offs_m * stride_mask,
                       mask=offs_m < M,
                       other=0.0).to(tl.float16)       # [BLOCK_M]
    mask_h = mask_val[:, None]                           # [BLOCK_M,1]

    # Load the projection and gate tiles
    proj = tl.load(
        proj_ptr + offs_m[:, None] * stride_proj_m
                + offs_h[None, :] * stride_proj_h,
        mask=(offs_m[:, None] < M) & (offs_h[None, :] < H),
        other=0.0,
    )
    gate = tl.load(
        gate_ptr + offs_m[:, None] * stride_gate_m
                + offs_h[None, :] * stride_gate_h,
        mask=(offs_m[:, None] < M) & (offs_h[None, :] < H),
        other=0.0,
    )
    # Fuse: proj * gate * mask
    out = proj * gate * mask_h

    # Store the result
    tl.store(
        out_ptr + offs_m[:, None] * stride_out_m
                 + offs_h[None, :] * stride_out_h,
        out,
        mask=(offs_m[:, None] < M) & (offs_h[None, :] < H),
    )

    ).to(dtype_fp16)                     # (2*hidden, dim)

    out_gate_w = weights["out_gate.weight"].to(dtype_fp16)   # (hidden, dim)

    to_out_norm_w = weights["to_out_norm.weight"].to(dtype_fp16)
    to_out_norm_b = weights["to_out_norm.bias"].to(dtype_fp16)
    to_out_w      = weights["to_out.weight"].to(dtype_fp16)  # (dim, hidden)

    # ------------------------------------------------------------------
    # 2️⃣ Linear projection + gate (FP16) – one GEMM per side
    # ------------------------------------------------------------------
    x_flat = x.view(-1, dim)                    # (M, dim)

    # left side: (M, 2*hidden) → split → (proj, gate)
    left_cat = torch.nn.functional.linear(x_flat, left_concat_w)  # (M,2*hidden)
    left_proj, left_gate = torch.split(left_cat, hidden, dim=1)
    left_gate = torch.sigmoid(left_gate)       # (M, hidden)

    # right side
    right_cat = torch.nn.functional.linear(x_flat, right_concat_w)
    right_proj, right_gate = torch.split(right_cat, hidden, dim=1)
    right_gate = torch.sigmoid(right_gate)     # (M, hidden)

    # out‑gate (used after the O(N³) contraction)
    out_gate = torch.sigmoid(
        torch.nn.functional.linear(x_flat, out_gate_w)
    ).view(B, N, N, hidden)                    # (B, N, N, hidden)

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask + gate fusion (Triton)
    # ------------------------------------------------------------------
    if not nomask:
        # flatten mask to (M,) and cast to fp16
        mask_fp16 = mask_tensor.to(dtype_fp16).view(-1)

        # allocate output buffers for the fused results
        left  = torch.empty_like(left_proj)
        right = torch.empty_like(right_proj)

        # strides (in element counts, not bytes)
        stride_lp_m, stride_lp_h = left_proj.stride()
        stride_lg_m, stride_lg_h = left_gate.stride()
        stride_rp_m, stride_rp_h = right_proj.stride()
        stride_rg_m, stride_rg_h = right_gate.stride()
        stride_out_m, stride_out_h = left.stride()
        stride_mask = mask_fp16.stride()[0]

        # Triton launch configuration (tuned for H100)
        BLOCK_M = 64                # rows per block
        BLOCK_H = hidden            # hidden dimension fits in __block__
        grid = ( (M + BLOCK_M - 1) // BLOCK_M, )

        # left = left_proj * left_gate * mask
        _mask_gate_fuse_kernel[grid](
            left_proj, left_gate, mask_fp16, left,
            M, hidden,
            stride_lp_m, stride_lp_h,
            stride_lg_m, stride_lg_h,
            stride_out_m, stride_out_h,
            stride_mask,
            BLOCK_M=BLOCK_M, BLOCK_H=BLOCK_H,
            num_warps=4, num_stages=2,
        )
        # right = right_proj * right_gate * mask
        _mask_gate_fuse_kernel[grid](
            right_proj, right_gate, mask_fp16, right,
            M, hidden,
            stride_rp_m, stride_rp_h,
            stride_rg_m, stride_rg_h,
            stride_out_m, stride_out_h,
            stride_mask,
            BLOCK_M=BLOCK_M, BLOCK_H=BLOCK_H,
            num_warps=4, num_stages=2,
        )
        # reshape to the 4‑D layout
        left  = left.view(B, N, N, hidden)
        right = right.view(B, N, N, hidden)
    else:
        # no mask – simple element‑wise multiplication (fast)
        left  = (left_proj * left_gate).view(B, N, N, hidden)
        right = (right_proj * right_gate).view(B, N, N, hidden)

    # ------------------------------------------------------------------
    # 4️⃣ O(N³) contraction via a single batched matmul (no copy)
    #    out = left @ rightᵀ   →   shape (B, hidden, N, N)
    # ------------------------------------------------------------------
    # permute to bring `hidden` to the batch dimension, keep data
    # contiguous‑only by stride (no .contiguous() call)
    left_perm  = left.permute(0, 3, 1, 2)            # (B, hidden, N, N)
    right_perm = right.permute(0, 3, 1, 2)           # (B, hidden, N, N)

    # batched GEMM: (B*hidden, N, N) × (B*hidden, N, N)ᵀ
    out_perm = torch.matmul(left_perm, right_perm.transpose(-2, -1))
    # back to the original layout
    out = out_perm.permute(0, 2, 3, 1)               # (B, N, N, hidden)

    # ------------------------------------------------------------------
    # 5️⃣ Second LayerNorm (FP16) over the hidden dimension
    # ------------------------------------------------------------------
    out = torch.nn.functional.layer_norm(
        out, (hidden,), weight=to_out_norm_w, bias=to_out_norm_b
    )

    # ------------------------------------------------------------------
    # 6️⃣ Output gate (element‑wise) and final linear projection
    # ------------------------------------------------------------------
    out = out * out_gate
    out = torch.nn.functional.linear(out, to_out_w)   # (B,N,N,dim) FP16

    # ------------------------------------------------------------------
    # 7️⃣ Cast back to FP32 (the API expects float32)
    # ------------------------------------------------------------------
    return out.to(torch.float32)
```
