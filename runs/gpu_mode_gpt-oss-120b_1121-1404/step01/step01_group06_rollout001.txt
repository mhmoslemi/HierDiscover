TriMul “outgoing” forward‑pass (AlphaFold3) – high‑performance Triton implementation.

Algorithm
---------
1. **Input LayerNorm** – standard torch.nn.functional.layer_norm.
2. **Linear projections** – four linear layers (left_proj, right_proj,
   left_gate, right_gate) are computed with torch.nn.functional.linear.
   The three gating tensors (left_gate, right_gate, out_gate) are passed
   through a sigmoid.
3. **Fused gating + mask** – a tiny Triton kernel fuses the three
   element‑wise operations that dominate memory traffic:
       left  = (left_proj  * sigmoid(left_gate )) * mask
       right = (right_proj * sigmoid(right_gate)) * mask
   The kernel works on a flattened view of the (B, N, N) grid and
   processes the hidden dimension in chunks (BLOCK_H).  It also handles
   the “no‑mask” case efficiently by broadcasting a constant 1.0.
4. **Batched GEMM over the hidden dimension** – after the gating step we
   have tensors `left` and `right` of shape [B, N, N, H].  By reshaping
   to (B*H, N, N) we can reuse cuBLAS via a single call to
   `torch.bmm(left_perm, right_perm.transpose(1, 2))`.  This is the
   O(N³·H) reduction.
5. **Output LayerNorm, gating and projection** – the result is layer‑
   normalized, multiplied element‑wise by the `out_gate` tensor and
   finally projected back to the original feature dimension with a
   bias‑free linear layer (`to_out`).

All heavy element‑wise work (steps 3) is performed on the GPU with
Triton, while the large matrix multiplications (step 4) use cuBLAS,
which gives the best possible performance on an H100.  The code
supports both masked and un‑masked inputs, arbitrary batch sizes (B ∈ {1,2}),
sequence lengths up to 1024, and hidden dimensions that are not a
multiple of the block size.

The final output is always float32, regardless of the input precision.

# Triton kernel: fused gating + mask

    stride_mask_b, stride_mask_i, stride_mask_j,

        left_out  = left_proj  * left_gate  * mask
        right_out = right_proj * right_gate * mask
    where mask is broadcasted over the hidden dimension.
    """
    pid = tl.program_id(0)                     # linear program id
    row_start = pid * BLOCK_ROW
    row_idx = row_start + tl.arange(0, BLOCK_ROW)   # [BLOCK_ROW]
    row_valid = row_idx < B * N * N

    # decode flattened index into (b,i,j)
    b = row_idx // (N * N)
    rem = row_idx % (N * N)
    i = rem // N
    j = rem % N

    # base address for each tensor (no hidden dimension yet)
    lp_base = b * stride_lp_b + i * stride_lp_i + j * stride_lp_j
    rp_base = b * stride_rp_b + i * stride_rp_i + j * stride_rp_j
    lg_base = b * stride_lg_b + i * stride_lg_i + j * stride_lg_j
    rg_base = b * stride_rg_b + i * stride_rg_i + j * stride_rg_j
    mask_base = b * stride_mask_b + i * stride_mask_i + j * stride_mask_j

    # load mask scalar (scalar per (b,i,j)).  If mask is all‑ones we still
    # load a constant 1.0, which the compiler can fold.
    mask_scalar = tl.load(mask_ptr + mask_base,
                          mask=row_valid, other=1.0)   # [BLOCK_ROW]

    # iterate over hidden dimension
    for h_off in range(0, H, BLOCK_H):
        # hidden indices for this block (may be out‑of‑bounds)
        h_idx = h_off + tl.arange(0, BLOCK_H)
        h_mask = h_idx < H

        # combine row mask with hidden mask -> shape [BLOCK_ROW, BLOCK_H]
        active = row_valid[:, None] & h_mask[None, :]

        # pointers with hidden offset
        lp_ptr = left_proj_ptr + lp_base[:, None] + h_idx[None, :] * stride_lp_h
        rp_ptr = right_proj_ptr + rp_base[:, None] + h_idx[None, :] * stride_rp_h
        lg_ptr = left_gate_ptr + lg_base[:, None] + h_idx[None, :] * stride_lg_h
        rg_ptr = right_gate_ptr + rg_base[:, None] + h_idx[None, :] * stride_rg_h

        # loads (zero for out‑of‑bounds elements)
        lp = tl.load(lp_ptr, mask=active, other=0.0)   # [BLOCK_ROW, BLOCK_H]
        rp = tl.load(rp_ptr, mask=active, other=0.0)
        lg = tl.load(lg_ptr, mask=active, other=0.0)
        rg = tl.load(rg_ptr, mask=active, other=0.0)

        # broadcast mask scalar across hidden dimension
        mask_vec = mask_scalar[:, None]                # [BLOCK_ROW, 1]

        # fused element‑wise computation
        left_res  = lp * lg * mask_vec
        right_res = rp * rg * mask_vec

        # store results
        tl.store(left_out_ptr  + lp_base[:, None] + h_idx[None, :] * stride_lp_h,
                 left_res, mask=active)
        tl.store(right_out_ptr + rp_base[:, None] + h_idx[None, :] * stride_rp_h,
                 right_res, mask=active)

# --------------------------------------------------------------------------- #
# Entry point
# --------------------------------------------------------------------------- #
def custom_kernel(data):
    """
    TritMul “outgoing” forward pass.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

        - input_tensor : torch.Tensor, shape [B, N, N, dim]
        - mask_tensor  : torch.Tensor, shape [B, N, N]   (may be None)
        - weights_dict : mapping of weight names to torch.Tensors
        - config_dict  : contains at least ``dim`` and ``hidden_dim`` and
                         optionally ``nomask`` (bool)

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32).
    """
    # ------------------------------------------------------------------- #
    # unpack arguments
    # ------------------------------------------------------------------- #
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    bs, seq_len, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", False)

    # ------------------------------------------------------------------- #
    # Ensure mask exists and has proper dtype
    # ------------------------------------------------------------------- #
    if mask is None or nomask:
        mask = torch.ones((bs, seq_len, seq_len), dtype=dtype, device=device)
    else:
        mask = mask.to(dtype)

    # ------------------------------------------------------------------- #
    # Load model parameters
    # ------------------------------------------------------------------- #
    norm_weight = weights["norm.weight"]
    norm_bias   = weights["norm.bias"]
    left_proj_weight  = weights["left_proj.weight"]   # (hidden_dim, dim)
    right_proj_weight = weights["right_proj.weight"]
    left_gate_weight  = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight   = weights["out_gate.weight"]
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias   = weights["to_out_norm.bias"]
    to_out_weight      = weights["to_out.weight"]      # (dim, hidden_dim)

    # ------------------------------------------------------------------- #
    # 1. Input LayerNorm
    # ------------------------------------------------------------------- #
    x = F.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias)

    # ------------------------------------------------------------------- #
    # 2. Linear projections (no bias) – we keep them in the original dtype
    #    but promote to fp16 if the model runs in half precision.
    # ------------------------------------------------------------------- #
    # NOTE: torch.nn.functional.linear is already highly optimized (cuBLAS)
    left_proj  = F.linear(x, left_proj_weight)    # [B,N,N,hidden_dim]
    right_proj = F.linear(x, right_proj_weight)

    left_gate_pre  = F.linear(x, left_gate_weight)   # pre‑sigmoid
    right_gate_pre = F.linear(x, right_gate_weight)

    left_gate  = torch.sigmoid(left_gate_pre)
    right_gate = torch.sigmoid(right_gate_pre)

    out_gate = torch.sigmoid(F.linear(x, out_gate_weight))

    # ------------------------------------------------------------------- #
    # 3. Fuse gating + mask with Triton
    # ------------------------------------------------------------------- #
    # Allocate output tensors for the gated & masked values
    left  = torch.empty_like(left_proj)
    right = torch.empty_like(right_proj)

    # Strides in element counts (not bytes)
    lp_str = left_proj.stride()   # (B, N, N, H)
    rp_str = right_proj.stride()
    lg_str = left_gate.stride()
    rg_str = right_gate.stride()
    mask_str = mask.stride()

    # Triton launch configuration
    total_rows = bs * seq_len * seq_len          # B * N * N
    BLOCK_ROW = 128   # rows per program – tuned for H100
    BLOCK_H   = 32    # hidden dim chunk – must divide hidden_dim moderately
    grid = (triton.cdiv(total_rows, BLOCK_ROW),)

    _fused_gate_mask_kernel[grid](
        # input pointers
        left_proj_ptr   = left_proj,
        right_proj_ptr  = right_proj,
        left_gate_ptr   = left_gate,
        right_gate_ptr  = right_gate,
        mask_ptr        = mask,
        # output pointers
        left_out_ptr    = left,
        right_out_ptr   = right,
        # strides (elements)
        stride_lp_b=lp_str[0], stride_lp_i=lp_str[1], stride_lp_j=lp_str[2], stride_lp_h=lp_str[3],
        stride_rp_b=rp_str[0], stride_rp_i=rp_str[1], stride_rp_j=rp_str[2], stride_rp_h=rp_str[3],
        stride_lg_b=lg_str[0], stride_lg_i=lg_str[1], stride_lg_j=lg_str[2], stride_lg_h=lg_str[3],
        stride_rg_b=rg_str[0], stride_rg_i=rg_str[1], stride_rg_j=rg_str[2], stride_rg_h=rg_str[3],
        stride_mask_b=mask_str[0], stride_mask_i=mask_str[1], stride_mask_j=mask_str[2],
        # problem sizes
        B=bs, N=seq_len, H=hidden_dim,
        # compile‑time constants
        BLOCK_ROW=BLOCK_ROW, BLOCK_H=BLOCK_H,
    )

    # ------------------------------------------------------------------- #
    # 4. Batched GEMM across the hidden dimension
    #    out_h = left_h @ right_hᵀ   for every hidden head h
    # ------------------------------------------------------------------- #
    # Permute to [B, H, N, N] and collapse B*H for a single bmm call
    left_perm  = left.permute(0, 3, 1, 2).reshape(bs * hidden_dim, seq_len, seq_len)
    right_perm = right.permute(0, 3, 1, 2).reshape(bs * hidden_dim, seq_len, seq_len)

    # rightᵀ: transpose the last two axes
    out_mat = torch.bmm(left_perm, right_perm.transpose(1, 2))   # [B*H, N, N]

    # Restore original layout: [B, N, N, H]
    out = out_mat.view(bs, hidden_dim, seq_len, seq_len).permute(0, 2, 3, 1)

    # ------------------------------------------------------------------- #
    # 5. Output LayerNorm + gating
    # ------------------------------------------------------------------- #
    out = F.layer_norm(out, (hidden_dim,), weight=to_out_norm_weight, bias=to_out_norm_bias)
    out = out * out_gate

    # ------------------------------------------------------------------- #
    # 6. Final linear projection back to dim (bias‑free)
    # ------------------------------------------------------------------- #
    out = F.linear(out, to_out_weight)   # shape [B, N, N, dim]

    # Ensure final dtype is float32 as required by the spec
    if out.dtype != torch.float32:
        out = out.to(torch.float32)

    return out
