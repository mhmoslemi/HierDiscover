Propose a step‑function (non‑negative heights) that minimises
evaluate_sequence().

Algorithm
---------
*   Parameterise the sequence as a soft‑max of unrestricted logits `x`:
        a_i = exp(x_i) / Σ_j exp(x_j)   (guarantees a_i ≥ 0, Σa_i = 1).
*   Approximate the true ℓ∞‑objective `max_k (a∗a)_k` by a smooth
    soft‑max:   f_β(a) = (1/β)·log Σ_k exp(β·(a∗a)_k).
    For β → ∞ the surrogate approaches the true max.
*   A continuation schedule drives β from a modest value (≈5) to a large
    one (≈3000) so that early iterations enjoy smooth gradients while
    later iterations focus on the true peak.
*   Gradients are obtained analytically:
        ∂f_β/∂a = 2·(a ⋆ w)   where   w_k ∝ exp(β·(a∗a)_k)
    (⋆ = correlation).  The chain rule yields the gradient w.r.t. the
    logits `x` using the Jacobian of the soft‑max.
*   Adam (adaptive‑momentum) updates the logits.  Learning‑rate and β
    are linearly annealed with elapsed time.
*   To avoid stagnation we inject occasional random jitter on `x` and
    a block‑wise multiplicative perturbation, and we restart from the
    current best solution if no improvement occurs for 120 s.
*   The best vector found during the run is returned (clipped to the
    limits enforced by `evaluate_sequence`).

The routine respects the 1000 s budget, prints progress stamps and
finally yields the candidate sequence.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: smallest power‑of‑two length that can hold the full linear
# convolution of two vectors of length n (i.e. length 2·n‑1).
# ----------------------------------------------------------------------
def _fft_len_for_n(n: int) -> int:
    size = 2 * n - 1
    return 1 << ((size - 1).bit_length())


# ----------------------------------------------------------------------
# Linear self‑convolution via FFT (returns length 2·len(a)‑1).
# ----------------------------------------------------------------------
def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)[: 2 * a.size - 1]
    return conv


# ----------------------------------------------------------------------
# Correlation a ⋆ w (used for the gradient of Σ w_k·(a∗a)_k).
# Returns a vector of length len(a); the correlation is computed via
# FFT of a reversed and w.
# ----------------------------------------------------------------------
def _grad_corr(a: np.ndarray, w: np.ndarray, fft_len_corr: int) -> np.ndarray:
    # convolution of a_rev and w gives the correlation a ⋆ w
    fw = np.fft.rfft(w, n=fft_len_corr)
    fa_rev = np.fft.rfft(a[::-1], n=fft_len_corr)
    corr_full = np.fft.irfft(fw * fa_rev, n=fft_len_corr)[: 3 * a.size - 2]
    # extract the central part (indices n‑1 … 2n‑2) which corresponds to
    # shifts 0 … n‑1
    start = a.size - 1
    return 2.0 * corr_full[start:start + a.size]
