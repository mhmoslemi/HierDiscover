Propose a deterministic low‑score step‑function.

The evaluation function is
    score = 2·n·max(conv(a,a)) / (sum(a)^2)

and it is scale‑invariant.
For a sequence a_i ≥ 0 with ∑a_i = 1 the dominant term of
max(conv) is the autocorrelation at shift n‑1:
    b_{n‑1} = Σ a_i·a_{n‑1‑i}.

If we choose a decreasing power‑law
    a_i ∝ (n‑i)^p ,     i = 0,…,n‑1
then (for large n)

    a_0 ≈ (p+1)/n ,      a_0² ≈ (p+1)² / n²
    b_{n‑1} ≈ (p+1)²·B(p+1,p+1) / n,
where B is the Beta‑function.
When p is small, b_{n‑1} dominates; when p is larger,
a_0² dominates.  The crossover occurs near  B(p+1,p+1) ≈ 1/n.
For the usual budget (n≈ few‑ten‑thousands) the optimal integer
p is 6, giving a score ≈ 2·(p+1)² / n = 98 / n,
which can be made arbitrarily small by increasing n.

The function below builds such a power‑law sequence (p = 6) with a

All numbers are non‑negative and the sum is exactly 1, satisfying

import time
import numpy as np

def _power_law_sequence(n: int, p: int) -> np.ndarray:
    """
    Return a decreasing sequence a_i ∝ (n‑i)^p, normalised to sum 1.
    """
    # (n, n‑1, …, 1) to the power p, cast to float64
    raw = np.arange(n, 0, -1, dtype=np.float64) ** p

        raw = np.full(n, 1.0 / n, dtype=np.float64)
    else:
        raw = raw / raw_sum
    return raw
