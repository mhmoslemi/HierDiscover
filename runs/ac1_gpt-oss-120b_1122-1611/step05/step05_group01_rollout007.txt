analysisFirst, we need to propose a candidate step function of arbitrary length that reduces the evaluation function. The evaluation function calculates:

- Input sequence list, nonnegative, with each element capped to [0,1000].
- Convert to float.
- Protected: sum_a must be >0.01 (for finite evaluation).
- Compute convolution of sequence with itself (linear convolution) using numpy.convolve.
- max_b = max of that convolution.
- sum_a = sum of sequence.
- Return 2 * n * max_b / (sum_a**2).

Thus the evaluation metric is: Score = 2 n max(conv(seq, seq)) / (sum(seq)^2).

Goal: minimize score.

Observations:

- Convolution of a sequence with itself yields a symmetrical "auto-correlation" (but linear convolution). The max of the convolution occurs at some location ~ at the centre likely where the sum of overlapping terms is maximum. """
propose_candidate
=================

Search for a non‑negative step‑function that minimises

    score = 2·n·max(conv(a,a)) / (sum(a)**2)

where ``conv`` is the linear self‑convolution.  The score is scale‑invariant,
so we keep the vector on the probability simplex (sum = 1).

The algorithm works in three phases

1. **Initial families** – generate a few deterministic candidates based on
   the inverse‑square‑root (arcsine) shape
   a_i ∝ 1/((i+½)(n‑½‑i))^α for several lengths `n` and exponents `α`.

2. **Smooth‑max mirror descent** – starting from each candidate we minimise a
   smooth approximation of the max‑convolution:
       S(a) = (1/λ)·log Σ_k exp(λ·(a*a)_k) .
   The gradient of S is
       ∇S_i = 2·Σ_k w_k·a_{k‑i},
   where w_k are the softmax weights of the convolution values.
   We perform a mirror‑descent step on the simplex using an
   exponentiated‑gradient update (a_i ← a_i·exp(−η·∇S_i)) and renormalise.
   The smoothing parameter `λ` is increased gradually, while the stepsize
   `η` is slowly decreased.  Random jitter is added occasionally to escape
   plateaus.

3. **Fine‑grained refinement** – the best sequence found so far is refined
   further with the same optimiser but with a larger `λ` and a smaller `η`.

All heavy work is done with FFTs (linear convolution and correlation) so the
method scales to several thousand coefficients within the 1000 s budget.
"""  # noqa: E501

import time
from typing import List

import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (no closures, top‑level)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    if x <= 1:
        return 1
    return 1 << ((x - 1).bit_length())


def _fft_len_for_n(n: int) -> int:
    """
    Length of the FFT that can hold the full linear self‑convolution of a
    vector of length ``n`` (size 2·n‑1).  The smallest power‑of‑two ≥ 2·n‑1
    is returned.
    """
    size = 2 * n - 1
    return _next_pow2(size)


def _conv_self_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear self‑convolution using real FFT.
    Returns an array of length 2·len(a)‑1.
    """
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)[: 2 * a.size - 1]
    return conv


def _corr_fft(a: np.ndarray, b: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear correlation (a ⋆ b)[k] = Σ_i a_i·b_{i+k} for k ≥ 0,
    computed via FFT.  The result has length ``fft_len``; the first
    ``len(a)`` entries correspond to the needed gradients.
    """
    A = np.fft.rfft(a, n=fft_len)
    B = np.fft.rfft(b, n=fft_len)
    corr = np.fft.irfft(np.conj(A) * B, n=fft_len)
    return corr


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex.
    (Not used in the current version – kept for possible experiments.)
    """
    if v.ndim != 1:
        raise ValueError("v must be 1‑D")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = ind[cond][-1]
        theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: float = 1000.0) -> List[float]:
    """
    Return a list of non‑negative heights that (approximately) minimises
    ``evaluate_sequence`` before the time budget elapses.
    """
    rng = np.random.default_rng(seed)

    start_time = time.monotonic()
    # stop a little before the deadline to avoid a hard timeout
    deadline = start_time + max(0.0, float(budget_s) - 0.5)

    best_seq: List[float] | None = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 0)  Keep the previous solution (if any) as a baseline
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        try:
            cand = list(map(float, globals()["height_sequence_1"]))
            sc = evaluate_sequence(cand)
            if np.isfinite(sc) and sc < best_score:
                best_score = sc
                best_seq = cand
                elapsed = time.monotonic() - start_time
                print(
                    f"[{elapsed:6.2f}s] baseline score = {sc:.6f} "
                    f"(length {len(cand)})"
                )
        except Exception:
            pass

    # ------------------------------------------------------------------
    # 1)  Generate deterministic arcsine‑family seeds
    # ------------------------------------------------------------------
    length_candidates = [256, 512, 1024, 2048, 3809, 4096, 5000]
    # a modest sweep of the exponent α around the classic 0.5
    alphas = np.linspace(0.35, 0.65, 7)

    for n in length_candidates:

        for alpha in alphas:

                # slowly decay step size, slowly increase λ
                eta *= 0.9996

                    elapsed = time.monotonic() - start_time
