    to index j (i != j).  The update uses the exact formula derived from
    (a+Δ)*(a+Δ) = a*a + 2*a*Δ + Δ*Δ.

    a : ndarray
        Current coefficient vector (length n).
    conv : ndarray

    i, j : int

    delta : float
        Amount transferred (positive, ≤ a[i]).

    Returns
    -------
    new_conv : ndarray
        Updated convolution.
    """
    n = a.size
    new_conv = conv.copy()
    # linear part: -2Δ·shift(a,i) + 2Δ·shift(a,j)
    new_conv[i : i + n] -= 2.0 * delta * a
    new_conv[j : j + n] += 2.0 * delta * a
    # quadratic part Δ*Δ
    new_conv[2 * i] += delta * delta
    new_conv[2 * j] += delta * delta
    new_conv[i + j] -= 2.0 * delta * delta
    return new_conv
