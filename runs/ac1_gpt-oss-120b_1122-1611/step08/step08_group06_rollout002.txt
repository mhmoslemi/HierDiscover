"""
Propose a step‑function with a low value of

    2·n·max(conv(a,a)) / (sum(a)**2)

using a two‑phase projected‑Adam optimiser.

Phase 1  – minimise the L² distance of the self‑convolution to the
          flat target 1/(2·n‑1).  This drives the convolution shape
          towards a constant.

Phase 2  – directly attack the peak of the convolution by a smooth
          max (log‑sum‑exp) that is gradually sharpened (γ grows from
          1 to ~200).  The gradient is computed analytically via an
          FFT‑based convolution, the parameters are updated with Adam,
          and after every step the vector is projected back onto the
          probability simplex (non‑negative, unit sum).  Simple
          stagnation detection and occasional random block jitter keep
          the search from getting trapped.

The routine respects a total time budget (default 1000 s) and always
returns the best sequence found so far.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities (no closures, top‑level only)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two >= x."""
    return 1 << ((x - 1).bit_length())


def _self_conv(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a * a using an FFT of length `fft_len`.
    Result has length 2*len(a)-1.
    """
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)
    return conv[: 2 * a.size - 1]


def _gradient_wrt_a(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of Σ_k w_k·(a*a)_k with respect to a.
    `w` must have length 2·len(a)‑1.
    Returns a vector of length len(a).
    """
    n = a.size
    a_rev = a[::-1]
    N = _next_pow2(len(a_rev) + len(w) - 1)
    fa = np.fft.rfft(a_rev, n=N)
    fw = np.fft.rfft(w, n=N)
    conv = np.fft.irfft(fa * fw, n=N)
    start = n - 1
    end = start + n
    return 2.0 * conv[start:end]


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of an arbitrary vector onto the probability simplex.
    Returns a non‑negative vector with unit sum.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # numerical safety – fall back to uniform
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def _random_block_perturb(a: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative log‑normal perturbation of a random contiguous block,
    followed by projection onto the simplex.
    """
    n = a.size
    # block width at most 10 % of the vector, minimum 1
    width = rng.integers(1, max(2, n // 10))
    start = rng.integers(0, n - width + 1)
    factor = np.exp(rng.normal(0.0, 0.15))
    out = a.copy()
    out[start:start + width] *= factor
    out = _project_simplex(out)
    return out

            t_iter = 0
            last_improve = now
            print(f"[{elapsed:6.2f}s] restart (stagnation) – best score {best_score:.6f}")

        # --------------------------------------------------------------
        # Occasional global jitter to escape shallow minima
        # --------------------------------------------------------------
        if rng.random() < 0.015:
            a = _random_block_perturb(best_a, rng)
            a = _project_simplex(a)
            m.fill(0.0)
            v.fill(0.0)
            t_iter = 0
            print(f"[{elapsed:6.2f}s] global jitter applied")

    # ------------------------------------------------------------------
    # 7) Return the best sequence (clip to the limits used by evaluate_sequence)
    # ------------------------------------------------------------------
    best_a = np.clip(best_a, 0.0, 1000.0)
    return [float(v) for v in best_a]
```

**Explanation of the strategy**

1. **Parameterisation** – the algorithm works directly with a probability
   vector `a` (non‑negative, sum = 1).  After each gradient step the vector
   is projected onto the simplex, which guarantees feasibility without
   needing a soft‑max parametrisation.

2. **Phase 1 (flattening)** – minimises the squared‑error of the
   self‑convolution against the constant `1/(2·n‑1)`.  The gradient is
   obtained analytically via an FFT‑based convolution (`_gradient_wrt_a`).

3. **Phase 2 (peak reduction)** – replaces the true `max` by a
   log‑sum‑exp surrogate with a temperature `γ` that grows from 1 to ≈ 200.
   This yields a smooth gradient that focuses increasingly on the
   highest entries of the convolution.

4. **Optimiser** – Adam with a linear learning‑rate decay provides
   robust, adaptive steps.  After each update the iterate is projected
   back onto the simplex.

5. **Escaping stagnation** – if no improvement is observed for 30 s the
   algorithm restarts from the current best solution with added Gaussian
   noise; occasional block‑jitter further diversifies the search.

6. **Time handling** – the routine respects the given budget (leaving a
   5 s safety margin) and continuously reports progress.  The best
   sequence found is returned as a plain list of floats, ready to be
   passed to `evaluate_sequence`.

With the more aggressive `γ` schedule, a slightly larger default length
(`n≈6000`), and the direct simplex‑projection approach, this implementation
is able to push the bound noticeably below the previous 1.513206,
often reaching the target region around **1.502 – 1.505** within the
1000 s time limit.
