assistantfinal**Solution Overview**

The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the self‑convolution of a non‑negative vector `a`.  
The score is invariant to a global scaling of `a`, therefore we can always keep the
vector normalised to sum = 1 while searching.

The search uses three ideas that differ from the original hill‑climbing approach:

1. **Exponentiated‑gradient updates** –  
   For the current maximal convolution index `k*` the sub‑gradient of
   `max(a*a)` is known analytically:
   \[
   \frac{\partial}{\partial a_j}\bigl[(a*a)_{k^*}\bigr]=2\,a_{k^*-j}.
   \]
   An exponentiated‑gradient step  
   `a_j ← a_j·exp(-η·2·a_{k*-j})` (followed by a projection onto the simplex)
   moves mass away from the positions that contribute most to the current peak.

2. **Temperature schedule & restarts** –  
   The learning rate `η` is annealed linearly from 0.5 to 0.005.
   If no improvement is observed for several seconds a random multiplicative
   perturbation (log‑normal noise) is applied to escape plateaus.

3. **Multi‑scale exploration** –  
   Several sequence lengths are tried (`n = 2048 … 32768`).  
   For each length we start from a handful of simple families (uniform,
   increasing β‑shape, decreasing β‑shape, arcsine) and run the exponentiated‑gradient
   optimiser for a dedicated time slice.  The best sequence over **all**
   lengths is returned.

All operations keep the vector non‑negative and on the simplex, satisfying the
security checks of `evaluate_sequence`.  The whole programme respects the
1000 s budget (a 5 s safety margin is kept).

```python
"""
Fast exponentiated‑gradient optimiser for the self‑convolution bound.

The algorithm works on many different lengths.  For each length a few simple
initial shapes (uniform, increasing beta, decreasing beta, arcsine) are
optimised by repeatedly:
  – compute the self‑convolution,
  – locate the maximal index,
  – take a sub‑gradient of the max‑convolution,
  – update the vector with a multiplicative (exponentiated‑gradient) step,
  – project back onto the probability simplex.
A linear learning‑rate schedule and occasional random restarts allow the
search to escape local minima.  The best sequence found before the time budget
expires is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – pure functions, no closures
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((int(x) - 1).bit_length())


def _max_self_convolution(a: np.ndarray) -> np.ndarray:
    """Return the full self‑convolution (length 2·n‑1) using a real FFT."""
    n = a.size
    L = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fa * fa, n=L)[: 2 * n - 1]
    # Numerical noise may create tiny negatives – clamp to 0.
    np.maximum(conv, 0.0, out=conv)
    return conv


def compute_score(a: np.ndarray) -> float:
    """Exact objective used by evaluate_sequence (without its clamping)."""
    n = a.size
    max_b = _max_self_convolution(a).max()
    s = a.sum()
    if s < 0.01:      # matches the protection in evaluate_sequence
        return float("inf")
    return 2.0 * n * max_b / (s * s)


def gen_beta_seq(n: int, alpha: float, beta: float) -> np.ndarray:
    """
    Discrete Beta(α,β) distribution on {0,…,n‑1}:
    a_i ∝ x_i^{α‑1}(1‑x_i)^{β‑1},  x_i = (i+½)/n.
    The result is normalised to sum = 1.
    """
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    eps = 1e-12
    x = np.clip(x, eps, 1.0 - eps)
    raw = np.power(x, alpha - 1.0) * np.power(1.0 - x, beta - 1.0)
    # Guard against numerical under‑flow.
    raw = np.clip(raw, 0.0, None)
    s = raw.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n, dtype=np.float64)
    return raw / s


def _random_block_perturb(a: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative log‑normal perturbation of a random contiguous block,
    followed by re‑normalisation onto the simplex.
    """
    n = a.size
    width = rng.integers(1, max(2, n // 10))
    start = rng.integers(0, n - width + 1)
    factor = np.exp(rng.normal(0.0, 0.15))
    out = a.copy()
    out[start:start + width] *= factor
    out = np.clip(out, 0.0, None)
    total = out.sum()
    if total == 0.0:
        out[:] = 1.0 / n
    else:
        out /= total
    return out


# ----------------------------------------------------------------------
# Exponentiated‑gradient optimiser for a fixed length
# ----------------------------------------------------------------------


def _expgrad_optimize(
    a0: np.ndarray,
    deadline: float,
    rng: np.random.Generator,
    length_id: int,
) -> tuple[np.ndarray, float]:
    """
    Run the exponentiated‑gradient optimiser starting from a0 until *deadline*.
    Returns the best vector seen and its score.
    """
    a = a0.copy()
    n = a.size
    best_a = a.copy()
    best_score = compute_score(best_a)

    # timing helpers
    start = time.monotonic()
    last_improve = start
    stagnation_limit = 10.0   # seconds without improvement → random restart

    while time.monotonic() < deadline:
        # ----- self‑convolution & max index -----
        conv = _max_self_convolution(a)
        max_val = conv.max()
        # extract all indices that are (almost) maximal – usually a single entry
        idxs = np.where(conv >= max_val - 1e-12)[0]

        # ----- sub‑gradient of the maximal convolution entry -----
        g = np.zeros_like(a)
        for k in idxs:
            # overlapping region between a and the shifted copy
            start_j = max(0, k - (n - 1))
            end_j = min(n - 1, k)
            i_start = k - end_j          # corresponding a‑index for start_j
            i_end = k - start_j          # corresponding a‑index for end_j
            # slice lengths are identical
            g[start_j : end_j + 1] += 2.0 * a[i_start : i_end + 1]

        # ----- annealed learning rate -----
        now = time.monotonic()
        elapsed = now - start
        frac = elapsed / (deadline - start)          # 0 … 1
        eta = 0.5 * (1.0 - frac) + 0.005             # from 0.5 down to 0.005

        # ----- multiplicative update (exponentiated gradient) -----
        a = a * np.exp(-eta * g)
        # keep a numerically stable
        a = np.clip(a, 1e-15, None)
        a /= a.sum()

        # ----- occasional jitter to shake off plateaus -----
        if rng.random() < 0.01:
            a = _random_block_perturb(a, rng)

        # ----- evaluate -----
        score = compute_score(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()
            last_improve = now
            print(
                f"    [{now - start_time:.2f}s] n={n} (id={length_id}) "
                f"new best → {best_score:.6f}"
            )

        # ----- stagnation handling -----
        if now - last_improve > stagnation_limit:
            # random log‑normal perturbation (restart)
            noise = np.exp(rng.normal(0.0, 0.12, size=n))
            a = a * noise
            a = np.clip(a, 0.0, None)
            a_sum = a.sum()
            a = a / a_sum if a_sum > 0 else np.full_like(a, 1.0 / n)
            restart_score = compute_score(a)
            if restart_score < best_score:
                best_score = restart_score
                best_a = a.copy()
                print(
                    f"    [{now - start_time:.2f}s] n={n} (id={length_id}) "
                    f"restart improvement → {best_score:.6f}"
                )
            last_improve = now

    return best_a, best_score

# Main entry point required by the challenge
# ----------------------------------------------------------------------


def propose_candidate(
    seed: int = 12345,
    budget_s: float = 1000.0,
    **kwargs,
) -> list[float]:
    """
    Search for a step‑function (non‑negative heights) that minimises
    ``evaluate_sequence``.  The routine respects the 1000 s budget and
    returns the best sequence found.
    """
    global start_time
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 0) Time‑budget handling (keep a small safety margin)
    # ------------------------------------------------------------------
    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 5.0)  # 5 s safety

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 1) If a previous construction is available, initialise from it
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        cand = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
        cand = np.clip(cand, 0.0, None)
        s = cand.sum()
        if s > 0.0:
            cand /= s
        else:
            cand = np.full_like(cand, 1.0 / cand.size)
        sc = compute_score(cand)
        best_seq = cand.copy()
        best_score = sc
        print(f"[{0.00:.2f}s] start from known sequence → score {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2) Multi‑scale exploration (≈90 % of the remaining time)
    # ------------------------------------------------------------------
    lengths = [2048, 4096, 8192, 16384, 32768]   # diverse sizes
    # Equal time slice per length
    remaining = deadline - time.monotonic()
    per_len_deadline = start_time + remaining / len(lengths)

    for idx, n in enumerate(lengths):
        if time.monotonic() >= deadline:
            break
        # allocate a slice of the budget for this length
        slice_deadline = min(per_len_deadline, deadline)
        per_len_deadline += remaining / len(lengths)   # advance slice end

        # ---- a few deterministic initial families ----
        init_families = [
            np.full(n, 1.0 / n, dtype=np.float64),            # uniform
            gen_beta_seq(n, 2.0, 1.0),                        # increasing beta (ramp)
            gen_beta_seq(n, 1.0, 2.0),                        # decreasing beta (reverse ramp)
            gen_beta_seq(n, 0.5, 0.5),                        # arcsine (U‑shape)
        ]

        for start_id, a0 in enumerate(init_families):
            if time.monotonic() >= deadline:
                break
            # allocate a few seconds for each start (roughly)
            sub_deadline = min(slice_deadline, time.monotonic() + 30.0)
            a_opt, sc_opt = _expgrad_optimize(a0, sub_deadline, rng, idx)
            if sc_opt < best_score:
                best_score = sc_opt
                best_seq = a_opt.copy()
                print(
                    f"[{time.monotonic() - start_time:.2f}s] "
                    f"global new best (n={n}, start={start_id}) → {best_score:.6f}"
                )

    # ------------------------------------------------------------------
    # 3) Final refinement of the globally best sequence (if any)
    # ------------------------------------------------------------------
    if best_seq is not None:
        # give the remainder of the budget to a final optimisation pass
        final_deadline = deadline
        print(
            f"Refining global best (len={best_seq.size}) "
            f"score={best_score:.6f}"
        )
        best_seq, best_score = _expgrad_optimize(
            best_seq, final_deadline, rng, length_id=-1
        )
        print(f"Refinement finished → best score {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4) Safety post‑processing and return
    # ------------------------------------------------------------------
    if best_seq is None:
        # fallback – a simple uniform sequence of moderate size
        n = 4096
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)

    # Clamp to the limits enforced by evaluate_sequence
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    total = best_seq.sum()
    if total == 0.0:
        best_seq[:] = 1.0 / best_seq.size
    else:
        best_seq /= total

    elapsed = time.monotonic() - start_time
    print(f"Finished search in {elapsed:.2f}s, final best score {best_score:.6f}")

    # Return a plain Python list as required
    return [float(x) for x in best_seq]
```
