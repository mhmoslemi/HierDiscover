Algorithm
---------
0.   Load the previously discovered sequence ``height_sequence_1`` (if
     available) and normalise it to a probability vector.  If it is not
     present, start from a random Dirichlet vector.

1.   **Phase I – smooth‑max Adam optimisation**  
     Optimise a smooth approximation of ``max(conv)`` using Adam on the
     log‑weights (softmax parametrisation).  The temperature ``γ`` grows
     from a small value to a large one, turning the surrogate into the true
     maximum.  Restarts are triggered after a period of stagnation.

2.   **Phase II – directed + stochastic hill‑climbing**  
     *Exact sub‑gradient*: for the current exact maximum of the convolution
     we build a weight vector that puts equal mass on all binding
     constraints and obtain the sub‑gradient ``g = ∂ max(conv)/∂a`` via a
     fast FFT‑based correlation.
     *Directed move*: move a fraction of mass from the index with the
     largest component of ``g`` (the steepest ascent direction) to the
     index with the smallest component (steepest descent).  The step size
     decays linearly during the phase.
     *Stochastic alternatives*: a simple random mass move and a block‑
     perturbation are also tried; the best of the three candidates is kept.
     Occasionally uphill moves are accepted with a temperature schedule
     (simulated annealing) to escape shallow local minima.
     If no improvement happens for a while the current iterate is
     re‑initialised near the best solution found so far.

3.   The best sequence encountered over the whole time budget is returned.
   All entries are clipped to the limits imposed by ``evaluate_sequence``.
"""

import time
import numpy as np
from numpy.fft import rfft, irfft

# Helper functions – must be top level (no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _self_conv(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear self‑convolution of a 1‑D array using an FFT of length ``fft_len``.
    Result length is 2·len(a)‑1.
    """
    fa = rfft(a, n=fft_len)
    fc = fa * fa
    conv = irfft(fc, n=fft_len)
    return conv[: 2 * a.size - 1]


def _gradient_wrt_a(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient ∂/∂a of the weighted sum  Σ_k w_k (a*a)_k .
    ``a`` – probability vector (length n).
    ``w`` – non‑negative weights over the 2·n‑1 convolution positions (sum = 1).
    Returns a vector of length n.
    """
    n = a.size
    a_rev = a[::-1]
    N = _next_pow2(len(a_rev) + len(w) - 1)
    fa = rfft(a_rev, n=N)
    fw = rfft(w, n=N)
    conv = irfft(fa * fw, n=N)
    start = n - 1
    end = start + n
    return 2.0 * conv[start:end]


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (outputs a probability vector)."""
    y = x - np.max(x)
    e = np.exp(y)
    return e / e.sum()


def _random_block_perturb(a: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiply a random contiguous block by a log‑normal factor,
    then renormalise to unit sum.
    """
    n = a.size
    width = rng.integers(1, max(2, n // 10))
    start = rng.integers(0, n - width + 1)
    factor = np.exp(rng.normal(0.0, 0.15))
    out = a.copy()
    out[start:start + width] *= factor
    out = np.clip(out, 0.0, None)
    s = out.sum()
    if s == 0.0:
        out[:] = 1.0 / n
    else:
        out /= s
    return out


def _move_mass(a: np.ndarray, rng: np.random.Generator, step_frac: float) -> np.ndarray:
    """
    Transfer a small fraction of mass from a random source index to a random
    destination index, then renormalise.
    """
    n = a.size
    i, j = rng.integers(0, n, size=2)
    if i == j or a[i] == 0.0:
        return a
    delta = step_frac * rng.random() * a[i]
    if delta <= 0.0:
        return a
    out = a.copy()
    out[i] -= delta
    out[j] += delta
    out_sum = out.sum()
    if out_sum == 0.0:
        out[:] = 1.0 / n
    else:
        out /= out_sum
    return out
