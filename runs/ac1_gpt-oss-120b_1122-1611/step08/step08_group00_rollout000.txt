"""
Hybrid optimizer for the step‑function challenge.

The algorithm works in two stages inside the allowed 1000 s budget:

1. **Soft‑max Adam (global polishing)** – the non‑smooth objective
   `max(conv)` is approximated by a temperature‑controlled soft‑max.
   The temperature (α) grows from 2 to 5 000, turning the surrogate
   gradually into the true max.  Adam with simplex projection provides
   fast convergence from a good starting point (the previously best
   construction if `height_sequence_1` exists).

2. **Hard‑max projected gradient descent (fine tuning)** – after the
   surrogate has become sharp we switch to the exact sub‑gradient of the
   max (for lag `k*` the gradient is `g_i = 2·a_{k*-i}` when the index is
   inside the support, otherwise 0).  A simple decreasing learning‑rate
   schedule, occasional stochastic jitter and a restart‑on‑stagnation
   scheme keep the search escaping shallow plateaus.

All iterates stay on the probability simplex (`a_i ≥ 0`, `∑a_i = 1`) by
means of Euclidean projection (`proj_simplex`).  The best sequence found
is returned as a plain list of floats, clipped to the limits enforced by
`evaluate_sequence`.
"""

import time

# ----------------------------------------------------------------------
# Simplex projection (Euclidean)
# ----------------------------------------------------------------------
def proj_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex (non‑negative, sum = 1)."""
    if v.ndim != 1:
        raise ValueError("v must be one‑dimensional")
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

    return 1 << ((x - 1).bit_length())

def _self_conv_fft(a: np.ndarray, fft_len: int, conv_len: int) -> np.ndarray:
    """Linear self‑convolution a*a using an FFT of length ``fft_len``."""
    fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[:conv_len]
    return conv

    conv = _self_conv_fft(a, fft_len_self, conv_len)

def softmax_weights(conv: np.ndarray, alpha: float) -> np.ndarray:
    """Soft‑max over the convolution vector with temperature 1/α."""
    cmax = conv.max()
    shifted = conv - cmax          # improve numerical stability
    w = np.exp(alpha * shifted)
    s = w.sum()
    if s == 0.0:
        return np.full_like(w, 1.0 / w.size)
    return w / s

def grad_softmax(a: np.ndarray,
                 w: np.ndarray,
                 fft_len_grad: int,
                 n: int) -> np.ndarray:
    """
    Gradient of the soft‑max surrogate:
        ∇ = 2·a * w_rev
    where * denotes linear convolution.
    """
    w_rev = w[::-1]
    fa = np.fft.rfft(a, n=fft_len_grad)
    fw = np.fft.rfft(w_rev, n=fft_len_grad)
    full = np.fft.irfft(fa * fw, n=fft_len_grad)
    start = w_rev.size - 1  # index of the first component that aligns with a
    return 2.0 * full[start:start + n]

def grad_hard_max(a: np.ndarray, k_max: int) -> np.ndarray:
    """
    Exact sub‑gradient of ``max(a*a)`` at the lag ``k_max``.

    mask = (idx >= 0) & (idx < n)
    grad = np.zeros_like(a)
    grad[mask] = 2.0 * a[idx[mask]]
    return grad

        a = proj_simplex(a)

        cur_score = compute_J(a, fft_len_self, conv_len)
        if cur_score < best_score - 1e-13:
            best_score = cur_score
            best_a = a.copy()
            last_improve = now
            print(f"[{now - start_time:6.2f}s] GD new best J = {best_score:.8f}")

        # restart/noise if stagnated for >30 s
        if now - last_improve > 30.0:
            a = best_a.copy()
            noise = np.exp(rng.normal(0.0, 0.07, size=n))
            a = proj_simplex(a * noise)
            last_improve = now
            print(f"[{now - start_time:6.2f}s] restart after stagnation – best J = {best_score:.8f}")

        # tiny random perturbations occasionally
        if rng.random() < 0.003:
            a = proj_simplex(a * np.exp(rng.normal(0.0, 0.02, size=n)))

    # ------------------------------------------------------------------
    # 5) Return the best sequence found (clipped to evaluation limits)
    # ------------------------------------------------------------------
    best_a = np.clip(best_a, 0.0, 1000.0)
    return [float(x) for x in best_a]
```

**Explanation of the new parts**

* The **soft‑max Adam** phase now drives the temperature up to 5 000, which makes the surrogate almost indistinguishable from the true `max`.  A slower learning‑rate decay and a tiny jitter improve robustness.

* In the **hard‑max GD** phase the exact sub‑gradient
  `g_i = 2·a_{k*‑i}` is used (computed in *O(n)*).  A simple linear schedule for the step size
  (`0.10 → 1e‑5`) together with periodic stochastic restarts gives the optimizer
  the ability to escape shallow plateaus and to converge to a lower
  `max(conv)`.  Because all iterates stay on the simplex, the objective
  `evaluate_sequence` (which is scale‑invariant) is directly minimised.

* The routine respects the 1 000 s budget (with a 5 s safety margin) and
  prints progress timestamps and the current best bound.

The function `propose_candidate` can be called directly; it will return a
list of non‑negative heights ready for evaluation.
