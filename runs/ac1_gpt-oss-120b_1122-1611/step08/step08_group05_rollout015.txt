Therefore we may restrict to the probability simplex (∑a = 1) and minimise
    F(a) = 2·n·max_i (a*a)_i .
F is non‑smooth because of the max; we approximate it by a log‑sum‑exp
(LSE) smooth surrogate

    F_γ(a) = (2·n/γ)·log Σ_i exp(γ·c_i) ,   c = a*a .

The gradient of the LSE can be evaluated without an explicit Jacobian:
    ∇_a F_γ = 2·a·(w⊗a) – 2·⟨a, w⊗a⟩·a,
where w is the soft‑max of the γ‑scaled convolution.
We optimise the *log‑weights* x (a = softmax(x)) with Adam while
increasing γ from a smooth value (≈0.4) to a very sharp one (≈300).
After every epoch we compute the exact score (via `evaluate_sequence`)
and keep the best vector seen.

To avoid stagnation we employ three complementary mechanisms

  * **Soft restarts** – when no improvement for 20 s we re‑initialise
    from the current best plus isotropic Gaussian noise.
  * **Block jitter** – with probability 0.01 we apply a multiplicative
    log‑normal perturbation to a random contiguous block of the best vector.
  * **Multi‑start** – at the very beginning we try three independent
    starts (uniform, Dirichlet and the optional global `height_sequence_1`);
    the best of the three seeds is taken as the initial point.

The whole routine is bounded by a 1000 s budget (5 s safety margin) and
returns the best sequence discovered, clipped to the limits enforced by
`evaluate_sequence`.  All helper functions are defined at module level.
"""

import time
import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Utility functions – all top‑level, no closures
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _self_conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear self‑convolution a*a using an FFT of length ``fft_len``."""
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)[: 2 * a.size - 1]
    return conv


def _self_conv_direct(a: np.ndarray) -> np.ndarray:
    """Fallback exact convolution (used only for final exact evaluations)."""
    return np.convolve(a, a)


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (returns a probability vector)."""
    y = x - np.max(x)
    e = np.exp(y)
    return e / e.sum()


def _gradient_wrt_a(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the LSE surrogate w.r.t. the probability vector ``a``.
    ``w`` is a probability vector of length 2·len(a)−1 (soft‑max of the
    γ‑scaled convolution).
    """
    n = a.size
    # correlation of rev(a) with w  (linear, not circular)
    a_rev = a[::-1]
    N = _next_pow2(len(a_rev) + len(w) - 1)
    fa = np.fft.rfft(a_rev, n=N)
    fw = np.fft.rfft(w, n=N)
    corr = np.fft.irfft(fa * fw, n=N)
    # the relevant slice corresponds to indices n‑1 … n‑1+n‑1
    start = n - 1
    end = start + n
    return 2.0 * corr[start:end]


def _block_perturb(a: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative log‑normal perturbation of a random contiguous block
    (width ≤ 12 % of the vector length), followed by renormalisation.
    """
    n = a.size
    max_width = max(2, n // 8)
    width = rng.integers(1, max_width + 1)
    start = rng.integers(0, n - width + 1)
    factor = np.exp(rng.normal(0.0, 0.2))
    out = a.copy()
    out[start:start + width] *= factor
    out = np.clip(out, 0.0, None)
    s = out.sum()
    if s == 0.0:                     # safety – should never happen
        out[:] = 1.0 / n
    else:
        out /= s
    return out


def _random_dirichlet(rng: np.random.Generator, dim: int, concentration: float = 1.0) -> np.ndarray:
    """Draw a random probability vector from a Dirichlet(α) distribution."""
    draws = rng.gamma(concentration, 1.0, size=dim)
    draws_sum = draws.sum()
    if draws_sum == 0.0:
        return np.full(dim, 1.0 / dim)
    return draws / draws_sum


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345,
                     budget_s: float = 1000.0,
                     **kwargs) -> List[float]:
    """
    Return a list of non‑negative heights (the best found) that minimises
    ``evaluate_sequence`` before the time budget elapses.

    The optimiser runs an Adam loop on the log‑weights with a log‑sum‑exp
    surrogate for the max‑convolution.  Three restarts (soft restart,
    block‑jitter and multi‑start) help to escape plateaus.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 0) Time budget (5 s safety margin)
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)

    # ------------------------------------------------------------------
    # 1) Choose the problem dimension.
    #    Prefer the length of a provided construction, otherwise fall back
    #    to a moderately large size (2048) which offers a good trade‑off
    #    between expressive power and speed.
    # ------------------------------------------------------------------
    init_seq = globals().get("height_sequence_1")
    if isinstance(init_seq, (list, tuple, np.ndarray)):
        a0 = np.asarray(init_seq, dtype=np.float64).ravel()
        n = max(2, a0.size)                     # protect against degenerate sizes
    else:
        n = 2048
    # ------------------------------------------------------------------
    # 2) Prepare possible starting points (uniform, Dirichlet, optional prev)
    # ------------------------------------------------------------------
    starts = []
    # uniform start
    starts.append(np.full(n, 1.0 / n, dtype=np.float64))
    # Dirichlet start (moderately peaked)
    starts.append(_random_dirichlet(rng, n, concentration=0.5))
    # previous construction (if available)
    if isinstance(init_seq, (list, tuple, np.ndarray)):
        a_prev = np.asarray(init_seq, dtype=np.float64).ravel()
        a_prev = np.clip(a_prev, 0.0, None)
        s = a_prev.sum()
        if s > 0.0:
            a_prev /= s
        else:
            a_prev = np.full_like(a_prev, 1.0 / a_prev.size)
        # if the previous vector has a different length, pad / truncate to n
        if a_prev.size < n:
            pad = np.full(n - a_prev.size, 1.0 / n, dtype=np.float64)
            a_prev = np.concatenate([a_prev, pad])
        elif a_prev.size > n:
            a_prev = a_prev[:n]
        starts.append(a_prev)

    # ------------------------------------------------------------------
    # 3) Common optimisation parameters
    # ------------------------------------------------------------------
    fft_len_self = _next_pow2(2 * n - 1)          # length for all FFT‑based convolutions
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12

    # ------------------------------------------------------------------
    # 4) Helper: convert log‑weights to a probability vector on the simplex
    # ------------------------------------------------------------------
    def _a_from_x(x_vec: np.ndarray) -> np.ndarray:
        return _softmax(x_vec)

    # ------------------------------------------------------------------
    # 5) Global best tracking (exact evaluation via the official evaluator)
    # ------------------------------------------------------------------
    best_overall = None
    best_score_overall = np.inf
    best_time = None

    # ------------------------------------------------------------------
    # 6) Main multi‑start loop
    # ------------------------------------------------------------------
    for start_id, a_start in enumerate(starts):
        # initialise log‑weights from the probability vector
        x = np.log(a_start + 1e-12)               # log‑soft weights
        m = np.zeros_like(x)
        v = np.zeros_like(x)
        t_iter = 0

        # Timers for this start
        start_time = time.monotonic()
        last_improve = start_time

        # Hyper‑parameter schedules (common to all starts)
        gamma_start = 0.4
        gamma_end = 300.0            # very sharp surrogate at the end
        lr_start = 0.7
        lr_end = 0.02                # final learning‑rate

        # ----------------------------------------------------------------
        # 7) Optimisation loop for the current start
        # ----------------------------------------------------------------
        while time.monotonic() < deadline:
            now = time.monotonic()
            elapsed = now - start_time
            total_allowed = deadline - start_time
            frac = elapsed / total_allowed if total_allowed > 0 else 1.0

            # ---- current probability vector and its convolution (FFT) ----
            a = _a_from_x(x)                              # sum(a) = 1
            conv = _self_conv_fft(a, fft_len_self)        # length 2·n‑1

            # ---- smooth‑max weights (LSE surrogate) --------------------
            gamma = gamma_start + (gamma_end - gamma_start) * frac
            c_shift = conv - np.max(conv)                 # for numerical stability
            w = np.exp(gamma * c_shift)
            w_sum = w.sum()
            if w_sum == 0.0:                              # extreme underflow guard
                w = np.full_like(w, 1.0 / w.size)
            else:
                w /= w_sum                                 # w becomes a probability vector

            # ---- gradient w.r.t. a ------------------------------------
            g_a = _gradient_wrt_a(a, w)                   # shape (n,)

            # ---- chain rule to log‑weights (projected onto simplex) ---
            avg = np.dot(a, g_a)                           # ⟨a,∇F⟩
            g_x = a * (g_a - avg)                         # ensures Σ a_i stays 1

            # ---- Adam update -----------------------------------------
            t_iter += 1
            m = beta1 * m + (1.0 - beta1) * g_x
            v = beta2 * v + (1.0 - beta2) * (g_x * g_x)
            m_hat = m / (1.0 - beta1 ** t_iter)
            v_hat = v / (1.0 - beta2 ** t_iter)
            lr = lr_start * (1.0 - frac) + lr_end * frac
            step = lr * m_hat / (np.sqrt(v_hat) + eps)
            x -= step

            # ---- exact evaluation (using the *real* evaluator) -------
            # We call the provided `evaluate_sequence` only when a *potential*
            # improvement is detected to keep overhead low.
            if (now - last_improve) > 0.8:  # every ~0.8 s we test the exact score
                try:
                    exact_score = evaluate_sequence(a.tolist())
                except Exception:          # defensive – any unexpected error -> skip
                    exact_score = np.inf
                if exact_score < best_score_overall - 1e-12:
                    best_score_overall = exact_score
                    best_overall = a.copy()
                    best_time = now - start_time
                    last_improve = now
                    print(f"[{now - start_time:6.2f}s] New global best (start {start_id}) = "
                          f"{best_score_overall:.6f}")

            # ---- stagnation handling (soft restart) -------------------
            if now - last_improve > 20.0:   # 20 s without improvement → restart
                noise = rng.normal(0.0, 0.9, size=n)
                x = np.log(best_overall + 1e-12) + noise
                m.fill(0.0)
                v.fill(0.0)
                t_iter = 0
                last_improve = now
                print(f"[{now - start_time:6.2f}s] Soft‑restart (no improvement) on start {start_id}")

            # ---- occasional block jitter (global jump) ---------------
            if rng.random() < 0.015:        # ~1.5 % chance per iteration
                a_jit = _block_perturb(best_overall if best_overall is not None else a, rng)
                x = np.log(a_jit + 1e-12)
                m.fill(0.0)
                v.fill(0.0)
                t_iter = 0
                print(f"[{now - start_time:6.2f}s] Block‑jitter on start {start_id}")

        # ----------------------------------------------------------------
        # End of optimisation for this start – report progress
        # ----------------------------------------------------------------
        if best_overall is not None:
            print(f"--- Start {start_id} finished: best score = {best_score_overall:.6f} "
                  f"(found after {best_time:.2f}s) ---")

        # If overall budget is exhausted we break early
        if time.monotonic() >= deadline:
            break

    # ------------------------------------------------------------------
    # 8) Return the best sequence (clipped to the limits of evaluate_sequence)
    # ------------------------------------------------------------------
    if best_overall is None:
        # As a fall‑back return a uniform vector (guaranteed to have a finite score)
        best_overall = np.full(n, 1.0 / n, dtype=np.float64)

    best_overall = np.clip(best_overall, 0.0, 1000.0)
    # Convert to plain Python floats for the caller
    return [float(v) for v in best_overall]
```
