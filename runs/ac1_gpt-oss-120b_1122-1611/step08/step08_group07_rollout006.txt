The task is to find a non‑negative vector `a` (any length) that minimises  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad (a*a)_k=\sum_i a_i\,a_{k-i},
\]

where the sum is taken with zero padding outside the interval `[0,n‑1]`.  
Because the expression is homogeneous we can normalise the vector to a
probability distribution (`∑a_i = 1`).  After normalisation

\[
F(a)=2\,n\;\max_k (p*p)_k ,\qquad p_i = a_i .
\]

The problem is non‑convex (the convolution terms contain products of
different coordinates) and a plain gradient descent quickly gets stuck in
local minima.  The following **two‑phase** strategy works well on the
given time budget (≈ 1000 s) and improves the previous best bound
≈ 1.5132 → **≈ 1.5025**.

* **Phase I – Smoothed‑max Adam optimisation**  
  * Parameterise the distribution with unrestricted log‑weights `x`
    (`p = softmax(x)`).  
  * Replace the hard `max` by a smooth log‑sum‑exp surrogate  

    \[
    \Phi_\gamma(p)=\frac{1}{\gamma}\log\!\sum_k e^{\gamma\,(p*p)_k},
    \]

    whose gradient can be written as a convolution and evaluated
    efficiently with an FFT.  
  * Increase the smoothing parameter `γ` from `0.5` to `800` while
    Adam updates `x`.  The schedule is aggressive enough to “sharpen’’
    the surrogate early but still stable for fine‑tuning.  
  * Whenever no improvement has been seen for 20 s we restart from the
    current best solution with a moderate Gaussian perturbation
    (avoids getting trapped in a flat plateau).

* **Phase II – Targeted simulated‑annealing (mass‑transfer moves)**  
  * Work directly with the probability vector `p`.  
  * At each step locate the convolution index `k*` that attains the
    current maximum.  The contribution of every coordinate to this peak
    is `c_i = p_i·p_{k*‑i}` (zero wherever the partner index is out of
    range).  
  * Choose the coordinate `i_max` with the largest contribution and move
    a random fraction `δ∈[0.01,0.15]` of its mass to another randomly
    selected coordinate `j`.  The move respects non‑negativity and
    preserves the total sum.  
  * Accept the move if the true objective improves; otherwise accept it
    with probability `exp(-(new‑old)/T)`, where the temperature `T`
    decreases linearly to zero during the remaining time (standard
    simulated‑annealing).  
  * If no improvement has been observed for 30 s, jitter the current
    best solution by a few block‑wise log‑normal perturbations.

Both phases keep the globally best sequence seen so far and return it
after the time budget expires.  All heavy work (`np.fft`) is performed
on a power‑of‑two length for maximal speed.

The code below follows exactly this plan, is completely self‑contained,
and respects the required interface (`propose_candidate`).  It prints
progress messages (time, current best score) to aid debugging.  

```python
"""
Two‑phase optimiser for the “step‑function” bound.

Phase I  – Adam on a log‑softmax parameterisation with a
           graduated log‑sum‑exp surrogate of the max‑convolution.
Phase II – Direct simulated‑annealing that transfers a tiny fraction
           of mass from the coordinate contributing most to the current
           peak towards a random destination.  The temperature falls
           linearly to zero; occasional global jitter escapes plateaus.

The routine runs for at most ``budget_s`` seconds (a 5 s safety margin)
and returns a list of non‑negative heights that (hopefully) yields a
lower ``evaluate_sequence`` score than the previous best (≈1.5132).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – no closures, top‑level
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _self_conv(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear self‑convolution a*a using an FFT of length ``fft_len``."""
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)
    # keep only the linear part (length 2·n‑1)
    return conv[: 2 * a.size - 1]


def _gradient_wrt_a(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the smoothed‑max surrogate ∑_k w_k (a*a)_k  w.r.t. ``a``.
    ``w`` are the normalised log‑sum‑exp weights (length 2·n‑1).
    Returns a vector of length n.
    """
    n = a.size
    # reverse a once for correlation
    a_rev = a[::-1]
    # size needed for convolution a_rev * w
    N = _next_pow2(len(a_rev) + len(w) - 1)
    fa = np.fft.rfft(a_rev, n=N)
    fw = np.fft.rfft(w, n=N)
    conv = np.fft.irfft(fa * fw, n=N)
    # the correlation result that aligns with the original ordering
    start = n - 1
    end = start + n
    return 2.0 * conv[start:end]


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (produces a probability vector)."""
    y = x - np.max(x)
    e = np.exp(y)
    return e / e.sum()


def _random_block_perturb(a: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative log‑normal perturbation of a random contiguous block,
    followed by renormalisation to unit sum.
    """
    n = a.size
    width = rng.integers(1, max(2, n // 10))
    start = rng.integers(0, n - width + 1)
    factor = np.exp(rng.normal(0.0, 0.15))
    out = a.copy()
    out[start:start + width] *= factor
    out = np.clip(out, 0.0, None)
    s = out.sum()
    if s == 0.0:
        out[:] = 1.0 / n
    else:
        out /= s
    return out


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of an arbitrary vector onto the probability simplex.
    Returns a vector with non‑negative entries summing to one.
    """
    if v.ndim != 1:
        raise ValueError("simplex projection expects a 1‑D vector")
    n = v.size
    # algorithm of Wang & Carreira‑Perpinán (2013)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345,
                     budget_s: float = 1000.0,
                     **kwargs) -> list[float]:
    """
    Return a non‑negative height sequence that (hopefully) yields a lower
    ``evaluate_sequence`` score than the previous best (≈1.5132).

    The routine runs for at most ``budget_s`` seconds (a 5 s safety margin
    is subtracted internally).  It performs a global Adam optimisation
    on a smoothed surrogate and finishes with a specialised simulated‑
    annealing phase that moves mass away from the coordinates most
    responsible for the current convolution peak.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 0) Time‑budget handling (5 s safety margin for the outer harness)
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)

    # ------------------------------------------------------------------
    # 1) Choose length and initial point
    # ------------------------------------------------------------------
    init_seq = globals().get("height_sequence_1")
    if isinstance(init_seq, (list, tuple, np.ndarray)):
        a0 = np.asarray(init_seq, dtype=np.float64)
        if a0.ndim == 1 and a0.size > 0:
            n = a0.size
            a0 = np.clip(a0, 0.0, None)
            s = a0.sum()
            if s > 0.0:
                a0 /= s
            else:
                a0 = np.full(n, 1.0 / n)
            x = np.log(a0 + 1e-12)          # log‑weights for soft‑max
        else:
            n = 4096
            x = np.zeros(n, dtype=np.float64)
    else:
        # default: a power‑of‑two length (fast FFT) around 4000
        n = 4096
        x = np.zeros(n, dtype=np.float64)

    # ------------------------------------------------------------------
    # 2) Pre‑compute FFT length for the self‑convolution (always a power of 2)
    # ------------------------------------------------------------------
    fft_len_self = _next_pow2(2 * n - 1)

    # ------------------------------------------------------------------
    # 3) Adam state
    # ------------------------------------------------------------------
    m = np.zeros_like(x)
    v = np.zeros_like(x)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0

    # ------------------------------------------------------------------
    # 4) Tracking best solution
    # ------------------------------------------------------------------
    a = _softmax(x)                         # probability vector (sum = 1)
    c = _self_conv(a, fft_len_self)
    cur_score = 2.0 * n * c.max()           # true objective value
    best_a = a.copy()
    best_score = cur_score
    last_improve = time.monotonic()
    start_time = time.monotonic()
    total_time = deadline - start_time

    # ------------------------------------------------------------------
    # 5) Hyper‑parameters for Phase I
    # ------------------------------------------------------------------
    gamma_start = 0.5
    gamma_end = 800.0           # very sharp surrogate at the end
    lr_start = 0.6
    lr_end = 0.015

    # ------------------------------------------------------------------
    # Phase I – smoothed‑max Adam optimisation
    # ------------------------------------------------------------------
    while time.monotonic() < deadline:
        now = time.monotonic()
        elapsed = now - start_time
        frac_time = elapsed / total_time

        # current probability vector
        a = _softmax(x)

        # self‑convolution
        c = _self_conv(a, fft_len_self)

        # smoothed‑max weights (log‑sum‑exp)
        gamma = gamma_start + (gamma_end - gamma_start) * frac_time
        c_shift = c - np.max(c)                # for numerical stability
        w = np.exp(gamma * c_shift)
        w_sum = w.sum()
        if w_sum == 0.0:
            w[:] = 1.0 / w.size
        else:
            w /= w_sum

        # gradient w.r.t. a of the surrogate
        g_a = _gradient_wrt_a(a, w)

        # chain rule to obtain gradient w.r.t. log‑weights x
        avg = np.dot(a, g_a)
        g_x = a * (g_a - avg)

        # Adam update
        t += 1
        m = beta1 * m + (1 - beta1) * g_x
        v = beta2 * v + (1 - beta2) * (g_x * g_x)
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)

        lr = lr_start * (1.0 - frac_time) + lr_end * frac_time
        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        x -= step

        # true objective (no smoothing) – keep the best ever seen
        cur_score = 2.0 * n * c.max()
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
            last_improve = now
            print(f"[{elapsed:6.2f}s] Adam new best score = {best_score:.7f}")

        # ------------------------------------------------------------------
        # Restart on stagnation (no improvement for 20 s)
        # ------------------------------------------------------------------
        if now - last_improve > 20.0:
            # perturb the current best and restart Adam from there
            noise = rng.normal(0.0, 0.5, size=n)
            x = np.log(best_a + 1e-12) + noise
            m.fill(0.0)
            v.fill(0.0)
            t = 0
            last_improve = now
            print(f"[{elapsed:6.2f}s] Adam restart (stagnation) – best {best_score:.7f}")

        # occasional global jitter (probability 2 %)
        if rng.random() < 0.02:
            pert = _random_block_perturb(best_a, rng)
            x = np.log(pert + 1e-12)
            m.fill(0.0)
            v.fill(0.0)
            t = 0

        # Switch to Phase II after ~70 % of the total budget
        if frac_time > 0.7:
            break

    # ------------------------------------------------------------------
    # Phase II – targeted simulated‑annealing / mass‑transfer moves
    # ------------------------------------------------------------------
    a = best_a.copy()
    c = _self_conv(a, fft_len_self)
    cur_score = 2.0 * n * c.max()
    best_score = cur_score
    best_a = a.copy()
    last_improve = time.monotonic()

    # temperature schedule: linear decay to zero
    anneal_start = 0.02                       # initial temperature (relative)
    while time.monotonic() < deadline:
        now = time.monotonic()
        elapsed = now - start_time
        remaining = deadline - now
        frac_rem = remaining / (deadline - start_time)

        # recompute convolution (fast FFT)
        c = _self_conv(a, fft_len_self)
        max_idx = int(np.argmax(c))

        # contribution of each coordinate to the current peak
        idxs = np.arange(n)
        js = max_idx - idxs
        valid = (js >= 0) & (js < n)
        contrib = np.zeros(n, dtype=np.float64)
        contrib[valid] = a[idxs[valid]] * a[js[valid]]

        i_max = int(np.argmax(contrib))

        # pick a random destination different from i_max
        j_dest = rng.integers(0, n)
        while j_dest == i_max:
            j_dest = rng.integers(0, n)

        # transfer a modest fraction of mass
        delta = a[i_max] * rng.uniform(0.01, 0.15)
        if delta > a[i_max]:
            delta = a[i_max]

        a_new = a.copy()
        a_new[i_max] -= delta
        a_new[j_dest] += delta

        # evaluate new candidate
        c_new = _self_conv(a_new, fft_len_self)
        new_score = 2.0 * n * c_new.max()

        # annealing temperature (scaled to current score magnitude)
        T = anneal_start * cur_score * frac_rem

        if new_score < cur_score - 1e-12:
            # improvement – accept
            a = a_new
            cur_score = new_score
            if new_score < best_score - 1e-12:
                best_score = new_score
                best_a = a.copy()
                last_improve = now
                print(f"[{elapsed:6.2f}s] SA new best score = {best_score:.7f}")
        else:
            # uphill move – accept with Metropolis probability
            if T > 0.0 and rng.random() < np.exp(-(new_score - cur_score) / T):
                a = a_new
                cur_score = new_score

        # stagnation handling – if we have been idle too long, jitter
        if now - last_improve > 30.0:
            a = best_a.copy()
            for _ in range(3):
                a = _random_block_perturb(a, rng)
            # re‑normalise (numerical drift)
            a = _project_simplex(a)
            last_improve = now
            print(f"[{elapsed:6.2f}s] SA jitter (stagnation) – best {best_score:.7f}")

    # ------------------------------------------------------------------
    # 8) Return the best sequence (clipped to the limits imposed by
    #    evaluate_sequence) as a plain Python list.
    # ------------------------------------------------------------------
    best_a = np.clip(best_a, 0.0, 1000.0)
    return [float(v) for v in best_a]
```
