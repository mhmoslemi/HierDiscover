Propose a near‑optimal step‑function.

The algorithm consists of three stages:

1. **Coarse grid search** – generate monotone power‑law sequences
   a_i ∝ (i+1)^(-p) for several lengths and exponents p.
   The best of these candidates is kept as a starting point.

2. **Targeted refinement** – from the current best sequence we apply
   a small set of stochastic moves:
      * block‑wise multiplicative perturbation,
      * transfer of mass between two positions,
      * smoothing with a short moving‑average,
      * optional symmetrisation.
   Moves are accepted if they improve the score, otherwise they are
   accepted with a temperature‑controlled probability (simulated
   annealing).  The temperature slowly cools, allowing the search to
   escape shallow local minima.

3. **Gradient‑inspired step** – once in a while we compute the index
   `k` where the self‑convolution attains its maximum and move the
   sequence in the direction that reduces this peak (a cheap
   projected‑gradient update).

All candidates are re‑normalised to unit sum (the evaluation function

`evaluate_sequence`.  The routine runs for the allotted time budget
(≤ 1000 s) and returns the best sequence it has found.

import math

def _make_power_sequence(n: int, p: float) -> np.ndarray:
    """Monotone power‑law: a_i ∝ (i+1)^(-p), normalised to unit sum."""
    idx = np.arange(n, dtype=np.float64) + 1.0
    seq = idx ** (-p)
    seq /= seq.sum()
    return seq


def _make_beta_sequence(n: int, a: float) -> np.ndarray:
    """
    Symmetric Beta distribution (a,a) on [0,1].
    a>0, the density is proportional to t^(a-1)*(1-t)^(a-1).
    """
    t = (np.arange(n, dtype=np.float64) + 0.5) / n
    seq = (t ** (a - 1.0)) * ((1.0 - t) ** (a - 1.0))
    seq /= seq.sum()
    return seq


def _make_sine_sequence(n: int, q: float) -> np.ndarray:
    """a_i ∝ sin(π*(i+0.5)/n)^q, normalised."""
    theta = np.pi * (np.arange(n, dtype=np.float64) + 0.5) / n
    seq = np.sin(theta) ** q
    seq /= seq.sum()
    return seq


def _make_gaussian_sequence(n: int, sigma: float) -> np.ndarray:
    """Discrete Gaussian centred in the middle, normalised."""
    centre = (n - 1) / 2.0
    x = np.arange(n, dtype=np.float64)
    seq = np.exp(-0.5 * ((x - centre) / (sigma * n)) ** 2)
    seq /= seq.sum()
    return seq

            cand /= s
        else:
            continue

        # clip to the hard bounds enforced by evaluate_sequence
        cand = np.clip(cand, 0.0, 1000.0)

        # evaluation
        score = _evaluate(cand)

        # acceptance rule (simulated annealing)
        delta = score - best_score
        if delta < 0.0 or rng.random() < math.exp(-delta / max(temperature, 1e-12)):
            best_seq = cand.copy()
            best_score = score
            print(f"[accept] score={best_score:.6f} (len={n})")

        # cool the temperature
        temperature = max(min_temperature, temperature * cooling_rate)

    # ------------------------------------------------------------------
    # 3) Final fall‑back (should never be needed)
    # ------------------------------------------------------------------
    if best_seq is None or best_seq.size == 0:
        best_seq = np.ones(256, dtype=np.float64)
        best_seq /= best_seq.sum()

    # Return a plain Python list as required by the caller
    return [float(x) for x in best_seq]
