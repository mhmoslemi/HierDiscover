The evaluation function is  

\[
J(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a\in\mathbb R_{\ge 0}^n .
\]

The objective is *scale invariant*: multiplying the whole vector by a
positive constant does not change `J`.  
Hence we may (and will) keep the **sum fixed to 1** – the denominator
becomes 1 and minimising `J` is equivalent to minimising the maximum
entry of the auto‑convolution `b = a*a`.

The maximum of `b` is a convex piecewise‑quadratic function of `a`,
but it is not smooth.  
A standard way to minimise a convex `ℓ∞`‑type objective is a
*sub‑gradient* method:

* find the index `t*` where `b` attains its current maximum,
* the sub‑gradient of `max(b)` w.r.t. `a` at that index is  
  \[
  g_i=
  \begin{cases}
     2\,a_{t^*-i}&\text{if }0\le t^*-i<n,\; i\neq t^*/2,\\[4pt]
     a_i          &\text{if }i=t^*/2\ (\text{the diagonal term}),\\[4pt]
     0            &\text{otherwise}.
   \end{cases}
  \]
* move a little in the opposite direction,
  project back onto the non‑negative simplex (clip to `≥0` and renormalise).

The method converges to a point with a small value of `max(b)`.  
To make the search fast we evaluate the convolution with an FFT (length
`M = 2^⌈log₂(2n‑1)⌉`).  
A few heuristic tricks improve robustness:

* **learning‑rate decay** (`lr = lr0·(1‑it/it_max)`),
* **momentum** (`v = β·v + (1‑β)·g`),
* occasional **random jitter** (restart from a noisy version of the
  current best when progress stalls),
* a **pre‑search** over several easy analytic families (exponential,
  power‑exponential, sinusoidal, polynomial, inverse‑power).  
  The best of those families is used as the starting point for the
  sub‑gradient phase.

The whole algorithm respects the 1000 s budget, uses only `numpy` and
the supplied `evaluate_sequence`, and finally returns the best sequence
found.

#!/usr/bin/env python
"""
Propose a candidate step‑function sequence with low evaluation score.

Algorithm
---------

1. **Parametric sweep** – evaluate a few classic families (exponential,
   power‑exponential, sinusoidal, polynomial, inverse‑power) and keep
   the best one.

2. **Sub‑gradient descent on the ℓ∞‑norm** – the objective
   `max(a*a)` is convex but not smooth.
   At the current maximum index `t*` the sub‑gradient is
   `g_i = 2*a[t*-i]` (with a correction on the diagonal).
   We take a step `a ← a – lr·g`, clip to non‑negative,
   renormalise the sum to 1, and repeat.
   The convolution is computed with an FFT for speed.
   Learning rate decays, a small momentum term is added and,
   every few thousand iterations, a random jitter is injected to
   escape plateaus.

3. The best sequence (clipped to the allowed range) is returned.
   The whole search stops a few seconds before the time limit
   to guarantee a result.

The method is deterministic for a given seed, needs only NumPy,
and fits comfortably into the 1000‑second budget.
"""

def _evaluate(seq: np.ndarray) -> float:
    """Wrapper around the externally provided evaluate_sequence."""
    # evaluate_sequence expects a Python list
    return float(evaluate_sequence(seq.tolist()))


def _subgradient(a: np.ndarray, t_star: int) -> np.ndarray:
    """
    Sub‑gradient of max(a*a) at the index t_star.

    Parameters
    ----------
    a : ndarray, shape (n,)
        Current non‑negative vector (sum is 1).
    t_star : int
        Index of the maximal convolution entry.

    Returns
    -------
    g : ndarray, shape (n,)
        Sub‑gradient (zero where the pair does not contribute).
    """
    n = a.size
    g = np.zeros_like(a)

    # indices i for which a[t_star-i] is defined
    i_min = max(0, t_star - n + 1)
    i_max = min(n - 1, t_star)
    idx = np.arange(i_min, i_max + 1, dtype=int)
    partners = t_star - idx
    g[idx] = 2.0 * a[partners]

    # diagonal correction when i == t_star-i
    if t_star % 2 == 0:
        diag = t_star // 2
        if 0 <= diag < n:
            g[diag] = a[diag]          # not doubled
    return g


def _project_simplex(x: np.ndarray) -> np.ndarray:
    """Project a non‑negative vector onto the simplex sum(x)=1."""
    # Simple scaling – because we never generate negative numbers.
    s = x.sum()
    if s <= 0.0:
        # re‑initialise to uniform if everything vanished
        return np.full_like(x, 1.0 / x.size)
    return x / s


def _fft_convolve_self(a: np.ndarray, M: int) -> np.ndarray:
    """
    Linear convolution a * a using an FFT of length M (power of two).
    Returns the first 2·len(a)‑1 entries.
    """
    A = np.fft.rfft(a, n=M)
    B = A * A
    conv = np.fft.irfft(B, n=M)
    return conv[: 2 * a.size - 1]

    best_seq = base_seq.copy()
    best_score = _evaluate(best_seq)

    def maybe_update(candidate: np.ndarray) -> None:
        """Evaluate `candidate`; keep it if it improves the best score."""
        nonlocal best_seq, best_score
        cand = np.clip(candidate, 0.0, 1000.0)
        cand = _project_simplex(cand)
        sc = _evaluate(cand)
        if np.isfinite(sc) and sc < best_score:
            best_score = sc
            best_seq = cand.copy()
            print(f"New best score {best_score:.6f}")

    # ------------------------------------------------------------------
    # 1) Coarse parametric exploration (identical to the previous script)
    # ------------------------------------------------------------------
    idx = np.arange(n, dtype=np.float64)
    N = n - 1

    # pure exponential a_i = r**i
    for c in np.linspace(0.5, 4.0, 35):               # 0.5 … 4.0
        r = math.exp(-c / N)
        seq = r ** idx
        maybe_update(seq)
        for eps in (0.0, 0.02, 0.05):
            cand = seq + eps
            cand = cand / cand.max()
            maybe_update(cand)

    # power‑exponential a_i = (i+1)**α * r**i
    alphas = [-1.0, -0.5, 0.0, 0.5, 1.0]
    for alpha in alphas:
        for c in np.linspace(0.8, 2.5, 15):
            r = math.exp(-c / N)
            seq = (idx + 1.0) ** alpha * (r ** idx)
            seq = np.clip(seq, 0.0, None)
            if seq.max() == 0:
                continue
            seq = seq / seq.max()
            maybe_update(seq)

    # simple sinusoidal window
    sin_seq = np.sin(np.pi * (idx + 1.0) / (n + 1.0))
    maybe_update(sin_seq / sin_seq.max())

    # Hann window
    hann_seq = 0.5 * (1 - np.cos(2.0 * np.pi * idx / N))
    maybe_update(hann_seq / hann_seq.max())

    # polynomial decay a_i = (1 - i/N)^p
    for p in (0.5, 1.0, 2.0, 4.0):
        seq = (1.0 - idx / N) ** p
        maybe_update(seq / seq.max())

    # inverse power law a_i = 1/(i+1)^β
    for beta in (0.5, 1.0, 1.5, 2.0):
        seq = 1.0 / ((idx + 1.0) ** beta)
        maybe_update(seq / seq.max())

    # ------------------------------------------------------------------
    # 2) Sub‑gradient descent on max(a*a)
    # ------------------------------------------------------------------
    # start from the best candidate found so far
    a = best_seq.copy()
    a = _project_simplex(a)

    # FFT length – next power of two >= 2*n-1
    M = 1 << ((2 * n - 1).bit_length())

    # hyper‑parameters
    lr_initial = 0.6
    max_iters = 150_000
    momentum = 0.9
    vel = np.zeros_like(a)           # momentum vector
    stagnation_counter = 0           # counts iterations without improvement

    it = 0
    while time.monotonic() < deadline and it < max_iters:
        # ---- convolution a*a (linear, via FFT) ----
        b = _fft_convolve_self(a, M)

        # ---- index of the current maximum ----
        t_star = int(np.argmax(b))

        # ---- sub‑gradient at that index ----
        g = _subgradient(a, t_star)

        # ---- momentum update ----
        vel = momentum * vel + (1.0 - momentum) * g

        # ---- learning‑rate schedule (linear decay) ----
        lr = lr_initial * (1.0 - it / max_iters)

        # ---- gradient step + projection onto the simplex ----
        a = a - lr * vel
        a = np.maximum(a, 0.0)
        a = _project_simplex(a)

        # ---- occasional evaluation (cheap, no extra FFT) ----
        if it % 500 == 0:
            maybe_update(a)

        # ---- restart with a small random jitter if stuck ----
        if it % 5000 == 0 and it > 0:
            # if the best score has not improved for a while,
            # inject multiplicative log‑normal noise
            if stagnation_counter > 20000:
                jitter = np.exp(rng.normal(0.0, 0.04, size=n))
                a = best_seq * jitter
                a = _project_simplex(a)
                vel.fill(0.0)                 # reset momentum
                stagnation_counter = 0
            else:
                stagnation_counter += 5000

        it += 1

    # final check
    maybe_update(a)

    # ------------------------------------------------------------------
    # Return the best sequence (clipped to allowed range)
    # ------------------------------------------------------------------
    final = np.clip(best_seq, 0.0, 1000.0)
    print(f"Search completed – best score {best_score:.6f}")
    return final.tolist()
