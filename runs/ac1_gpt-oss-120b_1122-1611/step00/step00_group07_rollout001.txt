"""
Propose a candidate sequence that (almost) provably minimises the evaluation
function used by the competition.

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

For any non‑negative vector `a` of length `n` the Cauchy–Schwarz inequality gives

    sum_i a_i**2  >=  (sum_i a_i)**2 / n

and `max(conv(a, a))` is exactly `sum_i a_i**2` (the zero‑shift term of the
full convolution).  Consequently

    score >= 2 * n * (sum(a)**2 / n) / (sum(a)**2) = 2

with equality if and only if all entries are equal.  Therefore the
theoretical optimum is the uniform sequence, which attains the lower bound
`score = 2`.  No amount of random perturbation, optimisation or linear
programming can beat this bound under the given constraints.

The function below therefore

1. Determines the required length (uses the global `height_sequence_1`
   if it exists, otherwise falls back to 256).
2. Constructs the uniform sequence of that length.
3. Returns it immediately – if the uniform sequence already reaches the
   lower bound (within a tiny tolerance) there is nothing else to search.
4. As a safety net, a very cheap stochastic hill‑climber is run for the
   remaining time; it can only improve the score if the bound were not
   tight, otherwise it will stop quickly.

The implementation obeys all platform restrictions:
* No closures, no lambdas.
* Only top‑level functions are defined.
* Uses only `numpy`, `time` and the already‑imported `evaluate_sequence`.
* Prints a few diagnostics for debugging.
"""

import time
import numpy as np

def make_random_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Produce a cheap O(n) random perturbation of ``base``.
    The perturbation multiplies a randomly chosen contiguous block by a
    log‑normally distributed factor and then clips to the allowed range.
    """
    cand = base.copy()
    n = cand.size
    # block width between 1 and roughly n/2
    width = int(rng.integers(1, max(2, n // 2 + 1)))
    start = int(rng.integers(0, max(1, n - width + 1)))
    factor = float(np.exp(rng.normal(0.0, 0.25)))
    cand[start:start + width] *= factor
    # enforce the [0, 1000] safety interval used by evaluate_sequence
    np.clip(cand, 0.0, 1000.0, out=cand)
    return cand

    search in case the bound is not tight for the hidden test data.
    """
    rng = np.random.default_rng(seed)
    # allocate a small margin for finalisation prints
    deadline = time.monotonic() + max(0.0, float(budget_s) - 3.0)

    # Determine problem size

            raise ValueError
