The evaluation routine can be written analytically:

```
b = np.convolve(a, a)                # full convolution
max_b = max(b) = Σ a_i²                # because a_i ≥ 0
score = 2·n·max_b / (Σ a_i)²
      = 2·n· Σ a_i² / (Σ a_i)²
```

For a fixed length `n` the quantity  

`Σ a_i² / (Σ a_i)²` is minimized when all entries are equal (by the
Cauchy‑Schwarz / QM‑AM inequality).  With a uniform vector `a_i = c`

```
Σ a_i = n·c ,   Σ a_i² = n·c²  →  Σ a_i² / (Σ a_i)² = 1/n
score = 2·n·(1/n) = 2
```

Thus **the global optimum of the supplied objective is exactly `2.0`**,
independent of the sequence length or of the common value `c` (as long as
`c∈[0,1000]`).  
Any deviation from uniformity can only increase the score.

The search therefore reduces to:
1. Build a uniform, non‑negative sequence (any length is fine).  
2. Return it – it is provably optimal for the given evaluator.

The code below implements a tiny “search” framework that:
* starts from the provided `height_sequence_1` (if present) and replaces it
  by a uniform vector,
* checks the score once (for logging),
* respects the time budget, and
* finally returns the optimal uniform sequence.

Even though no further improvement is possible, the structure leaves room

"""
Uniform‑sequence optimizer for `evaluate_sequence`.

The function `propose_candidate` constructs a constant (uniform) non‑negative
sequence of the same length as `height_sequence_1` (or a safe fallback).
For the given evaluator this sequence attains the provable global minimum
score (= 2.0).  The implementation respects the supplied time budget and
logs the intermediate evaluation.
"""

import time
import numpy as np

def _uniform_sequence(length: int, value: float = 1.0) -> np.ndarray:
    """
    Return a NumPy array of shape (length,) where every entry equals `value`.
    The `value` is clipped to the evaluator's admissible range [0, 1000].
    """
    v = float(value)
    v = max(0.0, min(1000.0, v))
    return np.full(length, v, dtype=np.float64)


def _evaluate(seq: np.ndarray) -> float:
    """
    Wrapper around the globally available `evaluate_sequence`.
    It converts a NumPy array into a list, calls the evaluator,
    and returns the floating‑point result (or np.inf on error).
    """
    # The global function `evaluate_sequence` is assumed to be imported already.
    return float(evaluate_sequence(seq.tolist()))


def propose_candidate(seed: int = 42, budget_s: float = 1100, **kwargs) -> list[float]:
    """
    Search for the best coefficient sequence within the time budget.

    Parameters
    ----------
    seed : int, optional
        Random seed (unused by the uniform strategy but kept for API compatibility).
    budget_s : float, optional
        Total wall‑clock time allowed for the search (seconds).

    Returns
    -------
    list[float]
        The optimal uniform sequence (as a plain Python list of floats).
    """
    # ------------------------------------------------------------------
    # 1. Determine sequence length.
    # ------------------------------------------------------------------
    # `height_sequence_1` is a global variable supplied by the surrounding
    # framework; if it is missing or malformed we fall back to a modest size.
    try:
        base = np.asarray(height_sequence_1, dtype=np.float64)
        if base.ndim != 1 or base.size == 0 or not np.isfinite(base).all():
            raise ValueError
        length = int(base.size)
    except Exception:
        length = 256                      # safe fallback
        print("[propose_candidate] Using fallback length:", length)

    # ------------------------------------------------------------------
    # 2. Create the uniform candidate.
    # ------------------------------------------------------------------
    # The absolute value does not matter; we pick 1.0 for clarity.
    candidate = _uniform_sequence(length, value=1.0)
    best_score = _evaluate(candidate)
    print(f"[propose_candidate] Initial uniform candidate: length={length}, score={best_score:.12f}")

    # ------------------------------------------------------------------
    # 3. Simple time‑bounded loop (kept for compatibility with the
    #    original protocol).  No improvement can be found, but we keep
    #    the structure to respect the time budget.
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 0.5)  # spare ~0.5 s for finalisation
    rng = np.random.default_rng(seed)

    while time.monotonic() < deadline:
        # Random perturbation – kept only for demonstration; it never beats the uniform vector.
        perturb = rng.normal(loc=0.0, scale=0.02, size=length)
        trial = np.clip(candidate + perturb, 0.0, 1000.0)
        # Enforce uniformity by averaging; this restores the optimal shape.
        trial = np.full_like(trial, np.mean(trial))
        score = _evaluate(trial)
        if np.isfinite(score) and score < best_score:
            candidate = trial
            best_score = score
            print(f"[propose_candidate] Improved score found: {best_score:.12f}")

    # ------------------------------------------------------------------
    # 4. Return the best sequence (converted to a plain list).
    # ------------------------------------------------------------------
    print(f"[propose_candidate] Final best score: {best_score:.12f}")
    # Convert to Python floats as required by the framework
    return [float(x) for x in candidate]
