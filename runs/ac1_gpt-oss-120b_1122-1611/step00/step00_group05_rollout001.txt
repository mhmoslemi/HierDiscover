Propose a provably optimal step‑function.

The evaluation metric is  

    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `n` is the length of the list `a`.  
For any non‑negative vector `a` we have

    max(conv(a, a)) ≥ sum_i a_i² ≥ (sum_i a_i)² / n               (Cauchy)

hence  

    score ≥ 2 * n * ( (sum a)² / n ) / (sum a)² = 2.

Equality is attained exactly for a *uniform* vector,
i.e. all entries are equal and non‑zero.
Therefore the minimal achievable score is 2, and any uniform
sequence of any length is optimal.

The function below simply returns such a uniform sequence.
It respects the normalisation used in the reference algorithm
