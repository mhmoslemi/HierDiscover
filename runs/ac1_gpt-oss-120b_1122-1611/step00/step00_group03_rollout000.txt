Propose a sequence of non‑negative heights that (almost) minimizes
``evaluate_sequence``.

Mathematical observation
------------------------
For a non‑negative vector `a` of length *n*

    M = max_k (a * a)[k]  ≥  ∑ a_i²  (zero‑shift term)
    ∑ a_i² ≥ (∑ a_i)² / n        (Cauchy‑Schwarz)

Hence

    2·n·M / (∑ a_i)² ≥ 2

and the lower bound *2* is attained exactly when all entries are equal.
Therefore a constant sequence is provably optimal; any non‑constant
perturbation can only increase the score.

Implementation strategy
-----------------------
* Start from a constant sequence (the provably optimal shape).
* Run a very cheap stochastic “local‑search” loop that tries random
  perturbations – if by numerical luck a better (slightly smaller) score
  appears it is kept, otherwise the constant sequence remains.
* The loop stops a few seconds before the allotted wall‑time so the
  function always returns a valid answer.
* All helper functions are defined at module level; no closures or lambdas

that could be useful if the problem definition changes.

def constant_sequence(length: int, value: float = 1.0) -> np.ndarray:
    """Return a vector of size ``length`` filled with ``value``."""
    return np.full(length, float(value), dtype=np.float64)


def make_block_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Produce an O(n)‑time perturbation of ``base``.
    A random contiguous block is scaled multiplicatively by a log‑normal factor.
    With probability 0.35 the candidate is symmetrised.
    The result is clipped to the allowed range [0, 1000].
    """
    candidate = base.copy()
    n = candidate.size
    # width is chosen between n/200 and n/12 (at least 1 element)
    low = max(1, n // 200)
    high = max(2, n // 12)
    width = int(rng.integers(low, high + 1))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)

    # multiplicative log‑normal perturbation
    factor = float(np.exp(rng.normal(0.0, 0.12)))
    candidate[start:stop] *= factor

    # optional symmetrisation (helps to keep the shape “smooth”)
    if rng.random() < 0.35:
        candidate = 0.5 * (candidate + candidate[::-1])

    # enforce the problem‑specific bounds
    np.clip(candidate, 0.0, 1000.0, out=candidate)
    return candidate
