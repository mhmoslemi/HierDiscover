Propose candidate – Gradient‐descent flattening of the self‑convolution.

The evaluation metric for a non‑negative sequence `a` is
    2 * n * max(conv(a,a)) / (sum(a)^2) .
Because the expression is invariant under scaling, we may restrict
the search to probability vectors `p` (sum(p)=1).  Then the score
simplifies to `2 * n * max(p * p)`.  The goal is to make the discrete
convolution `c = p * p` as flat as possible, i.e. to minimise its
ℓ∞‑norm.

We parameterise a probability vector by logits `x` with a softmax:
    p_i = exp(x_i) / Σ_j exp(x_j) .
The objective `max(c)` is approximated by the smooth
log‑sum‑exp (LSE) of the convolution entries:
    F(p) = (1/α) * log Σ_i exp(α * c_i)   (α > 0).

The gradient of `F` w.r.t. the logits is obtained analytically:
    ∂F/∂p = 2 * (w ⋆ p)          where `w` are the LSE weights
    w_i = exp(α * c_i) / Σ_j exp(α * c_j)
    ⋆ denotes linear cross‑correlation.
    ∂F/∂x = p * (∂F/∂p − ⟨p,∂F/∂p⟩).

We iteratively update the logits with a simple projected gradient
descent (the softmax guarantees the simplex constraints).  Fast
FFT‑based convolution / correlation makes each iteration O(n log n).

Multiple restarts with different lengths and random initial logits are
performed until the time budget expires.  The best sequence found
(evaluated with the provided `evaluate_sequence`) is returned.  If no
improvement is obtained we fall back to a uniform distribution.
"""

import time

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()

    """Linear convolution via FFT (real inputs)."""
    n = len(a) + len(b) - 1
    L = _next_pow2(n)
    A = np.fft.rfft(a, n=L)
    B = np.fft.rfft(b, n=L)
    C = np.fft.irfft(A * B, n=L)

    n = len(a) + len(b) - 1

    A = np.fft.rfft(a, n=L)
    B = np.fft.rfft(b, n=L)
    C = np.fft.irfft(A * np.conj(B), n=L)
    return C[:n]


def propose_candidate(seed: int = 42, budget_s: float = 1100, **kwargs):
    """Return a non‑negative sequence that (hopefully) beats the current bound.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Wall‑clock budget in seconds.  The function stops a few seconds
        before the limit to avoid forced termination.

    Returns
    -------
    list[float]
        The best sequence found (values are already non‑negative).
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 3.0)

    best_seq = None
    best_score = float('inf')

    # Lengths to explore – they are powers of two for efficient FFT.
    candidate_lengths = [128, 256, 512, 1024, 2048]

    # Helper: evaluate and store a new best sequence.
    def _maybe_update(p_vec: np.ndarray):
        nonlocal best_seq, best_score
        seq = p_vec.tolist()
        score = float(evaluate_sequence(seq))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = p_vec.copy()
            print(f"New best score {best_score:.6f} (len={len(p_vec)})")
        return score

    # Main optimisation loop – keep trying new lengths until time runs out.
    while time.monotonic() < deadline:
        n = int(rng.choice(candidate_lengths))

        # Initialise logits.
        # Prefer the current best vector if it exists (trim / pad as needed).
        if best_seq is not None and len(best_seq) >= n:
            logits = np.log(best_seq[:n] + 1e-12)
        elif best_seq is not None and len(best_seq) < n:
            pad = np.full(n - len(best_seq), 1e-12)
            logits = np.log(np.concatenate([best_seq, pad]))
        else:
            # Uniform logits + a tiny random perturbation to break symmetry.
            logits = rng.normal(0.0, 0.02, size=n)

        # Hyper‑parameters (tuned for stability).
        alpha = 12.0          # LSE temperature – larger → sharper max approximation.
        step = 0.15           # Initial step size on logits.
        step_decay = 0.9995   # Multiplicative decay per iteration.
        max_iters = 4000      # Hard cap per length (still respects overall budget).

        for it in range(max_iters):
            if time.monotonic() >= deadline:
                break

            # ---------- Softmax to obtain a probability vector ----------
            max_logit = np.max(logits)
            p = np.exp(logits - max_logit)
            p /= p.sum()                     # Σ p = 1, p_i ≥ 0

            # ---------- Convolution p * p ----------
            conv = _convolve_fft(p, p)       # length 2n‑1

            # ---------- Smooth approximation of max(conv) ----------
            e = alpha * conv
            e_max = np.max(e)
            w = np.exp(e - e_max)            # w_i ∝ exp(α conv_i)
            w /= w.sum()                     # Σ w = 1

            # ---------- Gradient of the smooth max ----------
            # grad_p = 2 * (w ⋆ p)   (cross‑correlation)
            corr = _correlate_fft(w, p)      # length 3n‑2
            # For lag -l the index is (n‑1)‑l ; we need l = 0…n‑1
            grad_p = 2.0 * corr[n - 1 :: -1][:n]

            # ---------- Chain rule through the softmax ----------
            dot = np.dot(p, grad_p)          # scalar ⟨p,grad_p⟩
            grad_logit = p * (grad_p - dot)  # ∂F/∂x

            # ---------- Logit update ----------
            logits -= step * grad_logit
            step *= step_decay               # slowly shrink the step

            # ---------- Periodic evaluation ----------
            if (it & 31) == 0:               # every 32 iterations
                _maybe_update(p)
                if best_score <= 1.5025:    # target reached – stop early
                    break

            # Early exit if the smooth objective is already tiny
            if np.max(conv) * 2 * n <= 1.55:   # generous bound to stop early
                # (2*n*max(conv) is the exact score for a probability vector)
                _maybe_update(p)
                break

        # Check global termination condition.
        if best_score <= 1.5025 or time.monotonic() >= deadline:
            break

    # ---------- Fallback -----------------------------------------------------------------
    if best_seq is None:
        # Uniform distribution of modest size – guaranteed to give 2.0.
        n = 256
        best_seq = np.ones(n) / n
        best_score = float(evaluate_sequence(best_seq.tolist()))
        print(f"Fallback uniform sequence (score {best_score:.6f})")

    print(f"Final best score {best_score:.6f} with length {len(best_seq)}")
    # Converting to a plain list of Python floats for the caller.
    return [float(v) for v in best_seq]
