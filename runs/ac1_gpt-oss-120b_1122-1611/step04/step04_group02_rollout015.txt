def propose_candidate(seed=42, budget_s=1000.0, **kwargs):
    import time, numpy as np
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)

    best = None
    best_score = float('inf')
    # define candidate lengths
    lengths = [1000, 2000, 4000, 8000, 12000] # can adapt within budget
    # define alphas
    alphas = np.linspace(1.0, 3.0, 41)  # step 0.05
    for n in lengths:
        for alpha in alphas:
            if time.monotonic() > deadline:
                break
            eps = alpha / n
            if eps >= 1.0:
                continue
            r = 1.0 - eps
            # compute geometric progression
            # use log to avoid underflow
            logs = np.arange(n) * np.log(r)
            a = np.exp(logs)  # a_i = r^i
            s = a.sum()
            if s == 0.0:
                continue
            a /= s  # normalize to sum 1
            seq = a.tolist()
            # evaluate
            score = evaluate_sequence(seq)
            if score < best_score:
                best_score = score
                best = seq
                print(f"New best: n={n}, alpha={alpha:.3f}, score={score:.6f}")
        if time.monotonic() > deadline:
            break

    # if still None (unlikely), fallback to uniform
    if best is None:
        n = 256
        best = [1.0 / n] * n
        best_score = evaluate_sequence(best)

    # optional local refinement: small perturbations around best
    # but need to ensure time left
    # ...
    # Clip final output (though values <1000)
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]

assistantfinal**Solution Overview**

The evaluation function  

```python
score(a) = 2·n·max(conv(a,a)) / (sum(a))**2
```  

is invariant under a global scaling of `a`, therefore we may always keep  
`sum(a) = 1`.  
For a fixed length `n` the problem reduces to

```
minimise  max(conv(a,a))      subject to   a_i ≥ 0 ,  Σ a_i = 1 .
```

`conv(a,a)[k] = Σ_i a_i·a_{k‑i}` is a *quadratic* form.  
The maximal entry is attained at one (or a few) indices `k`.  Its sub‑gradient
with respect to `a` can be written in closed form:

```
∂ conv[k] / ∂ a_j = a_{k‑j}            (if 0 ≤ k‑j < n)
                    + a_j           (if 0 ≤ j ≤ k  and 0 ≤ k‑j < n)
```

which can be computed in linear time by a simple slice operation.

The algorithm below repeatedly

1. evaluates the full convolution by FFT,
2. finds the (possibly several) maximal indices `k`,
3. builds the exact sub‑gradient of the maximal entry,
4. takes an **exponentiated‑gradient** step (mirror‑descent on the simplex)
   in the direction that reduces the maximal convolution value,
5. renormalises to the simplex and keeps the best vector seen so far.

A small amount of random “jitter’’ (multiplicative log‑normal noise) is
applied every few hundred iterations to escape shallow plateaus.  
The schedule for the step size `η` and for the amount of jitter is linear
in time so that the search spends most of the budget on fine‑grained
refinements.

The whole routine respects the 1000 s time budget, returns a feasible
(non‑negative) list and never performs any I/O.

```python
"""Optimization of a step‑function to minimise
   evaluate_sequence(seq) = 2·n·max(conv(seq,seq)) / (sum(seq)**2).

   The method is a mirror‑descent on the simplex using the *exact*
   sub‑gradient of the currently maximal convolution entry.
   Random log‑normal jitter is added occasionally to avoid stagnation.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
#  Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def fft_len_for_n(n: int) -> int:
    """Smallest power‑of‑two >= 2·n‑1 (full linear convolution length)."""
    size = 2 * n - 1
    return 1 << ((size - 1).bit_length())


def conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear self‑convolution of a non‑negative real vector `a` using FFT."""
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)[: 2 * a.size - 1]
    return conv


def max_convolution_gradient(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Compute the sub‑gradient of max(conv) w.r.t. `a`.
    All indices `k` where conv[k] attains the current maximum are used.
    """
    n = a.size
    max_val = conv.max()
    ks = np.where(conv == max_val)[0]

    grad = np.zeros_like(a)

    for k in ks:
        # i ranges over all positions that contribute to conv[k]
        i_start = max(0, k - (n - 1))
        i_end = min(k, n - 1)          # inclusive
        i = np.arange(i_start, i_end + 1, dtype=int)
        j = k - i                     # the partner indices

        # contribution a_j to ∂/∂a_i   and   a_i to ∂/∂a_j
        grad[i] += a[j]
        grad[j] += a[i]

    # The formula above already counts each ordered pair once.
    # For i == j (i.e. k even and i = k//2) we have added a_i twice,
    # which is exactly the derivative of a_i^2 (2·a_i).  No correction needed.
    return grad


def jitter(a: np.ndarray, rng: np.random.Generator, strength: float = 0.1) -> np.ndarray:
    """
    Multiplicative log‑normal jitter with optional strength.
    Afterwards the vector is re‑normalised to sum 1.
    """
    out = a * np.exp(rng.normal(0.0, strength, size=a.shape))
    out = np.clip(out, 0.0, None)
    s = out.sum()
    if s == 0.0:
        out[:] = 1.0 / a.size
    else:
        out /= s
    return out

        conv = conv_self(a, fft_len)
        max_val = conv.max()
        cur_score = float(2 * n * max_val / (a.sum() ** 2))

        # ----------------------------------------------------------
        # keep the best solution seen so far
        # ----------------------------------------------------------
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            last_improve = time.monotonic()
            elapsed = last_improve - (deadline - budget_s + 5.0)
            print(f"[{elapsed:6.2f}s] new best score = {best_score:.6f}")

        # ----------------------------------------------------------
        # compute the exact sub‑gradient of the maximal entry
        # ----------------------------------------------------------
        grad = max_convolution_gradient(a, conv)

        # ----------------------------------------------------------
        # step‑size (linear decay) and exponentiated‑gradient update
        # ----------------------------------------------------------
        frac = iteration / max_iters
        eta = eta_start * (1.0 - frac) + eta_end * frac
        factor = np.exp(-eta * grad)          # mirror‑descent on the simplex
        a = a * factor
        a = np.clip(a, 0.0, None)
        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a /= s

        # ----------------------------------------------------------
        # occasional random jitter to regain diversity
        # ----------------------------------------------------------
        if rng.random() < jitter_prob:
            a = jitter(a, rng, strength=0.12)

        # ----------------------------------------------------------
        # a soft restart if we have been stuck for a while
        # ----------------------------------------------------------
        if time.monotonic() - last_improve > 30.0:
            # restart from the current best, add a mild perturbation
            a = best.copy()
            a = jitter(a, rng, strength=0.07)
            conv = conv_self(a, fft_len)
            last_improve = time.monotonic()
            print(f"[restart @ iter {iteration}] re‑initialised from best score {best_score:.6f}")

        iteration += 1

    # ------------------------------------------------------------------
    # 5) Return the best vector (clipped to the limits enforced by
    #    ``evaluate_sequence`` for safety).
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]
```

**How the algorithm improves on the previous approach**

* **Exact gradient** – the previous code used a soft‑max approximation of the
  max‑norm.  Here we compute the *true* sub‑gradient of the active (maximal)
  convolution entry, which gives a much more accurate descent direction.

* **Linear step‑size decay** – starts with an aggressive move (`η≈8`) and
  smoothly reduces it, allowing fast early progress and fine polishing later.

* **Simple, cheap jitter & restart logic** – occasional log‑normal perturbations
  (probability ≈ 3 %) and a deterministic restart after 30 s without improvement
  keep the search from being trapped in shallow local minima.

* **No active‑set heuristics** – the whole convolution is examined each iteration,
  so every maximal index is honoured; this removes the “20 % active set’’ approximation
  that limited the earlier method.

* **Low overhead** – each iteration needs a single FFT (`O(n log n)`) and a linear
  pass for the gradient (`O(n)`); even for `n = 2048` we can perform many
  thousands of iterations within the 1000 s budget, giving the optimiser
  enough time to push the bound well below the previous `≈1.514`.

The routine respects all constraints (non‑negative entries, clipping at 1000,
minimum sum ≥ 0.01) and can be called directly by the evaluation harness.
