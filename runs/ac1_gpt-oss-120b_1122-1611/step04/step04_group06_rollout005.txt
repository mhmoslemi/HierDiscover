the evaluation metric.  The idea is to use a monotone power law
distribution a_i ∝ (i+1)^p.  For p=0 we obtain the uniform bound
(score≈2); as p grows the self‑convolution at the centre becomes
approximately (p+1)^2·B(p+1,p+1)/n, yielding a score ≈2·(p+1)^2·B(p+1,p+1)
which quickly drops below the target 1.5025.  The routine scans a small
grid of exponents on a short vector (n=256) using evaluate_sequence,
keeps the best exponent, then builds a longer final sequence (≈3800)
with that exponent and returns it.
"""

    """

    (i+1)**p, i = 0,…,n‑1, normalised to unit sum.
    """
    # use 1‑based indices to avoid zero to the power.
    i = np.arange(1, n + 1, dtype=np.float64)
    a = np.power(i, p, dtype=np.float64)
    s = a.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n, dtype=np.float64)

"""
Search for a simple parametric step‑function that dramatically lowers the
evaluation metric.

The key observation is that for a distribution a_i ≥ 0 with Σa_i = 1
the score reduces to

    score = 2·n·max_k (a * a)_k .

If we choose a monotone power‑law shape

    a_i ∝ (i+1)^p ,   i = 0 … n‑1 ,

the convolution at the centre (shift n‑1) becomes

    (p+1)²·B(p+1,p+1) / n  ≈  r(p)/n ,

where B is the beta‑function and r(p) = (p+1)²·B(p+1,p+1) drops quickly as
p grows (r(0)=1, r(1)=2/3, r(2)=0.3, …).  Consequently

    score ≈ 2·r(p)

and can be made far below the target 1.5025 simply by taking p≈5–8.
The algorithm therefore:

1. Scans a grid of exponents p on a modest vector (n≈256) and keeps the
   exponent giving the smallest value reported by ``evaluate_sequence``.
2. Builds a longer final sequence (≈3800 entries, matching the length
   of the previous best construction) using the best exponent.
3. Returns the final sequence after clipping to the limits required by
   ``evaluate_sequence``.

The whole search fits easily inside the 1000 s budget and usually finishes
within a few seconds.
"""

import time
import numpy as np

def _power_distribution(p: float, n: int) -> np.ndarray:
    """
    Return a non‑negative vector of length *n* with entries proportional
    to (i+1)^p (i = 0,…,n‑1) and normalised to unit sum.
    """
    # indices 1 … n avoid the 0^p issue
    i = np.arange(1, n + 1, dtype=np.float64)
    a = np.power(i, p, dtype=np.float64)
    total = a.sum()
    if total == 0.0:
        # fallback to uniform – should never happen for p ≥ 0
        return np.full(n, 1.0 / n, dtype=np.float64)
    return a / total


def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Return a list of heights that (approximately) minimise
    ``evaluate_sequence`` before the time budget elapses.

    The method searches over the one‑parameter family a_i ∝ (i+1)^p.
    """

    start_time = time.monotonic()

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------
    n_grid = 256

        try:
