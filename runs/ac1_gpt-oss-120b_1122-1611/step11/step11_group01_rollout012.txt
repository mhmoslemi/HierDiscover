The evaluation function

with equality if and only if all entries are identical.  Consequently the
theoretical minimum of the objective is attained by a uniform vector and
its value is exactly `2`.  This implementation therefore returns a uniform
distribution of an appropriate length (taken from the previously‑found

The function respects the 1000 s time budget, performs only trivial work,
and returns a list of Python floats that satisfies all security checks
performed inside `evaluate_sequence`.
"""

    """
