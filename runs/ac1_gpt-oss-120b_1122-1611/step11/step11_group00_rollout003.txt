Simulated‑annealing optimiser for the convolution‑peak objective.

The algorithm works on the probability simplex (∑a_i = 1) and repeatedly

global Dirichlet jump.  Moves are accepted with a Metropolis criterion
using an exponentially decaying temperature schedule.  If no improvement
is observed for a while the current state is jittered around the best
solution seen so far.  The routine adapts the step size as the run
progresses and returns the best vector discovered before the time budget
expires.

import time

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())

def _conv_full(a: np.ndarray, fft_len: int, conv_len: int) -> np.ndarray:
    """Full linear convolution a * a using a real FFT (output length = conv_len)."""
    A = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(A * A, n=fft_len)[:conv_len]
    return conv
