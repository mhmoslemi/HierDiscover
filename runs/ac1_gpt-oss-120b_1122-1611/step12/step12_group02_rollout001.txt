The objective is  

\[
J(a)=\frac{2\,n\;\max\limits_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0
\]

which is scale‑invariant.  Consequently we may restrict ourselves to the
probability simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

For a fixed vector `a` let  

* `c = a*a`  (full linear convolution)  
* `M = max(c)`  

Then `J = 2·n·M`.  
The sub‑gradient of `M` w.r.t. `a` is the (scaled) correlation of the
active‑constraint mask with `a` :

\[
\partial M = 2\;{\rm corr}(w,a),\qquad
w_k =\begin{cases}
1 &\text{if }c_k\text{ is (approximately) maximal}\\
0 &\text{otherwise.}
\end{cases}
\]

We optimise directly on the **log‑it** representation

\[
a_i = \frac{e^{x_i}}{\sum_j e^{x_j}},                 \tag{soft‑max}
\]

so the simplex constraints are satisfied automatically.
Using the chain rule the gradient w.r.t. `x` is

\[
\frac{\partial J}{\partial x_i}
= a_i\Bigl(\partial M_i - \sum_j a_j\partial M_j\Bigr) .
\]

The optimisation loop is a **projected Adam** on the logits `x`.  
Key ingredients:

* **Full‑FFT convolution** (`_conv_full`) – `O(n log n)`.
* **Weighted correlation** (`_weighted_gradient`) – also FFT based.
* **Multiple random restarts** – five independent Adam instances are
  evolved in parallel.
* **Exploration steps** – periodic Gaussian jitter on the logits.
* **Time‑bounded loop** – stops a few seconds before the 1000 s budget.

The algorithm continually records the best vector found (according to the
original `evaluate_sequence`) and returns it after the time limit.

```python
"""
Gradient‑based optimisation of the auto‑convolution max‑norm on the simplex.

* Variables are stored as logits `x` (soft‑max yields a probability vector
  `a` that automatically satisfies the non‑negative and sum‑to‑1 constraints).
* In each iteration we
  – compute the full convolution via FFT,
  – build an active mask of the (almost) maximal convolution entries,
  – obtain a sub‑gradient of the max‑convolution using a weighted FFT‑correlation,
  – translate that gradient to logit‑space,
  – apply the Adam optimiser,
  – occasionally jitter the logits to escape plateaus.
* Five independent Adam processes run in parallel; the globally best
  probability vector is kept and finally returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – top level (no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def proj_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("Simplex projection works on 1‑D arrays")
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _conv_full(a: np.ndarray, fft_len: int, conv_len: int) -> np.ndarray:
    """Full linear convolution a*a using a real FFT."""
    A = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(A * A, n=fft_len)[:conv_len]
    return conv


def _weighted_gradient(a: np.ndarray, weight: np.ndarray,
                       fft_len_corr: int, n: int) -> np.ndarray:
    """
    Compute 2·corr(weight, a) efficiently via FFT.
    `weight` has length (2·n‑1), `a` has length n.
    Returns a gradient vector of length n.
    """
    # reverse a for correlation
    a_rev = a[::-1]
    W_hat = np.fft.rfft(weight, fft_len_corr)
    A_rev_hat = np.fft.rfft(a_rev, fft_len_corr)
    full = np.fft.irfft(W_hat * A_rev_hat, n=fft_len_corr)
    # the valid part of the correlation starts at index n‑1
    grad = 2.0 * full[n - 1:n - 1 + n]
    return grad


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max."""
    mx = np.max(x)
    e = np.exp(x - mx)
    return e / e.sum()


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345,
                     budget_s: float = 1000.0,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function (list of heights) that minimises
    `evaluate_sequence`.  Returns the best sequence found within the time budget.

    The optimiser is a multi‑restart Adam on the log‑it (soft‑max) parametrisation.
    """
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # 1. Problem size – use the size of the previous best if available
    # --------------------------------------------------------------
    if "height_sequence_1" in globals():
        try:
            n0 = len(globals()["height_sequence_1"])
            n = max(256, min(n0, 8192))
        except Exception:
            n = 4096
    else:
        n = 4096                     # default comfortable size

    conv_len = 2 * n - 1
    fft_len = _next_pow2(conv_len)                # length for a*a
    fft_len_corr = _next_pow2(conv_len + n - 1)   # length for correlation

    # --------------------------------------------------------------
    # 2. Adam hyper‑parameters
    # --------------------------------------------------------------
    beta1 = 0.9
    beta2 = 0.999
    eps_adam = 1e-8
    base_lr = 0.05                     # base learning rate for logits
    jitter_interval = 200              # iterations between jitter steps
    jitter_sigma0 = 0.2                # initial jitter magnitude

    # --------------------------------------------------------------
    # 3. Initialise a small pool of independent Adam runs
    # --------------------------------------------------------------
    n_runs = 5                         # parallel Adam instances
    runs = []                          # each entry is a dict with the state
    for r in range(n_runs):
        # Choose an initial probability vector
        if r == 0 and "height_sequence_1" in globals():
            a0 = np.asarray(height_sequence_1, dtype=np.float64)
            a0 = np.clip(a0, 0.0, None)
            if a0.shape[0] < n:
                a0 = np.concatenate([a0, np.zeros(n - a0.shape[0])])
            elif a0.shape[0] > n:
                a0 = a0[:n]
            s = a0.sum()
            if s > 0:
                a0 = a0 / s
            else:
                a0 = np.full(n, 1.0 / n)
        else:
            # Dirichlet draw, concentration parameter varies with run index
            alpha = [0.01, 0.05, 0.1, 0.3, 1.0][r % 5]
            a0 = rng.dirichlet(np.ones(n) * alpha)

        # Log‑it representation (add tiny epsilon to avoid log(0))
        eps = 1e-12
        x0 = np.log(a0 + eps)

        runs.append({
            "x": x0,
            "m": np.zeros(n, dtype=np.float64),
            "v": np.zeros(n, dtype=np.float64),
            "t": 0,                     # iteration counter for bias‑correction
            "best_J": np.inf,
            "best_a": None,
        })

    # --------------------------------------------------------------
    # 4. Track the globally best solution
    # --------------------------------------------------------------
    global_best_J = np.inf
    global_best_a = None
    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 5.0)   # safety margin

    # --------------------------------------------------------------
    # 5. Main optimisation loop
    # --------------------------------------------------------------
    iteration = 0
    last_print = start_time
    while time.monotonic() < deadline:
        for run in runs:
            # ----- (a) retrieve state -----
            x = run["x"]
            m = run["m"]
            v = run["v"]
            t = run["t"] + 1
            run["t"] = t

            # ----- (b) probability vector via soft‑max -----
            a = _softmax(x)               # sum(a) == 1, a_i ≥ 0

            # ----- (c) convolution and objective -----
            conv = _conv_full(a, fft_len, conv_len)
            max_c = conv.max()
            J = 2.0 * n * max_c

            # ----- (d) update global best -----
            if J < global_best_J - 1e-12:
                global_best_J = J
                global_best_a = a.copy()
                now = time.monotonic()
                print(f"[{now - start_time:6.2f}s] New global best J = {global_best_J:.6f}")

            # ----- (e) sub‑gradient of max‑convolution -----
            # active mask (allow a tiny tolerance)
            tol = max_c * 1e-12 + 1e-15
            active = (conv >= max_c - tol).astype(np.float64)

            # gradient w.r.t. a (sub‑gradient of max)
            grad_a = _weighted_gradient(a, active, fft_len_corr, n)

            # ----- (f) translate to logit‑gradient -----
            dot_ag = np.dot(a, grad_a)           # scalar = expectation of grad
            grad_x = a * (grad_a - dot_ag)       # shape (n,)

            # ----- (g) Adam update on logits -----
            m = beta1 * m + (1.0 - beta1) * grad_x
            v = beta2 * v + (1.0 - beta2) * (grad_x * grad_x)

            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)

            # learning rate schedule: slowly decrease with time
            elapsed = time.monotonic() - start_time
            lr = base_lr * (1.0 - elapsed / budget_s)   # linear decay to 0

            x = x - lr * m_hat / (np.sqrt(v_hat) + eps_adam)

            # ----- (h) store back -----
            run["x"] = x
            run["m"] = m
            run["v"] = v

        # ----------------------------------------------------------
        # occasional jitter to increase diversity
        # ----------------------------------------------------------
        if iteration % jitter_interval == 0 and iteration > 0:
            sigma = jitter_sigma0 * (1.0 - (time.monotonic() - start_time) / budget_s)
            for run in runs:
                run["x"] += rng.normal(scale=sigma, size=n)

        # ----------------------------------------------------------
        # periodic status output (every ~5 s)
        # ----------------------------------------------------------
        now = time.monotonic()
        if now - last_print >= 5.0:
            print(f"[{now - start_time:6.2f}s] Current global best J = {global_best_J:.6f}")
            last_print = now

        iteration += 1

    # ------------------------------------------------------------------
    # 6. Final post‑processing
    # ------------------------------------------------------------------
    if global_best_a is None:
        # fallback – uniform distribution
        global_best_a = np.full(n, 1.0 / n, dtype=np.float64)

    # Clip to allowed numeric range and renormalise (should already be fine)
    global_best_a = np.clip(global_best_a, 0.0, 1000.0)
    s = global_best_a.sum()
    if s == 0.0:
        global_best_a[:] = 1.0 / n
    else:
        global_best_a /= s

    # Optional sanity check with evaluate_sequence (commented out for speed)
    # try:
    #     val = evaluate_sequence(global_best_a.tolist())
    #     print(f"Final evaluate_sequence = {val:.6f}")
    # except Exception:
    #     pass

    return [float(v) for v in global_best_a]
```
