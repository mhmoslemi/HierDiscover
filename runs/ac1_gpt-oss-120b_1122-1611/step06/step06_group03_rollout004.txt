The objective  

\[
\text{score}(a)=\frac{2\,n\,\max\bigl((a*a)_k\bigr)}{\Bigl(\sum_i a_i\Bigr)^2}
\]

is *scale‑invariant*, therefore we keep the vector on the probability simplex  
\(\sum_i a_i = 1\) and minimise  

\[
f(a)=2\,n\;\max_k (a*a)_k .
\]

`max` is non‑smooth, so we smooth it with a soft‑max:

\[
\phi_\beta(a)=\frac1\beta\log\!\Bigl(\sum_k e^{\beta\,(a*a)_k}\Bigr),
\qquad
\frac{\partial\phi_\beta}{\partial a}
   = 2\;a\star w,
\qquad
w_k=\frac{e^{\beta\,(a*a)_k}}{\sum_j e^{\beta\,(a*a)_j}} .
\]

`w` is a probability distribution over the convolution indices, `a⋆w` is the
cross‑correlation of `a` with `w`.  
Using an **exponentiated‑gradient** (mirror descent on the simplex) we obtain

```
a ← a ⊙ exp(-η·∇φβ(a))          (⊙ = element‑wise product)
```

followed by a projection onto the simplex (simple renormalisation).

The algorithm works in three phases:

1. **Initial candidates** – analytic √‑difference, uniform, a few power‑law
   shapes, a few Dirichlet samples and the optional global
   `height_sequence_1`. The best of them (according to the fast FFT score)
   seeds the optimisation.

2. **Smoothed gradient descent** – β is increased from a small value (smooth
   landscape) to a large value (approaches the true max). The learning rate η
   is decreased simultaneously.  
   In each iteration we:
   * compute the self‑convolution by FFT,
   * build the soft‑max weights `w`,
   * obtain the gradient via a cheap *active‑set* correlation
     (only the indices whose convolution value is within 0.2 % of the current
     maximum are used – usually < 20 entries),
   * perform the exponentiated‑gradient step with momentum,
   * occasionally (≈ 2 % of the steps) apply a random block‑scale jitter
     to escape shallow local minima.

3. **Polishing** – after the main loop the current best vector is refined
   with a few extra gradient steps at a high β, still using the active‑set
   method.

All operations are `O(n log n)` per iteration (FFT) and the active‑set
gradient costs at most `max_active·n` elementary operations (`max_active≈30`).
Even for `n≈4000` the code comfortably stays within the 1000 s budget.

The final vector is clipped to the limits imposed by `evaluate_sequence`
and returned as a plain Python list.

```python
"""
Propose a step‑function that minimises
    score = 2·n·max(a*a) / (sum a)^2

Algorithm
---------
* build several simple starting vectors (sqrt‑difference, uniform,
  power‑law, Dirichlet, optional global construction) and keep the best.
* run a smoothed gradient descent on the simplex:
    - soft‑max over the convolution (parameter β grows from 1 to 500)
    - exponentiated‑gradient update with decreasing step size η
    - momentum on the gradient
    - occasional random block‑scale jitter for exploration
    - gradient is evaluated only on an active set of indices whose
      convolution value is within 0.2 % of the current maximum (≤30 indices)
* finish with a short polishing phase at high β.
* return the best vector found (clipped to [0,1000]).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper FFT utilities
# ----------------------------------------------------------------------
def _fft_len_for_n(n: int) -> int:
    """Smallest power‑of‑two length able to hold the linear convolution of two vectors of length n."""
    size = 2 * n - 1
    return 1 << ((size - 1).bit_length())


def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a * a via real FFT."""
    fa = np.fft.rfft(a, n=fft_len)
    fc = fa * fa
    conv = np.fft.irfft(fc, n=fft_len)[: 2 * a.size - 1]
    return conv


def _compute_score(a: np.ndarray, fft_len: int) -> float:
    """Fast evaluation of the objective for a vector already normalised to sum = 1."""
    conv = _conv_self(a, fft_len)
    return 2.0 * a.size * float(conv.max())


# ----------------------------------------------------------------------
# Initial candidate generators
# ----------------------------------------------------------------------
def _analytic_start(n: int) -> np.ndarray:
    """√‑difference start: a_i = √(i+1)‑√i, normalised to sum = 1."""
    i = np.arange(n, dtype=np.float64)
    a = np.sqrt(i + 1.0) - np.sqrt(i)
    a /= a.sum()
    return a


def _maybe_use_global() -> np.ndarray | None:
    """If a previous construction exists as a global variable, return its normalised copy."""
    if "height_sequence_1" in globals():
        try:
            cand = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
            if cand.ndim == 1 and cand.size >= 2 and np.isfinite(cand).all():
                cand = np.clip(cand, 0.0, None)
                s = cand.sum()
                if s > 0.0:
                    return cand / s
        except Exception:
            pass
    return None


# ----------------------------------------------------------------------
# Gradient (active‑set) utilities
# ----------------------------------------------------------------------
def _active_gradient(a: np.ndarray, conv: np.ndarray, beta: float,
                     max_active: int = 30) -> np.ndarray:
    """
    Gradient of the softened max using only indices whose convolution value
    is within 0.2 % of the current maximum.
    """
    n = a.size
    maxb = float(conv.max())
    # active set (top values, tolerance 0.2 %)
    tol = maxb * 0.998
    active = np.where(conv >= tol)[0]
    if active.size > max_active:
        # keep the largest `max_active` entries
        active = np.argpartition(conv, -max_active)[-max_active:]
    # soft‑max weights on the active set
    w_raw = np.exp(beta * (conv[active] - maxb))
    w = w_raw / w_raw.sum()

    grad = np.zeros_like(a)
    for idx, weight in zip(active, w):
        # the contribution of a_i to (a*a)_idx is a_{idx-i}
        lo = max(0, idx - (n - 1))
        hi = min(n - 1, idx)
        rng = np.arange(lo, hi + 1, dtype=np.int64)
        grad[rng] += weight * 2.0 * a[idx - rng]
    return grad


# ----------------------------------------------------------------------
# Polishing helper (high‑β, few steps)
# ----------------------------------------------------------------------
def _polish(a: np.ndarray, fft_len: int, deadline: float,
            start_score: float) -> tuple[np.ndarray, float]:
    """
    Very short deterministic polishing at a large β.
    Returns the best vector seen and its (exact) score.
    """
    best = a.copy()
    best_score = start_score
    grad_prev = np.zeros_like(a)

    # schedules
    eta_start, eta_end = 0.08, 0.002
    beta = 500.0
    momentum = 0.85
    max_active = 30

    start_time = time.monotonic()
    while time.monotonic() < deadline:
        conv = _conv_self(a, fft_len)
        cur_score = 2.0 * a.size * float(conv.max())
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            print(f"[{time.monotonic() - start_time:6.2f}s] polish: new best = {best_score:.6f}")

        # gradient on (almost) true max
        grad = _active_gradient(a, conv, beta, max_active=max_active)

        # momentum
        grad = momentum * grad_prev + (1.0 - momentum) * grad
        grad_prev = grad

        # diminishing step size
        now = time.monotonic()
        elapsed = now - start_time
        total = deadline - start_time
        eta = eta_start * (1.0 - elapsed / total) + eta_end * (elapsed / total)

        factor = np.exp(np.clip(-eta * grad, -700, 700))
        a = a * factor
        a = np.clip(a, 0.0, None)
        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / a.size)
        else:
            a /= s

        if time.monotonic() > deadline - 0.1:
            break
    return best, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Return a list of non‑negative heights that (approximately) minimises
    ``evaluate_sequence`` before the time budget elapses.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Problem size
    # ------------------------------------------------------------------
    n = int(kwargs.get("n", 3800))
    if n < 2:
        n = 2
    fft_len = _fft_len_for_n(n)

    # ------------------------------------------------------------------
    # Build a small pool of starting vectors
    # ------------------------------------------------------------------
    starts = []

    # analytic √‑difference
    starts.append(_analytic_start(n))

    # uniform
    starts.append(np.full(n, 1.0 / n))

    # power‑law families  a_i ∝ (i+1)^{-p}
    for p in (0.3, 0.5, 0.7, 1.0, 1.3, 1.5):
        a = (np.arange(1, n + 1, dtype=np.float64) ** (-p))
        a /= a.sum()
        starts.append(a)

    # a few Dirichlet samples
    for _ in range(3):
        starts.append(rng.dirichlet(np.ones(n)))

    # optional global construction
    cand_global = _maybe_use_global()
    if cand_global is not None:
        starts.append(cand_global)

    # ------------------------------------------------------------------
    # Pick the best among the pool (fast internal score)
    # ------------------------------------------------------------------
    best = None
    best_score = np.inf
    for a0 in starts:
        sc = _compute_score(a0, fft_len)
        if sc < best_score:
            best_score = sc
            best = a0.copy()

    # ------------------------------------------------------------------
    # Book‑keeping
    # ------------------------------------------------------------------
    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 1.0)   # keep 1 s safety margin
    print(f"Starting optimisation, n={n}, initial score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Parameters for the smoothed gradient descent
    # ------------------------------------------------------------------
    eta_start, eta_end = 0.5, 0.02            # step‑size schedule
    beta_start, beta_end = 1.0, 500.0        # smoothing schedule
    momentum = 0.85
    max_active = 30                          # active‑set cap
    sigma_block = 0.25                       # jitter amplitude
    block_jitter_prob = 0.02                 # how often we perturb artificially
    grad_prev = np.zeros_like(best)

    a = best.copy()
    cur_score = best_score
    last_improve = start_time

    while time.monotonic() < deadline:
        now = time.monotonic()
        elapsed = now - start_time
        total = deadline - start_time
        frac = elapsed / total

        # schedules
        eta = eta_start * (1.0 - frac) + eta_end * frac
        beta = beta_start * (1.0 - frac) + beta_end * frac

        # --------------------------------------------------------------
        # convolution and exact score
        # --------------------------------------------------------------
        conv = _conv_self(a, fft_len)
        maxb = float(conv.max())
        cur_score = 2.0 * n * maxb
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            last_improve = now
            print(f"[{now - start_time:6.2f}s] new best score = {best_score:.6f}")

        # --------------------------------------------------------------
        # gradient (soft‑max on an active set)
        # --------------------------------------------------------------
        grad = _active_gradient(a, conv, beta, max_active=max_active)

        # momentum
        grad = momentum * grad_prev + (1.0 - momentum) * grad
        grad_prev = grad

        # --------------------------------------------------------------
        # exponentiated‑gradient update on the simplex
        # --------------------------------------------------------------
        factor = np.exp(np.clip(-eta * grad, -700, 700))
        a = a * factor
        a = np.clip(a, 0.0, None)

        # occasional random block‑scale jitter (exploration)
        if rng.random() < block_jitter_prob:
            width = rng.integers(1, max(2, n // 20))
            start = rng.integers(0, n - width + 1)
            factor_j = np.exp(rng.normal(0.0, sigma_block))
            a[start:start + width] *= factor_j

        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a /= s

        # ------------------------------------------------------------------
        # Early exit safeguard
        # ------------------------------------------------------------------
        if now > deadline - 0.2:
            break

    # ------------------------------------------------------------------
    # Polishing phase (high β, limited time)
    # ------------------------------------------------------------------
    remaining = deadline - time.monotonic()
    if remaining > 5.0:
        polish_deadline = time.monotonic() + remaining
        best, best_score = _polish(best, fft_len, polish_deadline, best_score)

    # ------------------------------------------------------------------
    # Final clipping required by evaluate_sequence()
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    final_score = evaluate_sequence(best.tolist())
    print(f"Finished: final score = {final_score:.6f} (internal best = {best_score:.6f})")
    return [float(v) for v in best]
