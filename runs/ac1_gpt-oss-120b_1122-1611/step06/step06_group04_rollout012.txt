We search for a non‑negative step‑function `a = (a₀,…,a_{n‑1})` that minimizes  

```
score(a) = 2·n·maxₖ (a * a)_k                (1)
```

where “*” is the linear (full) convolution.  
`evaluate_sequence` returns exactly this score after clipping the
elements to the interval [0, 1000] and guaranteeing a non‑zero sum,
therefore any candidate with the same `score` is optimal for the
challenge.

The optimisation problem is convex in the *soft‑max* surrogate of the
maximum, but the true objective (1) is non‑smooth.  Our method combines
the smooth surrogate (to obtain a good search direction) with a final
*hard‑max* phase that directly follows the sub‑gradient of the true
objective.  The main ingredients are

* **FFT based convolution** – `O(n log n)`.
* **Projection onto the probability simplex** – guarantees non‑negative
  coefficients and unit sum (the scale does not matter because the
  objective is homogeneous).
* **Adam optimizer** – adaptive steps for fast convergence.
* **Two‑phase schedule**  

  *Phase A* – `β` (soft‑max temperature) grows from `0.5` to a large
  value; we minimise the smooth surrogate.
  *Phase B* – the active set (`conv == max`) is used as a hard weight
  vector – a true sub‑gradient of the max‑function.
* **Escapes & restarts** – occasional multiplicative log‑normal noise,
  random pairwise mass transfers and a time‑based full restart with a
  small jitter around the best solution found so far.

The routine respects the 1000 s budget, continuously prints progress and
returns the best sequence discovered.

```python
"""
Propose a step‑function that minimises evaluate_sequence.

Algorithm
---------
* Work on the probability simplex (∑a_i = 1).  The objective
  depends only on the shape, not on the scale.
* Initialise from a known construction or from a random Dirichlet
  distribution.
* Optimise in two phases:
    – Phase A (soft‑max):  minimise a smooth surrogate
      f_β(a) = (1/β)·log Σₖ exp(β·(a*a)_k) using Adam.
    – Phase B (hard‑max):  after 70 % of the time replace the
      soft‑max weights by a hard mask (conv == max) – this is a
      sub‑gradient of the true max‑function.
* Occasionally inject multiplicative log‑normal noise and perform a
  random mass‑transfer to escape shallow minima.
* If no improvement is seen for a while, restart from the current best
  plus a small jitter.
* The loop runs until the time budget (≈1000 s) is exhausted and returns
  the best vector found (clipped to the limits of evaluate_sequence).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: smallest power‑of‑two ≥ 2·n‑1 (FFT length for a linear convolution)
# ----------------------------------------------------------------------
def _fft_len_for_n(n: int) -> int:
    """Return next power‑of‑two ≥ 2·n‑1, suitable for an FFT."""
    size = 2 * n - 1
    return 1 << ((size - 1).bit_length())


# ----------------------------------------------------------------------
# Linear self‑convolution via FFT (real‑valued inputs)
# ----------------------------------------------------------------------
def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Return the full linear convolution a*a (length = 2·len(a)‑1)."""
    fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[: 2 * a.size - 1]
    return conv


# ----------------------------------------------------------------------
# Correlation needed for the gradient of Σₖ wₖ (a*a)_k .
# ----------------------------------------------------------------------
def _gradient_correlation(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute ∇_a Σₖ wₖ (a*a)_k = 2·a ⋆ w   (⋆ = correlation).

    Parameters
    ----------
    a : (n,)   – current probability vector
    w : (2n‑1,) – weight vector (soft‑max or hard mask)

    Returns
    -------
    grad : (n,) – sub‑gradient of the weighted sum of convolutions
    """
    n = a.size
    L = w.size  # = 2·n‑1
    # Length needed for linear correlation = L + n – 1 = 3·n – 2
    fft_len = 1 << ((L + n - 2 - 1).bit_length())
    fw = np.fft.rfft(w, n=fft_len)
    # reversed a for correlation
    fa_rev = np.fft.rfft(a[::-1], n=fft_len)
    corr_full = np.fft.irfft(fw * fa_rev, n=fft_len)[: L + n - 1]
    start = n - 1
    grad = 2.0 * corr_full[start:start + n]
    return grad


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex {x≥0, Σx=1}
# ----------------------------------------------------------------------
def _proj_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto the simplex (non‑negative, unit sum)."""
    if v.ndim != 1:
        raise ValueError("v must be one‑dimensional")
    # Sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # Zero vector – return uniform distribution
        return np.full_like(v, 1.0 / len(v))
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    # Numerical cleanup – enforce exact sum 1
    s = w.sum()
    if s > 0:
        w /= s
    else:
        w = np.full_like(v, 1.0 / len(v))
    return w


# ----------------------------------------------------------------------
# Main optimisation routine – returns the best sequence found.
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: float = 1000.0,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative height sequence that minimises the
    ``evaluate_sequence`` objective within the given time budget.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.
    n : int, optional
        Length of the step sequence (default 3800, the size used in the
        reference implementation).

    Returns
    -------
    list[float]
        The best sequence discovered (values clipped to the limits
        enforced by ``evaluate_sequence``).
    """
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # Problem size
    # --------------------------------------------------------------
    n = int(kwargs.get("n", 3800))
    if n < 2:
        n = 2
    fft_len = _fft_len_for_n(n)

    # --------------------------------------------------------------
    # Initial vector – try the analytic “sqrt‑difference’’ start, but fall
    # back to uniform if a better historic construction is not available.
    # --------------------------------------------------------------
    i = np.arange(n, dtype=np.float64)
    a0 = np.sqrt(i + 1.0) - np.sqrt(i)          # Δ√i
    a0 /= a0.sum()                              # unit‑sum

    # If a previously found construction is present, use it when it looks
    # promising.
    if "height_sequence_1" in globals():
        try:
            cand = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
            if cand.ndim == 1 and cand.size > 0 and np.isfinite(cand).all():
                cand = np.clip(cand, 0.0, None)
                s = cand.sum()
                if s > 0.0:
                    cand /= s
                    # quick surrogate score (soft‑max with large β)
                    conv_c = _conv_self(cand, _fft_len_for_n(cand.size))
                    score_c = 2.0 * cand.size * conv_c.max()
                    score_a = 2.0 * n * _conv_self(a0, fft_len).max()
                    if score_c < score_a:
                        a0 = cand
                        n = cand.size
                        fft_len = _fft_len_for_n(n)
        except Exception:
            pass

    # --------------------------------------------------------------
    # Optimisation state
    # --------------------------------------------------------------
    a = a0.copy()
    best = a.copy()
    best_score = 2.0 * n * np.max(_conv_self(best, fft_len))

    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 1.0)  # small safety margin
    last_improve = start_time

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    t = 0

    # Schedules
    lr_start, lr_end = 0.25, 0.001
    # soft‑max temperature grows from 0.5 to 2500 in the first phase
    beta_start, beta_end = 0.5, 2500.0

    # Random‑perturbation parameters
    noise_prob, noise_sigma = 0.04, 0.14
    swap_prob = 0.07
    restart_gap = 120.0  # seconds without improvement → restart

    # --------------------------------------------------------------
    # Main optimisation loop
    # --------------------------------------------------------------
    while time.monotonic() < deadline:
        now = time.monotonic()
        elapsed = now - start_time
        total = deadline - start_time
        ratio = min(1.0, elapsed / total)

        # ---------- learning‑rate and temperature ----------
        lr = lr_start * (1.0 - ratio) + lr_end * ratio
        # Phase A (soft‑max) → first 70 % of the budget, otherwise hard mask
        if ratio < 0.70:
            beta = beta_start + (beta_end - beta_start) * (ratio / 0.70)
        else:
            # In Phase B we ignore the soft‑max temperature; the flag is kept
            # only to keep the variable name tidy.
            beta = None

        # ---------- convolution and current score ----------
        conv = _conv_self(a, fft_len)                     # length 2·n‑1
        cur_max = float(conv.max())
        cur_score = 2.0 * n * cur_max

        # ---------- keep the current best ----------
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            last_improve = now
            print(f"[{elapsed:6.2f}s] new best score = {best_score:.6f}")

        # ---------- compute weights ----------
        if ratio < 0.70:
            # soft‑max weights – numerically stable
            diff = conv - cur_max                # ≤ 0
            w_raw = np.exp(beta * diff)
            w_sum = w_raw.sum()
            if w_sum == 0.0 or not np.isfinite(w_sum):
                # fallback to uniform weight on the maximal indices
                mask = conv == cur_max
                w_raw = np.where(mask, 1.0, 0.0)
                w_sum = w_raw.sum()
            w = w_raw / w_sum
        else:
            # hard‑max sub‑gradient: equal weight on all active maximal indices
            mask = conv == cur_max
            w = mask.astype(float) / mask.sum()

        # ---------- gradient ----------
        grad = _gradient_correlation(a, w)          # shape (n,)

        # ---------- Adam update ----------
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a = a - step

        # ---------- projection onto the simplex ----------
        a = _proj_simplex(a)

        # ---------- occasional stochastic moves ----------
        if rng.random() < noise_prob:
            # multiplicative log‑normal jitter
            factor = np.exp(rng.normal(0.0, noise_sigma, size=n))
            a = a * factor
            a = _proj_simplex(a)

        if rng.random() < swap_prob:
            i, j = rng.integers(0, n, size=2)
            if i != j and a[i] > 1e-15:
                delta = rng.random() * a[i] * 0.5
                a[i] -= delta
                a[j] += delta
                a = _proj_simplex(a)

        # ---------- restart if we are stuck ----------
        if now - last_improve > restart_gap:
            a = best.copy()
            jitter = np.exp(rng.normal(0.0, 0.12, size=n))
            a = a * jitter
            a = _proj_simplex(a)
            m = np.zeros_like(a)
            v = np.zeros_like(a)
            t = 0
            last_improve = now
            print(f"[{elapsed:6.2f}s] restart – best score still {best_score:.6f}")

    # ------------------------------------------------------------------
    # Return the best sequence (apply the clipping performed by
    # evaluate_sequence – it only trims to [0, 1000]).
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]
```
