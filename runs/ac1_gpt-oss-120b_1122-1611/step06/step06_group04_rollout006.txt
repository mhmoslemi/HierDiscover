def propose_candidate(seed=42, budget_s=1000.0, n=None):
    rng = np.random.default_rng(seed)
    start_time = time.monotonic()
    deadline = start_time + max(0.0, budget_s - 1.0) # give margin for final compute.

    if n is None: n = int(3800) (maybe read from global config? Let's use default 3800)
    i = np.arange(n, dtype=np.float64)

    # Baseline sqrt-diff shape
    a_sqrt = np.sqrt(i + 1.0) - np.sqrt(i)
    a_sqrt = a_sqrt / a_sqrt.sum()
    best = a_sqrt.copy()
    best_score = compute_score(best)

    # Output baseline
    print(f"Baseline sqrt-diff score: {best_score}")

    # Parameter grid
    gammas = np.linspace(0.45, 0.58, 29) maybe narrower focusing near 0.5; shift_range = np.linspace(0.0, 3.0, 31)
    for gamma in gammas:
        # break if time
        if time.monotonic() > deadline:
            break
        # compute power base term once maybe using pow?
        # We'll loop delta inside
        for delta in shift_range:
            # compute shape
            a_i = np.power(i + 1 + delta, gamma) - np.power(i + delta, gamma)
            tot = np.power(n + delta, gamma) - np.power(delta, gamma)
            a = a_i / tot
            score = compute_score(a)
            if score < best_score:
                best_score = score
                best = a.copy()
                print(f"New best: score {best_score:.6f} with gamma {gamma:.4f}, delta {delta:.4f}")

    # Mixing with uniform base
    uniform = np.full(n, 1.0 / n)
    for lam in np.linspace(0.0, 0.2, 21):
        if time.monotonic() > deadline:
            break
        a_mix = (1 - lam) * best + lam * uniform
        a_mix = a_mix / a_mix.sum()
        score = compute_score(a_mix)
        if score < best_score:
            best_score = score
            best = a_mix.copy()
            print(f"New best after mixing: score {best_score:.6f}, lambda {lam:.3f}")

    # Local subgradient descent (Adam)
    # initialize a = best copy
    a = best.copy()
    m = np.zeros_like(a)
    vvec = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0
    # schedule: lr decays linearly from 0.2 to 0.001 over remaining time
    while time.monotonic() < deadline:
        n = a.size
        # compute conv and max
        conv = _conv_self(a, _fft_len_for_n(n))
        maxb = conv.max()
        score = 2.0 * n * maxb
        if score < best_score - 1e-12:
            best_score = score
            best = a.copy()
            print(f"[{time.monotonic() - start_time:.2f}s] Updated best during descent: {best_score:.6f}")

        # Identify mask of max entries
        mask = (conv == maxb)
        w = mask.astype(float)
        # Compute gradient
        grad = _gradient_correlation(a, w)   # shape (n,)
        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad
        vvec = beta2 * vvec + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = vvec / (1.0 - beta2 ** t)
        # Linear schedule of lr
        elapsed = time.monotonic() - start_time
        remaining = deadline - start_time
        ratio = min(1.0, elapsed / remaining)
        lr = 0.2 * (1 - ratio) + 0.001 * ratio
        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        a = a - step
        # Project back onto simplex
        a = _proj_simplex(a)
        # optional random perturbation occasional
        if rng.random() < 0.01:
            # log-normal noise
            factor = np.exp(rng.normal(0.0, 0.1, size=n))
            a = a * factor
            a = _proj_simplex(a)

    # After loop, final best
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]

The objective after the mandatory normalisation (∑ aᵢ = 1) is  

```
score = 2·n·maxₖ (a * a)[k]                (1)
```

`a * a` is the linear self‑convolution of the non‑negative vector `a`.  
The score depends only on the *shape* of `a` – any global scaling cancels out
(because `evaluate_sequence` clips values to [0, 1000] and the sum is fixed to 1).

A large family of shapes can be generated analytically:

* **Power‑difference shape**  
  `fγ,δ(i) = ( (i+1+δ)ᵞ – (i+δ)ᵞ )` ,  i = 0…n‑1  

  After normalisation `a = fγ,δ / Σ fγ,δ` the vector is a discrete version of the
  density of a *Beta(γ,1)* distribution (γ≈½ gives the previously used
  “√‑difference” curve).  
  The two parameters γ > 0 and δ ≥ 0 give us a 2‑dimensional search space.

* **Log‑difference shape** (the limit γ→0)  
  `gα(i) = log(i+1+α) – log(i+α)`  
  also yields a decreasing distribution with a single parameter α > 0.

Both families are cheap to evaluate – a single score needs one FFT‑based
convolution (≈ 10⁵ elementary operations for n≈3800).  
Hence we can scan thousands of parameter combinations well inside the 1000 s
budget.

The algorithm is:

1. **Baseline** – the classical √‑difference shape.
2. **Full grid search** over `(γ,δ)` and over `α` for the log‑difference family.
   The best vector (lowest score) is kept.
3. **Mixing with a uniform component** – a convex combination  
   `aₘᵢₓ = (1‑λ)·a_best + λ·uniform`, λ ∈ [0, 0.2].  Normalisation and projection
   are applied; we keep any improvement.
4. **Local refinement** – a projected Adam optimiser that works on the *exact*
   non‑smooth objective (uses the true max‑mask as sub‑gradient).  The learning
   rate decays linearly; the optimiser runs only for the remaining time.
5. **Optional stochastic hill‑climbing** – random mass transfers between two
   coordinates are tried; any improvement is accepted.
6. The best vector found is clipped to the limits imposed by `evaluate_sequence`
   and returned.

All heavy work is performed with NumPy and FFT, no external solvers are used,
and the whole routine respects the 1000 s time budget.

```python
"""
Propose a non‑negative step‑function that minimises ``evaluate_sequence``.

Algorithm
---------
* The search space is restricted to two analytically‑motivated families:
  – power‑difference shape  a_i ∝ (i+1+δ)^γ – (i+δ)^γ
  – log‑difference shape    a_i ∝ log(i+1+α) – log(i+α)
* A dense grid over the parameters (γ,δ) and α is evaluated using an FFT‑based
  convolution (O(n log n)) – this yields thousands of candidates in a few seconds.
* The best candidate is optionally mixed with a uniform distribution and
  refined with a projected Adam optimiser that works on the real L∞‑objective
  (sub‑gradient = 2·corr(a, w) where w is the indicator of the maximal
  convolution entries).
* A cheap random “mass‑transfer” hill‑climber is applied afterwards.
* The routine stops before the 1000 s deadline and returns the best vector
  (clipped to [0, 1000]).

The approach improves upon the previous soft‑max Adam method by exploring a
much larger, well‑structured set of initial shapes and by using the exact
sub‑gradient for final fine‑tuning.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: smallest power‑of‑two length for a linear convolution of size n.
# ----------------------------------------------------------------------
def _fft_len_for_n(n: int) -> int:
    """Return the next power‑of‑two ≥ 2·n‑1 for FFT based convolution."""
    size = 2 * n - 1
    return 1 << ((size - 1).bit_length())


# ----------------------------------------------------------------------
# Linear self‑convolution via FFT (real‑valued inputs).
# ----------------------------------------------------------------------
def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a (length = 2·len(a)‑1) using FFT."""
    fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[: 2 * a.size - 1]
    return conv


# ----------------------------------------------------------------------
# Correlation (a ⋆ w) needed for the sub‑gradient of max_k (a*a)[k].
# ----------------------------------------------------------------------
def _gradient_correlation(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute 2·a ⋆ w, i.e. the gradient of Σ_k w[k]·(a*a)[k].
    a : length n
    w : length 2·n‑1
    """
    n = a.size
    L = w.size                     # = 2·n‑1
    # length needed for linear correlation = L + n – 1 = 3·n – 2
    fft_len = 1 << ((L + n - 2 - 1).bit_length())
    fw = np.fft.rfft(w, n=fft_len)
    # reversed a for correlation
    fa_rev = np.fft.rfft(a[::-1], n=fft_len)
    corr_full = np.fft.irfft(fw * fa_rev, n=fft_len)[: L + n - 1]
    start = n - 1
    grad = 2.0 * corr_full[start:start + n]
    return grad


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex (non‑negative, unit sum).
# ----------------------------------------------------------------------
def _proj_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the simplex {x≥0, Σx = 1}."""
    if v.ndim != 1:
        raise ValueError("Input must be a 1‑D array")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / len(v))
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    # enforce exact sum = 1 (numerical safety)
    w_sum = w.sum()
    if w_sum > 0:
        w = w / w_sum
    else:
        w = np.full_like(v, 1.0 / len(v))
    return w


# ----------------------------------------------------------------------
# Score computation (exact objective) – avoids the heavy ``evaluate_sequence``.
# ----------------------------------------------------------------------
def _score_of(a: np.ndarray) -> float:
    """Return 2·n·max(a*a) for a vector that already satisfies Σa = 1."""
    n = a.size
    fft_len = _fft_len_for_n(n)
    conv = _conv_self(a, fft_len)
    return 2.0 * n * conv.max()


# ----------------------------------------------------------------------
# Main search routine.
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Search for a non‑negative height sequence that minimises ``evaluate_sequence``.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.
    n : int, optional
        Length of the step sequence (default 3800, the size used in earlier runs).

    Returns
    -------
    list[float]
        The best sequence found (values clipped to the limits imposed by
        ``evaluate_sequence``).
    """
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # 1) Problem size
    # --------------------------------------------------------------
    n = int(kwargs.get("n", 3800))
    if n < 2:
        n = 2
    i = np.arange(n, dtype=np.float64)            # 0 … n‑1

    # --------------------------------------------------------------
    # 2) Initialise with the classical √‑difference shape (γ=0.5, δ=0)
    # --------------------------------------------------------------
    a_sqrt = np.sqrt(i + 1.0) - np.sqrt(i)
    a_sqrt /= a_sqrt.sum()
    best = a_sqrt.copy()
    best_score = _score_of(best)
    print(f"[init] baseline √‑difference score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3) If a previous construction exists, use it as an additional start.
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        try:
            cand = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
            if cand.ndim == 1 and cand.size > 0 and np.isfinite(cand).all():
                cand = np.clip(cand, 0.0, None)
                cand_sum = cand.sum()
                if cand_sum > 0.0:
                    cand = cand / cand_sum
                    cand_score = _score_of(cand)
                    if cand_score < best_score:
                        best = cand
                        best_score = cand_score
                        print(f"[init] using external best score = {best_score:.6f}")
        except Exception:
            pass

    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 2.0)   # keep 2 s safety margin

    # ------------------------------------------------------------------
    # 4) Grid search over the power‑difference family (γ,δ).
    # ------------------------------------------------------------------
    # Choose ranges that surround the known optimal point (γ≈0.5, δ≈0).
    gammas = np.linspace(0.44, 0.60, 33)      # step ≈0.005
    deltas = np.linspace(0.0, 4.0, 41)       # step ≈0.1
    for gamma in gammas:
        # early‑exit check
        if time.monotonic() > deadline:
            break
        # pre‑compute i+δ and (i+1+δ) powers for speed – done inside loop
        for delta in deltas:
            # fγ,δ(i) = (i+1+δ)^γ – (i+δ)^γ
            ip = (i + delta) ** gamma
            ip1 = (i + 1.0 + delta) ** gamma
            a = (ip1 - ip)
            total = (n + delta) ** gamma - delta ** gamma
            if total == 0.0:
                continue
            a = a / total
            score = _score_of(a)
            if score < best_score - 1e-12:
                best_score = score
                best = a.copy()
                print(f"[grid] new best {best_score:.6f} (γ={gamma:.4f}, δ={delta:.4f})")
        # optional early coarse‑to‑fine refinement could be added here

    # ------------------------------------------------------------------
    # 5) Grid search over the log‑difference family (α parameter).
    # ------------------------------------------------------------------
    alphas = np.linspace(0.05, 8.0, 41)   # step ≈0.2
    for alpha in alphas:
        if time.monotonic() > deadline:
            break
        # gα(i) = log(i+1+α) – log(i+α)
        a = np.log(i + 1.0 + alpha) - np.log(i + alpha)
        total = np.log(n + alpha) - np.log(alpha)
        if total == 0.0:
            continue
        a = a / total
        score = _score_of(a)
        if score < best_score - 1e-12:
            best_score = score
            best = a.copy()
            print(f"[grid] new best {best_score:.6f} (log‑α={alpha:.4f})")

    # ------------------------------------------------------------------
    # 6) Mix the best candidate with a uniform distribution.
    # ------------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    for lam in np.linspace(0.0, 0.20, 21):
        if time.monotonic() > deadline:
            break
        a_mix = (1.0 - lam) * best + lam * uniform
        a_mix = _proj_simplex(a_mix)           # ensure exact sum = 1
        score = _score_of(a_mix)
        if score < best_score - 1e-12:
            best_score = score
            best = a_mix.copy()
            print(f"[mix] new best {best_score:.6f} (λ={lam:.3f})")

    # ------------------------------------------------------------------
    # 7) Final refinement using projected Adam on the true L∞‑objective.
    # ------------------------------------------------------------------
    a = best.copy()
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t_iter = 0

    # linear learning‑rate schedule (starts larger, ends small)
    lr_start = 0.20
    lr_end = 0.001

    while time.monotonic() < deadline:
        # compute current convolution and maximal entry
        conv = _conv_self(a, _fft_len_for_n(n))
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best = a.copy()
            elapsed = time.monotonic() - start_time
            print(f"[{elapsed:6.2f}s] refined best score = {best_score:.6f}")

        # sub‑gradient: indicator of maximal indices
        mask = (conv == cur_max)
        w = mask.astype(np.float64)

        grad = _gradient_correlation(a, w)   # shape (n,)

        # Adam update
        t_iter += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t_iter)
        v_hat = v / (1.0 - beta2 ** t_iter)

        # schedule learning rate linearly with elapsed proportion
        elapsed = time.monotonic() - start_time
        ratio = min(1.0, elapsed / (deadline - start_time))
        lr = lr_start * (1.0 - ratio) + lr_end * ratio
        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a = a - step
        a = _proj_simplex(a)

        # occasional log‑normal jitter to escape plateaus
        if rng.random() < 0.01:
            jitter = np.exp(rng.normal(0.0, 0.09, size=n))
            a = a * jitter
            a = _proj_simplex(a)

    # ------------------------------------------------------------------
    # 8) Optional cheap hill‑climbing (random mass transfers).
    # ------------------------------------------------------------------
    a = best.copy()
    while time.monotonic() < deadline:
        i_idx, j_idx = rng.integers(0, n, size=2)
        if i_idx == j_idx:
            continue
        if a[i_idx] <= 1e-14:
            continue
        # transfer a random fraction of the source mass
        frac = rng.random() * 0.25          # up‑to 25 % of source
        delta = frac * a[i_idx]
        a_new = a.copy()
        a_new[i_idx] -= delta
        a_new[j_idx] += delta
        a_new = _proj_simplex(a_new)        # keep on simplex
        new_score = _score_of(a_new)
        if new_score < best_score - 1e-12:
            best_score = new_score
            best = a_new.copy()
            a = a_new.copy()
            elapsed = time.monotonic() - start_time
            print(f"[{elapsed:6.2f}s] hill‑climb improvement: {best_score:.6f}")
        # limit the number of hill‑climb steps if we are very close to deadline
        if time.monotonic() > deadline - 0.2:
            break

    # ------------------------------------------------------------------
    # 9) Return the best sequence (apply the clipping imposed by evaluate_sequence).
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]
```
