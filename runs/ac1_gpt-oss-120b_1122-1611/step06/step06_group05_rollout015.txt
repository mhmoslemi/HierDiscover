"""
Propose a step‑function that lowers the evaluate_sequence() score.
------------------------------------------------------------------

The score is  2·n·max_k (a∗a)_k / (∑a_i)² .
Because the objective is homogeneous, we may fix ∑a_i = 1 and only
minimise  M = max_k (a∗a)_k.
A uniform sequence gives M = 1/n (score = 2).  The best known construction
has a slightly smaller M (≈0.75/n).  We obtain a better sequence by a
simple Monte‑Carlo / simulated‑annealing optimisation that works directly
on the simplex (non‑negative entries that sum to one).

The algorithm:
1.  Initialise a with the “square‑root‑difference’’ shape
    a_i ∝ √(i+1)−√i (the classical start‑point for this problem).
2.  Repeatedly propose a tiny transfer of mass δ from a randomly chosen
    index i to another index j (keeping all entries ≥0 and the total sum = 1).
3.  Compute the new convolution max M′ and the corresponding score
    S′ = 2·n·M′ (the denominator is constantly 1).
4.  Accept the move if it improves the score or with a Metropolis
    probability that slowly cools down (simulated annealing).  Keep the
    best sequence seen.
5.  The loop runs until the allotted time budget expires (≤ 1000 s).

All operations are O(n²) with n≈800 – fast enough for thousands of
iterations.  The final sequence is clipped to the limits enforced by
evaluate_sequence() and returned as a plain Python list.

The method is completely self‑contained, uses only NumPy and the standard
library, and makes no assumptions about the external evaluate_sequence()
implementation other than the contract described in the statement.

import time
import numpy as np


def _conv_max(a: np.ndarray) -> float:
    """
    Return the maximal entry of the full linear convolution a*a.
    For modest lengths (≤ 2000) np.convolve is faster than FFT.
    """
    conv = np.convolve(a, a)
    return float(conv.max())


def propose_candidate(seed: int = 42,

    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
