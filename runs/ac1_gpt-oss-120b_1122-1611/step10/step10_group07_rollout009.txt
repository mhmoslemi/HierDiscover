assistantfinal**Solution Overview**

The score to minimise is  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the score is invariant under a global scaling of `a` (as long as no entry hits the
hard‑cap 1000), we may **fix the sum to 1** and simply minimise the
maximum of the self‑convolution.  
The problem

\[
\min_{a\ge 0,\; \mathbf 1^Ta=1}\; \max_k a^{\top}C_k a ,
\qquad
(C_k)_{ij}=\begin{cases}
1 & i+j=k,\;0\le i,j<n\\[2pt]
0 & \text{otherwise}
\end{cases}
\]

is convex (the maximum of convex quadratic forms).  
A convenient way to move towards the optimum is the *epigraph* formulation

\[
\begin{array}{ll}
\min\limits_{a,t} & t \\[4pt]
\text{s.t.} &
a^{\top}C_k a \le t \quad (k=0,\dots,2n-2)\\[4pt]
& a_i\ge 0,\;\;\sum_i a_i = 1 .
\end{array}
\]

The quadratic constraints are convex; nevertheless solving the full problem
directly with a generic SDP/QCQP solver is too slow for the allocated time.
Instead we use a **two‑stage scheme** that is both fast and provably improves the objective:

1. **Linear‑programming refinement** –  
   With a current vector `a` we compute its current worst convolution value
   `M = max_k (a*a)[k]`.  
   The linear program  

   \[
   \max_{g\ge 0}\;\; \mathbf 1^{\!\top}g
   \quad\text{s.t.}\quad
   (a*g)[k] \le M,\;\; k=0,\dots,2n-2
   \]

   asks for the *most massive* non‑negative vector `g` that does **not**
   increase the worst convolution when convolved with the fixed `a`.  
   Its solution pushes mass into the “gaps’’ of `a`.  After a
   normalisation step we mix the old and the new vector

   \[
   a^{\text{new}} = (1-\tau)a + \tau\,\frac{g}{\sum g},
   \qquad \tau\in(0,1],
   \]

   which never raises the worst convolution.  Repeating this step,
   `a` quickly becomes more “flat’’ in the convolution domain.

2. **Fine‑grained projected‑gradient polishing** –  
   After a few LP refinements the vector is already close to a local optimum.
   A few iterations of exponentiated‑gradient descent (the same update used
   previously) clean up remaining irregularities.

Both stages are cheap:
* a convolution is performed by an FFT (`O(n log n)`),
* the LP has `n` variables, `2n‑1` linear constraints and a sparse matrix
  with exactly `n²` non‑zeros (for `n=1024` this is ~1 MiB).

The whole search consists of many random restarts (Dirichlet draws with
different concentration parameters).  For each restart we run a short
LP‑refinement (3–5 iterations) followed by the polishing phase.
The best vector seen so far is kept and finally returned.

The algorithm respects the 1000 s time limit, uses only top‑level functions,
relies on `numpy`, `scipy.sparse` and `scipy.optimize.linprog`,
and prints progress information.

"""
Propose a step‑function (non‑negative vector) with a low
evaluate_sequence() score.

Algorithm
---------
1. Choose a problem size `n` (default 1024).  If a previous solution
   (`height_sequence_1`) exists we reuse its length, otherwise we fix `n`
   ourselves.
2. Randomly initialise a vector `a` from a Dirichlet distribution
   (concentration is drawn uniformly from [0.2, 5]).
3. LP‑refinement:
   * Compute the current worst self‑convolution value `M`.
   * Build a sparse matrix `A` that represents the linear map
     `g ↦ a * g` (convolution with the fixed `a`).
   * Solve the linear programme
         maximise 1ᵀg   subject to  A·g ≤ M ,  g ≥ 0 .
   * Normalise `g` to unit sum, mix it with `a` (mixing factor τ=0.5)
     and keep the mixture only if the worst convolution does not increase.
   * Repeat the LP step a few times (default 4).
4. Polishing:
   Perform a few exponentiated‑gradient iterations using the exact
   sub‑gradient of the max‑convolution (active set).  This removes
   remaining spikes.
5. Keep the best vector ever observed (lowest score).  The whole loop runs
   until the allocated time budget (≈ 1000 s – 5 s safety margin) is exhausted.
6. Clip the final vector to the limits used by `evaluate_sequence`,
   call the evaluator once for the final score and return the vector.

import time

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex {x≥0, sum(x)=1}."""
    if v.ndim != 1:
        raise ValueError("Only 1‑D vectors are supported.")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / len(v))
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    w_sum = w.sum()
    if w_sum == 0.0:
        w[:] = 1.0 / len(v)
    else:
        w /= w_sum
    return w


def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a * a using FFT (returns length 2*len(a)-1)."""
    a_fft = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(a_fft * a_fft, n=fft_len)[: 2 * a.size - 1]
    return conv


def _active_set(conv: np.ndarray, eps_factor: float = 1e-7) -> np.ndarray:
    """Indices where conv attains (approximately) its maximum."""
    max_val = conv.max()
    eps = max_val * eps_factor
    return np.where(conv >= max_val - eps)[0]


def _gradient_from_active(a: np.ndarray, active: np.ndarray) -> np.ndarray:
    """
    Exact sub‑gradient of max_k (a*a)[k] for the active indices.
    For each active index k the contribution to ∂max/∂a_i is a_{k-i},
    respecting array bounds.
    """
    n = a.size
    grad = np.zeros_like(a)
    for k in active:
        i_start = max(0, k - (n - 1))
        i_end = min(n, k + 1)          # exclusive
        i = np.arange(i_start, i_end, dtype=int)
        grad[i] += a[k - i]
    return grad


def _build_conv_ub_matrix(a: np.ndarray) -> csr_matrix:
    """
    Build the sparse matrix A (shape (2n‑1, n)) that represents the
    linear map g ↦ a * g   (convolution of a with a variable g).
    Row k contains the coefficients a_{k‑j} for all feasible j.
    """
    n = a.shape[0]
    rows = []
    cols = []
    data = []
    for k in range(2 * n - 1):
        j_start = max(0, k - (n - 1))
        j_end = min(n - 1, k)
        js = np.arange(j_start, j_end + 1, dtype=int)
        coeffs = a[k - js]        # a[k‑j] for each j
        rows.extend([k] * len(js))
        cols.extend(js.tolist())
        data.extend(coeffs.tolist())
    return csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))


def _lp_refinement_step(a: np.ndarray,
                        fft_len: int,
                        mix: float = 0.5) -> tuple[np.ndarray, bool]:
    """
    Perform one LP‑based refinement.
    Returns (new_a, improved_flag).
    """
    n = a.shape[0]
    # current worst convolution value
    conv = _conv_fft(a, fft_len)
    M = conv.max()

    # Build the constraint matrix for (a * g) ≤ M
    A = _build_conv_ub_matrix(a)
    b = np.full(2 * n - 1, M, dtype=np.float64)

    # maximise total mass of g  →  minimise -1ᵀg
    c = -np.ones(n, dtype=np.float64)
    bounds = [(0.0, None)] * n

    # Solve LP using HiGHS (sparse support)
    res = linprog(c,
                  A_ub=A,
                  b_ub=b,
                  bounds=bounds,
                  method='highs',
                  options={'presolve': True, 'disp': False})

    if not res.success:
        return a, False

    g = res.x
    if g.sum() == 0.0:
        return a, False

    # Normalise g to the same total mass as a (the current sum is 1)
    g = g / g.sum()

    # Mix and re‑normalise
    a_new = (1.0 - mix) * a + mix * g
    a_new = a_new / a_new.sum()

    # Accept only if the max‑convolution does not increase
    new_conv = _conv_fft(a_new, fft_len)
    if new_conv.max() <= M + 1e-12:
        return a_new, True
    return a, False


def _exponentiated_gradient(a: np.ndarray,
                            fft_len: int,
                            max_iter: int = 30) -> np.ndarray:
    """
    Few exponentiated‑gradient steps using the exact sub‑gradient.
    The update is performed in the logarithmic domain and projected
    back onto the simplex.
    """
    n = a.size
    log_a = np.log(a + 1e-15)
    for it in range(max_iter):
        conv = _conv_fft(a, fft_len)
        max_val = conv.max()
        active = _active_set(conv, eps_factor=1e-7)
        grad = _gradient_from_active(a, active)

        # Diminishing step size
        eta = 0.6 / np.sqrt(it + 1.0)
        log_a -= eta * grad
        a = np.exp(log_a)
        a /= a.sum()
        # Early exit if the objective stops improving
        new_conv = _conv_fft(a, fft_len)
        if new_conv.max() >= max_val - 1e-14:
            # no improvement – keep going a little longer, but stop after
            # a few idle iterations
            if it > 5 and np.allclose(conv, new_conv, atol=0, rtol=1e-12):
                break
        else:
            # reset log_a to the improved point
            log_a = np.log(a + 1e-15)
    return a

    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 0) Choose problem dimension and initial vector
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        a0 = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
        a0 = np.clip(a0, 0.0, None)
        s0 = a0.sum()
        if s0 > 0.0:
            a0 /= s0
        else:
            a0 = np.full_like(a0, 1.0 / a0.size)
        n = a0.size
    else:
        # a moderate size – large enough for a good bound, small enough for
        # fast linear programmes.
        n = 1024
        a0 = np.full(n, 1.0 / n, dtype=np.float64)

    fft_len = _next_pow2(3 * n)          # enough for linear convolution

    # ------------------------------------------------------------------
    # 1) Book‑keeping
    # ------------------------------------------------------------------
    best = a0.copy()
    best_score = 2.0 * n * _conv_fft(best, fft_len).max()
    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 5.0)

    print(f"[0.00s] initial score = {best_score:.6f} (n={n})")

    # ------------------------------------------------------------------
    # 2) Main loop – random restarts with LP refinement + polishing
    # ------------------------------------------------------------------
    restarts = 0
    while time.monotonic() < deadline:
        # ----- random initial vector (Dirichlet) ----------------------
        alpha = rng.uniform(0.2, 5.0)                # concentration
        a = rng.dirichlet(np.full(n, alpha)).astype(np.float64)

        # ----- LP refinement (few iterations) ------------------------
        improved = True
        lp_iters = 0
        while improved and lp_iters < 5 and time.monotonic() < deadline:
            a, improved = _lp_refinement_step(a, fft_len, mix=0.5)
            lp_iters += 1

        # ----- short exponentiated‑gradient polishing -----------------
        a = _exponentiated_gradient(a, fft_len, max_iter=25)

        # ----- evaluate candidate --------------------------------------
        score = 2.0 * n * _conv_fft(a, fft_len).max()
        if score < best_score - 1e-12:
            best_score = score
            best = a.copy()
            elapsed = time.monotonic() - start_time
            print(f"[{elapsed:6.2f}s] new best = {best_score:.6f} "
                  f"(restart={restarts}, lp_iters={lp_iters})")
        restarts += 1

        # safety check – break if we have spent almost all time
        if time.monotonic() > deadline - 1.0:
            break

    # ------------------------------------------------------------------
    # 3) Final polishing (optional – a few more gradient steps)
    # ------------------------------------------------------------------
    best = _exponentiated_gradient(best, fft_len, max_iter=40)

    # ------------------------------------------------------------------
    # 4) Return the best sequence (respect evaluator limits)
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    final_score = evaluate_sequence(best.tolist())
    total_elapsed = time.monotonic() - start_time
    print(f"Finished in {total_elapsed:.2f}s – final score = {final_score:.6f}")
    return [float(x) for x in best]
