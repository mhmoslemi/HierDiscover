The optimizer works on the *simplex* (∑aᵢ = 1, aᵢ ≥ 0) – the evaluation function is homogeneous, therefore scaling does not matter.  
The idea is to combine three complementary strategies:

1. **Adam‑based projected gradient descent** on the sub‑gradient of the convolution maximum.  
   Adam’s adaptive step sizes and momentum are much more efficient than plain sub‑gradient descent and escape shallow plateaus quickly.

2. **Periodic smoothing / block‑scale moves** – a short “jitter” that multiplies a random short block by a factor ≈ 1 ± few % and re‑projects.  
   Such moves can reduce a dominant peak that the gradient cannot see because the active set is tiny.

3. **Simulated‑annealing “mass‑transfer” moves** – transfer a small fraction of the mass from one index to another, accepting worsening moves with a temperature schedule.  
   This provides a global exploration layer that can cross barriers left by the deterministic gradient steps.

The routine also *upsamples* an existing solution (if any) to a moderate size (≈ 4096) before optimisation – larger vectors give a lower theoretical lower bound (average convolution ≈ 1⁄(2n‑1)).  

All steps respect the 1000 s budget (a 5 s safety margin), log progress, and finally return the best sequence found (clipped to the limits required by `evaluate_sequence`).

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
    {x ≥ 0, sum(x) = 1}.
    """
    if v.ndim != 1:
        raise ValueError("Only 1‑D vectors are supported.")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fall back to the uniform distribution
        return np.full_like(v, 1.0 / len(v))
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    w_sum = w.sum()
    if w_sum == 0.0:
        w[:] = 1.0 / len(v)
    else:
        w /= w_sum
    return w


def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a * a using an FFT of length ``fft_len``.
    Returns the convolution of length 2·len(a)‑1.
    """
    a_fft = rfft(a, n=fft_len)
    conv = irfft(a_fft * a_fft, n=fft_len)[: 2 * a.size - 1]
    return conv


def _gradient_from_active(a: np.ndarray, active: np.ndarray) -> np.ndarray:
    """
    Exact sub‑gradient of max_k (a*a)[k] for a set of active
    convolution indices ``active`` (those attaining the current maximum).
    For each active index k, the contribution to ∂max/∂a_i is a_{k-i}.
    """
    n = a.size
    grad = np.zeros_like(a)
    for k in active:
        i_start = max(0, k - (n - 1))
        i_end = min(n, k + 1)          # exclusive
        i = np.arange(i_start, i_end, dtype=int)
        grad[i] += a[k - i]
    return grad

    Fast evaluation of the objective for a vector already on the simplex
    (∑a = 1).  Returns 2·n·max(conv(a,a)).
    """
    n = a.size
    fft_len = _next_pow2(2 * n)
    conv = _conv_fft(a, fft_len)
    return 2.0 * n * conv.max()
