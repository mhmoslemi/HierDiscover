The objective  

\[
F(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2}
\]

is *scale‑invariant* – we may restrict ourselves to the probability simplex  

\[
\sum_{i=0}^{n-1} a_i = 1,\qquad a_i\ge 0 .
\]

On the simplex  

\[
F(a)=2\,n\;\max_k (a*a)[k] .
\]

The map \(a\mapsto (a*a)[k]=\sum_{i+j=k}a_i a_j\) is a convex quadratic form,
hence the pointwise maximum of these quadratics is a **convex** function.
We minimise it with a *smoothed* gradient method:

* **Soft‑max smoothing** – instead of the non‑differentiable \(\max\) we use  

  \[
  \phi_\mu(a)=\mu\;\log\!\Big(\sum_k e^{(a*a)[k]/\mu}\Big)
  \]

  whose gradient is a weighted sum of the individual quadratic gradients.
  The smoothing parameter \(\mu\) is decreased from a relatively large value
  (smooth landscape) to a tiny one (close to the true max).

* **Gradient computation** – for the soft‑max weights \(w_k\) the exact
  gradient is  

  \[
  \nabla\phi_\mu(a)_i = 2\sum_{j=0}^{n-1} a_j\,w_{i+j}
  = 2\;(a * w_{\text{rev}})[\,2n-2-i\,],
  \]

  i.e. a single convolution of \(a\) with the reversed weight vector.
  All convolutions are performed with FFTs (length a power‑of‑two).

* **Projected gradient step** – after a step
  \(a\leftarrow a-\eta\nabla\phi_\mu(a)\) we project back onto the simplex
  by the classic Euclidean projection.

* **Line‑search & adaptive step‑size** – a cheap back‑tracking line‑search
  (factors \(1,½,¼,…\)) guarantees a monotone decrease of the *true* objective
  \(2n\max(a*a)\).  The base step length is chosen as
  \(\eta_0 = \frac{\alpha}{\|\nabla\phi_\mu(a)\|_2}\) (α≈0.5).

* **Annealing schedule** –  

  \[
  \mu(t)=\mu_{\text{start}}\Big(\frac{\mu_{\text{end}}}{\mu_{\text{start}}}\Big)^{\frac{t}{T}},
  \]

  where \(T\) is the total allotted time.  The algorithm therefore starts
  with a smooth problem and gradually focuses on the true \(\max\).

* **Restart & jitter** – if the line‑search cannot improve the objective,
  a small multiplicative jitter is applied to escape plateaus.

The whole optimisation runs until the time budget (≈ 1000 s) is exhausted.
The best sequence found is returned, clipped to the limits imposed by
`evaluate_sequence`.

"""
propose_candidate – convex smoothed‑gradient optimiser for the step‑function
objective 2*n*max(conv(a,a))/(sum(a)**2).

The algorithm keeps the vector on the probability simplex, uses a soft‑max
approximation of the max‑operator, computes the exact gradient via a single
FFT‑based convolution, performs a back‑tracking line‑search, and anneals the
smoothing parameter µ from 0.3 down to 0.001.  The best sequence seen is
returned as a list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("Simplex projection expects a 1‑D vector.")
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fallback to uniform vector
        return np.full_like(v, 1.0 / len(v))
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    # re‑normalise (numerical safety)
    ws = w.sum()
    if ws == 0.0:
        w[:] = 1.0 / len(v)
    else:
        w /= ws
    return w


def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a * a using an FFT of length ``fft_len``.
    Returns an array of length 2*len(a)-1.
    """
    a_fft = np.fft.rfft(a, n=fft_len)
    conv_full = np.fft.irfft(a_fft * a_fft, n=fft_len)
    return conv_full[: 2 * a.size - 1]


def _grad_softmax(a: np.ndarray, w: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Gradient of the soft‑max smoothed objective.
    w – soft‑max weights, length 2*n-1, already normalised (∑w = 1).
    Returns a vector of length n.
    """
    n = a.size
    # reversed weight vector
    w_rev = w[::-1]
    # convolution a * w_rev (linear)
    a_fft = np.fft.rfft(a, n=fft_len)
    w_fft = np.fft.rfft(w_rev, n=fft_len)
    full = np.fft.irfft(a_fft * w_fft, n=fft_len)
    # relevant part length = 3*n-2 (we only need the first 3*n-2 entries)
    full = full[: 3 * n - 2]
    offset = 2 * n - 2
    # gradient = 2 * full[offset - i]  for i=0,…,n-1
    grad = 2.0 * full[offset - np.arange(n)]
    return grad


def _score_from_a(a: np.ndarray, fft_len: int) -> float:
    """Exact objective for a probability‑simplex vector."""
    n = a.size
    conv = _conv_fft(a, fft_len)
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
# Core optimiser – one run on a given length
# ----------------------------------------------------------------------


def _optimise_one_length(a0: np.ndarray,
                         total_time: float,
                         start_time: float,
                         rng: np.random.Generator):
    """
    Smoothed‑gradient descent with annealing.
    Returns the best vector found (still on the simplex) and its score.
    """
    a = a0.copy()
    n = a.size
    fft_len = _next_pow2(3 * n)

    # best record
    conv = _conv_fft(a, fft_len)
    best = a.copy()
    best_score = float(2.0 * n * conv.max())

    # annealing parameters
    mu_start = 0.30
    mu_end = 0.001

    # step‑size control
    base_alpha = 0.55   # roughly η = α / ||grad||

    it = 0
    while True:
        now = time.monotonic()
        if now - start_time >= total_time:
            break

        # ------------------------------------------------------------------
        # 1) current smoothing parameter μ (geometric decay)
        # ------------------------------------------------------------------
        progress = (now - start_time) / total_time
        mu = mu_start * (mu_end / mu_start) ** progress

        # ------------------------------------------------------------------
        # 2) convolution a*a  (FFT, reused for gradient later)
        # ------------------------------------------------------------------
        a_fft = np.fft.rfft(a, n=fft_len)
        conv = np.fft.irfft(a_fft * a_fft, n=fft_len)[: 2 * n - 1]

        # ------------------------------------------------------------------
        # 3) soft‑max weights
        # ------------------------------------------------------------------
        shift = conv.max()
        # stable soft‑max
        w_unnorm = np.exp((conv - shift) / mu)
        w_sum = w_unnorm.sum()
        if w_sum == 0.0:            # numerical safeguard (should not happen)
            w = np.full_like(w_unnorm, 1.0 / w_unnorm.size)
        else:
            w = w_unnorm / w_sum

        # ------------------------------------------------------------------
        # 4) gradient of the smoothed objective
        # ------------------------------------------------------------------
        grad = _grad_softmax(a, w, fft_len)

        # ------------------------------------------------------------------
        # 5) line‑search on the true objective
        # ------------------------------------------------------------------
        grad_norm = np.linalg.norm(grad) + 1e-14
        eta0 = base_alpha / grad_norm
        cur_score = 2.0 * n * conv.max()
        improved = False

        for factor in (1.0, 0.5, 0.25, 0.125, 0.0625):
            eta = eta0 * factor
            cand = a - eta * grad
            cand = _project_onto_simplex(cand)
            cand_score = _score_from_a(cand, fft_len)
            if cand_score < cur_score - 1e-14:
                a = cand
                cur_score = cand_score
                improved = True
                if cand_score < best_score - 1e-12:
                    best_score = cand_score
                    best = cand.copy()
                break

        if not improved:
            # no improvement → small random jitter to escape a plateau
            jitter = np.exp(rng.normal(0.0, 0.018, size=n))
            a = _project_onto_simplex(a * jitter)

        # occasional progress report (once per second)
        if it % 200 == 0:
            elapsed = now - start_time
            print(f"[{elapsed:6.2f}s] it={it:6d} μ={mu:.6f} best={best_score:.6f}")

            # early stop if target already reached
            if best_score <= 1.5025:
                print("[early exit] target reached")
                break

        it += 1

    return best, best_score


# ----------------------------------------------------------------------
# Public entry point required by the harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: float = 1000.0) -> list[float]:
    """
    Search for a non‑negative step function minimising ``evaluate_sequence``.
    The routine runs a smoothed gradient descent with an annealing schedule,
    keeping the vector on the probability simplex.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Time handling (5 s safety margin)
    # ------------------------------------------------------------------
    start = time.monotonic()
    deadline = start + max(0.0, float(budget_s) - 5.0)

    # ------------------------------------------------------------------
    # Initialise a – use previous best if available, otherwise a uniform start
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        a0 = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
        a0 = np.clip(a0, 0.0, None)
        if a0.sum() > 0.0:
            a0 = a0 / a0.sum()
        else:
            a0 = np.full_like(a0, 1.0 / a0.size)
    else:
        # a modest size that performed well historically
        n0 = 3809
        a0 = np.full(n0, 1.0 / n0, dtype=np.float64)

    # ------------------------------------------------------------------
    # Run the optimiser until the time budget runs out
    # ------------------------------------------------------------------
    total_run_time = deadline - start
    best_vec, best_score = _optimise_one_length(a0, total_run_time, start, rng)

    # ------------------------------------------------------------------
    # Final post‑processing (evaluate with the official checker)
    # ------------------------------------------------------------------
    best_vec = np.clip(best_vec, 0.0, 1000.0)   # evaluator caps anyway
    final_score = evaluate_sequence(best_vec.tolist())
    elapsed = time.monotonic() - start
    print(f"Finished in {elapsed:.2f}s – final score = {final_score:.6f}")

    # expose the sequence for possible future runs
    globals()["height_sequence_1"] = best_vec.tolist()
    return [float(x) for x in best_vec]
