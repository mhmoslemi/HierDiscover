A convex‐optimization based search for a step function with a smaller
self‑convolution peak than the classic Catalan construction.

The problem (after scaling invariance) is::

    minimise   max_k (w * w)[k]          (w ≥ 0,  sum w = 1)

where * denotes the discrete (non‑circular) convolution.
The objective is convex because each term (w*w)[k] = wᵀA_k w is a convex
quadratic form and the pointwise maximum of convex functions is convex.

We therefore use a projected sub‑gradient method.
At every iteration we:
    1. compute the convolution b = w * w,
    2. locate an index i with maximal b[i],
    3. take a sub‑gradient ∂b[i]/∂w = 2·w shifted by i,
    4. move w opposite to the sub‑gradient,
    5. project back onto the probability simplex (w ≥ 0, ∑w = 1).

The step size η decays as η₀/√t.  To avoid stagnation we occasionally
apply a cheap random block‑perturbation (the same routine used in the
reference solution) and keep any improvement.

All operations are O(n log n) thanks to FFT‑based convolution, allowing
thousands of iterations within the 1000 s budget.  The final sequence
is scaled to the conventional √(2 n) L¹‑norm (the scaling does not
change the score) and returned as a plain Python list of floats.

def catalan_sequence(length: int) -> np.ndarray:
    """First ``length`` terms of a_i = C(2i,i)/4**i.
    Recurrence a_{i+1}=a_i*(2*i+1)/(2*i+2) is numerically stable."""
    seq = np.empty(length, dtype=np.float64)
    seq[0] = 1.0
    for i in range(1, length):
        seq[i] = seq[i - 1] * (2 * (i - 1) + 1) / (2 * i)
    return seq


def convolve_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution using real FFT (fast for n≈10⁴)."""
    n = a.size + b.size - 1
    N = 1 << (n - 1).bit_length()          # next power of two
    Fa = np.fft.rfft(a, N)
    Fb = np.fft.rfft(b, N)
    Fc = Fa * Fb
    c = np.fft.irfft(Fc, N)[:n]
    # Small negative round‑off errors are harmless; clip to 0.
    np.maximum(c, 0.0, out=c)
    return c


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex {x≥0,∑x=1}."""
    # Algorithm of Duchi et al. (2008)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are (almost) equal; fall back to uniform vector
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def block_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """Cheap O(n) perturbation used as a random jump."""
    cand = base.copy()

    lo = max(1, n // 200)
    hi = max(2, n // 12)
