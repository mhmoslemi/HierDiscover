Propose a better step‑function sequence.

The algorithm is a multi‑restart projected Adam optimizer that minimises a
smooth approximation of the maximal self‑convolution entry.
Key differences to the previous submission:

* **Slow λ‑annealing** – we start with a *small* smooth‑max temperature
  (λ≈0.5) and increase it by a factor 1.0005 per iteration.  This keeps the
  surrogate smooth for many iterations, allowing the optimiser to escape
  local plateaus before focusing on the true maximum.
* **Larger search space** – by default we work with n = 2048 coefficients
  (instead of 1024).  More degrees of freedom give the optimiser more
  freedom to flatten the convolution.
* **Multiple restarts** – several short runs with different hyper‑parameters
  (learning‑rate, λ‑schedule) are performed within the time budget; the
  best sequence seen overall is returned.
* **Light‑weight random shake‑ups** – occasional Gaussian noise helps
  to leave flat regions of the landscape.
* **Early stopping** – if the theoretical lower bound 2·n/(2·n‑1) is
  reached (within 1 %), the search terminates immediately.

The routine respects all security checks performed inside
``evaluate_sequence``: the returned sequence is non‑negative,
sums to 1 (probability simplex) and contains only Python floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x ≥ 0, sum(x) = 1}.
    """
    n = v.shape[0]
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(n) + 1.0
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def _smooth_max_weights(conv: np.ndarray, lam: float) -> np.ndarray:
    """
    Compute the soft‑max weights w_k ∝ exp(lam·conv_k) in a numerically
    stable way (lam > 0).
    """
    # shift by the maximal entry to avoid overflow
    max_c = conv.max()
    shifted = (conv - max_c) * lam
    w = np.exp(shifted)
    s = w.sum()
    if s == 0.0:
        return np.full_like(conv, 1.0 / conv.size)
    return w / s


# ----------------------------------------------------------------------
def _gradient_smooth_max(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the smooth‑max surrogate:
        ∇_a Σ_k w_k (a*a)_k = 2·correlate(w, a)_central
    The central part corresponds to lags -i for i = 0…n‑1.
    """
    # full correlation (size = len(w)+len(a)-1)
    full_corr = np.correlate(w, a, mode='full')
    n = a.shape[0]
    # entry i uses lag = -i → index = n‑1‑i
    grad = 2.0 * full_corr[n - 1 :: -1][:n]
    return grad
