Linear‑programming alternating improvement for the self‑convolution peak.

The objective (after normalising the L¹‑norm to √(2 n)) equals the maximum
entry of the linear self‑convolution a*a.  For a fixed sequence a we
construct the dense convolution matrix A (size (2n‑1) × n) such that

    A @ g = a * g   (linear convolution)

and solve the linear programme

    maximise   1ᵀ g
    subject to  A g ≤ M ,  g ≥ 0 ,  g ≤ U

where M = max(a*a) and U is a generous upper bound (10·√(2 n)).
The optimal g pushes the allowed mass as far as possible without
increasing the current peak M.  By mixing a and the scaled g we obtain
a new sequence with a strictly smaller peak.  The process is repeated
until the time budget expires or the target value (≈1.5025) is reached.

If a previous construction is available via the global variable
`height_sequence_1` we start from it; otherwise a random Dirichlet
vector is used.  All updates keep the L¹‑norm equal to √(2 n), so the
value returned by ``evaluate_sequence`` is simply the maximum of the
convolution.

The algorithm is fast (FFT for the convolution, dense matrix for the LP)
and fits well inside the 1000‑second budget.
"""

import time
import numpy as np
from scipy.optimize import linprog

# ----------------------------------------------------------------------
# Helper utilities (no closures, top‑level as required)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def conv_max_fft(a: np.ndarray) -> float:
    """Maximum entry of the linear self‑convolution a*a computed via FFT."""
    n = a.size
    fft_len = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[: 2 * n - 1]
    return float(conv.max())


def build_convolution_matrix(f: np.ndarray) -> np.ndarray:
    """
    Build the dense matrix A (shape (2n‑1, n)) such that ``A @ g`` equals
    the linear convolution ``np.convolve(f, g)``.
    """
    n = f.shape[0]
    rows = 2 * n - 1
    A = np.empty((rows, n), dtype=np.float64)
    A.fill(0.0)
    for k in range(rows):
        # column indices that participate in the k‑th convolution entry
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        j = np.arange(j_start, j_end + 1)
        # A[k, j] = f[k - j]
        A[k, j] = f[k - j]
    return A


def _random_noise(rng: np.random.Generator, n: int, scale: float = 0.2) -> np.ndarray:
    """Multiplicative log‑normal noise, useful for a jitter restart."""
    noise = np.exp(rng.normal(0.0, scale, size=n))
    return noise

# ----------------------------------------------------------------------

    Search for a non‑negative step‑function (list of heights) that minimises
    ``evaluate_sequence``.  The method alternates:

    1. compute the current peak M = max(a*a);
    2. solve a linear programme that maximises the L¹‑mass of a new vector
       g under the linear constraints ``a * g ≤ M``;
    3. scale g to keep the norm √(2 n);
    4. replace a by a convex combination of a and g that yields the lowest
       new peak.

    A simple jitter restart is performed after 30 s of stagnation.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------

        else:

        # ------------------------------------------------------------------

    #    evaluate_sequence for safety).
    # ------------------------------------------------------------------

    return [float(v) for v in best_a]
