assistantfinal**Solution Overview**

The evaluation function  

```python
score = 2 * n * max(a*a) / (sum(a)**2)
```  

depends only on the *shape* of the vector `a` – it is invariant under a
global scaling of the entries.  For a non‑negative vector the maximum of
the self‑convolution is always the zero‑lag term  
`max(a*a) = Σ a_i²`.  Consequently the score simplifies to  

```
score = 2 * n * Σ a_i² / (Σ a_i)² .
```

The Cauchy‑Schwarz inequality gives  

```
Σ a_i² ≥ (Σ a_i)² / n,
```

with equality **iff** all entries are equal.  Hence the theoretical lower
bound of the score is `2`.  Our optimiser therefore tries to drive the
vector towards the uniform distribution (the global optimum) while
respecting the limits imposed by `evaluate_sequence` (no negatives,
values ≤ 1000).

The implementation below combines three ideas:

1. **Fast exact objective** – the score is evaluated from the
   `Σ a_i²` and `Σ a_i` values only, avoiding an expensive convolution
   at every iteration.
2. **Simulated‑annealing style updates** – a randomly chosen pair of
   indices transfers a small amount of mass.  The move is accepted
   either because it improves the score or with a temperature‑dependent
   probability that slowly cools down.
3. **Periodic exact checks** – every few hundred iterations the true
   `evaluate_sequence` function is called to guard against floating‑point
   drift and to keep the best solution found so far.

The routine respects the 1000 s time budget, prints progress messages,
and finally returns the best (uniform) sequence it discovered.

```python
"""
Propose a step‑function (list of non‑negative heights) that minimises
evaluate_sequence within the given time budget.

The optimiser works as a simulated‑annealing / stochastic coordinate‑
descent hybrid:

* The exact objective can be written as
      2·n·Σ a_i² / (Σ a_i)² .
  Because Σ a_i² is the zero‑lag entry of the self‑convolution,
  we can update the score in O(1) when moving a small amount of mass
  between two coordinates.

* Starting from a random simplex point (or from the global variable
  ``height_sequence_1`` if it exists) we repeatedly pick two indices,
  transfer a random δ and accept the move according to a temperature
  schedule.  The temperature decays linearly from `T_start` to `T_end`
  so that the algorithm explores early and refines later.

* Every `CHECK_EVERY` iterations the exact `evaluate_sequence` function
  is called; the best vector seen so far is stored and finally returned.
  All entries are clipped to the admissible range `[0, 1000]` before the
  final return.

The algorithm finishes well before the 1000 s deadline and returns the
(best‑found) uniform vector, which is provably optimal for the given
objective.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top level – no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power‑of‑two ≥ x (used for FFT lengths, kept for compatibility)."""
    return 1 << ((x - 1).bit_length())


def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
        { x ≥ 0, sum(x) = 1 }.
    Implements the algorithm of Wang & Carreira‑Perpiñán (2013).
    """
    if v.ndim != 1:
        raise ValueError("Only 1‑D vectors are supported.")
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = np.arange(len(v)) + 1
    cond = u - cssv / rho_arr > 0
    if not np.any(cond):
        # fallback – uniform vector
        return np.full_like(v, 1.0 / len(v))
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    # renormalise to avoid tiny drift
    w_sum = w.sum()
    if w_sum == 0.0:
        w[:] = 1.0 / len(v)
    else:
        w /= w_sum
    return w


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(
    seed: int = 123456,
    budget_s: float = 1000.0,
    **kwargs,
) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises ``evaluate_sequence``.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.  The function stops a few seconds before the
        deadline so that the harness can still read the result.
    **kwargs
        Ignored – kept for compatibility with the evaluation framework.

    Returns
    -------
    list[float]
        The best height sequence found (values already clipped to the
        evaluator’s limits).
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Time‑budget handling (leave a 5 s safety margin)
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)
    start_time = time.monotonic()

    # ------------------------------------------------------------------
    # 0) Initialise the candidate vector on the simplex
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        a0 = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
        if a0.ndim != 1 or a0.size == 0 or not np.isfinite(a0).all():
            a0 = None
    else:
        a0 = None

    if a0 is None:
        # pick a moderate size – a power of two is convenient for FFTs
        n = 4096
        # start from a random point on the simplex (log‑normal to avoid exact zeros)
        raw = rng.lognormal(mean=0.0, sigma=1.0, size=n)
        raw = np.clip(raw, 0.0, None)
        a = _project_onto_simplex(raw)
    else:
        a = a0.astype(np.float64).copy()
        a = np.clip(a, 0.0, None)
        a_sum = a.sum()
        if a_sum > 0.0:
            a = a / a_sum
        else:
            a = np.full_like(a, 1.0 / a.size)
        n = a.size

    # ------------------------------------------------------------------
    # 1) Pre‑compute the exact score once (using the fast formula)
    # ------------------------------------------------------------------
    sum_a = a.sum()                     # = 1 after the projection
    sum_sq = np.dot(a, a)               # Σ a_i²
    cur_score = 2.0 * n * sum_sq / (sum_a ** 2)

    best = a.copy()
    best_score = cur_score
    best_time = time.monotonic()
    print(f"[0.00s] initial fast score = {cur_score:.12f}")

    # ------------------------------------------------------------------
    # 2) Simulated‑annealing parameters
    # ------------------------------------------------------------------
    T_start = 0.05      # initial temperature (in score‑units)
    T_end = 1e-6        # final temperature
    CHECK_EVERY = 2000   # call the exact evaluate_sequence this often
    RESTART_EVERY = 50000  # hard restart if no improvement for a while
    max_no_improve = 200000  # stop restarting after this many attempts
    no_improve_counter = 0

    iteration = 0
    # ------------------------------------------------------------------
    # 3) Main optimisation loop
    # ------------------------------------------------------------------
    while time.monotonic() < deadline:
        # ---- temperature schedule (linear cooling) ----
        elapsed = time.monotonic() - start_time
        frac = elapsed / (deadline - start_time)    # 0 … 1
        T = T_start * (1.0 - frac) + T_end * frac

        # ---- propose a random mass transfer between two indices ----
        i, j = rng.integers(0, n, size=2)
        while i == j:
            j = rng.integers(0, n)

        # amount to move – a fraction of the donor’s mass
        donor = a[i]
        if donor == 0.0:
            # nothing to move – skip this iteration
            continue
        # random fraction in (0, α] where α is a small constant
        α = 0.1
        δ = donor * rng.uniform(0.0, α)

        # ensure the receiver does not exceed the hard 1000‑limit after the move
        recv = a[j]
        if recv + δ > 1000.0:
            δ = 1000.0 - recv
            if δ <= 0.0:
                continue  # cannot move any mass

        # ---- fast update of Σ a_i² (quadratic term) ----
        new_sum_sq = sum_sq - donor ** 2 - recv ** 2 + (donor - δ) ** 2 + (recv + δ) ** 2
        new_score = 2.0 * n * new_sum_sq / (sum_a ** 2)   # sum_a unchanged

        # ---- Metropolis acceptance test ----
        improve = new_score < cur_score
        if improve or rng.random() < np.exp(-(new_score - cur_score) / max(T, 1e-12)):
            # accept the move
            a[i] = donor - δ
            a[j] = recv + δ
            sum_sq = new_sum_sq
            cur_score = new_score
            if improve:
                no_improve_counter = 0
            else:
                no_improve_counter += 1
        else:
            no_improve_counter += 1

        iteration += 1

        # ---- periodic exact evaluation (guards against drift) ----
        if iteration % CHECK_EVERY == 0:
            # use the official evaluator for a trustworthy score
            exact_score = evaluate_sequence(a.tolist())
            if exact_score < best_score - 1e-12:
                best_score = exact_score
                best = a.copy()
                best_time = time.monotonic()
                elapsed = best_time - start_time
                print(f"[{elapsed:6.2f}s] new best (exact) = {best_score:.6f} "
                      f"(iter={iteration}, T={T:.3e})")
            # also keep the fast‑score version for debugging
            # (fast_score and best_score should coincide up to rounding)

        # ---- restart if we have been stuck for a long time ----
        if no_improve_counter >= RESTART_EVERY:
            # re‑inject a modest amount of noise around the current best
            a = best.copy()
            noise = np.exp(rng.normal(0.0, 0.03, size=n))
            a *= noise
            a = np.clip(a, 0.0, 1000.0)
            a = _project_onto_simplex(a)      # renormalise sum to 1
            sum_a = a.sum()
            sum_sq = np.dot(a, a)
            cur_score = 2.0 * n * sum_sq / (sum_a ** 2)
            no_improve_counter = 0
            # reset temperature schedule (jump back a little)
            start_time = time.monotonic()
            print(f"[{time.monotonic() - start_time:6.2f}s] restart after stagnation")

        # stop early if we have already hit the theoretical optimum
        if best_score <= 2.000001:
            break

    # ------------------------------------------------------------------
    # 4) Return the best sequence (clipped to the evaluator’s limits)
    # ------------------------------------------------------------------
    best = np.clip(best, 0.0, 1000.0)
    return [float(x) for x in best]
```
