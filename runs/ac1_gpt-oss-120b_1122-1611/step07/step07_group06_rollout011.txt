assistantfinal**Solution Overview**

The function `propose_candidate` searches for a non‑negative step‑function (a 1‑D
vector) that minimises the value returned by the supplied
`evaluate_sequence`.  
The evaluation metric is:

```
score = 2·n·max(conv(a,a)) / ( sum(a)² )
```

Our search strategy is a fast, budget‑aware **hill‑climbing** algorithm
combined with a few random restarts:

* **Length selection** – we try several sizes (`32 … 8192`).  
  Small lengths make the exact convolution cheap while still giving
  enough degrees of freedom to lower the score.
* **Initialisation** – for each chosen length a random point on the
  probability simplex (Dirichlet distribution) is generated.
* **Local moves** – repeatedly pick two positions `i≠j` and transfer a
  random amount `δ ≤ a[i]` from `i` to `j`.  
  Because the transferred mass is taken from `i`, the simplex constraint
  (`a ≥ 0, Σa = 1`) stays satisfied without an extra projection.
* **Acceptance** – the move is kept if it improves the exact score.
  Occasionally a very small probability (`0.1 %`) of accepting a worse
  move is kept to escape shallow plateaus.
* **Restart logic** – after a configurable number of unsuccessful steps
  a fresh random vector is started.  The whole loop runs until the time
  budget is exhausted (the harness reserves a 5‑second safety margin).
* **Best‑ever bookkeeping** – the best vector and its score are stored
  throughout the run and finally returned.

The algorithm uses only `numpy` and the provided `evaluate_sequence`.
All heavy work (the convolution) is delegated to the exact evaluator,
so the implementation stays simple and robust.

```python
"""Hill‑climbing search for a low‑score step‑function.

The function ``propose_candidate`` receives a time budget (seconds) and
returns a list of non‑negative heights.  It repeatedly

* picks a random vector on the simplex,
* performs many lightweight “mass‑transfer” moves,
* keeps every improvement according to the exact ``evaluate_sequence``,
* restarts when progress stalls,

and finally returns the best vector discovered before the deadline.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (no closures, top‑level as required)
# ----------------------------------------------------------------------


def _random_simplex(rng: np.random.Generator, n: int) -> np.ndarray:
    """
    Return a random point on the probability simplex of dimension ``n``.
    Uses a Dirichlet(1,…,1) (i.e. i.i.d. exponential) distribution.
    """
    x = rng.random(n)
    s = x.sum()
    if s == 0.0:                     # extremely unlikely, but be safe
        return np.full(n, 1.0 / n, dtype=np.float64)
    return x / s


def _evaluate(seq: np.ndarray) -> float:
    """
    Thin wrapper around the external ``evaluate_sequence`` that accepts a
    NumPy array and returns a Python ``float``.
    """
    # ``evaluate_sequence`` is assumed to be already imported in the
    # execution environment.
    return evaluate_sequence(seq.tolist())


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(
    seed: int = 12345,
    budget_s: float = 1000.0,
    *,
    lengths: list[int] = None,
    max_local_steps: int = 3000,
    restart_interval: int = 600,
    accept_worse_prob: float = 0.001,
) -> list[float]:
    """
    Search for a step‑function that minimises ``evaluate_sequence``.

    Parameters
    ----------
    seed : int, optional
        Seed for the NumPy random generator.
    budget_s : float, optional
        Total time budget in seconds.  Five seconds are reserved as a
        safety margin for the harness.
    lengths : list[int], optional
        Sequence lengths to try.  If ``None`` a default geometric set is
        used.
    max_local_steps : int, optional
        Maximum number of hill‑climbing moves per restart.
    restart_interval : int, optional
        After this many steps without improvement a fresh random start is
        triggered.
    accept_worse_prob : float, optional
        Probability of accepting a move that does not improve the score
        (helps escaping plateaus).

    Returns
    -------
    list[float]
        The best sequence found (already clipped to the limits imposed
        by ``evaluate_sequence``).
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # 0) Time‑budget handling (5 s safety margin for the harness)
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)

    # ------------------------------------------------------------------
    # 1) Length candidates
    # ------------------------------------------------------------------
    if lengths is None:
        lengths = [32, 64, 128, 256, 512, 1024, 2048, 4096, 8192]

    best_seq = None
    best_score = np.inf
    best_time = None

    # ------------------------------------------------------------------
    # 2) Main search loop
    # ------------------------------------------------------------------
    while time.monotonic() < deadline:
        # pick a length at random – smaller lengths give cheap evaluations
        n = int(rng.choice(lengths))

        # ------------------------------------------------------------------
        #   a) Random start on the simplex
        # ------------------------------------------------------------------
        a = _random_simplex(rng, n)          # sum(a) == 1, a_i ≥ 0
        cur_score = _evaluate(a)

        # record if this start already beats the global best
        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            best_time = time.monotonic()
            print(f"[{best_time:.2f}s] New global best  n={n}  score={best_score:.6f}")

        # ------------------------------------------------------------------
        #   b) Hill‑climbing on the current start
        # ------------------------------------------------------------------
        steps_since_improve = 0

        for step in range(max_local_steps):
            # stop early if we are out of time
            if time.monotonic() >= deadline:
                break

            # pick two distinct indices i (source) and j (target)
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue

            # amount to move – at most half of the source entry
            delta = rng.random() * 0.5 * a[i]

            # propose the new vector (sum stays 1, non‑negativity guaranteed)
            a_new = a.copy()
            a_new[i] -= delta
            a_new[j] += delta

            new_score = _evaluate(a_new)

            # accept if better, otherwise with a tiny probability
            if new_score < cur_score or rng.random() < accept_worse_prob:
                a = a_new
                cur_score = new_score
                steps_since_improve = 0

                # global bookkeeping
                if new_score < best_score:
                    best_score = new_score
                    best_seq = a.copy()
                    best_time = time.monotonic()
                    elapsed = best_time - (deadline - budget_s + 5.0)
                    print(
                        f"[{elapsed:.2f}s] Improved global best  n={n}  "
                        f"score={best_score:.6f}  step={step}"
                    )
            else:
                steps_since_improve += 1

            # restart if we have been stuck for a while
            if steps_since_improve >= restart_interval:
                break

        # ------------------------------------------------------------------
        #   c) Small safety pause to keep the CPU usage modest
        # ------------------------------------------------------------------
        # (no explicit sleep – the loop runs fast enough)

    # ------------------------------------------------------------------
    # 3) Return the best sequence (clipped to evaluator limits)
    # ------------------------------------------------------------------
    if best_seq is None:                     # should never happen
        best_seq = _random_simplex(rng, 32)

    best_seq = np.clip(best_seq, 0.0, 1000.0)

    print(f"Finished. Best score = {best_score:.6f} (length={best_seq.size})")
    return [float(x) for x in best_seq]
```
