Propose a step‑function via an iterative linear‑programming refinement.

Algorithm
---------

1. **Normalization** –  Work with a fixed ℓ₁‑norm  
   `S = sqrt(2·n)`.  With this scaling the evaluation function
   `evaluate_sequence` reduces to `max(conv(f,f))`, i.e. we only need to
   minimise the peak of the self‑convolution.

2. **LP sub‑problem** –  Given the current vector `f` and its peak
   `M = max(conv(f,f))`, solve the linear programme

        maximise    1ᵀ b
        subject to  f * b ≤ M   (component‑wise)
                    b ≥ 0

   The convolution `f*b` is linear in `b`; the constraints are
   assembled as a sparse (2 n‑1) × n matrix.  The solution `b` is the
   “most massive” vector that still respects the current peak `M`.

3. **Rescaling & update** –  Scale `b` to the required ℓ₁‑norm
   (`g = b·(S/∑b)`).  If `max(conv(g,g))` improves the bound we replace
   `f ← g`; otherwise we take a convex combination
   `f ← (1‑t)·f + t·g` with `t = 0.5`.  This guarantees that the peak
   never increases.

4. **Loop** –  Repeat the LP + update step while time permits (≈30
   iterations in practice).  Keep the best vector seen so far.

5. **Return** –  Clip the best vector to the limits enforced by
   `evaluate_sequence` and return it as a plain list of floats.

The LP is solved with SciPy’s HiGHS interior‑point solver using a
sparse constraint matrix, which is fast enough for `n` up to ~2000.

    # if a previous construction is available, reuse its length (if not too large)
    if "height_sequence_1" in globals():
        cand = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
        if cand.ndim == 1 and cand.size > 0 and np.isfinite(cand).all():
            n = cand.size
            f = np.clip(cand, 0.0, None)
        else:
            n = 1500
            f = np.full(n, 1.0 / n, dtype=np.float64)
    else:
        n = 1500
        f = np.full(n, 1.0 / n, dtype=np.float64)

    # target ℓ₁‑norm S = sqrt(2·n)  – scaling does not affect the bound
    target_sum = np.sqrt(2.0 * n)
    f_sum = f.sum()
    if f_sum > 0.0:
        f = f * (target_sum / f_sum)
    else:
        f = np.full(n, target_sum / n, dtype=np.float64)

    # ------------------------------------------------------------------
    # 2) pre‑compute row / column indices for the Toeplitz convolution matrix
    # ------------------------------------------------------------------
    # For the constraint   (f * b)[k] = Σ_i f[i]·b[k‑i] ≤ M,
    # the coefficient of variable b_j in row k is f[k‑j] (if 0 ≤ k‑j < n).
    # This matrix is dense with exactly n² non‑zeros.
    i = np.arange(n, dtype=np.int32)[:, None]      # shape (n,1)
    j = np.arange(n, dtype=np.int32)[None, :]      # shape (1,n)
    row_idx = (i + j).ravel()                     # length n², values 0 … 2n‑2
    col_idx = np.repeat(np.arange(n, dtype=np.int32), n)

    # ------------------------------------------------------------------
    # 3) optimisation loop
    # ------------------------------------------------------------------
    best_f = f.copy()
    best_val = _convolution_max(best_f)   # with the fixed ℓ₁‑norm this equals the score
    iter_no = 0
    max_iters = 40                         # safety cap; we stop earlier if time runs out

    while time.monotonic() < deadline and iter_no < max_iters:
        # current peak
        M = _convolution_max(f)

        # ----- build the constraint matrix A (sparse) -----
        # data = f[i] repeated for each column j
        data = np.tile(f, n)                     # shape (n*n,)
        A = scipy.sparse.csr_matrix((data, (row_idx, col_idx)),
                                    shape=(2 * n - 1, n))

        # ----- linear programme: maximise 1ᵀb  (i.e. minimise –1ᵀb) -----
        c = -np.ones(n, dtype=np.float64)        # minimise –sum(b)
        b_ub = np.full(2 * n - 1, M, dtype=np.float64)

        # time allocated to the solver: leave a buffer for the next iteration
        time_left = deadline - time.monotonic()
        solver_opts = {"presolve": True}
        if time_left > 0:
            # HiGHS understands a ``time_limit`` (seconds)
            solver_opts["time_limit"] = min(30.0, time_left)

        res = scipy.optimize.linprog(
            c,
            A_ub=A,
            b_ub=b_ub,
            bounds=[(0.0, None)] * n,
            method="highs",
            options=solver_opts,
        )

        if not res.success:
            # If the LP fails we fall back to a simple random perturbation.
            print(f"[{time.monotonic() - start:.1f}s] LP failed: {res.message}")
            # random jitter
            jitter = np.exp(rng.normal(0.0, 0.08, size=n))
            f = f * jitter
            f = np.clip(f, 0.0, None)
            f /= f.sum()
            f *= target_sum
            iter_no += 1
            continue

        b = res.x
        sum_b = b.sum()
        if sum_b <= 0.0:
            break

        # ----- rescale b to the required ℓ₁‑norm -----
        scale = target_sum / sum_b
        g = b * scale

        # ----- evaluate the candidate g -----
        M_g = _convolution_max(g)

        # ----- accept the better candidate -----
        if M_g < M - 1e-12:
            f = g
            M = M_g
        else:
            # no improvement – try a convex combination (t = 0.5)
            t = 0.5
            f = (1.0 - t) * f + t * g
            M = _convolution_max(f)

        # keep the best ever seen
        if M < best_val - 1e-12:
            best_val = M
            best_f = f.copy()
            elapsed = time.monotonic() - start
            print(f"[{elapsed:6.2f}s] new best peak = {best_val:.6f}")

        iter_no += 1

    # ------------------------------------------------------------------
    # 4) final post‑processing and return
    # ------------------------------------------------------------------
    best_f = np.clip(best_f, 0.0, 1000.0)   # safety‐clipping required by evaluate_sequence
    return [float(x) for x in best_f]
