The function below searches for a non‑negative step‑function that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

i.e. the quantity returned by `evaluate_sequence`.  
The search is split into two clearly separated phases that together
exploit complementary ideas:

1. **Stochastic‑annealing phase** – a cheap, highly exploratory
   neighbourhood search that repeatedly moves a small amount of mass
   from one index to another.  The move is accepted according to a
   temperature schedule, allowing the algorithm to jump out of local
   minima.  The current best solution is kept at all times.

2. **Fine‑tuning phase** – an Adam optimiser that works on the
   log‑soft‑max parametrisation (exactly the parametrisation used in the
   reference implementation).  Starting from the best point found
   by the annealer, a relatively small number of Adam steps (a few
   thousand) sharpens the solution and often yields a small but
   noticeable improvement.

Both phases make heavy use of FFT‑based convolution ( `O(n log n)` ) so
that even for ~ 4000 coefficients a single score evaluation is fast
enough to run many thousands of iterations within the ~ 1000 s time
budget.

The code respects all the rules: everything is defined at the top
level, there are no closures, only `numpy`, `scipy.special`, and standard
library modules are imported, and the final sequence is clipped to the
range `[0, 1000]` required by the evaluator.

```python
"""Propose a low‑self‑convolution step function.

The algorithm consists of two stages:

1. Simulated‑annealing on the raw coefficients.
   Small amounts of mass are transferred between random positions.
   Acceptance follows a temperature schedule, permitting uphill moves.
   The best solution seen is stored.

2. Short Adam refinement on the log‑soft‑max parametrisation.
   This mirrors the reference gradient method but starts from the
   annealer's best point and runs only a few thousand iterations,
   giving a fine‑grained improvement.

Both stages use FFT‑based convolution for an O(n log n) score
computation, allowing thousands of iterations within the 1000 s budget.
"""

import time
import numpy as np
from scipy.special import logsumexp

# ----------------------------------------------------------------------
# Helper utilities – top level (no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _softmax_logits(logits: np.ndarray) -> np.ndarray:
    """Stable softmax transformation, returns a probability vector."""
    m = np.max(logits)
    exp = np.exp(logits - m)
    s = exp.sum()
    if s == 0.0:
        return np.full_like(logits, 1.0 / logits.size)
    return exp / s


def _score_of(a: np.ndarray, fft_len: int) -> float:
    """
    Compute the objective 2 * n * max(conv) / (sum(a)**2).
    The convolution is performed via FFT of length `fft_len`.
    """
    n = a.shape[0]
    a_fft = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(a_fft * a_fft, n=fft_len)[: 2 * n - 1]
    max_b = conv.max()
    sum_a = a.sum()
    if sum_a < 1e-12:  # should never happen for a valid start
        return np.inf
    return 2.0 * n * max_b / (sum_a ** 2)


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: float = 1000.0, **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function (list of heights) that minimises
    ``evaluate_sequence``.  The search consists of a simulated‑annealing stage
    followed by a short Adam refinement.  The best sequence found before the
    time budget expires is returned.
    """
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # Time handling (keep a safety margin)
    # --------------------------------------------------------------
    start = time.monotonic()
    deadline = start + max(0.0, float(budget_s) - 5.0)

    # --------------------------------------------------------------
    # Choose a length n and an initial distribution.
    # Prefer the previously found construction if present.
    # --------------------------------------------------------------
    if "height_sequence_1" in globals():
        base = np.asarray(globals()["height_sequence_1"], dtype=np.float64)
    else:
        # fallback – a uniform vector of length ≈ 4000
        base = np.full(3840, 1.0, dtype=np.float64)

    # Clip to valid range and normalise to sum‑1 (scale does not affect the score)
    base = np.clip(base, 0.0, None)
    total = base.sum()
    if total == 0.0:
        base[:] = 1.0 / base.size
    else:
        base /= total

    n = base.shape[0]

    # pre‑compute the FFT length for self‑convolution (used throughout)
    fft_len_conv = _next_pow2(2 * n - 1)

    # --------------------------------------------------------------
    # State variables for the annealing phase
    # --------------------------------------------------------------
    a = base.copy()                     # current candidate (sums to 1)
    cur_score = _score_of(a, fft_len_conv)
    best_a = a.copy()
    best_score = cur_score
    last_improve = start

    # Annealing hyper‑parameters
    T0 = 0.02          # initial temperature
    Tmin = 1e-6        # final temperature
    step_frac_start = 0.20   # start moving up to 20 % of the source mass
    step_frac_end = 0.004    # end moving only a tiny fraction
    RESTART_WAIT = 30.0      # seconds without improvement → restart

    # --------------------------------------------------------------
    # Simulated annealing loop
    # --------------------------------------------------------------
    while time.monotonic() < deadline:
        now = time.monotonic()
        fraction = (now - start) / (deadline - start)          # 0 → 1
        # linearly decay temperature and step size
        T = Tmin + (T0 - Tmin) * (1.0 - fraction)
        step_frac = step_frac_start + (step_frac_end - step_frac_start) * fraction

        # ---- propose a move: transfer a small chunk from i to j ----------
        # pick a source index with non‑zero mass (simple rejection sampling)
        i = rng.integers(n)
        while a[i] <= 0.0:
            i = rng.integers(n)
        # pick a different destination index
        j = rng.integers(n - 1)
        if j >= i:
            j += 1

        # amount to move – a random fraction of the source mass
        delta = step_frac * rng.random() * a[i]
        if delta <= 0.0:
            continue

        a_new = a.copy()
        a_new[i] -= delta
        a_new[j] += delta

        # ---- evaluate the new candidate ----------------------------------
        new_score = _score_of(a_new, fft_len_conv)

        # ---- acceptance test (Metropolis) --------------------------------
        accept = False
        if new_score < cur_score:
            accept = True
        else:
            # probability to accept an uphill move
            prob = np.exp(-(new_score - cur_score) / max(T, 1e-12))
            if rng.random() < prob:
                accept = True

        if accept:
            a = a_new
            cur_score = new_score
            if new_score < best_score - 1e-12:
                best_score = new_score
                best_a = a.copy()
                last_improve = now
                elapsed = now - start
                print(f"[{elapsed:6.2f}s] anneal new best = {best_score:.6f}")

        # ---- restart if stagnant -----------------------------------------
        if now - last_improve > RESTART_WAIT:
            # perturb the current best a little and continue from there
            perturb = rng.normal(0.0, 0.02, size=n)
            a = best_a + perturb
            a = np.clip(a, 0.0, None)
            s = a.sum()
            if s == 0.0:
                a[:] = 1.0 / n
            else:
                a /= s
            cur_score = _score_of(a, fft_len_conv)
            last_improve = now
            elapsed = now - start
            print(f"[{elapsed:6.2f}s] anneal restart – best {best_score:.6f}")

    # ------------------------------------------------------------------
    # Adam fine‑tuning (few thousand iterations, starts from best_a)
    # ------------------------------------------------------------------
    # Only perform the refinement if we still have a reasonable amount
    # of time left (otherwise return the annealer's best directly).
    remaining = deadline - time.monotonic()
    if remaining > 5.0:
        # Re‑initialise Adam on log‑soft‑max parameters
        eps = 1e-12
        x = np.log(best_a + eps)                 # logits
        m = np.zeros_like(x)
        v = np.zeros_like(x)

        # Adam hyper‑parameters
        lr = 0.6
        beta1 = 0.9
        beta2 = 0.999
        adam_eps = 1e-8

        # Soft‑max temperature schedule for the surrogate
        beta_start = 5.0
        beta_end = 200.0
        beta_ramp_iters = 2000

        # FFT length for the correlation needed in the gradient
        fft_len_corr = _next_pow2(3 * n - 2)

        it = 0
        while time.monotonic() < deadline:
            it += 1

            # logits → probability vector (the actual coefficients)
            a = _softmax_logits(x)

            # self‑convolution via FFT
            a_fft = np.fft.rfft(a, n=fft_len_conv)
            conv_full = np.fft.irfft(a_fft * a_fft, n=fft_len_conv)[: 2 * n - 1]

            # exact score (for bookkeeping)
            cur_max = conv_full.max()
            cur_score = 2.0 * n * cur_max
            if cur_score < best_score - 1e-12:
                best_score = cur_score
                best_a = a.copy()
                elapsed = time.monotonic() - start
                print(f"[{elapsed:6.2f}s] adam new best = {best_score:.6f}")

            # surrogate max – soft‑max over the convolution values
            beta = beta_end if it > beta_ramp_iters else \
                beta_start + (beta_end - beta_start) * it / beta_ramp_iters
            scaled = beta * conv_full
            lse = logsumexp(scaled)
            w = np.exp(scaled - lse)    # probability over 2n‑1 positions, sums to 1

            # gradient of surrogate w.r.t. a (correlation w ⋆ a)
            w_fft = np.fft.rfft(w, n=fft_len_corr)
            a_fft_corr = np.fft.rfft(a, n=fft_len_corr)
            corr_full = np.fft.irfft(w_fft * np.conj(a_fft_corr), n=fft_len_corr)
            start_idx = n - 1
            grad_a = 2.0 * corr_full[start_idx:start_idx + n]

            # chain rule → gradient w.r.t. logits
            dot = np.dot(grad_a, a)
            grad_x = a * (grad_a - dot)

            # Adam update
            m = beta1 * m + (1.0 - beta1) * grad_x
            v = beta2 * v + (1.0 - beta2) * (grad_x * grad_x)
            m_hat = m / (1.0 - beta1 ** it)
            v_hat = v / (1.0 - beta2 ** it)
            x -= lr * m_hat / (np.sqrt(v_hat) + adam_eps)

            # occasional jitter to help escape plateaus
            if it % 500 == 0:
                x += rng.normal(0.0, 0.02, size=n)

    # ------------------------------------------------------------------
    # Return the best sequence (clipped to evaluator limits)
    # ------------------------------------------------------------------
    best_a = np.clip(best_a, 0.0, 1000.0)
    return [float(v) for v in best_a]
```
