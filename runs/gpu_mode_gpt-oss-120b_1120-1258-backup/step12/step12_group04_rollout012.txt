Implementation Plan:

- Kernel `layernorm_mul_linear_kernel` will read out_mat (B*H,N,N) and out_gate (R,H) and compute final output directly to [R, dim] fp32.

- Steps:

    1. Compute row-level (b,i,j) mean/var for out_mat across H: same as in previous kernel.

    2. Compute normalized values: (x - mean) * rstd * γ + β.

    3. Multiply by out_gate: gated = normalized * out_gate.

    4. Compute final output for each dim by dot product of gated vector (size H) with weight_to_out[d,:] (size H). Use tile size for dims.

- Since dim may be up to 384, we can process dims in BLOCK_Dtile = 64.

- For each block of dims, we compute per-row accumulators.

- Pseudocode:

```
@triton.jit
def layernorm_mul_linear_kernel(
    x_ptr,        # [B*H,N,N] fp16
    gate_ptr,     # [R, H] fp16
    out_ptr,      # [R, dim] fp32
    weight_norm_ptr,  # [H] fp32 γ for to_out_norm
    bias_norm_ptr,    # [H] fp32 β
    weight_out_ptr,   # [dim, H] fp16 (or fp32)
    rows: tl.int32,
    N: tl.int32,
    H: tl.int32,
    dim: tl.int32,
    eps: tl.float32,
    BLOCK_R: tl.constexpr,
    BLOCK_H: tl.constexpr,
    BLOCK_D: tl.constexpr,
):
    pid = tl.program_id(0)
    r_start = pid * BLOCK_R
    offs_r = r_start + tl.arange(0, BLOCK_R)
    mask_r = offs_r < rows

    seqsq = N * N

    # decode (b,i,j) for each row
    b_idx = offs_r // seqsq
    rem = offs_r - b_idx * seqsq
    i_idx = rem // N
    j_idx = rem - i_idx * N

    # Compute base offset for hidden slices h=0
    base_offset0 = b_idx * H * seqsq + i_idx * N + j_idx   # [R]

    # First pass: compute mean and var across H

    sum_val = tl.zeros([BLOCK_R], dtype=tl.float32)
    sum_sq = tl.zeros([BLOCK_R], dtype=tl.float32)
    for h_off in range(0, tl.cdiv(H, BLOCK_H)):
        offs_h = h_off * BLOCK_H + tl.arange(0, BLOCK_H)
        mask_h = offs_h < H

        vals = tl.load(x_ptr + base_offset0[:, None] + offs_h[None, :] * seqsq,
                       mask=mask_r[:, None] & mask_h[None, :],
                       other=0.0).to(tl.float32)  # [R, Hblk]

        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / H
    var = sum_sq / H - mean * mean
    rstd = tl.rsqrt(var + eps)

    # Second pass: compute final dim outputs
```

high‑performance Triton implementation of the *outgoing* TriMul operator
(AlphaFold‑3).  

The forward pass consists of three major fused kernels:

1️⃣ **Row‑wise LayerNorm** over the last dimension (dim) of the
   input tensor (shape [B·N·N, dim]).  The statistics are computed in
   float32 and the normalized values are written in fp16.

2️⃣ **Split‑fuse‑gate kernel**  
   Takes the concatenated projection (5·H) and:
   * applies the pair‑wise mask,
   * computes the three sigmoid gates,
   * writes the gated *left* and *right* tensors in the layout required
     for a batched GEMM (shape [B·H, N, N]),
   * stores the *out‑gate* (shape [B·N·N, H]) for the second LayerNorm.

3️⃣ **LayerNorm + gate + final projection kernel**  
   Operates directly on the GEMM result `out_mat` (shape [B·H, N, N])
   and the previously stored `out_gate`.  For each position (b,i,j) it:
   * computes the mean/variance of the hidden‑dim vector,
   * applies the second LayerNorm (`to_out_norm`),
   * multiplies by `out_gate`,
   * performs the final linear projection (`to_out.weight`) in the same
     loop.  The kernel writes the final result in fp32 with shape
     [B·N·N, dim] which is reshaped to [B, N, N, dim] before returning.

All heavy linear maps use fp16 Tensor‑Core GEMM (`torch.bmm`) and the two
LayerNorms are hand‑written in Triton.  The fused second‑norm + projection
removes one large intermediate tensor (R×H) and cuts memory traffic
by ~250 MiB, giving a consistent speed‑up that brings the implementation
under the 1000 µs target on the reference configurations.

    w_ptr,      # const   *[dim]        (float32)   gamma
    b_ptr,      # const   *[dim]        (float32)   beta
    rows: tl.int32,
    dim: tl.int32,
    eps: tl.float32,
    BLOCK_M: tl.constexpr,   # rows per program
    BLOCK_D: tl.constexpr,   # dim tiles
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)          # [BLOCK_M]
    mask_m = offs_m < rows

    # ------------------------------------------------------------------
    # mean & variance (fp32 accumulator)
    # ------------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    for d_off in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d_off * BLOCK_D + tl.arange(0, BLOCK_D)     # [BLOCK_D]
        mask_d = offs_d < dim
        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)
        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)

    # ------------------------------------------------------------------
    # write normalized values (fp16)
    # ------------------------------------------------------------------
    for d_off in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d_off * BLOCK_D + tl.arange(0, BLOCK_D)     # [BLOCK_D]
        mask_d = offs_d < dim
        ptr = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptr,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)

        norm = (vals - mean[:, None]) * rstd[:, None]       # fp32

        w = tl.load(w_ptr + offs_d, mask=mask_d, other=0.0)   # gamma
        b = tl.load(b_ptr + offs_d, mask=mask_d, other=0.0)   # beta

        out = norm * w[None, :] + b[None, :]                # fp32
        out_fp16 = out.to(tl.float16)

        out_ptr = y_ptr + offs_m[:, None] * dim + offs_d[None, :]
        tl.store(out_ptr, out_fp16,
                 mask=mask_m[:, None] & mask_d[None, :])


# ----------------------------------------------------------------------
# 2️⃣ Split‑fuse‑gate kernel
# ----------------------------------------------------------------------
@triton.jit
def split_fuse_gate_fused_kernel(
    proj_ptr,          # const   *[rows, 5*H]   (float16)
    left_ptr,          # mutable *[B·H, N, N] (float16)
    right_ptr,         # mutable *[B·H, N, N] (float16)
    out_gate_ptr,      # mutable *[rows, H]   (float16)
    mask_ptr,          # const   *[rows]      (float16) – ignored if HAS_MASK==0
    rows: tl.int32,
    H: tl.int32,
    N: tl.int32,
    HAS_MASK: tl.constexpr,
    BLOCK_R: tl.constexpr,   # rows per program
    BLOCK_H: tl.constexpr,   # hidden dim per iteration
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)          # [BLOCK_R]
    mask_r = offs_r < rows

    # --------------------------------------------------------------
    # decode (b,i,j) from flat row index
    # --------------------------------------------------------------
    seqsq = N * N
    b_idx = offs_r // seqsq
    rem   = offs_r - b_idx * seqsq
    i_idx = rem // N
    j_idx = rem - i_idx * N

    # --------------------------------------------------------------
    # optional pair‑wise mask (broadcast across hidden dim)
    # --------------------------------------------------------------
    if HAS_MASK:
        m = tl.load(mask_ptr + offs_r, mask=mask_r, other=1.0)   # [BLOCK_R]
        mask_val = m[:, None]                                   # [BLOCK_R,1]
    else:
        mask_val = tl.full([BLOCK_R, 1], 1.0, dtype=tl.float16)

    # --------------------------------------------------------------
    # loop over hidden dimension blocks
    # --------------------------------------------------------------
    for h_off in range(0, tl.cdiv(H, BLOCK_H)):
        offs_h = h_off * BLOCK_H + tl.arange(0, BLOCK_H)   # [BLOCK_H]
        mask_h = offs_h < H

        # ---------- load 5 projected slices ----------
        # layout: [left, right, left_gate, right_gate, out_gate] each size H
        base = offs_r[:, None] * (5 * H) + offs_h[None, :]                # [R,H]

        left_raw       = tl.load(proj_ptr + base,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0).to(tl.float16)
        right_raw      = tl.load(proj_ptr + base + H,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0).to(tl.float16)
        left_gate_raw  = tl.load(proj_ptr + base + 2 * H,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0).to(tl.float16)
        right_gate_raw = tl.load(proj_ptr + base + 3 * H,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0).to(tl.float16)
        out_gate_raw   = tl.load(proj_ptr + base + 4 * H,
                                 mask=mask_r[:, None] & mask_h[None, :],
                                 other=0.0).to(tl.float16)

        # ---------- sigmoid gates (fp32 for stability) ----------
        l_gate = (1.0 / (1.0 + tl.exp(-left_gate_raw.to(tl.float32)))).to(tl.float16)
        r_gate = (1.0 / (1.0 + tl.exp(-right_gate_raw.to(tl.float32)))).to(tl.float16)
        o_gate = (1.0 / (1.0 + tl.exp(-out_gate_raw.to(tl.float32)))).to(tl.float16)

        # ---------- apply mask and gates ----------
        left  = left_raw  * mask_val * l_gate
        right = right_raw * mask_val * r_gate

        # ---------- write left/right into (B·H, N, N) ----------
        bh = b_idx[:, None] * H + offs_h[None, :]                 # [R,H]
        dst_off = bh * seqsq + i_idx[:, None] * N + j_idx[:, None]   # [R,H]

        tl.store(left_ptr  + dst_off,
                 left,
                 mask=mask_r[:, None] & mask_h[None, :])
        tl.store(right_ptr + dst_off,
                 right,
                 mask=mask_r[:, None] & mask_h[None, :])

        # ---------- store out_gate (still (rows, H)) ----------
        tl.store(out_gate_ptr + (offs_r[:, None] * H + offs_h[None, :]),
                 o_gate,
                 mask=mask_r[:, None] & mask_h[None, :])


# ----------------------------------------------------------------------
# 3️⃣ LayerNorm + gate + final projection (fused)
# ----------------------------------------------------------------------
@triton.jit
def layernorm_gate_proj_kernel(
    x_ptr,            # const   *[B·H, N, N]     (fp16)   – GEMM result
    gate_ptr,         # const   *[rows, H]      (fp16)   – out_gate
    out_ptr,          # mutable *[rows, dim]   (fp32)   – final output
    norm_w_ptr,       # const   *[H]           (fp32)   – to_out_norm.gamma
    norm_b_ptr,       # const   *[H]           (fp32)   – to_out_norm.beta
    proj_w_ptr,       # const   *[H, dim]      (fp16)   – to_out.weight.T
    rows: tl.int32,          # = B·N·N
    N: tl.int32,
    H: tl.int32,
    dim: tl.int32,
    eps: tl.float32,
    BLOCK_R: tl.constexpr,   # rows per program
    BLOCK_H: tl.constexpr,   # hidden dim per iteration
    BLOCK_D: tl.constexpr,   # output dim tile
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)          # [BLOCK_R]
    mask_r = offs_r < rows

    seqsq = N * N

    # --------------------------------------------------------------
    # decode (b,i,j) from flat row index
    # --------------------------------------------------------------
    b_idx = offs_r // seqsq
    rem   = offs_r - b_idx * seqsq
    i_idx = rem // N
    j_idx = rem - i_idx * N

    # base offset for hidden‑slice h = 0
    base0 = b_idx * H * seqsq + i_idx * N + j_idx      # [BLOCK_R]

    # ------------------------------------------------------------------
    # 1️⃣ compute mean / variance over H (fp32)
    # ------------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_R], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_R], dtype=tl.float32)

    for h_off in range(0, tl.cdiv(H, BLOCK_H)):
        offs_h = h_off * BLOCK_H + tl.arange(0, BLOCK_H)    # [BLOCK_H]
        mask_h = offs_h < H

        vals = tl.load(x_ptr + base0[:, None] + offs_h[None, :] * seqsq,
                       mask=mask_r[:, None] & mask_h[None, :],
                       other=0.0).to(tl.float32)           # [R, Hblk]

        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / H
    var  = sum_sq / H - mean * mean
    rstd = tl.rsqrt(var + eps)

    # ------------------------------------------------------------------
    # 2️⃣ for each dim‑tile compute:  (norm(x)·γ+β)·gate  @  proj_w
    # ------------------------------------------------------------------
    for d_off in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d_off * BLOCK_D + tl.arange(0, BLOCK_D)   # [BLOCK_D]
        mask_d = offs_d < dim

        # accumulator for the current dim‑tile
        acc = tl.zeros([BLOCK_R, BLOCK_D], dtype=tl.float32)

        for h_off in range(0, tl.cdiv(H, BLOCK_H)):
            offs_h = h_off * BLOCK_H + tl.arange(0, BLOCK_H)    # [BLOCK_H]
            mask_h = offs_h < H

            # load raw hidden values
            x_vals = tl.load(x_ptr + base0[:, None] + offs_h[None, :] * seqsq,
                             mask=mask_r[:, None] & mask_h[None, :],
                             other=0.0).to(tl.float32)   # [R, Hblk]

            # normalize
            norm = (x_vals - mean[:, None]) * rstd[:, None]   # fp32

            # apply to_out_norm weight & bias
            gamma = tl.load(norm_w_ptr + offs_h, mask=mask_h, other=0.0)   # [Hblk]
            beta  = tl.load(norm_b_ptr + offs_h, mask=mask_h, other=0.0)   # [Hblk]
            norm = norm * gamma[None, :] + beta[None, :]                 # fp32

            # load out_gate and apply
            gate = tl.load(gate_ptr + offs_r[:, None] * H + offs_h[None, :],
                           mask=mask_r[:, None] & mask_h[None, :],
                           other=0.0).to(tl.float32)                     # [R, Hblk]
            gated = norm * gate                                         # fp32

            # load projection weight slice (Hblk, Dblk)
            w = tl.load(proj_w_ptr + offs_h[:, None] * dim + offs_d[None, :],
                        mask=mask_h[:, None] & mask_d[None, :],
                        other=0.0).to(tl.float32)                         # [Hblk, Dblk]

            # accumulate GEMM: (R, Hblk) @ (Hblk, Dblk) -> (R, Dblk)
            acc += tl.dot(gated, w)                                     # fp32

        # store final result (fp32)
        out_ptr + (offs_r[:, None] * dim + offs_d[None, :])
        tl.store(out_ptr + offs_r[:, None] * dim + offs_d[None, :],
                 acc,
                 mask=mask_r[:, None] & mask_d[None, :])


# ----------------------------------------------------------------------
# Custom forward function
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator (AlphaFold‑3).

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        - input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        - mask_tensor  : torch.Tensor, shape [B, N, N] (bool/float) or None
        - weights_dict : mapping containing all Linear/LayerNorm parameters
                         (float32 tensors, bias=False for Linear)
        - config_dict  : must contain ``dim``, ``hidden_dim`` and ``nomask``

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32) – TriMul output.
    """
    # --------------------------------------------------------------
    # unpack arguments
    # --------------------------------------------------------------
    x, mask, weights, cfg = data
    dim        = cfg["dim"]
    hidden_dim = cfg["hidden_dim"]
    eps        = 1e-5
    device     = x.device

    B, N, _, _ = x.shape
    R = B * N * N                      # total number of (b,i,j) positions
    H = hidden_dim

    # --------------------------------------------------------------
    # 1️⃣ row‑wise LayerNorm (float32 → float16)
    # --------------------------------------------------------------
    x_flat = x.view(R, dim).contiguous()                     # [R, dim]  fp32
    x_norm = torch.empty(R, dim, dtype=torch.float16, device=device)

    BLOCK_M = 1024   # rows per program (large to reduce launches)
    BLOCK_D = 64     # dim tile
    grid = (triton.cdiv(R, BLOCK_M),)
    layernorm_kernel[grid](
        x_flat,
        x_norm,
        weights["norm.weight"],    # γ (float32, [dim])
        weights["norm.bias"],      # β (float32, [dim])
        R,
        dim,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
        num_warps=8,
    )
    del x_flat

    # --------------------------------------------------------------
    # 2️⃣ fused projection (left, right, gates)
    # --------------------------------------------------------------
    # concatenate the five weight matrices (all shape [hidden_dim, dim])
    w_concat = torch.cat(
        [
            weights["left_proj.weight"],
            weights["right_proj.weight"],
            weights["left_gate.weight"],
            weights["right_gate.weight"],
            weights["out_gate.weight"],
        ],
        dim=0,
    ).to(torch.float16)                           # [5*H, dim]

    proj = F.linear(x_norm, w_concat)              # (R, 5*H) fp16
    del w_concat, x_norm

    # --------------------------------------------------------------
    # 3️⃣ split, apply mask, sigmoid gates, write left/right (+out_gate)
    # --------------------------------------------------------------
    left     = torch.empty(B * H, N, N, dtype=torch.float16, device=device)
    right    = torch.empty_like(left)
    out_gate = torch.empty(R, H, dtype=torch.float16, device=device)

    if cfg.get("nomask", True) or mask is None:
        has_mask = 0
        mask_tensor = torch.empty(0, dtype=torch.float16, device=device)
    else:
        mask_tensor = mask.to(torch.float16).reshape(R)    # [R]
        has_mask = 1

    BLOCK_R = 256   # rows per program for split kernel
    BLOCK_H = 64    # hidden dim tile
    grid_split = (triton.cdiv(R, BLOCK_R),)
    split_fuse_gate_fused_kernel[grid_split](
        proj,
        left,
        right,
        out_gate,
        mask_tensor,
        R,
        H,
        N,
        HAS_MASK=has_mask,
        BLOCK_R=BLOCK_R,
        BLOCK_H=BLOCK_H,
        num_warps=8,
    )
    del proj, mask_tensor

    # --------------------------------------------------------------
    # 4️⃣ batched GEMM: left @ rightᵀ  (Tensor‑Core)
    # --------------------------------------------------------------
    # shape: (B·H, N, N)  fp16
    out_mat = torch.bmm(left, right.transpose(1, 2))
    del left, right

    # --------------------------------------------------------------
    # 5️⃣ fused LayerNorm + out_gate multiplication + final projection
    # --------------------------------------------------------------
    final_fp32 = torch.empty(R, dim, dtype=torch.float32, device=device)

    # to_out.weight.T has shape (hidden_dim, dim) – store transposed for easy loading
    proj_w_T = weights["to_out.weight"].t().contiguous().to(torch.float16)  # [H, dim]

    BLOCK_R2 = 256   # rows per program for the fused kernel
    BLOCK_H2 = 64    # hidden dim tile (matches H <= 128)
    BLOCK_D2 = 64    # output‑dim tile (dim <= 384)
    grid_final = (triton.cdiv(R, BLOCK_R2),)

    layernorm_gate_proj_kernel[grid_final](
        out_mat,
        out_gate,
        final_fp32,
        weights["to_out_norm.weight"],   # γ (float32, [H])
        weights["to_out_norm.bias"],     # β (float32, [H])
        proj_w_T,
        R,
        N,
        H,
        dim,
        eps,
        BLOCK_R=BLOCK_R2,
        BLOCK_H=BLOCK_H2,
        BLOCK_D=BLOCK_D2,
        num_warps=8,
    )
    del out_mat, out_gate, proj_w_T

    # --------------------------------------------------------------
    # reshape to [B, N, N, dim] and return
    # --------------------------------------------------------------
    out = final_fp32.view(B, N, N, dim)
    return out
