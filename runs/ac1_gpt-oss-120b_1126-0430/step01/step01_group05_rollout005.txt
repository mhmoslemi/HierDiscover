assistantfinal**Solution Overview**

The evaluation of a step‑function  

\[
E(a)=\frac{2\,n\;\max(a*a)}{(\sum a)^2}
\]

is *scale‑invariant*: multiplying all heights by a constant does not change the
score.  
Consequently we can restrict the search to families of sequences that are easy
to generate and adjust only their *shape*.

The best known analytic shape is a pure power‑law  

\[
a_i=(i+1)^{-p},\qquad 0<p<1,
\]

with an asymptotic optimum around \(p\approx0.58\) (score ≈ 1.35).  
The previous submission used exactly this family and a tiny hill‑climb on
single coordinates, reaching ≈ 1.575.

The new approach improves in two ways:

1. **Richer parametrisation** – we augment the power law with a *shift* and an
   *exponential cut‑off*  

   \[
   a_i=(i+\delta)^{-p}\,e^{-\lambda i},
   \qquad
   p\in[0.45,0.75],\;
   \delta\in[1,10],\;
   \lambda\in[0,2.5\!\times\!10^{-3}.
   \]

   The shift flattens the very first few values, the exponential tail
   removes the far‑right part of the distribution. Both help to lower the
   maximal autocorrelation without harming the total mass.

2. **Two‑phase optimisation**

   *Stage 1 – global search*  
   • a fine grid for `p` (≈ 120 points) – evaluated first (sorted by the cheap
     analytic proxy from the statement).  
   • a random search over the three parameters (`p,δ,λ`) to discover promising
     regions that a pure grid cannot reach.

   *Stage 2 – local refinement*  
   Starting from the best sequence found, we run a fast coordinate‑wise
   stochastic hill‑climb:

   *   **multiplicative perturbation** of a single entry,
   *   **mass transfer** between two random indices (keeps the global sum
       unchanged and explores non‑multiplicative directions).

   The step size is gradually reduced, and every accepted move updates the
   global best.  All operations are cheap (only a single `np.convolve` call).

The whole routine respects the 1000 s time limit, prints progress, and finally
returns the best list of heights found.

```python
#!/usr/bin/env python
"""
propose_candidate – minimise the evaluation of a non‑negative step function.

Algorithm
---------
1. Choose a working length `n`.  If the previous best sequence
   `height_sequence_1` exists, reuse its length; otherwise use 5000.
2. Global search:
   * Scan a fine grid of power‑law exponents `p` (delta=1, lambda=0) – the
     analytic proxy `_approx_score` is used to visit the most promising `p`
     first.
   * Randomly sample triples (p, delta, lam) in a wide range and keep the
     best sequence.
3. Local refinement:
   Starting from the best candidate, perform many stochastic moves
   (multiplicative perturbations and transfers of mass between two indices)
   with a slowly decreasing step size.  Every improvement updates the global
   best.
4. Return the best sequence discovered before the time budget expires.

The search is completely self‑contained; it only calls the already imported
`evaluate_sequence`.
"""

import time
import numpy as np


# ----------------------------------------------------------------------
# Helper functions – all top level, no closures
# ----------------------------------------------------------------------
def _approx_score(p: float) -> float:
    """
    Cheap analytic proxy for the evaluation of a pure power law.
    Used only to sort the grid of exponents.
    """
    from math import gamma

    u = 1.0 - p
    return 2.0 * (u ** 2) * (gamma(u) ** 2) / gamma(2.0 * u)


def _generate_sequence(p: float, delta: float, lam: float, n: int) -> list[float]:
    """
    Return a list of length `n` with entries
        a_i = (i + delta)^{-p} * exp(-lam * i) .
    All arguments are assumed to be non‑negative and delta≥1 to avoid a
    singularity at i=0.
    """
    i = np.arange(n, dtype=np.float64)
    # power‑law part
    seq = (i + delta) ** (-p)
    # exponential damping
    if lam != 0.0:
        seq = seq * np.exp(-lam * i)
    # convert to plain Python list – required by `evaluate_sequence`
    return seq.tolist()


def _evaluate(seq: list[float]) -> float:
    """
    Thin wrapper around the provided `evaluate_sequence`.
    Exists so that we can keep the call site tidy.
    """
    # `evaluate_sequence` is assumed to be already imported in the
    # execution environment.
    return evaluate_sequence(seq)  # type: ignore[name-defined]


# ----------------------------------------------------------------------
# Main entry point required by the competition framework
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a step‑function with a low evaluation score.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Total time budget in seconds.
    kwargs : dict
        Ignored – present only to match the required signature.

    Returns
    -------
    list[float]
        The best sequence found within the allotted time.
    """
    # ------------------------------------------------------------------
    # 0. Initialise RNG and timing
    # ------------------------------------------------------------------
    np.random.seed(seed)
    start_time = time.time()
    # leave a safety margin of a few seconds for the environment
    deadline = start_time + budget_s - 5.0

    # ------------------------------------------------------------------
    # 1. Choose the sequence length
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)  # type: ignore[name-defined]
    except Exception:
        n = 5000

    # ------------------------------------------------------------------
    # 2. Global search
    # ------------------------------------------------------------------
    best_seq: list[float] | None = None
    best_score = float("inf")

    # ---- 2a. pure power‑law grid (delta=1, lam=0) --------------------
    # The analytic proxy orders the exponents so we try promising ones first.
    p_grid = np.linspace(0.45, 0.75, 121)  # 121 points ≈ 0.003 step
    p_grid = sorted(p_grid, key=_approx_score)  # lower proxy first

    for p in p_grid:
        if time.time() >= deadline:
            break
        seq = _generate_sequence(p, delta=1.0, lam=0.0, n=n)
        score = _evaluate(seq)
        if score < best_score:
            best_score = score
            best_seq = seq
            print(f"[grid] p={p:.5f}  score={score:.6f}")

    # ---- 2b. random sampling of (p, delta, lam) --------------------
    # Allocate roughly half of the remaining time to this stage.
    stage2_deadline = start_time + budget_s * 0.55
    while time.time() < stage2_deadline:
        # Sample parameters from ranges that cover the interesting region.
        p = np.random.uniform(0.48, 0.70)          # power‑law exponent
        delta = np.random.uniform(1.0, 6.0)       # shift – makes the start flatter
        lam = np.random.uniform(0.0, 2.5e-3)      # exponential cut‑off
        seq = _generate_sequence(p, delta, lam, n)
        score = _evaluate(seq)
        if score < best_score:
            best_score = score
            best_seq = seq
            print(
                f"[rand] p={p:.5f} delta={delta:.3f} lam={lam:.6f}  score={score:.6f}"
            )

    # Sanity – we must have a candidate at this point.
    if best_seq is None:
        # fallback to a plain power law (should never happen)
        best_seq = _generate_sequence(0.6, delta=1.0, lam=0.0, n=n)
        best_score = _evaluate(best_seq)

    # ------------------------------------------------------------------
    # 3. Local stochastic refinement (hill climbing)
    # ------------------------------------------------------------------
    current_seq = best_seq.copy()
    current_score = best_score

    # Hill‑climb parameters
    max_iters = 200_000                      # upper bound, stopped by time
    step_factor = 0.12                       # initial relative change magnitude
    min_step = 0.001                         # lower bound for step_factor
    decay_rate = 0.9999                      # gradual decrease of the step size

    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1

        # Choose move type – 70 % perturbation, 30 % transfer
        if np.random.rand() < 0.7:
            # ---- multiplicative perturbation of a single entry ----
            idx = np.random.randint(n)
            old_val = current_seq[idx]
            # relative factor in [1-step, 1+step]
            factor = 1.0 + step_factor * (np.random.rand() - 0.5) * 2.0
            new_val = max(0.0, old_val * factor)
            if new_val == old_val:
                continue
            current_seq[idx] = new_val
            new_score = _evaluate(current_seq)

            if new_score < current_score:
                # accept
                current_score = new_score
                if new_score < best_score:
                    best_score = new_score
                    best_seq = current_seq.copy()
                    print(f"[impr] iter={it:06d}  score={best_score:.6f}")
            else:
                # reject – revert
                current_seq[idx] = old_val
        else:
            # ---- transfer a small amount of mass between two indices ----
            i = np.random.randint(n)
            j = np.random.randint(n)
            if i == j:
                continue
            # amount to move: fraction of source value
            transfer = step_factor * current_seq[i]
            if transfer <= 0.0:
                continue
            # apply transfer
            current_seq[i] -= transfer
            current_seq[j] += transfer
            new_score = _evaluate(current_seq)

            if new_score < current_score:
                # accept
                current_score = new_score
                if new_score < best_score:
                    best_score = new_score
                    best_seq = current_seq.copy()
                    print(f"[impr] iter={it:06d}  score={best_score:.6f}")
            else:
                # reject – revert both entries
                current_seq[i] += transfer
                current_seq[j] -= transfer

        # decrease step size slowly
        step_factor = max(min_step, step_factor * decay_rate)

    # ------------------------------------------------------------------
    # 4. Report and return
    # ------------------------------------------------------------------
    print(f"Finished – best score = {best_score:.6f} after {it} iterations")
    return best_seq
```
