The score  
\[
E(f)=\frac{2\,n\;\max (f*f)}{(\sum_i f_i)^2}
\]
is invariant under scaling of the whole sequence, therefore we may impose the
normalisation  \(\sum_i f_i=1\) and minimise the maximal convolution coefficient.
For a power‑law
\[
f_i=(i+1)^{-p}\qquad 0<p<1
\]
the asymptotic value of the score is  

\[
E(p)=2\,(1-p)^2\,
\frac{\Gamma(1-p)^2}{\Gamma(2-2p)},
\]

with a minimum around \(p\approx0.58\) giving \(E\approx1.35\).
Finite truncation makes the value a little larger; the truncation error
decreases when the length \(n\) grows.

The program therefore searches **only two parameters** – the length `n`
and the exponent `p`.  
* a coarse grid of `p`‑values is evaluated for a modest length (`n≈5·10⁴`);
* the best exponent is then refined on a much larger length (`n≈2·10⁵`);
* an adaptive refinement loop repeatedly narrows the interval around the
  current best exponent while the time budget permits.

All work is done with NumPy (vectorised power and `np.convolve` inside
`evaluate_sequence`).  The total number of expensive evaluations stays well
below a few hundred, comfortably fitting into the 1000 s limit.

The algorithm is deterministic (controlled by the supplied `seed`) and
returns the best sequence found.



```python
#!/usr/bin/env python
"""
Propose a step‑function (list of non‑negative heights) with a low evaluation
score.

The algorithm searches over two parameters of a simple power‑law family
    a_i = (i+1)^(-p)

* coarse grid on p for a medium length (≈5·10⁴) – cheap, gives a good
  neighbourhood of the optimum;
* finer grid on p for a large length (≈2·10⁵) – moves the score close to the
  asymptotic optimum (~1.35);
* optional adaptive refinement while time permits.

Only NumPy is used; the heavy work (convolution) is performed by the
already‑provided evaluate_sequence function.
"""

import time
import numpy as np
from math import gamma

# ----------------------------------------------------------------------
# helper functions (top level, no closures)
# ----------------------------------------------------------------------


def _approx_score(p: float) -> float:
    """
    Analytic approximation of the infinite‑length score for a power law.
    Used only for ordering the grid of exponents.
    """
    u = 1.0 - p          # u = 1-p  , 0 < u < 1
    return 2.0 * (u ** 2) * (gamma(u) ** 2) / gamma(2.0 * u)


def _make_power_sequence(n: int, p: float) -> list[float]:
    """
    Return the list [(i+1)^(-p) for i in range(n)] as plain Python floats.
    NumPy is used for speed and the result is converted with .tolist().
    """
    # i+1 runs from 1 to n inclusive
    idx = np.arange(1, n + 1, dtype=np.float64)
    seq = idx ** (-p)
    return seq.tolist()


# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function with a low evaluation score.

    Parameters
    ----------
    seed : int
        Random seed (not heavily used – kept for compatibility).
    budget_s : int
        Time budget in seconds.  The function returns before the deadline.
    **kwargs
        Ignored – part of the required signature.

    Returns
    -------
    list[float]
        The best sequence discovered within the time budget.
    """
    # ------------------------------------------------------------------
    # 0. initialisation
    # ------------------------------------------------------------------
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin so that we never exceed the budget
    deadline = start_time + budget_s - 0.5

    best_seq = None          # type: list[float] | None
    best_score = float("inf")
    best_p = None
    best_n = None

    # helper to evaluate a candidate and keep the global best
    def _evaluate_and_update(seq, n, p):
        nonlocal best_seq, best_score, best_p, best_n
        # evaluate_sequence is assumed to be imported already
        score = evaluate_sequence(seq)
        if score < best_score:
            best_score = score
            best_seq = seq
            best_p = p
            best_n = n
            print(
                f"[{time.time() - start_time:5.1f}s] "
                f"New best – n={n:,} p={p:.6f} score={score:.6f}"
            )
        return score

    # ------------------------------------------------------------------
    # 1. optional baseline – use the previous construction if available
    # ------------------------------------------------------------------
    try:
        # height_sequence_1 may be defined in the surrounding environment
        baseline_seq = height_sequence_1  # type: ignore[name-defined]
        _evaluate_and_update(baseline_seq, len(baseline_seq), None)
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 2. Coarse grid search (moderate length)
    # ------------------------------------------------------------------
    n_coarse = 50000
    # Dense grid around the expected optimum (0.5‑0.7)
    p_grid_coarse = np.concatenate(
        (
            np.linspace(0.45, 0.55, 30, endpoint=False),
            np.linspace(0.55, 0.65, 40, endpoint=False),
            np.linspace(0.65, 0.75, 20),
        )
    )
    # evaluate cheap analytic score first – helps to find good exponents early
    p_grid_coarse = sorted(p_grid_coarse, key=_approx_score)

    for p in p_grid_coarse:
        if time.time() >= deadline:
            break
        seq = _make_power_sequence(n_coarse, p)
        _evaluate_and_update(seq, n_coarse, p)

    # ------------------------------------------------------------------
    # 3. Fine search on a larger length – zoom around the best p found
    # ------------------------------------------------------------------
    n_fine = 200_000

    # fallback if the coarse stage never produced a candidate
    if best_p is None:
        best_p = 0.58

    # start with a ±0.03 window, then iteratively shrink while time permits
    p_center = best_p
    window = 0.03
    min_step = 1e-5

    while time.time() < deadline:
        p_low = max(0.01, p_center - window)
        p_high = min(0.99, p_center + window)
        # aim for about 50 points in the current window
        step = max(min_step, (p_high - p_low) / 50.0)
        p_grid = np.arange(p_low, p_high + step, step)

        # order by analytic approximation (cheapest first)
        p_grid = sorted(p_grid, key=_approx_score)

        any_improvement = False
        for p in p_grid:
            if time.time() >= deadline:
                break
            seq = _make_power_sequence(n_fine, p)
            score = _evaluate_and_update(seq, n_fine, p)
            if score < best_score:
                any_improvement = True

        # shrink the window around the current best exponent
        if best_p is not None:
            p_center = best_p
        window = window / 2.0
        # stop once the window becomes tiny or we have no time left
        if window < 5e-5:
            break

    # ------------------------------------------------------------------
    # 4. (optional) tiny random local perturbations – cheap because n is large
    #    but we limit the number of iterations aggressively.
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline:
        # perform at most 200 random single‑entry tweaks
        max_local_iters = 200
        cur_seq = best_seq.copy()
        cur_score = best_score
        n = len(cur_seq)

        for it in range(max_local_iters):
            if time.time() >= deadline:
                break
            idx = np.random.randint(n)
            # random factor in [0.9, 1.1]
            factor = 1.0 + 0.1 * (np.random.rand() - 0.5)
            old_val = cur_seq[idx]
            new_val = max(0.0, old_val * factor)
            cur_seq[idx] = new_val

            new_score = evaluate_sequence(cur_seq)
            if new_score < cur_score:
                cur_score = new_score
                if new_score < best_score:
                    best_score = new_score
                    best_seq = cur_seq.copy()
                    best_p = None      # shape no longer a pure power‑law
                    print(
                        f"[{time.time() - start_time:5.1f}s] "
                        f"Local tweak improved score to {new_score:.6f}"
                    )
            else:
                # revert
                cur_seq[idx] = old_val

    # ------------------------------------------------------------------
    # 5. final report
    # ------------------------------------------------------------------
    if best_seq is None:
        # sanity fallback – a simple power law with a reasonable length
        fallback_n = 5000
        fallback_p = 0.6
        best_seq = _make_power_sequence(fallback_n, fallback_p)
        best_score = evaluate_sequence(best_seq)
        print(
            f"Fallback constructed – n={fallback_n} p={fallback_p} "
            f"score={best_score:.6f}"
        )
    else:
        print(
            f"Finished search – best score {best_score:.6f} "
            f"found with n={best_n:,} p={best_p}"
        )

    return best_seq
```
