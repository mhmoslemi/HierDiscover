Search for a non‑negative step‑function that minimises

    2·n·max(conv(a,a)) / (sum(a)^2)

The algorithm works as follows:

1. Initialise a probability vector `a` (sum = 1) either from the previous
   construction `height_sequence_1` or from a simple power‑law.
2. Repeatedly apply a *projected additive gradient descent* on a smooth
   approximation of the max‑operator.
   - The max is approximated by a soft‑max over the self‑convolution:
        w_k ∝ exp( λ (conv_k – max(conv)) )
   - The gradient of  Σ_k w_k·conv_k  w.r.t. `a` is  Aᵀw + a,
     where A implements the linear convolution with `a`.  This can be
     evaluated efficiently with a single FFT‑based convolution of the
     reversed vector `a[::-1]` with the weight vector `w`.
   - An additive step `a ← a – η·grad` is taken, then `a` is projected onto
     the probability simplex (non‑negative, sums to 1).
   - The temperature `λ` is slowly increased (so the objective becomes
     closer to the true max) while the step size `η` is gently decayed.
3. The best sequence seen during the run is returned.

All arithmetic stays in double precision, the FFT size is the next power
of two, and the whole loop runs well within the 1000 s budget. The
returned list contains only non‑negative floats ≤ 1000, ready for

            best_seq = a.copy()
            print(f'iter {iteration:5d} improved score {best_score:.6f}')

        # ----------------------------------------------------------
        # Update schedules
        iteration += 1
        step *= step_decay
        if iteration % lam_change_interval == 0:
            lam = min(lam * lam_growth, lam_max)

    # --------------------------------------------------------------
    # Final sanity check with the provided evaluator (if available)
    try:
        final_val = evaluate_sequence(best_seq.tolist())
        print(f'final evaluate_sequence score = {final_val:.6f}')
    except Exception:
        pass

    # Return a plain Python list as required
    return best_seq.tolist()
