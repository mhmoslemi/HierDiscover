assistantfinal**Solution Overview**

The score returned by `evaluate_sequence` is  

\[
\text{score}= \frac{2\,n\;\max\limits_{k}(a*a)[k]}{(\sum_i a_i)^2}.
\]

If we keep the **ℓ₁‑norm fixed to**  

\[
\sum_i a_i=\sqrt{2n},
\]

the denominator equals `2 n` and the score reduces to the infinity‑norm of the linear
convolution `a*a`.  
Hence the optimisation problem is:

*Given a non‑negative vector `a` with a fixed sum, minimise*  

\[
\max_k (a*a)[k].
\]

The algorithm below consists of three stages

1. **Random sparse sampling** – generate a few “spike” vectors (a few non‑zero
   entries) and keep the best one.  Sparse vectors tend to have a small
   maximum convolution because most shifts contain few overlapping terms.

2. **Projected sub‑gradient descent** –  
   * maximise the active convolution entry (the current maximum), compute its
   sub‑gradient (which is just a reversed copy of `a` on the active window) and
   take a step opposite to that gradient.  
   After every step the vector is projected back onto the simplex
   `{a_i ≥ 0, Σ a_i = √(2 n)}`.  A simple back‑tracking line‑search is used to
   guarantee progress.  The step size is adapted automatically and the method
   is restarted from a fresh random point if it stalls.

3. **Short hill‑climbing / simulated‑annealing finish** – while time permits we
   repeatedly move a tiny amount of mass from one index to another; the move is
   kept if it improves the objective.

All linear‑algebra is performed with NumPy; the convolution is computed by an
FFT‑based routine (`_max_convolution`) which is *O(n log n)* and therefore fast
enough for thousands of iterations inside the 1000 s budget.

The code respects the required signature `propose_candidate()` and contains no
closures, file I/O or external libraries.

```python
"""
Propose a step‑function (non‑negative list of heights) with a low
max‑convolution score.

Algorithm
---------

1. **Initial sampling** – generate a handful of sparse vectors
   (few non‑zero entries) and keep the best one.
   Sparse vectors tend to have a small maximum value of the
   linear convolution because most shifts contain few overlapping terms.

2. **Projected sub‑gradient descent** – keep the ℓ₁‑norm fixed to
   sqrt(2·n) (the normalising value).  At every iteration the active
   shift `k* = argmax (a*a)[k]` is identified; its sub‑gradient is simply
   a reversed copy of `a` on the window where the shift overlaps.
   A step opposite to that gradient is taken, then the vector is
   projected back onto the simplex {a ≥ 0, Σa = √(2·n)}.
   A tiny back‑tracking line‑search guarantees improvement; the step size
   is increased after a successful step and decreased otherwise.
   If no improvement is observed for many iterations the algorithm restarts
   from a fresh random Dirichlet vector.

3. **Final local refinement** – a short hill‑climbing / simulated‑annealing
   phase moves a small fraction of mass from one index to another while
   preserving the sum.  Improvements are kept immediately.

The routine runs for at most ``budget_s`` seconds (default 1000) and finally
returns the best sequence found as a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _project_to_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Project a vector onto the simplex {x ≥ 0, Σx = target_sum}
    using the O(n) algorithm of Wang & Carreira‑Perpiñán (2013).
    """
    n = v.shape[0]
    if target_sum <= 0:
        return np.zeros_like(v)

    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    rho_arr = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho_arr.size == 0:
        theta = 0.0
    else:
        rho = rho_arr[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _max_convolution(seq: np.ndarray):
    """
    Return the maximum value of the linear convolution seq * seq
    together with the full convolution array.
    Uses an FFT (O(n log n)) implementation.
    """
    n = seq.shape[0]
    # length of the linear convolution
    conv_len = 2 * n - 1
    # next power of two for efficient FFT
    fft_len = 1 << ((conv_len - 1).bit_length())
    # forward FFT of zero‑padded sequence
    f = np.fft.rfft(seq, n=fft_len)
    # convolution in frequency domain (real → real)
    conv_full = np.fft.irfft(f * f, n=fft_len)[:conv_len]
    return float(conv_full.max()), conv_full


def _subgradient(seq: np.ndarray, k_active: int) -> np.ndarray:
    """
    Sub‑gradient of max_k (a*a)[k] at the active shift `k_active`.
    For a fixed k the gradient w.r.t. a_i is 2·a_{k−i} (if the index is valid,
    otherwise 0).  The function returns the summed gradient for the (single)
    active shift.
    """
    n = seq.shape[0]
    g = np.zeros(n, dtype=float)

    i_start = max(0, k_active - (n - 1))
    i_end = min(n - 1, k_active)
    if i_start > i_end:
        return g
    idx_i = np.arange(i_start, i_end + 1)
    idx_j = k_active - idx_i
    g[idx_i] = 2.0 * seq[idx_j]
    return g


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:
    """
    Search for a non‑negative height sequence that minimises the evaluation
    function.  The search respects a wall‑clock budget of ``budget_s`` seconds.
    The returned list is ready to be passed to the provided ``evaluate_sequence``.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.2   # tiny safety margin

    # ------------------------------------------------------------------
    # Problem size (use the previously found sequence length if available)
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        n = len(height_sequence_1)
        init_seq = np.array(height_sequence_1, dtype=float)
    else:
        n = 5000
        init_seq = None

    target_sum = math.sqrt(2.0 * n)          # the normalising ℓ₁‑norm

    # ------------------------------------------------------------------
    # Helper: create a feasible vector (non‑negative, correct sum)
    # ------------------------------------------------------------------
    def _make_feasible(raw: np.ndarray) -> np.ndarray:
        raw = np.maximum(raw, 0.0)
        total = raw.sum()
        if total == 0.0:
            return np.full(n, target_sum / n)
        return raw * (target_sum / total)

    # ------------------------------------------------------------------
    # 1) Random sparse sampling – keep the best sparse candidate
    # ------------------------------------------------------------------
    best_seq = None
    best_score = float("inf")
    # keep the initial vector if we have one
    if init_seq is not None:
        cur = _make_feasible(init_seq)
        cur_score, cur_conv = _max_convolution(cur)
        best_seq = cur.copy()
        best_score = cur_score
        print(f"[seed] start from provided sequence, score={best_score:.6f}")

    # generate a few sparse candidates
    for _ in range(300):
        # number of non‑zero spikes, roughly √(2n) (order of magnitude that works)
        m = max(1, int(np.random.uniform(0.5, 1.5) * math.sqrt(2 * n)))
        idx = np.random.choice(n, size=m, replace=False)
        raw = np.zeros(n, dtype=float)
        raw[idx] = 1.0
        cand = _make_feasible(raw)
        cand_score, _ = _max_convolution(cand)
        if cand_score < best_score:
            best_score = cand_score
            best_seq = cand.copy()
            print(f"[sparse] new best {best_score:.6f} with {m} spikes")

    # If we failed to generate anything (should not happen), fall back to uniform
    if best_seq is None:
        best_seq = np.full(n, target_sum / n, dtype=float)
        best_score, _ = _max_convolution(best_seq)

    cur = best_seq.copy()
    cur_score, cur_conv = _max_convolution(cur)

    # ------------------------------------------------------------------
    # 2) Projected sub‑gradient descent on max‑convolution
    # ------------------------------------------------------------------
    step_scale = target_sum * 0.02               # initial step magnitude
    min_step = target_sum * 1e-6
    stagnation = 0                               # counts iterations without improvement
    iteration = 0

    while time.time() < deadline:
        iteration += 1
        # active shift (index where the convolution attains its maximum)
        k_star = int(np.argmax(cur_conv))

        # compute sub‑gradient at the active shift
        g = _subgradient(cur, k_star)
        norm = np.linalg.norm(g)
        if norm == 0:
            break
        direction = g / norm                     # unit descent direction

        # --- back‑tracking line‑search (max 5 tries) -----------------
        step = step_scale
        improved = False
        for _ in range(5):
            new_seq = cur - step * direction
            new_seq = _project_to_simplex(new_seq, target_sum)
            new_score, new_conv = _max_convolution(new_seq)

            if new_score < cur_score:
                # successful step
                cur = new_seq
                cur_score = new_score
                cur_conv = new_conv
                improved = True
                # modestly increase the step size for the next iteration
                step_scale = max(step, step_scale * 1.05)
                break
            else:
                step *= 0.5                       # shrink and retry

        if not improved:
            # no progress – shrink the global step scale
            step_scale = max(step_scale * 0.7, min_step)
            stagnation += 1
        else:
            stagnation = 0

        # keep the globally best sequence
        if cur_score < best_score:
            best_score = cur_score
            best_seq = cur.copy()
            print(f"[sgd {iteration:06d}] new best {best_score:.6f}")

        # if we have been stuck for a long time, restart from a fresh random point
        if stagnation >= 300:
            cur = _make_feasible(
                np.random.gamma(shape=0.7, scale=1.0, size=n)
            )
            cur_score, cur_conv = _max_convolution(cur)
            stagnation = 0
            print(f"[restart {iteration}] fresh start, score={cur_score:.6f}")

    # ------------------------------------------------------------------
    # 3) Short hill‑climbing / simulated‑annealing phase (uses the fast FFT)
    # ------------------------------------------------------------------
    temperature = 0.03
    decay = 0.9997
    while time.time() < deadline:
        i, j = np.random.randint(0, n, size=2)
        if i == j or cur[i] <= 0.0:
            continue
        delta = cur[i] * np.random.uniform(0.0, 0.03)
        new_seq = cur.copy()
        new_seq[i] -= delta
        new_seq[j] += delta
        new_seq = _project_to_simplex(new_seq, target_sum)

        new_score, _ = _max_convolution(new_seq)

        if new_score < best_score:
            best_score = new_score
            best_seq = new_seq.copy()
            cur = new_seq
            cur_score = new_score
            print(f"[refine] improved to {best_score:.6f}")

        else:
            # occasional uphill move (simulated annealing)
            prob = math.exp(-(new_score - cur_score) / (temperature + 1e-12))
            if np.random.rand() < prob:
                cur = new_seq
                cur_score = new_score

        temperature *= decay

    print(f"[final] best score {best_score:.6f} after {iteration} SGD steps")
    # Convert to plain list for the external evaluator
    return best_seq.tolist()
