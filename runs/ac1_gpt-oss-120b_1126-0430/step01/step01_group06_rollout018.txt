\text{score}(a)=\frac{2\,n\,\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale invariant* – multiplying the whole vector by a constant does not
change the score.  Consequently we may restrict ourselves to vectors that
lie on the probability simplex  

\[
\Delta_n=\Bigl\{a\in\mathbb R_{\ge0}^n\;\Big|\;\sum_i a_i=1\Bigr\}.
\]

For a vector \(a\in\Delta_n\) the score simplifies to  

\[
\text{score}(a)=2\,n\;M(a),\qquad 
M(a)=\max_k (a*a)_k .
\]

The problem is therefore *minimise the maximal convolution value* under a
simplex constraint.

The algorithm consists of three stages

1. **Parametric initialisation** – we generate a large collection of
   candidates from the flexible family  

   \[
   a_i\;\propto\;(i+\text{shift})^{-\alpha}\,\exp(-\beta i) ,
   \qquad i=0,\dots,n-1,
   \]

   (power‑law, optional exponential tail).  The three parameters are
   explored by a coarse grid and by random sampling.  The best vector
   found becomes the starting point for the next phase.

2. **Projected sub‑gradient descent** – for a current vector \(a\) we locate
   the convolution index \(k^\star\) that attains the maximum.  The
   sub‑gradient of \(M(a)\) at this point is  

   \[
   g_i = 
   \begin{cases}
        2\,a_{k^\star-i} &\text{if }0\le k^\star-i<n,\\[2mm]
        0                &\text{otherwise.}
   \end{cases}
   \]

   We move a small step opposite to the gradient and re‑project onto the
   simplex (simple clipping + renormalisation – fast and sufficient).  The
   step size follows a decreasing schedule \(\eta_t = \eta_0/\sqrt{t+1}\).
   After every iteration we recompute the convolution, update the current
   best solution if the score improved and continue until the time budget
   is exhausted.

3. **Fine‑grained random perturbations** – after the sub‑gradient phase we
   apply a short hill‑climbing procedure (move a small amount of mass
   between two coordinates) exactly as in the reference code.  This often
   extracts a few extra units of improvement.

All heavy work is done with NumPy; a single convolution of a 2244‑long
vector takes only a few hundred micro‑seconds, so millions of iterations
fit comfortably into the 1000 s limit.

```python
"""
propose_candidate

Search for a non‑negative step‑function (list of heights) that minimises

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The method consists of

1. a fast parametric sampling (power‑law × optional exponential tail);
2. a projected sub‑gradient descent that directly reduces the maximal
   convolution entry;
3. a short random hill‑climbing refinement.

The whole routine stops before the supplied time budget and returns the
best sequence found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Simple projection onto the probability simplex (fast clipping + renorm)
# ----------------------------------------------------------------------
def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project a (possibly negative) vector onto the simplex {x >= 0, sum(x)=1}."""
    w = np.maximum(v, 0.0)
    s = w.sum()
    if s <= 0.0:
        # all entries non‑positive – fall back to the uniform distribution
        return np.full_like(v, 1.0 / len(v))
    return w / s


# ----------------------------------------------------------------------
# Helper: evaluate a raw vector (not yet normalised) using the provided
# evaluate_sequence function.
# ----------------------------------------------------------------------
def _eval_raw(vec: np.ndarray) -> float:
    """Normalise vec to sum=1 and evaluate it with the external evaluate_sequence."""
    total = vec.sum()
    if total <= 0.0:
        return float('inf')
    norm = vec / total
    # evaluate_sequence expects a plain Python list
    return evaluate_sequence(norm.tolist())


# ----------------------------------------------------------------------
# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 123, budget_s: float = 950.0, **kwargs) -> list:
    """
    Generate a step‑function that (hopefully) improves the current best bound.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.  The function stops a few seconds before the limit.
    **kwargs
        Ignored – present for API compatibility.

    Returns
    -------
    list[float]
        The best height sequence found within the allocated time.
    """
    np.random.seed(seed)
    start_time = time.time()
    time_margin = 5.0                     # keep a small safety margin

    # --------------------------------------------------------------
    # Determine the length of the sequence we will work with.
    # --------------------------------------------------------------
    try:
        n = len(height_sequence_1)        # provided by the competition environment
    except Exception:
        n = 2244                          # historic default
    idx = np.arange(n, dtype=float)

    # --------------------------------------------------------------
    # Start from the fallback construction (always available)
    # --------------------------------------------------------------
    try:
        best_seq = list(height_sequence_1)
        best_score = evaluate_sequence(best_seq)
    except Exception:
        best_seq = [1.0 / n] * n
        best_score = evaluate_sequence(best_seq)

    print(f"[init] length={n}, baseline score={best_score:.6f}")

    # --------------------------------------------------------------
    # 1) PARAMETRIC SEARCH (coarse grid + random sampling)
    # --------------------------------------------------------------
    # Parameter ranges – chosen wide enough to include the previously best
    # region (α≈0.5‑0.7, shift≈1‑3).  β adds an exponential tail.
    alphas = np.linspace(0.40, 0.80, 41)          # step 0.01
    shifts = np.linspace(0.5, 5.0, 10)            # step ≈0.5
    betas = np.array([0.0, 0.001, 0.003, 0.006]) # a few discrete exponential rates

    # -- Grid search ------------------------------------------------
    for alpha in alphas:
        if time.time() - start_time > budget_s - time_margin:
            break
        for shift in shifts:
            for beta in betas:
                raw = (idx + shift) ** (-alpha) * np.exp(-beta * idx)
                score = _eval_raw(raw)
                if score < best_score:
                    best_score = score
                    best_seq = (raw / raw.sum()).tolist()
                    print(f"[grid] α={alpha:.3f} sh={shift:.2f} β={beta:.4f} → {score:.6f}")

    # -- Random sampling --------------------------------------------
    max_random = 3000
    while (time.time() - start_time < budget_s - time_margin) and max_random > 0:
        max_random -= 1
        alpha = np.random.uniform(0.42, 0.78)
        shift = np.random.uniform(0.5, 6.0)
        beta = np.random.uniform(0.0, 0.008)
        raw = (idx + shift) ** (-alpha) * np.exp(-beta * idx)
        score = _eval_raw(raw)
        if score < best_score:
            best_score = score
            best_seq = (raw / raw.sum()).tolist()
            print(f"[rand] α={alpha:.4f} sh={shift:.2f} β={beta:.4f} → {score:.6f}")

    print(f"[search] best after parametric phase: score={best_score:.6f}")

    # --------------------------------------------------------------
    # 2) PROJECTED SUB‑GRADIENT DESCENT
    # --------------------------------------------------------------
    cur = np.array(best_seq, dtype=float)   # current iterate (sum≈1)
    # Ensure we are exactly on the simplex
    cur = _simplex_projection(cur)

    # Sub‑gradient parameters
    eta0 = 0.8                               # initial step size
    max_iter = 200000                        # hard limit (time will stop earlier)

    it = 0
    while time.time() - start_time < budget_s - time_margin and it < max_iter:
        it += 1

        # convolution and maximal entry
        conv = np.convolve(cur, cur)
        M = conv.max()
        # exact score (sum(cur) should be 1, but we keep the denominator)
        cur_score = 2.0 * n * M / (cur.sum() ** 2)

        # keep the best ever seen
        if cur_score < best_score:
            best_score = cur_score
            best_seq = cur.tolist()
            print(f"[subgrad] iter={it:,}  score={cur_score:.6f}")

        # index attaining the maximum (first occurrence)
        k_star = int(conv.argmax())

        # sub‑gradient of the maximal convolution entry
        # g_i = 2 * a_{k* - i}  if the index lies inside the array
        indices = k_star - np.arange(n)
        mask = (indices >= 0) & (indices < n)
        g = np.zeros_like(cur)
        g[mask] = 2.0 * cur[indices[mask]]

        # decreasing step size
        eta = eta0 / np.sqrt(it + 1.0)

        # gradient step + projection onto the simplex
        nxt = cur - eta * g
        cur = _simplex_projection(nxt)

    print(f"[subgrad] finished after {it:,} iterations, best score={best_score:.6f}")

    # --------------------------------------------------------------
    # 3) SHORT HILL‑CLIMB REFINEMENT (as in the reference code)
    # --------------------------------------------------------------
    cur = np.array(best_seq, dtype=float)    # start refinement from best found
    cur = _simplex_projection(cur)
    cur_score = best_score
    max_iter_refine = 30000
    it_ref = 0
    while time.time() - start_time < budget_s - time_margin and it_ref < max_iter_refine:
        it_ref += 1
        i, j = np.random.randint(n, size=2)
        if i == j:
            continue
        # move a small fraction of mass from i to j
        step = cur[i] * (np.random.rand() * 0.02)   # up to 2 % of cur[i]
        if step <= 0.0 or cur[j] - step < 0.0:
            continue
        new = cur.copy()
        new[i] -= step
        new[j] += step
        new = _simplex_projection(new)
        new_score = 2.0 * n * np.max(np.convolve(new, new)) / (new.sum() ** 2)
        if new_score < cur_score:
            cur = new
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_seq = new.tolist()
                print(f"[refine] iter={it_ref:,}  improved score={new_score:.6f}")

    print(f"[final] best score achieved: {best_score:.6f}")
    # Return the best sequence as a plain Python list
    return best_seq
```
