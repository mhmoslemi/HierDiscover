Propose a high‑quality step‑function sequence.

Algorithm
---------
1. Choose a moderate length (n≈4000) – large enough to approximate the
   continuous optimum but still cheap to convolve with FFT.
2. Initialise the distribution:
   * If a previous construction `height_sequence_1` exists, use it
     (interpolated to the chosen length).
   * Otherwise start from a simple power‑law a_i ∝ (i+1)⁻ᵝ (β=0.6).
3. Fast exploration of three parametric families (≈ 300 candidates):
   – Power‑law                p_i ∝ (i+1)⁻ᵝ
   – Symmetric Beta‑like      p_i ∝ x^{α‑1}(1‑x)^{α‑1}
   – Edge‑heavy (U‑shaped)    p_i ∝ ((i+1)(n‑i))⁻ᵝ
   For each candidate the maximal self‑convolution is obtained with
   an FFT‑based linear convolution; the score 2·n·max(conv) is kept.
   The best candidate becomes the starting point for the next phase.
4. Sub‑gradient descent on the active convolution index:
   * Find k_max where (p∗p)_k is maximal.
   * The gradient of this active term is g_i = 2·p_{k_max‑i}
     (zero when the index is out of range).
   * Take a safe step α·g that does not make any entry negative,
     renormalise the vector to sum = 1 and repeat.
   * Occasionally perform a small random mass‑transfer move to
     escape plateaus.
   * Stop when no improvement has been seen for many iterations
     or the time budget expires.
5. A short random hill‑climb (mass transfers) for the remaining
   seconds.  Whenever a candidate improves the fast score we verify
   it with the exact `evaluate_sequence` call.
6. Return the best found sequence (scaled by 100 – scaling does not
   affect the score because the evaluation function is scale‑invariant).

The whole routine respects the 1000 s budget, prints intermediate
progress and finally returns a list of non‑negative heights.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top‑level – no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two >= x."""
    return 1 << (x - 1).bit_length()


def max_conv_fft(p: np.ndarray) -> tuple[float, int]:
    """
    Compute the maximum value of the linear self‑convolution of p
    using an FFT (size is the next power of two for speed).

    Returns
    -------
    max_val : float
        The maximal convolution coefficient.
    kmax : int
        Index at which the maximum occurs (0 … 2·n‑2).
    """
    n = p.shape[0]
    m = _next_pow2(2 * n - 1)
    # real FFT, multiplication corresponds to linear convolution
    P = np.fft.rfft(p, m)
    conv = np.fft.irfft(P * P, m)[: 2 * n - 1]
    # eliminate tiny negatives due to rounding
    conv = np.maximum(conv, 0.0)
    kmax = int(conv.argmax())
    return float(conv.max()), kmax


def compute_score(p: np.ndarray) -> float:
    """
    Fast surrogate for ``evaluate_sequence``.
    The evaluation function is scale‑invariant, therefore we can work with
    a normalised probability vector (sum(p)=1).
    """
    n = p.shape[0]
    max_val, _ = max_conv_fft(p)
    return 2.0 * n * max_val


def project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Project a non‑negative vector onto the probability simplex (sum=1).
    Simple renormalisation after clipping works because all entries are
    already non‑negative.
    """
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s == 0.0:
        return np.full_like(v, 1.0 / v.size)
    return v / s


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------

    """
    Search for a step‑function sequence that minimises
    ``evaluate_sequence``.  Returns the sequence as a list of floats.
    """

    start = time.time()
    deadline = start + budget_s - 0.1          # tiny safety margin

    # ------------------------------------------------------------------
    # 1.   Choose length and initialise a probability vector
    # ------------------------------------------------------------------
    n = 4000                                   # good compromise between quality & speed
    best_seq = None
    best_score = float("inf")

    # try to use a previously found construction if it exists
    if "height_sequence_1" in globals():
        try:
            old = np.asarray(height_sequence_1, dtype=np.float64)
            if old.size == n:
                p = project_simplex(old)
                print("[init] Using existing height_sequence_1 (exact length).")
            else:
                # linear interpolation/resampling to the required length
                x_old = np.linspace(0.0, 1.0, old.size)
                x_new = np.linspace(0.0, 1.0, n)
                p = np.interp(x_new, x_old, old)
                p = project_simplex(p)
                print("[init] Resampled height_sequence_1 to length", n)

            p = None
