Now implement projection onto simplex:

def project_to_simplex(v, z= sqrt(2n)):
    """Project vector v onto the simplex {x >= 0, sum x = z}."""
    # based on algorithm from Duchi et al.
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]  # last True index (1-indexed)
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w

The evaluation function  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale‑invariant*: multiplying all coefficients by the same factor does not change the score.  
If we normalise the sequence so that  

\[
\sum_i a_i = \sqrt{2n},
\]

the score reduces to simply  

\[
\text{score}= \max_k (a*a)_k .
\]

Hence the task is to construct a non‑negative sequence whose **self‑convolution is as flat as possible**.  
A very convenient construction is a *blocked* sequence:

* choose a number of blocks `m` (>=2);
* each block has length `L`;
* blocks are separated by exactly `L` zero entries.

For a block of constant height `h`

```
... 0 0 0 | h h … h | 0 0 0 | h h … h | …
          ^L       ^L       ^L
```

*the self‑convolution of a single block* is a triangle of height `L·h²`.  
Because the blocks are spaced by `L` zeros, the triangles coming from different
blocks (and also the cross‑convolutions between distinct blocks) never overlap.
Consequently **every index of the full convolution attains the same maximum value**

\[
\max_k (a*a)_k = L\;h^{2}.
\]

If the total length of the sequence is `n`, the maximal admissible block length is  

\[
L = \Bigl\lfloor\frac{n}{2m}\Bigr\rfloor .
\]

The sum of the (un‑scaled) sequence equals `m·L`.  
To satisfy the normalisation `∑a_i = √(2n)` we multiply the whole vector by  

\[
\text{scale}= \frac{\sqrt{2n}}{m\,L}.
\]

The resulting score is

\[
\text{score}=L\;\text{scale}^{2}
           =\frac{2n}{m^{2}\,L}
           \approx \frac{4}{m}.
\]

Choosing `m = 4` already yields a score close to 1.0;  
with `m = 5` the score drops below 0.9, comfortably beating the target 1.503.

The algorithm below builds such a blocked sequence for the length of the
previous best construction (`height_sequence_1` if it is present,
