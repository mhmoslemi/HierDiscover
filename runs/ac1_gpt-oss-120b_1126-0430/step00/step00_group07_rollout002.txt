def simplex_projection(v, z=1.0):
    # v length n, ensure each >=0 after projection, sum = z
    # If sum(v) == z and all v >= 0 return v
    # else compute.
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, n+1)
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w
```

   non‑negative vector normalised to sum = 1 (or a truncation of the

   discrete Fourier transform to be constant while keeping the
   phase.  After each inverse transform the vector is clipped to
   non‑negative values and re‑normalised.  This step drives the
   autocorrelation towards a flat shape.

3. **Projected sub‑gradient descent** on the peak of the autocorrelation:
   - compute the convolution via FFT,

def simplex_projection(v: np.ndarray, z: float = 1.0) -> np.ndarray:
    """
    Euclidean projection of a vector onto the simplex {x : x >= 0, sum(x)=z}.
    """
    if np.all(v >= 0) and np.isclose(v.sum(), z):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0

        return np.zeros_like(v)

    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w
