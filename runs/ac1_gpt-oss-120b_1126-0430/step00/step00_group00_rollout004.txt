Mathematical argument
---------------------
For a non‑negative vector `a` of length `n`

    S = sum(a)                (ℓ¹‑norm)
    B0 = sum_i a_i² = (a*a)[0] (the first entry of the autocorrelation)

Using Cauchy‑Schwarz,
    B0 >= S² / n.

Since the convolution includes the entry `k = 0`,
    max_b = max_k (a*a)[k]  >=  B0  >= S² / n.

The evaluation metric is

    Q(a) = 2·n·max_b / S²   ≥ 2·n·(S²/n) / S² = 2.

Equality holds precisely when all entries are equal, i.e. when `a` is the
uniform step function.
