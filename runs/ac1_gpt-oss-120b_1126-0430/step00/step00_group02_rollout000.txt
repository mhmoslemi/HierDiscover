"""
Simple uniform baseline for the step‑function optimization problem.

The evaluation function is
    E(a) = 2 * n * max(conv(a,a)) / (sum(a))**2

For a non‑negative sequence `a` the maximum of the full convolution
occurs at the centre and equals `sum_i a_i**2`.  Hence

    E(a) = 2 * n * (∑ a_i²) / (∑ a_i)²

By the Cauchy–Schwarz inequality we have
    ∑ a_i² ≥ (∑ a_i)² / n

with equality if and only if all entries are equal.
Consequently the theoretical minimum of `E` is exactly **2**, attained by any
uniform (constant) sequence.

This implementation therefore returns a uniform sequence (all entries equal
to 1.0).  The length is chosen to be moderate (e.g. 1000) to keep the
runtime negligible while still satisfying all constraints.  No expensive
search is required, but the function is written in the same style as the
original framework so it can be swapped in without modification.
