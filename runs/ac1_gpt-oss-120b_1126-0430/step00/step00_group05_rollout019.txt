"""
Linear‑increasing construction.

The evaluation function is homogeneous:
    evaluate_sequence(c·a) == evaluate_sequence(a)  for any c>0.
Therefore we can freely scale the sequence to satisfy the
`np.clip(..., 0, 1000)` limits.

For a monotone increasing step function a_i = i (i = 1..n) the
convolution attains its maximum at the centre (k = n‑1) and
asymptotically

    max(a*a) ≈ n³ / 6 ,   Σ a_i ≈ n² / 2

which yields an evaluation value of 4/3 ≈ 1.333…, well below the
target 1.503.  By scaling the linear ramp so that its largest entry
equals 1000 we respect the element‑wise bound while preserving the
ratio.

The `propose_candidate` function builds this linear ramp of the same
length as the previously discovered construction (`height_sequence_1`
if available, otherwise a default of 5000), prints the achieved score
and returns the sequence.
"""

import time
import numpy as np

    Build a linear increasing sequence a_i = (i+1) * scale  (0 < a_i <= 1000).
    The length equals the current best construction if it exists.
    """
    start_time = time.time()

    # Use the length of the best known construction if it is defined.
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 5000                              # fallback length

    # Scale so that the last element equals the allowed maximum (1000).
    scale = 1000.0 / n
    seq = (np.arange(1, n + 1) * scale).tolist()   # values from ~scale to 1000

    # Evaluate and report the score (use the already imported evaluate_sequence).
    score = evaluate_sequence(seq)
    elapsed = time.time() - start_time

    return seq
