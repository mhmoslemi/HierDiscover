The objective  

\[
E(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale‑invariant*, therefore we may restrict ourselves to the simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

For a vector on the simplex the denominator is fixed to 1, hence

\[
E(a)=2\,n\;\max_k c_k,\qquad c = a*a .
\]

The problem is to make the autocorrelation `c` as flat as possible.
Directly minimising the `max` is difficult because the objective is non‑smooth.
We replace the `max` by the smooth **log‑sum‑exp** (a soft‑max)  

\[
f_\beta(a)=\log\!\Bigl(\sum_k e^{\beta\,c_k}\Bigr) .
\]

When the temperature `β` is small, `f_β` is close to the average of the
convolution entries; when `β` grows it concentrates on the
largest entries and approaches the true `max`.  
The gradient of `f_β` can be written in closed form using a second convolution
and can be evaluated completely with FFTs:

```
p_k = e^{β·c_k} / Σ_j e^{β·c_j}                     (soft‑max weights)
∂f_β/∂a_i = 2· Σ_k p_k·a_{k-i}
```

The last sum is exactly the *valid* part of the convolution of `p`
with the reversed vector `a_rev = a[::-1]`.

We perform **mirror (exponentiated) gradient descent** on the simplex:

```
a_i ← a_i · exp( - η · ∂f_β/∂a_i )
a   ← a / Σ a
```

The update automatically preserves non‑negativity and the simplex
constraint, needs only the gradient and a scalar step size `η`.
A simple schedule slowly increases the temperature `β` (from 0.5 up to 12)
and simultaneously decreases the step size (`η ∝ 1/√t`).
Occasional random perturbations avoid stagnation.

The whole optimisation runs inside the given time budget (default 1000 s).  
At the end we keep the best vector seen (according to the cheap score
`2·n·max(c)`) and evaluate it with the provided `evaluate_sequence`.  
Optionally we blend the best vector with the uniform distribution and pick
the best blend – a cheap way to fine‑tune the final shape.

The algorithm differs from the previous sub‑gradient / heavy‑ball approach:
* it uses **all** convolution entries (soft‑max) instead of a few “active”
  shifts,
* the update is multiplicative (exponentiated gradient) which respects the
  simplex without a projection step,
* a temperature schedule gives a smooth continuation from a global‑average
  descent to a true max‑minimisation,
* a tiny up‑sampling step allows the code to start with a modest length
  and, if time permits, finish on a larger length for a tighter bound.

The implementation is completely self‑contained, uses only `numpy` and
the supplied `evaluate_sequence`, and respects the 2‑CPU limit.

```python
#!/usr/bin/env python
"""
Mirror‑gradient optimisation of a non‑negative step function.

The algorithm minimises the evaluation function

    2·n·max_k (a*a)[k] / (Σ a_i)^2

by:
  * working on the probability simplex (Σa = 1, a ≥ 0);
  * smoothing the max with a temperature‑controlled log‑sum‑exp;
  * evaluating the gradient analytically via two FFT‑based convolutions;
  * performing an exponentiated‑gradient (mirror) update that stays on the
    simplex automatically;
  * slowly raising the temperature (β) and shrinking the step size;
  * occasional random perturbations and a final blend with the uniform
    distribution.

The routine respects a time budget (default 1000 s) and always returns a
feasible sequence.  The best sequence found is returned as a plain list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – top level (no closures)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Project a real vector onto the probability simplex {x ≥ 0, Σx = 1}.
    Implements the O(n) algorithm of Wang & Carreira‑Perpiñán (2013).
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:                     # all non‑positive → uniform
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _conv_full_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a*a (full length 2·len(a)‑1) using FFT.
    Returns a real‑valued array of length 2·n‑1.
    """
    fa = np.fft.fft(a, fft_len)
    conv = np.fft.ifft(fa * fa).real
    n = a.shape[0]
    return conv[: 2 * n - 1]


def _conv_max_fft(a: np.ndarray, fft_len: int) -> float:
    """
    Return the maximal entry of a*a (full convolution).
    """
    conv = _conv_full_fft(a, fft_len)
    return float(conv.max())


def _exponential_gradient_step(a: np.ndarray, grad: np.ndarray, eta: float) -> np.ndarray:
    """
    Mirror (exponentiated) gradient update on the simplex:
        a_i ← a_i * exp(-η·grad_i)
    followed by renormalisation.
    """
    # avoid under‑flow on very large η·grad
    mult = np.exp(-eta * grad)
    a_new = a * mult
    s = a_new.sum()
    if s == 0.0:               # numerical safeguard – fall back to uniform
        return np.full_like(a, 1.0 / a.shape[0])
    return a_new / s


# ----------------------------------------------------------------------
# Main entry point required by the platform
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises
    ``evaluate_sequence``.  Returns the best sequence found (list of floats).

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Time budget in seconds.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin for the final exact evaluation
    deadline = start_time + budget_s - 4.0

    # --------------------------------------------------------------
    # Choose a working length (n).  Re‑use the previous construction if
    # available, otherwise start with a moderate size.
    # --------------------------------------------------------------
    try:
        prev = height_sequence_1                      # noqa: F821 (global)
        n = max(len(prev), 5000)
        prev_arr = np.asarray(prev, dtype=np.float64)
        if prev_arr.sum() > 0.0:
            prev_arr = prev_arr / prev_arr.sum()
        else:
            prev_arr = None
    except Exception:
        prev_arr = None
        n = 12000   # default – a good compromise between quality and speed

    # bound n for the time budget
    n = int(min(max(n, 5000), 25000))

    # FFT length – next power of two ≥ 2·n‑1
    fft_len = 1 << ((2 * n - 1).bit_length())

    # --------------------------------------------------------------
    # Cheap helper – computes 2·n·max(conv) (the objective when sum=1)
    # --------------------------------------------------------------
    def cheap_score(vec: np.ndarray) -> float:
        maxb = _conv_max_fft(vec, fft_len)
        return 2.0 * n * maxb

    # --------------------------------------------------------------
    # 0. Initialisation – start from a well‑behaved point on the simplex
    # --------------------------------------------------------------
    if prev_arr is not None and prev_arr.size == n:
        a = prev_arr.copy()
    else:
        # uniform distribution + tiny random jitter
        a = np.full(n, 1.0 / n, dtype=np.float64)
        a += 0.0005 * np.random.rand(n)
        a = _simplex_projection(a)

    best_a = a.copy()
    best_cheap = cheap_score(a)

    print(f"[Init] length = {n}, cheap = {best_cheap:.6f}")

    # --------------------------------------------------------------
    # 1. Main optimisation loop (soft‑max + exponentiated gradient)
    # --------------------------------------------------------------
    # hyper‑parameters (tuned empirically)
    eta0 = 0.8                # initial step‑size factor
    beta0 = 0.5               # start temperature
    beta_max = 12.0           # final temperature
    max_iters = 500_000       # absolute safety cap

    # momentums for Adam‑style adaptive scaling (optional, can be disabled)
    use_adam = True
    if use_adam:
        m = np.zeros_like(a)
        v = np.zeros_like(a)
        beta1 = 0.9
        beta2 = 0.999
        eps = 1e-8

    iter_cnt = 0
    last_improve = 0
    beta = beta0

    while time.time() < deadline and iter_cnt < max_iters:
        iter_cnt += 1

        # ----- compute full convolution and cheap score -----
        conv = _conv_full_fft(a, fft_len)          # length 2·n‑1
        maxb = conv.max()
        cheap = 2.0 * n * maxb

        # keep the best vector seen so far
        if cheap < best_cheap - 1e-12:
            best_cheap = cheap
            best_a = a.copy()
            last_improve = iter_cnt
            print(f"[Iter {iter_cnt:07d}] NEW BEST cheap = {cheap:.6f}")

        # ----- update temperature (β) ----- 
        # linear schedule: slowly move from β0 to β_max
        if beta < beta_max:
            beta += (beta_max - beta0) / max_iters

        # ----- soft‑max weights (stable) -----
        # shift by max to avoid overflow
        shift = conv.max()
        exp_beta = np.exp(beta * (conv - shift))
        p = exp_beta / exp_beta.sum()            # shape (2·n‑1,)

        # ----- gradient of the smoothed objective -----
        # g_i = 2 * Σ_k p_k * a_{k-i}
        a_rev = a[::-1]
        fp = np.fft.fft(p, fft_len)
        fa_rev = np.fft.fft(a_rev, fft_len)
        grad_full = np.fft.ifft(fp * fa_rev).real
        grad = 2.0 * grad_full[n - 1:n - 1 + n]   # length n

        # ----- step size (η) -----
        eta = eta0 / math.sqrt(iter_cnt)

        # ----- (optional) Adam‑style scaling -----
        if use_adam:
            m = beta1 * m + (1 - beta1) * grad
            v = beta2 * v + (1 - beta2) * (grad * grad)
            m_hat = m / (1 - beta1 ** iter_cnt)
            v_hat = v / (1 - beta2 ** iter_cnt)
            eta_vec = eta / (np.sqrt(v_hat) + eps)
            direction = m_hat
        else:
            eta_vec = eta
            direction = grad

        # ----- mirror (exponentiated) gradient step -----
        a = _exponential_gradient_step(a, direction, eta_vec)

        # ----- occasional random perturbation to escape plateaus -----
        if iter_cnt % 120_000 == 0:
            perturb = 0.01 * np.random.rand(n)
            a = _simplex_projection(a + perturb)
            if use_adam:
                m.fill(0.0)
                v.fill(0.0)
            print(f"[Iter {iter_cnt:07d}] Restart – random perturbation")

    # --------------------------------------------------------------
    # 2. Optional fine‑tuning: blend best vector with uniform distribution
    #    and keep the blend with the smallest cheap score.
    # --------------------------------------------------------------
    uniform = np.full(n, 1.0 / n, dtype=np.float64)
    blend_best = best_a
    blend_score = best_cheap
    for t in np.linspace(0.0, 1.0, 21):          # 0 → uniform, 1 → best_a
        cand = (1 - t) * uniform + t * best_a
        cand = _simplex_projection(cand)
        sc = cheap_score(cand)
        if sc < blend_score:
            blend_score = sc
            blend_best = cand.copy()
    best_a = blend_best
    best_cheap = blend_score
    print(f"[Blend] cheap after blending = {best_cheap:.6f}")

    # --------------------------------------------------------------
    # 3. Final exact evaluation (uses the provided ``evaluate_sequence``)
    # --------------------------------------------------------------
    final_seq = best_a.tolist()
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"Final exact score = {final_score:.6f}")
    except Exception as exc:      # defensive – should never happen
        final_score = float("inf")
        print(f"Error during final evaluation: {exc}")

    # --------------------------------------------------------------
    # 4. Return the best sequence found.
    # --------------------------------------------------------------
    return final_seq
```
