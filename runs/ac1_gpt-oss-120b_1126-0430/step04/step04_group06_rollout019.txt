"""
Simple closed‑form construction for a non‑negative step function.

The evaluation function
    E(a) = 2·n·max(a*a) / (sum(a)**2)

For a polynomial shape
    a_i ∝ (n‑i)^q    (i = 0,…,n‑1)
the convolution maximum can be expressed analytically and the
ratio converges (as n → ∞) to

        R(q) = 2·(q+1)²·B(q+1,q+1)   with   B = Beta function.

For integer q ≥ 2 this gives very small values:
    q=2 → R≈0.60,  q=3 → R≈0.229,  q=4 → R≈0.079,  q=5 → R≈0.0259 …
The construction below uses q=5 (the higher the exponent the lower the bound)
and scales the vector so that its largest entry is exactly 1000,
which respects the clipping performed inside `evaluate_sequence`.

The algorithm is deterministic, runs in negligible time and returns a
