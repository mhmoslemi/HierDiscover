The bound
\[
O(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2}
\]
is minimised on the probability simplex \(\sum a_i =1,\;a_i\ge0\).
`evaluate_sequence` implements exactly this formula for a normalised
sequence, therefore we can work with a *probability vector* `a`.  

The previous approach used a plain mirror‑descent (exponentiated gradient)
with a manually tuned learning‑rate schedule.  To push the bound a few
hundredths lower we combine several tricks that are cheap enough to run
many‑times within the 1000 s budget:

* **Adam on the log‑variables** – an adaptive step size per coordinate
  accelerates convergence of the mirror–descent scheme.
* **Sharper soft‑max** – the temperature `β` grows much faster (exponential
  schedule) so the algorithm focuses on the truly binding convolution
  entries early on.
* **Periodic hard‑max** – when `β` becomes large we switch to a pure
  active‑set weight (`w` only on the maximal entries).  This yields the
  exact sub‑gradient of the \(\max\) operator.
* **Jitter & cheap restarts** – random perturbations and a restart from the
  best‑so‑far solution avoid stagnation.
* **Sparsification** – every few thousand iterations entries smaller than
  a dynamic percentile are set to zero and the vector is re‑normalised.
  This mimics the “Sidon‑set” intuition (few large spikes, many zeros)
  while keeping the optimisation on the full simplex.
* **Multi‑start** – if a previous solution (`height_sequence_1`) exists we
  start from it, otherwise we begin with a uniform distribution.

All heavy work is performed in the frequency domain using real FFTs;
a single iteration costs two size‑\(L\) FFTs (`L` is the next power‑of‑two
≥ \(2n\)).  With `n≈5000` we can comfortably run several hundred thousand
iterations inside the time limit.

The function returns the best sequence found (as a plain list of `float`);
the final value is printed for verification.

```python
"""
Propose a step‑function (non‑negative vector) that minimises
    O = 2 * n * max(conv(a, a))   (a summed to 1)

Algorithm
---------
* Work on log‑probabilities `u = log a` and use an Adam optimiser.
* At each iteration compute the full self‑convolution via a real FFT.
* Build a weight vector `w` over the convolution entries:
      – early phase : softened soft‑max  w_i ∝ exp(β·(conv_i‑max))
      – late phase  : hard‑max on the active set (conv_i ≥ max‑tol)
* Gradient = 2 * correlation(w, a)  (obtained by a second FFT).
* Adam update of the log‑variables, followed by re‑normalisation.
* Every `jitter_interval` add tiny Gaussian noise to `u`.
* Every `restart_interval` re‑initialise from the best‑so‑far solution.
* Every `sparsify_interval` zero out tiny entries (percentile cut) and
  renormalise – this encourages a sparse, low‑autocorrelation shape.
* Keep the best vector (smallest `O`) seen during the run.
* Stop when the 1000 s budget is exhausted and return the best sequence.

The routine respects the required time limit, prints progress and final
statistics, and works with the already imported ``evaluate_sequence``.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper FFT utilities ---------------------------------------------------
def _next_pow2(x: int) -> int:
    """Return the smallest power of two >= x."""
    return 1 << (x - 1).bit_length()


def _conv_self_fft(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a * a via a real FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(af * af, n=L)[: 2 * n - 1]
    return conv


def _correlation_fft(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Linear correlation g_i = Σ_t w[i+t]·a[t]  for i=0,…,n‑1.
    Implemented via FFT (real).  ``w`` has length 2·n‑1.
    """
    n = a.shape[0]
    m = w.shape[0]          # = 2·n‑1
    L = _next_pow2(m + n - 1)
    wf = np.fft.rfft(w, n=L)
    af = np.fft.rfft(a, n=L)
    corr_full = np.fft.irfft(wf * np.conj(af), n=L)
    return corr_full[:n]


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list:
    """
    Search for a non‑negative step‑function that minimises the bound
    evaluated by ``evaluate_sequence``.
    Returns the best sequence as a plain list of ``float``.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # safety margin

    # ------------------------------------------------------------------
    # 1) Choose problem size and initialise log‑probabilities.
    if 'height_sequence_1' in globals():
        a0 = np.asarray(height_sequence_1, dtype=float)
        # normalise to sum = 1 (probability vector)
        a0 = a0 / a0.sum()
        n = a0.size
        # small jitter to avoid exact zero‑log
        eps = 1e-12
        u = np.log(a0 + eps)
    else:
        # moderately sized problem – 5000 works well within the budget
        n = 5000
        u = np.full(n, -np.log(n))          # uniform log‑probability

    # Adam state
    m = np.zeros_like(u)   # first moment
    v = np.zeros_like(u)   # second moment
    beta1 = 0.9
    beta2 = 0.999
    adam_eps = 1e-8

    best_u = u.copy()
    best_score = np.inf
    best_iter = 0
    last_improve_iter = 0

    # ------------------------------------------------------------------
    # 2) Hyper‑parameter schedules
    max_iters_est = 600_000                # rough “full schedule” length
    beta_start = 2.0
    beta_end   = 40000.0
    eta_start  = 0.4                       # base learning‑rate
    eta_end    = 0.02

    jitter_interval   = 3000
    jitter_scale      = 5e-4
    restart_interval  = 30_000
    sparsify_interval = 15_000
    sparsify_percent  = 1.0   # percent of smallest entries to zero

    it = 0
    while time.time() < deadline:
        it += 1

        # --------------------------------------------------------------
        # (a) Build probability vector a from the log‑variables
        #     (stable exponentiation)
        a = np.exp(u - u.max())
        s = a.sum()
        if s == 0.0:                # numerical safety net
            a = np.full_like(a, 1.0 / n)
            s = 1.0
        a = a / s

        # (b) Full self‑convolution and current bound
        conv = _conv_self_fft(a)
        M = conv.max()
        cur_score = 2.0 * n * M          # because sum(a)=1

        # (c) Record best solution
        if cur_score < best_score - 1e-13:
            best_score = cur_score
            best_u = u.copy()
            best_iter = it
            last_improve_iter = it
            print(f"[iter {it:07d}] new best O={best_score:.6f}")

        # --------------------------------------------------------------
        # (d) Parameter schedules (fraction of the total schedule)
        fraction = min(it / max_iters_est, 1.0)

        # exponential growth of β gives a fast transition to a hard‑max
        beta = beta_start * (beta_end / beta_start) ** fraction

        # learning‑rate schedule (slow decay)
        eta = eta_start * (eta_end / eta_start) ** fraction

        # --------------------------------------------------------------
        # (e) Build weight vector w over convolution entries
        #     Early iterations: soft‑max, later: hard‑max on the active set
        if fraction < 0.35:          # soft‑max phase
            shifted = conv - M       # ≤ 0, max is 0
            w = np.exp(beta * shifted)
            w_sum = w.sum()
            if w_sum == 0.0:
                w = np.zeros_like(conv)
                w[conv.argmax()] = 1.0
            else:
                w /= w_sum
        else:                         # active‑set (hard‑max) phase
            # tolerance scaled with M; we keep a tiny window around the max
            tol = max(1e-14, M * 5e-9)
            active = np.where(conv >= M - tol)[0]
            if active.size == 0:     # fallback – should never happen
                w = np.zeros_like(conv)
                w[conv.argmax()] = 1.0
            else:
                w = np.zeros_like(conv)
                w[active] = 1.0 / active.size

        # --------------------------------------------------------------
        # (f) Gradient of the (smoothed) max‑convolution :=
        #     ∂/∂a  Σ_k w_k (a*a)[k]  =  2 * corr(w, a)
        g = 2.0 * _correlation_fft(w, a)   # shape (n,)

        # --------------------------------------------------------------
        # (g) Adam update of the log‑variables  u ← u – η· Adam‑step
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)

        # bias‑corrected moments
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = eta * (m_hat / (np.sqrt(v_hat) + adam_eps))
        u = u - step

        # --------------------------------------------------------------
        # (h) Random jitter to escape flat plateaus
        if it % jitter_interval == 0:
            u += np.random.randn(n) * jitter_scale

        # --------------------------------------------------------------
        # (i) Sparse‑ify: zero tiny entries periodically
        if it % sparsify_interval == 0:
            a = np.exp(u - u.max())
            a_sum = a.sum()
            a = a / a_sum
            # percentile cut – keep the larger values
            cutoff = np.percentile(a, sparsify_percent)
            mask = a > cutoff
            if mask.sum() == 0:
                # extremely unlikely, keep the full vector
                mask = np.arange(n) >= 0
            a_sparse = np.where(mask, a, 0.0)
            # re‑normalise and map back to log‑space
            a_sparse = a_sparse / a_sparse.sum()
            u = np.log(a_sparse + 1e-12)   # add tiny epsilon to avoid -inf

        # --------------------------------------------------------------
        # (j) Cheap restart if we have been stagnant for a while
        if it % restart_interval == 0 and (it - last_improve_iter) > (restart_interval // 2):
            u = best_u.copy()
            u += np.random.randn(n) * (jitter_scale * 0.5)
            m.fill(0.0)
            v.fill(0.0)
            print(f"[restart] iter {it}, re‑initialised from best (O={best_score:.6f})")

    # ------------------------------------------------------------------
    # 3) Produce the best sequence and evaluate it once more
    best_seq = np.exp(best_u - best_u.max())
    best_seq = best_seq / best_seq.sum()

    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"[final] evaluate_sequence reports O={final_score:.6f} "
              f"(best iteration {best_iter})")
    except Exception as exc:                 # pragma: no cover
        print("[final] evaluate_sequence call failed:", exc)

    return best_seq.tolist()
```
