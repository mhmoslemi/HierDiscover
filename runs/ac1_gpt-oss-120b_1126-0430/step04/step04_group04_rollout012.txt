The evaluation function is  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

Because the objective is homogeneous of degree 0 we can work on the
probability simplex  
\(\sum_i a_i = 1\); then  

\[
F(a)=2n\;\max_k (a*a)[k].
\]

The bottleneck is the “max‑convolution’’ term.  
Instead of using a sub‑gradient that only looks at the few largest
convolution entries (the previous code) we minimise a **smooth
approximation** of the maximum:

\[
M_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_{k}e^{\beta\,(a*a)[k]}\Bigr)
        \;\xrightarrow{\;\beta\to\infty\;}\; \max_k (a*a)[k].
\]

For a given \(\beta\)

*   \(w_k = \frac{e^{\beta\,(a*a)[k]}}{\sum_j e^{\beta\,(a*a)[j]}}\) are the
    soft‑max weights,
*   \(\displaystyle\frac{\partial M_\beta}{\partial a}
        = 2\,\operatorname{corr}(w,a)\)  (a valid correlation, i.e.
    \(\operatorname{corr}(w,a)[j]=\sum_i w_{i+j}\,a_i\)).

The gradient of the original objective is simply
\(2n\) times the above expression.  
We use an **exponentiated‑gradient** (mirror‑descent on the simplex)
update

\[
a_i \leftarrow a_i\,
      \exp\!\bigl(-\eta\,g_i\bigr),\qquad
a\leftarrow\frac{a}{\sum a},
\]

where \(g=\operatorname{corr}(w,a)\) and \(\eta\) is a decaying step size.
The exponentiated‑gradient automatically respects non‑negativity and the
simplex constraint, so no explicit projection is needed.

To obtain a good start we:

1. scan a set of power‑law profiles \(a_i\propto(i+1)^{-p}\),
2. draw many Dirichlet samples with a wide range of concentration
   parameters,
3. keep the best of those candidates.

After the initialisation we run the smooth‑max optimisation.
The smoothing parameter \(\beta\) is increased slowly so that the
algorithm first sees a “soft’’ objective (easy to optimise) and then
focuses on the true maximum.  If the score does not improve for a long
time we perturb the current best solution and continue – this provides
escapes from shallow local minima.

All heavy lifting (convolution, correlation) is performed with FFTs,
so a single iteration costs only \(O(N\log N)\) even for
\(N\approx 15000\).  The routine respects the 1000 s budget and always
returns a feasible sequence.

```python
#!/usr/bin/env python
"""
Propose a non‑negative step function that minimises

        2·n·max_k (a*a)[k] / (Σ a_i)²

The algorithm:
* start from a power‑law or a Dirichlet sample (both normalised to sum=1);
* minimise a smooth approximation of the max‑convolution using an
  exponentiated‑gradient (mirror‑descent) update;
* the gradient is the correlation of the soft‑max weights with the
  current vector – computed efficiently via FFT;
* the smoothing parameter β is increased gradually; occasional random
  perturbations restart the search if progress stalls.
All sequences are kept on the simplex, hence always feasible for
``evaluate_sequence``.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Basic utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _power_law_sequence(n: int, p: float) -> np.ndarray:
    """a_i ∝ (i+1)^(-p), normalised to sum = 1."""
    i = np.arange(1, n + 1, dtype=np.float64)
    seq = i ** (-p)
    seq /= seq.sum()
    return seq


def _conv_full_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Full linear convolution a*a using FFT.
    Returns exactly (2·len(a)‑1) entries.
    """
    fa = np.fft.fft(a, fft_len)
    conv = np.fft.ifft(fa * fa).real[: 2 * a.size - 1]
    return conv


def _corr_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Correlation g[j] = Σ_i w[i+j]·a[i]   (valid part, length len(a)).
    Implemented as convolution of w with a reversed, via FFT.
    """
    a_rev = a[::-1]
    fw = np.fft.fft(w, fft_len)
    far = np.fft.fft(a_rev, fft_len)
    conv = np.fft.ifft(fw * far).real
    start = a.size - 1                     # index where valid part begins
    return conv[start:start + a.size]      # length = len(a)


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 123, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function (list of heights) that minimises
    ``evaluate_sequence``.  The routine respects the given time budget
    (default 1000 s) and always returns a feasible sequence.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0        # safety margin

    # --------------------------------------------------------------
    # Choose the working length n
    # --------------------------------------------------------------
    try:
        prev = height_sequence_1               # type: ignore[name-defined]
        n = max(len(prev), 8000)
        prev_arr = np.asarray(prev, dtype=np.float64)
        if prev_arr.sum() > 0.0:
            prev_arr = prev_arr / prev_arr.sum()
        else:
            prev_arr = None
    except Exception:
        prev_arr = None
        n = 8000

    n = int(min(max(n, 5000), 20000))            # keep the work size reasonable

    # FFT lengths (next powers of two)
    fft_len_conv = _next_pow2(2 * n - 1)          # for a*a
    fft_len_corr = _next_pow2(3 * n - 2)          # for correlation (w * a_rev)

    # --------------------------------------------------------------
    # Helper to evaluate the cheap (exact) objective for a sum‑1 vector
    # --------------------------------------------------------------
    def cheap_score(vec: np.ndarray) -> float:
        conv = _conv_full_fft(vec, fft_len_conv)
        return 2.0 * n * conv.max()

    # --------------------------------------------------------------
    # 0 – Initial candidates (power‑law scan + random Dirichlet)
    # --------------------------------------------------------------
    best_a = None

            break

            best_a = cand.copy()

            best_val = val

    print(f"[Init] n = {n}, best cheap = {best_val:.6f}")

    # --------------------------------------------------------------
    a = best_a.copy()

    stagnation_limit = 25000

        eta = eta0 / math.sqrt(it)

        s = a.sum()
        if s <= 0 or not np.isfinite(s):

        a = a / s

        # ----- slowly increase the smoothness parameter -----

        # ----- restart if we are stuck for a while -----

            a /= a.sum()
            last_improve = it
            print(f"[Iter {it:07d}] Restart after stagnation.")
            beta = max(beta, 5.0)

    # --------------------------------------------------------------
    # 2 – Final exact evaluation and return
    # --------------------------------------------------------------
    final_seq = best_seq.tolist()
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"Final exact score = {final_score:.6f}")
    except Exception as exc:          # defensive – should never happen
        final_score = float("inf")
        print(f"Error during final evaluation: {exc}")

    return final_seq
```
