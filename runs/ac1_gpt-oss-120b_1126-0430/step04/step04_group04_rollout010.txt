assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\qquad a_i\ge 0,
\]

where ``a*a`` is the *polynomial* convolution (the same as `np.convolve`).  
Because the objective is homogeneous we can fix the ℓ₁‑norm of the vector
(`∑a_i = 1`).  With this normalisation the problem becomes

* minimise the largest coefficient of the self‑convolution.  

The optimum is approached when the convolution is as flat as possible – the
theoretical lower bound is  

\[
F_{\min}= \frac{2n}{2n-1}\approx 1 .
\]

The previous implementation uses a sub‑gradient based heavy‑ball scheme with a
fixed set of the *k* largest convolution entries.  In practice the maximum
often has a whole neighbourhood of near‑maximal coefficients; ignoring them
slows convergence.

The new algorithm improves on three points:

1. **Smooth approximation of the max** – we replace `max` by a
   *log‑sum‑exp* with a temperature `α`.  The gradient of this smooth
   surrogate is the weighted average of all convolution coefficients,
   which gives a much richer descent direction.

2. **Mirror descent on the simplex** – we use an exponentiated‑gradient
   (multiplicative) update, which automatically stays on the probability
   simplex (`∑a_i=1, a_i≥0`).  An Adam‑style moment estimator is added to
   adapt the per‑coordinate step size.

3. **Dynamic schedule & restarts** – the temperature `α` is increased
   gradually so the optimisation first moves in a smooth landscape and later
   focusses on the true maximum.  If no improvement is seen for a long
   time the current best vector is perturbed slightly to escape possible
   plateaus.

All operations are performed with FFTs, therefore each iteration costs
`O(n log n)` and even for `n=25000` thousands of iterations comfortably fit
into the 1000 s budget.

The code below implements this strategy.  It uses the globally available
`height_sequence_1` (if present) as a warm start, otherwise falls back to a
uniform distribution.  The best sequence found during the run is returned.



```python
#!/usr/bin/env python
"""
Gradient‑descent on a smooth max‑approximation with exponentiated‑gradient
updates (Adam‑style) on the probability simplex.

The algorithm works with any length `n` (default up to 25000).  It keeps the
vector normalised (ℓ₁‑norm = 1) at every step, uses FFTs for fast convolution,
and slowly raises the soft‑max temperature `α` so that the optimisation first
sees a smooth landscape and finally concentrates on the true maximum.  Periodic
restarts with a small random perturbation avoid stagnation.

The returned list can be fed directly to `evaluate_sequence`.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex {x ≥ 0, Σx = 1}."""
    n = v.shape[0]
    # sort decreasing
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.nonzero(rho_arr > 0)[0]
    if rho.size == 0:                # all non‑positive -> uniform
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _conv_full_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Full linear convolution a*a using FFT (real output, length 2·n‑1)."""
    fa = np.fft.fft(a, fft_len)
    conv = np.fft.ifft(fa * fa).real
    # keep only the first 2·n‑1 entries (the rest are numerical noise)
    return conv[: 2 * a.size - 1]


def _smooth_max_grad(a: np.ndarray,
                     conv: np.ndarray,
                     alpha: float,
                     fft_len: int,
                     fft_len2: int) -> np.ndarray:
    """
    Gradient of the smooth max (log‑sum‑exp) of the convolution.
    Returns a vector of length len(a).
    """
    # soft‑max weights (stable: shift by max)
    max_val = conv.max()
    w = np.exp(alpha * (conv - max_val))
    Z = w.sum()
    if Z == 0.0:
        # all entries underflow – fall back to uniform weights
        p = np.full_like(conv, 1.0 / conv.size)
    else:
        p = w / Z

    # convolution of the weights with a (cross‑correlation)
    # using FFT of length fft_len2 ≥ (len(p) + len(a) - 1)
    Fa = np.fft.fft(a, fft_len2)
    Fp = np.fft.fft(p, fft_len2)
    c = np.fft.ifft(Fp * Fa).real
    offset = a.size - 1                     # position of index 0 in the full conv
    g = 2.0 * c[offset: offset + a.size]    # factor 2 from derivative of a*a
    return g


def _interpolate_to_length(old: np.ndarray, new_len: int) -> np.ndarray:
    """Linear interpolation of a 1‑D array to a new length."""
    old_len = old.shape[0]
    if old_len == new_len:
        return old.copy()
    x_old = np.linspace(0.0, 1.0, old_len)
    x_new = np.linspace(0.0, 1.0, new_len)
    new = np.interp(x_new, x_old, old)
    new = np.maximum(new, 0.0)
    s = new.sum()
    if s == 0.0:
        new[:] = 1.0 / new_len
    else:
        new /= s
    return new

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function that minimises `evaluate_sequence`.

    The routine runs a smooth‑max gradient descent with Adam‑style mirror
    updates on the simplex, gradually increasing the temperature `α`.  It
    respects the time budget and always returns a feasible sequence.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin for the final exact evaluation
    deadline = start_time + budget_s - 5.0

    # ------------------------------------------------------------------
    # Choose the working length `n` (5k … 25k)
    # ------------------------------------------------------------------
    try:
        # use previous construction if it exists
        prev = np.asarray(height_sequence_1, dtype=np.float64)  # noqa: F821
        prev_len = prev.size
    except Exception:
        prev = None
        prev_len = 0

    # we aim for a long sequence – the longer the better (theoretical bound →1)
    n = max(prev_len, 20000)                 # at least 20 k entries
    n = min(n, 25000)                        # upper bound for speed

    # Initialise `a` ----------------------------------------------------
    if prev is not None:
        a = _interpolate_to_length(prev, n)
    else:
        a = np.full(n, 1.0 / n, dtype=np.float64)   # uniform start

    # FFT lengths -------------------------------------------------------
    fft_len = 1 << ((2 * n - 1).bit_length())          # ≥ 2·n‑1
    fft_len2 = 1 << ((3 * n - 2).bit_length())        # ≥ (2·n‑1)+n‑1

    # Adam‑style moment vectors
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12

    # Temperature schedule for the smooth max
    alpha = 5.0                 # start with a smooth approximation
    alpha_max = 60.0
    alpha_inc_iter = 30000      # increase α every this many iterations

    # Learning‑rate schedule
    eta0 = 0.6                  # base step size

    # Stagnation handling
    best_a = a.copy()
    # cheap score = exact objective because sum(a)=1
    conv = _conv_full_fft(a, fft_len)
    best_score = 2.0 * n * conv.max()
    last_improve_iter = 0

    iter_cnt = 0
    print(f"[Init] length = {n}, start score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Main optimisation loop
    # ------------------------------------------------------------------
    while time.time() < deadline:
        iter_cnt += 1

        # ---- full convolution and current score -----------------------
        conv = _conv_full_fft(a, fft_len)
        max_val = conv.max()
        curr_score = 2.0 * n * max_val

        # ---- keep best ------------------------------------------------
        if curr_score < best_score - 1e-12:
            best_score = curr_score
            best_a = a.copy()
            last_improve_iter = iter_cnt
            print(f"[Iter {iter_cnt:07d}] NEW BEST = {curr_score:.6f}")

        # ---- restart if stuck -----------------------------------------
        if iter_cnt - last_improve_iter > 120_000:
            # small random perturbation of the best vector
            perturb = 0.02 * np.random.rand(n)
            a = _simplex_projection(best_a + perturb)
            m.fill(0.0)
            v.fill(0.0)
            last_improve_iter = iter_cnt
            print(f"[Iter {iter_cnt:07d}] Restart (perturbation).")
            continue

        # ---- smooth‑max gradient --------------------------------------
        g = _smooth_max_grad(a, conv, alpha, fft_len, fft_len2)

        # ---- Adam moment updates ---------------------------------------
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)

        # bias‑corrected estimates
        m_hat = m / (1.0 - beta1 ** iter_cnt)
        v_hat = v / (1.0 - beta2 ** iter_cnt)

        # ---- exponentiated‑gradient (mirror descent) ------------------
        # adaptive per‑coordinate step
        step = eta0 / math.sqrt(iter_cnt)
        adap = step * (m_hat / (np.sqrt(v_hat) + eps))

        # multiplicative update, stay on simplex via renormalisation
        a = a * np.exp(-adap)
        s = a.sum()
        if s == 0.0 or not np.isfinite(s):
            a[:] = 1.0 / n
        else:
            a /= s

        # ---- temperature schedule --------------------------------------
        if iter_cnt % alpha_inc_iter == 0 and alpha < alpha_max:
            alpha = min(alpha * 1.5, alpha_max)

        # ----------------------------------------------------------------
        # safety check – do not exceed the time budget
        # ----------------------------------------------------------------
        if time.time() >= deadline:
            break

    # ------------------------------------------------------------------
    # Final exact evaluation (just for reporting)
    # ------------------------------------------------------------------
    final_seq = best_a.tolist()
    try:
        final_score = evaluate_sequence(final_seq)  # provided by the platform
        print(f"Final exact score = {final_score:.6f}")
    except Exception as exc:      # defensive – should never happen
        final_score = float("inf")
        print(f"Error during final evaluation: {exc}")

    return final_seq
```
