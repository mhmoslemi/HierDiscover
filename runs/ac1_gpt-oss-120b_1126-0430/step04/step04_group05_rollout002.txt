    L = 1 << ((3 * n - 2).bit_length())

    # Helper to evaluate the exact objective (O = 2·n·max(conv) because sum=1)
    def _objective(v):
        return 2.0 * n * _max_conv(v, L)

    cur_O = _objective(a)
    best_seq = a.copy()
    best_O = cur_O
    print(f"[init] n={n}, O={cur_O:.6f}")

    # We will perform at most `max_lp_iters` refinements or stop earlier
    max_lp_iters = 15
    lp_iter = 0
    while time.time() < deadline and lp_iter < max_lp_iters:
        # compute the current worst‑case convolution value M
        M = _max_conv(a, L)

        # Build the (2n‑1) × n matrix that represents convolution with a
        # (row k contains a_0 … a_{n-1} shifted by k)
        rows = 2 * n - 1
        A = np.empty((rows, n), dtype=np.float64)
        A.fill(0.0)
        for col in range(n):
            A[col:col + n, col] = a

        #   maximise   1ᵀ g

        c = -np.ones(n)                     # linprog minimises, so -1ᵀ g

        sum_g = g.sum()

        if sum_g <= 1.0 + 1e-8:

            break

        g_norm = g / sum_g

        O_new = _objective(g_norm)

        if O_new < cur_O - 1e-9:

            cur_O = O_new
        else:

            O_blend = _objective(blend)
            if O_blend < cur_O - 1e-9:
                a = blend
                cur_O = O_blend
                print(f"[LP {lp_iter}] accepted blended O = {cur_O:.6f}")
            else:

                break

        lp_iter += 1
        # free the large matrix before the next iteration
        del A

            break

    # We continue from the best LP‑derived vector.
    cur_seq = a.copy()
    cur_O = _objective(cur_seq)
    best_seq_local = best_seq.copy()
    best_O_local = best_O

    temperature = 0.05

    max_local_iters = 300_000

        cand[j] += delta

            cur_O = O_cand
            temperature *= 0.9999    # cool down slowly

        print(f"[final] evaluate_sequence reports O = {final_score:.6f}")
    except Exception as exc:
        print("[final] evaluation failed:", exc)

    return best_seq_local.tolist()

Propose a non‑negative step‑function minimizing

    O(a) = 2·n·max(conv(a,a)) / (sum(a)^2)

Algorithm
---------

1️⃣ Linear‑programming refinement (Frank‑Wolfe style):
   * Keep the current vector f on the probability simplex (sum = 1).
   * Let M = max(f∗f).  Solve the LP
        maximise   Σ g_j
        subject to A_f·g ≤ M·1,   0 ≤ g_j ≤ 1000
     where A_f is the (2n‑1)×n matrix that implements the convolution
     (row k contains f shifted by k).
   * If the LP raises the total mass (Σ g_j > 1) we normalise g to the
     simplex and obtain a strictly better vector (the new max‑convolution
     is at most M / Σ g_j).  Accept the improvement; otherwise stop.

2️⃣ Stochastic local refinement:
   * Starting from the best LP‑derived vector, repeatedly move a small
     random fraction of probability mass from one index to another.
   * Accept moves that improve the exact objective or, with a Metropolis
     probability, accept worse moves while a temperature slowly cools.
   * Occasionally perform a convex blend with the previous LP solution
     to escape tiny plateaus.

Both phases respect the 1000 s wall‑time budget.  The final candidate is
checked with the provided ``evaluate_sequence`` function before being
returned as a plain Python list of floats.
