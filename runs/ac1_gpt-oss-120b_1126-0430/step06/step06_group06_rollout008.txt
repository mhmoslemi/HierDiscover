The objective  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2}
\]

is *scale‑invariant*: we may impose the normalisation  
\(\sum_i a_i=1\) and minimise  

\[
\tilde F(a)=2\,n\;\max_k (a*a)[k]\; .
\]

`evaluate_sequence` finally computes the same expression, therefore the
search works with probability vectors (non‑negative, sum = 1) and at the very end
returns the raw vector – the required scaling is performed automatically by the
provided function.

The program consists of three independent phases that together explore a
large part of the search space while staying well inside the 1000 s budget.

* **Phase 0 – broad parametric sweep**  
  Families that are known to give low values (uniform, power‑law,
  exponential, mixed power‑law × exponential, stretched‑exponential,
  β‑distributions) are sampled on a fine grid.  Two additional families
  that concentrate mass near the ends of the interval – *edge‑power* and
  *symmetric‑exponential* – are also examined.  Random Dirichlet seeds with
  very small concentrations are tried as well.  The best vector from this
  inexpensive scan is kept as a starting point.

* **Phase 1 – smoothed mirror‑descent**  
  The non‑smooth max‑operator is replaced by a smooth soft‑max  

  \[
  \phi_\varepsilon(a)=\varepsilon\log\Bigl(\sum_k
  e^{(a*a)[k]/\varepsilon}\Bigr)
  \]

  (the “temperature’’ \(\varepsilon\) is decreased during the run).
  The gradient of \(\phi_\varepsilon\) has a simple closed form:
  let  

  \[
  w_k=\frac{e^{(a*a)[k]/\varepsilon}}{\sum_j e^{(a*a)[j]/\varepsilon}}
  \qquad\text{and}\qquad
  g = 2\;(w * a^{\mathrm{rev}})_{\,n-1\;..\;2n-2}
  \]

  where \(*\) denotes linear convolution and \(a^{\mathrm{rev}}\) is the
  reversed vector.  All convolutions are performed with a real FFT, so a
  full iteration costs only a few FFT calls.

  The descent step is carried out in the log‑domain (exponentiated‑gradient /
  mirror descent) and the result is projected onto the probability simplex
  with the standard \(O(n\log n)\) projection.  An Adam‑style adaptive step
  size is used, and the temperature is multiplied by 0.95 every 500
  iterations.  The procedure is started from several random Dirichlet
  seeds (mixed with the best vector from Phase 0) – the best result of all
  runs is kept.

* **Phase 2 – (1 + 1)‑ES fine‑tuning**  
  A cheap (log‑space Gaussian) mutation of the current best vector is
  accepted if the *cheap* score (i.e. \(2n\max(a*a)\)) improves.
  The mutation strength \(\sigma\) is adapted with the classic 1/5‑rule.

* **Phase 3 – exact evaluation**  
  The final candidate is handed to `evaluate_sequence` and returned.

All phases respect the global time budget (a 5 s safety margin is kept for the
final call).  The code uses only NumPy and the standard library, runs on a
single process, and follows the required “no closures, top‑level helpers”
policy.

```python
#!/usr/bin/env python
"""
Proposes a non‑negative step function (list of heights) that minimises

        2·n·max_k (a*a)[k] / (Σ a_i)²

The algorithm consists of three phases:

0. Exhaustive sweep over several parametric families (including new
   edge‑power and symmetric‑exponential families) and random Dirichlet
   seeds. The best vector (normalised to sum = 1) is kept.

1. Smoothed mirror‑descent on a soft‑max approximation of the max‑convolution.
   The gradient is obtained by a second convolution (FFT based) and the
   update is performed in the log‑domain with an Adam‑style adaptive step.
   Several random restarts are performed; the best result is retained.

2. Simple (1+1)‑ES hill‑climbing on the cheap objective (2 n·max(a*a)),
   with multiplicative Gaussian mutations and 1/5‑rule step‑size control.

3. Final exact evaluation with the supplied `evaluate_sequence` function.

The routine always returns a feasible sequence and finishes well before the
1000 s limit.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – top level (no closures)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project v onto the probability simplex {x ≥ 0, Σx = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.nonzero(rho_arr > 0)[0]
    if rho.size == 0:
        # all non‑positive → uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _conv_full_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Full linear convolution (a*a) using a real FFT, length 2·n‑1."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len).real[: 2 * a.size - 1]
    return conv


def _conv_max_fft(a: np.ndarray, fft_len: int) -> tuple[float, int]:
    """Maximum coefficient of a*a and its index."""
    conv = _conv_full_fft(a, fft_len)
    idx = int(conv.argmax())
    return float(conv[idx]), idx


# ----------------------------------------------------------------------
# Parametric families (all return a normalised probability vector)
# ----------------------------------------------------------------------


def _uniform_seq(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)


def _power_law_seq(n: int, p: float) -> np.ndarray:
    i = np.arange(1, n + 1, dtype=np.float64)
    seq = i ** (-p)
    seq /= seq.sum()
    return seq


def _exponential_seq(n: int, lam: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    seq = np.exp(-lam * i)
    seq /= seq.sum()
    return seq


def _power_law_exp_seq(n: int, p: float, lam: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    seq = (i + 1.0) ** (-p) * np.exp(-lam * i)
    seq /= seq.sum()
    return seq


def _stretched_exponential_seq(n: int, lam: float, gamma: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    seq = np.exp(-lam * (i ** gamma))
    seq /= seq.sum()
    return seq


def _beta_seq(n: int, alpha: float, beta: float) -> np.ndarray:
    x = (np.arange(1, n + 1, dtype=np.float64) / n)
    seq = (x ** alpha) * ((1.0 - x) ** beta)
    s = seq.sum()
    if s == 0.0:
        return None
    seq /= s
    return seq


def _dirichlet_seq(n: int, conc: float) -> np.ndarray:
    g = np.random.gamma(conc, 1.0, size=n)
    seq = g / g.sum()
    return seq


def _inverse_sqrt_seq(n: int) -> np.ndarray:
    i = np.arange(1, n + 1, dtype=np.float64)
    seq = 1.0 / np.sqrt(i)
    seq /= seq.sum()
    return seq


def _edge_power_seq(n: int, p: float) -> np.ndarray:
    """Power‑law decay from both ends, based on distance to the nearest endpoint."""
    d = np.minimum(np.arange(n), n - 1 - np.arange(n)) + 1.0
    seq = d ** (-p)
    seq /= seq.sum()
    return seq


def _symmetric_exponential_seq(n: int, lam: float) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    seq = np.exp(-lam * i) + np.exp(-lam * (n - 1 - i))
    seq /= seq.sum()
    return seq


# ----------------------------------------------------------------------
# Main entry point required by the platform
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function (list of non‑negative heights) that
    minimises ``evaluate_sequence`` within the given time budget.
    """
    np.random.seed(seed)
    start_time = time.time()
    # leave a few seconds for the final exact evaluation
    deadline = start_time + budget_s - 5.0

    # --------------------------------------------------------------
    # Determine working length n (preferably 5‑25 k)
    # --------------------------------------------------------------
    try:
        prev = globals()["height_sequence_1"]
        n = max(len(prev), 5000)
        prev_arr = np.asarray(prev, dtype=np.float64)
        if prev_arr.sum() > 0.0:
            prev_arr /= prev_arr.sum()
        else:
            prev_arr = None
    except Exception:
        prev_arr = None
        n = 5000

    n = int(min(max(n, 5000), 25000))          # 5 k ≤ n ≤ 25 k
    fft_len_conv = 1 << ((2 * n - 1).bit_length())      # for a*a
    fft_len_grad = 1 << ((3 * n - 2).bit_length())      # for w*a_rev

    # --------------------------------------------------------------
    # Cheap objective (assumes Σa_i = 1): 2·n·max(conv)
    # --------------------------------------------------------------
    def cheap_score(vec: np.ndarray) -> float:
        maxb, _ = _conv_max_fft(vec, fft_len_conv)
        return 2.0 * n * maxb

    # --------------------------------------------------------------
    # Phase 0 – exhaustive search over parametric families
    # --------------------------------------------------------------
    best_a = _uniform_seq(n)
    best_val = cheap_score(best_a)

    # use previous construction if it matches the current length
    if prev_arr is not None and prev_arr.size == n:
        val = cheap_score(prev_arr)
        if val < best_val:
            best_a, best_val = prev_arr.copy(), val

    # 1) Power‑law sweep
    for p in np.linspace(0.1, 2.0, 95):
        if time.time() >= deadline:
            break
        cand = _power_law_seq(n, p)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # 2) Exponential sweep
    for lam in np.linspace(0.0, 5.0, 101):
        if time.time() >= deadline:
            break
        cand = _exponential_seq(n, lam)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # 3) Mixed power‑law × exponential (coarse grid)
    for p in np.linspace(0.2, 1.5, 13):
        for lam in np.linspace(0.0, 3.0, 15):
            if time.time() >= deadline:
                break
            cand = _power_law_exp_seq(n, p, lam)
            val = cheap_score(cand)
            if val < best_val:
                best_a, best_val = cand, val

    # 4) Stretched exponential (several γ)
    for gamma in [0.5, 0.9, 1.2, 1.5, 2.0]:
        for lam in np.linspace(0.0, 4.0, 41):
            if time.time() >= deadline:
                break
            cand = _stretched_exponential_seq(n, lam, gamma)
            val = cheap_score(cand)
            if val < best_val:
                best_a, best_val = cand, val

    # 5) Beta‑shaped families – now also probing α,β < 0.2
    for alpha in np.concatenate([np.linspace(0.02, 0.18, 9), np.linspace(0.2, 8.0, 25)]):
        for beta in np.concatenate([np.linspace(0.02, 0.18, 9), np.linspace(0.2, 8.0, 25)]):
            if time.time() >= deadline:
                break
            seq = _beta_seq(n, alpha, beta)
            if seq is None:
                continue
            val = cheap_score(seq)
            if val < best_val:
                best_a, best_val = seq, val

    # 6) Edge‑power (mass near both ends)
    for p in np.linspace(0.5, 2.5, 21):
        if time.time() >= deadline:
            break
        cand = _edge_power_seq(n, p)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # 7) Symmetric exponential
    for lam in np.linspace(0.0, 4.0, 81):
        if time.time() >= deadline:
            break
        cand = _symmetric_exponential_seq(n, lam)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # 8) Inverse‑sqrt family
    cand = _inverse_sqrt_seq(n)
    val = cheap_score(cand)
    if val < best_val:
        best_a, best_val = cand, val

    # 9) Random Dirichlet seeds (very low concentration → spiky vectors)
    for conc in [0.001, 0.003, 0.005, 0.01, 0.02, 0.05, 0.1]:
        if time.time() >= deadline:
            break
        cand = _dirichlet_seq(n, conc)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # Additional random mixtures of power‑law and exponential
    for _ in range(200):
        if time.time() >= deadline:
            break
        p = np.random.uniform(0.05, 2.5)
        lam = np.random.exponential(scale=0.5)
        cand = _power_law_exp_seq(n, p, lam)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    print(f"[Phase 0] best cheap score = {best_val:.9f}")

    # --------------------------------------------------------------
    # Phase 1 – smooth mirror‑descent (soft‑max) refinement
    # --------------------------------------------------------------
    def _smooth_descent(start_vec: np.ndarray, max_iters: int):
        """Run Adam‑style mirror descent from `start_vec`."""
        a = start_vec.copy()
        eps = 1e-30
        log_a = np.log(a + eps)

        # Adam state
        m = np.zeros_like(a)
        v = np.zeros_like(a)
        beta1 = 0.9
        beta2 = 0.999
        eps_adam = 1e-8
        base_lr = 0.7

        # initial smoothing temperature – a fraction of the current max
        conv0 = _conv_full_fft(a, fft_len_conv)
        eps_temp = max(1e-7, 0.2 * conv0.max())

        best_local_a = a.copy()
        best_local_val = cheap_score(a)

        for it in range(1, max_iters + 1):
            if time.time() >= deadline - 2.0:
                break

            # ------- convolution a*a -------
            conv = _conv_full_fft(a, fft_len_conv)
            maxb = conv.max()

            # ------- soft‑max weights -------
            # stable soft‑max using the current maximum as offset
            offset = maxb
            exp_arg = (conv - offset) / eps_temp
            # avoid overflow / underflow
            exp_weights = np.exp(exp_arg)
            sum_exp = exp_weights.sum()
            w = exp_weights / sum_exp          # length 2n‑1, sums to 1

            # ------- gradient g = 2 * (w * a_rev) -------
            a_rev = a[::-1]
            wf = np.fft.rfft(w, fft_len_grad)
            ar = np.fft.rfft(a_rev, fft_len_grad)
            conv_rev = np.fft.irfft(wf * ar, fft_len_grad).real
            # slice the part that corresponds to g_j = 2 * sum_i w_i a_{i-j}
            g = 2.0 * conv_rev[n - 1 : n - 1 + n]

            # ------- Adam update on log‑space -------
            m = beta1 * m + (1.0 - beta1) * g
            v = beta2 * v + (1.0 - beta2) * (g * g)
            m_hat = m / (1.0 - beta1 ** it)
            v_hat = v / (1.0 - beta2 ** it)
            step = base_lr / (math.sqrt(it) * (np.sqrt(v_hat) + eps_adam))

            log_a -= step * m_hat
            a = np.exp(log_a)

            # ------- projection onto simplex -------
            a = _simplex_projection(a)

            # occasionally shrink the temperature
            if it % 500 == 0:
                eps_temp = max(1e-8, eps_temp * 0.95)

            # cheap objective for monitoring / best‑record
            cheap = cheap_score(a)
            if cheap < best_local_val - 1e-12:
                best_local_val = cheap
                best_local_a = a.copy()
                print(f"[Descent it {it:07d}] new best cheap = {cheap:.9f}")

        return best_local_a, best_local_val

    # Perform a few random restarts of the smooth descent
    best_seq = best_a.copy()
    best_val = cheap_score(best_seq)
    restarts = 3
    for r in range(restarts):
        if time.time() >= deadline - 5.0:
            break
        # start from a random Dirichlet seed blended with the current best
        init = _dirichlet_seq(n, np.random.uniform(0.001, 0.5))
        init = 0.3 * best_seq + 0.7 * init
        init = _simplex_projection(init)

        seq, val = _smooth_descent(init, max_iters=20000)
        if val < best_val:
            best_val = val
            best_seq = seq.copy()
            print(f"[Restart {r}] improved cheap to {val:.9f}")

    # --------------------------------------------------------------
    # Phase 2 – simple (1+1)‑ES hill‑climbing on the cheap objective
    # --------------------------------------------------------------
    sigma = 0.12
    fail_cnt = 0
    while time.time() < deadline - 2.0:
        cand = best_seq * np.exp(sigma * np.random.randn(n))
        cand = _simplex_projection(cand)
        cand_val = cheap_score(cand)
        if cand_val < best_val:
            best_val = cand_val
            best_seq = cand
            sigma = max(sigma * 0.85, 1e-5)
            fail_cnt = 0
            print(f"[ES] improved cheap = {cand_val:.9f} sigma={sigma:.6f}")
        else:
            fail_cnt += 1
            if fail_cnt > 250:
                sigma = min(sigma * 1.30, 0.6)
                fail_cnt = 0

    # --------------------------------------------------------------
    # Phase 3 – final exact evaluation
    # --------------------------------------------------------------
    final_seq = best_seq.tolist()
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"Final exact score = {final_score:.9f}")
    except Exception as exc:      # defensive – should never happen
        final_score = float("inf")
        print(f"Error during final evaluation: {exc}")

    return final_seq
```
