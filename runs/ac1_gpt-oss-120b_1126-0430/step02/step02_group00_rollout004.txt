Propose a non‑negative step‑function sequence that (approximately) minimises

    O(a) = 2·n·max(conv(a,a))   with   Σ a_i = 1  (i.e. a lies on the probability simplex).

Algorithm
---------
1. Initialise from a previous best sequence if available, otherwise from a uniform
   distribution on a modest size (≈4000).  All vectors are projected onto the simplex.

2. **Phase 1 – Adam on a smooth log‑sum‑exp surrogate**
   * Objective:  f_α(a) = (2·n/α)·log∑_k exp(α·conv_k) .
   * α is annealed linearly from 5 to 2000.
   * Gradient of f_α is obtained by a correlation of the soft‑max weights with a.
   * Adam (β₁=0.9, β₂=0.999) with a modest learning rate updates a,
     then a is projected back onto the simplex.
   * The exact objective O(a) is monitored and the best vector is stored.

3. **Phase 2 – deterministic sub‑gradient refinement**
   * Repeatedly takes a step opposite to the sub‑gradient of the true max‑convolution
     entry (the sum of two shifted copies of a).  Step size decays linearly.
   * Tiny Gaussian jitter is injected every 1000 iterations to avoid stagnation.

4. **Phase 3 – simulated‑annealing hill climbing**
   * Starting from the current best, repeatedly transfers a random fraction
     of mass from one index to another.
   * Moves are accepted if they improve O, otherwise with Metropolis probability
     exp(−ΔO/T).  Temperature T decays exponentially.
   * The global best is updated whenever an improvement is found.

5. Finally the found vector is evaluated with the provided `evaluate_sequence`
   (for sanity) and returned as a plain Python list.

The whole search respects the 1000 s budget; time limits for each phase are
derived from the remaining budget.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex {x ≥ 0, Σx = 1}
def _project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        # all non‑positive – return uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# FFT‑based full self‑convolution (length 2·n‑1)
def _conv_fft(a: np.ndarray, L: int) -> np.ndarray:
    """Return a*a (full convolution) using an FFT of length L."""
    fft_a = np.fft.rfft(a, n=L)
    conv_full = np.fft.irfft(fft_a * fft_a, n=L)
    return conv_full[: 2 * a.size - 1]


# ----------------------------------------------------------------------
# Exact objective for a simplex‑normalised vector
def _objective_simplex(a: np.ndarray, n: int, L: int) -> float:
    """2·n·max(conv(a,a)) – a is assumed to sum to 1."""
    conv = _conv_fft(a, L)
    return 2.0 * n * conv.max()


# ----------------------------------------------------------------------
# Sub‑gradient of the maximal convolution entry (used in Phase 2)
def _subgradient_max_conv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """Return the sub‑gradient of max(conv) w.r.t. a."""
    n = a.size
    max_val = conv.max()
    ks = np.flatnonzero(conv == max_val)          # indices achieving the maximum
    g = np.zeros_like(a)
    for k in ks:
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        i_idx = np.arange(i_start, i_end + 1, dtype=int)
        j_idx = k - i_idx
        g[i_idx] += 2.0 * a[j_idx]                # each pair contributes symmetrically
    g /= len(ks)                                   # average if several maximisers
    return g


# ----------------------------------------------------------------------
# Gradient of the smooth log‑sum‑exp surrogate
def _smooth_gradient(a: np.ndarray, conv: np.ndarray, alpha: float, L: int) -> np.ndarray:
    """
    Compute ∇_a ( (2·n/α)·log∑_k e^{α·conv_k} ).
    Result = 2·corr(w, a) where w_k ∝ e^{α·conv_k}.
    """
    # soft‑max weights (stable)
    scaled = alpha * conv
    max_scaled = np.max(scaled)
    exp_scaled = np.exp(scaled - max_scaled)
    w = exp_scaled / exp_scaled.sum()

    # correlation w ⋆ a   (g_i = 2·∑_j w_{i+j} a_j)
    a_rev = a[::-1]
    fft_w = np.fft.rfft(w, n=L)
    fft_a_rev = np.fft.rfft(a_rev, n=L)
    corr_rev = np.fft.irfft(fft_w * fft_a_rev, n=L)   # length ≥ 3·n‑2
    n = a.size
    grad = 2.0 * corr_rev[n - 1 : n - 1 + n]          # central n entries
    return grad
