   or from a uniform distribution.  The vector is normalised to the
   probability simplex ∑a_i = 1.

2. Phase A – Mirror‑Adam on a smooth log‑sum‑exp surrogate.
   * Parameterise a_i = softmax(v_i) (entropy‑mirror descent on the simplex).

         f_α(a) = (2·n/α)·log∑_k e^{α·(a*a)_k}
     whose gradient w.r.t. a is 2·corr(w,a) with
         w_k ∝ e^{α·(a*a)_k}.
   * Apply Adam on the logits v (the gradient is transformed by the
     soft‑max Jacobian).
   * α is increased linearly from 5 to 20000, so the surrogate gradually
     focuses on the true maximum.
   * Keep the best sequence seen (exact objective evaluated each iteration).

3. Phase B – Sub‑gradient descent + stochastic mass‑transfer hill climbing.
   * Starting from the best sequence of Phase A, repeatedly
       – take a sub‑gradient of the exact max‑convolution entry,
       – step along that direction with a linearly decaying step size,
       – project back onto the simplex.
   * Every few hundred iterations perform a random “mass‑transfer”
     move (move a fraction of probability mass from i to j) and accept
     it if it improves the exact objective (or with a tiny Metropolis
     probability to escape plateaux).

The whole search respects a 1000‑second wall‑clock budget, prints
progress, and finally returns the best sequence as a plain list of
floats.

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex {x ≥ 0, sum(x) = 1}
def _project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex."""
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:                     # all non‑positive -> uniform
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Full self‑convolution using FFT (returns length 2·n‑1)
def _conv_fft(a: np.ndarray, L: int) -> np.ndarray:
    """Return the full convolution a*a using an FFT of length L."""
    fft_a = np.fft.rfft(a, n=L)
    conv_full = np.fft.irfft(fft_a * fft_a, n=L)
    return conv_full[: 2 * a.size - 1]


# ----------------------------------------------------------------------
# Sub‑gradient of the maximal convolution entry (used in Phase B)
def _subgradient_max_conv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """Sub‑gradient of max(conv) w.r.t. a (average over all tying indices)."""
    n = a.size
    max_val = conv.max()
    ks = np.flatnonzero(conv == max_val)          # all maximising indices
    g = np.zeros_like(a)
    for k in ks:
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        i_idx = np.arange(i_start, i_end + 1, dtype=int)
        j_idx = k - i_idx
        g[i_idx] += 2.0 * a[j_idx]
    g /= len(ks)
    return g


# ----------------------------------------------------------------------
# Gradient of the smooth log‑sum‑exp surrogate
def _smooth_gradient(a: np.ndarray, conv: np.ndarray, alpha: float, L: int) -> np.ndarray:
    """
    Compute ∇_a ( (2·n/α)·log∑_k e^{α·conv_k} ).
    The result is 2·corr(w, a) where w_k ∝ e^{α·conv_k}.
    """
    # soft‑max weights
    scaled = alpha * conv
    max_scaled = np.max(scaled)
    exp_scaled = np.exp(scaled - max_scaled)     # stability shift
    w = exp_scaled / exp_scaled.sum()

    # correlation w ⋆ a  (g_i = 2·∑_j w_{i+j} a_j)
    a_rev = a[::-1]
    fft_w = np.fft.rfft(w, n=L)
    fft_a_rev = np.fft.rfft(a_rev, n=L)
    corr_rev = np.fft.irfft(fft_w * fft_a_rev, n=L)   # length >= 3·n‑2
    n = a.size
    grad = 2.0 * corr_rev[n - 1 : n - 1 + n]          # central n entries
    return grad
