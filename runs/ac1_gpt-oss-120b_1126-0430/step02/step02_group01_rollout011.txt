Propose a step‑function sequence that (approximately) minimizes

        O = 2·n·max(conv(a,a))   with  a_i ≥ 0 ,  Σ a_i = 1 .

The method is a projected Adam optimiser on a smooth approximation of the
max‑operator (soft‑max).  At each iteration we

1. compute the self‑convolution,
2. form a soft‑max weight vector w over the convolution entries,
3. obtain the gradient of O w.r.t. a (using a correlation a⋆w),
4. perform an Adam step and project back onto the probability simplex,
5. symmetrise the candidate (a ← (a+a[::-1])/2) – the optimal shape is
   known to be symmetric – and keep the best solution seen.

A simple random “mass‑transfer’’ move is tried every few hundred iterations

import time
import math
import numpy as np

def _normalize(v: np.ndarray) -> np.ndarray:
    """Project a non‑negative vector onto the simplex {x≥0, sum(x)=1}.
    For a non‑negative vector this is just scaling to unit sum."""
    s = v.sum()
    if s <= 0.0:
        # fallback: uniform distribution
        return np.full_like(v, 1.0 / v.size)
    return v / s

    """Exact objective O = 2·n·max(conv(a,a)) for a already normalised."""
    conv = np.convolve(a, a)
