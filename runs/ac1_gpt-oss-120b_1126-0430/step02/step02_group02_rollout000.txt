Let's write final code within triple backticks.assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

Because the ratio is *scale‑invariant* we can fix the simplex
\(\sum_i a_i = 1\).  
The problem is then

\[
\min_{a\in\Delta}\; 2n\;\max_k (a*a)[k],
\qquad 
\Delta=\{a\ge 0,\; \mathbf 1^{\!\top}a=1\}.
\]

A direct sub‑gradient on the single active index converges slowly.
We improve it in three ways

1. **Smooth approximation of the maximum**  
   Use the soft‑max  
   \[
   \phi_\alpha(a)=\frac1\alpha\log\!\Bigl(\sum_k e^{\alpha (a*a)[k]}\Bigr)
   \]
   ( α large  ≈  max ).  Its gradient is a weighted sum of the
   individual gradients and therefore contains more information
   than a single active constraint.

2. **Projected Adam optimisation**  
   The gradient of \(\phi_\alpha\) is computed analytically
   (cross‑correlation) and an Adam–style adaptive step is taken.
   After each step the iterate is projected back onto the probability
   simplex.

3. **Multi‑stage schedule**  
   * start with a moderate length (≈ 6000) and a good‐looking
     power‑law seed (or the previously discovered `height_sequence_1`);
   * increase the smoothing parameter α from 2 up to 200 while the
     optimisation proceeds;
   * sprinkle the run with tiny random perturbations to escape plateaus;
   * finally perform a cheap hill‑climbing phase that swaps tiny masses
     between two coordinates.

All heavy work (convolution, cross‑correlation) is performed with FFTs,
so each iteration costs only *O(n log n)* and thousands of iterations
fit comfortably into the 1000 s budget.

Below is a self‑contained implementation that follows the required
interface.  The function `propose_candidate` returns the best sequence
found within the time limit.  Progress is printed to stdout. 

```python
#!/usr/bin/env python
"""
Propose a non‑negative step‑function (list of heights) with a low
evaluation score.

Algorithm
---------
* Initialise a length‑n vector on the probability simplex.
  - If a previous construction ``height_sequence_1`` exists it is used
    (renormalised).
  - Otherwise a power‑law a_i ∝ (i+1)^{-p} is grid‑searched.
* minimise the smooth surrogate
        φ_α(a) = (1/α) log Σ_k exp(α·(a*a)[k])
  with projected Adam (simplex projection after each update).
  – α starts at 2 and is increased slowly up to 200.
  – Gradients are obtained by the identity
        ∇φ = 2·corr( w , a ) ,  w_k ∝ exp(α·conv_k).
* Occasionally add a tiny random jitter to the iterate.
* After the main loop, run a lightweight coordinate‑swap hill‑climber.
* Return the best sequence (exact evaluation performed once at the end).
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    { x >= 0 , Σ x = 1 }.
    """
    n = v.shape[0]
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are non‑positive → uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _power_law_sequence(n: int, p: float) -> np.ndarray:
    """Return a normalised power‑law vector a_i ∝ (i+1)^{-p}, Σa=1."""
    idx = np.arange(1, n + 1, dtype=np.float64)
    seq = idx ** (-p)
    seq /= seq.sum()
    return seq


def _convolution_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a using FFT (returns length 2·len(a)‑1)."""
    fa = np.fft.fft(a, fft_len)
    conv = np.fft.ifft(fa * fa).real
    return conv[: 2 * a.size - 1]


def _softmax_weights(conv: np.ndarray, alpha: float) -> np.ndarray:
    """
    Compute the (stable) soft‑max distribution over the convolution entries:
        w_k ∝ exp(alpha·conv_k).
    """
    if alpha <= 0.0:
        return np.full_like(conv, 1.0 / conv.size)
    cmax = conv.max()
    shifted = conv - cmax               # prevent overflow
    w_unnorm = np.exp(alpha * shifted)
    s = w_unnorm.sum()
    if s == 0.0:                        # numerical safety
        return np.full_like(conv, 1.0 / conv.size)
    return w_unnorm / s

        best_score = np.inf
        best_a = None

            a = a_new
```
