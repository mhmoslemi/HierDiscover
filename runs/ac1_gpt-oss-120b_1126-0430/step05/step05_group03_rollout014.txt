Linear decreasing step‑function (triangular) construction.

The sequence   a_i = 2·(n‑i) / (n·(n+1)),   i = 0 … n‑1

    max_k (a*a)[k] = (2·(n+2)) / (3·n·(n+1))

so that

    evaluate_sequence(a) = 2·n·max_k (a*a)[k] = 4·(n+2) / (3·(n+1))
                         → 4/3  as n → ∞.

For any reasonable length (e.g. n = 4000) the value is ≈ 1.333,

import time
import numpy as np

# ----------------------------------------------------------------------
def _linear_decreasing_sequence(n: int) -> list[float]:
    """
    Return a length‑n list implementing a_i = 2·(n‑i) / (n·(n+1)).
    The vector is already normalised to sum = 1 and contains only
    non‑negative entries.
    """
    # Using float64 arithmetic – the values are well‑behaved for the
    # required size (n up to a few ten‑thousands).
    idx = np.arange(n, dtype=np.float64)          # 0 … n‑1
    a = 2.0 * (n - idx) / (n * (n + 1))
    # Small numerical noise may make the sum deviate from exactly 1;
    # renormalise to guarantee the denominator in evaluate_sequence
    # is correct.
    a /= a.sum()
    return a.tolist()
