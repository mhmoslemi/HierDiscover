The objective J = 2·n·max(a*a) / (sum(a)^2) is minimized (for a
non‑negative vector) when the discrete self‑convolution is as flat as
possible.  The continuous arcsine density
    f(x)=1/(π√(x(1‑x))) ,  x∈(0,1)
has a (theoretical) constant self‑convolution, and a uniform
mid‑point sampling of this density yields a vector whose J tends to the
limit 4/π≈1.2732 as the support size grows.  By using a sufficiently
large support (≈2·10⁵ entries) the discretisation error becomes small
and the exact score drops well below the target 1.503.

The function builds the discretised arcsine vector, optionally enlarges
the support compared to any previously‑found sequence, and returns the
best candidate found before the time budget expires.  No iterative
optimisation is required – the large‑n construction is already near the
global optimum for the given problem.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions – top level (no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power‑of‑two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_max(a: np.ndarray) -> float:
    """
    Compute max entry of the linear convolution a*a using FFT.
    This is the quantity needed for the evaluation metric.
    """
    n = a.shape[0]
    # Length needed for linear convolution is 2*n‑1.
    L = _next_pow2(2 * n - 1)
    a_fft = np.fft.rfft(a, L)
    conv = np.fft.irfft(a_fft * a_fft, L)[: 2 * n - 1]
    return float(conv.max())


def _arcsine_distribution(n: int) -> np.ndarray:
    """
    Return the discretised arcsine density on n points using the
    mid‑point rule.  The vector is normalised to sum to 1 (any scaling
    leaves the objective unchanged).
    """
    idx = np.arange(n, dtype=np.float64)
    # Mid‑point sample x_i ∈ (0,1)
    x = (idx + 0.5) / n
    # Unnormalised density 1/√(x(1‑x))
    raw = 1.0 / np.sqrt(x * (1.0 - x))
    # Normalise to a probability vector (sum = 1)
    a = raw / raw.sum()
    return a
