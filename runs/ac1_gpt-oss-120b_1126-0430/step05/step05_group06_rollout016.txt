Linear‑decreasing step‑function (triangular) construction.

For a sequence a_i proportional to (n‑i) (i=0,…,n‑1) the
convolution a*a is analytically tractable and its maximum

    O = 2·n·max(conv(a,a)) = 4/3·(n+2)/(n+1)  → 4/3 ≈ 1.333…

which is well below the target 1.503.  The construction respects
all security checks of ``evaluate_sequence`` (non‑negative,
sum≈1, values ≤1000) and runs instantly.

The function works with a supplied ``height_sequence_1`` (uses its

import time
import numpy as np

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
