assistantfinal**Solution Overview**

The goal is to find a non‑negative vector `a` (the heights of a step function) that minimises  

\[
F(a)=\frac{2\,n\; \max_k (a*a)[k]}{(\sum_i a_i)^2},
\]

where `(a*a)` is the full linear convolution of `a` with itself.  
Since the denominator is homogeneous, we may fix `∑a_i = 1`.  
For a fixed length `n` the problem reduces to minimising the maximum entry of the
convolution.

The implementation follows three stages

1. **Exploratory initialization** – a cheap scan over several parametric families
   (exponential, power‑law, beta, truncated Gaussian, random Dirichlet) for a
   relatively large `n` (up to 25 000).  
   The best candidate of this stage is kept as the starting point.

2. **Smooth‑max mirror descent** – instead of the sub‑gradient of a single
   peak we use a **soft‑max** weighting  
   \[
   w_k = \frac{\exp(\beta\,c_k)}{\sum_\ell \exp(\beta\,c_\ell)},
   \qquad c = a*a .
   \]
   The gradient of the weighted sum is computed analytically via two FFT‑based
   convolutions, and the update is performed in the log‑space (exponentiated
   gradient) with projection onto the probability simplex.  
   The temperature `β` is increased gradually (continuation method) so the
   optimisation first follows a smooth landscape and finally focuses on the
   true maximum.

3. **Restarts & final evaluation** – if no improvement is observed for a
   while the current iterate is perturbed and re‑projected onto the simplex.
   The best vector ever seen is finally evaluated with the provided
   `evaluate_sequence` and returned.

All heavy work is done with FFT‑based convolutions (`O(n log n)`) and the
algorithm respects the 1000 s time budget.

```python
#!/usr/bin/env python
"""
Propose a non‑negative step function (list of heights) that minimises

        2·n·max_k (a*a)[k] / (Σ a_i)²

The algorithm works in three phases:

*  exhaustive search over several parametric families (exponential,
   power‑law, beta, truncated Gaussian, random Dirichlet) for a large
   length `n` (up to 25 000);
*  a smooth‑max mirror‑descent (exponentiated‑gradient) optimisation that
   directly follows the gradient of a soft‑max of the convolution;
   the temperature `β` is increased during the run (continuation);
*  occasional random restarts when progress stalls and a final exact call
   to ``evaluate_sequence``.

All convolutions are performed with FFTs, the iterate is kept on the
probability simplex (Σ a_i = 1) and the routine always returns a feasible
sequence before the time budget expires.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – top level (no closures)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x ≥ 0, Σ x = 1}.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:                 # all entries non‑positive → uniform
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _fft_convolve(a: np.ndarray, b: np.ndarray, length: int) -> np.ndarray:
    """
    Linear convolution a*b using real FFT.
    Returns the first (len(a)+len(b)-1) coefficients.
    """
    fa = np.fft.rfft(a, length)
    fb = np.fft.rfft(b, length)
    conv = np.fft.irfft(fa * fb, length)
    keep = len(a) + len(b) - 1
    return conv[:keep]


def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Full convolution a*a (length 2·n‑1) using the pre‑computed FFT length."""
    return _fft_convolve(a, a, fft_len)


def _conv_max(a: np.ndarray, fft_len: int) -> float:
    """Maximum entry of a*a (assumes Σ a_i = 1)."""
    conv = _conv_self(a, fft_len)
    return float(conv.max())


def _power_law_sequence(n: int, p: float) -> np.ndarray:
    """a_i ∝ (i+1)^{-p}, normalised to sum 1."""
    i = np.arange(1, n + 1, dtype=np.float64)
    seq = i ** (-p)
    seq /= seq.sum()
    return seq


def _smooth_max_and_grad(a: np.ndarray,
                         fft_len_self: int,
                         fft_len_cross: int,
                         beta: float):
    """
    Returns (M, g) where
      M = max_k (a*a)[k]
      g = gradient of  Σ_k w_k·(a*a)[k] with
          w_k ∝ exp(beta·(a*a)[k])   (soft‑max weights).

    The gradient is
        g_i = 2 * Σ_j w_{i+j} a_j  –  w_{2i}·a_i .
    Both convolutions are performed with FFTs.
    """
    # 1) self‑convolution and soft‑max weights
    conv = _conv_self(a, fft_len_self)          # length 2n‑1
    M = conv.max()
    # stable soft‑max
    exp_term = np.exp(beta * (conv - M))
    w = exp_term / exp_term.sum()               # length 2n‑1, Σ w = 1

    # 2) cross‑convolution w * a_rev  →  Σ_j w_{i+j} a_j
    a_rev = a[::-1]
    cross = _fft_convolve(w, a_rev, fft_len_cross)   # length 3n‑2
    n = a.shape[0]
    S = cross[n - 1: n - 1 + n]                       # S_i = Σ_j w_{i+j} a_j

    # 3) diagonal part (i=j) uses only one product
    diag = w[2 * np.arange(n)]

    # gradient
    g = 2.0 * S - diag * a
    return M, g


# ----------------------------------------------------------------------
# Main entry point required by the platform
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function (list of non‑negative heights) that
    minimises ``evaluate_sequence``.  The routine adapts its schedule to
    the available time budget and always returns a feasible sequence.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0            # safety margin

    # --------------------------------------------------------------
    # Choose a working length (5 k ≤ n ≤ 25 k)
    # --------------------------------------------------------------
    try:
        prev = height_sequence_1                      # provided globally
        n0 = len(prev)
    except Exception:
        prev = None
        n0 = 0

    # Prefer a fairly large n – more degrees of freedom improve the bound
    n = max(5000, min(25000, max(n0, 15000)))
    print(f"[Info] Working length n = {n}")

    # FFT lengths used throughout the search
    fft_len_self = 1 << ((2 * n - 1).bit_length())          # for a*a
    fft_len_cross = 1 << ((3 * n - 2).bit_length())         # for w * a_rev

    # --------------------------------------------------------------
    # Cheap objective (assumes Σa = 1): 2·n·max(a*a)
    # --------------------------------------------------------------
    def cheap_score(vec: np.ndarray) -> float:
        """2·n·max_k (vec*vec)[k]   (vec is already normalised)."""
        return 2.0 * n * _conv_max(vec, fft_len_self)

    # --------------------------------------------------------------
    # 0. Initialise with cheap parametric families
    # --------------------------------------------------------------
    best_a = np.full(n, 1.0 / n, dtype=np.float64)   # uniform baseline
    best_val = cheap_score(best_a)

    # previous construction (padded / normalised) as a candidate
    if prev is not None and n0 > 0:
        tmp = np.zeros(n, dtype=np.float64)
        tmp[:n0] = np.asarray(prev, dtype=np.float64)
        s = tmp.sum()
        if s > 0:
            tmp /= s
            val = cheap_score(tmp)
            if val < best_val:
                best_a, best_val = tmp.copy(), val

    # ----- power‑law sweep -------------------------------------------------
    for p in np.linspace(0.2, 3.0, 31):
        if time.time() >= deadline:
            break
        cand = _power_law_sequence(n, p)
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # ----- exponential sweep ----------------------------------------------
    for lam in np.linspace(0.0, 5.0, 51):
        if time.time() >= deadline:
            break
        cand = np.exp(-lam * np.arange(n, dtype=np.float64))
        cand /= cand.sum()
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # ----- power‑law × exponential -----------------------------------------
    for p in np.linspace(0.3, 2.0, 19):
        for lam in np.linspace(0.0, 3.0, 19):
            if time.time() >= deadline:
                break
            idx = np.arange(n, dtype=np.float64)
            cand = (idx + 1.0) ** (-p) * np.exp(-lam * idx)
            cand /= cand.sum()
            val = cheap_score(cand)
            if val < best_val:
                best_a, best_val = cand, val

    # ----- beta‑shaped families --------------------------------------------
    x = (np.arange(1, n + 1, dtype=np.float64) / n)
    for alpha in np.linspace(0.2, 5.0, 21):
        for beta in np.linspace(0.2, 5.0, 21):
            if time.time() >= deadline:
                break
            cand = (x ** alpha) * ((1.0 - x) ** beta)
            s = cand.sum()
            if s == 0.0:
                continue
            cand /= s
            val = cheap_score(cand)
            if val < best_val:
                best_a, best_val = cand, val

    # ----- truncated Gaussian -----------------------------------------------
    mu = (n - 1) / 2.0
    for sigma in np.linspace(n / 12.0, n / 2.0, 7):
        if time.time() >= deadline:
            break
        idx = np.arange(n, dtype=np.float64)
        cand = np.exp(-0.5 * ((idx - mu) / sigma) ** 2)
        s = cand.sum()
        if s == 0.0:
            continue
        cand /= s
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    # ----- random Dirichlet seeds -------------------------------------------
    for conc in [0.001, 0.01, 0.05, 0.1, 0.3, 0.7, 1.5]:
        if time.time() >= deadline:
            break
        g = np.random.gamma(conc, 1.0, size=n)
        cand = g / g.sum()
        val = cheap_score(cand)
        if val < best_val:
            best_a, best_val = cand, val

    print(f"[Init] best cheap score = {best_val:.6f}")

    # --------------------------------------------------------------
    # 1. Refine with smooth‑max mirror descent (exponentiated gradient)
    # --------------------------------------------------------------
    a = best_a.copy()
    best_iter_a = a.copy()
    best_iter_val = best_val
    last_improve = 0
    iter_cnt = 0

    # hyper‑parameters
    eta0 = 1.0                # initial step‑size factor
    beta = 1.0                # initial temperature for soft‑max
    beta_max = 64.0
    beta_inc = 1.05           # geometric increase every 500 iters
    stagnation_limit = 2000  # restart after this many non‑improving iters
    max_iters = 200_000

    while time.time() < deadline and iter_cnt < max_iters:
        iter_cnt += 1

        # ----- convolution, soft‑max weights and gradient -----
        M, g = _smooth_max_and_grad(a, fft_len_self, fft_len_cross, beta)
        cheap = 2.0 * n * M

        # ----- keep the best ever seen -----
        if cheap < best_iter_val - 1e-12:
            best_iter_val = cheap
            best_iter_a = a.copy()
            last_improve = iter_cnt
            print(f"[Iter {iter_cnt:07d}] NEW BEST cheap = {cheap:.6f}")

        # ----- mirror‑descent (exponentiated‑gradient) step -----
        eta = eta0 / math.sqrt(iter_cnt + 1.0)
        log_a = np.log(a + 1e-30) - eta * g
        a = np.exp(log_a)
        s = a.sum()
        if s == 0.0 or not np.isfinite(s):
            a = best_iter_a.copy()
            continue
        a /= s

        # ----- temperature schedule -----
        if iter_cnt % 500 == 0:
            beta = min(beta * beta_inc, beta_max)

        # ----- occasional restart when stuck -----
        if iter_cnt - last_improve > stagnation_limit:
            perturb = 0.02 * np.random.rand(n)
            a = _simplex_projection(best_iter_a + perturb)
            last_improve = iter_cnt
            print(f"[Iter {iter_cnt:07d}] Restart after stagnation.")

    # --------------------------------------------------------------
    # 2. Final exact evaluation (uses the provided ``evaluate_sequence``)
    # --------------------------------------------------------------
    final_seq = best_iter_a.tolist()
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"Final exact score = {final_score:.6f}")
    except Exception as exc:      # defensive – should never happen
        final_score = float("inf")
        print(f"Error during final evaluation: {exc}")

    # --------------------------------------------------------------
    # 3. Return the best sequence found (the one with the smallest exact score)
    # --------------------------------------------------------------
    # The exact score equals 2·n·max(conv) because our vectors are normalised.
    # If by any chance the final exact evaluation was worse than the best
    # cheap score seen during the run, we fall back to that best iterate.
    if final_score < best_iter_val:
        return final_seq
    else:
        return best_iter_a.tolist()
```
