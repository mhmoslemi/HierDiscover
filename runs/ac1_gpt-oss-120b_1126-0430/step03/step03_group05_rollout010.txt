The objective  

\[
E(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2}
\]

is scale‑invariant, therefore we may restrict the search to the simplex  
\(\sum_i a_i=1,\;a_i\ge 0\).  On this simplex the cheap proxy  

\[
\tilde E(a)=2\,n\;\max_k (a*a)[k]
\]

is sufficient for ranking candidates – the exact value is obtained only at
the end by calling the provided `evaluate_sequence`.

The program consists of three phases  

1. **Broad power‑law scan** – a dense grid of exponents yields a very
   good starting point (the previous best values lie in the range
   \(p\in[0.55,0.68]\); we scan a wider interval).
2. **Smoothed gradient descent** – we replace the non‑smooth `max`
   by a soft‑max  
   \[
   \operatorname{SM}_\lambda(b)=\frac{1}{\lambda}
   \log\!\Bigl(\sum_k e^{\lambda b_k}\Bigr)
   \]
   (with \(b=a*a\)).  
   Its gradient is a weighted correlation of `a` with the soft‑max
   weights and can be computed by a single pair of FFTs.
   An Adam optimiser (moment‑based, adaptive step size) follows the
   gradient while the iterate is projected onto the probability simplex.
   The smoothing parameter \(\lambda\) is increased linearly, so the
   optimisation first sees a smooth landscape and then concentrates on
   the true maximum.
3. **Sub‑gradient refinement** – once \(\lambda\) is large the soft‑max
   behaves like a true max.  From then on we switch to the cheap
   sub‑gradient (the active shift of the convolution) exactly as in the
   reference implementation, but we keep the Adam‑style adaptive step
   size.

Stagnation is avoided by occasional random perturbations of the current
best vector and by restarting the Adam moments.

All heavy work (convolution, correlation) is performed with FFTs of a
single length `L = 2^⌈log2(3n‑2)⌉`, which is sufficient for both the
convolution (`2n‑1`) and the correlation (`3n‑2`).  With `n≈15000` we
use `L=65536`, which fits comfortably in memory and is fast enough to
perform several hundred thousand iterations within the 1000 s budget.

The final candidate (the best iterate seen during the run) is returned
as a plain Python list, ready for `evaluate_sequence`.

#!/usr/bin/env python
"""
Optimisation of a non‑negative step‑function for

    2·n·max_k (a * a)[k] / (Σ a_i)²   (scale‑invariant)

Algorithm
---------
* Choose a moderate length (≈15 000).  Larger n improves the asymptotic
  bound while remaining fast for O(n log n) FFT based convolutions.
* Initialise with a normalised power‑law a_i ∝ (i+1)^‑p.
  The exponent p is scanned on a dense grid (0.30 … 0.90).
* **Smoothed Adam stage**  
  – Replace the hard max by a soft‑max with parameter λ, increasing λ
    from 0.5 to 8.0 during the first part of the run.  
  – The gradient of the smooth max is a weighted correlation
    a ⋆ w, where w is the soft‑max weight vector.  
  – Both the convolution a*a (needed for the cheap score) and the
    correlation are obtained with a single FFT size L ≥ 3·n.
  – Adam’s adaptive step‑size (β₁=0.9, β₂=0.999) together with a
    projection onto the probability simplex keeps the iterate feasible.
* **Sub‑gradient refinement**  
  – After λ has become large we switch to the exact sub‑gradient
    g_i = 2·a_{k*‑i} (k* = argmax (a*a)[k]), which is O(n).  
  – Adam’s moments are kept, giving a smoother descent than the
    heavy‑ball method of the reference code.
* Random perturbations are applied if no improvement is seen for a long
  period, to escape plateaus.
* The best iterate (according to the cheap proxy 2·n·max_conv) is finally
  evaluated with ``evaluate_sequence`` and returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (must stay at top level)
# ----------------------------------------------------------------------


def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the probability simplex (sum=1, non‑negative)."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.nonzero(u - cssv / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _power_law_sequence(n: int, p: float) -> np.ndarray:
    """Return a normalised power‑law vector a_i ∝ (i+1)^‑p (Σa_i = 1)."""
    i = np.arange(1, n + 1, dtype=np.float64)
    seq = i ** (-p)
    seq /= seq.sum()
    return seq


def _subgradient_max_convolution(a: np.ndarray, max_idx: int) -> np.ndarray:
    """
    Exact sub‑gradient of max_k (a*a)[k] at the active offset ``max_idx``.
    For the active shift k we have (∂/∂a_i) (a*a)[k] = 2·a_{k‑i}
    whenever the index is valid.
    """
    n = a.shape[0]
    lo = max(0, max_idx - (n - 1))
    hi = min(max_idx, n - 1)
    idx = np.arange(lo, hi + 1, dtype=np.int64)
    g = np.zeros_like(a)
    g[idx] = 2.0 * a[max_idx - idx]
    return g

# Core optimisation routine
# ----------------------------------------------------------------------

    ``evaluate_sequence``.  The routine respects the given time budget.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a safety margin for final evaluation and printing
    deadline = start_time + budget_s - 5.0

    # ------------------------------------------------------------------
    # 0. Choose a working length.
    #    Prefer the length of the previous best construction if available,
    #    but enforce a minimum of 5000.
    # ------------------------------------------------------------------
    try:
        prev = height_sequence_1               # type: ignore[name-defined]
        n = max(len(prev), 5000)
        prev_arr = np.asarray(prev, dtype=np.float64)
        if prev_arr.sum() == 0:
            prev_arr = None
        else:
            prev_arr = prev_arr / prev_arr.sum()
    except Exception:
        prev_arr = None
        n = 15000

    print(f"[Init] Working length n = {n}")

    # FFT size large enough for both convolution (2n‑1) and correlation (3n‑2)
    L = 1 << ((3 * n - 2).bit_length())
    print(f"[Init] FFT size L = {L}")

    # ------------------------------------------------------------------
    # 1. Scan a dense grid of power‑law exponents to obtain a good start.
    # ------------------------------------------------------------------
    p_grid = np.linspace(0.30, 0.90, 121)   # 0.30 … 0.90 in steps of 0.005
    best_a = None
    best_score = float("inf")
    best_p = None

    for p in p_grid:

        a = _power_law_sequence(n, p)
        # cheap max convolution (full) using FFT
        Fa = np.fft.fft(a, L)

        maxb = conv_full.max()
        cheap_score = 2.0 * n * maxb
        if cheap_score < best_score:
            best_score = cheap_score
            best_a = a.copy()
            best_p = p

            best_a = prev_arr.copy()
            best_p = "prev"

    # fallback – should never happen
    if best_a is None:

        maxb = conv_full.max()
        best_score = 2.0 * n * maxb
        best_p = 0.55

    print(f"[Init] Power‑law scan finished: best p = {best_p}, cheap score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2. Smoothed Adam optimisation followed by sub‑gradient refinement.
    # ------------------------------------------------------------------
    a = best_a.copy()                # current iterate (always Σa = 1)
    best_iter_a = a.copy()
    best_iter_score = best_score

    # Adam parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    # schedule for the soft‑max parameter λ
    lambda_start = 0.5
    lambda_end = 8.0
    smoothing_iters = 25000               # number of iterations spent in the smooth phase
    max_iters = 300000                    # absolute hard limit
    iter_cnt = 0
    last_improve = 0

    beta1_pow = 1.0
    beta2_pow = 1.0

    # ------------------------------------------------------------------
    while time.time() < deadline and iter_cnt < max_iters:
        iter_cnt += 1

        # ---------- convolution (full) ----------
        Fa = np.fft.fft(a, L)
        conv_full = np.fft.ifft(Fa * Fa).real[: 2 * n - 1]
        maxb = conv_full.max()
        cheap_score = 2.0 * n * maxb

        # keep track of the best cheap score
        if cheap_score < best_iter_score:
            best_iter_score = cheap_score
            best_iter_a = a.copy()
            last_improve = iter_cnt
            print(f"[Iter {iter_cnt:07d}] NEW BEST cheap score = {cheap_score:.6f}")

        # ---------- gradient computation ----------
        if iter_cnt <= smoothing_iters:
            # ----- smooth max (soft‑max) -----
            lam = lambda_start + (lambda_end - lambda_start) * (iter_cnt - 1) / max(1, smoothing_iters - 1)
            # stable soft‑max
            shifted = conv_full - maxb                     # maxb is the true max, ensures numerical stability
            exp_weights = np.exp(lam * shifted)
            w = exp_weights / exp_weights.sum()           # shape (2n‑1)

            # ----- correlation a ⋆ w (gradient) -----
            W = np.fft.fft(w, L)

            # linear correlation index range: 0 … L‑1,

            start = 2 * n - 2

        else:

            max_idx = int(conv_full.argmax())
            grad = _subgradient_max_convolution(a, max_idx)

        beta1_pow *= beta1
        beta2_pow *= beta2

            a = _simplex_projection(best_iter_a + noise)
            m.fill(0.0)
            v.fill(0.0)
            beta1_pow = 1.0
            beta2_pow = 1.0
            last_improve = iter_cnt
            print(f"[Iter {iter_cnt:07d}] Restart after stagnation (perturb).")

    # ------------------------------------------------------------------
    # 3. Final exact evaluation (the platform will call evaluate_sequence)
    # ------------------------------------------------------------------
    final_seq = best_iter_a.tolist()

        print(f"[Result] Error during final evaluation: {exc}")

    # ------------------------------------------------------------------
    # 4. Return the best sequence found.
    # ------------------------------------------------------------------
    return final_seq
