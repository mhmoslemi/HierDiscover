The function `propose_candidate` searches for a non‑negative step‑function that minimizes  

\[
O(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}\!,
\]

where `a*a` is the full linear convolution of the coefficient vector `a`.  
The algorithm consists of three stages:

1. **Two‑phase projected gradient descent**  
   * Phase 1 (≈ 60 % of the budget) uses a *soft‑max* approximation of the
     max‑operator.  The smoothing factor β grows from a small value up to a
     large one, so the gradient initially follows a smooth landscape and later
     focuses on the true maximum.  
   * Phase 2 switches to the exact sub‑gradient (indicator of the active
     convolution entries).  

   Both phases keep the iterate on the probability simplex
   (\(a_i\ge0,\ \sum a_i=1\)) by a Euclidean projection.  
   Momentum (exponential moving average of the gradient) and a slowly
   decreasing step size improve stability.

2. **Periodic random restarts** – if no improvement is observed for a long
   stretch we re‑initialise the current iterate from the best solution found
   so far and add a tiny random perturbation.

3. **Greedy local refinement** – after the main loop a cheap hill‑climbing
   routine repeatedly moves a small amount of mass from one index to another.
   Each trial is accepted only if it strictly improves the exact objective.
   This stage typically squeezes a few extra percent points out of the bound.

All heavy work (convolution and correlation) is performed with FFTs
(`numpy.fft.rfft` / `irfft`) which gives an \(O(n\log n)\) per iteration
runtime. The code respects the 1000 s budget, prints progress, and finally
returns the best sequence found (as a plain `list[float]`).  If a previous
solution `height_sequence_1` is available it is used as a warm start;
otherwise a random Dirichlet vector is generated.

"""
Two‑phase projected gradient descent with momentum,
followed by greedy local refinement, for minimizing the
bound  O = 2·n·max(conv(a,a)) / (sum(a)^2)  under a_i ≥ 0, sum(a)=1.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
#  Helper functions (no closures, no lambdas)
# ----------------------------------------------------------------------


def _project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:                     # all entries non‑positive
        return np.full_like(v, 1.0 / n)
    rho = rho[-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_self_fft(a: np.ndarray) -> np.ndarray:
    """Full linear self‑convolution a*a using a real FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(af * af, n=L)[: 2 * n - 1]
    return conv


def _correlation_fft(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Linear correlation g_i = Σ_t w[i+t]·a[t]   (i = 0 … n‑1).
    Implemented via FFT (real‑valued).
    """
    n = a.shape[0]
    m = w.shape[0]                          # = 2n‑1
    L = _next_pow2(m + n - 1)
    wf = np.fft.rfft(w, n=L)
    af = np.fft.rfft(a, n=L)
    corr_full = np.fft.irfft(wf * np.conj(af), n=L)
    return corr_full[:n]


def _objective(a: np.ndarray) -> float:
    """Exact objective value  O = 2·n·max(conv(a,a))  (sum(a)=1)."""
    n = a.size
    conv = _conv_self_fft(a)
    return 2.0 * n * conv.max()


def _softmax_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """Soft‑max weights w_k ∝ exp(β·(conv_k−max(conv)))."""
    M = conv.max()
    shifted = conv - M                     # ≤ 0, max is 0
    # exponentials are safe because the largest exponent is 0
    exp_vals = np.exp(beta * shifted)
    w = exp_vals / exp_vals.sum()
    return w


def _max_weights(conv: np.ndarray, tol: float = 1e-12) -> np.ndarray:
    """Exact sub‑gradient weights: uniform on the active set."""
    M = conv.max()
    active = np.where(conv >= M - tol)[0]
    w = np.zeros_like(conv)
    if active.size > 0:
        w[active] = 1.0 / active.size
    return w

#  Main search routine
# ----------------------------------------------------------------------

    Search for a non‑negative step‑function that minimises the bound.
    Returns the best sequence as a plain list of floats.
    """

    deadline = time.time() + budget_s - 0.5   # safety margin

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------

        max_iters = 180_000                # rough upper bound; real loop limited by time

        while time.time() < deadline:
