"""
Propose a low‑value sequence for `evaluate_sequence`.

The evaluation function is
    score = 2 * n * max(conv(a,a)) / (sum(a)**2)

which is invariant under scaling of the whole sequence.
For a continuous model, the function a(x)=x^{-p} (0<p<1) gives
    max(conv) ≈ B(1-p,1-p)·n^{1-2p},
    sum(a)  ≈ n^{1-p}/(1-p).

Thus the asymptotic score is
    score(p) = 2·(1-p)^2·B(1-p,1-p)      (p = exponent).

The minimum of this expression occurs around p≈0.6, which yields a
theoretical score ≈1.35 < 1.503.  A discrete analogue is

    a_i = (i+1)^{-p} ,   i = 0 … n‑1

with p≈0.6.

The algorithm:
  1. Choose a reasonable length (≈5400, similar to the previous best).
  2. Scan a small range of exponents (0.5 … 0.8) and keep the best
     sequence according to `evaluate_sequence`.
  3   – (optional) –  Perform a very cheap hill‑climbing phase:
        repeatedly move a small fraction of mass from a
        “high‑contributing’’ index to a random other index.
        Accept only improvements, keeping the best ever found.
  3. Return the best sequence.

All operations respect the security checks of `evaluate_sequence`
(non‑negative numbers, sum ≥ 0.01, values ≤ 1000).

The total running time stays well below the 1000 s budget.
"""

        step_fraction = 0.05

        # Simple hill‑climbing loop – stop when time runs out.
        while time.time() < deadline:
            # Choose two distinct indices.
            i = random.randrange(n)
            j = random.randrange(n - 1)
            if j >= i:
                j += 1

            # Transfer a small amount from i to j.
            delta = cur_seq[i] * step_fraction
            if delta <= 0.0:
                continue

            new_seq = cur_seq[:]
            new_seq[i] -= delta
            new_seq[j] += delta

            # Clamp to non‑negative (should already hold) and renormalise.
            # Renormalisation keeps the sum exactly 1, preserving scale‑invariance.
            new_seq = [max(0.0, x) for x in new_seq]
            total = sum(new_seq)
            if total < 1e-12:          # degenerate – skip
                continue
            new_seq = [x / total for x in new_seq]

            new_score = _conv_score(new_seq)

            # Accept only genuine improvements.
            if new_score < cur_score:
                cur_seq = new_seq
                cur_score = new_score
                if new_score < best_score:
                    best_score = new_score
                    best_seq = new_seq[:]
                    print(f"[hill] improved to {best_score:.6f}")

            # Occasionally inject a tiny random perturbation to escape plateaus.
            if random.random() < 0.001:
                pert = [max(0.0, x + random.gauss(0, 1e-3)) for x in cur_seq]
                total = sum(pert)
                if total > 0:
                    pert = [x / total for x in pert]
                    pert_score = _conv_score(pert)
                    if pert_score < cur_score:
                        cur_seq = pert
                        cur_score = pert_score
                        if pert_score < best_score:
                            best_score = pert_score
                            best_seq = pert[:]
                            print(f"[pert] improved to {best_score:.6f}")

    print(f"Best score found: {best_score:.6f}")
    return best_seq
