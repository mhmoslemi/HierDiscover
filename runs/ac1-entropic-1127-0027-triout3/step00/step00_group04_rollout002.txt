"""
propose_candidate – return the mathematically optimal uniform step function.

The objective that we have to minimise is

    E(a) = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where n = len(a) and conv is the discrete convolution.
For any non‑negative vector a we have

    max(conv(a, a)) ≥ conv(a, a)[0] = Σ a_i²
    Σ a_i² ≥ (Σ a_i)² / n                      (Cauchy–Schwarz)

Consequently

    E(a) ≥ 2 * n * (Σ a_i²) / (Σ a_i)² ≥ 2

with equality if and only if all entries of a are equal.
Thus the smallest achievable value of the evaluation function is exactly 2,
and it is attained by any uniform sequence.

The function below therefore builds a uniform sequence (the constant can be
chosen arbitrarily – we use 1.0).  If the global variable `height_sequence_1`
is present we keep its length; otherwise a default length of 1000 is used.
The candidate is returned together with a brief log of its score.
"""

import time

def _uniform_sequence(length: int, value: float = 1.0) -> list[float]:
    """Create a list of `length` entries, all equal to `value`."""
    return [float(value)] * length
