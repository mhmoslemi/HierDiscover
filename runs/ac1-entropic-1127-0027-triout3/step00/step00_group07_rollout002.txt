The objective  

\[
E(a)=\frac{2\,n\;\max\_{k}(a*a)\_k}{\bigl(\sum\_{i} a_i\bigr)^2},
\qquad a_i\ge 0
\]

is the ratio of the largest convolution entry to the squared sum.
If all heights are equal (`a_i=c`) the convolution is a triangle,
`max(a*a)=c²·n` and the ratio equals `2`.  
To beat this value we need a shape whose *pairwise* products are much
smaller than the total sum.

A **geometric (exponential) decay**  

\[
a_i = r^{\,i},\qquad 0<r<1,
\]

has exactly this property:

* the sum is a simple geometric series  

  \[
  S=\sum_{i=0}^{n-1}r^i =\frac{1-r^{\,n}}{1-r},
  \]

* the convolution value at shift `k` is  

  \[
  (a*a)_k = r^{\,k}\cdot\min(k+1,2n-1-k).
  \]

The maximum of the convolution is either at the ends (`k=0`) giving
`1` or in the centre (`k=n-1`) giving `n·r^{\,n-1}`.
Choosing `r` so that the centre value does **not** exceed `1`
makes the overall maximum exactly `1`.

Let  

\[
\varepsilon = 1-r,\qquad t = \varepsilon n .
\]

The condition `n·r^{n-1} ≤ 1` is equivalent to  

\[
t \;\ge\; \ln n .
\]

Taking the smallest possible `t` (i.e. `t = \ln n`) yields the smallest
possible `\varepsilon` and therefore the largest possible sum.
The resulting bound is

\[
E = \frac{2n}{S^{2}} \;=\; 2n\varepsilon^{2}
     \;\approx\;\frac{2(\ln n)^{2}}{n},
\]

which decays like `1/n`.  
For `n = 10 000` we obtain

```
E ≈ 2·(ln 10000)² / 10000  ≈ 0.017 .
```

Thus a plain geometric sequence of moderate length already beats the
target `1.503` by an order of magnitude, without any iterative search.

* selects a length `n` (up to 10 000 – still very fast to evaluate),
* sets `ε = 1.1·ln(n)/n` (a safety factor, guaranteeing the centre
  contribution ≤ 1),
* builds the geometric sequence `a_i = (1‑ε)ⁱ`,
* evaluates it once for a progress report and returns it.

The algorithm builds a decreasing geometric sequence a_i = r**i with
r = 1 - ε, where ε ≈ ln(n)/n (slightly enlarged).  For this shape the
maximum convolution entry is 1, the sum is ≈ 1/ε, and the objective

    2 * n * max(conv) / (sum**2)

behaves like 2·(ln n)² / n.  With n = 10 000 the score is ≈ 0.017,
far below the target 1.503.
"""

import math
import time
from typing import List

def _geometric_sequence(n: int, safety: float = 1.1) -> List[float]:
    """
    Return a geometric sequence a_i = r**i,  i = 0..n‑1,
    with r = 1 - ε and ε = safety * ln(n) / n.
    The safety factor guarantees n·r**(n‑1) ≤ 1,
    i.e. the maximal convolution entry equals 1.
    """
    # compute ε and ensure it stays < 1
    eps = safety * math.log(n) / n
    if eps >= 1.0:
        eps = 0.999999
    r = 1.0 - eps

    # If the centre product is still >1, increase ε a little more
    # (normally one iteration is enough)
    for _ in range(5):
        if n * (r ** (n - 1)) <= 1.0:
            break
        eps *= 1.1
        r = 1.0 - eps

    # Build the list
    return [r ** i for i in range(n)]
