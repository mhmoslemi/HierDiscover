"""
Uniform step function generator.

The evaluation function is
    E(a) = 2 * n * max(conv(a,a)) / (sum(a) ** 2)

For any non‑negative sequence a of length n we have
    max(conv(a,a)) ≥ sum_i a_i^2 ≥ (sum_i a_i)^2 / n,
hence E(a) ≥ 2.  Equality is attained when all entries are equal,
i.e. a_i = S / n with S = sum_i a_i.
Choosing S = sqrt(2·n) (the normalisation used in the reference code)
gives E(a) = 2, which is provably optimal.

The function below returns such a uniform sequence.  It uses the length of the
global `height_sequence_1` if that variable exists; otherwise it falls back to
