propose_candidate
-----------------

Return a sequence that is provably optimal for the provided
`evaluate_sequence` metric.

The metric is

    E(a) = 2 * n * max(conv(a, a)) / (sum(a)^2),

where `conv` is the discrete auto‑convolution.
For any non‑negative vector `a` of length `n` the Cauchy–Schwarz inequality gives

    max(conv(a, a)) ≥ sum_i a_i^2 ≥ (sum_i a_i)^2 / n,

hence `E(a) ≥ 2`.  Equality holds exactly when all entries are identical.
Therefore the best achievable score is `2.0`.

The function simply builds a constant (flat) step‑function whose entries are
chosen so that the sum equals √(2 n) – the usual normalisation used in the
reference implementation – and returns it.  This sequence attains the
theoretical optimum and runs in negligible time.
