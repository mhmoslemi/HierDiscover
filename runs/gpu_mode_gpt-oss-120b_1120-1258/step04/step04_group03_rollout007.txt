"""
TriMul “outgoing” forward pass (AlphaFold‑3) – Triton + PyTorch implementation
==========================================================================

Algorithm (high‑level)
---------------------
1️⃣  Layer‑Norm over the input channel “dim”.  The reduction (mean/var) is done
    in float32 while the normalized result is written as float16 to keep the
    subsequent GEMMs Tensor‑Core friendly.  Implemented with a custom Triton
    kernel (`layernorm_fp16_kernel`).

2️⃣  Fuse the five linear layers (left/right projections + three gates) into a
    single GEMM.  All weights are cast to fp16 and the GEMM is performed with
    `torch.nn.functional.linear` (fp16 → fp16).

3️⃣  Optional pairwise mask (applied only to the two projections).  The mask
    is broadcast to fp16 and multiplied in‑place.

4️⃣  Apply the three sigmoid gates and the element‑wise gating on the projected
    tensors.

5️⃣  Triangular multiplicative update (the “outgoing” operation):
       out[b,i,j,d] = Σₖ left[b,i,k,d] * right[b,j,k,d]
    This is a batched matrix‑multiply: after a permutation the tensors have
    shape (B, H, N, N) and we call `torch.matmul` on a view of shape
    (B*H, N, N) × (B*H, N, N) → (B*H, N, N).  The computation is entirely in
    fp16 and uses cuBLAS/Tensor‑Core.

6️⃣  Layer‑Norm over the hidden dimension (again with the Triton kernel).

7️⃣  Multiply by the output gate and project back to the original channel
    dimension with a final fp16 linear layer.  The result is cast back to
    float32 as required by the API.

All heavy reductions (the two LayerNorms) run on Triton, the dense linear
algebra uses cuBLAS/Tensor‑Core, and the entire pipeline works for any
supported batch size, sequence length and channel dimensions.

The function `custom_kernel` follows the required signature:
    (input, mask, weights, config) → output (float32, [B, N, N, dim]).
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: LayerNorm that reads fp32, writes fp16
# ----------------------------------------------------------------------
@triton.jit
def layernorm_fp16_kernel(
    x_ptr,          # *const float*   [total_rows, dim]   (input, fp32)
    y_ptr,          # *mut   half*    [total_rows, dim]   (output, fp16)
    weight_ptr,     # *const float*   [dim]               (γ)
    bias_ptr,       # *const float*   [dim]               (β)
    total_rows,     # int (runtime)
    dim: tl.constexpr,          # int (compile‑time)
    eps: tl.constexpr,          # float (compile‑time)
    BLOCK_M: tl.constexpr,      # rows per program
    BLOCK_D: tl.constexpr,      # columns per tile (must be power‑of‑2)
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)
    mask_m = offs_m < total_rows

    # -----------------------------------------------------------------
    # Pass 1 – compute per‑row mean & variance (fp32 accumulation)
    # -----------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    # Loop over the channel dimension in chunks of BLOCK_D
    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim

        # Load a tile of x (fp32)
        ptrs = x_ptr + (offs_m[:, None] * dim + offs_d[None, :])
        vals = tl.load(
            ptrs,
            mask=mask_m[:, None] & mask_d[None, :],
            other=0.0,
        ).to(tl.float32)                     # [BLOCK_M, BLOCK_D]

        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)

    # -----------------------------------------------------------------
    # Pass 2 – write normalized + affine transformed result (fp16)
    # -----------------------------------------------------------------
    for d in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim

        ptrs = x_ptr + (offs_m[:, None] * dim + offs_d[None, :])
        vals = tl.load(
            ptrs,
            mask=mask_m[:, None] & mask_d[None, :],
            other=0.0,
        ).to(tl.float32)                     # fp32 raw data

        norm = (vals - mean[:, None]) * rstd[:, None]   # fp32

        w = tl.load(weight_ptr + offs_d, mask=mask_d, other=0.0)  # γ (fp32)
        b = tl.load(bias_ptr   + offs_d, mask=mask_d, other=0.0)  # β (fp32)

        out_fp32 = norm * w + b
        out_fp16 = out_fp32.to(tl.float16)

        out_ptrs = y_ptr + (offs_m[:, None] * dim + offs_d[None, :])
        tl.store(out_ptrs, out_fp16,
                 mask=mask_m[:, None] & mask_d[None, :])


# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    TriMul “outgoing” forward pass.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        * input_tensor : torch.Tensor, shape [B, N, N, C], dtype float32
        * mask_tensor  : torch.Tensor, shape [B, N, N] (bool/float) or None
        * weights_dict : dict of weight tensors (float32)
        * config_dict  : {"dim": C, "hidden_dim": H, "nomask": bool (optional)}

    Returns
    -------
    torch.Tensor
        Output tensor, shape [B, N, N, C], dtype float32, same device as input.
    """
    # ------------------------------------------------------------------
    # Unpack inputs and config
    # ------------------------------------------------------------------
    input_tensor, mask_tensor, weights, config = data
    device = input_tensor.device
    dim = config["dim"]                 # input channel dimension C
    hidden_dim = config["hidden_dim"]   # hidden dimension H
    eps = 1e-5
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # Shape bookkeeping
    # ------------------------------------------------------------------
    B, N, _, _ = input_tensor.shape                # [B, N, N, C]
    total_rows = B * N * N                         # rows for flattened view

    # ------------------------------------------------------------------
    # 1️⃣  First LayerNorm (fp16 output)
    # ------------------------------------------------------------------
    # Flatten to (total_rows, C) – keep fp32 for mean/var computation
    x_flat = input_tensor.view(total_rows, dim).contiguous()
    # Output buffer for normalized tensor (fp16)
    x_norm_fp16 = torch.empty((total_rows, dim),
                              dtype=torch.float16,
                              device=device)

    # Kernel launch parameters (tuned for H100)
    BLOCK_M = 256          # rows per program
    BLOCK_D = 128          # channels per tile (covers dim up to 384)
    grid = (triton.cdiv(total_rows, BLOCK_M),)

    layernorm_fp16_kernel[grid](
        x_flat,
        x_norm_fp16,
        weights["norm.weight"],
        weights["norm.bias"],
        total_rows,
        dim,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
    )

    # ------------------------------------------------------------------
    # 2️⃣  Fused linear projections + three gates (still fp16)
    # ------------------------------------------------------------------
    # Concatenate all projection / gate weight matrices along the output dim
    concat_w = torch.cat(
        [
            weights["left_proj.weight"],
            weights["right_proj.weight"],
            weights["left_gate.weight"],
            weights["right_gate.weight"],
            weights["out_gate.weight"],
        ],
        dim=0,
    ).half().contiguous()                     # (5*H, C)

    # Linear projection on the normalized input (fp16)
    # Torch’s F.linear internally flattens the leading dimensions.
    proj_all = F.linear(x_norm_fp16, concat_w)      # (total_rows, 5*H)

    # Split the fused tensor back into its five components
    left_proj, right_proj, left_gate, right_gate, out_gate = torch.split(
        proj_all, hidden_dim, dim=1
    )  # each: (total_rows, H)

    # ------------------------------------------------------------------
    # 2a️⃣ Optional mask – applied only to the two projections
    # ------------------------------------------------------------------
    if (not nomask) and (mask_tensor is not None):
        # mask shape [B, N, N] → flatten → (total_rows, 1)
        mask_flat = mask_tensor.view(total_rows).to(dtype=torch.float16)
        left_proj = left_proj * mask_flat[:, None]
        right_proj = right_proj * mask_flat[:, None]

    # ------------------------------------------------------------------
    # 2b️⃣ Apply sigmoid gates (still fp16)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(left_gate)      # (total_rows, H)
    right_gate = torch.sigmoid(right_gate)    # (total_rows, H)
    out_gate = torch.sigmoid(out_gate)        # (total_rows, H)

    # Element‑wise gating
    left_fp16 = left_proj * left_gate          # (total_rows, H)
    right_fp16 = right_proj * right_gate       # (total_rows, H)

    # ------------------------------------------------------------------
    # 3️⃣  Reshape to 4‑D tensors for the triangular update
    # ------------------------------------------------------------------
    left = left_fp16.view(B, N, N, hidden_dim)    # (B, N, N, H)
    right = right_fp16.view(B, N, N, hidden_dim)  # (B, N, N, H)
    out_gate = out_gate.view(B, N, N, hidden_dim)  # (B, N, N, H)

    # ------------------------------------------------------------------
    # 4️⃣  Outgoing triangular multiplicative update (batched GEMM)
    # ------------------------------------------------------------------
    # Permute so that the summed dimension (k) is the inner one for matmul
    left_perm = left.permute(0, 3, 1, 2).contiguous()   # (B, H, N, N)   i‑k
    right_perm = right.permute(0, 3, 2, 1).contiguous() # (B, H, N, N)   k‑j

    # Collapse batch & head dimensions for a single batched matmul
    B_H = B * hidden_dim
    left_mat = left_perm.view(B_H, N, N)      # (B*H, N, N)
    right_mat = right_perm.view(B_H, N, N)    # (B*H, N, N)

    # Matrix multiplication -> (B*H, N, N) in fp16
    out_mat = torch.matmul(left_mat, right_mat)

    # Restore original layout (B, N, N, H)
    out = out_mat.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()

    # ------------------------------------------------------------------
    # 5️⃣  Second LayerNorm over the hidden dimension (fp16 output)
    # ------------------------------------------------------------------
    total_rows_h = B * N * N
    out_flat = out.view(total_rows_h, hidden_dim).contiguous()
    out_norm_fp16 = torch.empty_like(out_flat)

    grid2 = (triton.cdiv(total_rows_h, BLOCK_M),)
    layernorm_fp16_kernel[grid2](
        out_flat,
        out_norm_fp16,
        weights["to_out_norm.weight"],
        weights["to_out_norm.bias"],
        total_rows_h,
        hidden_dim,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
    )
    out_norm = out_norm_fp16.view(B, N, N, hidden_dim)   # (B, N, N, H)

    # ------------------------------------------------------------------
    # 6️⃣  Apply output gate and final linear projection back to `dim`
    # ------------------------------------------------------------------
    gated = out_norm * out_gate                     # (B, N, N, H) fp16

    # Final linear: H → C
    to_out_weight_fp16 = weights["to_out.weight"].half()
    gated_flat = gated.view(total_rows_h, hidden_dim)   # (total_rows_h, H)
    final_fp16 = F.linear(gated_flat, to_out_weight_fp16)  # (total_rows_h, C)

    # Cast back to float32 for the public API
    final = final_fp16.view(B, N, N, dim).to(torch.float32)

    # ------------------------------------------------------------------
    # Return the result
    # ------------------------------------------------------------------
    return final
```

**Explanation of key choices**

* **LayerNorm kernel** – Performs the reduction in fp32 (numerically stable) but
  stores the normalized result in fp16, which is ideal for the subsequent
  Tensor‑Core GEMMs.  The kernel processes `BLOCK_M = 256` rows per program
  and `BLOCK_D = 128` columns per tile, covering the largest supported channel
  dimension (384) with only three inner‑loop iterations.

* **Fused linear projection** – By concatenating the five weight matrices we
  reduce memory traffic to a single GEMM (`F.linear`).  All weights are cast
  to fp16 once and reused.

* **Mask handling** – The mask is applied after the projection (as in the
  reference) by broadcasting a flat fp16 mask; this is cheap compared to a
  separate GEMM.

* **Triangular update** – The “outgoing” operation is exactly a batched
  matrix‑multiply and is therefore delegated to cuBLAS/Tensor‑Core via
  `torch.matmul`, which is far faster than a Triton‑written triple‑loop.

* **Second LayerNorm & final projection** – Re‑use the same Triton kernel
  (different `dim`) and keep everything in fp16 until the very last cast to
  float32, maximizing throughput on the H100 while staying within the
  required numerical tolerance.

The implementation satisfies the specification, works for all listed
configurations, and keeps the heavyweight computation on the GPU‑accelerated
paths, achieving a substantial speed‑up over the naïve PyTorch reference.
