TriMul (outgoing) – fast forward pass.

Algorithm
---------
1️⃣  Row‑wise LayerNorm + 5× fused linear projection (left/right
    projections, left/right gates, output gate) are executed in a
    single custom Triton kernel.  The kernel:
       • computes mean/variance per row,
       • normalises the row (γ·β from the first LayerNorm),
       • multiplies the normalised row with the concatenated weight matrix
         (size (5·H, C)) and writes the 5·H results (fp16).

   The result is split into
        left_raw, right_raw, left_gate_raw, right_gate_raw, out_gate_raw.

2️⃣  Mask (if present) and three sigmoid gates are applied in PyTorch
    (the work‑load is negligible).

3️⃣  The cubic multiplicative update  out = left @ rightᵀ  is performed as a
    batched matrix multiplication of shape (B·H, N, N) → (B·H, N, N) using
    fp16 Tensor‑Core GEMM (torch.bmm).

4️⃣  The second LayerNorm, gating by `out_gate` and the final linear
    projection back to the original channel dimension are fused in a second
    Triton kernel:
       • computes per‑row mean/variance over the hidden dimension H,
       • normalises, applies the learnt γ/β (to_out_norm),
       • multiplies element‑wise by the already‑sigmoid‑ed `out_gate`,
       • evaluates the final linear map `to_out` (size (C, H)).

   The kernel writes the final tensor directly in fp16, which is finally
   reshaped to `[B, N, N, C]` and cast back to fp32.

Only two Triton kernels are written – the rest of the work is performed
with highly‑optimised Torch primitives (fused GEMMs, batched GEMM).  All
heavy arithmetic stays in FP16 to exploit H100 Tensor‑Cores, while the
LayerNorm statistics are evaluated in FP32 for numerical stability.

The implementation supports:
    * B ∈ {1,2}
    * N ∈ {128,256,512,1024}
    * C (dim) ∈ {128,384,768}
    * H (hidden_dim) = 128
    * optional binary mask

        x = tl.load(
            x_ptr + offs_r[:, None] * C + offs_c[None, :],
            mask=mask_r[:, None] & mask_c[None, :],
            other=0.0,
        ).to(tl.float32)                     # fp32 load
        sum_val += tl.sum(x, axis=1)
        sum_sq  += tl.sum(x * x, axis=1)

    mean = sum_val / C
    var  = sum_sq / C - mean * mean
    rstd = tl.rsqrt(var + eps)                 # 1/σ

    # --------------------------------------------------------------
    # 2️⃣ 5·H linear projections (deep‑fused)
    # --------------------------------------------------------------
    for m_off in range(0, tl.cdiv(M, BLOCK_M)):
        offs_m = m_off * BLOCK_M + tl.arange(0, BLOCK_M)
        mask_m = offs_m < M

        # accumulator for this output tile
        acc = tl.zeros((BLOCK_R, BLOCK_M), dtype=tl.float32)

        for d_off in range(0, tl.cdiv(C, BLOCK_D)):
            offs_c = d_off * BLOCK_D + tl.arange(0, BLOCK_D)
            mask_c = offs_c < C

            # load raw X
            x = tl.load(
                x_ptr + offs_r[:, None] * C + offs_c[None, :],
                mask=mask_r[:, None] & mask_c[None, :],
                other=0.0,
            ).to(tl.float32)

            # LayerNorm: ((x-μ)·rstd)·γ + β
            gamma = tl.load(ln_w_ptr + offs_c, mask=mask_c, other=0.0)
            beta  = tl.load(ln_b_ptr + offs_c, mask=mask_c, other=0.0)
            x_norm = ((x - mean[:, None]) * rstd[:, None]) * gamma[None, :] + beta[None, :]

            # weight tile (transposed) – shape [BLOCK_D, BLOCK_M]
            # w_ptr layout: [M, C] row‑major → transposed view [C, M]
            w = tl.load(
                w_ptr + offs_c[:, None] + offs_m[None, :] * C,
                mask=mask_c[:, None] & mask_m[None, :],
                other=0.0,
            ).to(tl.float32)

            # matmul on the tile
            acc += tl.dot(x_norm, w)    # (BLOCK_R, BLOCK_D)·(BLOCK_D, BLOCK_M)
        # write tile
        out_idx = offs_r[:, None] * M + offs_m[None, :]
        tl.store(
            out_ptr + out_idx,
            acc.to(tl.float16),
            mask=mask_r[:, None] & mask_m[None, :],
        )


# ----------------------------------------------------------------------
# 2️⃣  Second LayerNorm + gating + final linear projection
# ----------------------------------------------------------------------
@triton.jit
def norm_gate_linear_fused_kernel(
    x_ptr,               # fp16 intermediate tensor [R, H]
    gate_ptr,            # fp16 out_gate            [R, H]
    out_ptr,             # fp16 final output        [R, C]
    ln_w_ptr,            # fp32 to_out_norm.weight  [H]
    ln_b_ptr,            # fp32 to_out_norm.bias    [H]
    w_ptr,               # fp16 to_out.weight       [C, H]
    R, H, C,             # runtime scalars
    eps,                 # compile‑time scalar
    BLOCK_R: tl.constexpr,   # rows per program (e.g. 64)
    BLOCK_D: tl.constexpr,   # hidden‑dim tile (e.g. 64)
    BLOCK_O: tl.constexpr,   # output‑channel tile (e.g. 64)
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)
    mask_r = offs_r < R

    # --------------------------------------------------------------
    # mean / variance over hidden dimension H
    # --------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_R], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_R], dtype=tl.float32)

    for d_off in range(0, tl.cdiv(H, BLOCK_D)):
        offs_h = d_off * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_h = offs_h < H
        v = tl.load(
            x_ptr + offs_r[:, None] * H + offs_h[None, :],
            mask=mask_r[:, None] & mask_h[None, :],
            other=0.0,
        ).to(tl.float32)
        sum_val += tl.sum(v, axis=1)
        sum_sq  += tl.sum(v * v, axis=1)

    mean = sum_val / H
    var  = sum_sq / H - mean * mean
    rstd = tl.rsqrt(var + eps)

    # --------------------------------------------------------------
    # tiled output projection (C columns)
    # --------------------------------------------------------------
    for o_off in range(0, tl.cdiv(C, BLOCK_O)):
        offs_o = o_off * BLOCK_O + tl.arange(0, BLOCK_O)
        mask_o = offs_o < C
        acc = tl.zeros((BLOCK_R, BLOCK_O), dtype=tl.float32)

        for d_off in range(0, tl.cdiv(H, BLOCK_D)):
            offs_h = d_off * BLOCK_D + tl.arange(0, BLOCK_D)
            mask_h = offs_h < H

            # load hidden vector
            x = tl.load(
                x_ptr + offs_r[:, None] * H + offs_h[None, :],
                mask=mask_r[:, None] & mask_h[None, :],
                other=0.0,
            ).to(tl.float32)

            # LayerNorm on the hidden vector
            gamma = tl.load(ln_w_ptr + offs_h, mask=mask_h, other=0.0)
            beta  = tl.load(ln_b_ptr + offs_h, mask=mask_h, other=0.0)
            x_norm = ((x - mean[:, None]) * rstd[:, None]) * gamma[None, :] + beta[None, :]

            # gate (already sigmoid‑ed)
            g = tl.load(
                gate_ptr + offs_r[:, None] * H + offs_h[None, :],
                mask=mask_r[:, None] & mask_h[None, :],
                other=0.0,
            ).to(tl.float32)

            y = x_norm * g   # (BLOCK_R, BLOCK_D)

            # final weight tile – we need w_T of shape [H, C]
            # w_ptr layout: [C, H] row‑major → transposed view [H, C]
            w = tl.load(
                w_ptr + offs_h[:, None] + offs_o[None, :] * H,
                mask=mask_h[:, None] & mask_o[None, :],
                other=0.0,
            ).to(tl.float32)          # shape (BLOCK_D, BLOCK_O)

            # accumulate
            acc += tl.dot(y, w)        # (BLOCK_R, BLOCK_D)·(BLOCK_D, BLOCK_O)
        # write output tile
        out_idx = offs_r[:, None] * C + offs_o[None, :]
        tl.store(
            out_ptr + out_idx,
            acc.to(tl.float16),
            mask=mask_r[:, None] & mask_o[None, :],
        )


# ----------------------------------------------------------------------
# 3️⃣  Custom Triton‑backed TriMul forward
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)
        input_tensor : torch.Tensor, shape [B, N, N, C], fp32
        mask_tensor  : torch.Tensor, shape [B, N, N] (bool/float) or None
        weights_dict : dict of torch.Parameters (all fp32)
        config_dict  : dict with keys
            "dim"         – C, input channel dimension
            "hidden_dim" – H (always 128 in the test suite)
            "nomask"      – bool, if True the mask is ignored

    Returns
    -------
    torch.Tensor
        Output tensor of shape [B, N, N, C], dtype fp32
    """
    # --------------------------------------------------------------
    # unpack & constants
    # --------------------------------------------------------------
    x, mask, weights, cfg = data
    device = x.device
    B, N, _, C = x.shape
    H = cfg["hidden_dim"]
    nomask = cfg.get("nomask", True)
    eps = 1e-5

    R = B * N * N                      # total rows = B·N·N
    M = 5 * H                          # left, right, left_gate, right_gate, out_gate

    # ------------------------------------------------------------------
    # 1️⃣  Fuse first LayerNorm + 5 linear projections
    # ------------------------------------------------------------------
    # flatten input: [R, C] (fp32)
    x_flat = x.view(R, C).contiguous()

    # allocate fused output [R, M] (fp16)
    fused_out = torch.empty(R, M, dtype=torch.float16, device=device)

    # concatenated weight matrix for the 5 projections (fp16)
    w_fused = torch.cat(
        [
            weights["left_proj.weight"],   # [H, C]
            weights["right_proj.weight"],  # [H, C]
            weights["left_gate.weight"],   # [H, C]
            weights["right_gate.weight"],  # [H, C]
            weights["out_gate.weight"],    # [H, C]
        ],
        dim=0,
    ).contiguous().to(torch.float16)    # shape (5·H, C)

    # launch kernel
    BLOCK_R = 64   # rows per program
    BLOCK_D = 32   # columns of X processed per tile
    BLOCK_M = 64   # output‑channel tile
    grid = (triton.cdiv(R, BLOCK_R),)
    norm_linear_fused_kernel[grid](
        x_flat,
        fused_out,
        weights["norm.weight"],    # γ (fp32)
        weights["norm.bias"],      # β (fp32)
        w_fused,
        R,
        C,
        M,
        eps,
        BLOCK_R=BLOCK_R,
        BLOCK_D=BLOCK_D,
        BLOCK_M=BLOCK_M,
        num_warps=4,
    )

    # --------------------------------------------------------------
    # split fused tensor
    # --------------------------------------------------------------
    left_raw       = fused_out[:, 0:H]          # [R, H]
    right_raw      = fused_out[:, H:2 * H]
    left_gate_raw  = fused_out[:, 2 * H:3 * H]
    right_gate_raw = fused_out[:, 3 * H:4 * H]
    out_gate_raw   = fused_out[:, 4 * H:5 * H]

    # --------------------------------------------------------------
    # optional mask (applied before gating)
    # --------------------------------------------------------------
    if not nomask and mask is not None:
        mask_fp16 = mask.reshape(R, 1).to(torch.float16)   # broadcast on H
        left_raw  = left_raw * mask_fp16
        right_raw = right_raw * mask_fp16

    # --------------------------------------------------------------
    # apply sigmoid gates (in‑place, fp16)
    # --------------------------------------------------------------
    left_gate  = left_gate_raw.sigmoid_()
    right_gate = right_gate_raw.sigmoid_()
    out_gate   = out_gate_raw.sigmoid_()

    left  = left_raw * left_gate      # [R, H] fp16
    right = right_raw * right_gate    # [R, H] fp16

    # --------------------------------------------------------------
    # reshape for the cubic update
    # --------------------------------------------------------------
    left  = left.view(B, N, N, H)
    right = right.view(B, N, N, H)
    out_gate = out_gate.view(B, N, N, H)

    # bring H into batch dimension → [B·H, N, N]
    left_perm = left.permute(0, 3, 1, 2).contiguous()
    right_perm = right.permute(0, 3, 1, 2).contiguous()
    left_mat = left_perm.view(B * H, N, N)
    right_mat = right_perm.view(B * H, N, N)

    # ------------------------------------------------------------------
    # 2️⃣  Cubic multiplicative update: left @ rightᵀ (batched GEMM)
    # ------------------------------------------------------------------
    # (B·H, N, N) @ (B·H, N, N)ᵀ → (B·H, N, N)   fp16 Tensor‑Core GEMM
    out_mat = torch.bmm(left_mat, right_mat.transpose(1, 2))

    # reshape back to [B, N, N, H] → flatten to [R, H] for the next kernel
    out = out_mat.view(B, H, N, N).permute(0, 2, 3, 1).contiguous()
    out_flat = out.view(R, H).contiguous()          # fp16

    # ------------------------------------------------------------------
    # 3️⃣  Second LayerNorm + out_gate * final linear projection
    # ------------------------------------------------------------------
    final_fp16 = torch.empty(R, C, dtype=torch.float16, device=device)

    # final projection weight: [C, H] (fp16)
    to_out_w = weights["to_out.weight"].contiguous().to(torch.float16)

    block_R2 = 64      # rows per program for second pass
    block_D2 = 64      # hidden‑dim tile (H ≤ 128)
    block_O2 = 64      # output‑channel tile (C ≤ 768)

    grid2 = (triton.cdiv(R, block_R2),)
    norm_gate_linear_fused_kernel[grid2](
        out_flat,                     # input after cubic update (fp16)
        out_gate.view(R, H),          # sigmoid‑ed gate (fp16)
        final_fp16,                   # final output (fp16)
        weights["to_out_norm.weight"],# γ (fp32) for second LN
        weights["to_out_norm.bias"],  # β (fp32)
        to_out_w,                     # final linear weight (fp16)
        R,
        H,
        C,
        eps,
        BLOCK_R=block_R2,
        BLOCK_D=block_D2,
        BLOCK_O=block_O2,
        num_warps=4,
    )

    # ------------------------------------------------------------------
    # reshape to [B, N, N, C] and cast back to fp32
    # ------------------------------------------------------------------
    out_fp32 = final_fp16.view(B, N, N, C).to(torch.float32)
    return out_fp32
