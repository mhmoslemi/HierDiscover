analysisWe need to implement a custom kernel for TriMul "outgoing" version from AlphaFold3. The original PyTorch implementation performs the following steps:

1. Input x shape [B, N, N, D] (dim = D). Apply LayerNorm over last dimension D (i.e., per (B,N,N) separately). So x_norm = (x - mean)/sqrt(var+eps) * weight + bias. Need to apply LN using provided norm weights and bias.

2. left_proj = Linear(x_norm) => weight shape [hidden_dim, dim] (since bias=False). So left = x_norm @ left_proj_weight.T (or weight of shape [hidden_dim, dim]): out dim hidden_dim over last dim.

3. right_proj similarly.

4. mask shape [B,N,N]. Expand to [B,N,N,1] and multiply left and right elementwise (mask broadcast). In the "outgoing" version, likely mask applied as left[i,k] * mask[i,k] etc. We'll follow same.

If nomask True, skip mask: treat mask as all ones.

5. left_gate = Linear(x_norm) with weight left_gate_weight, shape [hidden_dim, dim]; apply sigmoid; then left = left * left_gate elementwise.

Similarly right_gate.

6. out_gate = Linear(x_norm) with weight out_gate_weight, shape [hidden_dim, dim]; apply sigmoid.

7. out = einsum('... i k d, ... j k d -> ... i j d', left, right). So we need to compute per batch and per d (hidden_dim) a sum over the k dimension: out[b,i,j,d] = sum_{k} left[b,i,k,d] * right[b,j,k,d].

Note that this is a tensor contraction of shape (B,N,N,hidden_dim) x (B,N,N,hidden_dim) -> (B,N,N,hidden_dim): second operand's the k dimension is second index j with k same, same hidden_dim.

This is similar to batched matrix multiplication per hidden_dim: treat left as a N x N matrix per hidden_dim: left_{i,k} for each hidden_dim. right as N x N: right_{j,k} (note j vs i but want right_{j,k} meaning row j and column k). Then out_{i,j} = sum_k left_{i,k} * right_{j,k} = left * right^T?? Actually standard matrix multiplication: (left) * (right).transpose? If right is shape (j,k), then left[i,k] * right[j,k] sum over k yields left @ right.T? Because left[i,:] dot right[j,:] = sum_k left[i,k] * right[j,k] = (left @ right.T)[i,j]. So out = left @ right.T (per hidden_dim). Equivalent to left matrix multiply with right transposed.

Thus, for each hidden_dim, we compute B*N*N matrix multiply. So shape (B, hidden_dim, N, N) mentally.

But our left and right share shape [B, N, N, hidden_dim] where N is input sequence dimension as both i and k for left; j and k for right. We need to sum over k.

Implementation approach:

We can restructure: left: [B, hidden_dim, N, N] (permute dims). right: [B, hidden_dim, N, N] (permute). Then perform batch matmul: out = torch.matmul(left, right.transpose(-1,-2)) => shape [B, hidden_dim, N, N] which corresponds to [B,N,N,hidden_dim] after transposing.

But this matmul can be performed via Triton kernel - the main compute heavy part.

He wants to implement at least part of the operations in a kernel. We can implement the einsum reduction via a Triton kernel: Given left and right flattened as [B*hidden_dim, N, N] perhaps each compute matmul.

Given constraints of seq_len up to 1024, hidden_dim up to 128. B small (1 or 2). So for worst-case B*hidden_dim=256 (if B=2 hidden=128). That results in 256 independent matmuls of size 1024 x 1024. Brute force N^3 might be heavy, but using efficient batched GEMM is okay.

Thus, we can implement a kernel similar to matmul but with batched dimensions.

Option: Use triton's fused matmul kernel: take left (B, hidden_dim, N, N) and right (B, hidden_dim, N, N). Compute out = left @ right.transpose(-1,-2). Use block sizes: BLOCK_M, BLOCK_N, BLOCK_K = maybe 128, 128, 32? But memory constraints: N up to 1024.

We will need to handle mask multiplication, layernorm, linear projections, gate sigmoids also. These can be done in PyTorch using torch.nn.functional, but we may incorporate some steps into the kernel (like layernorm and linear projection). However, the heavy compute is the bilinear contraction. So we can implement a custom Triton kernel for that part, while the rest of the ops remain in PyTorch.

We must return final output shape [B,N,N,dim] (original dim). After contraction, we have hidden_dim features; we then apply to_out_norm (layernorm); multiply by out_gate; then linear to_out weight for projection back to dim.

Thus: Steps:

- Use PyTorch to perform normalization and linear projections (+gate, mask), produce left and right tensors shape [B,N,N,hidden_dim].
- Use custom Triton kernel to compute out = einsum contracted result: [B,N,N,hidden_dim].
- Then apply to_out_norm + gate + linear using PyTorch.

Potential to also implement to_out_norm via PyTorch.

Alternatively, we could combine to_out_norm and to_out linear in same kernel but not necessary.

Thus minimal requirement: implement at least part of operations in a kernel. We'll implement the core contraction as a custom Triton kernel batched_matmul.

@triton.jit
def batched_matmul_triton(
    a_ptr, b_ptr, c_ptr,
    BATCH, HEADS, N,
    stride_a_batch, stride_a_row, stride_a_col,
    stride_b_batch, stride_b_row, stride_b_col,
    stride_c_batch, stride_c_row, stride_c_col,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    pid = tl.program_id(0)
    total_blocks_m = tl.cdiv(N, BLOCK_M)
    total_blocks_n = tl.cdiv(N, BLOCK_N)
    total_blocks_per_head = total_blocks_m * total_blocks_n
    # compute bih = pid // total_blocks_per_head
    bih = pid // total_blocks_per_head
    pid_rem = pid % total_blocks_per_head
    # compute batch idx and head idx
    batch_idx = bih // HEADS
    head_idx = bih % HEADS

    pid_m = pid_rem // total_blocks_n
    pid_n = pid_rem % total_blocks_n

    # offsets within matrix
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    # mask out-of-range:
    mask_m = offs_m < N
    mask_n = offs_n < N

    # pointers to A and B with correct batch/head offsets
    a_ptrs = a_ptr + batch_idx * stride_a_batch + head_idx * stride_a_row * 0 + offs_m[:, None] * stride_a_row + tl.arange(0, BLOCK_K)[None, :] * stride_a_col
    # Actually a_ptrs need to include row and K dimension: we need K offsets for inner loops.
    # We'll compute loads inside loop over k.

    # We'll compute accumulator:
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # iterate over K dimension in tiles
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        # compute offsets for this K tile
        k_offset = k * BLOCK_K + tl.arange(0, BLOCK_K)
        # load A block: shape (BLOCK_M, BLOCK_K)
        a = tl.load(a_ptr + batch_idx * stride_a_batch + head_idx * stride_a_row * 0 + offs_m[:, None] * stride_a_row + k_offset[None, :] * stride_a_col,
                    mask=mask_m[:, None] & (k_offset < N), other=0.0)
        # load B block: shape (BLOCK_N, BLOCK_K) (since B_T with rows = N, cols = K)
        b = tl.load(b_ptr + batch_idx * stride_b_batch + head_idx * stride_b_row * 0 + offs_n[:, None] * stride_b_row + k_offset[None, :] * stride_b_col,
                    mask=mask_n[:, None] & (k_offset < N), other=0.0)
        # now compute dot: need a (M,K) x b (N,K) -> effectively dot across K dimension, but we need to sum product of A[i,k] * B[j,k].
        # We can use tl.dot for each pair of rows? But tl.dot expects shape (M,K) and (K,N) -> blocked? Actually we can do:
        # acc += tl.dot(a, b.T) using tl.dot with transpositions? tl.dot expects shape (M,K) and (K,N) produce (M,N)
        # But our b is (BLOCK_N, BLOCK_K) we need to transpose to (BLOCK_K, BLOCK_N): we can use tl.dot(a, b, trans_b=True)
        # In Triton, tl.dot(A, B, trans_b=True) expects B shape (N,K), dot result shape (M,N). We'll set trans_b=True.
        acc += tl.dot(a, b, trans_b=True)

    # write back
    c_ptrs = c_ptr + batch_idx * stride_c_batch + head_idx * stride_c_row * 0 + offs_m[:, None] * stride_c_row + offs_n[None, :] * stride_c_col
    tl.store(c_ptrs, acc.to(tl.float16) if tl.typeof(acc) != tl.float32 else acc, mask=mask_m[:, None] & mask_n[None, :])

def custom_kernel(data):
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    B, N, _, D = input_tensor.shape
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    # Cast to appropriate dtype for compute: we can use half or keep float32.

    # Apply layernorm: (x - mean)/sqrt(var+eps) * weight + bias
    # We can do via torch.nn.functional.layer_norm.
    # Use eps = 1e-5 (default) maybe needed; but weights from weights dict have shape [dim].
    # Implementation:
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    eps = 1e-5
    # compute mean,var across last dim
    # Using torch.nn.functional.layer_norm
    x_norm = torch.nn.functional.layer_norm(input_tensor, normalized_shape=(dim,), weight=norm_weight, bias=norm_bias, eps=eps)

    # Linear projections via torch.einsum perhaps more efficient: Because Linear weight shape [hidden_dim, dim]; we can compute left = torch.einsum('...d,hd->...h', x_norm, left_proj_weight.T)? Actually left = x_norm @ left_proj_weight.T => shape [B,N,N,hidden_dim]
    left_proj_w = weights["left_proj.weight"]  # shape [hidden_dim, dim]
    # remove bias.
    # Compute left = torch.matmul(x_norm, left_proj_w.T) # shape [B,N,N,hidden_dim]
    left = torch.matmul(x_norm, left_proj_w.T)  # (B,N,N,dim) matmul (dim, hidden_dim) yields (B,N,N,hidden_dim)
    right = torch.matmul(x_norm, weights["right_proj.weight"].T)

    # Mask: if mask is None? The data tuple includes mask; config may have "nomask". But we still need to handle.
    # If config "nomask" true, treat mask as all ones.
    # mask shape [B,N,N].
    if config.get("nomask", False):
        mask_exp = None
    else:
        mask_exp = mask.unsqueeze(-1)  # shape [B,N,N,1]
        left = left * mask_exp
        right = right * mask_exp

    # Gates
    left_gate = torch.sigmoid(torch.matmul(x_norm, weights["left_gate.weight"].T))
    right_gate = torch.sigmoid(torch.matmul(x_norm, weights["right_gate.weight"].T))
    out_gate = torch.sigmoid(torch.matmul(x_norm, weights["out_gate.weight"].T))

    left = left * left_gate
    right = right * right_gate

    # Now compute contraction: out = einsum('... i k d, ... j k d -> ... i j d', left, right)

    # Prepare left,right for batched matmul:
    # left: [B, N, N, H] => permute to [B, H, N, N]
    left_permuted = left.permute(0,3,1,2).contiguous()
    right_permuted = right.permute(0,3,1,2).contiguous()
    # shape [B, H, N, N]
    # We'll compute out_permuted = batched_matmul(left_permuted, right_permuted.transpose(-2,-1))
    # Use Triton kernel:

    # Define Triton kernel function inside file; compile it with triton.compile?
    # In runtime, we can call kernel with grid.

    # We'll need to compute strides:
    # left stride: (stride_batch_head, stride_row, stride_col)
    # left_contiguous: shape (B*H, N, N) if we view as one combined dimension.
    # However easier: pass stride_a_batch = left_permuted.stride(0) (step to next batch*head)
    # stride_a_row = left_permuted.stride(2) (since dims: 0-B,1-H,2-N(row),3-N(col)) maybe stride(row) -> left_permuted.stride(2)
    # stride_a_col = left_permuted.stride(3)
    # Similarly for right_permuted.
    # For B_T we need to supply swapped strides for row and col.

    # Determine number of heads = hidden_dim
    # Compute grid for triton:
    # total_programs = B * hidden_dim * ceil(N/BLOCK_M) * ceil(N/BLOCK_N)
    # grid = (total_programs,)

    # After kernel execution, we get out_permuted shape [B, hidden_dim, N, N] (since multiplication yields N x N)
    # Then permute back: out = out_permuted.permute(0,2,3,1) -> shape [B,N,N,hidden_dim]

    # also we may need to cast to float32 after kernel.

    # After out computed, apply to_out_norm, multiply by out_gate, final to_out linear.

    # to_out_norm: weight b shape [hidden_dim], bias shape [hidden_dim]; apply LayerNorm over last dim (hidden_dim)
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    out = torch.nn.functional.layer_norm(out, normalized_shape=(hidden_dim,), weight=to_out_norm_weight, bias=to_out_norm_bias, eps=eps)

    # apply out gate:
    out = out * out_gate

    # final linear:
    to_out_weight = weights["to_out.weight"]  # shape [dim, hidden_dim] (like Linear(hidden_dim, dim))
    # out shape [B,N,N,hidden_dim]; matmul with to_out_weight.T (hidden_dim, dim) -> [B,N,N,dim]
    out = torch.matmul(out, to_out_weight.T)

    return out

def custom_kernel(data):
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # LayerNorm
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = torch.nn.functional.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias, eps=eps)

    # Linear projections
    left = torch.nn.functional.linear(x, weights["left_proj.weight"])
    right = torch.nn.functional.linear(x, weights["right_proj.weight"])

    # Mask
    if not config.get("nomask", False):
        mask_exp = mask.unsqueeze(-1).to(x.dtype)
        left = left * mask_exp
        right = right * mask_exp

    # Gates
    left_gate = torch.sigmoid(torch.nn.functional.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(torch.nn.functional.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(torch.nn.functional.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # reshape for kernel
    left = left.permute(0,3,1,2).contiguous()  # [B, H, N, N]
    right = right.permute(0,3,1,2).contiguous()

    # cast to half for kernel
    left_fp16 = left.to(torch.float16)
    right_fp16 = right.to(torch.float16)

    # flatten batch and heads
    num_instances = B * hidden_dim
    left_flat = left_fp16.reshape(num_instances, N, N)
    right_flat = right_fp16.reshape(num_instances, N, N)
    out_flat = torch.empty_like(left_flat)  # same dtype (fp16)

    # Triton kernel parameters
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    # compute stride integers (they are Python ints)
    stride_a_batch = left_flat.stride(0)
    stride_a_row = left_flat.stride(1)
    stride_a_col = left_flat.stride(2)

    stride_b_batch = right_flat.stride(0)
    stride_b_orig_row = right_flat.stride(1)
    stride_b_orig_col = right_flat.stride(2)
    # For transposed view
    stride_b_row_T = stride_b_orig_col
    stride_b_col_T = stride_b_orig_row

    stride_c_batch = out_flat.stride(0)
    stride_c_row = out_flat.stride(1)
    stride_c_col = out_flat.stride(2)

    # Grid
    total_blocks_m = (N + BLOCK_M - 1) // BLOCK_M
    total_blocks_n = (N + BLOCK_N - 1) // BLOCK_N
    total_blocks_per_instance = total_blocks_m * total_blocks_n
    grid = (num_instances * total_blocks_per_instance,)

    batched_matmul_kernel[grid](
        left_flat,
        right_flat,
        out_flat,
        num_instances,
        N,
        stride_a_batch,
        stride_a_row,
        stride_a_col,
        stride_b_batch,
        stride_b_row_T,
        stride_b_col_T,
        stride_c_batch,
        stride_c_row,
        stride_c_col,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # Reshape back
    out = out_flat.view(B, hidden_dim, N, N).permute(0,2,3,1).contiguous()
    out = out.to(torch.float32)

    # to_out_norm
    out = torch.nn.functional.layer_norm(out, (hidden_dim,), weight=weights["to_out_norm.weight"], bias=weights["to_out_norm.bias"], eps=eps)

    # multiply by out_gate
    out = out * out_gate

    # final linear
    out = torch.nn.functional.linear(out, weights["to_out.weight"])

    return out

import triton
import triton.language as tl

@triton.jit
def batched_matmul_kernel(
    a_ptr, b_ptr, c_ptr,
    num_instances, N,
    stride_a_batch, stride_a_row, stride_a_col,
    stride_b_batch, stride_b_row_T, stride_b_col_T,
    stride_c_batch, stride_c_row, stride_c_col,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    pid = tl.program_id(0)
    total_m = tl.cdiv(N, BLOCK_M)
    total_n = tl.cdiv(N, BLOCK_N)
    total_blocks_per_instance = total_m * total_n
    instance_idx = pid // total_blocks_per_instance
    pid_in_inst = pid % total_blocks_per_instance
    pid_m = pid_in_inst // total_n
    pid_n = pid_in_inst % total_n

    # Compute coordinate ranges
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    mask_m = offs_m < N
    mask_n = offs_n < N

    # Pointers base for this instance
    a_base = a_ptr + instance_idx * stride_a_batch
    b_base = b_ptr + instance_idx * stride_b_batch
    c_base = c_ptr + instance_idx * stride_c_batch

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        k_offset = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = k_offset < N

        # Load A tile (M x K)
        a = tl.load(a_base + offs_m[:, None] * stride_a_row + k_offset[None, :] * stride_a_col,
                    mask=mask_m[:, None] & mask_k[None, :],
                    other=0.0, dtype=tl.float16)
        # Load B_T tile (N x K) where B_T row stride = stride_b_row_T, col stride = stride_b_col_T
        b = tl.load(b_base + offs_n[:, None] * stride_b_row_T + k_offset[None, :] * stride_b_col_T,
                    mask=mask_n[:, None] & mask_k[None, :],
                    other=0.0, dtype=tl.float16)

        # Compute dot product (M,N) += A (M,K) * B (N,K)^T
        acc += tl.dot(a, b, trans_b=True)

    # Write back result
    c = acc.to(tl.float16)
    tl.store(c_base + offs_m[:, None] * stride_c_row + offs_n[None, :] * stride_c_col,
             c,
             mask=mask_m[:, None] & mask_n[None, :])

"""
custom_kernel
==============

Implements the *outgoing* Triangle Multiplicative Update (TriMul) from the
AlphaFold‑3 paper.  The heavy “pairwise‑multiplication‑and‑sum” step

    out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]

is realized as a batched matrix‑multiply using a fused Triton kernel.
All surrounding operations (LayerNorm, Linear projections, gates, final
Linear) are performed with PyTorch for simplicity.  The kernel works on
fp16 data (the inputs are cast to half before the mat‑mul) while the
accumulator is fp32, giving high throughput on an H100.  The result is
returned in float32.

The kernel processes a flattened batch‑head dimension:
    instances = B * hidden_dim
    left  : [instances, N, N] (fp16)
    right : [instances, N, N] (fp16) – accessed as transposed on‑the‑fly
    out   : [instances, N, N] (fp16)

Each program computes a TILE‑M×N block of the matrix product for a single
instance, looping over the K dimension in tiles.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def _batched_matmul_kernel(
    a_ptr,                     # pointer to left matrices  [inst, N, N]
    b_ptr,                     # pointer to right matrices [inst, N, N] (will be read transposed)
    c_ptr,                     # pointer to output matrices
    num_instances, N,          # runtime constants
    stride_a_batch, stride_a_row, stride_a_col,   # strides for a
    stride_b_batch, stride_b_row_T, stride_b_col_T,  # strides for b (transposed view)
    stride_c_batch, stride_c_row, stride_c_col,   # strides for c
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """Batched GEMM: out_i = left_i @ right_i.T   for i in [0, num_instances)."""
    pid = tl.program_id(0)

    # how many tiles per instance?
    total_m = tl.cdiv(N, BLOCK_M)
    total_n = tl.cdiv(N, BLOCK_N)
    tiles_per_inst = total_m * total_n

    # instance index and tile indices
    inst = pid // tiles_per_inst
    tile_id = pid % tiles_per_inst
    pid_m = tile_id // total_n
    pid_n = tile_id % total_n

    # coordinates of the tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)
    mask_m = offs_m < N
    mask_n = offs_n < N

    # base pointers for this instance
    a_base = a_ptr + inst * stride_a_batch
    b_base = b_ptr + inst * stride_b_batch
    c_base = c_ptr + inst * stride_c_batch

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K dimension
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        k_off = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = k_off < N

        # left tile  (M x K)
        a = tl.load(
            a_base
            + offs_m[:, None] * stride_a_row
            + k_off[None, :] * stride_a_col,
            mask=mask_m[:, None] & mask_k[None, :],
            other=0.0,
            dtype=tl.float16,
        )
        # right tile transposed (N x K) – we read the original matrix with
        # swapped row/col strides so that we get B_T on‑the‑fly.
        b = tl.load(
            b_base
            + offs_n[:, None] * stride_b_row_T
            + k_off[None, :] * stride_b_col_T,
            mask=mask_n[:, None] & mask_k[None, :],
            other=0.0,
            dtype=tl.float16,
        )
        # acc += a @ b.T     (a: M×K, b: N×K) → M×N
        acc += tl.dot(a, b, trans_b=True)

    # write result back in fp16
    c = acc.to(tl.float16)
    tl.store(
        c_base
        + offs_m[:, None] * stride_c_row
        + offs_n[None, :] * stride_c_col,
        c,
        mask=mask_m[:, None] & mask_n[None, :],
    )


def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.
    Arguments
    ---------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor   [B, N, N, dim]
        - mask         : torch.Tensor   [B, N, N]  (may be ignored)
        - weights      : dict of torch.Tensors (model parameters)
        - config       : dict with keys 'dim', 'hidden_dim', 'nomask', …
    Returns
    -------
    torch.Tensor of shape [B, N, N, dim] (float32).
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # ------------------------------------------------------------------
    # 1) LayerNorm over the last (dim) channel
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=eps,
    )

    # ------------------------------------------------------------------
    # 2) Linear projections (no bias)
    # ------------------------------------------------------------------
    left = F.linear(x, weights["left_proj.weight"])
    right = F.linear(x, weights["right_proj.weight"])

    # ------------------------------------------------------------------
    # 3) Optional mask (broadcast on the feature dimension)
    # ------------------------------------------------------------------
    if not config.get("nomask", False):
        mask_f = mask.to(x.dtype).unsqueeze(-1)               # [B, N, N, 1]
        left = left * mask_f
        right = right * mask_f

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid of linear)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, weights["left_gate.weight"]))
    right_gate = torch.sigmoid(F.linear(x, weights["right_gate.weight"]))
    out_gate = torch.sigmoid(F.linear(x, weights["out_gate.weight"]))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Prepare for the Triton matmul: reshape to [B, H, N, N] → flatten
    # ------------------------------------------------------------------
    # Permute to bring the hidden dim next to batch for a contiguous view
    left = left.permute(0, 3, 1, 2).contiguous()   # [B, H, N, N]
    right = right.permute(0, 3, 1, 2).contiguous() # [B, H, N, N]

    # Cast to fp16 for the heavy kernel
    left = left.to(torch.float16)
    right = right.to(torch.float16)

    # Flatten batch+head dimension
    num_instances = B * hidden_dim
    left_flat = left.view(num_instances, N, N)
    right_flat = right.view(num_instances, N, N)

    # Output buffer (fp16)
    out_flat = torch.empty_like(left_flat)

    # ------------------------------------------------------------------
    # 6) Triton kernel launch
    # ------------------------------------------------------------------
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    # Strides (in elements, not bytes)
    stride_a_batch = left_flat.stride(0)   # N*N
    stride_a_row   = left_flat.stride(1)   # N
    stride_a_col   = left_flat.stride(2)   # 1

    stride_b_batch = right_flat.stride(0)          # N*N
    stride_b_orig_row = right_flat.stride(1)       # N
    stride_b_orig_col = right_flat.stride(2)       # 1
    # Transposed view
    stride_b_row_T = stride_b_orig_col   # 1
    stride_b_col_T = stride_b_orig_row   # N

    stride_c_batch = out_flat.stride(0)
    stride_c_row   = out_flat.stride(1)
    stride_c_col   = out_flat.stride(2)

    # Compute grid size
    total_m = (N + BLOCK_M - 1) // BLOCK_M
    total_n = (N + BLOCK_N - 1) // BLOCK_N
    tiles_per_instance = total_m * total_n
    grid = (num_instances * tiles_per_instance,)

    _batched_matmul_kernel[grid](
        left_flat,
        right_flat,
        out_flat,
        num_instances,
        N,
        stride_a_batch,
        stride_a_row,
        stride_a_col,
        stride_b_batch,
        stride_b_row_T,
        stride_b_col_T,
        stride_c_batch,
        stride_c_row,
        stride_c_col,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------
    # 7) Reshape back to [B, N, N, hidden_dim] (float32)
    # ------------------------------------------------------------------
    out = (
        out_flat.view(B, hidden_dim, N, N)      # [B, H, N, N]
        .permute(0, 2, 3, 1)                     # [B, N, N, H]
        .to(torch.float32)
    )

    # ------------------------------------------------------------------
    # 8) Post‑processing: to_out_norm, gate, final linear
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=eps,
    )
    out = out * out_gate
    out = F.linear(out, weights["to_out.weight"])

    return out
