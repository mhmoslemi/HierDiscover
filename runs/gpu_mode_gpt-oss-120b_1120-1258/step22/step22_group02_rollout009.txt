Highly‑optimized outgoing TriMul (AlphaFold3) forward pass.

Algorithm
---------
1️⃣  Row‑wise LayerNorm on the flattened pairwise tensor (FP32 → FP16) using
    torch.nn.functional.layer_norm (highly‑tuned cuDNN kernel).

2️⃣  Fuse the five linear projections (left, right, left_gate, right_gate,
    out_gate) into a single GEMM:   proj = norm @ W_fusedᵀ   (FP16).

3️⃣  Split the fused projection, optionally mask the pairwise entries,
    apply sigmoid gates and store three tensors
    `left`, `right`, `out_gate` in layout [B, H, N, N] (FP16).

4️⃣  Batched GEMM over the hidden dimension (cuBLAS):
        out[b, h, i, j] = Σₖ left[b, h, i, k] * right[b, h, j, k]   (FP16).

5️⃣  Row‑wise mean & rsqrt‑variance of `out` (second LayerNorm) – Triton.

6️⃣  Fuse the second LayerNorm, the `out_gate` multiplication and the final

All heavy‑compute parts are written in Triton; the rest uses
torch.nn.functional for the best possible CUDA kernels.

# 2️⃣ Split fused projection + mask + sigmoid gates
# ----------------------------------------------------------------------
@triton.jit
def split_fuse_gate_kernel(
    proj_ptr,          # [R, 5·H]  fp16
    left_ptr,          # [B, H, N, N] fp16
    right_ptr,         # [B, H, N, N] fp16
    gate_ptr,          # [B, H, N, N] fp16  (out_gate)
    mask_ptr,          # [R]      fp16 (ignored if HAS_MASK==0)
    R, H, N,
    HAS_MASK: tl.constexpr,
    BLOCK_R: tl.constexpr, BLOCK_H: tl.constexpr,
):
    pid = tl.program_id(0)
    row_start = pid * BLOCK_R
    offs_r = row_start + tl.arange(0, BLOCK_R)               # [BLOCK_R]
    mask_r = offs_r < R

    # Decode flat pair index: r = b·N·N + i·N + k
    nn = N * N
    b = offs_r // nn
    rem = offs_r - b * nn
    i = rem // N
    k = rem - i * N

    if HAS_MASK:
        m_val = tl.load(mask_ptr + offs_r, mask=mask_r, other=1.0)   # fp16

        mask_h = offs_h < H

        proj_base = offs_r[:, None] * (5 * H) + offs_h[None, :]   # [R, H]

                                 mask=mask_r[:, None] & mask_h[None, :],
