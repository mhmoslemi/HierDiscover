custom_kernel – “outgoing” TriMul (AlphaFold‑3) implementation.

Algorithm
---------
1️⃣ Row‑wise LayerNorm over the input channel dim (`dim`).  Implemented in
   Triton to avoid a global reduction per row.
2️⃣ Cast to FP16 and fuse each projection + gate pair (left/right) into a
   single GEMM (weights are concatenated, bias‑free).  The output‑gate
   is also computed in FP16.
3️⃣ Apply the optional mask (broadcast over the hidden dim) and the
   sigmoid‑gates.
4️⃣ Triangular multiplicative update:
        out_h[i,j] = Σ_k left_h[i,k] · right_h[j,k]
   is exactly a batched matrix‑multiply `left @ rightᵀ` for every
   `(batch, hidden_dim)` pair.  We reshape to `(B*H, N, N)` and use
   `torch.bmm` on FP16 tensors.
5️⃣ Second LayerNorm over the hidden dimension (`hidden_dim`).  Again a
   Triton kernel.
6️⃣ Apply the output‑gate (sigmoid), a final FP16 linear projection back
   to `dim`, and cast the result to FP32.

All heavy reductions (the two LayerNorms) run in Triton, while the
dense linear algebra uses PyTorch’s highly‑optimised FP16 kernels.  The
implementation works for every configuration described in the prompt
(different batch sizes, sequence lengths, channel sizes, and with/without
mask).
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: row‑wise LayerNorm (float32)
# ----------------------------------------------------------------------
@triton.jit
def layernorm_kernel(
    x_ptr,          # const float*  [total_rows, dim]
    y_ptr,          #       float*  [total_rows, dim]
    w_ptr,          # const float*  [dim]   (γ)
    b_ptr,          # const float*  [dim]   (β)
    total_rows,     # int (runtime)
    dim: tl.constexpr,          # static dimension size
    eps: tl.constexpr,          # static epsilon
    BLOCK_M: tl.constexpr,      # rows per program
    BLOCK_D: tl.constexpr,      # columns per inner loop
):
    """
    Row‑wise LayerNorm for a 2‑D tensor stored in row‑major order.
    Computes:
        y = (x - μ) / √(σ² + eps) * γ + β
    """
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)          # [BLOCK_M]
    mask_m = offs_m < total_rows

    # ------------------------------------------------------------------
    # Pass 1 – compute mean and variance per row
    # ------------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

        offs_d = d * BLOCK_D + tl.arange(0, BLOCK_D)    # [BLOCK_D]

        ptrs = x_ptr + offs_m[:, None] * dim + offs_d[None, :]

            ptrs,
            mask=mask_m[:, None] & mask_d[None, :],
            other=0.0,
        ).to(tl.float32)                               # [BLOCK_M, BLOCK_D]

        sum_val += tl.sum(vals, axis=1)                # row‑wise sum
        sum_sq  += tl.sum(vals * vals, axis=1)         # row‑wise sum of squares

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)                         # 1 / √(var+eps)

    # ------------------------------------------------------------------
    # Pass 2 – write normalized values with γ (weight) and β (bias)
    # ------------------------------------------------------------------

# ----------------------------------------------------------------------
