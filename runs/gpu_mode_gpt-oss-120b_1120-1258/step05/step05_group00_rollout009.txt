assistantfinal**Solution Overview**

The outgoing TriMul update consists of three heavy building blocks:

1. **Row‑wise LayerNorm** – applied to the input tensor and later to the
   hidden representation.  A tiny Triton kernel computes mean / variance per
   row, normalises the data and writes the result in FP16.  (Only one kernel
   is required to satisfy the “must use Triton” rule.)

2. **Fused linear projection & gating** – the four linear layers
   (`left_proj`, `right_proj`, `left_gate`, `right_gate`) share the same
   input, therefore we concatenate their weight matrices and perform a single
   GEMM (`[R, dim] @ [4·H, dim]ᵀ → [R, 4·H]`).  The result is split into the
   four tensors, the optional mask is applied, and the three sigmoid gates
   are evaluated in‑place.

3. **Tri‑multiplicative update** – for every head `h` we need

   ```
   out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   ```

   This is exactly a batched matrix multiplication over the `k` axis.
   Using `torch.einsum` (`'b i k h, b j k h -> b i j h'`) lets PyTorch
   invoke a cuBLAS‑based GEMM without any explicit permutation or copy,
   saving a large amount of memory traffic.

4. **Second LayerNorm → output gate → final linear** – the hidden tensor
   (`[B·N·N, H]`) is normalised with the same Triton kernel, multiplied by the
   output gate, and projected back to the original dimension with a final
   FP16 GEMM.  The result is cast back to FP32 to match the reference
   implementation.

All heavy matrix multiplications are left to cuBLAS (Tensor‑Cores) while the
row‑wise normalisations are performed by a custom Triton kernel.  The overall
memory footprint is kept low by re‑using buffers and by performing the mask
and sigmoid operations in‑place.

```python
"""
Highly‑optimised outgoing TriMul (AlphaFold‑3) forward pass.

Algorithm
---------
1️⃣ Row‑wise LayerNorm on the input  → fp16 (Triton)
2️⃣ Fuse the four projection/gate Linear layers into one GEMM:
   `[R, dim] @ [4·H, dim]ᵀ → [R, 4·H]`.
3️⃣ Split, apply optional mask, sigmoid‑gate (in‑place) and obtain
   `left` and `right` tensors of shape [B, N, N, H] (fp16).
4️⃣ Tri‑multiplicative update:
   `out = einsum('b i k h, b j k h -> b i j h', left, right)`
   → batched GEMM (cuBLAS, Tensor‑Cores).
5️⃣ Second row‑wise LayerNorm on the hidden tensor → fp16 (Triton).
6️⃣ Multiply by the output gate and project back to `dim` with a final
   GEMM.  Cast the result to float32.

Only the two layer‑norms are implemented in Triton; all large GEMMs use
cuBLAS for maximal throughput on an H100.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: row‑wise LayerNorm (float32 → fp16)
# ----------------------------------------------------------------------
@triton.jit
def layernorm_kernel(
    x_ptr,               # const   * [total_rows, dim]   (float32)
    y_ptr,               # mutable * [total_rows, dim]   (float16)
    weight_ptr,          # const   * [dim]               (float32)
    bias_ptr,            # const   * [dim]               (float32)
    total_rows,          # int (runtime)
    dim,                 # int (runtime)
    eps,                 # float (compile‑time constexpr)
    BLOCK_M: tl.constexpr,   # rows processed per program
    BLOCK_D: tl.constexpr,   # columns processed per inner loop
):
    """Row‑wise LayerNorm:
       y = ((x - μ) / sqrt(σ²+eps)) * γ + β
       Output is FP16, accumulation is FP32.
    """
    pid = tl.program_id(0)
    row_start = pid * BLOCK_M
    offs_m = row_start + tl.arange(0, BLOCK_M)          # [BLOCK_M]
    mask_m = offs_m < total_rows

    # ------------------------------------------------------------------
    # 1️⃣ Compute mean and variance per row
    # ------------------------------------------------------------------
    sum_val = tl.zeros([BLOCK_M], dtype=tl.float32)
    sum_sq  = tl.zeros([BLOCK_M], dtype=tl.float32)

    # loop over the feature dimension
    for d_off in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d_off * BLOCK_D + tl.arange(0, BLOCK_D)   # [BLOCK_D]
        mask_d = offs_d < dim
        ptrs = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptrs,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)          # fp32 load
        sum_val += tl.sum(vals, axis=1)
        sum_sq  += tl.sum(vals * vals, axis=1)

    mean = sum_val / dim
    var  = sum_sq / dim - mean * mean
    rstd = tl.rsqrt(var + eps)               # 1 / sqrt(var+eps)

    # ------------------------------------------------------------------
    # 2️⃣ Write normalised values γ·(x−μ)·rstd + β  (fp16)
    # ------------------------------------------------------------------
    for d_off in range(0, tl.cdiv(dim, BLOCK_D)):
        offs_d = d_off * BLOCK_D + tl.arange(0, BLOCK_D)
        mask_d = offs_d < dim
        ptrs = x_ptr + offs_m[:, None] * dim + offs_d[None, :]
        vals = tl.load(ptrs,
                       mask=mask_m[:, None] & mask_d[None, :],
                       other=0.0).to(tl.float32)

        norm = (vals - mean[:, None]) * rstd[:, None]

        w = tl.load(weight_ptr + offs_d, mask=mask_d, other=0.0)   # γ
        b = tl.load(bias_ptr   + offs_d, mask=mask_d, other=0.0)   # β
        out = norm * w[None, :] + b[None, :]                      # fp32

        out_fp16 = out.to(tl.float16)
        out_ptrs = y_ptr + offs_m[:, None] * dim + offs_d[None, :]
        tl.store(out_ptrs, out_fp16,
                 mask=mask_m[:, None] & mask_d[None, :])


# ----------------------------------------------------------------------
# Custom forward kernel for the outgoing TriMul operator
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.

    Args:
        data = (input_tensor, mask_tensor, weights_dict, config_dict)

        - input_tensor : torch.Tensor, shape [B, N, N, dim], dtype float32
        - mask_tensor  : torch.Tensor, shape [B, N, N] (bool/float) – may be
                         ignored when config["nomask"] == True
        - weights_dict : mapping with all Linear/LayerNorm parameters
        - config_dict  : must contain
                         * "dim"          – input/ output feature size
                         * "hidden_dim"   – hidden dimension H
                         * "nomask" (bool, optional)

    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask_tensor, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    eps = 1e-5
    device = input_tensor.device

    B, N, _, _ = input_tensor.shape
    total_rows = B * N * N                         # R = B·N·N
    H = hidden_dim

    # ------------------------------------------------------------------
    # 1️⃣ First LayerNorm (row‑wise) → FP16
    # ------------------------------------------------------------------
    x_flat = input_tensor.view(total_rows, dim).contiguous()           # [R, dim] float32
    x_norm_half = torch.empty(total_rows, dim,
                              dtype=torch.float16,
                              device=device)

    # kernel launch parameters – tuned for H100
    BLOCK_M = 256                # rows per program
    BLOCK_D = 64                 # columns per inner loop (covers dim up to 384)
    grid = (triton.cdiv(total_rows, BLOCK_M),)
    layernorm_kernel[grid](
        x_flat,
        x_norm_half,
        weights["norm.weight"],          # γ (float32)
        weights["norm.bias"],            # β (float32)
        total_rows,
        dim,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
        num_warps=4,
    )

    # ------------------------------------------------------------------
    # 2️⃣ Fuse left/right projections + their two gates into ONE GEMM
    # ------------------------------------------------------------------
    # concatenate the four projection/gate weight matrices (shape: [4·H, dim])
    w_concat_4h = torch.cat(
        [
            weights["left_proj.weight"],   # (H, dim)
            weights["right_proj.weight"],  # (H, dim)
            weights["left_gate.weight"],   # (H, dim)
            weights["right_gate.weight"],  # (H, dim)
        ],
        dim=0,
    ).to(torch.float16)                                            # [4·H, dim]

    # single linear pass: [R, dim] @ [4·H, dim].T → [R, 4·H]  (fp16)
    proj_gate = F.linear(x_norm_half, w_concat_4h)                 # [R, 4·H]

    # split the concatenated result
    left_proj_raw  = proj_gate[:, 0:H]               # [R, H]
    right_proj_raw = proj_gate[:, H:2 * H]           # [R, H]
    left_gate_raw  = proj_gate[:, 2 * H:3 * H]       # [R, H]
    right_gate_raw = proj_gate[:, 3 * H:4 * H]       # [R, H]

    # output gate (separate linear)
    out_gate_raw = F.linear(
        x_norm_half,
        weights["out_gate.weight"].to(torch.float16)       # (H, dim) → (H, dim) after transposition
    )                                                       # [R, H]

    # ------------------------------------------------------------------
    # 3️⃣ Optional mask, sigmoid gates, gating
    # ------------------------------------------------------------------
    if not config.get("nomask", True):
        # mask shape [B, N, N] → flatten to [R, 1] (fp16)
        mask_h = mask_tensor.to(torch.float16).reshape(total_rows, 1)
        left_proj_raw = left_proj_raw * mask_h
        right_proj_raw = right_proj_raw * mask_h

    # in‑place sigmoid (no extra buffers)
    left_gate  = left_gate_raw.sigmoid_()
    right_gate = right_gate_raw.sigmoid_()
    out_gate   = out_gate_raw.sigmoid_()

    # element‑wise gating
    left  = left_proj_raw * left_gate      # [R, H] fp16
    right = right_proj_raw * right_gate    # [R, H] fp16

    # ------------------------------------------------------------------
    # 4️⃣ Reshape for the N³ multiplicative update
    # ------------------------------------------------------------------
    left  = left.view(B, N, N, H)          # [B, N, N, H]
    right = right.view(B, N, N, H)         # [B, N, N, H]
    out_gate = out_gate.view(B, N, N, H)   # [B, N, N, H]

    # Batched matmul via einsum – no explicit transposes / copies
    # out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    out = torch.einsum('b i k h, b j k h -> b i j h', left, right)  # fp16

    # ------------------------------------------------------------------
    # 5️⃣ Second LayerNorm over the hidden dimension → fp16
    # ------------------------------------------------------------------
    out_flat = out.view(total_rows, H).contiguous()
    out_norm_half = torch.empty_like(out_flat, dtype=torch.float16)

    grid2 = (triton.cdiv(total_rows, BLOCK_M),)
    layernorm_kernel[grid2](
        out_flat,
        out_norm_half,
        weights["to_out_norm.weight"],   # γ (float32)
        weights["to_out_norm.bias"],     # β (float32)
        total_rows,
        H,
        eps,
        BLOCK_M=BLOCK_M,
        BLOCK_D=BLOCK_D,
        num_warps=4,
    )

    out_norm = out_norm_half.view(B, N, N, H)   # fp16

    # ------------------------------------------------------------------
    # 6️⃣ Apply output gate and final projection (fp16 GEMM)
    # ------------------------------------------------------------------
    out_norm = out_norm * out_gate               # [B, N, N, H] fp16

    final_half = F.linear(
        out_norm.view(total_rows, H),            # [R, H]
        weights["to_out.weight"].to(torch.float16)  # (dim, H)
    )                                            # [R, dim] fp16

    # Cast back to float32 to match the reference implementation
    final = final_half.view(B, N, N, dim).to(torch.float32)

    return final
```
