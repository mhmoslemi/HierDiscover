Optimized forward‑only “outgoing” TriMul (AlphaFold‑3) using Triton.

Algorithm
---------
1. Input LayerNorm (FP32 → FP16 for speed).
2. Fuse four linear projections (left, right, left‑gate, right‑gate) into one
   GEMM, then reshape to (B, N, N, H) tensors (H = hidden_dim).
3. If a mask is present, a Triton kernel fuses:
     * loading of left/right projections,
     * sigmoid of gate pre‑activations,
     * element‑wise mask,
     * multiplication → gated & masked tensors.
   Otherwise cheap PyTorch sigmoid‑gate is applied.
4. Core contraction:
        out[b,i,j,h] = Σₖ left[b,i,k,h] * right[b,j,k,h]
   realized as a batched GEMM over (B·H) matrices:
        left[b,:, :,h] @ right[b,:, :,h]ᵀ
   (torch.bmm on a view of shape (B*H, N, N)).
5. Hidden‑dim LayerNorm (FP16), element‑wise output‑gate sigmoid, and final
   projection back to original channel dim (FP16 → FP32).
All heavy arithmetic is in FP16; the final result is cast to FP32 to match
the reference implementation.
"""

import torch.nn.functional as F
import triton
import triton.language as tl

# Triton kernel: apply mask, sigmoid‑gate and element‑wise multiplication
# ----------------------------------------------------------------------
@triton.jit
def _mask_gate_mul_kernel(
    # pointers (all tensors are half‑precision)
    left_ptr, right_ptr,               # (B,N,N,H) – will be overwritten
    left_gate_ptr, right_gate_ptr,     # (B,N,N,H) – pre‑gate values
    mask_ptr,                          # (B,N,N) – 0/1 mask (half)

    # problem size
    B, N, H,

    # strides (in elements, not bytes)

    stride_r_b, stride_r_i, stride_r_j, stride_r_h,

    stride_rg_b, stride_rg_i, stride_rg_j, stride_rg_h,

                         sigmoid(right_gate_pre[b,i,j,h]) *

    pid_j = tl.program_id(2)      # tile over j (seq dim)

            + h[None, None, :] * stride_r_h,

            other=0.0,
        )
        left_g = tl.load(
            left_gate_ptr
            + b * stride_lg_b
            + i[:, None, None] * stride_lg_i
            + j[None, :, None] * stride_lg_j
            + h[None, None, :] * stride_lg_h,
            mask=i_valid[:, None, None] & j_valid[None, :, None] & h_valid[None, None, :],

        )

            + j[None, :, None] * stride_rg_j

    Forward‑only outgoing TriMul.

    eps = config.get("layernorm_eps", 1e-5)

    right_proj_weight = weights["right_proj.weight"]      # (H, C)

    left_gate_weight = weights["left_gate.weight"]        # (H, C)
    right_gate_weight = weights["right_gate.weight"]      # (H, C)

        bias=norm_bias,
        eps=eps,
    )  # [B, N, N, C] float32

    x_fp16 = x.half()   # heavy path in FP16

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------

    right_proj = right_proj.view(B, N, N, hidden)

    # ------------------------------------------------------------------
    return out.float()
