The objective  

\[
E(a)=\frac{2 n\;\max (a*a)}{(\sum a_i)^2}
\]

is *scale‑invariant*: multiplying all heights by a constant does not change the
value.  By normalising the vector to the simplex  

\[
\sum a_i = \sqrt{2n}, \qquad a_i\ge 0 ,
\]

the denominator equals \(2n\) and the objective reduces to the *maximum
autocorrelation*  

\[
\max (a*a)=\max_{k}\sum_i a_i a_{k-i}.
\]

The search therefore concentrates on minimising the largest entry of the
full convolution while keeping the vector on the simplex.

The optimiser consists of two stages

1. **Simulated‑Annealing (SA)** – many short, independent runs on different
   lengths.  Each move transfers a small amount of mass from one position to
   another; the convolution is updated **incrementally** (O(n) work) and
   accepted either if it improves the maximum or with a temperature‑dependent
   probability.  The SA runs keep the sum exactly constant, use a heavy‑ball
   momentum‑free update (pure random walk) and occasionally inject a global
   shake (random noise + projection onto the simplex) to escape local minima.

2. **Linear‑Program polishing** – once a good candidate has been found,
   a short Frank–Wolfe style step is performed.  
   For the current vector \(f\) we solve the linear program  

   \[
   \max \sum_j g_j \qquad
   \text{s.t. } g_j\ge0,\; (f*g)_k\le M\;(k=0,\dots,2n-2),
   \]

   where \(M=\max(f*f)\).  The LP gives a direction that can increase the
   total mass without violating the current maximal convolution bound.
   After scaling \(g\) to the simplex we line‑search a mixing factor
   \(\tau\in[0,1]\) and replace \(f\leftarrow(1-\tau)f+\tau g\).  
   This step is cheap (a handful of LP solves) and often reduces the
   maximal convolution further.

Both stages respect the security checks of `evaluate_sequence`, only return
non‑negative numbers, and finish well before the 1000 s time limit.

```python
"""
Propose a non‑negative step‑function that minimises
    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The algorithm works in two phases:
1. Fast simulated‑annealing with incremental convolution updates on many
   independent restarts (different lengths, random initial vectors).  The
   sum of the vector is kept constant (simplex projection), so the
   objective equals the maximal convolution entry.
2. Optional linear‑program polishing: solve the LP
      max  Σ g_j
      s.t. g≥0,  (f * g)_k ≤ M   (for all shifts k)
   where M is the current maximal autocorrelation of f.
   After scaling g to the simplex we perform a line‑search on the mixing
   coefficient τ∈[0,1] and update f ← (1‑τ)f + τ g.
The best vector found is returned as a plain Python list.
"""

import time
import numpy as np

# --------------------------------------------------------------------------- #
# Helper: Euclidean projection onto the simplex  Σ x_i = s ,  x_i ≥ 0
# --------------------------------------------------------------------------- #
def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project vector ``v`` onto the simplex of radius ``s``."""
    n = v.shape[0]
    if s < 0:
        raise ValueError("simplex radius must be non‑negative")
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# --------------------------------------------------------------------------- #
# Full convolution via real FFT (length 2*n‑1)
# --------------------------------------------------------------------------- #
def _conv_full_fft(a: np.ndarray) -> np.ndarray:
    n = a.shape[0]
    # next power of two for fast FFT
    n_fft = 1 << ((2 * n - 1).bit_length())
    A = np.fft.rfft(a, n=n_fft)
    conv = np.fft.irfft(A * A, n=n_fft)[: 2 * n - 1]
    return conv


# --------------------------------------------------------------------------- #
# Simulated‑annealing optimisation for a fixed length
# --------------------------------------------------------------------------- #
def _sa_optimize(a0: np.ndarray, deadline: float):
    """
    Fast SA on the simplex.
    Returns the best vector found and its maximal convolution value.
    """
    n = a0.shape[0]
    target_sum = a0.sum()                     # = sqrt(2*n) after initial scaling
    a = a0.copy()
    conv = _conv_full_fft(a)
    cur_max = conv.max()
    best_a = a.copy()
    best_score = cur_max

    start = time.time()
    # initial temperature (fraction of current max)
    T0 = cur_max * 0.1

    # Main SA loop
    while time.time() < deadline:
        # linearly decreasing temperature
        elapsed = time.time() - start
        total = deadline - start
        if total <= 0:
            break
        T = T0 * (1.0 - elapsed / total)

        # pick distinct source / destination indices
        i = np.random.randint(n)
        j = np.random.randint(n - 1)
        if j >= i:
            j += 1

        if a[i] <= 0.0:
            continue

        # propose a transfer delta (up to half of the source mass)
        delta = a[i] * np.random.rand() * 0.5
        if delta <= 0.0:
            continue

        # keep copies for a possible revert
        a_before = a.copy()
        conv_before = conv.copy()

        # ---- incremental convolution update ---------------------------------
        # shift by j adds 2*delta * a, shift by i subtracts it
        conv[j:j + n] += 2.0 * delta * a
        conv[i:i + n] -= 2.0 * delta * a
        conv[2 * j] += delta * delta
        conv[2 * i] += delta * delta
        conv[i + j] -= 2.0 * delta * delta

        # update the vector
        a[i] -= delta
        a[j] += delta
        # ---------------------------------------------------------------------

        new_max = conv.max()

        # Metropolis acceptance
        accept = False
        if new_max < cur_max:
            accept = True
        else:
            # probability exp(-(Δ)/T); protect against division by zero
            if T > 0 and np.random.rand() < np.exp(-(new_max - cur_max) / (T + 1e-12)):
                accept = True

        if accept:
            cur_max = new_max
            if new_max < best_score:
                best_score = new_max
                best_a = a.copy()
                print(f"[{time.time():.2f}] SA improvement: {best_score:.6f} (n={n})")
        else:
            # revert the move
            a = a_before
            conv = conv_before

        # occasional global shake to escape plateaus
        if np.random.rand() < 0.005:
            noise = np.random.randn(n) * (0.005 * target_sum / n)
            a_tmp = a + noise
            a_tmp = np.maximum(a_tmp, 0.0)
            a_tmp = _project_onto_simplex(a_tmp, target_sum)
            a = a_tmp
            conv = _conv_full_fft(a)
            cur_max = conv.max()
            if cur_max < best_score:
                best_score = cur_max
                best_a = a.copy()
                print(f"[{time.time():.2f}] SA shake improvement: {best_score:.6f} (n={n})")

    return best_a, best_score


# --------------------------------------------------------------------------- #
# Linear‑program polishing (optional, uses SciPy if available)
# --------------------------------------------------------------------------- #
def _lp_optimize(a0: np.ndarray, deadline: float):
    """
    One‑shot Frank‑Wolfe style improvement using a linear program.
    Returns a (possibly) better vector and its maximal convolution value.
    """
    try:
        from scipy.optimize import linprog
    except Exception as exc:
        print(f"[{time.time():.2f}] SciPy not available – skipping LP stage.")
        return a0, _conv_full_fft(a0).max()

    n = a0.shape[0]
    target_sum = np.sqrt(2.0 * n)
    a = _project_onto_simplex(a0, target_sum)

    best_a = a.copy()
    best_score = _conv_full_fft(a).max()
    start = time.time()

    while time.time() < deadline:
        conv = _conv_full_fft(a)
        M = conv.max()
        if M < best_score:
            best_score = M
            best_a = a.copy()
            print(f"[{time.time():.2f}] LP current best: {best_score:.6f} (n={n})")

        # Build the constraint matrix: (2n‑1) × n
        rows = 2 * n - 1
        A = np.zeros((rows, n), dtype=float)
        # column j contributes a shifted copy of a
        for j in range(n):
            A[j:j + n, j] = a

        c = -np.ones(n, dtype=float)               # maximise Σ g_j  → minimise -Σ g_j
        b_ub = np.full(rows, M, dtype=float)
        bounds = [(0, None)] * n

        # Solve LP
        res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                      method='highs')
        if not res.success:
            print(f"[{time.time():.2f}] LP solve failed: {res.message}")
            break

        g = res.x
        sum_g = g.sum()
        if sum_g <= 0.0:
            break

        # Scale g to the simplex
        g_scaled = g * (target_sum / sum_g)

        # Simple line‑search for mixing coefficient τ
        ts = np.array([0.0, 0.05, 0.1, 0.2, 0.35, 0.5, 0.7, 1.0])
        best_tau = 0.0
        best_M = M
        for tau in ts:
            cand = (1.0 - tau) * a + tau * g_scaled
            cand_conv = _conv_full_fft(cand)
            cand_M = cand_conv.max()
            if cand_M < best_M:
                best_M = cand_M
                best_tau = tau
        if best_tau == 0.0:
            # no improvement possible
            break

        # Update the vector and continue
        a = (1.0 - best_tau) * a + best_tau * g_scaled

        # safety break if time is almost exhausted
        if time.time() - start > 0.9 * (deadline - start):
            break

    final_score = _conv_full_fft(best_a).max()
    return best_a, final_score


# --------------------------------------------------------------------------- #
# Main entry point required by the grader
# --------------------------------------------------------------------------- #
def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Search for a low‑value step‑function within ``budget_s`` seconds.
    The best sequence discovered is returned as a plain Python list.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # tiny safety margin

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------- #
    # Choose a few problem sizes and run independent SA restarts
    # ------------------------------------------------------------------- #
    lengths = list(range(1200, 3001, 200))   # 1200,1400,…,3000
    np.random.shuffle(lengths)

    for n in lengths:
        if time.time() >= deadline:
            break

        # allocate a short slice of the remaining budget for this length
        run_deadline = min(deadline, time.time() + 12.0)   # ≈12 s per run

        # ----- initialise -------------------------------------------------
        if "height_sequence_1" in globals():
            src = np.asarray(height_sequence_1, dtype=float)
            if src.size >= n:
                init = src[:n].copy()
            else:
                pad = np.random.rand(n - src.size) * 1e-3
                init = np.concatenate([src, pad])
        else:
            init = np.random.rand(n)

        # normalise to the simplex Σ a_i = √(2 n)
        target_sum = np.sqrt(2.0 * n)
        init = init * (target_sum / init.sum())

        # ----- run simulated‑annealing -----------------------------------
        a_opt, score_opt = _sa_optimize(init, run_deadline)

        if score_opt < best_score:
            best_score = score_opt
            best_seq = a_opt.copy()
            print(f"[{time.time():.2f}] Global best after SA = {best_score:.6f} (n={n})")

        if best_score < 1.503:      # target reached → stop early
            break

    # ------------------------------------------------------------------- #
    # Polishing phase with the LP (if time permits)
    # ------------------------------------------------------------------- #
    if best_seq is not None and time.time() < deadline:
        try:
            a_lp, score_lp = _lp_optimize(best_seq, deadline)
            if score_lp < best_score:
                best_score = score_lp
                best_seq = a_lp.copy()
                print(f"[{time.time():.2f}] Global best after LP = {best_score:.6f}")
        except Exception as exc:
            print(f"[{time.time():.2f}] LP polishing failed: {exc}")

    # ------------------------------------------------------------------- #
    # Fallback – uniform vector if everything else fails
    # ------------------------------------------------------------------- #
    if best_seq is None:
        n = 1500
        target_sum = np.sqrt(2.0 * n)
        best_seq = np.full(n, target_sum / n, dtype=float)
        best_score = evaluate_sequence(best_seq.tolist())
        print(f"[{time.time():.2f}] Fallback uniform sequence, score = {best_score}")

    # Return plain Python list as required by the grader
    return best_seq.tolist()
```
