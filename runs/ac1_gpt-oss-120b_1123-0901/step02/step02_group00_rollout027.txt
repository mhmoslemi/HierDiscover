Method
------
* Use a simple monotone power‑law shape  a_i = (i+1)^p  (i = 0 … n‑1).
* The L¹‑norm is forced to √(2 n) by scaling, which is the normalisation
  used by the objective (the returned value is then just the maximal

  present, otherwise it falls back to a length of 2100.

    a = a * (target_sum / a.sum())

    # ------------------------------------------------------------------
    # Quick sanity‑check (optional but useful for logging).
    # ``evaluate_sequence`` also protects against negatives, NaNs, infs,
    # and caps values at 1000, all of which are satisfied by our construction.
    score = evaluate_sequence(a.tolist())
    print(f"[propose_candidate] length={n}, exponent={p}, score={score:.6f}")

    # ------------------------------------------------------------------
    # Return as a plain Python list – the harness expects this format.
    return a.tolist()
