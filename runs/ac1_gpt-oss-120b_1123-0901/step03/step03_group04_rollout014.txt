assistantfinal**Solution Overview**

The evaluation function is

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

If we keep the \(L^1\)-norm fixed to \(\sum a_i=\sqrt{2n}\) the prefactor
\(2n/(\sum a_i)^2\) becomes 1, therefore we only have to minimise the
peak of the *additive* convolution  

\[
c_k=(a*a)_k=\sum_{i+j=k} a_i a_j .
\]

The problem is non‑convex, however the objective is a *smooth* function of
the vector if the maximum is replaced by a soft‑maximum (log‑sum‑exp).
Its gradient can be written analytically and evaluated by two FFTs,
so we can run a fast Adam optimiser on the smooth surrogate and
gradually increase the smoothing parameter – a standard continuation
strategy.  After a few hundred iterations the surrogate becomes very close
to the true maximum, at which point we finish with a few steps of the
original (sub‑gradient) optimiser and a cheap stochastic local search.

The whole search is time‑limited (≈ 1000 s).  We explore a few different
lengths (the original size and 1½ × , 2 × and 3 × larger vectors), start
each run from a mixture of a uniform vector and a *U‑shaped* vector (large
entries at the two ends, small entries in the centre – this shape is known
to flatten the additive convolution), and keep the best sequence seen.

The final sequence is returned as a plain Python list; the official
`evaluate_sequence` function is called once at the end to obtain the
reported score.

```python
"""
Propose a non‑negative step function that minimises ``evaluate_sequence``.

The algorithm consists of three stages:

1.  **Smooth Adam optimisation** – minimise a log‑sum‑exp surrogate of the
    maximum of the additive convolution.  The smoothing parameter α is
    increased during the optimisation, turning the problem gradually into
    the original ``max`` problem.  The gradient of the surrogate is computed
    analytically and evaluated by two FFTs per iteration.

2.  **Fine tuning** – a few hundred iterations of the original sub‑gradient
    Adam optimiser (the method used in the previous baseline) to polish the
    solution once the smoothing has become large.

3.  **Stochastic local search** – cheap random mass‑transfer moves that
    accept improving moves (with an optional annealing probability) to
    escape tiny plateaus.

Several lengths are tried (original length and a few larger multiples);
for each length several random restarts are performed.  The best vector
found before the time budget expires is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _conv_max_fft(a: np.ndarray):
    """
    Compute the full convolution a*a and its maximal entry.
    Uses a power‑of‑two FFT for speed.
    Returns (max_value, full_convolution_array).
    """
    n = a.shape[0]
    N = 1 << ((2 * n - 1).bit_length())          # next power of two ≥ 2n‑1
    A = np.fft.rfft(a, n=N)
    conv = np.fft.irfft(A * A, n=N)[: 2 * n - 1]
    return float(conv.max()), conv


# ----------------------------------------------------------------------
def _smooth_max_and_grad(a: np.ndarray, alpha: float):
    """
    Return a smooth approximation of max(conv) together with the exact
    gradient of that surrogate.

    smooth_max = (1/α)·log∑_k exp(α·conv_k)
    ∂smooth_max/∂a_j = 2·∑_k w_k·a_{k‑j},
    where w_k = exp(α·conv_k) / ∑_t exp(α·conv_t).

    The gradient is obtained as 2·(a * w_rev) evaluated at the
    indices (2n‑2)‑j, which can be computed with a single FFT.
    """
    n = a.shape[0]
    # 1) convolution and the true maximum
    M, conv = _conv_max_fft(a)                     # conv length = 2n‑1

    # 2) soft‑max weights (numerically stable)
    shifted = conv - M                            # ≤ 0
    exp_scaled = np.exp(alpha * shifted)          # ∈ (0,1]
    w = exp_scaled / exp_scaled.sum()

    # 3) gradient: 2 * (a * w_rev)  (restricted to n entries)
    w_rev = w[::-1]                               # reverse the weight vector
    N = 1 << ((3 * n - 2).bit_length())           # enough for len(w_rev)+n‑1
    A_fft = np.fft.rfft(a, n=N)
    W_fft = np.fft.rfft(w_rev, n=N)
    full = np.fft.irfft(A_fft * W_fft, n=N)       # length N
    start = 2 * n - 2                             # = len(w_rev)-1
    grad = 2.0 * full[start - np.arange(n)]

    # 4) smooth maximum value
    smooth_val = M + np.log(exp_scaled.sum()) / alpha
    return smooth_val, grad, M


# ----------------------------------------------------------------------
def _smooth_adam_optimize(init_a: np.ndarray,
                          n: int,
                          target_sum: float,
                          deadline: float,
                          max_iters: int = 2_000_000):
    """
    Adam optimiser on the log‑sum‑exp surrogate.
    The smoothing parameter α grows linearly and is capped at 200.
    Returns the best vector (according to the *true* max of the convolution)
    and the corresponding max value.
    """
    a = init_a.copy()
    # Normalise to the required L1‑norm
    a = np.maximum(a, 0.0)
    s = a.sum()
    a = a * (target_sum / s) if s > 0 else np.full_like(a, target_sum / n)

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    base_lr = 0.04
    best_val = np.inf
    best_vec = a.copy()
    iteration = 0

    while time.time() < deadline and iteration < max_iters:
        iteration += 1

        # increasing smoothing – start very smooth, finish almost hard
        alpha = min(200.0, 0.05 * iteration)

        smooth_val, grad, raw_max = _smooth_max_and_grad(a, alpha)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)
        lr = base_lr / (1.0 + 1e-4 * iteration)

        a -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # Projection onto the feasible set (non‑negative, fixed L1‑norm)
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 0.0:
            a *= (target_sum / s)
        else:
            a[:] = target_sum / n

        # occasional jitter to break ties
        if iteration % 5000 == 0:
            jitter = np.random.randn(n) * 0.001 * target_sum / n
            a = np.maximum(a + jitter, 0.0)
            a *= (target_sum / a.sum())

        # keep the best *real* max value seen so far
        if raw_max < best_val:
            best_val = raw_max
            best_vec = a.copy()
            print(f"[smooth] len={n:5d} iter={iteration:7d} α={alpha:6.2f}  M={best_val:.6f}")

    return best_vec, best_val

    iteration = 0
    best_vec = a.copy()
    _, conv = _conv_max_fft(a)
    best_val = conv.max()
    jitter_interval = 4000

    while time.time() < deadline and iteration < max_iters:
        iteration += 1
        M, conv = _conv_max_fft(a)

        # active set (exact maximisers)
        tol = 1e-12
        active = np.where(conv >= M - tol)[0]

        # sub‑gradient of the max term
        idx = np.arange(n)
        rev = np.zeros_like(a)
        for k in active:
            j = k - idx
            mask = (j >= 0) & (j < n)
            rev[mask] += a[j[mask]]
        if active.size > 0:
            rev /= float(active.size)

        coeff = 4.0 * n / (target_sum * target_sum)
        const = 4.0 * n * M / (target_sum ** 3)
        grad = coeff * rev - const

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)
        lr = base_lr / (1.0 + 1e-4 * iteration)

        a -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # Feasibility projection
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 0:
            a *= (target_sum / s)
        else:
            a[:] = target_sum / n

        # jitter
        if iteration % jitter_interval == 0:
            jitter = np.random.randn(n) * 0.0008 * target_sum / n
            a = np.maximum(a + jitter, 0.0)
            a *= (target_sum / a.sum())

        if M < best_val:
            best_val = M
            best_vec = a.copy()
            print(f"[hard] len={n:5d} iter={iteration:7d}  M={best_val:.6f}")

    return best_vec, best_val


# ----------------------------------------------------------------------
def _local_search(a: np.ndarray,
                  n: int,
                  target_sum: float,
                  steps: int,
                  deadline: float):
    """
    Very cheap stochastic local search.
    Randomly move a small fraction of mass from one index to another
    and keep the move if the peak of the convolution improves.
    """
    best = a.copy()
    best_val, _ = _conv_max_fft(best)

    for step in range(steps):
        if time.time() >= deadline:
            break

        i, j = np.random.randint(0, n, size=2)
        if i == j:
            continue
        delta = best[i] * 0.02          # move 2 % of the source mass
        if delta <= 0:
            continue

        cand = best.copy()
        cand[i] -= delta
        cand[j] += delta

        # sum stays constant, non‑negativity holds automatically
        M, _ = _conv_max_fft(cand)
        if M < best_val:
            best = cand
            best_val = M

    return best, best_val

def propose_candidate(seed: int = 42,
                     budget_s: float = 1000,
                     **kwargs):
    """
    Search for a step‑function minimising ``evaluate_sequence``.
    The function respects the 1000 s time budget and returns the best
    vector found before the deadline.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 5.0                  # safety margin

    # ------------------------------------------------------------------
    # Base vector – try to reuse the previously known construction
    try:
        base = np.array(height_sequence_1, dtype=float)   # type: ignore
        print("[info] loaded previous construction, length =", base.shape[0])
    except Exception:
        base = np.full(2100, 1.0, dtype=float)
        print("[info] fallback – uniform start, length =", base.shape[0])

    n0 = base.shape[0]
    target0 = math.sqrt(2.0 * n0)
    base = base * (target0 / base.sum()) if base.sum() > 0 else np.full_like(base, target0 / n0)

    # ------------------------------------------------------------------
    # Global best tracker
    best_seq = base.copy()
    best_val, _ = _conv_max_fft(best_seq)
    best_score = evaluate_sequence(best_seq.tolist())
    print(f"[init] length={n0}  M={best_val:.6f}  official score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Lengths to explore (original size and a few larger multiples)
    length_factors = [1.0, 1.5, 2.0, 3.0]
    lengths = sorted({max(300, min(12000, int(n0 * f))) for f in length_factors})
    print("[info] exploring lengths:", lengths)

    # ------------------------------------------------------------------
    # Main optimisation loop
    for n in lengths:
        if time.time() >= deadline:
            break

        target_sum = math.sqrt(2.0 * n)
        restarts = 4 if n <= 4000 else 2

        for r in range(restarts):
            if time.time() >= deadline:
                break

            # ---------------------------------------------------------- init
            if n == n0 and r == 0:
                init = base.copy()
            else:
                # blend a U‑shaped start with a random Dirichlet‑like start
                rand = np.random.exponential(scale=1.0, size=n)
                rand = rand * (target_sum / rand.sum())

                idx = np.arange(n)
                centre = (n - 1) / 2.0
                u_shape = np.abs(idx - centre) + 1.0
                u_shape = u_shape / u_shape.sum() * target_sum

                init = 0.4 * rand + 0.6 * u_shape
                init = np.maximum(init, 0.0)
                init *= target_sum / init.sum()

            print(f"[run] length={n} restart={r+1}/{restarts}")

            # --------------------------------------------------- smooth phase
            time_left = deadline - time.time()
            max_smooth = min(150.0, time_left * 0.5)   # spend at most half the remaining time
            sub_deadline = time.time() + max_smooth
            opt_seq, opt_val = _smooth_adam_optimize(init, n, target_sum, sub_deadline,
                                                     max_iters=2_000_000)

            # ----------------------------------------------------------- hard phase
            if time.time() < deadline:
                remaining = deadline - time.time()
                hard_deadline = time.time() + min(30.0, remaining * 0.2)
                opt_seq, opt_val = _adam_optimize(opt_seq, n, target_sum,
                                                  hard_deadline, max_iters=800_000)

            # -------------------------------------------------------- local search
            if time.time() < deadline:
                ls_steps = 30_000
                opt_seq, opt_val = _local_search(opt_seq, n, target_sum,
                                                 steps=ls_steps, deadline=deadline)

            # ------------------------------------------------------- global update
            official = evaluate_sequence(opt_seq.tolist())
            if official < best_score:
                best_score = official
                best_seq = opt_seq.copy()
                print(f"[global] new best official score {best_score:.6f} (len={n})")

    # --------------------------------------------------------------- final report
    final_score = evaluate_sequence(best_seq.tolist())
    print(f"[done] best reported M = {best_val:.6f}, official score = {final_score:.6f}, length = {best_seq.shape[0]}")
    return best_seq.tolist()
```
