The evaluation function  

\[
F(a)=\frac{2\,n\;\max (a*a)}{\bigl(\sum_i a_i\bigr)^2}
\]

is invariant under the rescaling  

\[
\sum_i a_i=\sqrt{2n}\; .
\]

When the sum is fixed to this value the objective reduces to the
maximum entry of the self‑convolution, i.e. we have to **flatten**
the convolution as much as possible.

The program below searches for a vector `a` that minimises that
maximum.  The main ideas are

* **projected Adam** – an adaptive gradient method that respects the
  simplex constraint (`a_i≥0, Σa_i = √{2n}`) by projecting after each step.
* **smooth‑max** – the non‑smooth `max` is replaced by a soft‑max with a
  temperature that is decreased during the optimisation.  This gives a
  usable gradient while still concentrating on the worst convolution
  entry.
* **many restarts / warm‑starts** – a large time budget (1000 s) is split
  into many short runs with different lengths and initial shapes
  (power‑law, exponential, mixed).  The current global best is reused
  as a warm‑start for subsequent runs.
* **dynamic problem size** – early in the search short sequences are
  tried (fast, many restarts).  As the remaining time shrinks the
  algorithm concentrates on larger `n` (more degrees of freedom, a
  lower theoretical lower bound ≈ 1).

All helper functions are pure top‑level functions; no closures or
file/​network I/O are used.  The code respects the 1000 s budget,
prints progress and finally returns the best sequence it has found.

```python
"""
Adaptive projected‑Adam optimiser for the step‑function bound.

The algorithm:
  * Choose a length n and an initial non‑negative shape (power‑law,
    exponential or a mixture).
  * Project the shape onto the simplex Σa_i = √(2 n).
  * Perform Adam updates of a smooth‑max surrogate of
    max(a * a) (the surrogate uses a temperature τ that decays).
    After each update the vector is projected back onto the simplex.
  * Keep the best sequence found, evaluate it with the supplied
    evaluate_sequence, and use it for warm‑starts.
  * Run many independent restarts (short runs for small n, longer runs
    for larger n) until the 1000 s budget expires.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Simplex projection (Euclidean projection onto {x ≥ 0, Σx = s})
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project vector v onto the simplex of radius s."""
    if s < 0:
        raise ValueError("simplex radius must be non‑negative")
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Full linear convolution using real FFT (fast for any length)
# ----------------------------------------------------------------------
def _full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Return the full linear convolution of real vectors x and y via FFT."""
    n = x.shape[0] + y.shape[0] - 1
    size = 1 << ((n - 1).bit_length())          # next power‑of‑2
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)[:n]
    # eliminate tiny negative artefacts caused by rounding
    np.maximum(conv, 0.0, out=conv)
    return conv


# ----------------------------------------------------------------------
# One optimisation run (projected Adam with a smooth‑max surrogate)
# ----------------------------------------------------------------------
def _optimise_one_length_adam(
    n: int,
    init: np.ndarray,
    run_deadline: float,
    *,
    init_tau_factor: float = 0.12,
    min_tau_factor: float = 0.001,
    lr_factor: float = 0.5,
    beta1: float = 0.9,
    beta2: float = 0.999,
    epsilon: float = 1e-8,
    shake_prob: float = 0.01,
) -> tuple[np.ndarray, float]:
    """
    Optimise a vector of length `n` starting from `init`.
    Returns the best vector found (as a NumPy array) and the exact
    evaluation score obtained by ``evaluate_sequence``.
    """
    target_sum = np.sqrt(2.0 * n)                # Σ a_i = √(2 n)
    a = _project_onto_simplex(init.astype(np.float64), target_sum)

    # best candidate seen during this run
    best_seq = a.copy()
    # fast surrogate score (max of the linear convolution)
    conv = _full_convolution_fft(a, a)
    best_surrogate = 2.0 * n * conv.max() / (target_sum ** 2)

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1_pow = 1.0
    beta2_pow = 1.0
    iteration = 0
    # learning‑rate expressed as a fraction of the target sum
    base_lr = lr_factor * target_sum

        # --------------------------------------------------------------

        # --------------------------------------------------------------
        conv = _full_convolution_fft(a, a)
        max_val = conv.max()

        # --------------------------------------------------------------
        # 2) smooth‑max weights
        # --------------------------------------------------------------
        tau = max(init_tau_factor * max_val * (0.95 ** iteration),
                  min_tau_factor * max_val)
        scaled = (conv - max_val) / tau
        w = np.exp(scaled)                     # all entries ≤ 1
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # --------------------------------------------------------------
        # 3) gradient of Σ w_k (a*a)_k  = 2 * Σ_j a_j w_{i+j}
        #    (cross‑correlation, computed via FFT)
        # --------------------------------------------------------------
        w_rev = w[::-1]
        corr = _full_convolution_fft(a, w_rev)       # length = 3n‑2
        idx = (2 * n - 2) - np.arange(n)             # pick the needed slice
        grad = 2.0 * corr[idx]

        # --------------------------------------------------------------
        # 4) Adam update (with bias‑correction)
        # --------------------------------------------------------------
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        beta1_pow *= beta1
        beta2_pow *= beta2
        m_hat = m / (1.0 - beta1_pow)
        v_hat = v / (1.0 - beta2_pow)
        step = base_lr * m_hat / (np.sqrt(v_hat) + epsilon)

        # --------------------------------------------------------------
        # 5) projected update
        # --------------------------------------------------------------
        a_new = a - step
        a_new = np.maximum(a_new, 0.0)
        a_new = _project_onto_simplex(a_new, target_sum)

        # --------------------------------------------------------------
        # 6) surrogate evaluation and bookkeeping
        # --------------------------------------------------------------
        conv_new = _full_convolution_fft(a_new, a_new)
        surrogate = 2.0 * n * conv_new.max() / (target_sum ** 2)
        if surrogate < best_surrogate:
            best_surrogate = surrogate
            best_seq = a_new.copy()
            print(f"[{time.time():.2f}] n={n}  new local best ≈ {surrogate:.6f}")

        a = a_new
        iteration += 1

        # occasional random shake‑up to escape plateaus
        if shake_prob > 0.0 and np.random.rand() < shake_prob:
            noise = np.random.randn(n) * (target_sum * 5e-4 / n)
            a = _project_onto_simplex(np.maximum(a + noise, 0.0), target_sum)

    # final exact evaluation of the best sequence found in this run
    final_score = evaluate_sequence(best_seq.tolist())
    return best_seq, final_score


# ----------------------------------------------------------------------
# Initial shape generators
# ----------------------------------------------------------------------
def _initial_shape(n: int) -> np.ndarray:
    """
    Produce a random monotone decreasing start vector of length n.
    The generator mixes three families (power‑law, exponential, mixed).
    """
    idx = np.arange(1, n + 1, dtype=np.float64)

    r = np.random.rand()
    if r < 0.35:                               # pure power‑law
        p = np.random.uniform(0.3, 0.8)
        init = idx ** (-p)
    elif r < 0.70:                             # power‑law + exponential taper
        p = np.random.uniform(0.3, 0.8)
        init = idx ** (-p)
        tau = np.random.uniform(0.4, 2.0) * n
        init *= np.exp(-idx / tau)
    else:                                      # pure exponential
        tau = np.random.uniform(0.2, 0.8) * n
        init = np.exp(-idx / tau)

    # tiny jitter to break symmetry and avoid exact zeros
    init += np.random.rand(n) * 1e-4
    init = np.maximum(init, 1e-12)
    return init


# ----------------------------------------------------------------------
# Main entry point required by the evaluator
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: float = 1000.0,
                     **kwargs):
    """
    Search for a non‑negative step‑function that minimises the provided
    evaluation function.  The routine respects the given time budget,
    keeps the best sequence found and returns it as a plain Python list.
    """
    np.random.seed(seed)
    start_time = time.time()
    # leave a tiny safety margin so that the caller does not cut us off
    deadline = start_time + budget_s - 0.2

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Warm‑start from a previously discovered construction if present
    # ------------------------------------------------------------------
    try:
        hs = globals()["height_sequence_1"]
        hs_arr = np.array(hs, dtype=float)
        hs_arr = np.clip(hs_arr, 0.0, 1000.0)
        warm_score = evaluate_sequence(hs_arr.tolist())
        if warm_score < best_score:
            best_score = warm_score
            best_seq = hs_arr.copy()
            print(f"[{time.time():.2f}] Warm‑start seed score = {warm_score:.6f}")
    except Exception:
        pass  # no global seed available

    # ------------------------------------------------------------------
    # Main restart loop
    # ------------------------------------------------------------------
    while time.time() < deadline:
        remaining = deadline - time.time()

        # Choose a length: early on we explore a wide range,
        # later we focus on larger n where the theoretical bound is lower.
        if remaining > 400:
            n = np.random.randint(800, 3500 + 1)
        elif remaining > 150:
            n = np.random.randint(1000, 5000 + 1)
        else:
            n = np.random.randint(1500, 8000 + 1)

        # ----------------------------------------------------------------
        # Build an initial vector
        # ----------------------------------------------------------------
        if best_seq is not None and np.random.rand() < 0.45:
            # warm‑start from the current global best (truncate / pad)
            bs = best_seq
            if bs.size >= n:
                init = bs[:n].copy()
            else:
                pad = np.random.rand(n - bs.size) * 1e-4
                init = np.concatenate([bs, pad])
        else:
            init = _initial_shape(n)

        # ----------------------------------------------------------------
        # Allocate a time slice for this optimisation run
        # ----------------------------------------------------------------
        # keep a fraction for the final wrap‑up; the slice never exceeds
        # the remaining time.
        slice_time = min(12.0, remaining * 0.4)
        run_deadline = time.time() + slice_time

        # ----------------------------------------------------------------
        # Run the optimiser
        # ----------------------------------------------------------------
        seq_local, score_local = _optimise_one_length_adam(
            n,
            init,
            run_deadline,
            init_tau_factor=0.12,
            min_tau_factor=0.001,
            lr_factor=0.5,
            beta1=0.9,
            beta2=0.999,
            epsilon=1e-8,
            shake_prob=0.01,
        )

        # ----------------------------------------------------------------
        # Update global best
        # ----------------------------------------------------------------
        if score_local < best_score:
            best_score = score_local
            best_seq = seq_local.copy()
            print(f"[{time.time():.2f}] GLOBAL new best = {best_score:.6f} (n={n})")
            # stop early if we already beat the target comfortably
            if best_score < 1.49:
                break

    # ------------------------------------------------------------------
    # Fallback – should never be needed but guarantees a valid return
    # ------------------------------------------------------------------
    if best_seq is None:
        # a uniform vector of modest length works as a safe default
        n = 1200
        target_sum = np.sqrt(2.0 * n)
        best_seq = np.full(n, target_sum / n, dtype=float)

    # The evaluator expects a plain Python list
    return best_seq.tolist()
```
