assistantfinal**Reasoning and proposed improvements**

The objective  

\[
F(a)=\frac{2\,n\,\max_k\;(a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is **scale‑invariant**: after projecting a onto the simplex  

\[
\sum_i a_i=\sqrt{2n},
\]

the denominator becomes constant and minimising \(F\) is equivalent to minimising the peak of the self‑convolution.  
The peak is a convex‐quadratic form, but the “max” makes the whole problem non‑smooth.  

The earlier code used a *soft‑max* approximation together with a plain momentum SGD.  
To obtain a tighter bound we introduce three changes:

1. **Adam‑style adaptive steps** – per‑coordinate learning‑rates that automatically
   shrink as the gradient stabilises.
2. **A slightly faster and more stable smooth‑max** – the temperature is annealed
   exponentially and the soft‑max is re‑normalised after a shift for numerical safety.
3. **Richer random initialisations** – besides power‑law shapes we also sample
   Beta‑distribution profiles and exponential tapers; a fraction of restarts
   are warm‑started from the current global best (truncated / padded as needed).

All iterates are projected onto the simplex (the projection routine from the
previous solution) so the normalisation is always satisfied.  Periodic tiny
Gaussian shakes prevent the optimiser from getting stuck.

The outer loop repeatedly picks a problem size \(n\) (larger \(n\) gives more
degrees of freedom, but we keep the runtime per iteration modest) and runs the
Adam optimiser for a few seconds.  Whenever a run discovers a sequence with a
strictly lower exact score (checked with the provided `evaluate_sequence`) we
store it as the new global best.  When the time budget is almost exhausted we
return the best sequence found.

The whole method stays within the 1000 s budget, uses only NumPy and the
provided evaluator, and works on a single CPU (or two if the platform decides
to parallelise NumPy’s FFT).

```python
"""
Optimises a non‑negative step‑function to minimise

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

Strategy
--------
* Randomly choose a length n (≈ 800 … 4800) and generate a parameterised
  initial shape (power‑law, beta‑distribution, exponential taper, or a mix).
* Run an Adam optimiser on the simplex using a soft‑max approximation of the
  max‑convolution.  The temperature is annealed and the gradient is obtained
  by a cross‑correlation (FFT‑based, O(n log n)).
* The iterate is always projected onto the simplex Σa_i = √(2 n), therefore the
  objective equals the peak of the convolution.
* Periodic small Gaussian perturbations (“shake‑ups”) help escape plateaus.
* The best exact score seen (via evaluate_sequence) over the whole budget is
  returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper – Euclidean projection onto the simplex {x_i ≥ 0, Σ x_i = s}
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project vector v onto the simplex of radius s (non‑negative, sum = s)."""
    if s < 0:
        raise ValueError("Simplex radius must be non‑negative")
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = u - cssv / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Helper – Full linear convolution using real FFT (fast for any length)
# ----------------------------------------------------------------------
def _full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Return the full linear convolution of real vectors x and y via FFT."""
    n = x.shape[0] + y.shape[0] - 1
    size = 1 << ((n - 1).bit_length())          # next power‑of‑2
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)[:n]
    np.maximum(conv, 0.0, out=conv)   # eliminate tiny negatives
    return conv


# ----------------------------------------------------------------------
# Fast objective (identical to evaluate_sequence up to clipping)
# ----------------------------------------------------------------------
def _fast_objective(a: np.ndarray) -> float:
    """Return 2*n*max(conv(a,a))/(sum(a)**2) assuming a >=0 and sum>0."""
    n = a.shape[0]
    target_sum = math.sqrt(2.0 * n)
    conv = _full_convolution_fft(a, a)
    return 2.0 * n * conv.max() / (target_sum ** 2)


# ----------------------------------------------------------------------
# Random initialisation of a shape
# ----------------------------------------------------------------------
def _random_initial_sequence(n: int) -> np.ndarray:
    """Generate a random non‑negative vector of length n (un‑normalised)."""
    idx = np.arange(1, n + 1, dtype=float)

    mode = np.random.randint(3)
    if mode == 0:
        # pure power‑law
        p = np.random.uniform(0.2, 0.8)
        seq = idx ** (-p)
    elif mode == 1:
        # beta‑distribution shaped curve (flexible bump)
        alpha = np.random.uniform(0.5, 3.0)
        beta = np.random.uniform(0.5, 3.0)
        x = (idx - 1) / (n - 1)                # in [0,1]
        seq = (x ** (alpha - 1)) * ((1 - x) ** (beta - 1))
        seq = np.where(np.isnan(seq), 0.0, seq)  # guard against 0⁰
        # optional flip for left‑skewed / right‑skewed
        if np.random.rand() < 0.5:
            seq = seq[::-1]
    else:
        # power‑law with exponential taper
        p = np.random.uniform(0.2, 0.8)
        seq = idx ** (-p)
        tau = np.random.uniform(0.2, 4.0) * n
        seq *= np.exp(-idx / tau)

    # tiny jitter to avoid perfect symmetry
    seq += np.random.rand(n) * 1e-4
    return seq


# ----------------------------------------------------------------------
# Adam optimiser for a fixed length (soft‑max approximation of max)
# ----------------------------------------------------------------------
def _optimise_one_length_adam(
    n: int,
    init: np.ndarray,
    run_deadline: float,
    *,
    init_tau_factor: float = 0.12,
    min_tau_factor: float = 0.001,
    lr: float = 0.05,
    beta1: float = 0.9,
    beta2: float = 0.999,
    eps: float = 1e-8,
) -> tuple[np.ndarray, float]:
    """
    Adam‑based optimisation for a given length `n`.
    Returns the best sequence (numpy array) and its exact score
    obtained from `evaluate_sequence`.
    """
    target_sum = math.sqrt(2.0 * n)

    # start on the simplex
    a = _project_onto_simplex(init.astype(np.float64), target_sum)

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    # best‑so‑far (exact evaluation)
    best_seq = a.copy()
    best_score = evaluate_sequence(a.tolist())

    iteration = 1

    while time.time() < run_deadline:
        # --------------------------------------------------------------
        # 1) self‑convolution and current maximum
        # --------------------------------------------------------------
        conv = _full_convolution_fft(a, a)
        max_val = conv.max()

        # --------------------------------------------------------------
        # 2) smooth‑max (soft‑max) weights – temperature annealing
        # --------------------------------------------------------------
        tau = max(
            init_tau_factor * max_val * (0.95 ** iteration),
            min_tau_factor * max_val,
        )
        # stability shift before exponentiation
        scaled = (conv - max_val) / tau
        w = np.exp(scaled - np.max(scaled))
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # --------------------------------------------------------------
        # 3) gradient of the weighted sum Σ w_k (a*a)_k
        #    grad_i = 2 * Σ_j a_j w_{i+j}
        # --------------------------------------------------------------
        w_rev = w[::-1]
        conv2 = _full_convolution_fft(a, w_rev)          # length = 3n‑2
        idx = (2 * n - 2) - np.arange(n)                 # positions that give Σ_j a_j w_{i+j}
        grad = 2.0 * conv2[idx]

        # --------------------------------------------------------------
        # 4) Adam update (followed by simplex projection)
        # --------------------------------------------------------------
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)

        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        # keep step size in a reasonable range (prevent huge jumps)
        max_step = np.max(np.abs(step)) + 1e-12
        if max_step > max_val:
            step = step * (max_val / max_step) * 0.9

        a_new = a - step
        a_new = np.maximum(a_new, 0.0)
        a_new = _project_onto_simplex(a_new, target_sum)

        # --------------------------------------------------------------
        # 5) fast evaluation & possible exact update of the best record
        # --------------------------------------------------------------
        fast_score = _fast_objective(a_new)
        if fast_score < best_score:
            exact_score = evaluate_sequence(a_new.tolist())
            if exact_score < best_score:
                best_score = exact_score
                best_seq = a_new.copy()
                print(
                    f"[{time.time():.2f}] n={n}  new local best = {best_score:.6f}"
                )

        a = a_new
        iteration += 1

        # occasional random shake‑up to escape plateaus
        if np.random.rand() < 0.008:
            noise = np.random.randn(n) * (target_sum * 0.0003 / n)
            a = _project_onto_simplex(np.maximum(a + noise, 0.0), target_sum)
            # reset Adam moments after a shake‑up
            m.fill(0.0)
            v.fill(0.0)

    # final exact evaluation of the best sequence found in this run
    final_score = evaluate_sequence(best_seq.tolist())
    return best_seq, final_score


# ----------------------------------------------------------------------
# Main entry point required by the evaluator
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):

    Search for a non‑negative height sequence that minimises the given
    evaluation function.  The routine runs for at most ``budget_s`` seconds
    and returns the best sequence discovered.
    """

    start_time = time.time()
    # small safety margin so we always finish before timeout
    deadline = start_time + budget_s - 0.2

    best_seq = None
    best_score = float("inf")

    # --------------------------------------------------------------
    # Optional warm‑start from a sequence that may already exist
    # --------------------------------------------------------------
    try:
        hs = globals()["height_sequence_1"]
        hs_arr = np.array(hs, dtype=float)
        hs_arr = np.clip(hs_arr, 0.0, 1000.0)
        score = evaluate_sequence(hs_arr.tolist())
        if score < best_score:
            best_score = score
            best_seq = hs_arr.copy()
            print(f"[{time.time():.2f}] Warm‑start from global seed = {score:.6f}")
    except Exception:
        pass  # no warm‑start available

    # --------------------------------------------------------------
    # Main restart loop – each restart receives a short time slice
    # --------------------------------------------------------------
    while time.time() < deadline:
        remaining = deadline - time.time()

        # choose a problem size; we bias towards larger n early on
        if remaining > 600:
            n = np.random.randint(2500, 4800 + 1)
        elif remaining > 300:
            n = np.random.randint(1800, 3500 + 1)
        elif remaining > 120:
            n = np.random.randint(1200, 2500 + 1)
        else:
            n = np.random.randint(800, 2000 + 1)

        # random shape
        init = _random_initial_sequence(n)

        # occasionally blend the current global best (truncating / padding)
        if best_seq is not None and np.random.rand() < 0.30:
            if best_seq.size >= n:
                blend = best_seq[:n]
            else:
                pad = np.random.rand(n - best_seq.size) * 1e-4
                blend = np.concatenate([best_seq, pad])
            alpha = np.random.rand()
            init = alpha * init + (1.0 - alpha) * blend

        # allocate a time slice for this optimisation run
        slice_deadline = min(deadline, time.time() + min(7.0, remaining * 0.35))

        seq_local, score_local = _optimise_one_length_adam(
            n,
            init,
            slice_deadline,
            init_tau_factor=0.12,
            min_tau_factor=0.001,
            lr=0.05,
            beta1=0.9,
            beta2=0.999,
        )

        if score_local < best_score:
            best_score = score_local
            best_seq = seq_local.copy()
            print(
                f"[{time.time():.2f}] GLOBAL new best = {best_score:.6f} (length={n})"
            )
            # early exit if we already beat the target by a comfortable margin
            if best_score < 1.49:
                break

    # --------------------------------------------------------------
    # Fallback in the extremely unlikely case no candidate was ever made
    # --------------------------------------------------------------
    if best_seq is None:
        n = 1000
        s = math.sqrt(2.0 * n)
        best_seq = np.full(n, s / n, dtype=float)

    # final sanity check (ensures exact rounding used by the evaluator)
    final_score = evaluate_sequence(best_seq.tolist())
    print(f"[{time.time():.2f}] Final best score = {final_score:.6f}")
    return best_seq.tolist()
```
