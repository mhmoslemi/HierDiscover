assistantfinal**Solution Overview**

The evaluation function  

\[
F(a)=\frac{2n\;\max_k (a*a)[k]}{(\sum_i a_i)^2}
\]

is *scale‑invariant*: multiplying the whole vector by a constant does not change the value.
Hence we may (and will) keep the vector normalised to a unit sum, i.e.  
\(\sum_i a_i = 1\).  
With this normalisation the objective reduces to  

\[
F(a)=2n\;\max_k (a*a)[k].
\]

For a fixed vector `f` we denote  

* `M = max_k (f*f)[k]`.
* the linear convolution `f*g` is linear in `g`.

The following classical “alternating LP” scheme (the one sketched in the statement) is guaranteed to never increase `M`:

1. **LP step** – keep `f` fixed, maximise the total mass of a new vector `g ≥ 0` under the *linear* constraints  

   \[
   (f*g)[k] \le M,\qquad k=0,\dots ,2n-2 .
   \]

   This is a linear program (LP) because the left‑hand side is linear in `g`.  
   The optimal `g` pushes as much mass as possible into the “holes’’ left by `f`.

2. **Mixture** – normalise `g` to unit sum and replace  

   \[
   f \gets (1-t)f + t\,g ,\qquad t\in(0,1] .
   \]

   The new `f` has the same total mass and, due to the construction of `g`,
   its maximal self‑convolution cannot be larger than the old `M`.  
   Repeating the two steps drives the maximum down.

The algorithm below implements exactly this scheme, using **CVXPY** for the LP
(and the `conv` atom for a compact linear description).  To obtain a
high‑quality solution we combine several tricks:

* **Multiple lengths** – we run the procedure for a few different sequence
  lengths (the larger the length the lower the theoretical limit, see the
  analysis).  
* **Randomised starts** – Dirichlet, exponential, half‑sine … – to avoid
  getting stuck in a local minimum.
* **Positivity buffer** – a tiny `ε` is added to every entry before each LP,
  so the problem never becomes unbounded.
* **Adaptive mixture weight** – we start with `t = 0.25` and slowly shrink it,
  which stabilises the iterations.
* **Final polishing** – a cheap Monte‑Carlo “swap” routine that makes tiny
  mass exchanges between two positions and accepts them only if the
  objective improves.

The whole search respects the supplied time‑budget (`budget_s`) and returns
the best vector encountered (as a plain Python list) – exactly the format
required by `evaluate_sequence`.

"""
Proposes a step‑function (non‑negative heights) that minimises
``evaluate_sequence``.  The method combines the linear‑programming
iteration described in the statement with a cheap random‑swap polishing
phase.

Algorithm
---------
1.  Choose a length `n` (several lengths are tried).
2.  Initialise a probability vector `f` (unit sum, all entries ≥ ε).
3.  Repeat
        M = max(f * f)                         # self‑convolution peak
        Solve the LP:
            maximise   sum(g)
            subject to (f * g)[k] ≤ M ,  ∀k
                       g ≥ 0
        Normalise g to unit sum and set
            f ← (1‑t)·f + t·g   (t slowly decays)
   until time runs out or no improvement.
4.  Polishing: repeatedly pick two indices, move a tiny amount of mass
   from one to the other, keep the change if it lowers 2·n·max(f*f).
5.  Return the best vector found (as a list of floats).

The LP uses CVXPY's ``conv`` atom, which yields a compact linear description
of the convolution.  An ε‑buffer (1e‑12) guarantees boundedness.
"""

def _max_conv_fft(a: np.ndarray) -> float:
    """Fast (FFT) computation of max_{k} (a*a)[k]."""
    n = a.shape[0]
    size = 1 << int(np.ceil(np.log2(2 * n - 1)))
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[: 2 * n - 1]
    return float(conv.max())


def _lp_max_sum_g(f: np.ndarray, M: float, eps: float = 1e-12) -> np.ndarray | None:
    """
    Solve   max   sum(g)
    s.t.    (f * g)[k] ≤ M   ∀k
           g ≥ 0
    where ``f`` is a *constant* vector.  Returns the optimal g (as a NumPy
    array) or ``None`` if the problem is infeasible / unbounded.
    """
    if not _HAVE_CVX:                     # pragma: no cover
        return None

    n = f.shape[0]
    # CVXPY objects
    g = cp.Variable(n, nonneg=True)
    conv_expr = cp.conv(cp.Constant(f), g)        # length 2n‑1
    # elementwise inequality conv_expr ≤ M (with a tiny tolerance)
    constraints = [conv_expr[i] <= M + 1e-12 for i in range(2 * n - 1)]

    prob = cp.Problem(cp.Maximize(cp.sum(g)), constraints)

    # ECOS is a fast interior‑point solver for small‑medium LPs
    try:
        prob.solve(solver=cp.ECOS, warm_start=True,
                   max_iters=5000, abstol=1e-9, reltol=1e-9)
    except Exception:                     # pragma: no cover
        return None

    if prob.status not in {"optimal", "optimal_inaccurate"}:
        return None

    g_val = g.value
    if g_val is None:
        return None
    return np.asarray(g_val, dtype=float)

        t = 0.25                     # initial mixing weight
        outer_iter = 0
        max_outer = 30               # safety limit per restart

        while time.time() < deadline and outer_iter < max_outer:
            outer_iter += 1

            # current max self‑convolution
            M = _max_conv_fft(f)      # max (f*f)[k]
            cur_val = 2.0 * n * M     # because sum(f) == 1

            if cur_val < best_val:
                best_val = cur_val
                best_seq = f.copy()
                print(f"[len {n}] outer {outer_iter:02d}   new best = {cur_val:.6f}")

            # ----------------------------------------------------------------
            # LP: maximise total mass of g under (f*g) ≤ M
            g_opt = _lp_max_sum_g(f, M, eps=eps)
            if g_opt is None:                     # LP failed – abort this restart
                break

            # normalise g to unit sum
            g_opt = np.maximum(g_opt, eps)
            sum_g = g_opt.sum()
            if sum_g == 0.0:
                break
            g_norm = g_opt / sum_g

            # convex combination (the mixture step)
            f = (1.0 - t) * f + t * g_norm
            f = np.maximum(f, eps)
            f /= f.sum()

            # decay the mixing weight – later steps become more cautious
            t = max(t * 0.92, 0.03)

        restart += 1

        # ----------------------------------------------------------------
        # Periodically log progress (once per restart)
        if time.time() >= deadline:
            break
        print(f"[Restart {restart:03d}] length {n}, best so far = {best_val:.6f}")

    # ------------------------------------------------------------------
    # ---------------------------------------------------------- Polishing
    # A cheap stochastic local‑search that moves tiny amounts of mass
    # between two positions and keeps the move if it improves the objective.
    if best_seq is not None:
        a = best_seq.copy()
        n = a.shape[0]
        temperature = 0.1                     # initial step size
        last_val = 2.0 * n * _max_conv_fft(a)

        while time.time() < deadline:
            # propose a random swap of a tiny amount ε
            i, j = np.random.randint(0, n, 2)
            if i == j:
                continue
            delta = (np.random.rand() - 0.5) * temperature
            if a[i] + delta < 0.0 or a[j] - delta < 0.0:
                continue
            a_new = a.copy()
            a_new[i] += delta
            a_new[j] -= delta

            new_val = 2.0 * n * _max_conv_fft(a_new)

            if new_val < last_val - 1e-12:      # accept only genuine improvements
                a = a_new
                last_val = new_val
                if new_val < best_val:
                    best_val = new_val
                    best_seq = a.copy()
                    print(f"[Polish] improvement → {new_val:.6f}")

            # anneal the step size
            temperature *= 0.9999
            if temperature < 1e-9:
                break

    # ------------------------------------------------------------------
    # Fallback – should never be hit, but guarantees a return value.
    if best_seq is None:
        n = 2500
        best_seq = np.full(n, 1.0 / n)

    print(f"Final best objective = {best_val:.6f} (length {len(best_seq)})")
    # ``evaluate_sequence`` expects a plain list, not a NumPy array.
    return best_seq.tolist()
