```
∑a = √(2 n)                (1)
```

and then the objective is simply `max(a∗a)`.  
The problem is therefore: *spread a given amount of mass over `n` positions so that the peak of the self‑convolution is as low as possible*.

The optimiser combines three ideas:

1. **Diverse initialisation** – a handful of analytically‑motivated shapes
   (uniform, Dirichlet, exponential, Hann, Blackman, small perturbations)
   plus linear interpolations of the previously known best vector.

2. **Linear‑programming warm‑start** – for moderate dimensions (`n ≤ 2500`)
   we solve the LP  

```
max  Σ b_j          (increase total mass)
s.t.  b_j ≥ 0
      (a ∗ b)_k ≤ M   ∀k                (M = max(a∗a))
```

   The solution tends to “push mass into regions that are not yet saturated”.
   The LP result is blended with the current iterate (mixing factor `t`).

3. **Smoothed Adam optimisation** – after the LP step we run a
   projected Adam optimiser.
   * A soft‑max over the convolution values gives a smooth approximation
     of the max during the first phase (temperature τ starts at a fraction
     of the current peak and decays exponentially).
   * When τ becomes tiny we fall back to the exact sub‑gradient
     (uniform weight on the active set).
   * After each Adam step the vector is projected onto the feasible set
     (`a_i ≥ 0` and (1)).  Small Gaussian jitter is added periodically
     to escape plateaus.

The whole search is time‑bounded (`budget_s`).  The remaining time is split
between several lengths (original length and 1.5 × / 2 × versions, capped at 8000)
and a small number of restarts per length.  The best vector found overall
is returned as a plain Python list.

```python
"""Step‑function optimiser for minimise ``evaluate_sequence``.

The algorithm proceeds as follows

* for each chosen length n we generate a diverse pool of starting vectors
  (uniform, Dirichlet, exponential, Hann, Blackman, perturbed uniform,
  linear interpolation of the previous best).

* For moderate n (≤ 2500) we perform a few iterations of a linear program
  that maximises the ℓ₁‑norm of a new vector b under the constraint
  ``(a ∗ b) ≤ max(a ∗ a)``.  The LP solution is mixed with the current iterate
  (convex combination) – this quickly pushes mass into “empty” parts of the
  convolution.

* The resulting vector is refined with a projected Adam optimiser.
  In the early stage a soft‑max with a slowly‑decreasing temperature
  gives a smooth approximation of the max‑convolution; later we switch to
  the exact sub‑gradient on the active set.

* All iterates are projected onto the feasible simplex
  (non‑negative, ℓ₁‑norm = √(2 n)).  Small random jitter is added every few
  thousand steps.

The routine respects the supplied time budget (default 1000 s) and returns
the best sequence found as a plain Python list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (all top‑level, no closures)
# ----------------------------------------------------------------------
def _softmax_weights(conv: np.ndarray, tau: float):
    """Stable soft‑max of the convolution values.
    Returns weight vector w (sums to 1) and the smoothed maximum Lτ."""
    maxc = conv.max()
    if tau <= 0.0:
        w = np.zeros_like(conv)
        w[np.argmax(conv)] = 1.0
        return w, maxc
    ex = np.exp((conv - maxc) / tau)
    sum_ex = ex.sum()
    w = ex / sum_ex
    Ltau = maxc + tau * np.log(sum_ex)
    return w, Ltau


def _weighted_rev(a: np.ndarray, w: np.ndarray, Nfft: int) -> np.ndarray:
    """
    Sub‑gradient of the (soft‑max) max‑convolution.
    Computes rev_i = Σ_k w_k * a_{k‑i}   (out‑of‑range indices ignored)
    using FFTs.
    """
    A_fft = np.fft.rfft(a, n=Nfft)
    # reverse the weight vector before FFT
    W_rev_fft = np.fft.rfft(w[::-1], n=Nfft)
    conv_rev = np.fft.irfft(W_rev_fft * A_fft, n=Nfft)
    # keep the part that corresponds to rev_i for i = 0..n‑1
    conv_rev = conv_rev[: len(w) + a.shape[0] - 1]
    idx_start = 2 * a.shape[0] - 2
    rev = conv_rev[idx_start - np.arange(a.shape[0])]
    return rev


def _max_convolution(a: np.ndarray, Nfft: int) -> float:
    """Return max_{k} (a∗a)[k] using an FFT of length Nfft."""
    A_fft = np.fft.rfft(a, n=Nfft)
    conv = np.fft.irfft(A_fft * A_fft, n=Nfft)[: 2 * a.shape[0] - 1]
    return float(conv.max())


def _make_initial_vectors(n: int, target_sum: float):
    """Create a small, diverse set of normalised starting vectors."""
    rng = np.random.default_rng()
    init = []

    # 1) uniform
    init.append(np.full(n, target_sum / n))

    # 2) random Dirichlet (Gamma(1,1))
    g = rng.gamma(1.0, 1.0, size=n)
    init.append(g / g.sum() * target_sum)

    # 3) exponential decay (random rate)
    rate = rng.uniform(0.0005, 0.01)
    x = np.exp(-rate * np.arange(n))
    init.append(x / x.sum() * target_sum)

    # 4) reversed exponential
    rev = x[::-1]
    init.append(rev / rev.sum() * target_sum)

    # 5) Hann window
    hann = 0.5 - 0.5 * np.cos(2.0 * np.pi * np.arange(n) / (n - 1))
    init.append(hann / hann.sum() * target_sum)

    # 6) Blackman window
    a0, a1, a2 = 0.42, 0.5, 0.08
    n_arr = np.arange(n)
    black = (a0
             - a1 * np.cos(2.0 * np.pi * n_arr / (n - 1))
             + a2 * np.cos(4.0 * np.pi * n_arr / (n - 1)))
    init.append(black / black.sum() * target_sum)

    # 7) small random perturbation of uniform
    pert = np.full(n, target_sum / n)
    pert += rng.normal(scale=0.01 * target_sum / n, size=n)
    pert = np.maximum(pert, 0.0)
    pert = pert / pert.sum() * target_sum
    init.append(pert)

    return init


def _solve_lp_linear(f: np.ndarray, M: float):
    """Linear programme:
         maximise Σ b_j  subject to  b ≥ 0  and  (f ∗ b) ≤ M .
       Returns the optimal b (or None on failure)."""
    try:
        from scipy.optimize import linprog
        from scipy.linalg import toeplitz
    except Exception:
        return None

    n = f.shape[0]
    col = np.concatenate([f, np.zeros(n - 1)])
    row = np.concatenate([np.array([f[0]]), np.zeros(n - 1)])
    # Toeplitz gives a (2n‑1)×n matrix whose rows are the convolution coefficients
    A = toeplitz(col, row)[: 2 * n - 1, :]

    c = -np.ones(n)                     # minimise –Σb  ⇔ maximise Σb
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n

    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return np.maximum(res.x, 0.0)    # numerical safety
    return None


def _lp_improve(a: np.ndarray, target_sum: float,
                max_lp_iters: int = 5, mix: float = 0.25):
    """Perform a few LP‑guided mixing steps starting from ``a``."""
    n = a.shape[0]
    Nfft = 1 << ((2 * n - 1).bit_length())
    for _ in range(max_lp_iters):
        M = _max_convolution(a, Nfft)
        b = _solve_lp_linear(a, M)
        if b is None:
            break
        s = b.sum()
        if s < 1e-12:
            break
        # scale b to the required ℓ₁‑norm
        b = b * (target_sum / s)
        a = (1.0 - mix) * a + mix * b
        # a stays non‑negative and already respects (1)
    return a


def _adam_optimize(a: np.ndarray, n: int, deadline: float,
                   max_iters: int, best_seq: np.ndarray,
                   best_score: float) -> tuple[np.ndarray, float]:
    """Adam optimiser with a soft‑max phase and a final exact sub‑gradient."""
    target_sum = math.sqrt(2.0 * n)

    # normalise the start vector
    a = a * (target_sum / a.sum())

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    lr0 = 0.15                     # a bit larger than the original code
    jitter_interval = 3000

    # temperature schedule
    tau_factor = 0.5               # start with a larger smoothing window
    decay_rate = max_iters / 12.0  # slightly faster decay

    Nfft = 1 << ((2 * n - 1).bit_length())   # next power‑of‑two ≥ 2·n‑1

    for iteration in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # exact convolution of the current iterate
        A_fft = np.fft.rfft(a, n=Nfft)
        conv = np.fft.irfft(A_fft * A_fft, n=Nfft)[: 2 * n - 1]
        M = float(conv.max())

        # temperature & soft‑max
        tau = tau_factor * M * math.exp(-iteration / decay_rate)
        if tau < 1e-9:
            # exact sub‑gradient (uniform weight on active set)
            mask = conv >= M - 1e-12
            cnt = mask.sum()
            w = mask.astype(float) / max(cnt, 1)
            Ltau = M
        else:
            w, Ltau = _softmax_weights(conv, tau)

        # weighted reverse convolution = sub‑gradient of the smoothed max
        rev = _weighted_rev(a, w, Nfft)

        # gradient of the original (scaled) objective
        coeff = 4.0 * n / (target_sum * target_sum)          # =2 after normalisation
        const = 4.0 * n * Ltau / (target_sum ** 3)
        grad = coeff * rev - const

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)

        lr = lr0 / (1.0 + 1e-4 * iteration)
        a = a - lr * m_hat / (np.sqrt(v_hat) + eps)

        # projection onto the feasible simplex
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s > 0.0:
            a = a * (target_sum / s)
        else:
            a = np.full_like(a, target_sum / n)

        # occasional jitter
        if iteration % jitter_interval == 0:
            jitter = np.random.randn(n) * (1e-3 * target_sum / n)
            a = np.maximum(a + jitter, 0.0)
            a = a * (target_sum / a.sum())

        # exact objective (after projection it equals M)
        cur_score = M
        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[len {n:5d} iter {iteration:8d}] new best = {best_score:.6f}")

    return best_seq, best_score

def propose_candidate(seed: int = 12345, budget_s: float = 1000, **kwargs):
    """
    Search for a step‑function (non‑negative vector) that minimises
    ``evaluate_sequence`` within the given time budget.

    The routine combines random initialisation, a short LP‑guided warm‑start

    smoothing of the max‑convolution.
    """

    start_time = time.time()
    deadline = start_time + budget_s - 5.0          # safety margin

    # ------------------------------------------------------------------

    except Exception:

    # ------------------------------------------------------------------
    # Choose lengths to explore (original, 1.5× and 2×, capped at 8000)

        n0 = base.shape[0]
    else:
        n0 = 2100                       # fall‑back used in earlier runs

    length_factors = [1.0, 1.5, 2.0]
    lengths = sorted({int(n0 * f) for f in length_factors})
    lengths = [max(300, min(l, 8000)) for l in lengths]

    # ------------------------------------------------------------------
    # Global best tracking
    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Main optimisation loop
    for n in lengths:
        if time.time() >= deadline:
            break

        target_sum = math.sqrt(2.0 * n)
        print(f"\n[run] length = {n}, target ℓ₁ = {target_sum:.3f}")

        # generate a diverse set of start vectors
        init_vectors = _make_initial_vectors(n, target_sum)

        # interpolate the previous best if it has a different size
        if base is not None and base.shape[0] != n:
            old_x = np.linspace(0.0, 1.0, base.shape[0])
            new_x = np.linspace(0.0, 1.0, n)
            interp = np.interp(new_x, old_x, base)
            interp = np.maximum(interp, 0.0)
            interp = interp / interp.sum() * target_sum
            init_vectors.append(interp)

        # ------------------------------------------------------------------
        # Optional LP warm‑start (only for moderate dimensions)
        if n <= 2500:
            lp_improved = []
            # apply LP improvement to a few representatives only (speed vs benefit)
            for v in init_vectors[:3]:
                v_lp = _lp_improve(v.copy(), target_sum,
                                   max_lp_iters=4, mix=0.25)
                lp_improved.append(v_lp)
            init_vectors.extend(lp_improved)

        # ------------------------------------------------------------------
        # Determine a per‑run iteration budget.
        # We allocate more iterations to the smallest length,
        # but never let a single run exceed the remaining time.
        remaining = max(0.0, deadline - time.time())
        # Rough estimate: 300 k iterations for the largest n, scaled inversely.
        base_iters = int(300_000 * 2100 / n)
        max_iters = max(200_000, base_iters)

        # Limit the iterations by the remaining time (very rough guard)
        # Assume ~0.0002 s per iteration for n≈2000 (empirical)
        max_possible = int(remaining / 0.00025)
        max_iters = min(max_iters, max_possible) if max_possible > 0 else max_iters

        print(f"  max_iters per start ≈ {max_iters}")

        for start_id, a0 in enumerate(init_vectors, 1):
            if time.time() >= deadline:
                break
            print(f"  start {start_id}/{len(init_vectors)} for length {n}")

            best_seq, best_score = _adam_optimize(
                a=a0.copy(),
                n=n,
                deadline=deadline,
                max_iters=max_iters,
                best_seq=best_seq if best_seq is not None else a0,
                best_score=best_score,
            )

    # ------------------------------------------------------------------
    # Fallback to a simple uniform vector if nothing was found
    if best_seq is None:
        n = n0
        target_sum = math.sqrt(2.0 * n)
        best_seq = np.full(n, target_sum / n)

        print("[fallback] using uniform sequence")

    print(f"\n[done] best score = {best_score:.6f}, length = {best_seq.shape[0]}")
    return best_seq.tolist()
```
