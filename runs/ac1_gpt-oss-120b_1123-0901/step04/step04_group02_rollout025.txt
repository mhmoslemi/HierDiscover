Propose a step‑function (non‑negative vector) that minimises

    F(a) = 2·n·max(conv(a,a)) / (sum(a)^2)

Because the objective is homogeneous we fix sum(a)=1 and minimise
2·n·max(conv).  The search proceeds in three stages:

1. **Parametric sweep** – test simple symmetric “U‑shaped’’ families
   a_i ∝ ((i+δ)·(n‑1‑i+δ))^{-γ} for several (n,γ,δ).  The best
   candidate from this cheap sweep seeds the next stage.

2. **Smooth‑max Adam optimisation** – minimise the log‑sum‑exp
   surrogate of the max using Adam updates on the probability simplex.
   A temperature (λ) is raised gradually so that the surrogate converges
   to the true max.  Stagnation is avoided by occasional random shakes.
   The best vector found (any length) is kept globally.

3. **Upscaling + fine‑tuning** – the current best vector is interpolated
   to larger lengths (2048, 4096, 8192) and short Adam runs further
   improve the bound.  Finally a tiny hill‑climbing phase swaps tiny
   amounts of mass between two coordinates.

The whole routine respects a global time budget (default 1000 s) and
returns the best sequence as a plain Python list.
"""

import time
import numpy as np

# Helper utilities – all are top‑level (no closures)

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _full_convolution(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a (length 2·len(a)‑1) via FFT."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * a.shape[0] - 1]
    return conv


def _cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Gradient of Σ_k w_k·(a*a)_k w.r.t. a.
    Returns a vector of length len(a).
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("Simplex projection works on 1‑D arrays")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries become equal
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _eval_obj(a: np.ndarray) -> float:
    """Exact objective for a (assumed to sum to 1)."""
    n = a.shape[0]
    conv = _full_convolution(a, _next_pow2(2 * n - 1))
    return float(2.0 * n * conv.max())
