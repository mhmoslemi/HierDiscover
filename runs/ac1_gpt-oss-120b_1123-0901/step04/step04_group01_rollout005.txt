        F(a) = 2·n·max(a*a) / (sum(a)²)

The algorithm is a multi‑scale stochastic optimisation:

*   Work on several lengths (512 … 16384).  Larger n allow a lower theoretical
    bound (≈1) but are more expensive, so we start small and warm‑start the
    next size by linear interpolation.
*   Represent the vector by unconstrained logits ``x`` and obtain probabilities
    via a soft‑max (ensuring a_i ≥ 0 and Σa_i = 1).
*   Replace the non‑smooth max by a temperature‑controlled soft‑max
    ``softmax(tau·conv)``; its gradient is a smooth approximation to the
    sub‑gradient of the true max.
*   Optimise the smooth objective with Adam (first‑moment, second‑moment
    adaptation).  The temperature ``tau`` is increased gradually so the
    optimisation first sees a smooth landscape and later focuses on the
    true max.
*   After each Adam run a cheap coordinate‑move refinement (transfer a small
    amount of mass between two random indices) is performed to escape
    possible local minima.
*   All steps use FFT‑based convolution / cross‑correlation for O(n log n)
    performance.  The best vector seen across all lengths is returned.

The implementation respects the 1000 s time budget, prints progress
information and falls back to a uniform vector if nothing is found.
"""

import time
import numpy as np


def full_convolution(a: np.ndarray, fft_len: int = None) -> np.ndarray:
    """
    Linear convolution a * a (length 2·len(a)-1) using the FFT.
    """
    n = a.shape[0]
    if fft_len is None:
        fft_len = 1 << int(np.ceil(np.log2(2 * n - 1)))
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * n - 1]
    return conv


def cross_correlation(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for the gradient.
    Returns a vector of length len(a) equal to
        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]   for i=0…n‑1.
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]
