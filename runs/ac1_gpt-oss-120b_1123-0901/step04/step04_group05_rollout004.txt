Propose a candidate step‑function using a deterministic linear‑programming refinement.

The algorithm follows the classical “alternating LP” scheme:

1. Choose a length `n` (default 2500) and start from a known construction
   (`height_sequence_1` if available) or a random Dirichlet distribution.
2. Normalise the vector to have Σ a_i = sqrt(2 n).  With this normalisation the
   evaluation function reduces to `max(conv(a,a))`, i.e. the maximum entry of
   the self‑convolution.
3. Repeatedly solve the linear program

       maximise   Σ b_i
       subject to  (a * b)_k ≤ M   for all k            (M = current max(conv))
                   b_i ≥ 0

   where `a * b` is the ordinary linear convolution.
   The LP gives a “more spread” vector `b` that respects the same bound `M`.

4. Rescale `b` back to the same ℓ₁‑norm as `a` and replace `a` by a convex
   combination `(1‑t) a + t b`.  A short line‑search (t = 1, ½, ¼, …) is used
   to keep the maximum convolution strictly decreasing.
5. Loop until no improvement is observed or the time budget expires.
6. Return the best vector found (as a plain Python list).

The method is deterministic apart from the random initialisations and works
well for lengths up to a few thousand – memory usage is ≈ (2 n‑1)·n ∼ 100 MiB
for `n = 2500`.  The whole routine respects the supplied time budget
(`budget_s`) and prints progress information.
"""

import time
import numpy as np
from scipy import linalg
from scipy.optimize import linprog


def _build_conv_matrix(a: np.ndarray) -> np.ndarray:
    """
    Return the dense matrix `A` such that A @ b = np.convolve(a, b)  (full mode).

    The matrix has shape (2·n‑1, n) where n = len(a).  It is constructed via a
    Toeplitz matrix with the first column equal to a padded with zeros.
    """
    n = a.shape[0]
    # first column: a followed by n‑1 zeros
    col = np.r_[a, np.zeros(n - 1, dtype=a.dtype)]
    # first row: a[0] followed by n‑1 zeros
    row = np.r_[a[0], np.zeros(n - 1, dtype=a.dtype)]
    # Toeplitz matrix, then cut to required size
    A_full = linalg.toeplitz(col, row)
    return A_full[: 2 * n - 1, :n]


def _downsample(seq: np.ndarray, new_len: int) -> np.ndarray:
    """
    Linear interpolation of a 1‑D sequence to a new length.
    """
    if seq.shape[0] == new_len:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, seq.shape[0])
    new_x = np.linspace(0.0, 1.0, new_len)
    return np.interp(new_x, old_x, seq)
