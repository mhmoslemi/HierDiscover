assistantfinal**Solution Explanation**

The score to minimise is  

```
score(a) = 2·n·max(conv(a,a)) / (sum(a)²)          (1)
```

with `a[i] ≥ 0`.  
The function is *scale invariant*: multiplying all `a[i]` by the same factor
cancels in (1), therefore we can keep the `ℓ₁`–norm of the vector fixed
(e.g. `sum(a)=1`) while searching for the best shape.

For a decreasing power law  

```
a[i] = (i+γ)⁻ᵖ        (p≈0.5, γ≈0.3)
```

the convolution `conv(a,a)` is almost constant and the obtained score is
≈ π/2 ≈ 1.571.  The challenge is to lower the score a little further.
The idea is to start from the best known power‑law construction and then
improve it by a **projected gradient hill‑climber**:

* the convolution is computed,
* the shift `k*` where the maximum is attained is identified,
* the gradient of `max(conv)` w.r.t. `a` at that shift is  
  `∂max/∂a[i] = 2·a[k*-i]` (zero when the index is out of range),
* we take a step opposite to the gradient (reducing the entries that
  contribute most to the current maximum) and compensate the loss of mass
  by adding the same amount uniformly to the whole vector – this keeps the
  `ℓ₁` norm fixed,
* the new vector is projected onto the feasible set (`a[i]≥0`),
* the new score is evaluated, and the step is kept only if the score
  improves.  The step size is reduced whenever no improvement is observed.

The algorithm stays extremely cheap – a single iteration needs only one
convolution (`O(n²)`) and a linear pass to build the gradient.
With `n = 3428` an iteration is well below 0.02 s, so thousands of
iterations fit easily into the 1000 s budget.

The final result is returned as a plain Python list, ready for
`evaluate_sequence`.

```python
import time
import numpy as np

# -------------------------------------------------------------
#  Minimal‑score step‑function construction
#
#  1.  Initialise with the best known power‑law (p≈0.5, γ≈0.321).
#  2.  Repeatedly improve the vector by a projected gradient step
#      that reduces the entry (or pair of entries) responsible for the
#      current maximal convolution value.
#  3.  Keep a step‑size adaptation and a simple back‑tracking line
#      search to guarantee monotone improvement.
# -------------------------------------------------------------


def _power_law_sequence(n: int, p: float, gamma: float) -> np.ndarray:
    """Return a_i = (i + gamma) ** (-p) for i = 0 … n‑1."""
    return (np.arange(n, dtype=float) + gamma) ** (-p)


def propose_candidate(seed: int = 12345,
                     budget_s: float = 1000.0,
                     n: int = 3428) -> list:
    """
    Return a list of non‑negative heights that (hopefully) beats the
    previous best score (~1.571).  The method starts from the optimal
    power‑law construction and performs a projected gradient hill‑climb
    that reduces the maximal convolution entry while keeping the
    ℓ₁‑norm constant.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.1   # safety margin

    # -----------------------------------------------------------------
    # 0) Initialise – the best power‑law found in previous experiments.
    # -----------------------------------------------------------------
    # power‑law parameters that gave the best known score (~1.571)
    p0, gamma0 = 0.5002, 0.3210
    a = _power_law_sequence(n, p0, gamma0)

    # Normalise to unit ℓ₁‑norm (any scaling leaves the score unchanged)
    a_sum = a.sum()
    if a_sum == 0:
        a = np.ones_like(a) / n
    else:
        a = a / a_sum

    best_seq = a.copy()
    best_score = float('inf')
    # First evaluation of the initial candidate
    best_score = evaluate_sequence(best_seq.tolist())
    print(f"[init] score={best_score:.6f}")

    # -----------------------------------------------------------------
    # 1) Hill‑climbing parameters
    # -----------------------------------------------------------------
    step_size = 0.02            # initial multiplicative step (2 % of entry)
    min_step = 1e-5
    patience = 0                # number of iterations without improvement

    # -----------------------------------------------------------------
    # 2) Main optimisation loop
    # -----------------------------------------------------------------
    while time.time() < deadline:
        # -------------------------------------------------------------
        # a) compute convolution and locate the maximal index k*
        # -------------------------------------------------------------
        conv = np.convolve(a, a)
        k_star = int(np.argmax(conv))

        # -------------------------------------------------------------
        # b) gradient of max(conv) : grad[i] = 2 * a[k*‑i]  (if inside)
        # -------------------------------------------------------------
        grad = np.zeros_like(a)
        i_low = max(0, k_star - (n - 1))
        i_high = min(n - 1, k_star)
        i_range = np.arange(i_low, i_high + 1, dtype=int)
        j_range = k_star - i_range
        grad[i_range] = 2.0 * a[j_range]

        # -------------------------------------------------------------
        # c) propose a move opposite to the gradient,
        #    then re‑normalise to keep the ℓ₁‑norm equal to 1.
        # -------------------------------------------------------------
        # a small step opposite to the gradient
        proposal = a - step_size * grad
        # enforce non‑negativity
        proposal = np.clip(proposal, 0.0, None)
        # renormalise (scale invariance of the score)
        if proposal.sum() == 0:
            # should never happen, but guard against division by zero
            proposal = a.copy()
        else:
            proposal = proposal / proposal.sum()

        # -------------------------------------------------------------
        # d) evaluate the proposal
        # -------------------------------------------------------------
        score = evaluate_sequence(proposal.tolist())

        # -------------------------------------------------------------
        # e) accept if the score improves, otherwise back‑track
        # -------------------------------------------------------------
        if score < best_score:
            best_score = score
            best_seq = proposal.copy()
            a = proposal               # continue from the improved point
            # enlarge step a little to accelerate when we are on a
            # descent direction
            step_size = min(step_size * 1.1, 0.5)
            patience = 0
            print(f"[improve] step={step_size:.5f} score={best_score:.6f}")
        else:
            # no improvement – reduce step size
            step_size = max(step_size * 0.5, min_step)
            patience += 1
            if patience > 2000:
                # after many failed attempts we perform a tiny random
                # jitter to try to escape a shallow plateau
                jitter = np.exp(np.random.randn(n) * (step_size * 0.1))
                proposal = a * jitter
                proposal = np.clip(proposal, 0, None)
                if proposal.sum() == 0:
                    proposal = a.copy()
                else:
                    proposal = proposal / proposal.sum()
                score = evaluate_sequence(proposal.tolist())
                if score < best_score:
                    best_score = score
                    best_seq = proposal.copy()
                    a = proposal
                    patience = 0
                    print(f"[jitter] score={best_score:.6f}")

        # safety break in case the step becomes too tiny
        if step_size <= min_step and patience > 5000:
            break

    # -----------------------------------------------------------------
    # 3) Return the best sequence found (plain Python list)
    # -----------------------------------------------------------------
    print(f"Finished – best score {best_score:.6f}")
    return best_seq.tolist()
```
