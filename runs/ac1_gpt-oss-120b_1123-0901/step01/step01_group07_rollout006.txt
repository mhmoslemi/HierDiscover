Propose a candidate step‑function (non‑negative heights) that minimises

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The implementation is an enlarged random search around the analytic
power‑law family

    a_i = (i + γ) ** (‑p)      , i = 0 … n‑1

but it explores **more degrees of freedom than the reference code**:

* Several sequence lengths (n) are tried – longer sequences give a
  flatter aperiodic autocorrelation and can beat the previous 1.571 bound.
* The exponent p is searched in a wide interval (≈0.5 … 0.9).  Theory shows
  that p > 0.5 can lower the asymptotic bound.
* The shift γ is allowed to be much larger (up to 30) – this removes the
  dominant contribution of the first few terms.
* After a cheap coarse grid the algorithm runs a timed stochastic
  refinement (random walk with decreasing step sizes) that also optionally
  changes the length n.  The search stops automatically after the allotted
  budget (default 1000 s).

The evaluation function `evaluate_sequence` is assumed to be available in the
global namespace.
"""

import time
import numpy as np

# --------------------------------------------------------------
# Helper to build a power‑law sequence.
# --------------------------------------------------------------
def _make_powerlaw_seq(n: int, p: float, gamma: float) -> np.ndarray:
    """Return a_i = (i + gamma) ** (-p) for i = 0 … n‑1."""
    # i + gamma is always positive because gamma > 0 is enforced.
    return (np.arange(n, dtype=float) + gamma) ** (-p)

    """
    Search for a low‑score step function.

    Parameters

    seed : int
        Random seed for reproducibility.
    budget_s : float
        Hard time budget (seconds).  The function finishes before this

    Returns
    -------
    list[float]
        Heights of the step function (plain Python list).
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.1   # safety margin

    # ------------------------------------------------------------------

    # A handful of lengths – larger lengths give a better asymptotic bound
