The algorithm repeatedly samples a random sparse non‑negative step
function of length n (n is chosen randomly in a moderate range).  The
total L1 norm is fixed to sqrt(2n) so that the evaluation function
simplifies to the maximal convolution value.  The support size m is
chosen proportional to sqrt(2n); with m ≈ 10·sqrt(2n) the expected
peak of the auto‑convolution is close to 1, well below the target
1.503.  Each candidate is evaluated and the best one is kept.
Optionally a short hill‑climbing phase moves a small amount of mass
from the largest coefficient to an empty location, which tends to
flatten the convolution further.

The search runs until the allotted time expires and returns the best
sequence discovered.
"""

import math
import numpy as np

    """Return a length‑n list with exactly m non‑zero entries of equal weight.
    The non‑zero positions are chosen uniformly at random without replacement.
    """
    if m > n:
        m = n
    # random distinct positions
    positions = np.random.choice(n, size=m, replace=False)
    a = np.zeros(n, dtype=float)
    val = total_sum / m
    a[positions] = val
    return a.tolist()

def hill_climb(seq: list, steps: int = 200, move_frac: float = 0.2) -> tuple[list, float]:
    """Simple hill‑climbing: move a fraction of the largest weight to a zero slot.
    Returns the best sequence found in the walk and its score."""
    # Convert to numpy array for speed
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    best_score = evaluate_sequence(a.tolist())
    best_seq = a.copy()

        src = int(np.argmax(a))
        if a[src] <= 1e-12:
            break
        # determine amount to move

"""
Random sparse step‑functions with a tiny hill‑climb.

The evaluation function simplifies (after fixing the L1 norm) to the
maximum value of the auto‑convolution.  For a random support of size
m the expected convolution is almost flat with mean 1, so the peak is
typically close to 1.  By choosing the support size proportional to
√(2 n) (≈ the natural scale of the L1 norm) we obtain sequences whose
score lies well below the target 1.503.

The algorithm repeatedly

* picks a length n in a modest range,
* chooses a support size m ≈ α·√(2 n) with α∈[5,12],
* puts equal weight on m random positions (the total sum is √(2 n)),
* evaluates the sequence,
* optionally performs a short hill‑climb that moves a small fraction of
  the largest coefficient to an empty slot, which tends to flatten the
  convolution further,
* keeps the best sequence seen before the time limit expires.

The search runs for the allotted budget (default 1000 s) and returns
the best sequence it discovered.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (must be top‑level – no closures)
# ----------------------------------------------------------------------


def generate_random_sequence(n: int, m: int, total_sum: float) -> list:
    """
    Create a length‑n non‑negative sequence with exactly m non‑zero entries.
    The non‑zero entries all have the same weight so that the L1 norm equals
    ``total_sum``.
    """
    if m > n:
        m = n
    # uniformly random distinct positions
    positions = np.random.choice(n, size=m, replace=False)
    seq = np.zeros(n, dtype=float)
    val = total_sum / m
    seq[positions] = val
    return seq.tolist()


def hill_climb(seq: list, steps: int = 200, move_frac: float = 0.2) -> tuple[list, float]:
    """
    Very cheap local optimisation.

    Repeatedly moves a random fraction (up to ``move_frac``) of the
    currently largest coefficient to a zero entry.  Only moves that
    improve the score are kept.  Returns the best sequence seen and its
    evaluation.
    """
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    # current best
    try:
        best_score = evaluate_sequence(a.tolist())
    except Exception:
        best_score = float('inf')
    best_seq = a.copy()

    for _ in range(steps):
        src = int(np.argmax(a))
        if a[src] <= 1e-12:
            break  # nothing to move

        # amount to move – a random fraction of the source value
        eps = a[src] * move_frac * np.random.rand()
        if eps <= 0.0:
            continue

        # pick a target index; prefer a zero slot
        zero_idxs = np.where(a == 0)[0]
        if zero_idxs.size:
            tgt = int(np.random.choice(zero_idxs))
        else:
            tgt = int(np.random.randint(n))
            while tgt == src:
                tgt = int(np.random.randint(n))

        a_new = a.copy()
        a_new[src] -= eps
        a_new[tgt] += eps

        try:
            new_score = evaluate_sequence(a_new.tolist())
        except Exception:
            continue

        if new_score < best_score:
            a = a_new
            best_score = new_score
            best_seq = a_new.copy()

    return best_seq.tolist(), best_score
