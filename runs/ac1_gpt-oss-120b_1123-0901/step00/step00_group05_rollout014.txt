Simple simulated‑annealing / hill‑climbing optimizer.

The evaluation function is scale‑invariant, so we keep the L1‑norm fixed
to √(2·n).  Starting from a random (or the provided) sequence we
repeatedly:

1. Compute the full auto‑convolution via FFT and find the index `k_max`
   where it attains its maximum.
2. Among the ordered pairs that contribute to this maximum we pick the
   pair with the largest product `a_i·a_j`.
3. Move a small fraction of mass from the heavier index of this pair to
   a random other position (keeping all entries non‑negative).
4. Accept the move if it improves the score, otherwise accept with a
   temperature‑dependent probability (simulated annealing).

The algorithm runs until the allotted time expires and returns the best
sequence seen.  All heavy work (convolutions) is performed with FFT,
so even a few hundred thousand iterations are feasible for a few‑thousand
element vector.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def _score_fft(a, target_sum):
    """
    Fast evaluation of the objective (without the security clamping).
    The vector `a` is assumed to already have L1‑norm `target_sum`.
    """
    n = a.size
    # pad to the next power of two for fast FFT
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    max_b = conv.max()
    # because `target_sum == sum(a)` the denominator is constant
    return 2.0 * n * max_b / (target_sum * target_sum)

    a = a * (target_sum / a.sum())              # normalise to the right sum

    # ------------------------------------------------------------------
