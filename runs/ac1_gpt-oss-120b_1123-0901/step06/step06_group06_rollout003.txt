Propose a non‑negative step‑function (list of heights) that minimises

        F(a) = 2·n·max(a*a) / (sum(a)²)

The search is based on three ideas:

1️⃣ **Rich parametric seeds** – families of symmetric shapes (arcsine,
   power‑law, double‑exponential) are sampled on a dense grid of the
   controlling exponent / decay parameter.  The best few seeds are kept.

2️⃣ **Fast exact evaluation** – convolution and cross‑correlation are done
   with FFTs (O(n log n)).  The objective is evaluated directly, so we can
   test thousands of candidates cheaply.

3️⃣ **Local sub‑gradient refinement** – for the most promising seeds a few
   iterations of an exponentiated‑gradient (EG) update are applied using
   the exact sub‑gradient of the max‑convolution.  Finally the current
   global best is fine‑tuned with a short Adam run on a smooth‑max
   surrogate.

The routine respects a time‑budget (default 1000 s).  It returns the best
sequence discovered as a plain Python list.
"""

import time
import numpy as np

# -------------------------------------------------------------
# FFT‑based linear convolution and cross‑correlation
def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a using an FFT of length ``fft_len``."""
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)
    # keep the linear‑convolution part (length 2·len(a)-1)
    return conv[: 2 * a.shape[0] - 1]


def _corr_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear cross‑correlation (w ★ a) needed for the sub‑gradient.
    Returns a vector of length len(a) equal to

        (w ★ a)[i] = Σ_k w[k]·a[i+k‑(n‑1)]

    where n = len(a).
    """
    n = a.shape[0]
    rev_a = a[::-1]
    fw = np.fft.rfft(w, fft_len)
    fr = np.fft.rfft(rev_a, fft_len)
    corr = np.fft.irfft(fw * fr, fft_len)
    start = n - 1
    return corr[start:start + n]

# Exact objective (no clipping)
def _objective(a: np.ndarray, n: int, conv_len: int) -> float:
    """Return 2·n·max(conv) / (sum(a)²) for a given sequence a."""
    conv = _conv_fft(a, conv_len)
    return 2.0 * n * conv.max() / (a.sum() ** 2)
