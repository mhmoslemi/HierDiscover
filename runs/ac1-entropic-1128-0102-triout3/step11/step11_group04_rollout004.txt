assistantfinal**Solution Overview**

The code below implements a new optimisation pipeline that improves on the previous
approach.  
The idea is to work directly on a *softmax* parametrisation of the step‑function,
so that non‑negativity and the simplex constraint are satisfied automatically.
A fast Adam optimiser is applied to the exact non‑smooth objective

```
F(a) = 2·n·max(conv(a,a))     (with Σ a = 1)
```

using the sub‑gradient of the max‑convolution (computed by FFT).  
After a long Adam phase a tiny stochastic hill‑climb polish finishes the search.

Key ingredients  

* **FFT‑based convolution** – O(n log n) for every iteration.  
* **Exact sub‑gradient** – obtained by convolving the indicator of the active
  (maximal) convolution entries with the reversed vector.  
* **Logit → softmax map** – guarantees a ≥ 0 and Σa = 1 without any projection.  
* **Adam with bias‑correction** – adaptive step sizes on the logit space.  
* **Restart & learning‑rate decay** – avoids stagnation.  
* **Fine hill‑climbing** – transfers a tiny fraction of mass between two
  positions and keeps the move only if the objective improves.

The whole routine respects a wall‑clock budget (default 1000 s) and returns the
best sequence found.

```python
"""
Propose a 4096‑length non‑negative step‑function that minimises
    2 * n * max(conv(a,a)) / (sum(a)**2)

Algorithm
---------

1.  Initialise from the global best `height_sequence_1` (or uniform) and
    express the vector as softmax logits `z`.
2.  **Adam on the exact objective**  
    – each iteration evaluates `conv(a,a)` by FFT, builds the hard‑max
      active mask, obtains the exact sub‑gradient via another FFT and
      updates the logits with Adam.  
    – learning‑rate decay and occasional restarts keep the search
      alive.
3.  **Hill‑climbing polish** – repeatedly move a tiny amount of mass from a
    source index (chosen proportionally to its current height) to a random
    destination; keep the move only if the objective improves.
4.  Return the best sequence (normalised to sum = 1).

All operations are O(n log n) and the routine runs well within the 1000 s
budget.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Basic FFT helpers
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int = None) -> np.ndarray:
    """
    Full linear self‑convolution a * a (length 2·len(a)‑1) using FFT.
    If L is given, it is used as the FFT length (must be ≥ 2·len(a)‑1).
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _conv_fft(u: np.ndarray, v: np.ndarray, L: int = None) -> np.ndarray:
    """
    Full linear convolution of u and v using FFT.
    Length of the result is len(u)+len(v)-1.
    """
    n = u.shape[0] + v.shape[0] - 1
    if L is None:
        L = _next_pow2(n)
    Uf = np.fft.rfft(u, n=L)
    Vf = np.fft.rfft(v, n=L)
    conv = np.fft.irfft(Uf * Vf, n=L)[:n]
    return conv


# ----------------------------------------------------------------------
# Fast exact evaluation (assumes Σa = 1)
# ----------------------------------------------------------------------


def _eval_fast(a: np.ndarray, L_self: int) -> float:
    """Exact objective value for a (non‑negative, sum≈1)."""
    conv = _conv_self(a, L_self)
    max_b = conv.max()
    n = a.shape[0]
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Adam optimisation on the exact objective
# ----------------------------------------------------------------------


def _adam_optimize(
    a0: np.ndarray,
    n: int,
    L_self: int,
    L_grad: int,
    deadline: float,
    start_time: float,
    max_iters: int = 500_000,
) -> tuple[np.ndarray, float]:
    """
    Adam on logits (softmax parametrisation) of a.
    Returns best sequence and its objective value.
    """
    # initialise logits from the starting vector
    eps = 1e-12
    z = np.log(a0 + eps)

    # Adam state
    m = np.zeros_like(z)
    v = np.zeros_like(z)
    beta1 = 0.9
    beta2 = 0.999
    eps_adam = 1e-8
    lr = 0.20  # initial learning rate
    t = 0

    best_a = a0.copy()
    best_score = _eval_fast(best_a, L_self)
    stagnation = 0  # iterations without improvement

    while time.time() < deadline - 5.0 and t < max_iters:
        t += 1

        # softmax (numerically stable)
        z_max = np.max(z)
        a = np.exp(z - z_max)
        a /= a.sum()

        # self‑convolution
        conv = _conv_self(a, L_self)
        max_val = conv.max()

        # active mask (hard max) – tolerance to catch floating‑point ties
        mask = (conv >= max_val - 1e-14).astype(float)

        # sub‑gradient of max‑convolution:
        #   grad_a = 2 * (a_rev * mask)  (slice the appropriate n entries)
        a_rev = a[::-1]
        mask_f = np.fft.rfft(mask, n=L_grad)
        rev_f = np.fft.rfft(a_rev, n=L_grad)
        conv_full = np.fft.irfft(mask_f * rev_f, n=L_grad)[: 3 * n - 2]
        grad_a = 2.0 * conv_full[n - 1 : n - 1 + n]

        # gradient w.r.t. logits (softmax chain rule)
        dot = np.dot(grad_a, a)  # scalar
        grad_z = a * (grad_a - dot)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z * grad_z)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps_adam)
        z -= step

        # evaluate current objective
        cur_score = 2.0 * n * max_val
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
            stagnation = 0
            print(f"[{time.time() - start_time:.2f}s] Adam it={t:,} score={cur_score:.6f}")
        else:
            stagnation += 1

            lr *= 0.80

            sigma_rand = 0.5
            z = best_log + sigma_rand * np.random.randn(n)
            m.fill(0.0)
            v.fill(0.0)
            stagnation = 0
            print(f"[{time.time() - start_time:.2f}s] Restarted Adam after stagnation (lr={lr:.4f})")

    return best_a, best_score
```
