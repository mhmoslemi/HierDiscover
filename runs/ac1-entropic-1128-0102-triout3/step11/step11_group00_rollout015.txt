The evaluation function  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}
\]

is scale‑invariant, therefore we may restrict ourselves to probability
vectors (`∑a = 1`).  
The goal is to find a non‑negative vector `a` that makes the maximal
entry of the self‑convolution as small as possible.

The algorithm proceeds in three phases

1. **Fast parametric sweep** – a large collection of low‑dimensional
   families (geometric, power‑law, beta‑type, mixtures) is explored.
   Every candidate is normalised to sum 1 and evaluated with a fast
   FFT based routine.

2. **Projected sub‑gradient descent** – starting from the best candidate
   of phase 1 we minimise  

   \[
   f(a)=2\,n\;\max (a*a)
   \]

   on the probability simplex.  
   The sub‑gradient of the active convolution entry is
   `grad_i = 2*a_{k-i}` (where `k` is the index of the maximal
   convolution).  A momentum term (`β≈0.9`) and a stepsize `α_t = α₀/√t`
   are used.  After each step the iterate is projected back onto the
   simplex by the Euclidean projection algorithm.

   When no improvement occurs for a while a tiny random perturbation is
   added to escape plateaus.

3. **Micro hill‑climb** – after the long descent a very fine‑grained
   exchange of a tiny amount of mass (`ε≈10⁻⁴·a_src`) between two random
   coordinates is attempted.  Only improving moves are kept.

All heavy lifting (convolution, FFT, projection) is performed with
NumPy, which is fast enough to allow several hundred thousand
iterations inside the 1000 s budget.

The implementation works for any length; we use `n = 8192` (twice the
previous size) because the additional degrees of freedom typically
lower the optimum.  If the global starter `height_sequence_1` is
available it is interpolated to the chosen size and used as an extra
initial point.

The function `propose_candidate` follows the required signature and
returns a plain Python list of floats ready for `evaluate_sequence`.  

```python
"""Propose a step‑function (non‑negative list) that minimises

    2 * n * max(conv(a, a)) / (sum(a)**2)

The search consists of

1️⃣ a fast parametric sweep over several low‑dimensional families,
2️⃣ a long projected sub‑gradient descent on the probability simplex
   (momentum + 1/√t stepsize, occasional tiny random kick),
3️⃣ a final micro‑hill‑climb that swaps an infinitesimal amount of mass
   between two random positions.

The whole routine respects the 1000 s time budget and returns the best
sequence found.  It works for any `n`; we use `n = 8192` to obtain a
tighter bound than the previous 4096‑element solution.
"""

import time
import math

import numpy as np
from scipy.optimize import linprog  # optional, not used in the final version


# ----------------------------------------------------------------------
# Linear‑algebra helpers
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """
    Linear self‑convolution a*a (length 2·len(a)‑1) using FFT.
    Zero‑padding length L is chosen automatically if omitted.
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
    w ≥ 0, sum(w) = 1.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Fast evaluation (sum≈1)
# ----------------------------------------------------------------------
def _eval_fast(a: np.ndarray, L_fft: int) -> float:
    """
    Exact objective 2·n·max(conv(a,a)) for a vector whose sum is ≈1.
    """
    conv = _conv_self(a, L=L_fft)
    max_b = conv.max()
    n = a.shape[0]
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Projected sub‑gradient descent (core optimiser)
# ----------------------------------------------------------------------
def _subgradient_descent(
    a0: np.ndarray,
    deadline: float,
    start_time: float,
) -> tuple[np.ndarray, float]:
    """
    Perform a long projected sub‑gradient descent on
        f(a) = 2·n·max(conv(a,a))

    a0 must already be normalised (sum = 1).  The routine returns the
    best vector seen and the corresponding objective value.
    """
    a = a0.copy()
    n = a.shape[0]
    L_fft = _next_pow2(2 * n - 1)

    best_a = a.copy()
    best_score = _eval_fast(a, L_fft)

    rng = np.random.default_rng()
    momentum = np.zeros_like(a)

    beta = 0.9            # momentum factor
    alpha0 = 0.7          # initial stepsize coefficient
    it = 0
    last_improve = 0

    while time.time() < deadline:
        it += 1

        # convolution and current score
        conv = _conv_self(a, L=L_fft)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

        # keep global best
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            last_improve = it
            print(f"[{time.time() - start_time:.2f}s] "
                  f"sub‑grad it={it:,} score={cur_score:.6f}")

        # ---- sub‑gradient of the max‑convolution ----
        k = int(conv.argmax())                # active shift
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad = np.zeros_like(a)
        # grad_i = 2 * a_{k-i}  (if inside the range)
        grad[idx] = 2.0 * a[k - idx]

        # momentum + projected step
        momentum = beta * momentum + (1.0 - beta) * grad
        step = alpha0 / math.sqrt(it)
        a = a - step * momentum
        a = _project_simplex(a)

        # ---- escape from a plateau ----
        if it - last_improve > 8000:
            # tiny Gaussian kick (scale ≈ 10⁻⁴ of the current entry)
            noise = 1e-4 * rng.standard_normal(n) * a
            a = a + noise
            a = _project_simplex(a)
            last_improve = it

    return best_a, best_score


# ----------------------------------------------------------------------
# Very small hill‑climb (final polishing)
# ----------------------------------------------------------------------
def _tiny_hill_climb(
    start_a: np.ndarray,
    deadline: float,
    start_time: float,
) -> tuple[np.ndarray, float]:
    """
    Move an infinitesimal amount of mass ε≈10⁻⁴·a_src between two random
    coordinates; keep the move only if it improves the exact objective.
    """
    a = start_a.copy()
    n = a.shape[0]
    L_fft = _next_pow2(2 * n - 1)

    best_score = _eval_fast(a, L_fft)
    best_a = a.copy()
    rng = np.random.default_rng()

    while time.time() < deadline:
        src = rng.integers(n)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-15:
            continue
        eps = a[src] * rng.random() * 1e-4
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps
        new_score = _eval_fast(a_prop, L_fft)
        if new_score < best_score:
            a = a_prop
            best_score = new_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] tiny hill‑climb "
                  f"score={best_score:.6f}")

    return best_a, best_score

        pass

    # ------------------------------------------------------------------
    # 1️⃣  Fast parametric sweep (geometric / power / beta / mixtures)
    # ------------------------------------------------------------------
    idx = np.arange(n, dtype=np.float64)

    # ----- geometric families -----
    eps_grid = np.logspace(-7, -1, 140)   # eps = 1‑r, r close to 1
    for eps in eps_grid:
        if time.time() >= deadline - 30:
            break
        r = 1.0 - eps
        geo = np.power(r, idx)            # r**i
        geo_sum = geo.sum()
        if geo_sum == 0:
            continue
        geo /= geo_sum
        for lam in np.linspace(0.0, 1.0, 13):   # finer mixing grid
            seq = lam * uniform + (1.0 - lam) * geo
            seq /= seq.sum()
            sc = _eval_fast(seq, L_fft)
            if sc < best_score:
                best_score = sc
                best_seq = seq.copy()
                print(f"[{time.time() - start_time:.2f}s] Geo eps={eps:.1e} lam={lam:.2f} score={sc:.6f}")

    # ----- power‑law families -----
    p_grid = np.linspace(-2.0, 3.0, 101)
    for p in p_grid:
        if time.time() >= deadline - 30:
            break
        pow_seq = np.power(idx + 1.0, p)   # (i+1)^p
        pow_sum = pow_seq.sum()
        if pow_sum == 0:
            continue
        pow_seq /= pow_sum
        sc = _eval_fast(pow_seq, L_fft)
        if sc < best_score:
            best_score = sc
            best_seq = pow_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Power p={p:.2f} score={sc:.6f}")

    # ----- beta‑type families (continuous shape parameters) -----
    alphas = np.logspace(-0.5, 1.0, 15)   # roughly 0.3 … 10
    betas = np.logspace(-0.5, 1.0, 15)
    for a in alphas:
        for b in betas:
            if time.time() >= deadline - 30:
                break
            beta_seq = np.power(idx + 0.5, a - 1.0) * np.power(n - idx - 0.5, b - 1.0)
            beta_sum = beta_seq.sum()
            if beta_sum == 0:
                continue
            beta_seq /= beta_sum
            sc = _eval_fast(beta_seq, L_fft)
            if sc < best_score:
                best_score = sc
                best_seq = beta_seq.copy()
                print(f"[{time.time() - start_time:.2f}s] Beta a={a:.3f} b={b:.3f} score={sc:.6f}")

    # ----- mixture of two exponentials -----
    for _ in range(30):
        if time.time() >= deadline - 30:
            break
        r1 = 1.0 - 10 ** np.random.uniform(-7, -1)
        r2 = 1.0 - 10 ** np.random.uniform(-7, -1)
        lam = np.random.rand()
        mix = lam * np.power(r1, idx) + (1.0 - lam) * np.power(r2, idx)
        mix_sum = mix.sum()
        if mix_sum == 0:
            continue
        mix /= mix_sum
        sc = _eval_fast(mix, L_fft)
        if sc < best_score:
            best_score = sc
            best_seq = mix.copy()
            print(f"[{time.time() - start_time:.2f}s] Two‑exp lam={lam:.3f} r1={r1:.5f} r2={r2:.5f} score={sc:.6f}")

    # ------------------------------------------------------------------
    # 2️⃣  Long projected sub‑gradient descent (bulk of the budget)
    # ------------------------------------------------------------------
    if time.time() < deadline - 15.0:
        print(f"[{time.time() - start_time:.2f}s] Starting long sub‑gradient descent")
        a_sub, sc_sub = _subgradient_descent(best_seq, deadline - 5.0, start_time)
        if sc_sub < best_score:
            best_score = sc_sub
            best_seq = a_sub.copy()
            print(f"[{time.time() - start_time:.2f}s] Sub‑grad improvement score={sc_sub:.6f}")

    # ------------------------------------------------------------------
    # 3️⃣  Final microscopic hill‑climb (polish)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        a_hc, sc_hc = _tiny_hill_climb(best_seq, deadline, start_time)
        if sc_hc < best_score:
            best_score = sc_hc
            best_seq = a_hc.copy()
            print(f"[{time.time() - start_time:.2f}s] Tiny hill‑climb final score={sc_hc:.6f}")

    # ------------------------------------------------------------------
    # Normalise finally (guard against numerical drift) and return
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```
