assistantfinal**Solution Overview**

The program searches for a non‑negative step‑function (a list of heights) that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the linear self‑convolution of `a`.  
The score is **scale‑invariant**, therefore we keep the vector on the probability simplex
(`sum(a)=1`).  

The search consists of three stages:

1. **Broad initialisation** – a collection of hand‑crafted families (geometric,
   power, Beta, arcsine), a few random Dirichlet draws and a “comb’’ with equally
   spaced spikes.  
   Every initial vector is normalised to sum = 1.

2. **Smoothed projected Adam optimisation** –  
   Instead of a non‑smooth sub‑gradient of the max, we minimise a smooth
   approximation  

   \[
   L_{\gamma}(a)=\frac{1}{\gamma}\log\!\Bigl(\sum_i e^{\gamma\,
   (a*a)_i}\Bigr),
   \]

   whose gradient is  

   \[
   \nabla L_{\gamma}(a)=2\;(w * a)_{0\ldots n-1},
   \qquad
   w_i=\frac{e^{\gamma\,(a*a)_i}}{\sum_j e^{\gamma\,(a*a)_j}} .
   \]

   The gradient is obtained with two FFT based convolutions
   ( `a*a` and `w*a` ).  
   An Adam step is taken, then the iterate is projected back onto the simplex.
   The smoothing parameter `γ` is increased gradually (`continuation`) so that
   the optimiser first sees a smooth landscape and finally focuses on the true
   max‑convolution.

   A tiny random perturbation is injected if no progress is made for a while,
   helping the method escape shallow plateaus.

3. **Micro hill‑climb** –  
   After optimisation a very small “mass‑transfer’’ neighbourhood search
   (ε≈10⁻⁴·aₛᵣc) is performed; only improving moves are kept.

All heavy work uses FFT‑based convolutions ( \(O(n\log n)\) ).  
The whole routine respects the 1000 s budget and returns the best sequence
found as plain Python floats.

```python
"""
Propose a non‑negative step function that minimises
    2 * n * max(conv(a,a)) / (sum(a)**2)

Algorithm
---------
1️⃣ Initialise many diverse candidates (geometric, power, Beta,
   arcsine, random Dirichlet, comb‑spikes).

2️⃣ For each candidate run a projected Adam optimiser that minimises the
   smooth log‑sum‑exp approximation of the max‑convolution.
   • Gradient = 2 * (w * a) where w are softmax weights of the current
     convolution.
   • Continuation on the smoothing parameter γ (start small, grow).
   • After each Adam step the vector is projected onto the probability
     simplex.
   • If no improvement for a while a tiny Gaussian perturbation is added.

3️⃣ Final micro hill‑climb that moves ε·a_src mass between two random
   indices; only moves that improve the true objective are kept.

The routine runs for ≤ budget_s seconds and returns a list of Python
floats ready for `evaluate_sequence`.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Basic linear‑algebra utilities (FFT based convolutions)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_full(x: np.ndarray, y: np.ndarray, L: int) -> np.ndarray:
    """
    Linear convolution x*y (full length) using real FFT.
    The result is truncated to the exact length (len(x)+len(y)-1).
    """
    X = np.fft.rfft(x, n=L)
    Y = np.fft.rfft(y, n=L)
    conv = np.fft.irfft(X * Y, n=L)
    return conv[: x.shape[0] + y.shape[0] - 1]


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex (w≥0, Σw=1)."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Fast exact evaluation (sum≈1) – used for logging and final score
# ----------------------------------------------------------------------
def _eval_fast(a: np.ndarray, L_fft: int) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a vector with sum≈1."""
    conv = _conv_full(a, a, L_fft)
    max_b = conv.max()
    n = a.shape[0]
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Smoothed gradient (log‑sum‑exp of the convolution)
# ----------------------------------------------------------------------
def _softmax_gradient(a: np.ndarray, gamma: float,
                      L_self: int, L_grad: int):
    """
    Returns (grad, conv) where
    * conv = a*a (full length 2n‑1)
    * grad = 2 * (w * a)[:n]   with w_i ∝ exp(gamma * conv_i)
    Both convolutions are computed via FFT.
    """
    n = a.shape[0]

    # 1) self‑convolution a*a
    conv = _conv_full(a, a, L_self)                     # length 2n‑1
    max_c = conv.max()
    # softmax weights
    exps = np.exp(gamma * (conv - max_c))
    w = exps / exps.sum()                               # length 2n‑1, sums to 1

    # 2) gradient = 2 * (w * a)[:n]
    grad_full = _conv_full(w, a, L_grad)                # length 3n‑2
    grad = 2.0 * grad_full[:n]

    return grad, conv


# ----------------------------------------------------------------------
# Projected Adam optimiser with continuation on γ
# ----------------------------------------------------------------------
def _adam_optimize(a0: np.ndarray,
                   deadline: float,
                   start_time: float,
                   L_self: int,
                   L_grad: int,
                   global_best_score: float):
    """
    Adam optimisation of the smoothed objective.
    Returns (best_a, best_score) obtained during the run.
    """
    n = a0.shape[0]
    rng = np.random.default_rng()

    # initialise on simplex
    a = np.maximum(a0, 0.0)
    if a.sum() == 0.0:
        a = np.full(n, 1.0 / n)
    else:
        a = a / a.sum()

    # bookkeeping
    best_a = a.copy()
    best_score = _eval_fast(a, L_self)
    last_improve = 0

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr0 = 0.20                     # initial learning‑rate
    t = 0

    # continuation schedule for γ
    gamma = 2.0
    gamma_step = 2000
    next_gamma = gamma_step

    while time.time() < deadline:
        t += 1

        # ---- gradient of the smoothed max ----
        grad, conv = _softmax_gradient(a, gamma, L_self, L_grad)

        # ---- Adam update ----
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        step = lr0 / math.sqrt(t)
        a = a - step * m_hat / (np.sqrt(v_hat) + eps)

        # ---- projection onto the simplex ----
        a = _project_simplex(a)

        # ---- occasional logging & best‑track ----
        if t % 250 == 0:
            cur_score = _eval_fast(a, L_self)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                last_improve = t
                print(f"[{time.time() - start_time:.2f}s] Adam it={t:,} "
                      f"γ={gamma:.2f} score={cur_score:.6f}")

            # early exit if we already beat the global best by a comfortable margin
            if best_score < global_best_score * 0.995:
                # enough improvement – continue only a little longer
                pass

        # ---- increase smoothing parameter γ ----
        if t >= next_gamma:
            gamma = min(gamma * 1.5, 200.0)   # cap to avoid overflow
            next_gamma += gamma_step

        # ---- escape plateaus (tiny random kick) ----
        if t - last_improve > 5000:
            noise = 1e-4 * rng.standard_normal(n) * a
            a = np.maximum(a + noise, 0.0)
            a = _project_simplex(a)
            last_improve = t

        # ---- time guard ----
        if time.time() > deadline - 0.5:
            break

    return best_a, best_score


# ----------------------------------------------------------------------
# Tiny hill‑climb (final polishing)
# ----------------------------------------------------------------------
def _tiny_hill_climb(start_a: np.ndarray,
                     deadline: float,
                     start_time: float,
                     L_self: int) -> tuple[np.ndarray, float]:
    """
    Very small mass transfers (ε≈10⁻⁴·a_src) that are accepted only if the
    true objective improves.  Fine‑tunes the solution after the Adam phase.
    """
    a = start_a.copy()
    best_a = a.copy()
    best_score = _eval_fast(a, L_self)
    rng = np.random.default_rng()
    n = a.shape[0]

    while time.time() < deadline:
        src = rng.integers(n)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-15:
            continue
        eps = a[src] * rng.random() * 1e-4
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps
        cur = _eval_fast(a_prop, L_self)
        if cur < best_score:
            a = a_prop
            best_score = cur
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] Tiny hill‑climb score={best_score:.6f}")

    return best_a, best_score

def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises the supplied
    evaluation function.  The routine respects the 1000 s budget and returns
    the best sequence found as a plain list of Python floats.
    """
    np.random.seed(seed)
    rng = np.random.default_rng(seed)

    start_time = time.time()
    # small safety margin
    deadline = start_time + budget_s - 0.30

    # --------------------------------------------------------------
    # Problem size (can be increased if time permits)
    # --------------------------------------------------------------
    n = 4096
    L_self = _next_pow2(2 * n - 1)            # for a*a
    L_grad = _next_pow2(3 * n - 2)            # for w*a (gradient)

    # --------------------------------------------------------------
    # Baseline – uniform distribution
    # --------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    best_seq = uniform.copy()
    best_score = _eval_fast(best_seq, L_self)
    print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    # --------------------------------------------------------------
    # 1️⃣  Build a pool of diverse initial candidates
    # --------------------------------------------------------------
    candidates = []

    idx = np.arange(n, dtype=np.float64)

    # geometric families (r close to 1)
    for eps in [1e-2, 5e-3, 2e-3, 1e-3]:
        r = 1.0 - eps
        geo = np.power(r, idx)
        geo /= geo.sum()
        candidates.append(geo)

    # power families
    for p in [-0.5, -0.2, 0.0, 0.2, 0.5, 1.0]:
        pow_seq = np.power(idx + 1.0, p)
        pow_seq /= pow_seq.sum()
        candidates.append(pow_seq)

    # Beta‑type families
    for p, q in [(0.5, 0.5), (0.3, 0.3), (1.0, 1.0), (2.0, 2.0)]:
        beta_seq = np.power(idx + 1.0, p) * np.power(n - idx, q)
        beta_seq /= beta_seq.sum()
        candidates.append(beta_seq)

    # arcsine (Beta(0.5,0.5)) – heavy near the ends
    arcs = 1.0 / np.sqrt((idx + 0.5) * (n - 0.5 - idx))
    arcs /= arcs.sum()
    candidates.append(arcs)

    # random Dirichlet draws with various concentration parameters
    for alpha in [0.1, 0.5, 2.0, 5.0]:
        cand = rng.dirichlet([alpha] * n)
        candidates.append(cand)

    # comb patterns – equally spaced spikes
    for k in [16, 32, 64]:
        positions = np.linspace(0, n - 1, k, dtype=int)
        comb = np.zeros(n)
        comb[positions] = 1.0 / k
        candidates.append(comb)

    # mixture of two geometric ends (left‑hand and right‑hand decays)
    for r_left in [0.995, 0.999]:
        left = np.power(r_left, idx)
        right = np.power(r_left, (n - 1 - idx))
        mix = left + right
        mix /= mix.sum()
        candidates.append(mix)

    # --------------------------------------------------------------
    # 2️⃣  Optimise each candidate with projected Adam
    # --------------------------------------------------------------
    for init in candidates:
        if time.time() >= deadline - 5.0:
            break
        a_opt, sc_opt = _adam_optimize(
            init, deadline, start_time, L_self, L_grad, best_score
        )
        if sc_opt < best_score:
            best_score = sc_opt
            best_seq = a_opt.copy()
            print(f"[{time.time() - start_time:.2f}s] New global best = {best_score:.6f}")

    # --------------------------------------------------------------
    # 3️⃣  Final micro hill‑climb polish
    # --------------------------------------------------------------
    if time.time() < deadline:
        a_hc, sc_hc = _tiny_hill_climb(best_seq, deadline, start_time, L_self)
        if sc_hc < best_score:
            best_score = sc_hc
            best_seq = a_hc.copy()
            print(f"[{time.time() - start_time:.2f}s] Final hill‑climb best = {best_score:.6f}")

    # --------------------------------------------------------------
    # Normalise finally (scale does not matter for the evaluator)
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
```
