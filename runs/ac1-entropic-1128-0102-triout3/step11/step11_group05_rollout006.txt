The search consists of three deterministic phases that use only NumPy,
no file or network access, and respect the 1000 s time budget.

1. **Smooth‑max mirror descent** –  
   The objective  
   \[
   F(a)=\frac{2n\max_k (a*a)_k}{(\sum_i a_i)^2}
   \]
   is scale‑invariant, therefore we keep the vector on the probability
   simplex (`∑a=1`).  
   We replace the non‑smooth `max` by a log‑sum‑exp
   \[
   \operatorname{S}_\alpha(a)=\frac1\alpha\log\!\Bigl(\sum_k
   e^{\alpha\,(a*a)_k}\Bigr)
   \]
   and perform exponentiated‑gradient (mirror descent) steps on the
   simplex.  The smoothing parameter `α` is increased geometrically from
   `0.5` up to `2000`; for each `α` we run many cheap FFT‑based updates.
   The best point seen is stored.

2. **Direct max‑subgradient (exponentiated) descent** –  
   After the smoothed phase we minimise the *real* maximum
   `(a*a)_k`.  At each iteration the index `k` that attains the maximum
   is found, a sub‑gradient
   `g_i = 2·a_{k-i}` (for the indices that actually contribute) is
   built, and an exponentiated‑gradient step is performed.
   The step size decays like `1/√t`.  This phase drives the true
   objective further down.

3. **Stochastic hill‑climbing (simulated annealing)** –  
   The final few seconds are spent on tiny random mass transfers.
   Each move is accepted if it improves the exact objective
   `evaluate_sequence`; otherwise it is accepted with a Metropolis
   probability under a rapidly cooling temperature schedule.
   The evaluation uses a single FFT per move, which is still cheap
   compared with the remaining budget.

All phases keep the vector non‑negative, renormalise it after each
update and keep the best sequence found.  The routine returns a Python
list of floats ready for the external `evaluate_sequence` call.

```python
"""
Three‑phase optimizer for the step‑function objective

    2 * n * max(conv(a,a)) / (sum(a)**2)

  1. Smooth‑max mirror descent (exponentiated‑gradient) with a
     geometric schedule of the smoothing parameter α up to 2000.
  2. Direct max‑subgradient descent on the true maximum,
     again with an exponentiated‑gradient update.
  3. Simulated‑annealing hill‑climbing for a final polish.

All computations stay on the probability simplex (∑a = 1) and respect
the 1000 s time budget.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Global problem size
# ----------------------------------------------------------------------
n = 4096
_L_SELF = 1 << ((2 * n - 2).bit_length())          # power of two ≥ 2n‑1
_L_GRAD = 1 << ((3 * n - 3).bit_length())          # power of two ≥ 3n‑2


# ----------------------------------------------------------------------
# Fast exact objective (uses FFT, works for any non‑negative a with sum≈1)
# ----------------------------------------------------------------------
def _exact_score(a: np.ndarray) -> float:
    """Return 2·n·max(conv(a,a)) / (sum(a)**2)."""
    # self‑convolution via FFT (full length 2·n‑1)
    Af = np.fft.rfft(a, n=_L_SELF)
    conv = np.fft.irfft(Af * Af, n=_L_SELF)[: 2 * n - 1]
    max_b = conv.max()
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Phase 1 – smooth‑max mirror descent
# ----------------------------------------------------------------------
def _smooth_descent(a: np.ndarray, deadline: float, start_time: float):
    """Exponentiated‑gradient on the log‑sum‑exp approximation of max."""
    best_a = a.copy()
    best_score = _exact_score(best_a)

    # geometric schedule of the smoothing parameter
    alphas = np.geomspace(0.5, 2000.0, num=48)

    it = 0
    for alpha in alphas:
        # stop early if we run out of time
        if time.time() >= deadline - 0.2:
            break

        # inner loop: as many iterations as time permits for the current α
        while time.time() < deadline - 0.2:
            it += 1

            # 1) self‑convolution a*a
            Af = np.fft.rfft(a, n=_L_SELF)
            conv = np.fft.irfft(Af * Af, n=_L_SELF)[: 2 * n - 1]

            # 2) smooth‑max weights w = softmax(α·conv)
            exp_arg = alpha * conv
            max_exp = exp_arg.max()
            w = np.exp(exp_arg - max_exp)          # stability
            w_sum = w.sum()
            if w_sum == 0.0:
                w.fill(1.0 / w.shape[0])
            else:
                w /= w_sum

            # 3) gradient = 2·(w ⋆ a_rev)
            a_rev = a[::-1]
            Wf = np.fft.rfft(w, n=_L_GRAD)
            Revf = np.fft.rfft(a_rev, n=_L_GRAD)
            grad_full = np.fft.irfft(Wf * Revf, n=_L_GRAD)[: 3 * n - 2]
            grad = 2.0 * grad_full[n - 1:n - 1 + n]

            # 4) exponentiated‑gradient step on the simplex
            eta = 0.1 / (math.sqrt(it) * max(1.0, math.sqrt(alpha)))
            a = a * np.exp(-eta * grad)
            a = np.maximum(a, 1e-30)          # avoid exact zeros
            a_sum = a.sum()
            if a_sum > 0.0:
                a /= a_sum
            else:
                a = np.full_like(a, 1.0 / n)

            # occasional exact evaluation
            if it % 8000 == 0:                # about once per few seconds
                cur_score = _exact_score(a)
                if cur_score < best_score:
                    best_score = cur_score
                    best_a = a.copy()
                    print(f"[{time.time() - start_time:.2f}s] "
                          f"smooth α={alpha:.1f} it={it:,} score={cur_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Phase 2 – direct max‑subgradient (exponentiated) descent
# ----------------------------------------------------------------------
def _max_subgradient_descent(a: np.ndarray, deadline: float, start_time: float):
    """Iteratively push mass away from the index that attains the current max."""
    best_a = a.copy()
    best_score = _exact_score(best_a)

    it = 0
    while time.time() < deadline - 0.2:
        it += 1

        # current self‑convolution and its maximum index
        Af = np.fft.rfft(a, n=_L_SELF)
        conv = np.fft.irfft(Af * Af, n=_L_SELF)[: 2 * n - 1]
        k = int(conv.argmax())

        # sub‑gradient: only entries that contribute to (a*a)[k]
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)

        grad = np.zeros_like(a)
        grad[idx] = 2.0 * a[k - idx]          # g_i = 2·a_{k‑i}

        # exponentiated‑gradient step (step size ~ 1/√t)
        eta = 0.5 / math.sqrt(it)
        a = a * np.exp(-eta * grad)
        a = np.maximum(a, 1e-30)
        a_sum = a.sum()
        if a_sum > 0.0:
            a /= a_sum
        else:
            a = np.full_like(a, 1.0 / n)

        # periodic exact evaluation
        if it % 5000 == 0:
            cur_score = _exact_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] sub‑grad it={it:,} score={cur_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Phase 3 – stochastic hill‑climbing (simulated annealing)
# ----------------------------------------------------------------------
def _hill_climb(a: np.ndarray, deadline: float, start_time: float):
    """Small random mass transfers with Metropolis acceptance."""
    cur = a.copy()
    cur_score = _exact_score(cur)

    best_seq = cur.copy()
    best_score = cur_score

    rng = np.random.default_rng()
    it = 0
    start_temp = 5e-2
    end_temp = 1e-10

    while time.time() < deadline:
        it += 1

        # linearised progress for temperature decay
        progress = (time.time() - start_time) / (deadline - start_time)
        T = start_temp * (end_temp / start_temp) ** progress

        src = rng.integers(n)
        if cur[src] < 1e-14:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue

        # move up to 30 % of the source mass
        eps = cur[src] * rng.random() * 0.30
        if eps <= 0.0:
            continue

        cand = cur.copy()
        cand[src] -= eps
        cand[dst] += eps
        cand = np.maximum(cand, 0.0)
        cand_sum = cand.sum()
        if cand_sum > 0.0:
            cand /= cand_sum
        else:
            continue

        cand_score = _exact_score(cand)
        delta = cand_score - cur_score

        # Metropolis acceptance
        if delta <= 0.0 or math.exp(-delta / T) > rng.random():
            cur = cand
            cur_score = cand_score

            if cand_score < best_score:
                best_score = cand_score
                best_seq = cand.copy()
                print(f"[{time.time() - start_time:.2f}s] hill‑climb it={it:,} best={best_score:.6f}")

    return best_seq, best_score

# Main entry point required by the competition framework
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):

        1. Smooth‑max mirror descent (heavy FFT‑based phase)
        2. Direct max‑subgradient descent (exponentiated‑gradient)
        3. Final stochastic hill‑climb (simulated annealing)
    """

    start_time = time.time()

    # ------------------------------------------------------------------

    # Adjust length to n

        else:

    else:

    best_seq = starter.copy()
    best_score = _exact_score(best_seq)
    print(f"[{time.time() - start_time:.2f}s] Starter score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – smooth‑max mirror descent
    # ------------------------------------------------------------------
    if time.time() < deadline - 40.0:      # leave room for later phases
        phase_deadline = deadline - 20.0
        best_seq, best_score = _smooth_descent(best_seq, phase_deadline, start_time)
        print(f"[{time.time() - start_time:.2f}s] After smooth descent best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – direct max‑subgradient descent
    # ------------------------------------------------------------------
    if time.time() < deadline - 10.0:
        phase_deadline = deadline - 5.0
        best_seq, best_score = _max_subgradient_descent(best_seq, phase_deadline, start_time)
        print(f"[{time.time() - start_time:.2f}s] After sub‑gradient best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – stochastic hill‑climb (annealing) for polish
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_seq, best_score = _hill_climb(best_seq, deadline, start_time)
        print(f"[{time.time() - start_time:.2f}s] Final hill‑climb best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation and conversion to plain Python list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
```
