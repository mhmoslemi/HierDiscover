assistantfinal**Solution Overview**

The evaluation function  

```
score = 2·n·max(conv(a,a)) / (sum(a)²)
```

is homogeneous – scaling the whole vector does not change the score – so we may
always normalise the candidate to have `sum(a)=1`.  
For a normalised vector the score is simply `2·n·max(conv(a,a))`.  
The maximum of the self‑convolution is always attained at shift 0,
i.e. `max(conv)=∑ a_i²`.  
Consequently the problem reduces to **minimise the ℓ₂‑norm of a probability
vector** (the uniform distribution is optimal).  In practice the score is
computed with floating‑point arithmetic, so the optimum is approached only up
to rounding errors.  The previous implementation already reaches a score of
≈ 1.508 > 1.503, but a more aggressive stochastic search can push the value a
little further.

The new solver follows three stages

1. **Parametric seeding** – a dense sweep over several families (geometric,
   power, beta, sinusoidal) plus a few random Dirichlet draws.  The best seed
   forms the starting point for the global search.

2. **Simulated‑annealing on the simplex** – we repeatedly move a tiny fraction
   of the mass from a source index to a destination index, normalise the
   vector (Euclidean projection onto the probability simplex) and accept the
   move with the Metropolis probability `exp(-(new‑old)/T)`.  The temperature
   `T` decreases geometrically, allowing large exploratory steps early on and
   fine‑grained exploitation later.  The convolution needed for the score is
   evaluated by an FFT‑based self‑convolution (`_conv_self`) which is
   O(n log n) and fast enough for many thousands of iterations.

3. **Micro‑hill‑climb polishing** – after the annealing phase the algorithm
   performs a deterministic sweep that transfers an infinitesimal amount of
   mass (`ε≈10⁻⁸·a_src`) between random pairs of indices, keeping only
   improving moves.

All heavy work uses NumPy vectorised code; the whole search respects the
1000 s budget (a small safety margin is kept).  The program prints progress
messages so that the optimisation path can be followed when it runs.

Below is the complete, self‑contained implementation.  The entry point is the
function `propose_candidate` which returns a plain Python list of floats ready
for `evaluate_sequence`.

```python
"""
Simulated‑annealing optimiser for the step‑function bound

    score = 2·n·max(conv(a,a)) / (sum(a)²)

The algorithm consists of

  1️⃣  a fast parametric sweep (geometric, power, beta, sinusoidal) and a
      handful of random Dirichlet draws – the best vector from this stage
      seeds the global search;

  2️⃣  a long simulated‑annealing run on the probability simplex.  At each
      iteration a small amount of mass is moved from a source index to a
      destination index, the vector is projected back onto the simplex and
      the new score is evaluated with an FFT based self‑convolution.  The
      Metropolis acceptance criterion with a geometrically cooling temperature
      allows the walk to escape shallow local minima;

  3️⃣  a final micro‑hill‑climb that transfers an extremely tiny amount of
      mass between randomly chosen indices and keeps only improving moves.

The routine respects a 1000 s wall‑time budget and returns the best sequence
found as a list of Python floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Linear‑algebra utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """
    Linear self‑convolution a*a (length 2·len(a)‑1) using FFT.
    Zero‑padding length L is chosen automatically if omitted.
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex.
    Returns w with w≥0 and sum(w)=1.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Fast evaluation (assumes a is on the simplex – i.e. sum≈1)
# ----------------------------------------------------------------------
def _score_fast(a: np.ndarray, L_fft: int) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a vector with sum≈1."""
    conv = _conv_self(a, L=L_fft)
    max_b = conv.max()
    n = a.shape[0]
    # sum(a) is ≈1 by construction; still compute it for safety
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Parametric families used for seeding
# ----------------------------------------------------------------------
def _geometric_family(n: int, eps_grid: np.ndarray, mix_grid: np.ndarray):
    """Yield mixtures of uniform and geometric decay."""
    idx = np.arange(n, dtype=np.float64)
    uniform = np.full(n, 1.0 / n)
    for eps in eps_grid:
        r = 1.0 - eps
        geo = np.power(r, idx)
        s = geo.sum()
        if s == 0.0:
            continue
        geo /= s
        for lam in mix_grid:
            seq = lam * uniform + (1.0 - lam) * geo
            seq /= seq.sum()
            yield seq


def _power_family(n: int, p_grid: np.ndarray):
    """Yield a_i ∝ (i+1)^p."""
    idx = np.arange(n, dtype=np.float64)
    uniform = np.full(n, 1.0 / n)
    for p in p_grid:
        seq = np.power(idx + 1.0, p)
        s = seq.sum()
        if s == 0.0:
            continue
        seq /= s
        # optionally mix with uniform for a smoother search
        seq = 0.5 * uniform + 0.5 * seq
        seq /= seq.sum()
        yield seq


def _beta_family(n: int, beta_vals: np.ndarray):
    """Yield a_i ∝ i^p (n‑i)^q."""
    idx = np.arange(n, dtype=np.float64)
    uniform = np.full(n, 1.0 / n)
    for p in beta_vals:
        for q in beta_vals:
            seq = np.power(idx + 1.0, p) * np.power(n - idx, q)
            s = seq.sum()
            if s == 0.0:
                continue
            seq /= s
            seq = 0.7 * uniform + 0.3 * seq
            seq /= seq.sum()
            yield seq


def _sinusoid_family(n: int, power_grid: np.ndarray):
    """Yield a_i ∝ sin(π·(i+0.5)/n)^p."""
    idx = np.arange(n, dtype=np.float64)
    base = np.sin(np.pi * (idx + 0.5) / n)
    uniform = np.full(n, 1.0 / n)
    for p in power_grid:
        seq = np.power(base, p)
        s = seq.sum()
        if s == 0.0:
            continue
        seq /= s
        seq = 0.6 * uniform + 0.4 * seq
        seq /= seq.sum()
        yield seq


def _random_dirichlet_candidates(n: int, rng: np.random.Generator,
                                 count: int = 20, alpha: float = 1.0):
    """Yield random points on the simplex (Dirichlet distribution)."""
    for _ in range(count):
        seq = rng.dirichlet([alpha] * n)
        yield seq


# ----------------------------------------------------------------------
# Simulated‑annealing on the simplex
# ----------------------------------------------------------------------
def _anneal_on_simplex(start_a: np.ndarray,
                       n: int,
                       deadline: float,
                       start_time: float,
                       L_fft: int) -> tuple[np.ndarray, float]:
    """
    Stochastic annealing on the probability simplex.
    Proposes mass‑transfer moves, projects back onto the simplex and accepts
    according to the Metropolis rule with a geometrically cooling temperature.
    """
    a = start_a.copy()
    best_a = a.copy()
    best_score = _score_fast(a, L_fft)

    rng = np.random.default_rng()
    it = 0

    # initial temperature – chosen so that a typical move is accepted
    T0 = 0.05
    T = T0
    cooling = 0.9995   # exponential cooling factor per iteration

    while time.time() < deadline:
        it += 1

        # ---- propose a mass‑transfer move ----
        src = rng.integers(n)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-12:
            continue

        # move a random fraction of the source mass
        frac = rng.random() * 0.25   # at most 25 % of src is moved
        delta = a[src] * frac

        a_prop = a.copy()
        a_prop[src] -= delta
        a_prop[dst] += delta

        # projection onto the simplex (keeps sum exactly 1)
        a_prop = _project_simplex(a_prop)

        # evaluate
        cur_score = _score_fast(a_prop, L_fft)

        # Metropolis acceptance
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_prop.copy()
            print(f"[{time.time() - start_time:.2f}s] New best (anneal) "
                  f"it={it:,} score={cur_score:.6f}")

        if cur_score < _score_fast(a, L_fft) or rng.random() < math.exp(-(cur_score - _score_fast(a, L_fft)) / max(T, 1e-12)):
            a = a_prop

        # cool down
        T *= cooling

        # occasional random restart if we seem stuck (very low temperature)
        if it % 100000 == 0 and T < 1e-8:
            a = rng.dirichlet(np.ones(n))
            a = _project_simplex(a)
            T = T0

    return best_a, best_score


# ----------------------------------------------------------------------
# Micro hill‑climb (very small transfers)
# ----------------------------------------------------------------------
def _tiny_hill_climb(start_a: np.ndarray,
                     deadline: float,
                     start_time: float,
                     L_fft: int) -> tuple[np.ndarray, float]:
    """
    Fine‑grained deterministic improvement: move ε≈10⁻⁸·a_src between two
    random positions, keep the move only if it improves the exact score.
    """
    a = start_a.copy()
    best_score = _score_fast(a, L_fft)
    best_a = a.copy()
    rng = np.random.default_rng()
    n = a.shape[0]

    while time.time() < deadline:
        src = rng.integers(n)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-15:
            continue
        eps = a[src] * rng.random() * 1e-4   # mass ≈10⁻⁴·a_src
        if eps == 0.0:
            continue

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps
        # re‑normalise (the move already conserves mass, but projection removes
        # tiny negative rounding artefacts)
        a_prop = _project_simplex(a_prop)

        new_score = _score_fast(a_prop, L_fft)
        if new_score < best_score:
            a = a_prop
            best_score = new_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] Tiny climb score={best_score:.6f}")

    return best_a, best_score

    # 2️⃣  Simulated‑annealing (bulk of the budget)
    # ------------------------------------------------------------------
    if time.time() < deadline - 15.0:
        print(f"[{time.time() - start_time:.2f}s] Starting simulated annealing")
        a_anneal, sc_anneal = _anneal_on_simplex(best_seq, n,
                                                 deadline - 5.0,
                                                 start_time,
                                                 L_fft)
        if sc_anneal < best_score:
            best_score = sc_anneal
            best_seq = a_anneal.copy()
            print(f"[{time.time() - start_time:.2f}s] Annealing improved score={sc_anneal:.6f}")

    # ------------------------------------------------------------------
    # 3️⃣  Final micro hill‑climb
    # ------------------------------------------------------------------
    if time.time() < deadline:
        a_hc, sc_hc = _tiny_hill_climb(best_seq, deadline, start_time, L_fft)
        if sc_hc < best_score:
            best_score = sc_hc
            best_seq = a_hc.copy()
            print(f"[{time.time() - start_time:.2f}s] Final hill‑climb score={sc_hc:.6f}")

    # ------------------------------------------------------------------
    # Normalise and return (evaluate_sequence will clamp anyway)
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```
