Let's write final code.assistantfinal**Solution Overview**

The task is to output a list of non‑negative numbers (the heights of a step function) that minimises  

\[
F(a)=\frac{2\,n\;\max (a*a)}{\Bigl(\sum_i a_i\Bigr)^2},
\]

where `a*a` is the linear self‑convolution of the vector `a` and `n=len(a)`.  
The score is invariant under scaling, therefore we keep the vector on the probability
simplex (`\sum a_i = 1`) and only have to respect the non‑negativity constraint.

The implementation below follows three phases

1. **Exploratory sweep** – generate a large collection of analytically‑motivated
   candidates (arcsine‑type, Beta‑type and mixtures with a uniform component) for a
   relatively large discretisation (`n = 16384`). The best candidate from this cheap
   sweep is kept.

2. **Projected gradient descent** – minimise the exact (non‑smooth) objective by
   using the true gradient of `F`.  
   For a current vector `a` let  

   * `k` be the index where the convolution attains its maximum,  
   * `M = (a*a)[k]`,  
   * `gM[i] = 2 a_{k-i}` for the indices that participate in the maximum
     (otherwise `0`).  

   The gradient of `F` is  

   \[
   \nabla F(a)=\frac{2n}{(\sum a)^2}\Bigl(g_M-\frac{2M}{\sum a}\mathbf 1\Bigr).
   \]

   After each gradient step the vector is projected back onto the simplex
   (the Euclidean projection is implemented in `_project_simplex`).  
   A diminishing step size (`step = step0 / sqrt(iter)`) and a small amount of
   momentum give a stable descent. The best iterate seen so far is stored.

3. **Light simulated‑annealing polish** – a few‑ten‑thousand cheap “mass‑transfer”
   moves are tried.  A move consists of moving a random fraction (≤ 20 %) of the
   mass from a source index (chosen proportionally to its current weight) to a
   random destination.  Moves are accepted if they improve the score (or with a
   tiny Metropolis probability to escape shallow plateaus).

All three phases respect the global wall‑time limit (`budget_s`).  
The final vector is normalised to unit sum and converted to a plain Python list,
which the verifier will accept.

```python
"""
Optimiser for the step‑function score 2·n·max(conv(a,a))/‖a‖₁².

Approach
--------
1.  Exhaustive cheap sweep over analytically inspired families
    (arcsine‑type, Beta‑type and mixtures with a uniform component)
    on a fairly fine discretisation (n = 16384).

2.  Projected gradient descent on the exact non‑smooth objective.
    The true gradient of  F(a)=2·n·M/(Σa)²  (M = max convolution) is used,
    together with a diminishing step size and Euclidean projection onto the
    probability simplex.

3.  Light simulated‑annealing polishing with random mass‑transfer moves.

All phases run inside the allocated time budget (default 1000 s) and
return the best sequence found.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based self‑convolution utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """Linear self‑convolution a*a using an FFT of length L (default next power of two)."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# Objective and gradient helpers
# ----------------------------------------------------------------------


def _objective(seq: np.ndarray) -> float:
    """Exact objective used by the verifier (no clipping, assumes seq ≥ 0)."""
    n = seq.shape[0]
    conv = _conv_self(seq)
    max_conv = conv.max()
    sum_seq = seq.sum()
    if sum_seq < 1e-12:
        return np.inf
    return float(2.0 * n * max_conv / (sum_seq ** 2))


def _grad_maxconv(a: np.ndarray):
    """
    Compute convolution, index k of the maximal entry, the maximal value M,
    and the gradient of M w.r.t. a (sub‑gradient of the max‑operator).
    Returns (conv, k, M, gM) where gM[i] = 2·a[k‑i] for the overlapping indices,
    otherwise 0.
    """
    conv = _conv_self(a)
    k = int(conv.argmax())
    M = conv[k]
    n = a.shape[0]

    lo = max(0, k - (n - 1))
    hi = min(n - 1, k)
    idx = np.arange(lo, hi + 1, dtype=int)

    # a[k‑idx] is the partner that forms the product a[i]·a[k‑i]
    gM = np.zeros_like(a)
    gM[idx] = 2.0 * a[k - idx]

    return conv, k, M, gM


# ----------------------------------------------------------------------
# Projection onto the probability simplex
# ----------------------------------------------------------------------


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto {w ≥ 0, Σ w = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = int(np.nonzero(cond)[0][-1])
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Projected gradient descent on the exact objective
# ----------------------------------------------------------------------


def _gradient_descent(a0: np.ndarray, deadline: float, start_time: float):
    """Projected gradient descent with diminishing step size."""
    a = a0.copy()
    n = a.shape[0]
    C = 2.0 * n

    best_a = a.copy()
    best_score = _objective(a)

    step0 = 0.5          # initial step size (will be divided by sqrt(iter))
    momentum = np.zeros_like(a)
    beta = 0.8           # momentum coefficient
    it = 0

    while time.time() < deadline:
        it += 1

        # gradient of the exact objective
        conv, k, M, gM = _grad_maxconv(a)
        s = a.sum()
        # full gradient of F
        grad = (C / (s * s)) * (gM - (2.0 * M / s) * np.ones_like(a))

        # momentum and step size
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)

        a_new = a - step * momentum
        a_new = _project_simplex(a_new)

        cur_score = _objective(a_new)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()
            print(
                f"[{time.time() - start_time:.2f}s] GD iter={it:,} score={cur_score:.6f}"
            )

        a = a_new

    return best_a, best_score


# ----------------------------------------------------------------------
# Light simulated‑annealing polish
# ----------------------------------------------------------------------


def _anneal(a0: np.ndarray, deadline: float, start_time: float):
    """Simple mass‑transfer annealing; returns the best vector seen."""
    a = a0.copy()
    cur_score = _objective(a)
    best = a.copy()
    best_score = cur_score
    rng = np.random.default_rng()
    n = a.shape[0]

    # linear cooling from T0 down to ~1e‑6
    total_steps = 30000
    it = 0

    while time.time() < deadline and it < total_steps:
        it += 1
        # temperature schedule (very low but allows occasional uphill moves)
        T = 0.01 * (1e-6 / 0.01) ** (it / total_steps)

        # source index – weighted by current mass (more mass ⇒ more impact)
        src = rng.choice(n, p=a)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-14:
            continue

        # move up to 20 % of the source mass
        eps_move = a[src] * rng.random() * 0.20
        a_prop = a.copy()
        a_prop[src] -= eps_move
        a_prop[dst] += eps_move

        new_score = _objective(a_prop)
        delta = new_score - cur_score

        # Metropolis acceptance
        if delta < 0.0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best = a.copy()
                print(
                    f"[{time.time() - start_time:.2f}s] anneal step={it:,} best={new_score:.6f}"
                )

    return best, best_score

    # ---- arcsine‑type ( (x·(1−x)+ε)^{−α} ) -----------------------
    alphas = np.linspace(0.45, 0.55, 21)        # 0.45 … 0.55 by 0.005
    epsilons = [0.0, 1e-9, 1e-7, 1e-5]

    for eps in epsilons:
        base = x * (1.0 - x) + eps
        for alpha in alphas:
            w = base ** (-alpha)
            a = w / w.sum()
            score = _objective(a)
            if score < best_score:
                best_score = score
                best_seq = a.copy()
                print(
                    f"[{time.time() - start_time:.2f}s] arcsine α={alpha:.3f} eps={eps:g} score={score:.6f}"
                )
            if best_score < 1.503:
                break
        if best_score < 1.503:
            break

    # ---- Beta‑type ( x^{a‑1}(1−x)^{b‑1} ) -----------------------
    if best_score >= 1.503:
        a_vals = np.linspace(0.30, 0.70, 9)   # a = b (symmetric)
        for a_par in a_vals:
            w = (x ** (a_par - 1.0)) * ((1.0 - x) ** (a_par - 1.0))
            a_vec = w / w.sum()
            score = _objective(a_vec)
            if score < best_score:
                best_score = score
                best_seq = a_vec.copy()
                print(
                    f"[{time.time() - start_time:.2f}s] beta a=b={a_par:.3f} score={score:.6f}"
                )
            if best_score < 1.503:
                break

    # ---- mixtures with a uniform component -----------------------
    if best_score >= 1.503:
        mix_lambdas = np.linspace(0.0, 1.0, 11)   # 0 = pure uniform, 1 = pure shape
        # use the currently best “shape” as a base for mixing
        base_shape = best_seq if best_seq is not None else np.ones_like(x)
        for lam in mix_lambdas:
            mixed = lam * base_shape + (1.0 - lam) * np.ones_like(x)
            a_mix = mixed / mixed.sum()
            score = _objective(a_mix)
            if score < best_score:
                best_score = score
                best_seq = a_mix.copy()
                print(
                    f"[{time.time() - start_time:.2f}s] mix λ={lam:.2f} score={score:.6f}"
                )
            if best_score < 1.503:
                break

    # --------------------------------------------------------------
    # 2) If a global starter is available, compare it
    # --------------------------------------------------------------
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            if starter.sum() > 0.0:
                starter = starter / starter.sum()
                cur_score = _objective(starter)
                print(
                    f"[{time.time() - start_time:.2f}s] global starter score={cur_score:.6f}"
                )
                if cur_score < best_score:
                    best_score = cur_score
                    best_seq = starter.copy()
        # note: the verifier will later clip values >1000, but our vectors stay far below that.
    except Exception:
        pass  # no global starter present

    # --------------------------------------------------------------
    # 3) Gradient‑descent refinement (major part of the remaining budget)
    # --------------------------------------------------------------
    if best_seq is None:
        # fallback – uniform distribution (should never happen)
        best_seq = np.full(n, 1.0 / n)
        best_score = _objective(best_seq)

    remaining = deadline - time.time()
    if remaining > 15.0:          # keep a few seconds for polishing later
        gd_deadline = time.time() + 0.78 * remaining
        refined_seq, refined_score = _gradient_descent(best_seq, gd_deadline, start_time)
        if refined_score < best_score:
            best_score = refined_score
            best_seq = refined_seq.copy()
            print(
                f"[{time.time() - start_time:.2f}s] gradient refined score={refined_score:.6f}"
            )

    # --------------------------------------------------------------
    # 4) Light simulated‑annealing polish
    # --------------------------------------------------------------
    if time.time() < deadline:
        anneal_deadline = deadline
        polished_seq, polished_score = _anneal(best_seq, anneal_deadline, start_time)
        if polished_score < best_score:
            best_score = polished_score
            best_seq = polished_seq.copy()
            print(
                f"[{time.time() - start_time:.2f}s] final anneal improve score={best_score:.6f}"
            )

    # --------------------------------------------------------------
    # 5) Final normalisation and conversion to plain list
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = np.full(n, 1.0 / n)

    # The verifier only cares about non‑negative numbers; scaling does not affect the score.
    return [float(v) for v in best_seq]
```
