assistantfinal**Solution Overview**

The target function is  

\[
F(a)=\frac{2n\;\max \bigl((a*a)\bigr)}{\bigl(\sum_i a_i\bigr)^2}
\]

and because the denominator cancels after scaling, we can restrict ourselves to
probability vectors (`∑a_i = 1 , a_i ≥ 0`).  
For a probability vector the objective becomes

\[
J(a)=2n\;\max_k\,(a*a)_k .
\]

The problem is non‑convex; the earlier implementation used a pure sub‑gradient
method and a short simulated‑annealing polish.  
To push the score a little further we combine three ideas:

1. **A small, diverse initial pool** – the same analytic families as before
   (uniform, power‑ramps, Beta, Gaussian, Dirichlet draws) but we stop early
   if the time budget is almost exhausted.

2. **Two complementary local searches**  
   * **Standard sub‑gradient descent** (mirrored‑gradient on the exact
     `max`‑convolution) – fast and good for large steps.  
   * **Smooth exponential descent** – we replace `max` by a soft‑max
     (log‑sum‑exp) with an annealing parameter `α`.  
     The gradient of the smoothed objective can be written as a convolution,
     which we evaluate with a single FFT per iteration.  The update is an
     exponentiated‑gradient step (`a_i ← a_i·exp(‑η g_i)`) followed by a
     projection onto the probability simplex.  
     By slowly increasing `α` the method first sees a smooth landscape and
     finally focuses on the true maximum, allowing it to escape the plateaus
     that trap the pure sub‑gradient method.

3. **A longer simulated‑annealing polish** – after the two descent phases we
   perform many cheap “mass‑move’’ proposals.  The temperature schedule is
   stretched to use almost the whole remaining budget.

All phases respect the global 1000 s limit, use only NumPy, and keep the
sequence on the simplex.  The final vector is returned as a plain Python list
of non‑negative numbers.

```python
"""
Hybrid optimisation for the max‑convolution objective.

1. Build a tiny pool of analytically‑generated probability vectors
   (uniform, power‑ramps, symmetric beta, Gaussian, Dirichlet draws) and
   keep the K best candidates.

2. Run two complementary local searches on the current best:
   • classic sub‑gradient descent on the exact max‑convolution,
   • smooth exponential descent where the max is replaced by a
     temperature‑controlled soft‑max.  The soft‑max gradient is a
     convolution, evaluated by a single FFT.

3. Finish with a prolonged simulated‑annealing polish that swaps small
   masses between randomly chosen bins.

All updates are projected onto the probability simplex; the whole
procedure fits into the 1000 s budget and returns a list suitable for
evaluate_sequence().
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: smallest power of two ≥ x (FFT sizing)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Return the smallest power of two not less than x."""
    return 1 << ((x - 1).bit_length())

# ----------------------------------------------------------------------
# Fast linear convolution via FFT (full length n+m‑1)
# ----------------------------------------------------------------------
def _conv_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Convolution of real vectors a and b using a real FFT."""
    L = _next_pow2(a.size + b.size - 1)
    Af = np.fft.rfft(a, n=L)
    Bf = np.fft.rfft(b, n=L)
    conv = np.fft.irfft(Af * Bf, n=L)[: a.size + b.size - 1]
    return conv

# ----------------------------------------------------------------------
# Self‑convolution (a*a) – length 2·n‑1
# ----------------------------------------------------------------------
def _conv_self(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv

# ----------------------------------------------------------------------
# Objective for a probability vector (sum == 1)
#   J(a) = 2·n·max(conv(a,a))
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    n = a.shape[0]
    conv = _conv_self(a)
    return float(2.0 * n * conv.max())

# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex {a ≥ 0, Σa = 1}
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Projection of v onto the simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w

# ----------------------------------------------------------------------
# Analytic families for the initial pool
# ----------------------------------------------------------------------
def _make_shape(n: int, p: float, plateau_frac: float) -> np.ndarray:
    """Power‑ramp with optional plateau, symmetrised and normalised."""
    plateau_len = int(round(plateau_frac * n))
    if plateau_len % 2 == 1 and plateau_len > 0:
        plateau_len -= 1
    side_len = (n - plateau_len) // 2
    if side_len <= 0:
        shape = np.ones(n)
    else:
        idx = np.arange(1, side_len + 1, dtype=float) / side_len
        ramp = idx ** p
        shape = np.concatenate([ramp, np.ones(plateau_len), ramp[::-1]])
        if shape.size < n:
            shape = np.concatenate([shape, np.zeros(n - shape.size)])
        else:
            shape = shape[:n]
    s = shape.sum()
    if s > 0:
        shape /= s
    else:
        shape = np.full(n, 1.0 / n)
    return shape


def _make_beta_shape(n: int, alpha: float) -> np.ndarray:
    """Symmetric Beta(α,α) density on {0,…,n‑1}."""
    x = (np.arange(n, dtype=float) + 0.5) / n
    eps = 1e-12
    x = np.clip(x, eps, 1.0 - eps)
    log_shape = (alpha - 1.0) * (np.log(x) + np.log(1.0 - x))
    shape = np.exp(log_shape)
    s = shape.sum()
    if s > 0:
        shape /= s
    else:
        shape = np.full(n, 1.0 / n)
    return shape


def _make_gaussian_shape(n: int, sigma: float) -> np.ndarray:
    """Discrete Gaussian centred in the middle."""
    x = np.arange(n, dtype=float)
    centre = (n - 1) / 2.0
    shape = np.exp(-0.5 * ((x - centre) / sigma) ** 2)
    s = shape.sum()
    if s > 0:
        shape /= s
    else:
        shape = np.full(n, 1.0 / n)
    return shape


# ----------------------------------------------------------------------
# Keep the K best candidates (sorted by score)
# ----------------------------------------------------------------------
def _push_top(pool: list, score: float, vec: np.ndarray, k: int) -> None:
    """Insert (score,vec) into the pool of size ≤k."""
    if len(pool) < k:
        pool.append((score, vec.copy()))
        pool.sort(key=lambda x: x[0])
    elif score < pool[-1][0]:
        pool[-1] = (score, vec.copy())
        pool.sort(key=lambda x: x[0])

# ----------------------------------------------------------------------
# Classic sub‑gradient descent (mirrored‑gradient on the exact max)
# ----------------------------------------------------------------------
def _subgrad_descent(a0: np.ndarray,
                     deadline: float,
                     start_time: float,
                     rng: np.random.Generator,
                     step0: float = 200.0,
                     max_move_frac: float = 0.02) -> tuple[np.ndarray, float]:
    """Exponentiated‑gradient descent on the true max‑convolution."""
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(a)

    it = 0
    while time.time() < deadline:
        it += 1

        conv = _conv_self(a)
        cur_max = conv.max()
        cur_score = float(2.0 * n * cur_max)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] SG iter={it:,} best={cur_score:.6f}")

        # indices attaining (or almost attaining) the maximum
        ks = np.where(conv >= cur_max - 1e-14)[0]

        # sub‑gradient of max‑convolution
        g = np.zeros_like(a)
        for k in ks:
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            idx = np.arange(i_start, i_end + 1, dtype=int)
            g[idx] += 2.0 * a[k - idx]

        # exponentiated‑gradient update
        step = step0 / math.sqrt(it)
        expo = np.exp(-step * g)
        a = a * expo
        s = a.sum()
        if s == 0 or np.isnan(s) or np.isinf(s):
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / s

        # occasional random mass move to increase exploration
        if it % 5000 == 0:
            src = rng.choice(n, p=a)
            dst = rng.integers(n)
            if src != dst:
                delta = a[src] * max_move_frac * rng.random()
                a[src] -= delta
                a[dst] += delta
                a = np.maximum(a, 0.0)
                a /= a.sum()

    return best_a, best_score

# ----------------------------------------------------------------------
# Smooth exponential descent (soft‑max of the convolution)
# ----------------------------------------------------------------------
def _smooth_exponential_descent(a0: np.ndarray,
                                deadline: float,
                                start_time: float,
                                rng: np.random.Generator,
                                step0: float = 200.0,
                                alpha0: float = 0.5,
                                alpha_max: float = 200.0,
                                alpha_mul: float = 1.001,
                                max_move_frac: float = 0.02) -> tuple[np.ndarray, float]:
    """Mirror‑descent on a smoothed max (log‑sum‑exp) of the auto‑correlation."""
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(a)

    # pre‑allocate FFT length for the convolution w * a_rev (w length = 2n‑1)
    L = _next_pow2( (2 * n - 1) + n - 1 )
    it = 0
    alpha = alpha0

    while time.time() < deadline:
        it += 1

        # exact self‑convolution
        conv = _conv_self(a)
        max_conv = conv.max()

        # soft‑max weights (stable by subtracting max)
        w_unnorm = np.exp(alpha * (conv - max_conv))
        w = w_unnorm / w_unnorm.sum()

        # gradient = 4·n * (w * a_rev)_{n‑1 … n‑1+n‑1}
        a_rev = a[::-1]
        Af = np.fft.rfft(w, n=L)
        Bf = np.fft.rfft(a_rev, n=L)
        g_full = np.fft.irfft(Af * Bf, n=L)[: (2 * n - 1) + n - 1]
        g = 4.0 * n * g_full[n - 1 : n - 1 + n]    # length n

        # exponentiated‑gradient step
        step = step0 / math.sqrt(it)
        a = a * np.exp(-step * g)
        s = a.sum()
        if s == 0 or np.isnan(s) or np.isinf(s):
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / s

        # evaluation
        cur_score = _objective(a)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] SmoothIter={it:,} best={cur_score:.6f}")

        # anneal the soft‑max temperature
        if alpha < alpha_max:
            alpha = min(alpha_max, alpha * alpha_mul)

        # occasional random mass move (helps to leave plateaus)
        if it % 4000 == 0:
            src = rng.choice(n, p=a)
            dst = rng.integers(n)
            if src != dst:
                delta = a[src] * max_move_frac * rng.random()
                a[src] -= delta
                a[dst] += delta
                a = np.maximum(a, 0.0)
                a /= a.sum()

    return best_a, best_score


# ----------------------------------------------------------------------
# Light‑weight simulated‑annealing polish (mass swaps)
# ----------------------------------------------------------------------
def _simulated_annealing(a0: np.ndarray,
                         deadline: float,
                         start_time: float,
                         rng: np.random.Generator,
                         max_move_frac: float = 0.03) -> tuple[np.ndarray, float]:
    a = a0.copy()
    cur_score = _objective(a)
    best_a = a.copy()
    best_score = cur_score

    n = a.shape[0]
    T_start = 0.2
    T_end = 1e-8
    it = 0

    while time.time() < deadline:
        it += 1
        elapsed = time.time() - start_time
        total = deadline - start_time
        frac = min(1.0, elapsed / total)
        T = T_start * ((T_end / T_start) ** frac)

        src = rng.choice(n, p=a)
        if a[src] < 1e-16:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue
        delta = a[src] * max_move_frac * rng.random()
        if delta <= 0.0:
            continue

        a_prop = a.copy()
        a_prop[src] -= delta
        a_prop[dst] += delta

        new_score = _objective(a_prop)
        if new_score < cur_score or rng.random() < math.exp(-(new_score - cur_score) / T):
            a = a_prop
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] SA iter={it:,} new best={new_score:.6f}")

    return best_a, best_score

def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a low‑score step‑function under the given time budget.
    Returns a plain Python list of non‑negative floats (no further normalisation
    is needed – the list itself is used by evaluate_sequence).
    """
    rng = np.random.default_rng(seed + 9999)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # safety margin

    # --------------------------------------------------------------
    # Choose a discretisation size (larger N gives more freedom)
    # --------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 600:
        N = 65536
    elif remaining > 300:
        N = 32768
    else:
        N = 16384

    # --------------------------------------------------------------
    # 1) Build a small but diverse pool of candidates
    # --------------------------------------------------------------
    TOP_K = 6
    pool = []   # (score, vector)

    # Uniform baseline
    uniform = np.full(N, 1.0 / N)
    _push_top(pool, _objective(uniform), uniform, TOP_K)

    # Power‑ramps
    p_grid = np.linspace(0.2, 2.0, 9)
    plate_grid = np.linspace(0.0, 0.5, 7)
    for p in p_grid:
        for plat in plate_grid:
            if time.time() >= deadline:
                break
            a = _make_shape(N, p, plat)
            _push_top(pool, _objective(a), a, TOP_K)

    # Symmetric Beta shapes
    for alpha in np.arange(0.05, 0.96, 0.05):
        if time.time() >= deadline:
            break
        a = _make_beta_shape(N, alpha)
        _push_top(pool, _objective(a), a, TOP_K)

    # Gaussian bumps
    for sigma in [N * 0.03, N * 0.07, N * 0.15]:
        if time.time() >= deadline:
            break
        a = _make_gaussian_shape(N, sigma)
        _push_top(pool, _objective(a), a, TOP_K)

    # A handful of Dirichlet draws (limited to keep time)
    concs = [0.01, 0.05, 0.12, 0.25, 0.5]
    for conc in concs:
        for _ in range(4):   # fewer draws than the previous script
            if time.time() >= deadline:
                break
            a = rng.gamma(conc, 1.0, size=N)
            s = a.sum()
            if s == 0:
                continue
            a /= s
            _push_top(pool, _objective(a), a, TOP_K)

    # Incorporate the previous best if it exists (global variable)
    try:
        starter = globals().get('height_sequence_1')
        if starter is not None:
            starter = np.asarray(starter, dtype=float)
            if starter.ndim == 1 and starter.size > 0:
                if starter.size != N:
                    # linear interpolation to required size
                    x_old = np.linspace(0, 1, starter.size, endpoint=False)
                    x_new = np.linspace(0, 1, N, endpoint=False)
                    starter_up = np.interp(x_new, x_old, starter)
                else:
                    starter_up = starter.copy()
                starter_up = np.maximum(starter_up, 0.0)
                if starter_up.sum() > 0:
                    starter_up /= starter_up.sum()
                    _push_top(pool, _objective(starter_up), starter_up, TOP_K)
    except Exception:
        pass

    # --------------------------------------------------------------
    # Pick the current best candidate
    # --------------------------------------------------------------
    pool.sort(key=lambda x: x[0])
    best_score, best_seq = pool[0][0], pool[0][1].copy()
    print(f"[{time.time() - start_time:.2f}s] Initial best score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 2) First phase: classic sub‑gradient descent (≈40 % of remaining time)
    # --------------------------------------------------------------
    remaining = deadline - time.time()

        sub_deadline = time.time() + remaining * 0.40
        refined_seq, refined_score = _subgrad_descent(best_seq,
                                                      sub_deadline,
                                                      start_time,
                                                      rng,
                                                      step0=250.0,
                                                      max_move_frac=0.02)
        if refined_score < best_score:
            best_score, best_seq = refined_score, refined_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] After sub‑grad best = {best_score:.6f}")

    # --------------------------------------------------------------

    # --------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 5.0:
        smooth_deadline = time.time() + remaining * 0.40
        smooth_seq, smooth_score = _smooth_exponential_descent(best_seq,
                                                               smooth_deadline,
                                                               start_time,
                                                               rng,
                                                               step0=200.0,
                                                               alpha0=0.5,
                                                               alpha_max=250.0,
                                                               alpha_mul=1.001,
                                                               max_move_frac=0.02)
        if smooth_score < best_score:
            best_score, best_seq = smooth_score, smooth_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] After smooth descent best = {best_score:.6f}")

    # --------------------------------------------------------------
    # 4) Final polish with simulated‑annealing (use whatever time is left)
    # --------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 3.0:

                                                    deadline,
                                                    start_time,
                                                    rng,
                                                    max_move_frac=0.03)

    # --------------------------------------------------------------
    # 5) Final normalisation (tiny numerical errors may accumulate)
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq /= total
    else:
        best_seq = np.full(N, 1.0 / N)

    final_score = _objective(best_seq)
    print(f"[{time.time() - start_time:.2f}s] Finished, final score ≈ {final_score:.6f}")

    # Return as a plain Python list – evaluate_sequence will clamp values
    # to the allowed range (0 … 1000) but the optimisation already respects it.
    return [float(v) for v in best_seq]
```
