assistantfinal**Solution Explanation**

The evaluation function is  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the denominator is scale‑invariant we may restrict ourselves to
probability vectors (`∑a = 1`).  
Hence we have to **minimise** the maximum entry of the self‑convolution.

The program below follows three ideas that improve the previous
implementation.

* **Larger problem size** – we use `n = 8192` (instead of 4096).  
  With a finer discretisation the optimal constant of the
  asymptotic bound (`≈ 0.75`) can be reached more closely.

* **Soft‑max proxy** – the exact objective contains a non‑smooth
  `max`.  We replace it by a smooth surrogate  

  \[
  \Phi_\alpha(a)=\log\!\Bigl(\sum_k e^{\alpha\,(a*a)_k}\Bigr),
  \]

  whose gradient can be written as a convolution.
  By slowly increasing the temperature parameter `α` the surrogate
  becomes tighter and we obtain a reliable descent direction.

* **Adam optimiser on the simplex** – the gradient of the surrogate is
  applied with the Adam adaptive step‑size, after which the iterate is
  projected back onto the probability simplex (`∑a = 1`, `a_i≥0`).
  Adam’s per‑coordinate learning rates accelerate convergence,
  especially when many entries become very small.

The whole search consists of four phases:

1. **Random parametric sweep** – a 4‑parameter family  
   \(a_i \propto r^i\,(i+1)^p\,(n-i)^q\) mixed with a uniform background is
   sampled for a short time; the best result seeds the next phase.

2. **Local hill‑climb of the four parameters** – stochastic perturbations
   with exponentially decaying amplitudes improve the parametric shape.

3. **Soft‑max Adam descent** – the smooth surrogate is minimised.
   The temperature `α` grows from `5` to `200`, the Adam step size starts
   at `0.02`.  The best exact score is stored throughout.

4. **Tiny random mass‑transfer hill‑climb** – a final cheap neighbourhood
   search moves a tiny fraction of probability mass between two coordinates
   and accepts any improvement.

All phases respect the 1000 s budget; the best vector found is returned.
The code prints intermediate scores so that progress can be monitored.

```python
"""
Search for a non‑negative step function (probability vector) that minimises

    2 * n * max(conv(a, a)) / (sum(a)**2)

The algorithm combines

* a random sweep over a 4‑parameter geometric‑power‑tail family,
* a stochastic hill‑climb of the four parameters,
* a smooth soft‑max surrogate of the max‑operator minimised with Adam,
* a final tiny random “mass‑transfer” hill‑climb.

The problem size is n = 8192 (larger than the previous 4096) which
allows the asymptotic constant ≈ 0.75 to be approached more closely.
All iterates are projected onto the probability simplex after each
update.  The routine respects a 1000 s time budget and returns the best
sequence found as a plain list of floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """
    Linear self‑convolution a*a using FFT.
    Returns the first (2·len(a)‑1) entries.
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    {w ≥ 0, sum w = 1}.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Fast exact evaluation (assumes sum≈1)
# ----------------------------------------------------------------------


def _eval_fast(a: np.ndarray, L_fft: int) -> float:
    """Return 2·n·max(conv(a,a)) / (sum(a)**2) using an FFT."""
    conv = _conv_self_fft(a, L_fft)
    max_b = conv.max()
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    n = a.shape[0]
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Shape generation (geometric‑power‑tail family)
# ----------------------------------------------------------------------


def _make_shape_general(n: int, r: float, p: float, q: float) -> np.ndarray:
    """
    Produce a normalised vector of length n with components
    proportional to r**i * (i+1)**p * (n-i)**q   (i = 0…n‑1).
    Computed in log‑space for numerical stability.
    """
    i = np.arange(n, dtype=np.float64)
    log_shape = i * np.log(r) + p * np.log(i + 1.0) + q * np.log(n - i)
    log_shape -= np.max(log_shape)                     # shift for stability
    shape = np.exp(log_shape)
    total = shape.sum()
    if total == 0.0 or not np.isfinite(total):
        shape = np.full(n, 1.0 / n, dtype=np.float64)
    else:
        shape /= total
    return shape


def _mix_with_uniform(shape: np.ndarray, lam: float) -> np.ndarray:
    """
    Return lam·uniform + (1‑lam)·shape  (both already sum to 1).
    The result is renormalised to guard against numerical drift.
    """
    n = shape.shape[0]
    uniform = np.full(n, 1.0 / n, dtype=np.float64)
    mixed = lam * uniform + (1.0 - lam) * shape
    mixed /= mixed.sum()
    return mixed


# ----------------------------------------------------------------------
# Random parametric sweep (geometric‑power‑tail family)
# ----------------------------------------------------------------------


def _random_param_search(n: int,
                         deadline: float,
                         start_time: float) -> tuple[np.ndarray,
                                                     float,
                                                     tuple[float, float, float, float]]:
    """
    Uniform‑in‑log random sampling of (r,p,q,λ) and keep the best vector.
    """
    rng = np.random.default_rng()
    L_fft = _next_pow2(2 * n - 1)

    best_seq = None
    best_score = float("inf")
    best_params = None

    while time.time() < deadline:
        # r in (0.85, 0.999999) – log‑uniform
        r = np.exp(rng.uniform(np.log(0.85), np.log(0.999999)))
        p = rng.uniform(-5.0, 5.0)
        q = rng.uniform(-5.0, 5.0)
        lam = rng.uniform(0.0, 1.0)

        shape = _make_shape_general(n, r, p, q)
        cand = _mix_with_uniform(shape, lam)
        sc = _eval_fast(cand, L_fft)

        if sc < best_score:
            best_score = sc
            best_seq = cand.copy()
            best_params = (r, p, q, lam)
            print(f"[{time.time() - start_time:.2f}s] random sweep r={r:.4f} "
                  f"p={p:.2f} q={q:.2f} λ={lam:.2f} score={sc:.6f}")

    return best_seq, best_score, best_params


# ----------------------------------------------------------------------
# Local hill‑climb on the four shape parameters
# ----------------------------------------------------------------------


def _hillclimb_params(initial_params: tuple[float, float, float, float],
                      start_seq: np.ndarray,
                      start_score: float,
                      deadline: float,
                      start_time: float) -> tuple[np.ndarray, float]:
    """
    Stochastic hill‑climb on (r,p,q,λ) with exponentially shrinking
    perturbations.
    """
    cur_r, cur_p, cur_q, cur_lam = initial_params
    cur_seq = start_seq.copy()
    cur_score = start_score

    sigma_r = 0.015
    sigma_p = 0.30
    sigma_q = 0.30
    sigma_lam = 0.12

    rng = np.random.default_rng()
    n = cur_seq.shape[0]
    L_fft = _next_pow2(2 * n - 1)

    best_seq = cur_seq.copy()
    best_score = cur_score

    while time.time() < deadline:
        # propose a new point in parameter space
        r_new = cur_r * np.exp(sigma_r * rng.standard_normal())
        p_new = cur_p + sigma_p * rng.standard_normal()
        q_new = cur_q + sigma_q * rng.standard_normal()
        lam_new = cur_lam + sigma_lam * rng.standard_normal()

        # clamp to admissible ranges
        r_new = float(np.clip(r_new, 0.85, 0.999999))
        lam_new = float(np.clip(lam_new, 0.0, 1.0))

        shape_new = _make_shape_general(n, r_new, p_new, q_new)
        cand_new = _mix_with_uniform(shape_new, lam_new)
        sc_new = _eval_fast(cand_new, L_fft)

        if sc_new < cur_score:
            cur_r, cur_p, cur_q, cur_lam = r_new, p_new, q_new, lam_new
            cur_seq = cand_new
            cur_score = sc_new
            if sc_new < best_score:
                best_score = sc_new
                best_seq = cand_new.copy()
                print(f"[{time.time() - start_time:.2f}s] param hill r={r_new:.6f} "
                      f"p={p_new:.4f} q={q_new:.4f} λ={lam_new:.4f} score={sc_new:.6f}")

        # decay the perturbation scales
        sigma_r *= 0.9995
        sigma_p *= 0.9995
        sigma_q *= 0.9995
        sigma_lam *= 0.9995

        # occasional jitter
        if rng.random() < 0.005:
            cur_seq = np.maximum(cur_seq + 1e-4 * rng.standard_normal(n) * cur_seq,
                                 0.0)
            cur_seq = _project_simplex(cur_seq)
            cur_score = _eval_fast(cur_seq, L_fft)

    return best_seq, best_score


# ----------------------------------------------------------------------
# Soft‑max Adam descent (smooth proxy of the max‑operator)
# ----------------------------------------------------------------------


def _softmax_adam_descent(a0: np.ndarray,
                          deadline: float,
                          start_time: float,
                          best_score_initial: float,
                          alpha_start: float = 5.0,
                          alpha_end: float = 200.0,
                          step0: float = 0.02) -> tuple[np.ndarray, float]:
    """
    Adam optimiser applied to the soft‑max surrogate of max(conv).
    The temperature α grows linearly from `alpha_start` to `alpha_end`
    during the run.  After each update the iterate is projected onto the
    probability simplex.
    """
    n = a0.shape[0]
    L_self = _next_pow2(2 * n - 1)
    L_w = _next_pow2(3 * n - 2)

    a = a0.copy()
    best_a = a.copy()
    best_score = best_score_initial

    rng = np.random.default_rng()

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    t = 0

    while time.time() < deadline:
        t += 1
        # current temperature
        frac = (time.time() - start_time) / (deadline - start_time)
        alpha = alpha_start + frac * (alpha_end - alpha_start)

        # convolution a*a
        conv = _conv_self_fft(a, L_self)                     # length 2n‑1
        max_conv = conv.max()

        # soft‑max weights
        w = np.exp(alpha * (conv - max_conv))
        w_sum = w.sum()
        if w_sum == 0.0:
            # numerical underflow – fall back to hard max
            w = np.zeros_like(conv)
            w[np.argmax(conv)] = 1.0
            w_sum = 1.0
        w /= w_sum

        # gradient = 2 * (w * a_rev) sliced to length n
        a_rev = a[::-1]
        W_fft = np.fft.rfft(w, n=L_w)
        A_rev_fft = np.fft.rfft(a_rev, n=L_w)
        conv_wa_rev = np.fft.irfft(W_fft * A_rev_fft, n=L_w)[: 3 * n - 2]
        g = 2.0 * conv_wa_rev[n - 1:2 * n - 1]                # shape (n,)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        step = step0 * m_hat / (np.sqrt(v_hat) + eps)

        a_candidate = a - step
        a_candidate = _project_simplex(a_candidate)

        # exact score of the candidate
        cur_score = _eval_fast(a_candidate, L_self)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a_candidate.copy()
            a = a_candidate
            # reset Adam moments after improvement – helps escaping plateaus
            m = np.zeros_like(a)
            v = np.zeros_like(a)
            print(f"[{time.time() - start_time:.2f}s] adam it={t:,} "
                  f"α={alpha:.1f} score={cur_score:.6f}")
        else:
            # occasional uphill move (simulated‑annealing flavour)
            prob = np.exp(-(cur_score - best_score) * 10.0 / (np.sqrt(t) + 1.0))
            if rng.random() < prob:
                a = a_candidate

        # jitter every few thousand iterations to avoid stagnation
        if t % 3000 == 0:
            eps_j = 1e-4 * rng.random(n) * a
            a = np.maximum(a + eps_j, 0.0)
            a = _project_simplex(a)

    return best_a, best_score


# ----------------------------------------------------------------------
# Final tiny hill‑climb (random mass transfers)
# ----------------------------------------------------------------------


def _final_local_search(a: np.ndarray,
                        deadline: float,
                        start_time: float,
                        best_score_initial: float) -> tuple[np.ndarray, float]:
    """
    Randomly move a tiny fraction of probability mass between two
    coordinates, keeping the vector on the simplex.
    """
    n = a.shape[0]
    L_fft = _next_pow2(2 * n - 1)
    best_a = a.copy()
    best_sc = best_score_initial
    rng = np.random.default_rng()

    while time.time() < deadline:
        src = rng.integers(n)
        if a[src] < 1e-15:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue
        # move up to 0.5 % of the source mass
        eps = a[src] * rng.random() * 5e-3
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps
        new_sc = _eval_fast(a_prop, L_fft)
        if new_sc < best_sc:
            best_sc = new_sc
            best_a = a_prop.copy()
            a = a_prop
            print(f"[{time.time() - start_time:.2f}s] final local score={new_sc:.6f}")
        else:
            if rng.random() < 0.001:
                a = a_prop

    return best_a, best_sc


# ----------------------------------------------------------------------
# Helper: prepare a starter vector (global `height_sequence_1` if present)
# ----------------------------------------------------------------------


def _prepare_initial(seq, n: int) -> np.ndarray | None:
    """Resize (by linear interpolation) and normalise a given sequence."""
    try:
        arr = np.asarray(seq, dtype=float)
    except Exception:
        return None
    if arr.ndim != 1 or arr.size == 0:
        return None
    arr = np.maximum(arr, 0.0)
    if arr.size != n:
        # linear interpolation to the target length
        x_old = np.linspace(0.0, 1.0, arr.size)
        x_new = np.linspace(0.0, 1.0, n)
        arr = np.interp(x_new, x_old, arr)
    total = arr.sum()
    if total < 1e-12:
        return None
    return arr / total


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises the target
    evaluation function.  The routine respects the 1000 s time budget and
    returns the best sequence as a list of floats.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.2   # safety margin

    # ------------------------------------------------------------------
    # Problem size – 8192 gives a finer discretisation (still fast enough)
    # ------------------------------------------------------------------
    n = 8192
    L_fft = _next_pow2(2 * n - 1)

    # ------------------------------------------------------------------
    # 0️⃣  Uniform baseline (score = 2.0)
    # ------------------------------------------------------------------
    uniform = np.full(n, 1.0 / n, dtype=np.float64)
    best_seq = uniform.copy()
    best_score = _eval_fast(best_seq, L_fft)
    print(f"[{time.time() - start_time:.2f}s] uniform baseline score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Optional global starter (`height_sequence_1` if defined)
    # ------------------------------------------------------------------
    try:
        starter = _prepare_initial(height_sequence_1, n)   # type: ignore[name-defined]
        if starter is not None:
            cur = _eval_fast(starter, L_fft)
            if cur < best_score:
                best_seq = starter.copy()
                best_score = cur
                print(f"[{time.time() - start_time:.2f}s] global starter score={cur:.6f}")
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1️⃣  Random parametric sweep (geometric × power × tail)
    # ------------------------------------------------------------------
    sweep_deadline = time.time() + min(180.0, (deadline - time.time()) * 0.20)
    rp_seq, rp_score, rp_params = _random_param_search(n, sweep_deadline, start_time)
    if rp_seq is not None and rp_score < best_score:
        best_seq = rp_seq.copy()
        best_score = rp_score
        best_params = rp_params
        print(f"[{time.time() - start_time:.2f}s] after random sweep best score={best_score:.6f}")
    else:
        # sensible fallback – works even if the random sweep found nothing
        best_params = (0.96, 0.0, 0.0, 0.3)

    # ------------------------------------------------------------------
    # 2️⃣  Fine hill‑climb on the four parameters
    # ------------------------------------------------------------------
    remaining = deadline - time.time()
    hill_deadline = time.time() + min(200.0, remaining * 0.25)
    best_seq, best_score = _hillclimb_params(best_params,
                                             best_seq,
                                             best_score,
                                             hill_deadline,
                                             start_time)

    # ------------------------------------------------------------------
    # 3️⃣  Soft‑max Adam descent (smooth proxy of max‑operator)
    # ------------------------------------------------------------------
    remaining = deadline - time.time()
    adam_deadline = time.time() + min(400.0, remaining * 0.45)
    if time.time() < adam_deadline:
        a_adam, sc_adam = _softmax_adam_descent(best_seq,
                                                adam_deadline,
                                                start_time,
                                                best_score,
                                                alpha_start=5.0,
                                                alpha_end=200.0,
                                                step0=0.02)
        if sc_adam < best_score:
            best_seq = a_adam.copy()
            best_score = sc_adam
            print(f"[{time.time() - start_time:.2f}s] soft‑max Adam final score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 4️⃣  Final tiny hill‑climb (random mass transfers)
    # ------------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 2.0:
        a_final, sc_final = _final_local_search(best_seq,
                                                deadline,
                                                start_time,
                                                best_score)
        if sc_final < best_score:
            best_seq = a_final.copy()
            best_score = sc_final
            print(f"[{time.time() - start_time:.2f}s] final local best score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Normalise finally (sum → 1) and return a plain Python list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq = best_seq / total
    else:
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)

    # ------------------------------------------------------------------
    # Log the official evaluation (security‑checked function)
    # ------------------------------------------------------------------
    try:
        final_val = evaluate_sequence(best_seq.tolist())
        print(f"[{time.time() - start_time:.2f}s] evaluate_sequence => {final_val:.6f}")
    except Exception as exc:
        print(f"Unable to call evaluate_sequence: {exc}")

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
```
