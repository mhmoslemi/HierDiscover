The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where `a*a` is the linear convolution of the step‑function with itself.  
The evaluation function normalises the sequence only by clipping – the
objective is invariant under a global scaling, therefore we may (and do)
enforce the *simplex* constraint  

\[
a_i\ge0,\qquad\sum_i a_i=1 .
\]

Under this constraint  

\[
F(a)=2\,n\;\max_k (a*a)_k .
\]

A smooth surrogate for the hard max is the **log‑sum‑exp** (soft‑max)

\[
S_\alpha(a)=\frac{1}{\alpha}\log\!\Bigl(\sum_k e^{\alpha\,(a*a)_k}\Bigr),
\qquad 
\lim_{\alpha\to\infty}S_\alpha(a)=\max_k (a*a)_k .
\]

For a fixed smoothing parameter `α` the function  

\[
\Phi_\alpha(b)=2\,n\,S_\alpha(\operatorname{softmax}(b)),
\qquad 
a=\operatorname{softmax}(b)=\frac{e^{b}}{\sum e^{b}}
\]

is smooth and differentiable.  Its gradient w.r.t. the unconstrained
parameters `b` is

```
grad_b = a * ( 4*n * (w ⋆ a_rev)  –  <4*n * (w ⋆ a_rev), a> ),
```

where  

* `w` = soft‑max weights of the convolution (`w_i ∝ exp(α·conv_i)`),  
* `a_rev` is `a` reversed,  
* `⋆` denotes correlation, efficiently computed by a single FFT.

The optimisation proceeds in three phases

1. **Diverse initial pool** – uniform, exponential, power‑law, beta and
   random Dirichlet shapes are generated, normalised to the simplex and
   scored with the exact evaluator. The best of them seeds the next
   stage.

2. **Continuation with L‑BFGS‑B** – we minimise `Φ_α` for an increasing
   schedule of smoothing parameters  
   `α∈{10,30,100,300,1000,3000}`.  
   Each stage runs a limited‑iteration L‑BFGS‑B optimisation (the
   gradient is supplied analytically).  After every stage the true
   bound is measured with `evaluate_sequence`; the best vector so far is
   kept.

3. **Fine‑grained polishing** – a short run of the multiplicative
   sub‑gradient method (the “exponentiated GD” from the reference code)
   is applied to the current best sequence to exploit the exact active‑set
   sub‑gradient of the hard max.

All work is bounded by the supplied time budget (default 1000 s).  
The routine automatically chooses the problem size `N` – larger `N`
gives a finer resolution but also a larger FFT; the schedule
`N∈{4096,8192,16384,32768}` adapts to the remaining time.

The final sequence is returned as a plain Python list; it is already
non‑negative and normalised (the evaluator will clip it only if
necessary).

```python
"""
propose_candidate – minimise 2·n·max(conv(a,a))/sum(a)².

The algorithm:
1. Build a small, diverse pool of analytic step‑functions (uniform,
   exponential, power‑law, beta, Dirichlet draws) and keep the best.
2. Optimise the smooth‐max surrogate Φ_α(b) with L‑BFGS‑B on the
   unconstrained logits b = log(a) (soft‑max enforces the simplex).
   α is increased (continuation) to approach the true max.
3. Finish with a short exponentiated sub‑gradient descent on the exact
   max‑convolution for extra polishing.

All FFTs are performed with numpy.  The routine respects the 1000 s
budget and returns a list of floats suitable for evaluate_sequence().
"""

import time
import math
import numpy as np
import scipy.optimize as opt

# ----------------------------------------------------------------------
# Basic linear‑algebra / FFT utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """Linear convolution a*a (full length 2·len(a)‑1) using real FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    A = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(A * A, n=L)[: 2 * n - 1]
    # tiny negative values caused by round‑off are irrelevant
    return np.maximum(conv, 0.0)


def _correlation(w: np.ndarray, a_rev: np.ndarray) -> np.ndarray:
    """Correlation w ⋆ a_rev (output length = len(a_rev))."""
    n = a_rev.shape[0]
    L = _next_pow2(3 * n - 2)
    W = np.fft.rfft(w, n=L)
    A = np.fft.rfft(a_rev, n=L)
    full = np.fft.irfft(W * A, n=L)
    return full[n - 1: n - 1 + n]


# ----------------------------------------------------------------------
# Analytic shape generators (all return a normalised probability vector)
# ----------------------------------------------------------------------
def _make_uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n)


def _make_power_ramp(n: int, p: float, plateau_frac: float) -> np.ndarray:
    plateau_len = int(round(plateau_frac * n))
    if plateau_len % 2 == 1 and plateau_len > 0:
        plateau_len -= 1
    side_len = (n - plateau_len) // 2
    if side_len <= 0:
        shape = np.ones(n)
    else:
        idx = np.arange(1, side_len + 1, dtype=float) / side_len
        ramp = idx ** p
        shape = np.concatenate([ramp, np.ones(plateau_len), ramp[::-1]])
        if shape.size < n:
            shape = np.concatenate([shape, np.zeros(n - shape.size)])
        else:
            shape = shape[:n]
    shape /= shape.sum()
    return shape


def _make_exponential(n: int, lam: float) -> np.ndarray:
    idx = np.arange(n, dtype=float)
    shape = np.exp(-lam * idx)
    shape /= shape.sum()
    return shape


def _make_power_law(n: int, p: float) -> np.ndarray:
    idx = np.arange(1, n + 1, dtype=float)
    shape = idx ** (-p)
    shape /= shape.sum()
    return shape


def _make_beta_shape_asym(n: int, alpha: float, beta: float) -> np.ndarray:
    x = (np.arange(n, dtype=float) + 0.5) / n
    eps = 1e-12
    x = np.clip(x, eps, 1.0 - eps)
    log_shape = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    shape = np.exp(log_shape)
    shape /= shape.sum()
    return shape


# ----------------------------------------------------------------------
# Exponentiated sub‑gradient optimiser (hard max)
# ----------------------------------------------------------------------
def _exp_subgradient_descent(a0: np.ndarray,
                             deadline: float,
                             start_time: float) -> tuple[np.ndarray, float]:
    """Multiplicative sub‑gradient descent on the hard max‑convolution."""
    a = a0.copy()
    n = a.shape[0]
    best = a.copy()
    best_score = _objective(a)  # exact objective 2·n·max(conv)/sum²

    it = 0
    eta0 = 0.5
    while time.time() < deadline:
        it += 1
        conv = _conv_self(a)
        max_conv = conv.max()
        # active set (indices attaining the max, tolerant to round‑off)
        tol = max(1e-12, max_conv * 1e-12)
        active = np.where(conv >= max_conv - tol)[0]
        if active.size == 0:
            active = np.array([conv.argmax()], dtype=int)

        w = np.zeros_like(conv)
        w[active] = 1.0 / active.size

        # gradient = 2·(w ⋆ a_rev)
        a_rev = a[::-1]
        L = _next_pow2(3 * n - 2)
        grad = np.fft.irfft(np.fft.rfft(w, n=L) *
                            np.fft.rfft(a_rev, n=L), n=L)
        grad = 2.0 * grad[n - 1: n - 1 + n]

        # diminishing step‑size
        eta = eta0 / (1.0 + it / 5000.0)

        factor = np.exp(np.clip(-eta * grad, -50.0, 50.0))
        a *= factor
        s = a.sum()
        if s > 0.0:
            a /= s
        else:
            a = np.full_like(a, 1.0 / n)

        cur_score = _objective(a)
        if cur_score < best_score:
            best_score = cur_score
            best = a.copy()
            print(f"[{time.time() - start_time:.2f}s] ExpGD iter={it:,} "
                  f"best={cur_score:.6f}")
    return best, best_score


def _objective(seq: np.ndarray) -> float:
    """Exact objective 2·n·max(conv(seq,seq)) / (sum(seq)²)."""
    n = seq.shape[0]
    conv = _conv_self(seq)
    max_conv = conv.max()
    s = seq.sum()
    if s < 1e-12:
        return np.inf
    return float(2.0 * n * max_conv / (s * s))


# ----------------------------------------------------------------------
# Smooth‑max (log‑sum‑exp) objective on the logits b = log(a)
# ----------------------------------------------------------------------
def _objective_and_grad_b(b: np.ndarray, alpha: float, n: int) -> tuple[float,
                                                                      np.ndarray]:
    """Return (Φ_α(b), ∇_b Φ_α(b)).  a = softmax(b) is guaranteed to lie on the simplex."""
    # softmax to obtain a on the simplex
    max_b = b.max()
    exp_b = np.exp(b - max_b)
    a = exp_b / exp_b.sum()

    # convolution a*a
    conv = _conv_self(a)

    # smooth‑max (log‑sum‑exp) of the convolution
    scaled = conv * alpha
    max_scaled = scaled.max()
    exp_scaled = np.exp(scaled - max_scaled)
    sum_exp = exp_scaled.sum()
    log_sum_exp = max_scaled + np.log(sum_exp)
    smax = log_sum_exp / alpha
    obj = 2.0 * n * smax

    # soft‑max weights over convolution indices
    w = exp_scaled / sum_exp          # shape (2n‑1,)

    # correlation w ⋆ a_rev  → gradient of smax w.r.t. a
    a_rev = a[::-1]
    corr = _correlation(w, a_rev)    # length n
    grad_a = 4.0 * n * corr           # ∂Φ/∂a (since Φ = 2n·smax)

    # chain rule through softmax: ∂a/∂b = diag(a) – a aᵀ
    avg = np.dot(grad_a, a)          # ⟨grad_a , a⟩
    grad_b = a * (grad_a - avg)

    return float(obj), grad_b.astype(np.float64)

# ----------------------------------------------------------------------

            print(f"[{time.time() - start:.2f}s] L‑BFGS α={alpha:.0f} score = {cur_score:.6f}")

    # --------------------------------------------------------------
    # 3) Final polishing with the exact hard‑max sub‑gradient method
    # --------------------------------------------------------------
    if time.time() < deadline - 5.0:
        seq, sc = _exp_subgradient_descent(best_vec, deadline, start)
        if sc < best_score:
            best_score, best_vec = sc, seq.copy()
            print(f"[{time.time() - start:.2f}s] Final ExpGD improvement → {sc:.6f}")

    # --------------------------------------------------------------
    # 4) Normalise, safety‑clip and return
    # --------------------------------------------------------------
    best_vec = np.maximum(best_vec, 0.0)
    total = best_vec.sum()
    if total > 0:
        best_vec /= total
    else:
        best_vec = np.full(N, 1.0 / N)

    final_score = evaluate_sequence(best_vec.tolist())
    print(f"[{time.time() - start:.2f}s] Finished, final score ≈ {final_score:.6f}")

    return [float(v) for v in best_vec]
```
