The target value  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}
\]

is invariant under a scaling of the vector `a`, therefore we may (and do) keep the
ℓ₁‑norm of the candidate equal to 1 while searching.  
With this normalisation the problem reduces to

*minimise* `max(conv(a,a))` *subject to* `a_i ≥ 0` and `∑ a_i = 1`.

The programme below performs a **multi‑phase, time‑controlled search**:

1. **Rich parametric families** – beta‑shapes, geometric mixtures,
   left/right exponential decays and arbitrary mixtures with the uniform
   distribution.  The parameters are explored on very fine grids and with a
   random‑sampling bias towards the most promising region.

2. **Heavy‑tailed Dirichlet draws** – 10 000 random vectors with concentration
   ranging from `10⁻³` to `10³`.  Each draw is normalised and evaluated.

3. **Projected gradient descent (PGD)** – from the `k` best vectors found
   so far (including the current best) we run a few hundred PGD steps.
   The sub‑gradient of `max(conv)` is computed exactly (averaged over all
   active shifts).  A back‑tracking line‑search guarantees feasibility and
   monotone improvement.

4. **Simulated annealing (SA)** – a long, annealed hill‑climb that repeatedly
   transfers a small fraction of the mass from a “high‑gradient’’ index to a
   “low‑gradient’’ one.  The temperature is decreased linearly; uphill moves
   are accepted with the usual Metropolis probability.

All convolutions are performed by a fast FFT (next‑power‑of‑two length) and
the objective value is obtained as  

```
score = 2 * n * max(conv)          # because ‖a‖₁ = 1
```

The programme constantly checks the time budget (1000 s) and stops the
current phase as soon as the remaining time is insufficient for the next
iteration.  The best vector encountered is returned as a plain list of
floats – ready to be handed to `evaluate_sequence`.

The combination of a far richer parameter sweep, many more random starts,
multiple PGD restarts and a more aggressive SA schedule gives a
significant chance of beating the previous bound `1.507818` and reaching the

```python
"""
propose_candidate – multi‑phase stochastic optimiser for

    2 * n * max(conv(a,a)) / (sum(a)**2)

The algorithm explores many parametric families, draws thousands of random
Dirichlet vectors, performs several projected‑gradient‑descent restarts and
finishes with a long simulated‑annealing hill‑climb.  All steps respect the
time budget (1000 s) and always keep the candidate on the probability simplex.
"""

import time
import numpy as np
import math

# ----------------------------------------------------------------------
# Low‑level utilities (FFT convolution, sub‑gradient, objective)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """
    Full self‑convolution a*a (length 2·n‑1) using an FFT of the next power of two.
    """
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _objective_score(a: np.ndarray) -> float:
    """
    Return 2·n·max(conv(a,a)) assuming the ℓ₁‑norm of a equals 1.
    """
    n = a.shape[0]
    conv = _conv_self(a)
    return float(2.0 * n * conv.max())


def _subgradient_maxconv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of  max(conv(a,a))  at a.
    All active shifts (within 1e‑12 of the maximum) are averaged.
    """
    n = a.shape[0]
    max_val = conv.max()
    tol = 1e-12
    active = np.where(conv >= max_val - tol)[0]
    grad = np.zeros_like(a)

    for k in active:
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad[idx] += a[k - idx]

    if active.size:
        grad = 2.0 * grad / active.size
    return grad


# ----------------------------------------------------------------------
# Helper to keep the best solution seen so far
# ----------------------------------------------------------------------
def _maybe_update_best(seq: np.ndarray, best):
    """
    Normalise `seq` to ℓ₁‑norm 1, compute its score and update the shared
    best‑state if the new score is smaller.
    Returns the (possibly new) best state.
    """
    best_seq, best_score, start = best
    s = seq.sum()
    if s < 1e-12:
        return best
    seq = seq / s
    sc = _objective_score(seq)
    if sc < best_score:
        best_score = sc
        best_seq = seq.copy()
        print(f"[{time.time() - start:.2f}s] New best score = {sc:.6f}")
    return (best_seq, best_score, start)


# ----------------------------------------------------------------------
# 1️⃣  Parametric families (very fine sweeps)
# ----------------------------------------------------------------------
def _sweep_beta(n, best, deadline):
    """U‑shaped beta PDFs: a_i ∝ (i+1)^{α-1}·(n-i)^{β-1}, plus a uniform mixture."""
    start = best[2]
    idx = np.arange(n, dtype=np.float64)
    uniform = np.full(n, 1.0 / n)

    # log‑space for α,β in (0.01, 0.8) – this region yields pronounced U‑shapes.
    alphas = np.logspace(-2, -0.1, 30)      # 0.01 … 0.79
    betas = alphas.copy()                  # symmetry may be good, but we also test all combos

    for α in alphas:
        for β in betas:
            if time.time() >= deadline:
                return best
            # log‑density to avoid overflow
            log_seq = (α - 1.0) * np.log(idx + 1.0) + (β - 1.0) * np.log(np.maximum(n - idx, 1))
            # keep numbers manageable
            log_seq -= np.max(log_seq)
            seq = np.exp(log_seq)
            # mixture with the uniform vector – λ tells how much uniform we keep
            for lam in (0.0, 0.2, 0.5, 0.8):
                seq_mixed = lam * uniform + (1.0 - lam) * seq
                best = _maybe_update_best(seq_mixed, best)
    return best


def _sweep_skewed_exp(n, best, deadline):
    """Left‑right independent exponentials, plus a uniform blend."""
    start = best[2]
    idx = np.arange(n, dtype=np.float64)
    mid = n // 2
    left_idx = idx[:mid]
    right_idx = idx[mid:]

    uniform = np.full(n, 1.0 / n)

    # λ in (1e‑4, 0.7) on a finer grid
    lambdas = np.logspace(-4, -0.1, 40)
    for lam_l in lambdas:
        for lam_r in lambdas:
            if time.time() >= deadline:
                return best
            seq = np.empty(n, dtype=np.float64)
            seq[:mid] = np.exp(-lam_l * left_idx)
            seq[mid:] = np.exp(-lam_r * (n - 1 - right_idx))
            # small uniform mix helps escaping shallow plateaus
            for lam in (0.0, 0.3, 0.6):
                seq_mixed = lam * uniform + (1.0 - lam) * seq
                best = _maybe_update_best(seq_mixed, best)
    return best


def _sweep_two_blocks_varsize(n, best, deadline):
    """Two uniform blocks of possibly different sizes and different mass splits."""
    start = best[2]
    for L_left in np.arange(1, n // 2 + 1, max(1, n // 200)):
        for L_right in np.arange(1, n // 2 + 1, max(1, n // 200)):
            if time.time() >= deadline:
                return best
            # allocate a fraction w of the total mass to the left block
            for w in np.linspace(0.05, 0.95, 19):
                seq = np.zeros(n, dtype=np.float64)
                seq[:L_left] = w / L_left
                seq[-L_right:] = (1.0 - w) / L_right
                best = _maybe_update_best(seq, best)
    return best


def _sweep_power_mix(n, best, deadline):
    """Mixture of a power‑law shape and the uniform distribution."""
    start = best[2]
    idx = np.arange(n, dtype=np.float64)
    uniform = np.full(n, 1.0 / n)

    # exponent p ∈ [‑2, 2] with finer steps near 0
    ps = np.concatenate([np.linspace(-2.0, -0.5, 30),
                         np.linspace(-0.5, 0.5, 60),
                         np.linspace(0.5, 2.0, 30)])
    for p in ps:
        if time.time() >= deadline:
            return best
        seq = np.power(idx + 1.0, p)
        if seq.sum() == 0:
            continue
        seq /= seq.sum()
        for lam in (0.0, 0.4, 0.7):
            seq_mixed = lam * uniform + (1.0 - lam) * seq
            best = _maybe_update_best(seq_mixed, best)
    return best

# ----------------------------------------------------------------------
def _random_dirichlet_trials(n, best, deadline):
    start = best[2]
    rng = np.random.default_rng()
    while time.time() < deadline:
        # concentration c ∈ [10⁻³, 10³] on log‑scale
        logc = rng.uniform(-3.0, 3.0)
        c = 10 ** logc
        a = rng.gamma(shape=c, scale=1.0, size=n)
        if a.sum() == 0:
            continue
        best = _maybe_update_best(a, best)
    return best

# 3️⃣ Projected Gradient Descent (run from several distinct starts)
# ----------------------------------------------------------------------
def _projected_gradient_descent(a0, max_iters, deadline, best):
    """
    Simple PGD that always keeps the vector on the simplex.
    Stops after `max_iters` iterations or when the deadline is hit.
    """
    a = a0.copy()
    n = a.shape[0]
    it = 0
    while it < max_iters and time.time() < deadline:
        it += 1
        conv = _conv_self(a)
        cur_score = float(2.0 * n * conv.max())
        # update global best
        best = _maybe_update_best(a, best)
        if cur_score <= best[1] + 1e-12:
            # no need to descend further if we already sit at the global best
            pass
        grad = _subgradient_maxconv(a, conv)
        # direction that preserves the sum (∑d = 0)
        d = -(grad - grad.mean())
        # maximal feasible step without negative entries
        idx_neg = np.where(d < 0)[0]
        if idx_neg.size:
            max_step = np.min(-a[idx_neg] / d[idx_neg])
        else:
            max_step = 1.0
        step = max_step * 0.9  # start a little shy of the boundary
        # back‑tracking line search
        while step > 1e-15:
            a_new = a + step * d
            if np.any(a_new < 0):
                step *= 0.5
                continue
            conv_new = _conv_self(a_new)
            new_score = float(2.0 * n * conv_new.max())
            if new_score <= cur_score:
                a = a_new
                break
            step *= 0.5
        # if line search failed, inject a tiny jitter to escape a flat region
        if step <= 1e-15:
            eps = 1e-8
            a = a + rng.uniform(-eps, eps, size=n)
            a = np.clip(a, 0.0, None)
            a /= a.sum()
    return best


# ----------------------------------------------------------------------
# 4️⃣ Simulated Annealing (aggressive hill‑climb)
# ----------------------------------------------------------------------
def _simulated_annealing(a0, deadline, best):
    """
    Mass‑transfer SA: repeatedly move a random fraction of mass from a
    high‑gradient index to a low‑gradient one.  Temperature decays linearly.
    """
    start = best[2]
    n = a0.shape[0]
    a = a0.copy()
    cur_score = _objective_score(a)
    best = _maybe_update_best(a, best)
    cur_score = best[1]

    rng = np.random.default_rng()
    total_time = deadline - time.time()
    it = 0
    no_improve = 0
    # pre‑compute an initial gradient for source bias
    grad = _subgradient_maxconv(a, _conv_self(a))

    while time.time() < deadline:
        it += 1
        elapsed = time.time() - start
        frac_time = elapsed / total_time
        temperature = (1.0 - frac_time) * cur_score * 0.001   # ~0.1 % of the current score

        # update gradient bias every few iterations
        if it % 80 == 0:
            grad = _subgradient_maxconv(a, _conv_self(a))

        # give higher probability to indices with large positive gradient
        prob = np.maximum(grad, 0.0)
        prob_sum = prob.sum()
        if prob_sum > 0:
            src = rng.choice(n, p=prob / prob_sum)
        else:
            src = rng.integers(n)

        dst = rng.integers(n)
        if src == dst:
            continue

        # transfer a random fraction of the source mass
        max_transfer = 0.30                      # allow up to 30 % of source
        transfer = rng.random() * max_transfer * a[src]
        if transfer <= 0.0:
            continue

        a_prop = a.copy()
        a_prop[src] -= transfer
        a_prop[dst] += transfer

        # evaluate the proposal
        cand_score = _objective_score(a_prop)
        delta = cand_score - cur_score

        if delta < 0 or rng.random() < math.exp(-delta / (temperature + 1e-15)):
            a = a_prop
            cur_score = cand_score
            best = _maybe_update_best(a, best)
            if cur_score < best[1]:
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1

        # occasional rejuvenation if stuck for a long time
        if no_improve > 5000:
            i1, i2 = rng.choice(n, size=2, replace=False)
            eps = a[i1] * (rng.random() * max_transfer)
            a[i1] -= eps
            a[i2] += eps
            a = np.clip(a, 0.0, None)
            a /= a.sum()
            cur_score = _objective_score(a)
            best = _maybe_update_best(a, best)
            no_improve = 0

    return best
```
