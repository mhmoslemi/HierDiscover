Propose a step‑function that minimises
        score = 2·n·max(conv(a,a)) / (sum(a)²)

The algorithm is deliberately different from the previous mirror‑descent code:

1. **Beta‑family search** –  The distribution
        a_i ∝ x_i^{p‑1} (1‑x_i)^{p‑1} ,    x_i = (i+½)/n
   (Beta(p,p) on a uniform grid) is scanned for a wide range of p.
   p=½ is the continuous arcsine law whose self‑convolution is uniform,
   i.e. it reaches the theoretical lower bound 1.  For each p we also try
   convex mixtures with the uniform vector because a tiny amount of uniform
   mass often smoothes discretisation artefacts.

2. **Global warm‑start** –  The code tries the optional global variable
   ``height_sequence_1`` (if present) and a few Dirichlet draws.

3. **Hill‑climbing refinement** –  Starting from the best candidate found
   above, random pairwise transfers of a tiny amount of mass are performed
   (accepting only improvements).  This cheap local search is able to push
   the score a little further when the optimum lies close to the discrete
   grid.

All operations stay on the probability simplex (∑a_i = 1) so the score is
scale‑invariant and the evaluator’s clipping does not affect the result.
The routine respects the supplied time budget (default 1000 s) and prints
progress.
"""

import time

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray, L_fft: int) -> np.ndarray:
    """Full linear convolution a⋆a (length 2·len(a)‑1) via FFT."""
    Af = np.fft.rfft(a, n=L_fft)
    conv = np.fft.irfft(Af * Af, n=L_fft)
    return conv[: 2 * a.shape[0] - 1]


def _score_of(a: np.ndarray, n: int, L_fft: int) -> tuple[float, np.ndarray]:
    """Exact score used by the evaluator."""
    conv = _conv_self_fft(a, L_fft)
    max_b = conv.max()
    # a is kept normalised, so sum(a)=1
    score = float(2.0 * n * max_b)
    return score, conv


def _beta_shape(n: int, p: float) -> np.ndarray:
    """
    Return the discretised Beta(p,p) density on the grid i=0,…,n‑1,
    i.e. a_i ∝ x_i^{p‑1} (1‑x_i)^{p‑1} with x_i = (i+0.5)/n.
    The result is normalised to sum 1.
    """
    i = np.arange(n, dtype=np.float64)
    x = (i + 0.5) / n
    # Avoid 0^negative by clipping (x never hits 0 or 1 because of +0.5)
    a = np.power(x, p - 1.0) * np.power(1.0 - x, p - 1.0)
    # Numerical safety
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n)
    return a / s
