Propose a step‑function with a lower evaluation score than the previous
≈1.5088 (target < 1.503).  

Algorithm
---------
1. **Problem size** – work with a longer sequence (n = 8192).  The
   asymptotic optimum (≈1.5) is approached from above as n grows,
   therefore a larger n gives a better discretisation of the optimal
   continuous density.

2. **Initial candidates** – generate many inexpensive candidates:
   * a family  a_i ∝ min(i,n‑1-i)^p  for a fine grid of exponents p,
   * convex mixtures of the above shape with the uniform distribution,
   * a few random Dirichlet draws.
   The best of these (according to the exact objective) seeds the local
   optimisation.

3. **Projected Adam optimisation** – minimise the exact objective
   2·n·max(conv(a,a))/∑a² .  The gradient of the max‑convolution is a
   sub‑gradient; we average the sub‑gradients of all indices whose
   convolution value is within a tiny tolerance of the maximum.  The
   update uses Adam (bias‑corrected first‑ and second‑moment estimates)
   and a Euclidean projection onto the probability simplex after every
   step.

4. **Light simulated‑annealing polish** – after the Adam phase we run a
   short annealing where a random ε‑mass is transferred between two
   coordinates; moves that improve the objective are always kept,
   otherwise they are accepted with a temperature‑dependent probability.

5. **Normalisation** – finally clip to non‑negative values, renormalise
   the vector to have sum > 0 and return a plain Python list.

The whole procedure respects the 1000 s budget and prints progress
messages so the evolution of the best score can be monitored.
"""

import time
import math
import numpy as np


# ----------------------------------------------------------------------
# FFT based convolution utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """Linear convolution a*a using FFT (returns length 2·len(a)-1)."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _objective(seq: np.ndarray) -> float:
    """Exact objective 2·n·max(conv(seq,seq))/sum(seq)²."""
    n = seq.shape[0]
    conv = _conv_self(seq)
    max_conv = conv.max()
    sum_seq = seq.sum()
    if sum_seq < 1e-12:
        return np.inf
    return float(2.0 * n * max_conv / (sum_seq ** 2))


# ----------------------------------------------------------------------
# Projection onto the probability simplex (Euclidean)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto {w ≥ 0, Σ w = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Sub‑gradient (Adam) optimisation of the exact objective
# ----------------------------------------------------------------------
def _adam_optimize(a0: np.ndarray,
                   deadline: float,
                   start_time: float) -> tuple[np.ndarray, float]:
    """
    Adam optimiser with projection onto the simplex.
    Returns the best iterate found before `deadline`.
    """
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(a)

    # Adam hyper‑parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr0 = 0.15                     # initial learning rate
    t = 0

    m = np.zeros_like(a)
    v = np.zeros_like(a)

    while time.time() < deadline:
        t += 1
        # current convolution and objective
        conv = _conv_self(a)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] Adam iter={t:,} "
                  f"score={cur_score:.6f}")

        # find all indices whose value is within a tiny tolerance of the max
        tol = 1e-14
        active = np.where(conv >= cur_max - tol)[0]

        # accumulate sub‑gradient from all active indices
        grad = np.zeros_like(a)
        for k in active:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            idx = np.arange(lo, hi + 1, dtype=int)
            grad[idx] += 2.0 * a[k - idx]

        if active.size > 1:
            grad /= float(active.size)      # average → valid sub‑gradient

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        lr = lr0 / math.sqrt(t)            # simple decay
        a = a - lr * m_hat / (np.sqrt(v_hat) + eps)

        # keep a on the simplex
        a = _project_simplex(a)

    return best_a, best_score

    total_steps = 30_000
    for it in range(1, total_steps + 1):
        if time.time() >= deadline:
            break
        # linear cooling from 0.01 to 1e‑6

        a_prop = a.copy()
