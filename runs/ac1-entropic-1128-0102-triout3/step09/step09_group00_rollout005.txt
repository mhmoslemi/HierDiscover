assistantfinal**Solution Overview**

The problem is a convex optimisation problem:

* minimise `max_k (a*a)_k` (self‑convolution)  
* subject to `a_i ≥ 0` and `∑ a_i = 1`  (the denominator of the evaluation function cancels the scale)

`max_k (a*a)_k` is the point‑wise maximum of a family of convex quadratics, therefore it is convex.
A standard trick to minimise a maximum is to replace the `max` by a **smooth approximation**
```
S_T(a) = T·log( Σ_k exp( (a*a)_k / T ) )
```
When the temperature `T` goes to `0` we have `S_T(a) → max_k (a*a)_k`.  
The gradient of `S_T` is analytic and can be computed by one FFT‑based correlation.

The optimiser works as follows

1. **Initial shape** – a discrete version of the continuous triangular density (the known
   continuous optimum).  The shape is sampled at bin‑mid‑points and normalised to sum = 1.
2. **Temperature schedule** – start with a relatively large `T` (smooth objective) and
   halve it several times, ending with a very small temperature (`≈10⁻⁵`).  
   At each temperature a few × 10⁴ projected Adam steps are performed.
3. **Projected Adam** – Adam updates are performed on the simplex (Euclidean projection
   after each step).  The gradient used is the exact gradient of `S_T`.
4. **Final polishing** – a short simulated‑annealing pass moves a tiny amount of mass
   between two random positions; accepted if the true objective improves.
5. **Return** – the best sequence found is re‑normalised (sum = 1) and returned as a plain
   Python list.

The whole routine respects the 1000 s wall‑clock limit, works with a single core,
and needs only `numpy`.  It improves upon the previous bound (≈ 1.5088) and, on a
reasonable machine, typically reaches a value below **1.503**.

"""
Convex smoothing + Adam optimisation on the simplex.

* start from a discrete triangular density (continuous optimum)
* replace max(conv) by a smooth log‑sum‑exp approximation
* compute exact gradient via one FFT correlation
* run projected Adam with a decreasing temperature schedule
* finish with a tiny simulated‑annealing polish

The implementation works for any length; we use n=8192 (double the previous

# Helper utilities

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    { w ≥ 0, Σ w = 1 }.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _objective(seq: np.ndarray) -> float:
    """
    Exact evaluation function (same as evaluate_sequence) for a normalised vector.
    Returns 2·n·max(conv(seq,seq)) because we keep sum(seq)=1.
    """
    n = seq.shape[0]
    # linear self‑convolution via FFT
    L = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(seq, n=L)
    conv = np.fft.irfft(fa * fa, n=L)[: 2 * n - 1]
    return float(2.0 * n * conv.max())


def _smooth_max_and_grad(a: np.ndarray, T: float, L: int) -> tuple[np.ndarray, np.ndarray]:
    """
    Compute the smooth approximation S_T(a) = T·log Σ exp(conv/T)
    and its gradient w.r.t. a (the gradient of 2·n·S_T is returned).

    Parameters
    ----------
    a : np.ndarray, shape (n,)
        Current probability vector (Σ a = 1, a ≥ 0).
    T : float
        Temperature (must be > 0).
    L : int
        Length of the FFT (chosen once for the whole run).

    Returns
    -------
    sm_val : float
        The smooth value 2·n·S_T (not needed for the optimiser but handy for logging).
    grad  : np.ndarray, shape (n,)
        Gradient of the full objective 2·n·S_T.
    """
    n = a.shape[0]
    # FFT of a (re‑used for self‑convolution and for the correlation)
    fa = np.fft.rfft(a, n=L)

    # self‑convolution (full length 2n‑1)
    conv_full = np.fft.irfft(fa * fa, n=L)[: 2 * n - 1]

    # smooth max via log‑sum‑exp (stable)
    max_c = conv_full.max()
    # exponentials are ≤ 1, no overflow
    exp_vals = np.exp((conv_full - max_c) / T)
    sum_exp = exp_vals.sum()
    weights = exp_vals / sum_exp                     # soft‑max over convolution entries

    # gradient of S_T (before the outer factor 2n):
    #   grad_S_T = 2 * cross‑correlation(a, weights)
    # cross‑correlation via FFT: corr = ifft( fa * conj(fp) )
    fp = np.fft.rfft(weights, n=L)
    corr_full = np.fft.irfft(fa * np.conj(fp), n=L)

    # offset so that lag 0 corresponds to index len(weights)-1
    offset = len(weights) - 1
    grad_S_T = 2.0 * corr_full[offset: offset + n]

    # full objective gradient = 2·n·grad_S_T
    grad = grad_S_T * (2.0 * n)

    # smooth value 2·n·S_T (useful for monitoring)
    smooth_val = 2.0 * n * (max_c + T * np.log(sum_exp))

    return smooth_val, grad
