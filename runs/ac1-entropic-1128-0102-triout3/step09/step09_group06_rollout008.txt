assistantfinal**Solution Overview**

The program searches a non‑negative step‑function (a probability vector) that minimises  

\[
\text{score}= \frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2}
\]

(the sum is kept equal to 1, therefore the score is simply `2*n*max(conv)`).

The optimiser consists of three stages

1. **Exploration (multiple restarts + Adam on a smooth‐max).**  
   Several initial candidates – uniform, the historic best, and a random Dirichlet – are optimised with a projected Adam optimiser on the smooth approximation  

   \[
   f_\alpha(a)=\frac1\alpha\log\!\Bigl(\sum_k e^{\alpha\,(a*a)[k]}\Bigr)
   \]

   The schedule of smoothing parameters `α` grows from `0.5` up to `2048`.  
   The best vector among all restarts is kept.

2. **Exact sub‑gradient polishing.**  
   Using the *binary* sub‑gradient of the true max (the active set of indices where the convolution attains its maximum) we perform projected sub‑gradient descent with momentum.  
   This directly reduces `max(conv)`.

3. **Greedy peak reduction + simulated annealing.**  
   A very cheap greedy move transfers a fraction of the coefficient that contributes most to the current peak towards the smallest coefficient.  
   After the greedy phase a short simulated‑annealing loop performs random small transfers; moves are accepted if they improve the score or with a temperature‑controlled probability.

All operations are performed on the probability simplex (projection via the O(n log n) algorithm).  
Convolutions are evaluated with FFTs for speed (`O(n log n)`).  
The total running time never exceeds the 1000 s budget.

The final vector is returned as a plain Python list; the evaluator will clip and normalise it automatically.

"""
Propose a non‑negative step function with a low evaluate_sequence score.

Algorithm
---------
1. Load the historic best (height_sequence_1) if available, otherwise start
   from a uniform distribution.  Additionally generate a random Dirichlet
   restart – three restarts in total.

2. For each restart run a long projected‑Adam optimisation on the
   smooth‑max approximation of the objective.
   The smoothing parameter α follows the schedule
        [0.5, 2, 8, 32, 128, 512, 2048]
   and the Adam step is projected onto the probability simplex.
   The best vector among all restarts is kept.

3. Starting from the best Adam candidate, run projected sub‑gradient descent
   on the *exact* max‑convolution using the binary sub‑gradient
   (active set of maximum entries).  A momentum term and a 1/√t step‑size
   are employed.

4. Fast greedy peak reduction: repeatedly move a small fraction of the
   coefficient that most contributes to the current peak towards the
   smallest coefficient, accepting only strict improvements.  The
   convolution array is updated incrementally (O(n) per move).

5. Simulated‑annealing refinement: with the remaining time perform random
   tiny mass transfers between two positions; accept moves that improve
   the score or, with a linearly decreasing temperature, accept worsening
   moves with probability exp(−Δ/ T).

The routine respects the 1000 s time limit, prints progress information
and finally returns the best sequence found (as a plain list of floats).
"""

import time

# Linear‑algebra utilities

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex.
    Returned vector sums to 1 and contains only non‑negative entries.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _conv_self_fft(a: np.ndarray, fft_len: int = None) -> np.ndarray:
    """
    Full linear convolution a * a using FFT.
    Returns an array of length 2*len(a)-1.
    """
    n = a.shape[0]
    if fft_len is None:
        fft_len = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)[: 2 * n - 1]
    return conv


def _grad_smooth_max(a: np.ndarray, conv: np.ndarray,
                     alpha: float, fft_len: int) -> np.ndarray:
    """
    Gradient of the smooth‑max surrogate
        f_α(a) = (1/α)·log Σ_k exp(α·conv_k)
    Returns ∂f/∂a (shape (n,)).
    """
    n = a.shape[0]

    # soft‑max weights over convolution entries
    scaled = alpha * conv
    max_scaled = scaled.max()
    w = np.exp(scaled - max_scaled)
    w /= w.sum()                     # shape (2n‑1,)

    # cross‑correlation a ⋆ w   (gradient = 2·(a⋆w))
    w_rev = w[::-1]
    Af = np.fft.rfft(a, n=fft_len)
    Wrev = np.fft.rfft(w_rev, n=fft_len)
    corr = np.fft.irfft(Af * Wrev, n=fft_len)[: n + len(w_rev) - 1]

    # centre slice yields the gradient
    grad = 2.0 * corr[len(w_rev) - 1 - np.arange(n)]
    return grad


def _grad_max_subgrad(a: np.ndarray, conv: np.ndarray,
                      fft_len: int) -> np.ndarray:
    """
    Sub‑gradient of   max_k (a*a)[k] .
    The active set is defined by entries whose value is within 1e-12 of the max.
    """
    n = a.shape[0]
    max_val = conv.max()
    # binary mask of active indices (could be more than one)
    mask = (conv >= max_val - 1e-12).astype(float)   # shape (2n‑1,)

    # same convolution trick as in the smooth case
    w_rev = mask[::-1]
    Af = np.fft.rfft(a, n=fft_len)
    Wrev = np.fft.rfft(w_rev, n=fft_len)
    corr = np.fft.irfft(Af * Wrev, n=fft_len)[: n + len(w_rev) - 1]
    grad = 2.0 * corr[len(w_rev) - 1 - np.arange(n)]
    return grad

def _adam_optimize(a0: np.ndarray,
                   end_time: float,
                   start_time: float) -> tuple[np.ndarray, float]:
    """
    Projected Adam on the smooth‑max surrogate.
    Returns the best vector (probability simplex) and its exact score.
    """
    a = a0.copy()
    n = a.shape[0]

    # pre‑compute FFT length sufficient for all convolutions
    fft_len = _next_pow2(3 * n - 2)

    # smoothing schedule
    alpha_schedule = [0.5, 2.0, 8.0, 32.0, 128.0, 512.0, 2048.0]

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    lr0 = 0.12
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    t = 0

    best_a = a.copy()
    best_score = float(evaluate_sequence(a.tolist()))

    for alpha in alpha_schedule:
        # keep iterating while we have time
        while time.time() < end_time:
            conv = _conv_self_fft(a, fft_len)
            # smooth‑max value (not needed for gradient but kept for monitoring)
            scaled = alpha * conv
            max_scaled = scaled.max()
            lse = max_scaled + np.log(np.exp(scaled - max_scaled).sum())
            f_val = lse / alpha                     # smooth‑max
            # objective factor 2·n (exact objective = 2·n*max(conv))
            obj = 2.0 * n * f_val

            # gradient (including outer factor 2·n)
            grad = _grad_smooth_max(a, conv, alpha, fft_len) * (2.0 * n)

            # Adam update
            t += 1
            m = beta1 * m + (1.0 - beta1) * grad
            v = beta2 * v + (1.0 - beta2) * (grad ** 2)
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            lr_t = lr0 / np.sqrt(t)

            a_new = a - lr_t * m_hat / (np.sqrt(v_hat) + eps)
            a = _project_simplex(a_new)

            # occasional exact evaluation (every 400 steps)
            if t % 400 == 0:
                sc = evaluate_sequence(a.tolist())
                if sc < best_score:
                    best_score = sc
                    best_a = a.copy()
                    print(f"[{time.time() - start_time:6.2f}s] Adam improve (α={alpha:.0f}) score={sc:.6f}")

    return best_a, best_score


def _subgrad_optimize(a0: np.ndarray,
                      end_time: float,
                      start_time: float,
                      beta: float = 0.94,
                      step0: float = 0.05) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent on   max_k (a*a)[k] .
    Uses the binary active‑set sub‑gradient.
    """
    a = a0.copy()
    n = a.shape[0]
    fft_len = _next_pow2(3 * n - 2)

    best_a = a.copy()
    best_score = float("inf")
    it = 0

    while time.time() < end_time:
        it += 1
        conv = _conv_self_fft(a, fft_len)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] Sub‑grad improve: iter={it:,} score={cur_score:.6f}")

        # sub‑gradient from the active set
        g = _grad_max_subgrad(a, conv, fft_len)

        # momentum and diminishing step size
        momentum = beta * (best_a - a) + (1.0 - beta) * g
        step = step0 / math.sqrt(it)

        a = _project_simplex(a - step * momentum)

    return best_a, best_score


def _greedy_improve(a0: np.ndarray,
                    end_time: float,
                    start_time: float,
                    max_iters: int = 500_000) -> tuple[np.ndarray, float]:
    """
    Fast O(n) greedy moves: move a small fraction of the coefficient that
    contributes most to the current convolution peak towards the smallest
    coefficient.  Only strict improvements are accepted.
    """
    a = a0.copy()
    n = a.shape[0]
    fft_len = _next_pow2(3 * n - 2)

    # initial full convolution (will be kept up‑to‑date incrementally)
    conv = _conv_self_fft(a, fft_len)
    best_score = 2.0 * n * conv.max()
    best_a = a.copy()
    it = 0

    while time.time() < end_time and it < max_iters:
        it += 1
        k_max = conv.argmax()
        cur_max = conv[k_max]

        # indices that participate in the peak
        lo = max(0, k_max - (n - 1))
        hi = min(n - 1, k_max)
        i_idx = np.arange(lo, hi + 1, dtype=int)
        j_idx = k_max - i_idx
        contrib = a[i_idx] * a[j_idx]

        # source = index with largest contribution to the peak
        src = i_idx[contrib.argmax()]

        # destination = smallest coefficient (different from src)
        dst_candidates = np.delete(np.arange(n), src)
        dst = dst_candidates[a[dst_candidates].argmin()]

        # transfer a modest fraction (decreases as optimisation proceeds)
        eps = 0.05 * a[src]
        if eps < 1e-14:
            break

        # --- incremental update of convolution (linear part) ---
        conv_tmp = conv.copy()
        # subtract effect of eps at src
        conv_tmp[src:src + n] -= 2.0 * eps * a
        # add effect of eps at dst
        conv_tmp[dst:dst + n] += 2.0 * eps * a
        # quadratic corrections (self‑terms and src‑dst interaction)
        conv_tmp[2 * src] += eps * eps
        conv_tmp[2 * dst] += eps * eps
        conv_tmp[src + dst] -= 2.0 * eps * eps

        new_max = conv_tmp.max()
        if new_max < cur_max:                      # accept only strict improvement
            conv = conv_tmp
            a[src] -= eps
            a[dst] += eps
            best_score = 2.0 * n * new_max
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] Greedy improve: iter={it:,} max={new_max:.6f}")

    return best_a, best_score


def _anneal_refine(a0: np.ndarray,
                   end_time: float,
                   start_time: float,
                   init_temp: float = 1e-4,
                   min_temp: float = 1e-7) -> tuple[np.ndarray, float]:
    """
    Simple simulated‑annealing refinement.
    Randomly transfers a tiny amount of mass between two indices.
    Acceptance follows the Metropolis rule with a linearly decreasing temperature.
    """
    a = a0.copy()
    n = a.shape[0]
    fft_len = _next_pow2(3 * n - 2)

    conv = _conv_self_fft(a, fft_len)
    cur_max = conv.max()
    best_a = a.copy()
    best_score = 2.0 * n * cur_max

    it = 0
    while time.time() < end_time:
        it += 1
        # linear temperature schedule
        t_frac = (end_time - time.time()) / (end_time - start_time)
        temp = max(min_temp, init_temp * t_frac)

        # propose a move
        i, j = np.random.choice(n, 2, replace=False)
        if a[i] < 1e-12:
            continue
        eps = 0.01 * a[i]                      # 1 % of source mass
        a_new = a.copy()
        a_new[i] -= eps
        a_new[j] += eps

        # re‑normalise (projection is cheap because only two entries changed)
        a_new = _project_simplex(a_new)

        # compute new max convolution
        conv_new = _conv_self_fft(a_new, fft_len)
        new_max = conv_new.max()
        new_score = 2.0 * n * new_max

        delta = new_score - best_score
        accept = False
        if delta < 0:
            accept = True
        else:
            prob = math.exp(-delta / temp) if temp > 0 else 0.0
            if np.random.rand() < prob:
                accept = True

        if accept:
            a = a_new
            conv = conv_new
            cur_max = new_max
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:6.2f}s] Anneal improve: iter={it:,} score={new_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Helper to build initial candidates
# ----------------------------------------------------------------------


def _initial_candidate(n: int, rng: np.random.Generator) -> list[np.ndarray]:
    """
    Return a list of several start vectors (all on the probability simplex):
        * uniform,
        * historic best (if available, resampled to length n),
        * a random Dirichlet draw.
    """
    candidates = []

    # uniform
    candidates.append(np.full(n, 1.0 / n))

    # historic best
    try:
        old = np.asarray(height_sequence_1, dtype=float)
        if old.ndim == 1 and old.size > 0:
            if old.shape[0] != n:
                # linear interpolation preserving the total mass
                old_x = np.linspace(0.0, 1.0, old.shape[0])
                new_x = np.linspace(0.0, 1.0, n)
                old = np.interp(new_x, old_x, old)
            old = np.maximum(old, 0.0)
            s = old.sum()
            if s > 0:
                candidates.append(old / s)
    except Exception:
        pass

    # random Dirichlet (α = 0.7 gives a slightly spiky start)
    candidates.append(rng.dirichlet(np.full(n, 0.7)).astype(float))

    return candidates


# ----------------------------------------------------------------------
# Main driver
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step function that minimises
    ``evaluate_sequence``.  The routine respects the 1000 s time budget.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    # tiny safety margin
    deadline = start_time + budget_s - 0.5

    # problem size – a power of two makes the FFT cheap
    n = 8192

    # ------------------------------------------------------------------
    # 1) generate several start vectors
    # ------------------------------------------------------------------
    start_vectors = _initial_candidate(n, rng)

    best_a = None
    best_score = float("inf")

    # Phase 1 – exploration with Adam (multiple restarts)
    explore_deadline = start_time + 0.55 * budget_s   # roughly 55 % of the total time
    print(f"[{time.time() - start_time:6.2f}s] Starting exploration (Adam)")

    for idx, a0 in enumerate(start_vectors):
        if time.time() >= explore_deadline:
            break
        print(f"[{time.time() - start_time:6.2f}s] Restart #{idx + 1}")
        a_opt, score_opt = _adam_optimize(a0, explore_deadline, start_time)
        if score_opt < best_score:
            best_score = score_opt
            best_a = a_opt.copy()
            print(f"[{time.time() - start_time:6.2f}s] New best after Adam restart #{idx + 1}: score={score_opt:.6f}")

    if best_a is None:
        # fallback – uniform (should never happen)
        best_a = np.full(n, 1.0 / n)
        best_score = evaluate_sequence(best_a.tolist())

    print(f"[{time.time() - start_time:6.2f}s] Exploration finished, best score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 2) sub‑gradient polishing (exact max)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        subgrad_deadline = min(deadline, time.time() + 0.30 * budget_s)
        print(f"[{time.time() - start_time:6.2f}s] Starting sub‑gradient polishing")
        best_a, sub_score = _subgrad_optimize(best_a, subgrad_deadline,
                                              start_time,
                                              beta=0.94,
                                              step0=0.05)
        if sub_score < best_score:
            best_score = sub_score
        print(f"[{time.time() - start_time:6.2f}s] Sub‑gradient phase finished, best score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 3) fast greedy peak reduction
    # ------------------------------------------------------------------
    if time.time() < deadline:
        greedy_deadline = min(deadline, time.time() + 0.10 * budget_s)
        print(f"[{time.time() - start_time:6.2f}s] Starting greedy refinement")
        best_a, gre_score = _greedy_improve(best_a, greedy_deadline, start_time)
        if gre_score < best_score:
            best_score = gre_score
        print(f"[{time.time() - start_time:6.2f}s] Greedy phase finished, best score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 4) simulated‑annealing fine tuning (remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        anneal_deadline = deadline
        print(f"[{time.time() - start_time:6.2f}s] Starting annealing refinement")
        best_a, ann_score = _anneal_refine(best_a, anneal_deadline, start_time)
        if ann_score < best_score:
            best_score = ann_score
        print(f"[{time.time() - start_time:6.2f}s] Annealing finished, best score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 5) final normalisation & evaluation
    # ------------------------------------------------------------------
    best_a = np.clip(best_a, 0.0, None)
    total = best_a.sum()
    if total > 0:
        best_a = best_a / total
    else:
        best_a = np.full_like(best_a, 1.0 / n)

    final_score = evaluate_sequence(best_a.tolist())
    print(f"[{time.time() - start_time:6.2f}s] Final reported score = {final_score:.6f}")

    return [float(x) for x in best_a.tolist()]
