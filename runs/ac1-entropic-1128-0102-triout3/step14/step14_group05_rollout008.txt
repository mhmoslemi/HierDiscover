assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\]

where `a*a` is the linear convolution of the non‑negative vector `a`.  
The ratio is invariant under positive scaling, therefore we may always normalise  

\[
\sum_i a_i = 1 .
\]

`F(a)` is cheap to evaluate if the convolution is performed by an FFT
(`O(n log n)`).  The only non‑smooth part is the `max` operator.
A standard trick is to replace it by a *soft‑max* (log–sum‑exp) with a
temperature `β`.  For small `β` the surrogate is very smooth, for large
`β` it approaches the true objective.  Optimising the surrogate with a
bounded‑variable L‑BFGS optimiser gives a good descent direction; after
each temperature we keep the solution as a warm‑start for the next,
higher temperature.

A pure gradient descent on the true objective is hard because of the
non‑differentiable `max`.  Instead we finish with a *targeted hill‑climb*
that directly reduces the current maximal convolution entry.  For a
given maximal index `k`, the contribution of the coefficient `a_i` to that
entry is `a_i·a_{k-i}`.  Moving a small amount of mass from the index with
the largest contribution to an index with very little mass almost always
decreases `F`.  The hill‑climb is performed until the time budget is
exhausted.

All steps are implemented with pure NumPy (FFT) and, when `scipy` is
available, with `scipy.optimize.fmin_l_bfgs_b`.  The total wall‑clock
budget is respected – the routine stops a little before the deadline and
returns the best sequence found.

The code below is self‑contained; the only external function it uses is
`evaluate_sequence` (provided by the grader) for the final check.



```python
"""
step_search_v2.py – Heuristic optimiser for the step‑function challenge.

The algorithm proceeds in four phases:

1️⃣  A cheap sweep over simple parametric families (geometric, power,
    logistic) and a uniform baseline.

2️⃣  Temperature‑annealed optimisation of a smooth‑max surrogate
    (log‑sum‑exp) using L‑BFGS.  The surrogate is differentiable, the
    temperature β is increased from 0.5 up to 500, and the solution of each
    stage seeds the next.

3️⃣  A few random restarts with short L‑BFGS runs to escape shallow local
    minima.

4️⃣  A specialised hill‑climb that repeatedly moves a tiny amount of mass
    from the coefficient that contributes the most to the current maximal
    convolution entry to a low‑mass coefficient.  The move is accepted
    only if it improves the exact objective.

All expensive convolution operations are performed with FFT (exact for
real data).  The routine honour‑s the 1000 s wall‑clock limit, prints
progress, and finally returns the best non‑negative, unit‑sum sequence as
a plain ``list[float]``.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Optional SciPy import
# ----------------------------------------------------------------------
try:
    import scipy.optimize
    _SCIPY_AVAILABLE = True
except Exception:  # pragma: no cover
    _SCIPY_AVAILABLE = False


# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray, L: int) -> np.ndarray:
    """
    Linear self‑convolution a*a using an FFT of length L.
    Returns a vector of length 2*len(a)-1.
    """
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * a.shape[0] - 1]
    return conv


def _eval_fast(a: np.ndarray, L_fft: int) -> float:
    """
    Exact objective 2·n·max(conv(a,a)) / (sum(a)**2)
    a must be non‑negative (any negative entries are clipped to 0).
    """
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    conv = _conv_self_fft(a, L_fft)
    max_b = conv.max()
    n = a.shape[0]
    return float(2.0 * n * max_b / (s * s))


def _softmax(z: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max – returns a probability vector."""
    shift = np.max(z)
    e = np.exp(z - shift)
    total = e.sum()
    if total == 0.0:                     # safety – should never happen
        return np.full_like(z, 1.0 / z.shape[0])
    return e / total


# ----------------------------------------------------------------------
# Surrogate (smooth‑max) objective used by L‑BFGS
# ----------------------------------------------------------------------
class _SurrogateMax:
    """
    Callable that returns (value, gradient) of the smooth‑max surrogate
    of max(conv(a,a)).  The optimisation variables are the log‑probabilities
    z, i.e. a = softmax(z).  The temperature β controls the tightness of
    the approximation (β → ∞ gives the exact max).
    """

    def __init__(self, n: int, beta: float, L_conv: int, L_corr: int):
        self.n = n
        self.beta = beta
        self.L_conv = L_conv          # length for a*a
        self.L_corr = L_corr          # length for w * a_rev (gradient)

    def __call__(self, z: np.ndarray):
        """
        Returns (surrogate value, gradient w.r.t. z).
        """
        a = _softmax(z)                       # a ≥ 0, Σa = 1
        # ---- linear self‑convolution ---------------------------------
        conv = _conv_self_fft(a, self.L_conv)      # length 2n‑1
        max_c = conv.max()

        # ---- smooth‑max (log‑sum‑exp) -------------------------------
        shifted = conv - max_c                     # stabilise exponentials
        exp_vals = np.exp(self.beta * shifted)
        sum_exp = exp_vals.sum()
        w = exp_vals / sum_exp                      # soft‑max weights

        surrogate = max_c + np.log(sum_exp) / self.beta

        # ---- gradient w.r.t. a ---------------------------------------
        # g_i = 2 * Σ_k w_k * a_{k-i}   (linear convolution with reversed a)
        a_rev = a[::-1]
        prod = np.fft.rfft(w, n=self.L_corr) * np.fft.rfft(a_rev, n=self.L_corr)
        conv_wa = np.fft.irfft(prod, n=self.L_corr)[: 3 * self.n - 2]
        # extract the needed slice and reverse it (see original paper)
        grad_a = 2.0 * conv_wa[self.n - 1 :: -1]     # length n

        # ---- back‑prop through soft‑max --------------------------------
        # ∂a_i/∂z_j = a_i (δ_{ij} – a_j)
        dot = np.dot(grad_a, a)                    # scalar  a·grad_a
        grad_z = a * (grad_a - dot)                # shape (n,)

        return surrogate, grad_z


# ----------------------------------------------------------------------
# Targeted hill‑climb that reduces the exact max‑convolution entry
# ----------------------------------------------------------------------
def _max_convolution_and_index(a: np.ndarray, L_fft: int):
    """Return (full convolution, index of the maximal entry)."""
    conv = _conv_self_fft(a, L_fft)
    idx = int(np.argmax(conv))
    return conv, idx


def _contribution_at_max(a: np.ndarray, k: int):
    """
    Vector c where c[i] = a[i] * a[k-i] if the pair is valid, else 0.
    This is the contribution of a[i] to the convolution entry at index k.
    """
    n = a.shape[0]
    i = np.arange(n, dtype=np.int64)
    j = k - i
    mask = (j >= 0) & (j < n)
    c = np.zeros_like(a)
    c[mask] = a[i[mask]] * a[j[mask]]
    return c


def _targeted_hill_climb(a: np.ndarray,
                         L_fft: int,
                         deadline: float,
                         start_time: float):
    """
    Repeatedly move a tiny amount of mass from the index that contributes
    most to the current maximal convolution entry to a low‑mass index.
    Only moves that strictly improve the exact objective are kept.
    """
    n = a.shape[0]
    best_a = a.copy()
    best_score = _eval_fast(best_a, L_fft)
    rng = np.random.default_rng()
    step_factor = 0.02                     # move about 2 % of the source mass

    while time.time() < deadline:
        conv, k = _max_convolution_and_index(best_a, L_fft)
        contrib = _contribution_at_max(best_a, k)

        src = int(np.argmax(contrib))                 # biggest offender
        # pick a destination among the lightest 10 % entries
        low_thr = np.percentile(best_a, 10)
        candidates = np.where(best_a <= low_thr)[0]
        if len(candidates) == 0:
            dst = int(np.argmin(best_a))
        else:
            dst = int(rng.choice(candidates))

        if src == dst:
            continue

        eps = best_a[src] * step_factor
        if eps < 1e-14:
            continue

        cand = best_a.copy()
        cand[src] -= eps
        cand[dst] += eps
        cand = np.maximum(cand, 0.0)
        cand /= cand.sum()

        sc = _eval_fast(cand, L_fft)
        if sc < best_score:
            best_score = sc
            best_a = cand
            print(f"[{time.time() - start_time:.2f}s] "
                  f"targeted hill‑climb score={best_score:.6f}")

        # occasional random perturbation to escape tiny plateaus
        if rng.random() < 0.01:
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and best_a[i] > 1e-12:
                eps2 = best_a[i] * rng.random() * step_factor
                cand2 = best_a.copy()
                cand2[i] -= eps2
                cand2[j] += eps2
                cand2 = np.maximum(cand2, 0.0)
                cand2 /= cand2.sum()
                sc2 = _eval_fast(cand2, L_fft)
                if sc2 < best_score:
                    best_score = sc2
                    best_a = cand2
                    print(f"[{time.time() - start_time:.2f}s] "
                          f"random perturbation score={best_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Main driver – propose_candidate
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises

        2 * n * max(conv(a, a)) / (sum(a)**2)

    The routine respects the time limit, records the best sequence and
    returns it as a plain ``list[float]``.
    """
    np.random.seed(seed)
    start_time = time.time()
    # leave a tiny margin for the final return
    deadline = start_time + budget_s - 0.15

    # ------------------------------------------------------------------
    # Problem size – 8192 gives more freedom while still being fast
    # ------------------------------------------------------------------
    n = 8192
    L_fft = _next_pow2(2 * n - 1)      # for exact evaluations
    L_corr = _next_pow2(3 * n - 2)     # for surrogate gradient

    # ------------------------------------------------------------------
    # 0️⃣  Baseline – uniform distribution
    # ------------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    best_seq = uniform.copy()
    best_score = _eval_fast(best_seq, L_fft)
    print(f"[{time.time() - start_time:.2f}s] uniform baseline score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 1️⃣  Fast parametric sweep (geometric / power / logistic families)
    # ------------------------------------------------------------------
    idx = np.arange(1, n + 1, dtype=np.float64)      # 1‑based index

    # ----- geometric * power -----
    r_grid = np.logspace(np.log10(0.90), np.log10(0.9999), num=45)
    p_grid = np.linspace(-3.5, 2.5, 45)

    for r in r_grid:
        if time.time() >= deadline - 150:
            break
        geo = np.power(r, np.arange(n, dtype=np.float64))
        for p in p_grid:
            if time.time() >= deadline - 150:
                break
            shape = geo * np.power(idx, p)
            s = shape.sum()
            if s == 0.0:
                continue
            shape /= s
            for lam in (0.0, 0.25, 0.5, 0.75, 1.0):
                cand = lam * uniform + (1.0 - lam) * shape
                cand /= cand.sum()
                sc = _eval_fast(cand, L_fft)
                if sc < best_score:
                    best_score = sc
                    best_seq = cand.copy()
                    print(f"[{time.time() - start_time:.2f}s] sweep r={r:.4f} "
                          f"p={p:.2f} λ={lam:.2f} score={sc:.6f}")

    # ----- logistic families (sigmoid‑shaped) -----
    sigma_grid = np.linspace(0.05 * n, 0.30 * n, 20)     # width of transition
    offset_grid = np.linspace(-0.2 * n, 0.2 * n, 20)    # shift of midpoint
    for sigma in sigma_grid:
        if time.time() >= deadline - 150:
            break
        for offs in offset_grid:
            if time.time() >= deadline - 150:
                break
            x = np.arange(n, dtype=np.float64) - (n / 2 + offs)
            shape = 1.0 / (1.0 + np.exp(x / sigma))
            shape /= shape.sum()
            for lam in (0.0, 0.5, 1.0):
                cand = lam * uniform + (1.0 - lam) * shape
                cand /= cand.sum()
                sc = _eval_fast(cand, L_fft)
                if sc < best_score:
                    best_score = sc
                    best_seq = cand.copy()
                    print(f"[{time.time() - start_time:.2f}s] logistic σ={sigma:.0f} "
                          f"offset={offs:.0f} λ={lam:.2f} score={sc:.6f}")

    # ------------------------------------------------------------------
    # 2️⃣  Smooth‑max L‑BFGS optimisation (annealed β)
    # ------------------------------------------------------------------
    if _SCIPY_AVAILABLE and time.time() < deadline - 250:
        eps = 1e-12
        z0 = np.log(np.maximum(best_seq, eps))

        beta_schedule = [0.5, 1.0, 2.0, 5.0, 10.0,
                         20.0, 50.0, 100.0, 200.0, 500.0]

        for beta in beta_schedule:
            if time.time() >= deadline - 250:
                break
            obj = _SurrogateMax(n=n, beta=beta,
                                L_conv=_next_pow2(2 * n - 1),
                                L_corr=_next_pow2(3 * n - 2))
            # spend more function evaluations for later (sharper) temperatures
            maxfun = 2000 if beta >= 20.0 else 1200
            try:
                z_opt, f_val, info = scipy.optimize.fmin_l_bfgs_b(
                    func=obj,
                    x0=z0,
                    maxfun=maxfun,
                    disp=False,
                    factr=1e7,
                )
            except Exception as e:          # pragma: no cover
                print(f"  L‑BFGS failed at β={beta}: {e}")
                break

            cand = _softmax(z_opt)
            real_score = _eval_fast(cand, L_fft)
            if real_score < best_score:
                best_score = real_score
                best_seq = cand.copy()
                print(f"[{time.time() - start_time:.2f}s] β={beta:.1f} → "
                      f"improved score={real_score:.6f}")

            z0 = z_opt        # warm‑start next temperature

    # ------------------------------------------------------------------
    # 3️⃣  Random restarts (short L‑BFGS runs with jitter)
    # ------------------------------------------------------------------
    restarts = 3
    for r in range(restarts):
        if time.time() >= deadline - 200:
            break
        rng = np.random.default_rng(seed + r + 12345)
        noisy = best_seq + rng.normal(scale=0.01, size=n)
        noisy = np.maximum(noisy, 0.0)
        noisy /= noisy.sum()
        z0 = np.log(np.maximum(noisy, 1e-12))
        beta = 5.0
        obj = _SurrogateMax(n=n, beta=beta,
                            L_conv=_next_pow2(2 * n - 1),
                            L_corr=_next_pow2(3 * n - 2))
        try:
            z_opt, f_val, info = scipy.optimize.fmin_l_bfgs_b(
                func=obj,
                x0=z0,
                maxfun=500,
                disp=False,
                factr=1e7,
            )
        except Exception:  # pragma: no cover
            continue
        cand = _softmax(z_opt)
        real_score = _eval_fast(cand, L_fft)
        if real_score < best_score:
            best_score = real_score
            best_seq = cand.copy()
            print(f"[{time.time() - start_time:.2f}s] restart {r+1}/{restarts} "
                  f"improved score={real_score:.6f}")

    # ------------------------------------------------------------------
    # 4️⃣  Final targeted hill‑climb (exact objective)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        a_hc, sc_hc = _targeted_hill_climb(best_seq,
                                           L_fft,
                                           deadline,
                                           start_time)
        if sc_hc < best_score:
            best_score = sc_hc
            best_seq = a_hc.copy()
            print(f"[{time.time() - start_time:.2f}s] final hill‑climb "
                  f"score={sc_hc:.6f}")

    # ------------------------------------------------------------------
    # Post‑process: enforce non‑negativity, normalise to unit sum
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ "
          f"{best_score:.6f}")
    return [float(v) for v in best_seq]
```
