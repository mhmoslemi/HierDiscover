The goal is to minimise  

\[
E(a)=\frac{2\,n\,\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a*a` is the self‑convolution of the non‑negative step heights `a`.  
Because the expression is invariant under scaling we may (and do) enforce
\(\sum_i a_i = 1\); then minimising `E` is equivalent to minimising the
maximum entry of the convolution.

The algorithm below is a *projected Adam optimiser* that works on the
simplex.  The non‑smooth `max` is replaced by a softmax (temperature
parameter τ) which yields a smooth surrogate

\[
F_\tau(a)=\sum_k w_k(a)\,(a*a)_k,
\qquad
w_k(a)=\frac{\exp\!\bigl((a*a)_k/\tau\bigr)}
         {\sum_j\exp\!\bigl((a*a)_j/\tau\bigr)} .
\]

For τ → 0 the weighted sum converges to the true maximum, while a larger τ
gives a smoother landscape that is easier to optimise.  τ is annealed
linearly from `τ_start` to `τ_end`.

The gradient of the weighted sum can be written as a *cross‑correlation*
between the current vector `a` and the weight vector `w`.  Using FFTs both
the convolution required for the objective and the cross‑correlation for the
gradient are computed in \(O(n\log n)\) time.

A usual Adam step is taken, followed by Euclidean projection onto the
probability simplex (`proj_simplex`).  To avoid stagnation we occasionally
perform a random “mass‑transfer’’ move and, if there has been no improvement
for several seconds, we re‑initialise from the best solution found so far
plus a small random perturbation.

The whole search runs for the allotted time budget (≈ 1000 s) and returns
the best sequence encountered.

```python
"""
Propose a low‑value step‑function sequence.

The algorithm is a projected Adam optimiser on the simplex.
The non‑smooth max‑operator in the objective is replaced by a softmax
with an annealed temperature τ.  The gradient of the softened objective
is a cross‑correlation a ⋆ w and is obtained via a single FFT per
iteration (plus the FFT for the self‑convolution).  Random mass‑transfer
moves and occasional re‑initialisation from the current best help to
escape plateaus.  The code respects the 1000 s time budget and returns the
best sequence found.
"""

import numpy as np
import time

# ----------------------------------------------------------------------
def fast_score(a: np.ndarray) -> float:
    """
    Fast version of `evaluate_sequence` (no safety checks).
    Assumes a is non‑negative, 1‑D and already normalised to sum = 1.
    Returns the same value as `evaluate_sequence`.
    """
    n = a.size
    s = a.sum()
    if s < 1e-12:
        return np.inf
    # length of full convolution
    conv_len = 2 * n - 1
    size = 1 << ((conv_len - 1).bit_length())   # next power of two
    fft_a = np.fft.rfft(a, size)
    conv = np.fft.irfft(fft_a * fft_a, size)[:conv_len]
    max_b = conv.max()
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
def proj_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex:
        {x | x_i ≥ 0, Σ x_i = 1}
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fallback – uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def build_power_law(n: int, p: float = 0.5, offset: float = 0.0) -> np.ndarray:
    """a_i ∝ (i+offset)^{-p}, normalised to sum = 1."""
    idx = np.arange(1, n + 1, dtype=np.float64) + offset
    a = 1.0 / np.power(idx, p)
    total = a.sum()
    if total == 0.0:
        a = np.full(n, 1.0 / n)
    else:
        a /= total
    return a


# ----------------------------------------------------------------------
def build_linear_descending(n: int) -> np.ndarray:
    """Linearly decreasing shape a_i = (n-i) (i=0..n‑1) normalised to sum = 1."""
    a = np.arange(n, 0, -1, dtype=np.float64)
    a /= a.sum()
    return a

        w = np.exp((conv - max_conv) / tau)
        w_sum = w.sum()
        if w_sum > 0.0:
            w /= w_sum
        else:
            w.fill(1.0 / w.size)

        # ----------------------------------------------------------
        # c) gradient of the smoothed objective:
        #    grad_j = 2 * Σ_i a_i * w_{i+j}
        w_rev = w[::-1]
        fft_w_rev = np.fft.rfft(w_rev, fft_len)
        grad_full = np.fft.irfft(fft_a * fft_w_rev, fft_len)
        # indices (2n‑2)‑j give the required cross‑correlation
        idx = (2 * n - 2) - np.arange(n)
        grad = 2.0 * grad_full[idx]

        # ----------------------------------------------------------
        # d) Adam update on the simplex (project after the step)
        it += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = base_lr * m_hat / (np.sqrt(v_hat) + eps)
        a_candidate = proj_simplex(a - step)

        # ----------------------------------------------------------
        # e) occasional random mass‑transfer move (helps to escape plateaus)
        if np.random.rand() < rand_move_prob:
            i, j = np.random.randint(0, n, size=2)
            if i != j and a[i] > 1e-12:
                transfer = rand_move_frac * a[i] * np.random.rand()
                cand = a.copy()
                cand[i] -= transfer
                cand[j] += transfer
                cand = proj_simplex(cand)

                # cheap evaluation (reuse FFTs would be a micro‑optimisation)
                fft_c = np.fft.rfft(cand, fft_len)
                conv_c = np.fft.irfft(fft_c * fft_c, fft_len)[:conv_len]
                cand_val = 2.0 * n * conv_c.max()

                if cand_val < best_val_global:
                    best_val_global = cand_val
                    best_seq_global = cand.copy()
                    a_candidate = cand
                    last_improve = time.time()
                elif np.random.rand() < 0.001:   # very occasional uphill
                    a_candidate = cand

        # ----------------------------------------------------------
        # f) accept the candidate (always keep feasibility)
        a = a_candidate

        # ----------------------------------------------------------
        # g) stagnation handling – re‑seed from best + tiny noise
        if time.time() - last_improve > stagnation_time:
            noise = np.random.rand(n)
            noise /= noise.sum()
            a = proj_simplex(0.9 * best_seq_global + 0.1 * noise)
            m.fill(0.0)
            v.fill(0.0)
            last_improve = time.time()

        # ----------------------------------------------------------
        # h) periodic progress report
        if it % 3000 == 0:
            print(f"[iter {it:7d}] cur {cur_val:.6f}  best {best_val_global:.6f}")

    # --------------------------------------------------------------
    print(f"[final] best value after {it} iterations: {best_val_global:.6f}")
    # The external checker normalises the sequence, so we can return it as‑is.
    return best_seq_global.tolist()
```
