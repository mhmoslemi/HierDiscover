assistantfinal**Solution Explanation**

The score to minimise is  

\[
\text{score}(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a*a` is the full discrete self‑convolution of the non‑negative vector `a`.  
Because the score is *scale‑invariant* we may (and do) normalise the vector
to unit `ℓ¹`‑norm (`∑ a_i = 1`).  After normalisation the score simplifies to  

\[
\text{score}(a)=2\,n\;\max_k (a*a)_k .
\]

The optimisation problem therefore is:

*choose `a_i ≥ 0`, `∑ a_i = 1` such that the maximal convolution entry
is as small as possible.*

--------------------------------------------------------------------

### 1.  Geometry of the objective  

For a given `a` the convolution values are  

\[
c_k = (a*a)_k = \sum_i a_i a_{k-i}.
\]

If we change `a` a little, the variation of a single entry `c_k` is  

\[
\frac{\partial c_k}{\partial a_j}=2\,a_{k-j}\qquad (0\le j < n).
\]

Hence the gradient of a **weighted** sum of the entries is a simple
cross‑correlation between `a` and the weight vector.

--------------------------------------------------------------------

### 2.  Smooth approximation of the “max”  

The max is replaced by a soft‑max with temperature `β`  

\[
w_k = \frac{\exp\bigl(\beta\,c_k\bigr)}
            {\sum_\ell \exp\bigl(\beta\,c_\ell\bigr)} .
\]

When `β` is small the weights are almost uniform (the objective behaves like
the `ℓ¹`‑norm of the convolution); when `β` grows they concentrate on the
largest entries.  By slowly increasing `β` we obtain a homotopy from a
well‑behaved smooth problem to the original non‑smooth one.

--------------------------------------------------------------------

### 3.  Gradient of the soft‑max objective  

The objective we minimise at a fixed `β` is  

\[
F(a) = \sum_k w_k\,c_k .
\]

Using the formula for `∂c_k/∂a_j` we get  

\[
\frac{\partial F}{\partial a_j}
   = \sum_k w_k\,2\,a_{k-j}
   = 2\,\bigl(w \star a\bigr)_j ,
\]

where `⋆` denotes the (full) **cross‑correlation**.
The correlation can be evaluated in `O(n log n)` time with a single FFT:

```python
def correlation_fft(x, y):
    """full linear cross‑correlation (x ⋆ y) using real FFTs"""
    m = len(x) + len(y) - 1               # length of the result
    X = np.fft.rfft(x, n=m)
    Y = np.fft.rfft(y, n=m)
    return np.fft.irfft(np.conj(X) * Y, n=m)
```

Thus the gradient is cheap to obtain.

--------------------------------------------------------------------

### 4.  Optimisation algorithm  

* **Initial point** – we start from the best power‑law vector known from the
  previous run (`p≈0.503, offset≈0.5`).  If the global variable
  `height_sequence_1` exists we use it (truncated/padded to the chosen length).

* **Projected Adam** – the gradient is fed to the Adam optimiser
  (first‑ and second‑moment estimates).  After each raw Adam step the vector
  is projected onto the probability simplex (`ℓ¹`‑norm = 1, non‑negative)
  with the standard Euclidean projection.  This guarantees feasibility.

* **Homotopy on β** – `β` starts very small (`0.5`) and is increased
  gradually (`β ← min(β+β_inc, β_max)`).  The schedule lets the optimiser
  first move in a smooth landscape and later focus on the true peak.

* **Multi‑restart** – the whole inner optimisation is executed several
  times (default 5).  Apart from the first run, the start vector is drawn from
  a sparse Dirichlet (`Gamma(0.7)`) to explore different basins.

* **Random jitter** – every few thousand iterations a tiny random redistribution
  of mass is added; this helps to escape flat plateaus.

* **Time bound** – the routine monitors the wall‑clock time and stops a
  little before the given budget (`budget_s‑5 s`).  The best vector seen so
  far is returned.

--------------------------------------------------------------------

### 5.  Why this should beat the previous score  

* The previous code used only the *top‑K* convolution entries in the gradient;
  our gradient incorporates **all** entries (soft‑max weighting).  This yields a
  much more balanced descent direction and prevents the optimiser from
  over‑fitting to a few peaks.

* Adam’s adaptive step‑size together with the simplex projection gives a
  more robust handling of the highly non‑convex landscape than a plain fixed‑step
  projected gradient descent.

* The homotopy on `β` starts from a globally smooth problem and ends at the
  true objective, a strategy that is known to improve final quality for max‑type
  problems.

* Multiple restarts and occasional jitter increase the chance of finding a
  better basin of attraction.

All these ingredients are cheap (FFT‑based convolution/correlation) and fit
comfortably into the 1000‑second budget.

"""
Propose a step‑function (non‑negative vector) that minimises

    score = 2·n·max(conv(a,a)) / (sum(a)^2)

using a multi‑restart projected Adam optimiser.
The gradient of a soft‑max approximation of the max‑convolution is computed
by an FFT‑based cross‑correlation, guaranteeing O(n log n) per iteration.
A homotopy on the soft‑max temperature β, occasional random jitter and simplex
projection keep the search stable and allow it to improve on the previous
state‑of‑the‑art score (~1.520).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities ------------------------------------------------------
def power_law_sequence(n: int, p: float, offset: float = 1.0) -> np.ndarray:
    """a_i = (i+offset)^(-p), normalised to unit L1‑norm."""
    i = np.arange(n, dtype=np.float64)
    a = (i + offset) ** (-p)
    total = a.sum()
    if total == 0.0:
        a[:] = 1.0 / n
    else:
        a /= total
    return a


def conv_fft(x: np.ndarray) -> np.ndarray:
    """Full self‑convolution x*x using a real FFT."""
    n = x.shape[0]
    m = 2 * n - 1
    X = np.fft.rfft(x, n=m)
    return np.fft.irfft(X * X, n=m)


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto {w ≥ 0, Σ w = 1}."""
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    return np.maximum(v - theta, 0.0)


def correlation_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full linear cross‑correlation (x ⋆ y) using real FFTs."""
    m = len(x) + len(y) - 1
    X = np.fft.rfft(x, n=m)
    Y = np.fft.rfft(y, n=m)
    return np.fft.irfft(np.conj(X) * Y, n=m)


def softmax_gradient(a: np.ndarray, conv: np.ndarray, beta: float) -> np.ndarray:
    """
    Gradient of the soft‑max weighted convolution sum:
        F(a) = Σ_k w_k c_k ,  w_k ∝ exp(beta * c_k)

    Returns   ∂F/∂a  (shape = a.shape)
    """
    max_c = conv.max()
    w = np.exp(beta * (conv - max_c))
    w_sum = w.sum()
    if w_sum == 0.0:
        w = np.full_like(w, 1.0 / w.size)
    else:
        w /= w_sum

    # ∂F/∂a = 2 * (w ⋆ a)   (first n entries of the correlation)
    corr = correlation_fft(w, a)        # length = len(w)+len(a)-1
    grad = 2.0 * corr[: a.shape[0]]
    return grad

    # ------------------------------------------------------------------

    deadline = time.time() + budget_s - 5.0     # safety margin

    try:

        init = np.array(height_sequence_1, dtype=np.float64)

            if init.shape[0] > n:
                init = init[:n]
            else:

        init = np.maximum(init, 0.0)
        init /= init.sum()
        a0 = init.copy()
    except Exception:

        a0 = power_law_sequence(n, p=0.503, offset=0.5)

    # ------------------------------------------------------------------
    # bookkeeping
    best_a = a0.copy()
    best_score = 2.0 * n * conv_fft(best_a).max()
    print(f"[init] score = {best_score:.6f}")

    # Adam hyper‑parameters
    lr = 0.02               # base learning rate
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8

    # soft‑max temperature schedule
    beta = 0.5
    beta_max = 10.0
    beta_inc = 0.0007       # increase per iteration

    # other controls

            a = best_a.copy()
        else:

            a /= a.sum()

        # Adam state
        m = np.zeros_like(a)
        v = np.zeros_like(a)

                    conv = new_conv

            beta = min(beta + beta_inc, beta_max)
