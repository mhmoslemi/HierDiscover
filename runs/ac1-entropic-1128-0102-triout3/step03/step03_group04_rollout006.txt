The goal is to find a non‑negative vector `a` (length `n`) that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a*a` is the *linear* self‑convolution (no reversal).  
Because the score is homogeneous, we may enforce `∑a_i = 1` during the whole search and simply minimise  

\[
f(a)=2\,n\;\max_k (a*a)_k .
\]

The routine below consists of three independent phases:

1. **Very‑wide parametric sweep** – candidates of the form  

   \[
   a_i \propto (i+{\rm offset})^{-p}\;e^{-\,\alpha i},
   \]

   are generated for many triples *(p, offset, α)*, normalised to unit‑sum and evaluated
   with a cheap `2·n·max(conv)` formula.

2. **Fine sweep** – a tighter grid around the best triple from phase 1.

3. **Projected Adam optimisation** – starting from the best candidate (and a few random restarts) we minimise a *smooth* approximation of the objective.  
   For a temperature `β` the soft‑max  

   \[
   w_k=\frac{e^{\beta (c_k-\max c)}}{\sum_j e^{\beta (c_j-\max c)}},
   \qquad c=a*a,
   \]

   approximates the indicator of the maximal entry.  
   The gradient of the smoothed objective is

   \[
   \nabla f_\beta(a)=
   2\;\bigl(w * a^{\mathrm{rev}}\bigr)_{\,n-1\ldots n-1+n-1},
   \]

   i.e. a convolution of the weight vector `w` with the reversed `a`.  
   The gradient is obtained with a single FFT, then an Adam step is taken
   and the vector is projected back onto the probability simplex
   (`∑a_i = 1, a_i ≥ 0`).  
   `β` is increased gradually (the approximation becomes sharper) and the
   learning‑rate decays.  The best vector ever seen is stored globally.

All loops respect a user supplied time‑budget (default ≈ 950 s).  
At the end the vector is fed to the official `evaluate_sequence`
function and returned.

```python
# -*- coding: utf-8 -*-
"""
Propose a step‑function that minimises
    score = 2·n·max(conv(a,a)) / (sum(a)^2)

Algorithm
---------
1. Broad parametric sweep (power‑law × exponential) → keep the best.
2. Fine grid around the best parameters.
3. Several Adam‑based projected gradient runs (including a random‑restart
   and, if available, the previously found global vector `height_sequence_1`).
   The Adam update uses the full soft‑max weighted gradient,
   computed with a single FFT, and the iterate is projected onto the
   probability simplex after each step.

The routine respects a ~950 s internal budget and prints progress.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities ------------------------------------------------------
# ----------------------------------------------------------------------


def full_convolution(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Full discrete convolution of two real vectors using a real FFT.
    Result length = len(x) + len(y) - 1.
    """
    n, m = x.size, y.size
    size = n + m - 1
    # next power of two for speed
    fft_len = 1 << (size - 1).bit_length()
    X = np.fft.rfft(x, n=fft_len)
    Y = np.fft.rfft(y, n=fft_len)
    conv = np.fft.irfft(X * Y, n=fft_len)[:size]
    return conv


def power_law_exp_sequence(
    n: int, p: float, offset: float = 1.0, alpha: float = 0.0
) -> np.ndarray:
    """
    a_i ∝ (i + offset)^{-p} · exp(-α·i)  (i = 0 … n‑1), finally normalised
    to unit L1‑norm.
    """
    i = np.arange(n, dtype=np.float64)
    a = (i + offset) ** (-p)
    if alpha != 0.0:
        a *= np.exp(-alpha * i)
    s = a.sum()
    if s == 0.0:          # fallback – very unlikely
        a[:] = 1.0 / n
    else:
        a /= s
    return a


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    { w ≥ 0, Σ w = 1 }.
    """
    v = np.asarray(v, dtype=np.float64)
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def softmax_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """
    Soft‑max of the convolution entries with temperature 1/β.
    The maximal entry receives weight 1, the others are scaled
    exponentially and finally normalised to sum‑1.
    """
    max_val = conv.max()
    # shift by max to avoid overflow
    w = np.exp(beta * (conv - max_val))
    w_sum = w.sum()
    if w_sum == 0.0:
        return np.full_like(w, 1.0 / w.size)
    return w / w_sum


def weighted_gradient(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the soft‑max weighted objective.
    Gradient_i = 2 * Σ_j a_j * w_{i+j}.
    Computed efficiently via a single convolution.
    """
    # a_rev = a reversed, required for the index alignment explained in the analysis
    a_rev = a[::-1]
    conv = full_convolution(w, a_rev)          # length = len(w) + n - 1 = 3n-2
    n = a.size
    # slice the part that corresponds to indices 0 … n‑1
    grad = 2.0 * conv[n - 1 : n - 1 + n]
    return grad


def fast_score(a: np.ndarray) -> float:
    """
    Fast (approximate) score used during the search.
    The vector is already normalised to unit sum, therefore the denominator is 1.
    """
    n = a.size
    conv = full_convolution(a, a)
    return 2.0 * n * conv.max()


# ----------------------------------------------------------------------
# Main search routine ---------------------------------------------------
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: float = 950.0) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises the official
    evaluation score.  The function respects a runtime budget and returns the
    best sequence found (as a plain Python list).
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0          # small safety margin

    # ------------------------------------------------------------------
    # 0) Determine the vector length ‑‑ use the length of the historical
    #    best if it exists, otherwise fall back to 2500.
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        try:
            n = len(height_sequence_1)
            a0 = np.asarray(height_sequence_1, dtype=np.float64)
            if a0.sum() == 0.0:
                a0 = np.ones(n) / n
            else:
                a0 = a0 / a0.sum()
        except Exception:
            n = 2500
            a0 = None
    else:
        n = 2500
        a0 = None

    print(f"[info] vector length set to n = {n}")

    # ------------------------------------------------------------------
    # 1) Very‑wide parametric sweep (power‑law × exponential)
    # ------------------------------------------------------------------
    best_a = None
    best_score = np.inf
    best_params = None

    p_vals = np.arange(0.20, 1.21, 0.05)          # coarse range
    offset_vals = np.arange(0.1, 5.1, 0.3)
    alpha_vals = np.array([0.0, 0.005, 0.010, 0.015, 0.020])

    print("[search] phase 1 – very wide parametric sweep")
    for offset in offset_vals:
        for p in p_vals:
            for alpha in alpha_vals:
                if time.time() > deadline:
                    break
                cand = power_law_exp_sequence(n, p, offset=offset, alpha=alpha)
                cur = fast_score(cand)
                if cur < best_score:
                    best_score = cur
                    best_a = cand.copy()
                    best_params = (p, offset, alpha)
                    print(f"[grid] new best: p={p:.3f}, off={offset:.2f}, α={alpha:.3f} → {cur:.6f}")

    # ------------------------------------------------------------------
    # 2) Fine sweep around the currently best triple
    # ------------------------------------------------------------------
    if best_params is not None:
        p0, off0, a0_alpha = best_params
        p_fine = np.arange(max(0.01, p0 - 0.02), min(1.5, p0 + 0.02) + 1e-9, 0.002)
        off_fine = np.arange(max(0.0, off0 - 0.5), off0 + 0.5 + 1e-9, 0.02)
        alpha_fine = np.arange(max(0.0, a0_alpha - 0.006), a0_alpha + 0.006 + 1e-9, 0.001)

        print("[search] phase 2 – fine sweep")
        for offset in off_fine:
            for p in p_fine:
                for alpha in alpha_fine:
                    if time.time() > deadline:
                        break
                    cand = power_law_exp_sequence(n, p, offset=offset, alpha=alpha)
                    cur = fast_score(cand)
                    if cur < best_score:
                        best_score = cur
                        best_a = cand.copy()
                        best_params = (p, offset, alpha)
                        print(f"[fine] new best: p={p:.4f}, off={offset:.3f}, α={alpha:.4f} → {cur:.6f}")

    # ------------------------------------------------------------------
    # 3) ADAM based projected gradient descent (multiple restarts)
    # ------------------------------------------------------------------
    print("[optim] phase 3 – projected Adam optimisation")
    max_restarts = 6
    max_iter_per_restart = 200_000            # hard cap; real number limited by time
    beta_start = 1.0
    beta_inc = 0.0005                         # increase per 1000 iterations
    lr_start = 0.08
    lr_decay = 0.85
    decay_every = 5000

    global_best_a = best_a if best_a is not None else np.full(n, 1.0 / n)
    global_best_score = fast_score(global_best_a)

    for restart in range(max_restarts):
        if time.time() > deadline:
            break

        # initialise a – first restart uses the best candidate,
        # others are random Dirichlet draws (slightly sparse)
        if restart == 0 and best_a is not None:
            a = best_a.copy()
        elif restart == 0 and a0 is not None:
            a = a0.copy()
        else:
            a = rng.gamma(0.7, 1.0, size=n)
            a /= a.sum()

        cur_score = fast_score(a)
        lr = lr_start
        beta = beta_start

        it = 0
        while time.time() < deadline and it < max_iter_per_restart:
            # --- compute convolution and soft‑max weights
            conv = full_convolution(a, a)
            w = softmax_weights(conv, beta)

            # --- gradient (full weighted version)
            grad = weighted_gradient(a, w)

            # --- Adam bookkeeping
            if it == 0:
                m = np.zeros_like(a)
                v = np.zeros_like(a)
            m = 0.9 * m + 0.1 * grad
            v = 0.999 * v + 0.001 * (grad ** 2)

            m_hat = m / (1.0 - 0.9 ** (it + 1))
            v_hat = v / (1.0 - 0.999 ** (it + 1))

            step = lr * m_hat / (np.sqrt(v_hat) + 1e-8)

            # keep the step modest (never flip sign of an entry)
            step = np.minimum(step, a * 0.95)

            a_trial = a - step

            # occasional tiny random jitter (helps escaping flat plateaus)
            if rng.random() < 0.003:
                a_trial += (rng.random(n) - 0.5) * 1e-6

            # projection back onto the simplex (preserves non‑negativity & unit sum)
            a_trial = project_onto_simplex(a_trial)

            trial_score = fast_score(a_trial)

            # bookkeeping of the globally best vector
            if trial_score < global_best_score:
                global_best_score = trial_score
                global_best_a = a_trial.copy()
                print(
                    f"[restart {restart} iter {it:07d}] global best = {global_best_score:.6f}"
                )

            # accept the trial if it improves the *local* score,
            # otherwise keep the current iterate (no Metropolis step – Adam already handles noise)
            if trial_score <= cur_score:
                a = a_trial
                cur_score = trial_score
            else:
                # even if not improving we still keep the Adam‑updated moments
                # – this is the standard Adam behaviour
                a = a_trial
                cur_score = trial_score

            # schedule updates
            if (it + 1) % decay_every == 0:
                lr = max(lr * lr_decay, 1e-6)
                beta += beta_inc * decay_every / 1000.0   # roughly +0.5 per 1000 iter

            it += 1

        print(f"[restart {restart}] finished – local best score = {cur_score:.6f}")

    # ------------------------------------------------------------------
    # 4) Final verification with the official evaluator
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(global_best_a.tolist())
    print(f"[done] final reported score = {final_score:.6f}")
    if best_params is not None:
        p, off, al = best_params
        print(f"[info] best parametric seed: p={p:.5f}, offset={off:.3f}, α={al:.5f}")

    return global_best_a.tolist()
```
