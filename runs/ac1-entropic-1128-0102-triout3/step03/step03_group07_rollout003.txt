The objective of `evaluate_sequence` is  

\[
\text{score}= \frac{2\,n\,\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the auto‑convolution of the non‑negative vector `a`.  
Because the score is *scale invariant* we may fix the normalization  

\[
\sum_{i} a_i = 1 .
\]

Under this normalization the score simplifies to  

\[
\text{score}=2n\;M,\qquad M=\max (a*a).
\]

Hence the whole problem is to **minimise the ℓ∞‑norm of the auto‑convolution** while keeping `a` a probability vector.

The programme below implements the classic *alternating linear‑program* method:

1. **Current vector `f`.** Compute its convolution peak `M`.  
2. **Linear program.**  
   Maximise the total mass `∑ g_i` subject to  

   \[
   (f * g)_k \le M\qquad \forall k .
   \]

   The constraints are linear in `g`; the constraint matrix is a Toeplitz matrix whose (constant) diagonal `d` equals `f_d`.  The LP is solved with SciPy’s HiGHS interior‑point solver (`linprog` with a sparse matrix).  
3. **Renormalise.** The LP solution `g⁰` is scaled to a probability vector  

   \[
   g = \frac{g⁰}{\sum g⁰}.
   \]

4. **Update.** Replace the current vector by a convex combination  

   \[
   f_{\text{new}}=(1-t)f + t\,g,
   \]

   with a step size `t` that is adapted automatically.  
5. **Book‑keeping.** Keep the best vector ever seen and restart from a random Dirichlet
   distribution if no improvement occurs for many iterations.

The algorithm runs for the given time budget (≈ 950 s ≈ 16 min).  
All helper functions are top‑level, there are no closures, and the only external
dependency is SciPy (already present in the execution environment).

"""
Linear‑programming alternating optimisation for the auto‑convolution peak.

The algorithm keeps a probability vector `a` (∑a = 1, a_i ≥ 0).
At each iteration it

  * evaluates M = max convolution of a with itself,
  * solves a sparse LP that maximises the total mass of a second vector g
    under the linear constraints (a * g)_k ≤ M,
  * normalises the LP solution to a probability vector,
  * moves a towards g with a step size t (t is increased on success,
    decreased on failure),
  * records the best sequence found and restarts from a random Dirichlet
    distribution after a long stagnation period.

The LP matrix is Toeplitz and built with `scipy.sparse.diags`, so each
iteration costs O(n²) memory but (for n≈2000) fits easily into RAM.
The whole routine respects the 1000 s time limit and returns the best
sequence discovered.
"""

import time
from typing import List

import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog


def half_binomial_series(n: int) -> np.ndarray:
    """First n coefficients of (1‑z)^‑½, normalised to sum 1."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def next_pow_two(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def build_toeplitz_matrix(f: np.ndarray, rows: int) -> sp.csr_matrix:
    """
    Returns the (rows × n) matrix A such that A @ g = f * g (linear convolution)
    for all rows = 2·n‑1.
    Each diagonal d (0 ≤ d < n) is constant f[d].
    """
    n = f.shape[0]
    # data[d] = column vector of length n filled with f[d]
    data = [np.full(n, f[d], dtype=np.float64) for d in range(n)]
    offsets = np.arange(0, n)                # only non‑negative offsets are needed
    A = sp.diags(data, offsets, shape=(rows, n), format="csr")
    return A

    """
    Search for a non‑negative step‑function that minimises the evaluation score.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds (a few seconds are kept as a safety margin).

    Returns
    -------
    List[float]
        The best sequence found, as a plain Python list of floats.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Problem size – 2000 gives a good trade‑off between speed and quality.
    n = 2000
    conv_len = 2 * n - 1
    fft_len = next_pow_two(conv_len)

    # ------------------------------------------------------------------
    # Initialise a either from the known best construction (if provided)
    # or from the classic half‑binomial series.
    if "height_sequence_1" in globals():

        if init.size == 0:
            a = half_binomial_series(n)
        else:
            if init.size > n:
                a = init[:n].copy()
            else:
                a = np.concatenate([init, np.zeros(n - init.size, dtype=np.float64)])
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s < 1e-12:
                a = half_binomial_series(n)
            else:
                a /= s
    else:
        a = half_binomial_series(n)

    # ------------------------------------------------------------------
    # Book‑keeping
    best_a = a.copy()
    # Because we keep ∑a = 1, the score is simply 2·n·max(conv)
    def score_from_a(vec):
        A = np.fft.rfft(vec, n=fft_len)
        conv_full = np.fft.irfft(A * A, n=fft_len)
        M = conv_full[:conv_len].max()
        return 2.0 * n * M, M

    cur_score, cur_M = score_from_a(a)
    best_score = cur_score
    print(f"[init] n={n}, initial score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Optimisation parameters
    t = 0.30                     # initial convex‑combination weight
    t_min = 1e-4
    t_max = 0.80
    stall_limit = 80             # iterations without improvement → restart
    last_improve = 0
    it = 0
    deadline = time.time() + budget_s - 5.0   # safety margin

    while time.time() < deadline:
        # --------------------------------------------------------------
        # 1) build the Toeplitz matrix for the current a (constraints (a*g) ≤ cur_M)
        A_mat = build_toeplitz_matrix(a, conv_len)

        # --------------------------------------------------------------
        # 2) solve LP: maximise ∑g_i  subject to A_mat @ g ≤ cur_M , g ≥ 0
        c = -np.ones(n, dtype=np.float64)           # linprog minimises; –c → maximise sum
        b_ub = np.full(conv_len, cur_M, dtype=np.float64)

        if sum_g0 <= 0.0:

    final_score = evaluate_sequence(best_a.tolist())
