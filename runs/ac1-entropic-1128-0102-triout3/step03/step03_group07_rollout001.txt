assistantfinal**Solution Overview**

The score returned by `evaluate_sequence` is  

\[
\text{score}= \frac{2\,n\,\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the (linear) auto‑convolution of the coefficient vector `a`.  
The score is *scale‑invariant*: if we multiply all entries of `a` by a
constant, both numerator and denominator are multiplied by the same
factor squared and the score does not change.  
Consequently we may **always keep the coefficients normalised to sum = 1**
and minimise only the maximal convolution value

\[
M(a)=\max (a*a) .
\]

The algorithm below is a continuous version of the linear‑programming
procedure described in the statement:

1. **Start** with a known good shape – the half‑binomial series,
   normalised to sum = 1.
2. **Iteratively improve** the shape.
   * For the current vector `a` compute `M = max(a*a)`.
   * Solve the linear program  

     \[
     \max\; \mathbf 1^{\!\top} b\qquad
     \text{s.t.}\; a * b \le M,\; b\ge 0,
     \]

     where `*` denotes convolution.  
     Because convolution is linear in the second argument, the constraints
     are a system of linear inequalities `A b ≤ M`.  `A` is a Toeplitz
     matrix that can be built efficiently with `scipy.linalg.toeplitz`.
   * The LP gives a feasible vector `b` whose sum is larger than 1 (unless
     `a` is already optimal).  Normalise it:
     `g = b / sum(b)`.  `g` still satisfies `a * g ≤ M`.
   * Move a small step toward `g` :

     \[
     a \leftarrow (1-\tau)\,a + \tau\,g,
     \]

     with a step size `τ` that decays geometrically.  This guarantees
     monotone non‑increase of `M`.
3. Keep the best vector ever seen (according to `evaluate_sequence`).
4. When the allotted time is almost exhausted, finish and return the best
   sequence.

The method combines a *global* LP improvement with a *smooth* interpolation,
which quickly drives `M` down while staying inside the feasible region.
It is far more decisive than the pure gradient/annealing approach and,
on modest dimensions (`n≈1000`), fits easily into the 1000 s budget.

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-

"""
Propose a coefficient sequence that minimises
    2·n·max(conv(a,a)) / (sum(a)**2)

The algorithm is an alternating linear‑programming improvement:

* Start with the half‑binomial series (good known shape) normalised to sum = 1.
* Repeatedly:
    - compute M = max(a*a)
    - solve   max 1ᵀb   subject to   a * b ≤ M , b ≥ 0
    - normalise the LP solution to obtain g (sum(g)=1)
    - update a ← (1‑τ)·a + τ·g with a geometrically decaying τ
* Keep the best sequence seen (according to evaluate_sequence).

The LP is solved with scipy.optimize.linprog (highs) and the constraint
matrix is built as a Toeplitz matrix using scipy.linalg.toeplitz.
The whole routine respects a time budget (default 950 s) and returns a
plain list of non‑negative floats.
"""

from __future__ import annotations

import time
from typing import List

import numpy as np
from scipy import linalg
from scipy.optimize import linprog

# The evaluation function is provided by the testing harness.
# from <module> import evaluate_sequence   # assumed to be already in the namespace


def half_binomial_series(n: int) -> np.ndarray:
    """
    First n coefficients of (1‑z)^‑½  (a_i = C(2i,i)/4^i) and normalised
    so that they sum to 1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def build_conv_matrix(a: np.ndarray) -> np.ndarray:
    """
    Build the (2n‑1) × n matrix A such that A @ b = a * b (linear convolution).
    A is a Toeplitz matrix with first column (a followed by zeros) and
    first row (a[0], 0, …, 0).
    """
    n = a.shape[0]
    m = 2 * n - 1
    # first column: a then zeros to length m
    c = np.concatenate([a, np.zeros(m - n, dtype=np.float64)])
    # first row: a[0] followed by zeros (length n)
    r = np.concatenate([np.array([a[0]], dtype=np.float64),
                        np.zeros(n - 1, dtype=np.float64)])
    return linalg.toeplitz(c, r)


def propose_candidate(seed: int = 0, budget_s: float = 950.0, **kwargs) -> List[float]:
    """
    Search for a non‑negative step‑function sequence that minimises the
    provided evaluation function.

    Parameters
    ----------
    seed : int
        Random seed (currently unused, kept for API compatibility).
    budget_s : float
        Time budget in seconds.  The routine stops a few seconds early
        to leave a safety margin.
    kwargs : dict
        Ignored – present only for signature compatibility.

    Returns
    -------
    List[float]
        The best coefficient sequence found (plain Python list).
    """
    # ------------------------------------------------------------------
    # configuration
    rng = np.random.default_rng(seed)

    # Choose a moderate problem size – large enough for a good bound,
    # small enough for fast LP solves.
    n = 1000                     # length of the coefficient vector
    max_iter = 5000             # absolute safety cap
    tau_initial = 0.5           # initial interpolation step size
    tau_min = 1e-5              # stop when step gets tiny
    tau_decay = 0.985           # geometric decay per iteration

    # ------------------------------------------------------------------
    # initialise a with the classic half‑binomial series (already sums to 1)
    a = half_binomial_series(n)

    # keep the best sequence ever produced
    best_seq = a.copy()
    best_score = evaluate_sequence(best_seq.tolist())
    print(f"[init] n={n}, initial score={best_score:.6f}")

    # ------------------------------------------------------------------
    # timing
    deadline = time.time() + budget_s - 5.0   # 5 s safety margin
    it = 0
    tau = tau_initial

    # ------------------------------------------------------------------
    while time.time() < deadline and it < max_iter and tau > tau_min:
        # ---------- 1) compute current max auto‑convolution ----------
        conv_aa = np.convolve(a, a)
        M = conv_aa.max()

        # ---------- 2) build the linear‑programming constraint matrix ----------
        A = build_conv_matrix(a)          # shape (2n‑1, n)
        m = A.shape[0]                    # equals 2*n-1

        # ---------- 3) solve   max sum(b)   s.t.   A b ≤ M , b ≥ 0 ----------
        c_obj = -np.ones(n, dtype=np.float64)        # linprog minimises cᵀx
        b_ub = np.full(m, M, dtype=np.float64)

        # bounds for each variable: b_i ≥ 0 , no upper bound
        bounds = [(0.0, None)] * n

        # solve with HiGHS (fast, robust)
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True})
        if not res.success:
            # If the LP fails, fall back to a tiny random perturbation
            print(f"[iter {it:06d}] LP failed ({res.message}). Applying perturbation.")
            perturb = rng.normal(scale=1e-4, size=n)
            a = np.maximum(a + perturb, 0.0)
            a /= a.sum()
            it += 1
            continue

        b = res.x
        sum_b = b.sum()
        if sum_b <= 0.0:
            # Degenerate solution – abort LP‑driven phase
            print(f"[iter {it:06d}] LP returned zero sum; exiting LP loop.")
            break

        # ---------- 4) obtain the feasible direction g ----------
        g = b / sum_b   # now sum(g) == 1 and a * g ≤ M

        # ---------- 5) interpolate towards g ----------
        a = (1.0 - tau) * a + tau * g
        # Numerical safety: enforce non‑negativity and renormalise
        a = np.maximum(a, 0.0)
        a_sum = a.sum()
        if a_sum > 0.0:
            a /= a_sum

        # ---------- 6) evaluate and keep the best ----------
        cur_score = evaluate_sequence(a.tolist())
        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[iter {it:06d}] new best score = {best_score:.6f}")

        # ---------- 7) schedule the step size ----------
        tau = max(tau * tau_decay, tau_min)

        it += 1

        # occasional cheap cheap random shake‑up to avoid stagnation
        if (it % 300) == 0 and rng.random() < 0.02:
            shake = rng.uniform(-1e-3, 1e-3, size=n)
            a = np.maximum(a + shake, 0.0)
            a /= a.sum()

    # ------------------------------------------------------------------
    # final reporting
    final_score = evaluate_sequence(best_seq.tolist())
    print(f"[done] iterations={it}, best reported score={final_score:.6f}")

    # Return a plain Python list as required by the harness
    return best_seq.tolist()
```
