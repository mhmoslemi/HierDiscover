Propose a candidate step‑function.

The routine follows a two‑phase scheme:

1. **Multi‑scale mirror descent** –  the current best shape (or a random
   simplex point) is linearly interpolated up to a target length
   (≈5000).  On the final size the vector is treated as a probability
   distribution and updated by an exponentiated‑gradient (mirror‑descent)
   step that uses the exact sub‑gradient of the objective
   `max(conv(p,p))`.  The step‑size decays as 1/√t and a relatively
   large active set (up to 20 indices close to the convolution maximum)
   is used to obtain a stable descent direction.

2. **Targeted simulated‑annealing** – after the gradient phase a
   temperature‑controlled hill‑climbing moves a small fraction of mass
   from indices that directly contribute to the current maximal
   convolution entry to a random destination.  Moves that improve the
   objective are always accepted; worsening moves are accepted with a
   probability that decays with the temperature.

Both phases keep the best sequence ever seen.  The final sequence is
renormalised to sum to one (scaling does not change the objective) and
returned as a plain list of Python floats.

def _conv_and_max(a: np.ndarray):
    """
    Compute the full auto‑convolution of a (using FFT) and return the
    convolution array together with its maximum value.
    """
    n = a.shape[0]
    # length of the FFT – the next power of two ≥ 2*n‑1
    fft_len = 1 << ((2 * n - 1).bit_length())
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)[: 2 * n - 1]
    return conv, conv.max()


def _active_indices(conv: np.ndarray, max_val: float,
                    rel_eps: float = 0.001, max_add: int = 8):
    """
    Return a small set of convolution indices that are (almost) maximal.
    All indices with value ≥ max_val·(1‑rel_eps) are taken; if there are
    fewer than ``max_add`` such indices the globally largest ones are
    added to reach ``max_add``.
    """
    eps = max_val * rel_eps
    K = np.where(conv >= max_val - eps)[0]
    if K.size < max_add:
        # add top‑k indices (might duplicate some already present)
        topk = min(max_add, conv.shape[0])
        more = np.argpartition(conv, -topk)[-topk:]
        K = np.unique(np.concatenate([K, more]))
    return K


def _gradient_active(a: np.ndarray, K: np.ndarray):
    """
    Sub‑gradient of ``max(conv(a,a))`` w.r.t. the active set K.
    For each active convolution index k we add 2·a_{k‑i} to the i‑th
    component (if the index is in range).  The result is a dense vector.
    """
    n = a.shape[0]
    g = np.zeros_like(a)
    for k in K:
        low = max(0, k - (n - 1))
        high = min(n - 1, k)
        i_idx = np.arange(low, high + 1, dtype=int)
        j_idx = k - i_idx
        # each contribution is 2·a[j_idx]
        g[i_idx] += 2.0 * a[j_idx]
    return g


def _score_of_seq(a: np.ndarray) -> float:
    """
    Objective value for a probability vector a (i.e. sum(a)=1):
        2·n·max(conv(a,a))
    """
    n = a.shape[0]
    _, max_val = _conv_and_max(a)
    return float(2.0 * n * max_val)
