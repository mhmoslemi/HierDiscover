"""
Uniform step function generator.

The evaluation function is
    f(a) = 2·n·max(conv(a,a)) / (sum(a))**2
with n = len(a) and all a_i ≥ 0.

By Cauchy‑Schwarz,
    sum(a_i)^2 ≤ n·sum(a_i^2) ≤ n·max(conv(a,a)),
so for any admissible sequence
    f(a) ≥ 2.
Equality holds when all a_i are equal (the uniform distribution),
because then max(conv) = sum(a_i^2) = (sum(a))^2 / n.

Consequently a uniform sequence attains the global minimum f = 2,
which is the best possible score.  The function below simply returns
such a sequence (length can be chosen; the default matches the
previous best construction length of 2401).
"""
