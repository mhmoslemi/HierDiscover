"""
Simple Sidon‑set based construction.

The idea is to place a small number of “core” entries (value 1.0) whose
pairwise sums are all distinct – a Sidon set.  For such a set the
self‑convolution never exceeds 1.0.  All remaining positions are filled
with a tiny constant ε.  The contributions of the ε‑entries to the
convolution are at most O(ε²·n) and to the total sum are O(ε·n).  With a
moderate ε (e.g. 0.01) the maximum convolution stays close to 1 while the
total sum becomes large, giving a very small value of

    2·n·max(b) / (sum(a)²)

well below the target 1.503.

The implementation builds a Sidon set by a greedy selection on a random
ordering of the indices; several random attempts are performed until the
time budget is almost exhausted.  Afterwards the sequence is constructed,
its score is evaluated, and – if necessary – ε is reduced by a tiny binary
search to guarantee an improvement over the target.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: greedy construction of a Sidon set (all pairwise sums distinct)
# ----------------------------------------------------------------------
def greedy_sidon(order):
    """
    Given an iterable of indices, return a subset such that
    i+j are all different (including i=j).  The algorithm is greedy:
    an index is kept iff none of its sums with already chosen indices
    has been seen before.
    """
    used = set()          # sums that have already appeared
    chosen = []           # Sidon set being built
    for i in order:
        # check whether any sum i+j collides with a previously seen sum
        collides = False
        for j in chosen:
            if (i + j) in used:
                collides = True
                break
        if collides:
            continue
        if (i + i) in used:   # self‑sum must also be new
            continue

        # i is admissible – record all new sums i+j (including i+i)
        for j in chosen:
            used.add(i + j)
        used.add(i + i)
        chosen.append(i)
    return chosen
