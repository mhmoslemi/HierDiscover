The function  

```python
evaluate_sequence(sequence) = 2·n·max(convolve(sequence,sequence)) /
                              (sum(sequence) ** 2)
```  

is homogeneous – scaling the whole sequence does not change the value.
For a non‑negative vector `a` of length `n`

```
max(convolve(a,a)) ≥ Σ a_i²                (value at shift 0)
Σ a_i² ≥ ( Σ a_i )² / n                     (Cauchy‑Schwarz)
```

Consequently  

```
evaluate_sequence(a) ≥ 2·n·( Σ a_i² ) / ( Σ a_i )² ≥ 2 .
```

Equality holds **iff** every entry is the same (a uniform step function).  
Therefore the global minimum of the given evaluation function is `2.0`,
and a uniform sequence already attains this optimum.

The proposer below

* builds several uniform sequences of various lengths,
* tries a quick random search –‑ only to demonstrate that any deviation
  from uniformity makes the score larger,
* keeps the best sequence found (which will be uniform with score = 2.0).

The implementation respects all limits (time budget, type checks, etc.) and
does not rely on any external files or network access.

```python
import time
import random
import numpy as np

def propose_candidate(seed: int = 42, budget_s: float = 990, **kwargs):
    """
    Generate a step‑function (list of non‑negative heights) that minimizes
    `evaluate_sequence`.  The mathematical analysis shows that the minimum
    possible value is exactly 2.0 and is achieved by any uniform sequence
    (all entries equal).  This function therefore:

    * evaluates a number of uniform candidates of different lengths,
    * performs a short random search as a sanity check,
    * returns the best sequence found (necessarily uniform with score 2.0).

    The routine respects the 1000 s overall time limit and never raises
    exceptions – invalid candidates are simply ignored.
    """
    # deadline a few seconds before the real limit so that the caller can
    # still finish cleanly
    deadline = time.time() + max(0.0, float(budget_s) - 2.0)

    # Make the result deterministic
    np.random.seed(seed)
    random.seed(seed)

    best_seq = None
    best_score = float("inf")

    # -----------------------------------------------------------------
    # 1) Try uniform sequences – they are provably optimal.
    # -----------------------------------------------------------------
    uniform_lengths = [1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 3401]
    for n in uniform_lengths:
        if time.time() >= deadline:
            break
        # any positive constant works; `1.0` keeps numbers small
        seq = [1.0] * n
        score = evaluate_sequence(seq)
        if score < best_score:
            best_score = score
            best_seq = seq
        print(f"[Uniform] length={n:<5d} → score={score:.12f}")

    # -----------------------------------------------------------------
    # 2) Light‑weight random exploration (mostly to verify that
    #    non‑uniform vectors give a larger score).
    # -----------------------------------------------------------------
    while time.time() < deadline:
        # random length between 100 and 5000
        n = np.random.randint(100, 5000)
        # random values in [0, 1)
        seq = np.random.random(size=n).tolist()

        # Ensure the sum is at least the tiny threshold required by the
        # evaluator – otherwise it would return ``inf``.
        s = sum(seq)
        if s < 0.01:
            # Scale up uniformly; this does not change the ratio.
            factor = 0.01 / max(s, 1e-12)
            seq = [x * factor for x in seq]

        # Evaluate – any exception (e.g. overflow) is caught and ignored.
        try:
            score = evaluate_sequence(seq)
        except Exception:          # pragma: no cover
            continue

        if score < best_score:
            best_score = score
            best_seq = seq
            print(f"[Random]  length={n:<5d} → new best score={score:.12f}")

    # -----------------------------------------------------------------
    # 3) Final report
    # -----------------------------------------------------------------
    print(f"Best score achieved: {best_score:.12f} (should be 2.0)")
    return best_seq
```
