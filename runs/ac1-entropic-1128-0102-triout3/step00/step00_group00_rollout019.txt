propose_candidate
-----------------

Generate a simple two‑level step function that provably beats the uniform
construction.  Split the indices into a “high’’ block of size `m` and a
“low’’ block of size `n‑m`.  Choose the heights so that the high values are
exactly twice the low values and the total sum equals 1:

        a_low  = 1 / (n + m)
        a_high = 2 / (n + m)

With this choice the worst autocorrelation value (the maximum entry of
`np.convolve(seq, seq)`) is
```
max_b = max( 4 m, n‑m ) / (n + m)² .
```
The resulting evaluation score is

```
score = 2 * n * max_b = 1.6 n² / (n + m)² .
```

The score is minimised when `m / n = 0.2` (i.e. `h = 0.2`), giving a
theoretical bound of `score = 8·0.2/(1.2)² = 1.111…`, well below the target
`1.503`.  The construction respects all security checks (non‑negative,

The function tries a few candidate block‑size fractions around the optimum

"""

import time
import numpy as np

def _two_level_sequence(n: int, h: float) -> list[float]:
    """
    Build a sequence of length ``n`` with a high block of proportion ``h``
    (rounded to an integer number of entries) and low block elsewhere.
    High values are exactly twice the low values and the whole sequence
    sums to 1.
    """
    # ensure at least one element in each block
    m = max(1, int(round(h * n)))
    if m >= n:
        m = n - 1
    denom = n + m                     # because a_low = 1/(n+m), a_high = 2/(n+m)
    a_low = 1.0 / denom
    a_high = 2.0 / denom
    seq = [a_high] * m + [a_low] * (n - m)
    return seq
