def project_onto_simplex(v):
    # ensure sum(v) = 1, v_i >= 0
    # using algorithm from https://arxiv.org/pdf/1101.6081.pdf
    # sort descending:
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond].max()
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w

"""
Simple deterministic construction for the step‑function minimisation task.

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `conv` is the discrete (non‑circular) convolution and the sequence
`a` must be non‑negative.  Because the score is homogeneous, scaling the
entire sequence does not change the result.  By choosing a monotone
increasing sequence

    a_i = (i + 1) * λ ,  i = 0 … n‑1

and fixing λ so that the largest entry equals 1000 (the upper bound
enforced by `evaluate_sequence`), the normalised weights become

    w_i = (i + 1) / (n (n + 1) / 2) .

For this distribution the maximal convolution value can be computed in
closed form:

    max(conv(w, w)) = 2 (n + 2) / (3 n (n + 1))

and consequently

    score = 4 (n + 2) / (3 (n + 1)) → 4/3 ≈ 1.333...

as n grows.  Even for moderate n (e.g. n = 3000) the score is ≈1.334,
comfortably below the target 1.503.

The algorithm therefore just builds this linear sequence, respecting the
1000‑height cap, and returns it.  No optimisation loop is required.
"""

    Generate a monotone increasing step‑function whose evaluation score
