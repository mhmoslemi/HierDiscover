"""
Propose a low‑evaluation step‑function sequence.

The evaluation function is
    E = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `conv` is the discrete convolution.
For a linearly increasing sequence a_i = c * (i+1) (i = 0 … n‑1) one can
show analytically

    max(conv) = n (n+1) (n+2) c^2 / 6
    sum(a)   = n (n+1) c / 2

so that

    E = (4/3) * (n+2) / (n+1)  → 4/3 ≈ 1.333

independently of the scaling factor `c`.  By choosing `c` so that the
largest entry equals the allowed maximum (1000) we respect all
security checks of `evaluate_sequence`.  The resulting value ≈1.33
comfortably beats the target 1.503.

The function below builds this “ramp” sequence.  If a reference sequence
`height_sequence_1` is present we use its length to keep the construction
compatible with the existing benchmark; otherwise a default length of
2000 is used.
