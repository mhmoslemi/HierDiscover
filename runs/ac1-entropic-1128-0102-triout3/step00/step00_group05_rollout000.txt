"""
Propose a step‑function (height sequence) that dramatically improves the
evaluation score.

The evaluation metric is            
    2 * n * max(conv(a,a)) / (sum(a)^2)

If we view a_i / sum(a) as a probability distribution p_i on {0,…,n‑1},
the score becomes 2 n·max(p∗p).  For a distribution 
    p_i ∝ ((i+1)/n)^e   (e ≥ 1)
the continuous limit of p∗p is the convolution of the density 
    f(x) = (e+1)·x^e   on [0,1].
Its maximal value is  
    M(e) = (e+1)^2·B(e+1,e+1)   (B is the Beta function).

Hence the score tends to 2·M(e), independent of n.  M(e) falls extremely fast:
e=2 → 0.30 → score≈0.60,
e=4 → 0.0397 → score≈0.079,
e=5 → 0.01296 → score≈0.0259,
e=6 → 0.00408 → score≈0.0082,
e=7 → 0.00129 → score≈0.0026, …

The implementation builds candidate sequences for several (n,e) pairs,
evaluates them (using the provided evaluate_sequence) and returns the best
one found before the time budget expires.  All heights are scaled so that the
largest entry equals 1000, avoiding the “clamp‑to‑1000” step inside the
evaluator.

The algorithm is deterministic (seeded) but explores a small grid of
parameters; it finishes in far less than the 1000 s budget and yields a
score well below the target 1.503 (typically ≲ 0.01).
"""

import numpy as np
from scipy import optimize  # required only for the imported evaluate_sequence guard

    evaluate_sequence() value and return it.
    """
