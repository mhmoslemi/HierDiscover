Propose a candidate sequence for the step-function minimisation problem.

The evaluation function is scale‑invariant, so the algorithm works with
probability vectors (sum of entries = 1).  For a fixed length n we wish
to make the self‑convolution `a * a` as flat as possible because the
evaluation equals

    2 * n * max(a * a)   (since sum(a)=1)

and the average value of the convolution is
    1 / (2*n‑1).

Thus minimising the maximum is equivalent (up to a constant factor) to
minimising the variance of the convolution.  The code performs many
random restarts and, for each restart, runs a simple projected gradient
descent on the variance of the convolution:

    g_k = Σ_t ( (a*a)_t – avg ) * a_{t‑k}

where `avg = 1/(2*n‑1)`.  After each gradient step we project onto the
non‑negative orthant and renormalise the vector (the renormalisation
does not change the evaluation).  The best sequence seen during the
budget is returned.

The method uses only ``numpy`` and ``time`` and respects the 1‑CPU,
1000‑second time limit.

        # --------------------------------------------------------
        n = int(np.random.choice(length_candidates))
        # Dirichlet(1,…,1) gives a random point on the simplex
        a = np.random.dirichlet(alpha=np.ones(n))

        # Occasionally start from the current best (truncated or padded)
        if best_seq is not None and np.random.rand() < 0.15:
            b = np.array(best_seq, dtype=float)
            if b.size > n:
                a = b[:n]
            else:
                extra = np.random.dirichlet(alpha=np.ones(n - b.size))
                a = np.concatenate([b, extra])
            a = a / a.sum()

        step = init_step

        # --------------------------------------------------------
        # Projected gradient descent on the variance of a*a
        # --------------------------------------------------------
        for _ in range(max_inner_iters):
            if time.time() >= deadline:
                break

            # Compute convolution and current score
            conv = np.convolve(a, a)                # length 2n-1
            max_val = conv.max()
            cur_score = 2.0 * n * max_val           # sum(a)=1 by construction

            # Keep the best overall sequence
            if cur_score < best_score:
                best_score = cur_score
                best_seq = a.tolist()
                print(f"[{time.time():.2f}] New best: score={best_score:.6f}, n={n}")

            # ----------------------------------------------------
            # Gradient of variance (flatness) of the convolution
            # ----------------------------------------------------
            # Average value of the convolution (for sum=1)
            avg = 1.0 / (2 * n - 1)
            diff = conv - avg                       # shape (2n-1,)

            # Gradient: g_k = Σ_t diff_t * a_{t‑k}
            # Efficiently compute by convolution with the reversed a.
            a_rev = a[::-1]
            full = np.convolve(diff, a_rev)        # length 3n-2
            # Extract the slice corresponding to k = 0..n-1:
            g = full[n - 1 : 2 * n - 1]             # shape (n,)

            # Gradient descent step (projected onto non‑negative orthant)
            a_new = a - step * g
            a_new = np.maximum(a_new, 0.0)

            # Renormalise to stay on the simplex (scale invariance)
            s = a_new.sum()
            if s == 0.0:
                # Re‑initialise if we have collapsed to the zero vector
                a_new = np.random.dirichlet(alpha=np.ones(n))
                s = 1.0
            a = a_new / s

            # Decay the step size slowly
            step *= step_decay

        # --------------------------------------------------------
        # Occasionally apply a random perturbation to escape plateaus
        # --------------------------------------------------------
        if np.random.rand() < 0.1:
            a += np.random.randn(len(a)) * 0.02
            a = np.clip(a, 0.0, None)
            a = a / a.sum()

    # ----------------------------------------------------------------
    # Fallback: constant sequence (score = 2) – should never be needed if
    # the search found something better.
    # ----------------------------------------------------------------
    if best_seq is None:
        n = 100
        best_seq = [1.0] * n

    return best_seq
