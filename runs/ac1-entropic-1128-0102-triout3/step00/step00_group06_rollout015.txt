"""Simple projected gradient descent on a smooth approximation of the L∞‐norm of
the self–convolution.

The objective to minimise is

    F(a) = max_k (a*a)[k]                (a≥0,  Σa = 1)

Because the max is non‑smooth we use a softmax (log‑sum‑exp) surrogate

    Φ_α(a) = (1/α) * log Σ_k exp( α·(a*a)[k] ) ,

whose gradient is easy to compute:

    ∂Φ/∂a_i = 2 Σ_k  w_k  a_{k-i} ,
    w_k = exp(α·b_k) / Σ_j exp(α·b_j) ,   b = a∗a .

We repeatedly take a small step opposite to this gradient,
project onto the simplex (non‑negative, unit sum) and slowly increase α
so that the surrogate becomes sharper and finally approximates the true
max.  Several random restarts are performed within the allotted time.
The best sequence found is returned.

The function ``evaluate_sequence`` is assumed to be available in the
environment (it is imported by the competition harness)."""

import time
import numpy as np

def _project_to_simplex(x: np.ndarray) -> np.ndarray:
    """Projection of a non‑negative vector onto the unit simplex.
    This is the classic O(n log n) algorithm."""
    if x.sum() == 0:
        # avoid division by zero – return uniform distribution
        return np.full_like(x, 1.0 / len(x))
    # make sure we stay non‑negative
    x = np.maximum(x, 0.0)
    u = np.sort(x)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(u)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(x - theta, 0)
    # normalise (numerical safety)
    w_sum = w.sum()
    if w_sum == 0:
        w = np.full_like(w, 1.0 / len(w))
    else:
        w = w / w_sum
    return w
