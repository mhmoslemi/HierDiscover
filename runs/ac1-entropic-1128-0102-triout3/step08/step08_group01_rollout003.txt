assistantfinal**Solution Explanation**

The goal is to find a non‑negative vector `a` (interpreted as a step‑function) that minimises  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `(a*a)` is the full discrete convolution of `a` with itself.
All entries are forced to be non‑negative and the sum is normalised to 1,
so the problem is equivalent to

```
minimise   2·n·max_k (a*a)_k     subject to   a_i ≥ 0 ,  Σa_i = 1 .
```

The code below searches for a better vector than the previously obtained
value ≈ 1.51229.  
It combines three complementary optimisation stages, each respecting the
global time budget (`budget_s` ≈ 1000 s):

1. **Frank‑Wolfe on a smooth approximation** –  
   We minimise a *log‑sum‑exp* (LSE) surrogate of the maximum:

   \[
   \phi_\alpha(a)=\frac{2n}{\alpha}\log\Bigl(\sum_k
   e^{\alpha\,(a*a)_k}\Bigr),
   \]

   which is convex and differentiable.  
   For a fixed smoothing parameter `α` the Frank‑Wolfe algorithm (a
   conditional‑gradient method) performs cheap *linear* sub‑problems:
   the minimiser over the probability simplex is always a unit vector
   `e_i`.  
   The step size is the classic decreasing schedule `λ_t = 2/(t+2)`.
   By increasing `α` during the run (continuation) the surrogate becomes
   increasingly tight, steering the iterate towards a true minimiser of
   the original max‑convolution objective.

2. **Projected sub‑gradient descent on the exact objective** –  
   After the smooth phase we finish with a classic sub‑gradient method on
   the genuine objective (`max(conv)`).  
   The sub‑gradient at the current maximising index `k` is simply
   `g_i = 2·a_{k-i}` (zero where the index is out of range).  
   A momentum term (`β=0.94`) and a stepsize `γ_t = 0.25/√t` give fast
   descent while the projection onto the simplex (`_project_simplex`) keeps
   feasibility.

3. **Targeted simulated annealing** –  
   The final polish moves a small amount of probability mass from a
   location that most contributes to the current maximal convolution entry
   towards a randomly chosen destination.  An exponential cooling schedule
   (`T_start = 5·10⁻² → T_end = 10⁻⁸`) permits occasional uphill moves
   and helps escape shallow plateaus.

Optionally, if time remains, a few short random restarts (perturbation + sub‑gradient + annealing) are performed.

The routine works with any length `n`; we use `n = 4096` (the same size as
the reference solution) because it is fast enough to perform many
iterations while still having enough degrees of freedom to improve the
objective.

All helper functions are top‑level, there are no closures or lambdas, and
the total running time never exceeds the supplied budget.

```python
"""
Propose a step‑function (non‑negative vector) that minimises
    2·n·max(a*a) / (sum(a)**2)

The algorithm consists of three phases:

1) Frank‑Wolfe on a smooth log‑sum‑exp surrogate of the max‑convolution.
   A continuation on the smoothing parameter α gradually tightens the
   approximation.

2) Projected sub‑gradient descent on the exact max‑convolution objective.

3) Targeted simulated annealing that moves probability mass away from the
   indices that dominate the current peak.

If time permits a few random restarts are tried.  The best sequence found
within the time budget is returned as a plain Python list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Linear‑algebra utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int) -> np.ndarray:
    """Self‑convolution a*a using FFT (length = 2·len(a)‑1)."""
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * a.shape[0] - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Phase 1 – Frank‑Wolfe on log‑sum‑exp surrogate
# ----------------------------------------------------------------------
def _grad_lse(a: np.ndarray, L: int, alpha: float):
    """
    Returns (conv, gradient) of the smoothed objective
        φ_α(a) = (1/α)·log Σ e^{α·conv_k}
    where conv = a*a.
    """
    conv = _conv_self(a, L)                     # length 2·n‑1
    scaled = alpha * conv
    max_scaled = scaled.max()
    w = np.exp(scaled - max_scaled)             # stability trick
    w /= w.sum()                                # soft‑max weights
    w_rev = w[::-1]

    Af = np.fft.rfft(a, n=L)
    Wrev = np.fft.rfft(w_rev, n=L)
    corr = np.fft.irfft(Af * Wrev, n=L)[: a.shape[0] + len(w_rev) - 1]
    grad = 2.0 * corr[len(w_rev) - 1 - np.arange(a.shape[0])]
    return conv, grad


def _run_frank_wolfe(a0: np.ndarray,
                     n: int,
                     deadline: float,
                     start_time: float):
    """
    Frank‑Wolfe optimisation on the LSE surrogate.
    Returns the best iterate (lowest true objective seen) and its score.
    """
    a = a0.copy()
    best_a = a.copy()
    best_score = float("inf")
    try:
        best_score = evaluate_sequence(a.tolist())
    except Exception:
        pass

    L = _next_pow2(2 * n - 1)
    it = 0
    # continuation schedule for the smoothing parameter
    alphas = [0.5, 1.0, 2.0, 5.0, 10.0, 20.0, 40.0, 80.0]

    for alpha in alphas:
        # a few thousand FW steps per α (adjusted later if time runs out)
        max_iter_alpha = 2000
        for _ in range(max_iter_alpha):
            if time.time() >= deadline:
                return best_a, best_score

            conv, grad = _grad_lse(a, L, alpha)

            # linear minimisation oracle for the simplex → unit vector e_i
            i = int(np.argmin(grad))
            direction = np.zeros_like(a)
            direction[i] = 1.0
            direction -= a

            it += 1
            lam = 2.0 / (it + 2.0)        # classic FW step size
            a = a + lam * direction

            # re‑normalise (numerical drift)
            a = np.maximum(a, 0.0)
            s = a.sum()
            if s > 0.0:
                a /= s

            # occasional exact evaluation
            if it % 200 == 0:
                cur_score = evaluate_sequence(a.tolist())
                if cur_score < best_score:
                    best_score = cur_score
                    best_a = a.copy()
                    print(f"[{time.time() - start_time:.2f}s] FW improve: iter={it:,}, score={cur_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Phase 2 – Projected sub‑gradient descent on the true max‑convolution
# ----------------------------------------------------------------------
def _run_subgradient_descent(a0: np.ndarray,
                             n: int,
                             deadline: float,
                             start_time: float,
                             best_score_initial: float,
                             max_iters: int | None = None) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent on f(a)=2·n·max(conv(a,a)).
    Uses momentum and a 1/√t step‑size schedule.
    """
    a = a0.copy()
    best_a = a.copy()
    best_score = best_score_initial
    momentum = np.zeros_like(a)
    beta = 0.94
    step0 = 0.25
    it = 0
    L = _next_pow2(2 * n - 1)

    while time.time() < deadline and (max_iters is None or it < max_iters):
        it += 1
        conv = _conv_self(a, L)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] sub‑grad improve: iter={it:,}, score={cur_score:.6f}")

        # sub‑gradient from the (first) maximal index
        k = int(conv.argmax())
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad = np.zeros_like(a)
        grad[idx] = 2.0 * a[k - idx]

        # momentum + projection onto simplex
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)
        a = a - step * momentum
        a = _project_simplex(a)

    return best_a, best_score


# ----------------------------------------------------------------------
# Phase 3 – Targeted simulated annealing
# ----------------------------------------------------------------------
def _run_targeted_annealing(a0: np.ndarray,
                            n: int,
                            deadline: float,
                            start_time: float,
                            cur_best_score: float,
                            cur_best_seq: np.ndarray,
                            start_temp: float = 5e-2,
                            end_temp: float = 1e-8,
                            steps: int = 150_000) -> tuple[np.ndarray, float]:
    """
    Annealing that repeatedly attacks the current maximal convolution index.
    A small amount of probability mass is moved away from the pair that
    contributes most to that peak.
    """
    a = a0.copy()
    L = _next_pow2(2 * n - 1)
    conv = _conv_self(a, L)
    score = 2.0 * n * conv.max()
    best_seq = cur_best_seq.copy()
    best_score = cur_best_score
    rng = np.random.default_rng()

    for it in range(1, steps + 1):
        if time.time() >= deadline:
            break
        # exponential cooling
        T = start_temp * (end_temp / start_temp) ** (it / steps)

        # locate current maximal convolution index
        k = int(conv.argmax())
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx_range = np.arange(lo, hi + 1)
        contrib = a[idx_range] * a[k - idx_range]
        if contrib.sum() > 0.0:
            src = rng.choice(idx_range, p=contrib / contrib.sum())
        else:
            src = rng.integers(n)

        dst = rng.integers(n)
        if src == dst or a[src] < 1e-14:
            continue

        # move at most 20 % of the source mass
        eps = a[src] * rng.random() * 0.20
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        conv_new = _conv_self(a_prop, L)
        new_score = 2.0 * n * conv_new.max()
        delta = new_score - score

        if delta < 0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            conv = conv_new
            score = new_score

        if score < best_score:
            best_score = score
            best_seq = a.copy()
            print(f"[{time.time() - start_time:.2f}s] anneal improve: iter={it:,}, score={score:.6f}")

    return best_seq, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function that minimises `evaluate_sequence`.
    Uses a three‑stage optimiser (Frank‑Wolfe, sub‑gradient, annealing)
    and optional random restarts.  Returns the best sequence found as a
    list of Python floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5    # safety margin

    # ------------------------------------------------------------------
    # Choose length and initialise a feasible point.
    # ------------------------------------------------------------------
    n = 4096

    # Try to reuse the previously discovered sequence if available.
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            # Interpolate to the required length.
            a0 = np.interp(
                np.linspace(0, 1, n),
                np.linspace(0, 1, starter.size),
                starter,
            )
            a0 = np.maximum(a0, 0.0)
            a0 /= a0.sum()
        else:
            raise ValueError
    except Exception:
        a0 = np.random.rand(n)
        a0 /= a0.sum()

    best_seq = a0.copy()
    try:
        best_score = evaluate_sequence(best_seq.tolist())
    except Exception:
        best_score = float("inf")

    # ------------------------------------------------------------------
    # Phase 1 – Frank‑Wolfe on the smoothed max.
    # ------------------------------------------------------------------
    if time.time() < deadline:
        remaining = deadline - time.time()
        phase1_deadline = time.time() + max(5.0, 0.10 * remaining)

        fw_seq, fw_score = _run_frank_wolfe(
            a0,
            n,
            phase1_deadline,
            start_time,
        )
        if fw_score < best_score:
            best_score = fw_score
            best_seq = fw_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] phase 1 (FW) improve: score={fw_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – Sub‑gradient descent on the exact objective.
    # ------------------------------------------------------------------
    if time.time() < deadline:
        remaining = deadline - time.time()
        phase2_deadline = time.time() + max(20.0, 0.70 * remaining)

        sub_seq, sub_score = _run_subgradient_descent(
            best_seq,
            n,
            phase2_deadline,
            start_time,
            best_score,
            max_iters=None,
        )
        if sub_score < best_score:
            best_score = sub_score
            best_seq = sub_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] phase 2 improve: score={sub_score:.6f}")

        # one brief extra run with a larger initial step
        if time.time() < deadline:
            extra_deadline = time.time() + min(10.0, deadline - time.time())
            sub_seq2, sub_score2 = _run_subgradient_descent(
                best_seq,
                n,
                extra_deadline,
                start_time,
                best_score,
                max_iters=200_000,
            )
            if sub_score2 < best_score:
                best_score = sub_score2
                best_seq = sub_seq2.copy()
                print(f"[{time.time() - start_time:.2f}s] extra sub‑grad improve: score={sub_score2:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – Targeted annealing.
    # ------------------------------------------------------------------
    if time.time() < deadline:
        anneal_seq, anneal_score = _run_targeted_annealing(
            best_seq,
            n,
            deadline,
            start_time,
            best_score,
            best_seq,
            start_temp=5e-2,
            end_temp=1e-8,
            steps=150_000,
        )
        if anneal_score < best_score:
            best_score = anneal_score
            best_seq = anneal_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] final anneal improve: score={anneal_score:.6f}")

    # ------------------------------------------------------------------
    # Optional random restarts if time is still left.
    # ------------------------------------------------------------------
    while time.time() < deadline - 5.0:
        time_left = deadline - time.time()
        block = min(30.0, time_left / 2.0)
        restart_deadline = time.time() + block

        # perturb current best a little
        pert = best_seq + 0.015 * np.random.randn(n)
        pert = np.maximum(pert, 0.0)
        pert /= pert.sum()

        # short sub‑gradient phase
        pert_seq, pert_score = _run_subgradient_descent(
            pert,
            n,
            restart_deadline,
            start_time,
            best_score,
            max_iters=120_000,
        )
        # quick anneal if we still have budget
        if time.time() < deadline:
            pert_seq, pert_score = _run_targeted_annealing(
                pert_seq,
                n,
                deadline,
                start_time,
                best_score,
                pert_seq,
                start_temp=2e-2,
                end_temp=1e-8,
                steps=80_000,
            )
        if pert_score < best_score:
            best_score = pert_score
            best_seq = pert_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] restart improve: score={pert_score:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation and conversion to plain Python list.
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    return [float(x) for x in best_seq]
```
