The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\]

with a non‑negative step function `a` (length `n`).  
All candidates are normalised to `sum(a)=1`, therefore the problem reduces to

* minimise the peak of the *full* self‑convolution `a*a`.

The code below implements a **three‑phase optimisation pipeline** that fits into the
1000 s budget:

1. **Exploration (soft‑max Adam).**  
   Several diverse initial vectors (uniform, exponential, Gaussian, Dirichlet and,
   if available, the previous best construction) are refined by Adam on a
   smooth approximation of the max‑convolution  
   \[
   f_\alpha(a)=\frac{1}{\alpha}\log\!\Bigl(\sum_k\exp\bigl(\alpha\,(a*a)_k\bigr)\Bigr).
   \]  
   The temperature `α` is raised gradually (up to 2048) and each run performs a
   few thousand Adam steps.  The best vector found across all starts is kept.

2. **Polishing (projected sub‑gradient).**  
   Using the exact non‑smooth objective, a momentum‑based sub‑gradient method
   moves the candidate toward lower peaks.  The step size decays like
   `step0 / sqrt(iter)` and the iterate is always projected onto the probability
   simplex.

3. **Local stochastic refinement.**  
   A cheap random‑move / simulated‑annealing loop perturbs the current best
   solution: a small amount of mass is shifted from a “heavy” index to a
   “light” one.  Moves that lower the convolution peak are accepted
   (occasionally uphill moves are allowed early on).  This phase removes the
   last remaining spikes of the peak.

All phases respect the global time budget and the final vector is
re‑normalised to sum = 1 before being returned.

The optimiser works for any `n`.  Empirically a size of **8000–10000**
offers a good trade‑off between expressiveness and speed; the default is
`n = 8000`.  The routine can be seeded for reproducibility.

```python
"""
Propose a non‑negative step function that (almost) minimises
evaluate_sequence.

Algorithm
---------
1.  Generate several diverse starts (uniform, exponential, Gaussian,
    Dirichlet, up‑sampled previous best).
2.  Exploration – Adam optimisation on a smooth log‑sum‑exp
    approximation of the max‑convolution.  The smoothing parameter α
    is increased (0.5 → 2048) while a few thousand Adam steps are taken
    for each α.  The best vector across all starts is retained.
3.  Polishing – projected sub‑gradient descent on the true
    max‑convolution objective, with momentum and a 1/√t step decay.
4.  Local stochastic refinement – repeatedly move a small fraction of
    mass from a coefficient that contributes most to the current peak
    towards a smallest coefficient; accept if the peak decreases
    (simulated‑annealing style early on).
5.  Normalise the final vector to sum = 1 and return it as a plain list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a via FFT (real‑to‑real)."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _grad_smooth_max(a: np.ndarray, conv: np.ndarray,
                     alpha: float, fft_len: int) -> np.ndarray:
    """
    Gradient of fα(a) = (1/α)·log Σ_k exp(α·conv_k).
    Returns ∂fα/∂a (shape (n,)).
    """
    n = a.shape[0]

    # soft‑max weights over the convolution entries
    scaled = alpha * conv
    max_scaled = scaled.max()
    w = np.exp(scaled - max_scaled)
    w /= w.sum()

    # cross‑correlation a ⋆ w   (gradient = 2·(a⋆w))
    w_rev = w[::-1]
    Af = np.fft.rfft(a, n=fft_len)
    Wrev = np.fft.rfft(w_rev, n=fft_len)
    corr = np.fft.irfft(Af * Wrev, n=fft_len)[: n + len(w_rev) - 1]

    # the required slice aligns the gradient with a
    grad = 2.0 * corr[len(w_rev) - 1 - np.arange(n)]
    return grad


def _upsample(seq: np.ndarray, new_n: int) -> np.ndarray:
    """Linear interpolation of `seq` to length `new_n` while preserving the sum."""
    old_n = seq.shape[0]
    if old_n == new_n:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    up = np.interp(new_x, old_x, seq)
    up = np.maximum(up, 0.0)
    s = up.sum()
    if s > 0:
        up /= s
    else:
        up = np.full_like(up, 1.0 / new_n)
    return up


# ----------------------------------------------------------------------
# Random start generators
# ----------------------------------------------------------------------


def _dirichlet_start(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Draw a Dirichlet vector with concentration `conc`."""
    x = rng.gamma(conc, 1.0, size=n)
    s = x.sum()
    if s == 0:
        return np.full(n, 1.0 / n)
    return x / s


def _gaussian_start(n: int) -> np.ndarray:
    """Discrete Gaussian centred on the interval, normalised."""
    sigma = n / 6.0
    centre = (n - 1) / 2.0
    x = np.arange(n)
    g = np.exp(-0.5 * ((x - centre) / sigma) ** 2)
    return g / g.sum()


def _exponential_start(n: int, r: float = 0.98) -> np.ndarray:
    """Geometric decay a_i ∝ r**i, normalised."""
    vec = np.array([r ** i for i in range(n)], dtype=float)
    return vec / vec.sum()


# ----------------------------------------------------------------------
# Adam optimisation on the smooth max‑convolution objective
# ----------------------------------------------------------------------


def _adam_optimize(a0: np.ndarray,
                   global_deadline: float,
                   start_time: float,
                   eps_log: float = 1e-16) -> tuple[np.ndarray, float]:
    """
    Adam on the log‑sum‑exp smooth approximation.
    Returns (best_vector, best_score).
    """
    a = a0.copy()
    n = a.shape[0]

    # work in log‑space to keep positivity and the simplex
    y = np.log(np.maximum(a, eps_log))

    fft_len = _next_pow2(3 * n - 2)

    # smoothing schedule – larger values make the landscape sharper
    alpha_schedule = [0.5, 2.0, 8.0, 32.0, 128.0, 512.0, 2048.0]
    iters_per_alpha = 3500   # a few thousand per temperature

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    eps_adam = 1e-8
    lr0 = 0.12
    m = np.zeros_like(y)
    v = np.zeros_like(y)
    t = 0

    best_a = a.copy()
    best_score = float(evaluate_sequence(a.tolist()))

    for alpha in alpha_schedule:
        for _ in range(iters_per_alpha):
            if time.time() >= global_deadline:
                return best_a, best_score

            # Soft‑max → probability vector
            maxy = np.max(y)
            exp_y = np.exp(y - maxy)
            a = exp_y / exp_y.sum()

            # Convolution and smooth objective
            conv = _conv_self(a)
            scaled = alpha * conv
            max_scaled = scaled.max()
            lse = max_scaled + np.log(np.exp(scaled - max_scaled).sum())
            f_val = lse / alpha
            obj = 2.0 * n * f_val  # identical scaling used later

            # Gradient w.r.t. a
            grad_a = _grad_smooth_max(a, conv, alpha, fft_len) * (2.0 * n)

            # Back‑prop to logits y (soft‑max Jacobian)
            grad_y = a * (grad_a - np.dot(grad_a, a))

            # Adam update
            t += 1
            m = beta1 * m + (1.0 - beta1) * grad_y
            v = beta2 * v + (1.0 - beta2) * (grad_y ** 2)
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            lr_t = lr0 * (np.sqrt(1.0 - beta2 ** t) / (1.0 - beta1 ** t))
            y = y - lr_t * m_hat / (np.sqrt(v_hat) + eps_adam)

            # Occasionally evaluate the exact score
            if t % 250 == 0:
                sc = evaluate_sequence(a.tolist())
                if sc < best_score:
                    best_score = sc
                    best_a = a.copy()
                    print(f"[{time.time() - start_time:6.2f}s] Adam improve: α={alpha:.0f}, score={sc:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Projected sub‑gradient descent on the true max‑convolution
# ----------------------------------------------------------------------


def _subgrad_optimize(a0: np.ndarray,
                      deadline: float,
                      start_time: float,
                      beta: float = 0.94,
                      step0: float = 0.3) -> tuple[np.ndarray, float]:
    """
    Momentum sub‑gradient descent on   f(a)=max_k (a*a)[k].
    Returns (best_vector, best_score).
    """
    a = a0.copy()
    n = a.shape[0]
    momentum = np.zeros_like(a)

    best_a = a.copy()
    best_score = float("inf")
    it = 0

    while time.time() < deadline:
        it += 1
        conv = _conv_self(a)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] sub‑grad improve: iter={it:,}, score={cur_score:.6f}")

        # Active set (indices where conv is within 1e‑12 of the max)
        rel_tol = 1e-12
        thresh = cur_max * (1.0 - rel_tol)
        active = np.where(conv >= thresh)[0]

        # Sub‑gradient: sum of 2·a shifted by each active index
        g = np.zeros_like(a)
        for k in active:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            i = np.arange(lo, hi + 1, dtype=int)
            j = k - i
            # each pair contributes to both coordinates
            g[i] += a[j]
            g[j] += a[i]

        # Momentum update (Nesterov‑style)
        momentum = beta * momentum + (1.0 - beta) * g
        step = step0 / math.sqrt(it)

        a = _project_simplex(a - step * momentum)

    return best_a, best_score


# ----------------------------------------------------------------------
# Local stochastic refinement (simulated‑annealing style)
# ----------------------------------------------------------------------


def _local_refine(a0: np.ndarray,
                  deadline: float,
                  start_time: float,
                  init_temp: float = 1e-3,
                  cool_rate: float = 0.9995) -> tuple[np.ndarray, float]:
    """
    Randomly shift a fraction of mass from a heavy position to a light one.
    Accepts downhill moves and, while the temperature is high,
    occasionally accepts uphill moves.
    Returns (best_vector, best_score).
    """
    a = a0.copy()
    n = a.shape[0]
    conv = _conv_self(a)
    cur_max = conv.max()
    best_score = 2.0 * n * cur_max
    best_a = a.copy()

    rng = np.random.default_rng()

    temp = init_temp
    it = 0

    while time.time() < deadline:
        it += 1
        # pick a source index with probability ∝ a (more mass → more likely)
        src = rng.choice(n, p=a / a.sum())
        # pick a destination index different from src uniformly
        dst = rng.integers(0, n - 1)
        if dst >= src:
            dst += 1

        # move a modest fraction (up to 30 %)
        eps_frac = rng.uniform(0.01, 0.30)
        eps = eps_frac * a[src]
        if eps <= 0:
            continue

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        # evaluate new peak (fast convolution)
        new_max = _conv_self(a_prop).max()
        new_score = 2.0 * n * new_max

        accept = False
        if new_score < best_score - 1e-12:
            accept = True
        else:
            # simulated‑annealing acceptance
            prob = math.exp(-(new_score - best_score) / max(temp, 1e-12))
            if rng.random() < prob:
                accept = True

        if accept:
            a = a_prop
            cur_max = new_max
            if new_score < best_score - 1e-12:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:6.2f}s] local refine improve: iter={it:,}, score={new_score:.6f}")

        # temperature decay
        temp *= cool_rate

    return best_a, best_score


# ----------------------------------------------------------------------
# Main optimisation driver
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises ``evaluate_sequence``.
    The routine consists of
       • exploration (soft‑max Adam with many starts),
       • polishing (projected sub‑gradient descent),
       • a final stochastic refinement.
    The returned vector is a plain Python list, normalised to sum = 1.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    # Small safety margin before the hard deadline
    deadline = start_time + budget_s - 0.5

    # ------------------------------------------------------------------
    # Problem size – 8000 points provides a good compromise between
    # expressiveness and speed.
    # ------------------------------------------------------------------
    n = 8000

    # ------------------------------------------------------------------
    # Build a collection of diverse start vectors.
    # ------------------------------------------------------------------
    starts = []

    # 1) previous construction, if it exists
    try:
        seq = np.asarray(height_sequence_1, dtype=float)
        if seq.ndim == 1 and seq.size > 0:
            if seq.shape[0] != n:
                seq = _upsample(seq, n)
            starts.append(seq / seq.sum())
    except Exception:
        pass

    # 2) uniform
    starts.append(np.full(n, 1.0 / n))

    # 3) exponential decay
    starts.append(_exponential_start(n, r=0.985))

    # 4) Gaussian bell
    starts.append(_gaussian_start(n))

    # 5) Dirichlet, moderate concentration
    starts.append(_dirichlet_start(n, conc=2.0, rng=rng))

    # 6) Dirichlet, low concentration (spikier)
    starts.append(_dirichlet_start(n, conc=0.5, rng=rng))

    # 7) a few random Dirichlet samples for extra diversity
    for _ in range(2):
        starts.append(_dirichlet_start(n, conc=rng.uniform(0.3, 3.0), rng=rng))

    # ------------------------------------------------------------------
    # Time split: 35 % exploitation (Adam), 45 % polishing (sub‑grad),
    # remaining 20 % stochastic refinement.
    # ------------------------------------------------------------------
    explore_deadline = start_time + 0.35 * budget_s
    polish_deadline = start_time + 0.80 * budget_s   # 45 % for polishing
    refine_deadline = deadline                       # rest for refinement

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Phase 1 – Exploration (Adam)
    # ------------------------------------------------------------------
    for idx, a0 in enumerate(starts):
        if time.time() >= explore_deadline:
            break
        print(f"[{time.time() - start_time:6.2f}s] Exploration start #{idx + 1}")

        cand_seq, cand_score = _adam_optimize(a0, explore_deadline, start_time)
        if cand_score < best_score:
            best_score = cand_score
            best_seq = cand_seq.copy()
            print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST (explore) "
                  f"score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – Polishing (projected sub‑gradient)
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < polish_deadline:
        print(f"[{time.time() - start_time:6.2f}s] Polishing phase start")
        polished_seq, polished_score = _subgrad_optimize(
            best_seq, polish_deadline, start_time, beta=0.94, step0=0.3
        )
        if polished_score < best_score:
            best_score = polished_score
            best_seq = polished_seq.copy()
            print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST (polish) "
                  f"score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – Local stochastic refinement
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < refine_deadline:
        print(f"[{time.time() - start_time:6.2f}s] Local stochastic refinement start")
        final_seq, final_score = _local_refine(
            best_seq, refine_deadline, start_time,
            init_temp=1e-3, cool_rate=0.9992
        )
        if final_score < best_score:
            best_score = final_score
            best_seq = final_seq.copy()
            print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST (refine) "
                  f"score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation and reporting
    # ------------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)

    best_seq = np.clip(best_seq, 0.0, None)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = np.full_like(best_seq, 1.0 / n)

    final_score = evaluate_sequence(best_seq.tolist())
    print(f"[{time.time() - start_time:6.2f}s] Final reported score = {final_score:.6f}")

    # Return a plain Python list as required by the harness
    return [float(x) for x in best_seq.tolist()]
```
