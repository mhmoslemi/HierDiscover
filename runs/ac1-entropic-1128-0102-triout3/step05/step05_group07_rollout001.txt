The evaluator computes  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\]

where `a*a` is the discrete convolution of the non‑negative vector `a`.  
Because the denominator is just the squared ℓ₁‑norm we can restrict ourselves to the simplex

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

On the simplex the score reduces to  

\[
\text{score}(a)=2\,n\;\max (a*a).
\]

The problem is non‑convex (the max‑norm is non‑smooth) but the sub‑gradient of the
objective is easy to obtain:

* let `c = a*a`  (full convolution, length `2n‑1`);
* let `w` be a probability vector concentrated on the *active* indices,
  e.g. `w_i = 1/|A|` for all `i` with `c_i = max(c)` (or a soft version);
* the sub‑gradient of `max(c)` w.r.t. `a` is  

\[
\partial\max(c)=2\,( \text{rev}(a) * w),
\]

where `rev(a)` is `a` reversed and `*` denotes convolution.

Two optimisation primitives are used:

1. **Smooth‑max Adam** – a standard Adam optimiser applied to the
   *soft‑max* approximation of the max‑norm.  
   Temperature `τ` is annealed from a relatively large value (the objective
   is smooth) down to a very small one (close to the true max).

2. **Exponential‑gradient (mirror‑descent)** – a multiplicative update on the
   simplex that uses the exact sub‑gradient (`w` is the hard indicator of the
   maximal entries).  The step size `η` is geometrically decayed.

Both primitives are written in a fully vectorised fashion and rely on FFT
convolutions (`O(n log n)`).  The search strategy is:

* try several problem sizes (`n` from 1500 up to 9000);
* create a diverse pool of initial vectors (uniform, cosine, triangle,
  Dirichlet samples, sparse spikes, up‑sampled best‑so‑far);
* run a short Adam phase followed by a longer exponential‑gradient phase;
* keep the best vector seen;
* occasionally perform a cheap *local random perturbation* of the current best
  and re‑optimise it – this helps escaping shallow local minima;
* the whole process respects the global time budget (default 1000 s).

The code below implements exactly this scheme and returns the best
sequence found as a plain Python list of floats.

```python
"""
Propose a low‑score step‑function.

The algorithm combines three ideas:

1. **Smooth‑max Adam** – Adam optimisation of the
   log‑sum‑exp approximation of max(conv(a,a)).  The temperature τ
   is annealed from a large to a tiny value, turning a smooth
   objective into the true max‑norm.

2. **Exact exponential‑gradient (mirror‑descent)** – a multiplicative
   update on the probability simplex that uses the genuine
   sub‑gradient of max(conv(a,a)).  The step size η decays
   geometrically.

3. **Multi‑scale search** – a schedule of problem sizes (1500 → 9000)
   and a rich pool of starting points (uniform, cosine, triangle,
   Dirichlet draws, sparse spikes, up‑sampled best vector).  After each
   refinement the current best is stored; random local perturbations
   are occasionally applied to explore new basins.

All heavy work (convolutions and gradients) is performed by FFT‑based
routines, yielding O(n log n) per iteration.  The routine respects a
global time budget (default 1000 s) and prints progress.
"""

from __future__ import annotations

import time
import math
import numpy as np
from typing import List, Tuple

# ----------------------------------------------------------------------

def project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fallback – uniform vector
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def conv_full(a: np.ndarray) -> np.ndarray:
    """
    Full linear convolution a * a using an FFT of appropriate length.
    Returns a real array of length 2*len(a)-1.
    """
    n = a.shape[0]
    fft_len = 1 << ((2 * n - 1).bit_length())
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)[: 2 * n - 1]
    return conv


def conv_max(a: np.ndarray) -> Tuple[float, np.ndarray]:
    """Return max(conv(a,a)) and the full convolution."""
    conv = conv_full(a)
    return float(conv.max()), conv


def gradient_from_weights(a: np.ndarray, w: np.ndarray, fft_len_grad: int) -> np.ndarray:
    """
    Gradient of Σ_k w_k * conv_k(a,a) w.r.t. a.
    Implements g = 2 * (rev(a) * w).
    """
    a_rev = a[::-1]
    W = np.fft.rfft(w, n=fft_len_grad)
    A_rev = np.fft.rfft(a_rev, n=fft_len_grad)
    conv2 = np.fft.irfft(W * A_rev, n=fft_len_grad)
    # conv2 length = len(w) + len(a) - 1
    start = a.shape[0] - 1
    grad = 2.0 * conv2[start:start + a.shape[0]]
    return grad


def smooth_max_adam(
    a0: np.ndarray,
    max_iters: int,
    deadline: float,
    alpha: float = 0.12,
    beta1: float = 0.9,
    beta2: float = 0.999,
    eps: float = 1e-8,
    tau_start: float = 0.12,
    tau_end: float = 5e-4,
) -> Tuple[np.ndarray, float]:
    """
    Adam optimiser on the smooth‑max (log‑sum‑exp) surrogate of the objective.
    Returns the best vector seen and its score (2·n·max(conv)).
    """
    n = a0.shape[0]
    a = a0.copy()
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    fft_len_conv = 1 << ((2 * n - 1).bit_length())
    fft_len_grad = 1 << ((3 * n - 2).bit_length())

    # keep the best encountered point
    cur_max, _ = conv_max(a)
    best_score = 2.0 * n * cur_max
    best_a = a.copy()

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # current objective
        cur_max, conv = conv_max(a)
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()

        # smooth‑max weights (log‑sum‑exp)
        tau = tau_start + (tau_end - tau_start) * (it / max_iters)
        # shift by max to avoid overflow
        shifted = (conv - cur_max) / tau
        w = np.exp(shifted)
        w_sum = w.sum()
        if w_sum > 0:
            w /= w_sum
        else:
            w.fill(1.0 / w.shape[0])

        # gradient of the smooth‑max surrogate
        g = gradient_from_weights(a, w, fft_len_grad)

        # Adam update (Euclidean)
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = alpha / (np.sqrt(v_hat) + eps)
        a = a - step * m_hat

        # projection back to the simplex
        a = project_simplex(a)

    return best_a, best_score


def exp_gradient_optimize(
    a0: np.ndarray,
    max_iters: int,
    deadline: float,
    eta_start: float = 0.7,
    eta_end: float = 4e-4,
    eps: float = 1e-12,
) -> Tuple[np.ndarray, float]:
    """
    Exponential‑gradient (mirror‑descent) optimiser that uses the *hard* max
    of the convolution (a sub‑gradient of the L∞‑norm).  The update rule is

        a_i ← a_i·exp(−η·g_i)   ,   g = 2·(rev(a) * indicator)

    followed by a normalisation step.  Returns the best vector and its score.
    """
    n = a0.shape[0]
    a = a0.copy()
    fft_len_grad = 1 << ((3 * n - 2).bit_length())

    best_score = float("inf")
    best_a = a.copy()

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        cur_max, conv = conv_max(a)
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()

        # indicator (mask) of active anti‑diagonals
        mask = conv >= cur_max - eps
        w = mask.astype(float)
        w_sum = w.sum()
        if w_sum == 0:
            w.fill(1.0 / w.size)
        else:
            w /= w_sum

        # sub‑gradient for the exact max‑norm
        g = gradient_from_weights(a, w, fft_len_grad)

        # geometric decay of the step size
        tau = it / max_iters
        eta = eta_start * (eta_end / eta_start) ** tau

        # multiplicative update (with clipping for numerical safety)
        upd = -eta * g
        upd = np.clip(upd, -30.0, 30.0)   # exp(±30) ≈ 1e13, safe for double
        a = a * np.exp(upd)

        # renormalise to the simplex
        s = a.sum()
        if s <= 0.0 or not np.isfinite(s):
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / s

    return best_a, best_score


def score_fast(a: np.ndarray) -> float:
    """Fast evaluation: 2·n·max(conv(a,a)) (sum(a)=1)."""
    n = a.shape[0]
    cur_max, _ = conv_max(a)
    return 2.0 * n * cur_max


def random_dirichlet(n: int) -> np.ndarray:
    """Draw a single Dirichlet(1,…,1) sample and return it as a simplex vector."""
    vec = np.random.gamma(1.0, 1.0, size=n)
    vec = np.maximum(vec, 0.0)
    s = vec.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n)
    return vec / s


def random_sparse_spikes(n: int, min_k: int = 3, max_k: int = 6) -> np.ndarray:
    """Create a sparse vector with 3‑6 random positive spikes, projected onto the simplex."""
    k = np.random.randint(min_k, max_k + 1)
    pos = np.random.choice(n, size=k, replace=False)
    spikes = np.zeros(n)
    spikes[pos] = np.random.rand(k) + 0.1   # avoid exact zeros
    return project_simplex(spikes)


def upsample_vector(old: np.ndarray, new_n: int) -> np.ndarray:
    """Linear interpolation of a simplex vector to a new length."""
    if old.shape[0] == new_n:
        return old.copy()
    x_old = np.linspace(0.0, 1.0, old.shape[0])
    x_new = np.linspace(0.0, 1.0, new_n)
    up = np.interp(x_new, x_old, old)
    return project_simplex(up)
```
