assistantfinal**Solution Overview**

The evaluation function is scale‑invariant, i.e. only the *shape* of the
non‑negative vector matters (the sum is normalised to 1).  
For a vector `a` of length `n`

```
score(a) = 2·n·max(conv(a,a))
```

with `conv` the full linear convolution.
The theoretical lower bound `score = 1` is obtained when `conv(a,a)` is
exactly uniform (its maximum would be `1/(2n‑1)`).  The previous code
searched the Beta‑family and performed random pairwise mass transfers.
It stopped at `1.507820`.

The new algorithm keeps the same cheap FFT based convolution but
improves the local search in two ways:

1. **Gradient‑guided mass transfer** –  
   For the current vector we compute the sub‑gradient of the
   quantity `max(conv)`.  The gradient tells which coordinates contribute
   most to the current maximum.  Moving a small amount of probability mass
   from a *high‑gradient* index to a *low‑gradient* index is the most
   promising local move.  This replaces the blind random pair swaps.

2. **Adaptive step size & occasional random jumps** –  
   The transferred amount is a fraction of the source entry; the fraction
   is reduced slowly so the search can first make large corrections and
   later fine‑tune.  If a gradient move does not improve the score we try
   a few random moves before decreasing the step size.

The overall flow

* warm‑start (global starter → Dirichlet draws → fine Beta/mixture scan)
* iterative gradient‑guided hill climbing until the time budget expires
* return the best vector found (renormalised to sum = 1).

All operations run in `O(n log n)` per iteration (FFT of length
`≈2·n`) and easily fit into the 1000 s budget for `n = 4096`.

```python
"""
Hybrid search for a step‑function that minimises
    score = 2·n·max(conv(a,a)) / (sum(a)²)

The algorithm consists of three phases:

1. Warm‑start:
   - optional global starter (`height_sequence_1`);
   - a few Dirichlet random vectors;
   - fine scan of the symmetric Beta(p,p) family together with convex
     mixtures with the uniform vector.

2. Gradient‑guided hill climbing:
   - The sub‑gradient of `max(conv(a,a))` is computed (exactly, no
     approximation).
   - Mass is transferred from the index with the largest gradient (most
     responsible for the current peak) to the index with the smallest
     gradient.
   - The transfer amount starts relatively large and decays over time.
   - If a gradient move fails to improve the score, a few random pair
     moves are tried before the step size is reduced.

3. Return the best sequence (renormalised to sum = 1).  The routine respects
   the supplied time budget and prints progress.
"""

import time
import numpy as np

# Low‑level utilities (no closures, no lambdas)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray, L_fft: int) -> np.ndarray:
    """
    Full linear convolution a⋆a (length 2·len(a)‑1) via FFT.
    Returns a 1‑D array of length 2·len(a)‑1.
    """
    Af = np.fft.rfft(a, n=L_fft)
    conv = np.fft.irfft(Af * Af, n=L_fft)
    return conv[: 2 * a.shape[0] - 1]


def _score_of(a: np.ndarray, n: int, L_fft: int) -> float:
    """Exact score used by the evaluator (a is assumed to sum to 1)."""
    conv = _conv_self_fft(a, L_fft)
    max_b = conv.max()
    return float(2.0 * n * max_b)


def _beta_shape(n: int, p: float) -> np.ndarray:
    """
    Symmetric Beta(p,p) density on the grid x_i = (i+0.5)/n,
    normalised to sum = 1.
    """
    i = np.arange(n, dtype=np.float64)
    x = (i + 0.5) / n
    a = np.power(x, p - 1.0) * np.power(1.0 - x, p - 1.0)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n)
    return a / s


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    {x | x_i ≥ 0, sum x_i = 1}.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are zero – return uniform
        return np.full(n, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _gradient_of_maxconv(a: np.ndarray, conv: np.ndarray, max_val: float) -> np.ndarray:
    """
    Sub‑gradient of max(conv(a,a)) at the current vector `a`.
    conv is the full convolution (length 2·n‑1), max_val = conv.max().
    The gradient has the same length as `a`.
    """
    n = a.shape[0]
    # indices where the convolution attains its maximum
    max_idx = np.where(conv >= max_val - 1e-14)[0]

    # uniform part coming from the a_j term in each active constraint
    grad = np.full_like(a, len(max_idx), dtype=np.float64) * a

    # add the a_{k‑j} contributions for every active k
    for k in max_idx:
        start = max(0, k - (n - 1))
        end = min(n - 1, k)
        # i runs over the indices that actually participate
        i = np.arange(start, end + 1, dtype=np.int64)
        grad[i] += a[k - i]
    return grad

        sample = rng.gamma(shape=c, scale=1.0, size=n)
        a = sample / sample.sum()
        sc = _score_of(a, n, L_fft)
        if sc < best_score:
            best_score, best_a = sc, a.copy()
            print(f"[{time.time() - start_time:.2f}s] Dirichlet warm‑start → score = {sc:.6f}")

    # --------------------------------------------------------------
    # 2️⃣  Fine scan of the symmetric Beta(p,p) family + mixtures
    # --------------------------------------------------------------
    print(f"[{time.time() - start_time:.2f}s] Fine Beta‑family scan")
    # p values – finer grid around the promising region near 0.5
    p_vals = np.concatenate((
        np.linspace(0.10, 0.30, 11),   # 0.10 … 0.30
        np.linspace(0.35, 0.70, 15),   # 0.35 … 0.70
        np.linspace(0.75, 1.50, 16)    # 0.75 … 1.50
    ))
    lam_grid = np.linspace(0.0, 1.0, 21)   # 0.0 … 1.0 step 0.05

    for p in p_vals:
        shape = _beta_shape(n, p)

        # pure Beta
        sc = _score_of(shape, n, L_fft)
        if sc < best_score:
            best_score, best_a = sc, shape.copy()
            print(f"[{time.time() - start_time:.2f}s] pure p={p:.3f} → score = {sc:.6f}")

        # mixtures with uniform
        for lam in lam_grid:
            cand = lam * shape + (1.0 - lam) * uniform
            cand /= cand.sum()
            sc = _score_of(cand, n, L_fft)
            if sc < best_score:
                best_score, best_a = sc, cand.copy()
                print(f"[{time.time() - start_time:.2f}s] p={p:.3f} λ={lam:.2f} → score = {sc:.6f}")

        if time.time() >= deadline:
            break

    # --------------------------------------------------------------
    # 3️⃣  Gradient‑guided hill‑climbing refinement
    # --------------------------------------------------------------
    print(f"[{time.time() - start_time:.2f}s] Gradient‑guided hill‑climb")
    a = best_a.copy()
    # initial absolute transfer amount (roughly twice the mean entry)
    step_abs = max(1e-4, 2.0 / n)
    # counters for adaptive reduction
    it = 0
    no_improve = 0

    while time.time() < deadline:
        it += 1
        # current convolution and its maximum
        conv = _conv_self_fft(a, L_fft)
        max_val = conv.max()

        # compute sub‑gradient of the max‑convolution
        grad = _gradient_of_maxconv(a, conv, max_val)

        # indices with highest / lowest gradient
        i_max = int(np.argmax(grad))
        i_min = int(np.argmin(grad))
        if a[i_max] <= 0.0 or i_max == i_min:
            # fallback to a random pair if the obvious move is impossible
            i_max, i_min = rng.choice(n, size=2, replace=False)

        # try a gradient move
        delta = min(a[i_max] * 0.5, step_abs)   # move at most half of the source mass
        if delta > 0.0:
            cand = a.copy()
            cand[i_max] -= delta
            cand[i_min] += delta
            sc = _score_of(cand, n, L_fft)
            if sc < best_score:
                best_score, best_a = sc, cand.copy()
                a = cand
                no_improve = 0
                print(f"[{time.time() - start_time:.2f}s] grad‑move → score = {sc:.6f}")
                continue
            else:
                no_improve += 1
        else:
            no_improve += 1

        # occasional random move (to escape possible plateaus)
        if no_improve % 50 == 0:
            i, j = rng.choice(n, size=2, replace=False)
            delta = min(a[i], step_abs * 0.5)
            if delta > 0.0:
                cand = a.copy()
                cand[i] -= delta
                cand[j] += delta
                sc = _score_of(cand, n, L_fft)
                if sc < best_score:
                    best_score, best_a = sc, cand.copy()
                    a = cand
                    no_improve = 0
                    print(f"[{time.time() - start_time:.2f}s] random‑jump → score = {sc:.6f}")

        # decay the step size slowly (geometric)
        if it % 500 == 0:
            step_abs = max(step_abs * 0.95, 1e-7)

    # --------------------------------------------------------------
    # Normalisation & return
    # --------------------------------------------------------------
    best_a = np.maximum(best_a, 0.0)
    total = best_a.sum()
    if total > 0.0:
        best_a = best_a / total
    else:
        best_a = uniform.copy()

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(v) for v in best_a]
```
