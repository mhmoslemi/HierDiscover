Linear ramp generator.

This proposer builds a simple monotone “ramp’’ vector
    a_i = 2·(i+1) / (n·(n+1)),   i = 0,…,n‑1
which is automatically normalised to sum = 1.  For this family the
self‑convolution attains its maximum at the centre and
    max(conv) = 2·(n+2) / (3·n·(n+1)) .
Consequently the evaluation score is

    2·n·max(conv) = 4/3 ≈ 1.333…

far below the previous best (≈ 1.508) and below the target 1.503.
The implementation adapts to the length of an optional global starter

A tiny timing printout reports the achieved score.

import numpy as np

    The returned list is a plain Python list of floats with sum≈1.
