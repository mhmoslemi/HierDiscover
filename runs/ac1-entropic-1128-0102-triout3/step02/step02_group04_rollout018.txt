Propose a step‑function that (hopefully) beats the previous 1.5365 bound.

The search consists of three stages:

1. **Exploratory parametric sweep** – try a handful of simple families
   (half‑binomial, uniform, power‑law, exponential, sine, semi‑circle,
   arcsine, and mixtures).  Each candidate is normalised to sum‑one and
   evaluated with ``evaluate_sequence``.  The best of these is kept as a
   starting point.

2. **Multiplicative (exponentiated) gradient descent on the simplex**.
   The variables are kept in the probability simplex via a
   multiplicative update `a ← a * exp(-η·g)` followed by renormalisation.
   The gradient `g` is an *aggregate sub‑gradient* obtained from the
   several largest peaks of the auto‑convolution (by default the top‑5).
   This drives the shape away from all high peaks, not only the global
   maximum.  An Adam‑style schedule for the learning rate and occasional
   Metropolis‑type uphill moves are employed.

3. **Restarts / perturbations** – after a long period without improvement
   the current iterate is re‑initialised from the best solution seen so
   far with a small random perturbation.

All heavy work (convolution, correlation) uses a real FFT with a power‑of‑2

def sqrt_series(n: int) -> np.ndarray:
    """
    Half‑binomial coefficients: a_i = C(2i,i) / 4**i, normalised to sum=1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def conv_fft(a: np.ndarray) -> np.ndarray:
    """
    Autoconvolution a*a (full length 2*n-1) using a real FFT.
    A power‑of‑2 transform length is chosen automatically.
    """
    n = a.shape[0]
    m = 2 * n - 1
    # next power of two ≥ m
    L = 1 << ((m - 1).bit_length())
    A = np.fft.rfft(a, n=L)
    conv_full = np.fft.irfft(A * A, n=L)[:m]
    return conv_full
