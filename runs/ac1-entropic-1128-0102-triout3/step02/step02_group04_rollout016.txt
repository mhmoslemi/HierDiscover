Propose a non‑negative step‑function sequence that minimizes the evaluation
function.

The algorithm is a two‑phase optimisation on the probability simplex:

1. **Initialisation** – start from the best known construction
   (`height_sequence_1`) if it exists, otherwise from the classic half‑binomial
   series (the coefficients of (1‑z)^‑½, normalised to sum = 1).

2. **Smooth exponential‑gradient refinement** – we minimise a smooth
   approximation of the max‑convolution using a log‑sum‑exp (soft‑max)
   with a temperature‑like parameter ``alpha`` that is slowly increased.
   The gradient of the smooth objective w.r.t. the coefficients is computed
   analytically (via a second convolution).  An exponentiated‑gradient (mirror
   descent) update on the simplex is performed, keeping the iterates
   non‑negative and automatically respecting the sum‐to‑1 constraint.
   The step size ``eta`` decays slowly and the gradient is centred
   (mean‑subtracted) to stay in the tangent space of the simplex.

   Random perturbations and occasional restarts (Dirichlet draws) are
   injected to escape plateaus.  The best sequence seen is tracked and the
   provided ``evaluate_sequence`` routine is called only when an improvement
   occurs (to keep overhead low).

The whole routine respects the 1000 s time budget; a few seconds are kept
as a safety margin.  The returned value is a plain list of floats ready for

import time
import numpy as np
from scipy import sparse  # only for potential future extensions; not used directly

# Helper functions (top‑level, no closures)

def sqrt_series(n: int) -> np.ndarray:
    """First n coefficients of the half‑binomial series, normalised to sum = 1."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection onto the probability simplex.
    Implements the algorithm of Duchi et al. (2008).
    """
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def conv_full(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Linear convolution of two real vectors using an FFT.
    Returns the full convolution of length len(x)+len(y)-1.
    """
    lx = x.shape[0]
    ly = y.shape[0]
    size = lx + ly - 1
    X = np.fft.rfft(x, n=size)
    Y = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(X * Y, n=size)
    return conv


def conv_self(x: np.ndarray) -> np.ndarray:
    """Fast self‑convolution x*x (full length)."""
    n = x.shape[0]
    return conv_full(x, x)
