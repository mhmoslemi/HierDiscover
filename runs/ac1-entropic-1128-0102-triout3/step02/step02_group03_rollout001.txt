The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2},
\qquad a_i\ge 0,
\]

where `a*a` denotes the linear (full) self‑convolution of the step‑function
`a`.  
For a fixed ℓ₁‑norm \(S=\sqrt{2n}\) the denominator is constant, so we only have to
reduce the maximal entry of the convolution.

The algorithm combines three complementary ideas

1. **Projected sub‑gradient descent** – the exact sub‑gradient of the
   maximal convolution entry is obtained from the active set of indices.
   The step size is adapted dynamically and the iterate is projected onto
   the ℓ₁‑simplex \(\{x\ge 0,\;\sum x=S\}\).

2. **Random mass‑transfer moves** – a simple simulated‑annealing style
   neighbourhood that can jump out of shallow local minima.

3. **Linear‑programming refinement** – given the current iterate `a`
   we solve  

   \[
   \max_{b\ge 0}\ \sum_i b_i\quad\text{s.t.}\quad (a*b)_k\le M\;\;\forall k,
   \]

   where \(M=\max_k(a*a)_k\).  
   The LP supplies a direction `b` that pushes mass to positions where
   the current bound is not tight.  Mixing `a` with the (renormalised) `b`
   strictly reduces the maximal convolution value.  The LP is solved
   with **CVXPY** (ECOS/​SCS).  It is only invoked periodically (≈ 5 % of
   all iterations) because it is the most expensive step.

The three moves are chosen probabilistically (`p_subgrad≈0.75`,
`p_random≈0.20`, `p_lp≈0.05`).  The whole procedure runs until the time
budget expires (default 1000 s) or the target bound `1.503` is reached.
All iterates are kept on the ℓ₁‑simplex, therefore the returned sequence
can be fed directly to `evaluate_sequence`.

```python
"""
Hybrid optimisation for the step‑function problem.

The routine ``propose_candidate`` searches for a non‑negative vector
``a`` (length n) that minimises the evaluation function

    2·n·max(conv(a,a)) / (sum(a)**2)

subject to the ℓ₁‑norm Σ a_i = √(2n).

Algorithmic components
----------------------
1. Projected sub‑gradient descent on the exact max‑convolution.
2. Random “mass‑transfer’’ moves (simulated‑annealing style).
3. Periodic linear‑programming refinement:
   maximise Σ b_i  s.t.  (a*b)_k ≤ M  (M = current max‑convolution).

All updates are projected onto the simplex {x≥0, Σx = √(2n)}.
The search runs until the time budget (default 1000 s) is exhausted
or the target bound 1.503 is attained.
"""

import time
import numpy as np
import cvxpy as cp

# ----------------------------------------------------------------------
# Helper utilities – top‑level functions (no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _convolve_self_fft(a: np.ndarray, nfft: int) -> np.ndarray:
    """Linear self‑convolution using FFT (real output)."""
    A = np.fft.rfft(a, n=nfft)
    conv = np.fft.irfft(A * A, n=nfft)[: 2 * a.size - 1]
    return conv


def _project_to_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of v onto the simplex {x ≥ 0, Σx = target_sum}.
    Implementation follows the algorithm of Duchi et al. (2008).
    """
    if target_sum < 0:
        raise ValueError("target_sum must be non‑negative")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.zeros_like(v)
    rho = ind[cond].max()
    theta = cssv[cond].max() / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _grad_max_subgrad(a: np.ndarray, mask: np.ndarray, nfft: int) -> np.ndarray:
    """
    Sub‑gradient of max_k (a*a)[k] at the current active set.

    Parameters
    ----------
    a   : array, shape (n,)
    mask: binary array, shape (2*n-1), 1 where convolution attains its max
    nfft: length of FFT (next power of two ≥ 2*n-1)

    Returns
    -------
    grad: array, shape (n,)
    """
    w = mask.astype(float)
    w_sum = w.sum()
    if w_sum == 0.0:
        return np.zeros_like(a)

    w = w / w_sum                     # normalise to a probability vector
    a_rev = a[::-1]

    A_rev = np.fft.rfft(a_rev, n=nfft)
    W = np.fft.rfft(w, n=nfft)

    grad_full = np.fft.irfft(W * A_rev, n=nfft)[: 2 * a.size - 1]

    n = a.size
    grad = 2.0 * grad_full[n - 1 : n - 1 + n]  # centre part
    return grad


def _build_conv_matrix(a: np.ndarray) -> np.ndarray:
    """
    Construct the dense matrix A (shape (2*n-1, n)) such that
    (a * b)_k = A[k, :] @ b for any b.
    """
    n = a.shape[0]
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    # column j contains a shifted copy of a
    for j in range(n):
        A[j : j + n, j] = a
    return A


# ----------------------------------------------------------------------
# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Hybrid sub‑gradient / random / LP search for a low‑max‑convolution
    step‑function.  Returns the best sequence found before the time budget
    expires.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # safety margin

    # --------------------------------------------------------------
    # Problem dimensions & normalisation
    # --------------------------------------------------------------
    if 'height_sequence_1' in globals():
        init_seq = np.array(height_sequence_1, dtype=np.float64)
        n = init_seq.size
    else:
        n = 2000
        init_seq = None

    S = np.sqrt(2.0 * n)                     # ℓ₁‑norm to keep fixed
    nfft = _next_pow2(2 * n - 1)

    # initialise the iterate
    if init_seq is not None:
        a = _project_to_simplex(init_seq, S)
    else:
        a = np.full(n, S / n, dtype=np.float64)   # uniform start

    # bookkeeping
    conv = _convolve_self_fft(a, nfft)
    cur_max = conv.max()
    cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

    best_a = a.copy()
    best_score = cur_score

    # --------------------------------------------------------------
    # Hyper‑parameters
    # --------------------------------------------------------------
    # sub‑gradient step size (base will be scaled by 1/√iteration)
    step_base = 0.9 * S / n
    eps_mask = 1e-12

    # probabilities for the three move types
    p_subgrad = 0.75
    p_random = 0.20
    p_lp = 0.05

    # random mass‑transfer parameters
    eps_transfer = 0.08

    # LP mixing coefficient
    lp_mix = 0.25   # a ← (1‑lp_mix)·a + lp_mix·b̂

    # restart handling
    no_improve = 0
    max_no_improve = 3000

    iteration = 0

    # --------------------------------------------------------------
    # Main optimisation loop
    # --------------------------------------------------------------
    while time.time() < deadline:
        # recompute convolution and objective for the current point
        conv = _convolve_self_fft(a, nfft)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

        # keep global best
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(
                f"[{iteration:07d}] New best: {best_score:.6f} (max={cur_max:.6f})"
            )
            no_improve = 0
        else:
            no_improve += 1

        # early exit if target reached
        if best_score < 1.503:
            print(
                f"Target reached after {iteration} iterations (best={best_score:.6f})"
            )
            break

        # ----------------------------------------------------------
        # Choose move type
        # ----------------------------------------------------------
        r = np.random.rand()
        if r < p_subgrad:
            # -------- Sub‑gradient step ----------
            mask = (conv >= cur_max - eps_mask).astype(int)
            grad = _grad_max_subgrad(a, mask, nfft)
            grad_norm = np.linalg.norm(grad)
            if grad_norm > 0:
                eta = step_base / np.sqrt(iteration + 1.0)
                step = eta * grad / grad_norm
                a_candidate = _project_to_simplex(a - step, S)
            else:
                a_candidate = a.copy()

        elif r < p_subgrad + p_random:
            # -------- Random mass‑transfer ----------
            if a.sum() > 0:
                src_probs = a / a.sum()
                i = np.random.choice(n, p=src_probs)
            else:
                i = np.random.randint(n)
            j = i
            while j == i:
                j = np.random.randint(n)

            delta = eps_transfer * a[i]
            if delta <= 0:
                delta = eps_transfer * S / n

            a_candidate = a.copy()
            a_candidate[i] -= delta
            a_candidate[j] += delta
            a_candidate = _project_to_simplex(a_candidate, S)

        else:
            # -------- Linear‑programming refinement ----------
            # Build convolution matrix for the current a
            A_mat = _build_conv_matrix(a)
            M = cur_max

            # Linear program: maximise Σ b_i  s.t. A·b ≤ M, b ≥ 0
            b_var = cp.Variable(n, nonneg=True)
            constraints = [A_mat @ b_var <= M + 1e-12]
            objective = cp.Maximize(cp.sum(b_var))
            prob = cp.Problem(objective, constraints)

            # Try ECOS first, fall back to SCS
            try:
                prob.solve(
                    solver=cp.ECOS,
                    warm_start=True,
                    max_iters=5000,
                    abstol=1e-8,
                    reltol=1e-6,
                )
            except Exception:
                prob.solve(
                    solver=cp.SCS,
                    warm_start=True,
                    max_iters=2000,
                    verbose=False,
                )

            b_val = b_var.value
            if b_val is None or np.isnan(b_val).any():
                # LP failed – fall back to a cheap random move
                a_candidate = a.copy()
            else:
                b_sum = b_val.sum()
                if b_sum <= 0:
                    a_candidate = a.copy()
                else:
                    # Scale b to the ℓ₁‑norm S
                    b_scaled = b_val * (S / b_sum)
                    # Mix the current iterate with the LP direction
                    a_candidate = (1.0 - lp_mix) * a + lp_mix * b_scaled
                    # Numerical drift may break the simplex constraint
                    a_candidate = _project_to_simplex(a_candidate, S)

        # ----------------------------------------------------------
        # Evaluate candidate and decide acceptance
        # ----------------------------------------------------------
        cand_conv = _convolve_self_fft(a_candidate, nfft)
        cand_max = cand_conv.max()
        cand_score = 2.0 * n * cand_max / (a_candidate.sum() ** 2)

        accept = False
        if cand_score < cur_score:
            accept = True
        else:
            # Metropolis acceptance with a slowly decaying temperature
            # (temperature is not a separate parameter any more – we use a
            # simple decreasing schedule based on the iteration number)
            temperature = max(0.02 * (0.9995 ** iteration), 1e-6)
            prob_acc = np.exp(-(cand_score - cur_score) / temperature)
            if np.random.rand() < prob_acc:
                accept = True

        if accept:
            a = a_candidate
        else:
            # occasional jitter to escape tiny plateaux
            if np.random.rand() < 0.01:
                jitter = np.random.randn(n) * (step_base * 0.5)
                a = _project_to_simplex(a + jitter, S)

        # Stagnation restart
        if no_improve >= max_no_improve:
            print(f"[{iteration:07d}] Stagnation restart (no improvement).")
            alpha = np.full(n, 0.4)
            a = np.random.dirichlet(alpha) * S
            no_improve = 0

        iteration += 1

    # ------------------------------------------------------------------
    # Final verification & return
    # ------------------------------------------------------------------
    best_a = _project_to_simplex(best_a, S)
    final_score = evaluate_sequence(best_a.tolist())
    print(
        f"Finished after {iteration} iterations. Best final score = {final_score:.6f}"
    )
    return best_a.tolist()
```
