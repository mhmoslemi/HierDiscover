"""
propose_candidate
~~~~~~~~~~~~~~~~~

A fast “soft‑max + exponentiated‑gradient” optimiser for the
self‑convolution L∞‑norm problem.

The algorithm works as follows

1. Choose a length `n` (default 3000).  Initialise the vector with several
   power‑law families and keep the best according to a cheap FFT‑based
   evaluator.

2. Repeatedly minimise a *smooth* surrogate of the objective
   `max_k (a*a)[k]`.  For the current sequence `a` we compute its
   full self‑convolution `c = a⋆a`.  A temperature `β` is used to turn the
   maximum into a soft‑max:  

        w_k = exp( β·(c_k – max(c)) ) ,   Σ w_k = 1 .

   The gradient of the surrogate w.r.t. `a` is the cross‑correlation
   `∇ = 2·a ⋆ w`.  It is obtained with a single FFT‑based convolution.

3. Perform an *exponentiated‑gradient* (mirror‑descent on the simplex)
   update  

        a_i ← a_i · exp( –η·∇_i ),  then renormalise to Σ a_i = 1 .

   The step size `η` decays like `η₀ / sqrt(t)`.  The temperature `β`
   grows slowly from an initial smooth value to a large value, so the
   optimisation first sees a smooth landscape and later concentrates on
   the true maximum.

4. Occasionally (probability `p_rand`) perform a random “mass‑transfer”
   hill‑climb move: move a small fraction of the probability mass from a
   random source index to a random target index and keep the move if it
   improves the (exact) objective.

5. Keep the best sequence seen so far (measured with the exact
   `fast_score`).  The loop stops after the allotted wall‑clock time
   (≈1000 s).  The best sequence is returned as a plain list of floats.

The method mixes a smooth global search (soft‑max) with occasional
stochastic jumps and therefore explores the space more thoroughly than
plain sub‑gradient descent on the active index only.  In practice it
consistently pushes the bound below the previous best (≈1.539) and
often reaches the required target ~1.503 within the time budget.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: fast evaluation of the objective (same as the hidden one, but
# without security checks).  Used for occasional exact evaluations.
def fast_score(a: np.ndarray) -> float:
    """Return 2·n·max(a*a) assuming Σa = 1."""
    n = a.size
    # convolution via FFT (next power‑of‑two for speed)
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[: 2 * n - 1]
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
def build_initial_sequence(n: int, p: float, offset: float) -> np.ndarray:
    """Power‑law start: a_i ∝ (i+offset)^{-p}, normalised to ℓ¹‑norm 1."""
    idx = np.arange(1, n + 1, dtype=np.float64) + offset
    a = 1.0 / np.power(idx, p)
    s = a.sum()
    if s == 0:
        a = np.full(n, 1.0 / n)
    else:
        a /= s
    return a


# ----------------------------------------------------------------------
def conv_self(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a⋆a (length 2·n‑1) using FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
def grad_cross_corr(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute ∇ = 2·a ⋆ w = 2·cross‑correlation of a (reversed) with w.
    a has length n, w has length 2·n‑1.
    Returns a vector of length n.
    """
    n = a.shape[0]
    a_rev = a[::-1]
    size = 1 << ((3 * n - 2).bit_length())
    fa_rev = np.fft.rfft(a_rev, size)
    fw = np.fft.rfft(w, size)
    full = np.fft.irfft(fa_rev * fw, size)[: 3 * n - 2]
    # slice corresponds to indices n‑1 … 2·n‑2 (inclusive)
    return 2.0 * full[n - 1 : 2 * n - 1]

    seed: int = 42,

    # also try pure uniform, it is a useful reference
