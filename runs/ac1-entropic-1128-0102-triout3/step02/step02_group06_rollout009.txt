```
        alpha = 0.001

    best_score = cur_score
```

The function below searches for a non‑negative step‑function `a = (a₀,…,aₙ₋₁)` that minimises  

```
    2·n·max(a*a) / (∑a)²     ( = max(a*a)  when Σa = √(2n) )
```

The approach combines three ideas that complement the previous Adam‑mirror‑descent
code:

1. **Start from the best known construction** (`height_sequence_1` if it exists).  
2. **Deterministic gradient moves** – for the index `k` where the self‑convolution
   is maximal we compute the exact sub‑gradient  
   `∂max/∂aᵢ = 2·a_{k‑i}` (only for the overlapping indices).  
   We move a small amount of mass from the coordinate with the largest
   gradient to the one with the smallest gradient and project back onto the
   simplex `Σa = √(2n)`.  This is a projected sub‑gradient step that always
   reduces (or keeps) the objective.
3. **Stochastic exploration** – when progress stalls we perform a random
   jitter (Gaussian noise) on the current best vector and continue the
   deterministic phase.  The jitter is followed by a Euclidean projection onto
   the simplex, keeping the ℓ₁‑norm fixed.

The loop runs until the time budget (≈ 1000 s) is exhausted or the target
objective `1.503` is reached.  All heavy work (convolution, gradient) is done
with FFTs (`O(n log n)`) and the code never creates large dense matrices, so it
comfortably fits into the given limits.

```python
"""
search for a step function that minimises
    2·n·max(a*a)/(sum(a)**2)
using projected sub‑gradient steps on the simplex together with
occasional random jitter to escape stagnation.
"""

import time
import numpy as np

# ---------------------------------------------------------------------------
# Helper functions – all top‑level (no closures)
# ---------------------------------------------------------------------------

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _convolve_self_fft(a: np.ndarray, nfft: int) -> np.ndarray:
    """
    Linear convolution a*a using the FFT.
    Returns the first (2·len(a)‑1) entries (real values).
    """
    A = np.fft.rfft(a, nfft)
    conv = np.fft.irfft(A * A, n=nfft)
    return conv[: 2 * a.size - 1]


def _grad_max(a: np.ndarray, k_max: int) -> np.ndarray:
    """
    Exact sub‑gradient of max(a*a) w.r.t. a at the index `k_max`.
    The derivative of (a*a)[k] w.r.t. a_i equals 2·a_{k‑i}
    if the index lies in the support, otherwise 0.
    """
    n = a.shape[0]
    grad = np.zeros_like(a)
    i_low = max(0, k_max - (n - 1))
    i_high = min(n - 1, k_max)
    if i_low <= i_high:
        idx = np.arange(i_low, i_high + 1)
        grad[idx] = 2.0 * a[k_max - idx]
    return grad


def _project_to_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of v onto the simplex {x ≥ 0, Σx = target_sum}.
    """
    if target_sum < 0:
        raise ValueError("target_sum must be non‑negative")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.zeros_like(v)
    rho = ind[cond].max()
    theta = cssv[cond].max() / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ---------------------------------------------------------------------------
# Main search routine
# ---------------------------------------------------------------------------

    previous best score (~1.5435).  The method performs projected sub‑gradient
    descent on the simplex with occasional random jitter.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5  # safety margin

    # --------------------------------------------------------------

    # --------------------------------------------------------------
    if 'height_sequence_1' in globals():

        n = a.size

        # a simple “U‑shape’’ initial guess (large on the edges, small in centre)

        alpha = 0.001                 # decay rate for the edge exponentials
        a = np.exp(-alpha * i) + np.exp(-alpha * (n - 1 - i))
        a = a.astype(np.float64)

    # Enforce the required ℓ₁‑norm Σa = √(2·n)
    S = np.sqrt(2.0 * n)
    a = a * (S / a.sum())

    # --------------------------------------------------------------

    # --------------------------------------------------------------
    nfft = _next_pow2(2 * n - 1)

    # --------------------------------------------------------------

    cur_score = _objective(a)
```
