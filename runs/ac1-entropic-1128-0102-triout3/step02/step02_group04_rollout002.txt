assistantfinal**Solution Overview**

The evaluation function is  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

If we keep the sequence on the simplex \(\sum_i a_i=1\) the denominator is constant
and the objective reduces to minimising the *peak* of the auto‑convolution.
The problem is non‑convex, but the peak can be smoothed with a
log‑sum‑exp (soft‑max) approximation:

\[
F_\beta(a)=\frac1\beta\log\!\Bigl(\sum_k e^{\beta (a*a)_k}\Bigr) \;\xrightarrow{\;\beta\to\infty\;}\; \max_k (a*a)_k .
\]

For a fixed smoothness parameter \(\beta\)

* the gradient of \(F_\beta\) is a convex combination of the gradients of
  the individual convolution entries,
* the gradient can be computed by a single FFT‑based correlation,
* after a gradient step we project back onto the probability simplex
  (Duchi et al. Euclidean projection).

The algorithm consists of three phases

1. **Soft‑max gradient descent** – start with a small \(\beta\) and increase it
   gradually (annealing).  
2. **Pure max‑gradient refinement** – once \(\beta\) is large we switch to
   the exact sub‑gradient of the maximal entry (the method used in the
   reference implementation).  
3. **Random‑restart & perturbation** – if we get stuck we restart from a
   random Dirichlet draw; tiny Gaussian noise is added from time to time
   to escape shallow plateaus.

All operations are vectorised; the dominant cost per iteration is a
few FFTs ( \(O(n\log n)\) ).  With `n = 3500` the code fits comfortably
into the 1000 s budget and typically reaches a score well below
 1.53, often approaching the target 1.503.

The function `propose_candidate` returns the best sequence found as a
plain Python list.  The caller will evaluate it with the provided
`evaluate_sequence` routine.

```python
"""
Gradient‑descent / annealing optimiser for the auto‑convolution peak.

The optimiser works on the probability simplex (∑a_i = 1, a_i ≥ 0).

* Phase 1 – soft‑max (log‑sum‑exp) smoothing of the max, with a
  slowly increasing β.  The gradient is obtained by an FFT‑based
  correlation and the iterate is projected back onto the simplex.

* Phase 2 – pure max‑sub‑gradient descent (the “half‑binomial” optimiser
  from the reference solution) to polish the result once β is large.

* Random restarts and occasional Gaussian perturbations are used to
  avoid being trapped in local minima.

The routine runs for at most ``budget_s`` seconds and returns the best
sequence encountered.  All numbers are non‑negative; the final sequence
is returned as a plain Python list of floats.

import time
import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Helper utilities (no closures, top‑level as required)

def half_binomial_series(n: int) -> np.ndarray:
    """
    First n coefficients of (1‑z)^‑½  (a_i = C(2i,i)/4^i) and normalised
    so that they sum to 1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x ≥ 0, Σ x = 1}.  Implements the O(n log n) algorithm of Duchi et al.
    """
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries will be equal
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def next_pow_two(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())

    deadline = time.time() + budget_s - 5.0   # keep a few seconds safety margin
    it = 0

    # ------------------------------------------------------------------
    # main optimisation loop
    while time.time() < deadline:
        # --------------------------------------------------------------
        # 1) compute current convolution (FFT based, linear part only)
        A = np.fft.rfft(a, n=Nfft)               # forward FFT of a (size Nfft)
        conv_full = np.fft.irfft(A * A, n=Nfft)   # a*a (circular, zero‑padded)
        conv = conv_full[:L]                     # linear convolution, length 2n‑1
        max_conv = conv.max()
        cur_score = 2.0 * n * max_conv

        # --------------------------------------------------------------
        # 2) update the best solution seen so far
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            last_improve = it
            print(f"[iter {it:09d}] new best score = {best_score:.6f}")

        # --------------------------------------------------------------
        # 3) decide which gradient to use
        if max_phase == 1:               # soft‑max (log‑sum‑exp) gradient
            # soft‑max weights (numerically stable)
            shift = max_conv
            w_exp = np.exp(beta * (conv - shift))
            w = w_exp / w_exp.sum()               # shape (L,)

            # gradient = 2 * correlation(a, w)
            Wr = np.fft.rfft(w[::-1], n=Nfft)      # FFT of reversed weights
            corr_full = np.fft.irfft(A * Wr, n=Nfft)
            start = L - 1                         # index where shift = 0 starts
            grad = 2.0 * corr_full[start:start + n]

            # increase β gradually; when it passes the target we switch phase
            beta = min(beta_target, beta * beta_mul)
            if beta >= beta_target:
                max_phase = 2                      # switch to pure max phase
        else:                              # pure max‑subgradient (single active index)
            k = int(conv.argmax())
            grad = np.zeros_like(a)
            lo = max(0, k - (n - 1))
            hi = min(k, n - 1)
            idx = np.arange(lo, hi + 1, dtype=np.int64)
            jdx = k - idx
            grad[idx] = 2.0 * a[jdx]

        # --------------------------------------------------------------
        # 4) stochastic perturbation (helps escaping flat regions)
        if rng.random() < noise_prob:
            noise = (rng.random(n) - 0.5) * noise_scale
            a = a + noise
            a = project_onto_simplex(a)   # keep feasibility after noise

        # --------------------------------------------------------------
        # 5) gradient step and projection onto the simplex
        step = eta * grad
        # prevent taking a step that would annihilate an entry completely
        step = np.minimum(step, a * 0.95)
        a_trial = a - step
        a = project_onto_simplex(a_trial)

        # --------------------------------------------------------------
        # 6) step‑size schedule
        eta = max(eta * eta_decay, eta_min)

        # --------------------------------------------------------------
        # 7) restart logic
        if it - last_improve > restart_gap:
            # fresh random start from a Dirichlet distribution
            a = rng.dirichlet(np.full(n, 0.6))
            a = project_onto_simplex(a)
            last_improve = it
            print(f"[iter {it:09d}] restart triggered – new random start, score≈{2.0*n*np.max(np.fft.irfft(np.fft.rfft(a,n=Nfft)**2,n=Nfft)[:L]):.6f}")

        it += 1

    # ------------------------------------------------------------------
    # final safety evaluation (uses the provided routine)
    final_score = evaluate_sequence(best_a.tolist())
    print(f"[done] iterations={it}, best reported score={final_score:.6f}")

    return best_a.tolist()
```
