Propose a step‑function that (hopefully) improves the known bound.
The algorithm consists of two stages:

1. **Linear‑programming refinement** – starting from a half‑binomial
   (or the previously discovered best sequence) we solve a small LP:
   maximise Σ bⱼ subject to the linear constraints (a∗b)ₖ ≤ M
   (M = max (a∗a)) and bⱼ ≥ 0.
   The solution b is scaled back to the original ℓ₁‑norm and mixed
   with the current a.  Repeating this a few times flattens the
   self‑convolution and typically yields a noticeable drop in the
   evaluation score.

2. **Projected (sub)‑gradient descent with annealing** – after the LP
   stage we continue a long‑running gradient descent on the simplex,
   exactly as in the previous state‑of‑the‑art code, but starting from
   a much better point.  Random perturbations, a cooling schedule and
   occasional restarts help to escape plateaus.

Both stages respect the non‑negativity and ∑a = 1 constraints, which
means the evaluation function reduces to 2·n·max(a∗a).  The routine
keeps the best sequence seen and returns it as a plain Python list.
"""

import time
import numpy as np
import scipy.optimize as opt

# ----------------------------------------------------------------------
# Helper functions (top‑level, no closures)
# ----------------------------------------------------------------------


def sqrt_series(n: int) -> np.ndarray:
    """
    First n coefficients of the half‑binomial series a_i = C(2i,i)/4**i,
    normalised to sum = 1 (i.e. a probability distribution).
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x ≥ 0, Σx = 1}.  Implements the algorithm of Duchi et al. (2008).
    """
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries become equal
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def conv_fft(x: np.ndarray) -> np.ndarray:
    """
    Fast convolution x ∗ x using a real FFT (length 2·len(x)‑1).
    """
    n = x.shape[0]
    m = 2 * n - 1
    X = np.fft.rfft(x, n=m)
    conv = np.fft.irfft(X * X, n=m)
    return conv
