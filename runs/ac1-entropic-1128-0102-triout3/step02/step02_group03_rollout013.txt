Hybrid search for a low‑max self‑convolution step function.

The algorithm works on the ℓ₁‑simplex {a ≥ 0, Σa = √(2n)}.
It alternates three types of moves:

1. **Soft‑max gradient step** – the max in the objective
   2·n·max(a*a)/(Σa)² is approximated by a smooth log‑sum‑exp.
   The gradient of the smooth approximation is a weighted
   convolution (weights given by a soft‑max of the current
   convolution).  An exponentiated‑gradient update (multiplicative
   update) keeps the variables non‑negative; after the update the
   vector is renormalised to the target ℓ₁‑norm.

2. **Random mass‑transfer** – a small fraction of the mass of a
   randomly chosen source index is moved to a random destination.
   The result is projected back onto the simplex.

3. **Sub‑gradient step on the exact max** – the active set of indices
   where the convolution attains its current maximum is used to form
   an exact sub‑gradient (as in the reference code).  A diminishing
   Euclidean step is taken and projected onto the simplex.

A Metropolis acceptance rule permits occasional uphill moves;
temperature and the soft‑max temperature (β) are slowly decreased/
increased, respectively.  Stagnation triggers a Dirichlet restart.
The routine runs until the time budget expires (or a target bound

def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()

    """
    Linear convolution a * a (full length 2·len(a)‑1) using FFT.
    Returns a real array of length 2·len(a)‑1.
    """
    A = np.fft.rfft(a, n=nfft)
    conv = np.fft.irfft(A * A, n=nfft)[: 2 * a.size - 1]
    return conv


def _project_to_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of vector v onto the simplex {x ≥ 0, Σx = target_sum}.
    """
    if target_sum < 0:
        raise ValueError("target_sum must be non‑negative")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.zeros_like(v)
    rho = ind[cond].max()
    theta = cssv[cond].max() / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _grad_max_subgrad(a: np.ndarray, mask: np.ndarray, nfft: int) -> np.ndarray:
    """
    Exact sub‑gradient of max_k (a*a)[k] at the current active set defined by mask.
    Returns a gradient vector of length len(a).

        return np.zeros_like(a)

    w = w / w_sum                     # turn mask into a probability vector
    a_rev = a[::-1]

    A_rev = np.fft.rfft(a_rev, n=nfft)
    W = np.fft.rfft(w, n=nfft)
    grad_full = np.fft.irfft(W * A_rev, n=nfft)[: 2 * a.size - 1]

    n = a.size
    grad = 2.0 * grad_full[n - 1 : n - 1 + n]
    return grad


def _grad_weighted(a: np.ndarray, w: np.ndarray, nfft: int) -> np.ndarray:
    """
    Gradient of the weighted sum Σ_i w_i·(a*a)[i] w.r.t. a.
    Here w must be a non‑negative vector of length 2·len(a)‑1
    (typically a probability distribution).  Returns a gradient of length len(a).
    """
    a_rev = a[::-1]

    A_rev = np.fft.rfft(a_rev, n=nfft)
    W = np.fft.rfft(w, n=nfft)
    conv_full = np.fft.irfft(W * A_rev, n=nfft)[: 2 * a.size - 1]

    n = a.size
    grad = 2.0 * conv_full[n - 1 : n - 1 + n]
    return grad
