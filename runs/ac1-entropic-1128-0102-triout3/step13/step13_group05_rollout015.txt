assistantfinal**Solution Overview**

The task is to return a non‑negative step‑function (a list of heights) that minimises  

\[
\text{score}= \frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the linear convolution of the vector with itself and `n` is its length.
The score is scale‑invariant, therefore we can keep the vector normalised to sum = 1 and simply
 minimise  

\[
\text{score}=2\,n\;\max (a*a).
\]

The previous implementation used simulated‑annealing with an expensive FFT
convolution at every trial move.  
The new code speeds the inner loop up by **keeping the convolution
incrementally**: moving a mass `δ` from index `src` to `dst` changes the
convolution by a known low‑cost formula, so a trial move can be evaluated
in *O(n)* instead of *O(n log n)*.  This allows many more iterations
within the 1000 s budget and gives a finer search.

The algorithm consists of three stages

1. **Initial pool** – a few analytic shapes (uniform, decreasing power‑ramps,
   random Dirichlet vectors, and the optional global starter) are generated,
   their exact score is computed with an FFT, and the best `K` candidates are
   kept.

2. **Fast simulated‑annealing** – starting from the current best candidate,
   repeated cheap moves are performed:
   * pick a source index proportionally to its weight,
   * pick a destination uniformly,
   * move a random fraction (up to `max_move_factor`) of the source mass,
   * update the convolution with the fast‑update formula,
   * accept the move according to a Metropolis rule with an exponential cooling
     schedule.
   The best vector seen so far is stored.  Every `recalc_interval` iterations the
   convolution is recomputed from scratch (FFT) to erase accumulated floating‑point
   error; occasional restarts from other top‑candidates are also performed.

3. **Polishing** – if time remains, a smooth‑max Adam optimiser (the same
   routine as the previous solution) is run for the remaining budget.

Finally the vector is projected back onto the probability simplex,
clipped to non‑negative values and returned as a plain Python list.

The combination of many cheap iterations and a final gradient‑based polish
improves the best known bound (≈ 1.50837) by a noticeable margin
within the allowed time.



```python
"""
Fast simulated‑annealing optimiser for the convolution‑max problem.

We keep the convolution a*a incrementally, which makes a trial move an
O(n) operation (slice updates + a few scalar updates).  This lets us
perform many more iterations than the previous FFT‑based approach.
After the annealing phase a short Adam‑style smooth‑max descent is run
to polish the result.

The returned sequence is normalised to sum 1 and contains only
non‑negative floats.
"""

import time
import math
import numpy as np


# ----------------------------------------------------------------------
# Utility helpers
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray) -> np.ndarray:
    """Exact linear convolution a*a using FFT (length 2·n‑1)."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _objective_from_conv(conv: np.ndarray, n: int) -> float:
    """Score = 2·n·max(conv) (vector assumed normalised to sum 1)."""
    return float(2.0 * n * conv.max())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex {x≥0, Σx = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Analytic shapes
# ----------------------------------------------------------------------
def _make_uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n)


def _make_decreasing_power(n: int, p: float) -> np.ndarray:
    """
    Monotone decreasing shape a[i] ∝ (n-i) ** p, normalised to sum 1.
    p = 0 gives the uniform distribution.
    """
    idx = np.arange(n, 0, -1, dtype=float)   # n, n‑1, … , 1
    shape = idx ** p
    total = shape.sum()
    if total > 0:
        shape /= total
    else:
        shape = np.full(n, 1.0 / n)
    return shape


# ----------------------------------------------------------------------
# Top‑K pool management
# ----------------------------------------------------------------------
def _push_top(pool: list, score: float, vec: np.ndarray, k: int) -> None:
    """Insert (score,vec) into a size‑k sorted pool (ascending scores)."""
    if len(pool) < k:
        pool.append((score, vec.copy()))
        pool.sort(key=lambda x: x[0])
    elif score < pool[-1][0]:
        pool[-1] = (score, vec.copy())
        pool.sort(key=lambda x: x[0])


# ----------------------------------------------------------------------
# Smooth‑max Adam optimiser (identical to the reference implementation)
# ----------------------------------------------------------------------
def _smooth_gradient_descent(a0: np.ndarray,
                             deadline: float,
                             start_time: float) -> tuple[np.ndarray, float]:
    """Adam‑style descent on a smooth surrogate of the max‑convolution."""
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective_from_conv(_conv_self_fft(a), n)

    # Adam hyper‑parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    step0 = 0.05
    T0 = 0.02
    T_end = 1e-4

    it = 0
    while time.time() < deadline:
        it += 1

        conv = _conv_self_fft(a)
        max_conv = conv.max()
        cur_score = 2.0 * n * max_conv / (a.sum() ** 2)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] SmoothGD iter={it:,} "
                  f"score={cur_score:.6f}")

        # temperature (linear decay)
        frac = it / (it + 1000.0)
        T = max(T_end, T0 * (1.0 - frac))

        # soft‑max over the convolution values
        w_raw = np.exp((conv - max_conv) / T)
        w = w_raw / w_raw.sum()

        # gradient = correlation of w with reversed a
        a_rev = a[::-1]
        L = _next_pow2(3 * n - 2)
        W = np.fft.rfft(w, n=L)
        A_rev = np.fft.rfft(a_rev, n=L)
        corr = np.fft.irfft(W * A_rev, n=L)[: 3 * n - 2]
        grad = 2.0 * corr[n - 1: n - 1 + n]

        # Adam update
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * (grad ** 2)
        m_hat = m / (1 - beta1 ** it)
        v_hat = v / (1 - beta2 ** it)
        step = step0 / math.sqrt(it)
        a -= step * m_hat / (np.sqrt(v_hat) + eps)

        # keep on the simplex
        a = _project_simplex(a)

    final_score = _objective_from_conv(_conv_self_fft(best_a), n)
    return best_a, final_score


# ----------------------------------------------------------------------
# Fast simulated‑annealing with incremental convolution updates
# ----------------------------------------------------------------------
def _fast_sa(initial_seq: np.ndarray,
             initial_conv: np.ndarray,
             budget_deadline: float,
             start_time: float,
             top_pool: list,
             max_move_factor: float = 0.2,
             temperature_start: float = 0.05,
             temperature_end: float = 1e-9,
             recalc_interval: int = 20000,
             restart_interval: int = 200000) -> tuple[np.ndarray, float]:
    """
    Perform SA using O(n) convolution updates.
    Returns the best sequence and its score.
    """
    n = initial_seq.shape[0]
    a = initial_seq.copy()
    conv = initial_conv.copy()           # length 2n‑1
    cur_max = conv.max()
    cur_score = 2.0 * n * cur_max
    best_a = a.copy()
    best_score = cur_score

    rng = np.random.default_rng()
    it = 0

    while time.time() < budget_deadline:
        it += 1

        # exponential cooling
        elapsed = time.time() - start_time
        total = budget_deadline - start_time
        frac = min(1.0, elapsed / total)
        T = temperature_start * (temperature_end / temperature_start) ** frac

        # pick source (probability proportional to its weight)
        src = rng.choice(n, p=a)
        if a[src] <= 1e-15:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue

        # propose moving a random fraction of src's mass
        delta = a[src] * max_move_factor * rng.random()
        if delta <= 0.0:
            continue

        # keep old values for possible rollback
        src_old = a[src]
        dst_old = a[dst]

        # ----- convolution update (use the *old* a) -----
        # slices
        src_slice = slice(src, src + n)
        dst_slice = slice(dst, dst + n)

        # 2·δ·a contribution (a is still the old vector)
        factor = 2.0 * delta
        conv[src_slice] -= factor * a
        conv[dst_slice] += factor * a

        # δ² terms
        d2 = delta * delta
        conv[2 * src] += d2
        conv[2 * dst] += d2
        conv[src + dst] -= 2.0 * d2

        # ----- vector update -----
        a[src] -= delta
        a[dst] += delta

        # ----- evaluate new score -----
        new_max = conv.max()
        new_score = 2.0 * n * new_max

        # acceptance
        if new_score < cur_score or rng.random() < math.exp(-(new_score - cur_score) / T):
            # accept
            cur_score = new_score
            cur_max = new_max
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                # keep the pool up‑to‑date
                _push_top(top_pool, best_score, best_a, len(top_pool))
                print(f"[{time.time() - start_time:.2f}s] SA iter={it:,} "
                      f"new best={new_score:.6f}")
        else:
            # ----- rollback (restore a first, then conv) -----
            a[src] = src_old
            a[dst] = dst_old

            # reverse the convolution updates using the restored a
            conv[src_slice] += factor * a
            conv[dst_slice] -= factor * a
            conv[2 * src] -= d2
            conv[2 * dst] -= d2
            conv[src + dst] += 2.0 * d2
            # cur_score stays unchanged

        # periodic full recomputation to avoid drift
        if it % recalc_interval == 0:
            conv = _conv_self_fft(a)
            cur_max = conv.max()
            cur_score = 2.0 * n * cur_max

        # occasional restart from another elite candidate
        if it % restart_interval == 0 and len(top_pool) > 1:
            choice = rng.integers(len(top_pool))
            a = top_pool[choice][1].copy()
            conv = _conv_self_fft(a)
            cur_max = conv.max()
            cur_score = 2.0 * n * cur_max

    return best_a, best_score

# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a low‑score step‑function within the given time budget.
    Returns a plain Python list of non‑negative floats.
    """
    np.random.seed(seed)
    rng = np.random.default_rng(seed + 12345)

    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # safety margin

    # Choose problem size – a smaller N gives many more iterations.
    remaining = deadline - time.time()
    if remaining > 600:
        N = 32768
    elif remaining > 300:
        N = 16384
    else:
        N = 8192

    # ------------------------------------------------------------------
    # 1) Build an initial pool of candidates
    # ------------------------------------------------------------------
    TOP_K = 7
    top = []   # list of (score, vector)

    # uniform
    uniform = _make_uniform(N)
    _push_top(top, _objective_from_conv(_conv_self_fft(uniform), N), uniform, TOP_K)

    # decreasing power‑ramps
    for p in np.linspace(0.0, 2.5, 9):          # 0,0.3125,…,2.5
        a = _make_decreasing_power(N, p)
        _push_top(top, _objective_from_conv(_conv_self_fft(a), N), a, TOP_K)

    # random Dirichlet vectors (sparse regime)
    for _ in range(40):
        if time.time() >= deadline:
            break
        a = rng.gamma(0.3, 1.0, size=N)   # Gamma(0.3) → sparse
        s = a.sum()
        if s == 0:
            continue
        a /= s
        _push_top(top, _objective_from_conv(_conv_self_fft(a), N), a, TOP_K)

    # incorporate the global starter if present
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            if starter.size != N:
                if N % starter.size == 0:
                    factor = N // starter.size
                    starter_up = np.repeat(starter, factor)
                else:
                    x_old = np.linspace(0, 1, starter.size, endpoint=False)
                    x_new = np.linspace(0, 1, N, endpoint=False)
                    starter_up = np.interp(x_new, x_old, starter)
            else:
                starter_up = starter.copy()
            starter_up = np.maximum(starter_up, 0.0)
            if starter_up.sum() > 0:
                starter_up /= starter_up.sum()
                _push_top(top,
                          _objective_from_conv(_conv_self_fft(starter_up), N),
                          starter_up,
                          TOP_K)
    except Exception:
        pass

    # current best
    best_score, best_seq = top[0][0], top[0][1].copy()
    print(f"[{time.time() - start_time:.2f}s] Initial best score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2) Fast simulated‑annealing refinement
    # ------------------------------------------------------------------
    init_conv = _conv_self_fft(best_seq)      # exact convolution for start
    best_seq, best_score = _fast_sa(best_seq,
                                    init_conv,
                                    deadline,
                                    start_time,
                                    top,
                                    max_move_factor=0.25,
                                    temperature_start=0.07,
                                    temperature_end=1e-9,
                                    recalc_interval=15000,
                                    restart_interval=120000)

    # ------------------------------------------------------------------
    # 3) Optional smooth‑max polishing (if any time left)
    # ------------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 15.0:
        sub_deadline = time.time() + remaining
        refined_seq, refined_score = _smooth_gradient_descent(best_seq,
                                                             sub_deadline,
                                                             start_time)
        if refined_score < best_score:
            best_score = refined_score
            best_seq = refined_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] After smooth GD best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4) Final normalisation and conversion to plain list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq /= total
    else:
        best_seq = np.full(N, 1.0 / N)

    final_score = _objective_from_conv(_conv_self_fft(best_seq), N)
    print(f"[{time.time() - start_time:.2f}s] Finished, final score ≈ {final_score:.6f}")

    return [float(v) for v in best_seq]
```
