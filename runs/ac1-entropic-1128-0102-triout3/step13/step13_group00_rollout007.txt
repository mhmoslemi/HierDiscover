The goal is to minimise  

\[
F(\mathbf a)=\frac{2n\;\max\bigl(\mathbf a*\mathbf a\bigr)}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where `*` denotes the linear convolution.  
Because `F` is scale‑invariant we may enforce \(\sum_i a_i = 1\) and
minimise  

\[
\Phi(\mathbf a)=2n\;\max\bigl(\mathbf a*\mathbf a\bigr).
\]

The optimiser works in four phases, each respecting the 1000 s budget:

1. **Rich parametric sweep** – several one‑parameter families
   (geometric, power, symmetric β) plus a *two‑parameter asymmetric β*
   family.  The ten best candidates are retained.

2. **Broad random Dirichlet starts** – 200 draws with concentration
   ranging from `0.01` to `10` (log‑uniform).  Again the best candidates
   are kept.

3. **Exponential‑gradient descent with a smooth‑max surrogate** –  
   a smooth approximation of the max,
   \(\operatorname{S}_\tau(\mathbf a)=\frac1\tau\log\sum_k e^{\tau\,c_k}\) with
   \(c_k=(\mathbf a*\mathbf a)_k\), is minimised.
   The gradient is obtained via a soft‑max weighting of the convolution,
   and the update is performed in the probability simplex using an
   *exponentiated‑gradient* step.  The temperature τ grows geometrically,
   turning the surrogate gradually into the true max.  The three
   best sequences from the previous phase are each refined for a
   dedicated time slice.

4. **Simulated‑annealing fine‑tuning** – from the best sequence
   discovered so far we repeatedly transfer a random amount of mass
   from one index to another.  Large moves are allowed early on (high
   temperature) and become tiny later.  Moves are accepted with a
   Metropolis criterion, which permits occasional uphill steps and
   helps escape shallow local minima.

5. **Final directed hill‑climb** – a deterministic move of a tiny
   fraction of mass from the index with the largest positive sub‑gradient
   to the index with the most negative sub‑gradient, accepting only
   improvements.  This polishes the solution to a (near) local optimum.

All convolutions are performed with the FFT (full‐length) for speed,
and every iterate is projected onto the probability simplex
(`_project_simplex`).  Throughout the run the best sequence and its
score are printed, allowing us to monitor progress.

The routine returns a plain Python list of non‑negative floats that can
be handed to `evaluate_sequence`.

```python
"""
Improved optimiser for the step‑function challenge.

The algorithm consists of:

1. A dense parametric sweep (geometric, power, symmetric β and
   asymmetric β families).
2. 200 random Dirichlet initialisers with a wide concentration range.
3. Exponential‑gradient descent on a smooth‑max surrogate of the
   max‑convolution, with a temperature schedule that gradually turns the
   surrogate into the true max.
4. Simulated‑annealing mass‑transfer moves with a Metropolis acceptance
   rule.
5. A final deterministic hill‑climb using the sub‑gradient of the
   non‑smooth max‑convolution.

All operations are performed in the probability simplex (sum = 1,
non‑negative) and use FFT‑based convolutions for speed.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """Full linear convolution of a with itself using FFT."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    A = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(A * A, n=L)[: 2 * n - 1]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full linear convolution via FFT (x*y)."""
    L = _next_pow2(len(x) + len(y) - 1)
    X = np.fft.rfft(x, n=L)
    Y = np.fft.rfft(y, n=L)
    conv = np.fft.irfft(X * Y, n=L)[: len(x) + len(y) - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex:
    { w | w_i ≥ 0, Σ w_i = 1 }.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _objective_score(a: np.ndarray) -> float:
    """
    Return 2·n·max(conv(a,a)) assuming Σ a = 1.
    This is the exact objective without the final scaling by Σa².
    """
    n = a.shape[0]
    conv = _conv_self(a)
    return float(2.0 * n * conv.max())


def _subgradient_maxconv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of max(conv(a,a)) at a.
    If several shifts attain the maximum the gradients are averaged.
    """
    n = a.shape[0]
    max_val = conv.max()
    tol = 1e-12
    active = np.where(conv >= max_val - tol)[0]
    grad = np.zeros_like(a)
    for k in active:
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad[idx] += a[k - idx]
    if active.size:
        grad = 2.0 * grad / active.size
    return grad

# 1️⃣  Parametric families (including asymmetric β)
# ----------------------------------------------------------------------
def _sweep_families(n: int,
                    best_seqs: list[np.ndarray],
                    best_scores: list[float],
                    deadline: float,
                    keep_top: int = 10) -> tuple[list[np.ndarray], list[float]]:
    """
    Exhaustive sweep over several parametric families.
    Keeps the `keep_top` best candidates.
    """
    idx = np.arange(n, dtype=np.float64)

    # Helper to insert candidate if it improves the global list
    def consider(seq: np.ndarray, score: float):
        if score < max(best_scores):
            # replace the worst entry
            worst = np.argmax(best_scores)
            best_scores[worst] = score
            best_seqs[worst] = seq.copy()
            # keep the list sorted for quick max lookup
            order = np.argsort(best_scores)
            best_scores[:] = [best_scores[i] for i in order]
            best_seqs[:] = [best_seqs[i] for i in order]

    # Uniform baseline (already present in the caller)
    # --------------- Geometric -----------------------------------------
    eps_grid = np.logspace(-5, -1, 250)
    for eps in eps_grid:
        if time.time() >= deadline:
            break
        r = 1.0 - eps
        geo = np.power(r, idx)
        geo_sum = geo.sum()
        if geo_sum == 0:
            continue
        geo /= geo_sum
        for lam in np.linspace(0.0, 1.0, 11):
            seq = lam * (1.0 / n) + (1.0 - lam) * geo
            seq /= seq.sum()
            sc = _objective_score(seq)
            consider(seq, sc)

    # --------------- Power -------------------------------------------
    p_grid = np.linspace(-2.5, 2.5, 151)
    for p in p_grid:
        if time.time() >= deadline:
            break
        pow_seq = np.power(idx + 1.0, p)
        s = pow_seq.sum()
        if s == 0:
            continue
        pow_seq /= s
        sc = _objective_score(pow_seq)
        consider(pow_seq, sc)

    # --------------- Symmetric beta ------------------------------------
    alphas = np.linspace(0.05, 8.0, 81)
    log_idx = np.log(idx + 1.0)
    log_rev = np.log(np.maximum(n - idx, 1.0))
    for a in alphas:
        if time.time() >= deadline:
            break
        log_seq = (a - 1.0) * (log_idx + log_rev)  # α=β gives symmetric Beta
        seq = np.exp(log_seq - np.max(log_seq))   # avoid overflow
        s = seq.sum()
        if s == 0 or not np.isfinite(s):
            continue
        seq /= s
        sc = _objective_score(seq)
        consider(seq, sc)

    # --------------- Asymmetric beta ----------------------------------
    alphas = np.linspace(0.05, 6.0, 31)
    betas = np.linspace(0.05, 6.0, 31)
    for a in alphas:
        if time.time() >= deadline:
            break
        for b in betas:
            if time.time() >= deadline:
                break
            log_seq = (a - 1.0) * log_idx + (b - 1.0) * log_rev
            seq = np.exp(log_seq - np.max(log_seq))
            s = seq.sum()
            if s == 0 or not np.isfinite(s):
                continue
            seq /= s
            sc = _objective_score(seq)
            consider(seq, sc)

    # --------------- Piecewise exponential (two‑sided) ---------------
    ratios = np.logspace(-3, -0.1, 15)          # decay per step
    mids = [n // 2]                            # only centre‑symmetry is needed
    for r_left in ratios:
        if time.time() >= deadline:
            break
        left = np.exp(-r_left * np.arange(mids[0]))
        for r_right in ratios:
            if time.time() >= deadline:
                break
            right = np.exp(-r_right * np.arange(n - mids[0] - 1, -1, -1))
            seq = np.concatenate([left, [1.0], right])
            seq = np.maximum(seq, 0.0)
            seq /= seq.sum()
            sc = _objective_score(seq)
            consider(seq, sc)

    return best_seqs, best_scores

def _random_dirichlet_trials(n: int,
                             best_seqs: list[np.ndarray],
                             best_scores: list[float],
                             deadline: float,
                             keep_top: int = 10,
                             trials: int = 200) -> tuple[list[np.ndarray], list[float]]:
    """
    Draw `trials` Dirichlet vectors with concentration uniformly sampled
    in log‑space between 0.01 and 10.  Keep the `keep_top` best.
    """
    rng = np.random.default_rng()
    for _ in range(trials):
        if time.time() >= deadline:
            break
        # log‑uniform concentration
        logc = rng.uniform(np.log(0.01), np.log(10.0))
        c = np.exp(logc)
        a = rng.gamma(shape=c, scale=1.0, size=n)
        a /= a.sum()
        sc = _objective_score(a)
        # insert if good
        if sc < max(best_scores):
            worst = np.argmax(best_scores)
            best_scores[worst] = sc
            best_seqs[worst] = a.copy()
            order = np.argsort(best_scores)
            best_scores[:] = [best_scores[i] for i in order]
            best_seqs[:] = [best_seqs[i] for i in order]
    return best_seqs, best_scores

# 3️⃣  Exponential‑gradient descent on smooth‑max surrogate
# ----------------------------------------------------------------------
def _exp_gradient_descent(a0: np.ndarray,
                          deadline: float,
                          start_time: float) -> tuple[np.ndarray, float]:
    """
    Minimise the smooth max (log‑sum‑exp) surrogate of max(conv(a,a)).
    Update rule: a ← ProjSimplex( a * exp(-η * grad) ),
    where grad is the gradient of the surrogate.
    Temperature τ grows geometrically, turning the surrogate into the true max.
    """
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective_score(a)

    # schedule parameters
    τ = 0.5            # start with a very smooth surrogate
    τ_factor = 1.35
    η0 = 0.25
    it = 0
    while time.time() < deadline:
        it += 1

        # ----- compute smooth soft‑max weights -----
        conv = _conv_self(a)                     # full length 2n‑1
        max_c = conv.max()
        # to avoid overflow we shift by max_c
        w = np.exp(τ * (conv - max_c))
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.zeros_like(conv)
            w[np.argmax(conv)] = 1.0
            w_sum = 1.0
        w /= w_sum

        # ----- gradient of the surrogate -----
        # grad = 2 * (w * a_rev) restricted to length n
        a_rev = a[::-1]
        Lg = _next_pow2(len(w) + n - 1)          # size for FFT
        grad_full = np.fft.irfft(
            np.fft.rfft(w, n=Lg) * np.fft.rfft(a_rev, n=Lg),
            n=Lg)[: len(w) + n - 1]
        grad = 2.0 * grad_full[n - 1: n - 1 + n]

        # ----- exponential update (mirror‑descent on simplex) -----
        η = η0 / np.sqrt(it)
        # clamp extreme gradient values to keep exp stable
        grad_clipped = np.clip(grad, -1e3, 1e3)
        a = a * np.exp(-η * grad_clipped)
        a = _project_simplex(a)

        # ----- bookkeeping -----
        cur_score = _objective_score(a)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] ExpGrad it={it:,} τ={τ:.1f} score={cur_score:.6f}")

        # ----- temperature schedule -----
        if it % 2500 == 0:
            τ = min(τ * τ_factor, 1e9)

    return best_a, best_score

# 4️⃣  Simulated annealing (mass‑transfer moves)
# ----------------------------------------------------------------------
def _simulated_annealing(start_a: np.ndarray,
                         deadline: float,
                         start_time: float) -> tuple[np.ndarray, float]:
    """
    Metropolis‑style annealing that repeatedly moves a random bucket of mass
    from one index to another.  The temperature is proportional to the
    remaining time, thus large moves are allowed early on and become tiny
    later.
    """
    a = start_a.copy()
    n = a.shape[0]

    cur_score = _objective_score(a)
    best_a = a.copy()
    best_score = cur_score

    # maximal fraction of source that may be moved (when T≈1)
    max_frac = 0.20

    while time.time() < deadline:
        # linear temperature: 1 at start, ≈0 at the end
        remain = deadline - time.time()
        total = deadline - start_time
        T = max(1e-8, remain / total)

        # pick source (must have some mass) and destination
        src_candidates = np.where(a > 1e-15)[0]
        if src_candidates.size == 0:
            break
        src = np.random.choice(src_candidates)
        dst = np.random.randint(n)
        if src == dst:
            continue

        # size of the move scales with temperature
        frac = np.random.rand() * max_frac * T
        eps = a[src] * frac
        if eps <= 1e-15:
            continue

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        # evaluate
        new_score = _objective_score(a_prop)
        delta = new_score - cur_score
        if delta < 0 or np.random.rand() < np.exp(-delta / (T + 1e-12)):
            # accept
            a = a_prop
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] Anneal T={T:.3f} score={new_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# 5️⃣  Final directed hill‑climb (tiny deterministic moves)
# ----------------------------------------------------------------------
def _hill_climb_directed(start_a: np.ndarray,
                         deadline: float,
                         start_time: float) -> tuple[np.ndarray, float]:
    """
    Repeatedly moves a tiny fraction of mass from the index with largest
    positive sub‑gradient to the index with most negative sub‑gradient.
    Only improving moves are kept.
    """
    a = start_a.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_score = _objective_score(a)

    rng = np.random.default_rng()
    while time.time() < deadline:
        conv = _conv_self(a)
        grad = _subgradient_maxconv(a, conv)

        src_cand = np.where(a > 1e-15)[0]
        if src_cand.size == 0:
            break
        src = src_cand[np.argmax(grad[src_cand])]
        dst = np.argmin(grad)

        # adaptive transfer size (up to 1 % of source)
        eps = a[src] * (rng.random() * 0.01 + 1e-6)
        if eps <= 0:
            continue

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        new_score = _objective_score(a_prop)
        if new_score < best_score:
            a = a_prop
            best_a = a.copy()
            best_score = new_score
            print(f"[{time.time() - start_time:.2f}s] Hill‑climb score={best_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step function that minimises ``evaluate_sequence``.
    The routine follows the multi‑phase strategy described above and
    respects the given time budget.
    """
    np.random.seed(seed)
    global start_time
    start_time = time.time()
    deadline = start_time + budget_s - 0.3   # small safety margin

    # --------------------------------------------------------------
    # Problem size
    # --------------------------------------------------------------
    n = 4096                     # length used in earlier experiments

    # --------------------------------------------------------------
    # Baseline (uniform)
    # --------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    best_score = _objective_score(uniform)
    best_seq = uniform.copy()
    print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    # --------------------------------------------------------------
    # Keep the ten best candidates throughout the first two phases
    # --------------------------------------------------------------
    best_seqs = [best_seq.copy() for _ in range(10)]
    best_scores = [best_score for _ in range(10)]

    # --------------------------------------------------------------
    # 1️⃣  Parametric sweep
    # --------------------------------------------------------------
    phase_deadline = deadline - 250.0   # reserve ~250 s later
    if time.time() < phase_deadline:
        best_seqs, best_scores = _sweep_families(
            n, best_seqs, best_scores, phase_deadline, keep_top=10)

    # --------------------------------------------------------------
    # 2️⃣  Random Dirichlet initialisers
    # --------------------------------------------------------------
    phase_deadline = deadline - 200.0
    if time.time() < phase_deadline:
        best_seqs, best_scores = _random_dirichlet_trials(
            n, best_seqs, best_scores, phase_deadline, keep_top=10, trials=200)

    # --------------------------------------------------------------
    # 3️⃣  Exponential‑gradient descent (multi‑start)
    # --------------------------------------------------------------
    # allocate time for three independent runs (≈120 s each)
    grad_time_per_run = (deadline - start_time - 150.0) / 3.0
    for i in range(3):
        run_deadline = time.time() + grad_time_per_run
        if time.time() >= deadline:
            break
        start_vec = best_seqs[i]          # the i‑th best so far
        refined_seq, refined_score = _exp_gradient_descent(start_vec, run_deadline, start_time)
        if refined_score < best_scores[-1]:
            # replace worst entry
            worst = np.argmax(best_scores)
            best_scores[worst] = refined_score
            best_seqs[worst] = refined_seq.copy()
            order = np.argsort(best_scores)
            best_scores = [best_scores[i] for i in order]
            best_seqs = [best_seqs[i] for i in order]
            print(f"[{time.time() - start_time:.2f}s] After gradient run {i+1} best score={refined_score:.6f}")

    # --------------------------------------------------------------
    # 4️⃣  Simulated annealing (global fine‑tuning)
    # --------------------------------------------------------------
    anneal_deadline = deadline - 120.0
    if time.time() < anneal_deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting simulated annealing")
        best_seq, best_score = _simulated_annealing(best_seqs[0], anneal_deadline, start_time)
        print(f"[{time.time() - start_time:.2f}s] After annealing score={best_score:.6f}")

    # --------------------------------------------------------------
    # 5️⃣  Final hill‑climb
    # --------------------------------------------------------------
    if time.time() < deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting final hill‑climb")
        best_seq, best_score = _hill_climb_directed(best_seq, deadline, start_time)
        print(f"[{time.time() - start_time:.2f}s] Final hill‑climb score={best_score:.6f}")

    # --------------------------------------------------------------
    # Normalisation and return
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = uniform.copy()

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```
