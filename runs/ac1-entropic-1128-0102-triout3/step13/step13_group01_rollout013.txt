The objective  

\[
F(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2}
\]

is invariant under scaling of the whole vector and, for non‑negative entries,
the Cauchy‑Schwarz inequality gives  

\[
\max (a*a)\;=\;a*a\;(0)=\sum_i a_i^{2}\;\ge\;\frac{(\sum_i a_i)^2}{n}.
\]

Hence  

\[
F(a)\;\ge\;2 .
\]

Equality holds **iff** all entries are identical (a constant step function).  
Therefore a constant vector is provably optimal – any other admissible
vector can only increase the score.

The implementation below simply returns a constant vector of moderate size
(​\(n=2^{14}=16384\)​).  The values are well inside the allowed range
\([0,1000]\) and the sum is far larger than the 0.01 safety‑threshold, so
`evaluate_sequence` will accept the result.  The function respects the
1000‑second time budget (the work is negligible) and contains a short
doc‑string as required.

    Return a provably optimal step‑function for the given objective.

    The objective
        F(a) = 2·n·max(conv(a, a)) / (sum(a)**2)
    satisfies   F(a) ≥ 2   for any non‑negative vector a,
    with equality if and only if all entries are equal.
    Consequently a constant vector is optimal.

    The function builds a constant list of length 2**14 (16384) with
    each entry = 1.0.  All entries are within the allowed range
    [0, 1000] and the sum (16384.0) is safely above the 0.01 lower‑bound.
    The computational cost is negligible compared with the 1000 s budget.
    """
    # Choose a power‑of‑two length – this size is a good trade‑off
    # between speed of later convolution and memory usage.
    n = 1 << 14               # 16384

    # Constant (uniform) step function – each height = 1.0.
    # Any positive constant works; 1.0 keeps the numbers well inside
    # the clipping limits of evaluate_sequence.
    uniform_seq = [1.0] * n

    # The list already satisfies all security checks performed by
    # evaluate_sequence (non‑negative, finite, not a bool, sum > 0.01).
    return uniform_seq
