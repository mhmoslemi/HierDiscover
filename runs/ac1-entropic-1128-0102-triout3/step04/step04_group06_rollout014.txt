def full_convolve_fft(x, y):
    L = 1 << ((len(x) + len(y) - 1).bit_length())
    X = np.fft.rfft(x, L)
    Y = np.fft.rfft(y, L)
    conv = np.fft.irfft(X * Y, L)[:len(x)+len(y)-1]
    return conv

The evaluation function is invariant under scaling of the step‑function, therefore we may restrict ourselves to
vectors `a` that lie on the simplex `a_i ≥ 0 , Σ a_i = 1`.  
For a given `a`

```
c = a * a               # full linear convolution (length 2·n‑1)
score = 2·n·max(c)
```

so minimising the score is equivalent to minimising the maximum entry of the autocorrelation `c`.

The maximum is a non‑smooth functional.  To obtain a reliable descent direction we replace the
`ℓ_∞`‑norm by a smooth `ℓ_p`‑norm (or, equivalently, a soft‑max).  
For a fixed `p>1`

```
F_p(a) = ( Σ_k c_k^p )^(1/p)      (≈ max(c)   when p → ∞ )
∂F_p/∂a_i ∝ Σ_k p·c_k^{p‑1}·∂c_k/∂a_i
```

and `∂c_k/∂a_i = 2·a_{k‑i}` (zero outside the index range).  
Thus the gradient can be written as a *weighted* convolution:

```
g_i = 2· Σ_k w_k · a_{k‑i}    with   w_k = c_k^{p‑1}   (up to a constant factor)
```

Computing both the convolution `c` and the weighted convolution `g` is done efficiently
with FFTs (≈ O(n log n) per iteration).

To stay on the simplex we optimise the *log‑probabilities* `θ` :

```
a_i = exp(θ_i) / Σ_j exp(θ_j)
∇_θ   = a ∘ ( g – ⟨a,g⟩ )            (∘ = element‑wise product)
θ ← θ – η·∇_θ                         (η = step size)
```

A homotopy on `p` is employed: start with a small `p` (smooth landscape) and increase it
linearly to a larger value (≈ 30) so that the algorithm gradually focuses on the true
`ℓ_∞` objective.  
Occasional random jitter is injected to avoid stagnation and, after the main descent,
a cheap stochastic hill‑climbing phase refines the solution.

def _full_convolve_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Return the full linear convolution of `x` and `y` using FFT."""
    L = 1 << ((len(x) + len(y) - 1).bit_length())   # next power of two

    Y = np.fft.rfft(y, n=L)
    conv = np.fft.irfft(X * Y, n=L)
    return conv[: len(x) + len(y) - 1]

        a = np.exp(theta)
        a /= a.sum()

        # ---- auto‑convolution and exact score -----------------------
        conv = _full_convolve_fft(a, a)            # length 2·n‑1
        max_c = conv.max()
        cur_score = 2.0 * target_n * max_c
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] iter={it:6d}  new best score={cur_score:.6f}")

        # ---- smoothed weight vector  --------------------------------
        # normalise so that the maximum entry becomes 1.0
        conv_norm = conv / max_c
        # homotopy on p
        p = p_start + (p_end - p_start) * min(1.0, it / p_ramp_iters)
        # w_k = (c_k / max)^{p‑1}  (largest entry gets weight 1)
        w = conv_norm ** (p - 1.0)

        # ---- gradient w.r.t. a (weighted convolution) ---------------
        a_rev = a[::-1]                            # reversed a
        conv_w_rev = _full_convolve_fft(w, a_rev)  # length 3·n‑2
        # gradient = 2 * conv_w_rev[n‑1 : n‑1+ n]
        grad_a = 2.0 * conv_w_rev[target_n - 1 : target_n - 1 + target_n]

        # ---- project gradient onto the simplex (log‑parameter) ------
        dot = np.dot(a, grad_a)                     # ⟨a,∇F⟩
        grad_theta = a * (grad_a - dot)             # ∇_θ  (see analysis)

        # ---- step‑size schedule ------------------------------------
        eta = eta0 / math.sqrt(it)
        theta -= eta * grad_theta

        # ---- occasional random jitter to help escape plateaus -------
        if it % 10_000 == 0:
            theta += np.random.randn(target_n) * 0.02

        # ----------------------------------------------------------------
        # safety stop when the time budget is almost exhausted
        # ----------------------------------------------------------------
        if time.time() >= deadline:
            break

    # ------------------------------------------------------------------
    # 3. Final stochastic hill‑climbing (fast local search)
    # ------------------------------------------------------------------
    a = best_a.copy()
    # recompute current score once more (may have changed after the loop)
    conv = _full_convolve_fft(a, a)
    cur_score = 2.0 * target_n * conv.max()

    while time.time() < deadline:
        i, j = np.random.randint(0, target_n, size=2)
        if i == j:
            continue
        eps_move = np.random.rand() * 0.05          # move up to 5 % of source mass
        delta = eps_move * a[i]
        if delta <= 0.0:
            continue
        a_new = a.copy()
        a_new[i] -= delta
        a_new[j] += delta
        # recompute the score for the trial
        conv_new = _full_convolve_fft(a_new, a_new)
        new_score = 2.0 * target_n * conv_new.max()
        if new_score < cur_score:
            cur_score = new_score
            a = a_new
            if new_score < best_score:
                best_score = new_score
                best_a = a_new.copy()
                print(f"[{time.time() - start_time:6.2f}s] local improve score={new_score:.6f}")

    print(f"[{time.time() - start_time:6.2f}s] finished – best score={best_score:.6f}")
    # Return a plain Python list (the evaluator expects a list)
    return [float(x) for x in best_a]
