Simulated‑annealing + sub‑gradient optimiser for the step‑function task.

The algorithm proceeds in three phases within the 1000 s wall‑clock limit:

1. **Quick seeding** – a handful of Dirichlet draws (and a sparse starter)
   are examined; the best among them becomes the initial point.
2. **Exact sub‑gradient descent** – the true L∞‑objective
   (max (a∗a)) is differentiated in the sense of a sub‑gradient.
   The update is projected onto the probability simplex.
   This removes most of the gap left by the smooth‑max continuation used
   previously.
3. **Simulated‑annealing refinement** – random mass transfers between two
   coordinates are performed, accepting worsening moves with a temperature
   that decays exponentially.  The move always preserves the total mass,
   so the evaluation function can be computed directly by an FFT‑based

    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())

    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]

    iter_sa = 0

    while time.time() < deadline:
        # pick source (must have some mass) and a different destination
        src = rng.integers(n)
        if a[src] <= 0.0:
            continue
        dst = rng.integers(n - 1)
        if dst >= src:
            dst += 1

        # fraction of source mass to move – bias toward small moves
        frac = rng.random()
        delta = a[src] * (frac ** 2) * 0.5        # ≤ 0.5·a[src]

        if delta <= 0.0:
            continue

        cand = a.copy()
        cand[src] -= delta
        cand[dst] += delta

        cand_score = _objective_score(cand)
        dscore = cand_score - current_score
        if dscore < 0.0 or rng.random() < np.exp(-dscore / T):
            a = cand
            current_score = cand_score
            if cand_score < best_score:
                best_score, best_seq = cand_score, cand.copy()
                print(f"[{time.time() - start:.2f}s] SA new best {best_score:.6f}")

        # exponential cooling
        T = max(T_end, T * cooling)
        iter_sa += 1

        # occasional broader perturbation (helps escaping deep basins)
        if iter_sa % 5000 == 0 and rng.random() < 0.03:
            # replace a small random fraction of the mass by a fresh Dirichlet draw
            alpha = 0.1
            mix = rng.gamma(shape=0.3, scale=1.0, size=n)
            mix /= mix.sum()
            a = (1 - alpha) * a + alpha * mix
            a = _project_simplex(a)                # re‑project to enforce exact sum=1
            current_score = _objective_score(a)
            if current_score < best_score:
                best_score, best_seq = current_score, a.copy()
                print(f"[{time.time() - start:.2f}s] Broad perturbation improved to {best_score:.6f}")

    # --------------------------------------------------------------
    # final normalisation and return
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)

    print(f"[{time.time() - start:.2f}s] Finished – best objective ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
