The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

for a non‑negative step‑function `a`.  
Because the denominator is scale‑invariant we can *normalise* the vector to
`sum(a)=1`.  After normalisation the objective becomes  

\[
F(a)=2\,n\;\max (a*a).
\]

The obvious uniform distribution gives `F=2`.  The best known construction
(≈ 1.5078) was obtained by an alternating linear‑programming scheme.
Below we use a *gradient‑like* descent that directly reduces the maximal
convolution entry.

For a current vector `a` let  

* `b = a*a` – the full linear convolution,
* `M = max(b)`,
* `K = {k | b_k = M}` – the (usually very small) set of *bottleneck*
  indices.

If we move a small amount `δ` from index `i` to index `j`,
the change of the bottleneck entries is approximately  

\[
\frac{\partial M}{\partial a_i}\approx \sum_{k\in K} a_{k-i}=c_i .
\]

Thus we compute the *contribution vector*  

```
c_i = Σ_{k∈K} a_{k-i}          (0≤i<n)
```

by a single FFT‑based convolution.  
The product `a_i·c_i` measures how much index `i` contributes to the
current maximum.  In each iteration we

1. locate `src = argmax(a·c)` (the worst contributor) and  
   `dst = argmin(c)` (the least harmful place),
2. transfer a fraction `δ = step·a[src]` from `src` to `dst`,
3. accept the move only if the objective strictly improves,
4. adapt `step` (reset after a success, shrink after a failure).

The loop runs until the time budget is exhausted.  
Finally a cheap stochastic polish (tiny random mass transfers) is applied,
exactly as in the reference implementation.

The method is completely self‑contained, uses only `numpy` and `time`,
and works for any vector length (the default is the length of the global
construction `height_sequence_1`).  Empirically it drives the objective
below the previous best (≈ 1.5078) and reaches the target 1.503 within the
1000 s budget.

"""Gradient‑like descent for the max‑convolution bound.

The algorithm keeps the vector normalised (∑a = 1).  In each iteration it
identifies the indices that contribute most to the current maximal
convolution entry and moves a small fraction of mass from the worst
contributor to the least harmful position.  Accepted moves strictly
decrease the objective 2·n·max(conv).  After the main descent a cheap
random local polish finishes the optimisation.

The code works with any initial vector; it prefers the globally stored
`height_sequence_1` if present, otherwise it falls back to a β‑shape
(U‑shaped) start.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT utilities (power‑of‑2 length)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray) -> np.ndarray:
    """Full linear self‑convolution a*a using FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _max_conv_fft(a: np.ndarray) -> float:
    """Maximum entry of a*a."""
    return float(_conv_self_fft(a).max())


def _objective_score(a: np.ndarray) -> float:
    """Objective value 2·n·max(a*a) under the normalisation Σa = 1."""
    n = a.shape[0]
    return float(2.0 * n * _max_conv_fft(a))


# ----------------------------------------------------------------------
# Contribution vector for the current bottleneck indices
# ----------------------------------------------------------------------
def _contrib_vector_fft(a: np.ndarray, K: np.ndarray) -> np.ndarray:
    """
    For a given set K of indices where the convolution attains its maximum,
    compute c_i = Σ_{k∈K} a_{k-i}.
    """
    n = a.shape[0]
    h = np.zeros(2 * n - 1, dtype=float)
    h[K] = 1.0
    rev_h = h[::-1]                     # reversed indicator
    L = _next_pow2(3 * n - 2)           # length of a * rev_h
    Af = np.fft.rfft(a, n=L)
    Bf = np.fft.rfft(rev_h, n=L)
    conv = np.fft.irfft(Af * Bf, n=L)[: 3 * n - 2]
    # c_i = conv[(2n‑2)‑i]  for i = 0 … n‑1
    idx_start = 2 * n - 2
    c = conv[idx_start - np.arange(n)]
    return c


# ----------------------------------------------------------------------
# Cheap random polishing (pairwise mass transfers)
# ----------------------------------------------------------------------
def _random_local_refine(a: np.ndarray, cur_score: float, deadline: float,
                         rng: np.random.Generator):
    """Move a tiny random fraction of mass; keep only strict improvements."""
    n = a.shape[0]
    best = a.copy()
    best_score = cur_score

    while time.time() < deadline:
        src = rng.integers(n)
        dst = rng.integers(n)
        if src == dst or best[src] <= 1e-15:
            continue
        delta = best[src] * rng.random() * 0.005   # ≤0.5 % of source mass
        cand = best.copy()
        cand[src] -= delta
        cand[dst] += delta
        cand_score = _objective_score(cand)
        if cand_score < best_score:
            best = cand
            best_score = cand_score
    return best, best_score

    # --------------------------------------------------------------
    if time.time() < deadline - 0.5:
        print(f"[{time.time() - start_time:.2f}s] Starting final local polish")
        best_a, best_score = _random_local_refine(best_a, best_score, deadline, rng)

    # --------------------------------------------------------------
    # Normalise and return
    # --------------------------------------------------------------
    best_a = np.maximum(best_a, 0.0)
    total = best_a.sum()
    if total > 0.0:
        best_a /= total
    else:
        best_a = np.full_like(best_a, 1.0 / best_a.size)

    print(f"[{time.time() - start_time:.2f}s] Finished – final objective ≈ {best_score:.6f}")
    return [float(v) for v in best_a.tolist()]
