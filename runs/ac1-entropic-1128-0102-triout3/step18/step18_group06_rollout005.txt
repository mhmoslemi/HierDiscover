The score of a step‐function `a = (a₀,…,a_{n‑1})` is  

```
score(a) = 2·n·max(conv(a,a)) / (sum a)² .
```

The expression is *homogeneous*: multiplying all entries of `a` by a constant does not change the score.  
Consequently we may **fix the ℓ¹‑norm to 1** and minimise  

```
f(a) = 2·n·max(conv(a,a))      with   a_i ≥ 0 ,  Σ a_i = 1 .
```

`conv(a,a)` is the *full* convolution of `a` with itself (length `2·n‑1`).  
The problem is highly non‑convex; a naive sub‑gradient method gets stuck at the
previous best value `≈1.5078`.  

The new search does three things

1. **Very cheap parametric sweeps** (geometric / power / exponential / two‑block) – they give good seeds.
2. **Random Dirichlet draws** – cheap global exploration.
3. **Smoothed mirror descent** – instead of the non‑smooth `max`, we minimise a
   *soft‑max*  

   ```
   g_β(a) = (1/β)·log Σ_k exp(β·conv_k(a))
   ```

   For a fixed β this function is smooth; its gradient can be written
   analytically and evaluated with a single FFT‑based convolution:

   ```
   w_k = softmax_β(conv_k)                     ( Σ w_k = 1 )
   ∇ g_β(a) = 2·( w  *  a )  (restricted to the first n entries)
   ```

   The algorithm keeps `β` modest at the start (smooth landscape) and
   increases it slowly – the iterates therefore follow the true max‑objective
   but are able to escape the plateaus that stopped the previous method.

   The mirror‑descent update on the simplex is multiplicative:

   ```
   a ← a ∘ exp( -η·∇g_β(a) )   (∘ = element‑wise product)
   a ← a / Σ a                (projection onto the probability simplex)
   ```

   Step size η follows the classic schedule `η_t = η₀ / √t`.

During the optimisation the best sequence (according to the exact objective
`f(a)`) is stored and finally returned.  All heavy work (convolutions,
soft‑max, gradient) is performed with FFT‑based `O(n log n)` kernels, allowing
many thousands of iterations inside the 1000 s budget.

The code below follows exactly this plan.  It is completely self‑contained,
uses only `numpy` and standard library modules, and respects the required
function signature `propose_candidate`.

```python
"""
Propose a non‑negative step‑function that minimises

        2 * n * max(conv(a, a)) / (sum(a)**2)

The search consists of four stages:

1️⃣  Very cheap parametric sweeps (geometric, power, exponential, two‑block)
    – produce decent initial guesses.

2️⃣  Random Dirichlet draws – cheap global exploration of the simplex.

3️⃣  Smoothed mirror‑descent on the probability simplex.
    The non‑smooth max‑operator is replaced by a soft‑max
    (log‑sum‑exp) with a temperature β that is increased slowly.
    The gradient of the smoothed objective can be written as a single
    convolution and is applied with a multiplicative (exponentiated‑gradient)
    update.  The step‑size follows η_t = η₀ / √t.

4️⃣  Return the best sequence found, normalised to sum = 1 (the scaling
    does not affect the official evaluation function).

The routine runs for at most `budget_s` seconds and prints progress
information.  All helper functions are top‑level – no closures or lambdas.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a (length 2·n‑1) using a real FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _conv_full(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    L = _next_pow2(len(x) + len(y) - 1)
    X = np.fft.rfft(x, n=L)
    Y = np.fft.rfft(y, n=L)
    conv = np.fft.irfft(X * Y, n=L)[:len(x) + len(y) - 1]
    return conv


def _objective_score(a: np.ndarray) -> float:
    """
    Exact objective for a probability vector (sum = 1):
    2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = _conv_self(a)
    return float(2.0 * n * conv.max())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# 1️⃣  Very cheap parametric families (light‑weight sweeps)
# ----------------------------------------------------------------------
def _sweep_geometric(n, best_seq, best_score, deadline):
    """Geometric decay a_i ∝ r^i, mix with uniform."""
    idx = np.arange(n, dtype=np.float64)
    eps_grid = np.logspace(-5, -1, 60)      # fewer points – quicker
    for eps in eps_grid:
        if time.time() >= deadline:
            break
        r = 1.0 - eps
        geo = np.power(r, idx)
        if geo.sum() == 0:
            continue
        geo /= geo.sum()
        for lam in (0.0, 0.5, 1.0):
            seq = lam * np.full(n, 1.0 / n) + (1.0 - lam) * geo
            seq /= seq.sum()
            sc = _objective_score(seq)
            if sc < best_score:
                best_score, best_seq = sc, seq.copy()
                print(f"[{time.time() - start_time:.2f}s] Geo eps={eps:.1e} lam={lam:.2f} score={sc:.6f}")
    return best_seq, best_score


def _sweep_power(n, best_seq, best_score, deadline):
    """Power law a_i ∝ (i+1)^p."""
    idx = np.arange(n, dtype=np.float64)
    for p in np.linspace(-2.0, 2.0, 41):
        if time.time() >= deadline:
            break
        seq = np.power(idx + 1.0, p)
        if seq.sum() == 0:
            continue
        seq /= seq.sum()
        sc = _objective_score(seq)
        if sc < best_score:
            best_score, best_seq = sc, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Power p={p:.3f} score={sc:.6f}")
    return best_seq, best_score


def _sweep_exponential(n, best_seq, best_score, deadline):
    """Symmetric exponential a_i ∝ exp(-λ·dist(i,center))."""
    idx = np.arange(n, dtype=np.float64)
    dist = np.minimum(idx, n - 1 - idx)
    for lam in np.logspace(-4, -0.3, 40):
        if time.time() >= deadline:
            break
        seq = np.exp(-lam * dist)
        if seq.sum() == 0:
            continue
        seq /= seq.sum()
        sc = _objective_score(seq)
        if sc < best_score:
            best_score, best_seq = sc, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Exp λ={lam:.1e} score={sc:.6f}")
    return best_seq, best_score


def _sweep_two_blocks(n, best_seq, best_score, deadline):
    """Two disjoint blocks of equal length, possibly with different densities."""
    for L_frac in (0.02, 0.05, 0.1, 0.2):
        L = int(L_frac * n)
        if L < 1:
            continue
        for w in (0.2, 0.5, 0.8):
            if time.time() >= deadline:
                break
            seq = np.zeros(n)
            seq[:L] = w / L
            seq[-L:] = (1.0 - w) / L
            sc = _objective_score(seq)
            if sc < best_score:
                best_score, best_seq = sc, seq.copy()
                print(f"[{time.time() - start_time:.2f}s] TwoBlocks L={L} w={w:.2f} score={sc:.6f}")
    return best_seq, best_score


# ----------------------------------------------------------------------
# 2️⃣  Random Dirichlet draws (cheap global search)
# ----------------------------------------------------------------------
def _random_dirichlet_trials(n, best_seq, best_score, deadline):
    rng = np.random.default_rng()
    while time.time() < deadline:
        logc = rng.uniform(-2.0, 0.5)                # concentration [10⁻², 3]
        c = 10 ** logc
        a = rng.gamma(shape=c, scale=1.0, size=n)
        s = a.sum()
        if s == 0.0:
            continue
        a /= s
        sc = _objective_score(a)
        if sc < best_score:
            best_score, best_seq = sc, a.copy()
            print(f"[{time.time() - start_time:.2f}s] Dirichlet c={c:.3f} score={sc:.6f}")
    return best_seq, best_score


# ----------------------------------------------------------------------
# 3️⃣  Smoothed mirror‑descent (exponential‑gradient) on the simplex
# ----------------------------------------------------------------------
def _smooth_max_mirror_descent(a0: np.ndarray, deadline: float,
                               best_seq: np.ndarray, best_score: float):
    """
    Mirror descent on the soft‑max of the convolution.
    β (temperature) is increased slowly; η follows η₀/√t.
    """
    a = a0.copy()
    n = a.shape[0]
    it = 0
    eta0 = 0.6               # initial step‑size (tuned empirically)
    beta = 0.8               # start with a smooth max
    beta_max = 5.0           # target temperature
    beta_inc = (beta_max / beta) ** (1.0 / 20000)   # geometric growth (≈20 000 it.)

    while time.time() < deadline:
        it += 1
        conv = _conv_self(a)                     # length 2·n‑1
        # smoothed max
        max_c = conv.max()
        # stable soft‑max
        exp_arg = beta * (conv - max_c)
        w = np.exp(exp_arg)
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # gradient: 2 * (w * a)  (restricted to first n entries)
        g_full = _conv_full(w, a)                # length 3·n‑2
        grad = 2.0 * g_full[n - 1: n - 1 + n]     # slice of length n

        # mirror‑descent (exponentiated‑gradient) update
        eta = eta0 / np.sqrt(it)
        a = a * np.exp(-eta * grad)
        a_sum = a.sum()
        if a_sum == 0.0:
            a = np.full(n, 1.0 / n)
        else:
            a = a / a_sum

        # occasional reporting
        if it % 2500 == 0:
            obj = _objective_score(a)
            if obj < best_score:
                best_score, best_seq = obj, a.copy()
                print(f"[{time.time() - start_time:.2f}s] Descent it={it:,} obj={obj:.6f} β={beta:.3f}")

        # improve best sequence with the *exact* objective every 5000 it.
        if it % 5000 == 0:
            obj = _objective_score(a)
            if obj < best_score:
                best_score, best_seq = obj, a.copy()
                print(f"[{time.time() - start_time:.2f}s] Exact‑check it={it:,} obj={obj:.6f}")

        # increase temperature slowly (never exceed beta_max)
        if beta < beta_max:
            beta = min(beta_max, beta * beta_inc)

    return best_seq, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function (list of floats) that minimises
    the evaluation function.  The routine runs cheap parametric sweeps,
    many Dirichlet samples and a smoothed mirror‑descent optimiser.
    The best sequence (normalised to sum = 1) is returned as a plain Python list.
    """
    np.random.seed(seed)
    global start_time
    start_time = time.time()
    deadline = start_time + budget_s - 0.1   # tiny safety margin

    # --------------------------------------------------------------
    # Problem size (power‑of‑two for fast FFT)
    # --------------------------------------------------------------
    n = 4096                               # can be changed if desired
    uniform = np.full(n, 1.0 / n)

    best_seq = uniform.copy()
    best_score = _objective_score(best_seq)
    print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    # --------------------------------------------------------------
    # Optional global starter (height_sequence_1) if supplied by the framework
    # --------------------------------------------------------------
    try:
        starter = np.asarray(height_sequence_1, dtype=float)  # type: ignore
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            s = starter.sum()
            if s > 0:
                starter = starter / s
                sc = _objective_score(starter)
                if sc < best_score:
                    best_score, best_seq = sc, starter.copy()
                    print(f"[{time.time() - start_time:.2f}s] Global starter score={sc:.6f}")
    except Exception:
        pass

    # --------------------------------------------------------------
    # 1️⃣  Light‑weight parametric sweeps (≈120 s)
    # --------------------------------------------------------------
    phase_deadline = deadline - 280.0
    if time.time() < phase_deadline:
        best_seq, best_score = _sweep_geometric(n, best_seq, best_score, phase_deadline)
    if time.time() < phase_deadline:
        best_seq, best_score = _sweep_power(n, best_seq, best_score, phase_deadline)
    if time.time() < phase_deadline:
        best_seq, best_score = _sweep_exponential(n, best_seq, best_score, phase_deadline)
    if time.time() < phase_deadline:
        best_seq, best_score = _sweep_two_blocks(n, best_seq, best_score, phase_deadline)

    # --------------------------------------------------------------
    # 2️⃣  Random Dirichlet exploration (≈200 s)
    # --------------------------------------------------------------
    phase_deadline = deadline - 120.0
    if time.time() < phase_deadline:
        best_seq, best_score = _random_dirichlet_trials(n, best_seq, best_score, phase_deadline)

    # --------------------------------------------------------------
    # 3️⃣  Smoothed mirror‑descent (use the remaining time)
    # --------------------------------------------------------------
    if time.time() < deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting smoothed mirror‑descent")
        best_seq, best_score = _smooth_max_mirror_descent(best_seq, deadline,
                                                          best_seq, best_score)
        print(f"[{time.time() - start_time:.2f}s] End of descent, best score≈{best_score:.6f}")

    # --------------------------------------------------------------
    # Normalise and return a plain Python list
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = uniform.copy()

    print(f"[{time.time() - start_time:.2f}s] Finished – best score≈{best_score:.6f}")
    return [float(x) for x in best_seq]
```
