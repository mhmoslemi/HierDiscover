The evaluation function is  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2}\;,
\]

where `(a*a)` is the ordinary (non‑circular) convolution of the vector with itself.  
Because the expression is homogeneous, scaling the whole vector does **not**
change the score – only the *shape* of the distribution matters.

If we interpret the normalised vector `a` as a probability distribution on
`{0,…,n‑1}`, the convolution `a*a` is the distribution of the sum of two
independent draws.  The maximum entry of this sum‑distribution is minimised
by putting most of the probability mass at one end of the support and letting
it increase roughly like a power law:

\[
a_i \propto (i+1)^p , \qquad p>0 .
\]

For large `n`

\[
\max_k (a*a)_k \;=\; \frac{C(p)}{n} + O\!\Bigl(\frac1{n^2}\Bigr),\qquad
C(p)=(p+1)^2\,B(p+1,p+1),
\]

where `B` is the beta‑function.  
Consequently the score tends to the constant `2·C(p)`.  The table below shows
the behaviour:

| p | C(p) | Score `2·C(p)` |
|---|------|----------------|
| 0 | 1  | 2 |
| 1 | 2/3 | 1 ⅓ |
| 2 | 0.30 | 0.60 |
| 3 | 0.114 | 0.228 |
| 4 | 0.0397 | 0.079 |
| 5 | 0.01296 | 0.0259 |
| 6 | 0.00408 | 0.0082 |

Even with a modest exponent (`p = 4` or `5`) the score drops far below the
target `1.503`.  The construction is completely deterministic, requires virtually
no search time and works for any length `n` (the score is almost independent of
`n` once `n` is large enough).

The implementation below

* tries a handful of exponents (`p = 1 … 6`);
* builds both the *increasing* and the *decreasing* power‑law shapes;
* evaluates every candidate with the supplied `evaluate_sequence`;
* returns the best sequence found before the time budget expires.

The whole routine finishes in well under a second, leaving plenty of time
for the harness to run the evaluation.

```python
"""
propose_candidate
-----------------

Construct a step‑function whose coefficients follow a simple power‑law
profile a_i ∝ (i+1)^p (or the mirrored version).  For p≥1 the maximal
self‑convolution entry scales like C(p)/n with C(p) = (p+1)^2·B(p+1,p+1),
so the evaluation score converges to the constant 2·C(p) < 1.5 already for
p = 4.  The algorithm enumerates a few exponents, evaluates each candidate
using the given `evaluate_sequence`, and returns the best vector.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: build a normalised power‑law sequence
# ----------------------------------------------------------------------
def _power_sequence(n: int, p: float, reverse: bool = False) -> np.ndarray:
    """
    Return a length‑n vector a with non‑negative entries, normalised to sum=1.
    The shape is a_i ∝ (i+1)^p; if reverse=True the exponent is applied to
    the reversed index (i.e. decreasing profile).
    """
    # use 1‑based indices to avoid a zero entry when p>0
    idx = np.arange(1, n + 1, dtype=np.float64)
    if reverse:
        idx = (n + 1) - idx  # i -> n+1-i, creates a decreasing shape
    a = idx ** p
    a_sum = a.sum()
    if a_sum > 0.0:
        a /= a_sum
    else:
        # fallback to uniform if something goes wrong
        a.fill(1.0 / n)
    return a


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a low‑self‑convolution step function.

    The search space consists of monotone power‑law profiles
    a_i ∝ (i+1)^p (and their mirrored versions).  For each exponent
    in a short list we build the normalised vector, evaluate it with
    `evaluate_sequence`, and keep the best result.
    """
    np.random.seed(seed)
    start_time = time.time()
    # tiny safety margin – the harness cuts us off at `budget_s` seconds
    deadline = start_time + budget_s - 0.5

    # Length of the candidate.  A few thousand entries give a good
    # approximation of the asymptotic constant while keeping the
    # convolution cheap.
    n = 4800

    # Exponents to try – the list is tiny, the whole check finishes in <1 s.
    exponents = [1, 2, 3, 4, 5, 6]

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Enumerate candidates (both increasing and decreasing shapes)
    # ------------------------------------------------------------------
    for p in exponents:
        if time.time() >= deadline:
            break

        for rev in (False, True):
            seq = _power_sequence(n, float(p), reverse=rev)

            # Convert to plain Python list for the evaluator
            seq_list = [float(x) for x in seq]
            score = evaluate_sequence(seq_list)

            # The evaluator returns `inf` on malformed inputs – ignore them.
            if not np.isfinite(score):
                continue

            if score < best_score:
                best_score = score
                best_seq = seq.copy()
                shape = "decreasing" if rev else "increasing"
                print(
                    f"[{time.time() - start_time:6.2f}s] "
                    f"p={p} ({shape}) → score={score:.8f}"
                )

    # ------------------------------------------------------------------
    # Fallback – in the very unlikely event that nothing succeeded.
    # ------------------------------------------------------------------
    if best_seq is None:
        print("Fallback to uniform distribution.")
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)

    # Final normalisation (tiny drift may appear after the loops)
    s = best_seq.sum()
    if s > 0.0:
        best_seq /= s
    else:
        best_seq = np.full_like(best_seq, 1.0 / best_seq.size)

    # Return a plain list, as required by the harness.
    return [float(x) for x in best_seq]
```
