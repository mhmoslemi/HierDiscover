The objective is to find a non‑negative vector `a` (the heights of a step function) that minimizes  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `*` denotes the linear convolution.  
Because the denominator is homogeneous, we can restrict ourselves to vectors with
`sum(a)==1`.  The problem is then to minimise the maximum entry of the
self‑convolution.

The previous approach already combines a smooth Adam optimiser, a few
projected‑gradient polishing steps and a short simulated‑annealing refinement.
To push the bound further we:

* **run several independent restarts** (different initialisations and
  different problem sizes) and keep the best result;
* **extend the Adam phase** – a longer schedule of the smoothing
  parameter `α` and many more iterations;
* **use a more aggressive projected‑gradient polish** (larger momentum,
  tighter stopping condition);
* **run a longer annealing stage** with a geometric cooling schedule that
  gradually reduces the move size;
* **adapt the time budget on‑the‑fly** so that each phase receives a
  reasonable share of the total 1000 s.

All helper routines are written at top‑level (no closures, no lambdas) and
the code respects the single‑CPU restriction.  The final vector is re‑normalised
to sum to 1 (the exact scaling does not affect the score).

```python
"""
Propose a step‑function that improves the known bound (~1.5128).

Algorithm
---------
1. Try a few problem sizes (n = 3600, 4800, 6000).  For each size we run an
   independent optimisation run – this guards against being stuck in a local
   minimum.
2. Initialise the probability vector in three different ways:
      * a random Dirichlet sample,
      * a monotone decreasing geometric profile,
      * the best sequence found in a previous run (``height_sequence_1`` if
        available).
   The best of the three initialisations is kept.
3. Adam optimisation on a *smooth* surrogate of the max‑convolution.
   The surrogate is
        f_α(a) = (1/α)·log∑_k exp(α·(a*a)_k)
   with an increasing schedule α = [0.5, 2, 5, 10, 20, 40, 80, 160].
   The parameters (iterations per α, learning‑rate, Adam betas) are chosen
   so that the whole phase occupies roughly 45 % of the allocated time.
4. Exact projected‑gradient polishing on the true max‑convolution.
   A momentum term and a 1/√t step‑size yield fast convergence.
   The polish runs until either the time budget for the current problem
   size expires or 1 e6 iterations are performed.
5. Simulated‑annealing fine‑tuning.
   At each step a random ε‑fraction of the mass is moved from a source index
   (chosen proportionally to its weight) to a destination index.
   The temperature is cooled geometrically from 5·10⁻² to 10⁻⁶.
   The number of annealing moves is proportional to the remaining time.
6. The best sequence over all problem sizes and restarts is returned.
   The vector is projected onto the probability simplex before returning.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# FFT utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """Linear convolution a*a (length 2·len(a)‑1) using FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# Smooth‑max (log‑sum‑exp) gradient
# ----------------------------------------------------------------------
def _grad_smooth_max(a: np.ndarray, conv: np.ndarray,
                     alpha: float, fft_len: int) -> np.ndarray:
    """
    Gradient of  f_α(a) = (1/α)·log∑_k exp(α·conv_k)   w.r.t. a.
    Returns ∂f/∂a (shape (n,)).
    """
    n = a.shape[0]

    # soft‑max weights over the convolution entries
    scaled = alpha * conv
    max_scaled = scaled.max()
    w = np.exp(scaled - max_scaled)
    w /= w.sum()                     # w_k = ∂f/∂conv_k

    # cross‑correlation a ⋆ w   (gradient = 2·(a⋆w))
    w_rev = w[::-1]
    Af = np.fft.rfft(a, n=fft_len)
    Wrev = np.fft.rfft(w_rev, n=fft_len)
    corr = np.fft.irfft(Af * Wrev, n=fft_len)[: n + len(w_rev) - 1]

    # centre the result (length n)
    grad = 2.0 * corr[len(w_rev) - 1 - np.arange(n)]
    return grad


# ----------------------------------------------------------------------
# Simple projection onto the probability simplex
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Projected‑gradient descent on the exact max‑convolution
# ----------------------------------------------------------------------
def _run_exact_gradient(a0: np.ndarray,
                       n: int,
                       deadline: float,
                       start_time: float,
                       beta: float = 0.94,
                       step0: float = 0.25,
                       max_iter: int = 1_000_000) -> tuple[np.ndarray, float]:
    """
    Projected gradient descent (with momentum) on the true objective
    2·n·max(a*a).  Returns the best vector found and its corresponding score.
    """
    a = a0.copy()
    momentum = np.zeros_like(a)

    best_a = a.copy()
    best_score = float("inf")
    it = 0
    rel_tol = 1e-12                     # active‑set tolerance

    while time.time() < deadline and it < max_iter:
        it += 1
        conv = _conv_self(a)
        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] proj‑grad improve: n={n}, iter={it:,}, score={cur_score:.6f}")

        # ---- sub‑gradient of max(conv) ----
        max_val = conv.max()
        thresh = max_val * (1.0 - rel_tol)
        active = np.where(conv >= thresh)[0]

        g = np.zeros_like(a)
        for k in active:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            i = np.arange(lo, hi + 1, dtype=int)
            j = k - i
            # each ordered pair (i,j) contributes a_j to ∂/∂a_i and vice‑versa
            g[i] += a[j]
            g[j] += a[i]

        # momentum (Nesterov‑style)
        momentum = beta * momentum + (1.0 - beta) * g

        step = step0 / math.sqrt(it)   # diminishing step size
        v = a - step * momentum
        a = _project_onto_simplex(v)

    return best_a, best_score


# ----------------------------------------------------------------------
# Simulated‑annealing refinement (mass‑transfer moves)
# ----------------------------------------------------------------------
def _run_annealing(a0: np.ndarray,
                   n: int,
                   deadline: float,
                   start_time: float,
                   cur_best_score: float,
                   cur_best_seq: np.ndarray,
                   start_temp: float = 5e-2,
                   end_temp: float = 1e-6,
                   steps: int = 200_000) -> tuple[np.ndarray, float]:
    """
    Very small‑scale annealing that repeatedly moves a random ε‑fraction of the
    mass from a source index to a destination index.
    """
    a = a0.copy()
    score = 2.0 * n * _conv_self(a).max()
    best_seq = cur_best_seq.copy()
    best_score = cur_best_score

    rng = np.random.default_rng()

    for it in range(1, steps + 1):
        if time.time() >= deadline:
            break

        # geometric cooling
        T = start_temp * (end_temp / start_temp) ** (it / steps)

        src = rng.choice(n, p=a / a.sum())
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-15:
            continue

        eps = a[src] * rng.random() * 0.30   # move at most 30 % of the source mass
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        new_score = 2.0 * n * _conv_self(a_prop).max()
        delta = new_score - score

        if delta < 0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            score = new_score

        if score < best_score:
            best_score = score
            best_seq = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] anneal improve: n={n}, iter={it:,}, score={score:.6f}")

    return best_seq, best_score


# ----------------------------------------------------------------------
# Core optimisation routine for a *single* problem size
# ----------------------------------------------------------------------
def _optimise_for_n(n: int,
                    deadline: float,
                    rng: np.random.Generator) -> tuple[list[float], float]:
    """
    Optimise a probability vector of length `n` within the supplied time window.
    Returns the best sequence (as a python list) and its raw score
    (i.e. 2·n·max(conv)).
    """
    start_time = time.time()
    # ---------- initialise three candidates ----------
    # (a) random Dirichlet
    a_random = rng.random(n)
    a_random /= a_random.sum()

    # (b) monotone decreasing geometric profile
    geom = np.logspace(0, -3, num=n, base=2.0)
    a_geom = geom / geom.sum()

    # (c) reuse the global best if available
    try:
        a_global = np.asarray(height_sequence_1, dtype=float)
        if a_global.ndim == 1 and a_global.size > 0:
            if a_global.shape[0] != n:
                # linear up‑sample / down‑sample while preserving total mass
                old_x = np.linspace(0.0, 1.0, a_global.shape[0])
                new_x = np.linspace(0.0, 1.0, n)
                a_global = np.interp(new_x, old_x, a_global)
            a_global = np.maximum(a_global, 0.0)
            if a_global.sum() == 0:
                a_global = a_random.copy()
            else:
                a_global /= a_global.sum()
    except Exception:
        a_global = a_random.copy()

    candidates = [a_random, a_geom, a_global]
    best_a = None
    best_score = float("inf")

    # ---------- quick evaluation of the three starters ----------
    for a in candidates:
        sc = float(2 * n * _conv_self(a).max())
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
    print(f"[{time.time() - start_time:6.2f}s] n={n} initial best score={best_score:.6f}")

    # ---------- Adam on the smooth surrogate ----------
    # Time allocation: roughly 45 % of the remaining budget
    remaining = deadline - time.time()
    adam_deadline = time.time() + 0.45 * remaining
    # log‑softmax parametrisation
    eps = 1e-16
    y = np.log(np.maximum(best_a, eps))

    fft_len = _next_pow2(3 * n - 2)          # length sufficient for all correlations

    # smoothing schedule
    alpha_schedule = [0.5, 2.0, 5.0, 10.0, 20.0, 40.0, 80.0, 160.0]
    iters_per_alpha = 10_000                # generous number – will be cut by time check

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    eps_adam = 1e-8
    lr0 = 0.12

    m = np.zeros_like(y)
    v = np.zeros_like(y)
    t = 0

    while time.time() < adam_deadline:
        for alpha in alpha_schedule:
            for _ in range(iters_per_alpha):
                if time.time() >= adam_deadline:
                    break

                # softmax
                maxy = np.max(y)
                exp_y = np.exp(y - maxy)
                a = exp_y / exp_y.sum()

                # smooth objective
                conv = _conv_self(a)
                scaled = alpha * conv
                max_scaled = scaled.max()
                lse = max_scaled + np.log(np.exp(scaled - max_scaled).sum())
                f_val = lse / alpha
                obj = 2.0 * n * f_val

                # gradient w.r.t. a
                grad_a = _grad_smooth_max(a, conv, alpha, fft_len) * (2.0 * n)

                # chain rule: ∂/∂y
                grad_y = a * (grad_a - np.dot(grad_a, a))

                # Adam update
                t += 1
                m = beta1 * m + (1.0 - beta1) * grad_y
                v = beta2 * v + (1.0 - beta2) * (grad_y ** 2)

                m_hat = m / (1.0 - beta1 ** t)
                v_hat = v / (1.0 - beta2 ** t)

                lr_t = lr0 * (np.sqrt(1.0 - beta2 ** t) / (1.0 - beta1 ** t))
                y = y - lr_t * m_hat / (np.sqrt(v_hat) + eps_adam)

                # occasional exact evaluation
                if t % 250 == 0:
                    sc = float(2 * n * _conv_self(a).max())
                    if sc < best_score:
                        best_score = sc
                        best_a = a.copy()
                        print(f"[{time.time() - start_time:6.2f}s] Adam improve: n={n}, score={sc:.6f}")

    # ---------- exact projected‑gradient polishing ----------
    remaining = deadline - time.time()
    if remaining > 2.0:                     # need at least a couple of seconds
        polish_deadline = time.time() + 0.30 * remaining
        a_polish, score_polish = _run_exact_gradient(best_a, n,
                                                     polish_deadline,
                                                     start_time,
                                                     beta=0.94,
                                                     step0=0.25)
        if score_polish < best_score:
            best_score = score_polish
            best_a = a_polish.copy()
            print(f"[{time.time() - start_time:6.2f}s] polishing improve: n={n}, score={score_polish:.6f}")

    # ---------- simulated‑annealing fine‑tuning ----------
    remaining = deadline - time.time()
    if remaining > 0.5:
        anneal_steps = int(5e5 * remaining / 1000.0)   # scale with remaining seconds
        a_final, score_final = _run_annealing(best_a, n,
                                              deadline,
                                              start_time,
                                              best_score,
                                              best_a,
                                              start_temp=5e-2,
                                              end_temp=1e-6,
                                              steps=max(10_000, anneal_steps))
        if score_final < best_score:
            best_score = score_final
            best_a = a_final.copy()
            print(f"[{time.time() - start_time:6.2f}s] final anneal improve: n={n}, score={score_final:.6f}")

    # final sanity projection
    best_a = np.maximum(best_a, 0.0)
    total = best_a.sum()
    if total > 0:
        best_a /= total
    else:
        best_a = np.full_like(best_a, 1.0 / n)

    # return as plain python list together with the *raw* score (not yet divided
    # by the sum because the sum is 1)
    return best_a.tolist(), best_score


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function that minimises ``evaluate_sequence``.
    The routine performs several restarts with different problem sizes, runs a
    long Adam phase, a projected‑gradient polish and a final annealing step,
    all respecting the supplied time budget (≈1000 s).
    """
    np.random.seed(seed)
    rng = np.random.default_rng(seed)

    start_time = time.time()
    # small safety margin so that we never exceed the budget
    deadline = start_time + budget_s - 0.5

    # try a few lengths – the best one (in terms of the final score) wins
    lengths = [3600, 4800, 6000]
    # allocate a share of the total budget to each length proportional to its size
    total_len = sum(lengths)
    best_seq = None
    best_score = float("inf")

    for n in lengths:
        if time.time() >= deadline:
            break
        # dedicated sub‑deadline for this length
        portion = n / total_len
        sub_deadline = min(deadline, time.time() + portion * budget_s)

        print(f"[{time.time() - start_time:6.2f}s] ---- Optimising length n={n} ----")
        seq, score = _optimise_for_n(n, sub_deadline, rng)

        if score < best_score:
            best_score = score
            best_seq = np.array(seq, dtype=float)
            print(f"[{time.time() - start_time:6.2f}s] New overall best: n={n}, score={score:.6f}")

    # final normalisation – the evaluation routine will re‑normalise anyway,
    # but we keep the vector on the probability simplex.
    if best_seq is None:
        # fallback – a plain uniform vector
        best_seq = np.full(4800, 1.0 / 4800)

    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq /= total
    else:
        best_seq = np.full_like(best_seq, 1.0 / best_seq.size)

    # the caller expects a plain python list
    return [float(x) for x in best_seq.tolist()]
```
