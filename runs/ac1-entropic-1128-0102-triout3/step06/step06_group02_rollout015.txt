The evaluation function  

```
score = 2·n·max(conv(a,a)) / (sum(a)²)
```

is scale‑invariant – multiplying the whole vector by a constant does not change the
score.  Hence we can always normalise the vector to a probability simplex
`sum(a)=1` and minimise simply  

```
score = 2·n·max(conv(a,a)).
```  

`max(conv(a,a))` is the largest entry of the (full) linear convolution of the
vector with itself.  The problem is non‑convex, but the objective is smooth
except at the points where the maximum switches from one shift to another.
A practical way to attack it is:

1. **Start from a good seed** – the previous best construction
   (`height_sequence_1`) is used when it exists; otherwise a random vector is
   generated.

2. **Soft‑max smoothing** – replace the hard maximum by a smooth
   `log‑sum‑exp` (soft‑max).  Its gradient can be written as a convolution, so a
   fast FFT based implementation works for large vectors.

3. **Exact sub‑gradient descent** – after the soft phase we switch to the true
   sub‑gradient of the max‑convolution (the gradient is simply a reversed copy of
   the vector on the active shift).

4. **Long simulated‑annealing walk** – the remaining budget is spent on a
   Metropolis walk that moves a small fraction of mass between two positions.
   A slower cooling schedule and a larger allowed transfer (up to 30 % of the
   source mass) give the walk enough freedom to escape shallow minima.

5. **Time‑aware orchestration** – the whole search runs inside the given time
   budget.  The budget is split in two parts:  
   *the first half* is used for the two gradient phases (soft‑max + sub‑gradient)
   on a fixed length (`n = 9600` – the length that gave the best result previously),
   *the second half* is devoted to the annealing walk.

All iterates are projected onto the simplex after each update
(`_project_simplex`).  The best vector found at any moment is stored and finally
returned as a plain Python list.


```python
"""
Proposes a non‑negative step‑function (vector) that minimises
`evaluate_sequence`.  The algorithm consists of

1) a smooth soft‑max gradient descent,
2) an exact sub‑gradient descent on the true max‑convolution,
3) a long simulated‑annealing walk.

The whole routine respects the given time budget (default 1000 s) and
returns the best vector found.  It uses FFT based convolutions for speed
and projects every iterate onto the probability simplex.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Simplex projection (Euclidean)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto the simplex {x ≥ 0, sum x = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Convolution utilities – linear convolution via FFT (O(n log n))
# ----------------------------------------------------------------------
def _conv_self(a: np.ndarray) -> np.ndarray:
    """Linear convolution a * a (full length = 2·len(a)-1)."""
    n = a.shape[0]
    fft_len = 1 << ((2 * n - 1).bit_length())
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# Soft‑max (smooth max) and its gradient
# ----------------------------------------------------------------------
def _softmax_gradient(a: np.ndarray,
                      conv: np.ndarray,
                      temperature: float) -> np.ndarray:
    """Gradient of  max_{k} conv[k] approximated by a soft‑max."""
    maxc = conv.max()
    # scaled exponentials, subtract maxc for numerical stability
    scaled = (conv - maxc) / temperature
    exps = np.exp(scaled)
    w = exps / exps.sum()                 # soft‑max weights, length = 2·n‑1

    rev_a = a[::-1]
    n = a.shape[0]
    m = w.shape[0]
    fft_len = 1 << ((n + m - 1).bit_length())
    A = np.fft.rfft(rev_a, n=fft_len)
    B = np.fft.rfft(w, n=fft_len)
    full = np.fft.irfft(A * B, n=fft_len)[: n + m - 1]

    # the gradient is the central n entries of 2·(rev_a * w)
    grad = 2.0 * full[n - 1:n - 1 + n]
    return grad


def _run_softmax_gd(a0: np.ndarray,
                    n: int,
                    deadline: float,
                    start_time: float,
                    step0: float = 0.6,
                    beta: float = 0.9,
                    temp_start: float = 2.0e-2,
                    temp_end: float = 5.0e-4) -> tuple[np.ndarray, float]:
    """Projected Nesterov‑style GD on the soft‑max approximation."""
    a = a0.copy()
    momentum = np.zeros_like(a)

    best_a = a.copy()
    best_score = float("inf")
    it = 0

    while time.time() < deadline:
        it += 1

        conv = _conv_self(a)
        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] softmax improve: "
                  f"iter={it}, score={cur_score:.6f}")

        # temperature schedule (geometric)
        T = temp_start * (temp_end / temp_start) ** (it / 20000.0)

        grad = _softmax_gradient(a, conv, T)
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)
        a = _project_simplex(a - step * momentum)

    return best_a, best_score


# ----------------------------------------------------------------------
# Exact sub‑gradient descent for max(conv)
# ----------------------------------------------------------------------
def _run_subgradient_gd(a0: np.ndarray,
                        n: int,
                        deadline: float,
                        start_time: float,
                        step0: float = 0.1,
                        beta: float = 0.9) -> tuple[np.ndarray, float]:
    """Projected sub‑gradient descent on 2·n·max(conv)."""
    a = a0.copy()
    momentum = np.zeros_like(a)

    best_a = a.copy()
    best_score = 2.0 * n * _conv_self(a).max()
    it = 0

    while time.time() < deadline:
        it += 1

        conv = _conv_self(a)
        max_val = conv.max()
        cur_score = 2.0 * n * max_val
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] subgrad improve: "
                  f"iter={it}, score={cur_score:.6f}")

        k = int(conv.argmax())   # active shift

        # sub‑gradient of conv[k] w.r.t. a
        grad = np.zeros_like(a)
        if k < n:
            grad[:k + 1] = 2.0 * a[k::-1]
        else:
            start = k - n + 1
            grad[start:] = 2.0 * a[start:][::-1]

        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)
        a = _project_simplex(a - step * momentum)

    return best_a, best_score


# ----------------------------------------------------------------------
# Simulated‑annealing refinement
# ----------------------------------------------------------------------
def _run_annealing(a0: np.ndarray,
                   n: int,
                   deadline: float,
                   start_time: float,
                   cur_best_score: float,
                   cur_best_seq: np.ndarray,
                   start_temp: float = 1.0,
                   end_temp: float = 1e-7,
                   max_steps: int = 3_000_000) -> tuple[np.ndarray, float]:
    """Metropolis walk that moves a small fraction of mass between two indices."""
    a = a0.copy()
    score = 2.0 * n * _conv_self(a).max()
    best_seq = cur_best_seq.copy()
    best_score = cur_best_score

    for it in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        # geometric cooling
        T = start_temp * (end_temp / start_temp) ** (it / max_steps)

        i, j = np.random.randint(0, n, size=2)
        if i == j or a[i] == 0.0:
            continue

        # move up to 30 % of the source mass
        eps = a[i] * np.random.rand() * 0.30
        a_prop = a.copy()
        a_prop[i] -= eps
        a_prop[j] += eps

        new_score = 2.0 * n * _conv_self(a_prop).max()
        delta = new_score - score

        if delta < 0 or math.exp(-delta / T) > np.random.rand():
            a = a_prop
            score = new_score

        if score < best_score:
            best_score = score
            best_seq = a.copy()
            print(f"[{time.time() - start_time:6.2f}s] anneal improve: "
                  f"iter={it}, score={score:.6f}")

    return best_seq, best_score
```
