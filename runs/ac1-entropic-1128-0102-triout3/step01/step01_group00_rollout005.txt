The code below searches for a non‑negative step‑function (a list of heights) that minimises  

\[
\text{score}= \frac{2\,n\;\max (a*a)}{(\sum a)^2}\ .
\]

Because the expression is scale‑invariant we *fix* the sum of the
coefficients to 1 and simply minimise  

\[
\text{score}=2\,n\;\max (a*a)\ .
\]

The optimisation is performed on the probability simplex  
\(\{a_i\ge 0,\;\sum a_i =1\}\) using a **projected Adam** optimiser.
Instead of the usual sub‑gradient that only looks at the single maximal
convolution entry we average the gradients of the *K* largest
convolution values (default K = 5).  This “soft‑max’’ variant smooths the
objective and helps the algorithm escape the plateaux that limit the
previous sub‑gradient implementation.

The search proceeds as follows

1. try several lengths `n` (larger `n` give a smaller theoretical bound);
2. for each length perform a few random restarts;
3. in every restart run a projected Adam loop until the global time
   budget (≈ 1000 s) is exhausted;
4. keep the best sequence ever seen (lowest score);
5. finally return that sequence as a plain Python list.

The only external dependency is NumPy; all operations are vectorised
and the dominant cost (the self‑convolution) is evaluated with FFTs.

"""
propose_candidate – search for a step function with a low evaluation score.

The algorithm is a projected Adam optimiser on the probability simplex.
At every iteration the convolution a*a is computed with FFTs, the K
largest convolution entries are identified and their sub‑gradients are
averaged.  The resulting direction is fed to Adam, after which the
vector is projected back onto the simplex (non‑negative, sum = 1).
Multiple sequence lengths and random restarts are tried until the
global time budget (≈ 1000 s) is exhausted.  The best sequence found
is returned as a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex
# (Duchi et al., 2008)
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto the simplex {x | x_i >= 0, sum x_i = 1}."""
    n = v.shape[0]
    if n == 0:
        return v
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    # find the last positive entry of (u - cssv / ind)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all non‑positive – return the centre of the simplex
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w

            if prev_seq and len(prev_seq) == n and restart_id == 0:
                a = np.array(prev_seq, dtype=np.float64)
                a = np.maximum(a, 0.0)
                s = a.sum()
                if s < 1e-12:
                    a = np.ones(n) / n
                else:
                    a = a / s
                print(f"[{time.time() - start_time:6.2f}s] "
                      f"Start from previous solution, n={n}")
            else:
                a = np.random.rand(n)
                a = a / a.sum()

            # Adam state
            m = np.zeros_like(a)
            v = np.zeros_like(a)
            beta1 = 0.9
            beta2 = 0.999
            eps = 1e-8
            lr = 0.04                     # initial learning rate

            # optimisation parameters
            it = 0
            max_iter = 80000              # hard upper bound per restart
            # FFT length – next power of two >= 2n‑1
            fft_len = 1 << ((2 * n - 1).bit_length())

            # ---------------------------------------------------------
            # optimisation loop
            while time.time() < deadline and it < max_iter:
                it += 1

                # ---- self‑convolution (linear, zero‑padded) -------------
                Af = np.fft.rfft(a, n=fft_len)
                conv = np.fft.irfft(Af * Af, n=fft_len)
                conv = conv[: 2 * n - 1]  # keep only the linear part

                max_val = conv.max()
                cur_score = 2.0 * n * max_val

                # keep the best ever seen
                if cur_score < best_score:
                    best_score = cur_score
                    best_seq = a.copy()
                    print(f"[{time.time() - start_time:6.2f}s] "
                          f"New best: n={n}, restart={restart_id}, "
                          f"iter={it}, score={cur_score:.6f}")

                # ---- gradient from the K largest convolution entries ----
                K = 5
                if K < conv.size:
                    top_idx = np.argpartition(-conv, K - 1)[:K]
                else:
                    top_idx = np.arange(conv.size)

                g = np.zeros_like(a)
                for k in top_idx:
                    low = max(0, k - (n - 1))
                    high = min(n - 1, k)
                    i_idx = np.arange(low, high + 1, dtype=np.int64)
                    j_idx = k - i_idx
                    # sub‑gradient of conv_k is 2*a_j
                    g[i_idx] += 2.0 * a[j_idx]
                g = g / len(top_idx)       # average over the selected ks

                # ---- Adam update ---------------------------------------
                m = beta1 * m + (1.0 - beta1) * g
                v = beta2 * v + (1.0 - beta2) * (g * g)

                # bias‑corrected estimates
                m_hat = m / (1.0 - beta1 ** it)
                v_hat = v / (1.0 - beta2 ** it)

                step = lr * m_hat / (np.sqrt(v_hat) + eps)
                a_new = a - step

                # ---- projection back onto the simplex ------------------
                a = _project_simplex(a_new)

                # ---- simple schedule to reduce lr if we stall ----------
                if it % 5000 == 0:
                    # if we are not improving fast, shrink the step size
                    if cur_score > best_score * 1.02:
                        lr *= 0.7
                        # also increase K a little, allowing more constraints
                        K = min(20, K + 5)

    # ------------------------------------------------------------------
    # fallback – should never happen, but keeps the contract safe.
    if best_seq is None:
        n_fallback = 1200
        best_seq = np.full(n_fallback, 1.0 / n_fallback)

    # The evaluator expects a plain Python list
    return [float(x) for x in best_seq]
