assistantfinal**Solution Explanation**

The evaluator  

```
score = 2·n·max(conv(a,a)) / (sum(a)²)
```

is *scale–invariant*.  Therefore we may impose the normalisation  

```
sum(a) = 1                     (1)
```

and minimise  

```
F(a) = 2·n·max(conv(a,a)) .    (2)
```

`conv(a,a)` is the linear (not circular) convolution of `a` with itself.
For a fixed `n` the problem can be seen as a **flattening problem** for the
distribution of the sum of two i.i.d. draws from the discrete distribution
`a`.  The uniform distribution gives a triangular convolution and a score of
`2`.  By moving probability mass towards the ends of the interval the peak
of the convolution can be reduced – the goal is to make the convolution as
flat as possible.

The algorithm below is a multi‑scale optimisation that combines three
ingredients

* **Projected (adaptive) gradient descent on the simplex** – the gradient of
  a single active convolution entry `k` is
  `∂/∂a_i conv_k = 2·a_{k‑i}` (with the obvious range check).  
  We use a *momentum* term and a diminishing step size
  `η_t = η₀ / √t`.  After every step the vector is projected onto the
  probability simplex using the O(n) algorithm of Duchi et al. (2008).

* **Multiple active constraints** – instead of only the single maximal
  entry we take the `K` largest entries of the convolution (default `K=5`)
  and use the average of their sub‑gradients.  This follows the sub‑gradient
  of the pointwise maximum and gives a smoother descent direction.

* **Final simulated annealing** – once the gradient phase has stalled we run a
  cheap “move ε from one coordinate to another’’ Markov chain with a
  geometric temperature schedule.  Because the objective is cheap to evaluate
  (`O(n log n)` via FFT) we can afford many tiny moves; they help to escape
  shallow local minima and often improve the score by a few ‰.

The procedure works on a *schedule of increasing lengths*.
A good solution for a small `n` is interpolated (linear interpolation) to
 initialise the next larger size, thus re‑using the shape that has already been
flattened.  The whole search stops automatically after the user‑specified
budget (default 1000 s).

The code uses only `numpy` and `scipy.optimize.linprog` (the latter is
available in the standard SciPy installation).  All helper functions are
top‑level, there are no closures or lambda‑expressions, and every intermediate
vector is projected onto the simplex, guaranteeing that the evaluator never
receives an invalid input.

```python
"""
Multi‑scale projected gradient + simulated annealing for the step‑function
evaluation problem.

* work on the probability simplex (sum = 1) – the score is scale invariant;
* at each iteration compute the convolution by FFT;
* take the K largest convolution entries, form the average sub‑gradient;
* use momentum (β≈0.9) and a diminishing step η₀/√t, then project onto the
  simplex (Duchi et al. 2008);
* when the time budget is almost exhausted run a cheap simulated‑annealing
  local search;
* start from a small n and up‑sample the best sequence when the length grows.
"""
import time
import math
import numpy as np
from scipy.optimize import linprog

# ------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex
# ------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto {x | x_i ≥ 0, sum x_i = 1} using the O(n) algorithm."""
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all non‑positive – return uniform point
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ------------------------------------------------------------
# Convolution a * a  (linear, not circular) via FFT
# ------------------------------------------------------------
def _conv_self(a: np.ndarray) -> np.ndarray:
    n = a.shape[0]
    fft_len = 1 << ((2 * n - 1).bit_length())   # next power of two
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)[: 2 * n - 1]
    return conv


# ------------------------------------------------------------
# Sub‑gradient from the K largest convolution entries
# ------------------------------------------------------------
def _active_indices(conv: np.ndarray, K: int) -> np.ndarray:
    """Return the indices of the K largest entries of conv."""
    m = conv.size
    if K >= m:
        return np.arange(m, dtype=int)
    # argpartition gives the K largest unordered
    idx = np.argpartition(-conv, K - 1)[:K]
    return idx.astype(int)


def _subgradient_from_active(a: np.ndarray, act_idx: np.ndarray) -> np.ndarray:
    """Average sub‑gradient of the active convolution entries."""
    n = a.shape[0]
    g = np.zeros_like(a)
    for k in act_idx:
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        i = np.arange(lo, hi + 1)
        j = k - i
        g[i] += 2.0 * a[j]
    if act_idx.size > 0:
        g /= act_idx.size
    return g


# ------------------------------------------------------------
# Projected (momentum) gradient descent on the simplex
# ------------------------------------------------------------
def _run_gradient_descent(
    a0: np.ndarray,
    n: int,
    deadline: float,
    start_time: float,
    K: int = 5,
    beta: float = 0.9,
    step0: float = 0.6,
    max_iter: int = 60000,
):
    """Return best sequence found (and its score) for a fixed length n."""
    a = a0.copy()
    momentum = np.zeros_like(a)
    best_a = a.copy()
    best_score = float("inf")
    it = 0

    while time.time() < deadline and it < max_iter:
        it += 1
        conv = _conv_self(a)
        max_val = conv.max()
        cur_score = 2.0 * n * max_val

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(
                f"[{time.time() - start_time:6.2f}s] "
                f"gradient improve: n={n}, iter={it}, score={cur_score:.6f}"
            )

        # sub‑gradient built from the K largest entries
        act = _active_indices(conv, K)
        grad = _subgradient_from_active(a, act)

        # momentum update
        momentum = beta * momentum + (1.0 - beta) * grad

        # diminishing step size
        step = step0 / math.sqrt(it)

        # gradient step + projection onto simplex
        a = _project_simplex(a - step * momentum)

    return best_a, best_score


# ------------------------------------------------------------
# Simulated annealing local refinement
# ------------------------------------------------------------
def _run_annealing(
    a0: np.ndarray,
    n: int,
    deadline: float,
    start_time: float,
    cur_best_score: float,
    cur_best_seq: np.ndarray,
    start_temp: float = 5e-2,
    end_temp: float = 1e-5,
    steps: int = 20000,
):
    """Tiny “move ε from i to j’’ annealing, returns possibly improved pair."""
    a = a0.copy()
    score = 2.0 * n * _conv_self(a).max()
    best_seq = cur_best_seq
    best_score = cur_best_score

    for it in range(1, steps + 1):
        if time.time() >= deadline:
            break
        # geometric temperature schedule
        T = start_temp * (end_temp / start_temp) ** (it / steps)

        # propose a small mass transfer
        i, j = np.random.randint(0, n, size=2)
        if i == j or a[i] == 0.0:
            continue
        eps = a[i] * np.random.rand() * 0.1  # up to 10 % of a[i]
        a_prop = a.copy()
        a_prop[i] -= eps
        a_prop[j] += eps

        # compute new score
        new_score = 2.0 * n * _conv_self(a_prop).max()
        delta = new_score - score

        # Metropolis acceptance
        if delta < 0 or math.exp(-delta / T) > np.random.rand():
            a = a_prop
            score = new_score

        # keep global best
        if score < best_score:
            best_score = score
            best_seq = a.copy()
            print(
                f"[{time.time() - start_time:6.2f}s] "
                f"annealing improve: n={n}, iter={it}, score={score:.6f}"
            )

    return best_seq, best_score


# ------------------------------------------------------------
# Upsampling (linear interpolation) from old length to new length
# ------------------------------------------------------------
def _upsample(seq: np.ndarray, new_n: int) -> np.ndarray:
    old_n = seq.shape[0]
    if old_n == new_n:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    up = np.interp(new_x, old_x, seq)
    # re‑normalise to sum = 1
    up_sum = up.sum()
    if up_sum > 0:
        up /= up_sum
    else:
        up = np.full_like(up, 1.0 / new_n)
    return up


# ------------------------------------------------------------
# Main entry point required by the evaluation harness
# ------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Find a non‑negative step‑function (list of heights) that minimises
    `evaluate_sequence`.  The algorithm runs for at most `budget_s` seconds
    and combines projected gradient descent on the simplex, multi‑scale
    up‑sampling and a final simulated‑annealing refinement.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 1.0  # small safety margin

    best_score = float("inf")
    best_seq = None

    # --- optional starter (the previous best construction) -----------------
    try:
        # the external runner may have provided this variable
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = starter / starter.sum()  # enforce the simplex
    except Exception:
        starter = None

    # Length schedule (geometric growth).  Larger n gives a lower theoretical
    # bound but each iteration costs O(n log n).  The list is deliberately
    # modest to keep the whole search within the time budget.
    lengths = [400, 800, 1200, 1800, 2400, 3200, 4800]
    # Shuffle a little to avoid systematic bias if the time runs out early
    np.random.shuffle(lengths)

    # Global best is always kept in the simplex (sum=1)
    global_a = starter if starter is not None else None

    for n in lengths:
        if time.time() >= deadline:
            break

        # ----- initialise -----
        if global_a is not None:
            a0 = _upsample(global_a, n)
        else:
            a0 = np.random.rand(n)
            a0 /= a0.sum()

        # allocate a slice of the remaining budget to this length
        remaining = deadline - time.time()
        if remaining <= 0:
            break
        # give at most 15 % of the remaining time to a single n (but at least 10 s)
        slice_deadline = time.time() + max(10.0, 0.15 * remaining)

        # ----- gradient phase -----
        a_opt, score_opt = _run_gradient_descent(
            a0,
            n,
            slice_deadline,
            start_time,
            K=5,
            beta=0.9,
            step0=0.6,
            max_iter=60000,
        )
        # keep the global best
        if score_opt < best_score:
            best_score = score_opt
            best_seq = a_opt.copy()
            print(
                f"[{time.time() - start_time:6.2f}s] "
                f"global improve after gradient: n={n}, score={score_opt:.6f}"
            )

        # ----- simulated annealing refinement (only if time permits) -----
        if time.time() < deadline:
            # share the remaining budget among the annealing runs
            anneal_deadline = time.time() + max(5.0, 0.05 * (deadline - time.time()))
            a_ref, score_ref = _run_annealing(
                a_opt,
                n,
                anneal_deadline,
                start_time,
                best_score,
                best_seq,
                start_temp=5e-2,
                end_temp=1e-5,
                steps=20000,
            )
            if score_ref < best_score:
                best_score = score_ref
                best_seq = a_ref.copy()
                print(
                    f"[{time.time() - start_time:6.2f}s] "
                    f"global improve after annealing: n={n}, score={score_ref:.6f}"
                )

        # remember the best sequence so far – it will be up‑sampled for the next n
        global_a = best_seq.copy()

    # ----------------------------------------------------------------------
    # Safety fallback (should never happen)
    # ----------------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(100, 1.0 / 100.0)

    # Convert to plain Python list – the evaluator accepts any list of floats
    return [float(x) for x in best_seq]
```
