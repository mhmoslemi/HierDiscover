"""
Propose a step‑function (non‑negative sequence) that minimizes the
evaluation function

    evaluate_sequence(a) = 2·n·max(conv(a,a)) / (sum(a)²)

where n = len(a).  The value is invariant under a global scaling of the
sequence, therefore we keep the ℓ¹‑norm fixed to √(2·n).  With this
normalisation the evaluation equals the peak of the self‑convolution,
so the task reduces to decreasing the supremum of a*a.

The algorithm combines two ideas:

1. **Linear‑programming exchange step** (the method described in the
   statement).  For a current shape `f` (ℓ¹‑norm = √(2n)) we compute
   `M = max(conv(f,f))`.  We then solve a linear program

        maximise   Σ g_i
        s.t.       conv(f,g) ≤ M   (one inequality for every shift)
                    g_i ≥ 0

   The optimum `g₀` typically has a much larger ℓ¹‑norm than `f`.  Scaling
   `g = (√(2n)/‖g₀‖₁)·g₀` restores the target norm and guarantees
   `max(conv(f,g)) < M`.  Mixing the two sequences
   `f ← (1‑t)·f + t·g` (with a decreasing step size `t`) strictly
   reduces the peak while preserving the norm.

2. **Fine‑grained hill‑climbing** – after the LP phase we perform a
   fast stochastic local search that repeatedly moves a tiny amount of
   mass between two positions and keeps the move only if the peak
   improves.  This refines the solution beyond the LP’s vertex.

The whole procedure runs inside the provided time budget (default
1000 s) and returns the best sequence discovered.  The implementation
uses only NumPy, SciPy’s `linprog` (highs) and standard library
functions, respects the non‑negativity constraint and caps values at
1000 (the final check performed by `evaluate_sequence`)."""

import time
import math
import numpy as np
from scipy.optimize import linprog
from scipy.linalg import toeplitz

# ----------------------------------------------------------------------
def build_initial_sequence(n: int, offset: float = 0.0) -> np.ndarray:
    """
    Analytic start: a_i ∝ 1/√(i+1+offset).  The sequence is ℓ¹‑normalised
    to sum = 1 (later scaled to √(2·n)).
    """
    idx = np.arange(1, n + 1, dtype=np.float64) + offset
    a = 1.0 / np.sqrt(idx)
    a /= a.sum()
    return a

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:

    Search for a non‑negative step‑function with a small evaluation
    value.  The function runs for at most ``budget_s`` seconds and
    returns the best sequence found as a plain Python list.
    """

    deadline = time.time() + budget_s - 0.5    # safety margin

    # --------------------------------------------------------------
    # 1. Choose a length.  n≈2000 balances memory, LP size and quality.
    n = 2000
    target_sum = math.sqrt(2.0 * n)            # ℓ¹‑norm we keep fixed

    # --------------------------------------------------------------
    # 2. Initialise the shape.

    # use the analytical 1/√i shape (with a short offset scan).
    try:

    except NameError:
        # no global variable – scan a few offsets and keep the best.
        best_val = np.inf
        best_seq = None
        for off in [0.0, 0.1, 0.5, 1.0, 2.0]:
            seq = build_initial_sequence(n, off)
            # fast evaluation for comparison (sum=1)
            conv = np.convolve(seq, seq)
            val = 2.0 * n * conv.max() / (seq.sum() ** 2)
            if val < best_val:

        init = best_seq

    # Rescale to the required ℓ¹‑norm.
    init = init * (target_sum / init.sum())
    init = np.maximum(0.0, init)                # safety

    def compute_peak(a: np.ndarray) -> float:
        return np.convolve(a, a).max()

    while time.time() < deadline:
        # Build the (2n‑1)×n Toeplitz matrix that maps g → conv(f,g).
        col = np.concatenate([cur, np.zeros(n - 1, dtype=np.float64)])
        row = np.zeros(n, dtype=np.float64)

            break

    # 4. Optional local refinement (stochastic mass‑transfer hill‑climb).
    # This stage is cheap (O(n log n) per trial) and often squeezes a

    # Clip values to the range accepted by evaluate_sequence and return.
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    return best_seq.tolist()
