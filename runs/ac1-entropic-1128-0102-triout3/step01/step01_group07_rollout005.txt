The evaluation function is  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

The objective is scale‑invariant, therefore we may enforce  

\[
\sum_i a_i = 1 .
\]

With this normalisation  

\[
F(a)=2\,n\;\max (a*a) .
\]

The only difficulty is the *max* of a quadratic form – the problem is not convex.
The following programme searches the space of admissible sequences with a
continuous optimisation method that respects the simplex constraints
automatically by re‑parameterising the variables with a soft‑max.

--------------------------------------------------------------------
### Main ideas  

1. **Soft‑max parametrisation**  
   Let `y∈ℝⁿ` and  

   \[
   a_i = \frac{e^{y_i}}{\sum_j e^{y_j}} .
   \]

   The mapping `y → a` always yields a non‑negative vector on the probability
   simplex, so the constraints are handled for free.

2. **Gradient of the active convolution entry**  
   For the index `k` where the convolution attains its maximum  
   \((a*a)_k\) we have  

   \[
   \frac{\partial (a*a)_k}{\partial a_i}=2\,a_{k-i}
   \qquad(\text{out‑of‑range indices give 0}).
   \]

   The gradient w.r.t. `y` follows from the Jacobian of the soft‑max:

   \[
   \frac{\partial F}{\partial y_i}= a_i\Bigl(
   2\,a_{k-i}-\sum_j a_j\,2\,a_{k-j}\Bigr) .
   \]

3. **Adam optimiser** – a robust first‑order method with adaptive
   step sizes.  
   The update is performed on the `y`‑variables, therefore we never have to
   project back onto the simplex.

4. **Multiple restarts & length sweep** – the search is run for several
   sequence lengths (`n` from 1500 up to 5000).  For every length a few random
   initialisations (random power‑law shapes) are tried; the best result over
   all runs is kept.

5. **Final local jitter** – after the main optimisation a cheap
   coordinate‑wise random walk (move a tiny amount of mass from one entry to
   another) is performed while time permits, to climb out of possible flat
   plateaus.

All operations are pure NumPy, the total running time stays well below the
1000 s limit.  The final sequence is returned as a plain Python list,
compatible with the supplied `evaluate_sequence` function.

"""
Gradient based optimisation of a non‑negative step function.

The sequence a (length n) is written as a soft‑max of an unconstrained vector
y.  Adam is used to minimise  2·n·max(conv(a,a)), i.e. the evaluation
function after fixing Σa_i = 1.  Several lengths and random restarts are
tried; a short random‑walk fine‑tuning is performed with the remaining
budget.
"""

import time
from typing import List

import numpy as np


# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def softmax(y: np.ndarray) -> np.ndarray:
    """Stable soft‑max returning a probability vector."""
    y_max = np.max(y)
    e = np.exp(y - y_max)
    return e / e.sum()


def conv_max_and_index(a: np.ndarray) -> tuple[float, int]:
    """Return (max(conv(a,a)), index_of_max)."""
    conv = np.convolve(a, a)
    idx = int(np.argmax(conv))
    return float(conv[idx]), idx


def active_gradient(a: np.ndarray, k: int) -> np.ndarray:
    """
    Gradient of the active convolution entry (a*a)_k w.r.t. a.

    For each i: d/d a_i (a*a)_k = 2 * a_{k-i}  (zero if the index is out of range).
    """
    n = a.shape[0]
    grad = np.zeros_like(a)
    start = max(0, k - (n - 1))
    end = min(k, n - 1)
    idx = np.arange(start, end + 1, dtype=int)
    grad[idx] = 2.0 * a[k - idx]
    return grad


def grad_y_from_a(a: np.ndarray, grad_a: np.ndarray) -> np.ndarray:
    """
    Convert a gradient w.r.t. a to a gradient w.r.t. the soft‑max parameters y.
    """
    inner = np.dot(grad_a, a)          # scalar = Σ_i a_i * ∂F/∂a_i
    return a * (grad_a - inner)       # Jacobian of soft‑max


def adam_update(
    y: np.ndarray,
    g: np.ndarray,
    m: np.ndarray,
    v: np.ndarray,
    t: int,
    alpha: float,
    beta1: float = 0.9,
    beta2: float = 0.999,
    eps: float = 1e-8,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """Perform one Adam step on y."""
    m = beta1 * m + (1.0 - beta1) * g
    v = beta2 * v + (1.0 - beta2) * (g * g)
    m_hat = m / (1.0 - beta1 ** t)
    v_hat = v / (1.0 - beta2 ** t)
    y_new = y - alpha * m_hat / (np.sqrt(v_hat) + eps)
    return y_new, m, v


def powerlaw_sequence(n: int, beta: float) -> np.ndarray:
    """Monotone decreasing sequence a_i ∝ (i+1)^{-β}, normalised to sum = 1."""
    idx = np.arange(1, n + 1, dtype=np.float64)
    seq = idx ** (-beta)
    seq /= seq.sum()
    return seq

def propose_candidate(seed: int = 42, budget_s: int = 1000, **_: None) -> List[float]:
    """
    Search for a step‑function sequence that minimises ``evaluate_sequence``.
    The function respects the 1000 s time budget and returns the best
    sequence found (as a list of floats).
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 5.0   # tiny safety margin

    # ------------------------------------------------------------------
    # 0) keep the best known construction (if it exists)
    # ------------------------------------------------------------------
    best_seq: List[float] | None = None
    best_score = float("inf")
    if "height_sequence_1" in globals():
        try:
            seq0 = list(height_sequence_1)  # type: ignore
            sc0 = evaluate_sequence(seq0)
            best_seq = seq0
            best_score = sc0
            print(f"[init] Using supplied height_sequence_1, score = {sc0:.6f}")
        except Exception:
            pass

    # ------------------------------------------------------------------
    # 1) try a few uniform baselines (they give score exactly 2.0)
    # ------------------------------------------------------------------
    for n0 in (1000, 2000, 3000):
        if time.time() >= deadline:
            break
        seq = np.full(n0, 1.0 / n0)
        sc = 2.0 * n0 * (np.convolve(seq, seq).max())
        if sc < best_score:
            best_score = sc
            best_seq = seq.tolist()
            print(f"[uniform] n={n0}, score={sc:.6f}")

    # ------------------------------------------------------------------
    # 2) main optimisation – sweep several lengths, several restarts
    # ------------------------------------------------------------------
    lengths = [1500, 2000, 2500, 2800, 3200, 3800, 4400, 5000]
    # for each length we perform a few independent Adam runs
    for n in lengths:
        if time.time() >= deadline:
            break

        restarts = 3
        for r in range(restarts):
            if time.time() >= deadline:
                break

            # ---- initial a -------------------------------------------------
            # use a random power‑law or the previous global best (if dimensions match)
            if best_seq is not None and len(best_seq) == n:
                a0 = np.array(best_seq, dtype=np.float64)
                a0 /= a0.sum()                     # re‑normalise to avoid round‑off drift
            else:
                beta = np.random.uniform(0.0, 3.0)
                a0 = powerlaw_sequence(n, beta)

            # tiny noise to escape exact symmetry
            a0 += np.random.rand(n) * 1e-4
            a0 = np.clip(a0, 0.0, None)
            a0 /= a0.sum()

            # ---- re‑parameterisation ---------------------------------------
            y = np.log(a0 + 1e-12)                 # keep numbers away from -inf

            # Adam bookkeeping
            m = np.zeros_like(y)
            v = np.zeros_like(y)

            # learning‑rate schedule (initial value)
            alpha0 = 0.5

            max_iter = 20000                       # hard cap per restart
            for it in range(1, max_iter + 1):
                if time.time() >= deadline:
                    break

                # ---- current a -------------------------------------------------
                a = softmax(y)

                # ---- evaluate -------------------------------------------------
                max_conv, kmax = conv_max_and_index(a)
                cur_score = 2.0 * n * max_conv

                # keep global best
                if cur_score < best_score:
                    best_score = cur_score
                    best_seq = a.tolist()
                    print(f"[best] n={n}, restart={r}, it={it}, score={cur_score:.6f}")

                # ---- gradient of active entry ---------------------------------
                grad_a = active_gradient(a, kmax)

                # ---- back‑prop to y -------------------------------------------
                grad_y = grad_y_from_a(a, grad_a)

                # ---- Adam step ------------------------------------------------
                # simple decay of the base learning rate
                alpha = alpha0 / (1.0 + 1e-5 * it)
                y, m, v = adam_update(y, grad_y, m, v, it, alpha)

                # ---- occasional jitter to avoid stagnation --------------------
                if it % 5000 == 0:
                    jitter = np.random.randn(n) * 0.01
                    y += jitter

                # ---- safety net ------------------------------------------------
                if np.isnan(y).any() or np.isinf(y).any():
                    # re‑initialise from the current a (safe fallback)
                    y = np.log(a + 1e-12)
                    m.fill(0.0)
                    v.fill(0.0)
                    print("[reset] NaN/Inf detected, re‑initialising y")

    # ------------------------------------------------------------------
    # 3) cheap random‑walk fine‑tuning while time permits
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 5.0:
        a_cur = np.array(best_seq, dtype=np.float64)
        n = a_cur.shape[0]
        cur_best = best_score

        # number of fine‑tuning steps is limited by remaining budget
        while time.time() < deadline:
            # pick two distinct indices
            i, j = np.random.choice(n, size=2, replace=False)
            # propose a small transfer δ from i to j
            max_transfer = min(a_cur[i], 0.05 * a_cur[i])  # bound magnitude
            if max_transfer <= 0:
                continue
            delta = (np.random.rand() * 2.0 - 1.0) * max_transfer
            if a_cur[i] - delta < 0.0 or a_cur[j] + delta < 0.0:
                continue

            a_new = a_cur.copy()
            a_new[i] -= delta
            a_new[j] += delta

            max_conv, _ = conv_max_and_index(a_new)
            new_score = 2.0 * n * max_conv

            if new_score < cur_best:
                cur_best = new_score
                a_cur = a_new
                best_score = new_score
                best_seq = a_cur.tolist()
                print(f"[fine] improved to {new_score:.6f}")

    # ------------------------------------------------------------------
    # 4) fallback (should never happen)
    # ------------------------------------------------------------------
    if best_seq is None:
        n = 500
        a_fallback = np.full(n, 1.0 / n)
        best_seq = a_fallback.tolist()
        best_score = evaluate_sequence(best_seq)

    print(f"Final best score ≈ {best_score:.6f} (length {len(best_seq)})")
    return best_seq
