assistantfinal**Solution Explanation**

The task is to minimise  

\[
E(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the evaluation is homogeneous we may (and will) keep the vector
normalised to a probability simplex, i.e.  \(\sum_i a_i = 1\).
Then  

\[
E(a)=2\,n\;\max_k (a*a)_k .
\]

The convolution is a smooth (quadratic) function of the vector `a`.  
A direct optimisation of the *maximum* is difficult because the maximum
is non‑differentiable.  
We therefore replace the maximum by a smooth *soft‑maximum*

\[
S_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_k\exp\bigl(\beta\,(a*a)_k\bigr)\Bigr)
\]

and perform projected (simplex) gradient descent on
\(S_\beta\).  When the smoothing parameter \(\beta\) is small the
objective is almost flat; as the algorithm proceeds \(\beta\) is
increased, turning the soft‑maximum into the true maximum.
The update direction is obtained analytically:

\[
\frac{\partial S_\beta}{\partial a}
    = 2\;a\star p ,
\qquad
p_k = \frac{\exp\bigl(\beta\,(a*a)_k\bigr)}{\sum_j \exp\bigl(\beta\,(a*a)_j\bigr)} .
\]

`a⋆p` is a **cross‑correlation** of the current vector `a`
with the probability vector `p`.  
Both the convolution and the cross‑correlation are computed with a real
FFT – \(O(n\log n)\) per iteration, fast enough for tens of thousands
of iterations within the 1000 s budget.

The algorithm
* starts from the classic half‑binomial (central‑binomial) sequence –
  a very good construction already,
* mixes a small uniform component to diversify the initial shape,
* repeatedly:
  * evaluates the current convolution,
  * builds the soft‑maximum weights `p`,
  * computes the gradient via a cross‑correlation,
  * takes a step opposite to the gradient,
  * projects the result back onto the probability simplex,
  * remembers the best vector ever seen,
  * slowly raises `β` and shrinks the step size,
  * occasionally accepts uphill moves (simulated annealing) to escape
    shallow local minima.

The whole routine is completely self‑contained, uses only NumPy,
and respects all execution limits.

```python
"""
Projected gradient descent with a soft‑maximum objective.

We minimise 2 · n · max(a∗a) under a_i≥0, Σa_i=1.
The maximum is replaced by a smooth log‑sum‑exp; the gradient is a
cross‑correlation that we compute with FFTs.  The algorithm starts from
the half‑binomial sequence, mixes a little uniform mass and then
performs many fast iterations, slowly sharpening the soft‑maximum.
The best sequence found before the time limit is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)

def sqrt_series(n: int) -> np.ndarray:
    """
    Generate the first n coefficients of (1‑z)^(-1/2):
        a_i = C(2i,i)/4**i .
    The result is normalised to sum==1 (probability simplex).
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    a /= a.sum()
    return a


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto {x | x_i ≥ 0, Σx_i = 1}
    (Duchi et al., 2008).  Returns a new array, does not modify v.
    """
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]

    u = np.sort(v)[::-1]                # descending sort
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)

    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries zero after projection – fall back to uniform
        return np.full_like(v, 1.0 / n)

    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def conv_fft(a: np.ndarray, L: int) -> np.ndarray:
    """
    Linear self‑convolution a*a using real FFT of length L (L ≥ 2·len(a)-1).
    Returns the first 2·len(a)-1 entries (the true convolution).
    """
    A = np.fft.rfft(a, n=L)
    conv_full = np.fft.irfft(A * A, n=L)
    n = a.shape[0]
    return conv_full[: 2 * n - 1]


def cross_corr_linear(a: np.ndarray, w: np.ndarray, L: int) -> np.ndarray:
    """
    Linear cross‑correlation (a ⋆ w)_i = Σ_j a_j * w_{i+j},
    where len(a)=n, len(w)=2·n-1.
    The result has length n (indices 0 … n‑1).
    Computed with a single pair of FFTs of length L (L ≥ n+len(w)-1).
    """
    A = np.fft.rfft(a, n=L)
    W = np.fft.rfft(w, n=L)
    corr_full = np.fft.irfft(A * np.conj(W), n=L)
    return corr_full[: a.shape[0]]


# ----------------------------------------------------------------------
def propose_candidate(budget_s: float = 950.0,
                     seed: int = 42,
                     length: int = 2500,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative sequence that minimises the provided
    ``evaluate_sequence`` function.

    Parameters
    ----------
    budget_s : float
        Time budget (seconds) – the loop stops a few seconds earlier.
    seed : int
        Random seed for reproducibility.
    length : int
        Number of coefficients (default 2500 – the same as the reference).

    Returns
    -------
    list[float]
        The best sequence found (already normalised, non‑negative).
    """
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # problem size and FFT length
    n = int(length)
    # L must be a power of two ≥ max(2·n‑1, 3·n‑2)
    L_conv = 1 << ((2 * n - 1).bit_length())
    L_corr = 1 << ((3 * n - 2).bit_length())
    L = max(L_conv, L_corr)                 # single length used for all FFTs

    # --------------------------------------------------------------
    # initial point: half‑binomial + a little uniform mass
    a = sqrt_series(n)                      # sums to 1
    uniform = np.full(n, 1.0 / n)
    a = 0.7 * a + 0.3 * uniform
    a = project_onto_simplex(a)             # safety projection

    # current evaluation (sum(a)=1 ⇒ denominator = 1)
    conv = conv_fft(a, L)
    cur_score = 2.0 * n * conv.max()
    best_a = a.copy()
    best_score = cur_score

    print(f"[init] n={n}, initial score={cur_score:.6f}")

    # --------------------------------------------------------------
    # hyper‑parameters
    eta = 0.12                               # initial step size
    beta = 0.5                               # soft‑max sharpness
    beta_max = 25.0
    beta_inc = (beta_max - beta) / 40000.0   # linear increase
    temperature = 0.02                       # for occasional uphill moves
    decay_factor = 0.995                     # applied each iteration
    min_eta = 5e-5
    min_temp = 1e-6

    # counters for restarts
    it_no_improve = 0
    restart_threshold = 5000

    # --------------------------------------------------------------
    deadline = time.time() + budget_s - 5.0   # safety margin
    it = 0
    while time.time() < deadline:
        # ----- current convolution & soft‑max weights -----
        conv = conv_fft(a, L)
        max_val = conv.max()
        # the convolution values are O(1/n); scaling by n improves the soft‑max contrast
        scaled = (conv - max_val) * n
        w = np.exp(beta * scaled)
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # ----- gradient (negative direction) -----
        grad = 2.0 * cross_corr_linear(a, w, L)      # shape (n,)

        # ----- trial step -----
        step = eta * grad
        # avoid removing more than 80 % of any entry in one step
        step = np.minimum(step, a * 0.8)
        a_trial = a - step

        # occasional tiny random jitter to maintain diversity
        if rng.random() < 0.006:
            a_trial += (rng.random(n) - 0.5) * 1e-5

        # projection onto the simplex (guarantees non‑negativity & sum=1)
        a_trial = project_onto_simplex(a_trial)

        # ----- evaluate trial -----
        conv_trial = conv_fft(a_trial, L)
        trial_score = 2.0 * n * conv_trial.max()

        # keep global best
        if trial_score < best_score:
            best_score = trial_score
            best_a = a_trial.copy()
            it_no_improve = 0
            print(f"[iter {it:07d}] new best = {best_score:.6f}")

        # ----- acceptance rule -----
        if trial_score <= cur_score:
            a = a_trial
            cur_score = trial_score
            it_no_improve = 0
        else:
            # simulated‑annealing acceptance for uphill moves
            delta = trial_score - cur_score
            if temperature > 0.0 and rng.random() < np.exp(-delta / temperature):
                a = a_trial
                cur_score = trial_score
            it_no_improve += 1

        # ----- parameter schedules -----
        beta = min(beta + beta_inc, beta_max)
        eta = max(eta * decay_factor, min_eta)
        temperature = max(temperature * decay_factor, min_temp)

        # ----- occasional restart if stuck -----
        if it_no_improve >= restart_threshold:
            # re‑initialise from a blend of the current best and uniform noise
            noise = (rng.random(n) - 0.5) * 1e-3
            a = 0.6 * best_a + 0.4 * uniform + noise
            a = project_onto_simplex(a)
            it_no_improve = 0
            print(f"[iter {it:07d}] restart triggered")

        it += 1

    # --------------------------------------------------------------
    # final verification with the provided evaluator (security checks)
    final_score = evaluate_sequence(best_a.tolist())
    print(f"[done] iterations={it}, best reported score={final_score:.6f}")

    return best_a.tolist()
```
