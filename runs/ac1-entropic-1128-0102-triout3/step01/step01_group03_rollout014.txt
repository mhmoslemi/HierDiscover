Mirror‑descent optimizer for the max‑auto‑convolution problem.

The algorithm maintains a probability vector a (non‑negative, sum = 1)
and repeatedly:
  * computes the full self‑convolution a*a,
  * builds a smooth approximation of the max via a softmax with temperature β,
  * obtains the gradient of this smooth objective as a cross‑correlation
    between the softmax weights and a,
  * updates a by an exponentiated‑gradient step (mirror descent on the
    simplex) and renormalises,
  * occasionally accepts uphill moves with a simple annealing schedule.

Parameters (β, step‑size, temperature) are slowly annealed so that the
method first performs large, noise‑tolerant moves and finally refines
the solution.  The best vector seen during the run is kept and returned.

import time
import numpy as np

def sqrt_series(n: int) -> np.ndarray:
    """Half‑binomial coefficients (central‑binomial) normalised to sum = 1."""

    a /= a.sum()
    return a

    """Return the smallest power‑of‑two ≥ x."""
    return 1 << (x - 1).bit_length()

    """Linear convolution a*a using FFT of length L ≥ 2·len(a)−1."""
    X = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(X * X, n=L)
    m = 2 * a.size - 1
    return conv[:m]


def compute_gradient(a: np.ndarray, p: np.ndarray, L: int) -> np.ndarray:
    """
    Gradient of the smooth‑max objective.

    Returns   g_i = 2 * Σ_k p_k a_{k-i}
    (linear‐cross‑correlation of p and a, restricted to i=0..n‑1).

Mirror‑descent optimizer for the max‑auto‑convolution problem.

The function seeks a non‑negative vector a (sum = 1) that minimises

        2·n·max(a∗a)          (the value returned by evaluate_sequence)

works on the probability simplex by:

1. Computing the full self‑convolution a∗a (FFT, O(n log n)).
2. Building a smooth approximation of the L∞‑norm via a soft‑max
   with temperature β (β grows during the run, so the surrogate
   gradually becomes the true max).
3. Obtaining the gradient of this smooth objective – it is just a
   cross‑correlation between the soft‑max weights and a (again via FFT).
4. Performing an exponentiated‑gradient (mirror descent w.r.t. KL) step
   a_i ← a_i·exp(‑η·grad_i) and re‑normalising onto the simplex.
5. Occasionally accepting uphill moves with a tiny Metropolis temperature
   to escape shallow local minima.

β, the step size η and the Metropolis temperature are annealed so that
the optimizer first makes large, noise‑tolerant jumps and then refines

            best_a = a_new.copy()
            stagnation_counter = 0
            print(f"[iter {it:08d}] new best score = {best_score:.6f}")

        # ---- 7) acceptance rule (always accept improvements)
        accepted = False
        if cand_score <= cur_score:
            accepted = True
        else:
            delta = cand_score - cur_score
            if temperature > 0 and rng.random() < np.exp(-delta / temperature):
                accepted = True

        if accepted:
            a = a_new
            a_fft = a_fft_new
            conv = conv_new
            cur_score = cand_score
        else:
            stagnation_counter += 1

        # ---- 8) annealing schedules
        beta = min(beta * beta_growth, beta_max)
        eta = max(eta * eta_decay, 1e-5)
        temperature = max(temperature * temp_decay, 1e-6)

        # ---- 9) occasional restart if we have been stuck for long
        if stagnation_counter > 200_000:
            # blend the current best with fresh randomness
            rnd = rng.random(n)
            rnd /= rnd.sum()
            a = 0.7 * best_a + 0.3 * rnd
            a /= a.sum()
            conv, a_fft = conv_fft_full_with_fft(a, L)
            cur_score = 2.0 * n * conv.max()
            stagnation_counter = 0
            print(f"[iter {it:08d}] restart after stagnation")

        if (it + 1) % log_interval == 0:
            print(f"[iter {it+1:08d}] score={cur_score:.6f} beta={beta:.3f} eta={eta:.5f}")

        it += 1

    # --------------------------------------------------------------
    # Final verification with the provided evaluate_sequence (safety)
    final_score = evaluate_sequence(best_a.tolist())
    print(f"[done] iterations={it}, best reported score={final_score:.6f}")

    return best_a.tolist()
```

This implementation uses a smooth‑max surrogate, fast FFT‑based convolution / correlation, and mirror‑descent on the simplex.  
It stays within the 1000‑second budget, prints progress, and returns the best sequence it discovers.
