The evaluation function  

\[
\text{score}= \frac{2\,n\;\max\limits_k (a*a)[k]}
                 {\bigl(\sum_i a_i\bigr)^2}
\]

depends only on the *shape* of a non‑negative vector `a` (the scale of the vector cancels out).  
For a fixed length `n` the uniform vector gives the worst possible value `score = 2`.  
All known good vectors are **asymmetric** – they put a little more mass at the left side,
which lowers the largest self‑convolution coefficient (the dominant term is the
convolution at the centre of the array).

The previous implementation explored only *symmetric* families, therefore it could
only reach `≈ 1.508`.  
The new program adds several **asymmetric families**, searches them quickly,
and then refines the best candidate with the same projected sub‑gradient descent
and a light simulated‑annealing polish.

Key ideas
* generate decreasing power‑law, exponential and front‑plateau shapes
  (`a_i ∝ (1‑i/(n‑1))^p`, `a_i ∝ e^{‑β i}`, …), normalise to a probability vector,
* keep a small pool of the best candidates,
* run a momentum based projected sub‑gradient descent that concentrates the
  gradient on the `top_k` largest convolution entries,
* finish with a fast Metropolis annealing that moves tiny packets of mass
  between random positions,
* all helper functions are top‑level (picklable) and the whole search stops
  safely before the 1000 s hard limit.

The code below implements the whole pipeline.  It returns a plain
`list[float]` that can be fed directly to `evaluate_sequence`.  

```python
"""
Propose a step‑function with a very low evaluation score.

Algorithm (≈1000 s budget)
--------------------------------
1.  Problem size – n = 2¹¹ = 2048 is a good compromise between
    discretisation error and FFT speed.  The lower bound 1.503 can already be
    approached with this size, and the whole search fits comfortably into the
    time budget.

2.  Initial pool – generate many asymmetric families:
        * decreasing power‑law   a_i ∝ (1‑i/(n‑1))^p
        * exponential decay      a_i ∝ exp(‑β i)
        * front‑plateau + ramp    a_i = const on a prefix, then a decreasing
                                  power‑law.
    Sweep the few parameters (p, β, plateau‑size) and keep the best few
    candidates.  Add a handful of random Dirichlet vectors for extra
    diversity.

3.  Projected sub‑gradient descent – start from the best pool element.
    In each iteration the convolution is obtained by a real FFT.
    The sub‑gradient is the average of the gradients of the *K* largest
    convolution entries (default K = 5).  Momentum (β = 0.95) and a
    step‑size ηₜ = η₀ / √t (η₀ = 1.0) are used, and after every step the
    vector is projected onto the probability simplex.

4.  Light simulated‑annealing polish – move a random fraction (up to 20 %)
    of the mass from a source index to a destination index.
    Acceptance follows a Metropolis rule with an exponential cooling schedule.

5.  Normalise and return a plain Python list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based linear self‑convolution (real FFT, length 2·n‑1)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray) -> np.ndarray:
    """Return linear convolution a*a using a real FFT."""
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


# ----------------------------------------------------------------------
# Exact objective (scale‑invariant)
# ----------------------------------------------------------------------
def _objective(seq: np.ndarray) -> float:
    """2·n·max(conv(seq,seq)) / (sum(seq)²) (no safety checks)."""
    n = seq.shape[0]
    conv = _conv_self(seq)
    max_conv = conv.max()
    s = seq.sum()
    if s < 1e-12:                     # should never happen for a probability vector
        return np.inf
    return float(2.0 * n * max_conv / (s * s))


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex {x≥0, Σx=1}
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Projection onto the simplex via the algorithm of Wang & Carreira‑Perpiñán."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:                               # numeric fallback – unlikely
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Asymmetric shape generators
# ----------------------------------------------------------------------
def _make_power_decay(n: int, p: float) -> np.ndarray:
    """Decreasing power‑law shape a_i ∝ (1‑i/(n‑1))^p, normalised to sum = 1."""
    if p <= 0.0:
        # uniform
        shape = np.full(n, 1.0 / n)
    else:
        idx = np.arange(n, dtype=np.float64)
        shape = (1.0 - idx / (n - 1)) ** p
        total = shape.sum()
        if total > 0.0:
            shape = shape / total
        else:
            shape = np.full(n, 1.0 / n)
    return shape


def _make_exponential(n: int, beta: float) -> np.ndarray:
    """Exponential decay a_i ∝ exp(‑beta·i), normalised."""
    if beta <= 0.0:
        return np.full(n, 1.0 / n)
    idx = np.arange(n, dtype=np.float64)
    shape = np.exp(-beta * idx)
    total = shape.sum()
    if total > 0.0:
        shape = shape / total
    else:
        shape = np.full(n, 1.0 / n)
    return shape


def _make_front_plateau(n: int, p: float, alpha: float) -> np.ndarray:
    """
    Front plateau of relative width alpha∈[0,0.5] followed by a decreasing
    power‑law (exponent p>0).  The whole vector is normalised to sum = 1.
    """
    alpha = max(0.0, min(0.5, alpha))
    front_len = int(round(alpha * n))
    ramp_len = n - front_len
    if ramp_len <= 0:
        shape = np.full(n, 1.0 / n)
    else:
        # constant plateau (height = 1 before normalisation)
        plateau = np.ones(front_len, dtype=np.float64)
        idx = np.arange(ramp_len, dtype=np.float64)
        ramp = (1.0 - idx / (ramp_len - 1)) ** p
        shape = np.concatenate([plateau, ramp])
    total = shape.sum()
    if total > 0.0:
        shape = shape / total
    else:
        shape = np.full(n, 1.0 / n)
    return shape


# ----------------------------------------------------------------------
# Projected sub‑gradient descent (using the K largest convolution entries)
# ----------------------------------------------------------------------
def _subgradient_descent_multi(a0: np.ndarray,
                               deadline: float,
                               start_time: float,
                               top_k: int = 5) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent until *deadline*.
    Returns the best iterate seen (and its score).
    """
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(a)

    momentum = np.zeros_like(a)
    beta = 0.95            # stronger momentum – helps escape shallow plateaux
    step0 = 1.0            # larger initial step
    it = 0

    while time.time() < deadline:
        it += 1
        conv = _conv_self(a)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] Sub‑grad iter={it:,} "
                  f"score={cur_score:.6f}")

        # indices of the K largest convolution values
        if top_k >= conv.size:
            ks = np.arange(conv.size)
        else:
            ks = np.argpartition(conv, -top_k)[-top_k:]

        # sub‑gradient (average over the selected ks)
        grad = np.zeros_like(a)
        for k in ks:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            idx = np.arange(lo, hi + 1, dtype=int)
            grad[idx] += 2.0 * a[k - idx]

        grad /= float(len(ks))

        # momentum + diminishing step‑size
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)
        a -= step * momentum

        # projection onto simplex
        a = _project_simplex(a)

    return best_a, best_score


# ----------------------------------------------------------------------
# Light simulated‑annealing polish
# ----------------------------------------------------------------------
def _anneal(seq: np.ndarray,
            deadline: float,
            start_time: float) -> tuple[np.ndarray, float]:
    """Metropolis moves that transfer a small packet of mass between positions."""
    a = seq.copy()
    n = a.shape[0]
    cur_score = _objective(a)
    best_a = a.copy()
    best_score = cur_score
    rng = np.random.default_rng()

    max_steps = 300_000   # enough to fill the remaining time

    for it in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        # exponential cooling (fast – only a light polish)
        T = 0.02 * (1e-6 / 0.02) ** (it / max_steps)

        # source proportional to its mass – more likely to move
        src = rng.choice(n, p=a)
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-14:
            continue

        # move a random fraction (≤20 %) of the source mass
        eps = a[src] * rng.random() * 0.20
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        new_score = _objective(a_prop)
        delta = new_score - cur_score

        if delta < 0.0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] Anneal iter={it:,} "
                      f"best={new_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function (probability vector) with
    a low value of ``evaluate_sequence``.
    Returns the sequence as a plain Python list.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin before the hard limit
    deadline = start_time + budget_s - 0.5

    # --------------------------------------------------------------
    # 1) Problem size – a power of two for fast FFTs
    # --------------------------------------------------------------
    n = 2048                       # 2¹¹ – enough for the target bound

    # --------------------------------------------------------------
    # 2) Build a diverse pool of promising candidates (asymmetric)
    # --------------------------------------------------------------
    best_seq = None
    best_score = float("inf")
    pool = []                      # list of (score, seq)
    pool_size = 12

    # ----- power‑law decay -------------------------------------------------
    for p in np.linspace(0.0, 5.0, 21):               # 0 → uniform, 5 → strong front‑bias
        a = _make_power_decay(n, p)
        sc = _objective(a)
        if sc < best_score:
            best_score, best_seq = sc, a.copy()
        if len(pool) < pool_size:
            pool.append((sc, a.copy()))
            pool.sort(key=lambda x: x[0])
        elif sc < pool[-1][0]:
            pool[-1] = (sc, a.copy())
            pool.sort(key=lambda x: x[0])

    # ----- exponential decay -----------------------------------------------
    for beta in np.logspace(-7, -2, 15):              # very slow → fast decay
        a = _make_exponential(n, beta)
        sc = _objective(a)
        if sc < best_score:
            best_score, best_seq = sc, a.copy()
        if len(pool) < pool_size:
            pool.append((sc, a.copy()))
            pool.sort(key=lambda x: x[0])
        elif sc < pool[-1][0]:
            pool[-1] = (sc, a.copy())
            pool.sort(key=lambda x: x[0])

    # ----- front‑plateau + power ramp ----------------------------------------
    for alpha in np.linspace(0.0, 0.5, 6):            # plateau width (0 → none)
        for p in np.linspace(0.5, 4.0, 8):
            a = _make_front_plateau(n, p, alpha)
            sc = _objective(a)
            if sc < best_score:
                best_score, best_seq = sc, a.copy()
            if len(pool) < pool_size:
                pool.append((sc, a.copy()))
                pool.sort(key=lambda x: x[0])
            elif sc < pool[-1][0]:
                pool[-1] = (sc, a.copy())
                pool.sort(key=lambda x: x[0])

    # ----- a few random Dirichlet vectors -----------------------------------
    rng = np.random.default_rng()
    for _ in range(200):
        if time.time() >= deadline:
            break
        # Dirichlet with concentration 0.5 gives slightly spiky vectors
        raw = rng.gamma(shape=0.5, scale=1.0, size=n)
        a = raw / raw.sum()
        sc = _objective(a)
        if sc < best_score:
            best_score, best_seq = sc, a.copy()
        if len(pool) < pool_size:
            pool.append((sc, a.copy()))
            pool.sort(key=lambda x: x[0])
        elif sc < pool[-1][0]:
            pool[-1] = (sc, a.copy())
            pool.sort(key=lambda x: x[0])

    print(f"[{time.time() - start_time:.2f}s] Initial best score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 3) Optional global starter (if the harness provides one)
    # --------------------------------------------------------------
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            if starter.sum() > 0.0:
                starter = starter / starter.sum()
                cur = _objective(starter)
                print(f"[{time.time() - start_time:.2f}s] Global starter score = {cur:.6f}")
                if cur < best_score:
                    best_score, best_seq = cur, starter.copy()
                    if len(pool) < pool_size:
                        pool.append((cur, starter.copy()))
                        pool.sort(key=lambda x: x[0])
                    elif cur < pool[-1][0]:
                        pool[-1] = (cur, starter.copy())
                        pool.sort(key=lambda x: x[0])
    except Exception:
        pass

    # --------------------------------------------------------------
    # 4) Local refinement – projected sub‑gradient descent
    # --------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)
        best_score = _objective(best_seq)

    remaining = deadline - time.time()
    if remaining > 40.0:                                 # keep a few seconds for polish
        sub_deadline = time.time() + 0.92 * remaining
        refined_seq, refined_score = _subgradient_descent_multi(best_seq,
                                                               sub_deadline,
                                                               start_time,
                                                               top_k=5)
        if refined_score < best_score:
            best_score, best_seq = refined_score, refined_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Refined score = {refined_score:.6f}")

    # --------------------------------------------------------------
    # 5) Light annealing polish (if any time left)
    # --------------------------------------------------------------
    if time.time() < deadline:
        anneal_seq, anneal_score = _anneal(best_seq, deadline, start_time)
        if anneal_score < best_score:
            best_score, best_seq = anneal_score, anneal_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Final anneal improve score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 6) Normalisation and conversion to plain Python list
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    tot = best_seq.sum()
    if tot > 0.0:
        best_seq = best_seq / tot
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished, final score ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
```
