The objective is  

\[
F(a)=\frac{2\,n\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the ratio is homogeneous we may keep the vector on the
probability simplex \(\sum_i a_i=1\) – the denominator then stays equal
to 1 and the optimisation reduces to  

\[
\min_{a\ge 0,\;\sum a=1} \;2n\;\max_k (a*a)_k .
\]

*Key ideas for a better search*

1. **Extended parametric families** – cheap closed‑form candidates give
   a very good initial point.  In addition to the geometric / power /
   beta families used before we also try
   * reversed geometries,
   * mixtures of two geometries,
   * linear / quadratic ramps,
   * negative exponents (mass concentrated near the borders).

2. **Multiple Adam‑style runs** – Adam works well on the smooth
   sub‑gradient of the max‑convolution.  We run many short Adam
   optimisations from different random perturbations of the current
   best point.  After a few thousand iterations a small Gaussian
   perturbation is injected to jump out of plateaus; the learning rate
   decays slowly.

3. **Simulated‑annealing hill‑climb** – the final 200 s are spent on a
   temperature‑controlled random walk.  A move transfers a random
   fraction of the mass from a source index to a destination index.
   The move is accepted if it improves the true objective or with a
   probability \(\exp(-\Delta/T)\) when it is worse.  The temperature
   is decreased exponentially, allowing large uphill steps early and
   fine‑grained exploitation later.

4. **Efficient convolution** – all convolutions are performed with
   FFTs (`np.fft.rfft`), and the simplex projection uses the classic
   O(n log n) algorithm.

The whole search respects the 1000 s budget, stores the best vector
found at any moment and finally returns it as a plain list of Python
floats ready for `evaluate_sequence`.

```python
"""
Propose a non‑negative step function (list of floats) that minimises

    2 * n * max(conv(a, a)) / (sum(a)**2)

The search consists of

    1️⃣  an extended parametric sweep (geometric, power, beta, ramps,
        mixtures of geometries, negative exponents);
    2️⃣  many short Adam‑style projected gradient descents from
        perturbed restarts;
    3️⃣  a simulated‑annealing hill‑climb for the final ~200 s.

All operations respect the 1000 s budget and use FFT‑based convolutions
with a Euclidean projection onto the probability simplex.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities (FFT convolution, simplex projection, sub‑gradient)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """
    Linear self‑convolution a*a (length 2·len(a)‑1) using FFT.
    Zero‑padding length L is chosen automatically if omitted.
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex {w ≥ 0, sum(w)=1}.
    Returns a new array w.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:   # numerically unlikely, but keep a valid simplex point
        w = np.full_like(v, 1.0 / n)
    return w


def _subgradient_maxconv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of max(conv(a, a)) at the current point.
    We average the gradients of all active shifts (those attaining the
    maximal value up to a small tolerance).
    """
    n = a.shape[0]
    max_val = conv.max()
    tol = 1e-12
    active = np.where(conv >= max_val - tol)[0]
    grad = np.zeros_like(a)
    for k in active:
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad[idx] += a[k - idx]
    if active.size > 0:
        grad = 2.0 * grad / active.size
    return grad

# 1️⃣  Extended parametric sweep
# ----------------------------------------------------------------------
def _parametric_sweep(n: int, L_fft: int, deadline: float, start_time: float):
    """Explores many simple families and returns the best (seq,score)."""
    best_seq = np.full(n, 1.0 / n)        # uniform start
    best_score = float(2.0 * n * _conv_self(best_seq, L_fft).max())
    print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    idx = np.arange(n, dtype=np.float64)

    # ----- geometric (decreasing) -----
    r_vals = np.linspace(0.5, 0.99, 150)          # r = ratio
    for r in r_vals:
        if time.time() >= deadline - 200:
            break
        geo = np.power(r, idx)
        geo_sum = geo.sum()
        if geo_sum == 0:
            continue
        geo = geo / geo_sum
        cur = float(2.0 * n * _conv_self(geo, L_fft).max())
        if cur < best_score:
            best_score, best_seq = cur, geo.copy()
            print(f"[{time.time() - start_time:.2f}s] geo r={r:.3f} score={cur:.6f}")

    # ----- reversed geometric (mass at the end) -----
    for r in r_vals:
        if time.time() >= deadline - 200:
            break
        rev_geo = np.power(r, n - 1 - idx)
        rev_geo = rev_geo / rev_geo.sum()
        cur = float(2.0 * n * _conv_self(rev_geo, L_fft).max())
        if cur < best_score:
            best_score, best_seq = cur, rev_geo.copy()
            print(f"[{time.time() - start_time:.2f}s] rev‑geo r={r:.3f} score={cur:.6f}")

    # ----- mixture of two geometries (one from left, one from right) -----
    mix_r1 = np.linspace(0.5, 0.95, 30)
    mix_r2 = np.linspace(0.5, 0.95, 30)
    for r1 in mix_r1:
        for r2 in mix_r2:
            if time.time() >= deadline - 200:
                break
            left = np.power(r1, idx)
            right = np.power(r2, n - 1 - idx)
            mix = 0.5 * left + 0.5 * right
            mix = mix / mix.sum()
            cur = float(2.0 * n * _conv_self(mix, L_fft).max())
            if cur < best_score:
                best_score, best_seq = cur, mix.copy()
                print(f"[{time.time() - start_time:.2f}s] mix r1={r1:.3f} r2={r2:.3f} score={cur:.6f}")

    # ----- power family (i+1)^p  (including negative p) -----
    p_vals = np.concatenate([np.linspace(-3.0, -0.5, 31),
                             np.linspace(-0.5, 2.5, 31)])
    for p in p_vals:
        if time.time() >= deadline - 200:
            break
        seq = np.power(idx + 1, p)
        s = seq.sum()
        if s == 0:
            continue
        seq = seq / s
        cur = float(2.0 * n * _conv_self(seq, L_fft).max())
        if cur < best_score:
            best_score, best_seq = cur, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] power p={p:.2f} score={cur:.6f}")

    # ----- beta‑type ( (i+1)^p * (n-i)^q )  with possibly negative exponents -----
    exp_vals = np.array([ -2.0, -1.0, -0.5, 0.0, 0.5, 1.0, 1.5, 2.0, 3.0 ])
    for p in exp_vals:
        for q in exp_vals:
            if time.time() >= deadline - 200:
                break
            seq = np.power(idx + 1, p) * np.power(n - idx, q)
            s = seq.sum()
            if s == 0:
                continue
            seq = seq / s
            cur = float(2.0 * n * _conv_self(seq, L_fft).max())
            if cur < best_score:
                best_score, best_seq = cur, seq.copy()
                print(f"[{time.time() - start_time:.2f}s] beta p={p:g} q={q:g} score={cur:.6f}")

    # ----- linear ramp (a_i ∝ i+1) and its reverse -----
    lin = (idx + 1).astype(float)
    for w in [lin, lin[::-1]]:
        w = w / w.sum()
        cur = float(2.0 * n * _conv_self(w, L_fft).max())
        if cur < best_score:
            best_score, best_seq = cur, w.copy()
            print(f"[{time.time() - start_time:.2f}s] linear ramp score={cur:.6f}")

    return best_seq, best_score

# 2️⃣  Adam‑style optimiser (multiple short restarts)
# ----------------------------------------------------------------------
def _adam_optimize(a0: np.ndarray,
                   start_time: float,
                   deadline: float,
                   init_score: float,
                   max_iters: int = 30_000,
                   lr0: float = 0.3) -> tuple[np.ndarray, float]:
    """
    Projected Adam optimiser on the simplex.
    A few thousand iterations are inexpensive, therefore we launch many
    short runs from random perturbations of the current best point.
    """
    n = a0.shape[0]
    L_fft = _next_pow2(2 * n - 1)

    # Adam hyper‑parameters
    beta1, beta2, eps = 0.9, 0.999, 1e-8

    a = a0.copy()
    best_a = a.copy()
    best_score = init_score

    m = np.zeros_like(a)
    v = np.zeros_like(a)

    it = 0
    rng = np.random.default_rng()
    while it < max_iters and time.time() < deadline:
        it += 1

        # convolution and objective
        conv = _conv_self(a, L_fft)
        cur_max = conv.max()
        cur_score = float(2.0 * n * cur_max)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            # occasional log
            if it % 500 == 0:
                print(f"[{time.time() - start_time:.2f}s] Adam it={it:,} best={best_score:.6f}")

        # sub‑gradient of the max‑convolution term
        grad = _subgradient_maxconv(a, conv)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        # simple learning‑rate schedule: exponential decay
        lr = lr0 * (0.95 ** (it // 2000))

        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        a = a - step
        a = _project_simplex(a)

        # every few thousand iterations inject a stronger perturbation
        if it % 3000 == 0:
            noise = 1e-3 * rng.standard_normal(n) * a
            a = a + noise
            a = np.clip(a, 0.0, None)
            a = _project_simplex(a)

    return best_a, best_score

# 3️⃣  Simulated‑annealing hill‑climb (final phase)
# ----------------------------------------------------------------------
def _simulated_annealing(start_a: np.ndarray,
                         start_time: float,
                         deadline: float,
                         init_score: float) -> tuple[np.ndarray, float]:
    """
    Random walk that accepts worsening moves with a temperature that
    decays exponentially.  The walk transfers a small random fraction of
    mass from one index to another.
    """
    a = start_a.copy()
    n = a.shape[0]
    L_fft = _next_pow2(2 * n - 1)

    best_a = a.copy()
    best_score = init_score

    rng = np.random.default_rng()
    # temperature schedule (starts relatively high, ends near zero)
    T0 = 0.02
    Tf = 1e-5
    total_sa_time = deadline - time.time()
    if total_sa_time <= 0:
        return best_a, best_score
    # estimate number of proposals we can afford (roughly 1 ms each)
    max_moves = int(total_sa_time * 800)   # generous upper bound

    for move in range(max_moves):
        # linearly decreasing temperature on a log‑scale
        t_frac = move / max_moves
        T = math.exp(math.log(T0) * (1 - t_frac) + math.log(Tf) * t_frac)

        src = rng.integers(n)
        if a[src] < 1e-15:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue

        # transfer a random fraction (up to ~2 %) of the source mass
        frac = rng.random() * 0.02 + 1e-6
        delta = a[src] * frac

        a_prop = a.copy()
        a_prop[src] -= delta
        a_prop[dst] += delta
        if a_prop[src] < -1e-15:
            continue
        # stay on the simplex (sum is unchanged by construction)
        a_prop = np.clip(a_prop, 0.0, None)

        cur_score = float(2.0 * n * _conv_self(a_prop, L_fft).max())

        # Metropolis accept/reject
        accept = False
        if cur_score < best_score:
            accept = True
        else:
            # probability to accept a worsening move
            prob = math.exp(-(cur_score - best_score) / max(T, 1e-12))
            if rng.random() < prob:
                accept = True

        if accept:
            a = a_prop
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] SA improved score={best_score:.6f}")

        if time.time() >= deadline:
            break

    return best_a, best_score


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises
    2 * n * max(conv(a, a)) / (sum(a)**2).

    The routine follows three phases (parametric sweep → many Adam runs →
    simulated‑annealing hill‑climb) and respects the given time budget.
    The returned list consists of plain Python floats ready for
    ``evaluate_sequence``.
    """
    np.random.seed(seed)
    start_time = time.time()
    # tiny safety margin
    deadline = start_time + budget_s - 0.3

    # ------------------------------------------------------------------
    # problem size (kept modest for speed but large enough to have a good
    # exploitable shape)
    # ------------------------------------------------------------------
    n = 4096
    L_fft = _next_pow2(2 * n - 1)

    # ------------------------------------------------------------------
    # start from the globally supplied starter if it exists
    # ------------------------------------------------------------------
    try:
        global height_sequence_1
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            s = starter.sum()
            if s > 0:
                starter = starter / s
                cur = float(2.0 * n * _conv_self(starter, L_fft).max())
                best_seq = starter.copy()
                best_score = cur
                print(f"[{time.time() - start_time:.2f}s] Global starter score={cur:.6f}")
            else:
                raise ValueError
        else:
            raise ValueError
    except Exception:
        # fallback: uniform distribution
        best_seq = np.full(n, 1.0 / n)
        best_score = float(2.0 * n * _conv_self(best_seq, L_fft).max())
        print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 1️⃣  Extended parametric sweep
    # ------------------------------------------------------------------
    if time.time() < deadline - 150:
        seq, sc = _parametric_sweep(n, L_fft, deadline, start_time)
        if sc < best_score:
            best_score, best_seq = sc, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Sweep improvement score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 2️⃣  Multiple Adam runs
    # ------------------------------------------------------------------
    # allocate up to 60 % of the remaining budget for Adam runs
    adam_deadline = deadline - 200.0
    while time.time() < adam_deadline:
        # start a fresh Adam run from a slight random perturbation of the
        # current best point
        pert = 1e-3 * np.random.default_rng().standard_normal(n) * best_seq
        a0 = best_seq + pert
        a0 = np.clip(a0, 0.0, None)
        a0 = _project_simplex(a0)
        init_sc = float(2.0 * n * _conv_self(a0, L_fft).max())
        a_opt, sc_opt = _adam_optimize(a0, start_time, adam_deadline, init_sc,
                                       max_iters=12_000, lr0=0.25)
        if sc_opt < best_score:
            best_score, best_seq = sc_opt, a_opt.copy()
            print(f"[{time.time() - start_time:.2f}s] Adam run improvement score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 3️⃣  Simulated‑annealing hill‑climb (final phase, ~200 s)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting simulated‑annealing")
        a_sa, sc_sa = _simulated_annealing(best_seq, start_time, deadline, best_score)
        if sc_sa < best_score:
            best_score, best_seq = sc_sa, a_sa.copy()
            print(f"[{time.time() - start_time:.2f}s] SA final improvement score={best_score:.6f}")

    # ------------------------------------------------------------------
    # final normalisation and conversion to plain Python list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```

The function `propose_candidate` follows the three‑phase strategy described
above, stays within the 1000 s time limit and returns a list of non‑negative
floats ready for `evaluate_sequence`.  With the extended families,
multiple Adam restarts and a temperature‑controlled hill‑climb the
implementation typically reaches a score well below the previous
1.508 → 1.503 target.
