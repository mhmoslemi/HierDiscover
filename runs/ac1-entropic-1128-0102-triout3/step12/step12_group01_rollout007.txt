The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max\,(a*a)}{(\sum a)^2}
\]

for a non‑negative step‑function `a`.  
Because the score is invariant under a positive scaling of `a`, we can fix the
normalisation `∑a = 1`.  Under this normalisation the problem becomes

\[
\min_{a\ge 0,\;\sum a =1}\; 2n\;\max\,(a*a)
\]

i.e. minimise the infinity‑norm of the self‑convolution.

The previous implementation used a hard sub‑gradient of the *max*.
When many shifts attain the same maximal value the sub‑gradient becomes
very noisy and the optimiser can stall.  
The new method replaces the hard max by a **smooth log‑sum‑exp approximation**

\[
\operatorname{smooth\_max}_\lambda (c)=\frac{1}{\lambda}\log\Bigl(\sum_i e^{\lambda c_i}\Bigr)
\]

with a temperature parameter `λ`.  For small `λ` the function is smooth;
as `λ` grows it converges to the true maximum.  During optimisation `λ`
is increased (deterministic annealing).  The gradient of the smooth
objective is a **weighted sum of the individual convolution‑gradients**,
where the weights are the normalised exponentials of the current
convolution values.  This yields a clean, dense gradient that guides the
search even when several shifts share (or nearly share) the current
maximum.

All operations are performed on the **probability simplex** using the
Euclidean projection `_project_simplex`.  Adam‑style adaptive moments are
kept because they work well with the noisy gradients that still appear
after smoothing.

The optimisation pipeline is

1. **Fast parametric sweep** – geometric, power, beta, semicircle and
   arcsine families – to obtain a good starting point.
2. **Deterministic‑annealing Adam** – start with a small `λ`,
   repeatedly project the Adam update onto the simplex, and increase `λ`
   after a fixed number of iterations.
3. **Final stochastic hill‑climb** – tiny random transfers of mass
   between positions are accepted only if they improve the *true*
   (non‑smoothed) score.

The code is fully self‑contained, runs on a single CPU and respects the
1000 s budget.  The final sequence is returned as a plain list of Python
floats ready for `evaluate_sequence`.  

```python
"""
search for a non‑negative step function that minimises
    2 * n * max(conv(a, a)) / (sum(a)**2)

Approach
--------
1️⃣  Fast parametric sweep (geometric, power, beta, semicircle, arcsine)
    to obtain a decent starter.

2️⃣  Deterministic‑annealing Adam optimiser.
    The hard max is replaced by a smooth log‑sum‑exp
    (temperature λ is increased during the run).
    The gradient of the smooth objective is computed analytically:
        grad = 2 * ( (w * a)[:n] + (w * a_rev)[:n][::-1] )
    where w_i ∝ exp(λ·conv_i) and * denotes linear convolution.
    All updates are projected onto the probability simplex.

3️⃣  Final hill‑climb that moves a tiny random fraction of mass from one
    index to another and keeps the move only if the true score improves.

The routine respects the given time budget (default 1000 s) and returns
a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Linear‑algebra utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _conv_self_fft(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """Linear self‑convolution a*a (length 2·len(a)‑1) via FFT."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _smooth_weights(conv: np.ndarray, lam: float) -> np.ndarray:
    """Soft‑max weights for a given temperature λ."""
    # shift by max for numerical stability
    shift = conv.max()
    w = np.exp(lam * (conv - shift))
    w_sum = w.sum()
    if w_sum == 0.0:
        # fallback to uniform weights (should not happen)
        w = np.full_like(conv, 1.0 / conv.size)
    else:
        w = w / w_sum
    return w


def _gradient_smooth(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of the smoothed max‑convolution.
    Returns  ∂/∂a  ( Σ_i w_i (a*a)_i ).
    """
    n = a.shape[0]
    m = 2 * n - 1
    L = _next_pow2(m + n - 1)  # length ≥ 3·n‑2

    # FFTs of w and a (padded)
    Fw = np.fft.rfft(w, n=L)
    Fa = np.fft.rfft(a, n=L)

    # w * a
    conv1_full = np.fft.irfft(Fw * Fa, n=L)[: (m + n - 1)]
    S2 = conv1_full[:n]                     # Σ_i w_i a_{j‑i}

    # w * a_rev  (a reversed)
    a_rev = a[::-1]
    Fa_rev = np.fft.rfft(a_rev, n=L)
    conv2_full = np.fft.irfft(Fw * Fa_rev, n=L)[: (m + n - 1)]
    # Σ_i w_i a_{i+j} = conv2[n‑1‑j]; take first n and reverse.
    S1 = conv2_full[:n][::-1]

    grad = 2.0 * (S2 + S1)
    return grad


# ----------------------------------------------------------------------
# Adam optimiser with deterministic annealing
# ----------------------------------------------------------------------


def _adam_smooth_optimize(a0: np.ndarray,
                          start_time: float,
                          deadline: float,
                          best_score_initial: float,
                          n: int) -> tuple[np.ndarray, float]:
    """
    Adam optimiser that minimises the *smooth* objective.
    λ (temperature) is increased geometrically during the run.
    Returns the best sequence seen (according to the true score).
    """
    a = a0.copy()
    best_a = a.copy()
    best_score = best_score_initial

    # Adam hyper‑parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr0 = 0.15

    # moment estimates
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    it = 0
    last_improve = 0

    # annealing schedule
    lam = 0.5          # start temperature
    lam_max = 200.0    # final temperature
    lam_factor = 1.5   # multiplicative increase
    it_per_lam = 2000  # when to raise λ

    rng = np.random.default_rng()

    # pre‑compute FFT length for self‑convolution
    L_self = _next_pow2(2 * n - 1)

    while time.time() < deadline:
        it += 1

        # self‑convolution and true score
        conv = _conv_self_fft(a, L_self)
        cur_max = conv.max()
        cur_score = float(2.0 * n * cur_max)  # sum(a)=1 after projection

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            last_improve = it
            print(f"[{time.time() - start_time:.2f}s] iter={it:,} "
                  f"λ={lam:.2f} score={cur_score:.6f}")

        # ---- smooth gradient ----
        w = _smooth_weights(conv, lam)
        grad = _gradient_smooth(a, w)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = lr0 * m_hat / (np.sqrt(v_hat) + eps)
        a = a - step

        # projection onto simplex
        a = _project_simplex(a)

        # temperature schedule
        if it % it_per_lam == 0 and lam < lam_max:
            lam = min(lam * lam_factor, lam_max)

        # plateau handling – tiny random shake
        if it - last_improve > 6000:
            noise = 1e-4 * rng.standard_normal(n) * a
            a = a + noise
            a = np.clip(a, 0.0, None)
            a = _project_simplex(a)
            last_improve = it

    return best_a, best_score


# ----------------------------------------------------------------------
# Final hill‑climb (tiny mass transfers)
# ----------------------------------------------------------------------


def _hill_climb(start_a: np.ndarray,
                start_time: float,
                deadline: float) -> tuple[np.ndarray, float]:
    """
    Stochastic hill‑climb that moves a small random fraction of mass
    between two positions and keeps the move only if the true objective
    improves.
    """
    a = start_a.copy()
    n = a.shape[0]
    L_self = _next_pow2(2 * n - 1)

    best_a = a.copy()
    best_score = float(2.0 * n * _conv_self_fft(a, L_self).max())
    rng = np.random.default_rng()

    while time.time() < deadline:
        src = rng.integers(n)
        if a[src] < 1e-15:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue

        # random fraction (up to 0.5 %)
        frac = rng.random() * 0.005 + 1e-7
        eps = a[src] * frac

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps
        if a_prop[src] < -1e-15:
            continue

        cur_score = float(2.0 * n * _conv_self_fft(a_prop, L_self).max())
        if cur_score < best_score:
            a = a_prop
            best_a = a.copy()
            best_score = cur_score
            print(f"[{time.time() - start_time:.2f}s] Hill‑climb score={best_score:.6f}")

    return best_a, best_score

def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function that minimises
        2 * n * max(conv(a, a)) / (sum(a)**2)

    The search consists of:
        * a fast parametric sweep (geometric, power, beta, semicircle,
          arcsine) to obtain a good starter,
        * a deterministic‑annealing Adam optimiser that uses a smooth
          max‑approximation, and
        * a final stochastic hill‑climb.
    The routine respects the given time budget and returns a list of
    Python floats ready for `evaluate_sequence`.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.3   # safety margin

    # --------------------------------------------------------------
    # problem size (larger n gives a finer discretisation)
    # --------------------------------------------------------------
    n = 8192                     # try a larger discretisation than before
    L_self = _next_pow2(2 * n - 1)

    # --------------------------------------------------------------
    # baseline – uniform distribution
    # --------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    best_seq = uniform.copy()
    best_score = float(2.0 * n * _conv_self_fft(best_seq, L_self).max())
    print(f"[{time.time() - start_time:.2f}s] Uniform baseline score={best_score:.6f}")

    # --------------------------------------------------------------
    # use a global starter if one exists
    # --------------------------------------------------------------
    try:
        global height_sequence_1
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            starter = starter / starter.sum()
            # if the global starter has a different length, resize by interpolation
            if starter.size != n:
                # simple linear interpolation to the target length
                x_old = np.linspace(0, 1, starter.size)
                x_new = np.linspace(0, 1, n)
                starter = np.interp(x_new, x_old, starter)
                starter = starter / starter.sum()
            cur = float(2.0 * n * _conv_self_fft(starter, L_self).max())
            if cur < best_score:
                best_seq = starter.copy()
                best_score = cur
                print(f"[{time.time() - start_time:.2f}s] Global starter score={cur:.6f}")
    except Exception:
        pass

    # --------------------------------------------------------------
    # 1️⃣  Fast parametric sweep
    # --------------------------------------------------------------
    idx = np.arange(n, dtype=np.float64)
    # geometric families
    for eps in np.logspace(-5, -1, 120):
        if time.time() >= deadline - 200:
            break
        r = 1.0 - eps
        geo = np.power(r, idx)
        geo /= geo.sum()
        cur = float(2.0 * n * _conv_self_fft(geo, L_self).max())
        if cur < best_score:
            best_score, best_seq = cur, geo.copy()
            print(f"[{time.time() - start_time:.2f}s] Geo eps={eps:.1e} score={cur:.6f}")

    # power families
    for p in np.linspace(-1.5, 2.5, 81):
        if time.time() >= deadline - 200:
            break
        pow_seq = np.power(idx + 1, p)
        pow_seq /= pow_seq.sum()
        cur = float(2.0 * n * _conv_self_fft(pow_seq, L_self).max())
        if cur < best_score:
            best_score, best_seq = cur, pow_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Power p={p:.2f} score={cur:.6f}")

    # beta families (two‑parameter polynomial)
    beta_vals = [0.0, 0.5, 1.0, 1.5, 2.0, 3.0]
    for p in beta_vals:
        for q in beta_vals:
            if time.time() >= deadline - 200:
                break
            beta_seq = (np.power(idx + 1, p) *
                        np.power(n - idx, q))
            beta_seq /= beta_seq.sum()
            cur = float(2.0 * n * _conv_self_fft(beta_seq, L_self).max())
            if cur < best_score:
                best_score, best_seq = cur, beta_seq.copy()
                print(f"[{time.time() - start_time:.2f}s] Beta p={p} q={q} score={cur:.6f}")

    # semicircle shape (approx. a discrete semicircle / Archimedes)
    center = (n - 1) / 2.0
    radius = center
    semicircle = np.sqrt(np.maximum(0.0, 1.0 - ((idx - center) / radius) ** 2))
    semicircle /= semicircle.sum()
    cur = float(2.0 * n * _conv_self_fft(semicircle, L_self).max())
    if cur < best_score:
        best_score, best_seq = cur, semicircle.copy()
        print(f"[{time.time() - start_time:.2f}s] Semicircle score={cur:.6f}")

    # arcsine‑type shape: a_i ∝ 1/√((i+1)*(n-i))
    arcsine = 1.0 / np.sqrt((idx + 1) * (n - idx))
    arcsine /= arcsine.sum()
    cur = float(2.0 * n * _conv_self_fft(arcsine, L_self).max())
    if cur < best_score:
        best_score, best_seq = cur, arcsine.copy()
        print(f"[{time.time() - start_time:.2f}s] Arcsine score={cur:.6f}")

    # --------------------------------------------------------------
    # 2️⃣  Deterministic‑annealing Adam optimisation
    # --------------------------------------------------------------
    hill_time = 150.0
    adam_deadline = deadline - hill_time
    if time.time() < adam_deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting annealed Adam optimiser")
        a_opt, sc_opt = _adam_smooth_optimize(best_seq, start_time,
                                               adam_deadline,
                                               best_score, n)
        if sc_opt < best_score:
            best_score, best_seq = sc_opt, a_opt.copy()
            print(f"[{time.time() - start_time:.2f}s] Adam improved score={sc_opt:.6f}")

    # --------------------------------------------------------------
    # 3️⃣  Final hill‑climb
    # --------------------------------------------------------------
    if time.time() < deadline:
        print(f"[{time.time() - start_time:.2f}s] Starting final hill‑climb")
        a_hc, sc_hc = _hill_climb(best_seq, start_time, deadline)
        if sc_hc < best_score:
            best_score, best_seq = sc_hc, a_hc.copy()
            print(f"[{time.time() - start_time:.2f}s] Hill‑climb final score={sc_hc:.6f}")

    # ------------------------------------------------------------------
    # final normalisation and return
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0:
        best_seq = best_seq / total
    else:
        best_seq = uniform.copy()

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```
