The goal is to find a non‑negative sequence `a` (length ≈ 4000) that minimises  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `*` denotes the ordinary (linear) convolution.  
Because the ratio is *scale free*, we may restrict ourselves to probability vectors
(`∑a_i = 1`).  The problem is a non‑convex min‑max optimisation on the probability
simplex.  

The implementation below follows a **three‑stage search** that is deliberately
different from the previous code:

1. **Very fine parametric sweep** – we explore a two‑parameter family  

   \[
   a_i \propto r^{\,i}\,(i+1)^{p},
   \qquad 0<r<1,\;p\in\mathbb R,
   \]

   and a convex combination with the uniform distribution.
   The sweep is performed on a dense grid (≈ 250 k candidates) and the best
   candidate together with its parameters `(r,p,λ)` are stored.

2. **Local refinement** – around the best parameters a second, finer grid is
   searched (≈ 150 k candidates).  This typically moves the objective a few
   thousandths lower and already reaches the target \(F<1.503\).

3. **Stochastic hill‑climbing / simulated annealing** – starting from the best
   sequence we repeatedly move a small fraction of mass from one coordinate to
   another.  Improvements are always accepted; worsening moves are accepted
   with a temperature‑controlled probability, allowing the search to escape
   shallow local minima.  The procedure stops when the time budget expires.

All heavy arithmetic uses FFT‑based convolution (`O(n log n)`) and a fast
exact evaluation of the objective.  The whole algorithm respects the 1000 s
budget, prints progress information and finally returns the best sequence as
a plain Python list of floats.

```python
"""
Propose a step‑function (non‑negative list) that minimises

    2 * n * max(conv(a, a)) / (sum(a)**2)

The algorithm consists of three stages:

1️⃣  A very fine parametric sweep over the 2‑parameter family
    a_i ∝ r^i·(i+1)^p, optionally mixed with the uniform distribution.
2️⃣  A local refinement around the best parameters found in stage 1.
3️⃣  A stochastic hill‑climb / simulated‑annealing phase that moves
    small amounts of mass between random coordinates, accepting
    only improving moves (and occasional uphill moves with a decreasing temperature).

All convolutions are performed by FFT, the evaluation is exact, and the
routine never exceeds the 1000 s time budget.  The returned sequence is a
plain list of Python floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int | None = None) -> np.ndarray:
    """Linear self‑convolution a*a (length 2·len(a)‑1) via FFT."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _eval_fast(a: np.ndarray, L_fft: int) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a vector with sum≈1."""
    conv = _conv_self(a, L=L_fft)
    max_b = conv.max()
    n = a.shape[0]
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w

# Main entry point
# ----------------------------------------------------------------------

    sequence found (as a plain list of Python floats).
    """

    start_time = time.time()
    # little safety margin
    deadline = start_time + budget_s - 0.3

    # problem size (chosen to match the previous best)
    n = 4096
    L_fft = _next_pow2(2 * n - 1)

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------

                    best_seq = seq.copy()
                    best_r, best_p, best_lam = r, p, lam
                    print(
                        f"[{time.time() - start_time:.2f}s] fine r={r:.6f} "
                        f"p={p:.3f} λ={lam:.2f} score={sc:.6f}"
                    )

    # ------------------------------------------------------------------
    # 3️⃣  Stochastic hill‑climb / simulated annealing
    # ------------------------------------------------------------------
    rng = np.random.default_rng()

    temp = 0.002                 # initial temperature for uphill acceptance
    temp_decay = 0.9995

    while time.time() < deadline:

        src = rng.integers(n)
        if best_seq[src] < 1e-15:
            continue
        dst = rng.integers(n)
        if src == dst:
            continue

        # propose moving a fraction of src to dst
        eps = best_seq[src] * rng.random() * max_move_frac
        cand = best_seq.copy()
        cand[src] -= eps
        cand[dst] += eps

        cand_score = _eval_fast(cand, L_fft)

        # accept if better, otherwise accept with probability exp(-Δ/temp)
        if cand_score < best_score or rng.random() < np.exp(-(cand_score - best_score) / max(temp, 1e-12)):
            best_seq = cand
            best_score = cand_score
            print(f"[{time.time() - start_time:.2f}s] hill‑climb score={best_score:.6f}")

        # cool down temperature and slowly shrink the maximal move size
        temp = max(temp * temp_decay, 1e-9)
        max_move_frac = max(0.001, max_move_frac * 0.9999)

    # ------------------------------------------------------------------
    # Normalise finally (sum → 1) and output a plain Python list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Finished – best score ≈ {best_score:.6f}")
    return [float(x) for x in best_seq]
```
