The objective  

\[
\text{score}(a)=\frac{2 n\;\max (a*a)}{(\sum a)^2}
\]

is *scale‑invariant*: multiplying the whole vector by a positive constant does not change the score.  
Therefore we can restrict ourselves to probability vectors (`∑a = 1`) and minimise  

\[
2n\;\max (a*a) .
\]

The score is non‑convex; a simple random walk quickly gets stuck in a local minimum
(the previous best is ≈ 1.508476).  
The new optimiser has three ideas:

1. **Start from the best known construction** (or a uniform start) and keep the vector on the simplex.
2. **Targeted hill‑climbing** – at each iteration we look at the index `k` where the
   self‑convolution is maximal, compute the contribution of every component to this
   entry and move mass from the *worst* contributing index to the *best* one.
   This is a deterministic descent direction derived from the exact sub‑gradient of the
   \(\max\)‑operator.
3. **Multiple random restarts** – the same targeted climb is launched from a few
   random Dirichlet‑drawn start points (different sparsities) to avoid being trapped
   in the same basin.

All expensive operations (the convolution and the maximal index) are performed by
FFT, which is fast enough to allow several × 10⁵ iterations inside the 1000 s budget.

The code below implements the described optimiser and returns the best sequence
found within the allotted time.

```python
"""
Targeted hill‑climbing optimiser for minimise
    2·n·max(conv(a,a)) / (sum(a)**2)

* works on the probability simplex (∑a = 1)
* uses FFT for fast convolution
* at each step moves probability mass from the index that contributes most
  to the current maximal convolution entry to the index that contributes least.
* runs several random restarts (Dirichlet draws) and keeps the best result.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Global problem size (fixed to the size used in the reference run)
# ----------------------------------------------------------------------
n = 4096
# length of FFT – next power of two ≥ 2·n‑1 (required by the convolution code)
_L_SELF = 1 << ((2 * n - 2).bit_length())


# ----------------------------------------------------------------------
# Exact (fast) objective – works for any non‑negative vector with sum>0
# ----------------------------------------------------------------------
def _exact_score(a: np.ndarray) -> float:
    """Return 2·n·max(conv(a,a)) / (sum(a)**2)."""
    Af = np.fft.rfft(a, n=_L_SELF)
    conv = np.fft.irfft(Af * Af, n=_L_SELF)[: 2 * n - 1]
    max_b = conv.max()
    s = a.sum()
    if s < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (s * s))


# ----------------------------------------------------------------------
# Targeted hill‑climb that follows the exact sub‑gradient of the max‑operator
# ----------------------------------------------------------------------
def _targeted_hill_climb(start: np.ndarray,
                         deadline: float,
                         global_start: float) -> tuple[np.ndarray, float]:
    """
    Deterministic hill‑climbing:
        * locate the index k where self‑convolution is maximal,
        * compute the contribution a_{k‑i} of each component i,
        * move a fraction of probability mass from the index with the largest
          contribution (and positive mass) to the index with the smallest
          contribution,
        * accept the move if it improves the score; otherwise accept with a
          tiny Metropolis probability (simulated‑annealing style) to escape plateaus.
    Returns the best vector seen during the run and its score.
    """
    cur = start.copy()
    cur_score = _exact_score(cur)
    best = cur.copy()
    best_score = cur_score

    rng = np.random.default_rng()
    it = 0

    while time.time() < deadline - 0.01:
        # ----- convolution and maximal index ----------------------------------------------------
        Af = np.fft.rfft(cur, n=_L_SELF)
        conv = np.fft.irfft(Af * Af, n=_L_SELF)[: 2 * n - 1]
        k = int(conv.argmax())

        # ----- contribution of every entry to conv[k] -----------------------------------------
        lo = max(0, k - (n - 1))
        hi = min(k, n - 1)
        idx = np.arange(lo, hi + 1, dtype=int)          # indices that actually contribute
        contrib = cur[k - idx]                           # a_{k‑i}

        # ----- choose source (largest contribution, positive mass) ----------------------------
        mask_pos = cur[idx] > 1e-15
        if np.any(mask_pos):
            src_candidates = idx[mask_pos]
            contrib_src = contrib[mask_pos]
            src = src_candidates[np.argmax(contrib_src)]
        else:
            src = rng.integers(n)

        # ----- choose destination (smallest contribution) --------------------------------------
        dst = idx[np.argmin(contrib)]
        if src == dst:
            dst = rng.integers(n)
            while dst == src:
                dst = rng.integers(n)

        # ----- move a fraction of the source mass ---------------------------------------------
        src_mass = cur[src]
        if src_mass <= 1e-15:
            # nothing to move – skip this iteration
            continue
        eps = src_mass * rng.random() * 0.30 + 1e-14   # up to 30 % of the source mass
        cand = cur.copy()
        cand[src] -= eps
        cand[dst] += eps
        cand = np.maximum(cand, 0.0)

        # re‑normalise (removes tiny drift caused by floating point arithmetic)
        total = cand.sum()
        if total == 0.0:
            continue
        cand /= total

        cand_score = _exact_score(cand)

        # ----- accept the move -----------------------------------------------------------------
        if cand_score < cur_score:
            cur = cand
            cur_score = cand_score
            if cand_score < best_score:
                best = cand.copy()
                best_score = cand_score
                print(f"[{time.time() - global_start:.2f}s] "
                      f"targeted it={it:,} new best={best_score:.6f}")
        else:
            # occasional Metropolis acceptance to escape flat plateaus
            progress = (time.time() - global_start) / (deadline - global_start)
            T = 5e-2 * (1e-10 / 5e-2) ** progress          # geometric temperature decay
            delta = cand_score - cur_score
            if math.exp(-delta / T) > rng.random():
                cur = cand
                cur_score = cand_score

        # ----- occasional global perturbation (helps crossing tiny barriers) --------------------
        if it % 5000 == 0 and it > 0:
            perturb = cur * (1.0 + 0.02 * (rng.random(size=n) - 0.5))
            perturb = np.maximum(perturb, 0.0)
            perturb /= perturb.sum()
            pert_score = _exact_score(perturb)
            if pert_score < cur_score:
                cur = perturb
                cur_score = pert_score
                if pert_score < best_score:
                    best = perturb.copy()
                    best_score = pert_score
                    print(f"[{time.time() - global_start:.2f}s] perturb it={it:,} best={best_score:.6f}")

        it += 1

    return best, best_score


# ----------------------------------------------------------------------
# Main entry point required by the competition framework
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function (list of heights) that minimises
    `evaluate_sequence`.  The algorithm:
        1. starts from the best known construction (if available) or a uniform vector,
        2. performs a focused targeted hill‑climb on that vector,
        3. launches a few random restarts (Dirichlet draws with random sparsity)
           each of which runs the same hill‑climb,
        4. returns the best sequence found before the time budget expires.
    """
    np.random.seed(seed)
    start_time = time.time()
    # small safety margin to avoid overruns
    deadline = start_time + budget_s - 0.2

    # ------------------------------------------------------------------
    # Initialise from the previously known best (if any) or uniform
    # ------------------------------------------------------------------
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
    except Exception:
        starter = None

    if starter is None or starter.ndim != 1 or starter.size == 0:
        starter = np.full(n, 1.0 / n)
    else:
        # adjust length to n (pad or truncate)
        if starter.size != n:
            if starter.size > n:
                starter = starter[:n]
            else:
                starter = np.pad(starter, (0, n - starter.size), mode='constant')
        starter = np.maximum(starter, 0.0)
        total = starter.sum()
        starter = starter / total if total > 0.0 else np.full(n, 1.0 / n)

    best_seq = starter.copy()
    best_score = _exact_score(best_seq)
    print(f"[{time.time() - start_time:.2f}s] initial score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – aggressive targeted hill‑climb from the best known start
    # ------------------------------------------------------------------
    if time.time() < deadline - 30.0:                       # reserve time for restarts
        phase_deadline = min(deadline - 10.0, start_time + 200.0)
        best_seq, best_score = _targeted_hill_climb(best_seq,
                                                    phase_deadline,
                                                    start_time)
        print(f"[{time.time() - start_time:.2f}s] after focused climb best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – several random restarts (different sparsities)
    # ------------------------------------------------------------------
    restart = 0
    while time.time() < deadline - 5.0:
        restart += 1
        # draw a Dirichlet vector; the concentration parameter is random
        # (values < 1 produce sparse vectors, >1 give dense vectors)
        alpha = 10 ** np.random.uniform(-1.5, 0.7)          # ≈ 0.03 … 5
        rand = np.random.gamma(alpha, 1.0, size=n)
        rand /= rand.sum()

        # give each restart about 30 s (or whatever is left)
        remaining = deadline - time.time()
        if remaining < 30.0:
            phase_deadline = deadline
        else:
            phase_deadline = time.time() + 30.0

        cur_seq, cur_score = _targeted_hill_climb(rand,
                                                  phase_deadline,
                                                  start_time)
        if cur_score < best_score:
            best_seq = cur_seq.copy()
            best_score = cur_score
            print(f"[{time.time() - start_time:.2f}s] restart {restart} new best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation and conversion to plain Python list
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    tot = best_seq.sum()
    if tot > 0.0:
        best_seq /= tot
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] finished – best score ≈ {best_score:.6f}")
    return [float(v) for v in best_seq]
```
