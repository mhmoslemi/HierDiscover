Propose a step‑function with a low evaluation score.

Algorithm (≈ 1000 s budget)
--------------------------------
1. Choose a moderate size (n = 8192) – large enough to make the
   theoretical lower bound ≈ 1 while still fast to FFT‑convolve.
2. Initialise with the continuous arcsine density (β(½,½)), projected
   onto the probability simplex.
3. minimise a *smoothed* version of the objective:
        f_p(a) = ( Σ (a∗a)_k^p )^{1/p}   (p‑norm of the self‑convolution)
   For p = 4, 8, 16, 32, 64 we run a projected gradient descent.
   The gradient of f_p can be written using one FFT for the convolution
   and one FFT for the correlation; both are O(L log L) with
   L = next_pow2(3 n‑2).  After each step we project onto the simplex.
   The step size decays like 1/√t and is scaled down for larger p.
   The best iterate (according to the *exact* objective)
   2 n·max(a∗a)/(∑a)² is kept.
4. A very light simulated‑annealing “mass‑transfer’’ polish is applied
   to the best vector found so far.
5. Final normalisation onto the simplex and return as a plain list.
"""

# Helper utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _conv_self(a: np.ndarray, L: int = None) -> np.ndarray:
    """
    Linear self‑convolution a*a using FFT.
    Returns an array of length 2·len(a)‑1.
    """
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    A = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(A * A, n=L)[: 2 * n - 1]
    return conv


def _objective(a: np.ndarray) -> float:
    """
    Exact objective used by the evaluator:
        2·n·max(conv(a,a)) / (sum(a)²)
    (a is assumed to be non‑negative).
    """
    n = a.shape[0]
    conv = _conv_self(a)
    max_conv = conv.max()
    sum_a = a.sum()
    if sum_a < 1e-12:
        return np.inf
    return float(2.0 * n * max_conv / (sum_a ** 2))
