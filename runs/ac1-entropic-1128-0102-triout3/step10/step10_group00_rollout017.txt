The task is to minimise  

\[
F(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where `(a*a)` is the linear self‑convolution of the sequence `a`.
The denominator is scale‑invariant, therefore we restrict ourselves to the
probability simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

For a vector on the simplex,  

\[
F(a)=2\,n\;\max_k (a*a)_k .
\]

The problem is non‑smooth because of the `max`.  
The previous solution used a plain sub‑gradient (only the single maximal
convolution entry).  Here we improve the search in three ways

1. **Larger canvas** – we work with `n = 16384` (instead of 8192).  
   A finer discretisation brings the discrete optimum closer to the
   continuous one (≈ 1.5).

2. **Smoothed objective** – we replace `max` by the differentiable
   log‑sum‑exp:

   \[
   \operatorname{LSE}_\lambda(c)=\frac{1}{\lambda}
        \log\!\Bigl(\sum_k e^{\lambda c_k}\Bigr)
   \Longrightarrow
   \max_k c_k \le \operatorname{LSE}_\lambda(c) .
   \]

   For a fresh value of `λ` the gradient can be computed analytically
   with one extra FFT per iteration (still O(n log n)).  
   Starting with a small `λ` gives a smooth landscape, then `λ` is
   increased (continuation method) so that the final iterate minimises
   the true `max`.

3. **Projected gradient descent with momentum** – after each gradient step
   the iterate is projected back onto the simplex by the O(n log n) algorithm
   of Wang & Carreira‑Perpiñán.  

   The whole optimisation chain is:
   * warm‑start from a few simple “tent’’ shapes,
   * optional up‑sampling of the previously best construction,
   * smoothed gradient descent (most of the time budget),
   * a short sub‑gradient refinement (as in the reference code),
   * a light annealing polish.

All helper functions are top‑level so the harness can pickle them.
The final sequence is normalised to sum = 1, guaranteeing a valid call to
`evaluate_sequence`.

"""
Propose a step‑function (non‑negative heights) that improves the
bound ≈ 1.5087 → target ≈ 1.503.

Algorithm
---------
* Use a larger canvas (n = 16384) – a finer discretisation of the
  continuous problem.
* Warm‑start from a few symmetric tent‑type shapes (a_i ∝ min(i,n‑1‑i)^p)
  and, if available, from the previously found global construction
  (height_sequence_1) up‑sampled to the current canvas.
* Perform *smoothed* projected gradient descent:
      – replace max(conv) by a log‑sum‑exp with a continuation parameter λ,
      – compute the exact gradient using FFT‑based convolutions,
      – use momentum and a 1/√t step‑size,
      – after each step project onto the probability simplex.
  λ starts small (5) and is multiplied by 1.05 every 1000 iterations
  up to λ_max = 200.
* When the time budget is almost exhausted run a short sub‑gradient
  descent (as in the reference implementation) and a cheap simulated‑annealing
  polish.
* Return the best sequence (list of floats) found.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# FFT utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self_fft(a: np.ndarray, L_self: int) -> np.ndarray:
    """
    Linear self‑convolution a*a using a single FFT of length L_self.
    Returns the first (2·n‑1) entries.
    """
    Af = np.fft.rfft(a, n=L_self)
    conv = np.fft.irfft(Af * Af, n=L_self)[: 2 * a.shape[0] - 1]
    return conv


def _conv_full_fft(x: np.ndarray, y: np.ndarray, L_full: int) -> np.ndarray:
    """
    Linear convolution of x and y (both real) using FFT of length L_full.
    Returns the full result of length len(x)+len(y)-1.
    """
    Xf = np.fft.rfft(x, n=L_full)
    Yf = np.fft.rfft(y, n=L_full)
    conv = np.fft.irfft(Xf * Yf, n=L_full)[: len(x) + len(y) - 1]
    return conv


# ----------------------------------------------------------------------
# Simplex projection (Wang & Carreira‑Perpiñán 2013)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto { w ≥ 0, Σ w = 1 }."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


# ----------------------------------------------------------------------
# Exact objective (scale invariant – sum == 1)
# ----------------------------------------------------------------------
def _objective(seq: np.ndarray) -> float:
    """Exact version of evaluate_sequence for a normalised sequence."""
    n = seq.shape[0]
    conv = _conv_self_fft(seq, _next_pow2(2 * n - 1))
    max_conv = conv.max()
    return float(2.0 * n * max_conv)


# ----------------------------------------------------------------------
# Smoothed gradient (log‑sum‑exp) of the objective
# ----------------------------------------------------------------------
def _smooth_gradient(a: np.ndarray, lam: float,
                     L_self: int, L_rev: int) -> tuple[np.ndarray, np.ndarray]:
    """
    Returns (gradient, conv) where gradient is ∇F_λ(a) and conv = a*a.
    F_λ(a) = 2·n·log‑sum‑exp_λ(conv) / λ.
    """
    n = a.shape[0]

    # self‑convolution (needed both for the smoothed value and for w)
    Af = np.fft.rfft(a, n=L_self)
    conv = np.fft.irfft(Af * Af, n=L_self)[: 2 * n - 1]

    # smoothed weights w_k = exp(λ·(conv_k−max))/∑exp(...)
    maxc = conv.max()
    # shift to avoid overflow
    shifted = lam * (conv - maxc)
    # np.exp might underflow for very negative values – that's fine
    w = np.exp(shifted)
    w_sum = w.sum()
    if w_sum == 0.0:               # numerical safety
        w = np.full_like(w, 1.0 / w.shape[0])
    else:
        w /= w_sum

    # gradient = 4·n·sum_k w_k·a_{k‑i}
    a_rev = a[::-1]
    conv_rev = _conv_full_fft(w, a_rev, L_rev)          # length = 3n‑2
    offset = a_rev.shape[0] - 1                         # = n‑1
    grad_tmp = conv_rev[offset: offset + n]            # Σ w_k a_{k‑i}
    gradient = 4.0 * n * grad_tmp
    return gradient, conv


# ----------------------------------------------------------------------
# Smoothed projected gradient descent (continuation on λ)
# ----------------------------------------------------------------------
def _smooth_descent(a0: np.ndarray,
                    deadline: float,
                    start_time: float) -> tuple[np.ndarray, float]:
    """
    Projected gradient descent on the log‑sum‑exp smoothed objective.
    Returns the best iterate (lowest true objective) found before deadline.
    """
    a = a0.copy()
    n = a.shape[0]

    # pre‑compute FFT lengths (they never change)
    L_self = _next_pow2(2 * n - 1)
    L_rev = _next_pow2(3 * n - 2)

    best_a = a.copy()
    best_score = _objective(a)

    # schedule for λ
    lam = 5.0
    lam_max = 200.0
    lam_mul = 1.05
    lam_step = 1000

    # momentum parameters
    momentum = np.zeros_like(a)
    beta = 0.9
    step0 = 0.5

    it = 0
    while time.time() < deadline:
        it += 1

        # increase λ periodically
        if it % lam_step == 0 and lam < lam_max:
            lam = min(lam * lam_mul, lam_max)

        # gradient of the smoothed objective
        grad, conv = _smooth_gradient(a, lam, L_self, L_rev)

        # momentum + step‑size
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)

        a = a - step * momentum
        a = _project_simplex(a)                     # back to the simplex

        cur_score = _objective(a)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] smoothIter={it:,} "
                  f"λ={lam:.2f} score={cur_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Sub‑gradient descent (same as the reference implementation)
# ----------------------------------------------------------------------
def _subgradient_descent(a0: np.ndarray,
                         deadline: float,
                         start_time: float) -> tuple[np.ndarray, float]:
    """Plain sub‑gradient descent on the true max‑based objective."""
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(a)

    momentum = np.zeros_like(a)
    beta = 0.9
    step0 = 0.5
    it = 0

    L_self = _next_pow2(2 * n - 1)

    while time.time() < deadline:
        it += 1
        # self‑convolution
        conv = _conv_self_fft(a, L_self)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)   # = _objective(a)

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] subGradIter={it:,} "
                  f"score={cur_score:.6f}")

        # sub‑gradient from the (single) maximal entry
        k = int(conv.argmax())
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)

        grad = np.zeros_like(a)
        grad[idx] = 2.0 * a[k - idx]   # derivative of max(conv) w.r.t. a

        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / math.sqrt(it)
        a -= step * momentum
        a = _project_simplex(a)

    return best_a, best_score


# ----------------------------------------------------------------------
# Very light simulated‑annealing polish
# ----------------------------------------------------------------------
def _anneal(seq: np.ndarray,
            deadline: float,
            start_time: float) -> tuple[np.ndarray, float]:
    """Cheap annealing that moves tiny mass packets; returns the best found."""
    a = seq.copy()
    n = a.shape[0]
    cur_score = _objective(a)
    best_a = a.copy()
    best_score = cur_score
    rng = np.random.default_rng()

    total_steps = 30_000
    for it in range(1, total_steps + 1):
        if time.time() >= deadline:
            break

        # exponential cooling (fast)
        T = 0.01 * (1e-6 / 0.01) ** (it / total_steps)

        src = rng.choice(n, p=a)          # more mass → more likely to be moved
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-14:
            continue

        eps = a[src] * rng.random() * 0.30
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        new_score = _objective(a_prop)
        delta = new_score - cur_score
        if delta < 0.0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = a.copy()
                print(f"[{time.time() - start_time:.2f}s] annealIter={it:,} "
                      f"best={new_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Helper: up‑sample a shorter sequence to a new length
# ----------------------------------------------------------------------
def _upscale(seq: np.ndarray, new_n: int) -> np.ndarray:
    """Linear interpolation of a simplex‑normalised sequence to length new_n."""
    old_n = seq.shape[0]
    if old_n == new_n:
        return seq.copy()
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    up = np.interp(new_x, old_x, seq)
    up = np.maximum(up, 0.0)
    s = up.sum()
    if s > 0.0:
        up /= s
    else:
        up = np.full(new_n, 1.0 / new_n)
    return up

# Main entry point required by the harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a low‑objective step‑function.
    Returns a plain Python list of non‑negative floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    # Safety margin
    deadline = start_time + budget_s - 0.5

    # --------------------------------------------------------------
    # Problem size – a larger canvas gives a finer approximation.
    # --------------------------------------------------------------
    n = 16384          # 2 × the size used in the reference run

    # --------------------------------------------------------------
    # 1) Warm‑start: symmetric tent‑type shapes a_i ∝ min(i,n‑1‑i)^p
    # --------------------------------------------------------------
    x = np.arange(n, dtype=float) / (n - 1)   # points in [0,1]
    exponents = [0.6, 0.8, 0.9, 1.0, 1.1, 1.2]   # cheap sweep
    best_seq = None
    best_score = float("inf")

    for p in exponents:
        w = np.minimum(x, 1.0 - x) ** p
        if w.sum() == 0.0:
            continue
        a = w / w.sum()
        score = _objective(a)
        print(f"[{time.time() - start_time:.2f}s] exponent={p:.2f} "
              f"score={score:.6f}")
        if score < best_score:
            best_score = score
            best_seq = a.copy()

    # --------------------------------------------------------------
    # 2) Include the previous global construction if available
    # --------------------------------------------------------------
    try:
        starter = np.asarray(height_sequence_1, dtype=float)
        if starter.ndim == 1 and starter.size > 0:
            starter = np.maximum(starter, 0.0)
            if starter.sum() > 0.0:
                starter = _upscale(starter, n)
                cur = _objective(starter)
                print(f"[{time.time() - start_time:.2f}s] "
                      f"global starter score={cur:.6f}")
                if cur < best_score:
                    best_score = cur
                    best_seq = starter.copy()
    except Exception:
        pass

    # --------------------------------------------------------------
    # 3) If everything failed, fall back to a uniform distribution
    # --------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)
        best_score = _objective(best_seq)
        print(f"[{time.time() - start_time:.2f}s] fallback uniform score={best_score:.6f}")

    # --------------------------------------------------------------
    # 4) Smoothed projected gradient descent (main workhorse)
    # --------------------------------------------------------------
    remaining = deadline - time.time()
    if remaining > 30.0:                 # keep some time for polishing
        smooth_deadline = time.time() + remaining * 0.70
        smooth_seq, smooth_score = _smooth_descent(best_seq,
                                                   smooth_deadline,
                                                   start_time)
        if smooth_score < best_score:
            best_score = smooth_score
            best_seq = smooth_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Smoothed best score={smooth_score:.6f}")

    # --------------------------------------------------------------
    # 5) A short sub‑gradient refinement (helps escape tiny plateaus)
    # --------------------------------------------------------------
    if time.time() < deadline - 5.0:
        sub_deadline = time.time() + (deadline - time.time()) * 0.25
        refined_seq, refined_score = _subgradient_descent(best_seq,
                                                          sub_deadline,
                                                          start_time)
        if refined_score < best_score:
            best_score = refined_score
            best_seq = refined_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Refined score={refined_score:.6f}")

    # --------------------------------------------------------------
    # 6) Very light annealing polish (if any time left)
    # --------------------------------------------------------------
    if time.time() < deadline:
        anneal_seq, anneal_score = _anneal(best_seq, deadline, start_time)
        if anneal_score < best_score:
            best_score = anneal_score
            best_seq = anneal_seq.copy()
            print(f"[{time.time() - start_time:.2f}s] Final anneal improve score={best_score:.6f}")

    # --------------------------------------------------------------
    # 7) Final normalisation and conversion to plain list
    # --------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq /= total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] Final objective={_objective(best_seq):.6f}")

    return [float(v) for v in best_seq]
