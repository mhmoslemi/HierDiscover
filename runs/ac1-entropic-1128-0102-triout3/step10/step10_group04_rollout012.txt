assistantfinal**Solution Overview**

The objective is  

\[
\text{score}(a)=\frac{2\,n\;\max\limits_{k}(a*a)[k]}{\big(\sum_i a_i\big)^2},
\]

where `a*a` is the linear self‑convolution of the non‑negative vector `a`.  
Because the score is homogeneous, we may restrict ourselves to vectors with
`sum(a)=1`.  Minimising the maximal entry of the convolution is therefore the
only remaining task.

The optimizer consists of three independent phases that together stay well
within the 1000 s budget.

1. **Soft‑max gradient descent** – a smooth approximation of the “max’’ is
   used (`log‑sum‑exp`).  The gradient of  

   \[
   L(a)=\frac1\alpha\log\!\Big(\sum_k e^{\alpha\,(a*a)[k]}\Big)
   \]

   is a *weighted* sum of the usual sub‑gradients.  Using this smoother
   direction helps to escape the plateaus where the pure max‑gradient gets
   stuck.  After each update the iterate is projected onto the probability
   simplex (`_project_simplex`).

2. **Hard‑max exponentiated‑gradient descent** – the classic sub‑gradient
   (derived from the currently active convolution index) is applied with a
   multiplicative (exponentiated) update, exactly as in the reference code.
   This phase rapidly reduces the peak once we are already close to a good
   region.

3. **Deterministic greedy “peak flattening’’** – a tiny amount of probability
   mass is moved from the index that contributes most to the current peak
   towards an index that contributes least.  The full convolution is updated
   incrementally, which makes a single move \(O(n)\) and allows millions of
   cheap refinements.

All three phases share the same helper utilities (FFT‑based convolution,
simplex projection, etc.).  The code automatically adapts the time
allocation to the remaining budget, prints progress, and finally returns the
best sequence found as a plain Python list of floats.

```python
"""
Improved step‑function optimiser.

The algorithm works in three stages:

1.  Soft‑max (log‑sum‑exp) gradient descent – a smooth surrogate for the max
    convolution is minimised.  The gradient is obtained via FFT‑based
    correlations, the iterate stays on the probability simplex by Euclidean
    projection.

2.  Classical hard‑max exponentiated‑gradient descent (as in the reference
    implementation) to further lower the peak.

3.  Deterministic greedy “peak‑flattening’’ that moves a tiny amount of mass
    from the most responsible index to the least responsible one, updating
    the self‑convolution incrementally.

The routine respects a 1000 s budget, prints intermediate scores and
returns the best sequence as a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int) -> np.ndarray:
    """
    Full self‑convolution a*a (length 2·len(a)‑1) via FFT.
    Returns the linear (not circular) convolution.
    """
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * a.shape[0] - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex (sum=1, v>=0)."""
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:  # fallback – should never happen for non‑empty v
        w = np.full_like(v, 1.0 / v.shape[0])
    return w


# ----------------------------------------------------------------------
# Phase 1 – Soft‑max (log‑sum‑exp) gradient descent
# ----------------------------------------------------------------------
def _run_softmax_gradient(a0: np.ndarray,
                          n: int,
                          deadline: float,
                          start_time: float,
                          alpha_start: float = 0.5,
                          alpha_end: float = 500.0,
                          eta0: float = 0.5) -> tuple[np.ndarray, float]:
    """
    Minimises a smooth approximation of the peak of a*a.
    Returns the best vector seen and its (hard‑max) score.
    """
    a = _project_simplex(a0.copy())
    best_a = a.copy()
    best_score = float("inf")
    it = 0

    # FFT sizes that will be reused
    L_conv = _next_pow2(2 * n - 1)          # for a*a
    L_corr = _next_pow2(3 * n)             # for correlation a ↔ p (len(p)=2n-1)

    while time.time() < deadline:
        it += 1

        # ----- current convolution and score (hard max) -----
        Af = np.fft.rfft(a, n=L_conv)
        conv = np.fft.irfft(Af * Af, n=L_conv)[: 2 * n - 1]
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] soft‑max iter={it:,} "
                  f"score={cur_score:.6f}")

        # ----- annealing of alpha (smoothness) -----
        prog = (time.time() - start_time) / (deadline - start_time)
        alpha = alpha_start + prog * (alpha_end - alpha_start)

        # ----- softmax weights ----------
        # stable subtraction of the maximal entry
        exp_arg = alpha * (conv - cur_max)
        # clip for safety (very large arguments would overflow)
        exp_arg = np.clip(exp_arg, -700, 700)          # np.exp overflow guard
        p = np.exp(exp_arg)
        s = p.sum()
        if s == 0.0 or np.isnan(s):
            p = np.full_like(p, 1.0 / p.size)
        else:
            p /= s

        # ----- gradient via correlation (FFT) ----------
        # correlation a ⋆ p
        A_f = np.fft.rfft(a, n=L_corr)
        P_f = np.fft.rfft(p, n=L_corr)
        corr = np.fft.irfft(np.conj(A_f) * P_f, n=L_corr)[: n + p.size - 1]

        # correlation a ⋆ rev(p)
        p_rev = p[::-1]
        P_rev_f = np.fft.rfft(p_rev, n=L_corr)
        corr_rev = np.fft.irfft(np.conj(A_f) * P_rev_f, n=L_corr)[: n + p.size - 1]

        offset = p.size - 1
        grad = 2.0 * (corr[offset: offset + n] + corr_rev[offset: offset + n])

        # ----- multiplicative (exponentiated) update -----
        eta = eta0 / math.sqrt(it)
        # avoid overflow in the exponent
        grad = np.clip(grad, -20.0, 20.0)
        a = a * np.exp(-eta * grad)

        # ----- back to the simplex -----
        a = _project_simplex(a)

    return best_a, best_score

# Phase 2 – Hard‑max exponentiated‑gradient descent (original method)
# ----------------------------------------------------------------------
def _run_exp_gradient(a0: np.ndarray,
                      n: int,
                      deadline: float,
                      start_time: float,
                      eta0: float = 0.6) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent optimiser that directly minimises max(conv).
    Returns the best vector seen and its (hard‑max) score.
    """
    a = _project_simplex(a0.copy())
    best_a = a.copy()
    best_score = float("inf")
    L = _next_pow2(2 * n - 1)
    it = 0

    while time.time() < deadline:
        it += 1

        conv = _conv_self(a, L)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] exp‑grad iter={it:,} "
                  f"score={cur_score:.6f}")

        # sub‑gradient coming from the active (max) index
        k = int(conv.argmax())
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)
        grad = np.zeros_like(a)
        grad[idx] = 2.0 * a[k - idx]          # d/d a_i of conv[k]

        eta = eta0 / math.sqrt(it)
        a = a * np.exp(-eta * grad)
        a = _project_simplex(a)

    return best_a, best_score

# Phase 3 – Deterministic greedy peak flattening
# ----------------------------------------------------------------------
def _run_greedy_reduction(a0: np.ndarray,
                          n: int,
                          deadline: float,
                          start_time: float,
                          cur_best_score: float,
                          cur_best_seq: np.ndarray,
                          max_iters: int = 5_000_000) -> tuple[np.ndarray, float]:
    """
    Repeatedly moves a tiny amount of mass from the index that most contributes
    to the current peak towards an index that contributes the least.
    The convolution is updated incrementally (O(n) per move).
    """
    a = a0.copy()
    Lfft = _next_pow2(2 * n - 1)
    conv = _conv_self(a, Lfft)               # length 2·n‑1
    best_a = a.copy()
    best_score = cur_best_score
    it = 0
    recompute_interval = 500

    while time.time() < deadline and it < max_iters:
        it += 1

        max_idx = int(conv.argmax())
        max_val = conv[max_idx]

        # second largest entry (ignore the current maximum)
        mask = np.ones_like(conv, dtype=bool)
        mask[max_idx] = False
        second_max = conv[mask].max()

        # indices that actually participate in this max
        lo = max(0, max_idx - (n - 1))
        hi = min(n - 1, max_idx)
        idx = np.arange(lo, hi + 1, dtype=int)
        contrib = a[idx] * a[max_idx - idx]
        src = idx[np.argmax(contrib)]

        # partner values for src and every other candidate
        partner_vals = a[max_idx - idx]

        # choose destination with smallest partner value (and not src)
        dst_cand = idx[partner_vals == partner_vals.min()]
        dst_cand = dst_cand[dst_cand != src]
        if dst_cand.size == 0:
            dst = np.random.randint(0, n)
            while dst == src:
                dst = np.random.randint(0, n)
        else:
            dst = np.random.choice(dst_cand)

        partner_src = a[max_idx - src] if 0 <= max_idx - src < n else 0.0
        partner_dst = a[max_idx - dst] if 0 <= max_idx - dst < n else 0.0
        delta_a = partner_src - partner_dst

        # decide a small move size epsilon
        if delta_a <= 0.0:
            eps = min(a[src], 0.02 * a[src])
        else:
            eps_target = (max_val - second_max) / (2.0 * delta_a)
            eps = min(a[src], max(0.0, 0.9 * eps_target))
            if eps < 1e-12:
                eps = min(a[src], 0.02 * a[src])

        if eps <= 0.0:
            continue

        # ----- incremental update of the convolution -----
        a_old = a.copy()
        # make the slices explicit – numpy will broadcast efficiently
        conv[dst:dst + n] += 2.0 * eps * a_old
        conv[src:src + n] -= 2.0 * eps * a_old
        a[src] -= eps
        a[dst] += eps
        a[a < 0] = 0.0

        # occasional exact recomputation to avoid drift
        if it % recompute_interval == 0:
            conv = _conv_self(a, Lfft)

        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] greedy iter={it:,} "
                  f"score={cur_score:.6f}")

    return best_a, best_score

        if starter.ndim == 1 and starter.size > 0:
            interp = np.interp(
                np.linspace(0, 1, n),
                np.linspace(0, 1, starter.size),
                starter,
            )
            interp = np.maximum(interp, 0.0)
            if interp.sum() > 0.0:
                interp = interp / interp.sum()
                initial_candidates.append(interp)
    except Exception:
        pass

    # 2) uniform
    initial_candidates.append(np.full(n, 1.0 / n))

    # 3) linear decreasing
    lin = np.arange(n, 0, -1, dtype=float)
    initial_candidates.append(lin / lin.sum())

    # 4) sqrt‑law
    sqrt_shape = 1.0 / np.sqrt(np.arange(1, n + 1, dtype=float))
    initial_candidates.append(sqrt_shape / sqrt_shape.sum())

    # 5) exponential decay
    q = 0.9995
    exp_shape = (1 - q) * (q ** np.arange(n, dtype=float))
    if exp_shape.sum() > 0.0:
        initial_candidates.append(exp_shape / exp_shape.sum())

    # pick the best out of the deterministic seeds (cheap evaluation)
    best_seq = None
    best_score = float("inf")
    for cand in initial_candidates:
        conv = _conv_self(cand, _next_pow2(2 * n - 1))
        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score:
            best_score = cur_score
            best_seq = cand.copy()
    print(f"[{time.time() - start_time:.2f}s] initial best score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – soft‑max gradient descent (≈25 % of remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        phase_deadline = time.time() + (deadline - time.time()) * 0.25
        seq, scr = _run_softmax_gradient(best_seq, n, phase_deadline, start_time,
                                         alpha_start=0.5, alpha_end=500.0,
                                         eta0=0.5)
        if scr < best_score:
            best_score, best_seq = scr, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] soft‑max improve: {scr:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – hard‑max exponentiated‑gradient descent (≈55 % of remaining)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        phase_deadline = time.time() + (deadline - time.time()) * 0.55
        seq, scr = _run_exp_gradient(best_seq, n, phase_deadline, start_time,
                                     eta0=0.6)
        if scr < best_score:
            best_score, best_seq = scr, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] exp‑grad improve: {scr:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – deterministic greedy peak flattening (use all time left)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        seq, scr = _run_greedy_reduction(
            best_seq,
            n,
            deadline,
            start_time,
            best_score,
            best_seq,
            max_iters=10_000_000,
        )
        if scr < best_score:
            best_score, best_seq = scr, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] greedy improve: {scr:.6f}")

    # ------------------------------------------------------------------
    # Optional tiny random‑restart polishing if a few seconds still remain.
    # ------------------------------------------------------------------
    while time.time() < deadline - 2.0:
        pert = best_seq + 0.01 * np.random.randn(n)
        pert = np.clip(pert, 0.0, None)
        if pert.sum() == 0.0:
            pert = np.full(n, 1.0 / n)
        else:
            pert = pert / pert.sum()
        tmp_deadline = time.time() + 1.5
        seq, scr = _run_exp_gradient(pert, n, tmp_deadline, start_time,
                                     eta0=0.5)
        if scr < best_score:
            best_score, best_seq = scr, seq.copy()
            print(f"[{time.time() - start_time:.2f}s] random‑restart improve: {scr:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation (the objective is homogeneous, any scaling works)
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq = best_seq / total
    else:
        best_seq = np.full(n, 1.0 / n)

    print(f"[{time.time() - start_time:.2f}s] final best score = {best_score:.6f}")
    return [float(x) for x in best_seq]
```
