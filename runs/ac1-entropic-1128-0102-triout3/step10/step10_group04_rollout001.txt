The goal is to find a non‑negative vector `a` (the heights of a step function) that minimises  

```
score(a) = 2·n·max(a*a) / (sum a)²
```  

where `a*a` is the discrete self‑convolution.  
Because the objective is homogeneous of degree 0 we can safely enforce `sum a = 1`.  
The problem is non‑convex: each convolution entry is a quadratic form in `a`.  
The previous optimiser used a pure *max‑gradient* (exponentiated‑gradient) that stalls once several convolution entries become equally large.

---

### New optimisation strategy  

1. **Smooth surrogate for the max**
   * Replace `max(conv)` by the *log‑sum‑exp* (LSE)  
     `fβ(conv) = (1/β)·log( Σₖ exp(β·convₖ) )`.  
     For β → ∞ the LSE tends to the true max, but for moderate β the
     gradient depends on *all* convolution entries, which helps the
     optimiser escape the plateaus that stopped the previous method.

2. **Mirror‑descent with the smoothed gradient**
   * The gradient of `fβ(conv)` w.r.t. `a` can be written as a convolution
     `grad = 2·(w * a_rev)[n‑1 : n‑1+n]` where `wₖ = softmax(β·convₖ)`.
   * An exponentiated‑gradient update  
     `a ← a·exp(‑η·grad)` is performed, followed by a **Euclidean projection
     onto the probability simplex** (so `sum a = 1` and `a_i ≥ 0`).

   * **Continuation on β** – we start with a small β (very smooth LSE) and
     increase it slowly up to a large β (≈ 200).  Early iterations move the
     mass globally, later iterations fine‑tune the peak.

   * Step‑size schedule: `η = η₀ / sqrt(t)` (standard diminishing steps).

3. **Final deterministic polishing**
   * After the smoothed gradient phase we run the *greedy peak‑flattening*
     routine from the reference implementation.  This stage moves tiny
     amounts of mass from a “bad’’ index to a “good’’ one and reliably
     shaves the last few 10⁻³ from the objective.

4. **Random restarts (optional)**
   * If a few seconds remain we add a tiny Gaussian jitter to the current
     best vector and run a short burst of the smoothed gradient again.
     This can escape tiny local minima.

The whole pipeline respects the 1000 s budget, prints progress, and finally
returns the best sequence found as a plain Python list.

---

### Implementation notes  

* All convolutions are performed with FFTs (`np.fft.rfft`), which gives an
  **O(n log n)** cost per iteration (`n = 4096`).  
* Two FFT lengths are needed:
  * `L_self = next_pow2(2·n‑1)` for the self‑convolution.
  * `L_grad = next_pow2(3·n‑2)` for the gradient convolution (no circular
    aliasing).
* The simplex projection follows the algorithm of Duchi *et al.* (2008).
* The code is fully self‑contained; it never reads or writes files and
  does not rely on external optimisation libraries.

```python
"""
Smooth‑gradient optimiser for the step‑function convolution problem.

The algorithm:
  1. Initialise from a few simple deterministic shapes.
  2. Run a continuation method:
        – minimise a log‑sum‑exp surrogate of the convolution peak,
        – use exponentiated‑gradient updates,
        – increase the smoothing parameter β during the run.
  3. Finish with the deterministic greedy “peak‑flattening’’ routine
     (the same one used in the reference solution).
  4. If time permits, perform tiny random‑restart polishing steps.

All updates keep the vector on the probability simplex (sum = 1,
non‑negative).  The final result is returned as a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:  # fallback – should never happen for non‑empty v
        w = np.full_like(v, 1.0 / v.shape[0])
    return w


def _conv_self_fft(a: np.ndarray, L_self: int) -> np.ndarray:
    """Full self‑convolution a*a (length 2·len(a)‑1) via FFT of length L_self."""
    Af = np.fft.rfft(a, n=L_self)
    conv = np.fft.irfft(Af * Af, n=L_self)[: 2 * a.shape[0] - 1]
    return conv


def _softmax(beta_conv: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max of β·conv (β already multiplied)."""
    shift = beta_conv.max()
    exps = np.exp(beta_conv - shift)
    return exps / exps.sum()


def _grad_lse(a: np.ndarray,
              conv: np.ndarray,
              beta: float,
              L_grad: int) -> np.ndarray:
    """
    Gradient of the log‑sum‑exp surrogate w.r.t. a.
    Uses FFT‑based convolution with the softmax weights.
    """
    # soft‑max weights (wₖ ∝ exp(β·convₖ))
    w = _softmax(beta * conv)          # length = 2n‑1
    # reversed a
    a_rev = a[::-1]
    # FFTs for the gradient convolution
    Wf = np.fft.rfft(w, n=L_grad)
    Af_rev = np.fft.rfft(a_rev, n=L_grad)
    full = np.fft.irfft(Wf * Af_rev, n=L_grad)
    n = a.shape[0]
    # slice the relevant part: indices n‑1 … n‑1+n‑1
    grad = 2.0 * full[n - 1 : n - 1 + n]
    return grad


# ----------------------------------------------------------------------
# Phase 1 – Smoothed exponentiated‑gradient descent (continuation)
# ----------------------------------------------------------------------


def _run_smooth_exp_gradient(a0: np.ndarray,
                             n: int,
                             deadline: float,
                             start_time: float,
                             eta0: float = 0.6,
                             beta0: float = 0.5,
                             beta_max: float = 200.0,
                             beta_factor: float = 1.001) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent optimiser that minimises the log‑sum‑exp surrogate of the
    convolution peak.  Returns the best vector seen and its true score.
    """
    a = a0.copy()
    best_a = a.copy()
    # initial score (exact objective)
    L_self = _next_pow2(2 * n - 1)
    conv = _conv_self_fft(a, L_self)
    best_score = 2.0 * n * conv.max()

    L_grad = _next_pow2(3 * n - 2)
    it = 0
    beta = beta0

    while time.time() < deadline:
        it += 1

        # --- full self‑convolution (exact, needed for true score) ---
        conv = _conv_self_fft(a, L_self)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] smooth‑grad iter={it:,} "
                  f"score={cur_score:.6f}")

        # --- update smoothing parameter β (continuation) ---
        beta = min(beta_max, beta * beta_factor)

        # --- gradient of the smoothed objective ---
        grad = _grad_lse(a, conv, beta, L_grad)

        # --- mirror‑descent multiplicative step ---
        eta = eta0 / math.sqrt(it)
        a = a * np.exp(-eta * grad)

        # --- projection onto the simplex (exact sum = 1) ---
        total = a.sum()
        if total <= 0.0 or np.isnan(total):
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / total

    return best_a, best_score


# ----------------------------------------------------------------------
# Phase 2 – Deterministic greedy reduction (same as reference)
# ----------------------------------------------------------------------


def _run_greedy_reduction(a0: np.ndarray,
                          n: int,
                          deadline: float,
                          start_time: float,
                          cur_best_score: float,
                          cur_best_seq: np.ndarray,
                          max_iters: int = 5_000_000) -> tuple[np.ndarray, float]:
    """
    Repeatedly move a tiny amount of mass from the index that most
    contributes to the current peak to an index that contributes least,
    updating the full convolution incrementally.
    """
    a = a0.copy()
    L = 2 * n - 1
    Lfft = _next_pow2(L)
    conv = np.fft.irfft(np.fft.rfft(a, n=Lfft) * np.fft.rfft(a, n=Lfft), n=Lfft)[:L]
    best_a = a.copy()
    best_score = cur_best_score
    it = 0
    recompute_interval = 500

    while time.time() < deadline and it < max_iters:
        it += 1

        max_idx = int(conv.argmax())
        max_val = conv[max_idx]

        # second largest entry (ignore the current maximum)
        mask = np.ones_like(conv, dtype=bool)
        mask[max_idx] = False
        second_max = conv[mask].max()

        # indices that actually participate in this max
        lo = max(0, max_idx - (n - 1))
        hi = min(n - 1, max_idx)
        idx = np.arange(lo, hi + 1)
        contrib = a[idx] * a[max_idx - idx]
        src = idx[np.argmax(contrib)]

        # partner values for src and every other candidate
        partner_vals = a[max_idx - idx]

        # choose destination with smallest partner value (and not src)
        dst_cand = idx[partner_vals == partner_vals.min()]
        dst_cand = dst_cand[dst_cand != src]
        if dst_cand.size == 0:
            dst = np.random.randint(0, n)
            while dst == src:
                dst = np.random.randint(0, n)
        else:
            dst = np.random.choice(dst_cand)

        partner_src = a[max_idx - src] if 0 <= max_idx - src < n else 0.0
        partner_dst = a[max_idx - dst] if 0 <= max_idx - dst < n else 0.0
        delta_a = partner_src - partner_dst

        # decide a small move size epsilon
        if delta_a <= 0.0:
            eps = min(a[src], 0.02 * a[src])
        else:
            eps_target = (max_val - second_max) / (2.0 * delta_a)
            eps = min(a[src], max(0.0, 0.9 * eps_target))
            if eps < 1e-12:
                eps = min(a[src], 0.02 * a[src])

        if eps <= 0.0:
            continue

        # ----- incremental update of the convolution -----
        a_old = a.copy()
        conv[dst:dst + n] += 2.0 * eps * a_old
        conv[src:src + n] -= 2.0 * eps * a_old
        a[src] -= eps
        a[dst] += eps
        a[a < 0] = 0.0

        # occasional exact recomputation to avoid drift
        if it % recompute_interval == 0:
            conv = np.fft.irfft(np.fft.rfft(a, n=Lfft) * np.fft.rfft(a, n=Lfft),
                                n=Lfft)[:L]

        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"[{time.time() - start_time:.2f}s] greedy iter={it:,} "
                  f"score={cur_score:.6f}")

    return best_a, best_score

    initial_candidates.append(np.full(n, 1.0 / n))

    # 2) linear decreasing
    lin = np.arange(n, 0, -1, dtype=float)
    initial_candidates.append(lin / lin.sum())

    # 3) sqrt‑law
    sqrt_shape = 1.0 / np.sqrt(np.arange(1, n + 1, dtype=float))
    initial_candidates.append(sqrt_shape / sqrt_shape.sum())

    # 4) exponential decay
    q = 0.9995
    exp_shape = (1 - q) * (q ** np.arange(n, dtype=float))
    initial_candidates.append(exp_shape / exp_shape.sum())

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Very short warm‑up runs to pick a promising start (≈5 s total)
    # ------------------------------------------------------------------
    for cand in initial_candidates:
        if time.time() >= deadline:
            break
        tmp_deadline = time.time() + min(2.0, (deadline - time.time()) * 0.02)
        seq, scr = _run_smooth_exp_gradient(cand, n, tmp_deadline, start_time,
                                            eta0=0.8, beta0=0.5,
                                            beta_max=30.0, beta_factor=1.003)
        if scr < best_score:
            best_score = scr
            best_seq = seq.copy()
            print(f"[{time.time() - start_time:.2f}s] warm‑up improve: score={scr:.6f}")

    # fallback to uniform if nothing succeeded
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)

    # ------------------------------------------------------------------
    # Phase 1 – long smoothed exponentiated‑gradient descent
    # Use ~55 % of the remaining budget.
    # ------------------------------------------------------------------
    if time.time() < deadline:
        remaining = deadline - time.time()
        phase1_deadline = time.time() + remaining * 0.55
        seq, scr = _run_smooth_exp_gradient(best_seq, n, phase1_deadline,
                                            start_time,
                                            eta0=0.6,
                                            beta0=0.5,
                                            beta_max=200.0,
                                            beta_factor=1.001)
        if scr < best_score:
            best_score = scr
            best_seq = seq.copy()
            print(f"[{time.time() - start_time:.2f}s] phase‑1 improve: score={scr:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – deterministic greedy polishing (uses the reference code)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        seq, scr = _run_greedy_reduction(
            best_seq,
            n,
            deadline,
            start_time,
            best_score,
            best_seq,
            max_iters=10_000_000,
        )
        if scr < best_score:
            best_score = scr
            best_seq = seq.copy()
            print(f"[{time.time() - start_time:.2f}s] greedy improve: score={scr:.6f}")

    # ------------------------------------------------------------------
    # Optional tiny random‑restart polishing if a few seconds remain.
    # ------------------------------------------------------------------
    while time.time() < deadline - 2.0:
        pert = best_seq + 0.01 * np.random.randn(n)
        pert = np.clip(pert, 0.0, None)
        pert /= pert.sum()

        tmp_deadline = time.time() + 2.0
        seq, scr = _run_smooth_exp_gradient(pert, n, tmp_deadline, start_time,
                                            eta0=0.6,
                                            beta0=0.5,
                                            beta_max=150.0,
                                            beta_factor=1.002)
        if scr < best_score:
            best_score = scr
            best_seq = seq.copy()
            print(f"[{time.time() - start_time:.2f}s] restart improve: score={scr:.6f}")

    # ------------------------------------------------------------------
    # Final normalisation – the objective is scale‑invariant.
    # ------------------------------------------------------------------
    best_seq = np.maximum(best_seq, 0.0)
    total = best_seq.sum()
    if total > 0.0:
        best_seq = best_seq / total
    else:
        best_seq = np.full(n, 1.0 / n)

    # Return as a plain Python list (the orchestration code expects this)
    return [float(x) for x in best_seq]
```
