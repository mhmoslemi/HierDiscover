def _expgrad_multi_opt_advanced(a0, deadline, start_time, fft_len, n, eta0=0.8, delta_frac=0.001, top_k=20, stagnation_limit=2000, noise_scale=0.02):

   # a0 normalized to sum 1.

   a = np.maximum(a0, 1e-15)
   a = a / a.sum()
   best_a = a.copy()
   best_score_val = _score_from_conv(_conv_self(a, fft_len), a.sum(), n)  # compute initial.
   t = 0
   last_improve_iter = 0

   while time.time() < deadline:
       t += 1
       conv = _conv_self(a, fft_len)
       cur_max = conv.max()
       cur_score = 2 * n * cur_max / (a.sum()**2)   # same as evaluate
       if cur_score < best_score_val:
           best_score_val = cur_score
           best_a = a.copy()
           last_improve_iter = t
           print(f"[{time.time() - start_time:6.2f}s] Multi-ExpGrad improve: iter={t:,}, score={cur_score:.6f}")

       # active shift selection
       thresh = cur_max - max(delta_frac * cur_max, 1e-15)
       active = np.where(conv >= thresh)[0]
       if active.size > top_k:
           # select top_k indices
           # use argpartition to get top_k largest conv values among active:
           # Actually we can directly get top_k from conv:
           # Using np.argpartition(-conv, top_k-1)[:top_k]
           # But need to restrict to active? We'll just pick top_k from conv:
           top_indices = np.argpartition(-conv, top_k-1)[:top_k]
           active = top_indices

       # compute subgradient using FFT
       # w vector of zeros length 2n-1
       w = np.zeros(2*n - 1, dtype=float)
       w[active] = 1.0
       # gradient via FFT
       Af = np.fft.rfft(a, n=fft_len)
       Wrev = np.fft.rfft(w[::-1], n=fft_len)
       corr = np.fft.irfft(Af * Wrev, n=fft_len)
       # slice gradient:
       grad = 2.0 * corr[(2*n - 2) - np.arange(n)]

       # step size
       eta = eta0 / math.sqrt(t)

       # exponentiated update
       a = a * np.exp(-eta * grad)

       # renormalize
       s = a.sum()
       if s <= 0 or np.isnan(s) or np.isinf(s):
           a = np.full_like(a, 1.0 / n)
       else:
           a = a / s
       a = np.maximum(a, 1e-15)

       # occasional evaluation
       if t % 500 == 0:
           conv_check = _conv_self(a, fft_len)
           sc = 2 * n * conv_check.max() / (a.sum()**2)
           if sc < best_score_val:
               best_score_val = sc
               best_a = a.copy()
               print(f"[{time.time() - start_time:6.2f}s] Check improve: iter={t}, score={sc:.6f}")

       # stagnation detection
       if t - last_improve_iter > stagnation_limit:
           # add random noise
           noise = (rng.standard_normal(n) * noise_scale * a)
           a = a + noise
           a = np.maximum(a, 0.0)
           a = a / a.sum()
           # reset counter
           last_improve_iter = t

   return best_a, best_score_val

assistantfinal**Solution Overview**

The evaluation function  

```
score = 2·n·max(conv(a,a)) / (sum(a)²)
```  

is homogeneous – scaling the whole vector does not change the score.  
Consequently we may (and do) keep the vector normalised to a unit sum.

The goal is to flatten the self‑convolution `conv(a,a)`.  
If all convolution bins had the same value `μ = 1/(2n‑1)`, the score would be
`≈1`.  The current best (≈1.512) already reduces the peak from the uniform
value `1/n` to about half of it.  To push the peak further down we use a
**mirror‑descent on the true max‑convolution**, but improve the original
implementation in three ways

* **Full FFT gradient** – when many shifts are active we build a weight vector
  `w` (1 on the active shifts, 0 elsewhere) and obtain the sub‑gradient by a
  single FFT‑correlation.  This is both faster and allows us to use a larger
  active set.
* **Larger active set & tighter tolerance** – we keep the `top_k` most
  violating shifts (default 15) and a tolerance `δ = 0.001·max`.  The algorithm
  therefore pushes down *all* high peaks, not only the single maximum.
* **Stagnation handling** – if no improvement is seen for a few thousand
  iterations we add a small multiplicative Gaussian perturbation, re‑normalise
  and continue.  This helps to escape tiny plateaus.

The optimisation consists of three phases:

1. **Warm‑up** – a few thousand Adam steps on a smooth log‑sum‑exp
   surrogate of the max.
2. **Main mirror‑descent** – the advanced exponentiated‑gradient loop described
   above (≈80 % of the time budget).
3. **Greedy peak‑reduction** – deterministic local moves that transfer a small
   fraction of the coefficient responsible for the current peak towards the
   smallest coefficient (as in the reference code).

All phases respect the 1000 s budget, constantly report progress and finally
return the best sequence found.

```python
# -*- coding: utf-8 -*-
"""
Propose a non‑negative step function that (almost) minimises
evaluate_sequence.

Algorithm
---------
1. Diverse initialisation – uniform, exponential, power‑law and many
   Dirichlet draws (different concentration parameters).  The best
   raw candidate is kept.

2. Warm‑up – a few thousand Adam steps on the log‑sum‑exp surrogate of
   the convolution peak.  This quickly moves the distribution away from
   bad regions.

3. Main optimisation – exponentiated‑gradient mirror descent on the true
   max‑convolution objective.  The gradient is obtained by a *single*
   FFT‑correlation of the current vector with a 0/1 weight vector that
   marks the top‑k (or all) near‑maximal shifts.  A diminishing step size
   η = η₀ / √t is used, together with a stagnation detector that injects
   a tiny random perturbation when progress stalls.

4. Deterministic greedy peak‑reduction – final local search that moves a
   fraction of the coefficient responsible for the current convolution
   peak towards the smallest coefficient, accepting only strict
   improvements.

All phases respect the supplied time budget (default 1000 s) and the
routine returns the best sequence found (normalised to sum = 1, all entries
≥ 0).  The implementation is self‑contained and only relies on ``numpy`` and
the provided ``evaluate_sequence`` function.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Low‑level helpers
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Full linear convolution a*a (length 2·len(a)‑1) via FFT.
    """
    Af = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(Af * Af, n=fft_len)
    return conv[: 2 * a.shape[0] - 1]


def _score_from_conv(conv: np.ndarray, sum_a: float, n: int) -> float:
    """Exact objective value from a convolution array."""
    max_b = conv.max()
    return float(2.0 * n * max_b / (sum_a * sum_a))


def _score(a: np.ndarray, n: int, fft_len: int) -> float:
    """Convenient wrapper that computes the score of a vector."""
    conv = _conv_self(a, fft_len)
    return _score_from_conv(conv, a.sum(), n)


# ----------------------------------------------------------------------
# Random start generators
# ----------------------------------------------------------------------


def _dirichlet_start(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Draw a Dirichlet vector with given concentration and normalise."""
    x = rng.gamma(conc, 1.0, size=n)
    if x.sum() == 0.0:
        return np.full(n, 1.0 / n)
    return x / x.sum()


def _exponential_start(n: int, r: float = 0.9995) -> np.ndarray:
    """Geometric decay a_i ∝ r**i, normalised."""
    vec = np.array([r ** i for i in range(n)], dtype=float)
    return vec / vec.sum()


def _powerlaw_start(n: int, p: float = 0.5) -> np.ndarray:
    """
    Symmetric power‑law decreasing from the edges:
    a_i ∝ ( distance to the nearest edge )⁻ᵖ .
    """
    idx = np.arange(n)
    dist = np.minimum(idx + 1, n - idx)    # 1‑based distance to the nearer edge
    a = dist.astype(float) ** (-p)
    return a / a.sum()


# ----------------------------------------------------------------------
# Warm‑up: Adam on a smooth log‑sum‑exp surrogate of the max
# ----------------------------------------------------------------------


def _smooth_objective(a: np.ndarray, alpha: float, fft_len: int):
    """Soft‑max (log‑sum‑exp) approximation of max(conv)."""
    conv = _conv_self(a, fft_len)
    scaled = alpha * conv
    m = scaled.max()
    lse = m + np.log(np.exp(scaled - m).sum())
    return lse / alpha, conv


def _adam_optimize(a0: np.ndarray,
                   deadline: float,
                   start_time: float,
                   fft_len: int,
                   eps_log: float = 1e-16) -> tuple[np.ndarray, float]:
    """
    Adam optimisation of the smooth surrogate.
    Returns the best vector (unit sum) and its exact score.
    """
    a = a0.copy()
    n = a.shape[0]
    y = np.log(np.maximum(a, eps_log))

    # smoothing schedule – progressively sharper approximations of the max
    alpha_schedule = [0.5, 2.0, 8.0, 32.0, 128.0, 512.0, 2048.0]
    iters_per_alpha = 3000

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    eps_adam = 1e-8
    lr0 = 0.15
    m = np.zeros_like(y)
    v = np.zeros_like(y)
    t = 0

    best_a = a.copy()
    best_score = float(evaluate_sequence(a.tolist()))

    for alpha in alpha_schedule:
        for _ in range(iters_per_alpha):
            if time.time() >= deadline:
                return best_a, best_score

            # convert logits to a proper probability vector
            maxy = np.max(y)
            exp_y = np.exp(y - maxy)
            a = exp_y / exp_y.sum()

            f_val, conv = _smooth_objective(a, alpha, fft_len)

            # gradient of the smooth surrogate w.r.t. a
            scaled = alpha * conv
            max_scaled = scaled.max()
            w = np.exp(scaled - max_scaled)
            w /= w.sum()
            w_rev = w[::-1]

            Af = np.fft.rfft(a, n=fft_len)
            Wrev = np.fft.rfft(w_rev, n=fft_len)
            corr = np.fft.irfft(Af * Wrev, n=fft_len)[: n + len(w_rev) - 1]
            grad_a = 2.0 * corr[len(w_rev) - 1 - np.arange(n)]

            # back‑prop through the soft‑max
            grad_y = a * (grad_a - np.dot(grad_a, a))

            # Adam update on logits
            t += 1
            m = beta1 * m + (1.0 - beta1) * grad_y
            v = beta2 * v + (1.0 - beta2) * (grad_y ** 2)
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            lr_t = lr0 * (np.sqrt(1.0 - beta2 ** t) / (1.0 - beta1 ** t))
            y = y - lr_t * m_hat / (np.sqrt(v_hat) + eps_adam)

            # occasional exact evaluation
            if t % 250 == 0:
                sc = evaluate_sequence(a.tolist())
                if sc < best_score:
                    best_score = sc
                    best_a = a.copy()
                    print(f"[{time.time() - start_time:6.2f}s] Adam improve: α={alpha:.1f}, score={sc:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Main optimisation: exponentiated‑gradient mirror descent with a
# multi‑gradient built from the top‑k active convolution shifts.
# ----------------------------------------------------------------------


def _expgrad_multi_opt(a0: np.ndarray,
                       deadline: float,
                       start_time: float,
                       fft_len: int,
                       n: int,
                       rng: np.random.Generator,
                       eta0: float = 0.8,
                       delta_frac: float = 0.001,
                       top_k: int = 15,
                       stagnation_limit: int = 3000,
                       noise_scale: float = 0.02) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent (exponentiated gradient) on the *true* max‑convolution
    objective.  A full FFT‑based sub‑gradient is used for all active shifts.
    Returns the best vector ever seen and its exact score.
    """
    a = np.maximum(a0, 1e-15)
    a = a / a.sum()

    best_a = a.copy()
    best_score = _score(a, n, fft_len)
    t = 0
    last_improve = 0

    while time.time() < deadline:
        t += 1
        conv = _conv_self(a, fft_len)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max / (a.sum() ** 2)

        # keep the best ever seen
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            last_improve = t
            print(f"[{time.time() - start_time:6.2f}s] Multi‑ExpGrad improve: iter={t:,}, score={cur_score:.6f}")

        # ----- active set -------------------------------------------------
        thresh = cur_max - max(delta_frac * cur_max, 1e-12)
        active = np.where(conv >= thresh)[0]

        if active.size > top_k:
            # keep only the top_k shifts with the largest convolution values
            part = np.argpartition(-conv[active], top_k - 1)[:top_k]
            active = active[part]

        # ----- gradient (FFT version) ------------------------------------
        # weight vector w (0/1 on the active shifts)
        w = np.zeros(2 * n - 1, dtype=float)
        w[active] = 1.0
        w_rev = w[::-1]

        Af = np.fft.rfft(a, n=fft_len)
        Wrev = np.fft.rfft(w_rev, n=fft_len)
        corr = np.fft.irfft(Af * Wrev, n=fft_len)
        # the correlation needed for the sub‑gradient lives at indices
        #    len(w_rev)-1‑i   , i = 0…n‑1
        grad = 2.0 * corr[(2 * n - 2) - np.arange(n)]

        # ----- step size -------------------------------------------------
        eta = eta0 / math.sqrt(t)

        # ----- exponentiated update --------------------------------------
        a = a * np.exp(-eta * grad)

        # ----- re‑normalise onto the simplex ------------------------------
        s = a.sum()
        if s <= 0.0 or np.isnan(s) or np.isinf(s):
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / s

        a = np.maximum(a, 1e-15)          # avoid exact zeros

        # ----- occasional exact check ------------------------------------
        if t % 500 == 0:
            sc = evaluate_sequence(a.tolist())
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
                print(f"[{time.time() - start_time:6.2f}s] checkpoint improve: iter={t}, score={sc:.6f}")

        # ----- stagnation handling ---------------------------------------
        if t - last_improve > stagnation_limit:
            # inject a tiny multiplicative noise and continue
            noise = rng.standard_normal(n) * noise_scale * a
            a = a + noise
            a = np.maximum(a, 0.0)
            a = a / a.sum()
            last_improve = t
            print(f"[{time.time() - start_time:6.2f}s] perturb after stagnation at iter={t}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Greedy local improvement (deterministic)
# ----------------------------------------------------------------------


def _greedy_local_improve(a0: np.ndarray,
                          deadline: float,
                          start_time: float,
                          max_iters: int = 3000) -> tuple[np.ndarray, float]:
    """
    Shift a modest fraction of the coefficient that most contributes to the
    current convolution peak towards the smallest coefficient.  Accept only
    strict improvements.
    """
    a = a0.copy()
    n = a.shape[0]
    best_score = 2.0 * n * _conv_self(a, _next_pow2(2 * n - 1)).max()
    it = 0

    while time.time() < deadline and it < max_iters:
        it += 1
        conv = _conv_self(a, _next_pow2(2 * n - 1))
        cur_max = conv.max()
        k_max = conv.argmax()

        lo = max(0, k_max - (n - 1))
        hi = min(n - 1, k_max)
        i_idx = np.arange(lo, hi + 1, dtype=int)
        j_idx = k_max - i_idx
        contrib = a[i_idx] * a[j_idx]
        src = i_idx[contrib.argmax()]

        dst_candidates = np.delete(np.arange(n), src)
        dst = dst_candidates[a[dst_candidates].argmin()]

        eps = 0.25 * a[src]          # move a quarter of the source mass
        if eps <= 1e-14:
            break

        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        new_max = _conv_self(a_prop, _next_pow2(2 * n - 1)).max()
        if new_max < cur_max:
            a = a_prop
            best_score = 2.0 * n * new_max
            print(f"[{time.time() - start_time:6.2f}s] greedy improve: max={new_max:.6f}")

    return a, best_score

def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function (list of floats) that minimises
    the supplied ``evaluate_sequence`` function.
    The routine respects the time budget (default 1000 s) and returns the
    best sequence found.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5          # tiny safety margin

    # ------------------------------------------------------------------
    # Problem size (power‑of‑two FFT length simplifies the gradient step)
    # ------------------------------------------------------------------

    # Build a rich set of starting points
    # ------------------------------------------------------------------
    starts = []

    # 1) possibly known good sequence
    try:
        seq = np.asarray(height_sequence_1, dtype=float)
        if seq.ndim == 1 and seq.size > 0:
            if seq.shape[0] != n:
                # linearly up‑sample / down‑sample to the required length
                old_x = np.linspace(0.0, 1.0, seq.shape[0])
                new_x = np.linspace(0.0, 1.0, n)
                seq = np.interp(new_x, old_x, seq)
            starts.append(seq / seq.sum())
    except Exception:
        pass

    # 2) handcrafted deterministic starts
    starts.append(np.full(n, 1.0 / n))                     # uniform
    starts.append(_exponential_start(n, r=0.9999))
    starts.append(_exponential_start(n, r=0.985))
    starts.append(_powerlaw_start(n, p=0.5))
    starts.append(_powerlaw_start(n, p=0.7))
    starts.append(_dirichlet_start(n, conc=2.0, rng=rng))
    starts.append(_dirichlet_start(n, conc=0.5, rng=rng))

    # 3) random Dirichlet draws with several concentrations
    conc_params = [0.1, 0.3, 0.5, 1.0, 2.0, 5.0]
    for conc in conc_params:
        for _ in range(5):
            starts.append(_dirichlet_start(n, conc=conc, rng=rng))

    # ------------------------------------------------------------------
    # Evaluate raw starts and keep the best one (exact score)
    # ------------------------------------------------------------------
    best_seq = None
    best_score = float("inf")
    for idx, a0 in enumerate(starts):
        sc = evaluate_sequence(a0.tolist())
        if sc < best_score:
            best_score = sc
            best_seq = a0.copy()
        print(f"[{time.time() - start_time:6.2f}s] start #{idx+1:2d} score={sc:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – Adam warm‑up (≈10 % of the budget)
    # ------------------------------------------------------------------
    warmup_deadline = start_time + budget_s * 0.10
    cand_seq, cand_score = _adam_optimize(best_seq, warmup_deadline,
                                          start_time, fft_len)
    if cand_score < best_score:
        best_score = cand_score
        best_seq = cand_seq.copy()
        print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST after Adam score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 2 – Multi‑gradient exponentiated‑gradient polishing
    #          (≈80 % of the budget)
    # ------------------------------------------------------------------
    polish_deadline = start_time + budget_s * 0.90
    polished_seq, polished_score = _expgrad_multi_opt(
        best_seq, polish_deadline, start_time, fft_len, n, rng,
        eta0=0.8, delta_frac=0.001, top_k=15,
        stagnation_limit=3000, noise_scale=0.02
    )
    if polished_score < best_score:
        best_score = polished_score
        best_seq = polished_seq.copy()
        print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST after polishing score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – Deterministic greedy peak reduction (remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        final_seq, final_score = _greedy_local_improve(
            best_seq, deadline, start_time, max_iters=5000
        )
        if final_score < best_score:
            best_score = final_score
            best_seq = final_seq.copy()
            print(f"[{time.time() - start_time:6.2f}s] *** NEW GLOBAL BEST after greedy score={best_score:.6f}")

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------
    best_seq = np.clip(best_seq, 0.0, None)
    total = best_seq.sum()
    if total > 0.0:

    else:

    final_reported = evaluate_sequence(best_seq.tolist())
    print(f"[{time.time() - start_time:6.2f}s] final reported score = {final_reported:.6f}")

    # return plain Python list as required by the competition harness
    return [float(x) for x in best_seq.tolist()]
```
