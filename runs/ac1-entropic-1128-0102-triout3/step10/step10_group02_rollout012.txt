assistantfinal**Solution Overview**

The function `propose_candidate` builds a non‑negative step‑function `a` of length `n = 4096` that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max(\text{conv}(a,a))}{\bigl(\sum_i a_i\bigr)^2 } .
\]

The score is *scale invariant*: multiplying the whole vector by a constant does not change it, therefore we can (and do) keep the vector on the probability simplex (`∑a_i = 1`).  

The optimisation is performed in three independent phases:

1. **Random‑restart smooth‑max mirror descent** – a differentiable approximation of the `max` is built with a soft‑max (log‑sum‑exp) and exponentiated‑gradient updates are applied on the simplex.  
   * Several restarts with different random Dirichlet seeds are executed.  
   * After every update the vector is symmetrised (`a ← (a+rev(a))/2`) – the objective is symmetric, and symmetrisation never hurts the score (by convexity it can only improve it).  

2. **Projected Adam sub‑gradient descent** – once a good neighbourhood is found we switch to the exact sub‑gradient of the (non‑smooth) max.  Adam‑style adaptive moments are used together with a simplex projection.  The same symmetrisation trick is employed.

3. **Fine‑grained simulated‑annealing polish** – a cheap mass‑transfer move (`ε` taken from one index and added to another) is accepted with the Metropolis rule.  The temperature is driven from `1e‑2` down to `1e‑9`, and the whole phase runs until the time budget is exhausted.

All three phases are time‑controlled; the best sequence seen so far is kept permanently.  The final vector is normalised to a proper probability distribution and returned as a plain Python list.

The code is fully self‑contained, uses only `numpy` and the standard library, and respects the 1000 s wall‑clock limit.

```python
"""
propose_candidate – minimise 2·n·max(conv(a,a))/sum(a)^2 for n=4096.

Algorithm (≈ 1000 s total)

1️⃣  Random‑restart smooth‑max mirror descent  
    • soft‑max (log‑sum‑exp) approximation of the max  
    • exponentiated‑gradient updates on the simplex  
    • after each step a ← (a+rev(a))/2  (symmetrisation)  
    • many short restarts with Dirichlet(α) initialisations.

2️⃣  Projected Adam sub‑gradient descent on the exact max  
    • sub‑gradient for the active convolution index  
    • Adam moments, bias‑correction, simplex projection  
    • symmetrisation after every update.

3️⃣  Fine simulated‑annealing polish (mass‑transfer moves)  
    • Metropolis acceptance with a geometric temperature schedule  
    • runs until the deadline.

The best sequence (non‑negative, sum=1) is returned as a plain list of floats.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (FFT convolution, simplex projection, symmetrisation)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_self(a: np.ndarray, L: int = None) -> np.ndarray:
    """Linear self‑convolution a*a (full length 2·len(a)-1) via FFT."""
    n = a.shape[0]
    if L is None:
        L = _next_pow2(2 * n - 1)
    Af = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(Af * Af, n=L)[: 2 * n - 1]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
        w = np.maximum(v - theta, 0.0)
    else:
        w = np.full_like(v, 1.0 / n)
    return w


def _symmetrize(a: np.ndarray) -> np.ndarray:
    """Enforce a_i = a_{n-1-i} (averaging with the reversed vector)."""
    return (a + a[::-1]) * 0.5


def _score(a: np.ndarray, L_self: int) -> float:
    """Exact objective (no scaling, sum must be 1)."""
    conv = _conv_self(a, L_self)
    return float(2.0 * a.shape[0] * conv.max() / (a.sum() ** 2))


# ----------------------------------------------------------------------
# Phase‑1 : smooth‑max mirror descent (multiple restarts)
# ----------------------------------------------------------------------
def _smooth_descent_restart(
    a0: np.ndarray,
    n: int,
    deadline: float,
    L_self: int,
    L_grad: int,
) -> tuple[np.ndarray, float]:
    """
    Exponentiated‑gradient descent on the log‑sum‑exp approximation of the max.
    Symmetrisation is applied after each update.
    """
    a = a0.copy()
    best_a = a.copy()
    best_sc = _score(a, L_self)

    # geometric schedule for the smoothing parameter (more aggressive than before)
    alphas = np.geomspace(0.1, 2000.0, num=55)

    it = 0
    max_iters = 300_000

    for alpha in alphas:
        while time.time() < deadline - 0.3 and it < max_iters:
            it += 1

            # 1) self‑convolution
            Af = np.fft.rfft(a, n=L_self)
            conv = np.fft.irfft(Af * Af, n=L_self)[: 2 * n - 1]

            # 2) soft‑max weights (stable)
            exp_arg = alpha * conv
            max_arg = exp_arg.max()
            w = np.exp(exp_arg - max_arg)
            w_sum = w.sum()
            if w_sum == 0.0:
                w.fill(1.0 / w.shape[0])
            else:
                w /= w_sum

            # 3) gradient of the smooth max: 2 * (w ⋆ rev(a))
            a_rev = a[::-1]
            Wf = np.fft.rfft(w, n=L_grad)
            Revf = np.fft.rfft(a_rev, n=L_grad)
            grad_full = np.fft.irfft(Wf * Revf, n=L_grad)[: 3 * n - 2]
            grad = 2.0 * grad_full[n - 1:n - 1 + n]

            # 4) exponentiated‑gradient step on the simplex
            eta = 0.07 / (math.sqrt(it) * max(1.0, math.sqrt(alpha)))
            a = a * np.exp(-eta * grad)
            a = np.maximum(a, 1e-20)    # avoid exact zeros
            a = a / a.sum()             # simplex
            a = _symmetrize(a)          # keep symmetry

            # occasional exact‑objective check
            if it % 700 == 0:
                sc = _score(a, L_self)
                if sc < best_sc:
                    best_sc = sc
                    best_a = a.copy()
                    print(f"[{time.time() - start:.2f}s] smooth restart it={it:,} α={alpha:.2f} score={sc:.6f}")

        if time.time() >= deadline - 0.3:
            break

    return best_a, best_sc


# ----------------------------------------------------------------------
# Phase‑2 : projected Adam sub‑gradient descent (exact max)
# ----------------------------------------------------------------------
def _adam_subgradient(
    a0: np.ndarray,
    n: int,
    deadline: float,
    L_self: int,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser on f(a)=max(conv(a,a)) with simplex projection.
    Symmetrisation after each step.
    """
    a = a0.copy()
    best_a = a.copy()
    best_sc = _score(a, L_self)

    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12
    step0 = 0.45
    it = 0

    while time.time() < deadline - 0.2:
        it += 1
        conv = _conv_self(a, L_self)
        k = int(conv.argmax())                # active index
        lo = max(0, k - (n - 1))
        hi = min(n - 1, k)
        idx = np.arange(lo, hi + 1, dtype=int)

        grad = np.zeros_like(a)
        grad[idx] = 2.0 * a[k - idx]          # sub‑gradient of the active conv entry

        # Adam updates
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = step0 / math.sqrt(it)
        a = a - step * m_hat / (np.sqrt(v_hat) + eps)

        # simplex projection + symmetrisation
        a = np.maximum(a, 0.0)
        a = _project_simplex(a)
        a = _symmetrize(a)

        # keep the best
        sc = _score(a, L_self)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
            print(f"[{time.time() - start:.2f}s] Adam it={it:,} score={sc:.6f}")

    return best_a, best_sc


# ----------------------------------------------------------------------
# Phase‑3 : fine simulated‑annealing polish (mass‑transfer moves)
# ----------------------------------------------------------------------
def _annealing_fine(
    a0: np.ndarray,
    n: int,
    deadline: float,
    start_score: float,
    start_temp: float = 5e-2,
    end_temp: float = 1e-9,
    max_steps: int = 1_200_000,
) -> tuple[np.ndarray, float]:
    """
    Tiny random mass‑transfer moves accepted with a Metropolis rule.
    Very low final temperature; runs until time runs out or max_steps.
    """
    a = a0.copy()
    sc = start_score
    best_a = a.copy()
    best_sc = sc
    rng = np.random.default_rng()
    L_self = _next_pow2(2 * n - 1)

    for it in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        # linear temperature in log‑space
        T = start_temp * (end_temp / start_temp) ** (it / max_steps)

        src = rng.choice(n, p=a)                 # draw proportionally to mass
        dst = rng.integers(n)
        if src == dst or a[src] < 1e-14:
            continue

        eps = a[src] * rng.random() * 0.25       # transfer ≤25 % of source mass
        a_prop = a.copy()
        a_prop[src] -= eps
        a_prop[dst] += eps

        # exact evaluation (fast because we use the same FFT size)
        conv = _conv_self(a_prop, L_self)
        new_sc = float(2.0 * n * conv.max() / (a_prop.sum() ** 2))
        delta = new_sc - sc

        if delta < 0.0 or math.exp(-delta / T) > rng.random():
            a = a_prop
            sc = new_sc

        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
            print(f"[{time.time() - start:.2f}s] anneal it={it:,} best={best_sc:.6f}")

    return best_a, best_sc
```
