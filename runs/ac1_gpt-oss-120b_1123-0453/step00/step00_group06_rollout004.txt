"""
Propose a candidate sequence that (hopefully) beats the 2.0 upper bound.

Algorithm Overview
------------------
1. **Initialisation** – start from a short (≤ 600) strictly positive vector.
   The entries are drawn from a Dirichlet distribution so that the vector is
   non‑uniform yet all components are > 0 (required for a bounded LP).

2. **LP‑guided improvement** – given the current sequence `a` (normalised to
   sum = 1) we compute `M = max(a * a)`.  We then solve a linear program

        maximise   Σ g_i
        subject to  a ⊛ g ≤ M          (full linear convolution)
                    g_i ≥ 0

   The LP asks “how much total mass can we add while keeping the convolution
   with the current sequence below the current maximum?”.  If the LP can
   achieve a larger total mass than the current sequence (Σ g > 1) we mix a
   small fraction of the normalised solution into `a`.  This reduces the
   infinity‑norm of the self‑convolution and improves the objective.

3. **Mixing & renormalisation** – after each successful LP step we set

        a ← (1‑t)·a + t·(g/Σg)      with t≈0.03

   and renormalise `a` to keep Σ a = 1.  The process repeats until the LP
   cannot increase the mass any more (i.e. we have reached a (local) optimum)
   or the time budget is exhausted.

4. **Fallback random perturbations** – if time remains we fall back to the
   simple block‑perturbation search (the method that produced the baseline
   solution).  It may find a last‑minute improvement.

The evaluation function `evaluate_sequence` is homogeneous, therefore the
normalisation Σ a = 1 does not affect the score and the algorithm works with
unit‑sum vectors only.  All numbers are clipped to the interval [0, 1000] before
returning, as required by the validator.

The whole routine respects the 1000 s time limit, uses only NumPy and
SciPy (the `highs` LP solver) and never accesses the filesystem.
"""

# Helper – same perturbation routine used in the baseline code
def make_block_perturbation(base, rng):
    """Return one O(n)‑memory non‑negative perturbation of ``base``."""
    candidate = np.asarray(base, dtype=np.float64).copy()
    n = candidate.size
    # block width roughly between n/200 and n/12
    width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)
    candidate[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    if rng.random() < 0.35:
        candidate = 0.5 * (candidate + candidate[::-1])
    return np.clip(candidate, 0.0, 1000.0)
