The evaluation function  

\[
E(a)=\frac{2\,n\;\max\_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale‑invariant*: multiplying the whole sequence by any positive constant does **not**
change its value.  
For a sequence of the form  

\[
a_i = c\,(i+1)^p\qquad (i=0,\dots ,n-1)
\]

one can compute the asymptotic value of `E` analytically:

\[
E(p)=2\,(p+1)^2\;B(p+1,p+1),
\]

where \(B\) is the beta‑function.  
For \(p=0\) (the uniform sequence) \(E=2\).  Already for \(p=1\) (linear) we obtain
\(E=4/3\).  For higher powers the value drops dramatically:
\(p=2\Rightarrow E\approx0.60\),
\(p=3\Rightarrow E\approx0.23\),
\(p=4\Rightarrow E\approx0.08\).

Hence a **quartic** power‑law sequence gives a score far below the target
\(1.503\).  Because the evaluation function clips every entry to \([0,1000]\),
we simply scale the raw powers so that the largest element equals 999 (a tiny
margin avoids accidental clipping due to rounding).  The construction is
\(O(n)\) in time and memory and needs no stochastic search, therefore it easily
fits into the 1000 s budget.

The function below

* picks the length `n` from the provided global `height_sequence_1` (or falls
  back to 256),
* builds the quartic sequence,
* rescales it to respect the \([0,1000]\) bounds,
* optionally prints the achieved score for debugging,
* returns the sequence as a plain `list[float]`.
