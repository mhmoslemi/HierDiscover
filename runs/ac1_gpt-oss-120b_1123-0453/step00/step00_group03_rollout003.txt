The goal is to produce a search method that finds a sequence with minimal evaluation value; then we want to output (return) that sequence as a list of floats.

The evaluate_sequence computes:

- Input sequence l: list of numbers.
- If invalid, returns inf.
- After safety checks, sequence is forced to be nonnegative, clipped to [0,1000].
- n = len(sequence)
- b_sequence = np.convolve(sequence, sequence). That's the discrete convolution of the sequence with itself, length = 2n - 1.
- max_b = max(b_sequence)
- sum_a = sum(sequence)
- If sum_a < 0.01: return inf
- Return float(2 * n * max_b / (sum_a**2))

Thus we want to minimize (2*n*max_b) / (sum_a^2). Equivalent target: minimize max_b / (sum_a^2 / n).

```
def simplex_projection(v):
    # ensure v is 1D
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.nonzero(u + (1 - cssv) / np.arange(1, n+1) > 0)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w
```

"""
Gradient‑descent optimizer for the “max‑convolution” objective.

The evaluation function
    score = 2·n·max_k (a∗a)[k] / (Σ a_i)^2
is invariant under a global scaling of the sequence.
If we set Σ a_i = 1 (i.e. work on the probability simplex) the
objective becomes simply

    score = 2·n·max_k p_k            where   p = a∗a   (convolution)

Thus the problem is to make the distribution of the sum of two i.i.d.
samples from p as flat as possible.  The algorithm keeps the vector
`a` on the simplex and performs projected gradient descent on a smooth
approximation of the max:

    S_β(a) = (1/β)·log Σ_k exp(β·(a∗a)_k)

When β is small S_β is a smooth average; as β grows it approaches the
true max.  The gradient of S_β w.r.t. a can be written as a convolution,
so each iteration costs only O(n log n) (numpy’s ``np.convolve``).

The steps are:

1. Initialise a uniform probability vector of length n (n is taken from
   the supplied ``height_sequence_1`` if available).
2. Repeatedly
   * compute the self‑convolution ``b = a∗a``,
   * form soft‑max weights ``w = exp(β·(b−max(b)))`` and normalise,
   * obtain the gradient ``g = 2·conv(reverse(a), w)[n‑1:n‑1+n]``,
   * take a projected gradient step ``a ← Π_simplex(a − η·g)`` (back‑track
     until the true objective does not increase),
   * keep the best vector seen so far.
   The smoothing parameter β is increased gradually so that the
   optimisation first moves smoothly and later focuses on the true
   maximum.
3. Occasionally a tiny random perturbation is added to escape shallow
   plateaus; after a long stagnation the algorithm re‑initialises from
   the current best point with a small amount of noise.
4. When the time budget expires the best sequence found is returned.

All numbers are non‑negative, lie well below the clipping limit 1000,
and sum to one, so the official ``evaluate_sequence`` yields exactly the
same score as the internal computation.
"""

import time
import numpy as np

def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
        { x | x_i ≥ 0 , Σ x_i = 1 }.
    Reference: Duchi et al., “Efficient Projections onto the l1‑Ball for
    Learning in High Dimensions”, ICML 2008.
    """
    if v.ndim != 1:
        raise ValueError("Simplex projection expects a 1‑D array")
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.nonzero(u + (1.0 - cssv) / np.arange(1, n + 1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def compute_score(a: np.ndarray) -> float:
    """
    Returns the exact value of ``evaluate_sequence`` for a non‑negative
    vector ``a`` that already respects the clipping limits.
    """
    s = a.sum()
    if s < 0.01:
        return np.inf
    b = np.convolve(a, a)
    max_b = b.max()
    n = a.shape[0]
    return float(2.0 * n * max_b / (s * s))


def propose_candidate(seed: int = 42, budget_s: float = 1100, **kwargs):
    """
    Gradient‑descent based search for a low‑score step‑function.
    The function respects the required signature and returns a list of
    floats.  It works completely inside memory, uses only ``numpy`` and
    ``time``, and never performs file or network I/O.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Determine the length of the sequence.
    # ------------------------------------------------------------------
    try:
        base = np.asarray(height_sequence_1, dtype=np.float64)
        n = int(base.size)
        if n == 0:
            raise Exception()
    except Exception:
        # Fallback: a modest length that is fast to optimise.
        n = 256

    # ------------------------------------------------------------------
    # Initialise a uniform probability vector (sum = 1, non‑negative).
    # ------------------------------------------------------------------
    a = np.full(n, 1.0 / n, dtype=np.float64)
    cur_score = compute_score(a)
    best = a.copy()
    best_score = cur_score

    # Hyper‑parameters (may be tuned on the fly).
    beta = 1.0          # smoothing for the soft‑max (will grow)
    eta = 0.5           # base step size
    iteration = 0
    last_improve = 0    # iteration index of the last improvement
    # ------------------------------------------------------------------
    # Main optimisation loop – stop a few seconds before the deadline.
    # ------------------------------------------------------------------
    deadline = time.monotonic() + max(0.0, float(budget_s) - 3.0)

    while time.monotonic() < deadline:
        iteration += 1

        # ----- slowly increase the smoothing parameter            -----
        if iteration % 300 == 0:
            beta = min(beta * 1.2, 150.0)

        # ----- convolution and soft‑max weights --------------------
        b = np.convolve(a, a)                 # self‑convolution, length 2n‑1
        max_b = b.max()
        # soft‑max on the convolution values (shifted by max to avoid overflow)
        w = np.exp(beta * (b - max_b))
        w /= w.sum()                          # normalised weights, Σ w = 1

        # ----- gradient of the smoothed max -----------------------
        rev_a = a[::-1]
        conv = np.convolve(rev_a, w)          # length 3n‑2
        # extract the part corresponding to indices 0 … n‑1
        g = 2.0 * conv[n - 1:n - 1 + n]

        # ----- back‑tracking line search (max 5 trials) ----------
        trial_eta = eta
        for _ in range(5):
            a_candidate = a - trial_eta * g
            a_candidate = simplex_projection(a_candidate)
            cand_score = compute_score(a_candidate)
            if cand_score <= cur_score:
                break
            trial_eta *= 0.5
        else:
            # No improvement found – inject a small random jitter
            if rng.random() < 0.10:
                jitter = 0.01 * rng.normal(size=n)
                a_candidate = simplex_projection(a + jitter)
                cand_score = compute_score(a_candidate)
                if cand_score > cur_score:
                    a_candidate = a
                    cand_score = cur_score
            else:
                a_candidate = a
                cand_score = cur_score

        # ----- accept the candidate if it improves the true objective -----
        if cand_score < cur_score - 1e-12:
            a = a_candidate
            cur_score = cand_score

            if cand_score < best_score - 1e-12:
                best = a.copy()
                best_score = cand_score
                last_improve = iteration
                print(f"[Iter {iteration}]  new best score = {best_score:.6f}")

        # ----- occasional random block perturbation (exploration) -----
        if iteration % 200 == 0:
            width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
            start = int(rng.integers(0, max(1, n - width + 1)))
            factor = float(np.exp(rng.normal(0.0, 0.15)))
            block = a.copy()
            block[start:start + width] *= factor
            block = simplex_projection(block)
            block_score = compute_score(block)
            if block_score < best_score:
                best = block.copy()
                best_score = block_score
                a = block
                cur_score = block_score
                last_improve = iteration
                print(f"[Iter {iteration}]  block perturb improved best to {best_score:.6f}")

        # ----- re‑initialise after long stagnation -------------------
        if iteration - last_improve > 2000:
            # perturb the current best slightly and continue from there
            a = simplex_projection(best + 0.01 * rng.normal(size=n))
            cur_score = compute_score(a)
            last_improve = iteration
            print(f"[Iter {iteration}]  stagnation detected – re‑initialising")

    # ------------------------------------------------------------------
    # Return the best sequence found (as a plain Python list of floats).
    # ------------------------------------------------------------------
    # The values are already non‑negative and far below the clipping
    # threshold, so they are safe to feed to the official evaluator.
    return [float(x) for x in best]
