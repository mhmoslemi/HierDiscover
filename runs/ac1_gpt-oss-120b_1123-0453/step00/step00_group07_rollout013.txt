    the exact evaluation is performed; the best shape found so far is
    kept as the current “parent”.

2.  A fast local‑search that repeatedly perturbs the current best vector
    with multiplicative block changes (the same idea as the reference
    implementation) and also tries small random changes of the exponent
    p or a random permutation of the entries.  Each proposal is evaluated
    with evaluate_sequence; any improvement replaces the parent.

def make_block_perturbation(base, rng):
    """Return a cheap O(n) non‑negative perturbation of ``base``.
    A random contiguous block is multiplied by a log‑normal factor.
    With probability 0.35 the vector is averaged with its reverse
    (optional symmetry – kept for compatibility with the reference)."""
    candidate = np.asarray(base, dtype=np.float64).copy()

    # choose a width between n/200 and n/12 (at least 1)
    width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
    start = int(rng.integers(0, max(1, n - width + 1)))
