"""
Algorithm:
- Construct an initial sequence based on the continuous kernel
  a_i = (i+1)^(-0.5), which makes the self‑convolution
  approximately constant (theoretical optimum ≈π/2≈1.571).
- Search a small neighbourhood of the exponent (α) and a small
  additive offset (β) to mitigate discretisation effects.
- Keep the best candidate found.
- Perform a fast hill‑climbing greedy search with multiplicative
  block perturbations to further lower the peak of the convolution.
- Stop when the allocated budget expires and return the best sequence.
"""
import time
import numpy as np

def generate_power_sequence(n, exponent=0.5, offset=0.0):
    """Return a non‑negative sequence of length n: a_i = (i+offset)^(-exponent)."""
    # +1 to avoid division by zero if offset==0 and i==0
    idx = np.arange(n, dtype=np.float64) + offset + 1.0
    seq = idx ** (-exponent)
    return np.clip(seq, 0.0, 1000.0)

def block_perturb(seq, rng):
    """Multiplicative perturbation of a random contiguous block."""
    n = seq.size
    # block width between n//200 and n//12

Algorithm
---------

1.  Initialise a candidate using the analytic kernel
    a_i = (i+1)^(-0.5).  For this kernel the linear convolution
    a*a is (almost) constant, giving a theoretical bound
    ≈ π/2 ≈ 1.571 on the evaluation function.

2.  Sweep a tiny grid of exponents (≈0.5) and a small additive
    offset before the +1 term.  Because the problem is discrete,
    a very small deviation from the continuous optimum can improve
    the peak of the convolution.

3.  Keep the best sequence found on the grid.

4.  Perform a fast greedy hill‑climbing phase until the time
    budget expires:
        * with high probability apply a multiplicative
          perturbation to a random contiguous block;
        * occasionally apply a tiny multiplicative noise to the
          whole vector;
        * accept a candidate only if it yields a strictly lower
          evaluation score.
    Very occasional random‑restarts use a fresh power‑law seed.

5.  Return the best sequence discovered (as a plain Python list).

The method needs only O(n) memory, runs entirely with NumPy,
and respects the supplied time budget.

import numpy as np

def generate_power_sequence(n: int, exponent: float = 0.5, offset: float = 0.0) -> np.ndarray:
    """Return a non‑negative sequence a_i = (i+offset+1)^(-exponent)."""
    # i+1 avoids division by zero when offset==0.
    idx = np.arange(n, dtype=np.float64) + offset + 1.0
    seq = idx ** (-exponent)
    return np.clip(seq, 0.0, 1000.0)
