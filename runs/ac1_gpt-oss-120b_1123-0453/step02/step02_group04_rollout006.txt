The scorer evaluates  

\[
\text{score}= \frac{2\,n\;\max_k (a*a)[k]}{\Bigl(\sum_i a_i\Bigr)^2},
\qquad a_i\ge 0 .
\]

If we keep the ℓ¹‑norm fixed to \(\sqrt{2n}\) the factor \(2n/\bigl(\sum a_i\bigr)^2\) becomes 1 and the score is exactly the worst auto‑convolution value `max_b`.  
Consequently the optimisation problem is:

*fix the length `n` and the ℓ¹‑norm, minimise the maximal entry of the convolution*.

The programme below uses a **projected gradient descent** on a smooth approximation of the maximum.
The steps are:

1. **parameter choice** – several lengths (200‑1000) are tried, the best
   result over all lengths is kept.
2. **initialisation** – uniform vector with the required ℓ¹‑norm,
   optionally jittered.
3. **smooth max** – a soft‑max
   \(\displaystyle
      \phi_\alpha(b)=\frac{1}{\alpha}\log\!\sum_k e^{\alpha b_k}
   \)
   with temperature `α`.  
   Its gradient w.r.t. the convolution `b = a*a` is the soft‑max
   probabilities `w_k`.
4. **gradient of the smooth max** – using the identity  
   \(\displaystyle
      \frac{\partial (a*a)_k}{\partial a_j}=2a_{k-j}
   \)  
   we obtain  
   \(\displaystyle
      \nabla\phi_\alpha(a)=2\; (a * w)_{\,n-1\,:\,n-1+n}
   \)  
   (the slice of the full convolution of `a` and `w`).
   Convolutions are evaluated with FFTs (`O(n log n)`).
5. **projected update** – a step in the opposite gradient direction,
   clamping to non‑negative values and renormalising to the prescribed
   ℓ¹‑norm (simple scaling works because all entries stay non‑negative).
6. **schedule** – the step size decays geometrically, the temperature
   `α` is increased slowly so that the optimisation starts smooth and
   finishes with an accurate approximation of the true maximum.
7. **polishing** – after the main loop a short random‑walk hill‑climb
   explores the neighbourhood of the best vector.
8. **fallback** – if the time budget expires before any solution is found
   a cheap random‑search is executed.

All heavy work is performed with NumPy only; the algorithm respects the
1000 s budget, prints intermediate scores and finally returns a plain
Python list of floats.

Projected gradient descent with a smooth max approximation.

The algorithm works on a fixed length `n` and keeps the ℓ¹‑norm equal to
sqrt(2·n) (the normalisation used by the scorer).  At each iteration we

* compute the full auto‑convolution a*a,
* build a soft‑max weight vector w that approximates the location of the
  maximal entry,
* obtain the gradient of the smoothed maximum via another convolution
  (grad = 2 * (a * w)[n‑1 : n‑1+n]),
* take a step opposite to the gradient,
* clamp to non‑negative values and renormalise to the target ℓ¹‑norm.

The temperature of the soft‑max is increased slowly, the learning rate
is decayed, and a short random perturbation phase is executed after each
length.  The best sequence over several lengths (200 … 1000) is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: evaluate a candidate sequence with the provided scorer.
# ----------------------------------------------------------------------
def _score(seq: np.ndarray) -> float:
    """Return the objective value for ``seq`` (list or ndarray)."""
    # ``evaluate_sequence`` is assumed to be available in the global scope.
    return float(evaluate_sequence(seq.tolist()))


# ----------------------------------------------------------------------
# Full convolution using FFT (real inputs, real output).
# ----------------------------------------------------------------------
def _full_convolve_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Return the full discrete convolution of 1‑D arrays ``a`` and ``b``.
    FFT based O(N log N) implementation, safe for lengths up to a few
    thousand.
    """
    n = a.shape[0] + b.shape[0] - 1
    # next power of two for efficient FFT
    m = 1 << ((n - 1).bit_length())
    A = np.fft.rfft(a, n=m)
    B = np.fft.rfft(b, n=m)
    C = A * B
    conv = np.fft.irfft(C, n=m)[:n]
    return conv


# ----------------------------------------------------------------------
# Simple random‑search fallback (used when everything else fails).
# ----------------------------------------------------------------------
def _fallback_random_search(budget_s: float, seed: int = 0):
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + budget_s
    # start with a uniform vector of length 256 (a safe default)
    n = 256
    target_sum = math.sqrt(2.0 * n)
    seq = np.full(n, target_sum / n, dtype=np.float64)
    best_seq = seq.copy()
    best_score = _score(seq)

    while time.monotonic() < deadline:
        cand = seq + rng.normal(scale=0.01 * target_sum, size=n)
        cand = np.clip(cand, 0.0, 1000.0)
        cand_sum = np.sum(cand)
        if cand_sum > 1e-12:
            cand = cand * (target_sum / cand_sum)
        sc = _score(cand)
        if sc < best_score:
            best_score = sc
            best_seq = cand.copy()
            seq = cand
    print("[fallback] best score =", best_score)
    return best_seq, best_score


# ----------------------------------------------------------------------
# Main entry point required by the judging system.
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: float = 1000.0, **kwargs):
    """
    Return a list of non‑negative heights with a low evaluation score.

    The routine runs a projected gradient descent on several problem sizes,
    gradually increases the soft‑max temperature and decays the learning
    rate.  After the optimisation a short random walk is performed to polish
    the best solution.
    """
    rng = np.random.default_rng(seed)
    start_time = time.monotonic()
    # Small safety margin so we can finish cleanly.
    deadline = start_time + max(0.0, float(budget_s) - 0.5)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # If a sequence has been supplied by the harness, use it as a warm‑start.
    # ------------------------------------------------------------------
    try:
        init_seq = np.array(height_sequence_1, dtype=np.float64)
        if init_seq.ndim == 1 and init_seq.size > 0:
            # normalise to the target ℓ¹‑norm for its length
            n0 = init_seq.shape[0]
            target0 = math.sqrt(2.0 * n0)
            sum0 = np.sum(init_seq)
            if sum0 > 1e-12:
                init_seq = init_seq * (target0 / sum0)
            init_score = _score(init_seq)
            best_seq = init_seq.copy()
            best_score = init_score
            print("[init] using provided height_sequence_1, score =", init_score)
    except Exception:
        pass  # no usable external init

    # ------------------------------------------------------------------
    # Lengths we will try – larger n gives more freedom but also a larger
    # optimisation problem.  The list balances quality and runtime.
    # ------------------------------------------------------------------
    lengths = [200, 300, 400, 500, 600, 800, 1000]

    for n in lengths:
        if time.monotonic() >= deadline:
            break

        target_sum = math.sqrt(2.0 * n)      # ℓ¹‑norm that makes the score = max_b

        # --------------------------------------------------------------
        # Initial vector for the current length.
        # --------------------------------------------------------------
        if best_seq is not None and best_seq.shape[0] == n:
            f = best_seq.copy()
            cur = np.sum(f)
            if cur > 1e-12:
                f = f * (target_sum / cur)
        else:
            # embed a shorter best sequence (if any) or start uniform + jitter
            if best_seq is not None and best_seq.shape[0] < n:
                f = np.zeros(n, dtype=np.float64)
                f[:best_seq.shape[0]] = best_seq
                cur = np.sum(f)
                if cur > 1e-12:
                    f = f * (target_sum / cur)
                else:
                    f = rng.random(n)
                    f = f / np.sum(f) * target_sum
            else:
                f = np.full(n, target_sum / n, dtype=np.float64)  # uniform
                # small random jitter to break symmetry
                f += rng.normal(scale=0.01 * target_sum, size=n)
                f = np.clip(f, 0.0, None)
                s = np.sum(f)
                if s > 1e-12:
                    f = f * (target_sum / s)

        # --------------------------------------------------------------
        # Gradient‑descent parameters (they are generous but safe).
        # --------------------------------------------------------------
        max_iters = 20000                # hard upper bound, will be cut by time
        lr = 0.6                         # initial learning rate
        lr_decay = 0.9995                # geometric decay
        alpha = 5.0                      # initial soft‑max temperature
        alpha_inc = 0.015                # increase per iteration (slow)

        for it in range(max_iters):
            if time.monotonic() >= deadline:
                break

            # ----- 1) full auto‑convolution (a * a) -----
            conv_ff = _full_convolve_fft(f, f)          # length 2n‑1

            # ----- 2) soft‑max weights -----
            # stable soft‑max
            scaled = alpha * conv_ff
            c = np.max(scaled)
            exp_vals = np.exp(scaled - c)
            w = exp_vals / np.sum(exp_vals)            # sum(w)=1

            # ----- 3) gradient = 2 * (a * w)[n‑1 : n‑1+n] -----
            conv_fw = _full_convolve_fft(f, w)         # length 3n‑2
            grad = 2.0 * conv_fw[n - 1 : n - 1 + n]

            # ----- 4) projected gradient step -----
            f_new = f - lr * grad
            f_new = np.maximum(f_new, 0.0)               # non‑negative
            s = np.sum(f_new)
            if s < 1e-12:
                # numerical collapse – restart randomly
                f_new = rng.random(n)
                f_new = f_new / np.sum(f_new) * target_sum
            else:
                f_new = f_new * (target_sum / s)        # enforce ℓ¹‑norm

            f = f_new

            # ----- 5) occasional evaluation -----
            if it % 7 == 0:
                sc = _score(f.tolist())
                if sc < best_score:
                    best_score = sc
                    best_seq = f.copy()
                    print(f"[grad] n={n:4d} it={it:5d} lr={lr:.4f} α={alpha:.2f} score={sc:.6f}")
                # early stop if we already passed the target
                if best_score < 1.503:
                    break

            # ----- 6) update hyper‑parameters -----
            lr *= lr_decay
            alpha = min(80.0, alpha + alpha_inc)

        # ------------------------------------------------------------------
        # Short random‑perturbation hill‑climb to polish the best sequence.
        # ------------------------------------------------------------------
        if best_seq is None:
            continue
        n_best = best_seq.shape[0]
        for _ in range(300):
            if time.monotonic() >= deadline:
                break
            cand = best_seq + rng.normal(scale=0.004 * target_sum, size=n_best)
            cand = np.clip(cand, 0.0, 1000.0)
            s = np.sum(cand)
            if s > 1e-12:
                cand = cand * (target_sum / s)
            else:
                continue
            sc = _score(cand.tolist())
            if sc < best_score:
                best_score = sc
                best_seq = cand.copy()
                print(f"[perturb] n={n_best} score={sc:.6f}")
                if best_score < 1.503:
                    break

    # ------------------------------------------------------------------
    # Fallback – extremely unlikely to be needed, but guarantees a result.
    # ------------------------------------------------------------------
    if best_seq is None:
        remaining = max(0.0, float(budget_s) - (time.monotonic() - start_time))
        fallback_seq, fallback_score = _fallback_random_search(remaining, seed=seed)
        best_seq = fallback_seq
        best_score = fallback_score

    print("[final] best score =", best_score, "length =", best_seq.shape[0])
    # Return a plain Python list as required by the judging system.
    return [float(x) for x in best_seq]
