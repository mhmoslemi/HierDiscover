assistantfinal**Solution Overview**

The evaluation function only depends on the *maximum* entry of the auto‑convolution
`c = a * a` because the ℓ¹‑norm is fixed to `√(2·n)`.  
Therefore we need a non‑negative vector `a` (length `n`) with

```
sum(a) = √(2·n)          (normalisation)
max( a * a )   →  minimum
```

The new search routine works with a **smooth approximation** of the max‑operator,
optimises the resulting objective by **projected gradient descent**, and
occasionally adds random jitter to escape plateaus.  

*Soft‑max surrogate*  

```
fβ(a) =  (1/β)·log( Σk exp( β·c[k] ) ) ,   c = a*a
```

As β → ∞, `fβ(a) → max(c)`.  Its gradient is easily obtained because

```
∂c[k]/∂a[j] = 2·a[k‑j]   (a out‑of‑range ⇒ 0)
```

Hence, for the weight vector

```
w[k] = exp(β·c[k]) / Σℓ exp(β·c[ℓ])
```

the (sub)gradient of `fβ` is

```
g[j] = 2· Σk w[k]·a[k‑j]   = 2· ( w  ⊛  a_rev )[j+n‑1] ,
```

where `a_rev = a[::-1]` and `⊛` denotes convolution.
Both the convolution `c` and the gradient can be computed with a single FFT,
so each iteration costs `O(n log n)`.

**Algorithm sketch**

1. Choose a set of lengths `n` (larger `n` give a better theoretical bound).
2. For each length start several *random restarts*:
   * initialise `a` (uniform random, or an expanded version of the current best).
   * run projected gradient descent  
     – increase β from a small value to a moderate one (≈ 10)  
     – decay the step size  
     – after each update clip to `[0,1000]` and renormalise to the required ℓ¹‑norm.
   * keep the best vector of this restart.
3. Keep the globally best vector over all lengths.
4. Return the best vector as a plain Python list.

The routine respects the 1000 s budget, prints progress, and is completely
self‑contained (no external LP solver is required).

"""
projected‑gradient search for a step‑function with minimal max auto‑convolution.

The code builds a smooth approximation of the max‑operator (soft‑max) and
optimises it with projected gradient descent.  Convolutions and gradients are
computed by FFT, so a single iteration costs O(n log n).  Several lengths and
random restarts are tried until the time budget (≈ 1000 s) expires.  The best
sequence found (non‑negative, ℓ¹‑norm = √(2·n)) is returned as a list of floats.
"""

import time
import math
import numpy as np


# ----------------------------------------------------------------------
# FFT‑based convolution utilities
# ----------------------------------------------------------------------


def _fft_size(length):
    """next power of two ≥ length."""
    return 1 << (length - 1).bit_length()


def full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full discrete convolution of x and y using FFT (real inputs)."""
    size = _fft_size(x.size + y.size - 1)
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)[: x.size + y.size - 1]
    # numerical noise may create tiny negatives – clip
    return np.maximum(conv, 0.0)


def auto_convolution_fft(a: np.ndarray) -> np.ndarray:
    """Return a*a (full convolution) using FFT."""
    return full_convolution_fft(a, a)


def max_auto_convolution(a: np.ndarray) -> float:
    """Maximum entry of a*a (fast, using FFT)."""
    conv = auto_convolution_fft(a)
    return float(conv.max())


# ----------------------------------------------------------------------
# Gradient descent with soft‑max surrogate
# ----------------------------------------------------------------------


def _softmax_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """Soft‑max weights for a given convolution vector."""
    # shift by the maximum to avoid overflow
    max_val = conv.max()
    shifted = conv - max_val
    # exp may under‑flow → use np.exp safely
    exp_vals = np.exp(beta * shifted)
    total = exp_vals.sum()
    if total == 0.0:  # completely under‑flowed – fall back to uniform
        return np.full_like(conv, 1.0 / conv.size)
    return exp_vals / total


def _gradient(a: np.ndarray, weights: np.ndarray) -> np.ndarray:
    """
    Gradient of the soft‑max objective.
    g = 2 * (weights ⊛ a_rev)[n‑1 : n‑1+n]
    """
    n = a.size
    a_rev = a[::-1]
    grad_full = full_convolution_fft(weights, a_rev)
    # extract the central n entries
    return 2.0 * grad_full[n - 1 : n - 1 + n]


def _project_onto_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of a non‑negative vector onto the simplex
    {x ≥ 0, sum(x)=target_sum}.  The classic O(n log n) algorithm is used.
    """
    if v.ndim != 1:
        raise ValueError("v must be one‑dimensional")
    # clip negative values first, they will stay zero after projection
    v = np.clip(v, 0.0, None)
    if v.sum() == 0.0:
        # uniform fill if everything is zero
        return np.full_like(v, target_sum / v.size)

    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(len(v)) + 1
    # find the rho index
    cond = u - cssv / ind > 0
    if not np.any(cond):
        tau = 0.0
    else:
        rho = ind[cond].max() - 1
        tau = cssv[rho] / (rho + 1)
    w = np.maximum(v - tau, 0.0)
    # tiny numerical errors may shift sum slightly – renormalise
    s = w.sum()
    if s > 0:
        w *= target_sum / s
    else:
        w = np.full_like(v, target_sum / v.size)
    return w


def gradient_descent(
    a0: np.ndarray,
    target_sum: float,
    deadline: float,
    rng: np.random.Generator,
    max_iters: int = 5000,
) -> tuple[np.ndarray, float]:
    """
    Projected gradient descent on the soft‑max surrogate.
    Returns the best vector seen and its max auto‑convolution.
    """
    n = a0.size
    a = a0.copy()
    best_a = a.copy()
    best_val = max_auto_convolution(a)

    # schedule parameters
    beta_start = 0.5
    beta_end = 10.0
    step_start = 2.0 * math.sqrt(2.0 / n)   # ≈ 2·average entry
    step_end = 0.1 * step_start

    for it in range(max_iters):
        if time.monotonic() >= deadline:
            break

        # --- current objective -------------------------------------------------
        conv = auto_convolution_fft(a)
        cur_max = float(conv.max())
        if cur_max < best_val - 1e-12:
            best_val = cur_max
            best_a = a.copy()
            print(f"[GD] n={n} iter={it} new best max={best_val:.6f}")

        # --- soft‑max weights --------------------------------------------------
        frac = it / max_iters
        beta = beta_start + frac * (beta_end - beta_start)
        w = _softmax_weights(conv, beta)

        # --- gradient ---------------------------------------------------------
        g = _gradient(a, w)

        # --- step size --------------------------------------------------------
        step = step_start + frac * (step_end - step_start)

        # --- projected update --------------------------------------------------
        a_new = a - step * g
        a_new = np.clip(a_new, 0.0, 1000.0)
        a_new = _project_onto_simplex(a_new, target_sum)

        a = a_new

        # occasional tiny random jitter to help escape plateaus
        if (it + 1) % 400 == 0:
            jitter = rng.normal(scale=target_sum * 0.001, size=n)
            a = np.clip(a + jitter, 0.0, 1000.0)
            a = _project_onto_simplex(a, target_sum)

    final_max = max_auto_convolution(best_a)
    return best_a, final_max


# ----------------------------------------------------------------------
# Helpers for changing the length of a sequence
# ----------------------------------------------------------------------


def expand_sequence(seq: np.ndarray, new_len: int) -> np.ndarray:
    """
    Stretch an existing sequence to a longer length by nearest‑index mapping
    and renormalise to the ℓ¹‑norm √(2·new_len).
    """
    old_len = seq.size
    out = np.zeros(new_len, dtype=np.float64)
    for i, val in enumerate(seq):
        idx = int(i * new_len / old_len)
        if idx >= new_len:
            idx = new_len - 1
        out[idx] += val
    total = out.sum()
    if total > 0.0:
        out *= math.sqrt(2.0 * new_len) / total
    return out


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: float = 1100, **kwargs) -> list:
    """
    Search for a step‑function with a low evaluation score.
    The routine respects the 1000 s limit (≈ budget_s‑2 s for safety)
    and returns the best sequence found as a plain Python list.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 2.0)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Use the previously‑found construction as a warm‑start if available.
    # ------------------------------------------------------------------
    try:
        init = np.asarray(height_sequence_1, dtype=np.float64)
        if init.ndim == 1 and init.size > 0:
            n0 = init.size
            target0 = math.sqrt(2.0 * n0)
            if init.sum() > 0.0:
                init = init * (target0 / init.sum())
                sc0 = max_auto_convolution(init)
                best_seq = init.copy()
                best_score = sc0
                print(f"[init] height_sequence_1 (n={n0}) – score={sc0:.6f}")
    except Exception:
        pass

    # ------------------------------------------------------------------
    # Lengths to explore – bigger n gives a better theoretical bound.
    # ------------------------------------------------------------------
    lengths = [200, 300, 400, 600, 800, 1000]

    # ------------------------------------------------------------------
    # Main outer loop over lengths.
    # ------------------------------------------------------------------
    for n in lengths:
        if time.monotonic() >= deadline:
            break

        target_sum = math.sqrt(2.0 * n)

        # Decide how many restarts we can afford for this length.
        # Roughly equal time per length.
        restarts = 0
        max_restarts = 30
        while time.monotonic() < deadline and restarts < max_restarts:
            restarts += 1

            # ------------------------------------------------------------------
            # Starting point – either a fresh random vector or an enlarged copy
            # of the global best found so far.
            # ------------------------------------------------------------------
            if best_seq is not None and best_seq.size < n and rng.random() < 0.6:
                a0 = expand_sequence(best_seq, n)
            else:
                a0 = rng.random(n)
                a0 = a0 / a0.sum() * target_sum

            # ------------------------------------------------------------------
            # Gradient descent optimisation
            # ------------------------------------------------------------------
            a_opt, max_val = gradient_descent(
                a0,
                target_sum,
                deadline,
                rng,
                max_iters=5000,
            )

            # ------------------------------------------------------------------
            # Record global best
            # ------------------------------------------------------------------
            if max_val < best_score - 1e-12:
                best_score = max_val
                best_seq = a_opt.copy()
                print(
                    f"[global] n={n} restart={restarts} "
                    f"new best score={best_score:.6f}"
                )
                if best_score < 1.503:
                    print("[stop] target bound reached")
                    break

        # early exit if target already achieved
        if best_score < 1.503:
            break

    # ------------------------------------------------------------------
    # Fallback – should never be needed, but guarantees a return.
    # ------------------------------------------------------------------
    if best_seq is None:
        n = 200
        target = math.sqrt(2.0 * n)
        best_seq = np.full(n, target / n, dtype=np.float64)
        best_score = max_auto_convolution(best_seq)
        print("[fallback] uniform sequence used, score=", best_score)

    # Convert to a plain Python list of floats.
    return [float(x) for x in best_seq]
