Optimiser for the auto‑convolution bound.

The algorithm works in three stages inside the 1000‑second budget.

1️⃣  LP‑based refinement (the idea from the reference solution):
    - Keep the ℓ¹‑norm fixed to √(2·n) so the evaluation reduces to the
      worst value of the auto‑convolution.
    - For a current vector f compute M = max(f*f).
    - Solve the linear programme   maximise Σ g_i   s.t.   (f*g)_k ≤ M  (∀k),
      g_i ≥ 0.
    - Rescale g to the same ℓ¹‑norm and mix it with f.
      A small line‑search over a few mixing weights {0,0.1,0.25,0.5,0.75,1}
      is used to obtain the best reduction of M.
    - The process is repeated for several lengths (400‑800) and a few
      random restarts.  The best sequence ever seen is kept.

2️⃣  Greedy “max‑peak” reduction:
    - Re‑compute the convolution, locate the index k* of the current
      maximum and the contribution a_i·a_{k*‑i} of each coefficient.
    - Move a small fraction of the mass from an index with a large
      contribution to an index with a small contribution.
    - Accept only if the overall maximum decreases.  This directly
      attacks the active peak and can push the bound below the LP
      optimum.

3️⃣  Final stochastic polishing:
    - Simple Gaussian perturbations with an exponentially decaying step

def _conv_matrix(f: np.ndarray) -> np.ndarray:
    """Build the (2·n‑1) × n matrix A with (A @ g)[k] = (f * g)[k]."""
    n = f.shape[0]
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    for k in range(rows):
        i_start = max(0, k - (n - 1))
        i_end = min(k, n - 1)
        for i in range(i_start, i_end + 1):
            col = k - i
            A[k, col] = f[i]
    return A


def _score(seq: np.ndarray) -> float:
    """Thin wrapper around the provided evaluate_sequence."""
    return float(evaluate_sequence(seq.tolist()))
