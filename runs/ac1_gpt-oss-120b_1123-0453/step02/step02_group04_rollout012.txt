def compute_score(seq):
    seq = np.asarray(seq, dtype=np.float64)
    n = seq.size
    s = np.sum(seq)
    if s < 1e-12:
        return np.inf
    conv = np.convolve(seq, seq)
    max_b = np.max(conv)
    return float(2.0 * n * max_b / (s * s))

"""
search for a low‑value non‑negative step sequence.

The algorithm is a simple yet effective stochastic descent that works
directly on the quantity that the scorer returns:

        score(a) = 2·n·max(a*a) / (sum(a)^2)

Because the score is scale‑invariant we keep the ℓ¹‑norm fixed to
√(2·n) for each problem size n.  For a given n we repeatedly:

1. compute the full auto‑convolution,
2. locate the index k with the largest convolution value,
3. compute the contribution a[i]·a[k−i] of every entry to that maximum,
4. move a small amount of mass from the entry that contributes the most
   to a low‑impact entry (chosen near the ends of the array, where it
   participates in few diagonals),
5. accept the move only if the score improves; otherwise shrink the
   step size.

Occasional Gaussian perturbations are applied to escape plateaus.
The procedure is executed for several lengths (200 … 1000); the best
sequence over all lengths is returned.  All operations are pure NumPy,
so the implementation runs comfortably within the 1000 s budget.
"""

import math

    n = a.shape[0]
    s = np.sum(a)
    if s < 1e-12:
        return float("inf")
    conv = np.convolve(a, a)
    return float(2.0 * n * np.max(conv) / (s * s))
