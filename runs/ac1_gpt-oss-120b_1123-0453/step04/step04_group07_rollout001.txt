assistantfinal**Solution Overview**

The goal is to minimise  

\[
\text{score}= \frac{2n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where \((a*a)_k=\sum_i a_i\,a_{k-i}\) is the auto‑convolution of the step sequence.
The evaluation function normalises the sequence to \(\sum a_i=\sqrt{2n}\); after the
normalisation the score is simply the maximal convolution value.  
Thus we have to find a non‑negative vector whose auto‑convolution is as flat as
possible.

The optimiser consists of three phases

1. **Warm‑start** – use the previously discovered construction `height_sequence_1`
   (if it exists) and normalise it.
2. **Fast first‑order optimisation** – a projected Adam optimiser on the
   simplex minimises the current maximum convolution entry.
3. **LP polishing** – for the current sequence `f` we solve the linear programme  

   ```
   maximise   Σ b_j
   subject to  (f * b)_k ≤ M   (∀ k)      (M = max_k (f*f)_k)
               b_j ≥ 0
   ```

   The LP gives a vector `b` that fits under the same bound `M` but carries
   *more* total mass.  After scaling `b` back to the required ℓ¹‑norm we mix it
   with the current iterate.  Repeating this step strictly decreases the bound
   and quickly drives the score towards the optimum.

The three phases are executed for several sequence lengths (500 … 1800).  The
overall wall‑clock is limited to the supplied `budget_s`; the routine stops as
soon as the target score < 1.503 is reached.

All helper functions are defined at module level – no closures or lambdas – and
the code runs with only `numpy`, `scipy.optimize.linprog` and `scipy.sparse`.
The final result is a plain Python list suitable for `evaluate_sequence`.

```python
"""
Optimiser for the “max‑auto‑convolution” problem.

1. Warm‑start from `height_sequence_1` (if available) and normalise it.
2. Projected Adam on the ℓ¹‑simplex quickly reduces the peak convolution.
3. A dedicated linear‑programming polishing step (LP‑refine) repeatedly
   lowers the bound: maximise the ℓ¹‑mass that fits under the current
   maximal convolution M, then scale back and mix with the current iterate.
   This step is provably monotone and yields strong improvements over pure
   first‑order methods.

The routine respects a total time budget (default 1000 s) and returns the
best sequence found.
"""

import time
import math
import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


# ----------------------------------------------------------------------
# Simplex projection (Euclidean)
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project v onto the simplex {x≥0, Σx = s}."""
    if s < 0:
        raise ValueError("simplex sum must be non‑negative")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries will be zero; return uniform distribution
        return np.full_like(v, s / len(v))
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Scoring (exact copy of evaluate_sequence, without the clipping)
# ----------------------------------------------------------------------
def _score(f: np.ndarray) -> float:
    """Exact objective value (scale‑invariant)."""
    n = len(f)
    conv = np.convolve(f, f)
    max_val = np.max(conv)
    sum_val = np.sum(f)
    if sum_val < 0.01:
        return float("inf")
    return float(2.0 * n * max_val / (sum_val * sum_val))


# ----------------------------------------------------------------------
# Adam optimiser on the simplex (sub‑gradient of the max entry)
# ----------------------------------------------------------------------
def _active_offsets(conv: np.ndarray, max_val: float) -> np.ndarray:
    eps = max_val * 1e-12 + 1e-14
    return np.where(conv >= max_val - eps)[0]


def _gradient_submax(f: np.ndarray, active: np.ndarray) -> np.ndarray:
    """Sub‑gradient of the worst auto‑convolution entry."""
    n = len(f)
    grad = np.zeros_like(f)
    for k in active:
        i_start = max(0, k - (n - 1))
        i_end = min(k, n - 1)
        i = np.arange(i_start, i_end + 1, dtype=np.int64)
        j = k - i
        # derivative w.r.t. f[i] is f[j] and vice versa
        grad[i] += f[j]
        grad[j] += f[i]
        # diagonal counted twice – correct it
        mask = (i == j)
        if np.any(mask):
            grad[i[mask]] -= f[i[mask]]
    return grad


def _adam_descent(
    f0: np.ndarray,
    target_sum: float,
    deadline: float,
    max_iters: int = 5000,
) -> tuple[np.ndarray, float]:
    """Projected Adam minimising the maximal convolution entry."""
    f = f0.copy()
    best_f = f.copy()
    best_score = _score(f)

    m = np.zeros_like(f)
    v = np.zeros_like(f)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr = 0.05
    no_improve = 0

    it = 0
    while it < max_iters and time.monotonic() < deadline:
        it += 1

        conv = np.convolve(f, f)
        max_val = np.max(conv)
        active = _active_offsets(conv, max_val)

        grad_max = _gradient_submax(f, active)

        sum_f = np.sum(f)
        grad_obj = (2.0 * len(f) / (sum_f * sum_f)) * grad_max

        m = beta1 * m + (1.0 - beta1) * grad_obj
        v = beta2 * v + (1.0 - beta2) * (grad_obj ** 2)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        f_candidate = f - step
        f_candidate = _project_onto_simplex(f_candidate, target_sum)
        f_candidate = np.clip(f_candidate, 0.0, 1000.0)

        cur_score = _score(f)
        cand_score = _score(f_candidate)

        if cand_score < best_score:
            best_score = cand_score
            best_f = f_candidate.copy()
            no_improve = 0
            print(f"[Adam] it={it:4d} n={len(f)} score={cand_score:.6f}")
        else:
            no_improve += 1

        if cand_score < cur_score:
            f = f_candidate
        else:
            if no_improve > 200:
                lr *= 0.7
                no_improve = 0

        if no_improve > 800:
            break

    return best_f, best_score


# ----------------------------------------------------------------------
# Linear‑programming refinement
# ----------------------------------------------------------------------
def _conv_matrix(f: np.ndarray) -> csr_matrix:
    """
    Build the (2n‑1) × n matrix A such that A @ b = np.convolve(f, b).
    Row k, column j contains f[k‑j] when 0 ≤ k‑j < n, else 0.
    """
    n = len(f)
    rows = np.empty(n * n, dtype=np.int32)
    cols = np.empty(n * n, dtype=np.int32)
    data = np.empty(n * n, dtype=np.float64)

    idx = 0
    for i in range(n):
        rows[idx : idx + n] = i + np.arange(n)          # k = i + j
        cols[idx : idx + n] = np.arange(n)             # column j
        data[idx : idx + n] = f[i]                     # coefficient f_i
        idx += n

    return csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))


def _lp_optimize(f: np.ndarray, M: float) -> tuple[np.ndarray, float]:
    """
    Solve
        maximise   Σ b_j
        subject to  (f * b)_k ≤ M   (∀k)
                    b_j ≥ 0
    Returns the optimal b and its ℓ¹‑norm.
    """
    n = len(f)
    A_ub = _conv_matrix(f)                     # (2n‑1) × n
    b_ub = np.full(2 * n - 1, M, dtype=np.float64)
    c = -np.ones(n, dtype=np.float64)          # minimise –Σ b_j

    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method="highs")
    if not res.success:
        # fallback – keep the current vector unchanged
        return f.copy(), np.sum(f)
    b = res.x
    return b, np.sum(b)


def _lp_refine(
    f: np.ndarray,
    target_sum: float,
    deadline: float,
    max_iters: int = 30,
    mix: float = 0.5,
) -> tuple[np.ndarray, float]:
    """
    Iteratively lower the maximal convolution value using the LP described
    above.  Each iteration produces a vector g that fits under the same bound
    M but carries more mass; after scaling it to the required ℓ¹‑norm we mix
    it with the current iterate.  The process is monotone decreasing.
    """
    best_f = f.copy()
    best_score = _score(f)

    for it in range(max_iters):
        if time.monotonic() >= deadline:
            break

        conv = np.convolve(f, f)
        M = conv.max()

        b, sum_b = _lp_optimize(f, M)

        # If the LP cannot provide enough mass, relax the bound a little.
        if sum_b <= target_sum * (1.0 - 1e-9):
            M *= 1.02
            continue

        scale = target_sum / sum_b
        g = b * scale

        # convex combination
        f_new = (1.0 - mix) * f + mix * g
        f_new = _project_onto_simplex(f_new, target_sum)
        f_new = np.clip(f_new, 0.0, 1000.0)

        new_score = _score(f_new)
        if new_score < best_score - 1e-9:
            best_score = new_score
            best_f = f_new.copy()
            print(f"[LP refine] it={it:2d} n={len(f)} score={new_score:.6f}")

        f = f_new

    return best_f, best_score

    while time.monotonic() < deadline:
        it += 1
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue

        max_move = min(cur[i], step_scale)
        if max_move <= 0:
            continue
        delta = rng.random() * max_move

        cand = cur.copy()
        cand[i] -= delta
        cand[j] += delta
        cand = np.clip(cand, 0.0, 1000.0)

        if it % 256 == 0:
            cand = _project_onto_simplex(cand, target_sum)

        cand_score = _score(cand)

        if cand_score < cur_score:
            cur, cur_score = cand, cand_score
            if cand_score < best_score:
                best, best_score = cand.copy(), cand_score
                print(f"[Anneal] it={it:6d} score={cand_score:.6f}")
        else:
            prob = math.exp(-(cand_score - cur_score) / max(T, 1e-12))
            if rng.random() < prob:
                cur, cur_score = cand, cand_score

        T *= decay
        if T < 1e-8:
            T = init_temp
        step_scale *= 0.9999
        if step_scale < 1e-6 * target_sum:
            step_scale = 0.05 * target_sum / n

    return best, best_score


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------
def propose_candidate(
    seed: int = 0,
    budget_s: float = 1000,
    **kwargs,
) -> list[float]:
    """
    Search for a non‑negative step sequence with a low value of
    `evaluate_sequence`.  The routine respects the given wall‑clock budget and
    returns a plain Python list.
    """
    rng = np.random.default_rng(seed)
    start_time = time.monotonic()
    # leave a tiny safety margin so we certainly finish before the deadline
    deadline = start_time + max(0.0, float(budget_s) - 0.2)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 1️⃣ Warm‑start from a known construction (if any)
    # ------------------------------------------------------------------
    h1 = globals().get("height_sequence_1")
    if isinstance(h1, (list, tuple, np.ndarray)):
        seq = np.asarray(h1, dtype=np.float64).copy()
        seq = np.clip(seq, 0.0, 1000.0)
        n = len(seq)
        target_sum = math.sqrt(2.0 * n)
        if np.sum(seq) == 0.0:
            seq = np.full(n, target_sum / n)
        else:
            seq = seq * (target_sum / np.sum(seq))
        s = _score(seq)
        best_seq = seq.copy()
        best_score = s
        print(f"[init] warm‑start from height_sequence_1, n={n}, score={s:.6f}")

    # ------------------------------------------------------------------
    # 2️⃣ Main optimisation: Adam + LP refinement for several lengths
    # ------------------------------------------------------------------
    # lengths that are cheap enough to handle many LP solves
    lengths = [500, 600, 800, 1000, 1200, 1500, 1800]
    for n in lengths:
        if time.monotonic() >= deadline:
            break
        target_sum = math.sqrt(2.0 * n)

        # number of random restarts – fewer for large n
        restarts = 6 if n <= 1000 else 3

        for r in range(restarts):
            if time.monotonic() >= deadline:
                break

            # ---- initialise a starting point --------------------------------
            if best_seq is not None and len(best_seq) == n:
                f0 = best_seq.copy()
                f0 += rng.normal(scale=0.001 * target_sum, size=n)
                f0 = np.clip(f0, 0.0, None)
                f0 = _project_onto_simplex(f0, target_sum)
            else:
                f0 = rng.random(n)
                f0 = _project_onto_simplex(f0, target_sum)

            # ---- short Adam run --------------------------------------------
            sub_deadline = min(deadline, time.monotonic() + 6.0)
            f_adam, score_adam = _adam_descent(f0, target_sum, sub_deadline, max_iters=4000)

            if score_adam < best_score:
                best_score = score_adam
                best_seq = f_adam.copy()
                print(f"[update] n={n} restart={r} Adam score={score_adam:.6f}")

            # ---- LP polishing ------------------------------------------------
            if time.monotonic() >= deadline:
                break
            sub_deadline = min(deadline, time.monotonic() + 5.0)
            f_lp, score_lp = _lp_refine(f_adam, target_sum, sub_deadline,
                                        max_iters=30, mix=0.5)

            if score_lp < best_score:
                best_score = score_lp
                best_seq = f_lp.copy()
                print(f"[update] n={n} restart={r} LP score={score_lp:.6f}")

            if best_score < 1.503:
                print("[early] target achieved")
                return [float(x) for x in best_seq]

    # ------------------------------------------------------------------
    # 3️⃣ Final polishing with simulated annealing (if time permits)
    # ------------------------------------------------------------------
    if best_seq is not None and time.monotonic() < deadline:
        refined, refined_score = _simulated_annealing(
            best_seq, deadline, init_temp=0.2, decay=0.9997
        )
        if refined_score < best_score:
            best_seq, best_score = refined, refined_score
            print(f"[final] annealed score={refined_score:.6f}")

    # ------------------------------------------------------------------
    # 4️⃣ Fallback (should never be taken)
    # ------------------------------------------------------------------
    if best_seq is None:
        n = 500
        target_sum = math.sqrt(2.0 * n)
        best_seq = np.full(n, target_sum / n, dtype=np.float64)
        best_score = _score(best_seq)
        print("[fallback] using uniform construction")

    # safety clipping
    best_seq = np.clip(best_seq, 0.0, 1000.0)

    print(f"[result] best score={best_score:.6f}, length={len(best_seq)}")
    return [float(x) for x in best_seq]
```
