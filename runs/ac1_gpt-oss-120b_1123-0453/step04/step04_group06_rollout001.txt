assistantfinal**Solution Overview**

The goal is to minimise  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where \((a*a)_k\) is the linear convolution of the non‑negative step heights.
If we keep the ℓ¹‑norm fixed to \(\sum_i a_i=\sqrt{2n}\) the denominator equals \(2n\) and  

\[
E(a)=\max_k (a*a)_k .
\]

Hence the problem becomes *“find a non‑negative vector on the simplex whose
autocorrelation has the smallest possible peak”.*

The previous implementation used a smoothed‑max gradient descent.
It often stalls because the smooth approximation spreads the gradient over
all offsets, whereas only the active (maximal) offsets really matter.

The new algorithm concentrates the optimisation on the **active set**
(maximum convolution entries) and uses a classic **projected sub‑gradient**
method:

1. **Projection onto the ℓ¹‑simplex** – guarantees the normalisation
   \(\sum a_i=\sqrt{2n}\) after every update.
2. **Active‑set gradient** – at each iteration we identify all indices
   `k` where the convolution attains its current maximum and
   compute the exact sub‑gradient of those entries only.
3. **Adaptive step size** – the step is increased when the iteration is
   successful and halved otherwise.  When progress stalls we perform a
   random “kick” to escape shallow local minima.
4. **Multiple lengths & random restarts** – we search several values of
   `n` (300 … 1000) and perform a few restarts for each length.
5. **Polishing** – after the sub‑gradient phase a short smoothed‑max
   descent (as in the reference code) and a tiny Gaussian hill‑climb are
   applied to refine the best candidate.

All heavy work is vectorised; convolution is performed via an FFT
(O(n log n)) and the gradient of a single offset is obtained by two
simple shifts, so thousands of iterations on vectors of size 1000 are
well within the 1000 s budget.

The function `propose_candidate` follows the required signature and
returns a plain Python list of non‑negative floats ready for
`evaluate_sequence`.

```python
"""
Improved optimisation for the step‑function bound.

The algorithm consists of:
1. Projected sub‑gradient descent that updates only the active (maximal)
   convolution entries.
2. Adaptive step‑size with occasional random kicks to avoid stagnation.
3. A final polishing stage (smooth‑max GD + Gaussian hill‑climb).

All vectors are kept on the ℓ¹‑simplex Σ a_i = sqrt(2·n) so that the
evaluation equals the maximal autocorrelation entry.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Simple utilities
# ----------------------------------------------------------------------


def _project_onto_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Euclidean projection of v onto {x | x_i ≥ 0, Σ x_i = s}."""
    if s < 0:
        raise ValueError("simplex sum must be non‑negative")
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are zero – return the uniform point
        return np.full_like(v, s / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _conv_linear_fft(a: np.ndarray) -> np.ndarray:
    """Linear convolution a * a computed via FFT (real input)."""
    n = a.shape[0]
    L = 1 << ((2 * n - 1).bit_length())   # next power of two
    A = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(A * A, n=L)[: 2 * n - 1]
    return conv


def _compute_score(v: np.ndarray) -> float:
    """Exact evaluation of the provided evaluate_sequence formula."""
    n = v.shape[0]
    conv = np.convolve(v, v)          # small n, direct method is fine
    max_val = np.max(conv)
    sum_val = np.sum(v)
    if sum_val < 0.01:
        return float("inf")
    return float(2.0 * n * max_val / (sum_val * sum_val))


# ----------------------------------------------------------------------
# Gradient of a single convolution offset
# ----------------------------------------------------------------------


def _grad_of_offset(a: np.ndarray, k: int) -> np.ndarray:
    """
    Gradient of (a*a)_k w.r.t. a.
    k is in [0, 2n‑2].
    """
    n = a.shape[0]
    grad = np.zeros_like(a)
    # contributions from a_i * a_{i+k}
    if k < n:
        grad[: n - k] += a[k:]          # a_i contributes a_{i+k}
        grad[k:] += a[: n - k]          # a_{i+k} contributes a_i
    else:
        # for k >= n the overlapping region mirrors the case 2n‑2‑k
        kk = 2 * n - 2 - k
        # the same code as above with kk works because conv is symmetric
        if kk < n:
            grad[: n - kk] += a[kk:]
            grad[kk:] += a[: n - kk]
    return grad


# ----------------------------------------------------------------------
# Projected sub‑gradient optimiser (active‑set)
# ----------------------------------------------------------------------


def _subgradient_optimize(
    a0: np.ndarray,
    target_sum: float,
    deadline: float,
    max_iters: int = 5000,
    step_initial: float = 0.1,
    step_factor_up: float = 1.02,
    step_factor_down: float = 0.5,
    kick_interval: int = 200,
    kick_scale: float = 0.2,
) -> tuple[np.ndarray, float]:
    """
    Sub‑gradient descent that focuses on the active (maximal) convolution
    offsets only.  Returns the best vector seen and its score.
    """
    a = a0.copy()
    best_a = a.copy()
    best_score = _compute_score(a)

    step = step_initial
    n = a.shape[0]
    rng = np.random.default_rng()

    for it in range(max_iters):
        if time.monotonic() >= deadline:
            break

        # current convolution and active set
        conv = np.convolve(a, a)
        max_val = conv.max()
        active = np.where(conv >= max_val - 1e-12)[0]

        # build gradient as the average of gradients of all active offsets
        grad = np.zeros_like(a)
        for k in active:
            grad += _grad_of_offset(a, k)
        grad /= max(1.0, float(len(active)))  # avoid division by zero

        # propose a projected step
        cand = a - step * grad
        cand = _project_onto_simplex(cand, target_sum)
        cand = np.clip(cand, 0.0, 1000.0)
        cand_score = _compute_score(cand)

        if cand_score + 1e-12 < best_score:
            # successful step – keep it and slightly increase the step size
            best_a, best_score = cand.copy(), cand_score
            a = cand
            step *= step_factor_up
        else:
            # reject – shrink the step
            step *= step_factor_down

        # occasional random kick to escape plateaus
        if (it + 1) % kick_interval == 0:
            kick = kick_scale * rng.normal(size=n)
            a_kick = a + kick
            a_kick = np.clip(a_kick, 0.0, 1000.0)
            a_kick = _project_onto_simplex(a_kick, target_sum)
            a = a_kick

        # avoid vanishing step
        if step < 1e-12:
            break

    return best_a, best_score


# ----------------------------------------------------------------------
# Smoothed‑max optimiser (kept from the reference code)
# ----------------------------------------------------------------------


def _weighted_gradient(f: np.ndarray, w: np.ndarray) -> np.ndarray:
    """Gradient of Σ_k w_k·(f*f)_k (w must sum to 1)."""
    n = f.shape[0]
    grad = np.zeros_like(f)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk == 0.0:
            continue
        i_start = max(0, k - (n - 1))
        i_end = min(k, n - 1)
        i_range = np.arange(i_start, i_end + 1)
        j_range = k - i_range
        grad[i_start : i_end + 1] += wk * 2.0 * f[j_range]
        # diagonal correction for i == j
        if (k & 1) == 0:
            i_eq = k // 2
            if i_start <= i_eq <= i_end:
                grad[i_eq] -= wk * f[i_eq]
    return grad


def _smooth_max_optimize(
    f0: np.ndarray,
    target_sum: float,
    deadline: float,
    max_iters: int = 2000,
    beta_start: float = 0.5,
    beta_factor: float = 1.5,
    beta_max: float = 256.0,
    step_initial: float = 0.5,
) -> tuple[np.ndarray, float]:
    """
    Gradient descent on a smoothed max of the auto‑convolution.
    Returns the best vector seen and its score.
    """
    f = f0.copy()
    best_f = f.copy()
    best_score = _compute_score(f)

    step = step_initial
    beta = beta_start
    no_improve = 0

    for it in range(max_iters):
        if time.monotonic() >= deadline:
            break

        conv = np.convolve(f, f)
        max_val = conv.max()

        # stable soft‑max weights
        exp_vals = np.exp(beta * (conv - max_val))
        w_sum = exp_vals.sum()
        w = exp_vals / w_sum if w_sum != 0.0 else np.full_like(conv, 1.0 / conv.size)

        grad = _weighted_gradient(f, w)

        cand = _project_onto_simplex(f - step * grad, target_sum)
        cand = np.clip(cand, 0.0, 1000.0)
        cand_score = _compute_score(cand)

        if cand_score + 1e-12 < best_score:
            best_f, best_score = cand.copy(), cand_score
            f = cand
            step *= 1.02
            no_improve = 0
        else:
            step *= 0.7
            no_improve += 1

        beta = min(beta * beta_factor, beta_max)

        if no_improve >= 200:
            beta = max(beta_start, beta / 2.0)
            no_improve = 0

        if step < 1e-12:
            break

    return best_f, best_score


def _hill_climb(
    start: np.ndarray,
    target_sum: float,
    deadline: float,
    sigma_initial: float = 0.2,
    max_iters: int = 5000,
) -> tuple[np.ndarray, float]:
    """
    Small Gaussian perturbation hill‑climbing on the simplex.
    """
    rng = np.random.default_rng()
    best = start.copy()
    best_score = _compute_score(best)
    sigma = sigma_initial

    while time.monotonic() < deadline and max_iters > 0:
        cand = best + sigma * rng.normal(size=best.shape)
        cand = np.clip(cand, 0.0, 1000.0)
        cand = _project_onto_simplex(cand, target_sum)
        cand_score = _compute_score(cand)
        if cand_score < best_score:
            best, best_score = cand, cand_score
        sigma *= 0.9995
        max_iters -= 1
        if sigma < 1e-9:
            sigma = sigma_initial
    return best, best_score

# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: float = 1000, **kwargs) -> list[float]:
    """
    Search for a low‑value step sequence within the given time budget.
    Returns a plain Python list of non‑negative floats.
    """
    rng = np.random.default_rng(seed)
    start_time = time.monotonic()
    # leave a safety margin for the external harness
    deadline = start_time + max(0.0, float(budget_s) - 0.5)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 1️⃣  Warm‑start from the previously found construction (if any)
    # ------------------------------------------------------------------
    h1 = globals().get("height_sequence_1")
    if isinstance(h1, (list, tuple, np.ndarray)):
        h1 = np.asarray(h1, dtype=np.float64)
        h1 = np.clip(h1, 0.0, 1000.0)
        n0 = len(h1)
        target0 = math.sqrt(2.0 * n0)
        if h1.sum() > 0:
            h1 = h1 * (target0 / h1.sum())
        else:
            h1 = np.full(n0, target0 / n0, dtype=np.float64)

        sc0 = _compute_score(h1)
        best_seq, best_score = h1.copy(), sc0
        print(f"[warm‑start] n={n0} score={sc0:.6f}")

    # ------------------------------------------------------------------
    # 2️⃣  Main search – multiple lengths, restarts and sub‑gradient descent
    # ------------------------------------------------------------------
    lengths = [300, 400, 500, 600, 800, 1000]
    for n in lengths:
        if time.monotonic() >= deadline:
            break
        target_sum = math.sqrt(2.0 * n)

        # number of random restarts per length (more restarts for smaller n)
        restarts = 12 if n <= 600 else 8

        for rs in range(restarts):
            if time.monotonic() >= deadline:
                break

            # initialise a starting point on the simplex
            if best_seq is not None and len(best_seq) == n:
                f0 = best_seq.copy()
            elif best_seq is not None and len(best_seq) < n:
                # pad the warm‑start with zeros and renormalise
                f0 = np.zeros(n, dtype=np.float64)
                f0[: len(best_seq)] = best_seq
                if f0.sum() > 0:
                    f0 = f0 * (target_sum / f0.sum())
                else:
                    f0 = np.full(n, target_sum / n, dtype=np.float64)
            else:
                # uniform random point on the simplex
                f0 = rng.random(n) + 1e-8
                f0 = f0 / f0.sum() * target_sum

            # -----------------------
            # Sub‑gradient phase
            # -----------------------
            sub_deadline = min(deadline, time.monotonic() + 12.0)
            f_sub, sc_sub = _subgradient_optimize(
                f0,
                target_sum,
                sub_deadline,
                max_iters=4000,
                step_initial=0.2,
                step_factor_up=1.02,
                step_factor_down=0.5,
                kick_interval=250,
                kick_scale=0.15,
            )

            if sc_sub < best_score:
                best_seq, best_score = f_sub.copy(), sc_sub
                print(f"[sub‑grad] n={n} restart={rs} score={sc_sub:.6f}")

            # -----------------------
            # Smooth‑max polishing (if time permits)
            # -----------------------
            if time.monotonic() < deadline:
                smooth_deadline = min(deadline, time.monotonic() + 6.0)
                f_smooth, sc_smooth = _smooth_max_optimize(
                    f_sub,
                    target_sum,
                    smooth_deadline,
                    max_iters=2000,
                    beta_start=0.5,
                    beta_factor=1.5,
                    beta_max=256.0,
                    step_initial=0.5,
                )
                if sc_smooth < best_score:
                    best_seq, best_score = f_smooth.copy(), sc_smooth
                    print(f"[smooth] n={n} restart={rs} score={sc_smooth:.6f}")

            # early exit if we have already passed the target bound
            if best_score < 1.503:
                print("[early‑exit] target achieved")
                deadline = time.monotonic() + 0.3
                break

    # ------------------------------------------------------------------
    # 3️⃣  Final polishing – short hill‑climbing
    # ------------------------------------------------------------------
    if best_seq is not None and time.monotonic() < deadline:
        n = len(best_seq)
        target_sum = math.sqrt(2.0 * n)
        refined, refined_sc = _hill_climb(
            best_seq,
            target_sum,
            deadline,
            sigma_initial=0.2,
            max_iters=6000,
        )
        if refined_sc < best_score:
            best_seq, best_score = refined, refined_sc
            print(f"[refine] final score={refined_sc:.6f}")

    # Safety clip – evaluate_sequence performs the same but we duplicate it
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    print(f"[result] best score={best_score:.6f}, length={len(best_seq)}")
    return [float(x) for x in best_seq]
```
