"""
Propose a step‑function sequence that minimizes the evaluation score.

Idea
----
The score returned by ``evaluate_sequence`` is

    score = 2·n·max(conv(f,f)) / (sum(f)^2)

Because the denominator is the square of the ℓ¹‑norm, scaling the whole
vector does **not** change the score.  We may therefore fix the sum to the
canonical value `√(2·n)`.  With this normalization the score equals the
maximum entry of the auto‑convolution.

For a non‑negative vector the central convolution term
``conv[n‑1] = Σ_i f[i]·f[n‑1‑i]``
is dominant.  This term is the inner product of the vector with its
reversed version.  By the rearrangement inequality it is minimised when the
entries are sorted increasingly (small values meet large ones).

A simple family of increasing vectors is
        a[i] = i^p      (i = 0,…,n‑1,  p > 0)

After normalising the ℓ¹‑norm the maximum convolution can be computed
asymptotically

    score(p) = 2·(p+1)²·B(p+1,p+1)

where `B` is the Beta function.
Even for `p = 2` the score is 0.6, far below the target 1.503; larger
exponents give still smaller scores.

The algorithm therefore:
1. Choose a length `n` (we reuse the length of the existing best
   construction if available, otherwise 500).
2. Try a few integer exponents `p = 1 … 6`.
3. For each `p` build the raw vector `i**p`, scale it so that the sum is
   `√(2·n)`, evaluate the score and keep the best one.
4. Return the best sequence as a plain Python list of floats.

All numbers are non‑negative, far below the clipping limit (1000) and the
function finishes well within the 1000‑second budget.
"""

import time
import math
import numpy as np

def propose_candidate(seed: int = 0,
                     budget_s: float = 1000,
                     **kwargs) -> list[float]:
    """Return a low‑score step‑function sequence.

    The function ignores `seed` and `kwargs`; it runs a deterministic,
    analytical construction based on power‑law increasing vectors.
    """
    start = time.monotonic()
    # leave a tiny safety margin
    deadline = start + max(0.0, float(budget_s) - 0.5)

    # ------------------------------------------------------------------
    # Determine the length of the vector.
    # Reuse the length of a previously found construction if present.
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals():
        try:
            n = int(len(height_sequence_1))
        except Exception:  # pragma: no cover
            n = 500
    else:
        n = 500

    # The ℓ¹‑norm that makes the score equal to the max‑convolution.
    target_sum = math.sqrt(2.0 * n)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Try a handful of exponents p.  Integer exponents are sufficient;
    # p = 2 already beats the target comfortably, higher p give even
    # smaller scores.
    # ------------------------------------------------------------------
    for p in range(1, 7):
        if time.monotonic() >= deadline:
            break

        # raw power‑law vector i**p (i = 0 … n‑1)
        raw = np.arange(n, dtype=np.float64) ** p

        # Scale so that the ℓ¹‑norm equals √(2·n)
        scale = target_sum / raw.sum()
        seq = raw * scale

        # Clip to the interval required by evaluate_sequence (not really
        # needed but kept for safety).
        seq = np.clip(seq, 0.0, 1000.0)

        # Evaluate – the function returns a Python float.
        score = evaluate_sequence(seq.tolist())

        print(f"[p={p}] score={score:.6f}")

        if score < best_score:
            best_score = score
            best_seq = seq.copy()

    # ------------------------------------------------------------------
    # Fallback: if something went wrong (unlikely) return a uniform vector.
    # ------------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, target_sum / n, dtype=float)
        best_score = evaluate_sequence(best_seq.tolist())
        print(f"[fallback] uniform score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Return the best sequence found as a plain Python list of floats.
    # ------------------------------------------------------------------
    return [float(x) for x in best_seq]
