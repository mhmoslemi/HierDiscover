propose_candidate
-----------------
A gradient‑descent / simulated‑annealing hybrid that attempts to flatten the
autocorrelation (self‑convolution) of a non‑negative step function.
The objective of ``evaluate_sequence`` is

    J(a) = 2·n·max(a*a) / (sum(a)^2) ,

which is homogeneous of degree 0, i.e. invariant under uniform scaling of the
vector.  The algorithm therefore works with any scale but keeps a modest sum
to stay clear of the ``evaluate_sequence`` “sum too small” guard.

Main ideas
~~~~~~~~~~
* Start from a symmetric power‑law (arcsine‑like) sequence.
* At each iteration compute the full convolution `c = a*a`.
* Approximate the non‑smooth ``max`` using a soft‑max with a temperature β.
  The gradient of the soft‑max weighted sum w.r.t. ``a`` can be written as a
  convolution, which we evaluate with `np.convolve` (O(n²) but fast for
  moderate n≈2000).
* Perform a projected gradient step:
      a ← a − η·∇J   ( η – step size )

def make_power_law(n: int, alpha: float) -> np.ndarray:

    idx = np.arange(n, dtype=np.float64)

    """

    return np.clip(cand, 0.0, 1000.0)


def weighted_grad(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Given a vector ``a`` (length n) and a weight vector ``w`` (length 2n‑1)
    that represents the soft‑max weights on the convolution entries,

    The formula simplifies to a convolution with the reversed weight vector.
    """
    n = a.size
    w_rev = w[::-1]                     # reverse the weight vector
    full = np.convolve(a, w_rev)        # length = 3n‑2
    idx = 2 * n - 2                     # the index that maps to grad[0]
    # grad[i] = full[idx - i]
    grad = full[idx - np.arange(n)]
    return grad
