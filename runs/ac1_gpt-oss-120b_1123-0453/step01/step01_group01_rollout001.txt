Propose a candidate step‑function (non‑negative vector) that minimises

    2·n·max(conv(a,a)) / (sum(a)**2)

by a projected‑gradient descent on a smooth approximation of the
max‑convolution.  The algorithm uses a soft‑max (log‑sum‑exp) surrogate
for the maximum, gradually sharpening it (β increases).  At each
iteration we

1. compute the full self‑convolution,
2. form weights w_j = exp(β·(conv_j − max(conv)))  (w_max = 1),
3. obtain the gradient of the smoothed objective as the correlation

4. take a step opposite to this gradient, add a tiny isotropic noise,
5. project the result back onto the probability simplex (non‑negative,
   sum = 1) – this guarantees that the evaluation score is simply
   `2·n·max(conv)`,
6. occasionally perform a random block‑perturbation and, if it is

The step size decays slowly, β is ramped from 1 to 30, and a simple

def proj_simplex(v: np.ndarray) -> np.ndarray:
    """Projection of a vector onto the probability simplex (sum = 1, v ≥ 0)."""
    n = v.shape[0]
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    rho = np.where(u - cssv / ind > 0)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def arcsine_sequence(n: int) -> np.ndarray:
    """Return the “arcsine’’ sequence a_i = C(2i,i) / 4^i, normalised to sum = 1."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2 * i - 1) / (2.0 * i)
    a /= a.sum()
    return a


def self_convolution(x: np.ndarray) -> np.ndarray:
    """Linear convolution of a real vector with itself (via FFT)."""
    n = x.shape[0]
    size = 2 * n - 1
    f = np.fft.rfft(x, n=size)
    conv = np.fft.irfft(f * f, n=size)
    return conv
