assistantfinal**Solution Overview**

The routine below implements a fast local‑search optimiser for the step‑function
evaluation problem.

* **Scale invariance** – the objective does not change when the whole sequence
  is multiplied by a constant.  We therefore keep the `L1`‑norm of the
  sequence equal to 1 (any positive value works) and only move mass between
  entries.

* **Gradient‑like move** – for the index `k` where the convolution is maximal
  we compute the contribution `c[i] = a[i]·a[k‑i]`.  
  The element with the largest contribution is the *donor* (it pushes the
  maximum up) and the element with the smallest contribution is the
  *receiver* (it helps to lower the maximum).  The exact effect of moving a
  quantity `Δ` from donor to receiver on the maximal convolution value can be
  expressed analytically, therefore we try several candidate `Δ` (full amount,
  half, …) and keep the one that yields the best improvement.

* **Adaptive step size** – after a successful move the step size is increased,
  otherwise it is reduced.  This gives fast early progress and fine‑grained
  adjustments later on.

* **Exploration** – with a small probability a random block perturbation
  (multiplicative log‑normal change on a contiguous block) is applied; this
  helps to escape plateaux.

* **Restarts** – if the optimiser does not improve the best score for a while
  it restarts from a fresh power‑law sequence `a[i] = (i+1)^{‑α}` with a
  slightly different exponent `α∈[0.45,0.55]`.

* **Time‑budget handling** – the loop runs until the supplied budget (default
  1000 s) is almost exhausted and finally returns the best sequence found.
  All helper functions are defined at module level, no closures are used and
  only `numpy`, `time` and the provided `evaluate_sequence` are required.

```python
"""
Fast local‑search optimiser for the step‑function evaluation problem.

The algorithm keeps a non‑negative L1‑normalised sequence `a`.  In each
iteration it:
  – computes the self‑convolution and finds the index `k_max` where the
    convolution attains its maximum;
  – evaluates the per‑element contributions `c[i] = a[i] * a[k_max-i]`;
  – selects a donor (largest contribution) and a receiver (smallest
    contribution);
  – tries a few candidate mass transfers `Δ` from donor to receiver,
    computes the objective for each candidate and keeps the best improvement;
  – adapts the step size, performs occasional random block perturbations,
    and restarts from a fresh power‑law when progress stalls.

The routine respects the 1000 s time budget and returns the best sequence
found.  All numbers are clipped to the range required by `evaluate_sequence`.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top‑level – no closures)
# ----------------------------------------------------------------------


def make_power_law(n: int, alpha: float) -> np.ndarray:
    """Return a non‑negative power‑law vector a_i = (i+1)^‑α (i=0..n‑1)."""
    idx = np.arange(n, dtype=np.float64)
    a = np.power(idx + 1.0, -alpha)
    # Clip to the safe interval also applies the “max(0,·), min(1000,·)”
    return np.clip(a, 0.0, 1000.0)


def contributions_to_max(seq: np.ndarray, k: int) -> np.ndarray:
    """
    For a given sequence `seq` (length n) and a convolution index `k`,
    return the array of contributions a[i] * a[k-i] (zero when the partner
    index is out of range).
    """
    n = seq.size
    i = np.arange(n, dtype=np.int64)
    j = k - i
    mask = (j >= 0) & (j < n)
    contrib = np.zeros_like(seq)
    contrib[mask] = seq[i[mask]] * seq[j[mask]]
    return contrib


def move_mass(seq: np.ndarray, donor: int, receiver: int, delta: float) -> np.ndarray:
    """
    Return a copy of `seq` with `delta` mass moved from `donor` to `receiver`
    (clipping to the allowed interval afterwards).
    """
    cand = seq.copy()
    cand[donor] -= delta
    cand[receiver] += delta
    # clipping enforces the same safety checks that evaluate_sequence performs
    np.clip(cand, 0.0, 1000.0, out=cand)
    return cand


def random_block_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative log‑normal perturbation on a random contiguous block,
    optionally mirrored to keep approximate symmetry.
    """
    cand = base.copy()
    n = cand.size
    # block width between n/200 and n/12 (inclusive)
    lo = max(1, n // 200)
    hi = max(lo + 1, n // 12)
    width = int(rng.integers(lo, hi + 1))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = start + width
    cand[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    if rng.random() < 0.35:                           # optional mirroring
        cand = 0.5 * (cand + cand[::-1])
    return np.clip(cand, 0.0, 1000.0)


def evaluate_fast(seq: np.ndarray) -> float:
    """
    A lightweight replica of `evaluate_sequence` that works directly on a
    NumPy array.  It follows exactly the same clipping and zero‑check rules.
    """
    # safety clipping – matches evaluate_sequence
    seq = np.clip(seq, 0.0, 1000.0)
    n = seq.size
    conv = np.convolve(seq, seq)
    max_b = conv.max()
    sum_a = seq.sum()
    if sum_a < 0.01:
        return float('inf')
    return float(2.0 * n * max_b / (sum_a * sum_a))


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: float = 1000, **kwargs):
    """
    Search for a low‑value step function within the allotted time.
    Returns a list of floats suitable for `evaluate_sequence`.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 3.0)   # tiny safety margin

    # ------------------------------------------------------------------
    # Determine working length (use the supplied construction if possible)
    # ------------------------------------------------------------------
    try:
        n = int(len(height_sequence_1))
        if n < 2:
            raise ValueError
    except Exception:
        n = 4000   # safe default for an empty environment

    # ------------------------------------------------------------------
    # Initialise: try a few power‑law exponents and keep the best start
    # ------------------------------------------------------------------
    best_seq = None
    best_score = np.inf

    for _ in range(6):
        alpha = rng.uniform(0.45, 0.55)
        cand = make_power_law(n, alpha)
        score = evaluate_fast(cand)
        if score < best_score:
            best_seq = cand
            best_score = score

    # also evaluate the historic construction if present
    try:
        hist = np.asarray(height_sequence_1, dtype=np.float64)
        if hist.ndim == 1 and hist.size > 0 and np.isfinite(hist).all():
            hist = np.clip(hist, 0.0, 1000.0)
            pscore = evaluate_fast(hist)
            if pscore < best_score:
                best_seq = hist
                best_score = pscore
    except Exception:
        pass

    if best_seq is None:
        best_seq = np.ones(n, dtype=np.float64) / n   # fallback uniform (never optimal)

    # ------------------------------------------------------------------
    # Parameters for the adaptive search
    # ------------------------------------------------------------------
    # base fraction of donor mass that we are willing to move (will be adapted)
    step_frac = 0.12
    last_improve = time.monotonic()
    iter_counter = 0
    stagnation_threshold = 30.0      # seconds without improvement before restart
    fractions = [0.05, 0.10, 0.20, 0.50, 1.0]   # candidate Δ‑fractions

    while time.monotonic() < deadline:
        iter_counter += 1

        # ------------------------------------------------------------------
        # Compute full convolution and locate the maximal entry
        # ------------------------------------------------------------------
        conv = np.convolve(best_seq, best_seq)
        k_max = int(conv.argmax())
        max_val = conv[k_max]

        # ------------------------------------------------------------------
        # Contributions of each position to the maximal convolution term
        # ------------------------------------------------------------------
        contrib = contributions_to_max(best_seq, k_max)
        donor = int(np.argmax(contrib))
        receiver = int(np.argmin(contrib))

        # safeguard against trivial donor==receiver
        if donor == receiver:
            donor = rng.integers(0, n)
            receiver = rng.integers(0, n)
            while receiver == donor:
                receiver = rng.integers(0, n)

        donor_mass = best_seq[donor]
        if donor_mass <= 0.0:
            # nothing to move – trigger a random perturbation instead
            cand = random_block_perturbation(best_seq, rng)
            cand_score = evaluate_fast(cand)
        else:
            # --------------------------------------------------------------
            # Try several Δ‑values and keep the best improvement
            # --------------------------------------------------------------
            cand = None
            cand_score = np.inf
            for f in fractions:
                delta = min(donor_mass, f * donor_mass)
                if delta <= 0.0:
                    continue
                trial = move_mass(best_seq, donor, receiver, delta)
                score = evaluate_fast(trial)
                if score < cand_score:
                    cand = trial
                    cand_score = score

        # --------------------------------------------------------------
        # Accept the best candidate if it improves the score
        # --------------------------------------------------------------
        if cand_score < best_score:
            best_seq = cand
            best_score = cand_score
            last_improve = time.monotonic()
            # increase step size modestly after a success
            step_frac = min(0.30, step_frac * 1.05)
        else:
            # no improvement – shrink step size and maybe try a random move
            step_frac = max(0.001, step_frac * 0.97)

        # --------------------------------------------------------------
        # Occasional random block perturbation (exploration)
        # --------------------------------------------------------------
        if rng.random() < 0.02:
            cand2 = random_block_perturbation(best_seq, rng)
            score2 = evaluate_fast(cand2)
            if score2 < best_score:
                best_seq = cand2
                best_score = score2
                last_improve = time.monotonic()
                step_frac = 0.12

        # --------------------------------------------------------------
        # Restart if we have been idle for too long
        # --------------------------------------------------------------
        if time.monotonic() - last_improve > stagnation_threshold:
            alpha = rng.uniform(0.45, 0.55)
            restart = make_power_law(n, alpha)
            restart_score = evaluate_fast(restart)
            if restart_score < best_score:
                best_seq = restart
                best_score = restart_score
                last_improve = time.monotonic()
                step_frac = 0.12
            else:
                # even if not better, we still give the algorithm a fresh start
                best_seq = restart
                step_frac = 0.12

        # --------------------------------------------------------------
        # Periodic status output
        # --------------------------------------------------------------
        if iter_counter % 250 == 0:
            print(f"[{time.monotonic():.1f}] iter={iter_counter}  best_score={best_score:.6f}")

        # early exit if we already beat the target bound
        if best_score < 1.503:
            print("Target bound reached – stopping early.")
            break

    # ------------------------------------------------------------------
    # Return the best sequence (as plain Python list of floats)
    # ------------------------------------------------------------------
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    print(f"Search finished – best score = {best_score:.6f} after {iter_counter} iterations.")
    return [float(x) for x in best_seq]
```
