"""
Propose a near‑optimal step‑function using projected gradient descent on the
max‑convolution objective.  The algorithm works on a symmetric sequence and
repeatedly moves mass from indices with large contribution to the current
maximal convolution towards indices with small contribution while keeping the
total L1‑norm (and hence the scale) fixed.  An adaptive step size and occasional
random block perturbations are used to escape plateaus.
"""

import time
import numpy as np

def make_power_law(n, alpha):
    idx = np.arange(n, dtype=np.float64)
    a = (idx + 1.0) ** (-alpha)
    return np.clip(a, 0.0, 1000.0)

def make_block_perturbation(base, rng):

The routine works on a symmetric (mirror‑image) sequence a of length n.
At every iteration the full autocorrelation c = a*a is computed with a
