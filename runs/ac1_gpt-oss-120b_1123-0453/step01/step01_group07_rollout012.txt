The algorithm works on a *fixed* length n (taken from the supplied
`height_sequence_1` when it exists) and optimises the shape of the
non‑negative sequence a with respect to the evaluation function

    F(a) = 2·n·max(a*a) / (∑a)² .

Because F is scale‑invariant we keep the vector normalised to unit
sum (∑a = 1) during the whole run – this makes the objective very
cheap to compute: F = 2·n·max(conv), where conv = a*a.

Main ideas
----------

* **Fast convolution** – every evaluation uses an FFT (O(n log n))
  instead of the O(n²) `np.convolve`.  With n≈6000 the FFT fits comfortably
  in the time budget and allows thousands of iterations.

* **Sub‑gradient descent on the ∞‑norm** – the objective is the maximum
  entry of the convolution.  For a given index k the gradient of
  (a*a)[k] w.r.t. a is simply `2·a_{k‑i}` (zero outside the support).
  We therefore move a in the opposite direction of the gradient of the
  *current* maximal entry.  The step size is chosen so that no component
  becomes negative and it decays like 1/√iteration.

* **Exploration** – occasionally a random “block perturbation’’ (the
  same operator that the reference code used) or a fresh random
  parametrised power‑law kernel is tried.  If the trial gives a lower
  score it becomes the new current vector; otherwise it is discarded.

* **Parameterised kernels** – a family
        a_i = (i+offset+1)^(-exponent)·(1‑α·exp(-(i+1)/L))
  is sampled (exponent≈0.5, α∈[0,1], L a decay length).  This gives the
  usual 1/√i shape with a tunable reduction of the very first entries,
  which can lower the peak of the convolution.

The loop runs until the supplied time budget (default 1000 s) is
exhausted and returns the best sequence found as a plain Python list.
All numbers are guaranteed to be non‑negative and ≤ 1000, so the

    idx = np.arange(n, dtype=np.float64) + offset + 1.0
    seq = idx ** (-exponent)
    return np.clip(seq, 0.0, 1000.0)


def generate_windowed_sequence(n: int,
                               exponent: float = 0.5,
                               offset: float = 0.0,
                               L: float = 20.0,
                               alpha: float = 0.5) -> np.ndarray:
    """
    Power‑law kernel multiplied by a smooth cut‑off:

        a_i = (i+offset+1)^(-exponent) * (1‑α·exp(-(i+1)/L))

    The factor damps the very first coefficients while leaving the tail
    virtually untouched.
    """
    i = np.arange(n, dtype=np.float64)
    base = (i + offset + 1.0) ** (-exponent)
    factor = 1.0 - alpha * np.exp(-(i + 1.0) / L)
    seq = base * factor
    return np.clip(seq, 0.0, 1000.0)


def block_perturb(seq: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Multiplicative perturbation of a random contiguous block.
    Very similar to the routine used by the reference implementation.
    """
    n = seq.size
    lo = max(1, n // 200)
    hi = max(2, n // 12)
    width = int(rng.integers(lo, hi + 1))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = start + width
    factor = float(np.exp(rng.normal(0.0, 0.06)))   # ≈6 % log‑normal change
    new = seq.copy()
    new[start:stop] *= factor
    if rng.random() < 0.1:                     # occasional symmetrisation
        new = 0.5 * (new + new[::-1])
    return np.clip(new, 0.0, 1000.0)


def fft_convolve_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Return the linear convolution a*a using an FFT of length `fft_len`."""
    f = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(f * f, n=fft_len)
    # keep only the relevant 2·n‑1 entries
    return conv[: 2 * a.size - 1]


def objective_from_conv(conv: np.ndarray, n: int, sum_a: float) -> float:
    """Exact objective value given a pre‑computed convolution."""
    return float(2.0 * n * conv.max() / (sum_a * sum_a))


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: float = 1000.0,
                     **kwargs) -> list[float]:
    """
    Return a list of non‑negative heights that (heuristically) minimise
    `evaluate_sequence`.  The method mixes fast sub‑gradient descent on
    the maximum of the autocorrelation with occasional random restarts
    and block perturbations.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Problem size – reuse the length of the previously found sequence
    # when it is present; otherwise fall back to a reasonable default.
    # ------------------------------------------------------------------
    try:
        n = int(len(height_sequence_1))
        # guard against enormously large historic solutions
        n = min(n, 20000)
    except Exception:
        n = 8000

    # FFT length – next power of two ≥ 2·n‑1 (fastest for rfft)
    fft_len = 1 << ((2 * n - 1).bit_length())

    # ------------------------------------------------------------------
    # Start from the classic 1/√(i+1) kernel (unit‑sum normalised)
    # ------------------------------------------------------------------
    a = generate_power_sequence(n, exponent=0.5, offset=0.0)
    a = a / a.sum()                     # ∑a = 1  (scale‑invariant)

    conv = fft_convolve_self(a, fft_len)
    best_score = objective_from_conv(conv, n, a.sum())
    best_seq = a.copy()

    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 0.5)   # safety margin

    iteration = 0
    # step‑size control (decreases like 1/√iter)
    step_factor = 1.0
    # temperature for the tiny uphill‑acceptance mechanism
    temperature = 1e-3

    while time.monotonic() < deadline:
        iteration += 1

        # ----- 1.  current convolution and the index of the maximal entry
        conv = fft_convolve_self(a, fft_len)
        max_val = conv.max()
        k_max = int(conv.argmax())

        # ----- 2.  sub‑gradient of the *maximal* entry
        idx = k_max - np.arange(n)                     # k_max‑i
        mask = (idx >= 0) & (idx < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[idx[mask]]                  # ∂(a*a)[k_max]/∂a_i

        # ----- 3.  compute a safe step size (no component becomes negative)
        pos = g > 0
        if np.any(pos):
            # maximal admissible α so that a‑α·g stays ≥0
            alpha_max = np.min(a[pos] / g[pos])
            # a slowly decreasing step; the 0.8 factor keeps a little margin
            alpha = min(alpha_max * 0.8,
                        step_factor / np.sqrt(iteration + 1.0))
        else:
            alpha = 0.0

        # ----- 4.  propose the gradient step
        cand = a - alpha * g
        cand = np.maximum(cand, 0.0)
        s = cand.sum()
        if s < 1e-12:                     # degenerate – fall back to old a
            cand = a.copy()
            s = cand.sum()
        cand /= s                          # renormalise (∑=1)

        # ----- 5.  evaluate the candidate (fast, no call to evaluate_sequence)
        conv_cand = fft_convolve_self(cand, fft_len)
        cand_score = objective_from_conv(conv_cand, n, cand.sum())

        # ----- 6.  accept if we improve the best known score
        if cand_score < best_score - 1e-12:
            best_score = cand_score
            best_seq = cand.copy()
            a = cand
            elapsed = time.monotonic() - start_time
            print(f"Iter {iteration:6d}: new best {best_score:.6f} (t={elapsed:.1f}s)")
            continue

        # ----- 7.  occasional uphill move (simulated‑annealing style)
        if rng.random() < np.exp((best_score - cand_score) / max(temperature, 1e-12)):
            a = cand                    # accept as current point, but not best

        # ----- 8.  occasional random “global’’ perturbation
        if rng.random() < 0.03:
            # block perturbation of the current vector
            cand2 = block_perturb(a, rng)
            cand2 /= cand2.sum()
            conv2 = fft_convolve_self(cand2, fft_len)
            score2 = objective_from_conv(conv2, n, cand2.sum())
            if score2 < best_score - 1e-12:
                best_score = score2
                best_seq = cand2.copy()
                a = cand2
                elapsed = time.monotonic() - start_time
                print(f"Iter {iteration:6d} (block): new best {best_score:.6f} (t={elapsed:.1f}s)")
                continue
            # occasional uphill acceptance for the perturbation as well
            if rng.random() < np.exp((best_score - score2) / max(temperature, 1e-12)):
                a = cand2

        # ----- 9.  rare random restart with a fresh parametrised kernel
        if rng.random() < 0.008:
            exp = rng.uniform(0.35, 0.65)
            off = rng.uniform(0.0, 2.0)
            L = rng.exponential(30.0) + 5.0          # typical scale 5‑50
            alp = rng.uniform(0.0, 1.0)
            cand3 = generate_windowed_sequence(n,
                                               exponent=exp,
                                               offset=off,
                                               L=L,
                                               alpha=alp)
            cand3 /= cand3.sum()
            conv3 = fft_convolve_self(cand3, fft_len)
            score3 = objective_from_conv(conv3, n, cand3.sum())
            if score3 < best_score:
                best_score = score3
                best_seq = cand3.copy()
                a = cand3
                elapsed = time.monotonic() - start_time
                print(f"Iter {iteration:6d} (restart): new best {best_score:.6f} (t={elapsed:.1f}s)")

        # ----- 10.  temperature cooling
        temperature *= 0.9999

    # ------------------------------------------------------------------
    # Return the best sequence discovered – a plain Python list of floats.
    # ------------------------------------------------------------------
    return [float(x) for x in best_seq]
