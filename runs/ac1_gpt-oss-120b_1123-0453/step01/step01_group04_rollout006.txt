The objective to minimise is  

\[
J(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2},
\]

where `*` denotes the discrete convolution.  
The score is invariant under a global scaling of the vector, therefore we can keep the
sequence normalised to a unit sum (`∑a = 1`).  With this normalisation the score reduces to  

\[
J(a)=2\,n\;\max (a*a).
\]

The problem is non‑convex, but the sub‑gradient of the maximal convolution entry is easy to
compute:

*let* `k*` be an index where the convolution attains its maximum,  
*let* `K = {k*}` (or all ties).  
For a fixed `k∈K`

\[
\frac{\partial}{\partial a_i}\bigl((a*a)[k]\bigr)=2\,a_{k-i}
\qquad (a_j = 0\; \text{if} \;j\notin[0,n-1]).
\]

Hence a (sub‑)gradient of `J` at `a` is  

\[
g_i = 2\sum_{k\in K} a_{k-i}.
\]

Moving mass from indices with a large value of `g_i` to indices with a small value
decreases the maximal convolution.  A robust way to do this while preserving non‑negativity
and the unit‑sum constraint is **multiplicative (exponentiated) gradient descent**:

```
a ← a ⊙ exp(‑η·g)          # element‑wise product
a ← (a + a[::-1]) / 2      # enforce symmetry (the problem is symmetric)
a ← a / sum(a)             # unit‑sum projection
```

`η>0` is a step size that is adapted during the run: it is increased after a successful
step and decreased after a non‑improving step.  The algorithm is accelerated by occasional
random block perturbations (the same primitive used by the reference solution) and by
re‑initialising from a fresh power‑law when the search stagnates.

All heavy work (the convolution and the gradient) is performed with an FFT‑based
`O(n log n)` routine, allowing thousands of iterations within the 1000 s budget.

The code below follows this plan, keeps the sequence length equal to the supplied
`height_sequence_1` (default ≈ 5600), and returns the best sequence found.

"""
Gradient‑descent search for a step‑function that minimises
evaluate_sequence().  The algorithm works with a unit‑sum normalisation,
uses the exact sub‑gradient of the maximal self‑convolution,
applies exponentiated updates, enforces symmetry, and performs occasional
random block perturbations to escape plateaux.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – top level, no closures
# ----------------------------------------------------------------------


def fft_convolve_full(a: np.ndarray) -> np.ndarray:
    """
    Return the full (linear) convolution a * a using a real FFT.
    The result has length 2*len(a)-1.
    """
    n = a.size
    # nearest power of two >= 2*n-1 for efficient FFT
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return conv


def subgradient_max_conv(a: np.ndarray, conv: np.ndarray, tol: float = 1e-12) -> np.ndarray:
    """
    Compute a sub‑gradient of max(conv) w.r.t. a.
    For all indices k where conv[k] is maximal (within tol) we add
    2 * a_{k-i} to the i‑th component.
    """
    n = a.size
    max_val = conv.max()
    # indices attaining (almost) the maximum
    K = np.where(conv >= max_val - tol)[0]
    g = np.zeros_like(a)

    for k in K:
        i_start = max(0, k - (n - 1))
        i_end = min(k, n - 1)
        # i runs from i_start … i_end inclusive
        i_range = np.arange(i_start, i_end + 1, dtype=np.int64)
        partner = k - i_range                     # partner index in a
        g[i_range] += a[partner]

    # factor 2 because ∂(a*a)[k]/∂a_i = 2 a_{k‑i}
    g *= 2.0
    return g


def make_arcsine_like(n: int) -> np.ndarray:
    """
    Return a symmetric arcsine‑type sequence:
        a_i ∝ 1 / sqrt( (i+0.5) * (n-0.5-i) )
    The vector is normalised to unit sum.
    """
    idx = np.arange(n, dtype=np.float64) + 0.5
    a = 1.0 / np.sqrt(idx * (n - idx))
    # enforce symmetry (numerical round‑off may break perfect symmetry)
    a = (a + a[::-1]) / 2.0
    a /= a.sum()
    return a


def make_power_law(n: int, alpha: float) -> np.ndarray:
    """   a_i = (i+1)^‑α   (simple decreasing shape)   """
    idx = np.arange(n, dtype=np.float64) + 1.0
    a = np.power(idx, -alpha)
    a = (a + a[::-1]) / 2.0          # enforce symmetry
    a /= a.sum()
    return a


def block_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Random contiguous block multiplicative perturbation.
    The block width is chosen between n/200 and n/12.
    With 35 % probability the whole vector is mirrored.
    """
    cand = base.copy()
    n = cand.size
    width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)
    cand[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    if rng.random() < 0.35:
        cand = 0.5 * (cand + cand[::-1])
    cand = np.clip(cand, 0.0, 1000.0)
    cand /= cand.sum()                     # keep unit sum
    return cand


def objective_from_conv(conv: np.ndarray, n: int) -> float:
    """
    With a unit‑sum sequence the objective is 2·n·max(conv).
    """
    return 2.0 * n * conv.max()
