Greedy mass‑filling + local hill‑climb.

The evaluation function is  2·n·max(conv(a,a)) / (sum(a))² .
For a non‑negative sequence the best possible value is 2·n/(2·n‑1)≈1,
obtained when the self‑convolution is perfectly flat.
A sequence a_i≈(i+1)⁻½ gives a convolution that is almost constant
(≈π), yielding the classic bound π/2≈1.571.  To improve, we keep the
maximum convolution value M fixed and repeatedly add as much mass as
possible to entries where the convolution is far below M.  Each addition
raises the total sum while leaving the peak unchanged, driving the
score down towards the theoretical optimum.  When no further increase
is possible we fall back to a short hill‑climbing phase (random block
perturbations) to lower M slightly.

The algorithm runs in O(n) per greedy step and respects the 1000‑second
budget.  It works with the supplied `height_sequence_1` if present,
otherwise starts from a fresh power‑law kernel.
"""

import time
import numpy as np

# Helper utilities (copied from the reference implementation)
# ----------------------------------------------------------------------
def generate_power_sequence(n: int, exponent: float = 0.5, offset: float = 0.0) -> np.ndarray:
    """Return a non‑negative sequence a_i = (i+offset+1)^(-exponent)."""
    idx = np.arange(n, dtype=np.float64) + offset + 1.0
    seq = idx ** (-exponent)
    return np.clip(seq, 0.0, 1000.0)


def block_perturb(seq: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """Multiplicative perturbation of a random contiguous block."""
    n = seq.size
    lo = max(1, n // 200)
    hi = max(2, n // 12)
    width = int(rng.integers(lo, hi + 1))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = start + width
    factor = float(np.exp(rng.normal(0.0, 0.06)))   # ≈6 % log‑normal change
    new = seq.copy()
    new[start:stop] *= factor
    if rng.random() < 0.1:                     # occasional symmetrisation
        new = 0.5 * (new + new[::-1])
    return np.clip(new, 0.0, 1000.0)
