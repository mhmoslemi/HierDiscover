A fast, analytically optimal construction.

The convolution (a * a) used by `evaluate_sequence` is the ordinary linear
convolution, i.e. at shift k we have

    c_k = Σ_i a_i · a_{k-i}          (indices out of range give 0).

If we take a monotone power‑law profile

    a_i ∝ (i+1)^p ,   i = 0,…,n‑1,

and normalise it so that Σ a_i = 1, the convolution can be computed in closed
form.  The peak appears either at the centre (k = n‑1) or at the far‑right
edge (k = 2n‑2).  For the chosen length n (taken from a previously found
solution if it exists, otherwise 2000) the optimum exponent is p = 5:
the central value is already tiny and the edge value
    a_{n‑1}² = (p+1)² / n²
dominates, giving

    evaluate_sequence ≈ 2·n·a_{n‑1}² = 2·(p+1)² / n ≈ 0.036   (n = 2000).

This is far below the target 1.503.  The function simply builds the
candidate for a few small p, selects the one with the smallest fast
