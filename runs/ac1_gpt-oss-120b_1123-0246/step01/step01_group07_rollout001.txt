The task is to output a list `height_sequence` that minimizes  

\[
E(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the (full) self‑convolution of the non‑negative vector `a`
and `n = len(a)`.  
`E(a)` is invariant under a uniform scaling of `a`, therefore we can
fix the sum of the entries to `1` and only optimise the *shape* of the
vector.

The algorithm below consists of two phases.

1. **LP‑based global improvement** –  
   For a current shape `f` we compute `M = max(f*f)`.  
   The linear programme  

   ```
   maximise   Σ g_i
   subject to  (f * g)_k ≤ M   for every k
               g_i ≥ 0 , g_i ≤ 1000
   ```

   finds a vector `g` that has the largest possible total mass while
   keeping the convolution with `f` below the current peak `M`.  
   After solving the LP we normalise `g` to unit sum and replace the
   current shape by a convex combination `f ← (1‑t) f + t g` (with
   `t = 0.15`).  This step never worsens `M` and usually reduces it.

2. **Stochastic local refinement** –  
   After the LP stage a cheap block‑wise multiplicative perturbation
   (log‑normal noise on a random contiguous block) is applied many
   times.  Whenever a perturbation yields a lower `E(a)` it becomes the
   new best candidate.

Both phases run while the allotted time budget permits (the harness
gives a maximum of 1000 s; we keep a small safety margin).  The best
sequence seen so far is returned.

The code falls back to the earlier block‑perturbation hill‑climber if
`scipy` (required for the linear programme) is unavailable.

```python
"""
Propose a step‑function sequence that minimises the self‑convolution
L∞‑norm ratio.  The method consists of:

1. An LP‑based global step: for the current shape f we solve
   max Σ g_i   s.t. (f*g)_k ≤ max(f*f)   and g≥0.
   The solution g (renormalised to unit sum) is mixed into f.

2. A fast stochastic block‑perturbation hill‑climber (log‑normal
   noise on a random block, occasional symmetrisation) that refines
   the best candidate found.

Both phases respect the non‑negative, ≤ 1000 domain required by
``evaluate_sequence``.  If SciPy is not available the algorithm falls
back to a pure stochastic local search.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Fast replica of the evaluation function (no security checks)
def _evaluate_fast(seq: np.ndarray) -> float:
    """Return the objective value for a non‑negative vector."""
    n = seq.size
    conv = np.convolve(seq, seq)
    max_b = conv.max()
    total = seq.sum()
    if total < 1e-12:
        return float("inf")
    return float(2.0 * n * max_b / (total * total))


# ----------------------------------------------------------------------
# Block‑wise multiplicative perturbation (used in the local refinement)
def _make_block_perturbation(base: np.ndarray,
                             rng: np.random.Generator) -> np.ndarray:
    """Multiply a random contiguous block by log‑normal noise."""
    cand = base.copy()
    n = cand.size
    # block size between 0.5 % and 8 % of the vector length
    lo = max(1, n // 200)
    hi = max(2, n // 12)
    width = int(rng.integers(lo, hi + 1))
    start = int(rng.integers(0, n - width + 1))
    stop = start + width
    cand[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    # occasional symmetrisation – helps avoid a single dominant peak
    if rng.random() < 0.35:
        cand = 0.5 * (cand + cand[::-1])
    # keep within the allowed domain
    return np.clip(cand, 0.0, 1000.0)


# ----------------------------------------------------------------------
# Helper: build the convolution matrix A such that (f * g) = A @ g
def _make_conv_matrix(f: np.ndarray) -> np.ndarray:
    """Return matrix A (size (2n‑1) × n) with A @ g = f * g."""
    n = f.size
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    # column j contains f shifted down by j positions
    for j in range(n):
        A[j:j + n, j] = f
    return A

            if s == 0.0:
                break

            # Normalise to unit sum (the objective is scale‑invariant)
            g = g_raw / s

            # Evaluate the candidate
            score_g = _evaluate_fast(g)
            if score_g < best_score:
                best = g.copy()
                best_score = score_g
                print(f"[LP {iteration}] new best   score={best_score:.6f}")

            # Decide how to update the current sequence
            conv_g = np.convolve(g, g)
            M_g = conv_g.max()

            if M_g < M_f * 0.99:          # genuine improvement – adopt g
                seq = g.copy()
                # keep exact unit sum (tiny numerical drift may appear)
                seq /= seq.sum()
                print(f"[LP {iteration}] accepted g (M reduced {M_f:.6e}->{M_g:.6e})")
            else:
                # Mix a fraction of g into seq
                seq = (1.0 - t) * seq + t * g
                seq = np.clip(seq, 0.0, 1000.0)
                seq /= seq.sum()

            # Occasionally symmetrise to keep the shape balanced
            if rng.random() < 0.3:
                seq = 0.5 * (seq + seq[::-1])

    # ------------------------------------------------------------------
    # Phase 2 – Fast stochastic hill‑climber (uses the best candidate
    #           found so far as a starting point)
    while time.monotonic() < deadline:
        cand = _make_block_perturbation(best, rng)
        score = _evaluate_fast(cand)
        if score < best_score:
            best = cand
            best_score = score
            print(f"[HC] new best   score={best_score:.6f}")

    print(f"final best score={best_score:.6f}")
    # Convert back to plain Python list (the external evaluator will
    # again clip to the allowed range).
    return best.tolist()
```
