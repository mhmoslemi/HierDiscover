"""
propose_candidate
-----------------
A fast stochastic optimizer for the evaluation function.  It starts from the
best known construction (`height_sequence_1` if available) and performs a
mixture of three moves:

1. **Block perturbations** – multiplicative log‑normal changes on a random
   contiguous block whose size shrinks over time.
2. **Targeted mass transfer** – using the current worst convolution index it
   moves a small amount of mass from positions that contribute most to that
   peak to positions that contribute the least.
3. **Fine‑grained random tweaks** – occasional small multiplicative changes
   on a few random coordinates.

The convolution is evaluated with an FFT based routine (`fast_score`) which
is much faster than `np.convolve`.  A candidate is first filtered with this
cheap estimate and only when it improves the best score the full
`evaluate_sequence` (which also enforces the hard clipping) is called.

The algorithm includes:
* a linear cooling schedule for the perturbation magnitude,
* occasional acceptance of slightly worse solutions (simulated‑annealing style),
* a restart mechanism that injects a new random power‑law shape if no
  improvement has been seen for a long while.

The whole search runs for the allotted time budget (default 500 s, can be
overridden) and returns the best sequence found.
"""

import time
import numpy as np

def _fft_max_convolution(a: np.ndarray, fft_len: int) -> tuple[float, int]:
    """
    Compute the maximum value of the linear self‑convolution of ``a`` using FFT.
    Returns (max_value, index_of_max).
    """
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * a.size - 1]
    idx = int(conv.argmax())
    return float(conv[idx]), idx


def _fast_score(a: np.ndarray, fft_len: int) -> float:
    """
    Fast approximation of ``evaluate_sequence``.
    Assumes ``a`` is already clipped to [0,1000].
    """
    s = a.sum()
    if s < 0.01:
        return float("inf")
    maxb, _ = _fft_max_convolution(a, fft_len)
    return float(2 * a.size * maxb / (s * s))

    Search for a step‑function (list of non‑negative heights) that minimises
    the provided evaluation function.  Returns the best list found before the
    time budget expires.

    best_seq = base.copy()

    # ----------------------------------------------------------------------

            )
