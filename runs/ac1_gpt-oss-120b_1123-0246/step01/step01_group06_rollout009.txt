def subgradient_descent(a, deadline, seed):
    rng = np.random.default_rng(seed)
    best_seq = a.copy()
    best_score = evaluate_sequence(a.tolist())
    iter = 0
    eta0 = 0.2
    while time.monotonic() < deadline:
        # compute convolution
        b = np.convolve(a, a)
        k_max = int(np.argmax(b))
        # compute gradient
        n = a.size
        idx = np.arange(n)
        mask = (k_max - idx >= 0) & (k_max - idx < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[k_max - idx[mask]]
        # step size
        eta = eta0 / np.sqrt(iter + 1)
        # multiplicative update
        a = a * np.exp(-eta * g)
        # renormalize to sum 1
        s = a.sum()
        if s == 0:
            a = np.full(n, 1.0/n)
        else:
            a = a / s
        # maybe occasionally add small random noise to explore
        if iter % 100 == 0:
            # add small log-normal perturbation
            a *= np.exp(rng.normal(0.0, 0.02, size=n))
            a = a / a.sum()
        # evaluate
        score = evaluate_sequence(a.tolist())
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a.copy()
            print(f"[sgd] iter {iter} new best {best_score:.6f}")
        iter += 1
    return best_seq, best_score

The evaluator is scale‑invariant, therefore the search works with
sequences whose sum is 1.  The algorithm has three phases:

1.  Several warm‑starts (power‑law shapes with different exponents
    and a few Dirichlet‑distributed random vectors) are fed to a
    simple exponentiated‑gradient/sub‑gradient descent that directly

2.  The best vector found so far is further refined with the

3.  The final vector is scaled so that its maximum entry equals 1000 –
