Propose a step‑function sequence with a low evaluation score.

Algorithm
---------

1. **Initial sequence** – a truncated binomial series
   a_i = C(2i,i)/4^i  (the coefficients of (1‑z)^‑1/2).  This already gives
   a score close to π/2 ≈ 1.5708.

2. **Guided sub‑gradient descent** – the objective is
        f(a) = 2·n·max(a*a) / (sum(a))² .
   The gradient of the numerator w.r.t. a_i (when the maximal convolution
   index is k) is 2·a_{k‑i}.  Using the sub‑gradient of the max we obtain
   a simple update direction that pushes mass from positions whose
   “mirror’’ partner a_{k‑i} is large towards positions where it is small.
   After each step we project back to the feasible set (non‑negative,
   ≤1000).

3. **Exploration moves** – to avoid getting trapped in a flat region
   we occasionally (≈5 % of the iterations) apply a stochastic block
   perturbation (multiplicative log‑normal noise on a short block) and,
   with a smaller probability, a random mirror‑swap of a tiny amount of
   mass between a position and its opposite side.

4. **Adaptive step size** – the step length is multiplied by 0.9995 each
   iteration and is reset to a larger value after a long streak without
   improvement.

5. **Best‑ever tracking** – the best sequence seen so far (lowest score)
   is stored and finally returned.

The whole loop runs until the allotted wall‑clock budget expires (default

# ----------------------------------------------------------------------
# Helper: truncated binomial coefficients (optimal analytic starting point)
# ----------------------------------------------------------------------
def _binomial_sequence(length: int) -> np.ndarray:
    """Return a length‑`length` array with a_i = C(2i,i)/4^i (truncated)."""
    a = np.empty(length, dtype=np.float64)
    a[0] = 1.0
    for i in range(length - 1):
        # recurrence a_{i+1} = a_i * (2i+1) / (2(i+1))
        a[i + 1] = a[i] * (2.0 * i + 1.0) / (2.0 * (i + 1))
    # safety clipping – the coefficients are ≤ 1 anyway
    return np.clip(a, 0.0, 1000.0)

def _make_block_perturbation(base: np.ndarray, rng: np.random.Generator) -> np.ndarray:
    """
    Return a new candidate obtained by a multiplicative log‑normal perturbation
    of a random contiguous block of `base`.  With probability 0.35 the result is
    symmetrised with its mirror image.
    """
    cand = base.copy()
    n = cand.size
    # block width ≈ 0.5% … 8% of the length
    w_min = max(1, n // 200)
    w_max = max(2, n // 12)

    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = start + width
    cand[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    if rng.random() < 0.35:
        cand = 0.5 * (cand + cand[::-1])
    return np.clip(cand, 0.0, 1000.0)

            end_i = min(n - 1, k)
            idx = np.arange(start_i, end_i + 1, dtype=np.int64)
            partner[idx] = best[k - idx]

            # sub‑gradient of the objective (see analysis for derivation)
            grad = (4.0 * n / (total * total)) * partner - (4.0 * n * M / (total ** 3))

            # simple adaptive learning rate
            step *= 0.9995
            if step < 1e-6:
                step = 1e-6

            candidate = best - step * grad
            candidate = np.clip(candidate, 0.0, 1000.0)

        # ----------------------------------------------------------------
        # 2c. Evaluate the trial candidate (fast internal formula)
        # ----------------------------------------------------------------
        cand_total = candidate.sum()
        if cand_total < 1e-12:
            continue
        cand_conv = np.convolve(candidate, candidate)
        cand_M = cand_conv.max()
        cand_score = 2.0 * n * cand_M / (cand_total * cand_total)

        # ----------------------------------------------------------------
        # 2d. Accept / reject logic and best‑ever update
        # ----------------------------------------------------------------
        if np.isfinite(cand_score) and cand_score < best_score:
            best = candidate
            best_score = cand_score
            no_improve = 0
            print(f"[{iteration:6d}] new best: {best_score:.6f}")
        else:
            no_improve += 1

        # simple Metropolis criterion to allow occasional worsening moves
        if cand_score <= cur_score or rng.random() < np.exp(-(cand_score - cur_score) / (0.01 + iteration * 1e-5)):
            best = candidate          # move to the new point for the next iteration

        # ----------------------------------------------------------------
        # 2e. Stagnation handling – occasional randomisation
        # ----------------------------------------------------------------
        if no_improve > 4000:
            # inject a modest random jitter and reset the step size
            best *= np.exp(rng.normal(0.0, 0.03, size=n))
            best = np.clip(best, 0.0, 1000.0)
            step = 0.5
            no_improve = 0

    # ------------------------------------------------------------------
    # 3. Final report and return
    # ------------------------------------------------------------------
    print(f"[done] iterations={iteration}, final best score={best_score:.6f}")
    # Ensure the result conforms to the required format (list of Python floats)
    return [float(v) for v in best]
