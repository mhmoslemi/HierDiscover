def make_transfer_move(base, rng):
    a = base.copy()
    n = len(a)
    i = rng.integers(0, n)
    j = rng.integers(0, n)
    if i == j:
        return a
    amount = a[i] * rng.uniform(0.01, 0.2)  # up to 20% of a_i
    a[i] -= amount
    a[j] += amount
    return a

Searches for a non‑negative step‑function that minimises

using a two‑phase strategy:

1. **Coarse global sweep** – tries a handful of sequence lengths
   (including much shorter ones than the previously supplied
   `height_sequence_1`) together with two simple parametric families:
   power‑law a[i]∝(i+1)^‑p and exponential a[i]∝exp(-p·i).  Every candidate
   is scaled so that its maximum entry equals the allowed bound 1000;
   the best candidate found so far is kept.

2. **Local stochastic refinement** – starting from the best sequence of
   phase‑1 a mixture of cheap moves is applied:
   * block‑wise multiplicative perturbations (the same move used in the
     reference solution);

     index to another, keeping the total sum essentially unchanged;
   * a small global log‑normal scaling (simulated‑annealing‑style noise).

   the evaluation function is accepted and logged.
