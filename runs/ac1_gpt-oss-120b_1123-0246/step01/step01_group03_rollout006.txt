Propose a step‑function with a low evaluation score.

The algorithm starts from the Catalan‑type sequence (a_i = binom(2i,i)/4**i)
which already gives a score ≈ π/2 ≈ 1.571.  It then iteratively solves a
linear program (using SciPy’s high‑performance HiGHS solver) that maximises
the ℓ₁‑norm of a non‑negative vector g under the convolution bound
    (a * g)_k ≤ M   (where M = max(a*a)).
Mixing the current sequence a with the LP solution g (a ← (1‑t)a + t g)
strictly increases the sum of the coefficients while keeping the worst
convolution essentially unchanged; consequently the evaluation score
 2·n·max(b) / sum(a)²  steadily drops.  Small step sizes are tried, and if
the LP does not yield improvement a cheap random perturbation is applied.

The LP is expressed with a sparse convolution matrix (size (2n‑1)×n) so that
even for n≈1000 the problem remains fast and memory‑friendly.  The routine
stops when the time budget is exhausted or when no improvement is seen for

import numpy as np
from scipy.optimize import linprog
from scipy.sparse import diags, csr_matrix

# Helper: Catalan‑type coefficients (a_i = binom(2i,i)/4**i)
# ----------------------------------------------------------------------
def _catalan_sequence(n: int) -> np.ndarray:
    """Return the first n Catalan‑type coefficients."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    # recurrence a[i] = a[i‑1] * (2*i‑1)/(2*i)
    for i in range(1, n):
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    # safety clipping – values are already ≤1, but keep the bounds used by evaluate_sequence
    return np.clip(a, 0.0, 1000.0)
