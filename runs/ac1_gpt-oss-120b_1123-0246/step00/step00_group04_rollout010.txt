The method works as follows:

   ``height_sequence_1`` if it exists, otherwise a random log‑normal
   vector).  The sequence is truncated to at most 1024 entries and
   renormalised so that its ℓ₁‑norm equals √(2·n).

2. Repeatedly perform an LP‑based improvement:
   * Compute M = max(conv(f,f)).
   * Solve the linear program
         maximise   1ᵀ g
         subject to A·g ≤ M  (A encodes the convolution f∗g)
                     g ≥ 0 , g ≤ 1000
     where `g` has the same length as `f`.  The LP finds a non‑negative
     sequence which can be added to `f` without increasing the maximal
     convolution value.
   * If the optimal ‖g‖₁ is larger than that of `f`, scale `g` to the
     target ℓ₁‑norm √(2·n) and mix it with `f`:
         f ← (1‑t)·f + t·g_scaled   (t starts at 0.3 and is decreased a
                                    little after each successful step).

3. If the LP yields no improvement or runs out of time, fall back to the
   simple block‑perturbation search used in the reference implementation.
   The best sequence found (lowest value of ``evaluate_sequence``) is
   returned.

The whole procedure respects the supplied ``budget_s`` time limit and
contains a few ``print`` statements to trace progress.
"""

import time
import numpy as np
import cvxpy as cp
import scipy.sparse as sp


def make_block_perturbation(base, rng):
    """Return a cheap O(n) non‑negative perturbation of ``base``."""
    candidate = np.asarray(base, dtype=np.float64).copy()
    n = candidate.size
    # width of the perturbed block – a fraction of the length
    width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)
    # multiplicative log‑normal perturbation within the block
    candidate[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    # optional symmetrisation (helps to keep the convolution flat)
    if rng.random() < 0.35:
        candidate = 0.5 * (candidate + candidate[::-1])
    # enforce the hard limits of ``evaluate_sequence``
    return np.clip(candidate, 0.0, 1000.0)


def _build_convolution_matrix(f):
    """Build the sparse matrix A  (shape (2n‑1, n))   such that  A·g = conv(f,g)."""
    n = f.size
    rows = []
    cols = []
    data = []
    # For each i we place f[i] on the diagonal k = i + j
    for i, fi in enumerate(f):
        if fi == 0.0:
            continue
        js = np.arange(n, dtype=np.int32)
        ks = i + js                     # row indices i+j
        rows.extend(ks.tolist())
        cols.extend(js.tolist())
        data.extend([fi] * n)
    return sp.csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))
