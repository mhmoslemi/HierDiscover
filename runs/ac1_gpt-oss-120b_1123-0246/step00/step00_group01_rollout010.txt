"""
Simple polynomial ramp generator.

The evaluation function is
    score = 2 * n * max(a*a) / (sum(a)^2)

For a monotone polynomial sequence a_i = C * (i/(n-1))^p
(where C is chosen so the largest entry is exactly 1000) the
convolution at the centre behaves like
    max(a*a) ≈ 1000^2 * n * B(p+1, p+1)

and the score reduces to
    score = 2 * (p+1)^2 * B(p+1, p+1)

where B is the beta‑function.  This value drops rapidly with the
exponent p (e.g. p=6 gives ≈0.016 for n≈6000).  Hence a high‑degree
ramp provides a very low score without any heavy search or optimisation.

The function below builds such a sequence (exponent 6) with the same
length as the previously‑found `height_sequence_1` if it exists,
otherwise a default length of 5000.  All numbers are clipped to the
allowed range [0,1000] and the sum is comfortably above the
`evaluate_sequence` safety threshold.
