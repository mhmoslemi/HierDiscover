The evaluation function is  

\[
\text{score}= \frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `max(a*a)` is the maximum entry of the full self‑convolution of the
non‑negative sequence `a`.  
For a monotone power‑law sequence  

\[
a_i = 1000\Bigl(\frac{i}{n-1}\Bigr)^p ,\qquad i=0,\dots ,n-1 ,
\]

the convolution peak can be computed analytically and the score tends to  

\[
\text{score}= 2\,(p+1)^2\,
\frac{\Gamma(p+1)^2}{\Gamma(2p+2)} .
\]

For `p = 2` the score is already `0.6`; increasing `p` makes the score
drop dramatically (e.g. `p = 4` → `≈0.08`).  
All values stay in the allowed range `[0,1000]`, so no clipping occurs.

The algorithm:

1. Choose the length `n` from the provided global `height_sequence_1`
   (fallback = 256).
2. Build several candidates with `p ∈ {1,2,3,4,5,6,8,10,12}`.
3. Evaluate each candidate with the given `evaluate_sequence` and keep the
   best one.
4. Optionally perform a very short stochastic local‑search around the
   best candidate (block perturbations) until the time budget expires.
5. Return the best sequence discovered.

The method is completely deterministic apart from the optional local
search, runs in `O(n·|P|)` time for the exponent sweep (tiny) and needs only
`O(n)` memory.

```python
import numpy as np
import time

def make_block_perturbation(base, rng):
    """
    One‑dimensional O(n) non‑negative perturbation of ``base``.
    Scales a random contiguous block and (with 35 % probability) symmetrises.
    """
    candidate = np.asarray(base, dtype=np.float64).copy()
    n = candidate.size
    # block width between n/200 and n/12 (at least 1 element)
    width = int(rng.integers(max(1, n // 200), max(2, n // 12)))
    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)
    # multiplicative log‑normal perturbation
    factor = float(np.exp(rng.normal(0.0, 0.12)))
    candidate[start:stop] *= factor
    # optional mirror averaging
    if rng.random() < 0.35:
        candidate = 0.5 * (candidate + candidate[::-1])
    # enforce the problem bounds
    np.clip(candidate, 0.0, 1000.0, out=candidate)
    return candidate


def propose_candidate(seed=42, budget_s=500, **kwargs):
    """
    Generate a low‑autocorrelation step function.
    The sequence is a power‑law a_i = 1000·(i/(n‑1))^p.
    Several exponents are tried, the best is kept,
    then a brief stochastic refinement is performed.
    """
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------
    # Determine the length of the sequence (use the provided one if possible)
    try:
        base = np.asarray(height_sequence_1, dtype=np.float64)
        if base.ndim != 1 or base.size == 0:
            raise ValueError
        n = base.size
    except Exception:
        n = 256

    # ------------------------------------------------------------
    # Try a small grid of exponents
    exponents = [1, 2, 3, 4, 5, 6, 8, 10, 12]
    t = np.linspace(0.0, 1.0, n, dtype=np.float64)   # values in [0,1]
    best_seq = None
    best_score = float('inf')
    best_p = None

    for p in exponents:
        # a_i = 1000 * (i/(n-1))^p
        seq = (t ** p) * 1000.0
        # direct call to the supplied evaluator
        score = float(evaluate_sequence(seq.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = seq
            best_p = p

    # ------------------------------------------------------------
    # Optional short stochastic refinement (block perturbations)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 3.0)
    while time.monotonic() < deadline:
        cand = make_block_perturbation(best_seq, rng)
        score = float(evaluate_sequence(cand.tolist()))
        if np.isfinite(score) and score < best_score:
            best_seq = cand
            best_score = score

    # ------------------------------------------------------------
    # Report what we found (useful for debugging)
    print(f"Chosen exponent p = {best_p}, final score = {best_score:.6f}")

    # Return a plain Python list as required by the runner
    return [float(x) for x in best_seq]
```
