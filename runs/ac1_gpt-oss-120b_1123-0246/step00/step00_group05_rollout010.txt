The algorithm starts from a uniform distribution (sum = sqrt(2·n)) and repeatedly
moves a small amount of mass from indices that contribute most to the current
maximum convolution entry to random other indices.  Accepted moves follow a
decreasing temperature schedule (simulated annealing) and the best sequence
found within the time budget is returned.
"""

import numpy as np
import time

            #   directed mass transfer – from a high‑impact index to a random one
            # ---------------------------------------------------------

            conv = np.convolve(current, current)

            total_weight = weights.sum()

                # fallback to a simple random move
                i = rng.integers(0, n)
                j = rng.integers(0, n-1)
                if j >= i:
                    j += 1
                if current[i] == 0.0:

                candidate = current.copy()
                candidate[i] -= delta
                candidate[j] += delta

"""
Simulated‑annealing optimiser for the self‑convolution bound.

The objective of ``evaluate_sequence`` is
    2·n·max(conv) / (sum(a)^2)

For a fixed total mass the denominator does not change under scaling,
so minimising the bound is equivalent to flattening the convolution
(i.e. reducing the maximal entry).  The algorithm starts from a uniform
distribution (sum = sqrt(2·n), which yields a value of exactly 2.0) and
repeatedly moves a small amount of mass from indices that contribute most
to the current maximal convolution entry to random other indices.  Moves are
accepted according to a simple simulated‑annealing schedule; the best
sequence seen so far is kept and returned when the time budget expires.
A cheap block‑wise perturbation (as used in the reference code) is also
occasionally applied to escape plateaus, and a tiny symmetrisation step
helps to smooth the shape.
"""

import time
import numpy as np

def make_block_perturbation(base, rng):
    """One O(n) non‑negative perturbation of ``base``."""

    start = int(rng.integers(0, max(1, n - width + 1)))
    stop = min(n, start + width)
    candidate[start:stop] *= float(np.exp(rng.normal(0.0, 0.12)))
    if rng.random() < 0.35:               # occasional symmetrisation
        candidate = 0.5 * (candidate + candidate[::-1])
    return np.clip(candidate, 0.0, 1000.0)

    best_seq = current.copy()

            weights = np.zeros(n, dtype=np.float64)
            weights[valid] = current[idx[valid]] * current[partner[valid]]
            total_weight = weights.sum()

            if total_weight <= 0.0:
                # Very unlikely, fall back to a blind random transfer
                i = rng.integers(0, n)

    return [float(x) for x in best_seq]
