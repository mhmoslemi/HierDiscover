Define function project_to_simplex(v) returns array of non-negative numbers summing to 1. Using algorithm that sorts v descending and find threshold.

Pseudo:

```
def simplex_projection(v):
    # ensure sum(v)=1 and v>=0
    n = v.shape[0]
    # shift v so sum is 1
    # Actually we find rho = max { j | v_sorted[j] + (1 - cumulative_sum[j])/(j+1) > 0}
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n+1)
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0)
    return w
```

Propose a low‑value step‑function by continuous optimisation.

The evaluation metric is 2 n·max(a∗a) (sum is irrelevant because the
objective is scale‑invariant).  The goal is to minimise the maximum
autocorrelation (the convolution of the sequence with itself).

Strategy
--------
* Work on a probability simplex: initialise a non‑negative vector a with
  Σa = 1 (the scaling does not affect the score).
* Use a smooth approximation of the max‑operator (soft‑max) and perform
  projected gradient descent on the objective.
  – For temperature T the weights w_k = exp(T·(c_k−max(c))) give the
    gradient of the smooth max.
  – The gradient w.r.t. a is g_i = 2·∑_j w_{i+j}·a_j, which can be
    computed efficiently with a single correlation (numpy.correlate).
* After each gradient step the vector is projected back onto the simplex
  (non‑negative, sums to 1).  The step size and temperature are annealed.
* Keep the best sequence seen (lowest score from evaluate_sequence).
* When the time budget is almost exhausted, perform a short
  block‑perturbation local search (the heuristic used by the reference
  solution) starting from the best candidate.

The whole optimisation runs inside the time budget (default 500 s) and
returns a list of floats ready for evaluate_sequence().
"""

import time
import numpy as np

def simplex_projection(v):
    """Project a vector onto the probability simplex (non‑negative, sum = 1)."""
    n = v.shape[0]
    # If all entries are non‑positive, return the uniform distribution.
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / n)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fallback – uniform
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    # Numerical safety: renormalise exactly to 1
    w_sum = w.sum()
    if w_sum > 0:
        w = w / w_sum
    else:
        w = np.full_like(v, 1.0 / n)
    return w
