Implementation of propose_candidate using an arcsine distribution.
The sequence approximates the Beta(1/2,1/2) density whose self‑convolution
is (almost) uniform, which drives the evaluation function towards its
theoretical lower bound 1.

import time

def arcsine_sequence(length: int) -> np.ndarray:
    """Return a non‑negative sequence of given length approximating
    f(x)=1/sqrt(x(1-x)) on (0,1).  The sequence is scaled so that its
    maximum value does not exceed 1000."""

"""
Arcsine‑based construction for the step‑function optimisation task.

The continuous density f(x)=1/sqrt(x(1−x)) on (0,1) (the
Beta(½,½) distribution) has the remarkable property that its
self‑convolution is exactly uniform on [0,2].  Discretising this
density yields a non‑negative sequence whose discrete convolution is
almost flat, i.e. the maximal entry of the convolution is very close
to its average.  Because the evaluation function

    score = 2·n·max(conv) / (sum(a)^2)

is minimal when max(conv) equals its average, the arcsine shape drives
the score close to the theoretical lower bound 1 (for large n).

The algorithm:
  1. Build a sequence of the same length as the previously discovered
     one (or 6000 if that variable is missing) by sampling the
     arcsine density.
  2. Optionally perform a cheap local search: repeatedly shrink the
     region that produces the current maximal convolution value,
     renormalise the whole vector to keep the total sum unchanged and
     accept the change whenever the score improves.
  3. Return the best sequence found within the allocated time budget.

The implementation respects all platform restrictions: no closures,
no file/network I/O, only top‑level functions, and it uses only the
standard library, NumPy and the provided ``evaluate_sequence``.
"""
