"""Uniform sequence generator.

The evaluation function  

    2 * n * max(conv(a,a)) / (sum(a)**2)

has a provable lower bound of 2, attained exactly when the sequence is
uniform (all entries equal).  Any deviation from uniformity makes
∑a_i² larger than (∑a_i)²/n and therefore raises the score.
Consequently the best possible score is 2, and a uniform sequence
reaches it.

This `propose_candidate` therefore builds a uniform sequence whose
length matches the globally‑provided `height_sequence_1` (or falls back
to 256).  The uniform value is chosen so that the L¹‑norm equals
√(2 n) – this matches the normalisation used in the reference
algorithm, but any positive constant would give the same score.

The function prints the obtained score for logging and returns the
sequence as a plain Python list of floats.
"""

import numpy as np
import time

    Parameters

    budget_s : float
        Ignored – the uniform candidate is computed instantaneously.
    **kwargs
        Additional unused arguments accepted for API compatibility.

        The candidate sequence.
