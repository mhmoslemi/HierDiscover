"""
propose_candidate
-----------------
A fast, constructive search for a step‑function that beats the
2.0 upper bound of ``evaluate_sequence``.

Idea
~~~~
The score is  

    score = 2·n·max(b) / (sum(a))² ,   b = a * a (linear convolution)

For a uniform block of length ``m`` (all values = 1) the maximum
convolution value is ``m`` and the score is always exactly 2,
independent of the block size.

If we place several *identical* blocks separated by *different* gaps,
the following facts hold (block length = ``m``):

* a block’s self‑convolution contributes at most ``m``;
* the convolution of two distinct blocks contributes at most ``2·m``
  (ordered pairs from the two blocks);
* By choosing the gaps so that every pair of blocks has a unique
  ``start_i + start_j`` sum, the peaks of the cross‑convolutions never
  coincide with each other nor with any self‑peak.  
  Consequently the global maximum is exactly ``2·m``.

If we use ``k`` blocks, the total sum is ``k·m`` and the total length
is roughly ``k·m`` (the gaps are negligible).  The resulting score
approaches

    score ≈ 4 / k        (for large ``m``).

Thus with ``k = 5`` blocks we can obtain a score around ``0.8``,
comfortably below the target ``1.503``.

The algorithm builds such block‑structures, evaluates them,
and then performs a cheap random search over the parameters
(number of blocks, block length and gap sizes) while staying within
the time budget.  The best sequence found is returned.

The sequence consists only of 0.0 and 1.0 values, already satisfying
the non‑negative and range constraints of ``evaluate_sequence``.
"""

import numpy as np
import time
from typing import List

def build_block_sequence(k: int, m: int, gaps: List[int]) -> np.ndarray:
    """
    Construct a sequence consisting of ``k`` identical blocks of length ``m``
    (filled with 1.0) separated by zero‑filled gaps.
    ``gaps`` must have length ``k-1``; they are the sizes of the gaps
    between consecutive blocks.  The first block starts at index 0.
    """
    parts = []
    for i in range(k):
        parts.append(np.ones(m, dtype=np.float64))
        if i < k - 1:
            parts.append(np.zeros(gaps[i], dtype=np.float64))
    return np.concatenate(parts)

    ``evaluate_sequence``.  The search is time‑bounded by ``budget_s`` seconds.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 0.5)

    # ------------------------------------------------------------------
    # Start with a deterministic good construction (k=5 blocks, distinct gaps)
    # ------------------------------------------------------------------
    k0 = 5
    m0 = 800                     # block length – can be changed later
    gaps0 = [1, 2, 4, 8]          # distinct small gaps, ensure pairwise sums differ
    best_seq = build_block_sequence(k0, m0, gaps0)
    best_score = float(evaluate_sequence(best_seq.tolist()))
    print(f"[init] k={k0}, m={m0}, gaps={gaps0} -> score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Random local search: vary k, block size and the gaps.
    # ------------------------------------------------------------------
    while time.monotonic() < deadline:
        # Randomly pick number of blocks (3 to 6)
        k = rng.integers(3, 7)
        # Random block length, at least 200 to keep max_b moderate
        m = rng.integers(200, 2501)

        # Produce distinct gap sizes (positive integers, up to 20)
        # Using a simple method: sample without replacement.
        gap_candidates = np.arange(1, 21, dtype=np.int64)
        rng.shuffle(gap_candidates)
        gaps = gap_candidates[: max(0, k - 1)].tolist()
        # Ensure gaps are distinct – they are by construction.

        seq = build_block_sequence(k, m, gaps)
        score = float(evaluate_sequence(seq.tolist()))

        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = seq
            print(f"[improve] k={k}, m={m}, gaps={gaps} -> score={best_score:.6f}")

    # Convert to plain Python list of floats for the caller.
    return best_seq.tolist()
