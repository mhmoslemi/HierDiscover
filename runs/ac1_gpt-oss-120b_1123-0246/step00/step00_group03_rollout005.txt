propose_candidate
=================

A fast simulated‑annealing / hill‑climbing search for a non‑negative step
function that minimises `evaluate_sequence`.  The objective is

    score = 2·n·max(conv(a,a)) / (sum(a)**2)

(which is exactly what `evaluate_sequence` returns as long as no entry is
clipped to 0…1000).  The algorithm works as follows

1. **Initialisation** – use the global `height_sequence_1` if it exists,
   otherwise fall back to a uniform vector.  The vector is scaled so that
   ``sum(a) = sqrt(2·n)`` (any positive scaling leaves the score unchanged).

2. **Main loop** – while the allotted time has not expired  
   * compute the full convolution `b = a * a` (numpy `convolve`);
   * decide between a *targeted* update (40 % chance) and a *random* mass
     transfer (60 % chance).
   * *Targeted* update  
        – locate the index `k` where `b` attains its maximum;
        – among the pairs `(i, k‑i)` contributing to that maximum, pick the
          one with the largest product (the worst‑offending pair);
        – move a small fraction of the mass from the larger element of that
          pair to another index that contributes little to the same `k`;
   * *Random* update  
        – pick two positions `i≠j` uniformly, move a small fraction of the
          mass from `i` to `j`.
   * After the move, clip to the allowed range `[0,1000]` and renormalise
     the vector back to the original total sum (the problem is scale‑invariant).
   * Compute the cheap score `2·n·max(b)/(sum(a)**2)`.  If the new score is
     better, keep it.  Otherwise accept it with a Metropolis probability
     that slowly cools down (simulated annealing).

3. **Periodical large perturbation** – every few thousand iterations a
   block perturbation (the same heuristic used in the reference implementation)
   is applied to help the search escape plateaux.

4. **Return** – the best vector found is converted to a plain Python list
   and returned.  A final call to the official `evaluate_sequence` is made
   only for logging; the returned sequence itself is not re‑evaluated.

The method uses only `numpy`, `time`, `math` and the already‑imported

            b = np.convolve(a, a)
            k = int(b.argmax())                   # index attaining the current max

            # valid i where both i and k-i lie in [0,n)
            i_low = max(0, k - (n - 1))
            i_high = min(k, n - 1)
            idx = np.arange(i_low, i_high + 1, dtype=int)

            # contribution of each admissible pair to the responsible convolution entry
            contrib = a[idx] * a[k - idx]

            # largest offending pair (i_max, j_max = k-i_max)
            i_max = idx[int(contrib.argmax())]
            j_max = k - i_max

            # pick a destination index that contributes *little* to that same k
            # (i.e. has a small partner product).  If none is “tiny”, just pick a random one.
            partner = np.zeros(n, dtype=np.float64)
            mask = (np.arange(n) >= 0) & (np.arange(n) < n) & (k - np.arange(n) >= 0) & (k - np.arange(n) < n)
            partner[mask] = a[mask] * a[k - np.arange(n)[mask]]

            # indices with product at most 10 % of the worst offender
            low_candidates = np.where(partner <= 0.1 * partner[i_max])[0]
            if low_candidates.size == 0:
                low_candidates = np.arange(n)
            i_low_dest = int(rng.choice(low_candidates))

            # move a small amount from the larger entry of the worst pair to the low‑contrib index
            src = i_max if a[i_max] >= a[j_max] else j_max
            delta = base_step_frac * a[src]
            delta = min(delta, a[src])               # cannot move more than we have
            cand = a.copy()
            cand[src] -= delta
            cand[i_low_dest] += delta

        else:                                      # ----- RANDOM MASS TRANSFER -----
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            delta = base_step_frac * a[i]
            delta = min(delta, a[i])
            cand = a.copy()
            cand[i] -= delta
            cand[j] += delta

        # ----- enforce problem‑specific bounds ---------------------------------
        np.clip(cand, 0.0, 1000.0, out=cand)

        # re‑scale to keep the total sum exactly target_sum (scale invariance)
        s = cand.sum()
        if s == 0.0:
            continue
        cand *= (target_sum / s)

        # ----- cheap score evaluation -------------------------------------------
        cand_score = _score(cand, n)

        # ----- annealing acceptance ---------------------------------------------
        elapsed = time.monotonic() - start_time
        frac = elapsed / (deadline - start_time)
        temp = temp_start * (1.0 - frac) + temp_end * frac

        improved = cand_score < best_score
        if improved or rng.random() < math.exp(-(cand_score - best_score) / max(temp, 1e-12)):
            a = cand
            if improved:
                best = cand.copy()
                best_score = cand_score
                print(f"[{iteration:07d}] new best: {best_score:.6f}")

        # ----- occasional large block perturbation to escape plateaus ----------
        if iteration % 5000 == 0:
            width = max(1, n // 100)                   # a few per cent of the vector
            start = rng.integers(0, max(1, n - width + 1))
            factor = math.exp(rng.normal(0.0, 0.12))
            blk = a.copy()
            blk[start:start + width] *= factor
            np.clip(blk, 0.0, 1000.0, out=blk)
            blk *= (target_sum / blk.sum())
            blk_score = _score(blk, n)
            if blk_score < best_score:
                best = blk.copy()
                best_score = blk_score
                a = blk
                print(f"[{iteration:07d}] block jump: {best_score:.6f}")

    # -----------------------------------------------------------------
    # 4.  Final reporting ------------------------------------------------
    # -----------------------------------------------------------------
    final_seq = [float(x) for x in best]
    # one final call to the official evaluator (mainly for sanity‑checking)
    final_val = float(evaluate_sequence(final_seq))
    print(f"[done] iterations={iteration}  best_score={best_score:.6f}  eval={final_val:.6f}")

    return final_seq
