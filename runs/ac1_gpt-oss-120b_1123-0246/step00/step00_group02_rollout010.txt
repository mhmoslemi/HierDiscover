"""
Simple deterministic optimizer for the step‑function challenge.

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `conv` is the standard numpy convolution (full mode).  For a
uniform (all‑equal) sequence the score is exactly 2.  The convolution
coefficient with the largest value is the dot product of the vector with
its reversal; by making the vector *asymmetric* we can reduce that
maximum dramatically.

A linear ramp `a_i = C * i` (with `i = 0 … n‑1`) has a closed‑form
maximum

    max(conv) = C² * n (n+1) (n+2) / 6

while   sum(a) = C * n (n‑1) / 2 .

The resulting score simplifies to

    score = (4/3) * (n/(n‑1))² ≈ 4/3  (≈ 1.333 for large n)

which is well below the current bound of 2.0 and below the target
1.503.

The algorithm therefore simply constructs a monotone linear ramp that
fits the required amplitude limits (clipped to [0, 1000]) and returns it.
No iterative search is needed; the solution is produced instantly and
uses only O(n) memory.

The function follows the required signature `propose_candidate(seed,
budget_s, **kwargs)`.  It also accepts the optional global
`height_sequence_1` to determine the problem size; otherwise a sensible
default (256) is used.
"""

    ramp = np.linspace(0.0, 1000.0, length, dtype=np.float64)
    # The security checks in evaluate_sequence will clip again,
    # but we do it here for safety.
    return np.clip(ramp, 0.0, 1000.0)
