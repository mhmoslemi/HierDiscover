Subgradient descent optimiser for the max‑convolution objective.

The evaluation metric for a non‑negative step‑function a of length n,
with sum fixed to √(2 n), equals the maximum entry of the full linear
convolution a∗a (the exact score returned by ``evaluate_sequence`` is
exactly that maximum).  This routine directly minimises that maximum
by a projected sub‑gradient method:

* For the current sequence a the self‑convolution b = a∗a is computed.
* All indices where b attains its maximum are collected; a weight
  vector w (uniform over those indices) is built.
* The sub‑gradient of ``max(b)`` w.r.t. a is 2·corr(w, a), where
  ``corr`` denotes the full correlation.  The correlation is obtained
  efficiently with real FFTs.
* A decreasing step size (and optional momentum) is used, then the
  candidate is projected onto the feasible set:
  – non‑negative,
  – clipped to the range [0, 1000] (as required by the evaluator),
  – renormalised so that its ℓ₁‑norm equals √(2 n).

The optimiser runs several independent restarts (uniform, random,
geometric, U‑shaped, the previous best if available, etc.) inside the
given time budget and keeps the best exact solution found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper FFT utilities (no closures, top‑level as required)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _self_convolution_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Full linear convolution a * a using real FFTs.
    Returns the first (2*len(a)-1) entries.
    """
    fa = np.fft.rfft(a, fft_len)
    conv_full = np.fft.irfft(fa * fa, fft_len)
    return conv_full[: 2 * a.size - 1]


def _correlation_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Full correlation (w ⋆ a) = convolution(w[::-1], a) using FFTs.
    Returns an array of length len(w) + len(a) - 1.
    """
    w_rev = w[::-1]
    fw = np.fft.rfft(w_rev, fft_len)
    fa = np.fft.rfft(a, fft_len)
    corr_full = np.fft.irfft(fw * fa, fft_len)
    return corr_full[: len(w) + len(a) - 1]
