Propose a step‑function sequence that minimises
    2·n·max(conv(a,a)) / (sum(a)^2)

The algorithm works in several stages:

1.  Choose a set of candidate lengths (starting from the previously
    discovered sequence if available).  For each length we construct several
    diverse initial vectors (uniform, random, power‑law, Gaussian‑like and an
    interpolated copy of the current best).

2.  Optimise every start with an Adam‑style optimiser that minimises a
    smooth approximation of the maximum convolution value.
    The smooth max is obtained with a temperature‑parameter β and a
    soft‑max weighting w_k ∝ exp(β·(b_k−max(b))) where b = a*a.
    The gradient of this surrogate is evaluated efficiently with real FFTs:
        ∇ = 2·β·corr(w, a) .
    After each update the vector is projected onto the feasible set
    (non‑negative, ≤1000, and renormalised to the target sum √(2·n)).

3.  A simple simulated‑annealing acceptance rule (always accept improvements,
    occasionally accept worsening moves) together with occasional random
    multiplicative perturbations prevents the optimiser from getting stuck.

4.  The best sequence found so far (according to the exact
    ``evaluate_sequence`` function) is kept globally.  After the multi‑scale
    pass a final refinement of the global best is performed with a higher β
    to tighten the max‑approximation.

The whole routine respects the supplied time budget (default 950 s) and
returns the best sequence discovered as a plain list of floats.

# Helper functions (must be top‑level)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _self_convolution_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Linear convolution a * a using a real FFT of length ``fft_len``.
    Returns the first (2*len(a)-1) entries.
    """
    fa = np.fft.rfft(a, fft_len)
    conv_full = np.fft.irfft(fa * fa, fft_len)
    return conv_full[: 2 * a.size - 1]


def _correlation_fft(w: np.ndarray, a: np.ndarray, fft_len: int) -> np.ndarray:
    """
    Full correlation (w ⋆ a) = convolution(w[::-1], a) using a real FFT.
    ``w`` is the soft‑max weight vector (length 2·n−1) and ``a`` has length n.
    Returns an array of length len(w)+len(a)-1 (i.e. 3·n−2).
    """
    w_rev = w[::-1]
    fw = np.fft.rfft(w_rev, fft_len)
    fa = np.fft.rfft(a, fft_len)
    corr_full = np.fft.irfft(fw * fa, fft_len)
    return corr_full[: len(w_rev) + len(a) - 1]


def _softmax_weights(b: np.ndarray, beta: float) -> np.ndarray:
    """
    Compute numerically stable soft‑max weights from convolution values.
    Returns a vector w of same length as ``b`` that sums to 1.
    """
    cur_max = b.max()
    shifted = b - cur_max          # stability
    w = np.exp(beta * shifted)
    w_sum = w.sum()
    if w_sum == 0.0:
        w_norm = np.zeros_like(w)
        w_norm[np.argmax(b)] = 1.0
    else:
        w_norm = w / w_sum
    return w_norm


def _gradient_softmax(w_norm: np.ndarray, a: np.ndarray, fft_len: int, beta: float) -> np.ndarray:
    """
    Gradient of the soft‑max objective w.r.t. ``a``.
    Uses the correlation routine; returns a gradient of shape ``a``.
    """
    n = a.size
    corr = _correlation_fft(w_norm, a, fft_len)
    L = 2 * n - 1
    # gradient_i = 2·β·corr[L‑1‑i]
    grad = 2.0 * beta * corr[L - 1 - np.arange(n)]
    return grad
