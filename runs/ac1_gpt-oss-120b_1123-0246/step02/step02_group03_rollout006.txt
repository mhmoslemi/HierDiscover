Uniform baseline for the max‑autocorrelation step‑function problem.

The evaluation function is

    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

For any non‑negative vector `a`,

Cauchy–Schwarz inequality

    (∑ a_i)² ≤ n * ∑ a_i²   ⇒   score ≥ 2.

Equality holds iff all entries are equal, i.e. for a uniform step
function.  Hence the theoretical optimum of the provided evaluation
function is exactly 2, and a simple uniform vector attains this bound.
