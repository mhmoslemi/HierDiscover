Simple exponential‑gradient optimiser for the convolution‑max problem.

The algorithm works in three phases:

1. **Coarse power‑law seeding** – a dense grid over the exponent α∈[0.45,0.55] and
   offset β∈[0,1.5] is explored; the best candidate (lowest value of
   evaluate_sequence) becomes the starting point.

2. **Exponentiated Adam optimisation** – the decision variables are kept as
   log‑weights `w` so that `a = softmax(w)` automatically satisfies
   non‑negativity and ∑a = 1.  At each iteration a sub‑gradient of the
   objective `max(conv(a,a))` is built from a few largest convolution peaks,
   transformed to the `w`‑space (the Jacobian of the softmax) and fed into an
   Adam optimiser with a decaying learning‑rate schedule.

3. **Stochastic mass‑transfer moves** – with a small probability a random
   amount of probability mass is shifted from a heavy index to a light one.
   The move is accepted by a Metropolis rule with a cooling temperature,
   allowing the optimiser to escape flat plateaus.

All operations respect the bounds enforced by ``evaluate_sequence``.
The function stops after the allocated time budget (≈ budget_s seconds) and
returns the best sequence found.
"""

def _evaluate_fast(seq: np.ndarray) -> float:
    """
    Fast analogue of ``evaluate_sequence`` for a non‑negative vector that
    already satisfies the sum‑to‑1 normalisation.  The return value equals
    ``evaluate_sequence(seq)`` (the division by the squared sum cancels out).
    """
    total = seq.sum()
    if total < 1e-12:
        return float("inf")
    conv = np.convolve(seq, seq)
    max_b = conv.max()
    n = seq.size
    return float(2.0 * n * max_b)


def _shift(seq: np.ndarray, k: int) -> np.ndarray:
    """
    Return the vector d_i = a_{k-i} (zero outside the domain).  It is the
    sub‑gradient of the convolution term (a*a)[k] with respect to ``seq``.
    """
    n = seq.size
    out = np.zeros_like(seq)
    start = max(0, k - (n - 1))
    end = min(k, n - 1)
    if start <= end:
        idx = np.arange(start, end + 1, dtype=int)
        out[idx] = seq[k - idx]
    return out
