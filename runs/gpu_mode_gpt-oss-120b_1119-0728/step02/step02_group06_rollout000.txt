"""
TriMul (outgoing) – Triton‑accelerated forward pass.

The module implements the exact forward logic of the PyTorch reference
provided in the problem statement with the following optimisations:

*   Input LayerNorm and the final LayerNorm are kept in fp32 for numerical
    stability (the reference does the same).
*   All heavy linear projections and sigmoid‑gates are performed in fp16.
    The corresponding weight tensors are cast once to fp16.
*   The N³ “tri‑multiplicative” contraction
        out[b,i,j,h] = Σₖ left[b,i,k,h]·right[b,j,k,h]
    is realised as a batched matrix‑multiply (B·H GEMMs of size N×N) using
    `torch.bmm`, which on an H100 maps to a Tensor‑Core kernel.
*   The final element‑wise multiplication with the output‑gate is fused into
    a tiny Triton kernel (`_eltwise_mul_kernel`).  This removes an extra
    PyTorch kernel launch and keeps the data on‑device.
*   When a mask is supplied (`nomask == False`) the mask is applied
    *before* the gates, exactly as in the reference implementation.

The function `custom_kernel` receives a tuple as described in the task,
runs the forward pass and returns a tensor of shape
[batch, seq_len, seq_len, dim] in **float32**.
All operations are performed on the input device (CUDA) and respect the
provided weight and configuration dictionaries.
"""

import torch
import triton
import triton.language as tl


@triton.jit
def _eltwise_mul_kernel(
    a_ptr,               # float32*   – first operand (out_norm)
    b_ptr,               # float32*   – second operand (out_gate)
    c_ptr,               # float32*   – output buffer
    size,                # total number of elements
    BLOCK_SIZE: tl.constexpr,
):
    """
    Multiply two 1‑D views element‑wise.
    This kernel is launched with a 1‑D grid that covers ``size`` elements.
    """
    pid = tl.program_id(0)
    offs = pid * BLOCK_SIZE + tl.arange(0, BLOCK_SIZE)
    mask = offs < size

    a = tl.load(a_ptr + offs, mask=mask, other=0.0)
    b = tl.load(b_ptr + offs, mask=mask, other=0.0)
    tl.store(c_ptr + offs, a * b, mask=mask)


def custom_kernel(data):
    """
    Triton‑accelerated forward of the *outgoing* TriMul module.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask, weights, config)
        - input_tensor : torch.Tensor [B, N, N, dim] (float32)
        - mask         : torch.Tensor [B, N, N]  (bool / float)
        - weights      : dict of torch.Tensor (model weights)
        - config       : dict with keys ``dim``, ``hidden_dim``, ``nomask``

    Returns
    -------
    torch.Tensor
        Tensor of shape [B, N, N, dim] (float32) – the module output.
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", False)

    eps = 1e-5
    dev = input_tensor.device

    # ------------------------------------------------------------------
    # 1) Input LayerNorm (fp32)
    # ------------------------------------------------------------------
    x_norm = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
        eps=eps,
    )                                                   # [B, N, N, dim] float32

    # ------------------------------------------------------------------
    # 2) Cast to fp16 for all heavy linear work
    # ------------------------------------------------------------------
    x = x_norm.to(torch.float16)                        # [B, N, N, dim] fp16

    # ------------------------------------------------------------------
    # 3) Linear projections and gates (fp16)
    # ------------------------------------------------------------------
    # Linear weights are stored as fp32 – cast once to fp16
    left_proj_w = weights["left_proj.weight"].to(torch.float16)   # [hidden, dim]
    right_proj_w = weights["right_proj.weight"].to(torch.float16)
    left_gate_w = weights["left_gate.weight"].to(torch.float16)
    right_gate_w = weights["right_gate.weight"].to(torch.float16)
    out_gate_w = weights["out_gate.weight"].to(torch.float16)    # [hidden, dim]
    to_out_w = weights["to_out.weight"]                         # keep fp32 for final proj

    # projection
    left_proj = torch.nn.functional.linear(x, left_proj_w)      # [B,N,N,hidden] fp16
    right_proj = torch.nn.functional.linear(x, right_proj_w)

    # gate pre‑sigmoid
    left_gate_pre = torch.nn.functional.linear(x, left_gate_w)  # fp16
    right_gate_pre = torch.nn.functional.linear(x, right_gate_w)

    # ------------------------------------------------------------------
    # 4) Optional mask (applied before the sigmoid gates)
    # ------------------------------------------------------------------
    if (not nomask) and mask is not None:
        # mask shape [B, N, N] → broadcast over hidden dimension
        mask_h = mask.unsqueeze(-1).to(x.dtype)                 # [B,N,N,1] fp16
        left_proj = left_proj * mask_h
        right_proj = right_proj * mask_h

    # ------------------------------------------------------------------
    # 5) Apply sigmoid gates
    # ------------------------------------------------------------------
    left_gate = left_gate_pre.sigmoid()
    right_gate = right_gate_pre.sigmoid()

    left = left_proj * left_gate          # [B,N,N,hidden] fp16
    right = right_proj * right_gate

    # output gate (used after the output LayerNorm)
    out_gate = torch.nn.functional.linear(x, out_gate_w).sigmoid()   # [B,N,N,hidden] fp16

    # ------------------------------------------------------------------
    # 6) Tri‑multiplicative contraction: batched GEMM
    # ------------------------------------------------------------------
    B, N, _, _ = left.shape

    # left: (B, N, N, H) → (B*H, N, N)
    left_flat = left.permute(0, 3, 1, 2).contiguous().view(B * hidden_dim, N, N)
    # right needs to be transposed on the last two dims (j,k) → (k,j)
    right_flat = right.permute(0, 3, 2, 1).contiguous().view(B * hidden_dim, N, N)

    # GEMM: (B*H, N, N) @ (B*H, N, N)ᵀ  →  (B*H, N, N)
    out_flat = torch.bmm(left_flat, right_flat)               # fp16

    # reshape back to [B, N, N, hidden] and cast to fp32 for the next LayerNorm
    out = (
        out_flat.view(B, hidden_dim, N, N)
        .permute(0, 2, 3, 1)
        .float()
    )                                                          # [B,N,N,hidden] fp32

    # ------------------------------------------------------------------
    # 7) Output LayerNorm (fp32)
    # ------------------------------------------------------------------
    out_norm = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=eps,
    )                                                          # fp32

    # ------------------------------------------------------------------
    # 8) Fuse out_norm * out_gate using a tiny Triton kernel
    # ------------------------------------------------------------------
    out_gate_f32 = out_gate.float()       # [B,N,N,hidden] fp32
    gated = torch.empty_like(out_norm)    # allocate fp32 output buffer
    total_elems = out_norm.numel()
    BLOCK = 8192                         # 8K elements per program
    grid = (triton.cdiv(total_elems, BLOCK),)

    _eltwise_mul_kernel[grid](
        out_norm,
        out_gate_f32,
        gated,
        total_elems,
        BLOCK_SIZE=BLOCK,
    )

    # ------------------------------------------------------------------
    # 9) Final projection back to `dim` (fp32)
    # ------------------------------------------------------------------
    result = torch.nn.functional.linear(gated, to_out_w)   # [B,N,N,dim] fp32

    return result
```

**Explanation of the algorithm**

1. **Normalization** – The input pairwise tensor `[B,N,N,dim]` is layer‑normalised
   over the last dimension (`dim`).  This step stays in fp32 for precision.

2. **Half‑precision linear work** – The normalised tensor is cast to `float16`
   and passed through four linear layers (`left_proj`, `right_proj`,
   `left_gate`, `right_gate`).  The gates are passed through a sigmoid.
   If a mask is present it is applied *before* the gates, matching the
   reference code.

3. **Tri‑multiplicative contraction** – After gating we have two tensors
   `left` and `right` of shape `[B,N,N,hidden]`.  The core operation
   `out[b,i,j,h] = Σₖ left[b,i,k,h]·right[b,j,k,h]` is equivalent to a batch
   of matrix multiplications:
   ```
   left_flat  = left.permute(0,3,1,2).view(B*hidden, N, N)
   right_flat = right.permute(0,3,2,1).view(B*hidden, N, N)
   out_flat   = torch.bmm(left_flat, right_flat)
   ```
   On an H100 this leverages Tensor‑Core GEMMs.

4. **Output LayerNorm + gating** – The result is reshaped, cast back to
   `float32`, normalised, multiplied with the output gate, and finally
   projected back to the original `dim` with another linear layer.

5. **Triton fusion** – The only part still executed in PyTorch that would
   otherwise require an extra kernel launch is the final element‑wise
   multiplication (`out_norm * out_gate`).  This is replaced by the tiny
   Triton kernel `_eltwise_mul_kernel`, reducing launch overhead.

All tensors remain on the original CUDA device, and the function returns a
float‑32 tensor of the expected shape, compatible with the reference
implementation.
