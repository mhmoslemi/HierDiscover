Propose a step‑function sequence that minimises

    2·n·max(conv(a,a)) / (sum(a)**2)

The algorithm works entirely on the simplex Σa = 1 (scale‑invariant).
It combines several ideas that go beyond the previous implementation:

1. **Diverse initialisation** – we start from the previous best,
   from uniform, from a few random Dirichlet draws and from a family of
   “U‑shaped’’ power‑law profiles a_i ∝ ((i+1)*(n‑i))**p (p<0).  The best
   among them is retained as a warm start.

2. **Long Adam optimisation with a smooth‑max surrogate** – we use the
   same log‑sum‑exp smooth approximation of the max‑convolution, but
   increase the smoothness parameter β up to a much larger value
   (β≈400) and allow many more Adam steps (≈15000 per restart).  The learning
   rate decays slowly and we clip the soft‑max parameters to avoid overflow.

3. **Many short restarts** – after the first long run we launch a large
   number of cheap restarts (random Dirichlet seeds, 3000 – 6000 Adam
   steps each) while the time budget permits.  This mitigates getting
   trapped in a local minimum.

4. **Mixing of elite solutions** – the top few candidates found so far
   are linearly combined (convex mixtures) and the mixtures are re‑optimised.
   Convex combinations tend to flatten the autocorrelation further.

5. **Time‑aware loop** – the whole search stops a few seconds before the
   hard timeout, guaranteeing that a valid sequence is always returned.

The result is re‑scaled to the normalisation used by ``evaluate_sequence``,
clipped to the admissible range [0, 1000] and returned as a plain list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top‑level – no closures)

def _softmax(v: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (sum = 1, all entries ≥ 0)."""
    v_max = v.max()
    e = np.exp(v - v_max)
    return e / e.sum()


def _conv_full(a: np.ndarray, L: int) -> np.ndarray:
    """Linear convolution a * a, length = 2·len(a)‑1 (truncated)."""
    fft_a = np.fft.fft(a, n=L)
    conv = np.real(np.fft.ifft(fft_a * fft_a))
    return conv[: 2 * a.size - 1]


def _correlation_full(w: np.ndarray, a_rev: np.ndarray, L: int) -> np.ndarray:
    """Full correlation w ⋆ a_rev (length = len(w)+len(a_rev)‑1)."""
    fft_w = np.fft.fft(w, n=L)
    fft_rev = np.fft.fft(a_rev, n=L)
    corr = np.real(np.fft.ifft(fft_w * fft_rev))
    return corr[: len(w) + len(a_rev) - 1]


def _objective_score(a: np.ndarray, n: int, L_conv: int) -> float:
    """return 2·n·max(conv(a,a)) for a already on the simplex (Σa = 1)."""
    conv = _conv_full(a, L_conv)
    return 2.0 * n * conv.max()

    L_conv = 1 << ((2 * n - 1).bit_length())

            # shift by conv_max for numerical stability

            w = w_exp / w_exp.sum()               # shape (2n‑1,)

            dot = np.dot(grad_a, a)

            # ----- Adam update -----
            t = it + 1
            m = beta1 * m + (1.0 - beta1) * grad_v
            v2 = beta2 * v2 + (1.0 - beta2) * (grad_v ** 2)
