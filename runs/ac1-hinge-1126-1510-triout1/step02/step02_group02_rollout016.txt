Propose a step‑function with a low value of

    2 * n * max(conv(a, a)) / (sum(a)**2)

The algorithm works in three stages:

1.  **Parametric sweep** – generate a variety of simple families
    (power‑law, exponential, linear ramps, “U‑shape”, sin‑shapes,
    mixtures) and keep the best one (unit‑sum simplex).

2.  **Adam optimisation** – minimise a smooth approximation of the
    supremum norm of the convolution.  The smooth max is a soft‑max
    (log‑sum‑exp) with a temperature that is increased from a small
    value to a large one, so the optimiser first sees a smooth
    landscape and then focuses on the true max.  Gradients are obtained
    in the frequency domain and the iterate is projected onto the
    probability simplex after each step.

3.  **Fast hill‑climbing** – start from the best point found in (2) and
    perform many cheap mass‑transfer moves.  The convolution is kept
    incrementally: moving a small amount `δ` from index `i` to `j`
    updates the full convolution in O(n) by simple slice operations.
    Only improving moves (or rare uphill moves with a cooling temperature)
    are accepted, allowing thousands of cheap iterations within the time
    budget.

The final sequence is scaled to the normalisation used by the reference
code (`sum = sqrt(2·n)`).  The function returns a plain Python list of
floats and prints progress information.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """ Euclidean projection of v onto the simplex {x ≥ 0, Σx = 1}. """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w

# ----------------------------------------------------------------------
def _conv_max(a: np.ndarray, L: int) -> float:
    """Return max(conv(a, a)) for a (unit‑sum).  Uses FFT of length L."""
    fft_a = np.fft.fft(a, n=L)
    conv = np.real(np.fft.ifft(fft_a * fft_a))[: 2 * len(a) - 1]
    return conv.max()
