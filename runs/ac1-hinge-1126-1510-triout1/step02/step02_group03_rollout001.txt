assistantfinal**Solution Overview**

The evaluation function  

\[
score(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2}
\]

is invariant under positive scaling, therefore we may keep all candidates normalised to  
\(\sum_i a_i = 1\) during the search.  

For a fixed normalisation the problem of minimising the peak autocorrelation  

\[
\max_k (a*a)_k
\]

is convex: the mapping \(a\mapsto (a*a)_k\) is a quadratic form with a
positive‑semidefinite kernel, and the pointwise maximum of convex
functions is convex.  A convenient way to decrease the peak is the
following **alternating linear‑program / convex‑combination** scheme
(essentially the one described in the statement):

1. **Current vector** `f` (normalised, non‑negative).  
   Compute its peak \(M = \max_k (f*f)_k\).

2. **Linear program**  
   Find a non‑negative vector `g₀` of maximal \(\ell_1\)‑norm under the
   constraint that its convolution with `f` never exceeds the current
   peak:

   \[
   \max_{g\ge 0}\; \sum_i g_i \quad\text{s.t.}\quad (f*g)_k\le M
   \quad\forall k .
   \]

   The LP has `n` variables and `2n‑1` linear constraints, and is
   solved with SciPy’s HiGHS solver.

3. **Rescaling**  
   `g = g₀ / sum(g₀)` – now `g` also has unit sum (the scaling may
   violate the inequality, but we will blend it only a little).

4. **Best convex blend**  
   For a blend `h(t) = (1‑t)·f + t·g` the full autocorrelation can be
   written analytically

   \[
   (h*h)_k = (1-t)^2 (f*f)_k + t^2 (g*g)_k + 2t(1-t)(f*g)_k .
   \]

   We evaluate this expression for a small grid of `t∈[0,1]` and pick the
   value giving the smallest new peak.  The selected blend replaces `f`.

5. **Loop** – repeat the LP / blend step a few times, then start a new
   random restart (different initial `f`).  The best vector seen over
   all restarts is stored.

6. **Polishing** – after the main optimisation a cheap “mass‑swap”
   local search (randomly moving a tiny fraction of mass between two
   positions) is performed for the remaining time.

The algorithm finishes well inside the 1000 s budget and usually drives
the score below the target 1.503.

# ----------------------------------------------------------------------
# Helper: convolution via FFT (real sequences, full length)
# ----------------------------------------------------------------------
def _conv_fft(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a * a using FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)
    return conv[: 2 * n - 1]


def _conv_fft_general(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution a * b using FFT."""
    n, m = a.shape[0], b.shape[0]
    size = 1 << ((n + m - 1).bit_length())
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    conv = np.fft.irfft(fa * fb, size)
    return conv[: n + m - 1]


# ----------------------------------------------------------------------
# Build the matrix that maps g -> conv(f,g) (size (2n‑1) × n)
# ----------------------------------------------------------------------
def _build_conv_matrix(f: np.ndarray) -> np.ndarray:
    """Return dense matrix A with A @ g = conv(f,g) for all shifts."""
    n = f.shape[0]
    # first column of the Toeplitz matrix: f followed by zeros
    col = np.concatenate((f, np.zeros(n - 1, dtype=f.dtype)))
    # first row: f[0] and then zeros (length n)
    row = np.concatenate((f[:1], np.zeros(n - 1, dtype=f.dtype)))
    A = toeplitz(col, row)[: 2 * n - 1, :]  # keep only needed rows
    return A


# ----------------------------------------------------------------------
# Line‑search on the blending factor t ∈ [0,1]
# ----------------------------------------------------------------------
def _best_blend_t(f: np.ndarray,
                  conv_ff: np.ndarray,
                  g: np.ndarray,
                  conv_gg: np.ndarray,
                  conv_fg: np.ndarray) -> float:
    """Return t∈[0,1] that minimises the peak of ( (1‑t)f + t g )* itself."""
    # candidate grid – 21 uniformly spaced points works well
    t_grid = np.linspace(0.0, 1.0, 21)
    best_t = 0.0
    best_peak = conv_ff.max()

    # pre‑compute coefficients of the quadratic for every lag
    a2 = conv_gg            # coefficient of t²
    b2 = conv_ff            # coefficient of (1‑t)² = 1‑2t+ t² → handled later
    c2 = 2.0 * conv_fg      # coefficient of 2t(1‑t)

    for t in t_grid[1:]:  # skip t=0 – we already have its peak
        # (1‑t)² (f*f)  +  t² (g*g)  +  2t(1‑t) (f*g)
        conv_new = ((1.0 - t) ** 2) * b2 + (t ** 2) * a2 + t * (1.0 - t) * c2
        peak = conv_new.max()
        if peak < best_peak:
            best_peak = peak
            best_t = t
    return best_t

                p = np.random.uniform(0.1, 1.8)
                a = (np.arange(1, n + 1, dtype=float) ** (-p))
            else:  # "random"
                a = np.random.rand(n)

        a = np.clip(a, 0.0, None)
        a = _normalise(a)

        # ------------------------------------------------------------------
        # Alternating LP / blend iterations (few per restart)
        # ------------------------------------------------------------------
        max_iter = 8
        for it in range(max_iter):
            # time check (inner loop)
            if time.time() >= deadline:
                break

            # 1) current peak
            conv_ff = _conv_fft(a)
            M = conv_ff.max()

            # 2) build linear‑program matrix A (conv(f,g) = A @ g)
            A = _build_conv_matrix(a)

            # 3) solve LP: maximise sum(g)  s.t. A g ≤ M
            c = -np.ones(n)                      # minimising -sum(g) == maximising sum(g)
            b = np.full(2 * n - 1, M, dtype=float)
            # SciPy HiGHS works well for this size
            res = linprog(c,
                          A_ub=A,
                          b_ub=b,
                          bounds=(0, None),
                          method='highs',
                          options={'presolve': True, 'time_limit': max(0.0, deadline - time.time())})
            if not res.success:
                # LP failed – stop improving this restart
                break

            g0 = res.x
            sum_g0 = g0.sum()
            if sum_g0 <= 1e-12:
                # nothing useful was found

            g = g0 / sum_g0

            # 5) compute the needed convolutions for the line‑search
            conv_gg = _conv_fft(g)
            conv_fg = _conv_fft_general(a, g)

            # 6) find the best blending factor
            t_opt = _best_blend_t(a, conv_ff, g, conv_gg, conv_fg)

            if t_opt <= 0.0:
                # no improvement possible – stop this restart
                break

        # ------------------------------------------------------------------

                    best_seq = a_new.copy()
                    a_local = a_new
                    elapsed = time.time() - start_time
                    print(f"[Polish] improved to {best_score:.6f} (t={elapsed:.1f}s)")

        # continue with next restart if we still have time
        if time.time() >= deadline:
            break

    # ------------------------------------------------------------------
    # Fallback (should never be required)
    # ------------------------------------------------------------------
    if best_seq is None:
        fallback = np.sqrt(np.arange(1, n + 1, dtype=float)) - np.sqrt(np.arange(0, n, dtype=float))
        best_seq = _normalise(fallback)

    # ------------------------------------------------------------------
    # Final scaling to the required range [0,1000] (has no effect on score)
    # ------------------------------------------------------------------

    final_seq = np.clip(final_seq, 0.0, 1000.0)
