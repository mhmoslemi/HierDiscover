assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\qquad a_i\ge 0 .
\]

The ratio is scale‑invariant, therefore we keep the vector on the probability
simplex (`∑a = 1`).  
The algorithm consists of three stages

1. **Diverse random sampling** – generate thousands of candidate shapes
   (power‑law, exponential, two‑sided power‑law, logistic, linear).  
   Each candidate is normalised and scored with a cheap FFT‑based routine.
   The best few candidates are kept.

2. **Smoothed‑max projected gradient descent** – starting from the current
   best candidate we minimise a *soft* version of the max‑convolution

   \[
   G(a)=\sum_{k} w_k\;(a*a)_k,
   \qquad
   w_k=\frac{\exp\!\big(\alpha\big((a*a)_k-M\big)\big)}{\sum_j\exp\!\big(\alpha\big((a*a)_j-M\big)\big)},
   \]

   where `M = max(a*a)`.  
   For `α → ∞` the weights concentrate on the active indices,
   while for moderate `α` the whole profile is taken into account,
   which helps to escape the shallow plateaux that limited the previous
   pure sub‑gradient method.

   The Euclidean gradient of `G` is `∇G = 2·(w * a)` (linear convolution).
   A diminishing step size `η_t = η₀ / sqrt(t)` and a Euclidean projection
   onto the simplex keep the iterates feasible.

3. **Final polishing** – a few iterations of the classic
   “max‑index sub‑gradient” step are performed to fine‑tune the solution.

All work fits into the 1000 s wall‑clock budget; intermediate results are
printed so that progress is visible.  The function `propose_candidate`
returns the best sequence found as a plain Python list.

```python
"""Search for a non‑negative step‑function that minimises
   2 * n * max(conv(a, a)) / (sum(a) ** 2).

   The routine combines:
   1) a fast random sweep over several parametric families,
   2) a smoothed‑max projected gradient descent on the simplex,
   3) a short pure sub‑gradient polishing phase.

   It respects a 1000 s wall‑clock budget and returns the best sequence
   (as a Python list) discovered during the run.
"""

import time
import random
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (must stay at top‑level)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    p = 1
    while p < x:
        p <<= 1
    return p


def fast_score(seq: np.ndarray) -> float:
    """Cheap evaluation using FFT.  `seq` is assumed non‑negative."""
    n = seq.shape[0]
    s = seq.sum()
    if s < 1e-12:
        return float("inf")
    fft_len = next_pow2(2 * n)
    fa = np.fft.rfft(seq, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[: 2 * n - 1]
    max_conv = float(np.max(conv.real))
    return float(2.0 * n * max_conv / (s * s))


def project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # corner case: all zero (should not happen)
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def generate_power_law(n: int, p: float) -> np.ndarray:
    """a_i ∝ (i+1)^{-p}."""
    i = np.arange(1, n + 1, dtype=np.float64)
    return i ** (-p)


def generate_exponential(n: int, lam: float) -> np.ndarray:
    """a_i = exp(-lam * i)."""
    i = np.arange(n, dtype=np.float64)
    return np.exp(-lam * i)


def generate_two_sided_power_law(
    n: int,
    p_left: float,
    p_right: float,
    w_left: float = 1.0,
    w_right: float = 1.0,
) -> np.ndarray:
    """a_i = w_left·(i+1)^{-p_left} + w_right·(n-i)^{-p_right}."""
    i = np.arange(1, n + 1, dtype=np.float64)
    left = w_left * i ** (-p_left)
    right = w_right * (n - i + 1) ** (-p_right)
    return left + right


def generate_logistic(n: int, k: float = 0.001, shift: float = None) -> np.ndarray:
    """Logistic (sigmoid) decreasing shape."""
    if shift is None:
        shift = n / 2.0
    i = np.arange(n, dtype=np.float64)
    return 1.0 / (1.0 + np.exp(k * (i - shift)))


def generate_linear_decreasing(n: int) -> np.ndarray:
    """a_i = (n-i) (linearly decreasing)."""
    i = np.arange(n, 0, -1, dtype=np.float64)
    return i

        g = np.zeros_like(a)
        i_start = max(0, max_idx - (n - 1))
        i_end = min(n - 1, max_idx)
        if i_start <= i_end:
            i_range = np.arange(i_start, i_end + 1)
            j_range = max_idx - i_range
            g[i_range] = 2.0 * a[j_range]

        eta = 0.5 / math.sqrt(t + it)  # continue the decay
        a = project_simplex(a - eta * g)

    final_seq = a.tolist()
    # ------------------------------------------------------------------
    # 4. Verify with the provided expensive evaluator
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(final_seq)  # type: ignore[name-defined]  # noqa: F821
    print(f"Finished. Final score reported by evaluate_sequence = {final_score:.6f}")
    return final_seq
```
