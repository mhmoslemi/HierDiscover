"""
Propose a candidate step‑function sequence.

The evaluation function is scale invariant:
if every element of the sequence is multiplied by the same factor,
the returned value stays unchanged.
Hence we can freely scale a prototype sequence as long as every entry
remains ≤1000 (the internal capping of evaluate_sequence).

A simple family that yields a very low peak‑to‑average ratio is

    a_i = (i+1)^p   for i = 0 … n‑1

with a moderate exponent p≥2.  The convolution of such a power‑law
distribution becomes almost flat when n is large, and the theoretical
limit of the evaluation function is

    2·(p+1)^2·Beta(p+1,p+1)   (≈0.08 for p=4, ≈0.026 for p=5, ≈0.008 for p=6).

We therefore generate several candidates for p = 2 … 6 and a set of
lengths (up to a few hundred).  Each candidate is scaled so that its
largest entry equals exactly 1000 – this respects the internal limits
while leaving the evaluation unchanged.  The best candidate (smallest
value) is kept and a tiny random local search is performed until the
time budget expires.

The function returns the best sequence found; it never returns an empty
list and all entries are non‑negative and ≤1000, so it satisfies the
security checks of evaluate_sequence().
"""

import time
import random

def propose_candidate(seed=0, budget_s=1000, **kwargs):
    """Return a step‑function (list of heights) with a low evaluation score."""
    random.seed(seed)
    start = time.time()
    best_seq = None
    best_score = float('inf')
    max_val = 1000.0          # hard limit imposed by evaluate_sequence

    # ----------------------------------------------------------------------
    # 1) generate deterministic power‑law candidates and keep the best one
    # ----------------------------------------------------------------------
    for p in range(2, 7):                 # exponents 2 … 6

        for n in (20, 50, 100, 200, 400, 800):
            if n < 2:
                continue

            max_raw = float(n ** p)

            scale = min(1.0, max_val / max_raw)

            # build the scaled power‑law sequence
            seq = [((i + 1) ** p) * scale for i in range(n)]

            try:
                score = evaluate_sequence(seq)
            except Exception:
                score = float('inf')

            if score < best_score:
                best_score = score
                best_seq = seq
                print(f'New best: p={p}, n={n}, score={score:.6f}')

            if time.time() - start > budget_s - 2.0:

        if time.time() - start > budget_s - 2.0:

    if best_seq is not None:
