The score of a non‑negative sequence `a` (with `sum(a)=1`) is  

\[
\text{score}=2\,n\;\max_k (a*a)_k .
\]

The maximum is always attained for a convolution index where many large
entries of `a` overlap.  A simple decreasing power‑law  

\[
a_i\propto (i+{\sf shift}+1)^{-p}
\]

produces a fairly flat convolution.  Two extra degrees of freedom are
useful:

* **`p`** – controls how fast the sequence decays.  
* **`shift`** – moves the whole power‑law to the right, thereby
  reducing the very first entries (which otherwise dominate the early
  convolution values).

The optimizer explores a modest grid of lengths `n`, exponents `p` and
shifts, keeps the best candidate and then performs a local refinement
around the best parameters (finer `p`, `shift` and `n`).  Finally a few
tiny convex mixes with the uniform distribution are tried – this can
smooth isolated spikes without breaking the overall shape.

All evaluations are performed with the same arithmetic as
`evaluate_sequence` (clipping, normalization, convolution).  The whole
search fits easily into the 1000 s budget.

```python
"""
Propose a step‑function (list of non‑negative heights) that minimises

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The algorithm performs a bounded grid search over three
parameters:
    • n      – sequence length,
    • p      – power‑law exponent,
    • shift  – right shift of the power‑law (a_i ∝ (i+shift+1)^{-p}).

A coarse grid is evaluated first; afterwards a local refinement with
finer steps around the best parameters is executed.  Finally a few
small convex combinations with the uniform sequence are tested.
The best sequence found before the time budget expires is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def score_of_sequence(seq: np.ndarray) -> float:
    """
    Compute the same score that ``evaluate_sequence`` returns.
    ``seq`` is assumed to contain non‑negative numbers.
    """
    # apply the same safety checks as the original function
    arr = np.clip(seq, 0.0, 1000.0)
    sum_a = arr.sum()
    if sum_a < 0.01:
        return float("inf")
    conv = np.convolve(arr, arr)
    max_b = np.max(conv)
    n = arr.size
    return float(2.0 * n * max_b / (sum_a ** 2))


def generate_power_law_shift(n: int, p: float, shift: int = 0) -> np.ndarray:
    """
    Produce a non‑negative sequence of length ``n``:

        a_i ∝ (i + shift + 1)^{-p} ,  i = 0 … n‑1

    The sequence is normalised so that its sum equals 1.
    """
    # indices start at 1+shift, end at n+shift
    idx = np.arange(1 + shift, n + 1 + shift, dtype=np.float64)
    seq = idx ** (-p)
    seq /= seq.sum()
    return seq


def mix_with_uniform(base: np.ndarray, alpha: float) -> np.ndarray:
    """
    Return (1‑α)·base + α·uniform, where both operands sum to 1.
    The result automatically sums to 1 as well.
    """
    n = base.size
    uniform = np.full(n, 1.0 / n, dtype=np.float64)
    return (1.0 - alpha) * base + alpha * uniform

    best_score = float("inf")
    best_seq = None
    best_n = None
    best_p = None

    # sensible ranges – they have been chosen after inspecting the

    p_grid = np.linspace(0.30, 0.80, 26)      # step ≈ 0.02
```
