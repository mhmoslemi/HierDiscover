Iterative linear‑programming refinement for a non‑negative step function.

The evaluation metric is 2·n·max(conv(a,a)) / (sum(a)²).  Because the
metric is homogeneous we fix the ℓ₁‑norm of the candidate to 1 during
the search.  Starting from the classic “sqrt‑difference” profile we
repeat the following steps until the time budget expires:

1.  Compute the current autocorrelation peak M = max(conv(a,a)).
2.  Build the full convolution matrix A such that (A @ g)ₖ = (a * g)ₖ.
3.  Solve a linear program  
        maximise   1ᵀ g                (i.e. maximise the total mass)  
        subject to  A @ g ≤ M ,   g ≥ 0 .
    The optimum g pushes mass to positions that do not increase the
    current peak.
4.  Rescale g to have the same ℓ₁‑norm as a and mix the two vectors:
        a₊ = (1‑t)·a + t·g   with several trial values t∈{0.05,0.1,0.2,0.4,0.6}.
    The mixture that yields the largest reduction in the evaluation
    function is kept.
5.  If no improvement occurs for several iterations a small random
    redistribution is performed to escape possible stagnation.

After the main loop a short random‑move polishing phase is run.
Finally the best ℓ₁‑normalised vector is scaled so that its maximum
value equals 1000 (the scaling does not affect the score) and returned
as a plain Python list.

The algorithm only uses NumPy and SciPy (linprog with the HiGHS
solver) and respects the 1000‑second time limit.
"""

from scipy.optimize import linprog

# ----------------------------------------------------------------------
def build_convolution_matrix(f: np.ndarray) -> np.ndarray:
    """
    Return a dense matrix A such that (A @ g) is the full convolution f*g.
    A has shape (2*len(f)-1, len(f)).
    """
    n = f.size
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    # Each column i contains the coefficient f[i] on rows i … i+n‑1
    for i in range(n):
        A[i:i + n, i] = f[i]
    return A
