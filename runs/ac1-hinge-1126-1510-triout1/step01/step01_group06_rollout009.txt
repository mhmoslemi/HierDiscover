"""
Propose a coefficient sequence that minimizes the evaluation function.

Algorithm
---------
1. Initialise a non‑negative sequence `a` (the current step function).
   - If a global `height_sequence_1` exists, use it; otherwise start from the
     classic “sqrt‑difference’’ profile a_i = √(i+1)−√i, normalised to L1=1.

2. Iteratively improve the sequence by solving a linear programme.
   For the current sequence `a` let M = max(a∗a).  We maximise the total
   mass Σg_i while keeping the *mixed* convolution a∗g below the same bound M:
        maximise   Σ g_i
        subject to A·g ≤ M·1   (A is the Toeplitz matrix of a)
                    g_i ≥ 0.

   The solution `g` therefore has a larger ℓ1‑norm but respects the same
   peak‑convolution bound when mixed with `a`.

3. Mix the old and the new vectors:
   try mixing factors t∈{1, ½, ¼, ⅛, …}.  For each t compute
        candidate = (1−t)·a + t·g
   and evaluate it with `evaluate_sequence`.  Keep the best improving candidate
   (any improvement is accepted, even if the actual convolution peak rises,
   because the objective also contains Σa_i²).

4. Repeat steps 2‑3 until the allotted time (~1000 s) is exhausted.

5. Perform a short random‑move local‑search polish (transfer a tiny amount of
   mass between two random positions) to squeeze out a few extra gains.

6. Rescale the best sequence to the full [0, 1000] range (the evaluation metric
   is homogeneous, so the scaling does not affect the score) and return it.

The LP has only n≈1500 variables and 2·n−1≈3000 linear constraints, so it
solves quickly with SciPy's HiGHS interior‑point method.  By repeatedly
increasing the ℓ1‑norm while keeping the convolution peak under control the
algorithm pushes the ratio 2·n·max(b)/(Σa)² far below the previous best
≈1.576, aiming for the target ≈1.503.

"""

    """Return the maximum value of the full self‑convolution."""
    return float(np.convolve(seq, seq).max())
