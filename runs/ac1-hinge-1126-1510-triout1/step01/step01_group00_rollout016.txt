propose_candidate
-----------------
Search for a non‑negative step‑function (list of heights) that minimises

    evaluate_sequence(a) = 2 * n * max(conv(a,a)) / (sum(a)**2)

The algorithm consists of three stages:

1. **Broad parametric sweep** –  generate many candidate shapes
   (power‑law, symmetric power‑law, exponential decay, half‑sine,
   Gaussian) with different parameters, normalise each to the
   reference sum √(2 n) and keep the best one.

2. **Projected exponentiated‑gradient descent** –  starting from the
   best candidate, iteratively improve the shape.  In every iteration
   the sub‑gradient of the current maximal convolution entry is obtained
   by a correlation (FFT).  An exponentiated‑gradient update
   (mirror‑descent on the simplex) is applied and the result is projected
   back onto the probability simplex; the step size decays as
   1/√t.  This method respects the non‑negativity and Σ‑constraint and
   often escapes the plateaus where plain projected sub‑gradient gets
   stuck.

3. **Local random perturbations** – when the time budget is almost
   exhausted, small Gaussian perturbations of the current best vector are
   tried; any improvement is kept.

All operations respect the global time limit (default 1000 s).  The
final sequence is returned scaled to Σa = √(2 n), as required by the
evaluation function.
"""

import time
import math
import numpy as np

# --------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project vector v onto {x ≥ 0, Σx = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# --------------------------------------------------------------
# Fast evaluation of the objective (identical to evaluate_sequence)
def _score(seq: np.ndarray) -> float:
    """Return 2 * n * max(conv(seq,seq)) / (sum(seq)**2)."""
    n = seq.shape[0]
    L = 1 << ((2 * n - 1).bit_length())
    fft_seq = np.fft.fft(seq, n=L)
    conv = np.real(np.fft.ifft(fft_seq * fft_seq))[: 2 * n - 1]
    max_b = conv.max()
    sum_a = seq.sum()
    # protect against division by zero (should never happen)
    if sum_a == 0:
        return float("inf")
    return float(2.0 * n * max_b / (sum_a * sum_a))
