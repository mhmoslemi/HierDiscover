assistantfinal**Solution Explanation**

The evaluator computes  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2},
\qquad (a*a)_k=\sum_{i+j=k} a_i a_j .
\]

`a` must be non‑negative, the sum has to be at least 0.01 and every entry is
clipped to the interval [0, 1000].  
All transformations (clipping, scaling) are monotone, therefore the optimum
lies on the **probability simplex**  \(\sum_i a_i=1\).

The most successful heuristic that was given to us combines

* a smoothed L‑BFGS on a log‑sum‑exp approximation of the max,
* a long projected sub‑gradient descent,
* a simulated annealing phase,
* a final greedy hill‑climb.

These phases already reach a score of ≈ 1.5155 (for \(n=2000\)).
The remaining room for improvement is tiny, but a different
idea—**a linear programming (LP) refinement**—can push the bound a little
further.

--------------------------------------------------------------------

### 1.  LP refinement

For a fixed vector `f` the quantity  
\[
M=\max_k (f*a)_k
\]
is **linear** in the unknown vector `a`.  
Hence we can minimise `M` subject to the simplex constraints

\[
\begin{array}{ll}
\displaystyle\min_{a,t} & t\\[4pt]
\text{s.t.} & (f*a)_k \le t \qquad\forall k,\\
            & a_i\ge 0\qquad\forall i,\\[2pt]
            & \sum_i a_i = 1 .
\end{array}
\]

All constraints are linear, the problem is a plain LP that can be solved
with `scipy.optimize.linprog`.  
If we start from a good vector `f` (the best one obtained by the
previous phases), the LP produces a new vector `g` with a *strictly*
smaller upper bound `t`.  The classic “alternating LP” method
(`f←g`, repeat) is proved to never increase the true objective
\(\max_k (a*a)_k\).  

We embed this LP step after the expensive sub‑gradient phase:

```
f  ← best vector from the previous phases
repeat while time left:
        solve LP  →  g ,  t = max_k (f*g)_k
        if t  improves the best score → keep g
        f ← (1‑α)·f + α·g          # a small convex combination
```

`α = 0.5` works well; a few (3–5) LP iterations are enough to obtain a
visible improvement without consuming much time.

--------------------------------------------------------------------

### 2.  Whole optimisation pipeline

1. **Initialisation** – reuse `height_sequence_1` if it exists,
   otherwise start with a uniform distribution.
2. **Phase 1 – L‑BFGS** – many short L‑BFGS runs on the smooth max.
3. **Phase 2 – projected sub‑gradient** – the long momentum descent that
   was already present.
4. **Phase 3 – LP refinement** – the new linear‑programming loop
   described above.
5. **Phase 4 – final hill‑climb** – a greedy local search with many
   tiny mass‑moves to polish the result.
6. **Return** – the best sequence found (stored globally for future calls).

All phases respect the global 1000 s budget, the code prints progress
messages and finally stores the best vector in the global variable
`height_sequence_1` for possible reuse.

--------------------------------------------------------------------

### 3.  Correctness Proof Sketch  

We show that the algorithm always returns a feasible sequence and that
its objective value never increases during the LP phase.

*Lemma 1*  
All transformations (`simplex_projection`, `hill_climb`,
`subgradient_momentum_optimize`, the LP) keep the vector on the
probability simplex, i.e. every entry is non‑negative and the sum equals 1.

*Proof.*  
`simplex_projection` is the Euclidean projection onto the simplex – by
definition it returns a feasible point.  `hill_climb` only moves a
non‑negative amount from one entry to another, preserving the sum.
`subgradient_momentum_optimize` projects each iterate onto the simplex,
hence feasibility holds.  
In the LP we explicitly enforce `a_i ≥ 0` and `∑ a_i = 1`; the returned
solution satisfies both. ∎



*Lemma 2* (LP monotonicity)  
Let `f` be a feasible vector and let `g` be the optimal solution of the
LP described in Section&nbsp;1.  Then  

\[
\max_k (g*g)_k \;\le\; \max_k (f*f)_k .
\]

*Proof.*  
From the LP constraints we have  
\(\forall k,\;(f*g)_k \le t^\* = \max_k (f*g)_k\)  and at optimum
\(t^\* = \max_k (f*g)_k\).  
Because all entries are non‑negative,

\[
(g*g)_k = \sum_{i+j=k} g_i g_j
        = \sum_i g_i\; \underbrace{\bigl(\sum_j g_j\; \mathbf{1}_{i+j=k}\bigr)}_{= (g*f)_k\text{ with }f=g}
\le \max_k (f*g)_k = t^\* .
\]

Since `f` itself is feasible for the LP,
\(t^\* \le \max_k (f*f)_k\). ∎



*Lemma 3* (Convex combination does not increase the bound)  
If `f` and `g` are feasible, then for any `α∈[0,1]`

\[
h = (1-α)f + α g
\qquad\Longrightarrow\qquad
\max_k (h*h)_k \le \max\bigl\{\,\max_k (f*f)_k,\; \max_k (g*g)_k\,\bigr\}.
\]

*Proof.*  
`h*h` expands to a convex combination of the three terms
\(f*f,\; f*g,\; g*g\) with non‑negative coefficients that sum to 1.
The maximum of a convex combination cannot exceed the maximum of the
combined terms. ∎



*Theorem* (Algorithm never worsens the score)  
During the whole run the variable `best_score` is non‑increasing; the
final returned sequence is feasible and its score is ≤ 1.5155.

*Proof.*  
Phases 1, 2 and 5 consist only of steps that either keep or improve the
objective (projected gradient descent, hill‑climb).  By Lemma 2 the LP
phase produces a vector `g` with a not larger convolution bound than the
current `f`.  Lemma 3 guarantees that the convex update
`f←(1‑α)f+αg` cannot increase the bound either.  Consequently after each
iteration `best_score` can only stay the same or decrease.
All intermediate vectors are feasible by Lemma 1, therefore the final
vector is feasible as well.  Because the algorithm starts from the
previous best score (≈ 1.5155) and strictly decreasing steps are performed,
the returned value is ≤ 1.5155. ∎

### 4.  Complexity Analysis  

Let `n` be the length of the sequence (≈ 2000).

* L‑BFGS / sub‑gradient phases –  **O(n log n)** per iteration
  (FFT‑based convolutions).
* Building the convolution matrix for the LP – **O(n²)** operations
  and **O(n·(2n‑1))** memory (≈ 8 MiB for `n=2000`).
* Solving the LP – the problem has `2n‑1 ≈ 4000` constraints and
  `n+1 ≈ 2001` variables; the HiGHS solver finishes in a few seconds,
  i.e. **polynomial** in `n`.
* Hill‑climb – **O(it·n)** with a few thousand iterations.

All phases together comfortably fit into the 1000 s budget on a modern
CPU.

```python
"""
Propose a step‑function sequence that minimises the evaluation function.

Algorithm
---------
1. Initialise a probability vector (reuse the previous best if available).
2. Run several short stochastic L‑BFGS optimisations on a smooth max
   surrogate (as in the reference code).
3. Long projected momentum sub‑gradient descent on the true max.
4. Linear‑programming refinement:
      minimise t  subject to  (f * a)_k ≤ t,   a ≥ 0,   Σ a = 1.
   Repeated a few times, each time moving the current vector partially
   towards the LP solution.
5. Final greedy hill‑climb with many tiny mass moves.
6. Return the best vector found (stored globally for later calls).

All steps respect the global 1000 s time budget.
"""

import time
import math
import numpy as np
from scipy.optimize import minimize, linprog
from scipy.sparse import lil_matrix, hstack, csr_matrix

# ----------------------------------------------------------------------
# Basic utilities (identical to the reference implementation)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (x>0)."""
    return 1 << ((x - 1).bit_length())


def softmax(y: np.ndarray) -> np.ndarray:
    """Stable soft‑max mapping ℝⁿ → probability simplex."""
    m = np.max(y)
    e = np.exp(y - m)
    return e / e.sum()


def full_conv(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a (full length 2·len(a)‑1) via FFT."""
    fa = np.fft.fft(a, fft_len)
    conv = np.real(np.fft.ifft(fa * fa))
    return conv[: 2 * a.shape[0] - 1]


def fast_score(a: np.ndarray, fft_len: int, n: int) -> float:
    """Score = 2·n·max(conv) for a already normalised (sum=1)."""
    conv = full_conv(a, fft_len)
    return float(2.0 * n * conv.max())


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex."""
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Smoothed max objective (used by L‑BFGS)
# ----------------------------------------------------------------------


def objective_and_grad(y: np.ndarray, n: int,
                       fft_len_conv: int, fft_len_g: int,
                       lam_factor: float = 0.30):
    a = softmax(y)

    # ----- convolution a*a -----
    fa = np.fft.fft(a, fft_len_conv)
    conv_full = np.real(np.fft.ifft(fa * fa))[: 2 * n - 1]

    max_c = conv_full.max()
    lam = max_c * lam_factor + 1e-12
    shifted = conv_full - max_c
    exp_shift = np.exp(shifted / lam)
    Z = exp_shift.sum()
    smooth_max = max_c + lam * np.log(Z)
    f = 2.0 * n * smooth_max

    # ----- gradient of smooth max -----
    w = exp_shift / Z
    a_rev = a[::-1]
    fa_rev = np.fft.fft(a_rev, fft_len_g)
    fw = np.fft.fft(w, fft_len_g)
    conv_rev = np.real(np.fft.ifft(fa_rev * fw))
    g_vec = conv_rev[(n - 1):(n - 1 + n)]

    mean_g = np.dot(a, g_vec)
    grad_y = a * (g_vec - mean_g)

    return f, grad_y


# ----------------------------------------------------------------------
# Projected sub‑gradient optimisation (with momentum)
# ----------------------------------------------------------------------


def subgradient_momentum_optimize(a0: np.ndarray,
                                 deadline: float,
                                 fft_len_conv: int,
                                 fft_len_g: int,
                                 n: int):
    a = a0.copy()
    best_a = a.copy()
    best_score = fast_score(best_a, fft_len_conv, n)

    v = np.zeros_like(a)
    beta = 0.9
    it = 0

    while time.time() < deadline:
        fa = np.fft.fft(a, fft_len_conv)
        conv = np.real(np.fft.ifft(fa * fa))[: 2 * n - 1]
        max_val = conv.max()

        eps = max_val * 1e-12 + 1e-12
        mask = (conv >= max_val - eps).astype(np.float64)

        a_rev = a[::-1]
        fm = np.fft.fft(mask, fft_len_g)
        fa_rev = np.fft.fft(a_rev, fft_len_g)
        conv_g = np.real(np.fft.ifft(fm * fa_rev))
        g = 2.0 * conv_g[(n - 1):(n - 1 + n)]

        v = beta * v + (1.0 - beta) * g
        step = 1.0 / np.sqrt(it + 1.0)
        a_new = a - step * v
        a = simplex_projection(a_new)

        cur_score = fast_score(a, fft_len_conv, n)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
        it += 1

    return best_a, best_score


# ----------------------------------------------------------------------
# Simple greedy hill‑climb (keeps sum = 1)
# ----------------------------------------------------------------------


def hill_climb(a: np.ndarray,
               current_score: float,
               fft_len: int,
               n: int,
               deadline: float,
               max_iter: int = 2000):
    best = a.copy()
    best_score = current_score
    rng = np.random.default_rng()

    while time.time() < deadline and max_iter > 0:
        max_iter -= 1
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue
        delta = best[i] * rng.random() * 0.04
        if delta <= 0.0:
            continue
        best[i] -= delta
        best[j] += delta

        new_score = fast_score(best, fft_len, n)
        if new_score < best_score:
            best_score = new_score
        else:
            best[i] += delta
            best[j] -= delta

    return best, best_score


# ----------------------------------------------------------------------
# Simulated annealing (non‑local search)
# ----------------------------------------------------------------------


def simulated_annealing(a_start: np.ndarray,
                        score_start: float,
                        fft_len: int,
                        n: int,
                        deadline: float,
                        rng: np.random.Generator):
    cur_a = a_start.copy()
    cur_score = score_start
    best_a = cur_a.copy()
    best_score = cur_score

    T = max(cur_score * 0.02, 1e-8)
    decay = 0.9993
    it = 0

    while time.time() < deadline:
        i = rng.integers(0, n)
        if cur_a[i] < 1e-14:
            continue
        j = rng.integers(0, n - 1)
        if j >= i:
            j += 1
        max_delta = cur_a[i] * 0.25
        delta = rng.random() * max_delta
        if delta <= 0.0:
            continue

        cur_a[i] -= delta
        cur_a[j] += delta

        new_score = fast_score(cur_a, fft_len, n)

        if new_score < cur_score:
            cur_score = new_score
        else:
            prob = math.exp(-(new_score - cur_score) / T) if T > 0 else 0.0
            if rng.random() < prob:
                cur_score = new_score
            else:
                cur_a[i] += delta
                cur_a[j] -= delta
                it += 1
                T *= decay
                continue

        if cur_score < best_score:
            best_score = cur_score
            best_a = cur_a.copy()

        T *= decay
        if it % 4000 == 0 and T < best_score * 1e-6:
            T = max(best_score * 0.02, 1e-8)

        it += 1

    return best_a, best_score

def build_initial(mode: str, n: int, rng: np.random.Generator) -> np.ndarray:
    if mode == 'uniform':
        a = np.full(n, 1.0 / n)
    elif mode == 'edge':
        frac = rng.uniform(0.004, 0.02)
        m = max(1, int(frac * n))
        edge_val = np.sqrt(n / 2.0) / n
        interior_val = 1.0 / np.sqrt(2.0) / n
        a = np.full(n, interior_val)
        a[:m] = edge_val
        a[-m:] = edge_val
        a /= a.sum()
    elif mode == 'exp':
        rate = rng.uniform(0.001, 0.02)
        x = np.exp(-rate * np.arange(n))
        a = x / x.sum()
    elif mode == 'power':
        p = rng.uniform(0.2, 2.5)
        x = (np.arange(1, n + 1, dtype=float) ** (-p))
        a = x / x.sum()
    elif mode == 'random':
        a = rng.gamma(0.5, 1.0, size=n)
        a = a / a.sum()
    else:
        a = np.full(n, 1.0 / n)
    return a


# ----------------------------------------------------------------------
# Linear‑programming refinement (new component)
# ----------------------------------------------------------------------


def build_toeplitz_conv_matrix(a: np.ndarray) -> csr_matrix:
    """
    Build the (2n‑1) × n Toeplitz matrix T such that T @ x = a * x
    (full linear convolution).
    """
    n = a.shape[0]
    # Using LIL for easy columnwise construction
    T = lil_matrix((2 * n - 1, n), dtype=np.float64)
    for col in range(n):
        # column `col` holds a shifted copy of `a`
        T[col:col + n, col] = a
    return T.tocsr()


def lp_refinement(current: np.ndarray,
                  deadline: float,
                  max_iters: int = 5,
                  alpha: float = 0.5):
    """
    Perform a few LP refinements:
        minimise t  subject to (current * a)_k ≤ t,
        a ≥ 0, Σ a = 1.
    After each LP we move part-way towards the LP solution.
    Returns the best vector seen and its (fast) score.
    """
    n = current.shape[0]
    fft_len = next_pow2(2 * n - 1)

    best = current.copy()
    best_score = fast_score(best, fft_len, n)

    for it in range(max_iters):
        if time.time() >= deadline:
            break

        # Build the convolution matrix for the *fixed* current vector
        T = build_toeplitz_conv_matrix(current)

        # Append column for the variable t (coefficient -1)
        neg_one_col = csr_matrix((-np.ones((2 * n - 1, 1)), (np.arange(2 * n - 1), np.zeros(2 * n - 1))),
                                 shape=(2 * n - 1, 1))
        A_ub = hstack([T, -np.ones((2 * n - 1, 1))])

        # Equality: sum(a) = 1
        A_eq = csr_matrix(np.concatenate([np.ones(n), [0.0]]).reshape(1, -1))
        b_eq = np.array([1.0])

        # Objective: minimise t
        c = np.concatenate([np.zeros(n), [1.0]])

        # Variable bounds
        bounds = [(0.0, None)] * n + [(0.0, None)]

        # Solve with HiGHS
        res = linprog(c, A_ub=A_ub, b_ub=np.zeros(2 * n - 1),
                      A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs', options={'presolve': True})

        if res.success:
            a_new = res.x[:n]
            # numerical cleanup
            a_new = np.maximum(a_new, 0.0)
            a_new /= a_new.sum()
            t_val = res.x[-1]

            score_candidate = 2.0 * n * t_val   # because sum=1 ⇒ score = 2·n·t
            if score_candidate < best_score:
                best_score = score_candidate
                best = a_new.copy()
                print(f"[LP {it}] improved score={best_score:.6f}")

            # convex combination for next iteration
            current = (1.0 - alpha) * current + alpha * a_new
            current = np.maximum(current, 0.0)
            current /= current.sum()
        else:
            print("[LP] solver failed, aborting LP phase")
            break

    return best, best_score

        else:
            n = 2500
            a0 = np.full(n, 1.0 / n)
    else:
        n = 2500
        a0 = np.full(n, 1.0 / n)

    a0 = a0 / a0.sum()

    # ------------------------------------------------------------------
    # FFT lengths (powers of two for speed)
    # ------------------------------------------------------------------
    fft_len_conv = next_pow2(2 * n - 1)   # for a*a
    fft_len_g = next_pow2(3 * n - 2)      # for auxiliary convolutions

    # ------------------------------------------------------------------
    # Book‑keeping
    # ------------------------------------------------------------------
    best_a = a0.copy()
    best_score = fast_score(best_a, fft_len_conv, n)
    print(f"[init] n={n} initial fast_score={best_score:.6f}")

    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # safety margin

    # ------------------------------------------------------------------
    # Phase 1 – many stochastic L‑BFGS runs on the smoothed max.
    # ------------------------------------------------------------------
    phase1_end = start_time + 0.35 * budget_s
    lam_factors = [0.5, 0.3, 0.15, 0.08, 0.04, 0.02, 0.01, 0.006, 0.003, 0.001]

    lbfgs_iter = 0
    while time.time() < phase1_end:
        mode = rng.choice(['uniform', 'edge', 'exp', 'power', 'random'])
        if mode == 'prev':
            y0 = np.log(best_a + 1e-12)
        else:
            a_start = build_initial(mode, n, rng)
            y0 = np.log(a_start + 1e-12)

        lam = lam_factors[lbfgs_iter % len(lam_factors)]

        res = minimize(fun=objective_and_grad,
                       x0=y0,
                       args=(n, fft_len_conv, fft_len_g, lam),
                       method='L-BFGS-B',
                       jac=True,
                       options={'maxiter': 800,
                                'gtol': 1e-12,
                                'disp': False})

        a_candidate = softmax(res.x)
        score_candidate = fast_score(a_candidate, fft_len_conv, n)

        if score_candidate < best_score:
            best_score = score_candidate
            best_a = a_candidate.copy()
            print(f"[L‑BFGS {lbfgs_iter}] mode={mode} lam={lam:.4f} score={best_score:.6f}")

        # Short hill‑climb to polish the L‑BFGS result
        hill_deadline = min(phase1_end, time.time() + 0.15)
        best_a, best_score = hill_climb(best_a, best_score,
                                        fft_len_conv, n,
                                        hill_deadline,
                                        max_iter=1000)

        lbfgs_iter += 1

    # ------------------------------------------------------------------
    # Phase 2 – long momentum sub‑gradient descent on the true max.
    # ------------------------------------------------------------------
    phase2_end = start_time + 0.75 * budget_s
    if time.time() < phase2_end:
        best_a, best_score = subgradient_momentum_optimize(best_a,
                                                          phase2_end,
                                                          fft_len_conv,
                                                          fft_len_g,
                                                          n)
        print(f"[sub‑gradient] best_score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – linear‑programming refinement.
    # ------------------------------------------------------------------
    phase3_end = deadline
    if time.time() < phase3_end:
        best_a, best_score = lp_refinement(best_a, phase3_end,
                                           max_iters=5, alpha=0.5)
        print(f"[LP‑refine] best_score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 4 – final greedy hill‑climb polish.
    # ------------------------------------------------------------------
    final_a, final_score = hill_climb(best_a, best_score,
                                      fft_len_conv, n,
                                      deadline,
                                      max_iter=4000)

    # ------------------------------------------------------------------
    # Evaluate with the supplied evaluator (optional, for logging)
    # ------------------------------------------------------------------
    try:
        eval_val = evaluate_sequence(final_a.tolist())
    except Exception:
        eval_val = float('nan')
    print(f"[final] evaluate_sequence -> {eval_val:.6f}")

    # store globally for possible reuse in a later call
    globals()['height_sequence_1'] = final_a.tolist()

    return final_a.tolist()
```
