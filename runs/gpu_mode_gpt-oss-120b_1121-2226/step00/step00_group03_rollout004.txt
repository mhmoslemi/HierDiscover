analysisThe task:

We need to implement a custom forward kernel for TriMul. The TriMul consists of:

- Input: tensor x shape (B, N, N, D) where D = dim. Another mask shape (B, N, N) optionally. We also have weights (multiple weight matrices) and config.

- The operation:

1) Normalize x via layernorm grammar:

   x_norm = layernorm(x, weight=norm_weight, bias=norm_bias).

   The layernorm caches mean, var over dim axis (the last dimension). Input shape (B,N,N,D). Layernorm across D dimension: for each (b,i,j) we compute mean and variance of D entries.

2) left = left_proj(x_norm) = x_norm @ left_proj_weight.T (weight shape hidden_dim x dim). No bias.

3) right = right_proj(x_norm) = x_norm @ right_proj_weight.T

4) If mask is present, we do left = left * mask[..., None], similarly for right. So mask shape (B, N, N) broadcast along hidden_dim.

5) left_gate = sigmoid( left_gate(x_norm) ), where left_gate(x_norm) = x_norm @ left_gate_weight.T (no bias). Similarly right_gate and out_gate.

6) left = left * left_gate

   right = right * right_gate

7) Compute out = einsum('... i k d, ... j k d -> ... i j d', left, right)

   left shape: (B,N,N,h), where h = hidden_dim. Because after left_proj we have shape (B,N,N,H). Actually left_proj: mapping D->H. So left shape (B,N,N,H)

   right shape similarly (B,N,N,H). The einsum is sum over k dimension (the second N). The shape: left indices: ... i k d (i = first N index, k = second N index (like sum?), d = hidden_dim channels). Right indices: ... j k d (j = second N index of output, k same second dimension of right). So effectively out_{i,j,d} = sum_{k} left_{i,k,d} * right_{j,k,d}. Note that left's first two dims are (i,k). right's first two dims are (j,k). So for each d, it's like multiplication: left[b,i,:,d] (1 x N) dot right[b,j,:,d]^T (N x 1). So out shape (B,N,N,H). That's a matrix multiplication per channel d. This is essentially an N x N matrix computed by a batched, per-channel matrix multiplication: for each d in hidden_dim, compute left_slice: (B,N,N) -> we need left per channel d: shape (B,N,N). Multiply left_slice @ right_slice_T? Actually left_slice @ right_slice^T yields (B,N,N) where left_slice is (B,N,N) with sum over second dimension (k). But right_slice we need shape (B,N,N) not transposed? Let's compute:

If we fix b and d, we have left[b,i,k,d] and right[b,j,k,d] (k axis same). The sum over k: sum_k left_{i,k} * right_{j,k} yields left @ right.T (N x N matrix). Because right_{j,k} as row j, column k. Then right.T has element (k,j). Actually dot between left[i,:] (size N) and right[j,:] (size N). So out[i,j] = dot(left[i,:], right[j,:]). So out = left @ right^T (matrix multiplication where right's rows are used as row vectors but we need to sum across k). So we can compute that using batched matrix multiplication for each channel d: out[:, :, :, d] = left[..., :, :, d] @ right[..., :, :, d].transpose(-2, -1). So shape (B,N,N). Essentially we need to compute for each channel d and batch.

Thus TriMul is like:

Given left, right shape (B, N, N, H). For each h (call channels), compute out[...,h] = torch.einsum('bik, bjk -> bij', left[...,h], right[...,h]) = left[...,h] @ right[...,h].transpose(-2, -1). Note: The right operand's dimension is (B,N,N) with j index across first N, and k is second N, but we want dot across k, so yes we need to transpose second and third indices of right: shape (B,N,N) where we treat it as (B,N,N). So to compute all channels, we can reshape left to (B*H, N, N) and right to (B*H, N, N). Then compute out = torch.bmm(left_flat, right_flat.transpose(1,2)). Output shape (B*H,N,N) then reshape to (B,N,N,H). This is effective.

import triton
import triton.language as tl

@triton.jit
def tri_mul_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid = tl.program_id(0)
    pid_n = tl.program_id(1)
    pid_bc = tl.program_id(2)

    # Compute batch index and channel index
    batch = pid_bc // H
    ch = pid_bc % H

    # Compute offsets
    offs_m = pid * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # Masks for out of bounds
    mask_m = offs_m < N
    mask_n = offs_n < N

    # Initialize accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension
    for k in range(tl.cdiv(N, BLOCK_K)):
        # Compute K offsets
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # Compute pointers
        a_ptrs = left_ptr + batch * stride_left_b + ch * stride_left_h + offs_m[:, None] * stride_left_i + offs_k[None, :] * stride_left_k
        b_ptrs = right_ptr + batch * stride_right_b + ch * stride_right_h + offs_k[:, None] * stride_right_k + offs_n[None, :] * stride_right_i

        # Load with mask
        a = tl.load(a_ptrs, mask=mask_m[:, None] & mask_k[None, :], other=0.0)
        b = tl.load(b_ptrs, mask=mask_k[:, None] & mask_n[None, :], other=0.0)

        # Convert to fp32
        a = a.to(tl.float32)
        b = b.to(tl.float32)

        # Accumulate dot product
        acc += tl.dot(a, b)

    # Store result
    out_ptrs = out_ptr + batch * stride_out_b + ch * stride_out_h + offs_m[:, None] * stride_out_i + offs_n[None, :] * stride_out_j

    tl.store(out_ptrs, acc, mask=mask_m[:, None] & mask_n[None, :])

"""
TriMul forward implementation with a fused Triton kernel.

Algorithm
---------

1. **Layer‑norm** the input tensor over the last dimension.
2. **Linear projections** (left/right) and **gates** (left/right/out) are
   performed with `torch.nn.functional.linear`.  Gating uses a sigmoid.
3. Optional mask (shape [B,N,N]) is applied to the left/right projected tensors.
4. The core operation is
        out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
   which is a per‑channel matrix multiplication: for each hidden channel *h*
   we compute `left[...,h] @ right[...,h].T`.  This $O(N^3)$ step is
   implemented in a custom Triton kernel that treats each `(batch, hidden)`
   pair as an independent matrix‑multiply problem and tiles the computation
   along the M, N and K dimensions (BLOCK_M, BLOCK_N, BLOCK_K).
5. The result is multiplied by the *out‑gate*, layer‑normed, and passed through
   a final linear projection back to `dim`.

Only the expensive $N^3$ part is written in Triton; the surrounding operations
remain in PyTorch for simplicity and correctness.
"""

import math
import torch
import torch.nn.functional as F
import triton
import triton.language as tl


@triton.jit
def tri_mul_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_i, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    """
    Compute, for each (batch, hidden) pair:
        out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]

    left  : (B, N, N, H)  -> (i, k) matrix
    right : (B, N, N, H)  -> (j, k) matrix (accessed transposed)
    out   : (B, N, N, H)  -> (i, j) matrix
    """
    pid_m = tl.program_id(0)          # block along M (i dimension)
    pid_n = tl.program_id(1)          # block along N (j dimension)
    pid_bc = tl.program_id(2)         # combined batch * hidden

    # De‑interleave batch and hidden indices
    batch_idx = pid_bc // H
    hidden_idx = pid_bc % H

    # Offsets for the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # Accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension
    for kk in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = kk * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # ----------- Load a block of A (left) -----------------
        # A layout: (b, i, k, h)
        a_ptrs = (
            left_ptr
            + batch_idx * stride_left_b
            + hidden_idx * stride_left_h
            + offs_m[:, None] * stride_left_i
            + offs_k[None, :] * stride_left_k
        )
        a = tl.load(a_ptrs,
                    mask=(mask_m[:, None] & mask_k[None, :]),
                    other=0.0)
        a = a.to(tl.float32)

        # ----------- Load a block of B (right) -----------------
        # We need B transposed: access (k, j) instead of (j, k)
        # B layout: (b, j, k, h)  (same storage as left)
        b_ptrs = (
            right_ptr
            + batch_idx * stride_right_b
            + hidden_idx * stride_right_h
            + offs_k[:, None] * stride_right_k   # rows = k
            + offs_n[None, :] * stride_right_i   # cols = j
        )
        b = tl.load(b_ptrs,
                    mask=(mask_k[:, None] & mask_n[None, :]),
                    other=0.0)
        b = b.to(tl.float32)

        # ----------- Accumulate dot product --------------------
        acc += tl.dot(a, b)

    # ----------- Store the result ----------------------------
    out_ptrs = (
        out_ptr
        + batch_idx * stride_out_b
        + hidden_idx * stride_out_h
        + offs_m[:, None] * stride_out_i
        + offs_n[None, :] * stride_out_j
    )
    tl.store(out_ptrs, acc, mask=(mask_m[:, None] & mask_n[None, :]))


def custom_kernel(data):
    """
    Forward pass of the “outgoing” TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Tensor of shape [bs, seq_len, seq_len, dim] (float32)
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask_tensor, weights, config = data

    device = input_tensor.device
    dtype = input_tensor.dtype

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    bs, seq_len, _, _ = input_tensor.shape
    nomask = config.get("nomask", True)

    # ------------------------------------------------------------------
    # Retrieve weights (all expected to be on the same device)
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]

    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]

    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]

    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    to_out_weight = weights["to_out.weight"]

    # ------------------------------------------------------------------
    # 1) Layer‑norm over the last dimension (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(input_tensor,
                     normalized_shape=(dim,),
                     weight=norm_weight,
                     bias=norm_bias)

    # ------------------------------------------------------------------
    # 2) Linear projections (no bias)
    # ------------------------------------------------------------------
    left = F.linear(x, left_proj_weight)      # (B, N, N, H)
    right = F.linear(x, right_proj_weight)    # (B, N, N, H)

    # ------------------------------------------------------------------
    # 3) Optional mask (broadcast on hidden dim)
    # ------------------------------------------------------------------
    if not nomask:
        # mask is [B, N, N]; expand to [B,N,N,1]
        mask = mask_tensor.to(x.dtype).unsqueeze(-1)
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid) and element‑wise gating
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, left_gate_weight))
    right_gate = torch.sigmoid(F.linear(x, right_gate_weight))
    out_gate = torch.sigmoid(F.linear(x, out_gate_weight))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5) Core TriMul (batched per‑channel matmul) – Triton kernel
    # ------------------------------------------------------------------
    # Cast to FP16 for the kernel (saves bandwidth, still accumulates in FP32)
    left_h = left.to(torch.float16).contiguous()
    right_h = right.to(torch.float16).contiguous()

    # Output buffer (FP32 accumulator)
    out_h = torch.empty_like(left_h, dtype=torch.float32, device=device)

    # Strides (must be in element units, not bytes)
    stride_left_b, stride_left_i, stride_left_k, stride_left_h = left_h.stride()
    stride_right_b, stride_right_i, stride_right_k, stride_right_h = right_h.stride()
    stride_out_b, stride_out_i, stride_out_j, stride_out_h = out_h.stride()

    # Tiling parameters – chosen to give good occupancy on H100
    BLOCK_M = 128
    BLOCK_N = 128
    BLOCK_K = 32

    grid = (
        triton.cdiv(seq_len, BLOCK_M),   # M‑grid
        triton.cdiv(seq_len, BLOCK_N),   # N‑grid
        bs * hidden_dim,                 # batch‑×‑hidden grid
    )

    tri_mul_kernel[grid](
        left_h,
        right_h,
        out_h,
        bs,
        seq_len,
        hidden_dim,
        stride_left_b,
        stride_left_i,
        stride_left_k,
        stride_left_h,
        stride_right_b,
        stride_right_i,
        stride_right_k,
        stride_right_h,
        stride_out_b,
        stride_out_i,
        stride_out_j,
        stride_out_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )
    # out_h now holds the result of the einsum, shape (B,N,N,H), dtype FP32

    # ------------------------------------------------------------------
    # 6) Apply out‑gate, output layer‑norm and final linear projection
    # ------------------------------------------------------------------
    out = out_h * out_gate  # element‑wise gating, still (B,N,N,H)

    out = F.layer_norm(out,
                       normalized_shape=(hidden_dim,),
                       weight=to_out_norm_weight,
                       bias=to_out_norm_bias)

    # Final linear to project back to `dim`
    output = F.linear(out, to_out_weight)   # (B, N, N, dim)

    return output
```
