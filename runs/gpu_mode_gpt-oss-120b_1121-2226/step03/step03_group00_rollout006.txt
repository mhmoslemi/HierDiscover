      out = x_flat @ W.T   (W shape (5*H, D), x_flat shape (B·N·N, D))
   Split the result into
      left, right, left_gate_raw, right_gate_raw, out_gate_raw.
3. Optional mask (broadcasted) applied to left and right (FP32 → FP16).
4. Sigmoid gates and element‑wise gating:
      left  = left  * sigmoid(left_gate_raw)
      right = right * sigmoid(right_gate_raw)
      out_gate = sigmoid(out_gate_raw)
5. Core cubic update: for each hidden channel h,
      out_{i,j,h} = Σ_k left_{i,k,h} * right_{j,k,h}
   Implemented as a batched mat‑mul L @ Rᵀ using a custom Triton
   kernel that tiles the work with (BLOCK_M×BLOCK_N×BLOCK_K) =
   (128×128×32) and accumulates in FP32.
6. Output LayerNorm (FP16), multiply by out_gate and a final
   bias‑free linear projection back to the original dimension.
7. Cast the result back to FP32 (required API output).

All heavy compute (steps 2‑5) are performed in‑place on the GPU,
using mixed precision (FP16 inputs, FP32 accumulators) to exploit
the tensor‑core units of an H100.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# ----------------------------------------------------------------------
# Triton kernel: batched matrix multiplication C = A @ Bᵀ
#   A : (batch, M, K)   fp16
#   B : (batch, N, K)   fp16   (the kernel treats B as transposed)
#   C : (batch, M, N)   fp16   (accumulator is fp32)
# ----------------------------------------------------------------------
@triton.jit
def _batched_matmul_kernel(
    A_ptr, B_ptr, C_ptr,               # pointers
    M, N, K,                           # matrix dimensions
    stride_ah, stride_am, stride_ak,   # strides for A (batch, M, K)
    stride_bh, stride_bn, stride_bk,   # strides for B (batch, N, K)
    stride_ch, stride_cm, stride_cn,   # strides for C (batch, M, N)
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # Program IDs (block indices)
    pid_m = tl.program_id(0)   # row tile
    pid_n = tl.program_id(1)   # col tile
    pid_b = tl.program_id(2)   # batch tile (B * H)

    # Offsets of the current tile
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # Base pointers for this batch
    a_batch = A_ptr + pid_b * stride_ah
    b_batch = B_ptr + pid_b * stride_bh
    c_batch = C_ptr + pid_b * stride_ch

    # Accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension in tiles
    for k in range(0, tl.cdiv(K, BLOCK_K)):
        k_off = k * BLOCK_K

        # Load A tile: (BLOCK_M, BLOCK_K)
        a_ptrs = a_batch + offs_m[:, None] * stride_am \
                 + (k_off + tl.arange(0, BLOCK_K))[None, :] * stride_ak
        mask_a = (offs_m[:, None] < M) & (k_off + tl.arange(0, BLOCK_K)[None, :] < K)
        a_tile = tl.load(a_ptrs, mask=mask_a, other=0.0)   # fp16

        # Load B tile as (BLOCK_K, BLOCK_N) → effectively Bᵀ
        b_ptrs = b_batch + (k_off + tl.arange(0, BLOCK_K))[:, None] * stride_bk \
                 + offs_n[None, :] * stride_bn
        mask_b = (k_off + tl.arange(0, BLOCK_K)[:, None] < K) & (offs_n[None, :] < N)
        b_tile = tl.load(b_ptrs, mask=mask_b, other=0.0)   # fp16

        # Dot product with FP32 accumulator
        acc += tl.dot(a_tile, b_tile)

    # Write back result (cast to fp16)
    c_ptrs = c_batch + offs_m[:, None] * stride_cm + offs_n[None, :] * stride_cn
    mask_c = (offs_m[:, None] < M) & (offs_n[None, :] < N)
    tl.store(c_ptrs, acc.to(tl.float16), mask=mask_c)


def _batched_matmul_triton(A: torch.Tensor,
                           B: torch.Tensor,
                           BLOCK_M: int = 128,
                           BLOCK_N: int = 128,
                           BLOCK_K: int = 32) -> torch.Tensor:
    """
    Wrapper around the Triton kernel.  A and B must be fp16 tensors
    with shapes (batch, M, K) and (batch, N, K) respectively.
    Returns C of shape (batch, M, N) in fp16.
    """
    assert A.is_cuda and B.is_cuda, "CUDA tensors required"
    assert A.dtype == torch.float16 and B.dtype == torch.float16
    batch, M, K = A.shape
    _, N, Kb = B.shape
    assert K == Kb, "Inner dimensions must match"

    C = torch.empty((batch, M, N), dtype=torch.float16, device=A.device)

    stride_ah, stride_am, stride_ak = A.stride()
    stride_bh, stride_bn, stride_bk = B.stride()
    stride_ch, stride_cm, stride_cn = C.stride()

    grid = ((M + BLOCK_M - 1) // BLOCK_M,
            (N + BLOCK_N - 1) // BLOCK_N,
            batch)

    _batched_matmul_kernel[grid](
        A, B, C,
        M, N, K,
        stride_ah, stride_am, stride_ak,
        stride_bh, stride_bn, stride_bk,
        stride_ch, stride_cm, stride_cn,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,
        num_stages=4,
    )
    return C


# ----------------------------------------------------------------------
# Entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Triton‑accelerated forward pass for the TriMul “outgoing” module.

    Args:
        data: tuple (input_tensor, mask, weights_dict, config_dict)
              - input_tensor : torch.Tensor [B, N, N, D] (float32)
              - mask         : torch.Tensor [B, N, N] (bool/int) or None
              - weights       : dict of model parameters (float32)
              - config        : dict with keys "dim", "hidden_dim", optional "nomask"

    Returns:
        Tensor [B, N, N, D] (float32) – forward output.
    """
    # --------------------------------------------------------------
    # 1) Unpack inputs and configuration
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dim = config["dim"]                 # D
    hidden_dim = config["hidden_dim"]   # H
    nomask = config.get("nomask", True)

    # --------------------------------------------------------------
    # 2) Input LayerNorm (high‑precision FP32)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )  # [B, N, N, D]  (float32)

    B, N, _, _ = x.shape

    # --------------------------------------------------------------
    # 3) Fuse the five bias‑free linear projections into a single GEMM
    # --------------------------------------------------------------
    # Stack weights: order -> left_proj, right_proj, left_gate, right_gate, out_gate
    weight_list_fp16 = [
        weights["left_proj.weight"].to(torch.float16, device=device),
        weights["right_proj.weight"].to(torch.float16, device=device),
        weights["left_gate.weight"].to(torch.float16, device=device),
        weights["right_gate.weight"].to(torch.float16, device=device),
        weights["out_gate.weight"].to(torch.float16, device=device),
    ]
    fused_W = torch.cat(weight_list_fp16, dim=0)          # (5*H, D)  fp16

    # Reshape input to (B·N·N, D) for the fused GEMM
    x_flat = x.view(-1, dim)                             # (B*N*N, D)  fp32 → casted
    x_flat_f16 = x_flat.to(torch.float16)                # cast once for the GEMM

    # Perform the fused linear projection (fp16 inputs × fp16 weights → fp16 output)
    all_proj = F.linear(x_flat_f16, fused_W)             # (B·N·N, 5*H)  fp16

    # Reshape back to 4‑D tensor
    all_proj = all_proj.view(B, N, N, 5 * hidden_dim)    # [B,N,N,5H] fp16

    # --------------------------------------------------------------
    # 4) Slice the fused result into the three component groups
    # --------------------------------------------------------------
    left = all_proj[..., 0:hidden_dim]                                 # [B,N,N,H]
    right = all_proj[..., hidden_dim:2 * hidden_dim]                   # [B,N,N,H]

    left_gate_raw = all_proj[..., 2 * hidden_dim:3 * hidden_dim]       # [B,N,N,H]
    right_gate_raw = all_proj[..., 3 * hidden_dim:4 * hidden_dim]      # [B,N,N,H]
    out_gate_raw = all_proj[..., 4 * hidden_dim:]                      # [B,N,N,H]

    # --------------------------------------------------------------
    # 5) Optional binary mask (broadcasted on the feature dim)
    # --------------------------------------------------------------
    if not nomask and mask is not None:
        # mask → FP16 & broadcast
        mask_fp16 = mask.to(torch.float16, device=device).unsqueeze(-1)  # [B,N,N,1]
        left = left * mask_fp16
        right = right * mask_fp16

    # --------------------------------------------------------------
    # 6) Compute sigmoid gates (still fp16) and apply them
    # --------------------------------------------------------------
    left_gate = torch.sigmoid(left_gate_raw)          # fp16
    right_gate = torch.sigmoid(right_gate_raw)        # fp16
    out_gate = torch.sigmoid(out_gate_raw)            # fp16

    left = left * left_gate
    right = right * right_gate

    # --------------------------------------------------------------
    # 7) Core cubic update – batched mat‑mul over the last two axes
    #    Shape needed for the Triton kernel: (B·H, N, N)
    # --------------------------------------------------------------
    # Rearrange to (batch, hidden, i, k) -> view as (B·H, N, N)
    left_mat = left.permute(0, 3, 1, 2).contiguous().view(B * hidden_dim, N, N)   # fp16
    right_mat = right.permute(0, 3, 1, 2).contiguous().view(B * hidden_dim, N, N)  # fp16

    # Batched matrix multiplication: L @ Rᵀ for each hidden channel
    out_mat = _batched_matmul_triton(
        left_mat,
        right_mat,
        BLOCK_M=128,
        BLOCK_N=128,
        BLOCK_K=32,
    )   # (B·H, N, N)  fp16

    # Reshape back to [B, N, N, H]
    out = out_mat.view(B, hidden_dim, N, N).permute(0, 2, 3, 1).contiguous()  # fp16

    # --------------------------------------------------------------
    # 8) Output LayerNorm (fp16), out‑gate multiplication and final projection
    # --------------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"].to(torch.float16, device=device)
    to_out_norm_b = weights["to_out_norm.bias"].to(torch.float16, device=device)

    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=to_out_norm_w,
        bias=to_out_norm_b,
    )   # fp16

    out = out * out_gate

    to_out_w = weights["to_out.weight"].to(torch.float16, device=device)   # (D, H)
    out = F.linear(out, to_out_w)                                         # fp16, shape [B,N,N,D]

    # --------------------------------------------------------------
    # 9) Cast the final result back to FP32 as required by the API
    # --------------------------------------------------------------
    out = out.to(torch.float32)

    return out
```

**Explanation of key optimisations**

* **Fused linear projection** – Instead of five separate `nn.Linear` calls we stack the five weight matrices and perform a single GEMM (`x_flat @ W.T`). This reduces the memory traffic of the input tensor (`x`) from five reads to a single read, which is the dominant cost for large sequence lengths.

* **Mixed‑precision** – All expensive dense operations (the fused GEMM and the cubic `L @ Rᵀ` multiplication) run in FP16 with FP32 accumulation, fully exploiting the Tensor‑Core units of an H100. Only the LayerNorms are kept in FP32 for numerical stability.

* **Triton‑accelerated batched mat‑mul** – The core O(N³) operation is performed by a custom Triton kernel that tiles the matrices (128×128×32) and uses `tl.dot` (Tensor‑Core friendly) with FP32 accumulation. The kernel processes each `(batch * hidden_dim)` slice independently, providing massive parallelism.

* **In‑place view / permute tricks** – By permuting `(B, N, N, H) → (B, H, N, N)` and reshaping, we obtain a contiguous layout that matches the kernel’s expectations without extra copies.

* **Mask handling** – The mask is applied only once, after the fused projection, and in the same precision as the projections to avoid extra casts.

Overall the implementation minimizes the number of passes over the large `[B, N, N, D]` tensor, keeps the most compute‑intensive part on the GPU in a highly‑optimised Triton kernel, and stays fully compatible with the required forward‑only API.
