Triton‑accelerated “outgoing” TriMul (AlphaFold3).

Algorithm
---------

1️⃣ Input LayerNorm (float‑32, cuDNN).

2️⃣ Cast to fp16 – all heavy work runs in half precision.

3️⃣ **Fused linear projections**:  
   Concatenate the two projection matrices (left/right) → a single
   GEMM `x_flat @ W_proj` that produces `[B·N·N, 2·H]`.  The result is
   split into `left` and `right`.

4️⃣ **Fused gate linear layers**:  
   Concatenate the two gate matrices (left/right) → a single GEMM
   `x_flat @ W_gate`.  Apply `sigmoid` and split into `left_gate`,
   `right_gate`.  The `out_gate` (used after the output LayerNorm) is
   computed with a third GEMM.

5️⃣ **Trition kernel – gate multiplication**:  
   A tiny Triton kernel fuses the two element‑wise products
   `left *= left_gate` and `right *= right_gate` (optionally also the
   binary mask).  This reduces three separate element‑wise passes to one.

6️⃣ **Cubic update (core of TriMul)**:  
   The outgoing update is
   `out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]`.
   It is expressed as `torch.einsum('b i k h, b j k h -> b i j h', left, right)`,
   which lets cuBLAS handle the reduction without any temporary
   transposes or copies (no costly `permute(...).contiguous()`).

7️⃣ Output LayerNorm on the hidden dimension (fp16).

8️⃣ Scale by `out_gate` and apply the final bias‑free linear projection
   back to the original feature dimension.

9️⃣ Cast the result back to float32 – the API expects fp32.

The implementation reduces the number of large GEMMs from four to three,
eliminates an expensive data‑reordering before the N³ batched matmul,
and fuses the gating element‑wise work into a single Triton kernel.

    offs = pid * BLOCK_SIZE + tl.arange(0, BLOCK_SIZE)
    mask = offs < total

    # Load
    l  = tl.load(left_ptr + offs,       mask=mask)
    r  = tl.load(right_ptr + offs,      mask=mask)
    lg = tl.load(left_gate_ptr + offs,  mask=mask)
    rg = tl.load(right_gate_ptr + offs, mask=mask)

    # Multiply (gates are already sigmoid‑ed)
    l = l * lg
    r = r * rg

    # Store in‑place
    tl.store(left_out_ptr  + offs, l, mask=mask)
    tl.store(right_out_ptr + offs, r, mask=mask)


def _apply_gates_triton(left, right, left_gate, right_gate, block_size: int = 1024):
    """Fuse `left *= left_gate` and `right *= right_gate` with a Triton kernel."""
    total = left.numel()
    grid = ( (total + block_size - 1) // block_size, )
    _gate_mul_kernel[grid](
        left,
        right,
        left_gate,
        right_gate,
        left,          # write‑back to the same buffer (in‑place)
        right,
        total,
        BLOCK_SIZE=block_size,
        num_warps=4,
        num_stages=2,
    )
    return left, right


# ----------------------------------------------------------------------
# Entry point required by the evaluation harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Triton‑accelerated forward pass of the TriMul “outgoing” module.

    Args:
        data: tuple (input_tensor, mask, weights_dict, config_dict)
            - input_tensor : torch.Tensor [B, N, N, D] (float32)
            - mask         : torch.Tensor [B, N, N] (bool/int) or None
            - weights      : dict of model parameters (float32)
            - config       : dict with keys "dim", "hidden_dim", optional "nomask"

    Returns:
        Tensor of shape [B, N, N, D] (float32) – the forward output.
    """
    # --------------------------------------------------------------
    # 1) Unpack and basic shapes
    # --------------------------------------------------------------
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    B, N, _, D = input_tensor.shape
    dim = config["dim"]                # should equal D
    hidden_dim = config["hidden_dim"]  # H
    nomask = config.get("nomask", True)

    # --------------------------------------------------------------
    # 2) Input LayerNorm (float32)
    # --------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )  # [B, N, N, D]  (float32)

    # --------------------------------------------------------------
    # 3) Cast to fp16 and flatten for GEMMs
    # --------------------------------------------------------------
    x_f16 = x.half()                               # [B, N, N, D]  fp16
    x_flat = x_f16.view(-1, dim)                    # [(B·N·N), D]

    # --------------------------------------------------------------
    # 4) Fused projection (left & right)  → 2 * hidden_dim channels
    # --------------------------------------------------------------
    proj_weight = torch.cat(
        [weights["left_proj.weight"], weights["right_proj.weight"]], dim=0
    ).half()                                        # [2·H, D]
    proj = F.linear(x_flat, proj_weight)            # [(B·N·N), 2·H]  fp16

    left  = proj[:, :hidden_dim].view(B, N, N, hidden_dim)   # [B,N,N,H]
    right = proj[:, hidden_dim:].view(B, N, N, hidden_dim)   # [B,N,N,H]

    # --------------------------------------------------------------
    # 5) Fused gate linear layers (left_gate & right_gate)
    # --------------------------------------------------------------
    gate_weight = torch.cat(
        [weights["left_gate.weight"], weights["right_gate.weight"]], dim=0
    ).half()                                        # [2·H, D]
    gate = F.linear(x_flat, gate_weight)            # [(B·N·N), 2·H]  fp16

    left_gate  = torch.sigmoid(gate[:, :hidden_dim]).view(B, N, N, hidden_dim)   # fp16
    right_gate = torch.sigmoid(gate[:, hidden_dim:]).view(B, N, N, hidden_dim)   # fp16

    # --------------------------------------------------------------
    # 6) Out‑gate (used after output LayerNorm)
    # --------------------------------------------------------------
    out_gate = torch.sigmoid(
        F.linear(x_flat, weights["out_gate.weight"].half())
    ).view(B, N, N, hidden_dim)                    # fp16

    # --------------------------------------------------------------
    # 7) Fuse gate multiplication with a tiny Triton kernel
    # --------------------------------------------------------------
    left, right = _apply_gates_triton(left, right, left_gate, right_gate)

    # --------------------------------------------------------------
    # 8) Optional mask (broadcast over the hidden dimension)
    # --------------------------------------------------------------
    if not nomask and mask is not None:
        # mask shape → [B, N, N, 1] (fp16), automatically broadcasts over H
        mask_f16 = mask.to(torch.float16).unsqueeze(-1)
        left = left * mask_f16
        right = right * mask_f16

    # --------------------------------------------------------------
    # 9) Core cubic update – outgoing TriMul
    # --------------------------------------------------------------
    # Einstein summation implements:
    # out[b,i,j,h] = Σ_k left[b,i,k,h] * right[b,j,k,h]
    out = torch.einsum('b i k h, b j k h -> b i j h', left, right)   # fp16

    # --------------------------------------------------------------
    # 10) Output LayerNorm (hidden dimension)
    # --------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"].half(),
        bias=weights["to_out_norm.bias"].half(),
    )  # fp16

    # --------------------------------------------------------------
    # 11) Scale with out_gate and final projection back to `dim`
    # --------------------------------------------------------------
    out = out * out_gate                                            # fp16
    out = F.linear(out, weights["to_out.weight"].half())           # fp16

    # --------------------------------------------------------------
    # 12) Cast back to float32 (API requirement) and return
    # --------------------------------------------------------------
    return out.float()
