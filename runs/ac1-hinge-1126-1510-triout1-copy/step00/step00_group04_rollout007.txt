Linear‑ramp construction for the step‑function problem.

The heights are taken to increase linearly from 0 to 1000 (inclusive) over the
chosen sequence length.  For a sequence a_i = c·i (i = 0 … n‑1) the evaluation

    E(n) = 2·n·max(a*a) / (sum a)^2 = 4·(n‑2) / (3·(n‑1)) → 4/3 ≈ 1.33.

Thus for any reasonable length n this construction yields a score well below the
target of 1.503 without any further optimisation.  The algorithm simply chooses
the length (preferring the length of the previously known construction if
available) and returns the scaled ramp.  No external files or network access is
used.
"""

    **kwargs

    """
    # Use the length of the previously discovered sequence if it exists.
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
