assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{\bigl(\sum a_i\bigr)^2},
\]

where `a` is a non‑negative step–function (a list of heights) and `*` denotes the linear convolution.
Because `F(c·a)=F(a)`, the optimisation can be performed under the normalisation  

\[
\sum_i a_i = 1 .
\]

The code below implements a multi‑stage search:

1. **Global shape search** – families of symmetric analytical shapes
   (`power`, `beta` and `exponential`) are sampled on a coarse grid.
   Each shape is normalised, its fast (FFT based) score is computed and the
   best shape is kept.

2. **Continuation optimisation** – the best shape is turned into logits
   `y` (`a = softmax(y)`) and a *smooth‑max* approximation of the true
   objective is minimised with L‑BFGS‑B.  A schedule of decreasing smoothing
   parameters (`lam_factor`) drives the solution towards the real max.

3. **Targeted hill‑climbing** – after the L‑BFGS phase a greedy local
   improvement moves a small fraction of mass from indices that contribute
   heavily to the current maximal convolution entry to indices that contribute
   little.  Symmetry (`a_i = a_{n‑1‑i}`) is forced after each move and the
   vector is re‑normalised.

4. **Iterated random restarts** – while time permits the whole pipeline
   (shape → L‑BFGS → hill‑climb) is repeated from many random initial logits.
   The best sequence found during the whole run is returned.

All heavy work (convolutions, smooth‑max, gradients) uses FFTs
(`np.fft`) and runs in *O(n log n)*.
The algorithm respects the 1000 s time budget, prints progress and finally
calls `evaluate_sequence` on the best candidate.

```python
"""Step‑function optimiser.

The optimiser works in three layers:
1. a coarse grid over symmetric analytic shapes (power, beta, exponential)
   provides good starting points;
2. a continuation method minimises a smooth‑max surrogate of the true
   max‑convolution using L‑BFGS‑B on the soft‑max (logit) parametrisation;
3. a targeted greedy hill‑climb reduces the true max directly while
   enforcing symmetry a_i = a_{n‑1‑i}.

The whole pipeline is repeated with many random restarts until the time
budget expires.  The best sequence found is returned as a plain list of
non‑negative floats.
"""

import time
import numpy as np
from scipy.optimize import minimize

# ------------------------------------------------------------
# Basic utilities
# ------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (x>0)."""
    return 1 << ((x - 1).bit_length())


def softmax(y: np.ndarray) -> np.ndarray:
    """Stable soft‑max, returns a probability vector (sum = 1)."""
    m = np.max(y)
    e = np.exp(y - m)
    return e / e.sum()


def conv_fft(a: np.ndarray, fft_len: int, n: int) -> np.ndarray:
    """Linear convolution a*a using FFT (real part only)."""
    fa = np.fft.fft(a, fft_len)
    conv = np.fft.ifft(fa * fa)
    return np.real(conv)[: 2 * n - 1]


def fast_score(a: np.ndarray, fft_len: int, n: int) -> float:
    """Fast evaluation of 2·n·max(a*a) for a normalised probability vector."""
    conv = conv_fft(a, fft_len, n)
    return float(2.0 * n * conv.max())


def symmetrize_and_normalise(a: np.ndarray) -> np.ndarray:
    """Enforce a_i = a_{n‑1‑i} and renormalise to sum 1."""
    a = (a + a[::-1]) * 0.5
    s = a.sum()
    if s > 0.0:
        a /= s
    else:
        a[:] = 1.0 / a.size
    return a


# ------------------------------------------------------------
# Smooth‑max objective (used by L‑BFGS)
# ------------------------------------------------------------


def objective_and_grad(
    y: np.ndarray,
    n: int,
    fft_len_conv: int,
    fft_len_g: int,
    lam_factor: float = 0.30,
) -> tuple[float, np.ndarray]:
    """
    Smooth‑max surrogate of 2·n·max(a*a) and its gradient w.r.t.
    the unconstrained logit vector y.
    """
    # a lives on the probability simplex
    a = softmax(y)

    # ----- convolution a*a -----
    fa = np.fft.fft(a, fft_len_conv)
    conv = np.real(np.fft.ifft(fa * fa))[: 2 * n - 1]

    # smooth‑max of the convolution
    max_c = conv.max()
    lam = max_c * lam_factor + 1e-12
    shifted = conv - max_c                 # now max = 0
    exp_shift = np.exp(shifted / lam)
    Z = exp_shift.sum()
    smooth_max = max_c + lam * np.log(Z)
    f = 2.0 * n * smooth_max

    # ----- gradient of smooth‑max w.r.t. conv -----
    w = exp_shift / Z                     # d smooth_max / d conv_i

    # ----- back‑propagation through the convolution -----
    # g_i = Σ_j a_j * w_{i+j}, i = 0..n‑1
    fa_rev = np.fft.fft(a[::-1], fft_len_g)
    fw = np.fft.fft(w, fft_len_g)
    conv_rev = np.real(np.fft.ifft(fa_rev * fw))
    g_vec = conv_rev[(n - 1) : (n - 1 + n)]

    # ----- chain‑rule through the soft‑max -----
    mean_g = np.dot(a, g_vec)
    grad_y = a * (g_vec - mean_g)

    return f, grad_y


def schedule_optimize(
    y_start: np.ndarray,
    n: int,
    fft_len_conv: int,
    fft_len_g: int,
    lam_schedule: list[float],
    maxiter_per_stage: int = 250,
) -> np.ndarray:
    """
    Run a continuation of L‑BFGS‑B optimisations with decreasing
    smoothing (lam_factor).  Each stage starts from the result of the
    previous one.
    """
    y = y_start.copy()
    for lam in lam_schedule:
        res = minimize(
            fun=objective_and_grad,
            x0=y,
            args=(n, fft_len_conv, fft_len_g, lam),
            method="L-BFGS-B",
            jac=True,
            options={"maxiter": maxiter_per_stage, "gtol": 1e-12, "disp": False},
        )
        y = res.x
    return y


# ------------------------------------------------------------
# Targeted hill‑climb (reduces the true max directly)
# ------------------------------------------------------------


def hill_climb_targeted(
    a: np.ndarray,
    cur_score: float,
    fft_len: int,
    n: int,
    deadline: float,
    max_iter: int = 4000,
    move_frac: float = 0.05,
) -> tuple[np.ndarray, float]:
    """
    Greedy hill‑climb that always moves mass away from indices
    contributing most to the current maximal convolution entry.
    Symmetry a_i = a_{n‑1‑i} is enforced after every move.
    """
    best = a.copy()
    best_score = cur_score
    rng = np.random.default_rng()
    while time.time() < deadline and max_iter > 0:
        max_iter -= 1

        # compute convolution and the index of its maximum
        conv = conv_fft(best, fft_len, n)
        k_max = int(np.argmax(conv))

        # gradient of the *actual* max entry: g_i = 2·best[k_max‑i]  (zero outside)
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        g = np.zeros_like(best)
        g[mask] = 2.0 * best[idx[mask]]

        # pick a source index weighted by its contribution to the max
        if g.sum() > 0:
            prob_src = g / g.sum()
            i = rng.choice(n, p=prob_src)
        else:
            i = rng.integers(0, n)

        # pick a destination index where the contribution is relatively low
        low_mask = g < np.median(g)
        if low_mask.any():
            j = rng.choice(np.where(low_mask)[0])
        else:
            j = rng.integers(0, n)

        if i == j:
            continue

        # transfer a small fraction of mass from i to j
        delta = best[i] * rng.random() * move_frac
        if delta <= 0.0:
            continue
        cand = best.copy()
        cand[i] -= delta
        cand[j] += delta

        # enforce symmetry and renormalise
        cand = symmetrize_and_normalise(cand)

        new_score = fast_score(cand, fft_len, n)
        if new_score < best_score:
            best = cand
            best_score = new_score
            # keep the improvement
        # else discard the move

    return best, best_score


# ------------------------------------------------------------
# Analytic shape generators (symmetric)
# ------------------------------------------------------------


def shape_power(n: int, p: float) -> np.ndarray:
    """a_i ∝ ((i+1)*(n‑i))**p   (symmetric)"""
    i = np.arange(n, dtype=np.float64) + 1.0
    prod = i * (n - i + 1.0)      # (i+1)*(n-i)  in 1‑based indexing
    a = np.power(prod, p, where=prod > 0, out=np.ones_like(prod))
    a = np.maximum(a, 1e-30)
    a /= a.sum()
    return a


def shape_beta(n: int, alpha: float, beta: float) -> np.ndarray:
    """a_i ∝ (i+1)^α * (n‑i)^β   (symmetric when α=β)"""
    i = np.arange(n, dtype=np.float64) + 1.0
    left = np.power(i, alpha, where=i > 0, out=np.ones_like(i))
    right = np.power(n - i + 1.0, beta, where=(n - i + 1.0) > 0, out=np.ones_like(i))
    a = left * right
    a = np.maximum(a, 1e-30)
    a /= a.sum()
    return a


def shape_exponential(n: int, rate: float) -> np.ndarray:
    """
    a_i ∝ exp(-rate * distance_to_nearest_edge)
    symmetric U‑shaped distribution.
    """
    i = np.arange(n, dtype=np.float64)
    dist = np.minimum(i, n - 1 - i)
    a = np.exp(-rate * dist)
    a = np.maximum(a, 1e-30)
    a /= a.sum()
    return a

        init_seq = globals()["height_sequence_1"]   # may be defined by the harness
        if isinstance(init_seq, (list, tuple, np.ndarray)):
            arr = np.asarray(init_seq, dtype=float)
            if arr.ndim == 1 and arr.size >= 1000:
                n = max(n, int(arr.size))
    except Exception:
        pass

    # enforce an even length – symmetry works most naturally with even n
    if n % 2 == 1:
        n += 1

    fft_len_conv = next_pow2(2 * n - 1)
    fft_len_g = next_pow2(3 * n - 2)

    # --------------------------------------------------------
    # Baseline (uniform) – also serves as a fallback
    # --------------------------------------------------------
    best_a = np.full(n, 1.0 / n)
    best_score = fast_score(best_a, fft_len_conv, n)
    best_y = np.log(best_a + 1e-12)
    print(f"[init] n={n} uniform fast score = {best_score:.6f}")

    # --------------------------------------------------------
    # Grid search over analytic shapes (coarse but cheap)
    # --------------------------------------------------------
    shape_candidates = []

    # power‑law shapes
    for p in np.linspace(-2.0, 2.0, 41):
        shape_candidates.append((shape_power(n, p), f"pow_{p:.2f}"))

    # beta‑type shapes (α,β)
    alphas = np.linspace(-2.0, 2.0, 21)
    betas = np.linspace(-2.0, 2.0, 21)
    for α in alphas:
        for β in betas:
            shape_candidates.append((shape_beta(n, α, β), f"beta_{α:.2f}_{β:.2f}"))

    # exponential (U‑shaped)
    for rate in np.linspace(0.0005, 0.020, 25):
        shape_candidates.append((shape_exponential(n, rate), f"exp_{rate:.4f}"))

    # evaluate all shapes (stop early if we run out of time)
    for a_shape, tag in shape_candidates:
        if time.time() >= deadline:
            break
        a_shape = symmetrize_and_normalise(a_shape)  # guarantee symmetry
        score = fast_score(a_shape, fft_len_conv, n)
        if score < best_score:
            best_score = score
            best_a = a_shape.copy()
            best_y = np.log(best_a + 1e-12)
            print(f"[shape] {tag} improved fast score = {best_score:.6f}")

    # --------------------------------------------------------
    # Continuation optimisation parameters
    # --------------------------------------------------------
    lam_schedule = [
        0.70,
        0.50,
        0.30,
        0.15,
        0.07,
        0.03,
        0.015,
        0.007,
        0.003,
        0.001,
        0.0005,
        0.0002,
    ]

    iteration = 0

    # --------------------------------------------------------
    # Main stochastic optimisation loop
    # --------------------------------------------------------
    while time.time() < deadline:
        # ---------- choose a start point ----------
        mode = rng.choice(["random", "perturb", "best"])
        if mode == "random":
            y0 = rng.standard_normal(n)
        elif mode == "perturb":
            y0 = best_y + rng.normal(scale=0.08, size=n)
        else:  # mode == "best"
            y0 = best_y.copy()

        # ---------- L‑BFGS continuation ----------
        y_opt = schedule_optimize(
            y0,
            n,
            fft_len_conv,
            fft_len_g,
            lam_schedule,
            maxiter_per_stage=250,
        )
        a_opt = softmax(y_opt)
        a_opt = symmetrize_and_normalise(a_opt)
        score_opt = fast_score(a_opt, fft_len_conv, n)

        if score_opt < best_score:
            best_score = score_opt
            best_a = a_opt.copy()
            best_y = y_opt.copy()
            print(
                f"[{iteration}] mode={mode} improved fast score = {best_score:.6f}"
            )

        # ---------- targeted greedy hill‑climb ----------
        # allocate a short slice of time for a deeper local search
        hc_deadline = min(deadline, time.time() + 0.6)
        best_a, best_score = hill_climb_targeted(
            best_a,
            best_score,
            fft_len_conv,
            n,
            hc_deadline,
            max_iter=5000,
            move_frac=0.07,
        )
        best_y = np.log(best_a + 1e-12)

        iteration += 1

    # --------------------------------------------------------
    # Final refinement (another continuation + hill‑climb)
    # --------------------------------------------------------
    for lam in lam_schedule:
        if time.time() >= deadline:
            break
        res = minimize(
            fun=objective_and_grad,
            x0=best_y,
            args=(n, fft_len_conv, fft_len_g, lam),
            method="L-BFGS-B",
            jac=True,
            options={"maxiter": 300, "gtol": 1e-12, "disp": False},
        )
        best_y = res.x
        best_a = softmax(best_y)
        best_a = symmetrize_and_normalise(best_a)
        best_score = fast_score(best_a, fft_len_conv, n)
        print(f"[final refine] lam={lam:.5f} fast score = {best_score:.6f}")

    # one last aggressive hill‑climb if time permits
    if time.time() < deadline:
        best_a, best_score = hill_climb_targeted(
            best_a,
            best_score,
            fft_len_conv,
            n,
            deadline,
            max_iter=8000,
            move_frac=0.08,
        )
        best_y = np.log(best_a + 1e-12)

    # --------------------------------------------------------
    # Return the result (official evaluation printed for logging)
    # --------------------------------------------------------
    final_seq = best_a.tolist()
    final_val = evaluate_sequence(final_seq)
    print(f"[final] evaluated score = {final_val:.6f}")

    return final_seq
```
