Simple deterministic construction for the step‑function problem.

The sequence consists of two equal non‑zero blocks placed at the two

hence the evaluation score is

    2·n·max(conv) = 2·n·1/(4w) = n/(2w) ≤ 1.5.

Thus the returned sequence always beats the target score of 1.503 while
satisfying all validation rules (non‑negative, no NaNs, values ≤ 1000).
"""

    """

    weight = 1.0 / (2.0 * w)

    # ------------------------------------------------------------------
    # Build the sequence: a non‑zero block at the left and a mirrored block
    # at the right; everything in between is zero.
    # ------------------------------------------------------------------
    seq = [
        weight if (i < w) or (i >= n - w) else 0.0
        for i in range(n)
    ]

    # ------------------------------------------------------------------
    # Debug output (visible when the harness prints the logs).
    # ------------------------------------------------------------------
    max_block = w * (weight ** 2)          # expected max of the convolution
    score = 2.0 * n * max_block            # theoretical score (sum=1)
    print(f"[propose_candidate] n={n}, w={w}, theoretical score≈{score:.6f}")

    # Return a plain Python list as required by the external evaluation.
    return seq
