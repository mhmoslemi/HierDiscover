The goal is to find a non‑negative vector `a` (the heights of a step function) that minimises  

```
score(a) = 2 * n * max(conv(a,a)) / (sum(a)**2)
```

Because the score is invariant under a global scaling we can restrict the search to
the probability simplex `Σ a_i = 1 , a_i ≥ 0`.  
With this normalisation the score is simply `2 n · max(conv(a,a))`.

The program follows three phases

1. **Initialisation** – Start either from the previously found global solution
   (`height_sequence_1`) or from a cheap parametric sweep (exponential / power‑law /
   “U‑shaped” families).  
   The best candidate of this stage is kept as the starting point of the optimiser.

2. **Long Adam optimisation** –  
   * a smoothed version of the `max` is used:
     `softmax_α(conv) = log Σ exp(α·conv) / α`.  
   * The smoothing parameter `α` is raised from a small value (≈ 0.5) to a very
     large one (≈ 2000). For large `α` the soft‑max collapses to a hard
     sub‑gradient (only the maximal index contributes).  
   * Adam’s first‑ and second‑moment estimates are employed, the learning‑rate is
     decayed linearly and after every update the vector is projected onto the
     probability simplex **and symmetrised** (`a_i ← (a_i+a_{n‑1‑i})/2`).  
   * The loop runs as long as the global time budget permits (≈ 850 s).

3. **Cheap hill‑climbing** – After the smooth optimisation a fast stochastic
   local search moves a tiny amount of mass from a randomly chosen “rich’’ index
   to a random destination. Whenever the move reduces `max(conv)` the new vector
   is accepted, symmetrised again and a short Adam mini‑run (10 steps) is performed
   to polish the improvement.

The best sequence found is finally scaled to the reference normalisation
`sum = sqrt(2·n)` (the evaluation function is scale‑invariant) and returned as a plain
Python list.

All steps respect the 1000 s wall‑time limit, avoid any filesystem or network I/O,
and do not rely on external optimisation libraries – only `numpy` and the provided
`evaluate_sequence` are used.

import time
import math
import numpy as np

# ------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex {x≥0, Σx=1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = np.nonzero(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ------------------------------------------------------------
def _conv_max(a: np.ndarray, L: int) -> float:
    """Return max(conv(a,a)) using an FFT of length L (L >= 3·len(a)-2)."""
    fft_a = np.fft.fft(a, n=L)
    conv = np.real(np.fft.ifft(fft_a * fft_a))[: 2 * a.shape[0] - 1]
    return conv.max()


# ------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: float = 1000, **_):
    """
    Search for a non‑negative step function that minimises

        2 * n * max(conv(a,a)) / (sum(a)**2)

    The algorithm consists of three stages:
    1. a quick parametric sweep (exponential / power‑law / U‑shape)
       to obtain a decent starting point;
    2. a long Adam optimisation on a smoothed max (soft‑max) with a
       schedule α∈[0.5, 2000] and a linearly decaying learning rate;
    3. a cheap stochastic hill‑climber that moves a few per‑cent of the
       mass between entries, keeping the best sequence found.
    The best vector is finally scaled to the reference normalisation
    (sum = sqrt(2·n)) and returned as a plain list of floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a safety margin for the final scaling / printing
    deadline = start_time + budget_s - 5.0

    # --------------------------------------------------------
    # 0. length of the step function (use existing solution if present)
    try:
        init = np.array(height_sequence_1, dtype=np.float64)  # type: ignore
        n = len(init)
        init = init / init.sum() if init.sum() > 0 else None
    except Exception:
        init = None
        # a larger n gives more degrees of freedom – 10 000 works well
        n = 10000

    target_sum = math.sqrt(2.0 * n)          # normalisation required by the reference code
    L = 1 << ((3 * n - 2).bit_length())      # FFT length (≥ 3n‑2)

    # --------------------------------------------------------
    # 1. parametric sweep (very cheap – only a few seconds)
    best_seq = None
    best_obj = float("inf")   # this will store max(conv) (sum(a)=1)

    def _maybe_update(raw):
        """Normalise raw, compute max(conv) and keep the best."""
        nonlocal best_seq, best_obj
        a = raw.astype(np.float64)
        if a.sum() == 0:
            return
        a = a / a.sum()
        cur = _conv_max(a, L)
        if cur < best_obj:
            best_obj = cur
            best_seq = a.copy()
            print(f"  sweep improvement: max(conv)={cur:.8e}  score={2*n*cur:.6f}")

    # --- power‑law families ------------------------------------------------
    exponents = np.linspace(0.0, 2.0, 21)
    for p in exponents:
        if time.time() > deadline:
            break
        base = np.arange(1, n + 1, dtype=np.float64) ** p
        _maybe_update(base)            # increasing
        _maybe_update(base[::-1])       # decreasing

    # --- pure exponential --------------------------------------------------
    lambdas = np.linspace(0.0, 5.0, 21)
    for lam in lambdas:
        if time.time() > deadline:
            break
        exp_shape = np.exp(-lam * np.arange(n, dtype=np.float64))
        _maybe_update(exp_shape)               # decreasing
        _maybe_update(exp_shape[::-1])          # increasing

    # --- U‑shape (sum of two exponentials) -------------------------------
    for lam in lambdas[::4]:
        if time.time() > deadline:
            break
        left = np.exp(-lam * np.arange(n, dtype=np.float64))
        u_shape = left + left[::-1]
        _maybe_update(u_shape)

    # fallback: uniform distribution (should never be chosen)
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)
        best_obj = _conv_max(best_seq, L)

    # if a previous global solution exists, try it as well
    if init is not None:
        cur = _conv_max(init, L)
        if cur < best_obj:
            best_seq = init.copy()
            best_obj = cur
            print(f"  global start improvement: max(conv)={cur:.8e}  score={2*n*cur:.6f}")

    # --------------------------------------------------------
    # 2. Long Adam optimisation on smoothed max
    a = best_seq.copy()
    best_obj = _conv_max(a, L)

    # Adam hyper‑parameters
    max_iters = 250000                     # large enough – loop exits on time‑out
    lr_initial = 0.08
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    # smoothing schedule (geometric progression works well)
    alpha_start = 0.5
    alpha_end = 2000.0

    # pre‑compute the phase factor needed for the reversed FFT
    phase = np.exp(2j * np.pi * np.arange(L) / L)

    it = 0
    print("--- Phase 2: Adam on smoothed max (very long) ---")
    while time.time() < deadline and it < max_iters:
        it += 1

        # ---- current convolution and (soft) max ----
        fft_a = np.fft.fft(a, n=L)
        conv = np.real(np.fft.ifft(fft_a * fft_a))[: 2 * n - 1]
        cur_max = conv.max()

        # ---- smoothing parameter α (geometric) ----
        alpha = alpha_start * (alpha_end / alpha_start) ** (it / max_iters)

        # ---- compute soft‑max weights w ----
        if alpha < 200.0:                         # smooth regime
            scaled = alpha * conv
            shift = scaled.max()
            exp_scaled = np.exp(scaled - shift)
            w = exp_scaled / exp_scaled.sum()
        else:                                     # hard max (sub‑gradient)
            w = np.zeros_like(conv)
            w[conv.argmax()] = 1.0

        # ---- gradient of the smoothed max (2 × correlation) ----
        # FFT of reversed a (no extra FFT needed)
        fft_a_rev = np.conj(fft_a) * phase
        fft_w = np.fft.fft(w, n=L)
        corr = np.real(np.fft.ifft(fft_w * fft_a_rev))
        grad = 2.0 * corr[n - 1 : n - 1 + n]

        # ---- Adam update ----------------------------------------------------
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        # linear decay of the learning‑rate
        lr = lr_initial * (1.0 - it / max_iters)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a_new = a - step
        # keep the vector on the simplex and enforce symmetry
        a_new = (a_new + a_new[::-1]) * 0.5
        a_new = _project_simplex(a_new)

        # ---- evaluate the new point ----
        fft_an = np.fft.fft(a_new, n=L)
        conv_new = np.real(np.fft.ifft(fft_an * fft_an))[: 2 * n - 1]
        obj_new = conv_new.max()
        if obj_new < best_obj - 1e-12:      # a tiny tolerance avoids noisy prints
            best_obj, best_seq = obj_new, a_new.copy()
            print(f"Iter {it:5d}: improved max(conv)={obj_new:.8e}   score={2*n*obj_new:.6f}")

        a = a_new

    # --------------------------------------------------------
    # 3. Local random moves (cheap hill‑climbing)
    print("--- Phase 3: random local moves ---")
    a_current = best_seq.copy()
    # limit the move‑phase to the remaining ~10 % of the budget
    move_deadline = deadline
    while time.time() < move_deadline:
        # source index – probability proportional to its mass
        i = np.random.choice(n, p=a_current)
        j = np.random.randint(0, n)
        if i == j:
            continue
        # move at most 2 % of the source mass
        delta = np.random.rand() * 0.02 * a_current[i]
        if delta <= 0.0:
            continue
        a_new = a_current.copy()
        a_new[i] -= delta
        a_new[j] += delta
        # enforce symmetry after the move
        a_new = (a_new + a_new[::-1]) * 0.5
        # safety check
        if (a_new < 0).any():
            continue

        fft_an = np.fft.fft(a_new, n=L)
        conv_new = np.real(np.fft.ifft(fft_an * fft_an))[: 2 * n - 1]
        obj_new = conv_new.max()
        if obj_new < best_obj:
            best_obj, best_seq = obj_new, a_new.copy()
            a_current = a_new
            print(f"  move improved: max(conv)={obj_new:.8e}   score={2*n*obj_new:.6f}")

            # short polishing Adam run (10 steps) after a successful move
            for _ in range(10):
                fft_a = np.fft.fft(a_current, n=L)
                conv = np.real(np.fft.ifft(fft_a * fft_a))[: 2 * n - 1]
                # hard max gradient (sub‑gradient)
                w = np.zeros_like(conv)
                w[conv.argmax()] = 1.0
                fft_w = np.fft.fft(w, n=L)
                corr = np.real(np.fft.ifft(fft_w * fft_a_rev))
                grad = 2.0 * corr[n - 1 : n - 1 + n]

                m = beta1 * m + (1.0 - beta1) * grad
                v = beta2 * v + (1.0 - beta2) * (grad * grad)
                m_hat = m / (1.0 - beta1)
                v_hat = v / (1.0 - beta2)
                step = lr_initial * 0.02 * m_hat / (np.sqrt(v_hat) + eps)   # tiny step
                a_current = a_current - step
                a_current = (a_current + a_current[::-1]) * 0.5
