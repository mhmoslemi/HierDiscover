assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\,\max (a*a)}{(\sum a)^2},
\qquad a_i\ge 0 ,
\]

where `a*a` denotes the discrete self‑convolution of the non‑negative vector `a`.
Because the evaluation function normalises the sequence anyway, we fix  

\[
\sum_{i=0}^{n-1} a_i = 1 .
\]

For a fixed length `n` the problem becomes  

\[
\min_{a\ge 0,\;\mathbf 1^\top a = 1}\; 2\,n\; \max_k c_k, \qquad
c = a*a .
\]

*The strategy* is a two‑phase hybrid optimiser:

1. **Smooth‑max gradient descent** –  
   Replace the non‑smooth `max` by the smooth approximation  

   \[
   f_\lambda(a)=\frac{1}{\lambda}\log\!\Bigl(\sum_k e^{\lambda c_k}\Bigr),
   \qquad \lambda>0 .
   \]

   For large `\lambda` the function approaches `max_k c_k`.  
   Its gradient can be written compactly using one extra convolution:

   \[
   \nabla f_\lambda(a)=
   \frac{2}{\sum_k e^{\lambda c_k}}\;
   \bigl(e^{\lambda c}\ast a^{\text{rev}}\bigr)_{\,n-1:\,n-1+n},
   \]

   where `a^{rev}` is `a` reversed.  A simple projected gradient step
   (clip to non‑negative, renormalise to sum = 1) is performed.
   The smoothing parameter `\lambda` is increased slowly so that the
   optimisation gradually focuses on the true maximum.

2. **Fine‑grained simulated annealing** –  
   After the gradient phase the best sequence is taken as a starting
   point for a cheap annealing loop (multiplicative random noise,
   Metropolis acceptance).  This phase can resolve small remaining peaks
   that the gradient descent cannot see because it treats the whole
   objective as smooth.

The whole routine respects the global time budget (default 1000 s) and
keeps the best sequence found so far.  All operations are vectorised,
use only `numpy`, and run comfortably within the allowed resources.

```python
"""
Hybrid optimiser for the step‑function bound.

1. Initialise with a truncated central‑binomial (half‑order) series,
   normalised to sum = 1.
2. Phase 1 – smooth‑max projected gradient descent.
   * objective  f_λ(a) = (1/λ)·log Σ exp(λ·(a*a)_k)
   * gradient   ∇f_λ = 2·(exp(λ·c) * a_rev)[n‑1:n‑1+n] / Σ exp(λ·c)
   * after each step clip to ≥0, renormalise, adapt step‑size,
     increase λ (sharpen the approximation).
3. Phase 2 – short simulated‑annealing refinement on the current best.
   Random multiplicative perturbations, Metropolis acceptance,
   occasional small gradient tweaks.
4. Return the best sequence (list of non‑negative floats).
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper 1 – truncated half‑order series (central binomial coeff / 4**i)
# ----------------------------------------------------------------------
def half_order_series(n: int) -> np.ndarray:
    """Return the first `n` coefficients of a_i = C(2i,i)/4**i,
    normalised so that the sum equals 1."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        # recurrence a_i = a_{i-1} * ((2i-1)*(2i)) / (4*i*i)
        a[i] = a[i - 1] * ((2.0 * i - 1.0) * (2.0 * i)) / (4.0 * i * i)
    a /= a.sum()
    return a


# ----------------------------------------------------------------------
# Helper 2 – smooth‑max objective and its gradient (vectorised)
# ----------------------------------------------------------------------
def smooth_max_and_grad(a: np.ndarray, lamb: float):
    """
    Compute the smooth‑max value  f_λ(a)  and its gradient w.r.t. `a`.
    a : 1‑d non‑negative array, sum(a)=1
    lamb : smoothing parameter λ>0
    Returns (value, grad) where `grad` has the same shape as `a`.
    """
    # self‑convolution (full length = 2n‑1)
    conv = np.convolve(a, a)
    # shift by max for numerical stability
    max_c = conv.max()
    # weights w_k = exp(λ (c_k - max_c))  (max weight = 1)
    w = np.exp(lamb * (conv - max_c))
    sum_w = w.sum()
    # gradient = 2 * (w * a_rev) / sum_w, extracted via a single convolution
    rev_a = a[::-1]
    tmp = np.convolve(w, rev_a)                       # length = 2n‑1 + n‑1
    grad = 2.0 * tmp[len(a) - 1 : len(a) - 1 + len(a)] / sum_w
    # smooth‑max value (optional, not used for optimisation)
    smooth_val = (max_c + np.log(sum_w) / lamb)       # = (1/λ) log Σ e^{λ c_k}
    return smooth_val, grad, conv.max()


# ----------------------------------------------------------------------
# Helper 3 – simple projected gradient step
# ----------------------------------------------------------------------
def projected_gradient_step(a: np.ndarray, grad: np.ndarray, step: float) -> np.ndarray:
    """
    One projected gradient update: a ← a - step·grad,
    then clip to ≥0 and renormalise to sum = 1.
    """
    cand = a - step * grad
    cand = np.maximum(cand, 0.0)
    s = cand.sum()
    if s == 0.0:               # shouldn't happen, fallback to original a
        return a
    cand /= s
    return cand


# ----------------------------------------------------------------------
# Helper 4 – cheap simulated‑annealing move (multiplicative noise)
# ----------------------------------------------------------------------
def annealing_move(a: np.ndarray, sigma: float) -> np.ndarray:
    """
    Apply a multiplicative Gaussian perturbation with standard deviation `sigma`,
    then re‑normalise to sum = 1.
    """
    noisy = a * (1.0 + np.random.randn(len(a)) * sigma)
    noisy = np.clip(noisy, 0.0, None)
    s = noisy.sum()
    if s == 0.0:
        return a
    noisy /= s
    return noisy

# ----------------------------------------------------------------------

    Returns the best non‑negative sequence (list of floats) found within
    the allocated time budget.

    # 1) problem size & initialisation

    # keep the overall best
    best_seq = a.copy()
    best_score = evaluate_sequence(best_seq.tolist())

    # --------------------------------------------------------------
    # 2) Phase 1 – smooth‑max projected gradient descent
    # --------------------------------------------------------------
    # hyper‑parameters (tuned experimentally)
    step = 0.12                  # initial gradient step size
    step_min = 5e-6
    step_max = 0.5
    lamb = 1.0                   # initial smoothing λ

    grad_deadline = start_time + 0.60 * budget_s

        temp_progress = elapsed / total_anneal
        temperature = init_temp * (final_temp / init_temp) ** temp_progress

        # random multiplicative perturbation
        sigma = 0.02 * (1.0 - temp_progress) + 0.001
        cand = annealing_move(cur_seq, sigma)

        cand_obj = 2.0 * n * np.convolve(cand, cand).max()

        # Metropolis acceptance (we minimise)
        if cand_obj < cur_obj:
            accept = True
        else:
            prob = math.exp(-(cand_obj - cur_obj) / max(temperature, 1e-12))
            accept = np.random.rand() < prob

        if accept:
            cur_seq = cand
            cur_obj = cand_obj
            # update global best if improved
            if cand_obj < 2.0 * n * np.convolve(best_seq, best_seq).max():
                best_seq = cand.copy()
                best_score = evaluate_sequence(best_seq.tolist())
                print(f"[AN {iteration:6d}] new best score {best_score:.6f} "
                      f"(obj={cand_obj:.6f})")

        # every few iterations take a cheap gradient step on the current peak
        if iteration % 250 == 0:
            conv = np.convolve(best_seq, best_seq)
            max_val = conv.max()
            max_idxs = np.where(conv == max_val)[0]
            k = np.random.choice(max_idxs)
            # use the same gradient formula but only for index k (exact sub‑gradient)
            # sub‑gradient: ∂c_k/∂a_i = 2 a_{k-i} (if index valid)
            grad_sub = np.zeros_like(best_seq)
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            idx = np.arange(lo, hi + 1, dtype=np.int64)
            rev = k - idx
            grad_sub[idx] = 2.0 * best_seq[rev]
            step_sz = 0.004
            cand = projected_gradient_step(best_seq, grad_sub, step_sz)
            cand_obj = 2.0 * n * np.convolve(cand, cand).max()
            if cand_obj < 2.0 * n * np.convolve(best_seq, best_seq).max():
                best_seq = cand.copy()
                best_score = evaluate_sequence(best_seq.tolist())
                cur_seq = cand
                cur_obj = cand_obj
                print(f"[AN {iteration:6d}] gradient tweak improved to {best_score:.6f}")

        iteration += 1

    # --------------------------------------------------------------
    # 4) Return the best sequence found
    # --------------------------------------------------------------
    # Ensure the result is a plain Python list of floats
    return best_seq.tolist()
```
