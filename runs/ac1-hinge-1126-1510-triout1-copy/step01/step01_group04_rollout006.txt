The evaluation function  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}
\]

is scale‑invariant – multiplying the whole vector by a constant does not change the score.
Hence we can fix the \(\ell_1\)-norm to the convenient value  
\(\displaystyle S=\sqrt{2n}\) and optimise only the *shape* of the step‑function.

The algorithm consists of three stages

1. **Coarse grid search** – try a few lengths (1500‑3000) and a small family of
   analytically‑motivated shapes  
   \(a_i=(i+1+\delta)^{-\alpha}\) (the classic “arcsine” shape) and keep the best
   candidate.

2. **LP‑refinement** – for a fixed vector `f` let \(M=\max (f*f)\).
   The linear programme  

   \[
   \max_{g\ge 0}\;\sum_j g_j\quad\text{s.t. }\;(f*g)_k\le M\;(k=0\ldots2n-2)
   \]

   finds a vector `g` that carries as much mass as possible without increasing the
   maximal auto‑convolution value.
   After scaling `g` to the same \(\ell_1\)‑norm as `f` we replace  

   \[
   f\leftarrow (1-t)f+t\,g,
   \]

   with a modest step‑size `t`.  Repeating this step monotonically drives the
   maximal entry of the auto‑convolution down.

   The constraints are exactly the Toeplitz matrix of `f`; it is built as a
   sparse matrix (`scipy.sparse.diags`) and solved with the high‑performance
   `highs` LP solver.

3. **Fine‑grained projected gradient** – after the LP phase the solution is already
   close to a local optimum.  A cheap projected gradient descent on the *active*
   maximal entry (as in the baseline code) removes the last remaining slack.
   The gradient is projected onto the hyper‑plane \(\sum a = S\) and a decreasing
   step size is used.  Random jitter is added occasionally to escape tiny plateaus.

All three phases respect the 1000 s budget, keep the vector non‑negative,
re‑normalise to the fixed \(\ell_1\)‑norm after each update and constantly keep
track of the best sequence seen so far.

The implementation below follows exactly this plan, uses only `numpy`,
`scipy.sparse`, `scipy.optimize` and prints progress information.  No file‑IO,
no closures and no external solvers are required.

```python
"""
Propose a low‑score step‑function.

The algorithm works in three phases:
  1. Coarse grid search over a few lengths and arcsine‑type shapes.
  2. LP‑based refinement that repeatedly solves a linear programme
     (maximise ℓ₁‑norm of a vector g under the constraint
     (f * g) ≤ max(f * f)) and mixes the result with the current vector.
  3. Final cheap projected‑gradient descent on the active maximal
     convolution entry to polish the solution.

All helpers are defined at module level; no closures are used.
"""

import time
import numpy as np
from scipy import sparse, optimize

# ----------------------------------------------------------------------
# Helper functions (top level, no closures)
# ----------------------------------------------------------------------


def generate_initial_sequence(length: int,
                              exponent: float = 0.5,
                              offset: float = 0.0) -> np.ndarray:
    """
    Produce an arcsine‑type vector a_i = (i+1+offset)^(-exponent),
    clip it to the allowed [0,1000] range and normalise its ℓ₁‑norm
    to S = sqrt(2*length) (the scale used by the original reference).
    """
    idx = np.arange(length, dtype=np.float64) + 1.0 + offset
    seq = np.power(idx, -exponent)
    seq = np.clip(seq, 0.0, 1000.0)
    target_sum = np.sqrt(2.0 * length)
    if np.sum(seq) == 0.0:
        seq = np.full(length, target_sum / length)
    else:
        seq = seq * (target_sum / np.sum(seq))
    return seq


def build_convolution_matrix(a: np.ndarray) -> sparse.csr_matrix:
    """
    Build the Toeplitz matrix T such that (T @ g) = a * g (full auto‑convolution
    of a with a variable g).  T has shape (2*n-1, n) and is stored as CSR.
    """
    n = a.shape[0]
    # each diagonal offset –d contains the constant a[d]
    data = [np.full(n, a[d], dtype=np.float64) for d in range(n)]
    offsets = [-d for d in range(n)]
    T = sparse.diags(data, offsets, shape=(2 * n - 1, n), format="csr")
    return T


def lp_refine(initial: np.ndarray,
              deadline: float,
              max_iters: int = 80,
              step_size: float = 0.2) -> (np.ndarray, float):
    """
    LP‑based refinement described in the docstring.
    Returns the best vector found and its evaluate_sequence score.
    """
    n = initial.shape[0]
    total_mass = np.sqrt(2.0 * n)          # fixed ℓ₁‑norm
    a = initial.copy()
    best_a = a.copy()
    best_score = float("inf")

    # objective for linprog: maximise sum(g) → minimise -sum(g)
    c = -np.ones(n, dtype=np.float64)

    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1

        # current maximal auto‑convolution entry
        conv = np.convolve(a, a)
        M = float(conv.max())

        # build constraint matrix for (a * g) ≤ M
        T = build_convolution_matrix(a)
        b_ub = np.full(2 * n - 1, M, dtype=np.float64)

        # solve LP
        res = optimize.linprog(c, A_ub=T, b_ub=b_ub,
                               bounds=(0, None), method="highs")
        if not res.success:
            print(f"[LP] iteration {it}: LP failed – {res.message}")
            break

        g0 = res.x
        sum_g0 = float(np.sum(g0))
        if sum_g0 <= 0.0:
            break

        # rescale to the fixed ℓ₁‑norm
        g = g0 * (total_mass / sum_g0)

        # convex combination
        a_new = (1.0 - step_size) * a + step_size * g
        a_new = np.maximum(a_new, 0.0)               # enforce non‑negativity

        # evaluate
        try:
            score = evaluate_sequence(a_new.tolist())
        except Exception:
            print("[LP] evaluation exception – aborting")
            break

        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            print(f"[LP] iter {it:3d}: improved score = {best_score:.6f}")

        # accept if not much worse; otherwise occasional rollback
        if score <= best_score * 1.001:
            a = a_new
        else:
            if np.random.rand() < 0.05:
                a = best_a.copy()

        # slowly shrink the step size
        if it % 10 == 0:
            step_size = max(step_size * 0.95, 0.02)

        # jitter every few iterations to escape plateaus
        if it % 20 == 0:
            jitter = np.random.randn(n) * 1e-4
            a = np.maximum(a + jitter, 0.0)
            a = a * (total_mass / np.sum(a))

    return best_a, best_score


def gradient_refine(initial: np.ndarray,
                    deadline: float,
                    start_step: float = 0.02,
                    best_so_far: float = None) -> (np.ndarray, float):
    """
    Cheap projected‑gradient descent that only moves mass away from the
    currently maximal convolution entry.  Used as a polishing step after LP.
    """
    n = initial.shape[0]
    total_mass = float(np.sum(initial))
    a = initial.copy()
    best_a = a.copy()
    best_score = float("inf") if best_so_far is None else best_so_far

    step = start_step
    it = 0
    while time.time() < deadline:
        it += 1

        conv = np.convolve(a, a)
        max_val = float(conv.max())
        k_max = int(conv.argmax())

        # gradient of the active entry
        grad = np.zeros_like(a)
        lo = max(0, k_max - (n - 1))
        hi = min(n - 1, k_max)
        if lo <= hi:
            j = np.arange(lo, hi + 1, dtype=np.int64)
            i = k_max - j
            grad[j] = 2.0 * a[i]

        # project onto the hyper‑plane Σa = total_mass
        grad -= grad.mean()

        a_new = a - step * grad
        a_new = np.maximum(a_new, 0.0)
        cur_sum = float(np.sum(a_new))
        if cur_sum == 0.0:
            a_new = a.copy()
        else:
            a_new *= (total_mass / cur_sum)

        try:
            score = evaluate_sequence(a_new.tolist())
        except Exception:
            break

        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            print(f"[GRAD] iter {it:5d}: improved score = {best_score:.6f}")

        # accept move if not significantly worse
        if score <= best_score * 1.001:
            a = a_new
        else:
            if np.random.rand() < 0.05:
                a = best_a.copy()

        # step‑size decay
        if it % 200 == 0:
            step = max(step * 0.9, 1e-4)

        # occasional random jitter
        if it % 250 == 0:
            jitter = np.random.randn(n) * 1e-4
            a = np.maximum(a + jitter, 0.0)
            a = a * (total_mass / np.sum(a))

    return best_a, best_score


def coarse_grid_search(lengths, params, deadline):
```
