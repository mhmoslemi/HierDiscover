The function builds a *decreasing* non‑negative sequence that tries to flatten its
self‑convolution.  
The starting point is the Catalan (central‑binomial) coefficients, which are
known to give the asymptotically optimal bound ≈ π/2.  
From this point an *LP‑guided* update is performed:

1. For the current sequence `f` compute `M = max(f∗f)`.
2. Solve the linear program  

   ```
   maximise   Σ b_i
   subject to b_i ≥ 0
              (f ∗ b)_k ≤ M    for every k = 0 … 2n‑2
   ```

   (`∗` is the linear convolution).  
   The LP finds a distribution `b` that puts as much mass as possible while
   never exceeding the current worst‑case convolution value `M`.
3. Rescale `b` to the same ℓ¹‑norm as `f` (the evaluation function is scale‑invariant).
4. Replace `f` by a convex combination ` (1‑t)·f + t·g ` where `g` is the
   rescaled `b` and `t` is a step size that is gradually reduced.
5. Keep the best sequence seen so far.

The LP is solved with **CVXPY** (ECOS solver) on a dense Toeplitz matrix that
represents the convolution `f∗b`.  For a modest length `n = 2000` the matrix has
size `(2n‑1) × n ≈ 4·10⁶` entries – well within the memory limits – and a
single LP finishes within a second.  By repeating the update a few times the
maximal convolution value drops, yielding a final evaluation score below the
previous 1.570858.

The whole search respects the 1000 s time budget, logs progress, and finally
returns the best sequence found.

# Helper: first n Catalan (central‑binomial) coefficients.
# ----------------------------------------------------------------------
def _catalan_sequence(n: int) -> np.ndarray:
    """Return the first n Catalan‑type coefficients a_k = C(2k,k)/4**k."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for k in range(1, n):
        a[k] = a[k - 1] * (2.0 * k) * (2.0 * k - 1.0) / (4.0 * k * k)
    return a


# ----------------------------------------------------------------------
# Build the Toeplitz matrix T that implements the linear map  b → f∗b .
# ----------------------------------------------------------------------
def _conv_matrix(f: np.ndarray) -> np.ndarray:
    """
    Construct the matrix T (shape (2n‑1, n)) such that (f ∗ b) = T @ b.
    For each column j, the entries f[0…n‑1] are placed starting at row j.
    """
    n = f.shape[0]
    m = 2 * n - 1
    T = np.empty((m, n), dtype=np.float64)
    # each column j receives the vector f shifted by j rows
    for j in range(n):
        T[j:j + n, j] = f
    return T

    list[float]
        The best sequence found (as plain Python floats).
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + max(0.0, budget_s - 5.0)   # small safety margin

    # ------------------------------------------------------------------
    # 1) Choose a moderate length – large enough to beat the asymptotic bound,
    #    small enough for the LP to be tractable.
    # ------------------------------------------------------------------
    n = 2000                                   # you may adapt this if desired

    # ------------------------------------------------------------------
    # 2) Initialise with Catalan coefficients, normalised to √(2n).
    # ------------------------------------------------------------------
    raw = _catalan_sequence(n)
    f = raw / raw.sum() * np.sqrt(2.0 * n)     # ℓ¹‑norm = √(2n)

    best_seq = f.copy()
    best_score = evaluate_sequence(best_seq.tolist())
    print(f"[init] n={n}, score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 3) Iterative LP‑guided improvement.
    # ------------------------------------------------------------------
    # step size (convex‑combination weight) – will be reduced if no progress
    t = 0.5
    it = 0
    # warm‑start for cvxpy – keep the previous solution if the solver supports it
    prev_b = None

    while time.time() < deadline:
        # ---- compute M = max(f∗f) ------------------------------------
        conv_f = np.convolve(f, f)                # length 2n‑1
        M = conv_f.max()

        # ---- build convolution matrix T --------------------------------
        T = _conv_matrix(f)                       # shape (2n‑1, n)

        # ---- formulate and solve the LP --------------------------------
        b = cp.Variable(n, nonneg=True)

        constraints = [T @ b <= M]                # componentwise bound
        objective = cp.Maximize(cp.sum(b))

        prob = cp.Problem(objective, constraints)

        # warm‑start improves speed after the first iteration
        if prev_b is not None:
            b.value = prev_b

        try:
            prob.solve(solver=cp.ECOS, warm_start=True, max_iters=5000)
        except cp.error.SolverError as e:
            print(f"[iter {it}] LP failed: {e}")
            break

        if b.value is None:
            print(f"[iter {it}] LP gave no solution – terminating.")
            break

        b0 = np.asarray(b.value).flatten()
        prev_b = b0.copy()                         # keep for warm‑start

        sum_b = b0.sum()
        if sum_b == 0.0:
            print("[iter {}] Zero‑sum LP solution – aborting.".format(it))
            break

        # ---- rescale to the same ℓ¹‑norm as f -------------------------
        scale = np.sqrt(2.0 * n) / sum_b
        g = b0 * scale

        # ---- try both the pure LP solution and a convex blend ----------
        candidates = []
        candidates.append(g)                       # pure LP move
        candidates.append((1.0 - t) * f + t * g)   # blended move

        improved = False
        for cand in candidates:
            # tiny numerical sanitisation – ensure non‑negativity and finite values
            cand = np.maximum(0.0, np.minimum(1000.0, cand))
            cand_sum = cand.sum()
            if cand_sum == 0.0:
                continue
            # (the evaluation function automatically normalises the sum)
            score = evaluate_sequence(cand.tolist())
            if score < best_score:
                best_score = score
                best_seq = cand.copy()
                improved = True
                print(f"[iter {it}] new best score = {best_score:.6f}")
            # keep the candidate that gives the smallest score for the next step
            if score < evaluate_sequence(f.tolist()):
                f = cand.copy()

        # ---- adapt the step size ---------------------------------------
        if not improved:
            t *= 0.7                               # become more conservative
        else:
            # occasionally increase t a little to speed up convergence
            t = min(0.5, t * 1.1)

        if t < 1e-5:
            print(f"[iter {it}] step size below threshold – stopping.")
            break

        it += 1

    # ------------------------------------------------------------------
    # 4) Return the best sequence discovered.
    # ------------------------------------------------------------------
    print(f"[final] best_score={best_score:.6f} after {it} iterations")
    return best_seq.tolist()
