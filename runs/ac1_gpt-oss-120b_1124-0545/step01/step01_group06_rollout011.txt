The target function  

\[
F(a)=\frac{2\,n\;\max\bigl((a*a)\bigr)}{\bigl(\sum a\bigr)^2}
\]

is homogeneous – scaling the vector does not change the value.  
Hence we may *always* keep the sequence on the probability simplex
\(\{a_i\ge0,\;\sum a_i=1\}\).  
For a vector on the simplex  

\[
F(a)=2\,n\;\max\bigl((a*a)\bigr)
\]

so the problem is to make the linear convolution \(a*a\) as flat as
possible.

The algorithm consists of three independent phases

1. **Parametric sweep** – a cheap exploration of several families
   (geometric, power‑law, geometric·power, symmetric geometric,
   plateau‑geometric and double‑exponential).  Every candidate is
   normalised to sum 1 and evaluated with an FFT‑based convolution.
2. **Smoothed‑max gradient descent** – the non‑differentiable “max”
   is replaced by a log‑sum‑exp with a temperature parameter β.
   The resulting gradient is computed by a second FFT‑convolution.
   An exponentiated‑gradient update together with a Euclidean projection
   onto the simplex drives the sequence toward a flatter autocorrelation.
3. **Linear‑programming refinement** – for the current iterate
   \(f\) we compute \(M=\max(f*f)\) and solve the LP  

   \[
   \max\ \mathbf 1^\top g\quad\text{s.t.}\quad (f*g)_k\le M\;(k=0,\dots,2n-2),
   \qquad g\ge0 .
   \]

   The LP pushes mass into positions where \(f\) is small without
   increasing any convolution entry beyond the current bound \(M\).
   The solution \(g\) is normalised to a probability vector and mixed
   with the current iterate \(f\) (`f←(1‑t)f+tg`).  After each mix we
   run a short gradient‑descent warm‑up.  This “active‑set” step is the
   principle described in the statement and drastically improves the
   bound after the pure gradient phase.

All three phases respect the global time budget (default 1000 s).  
The best vector encountered during the whole run is returned as a plain
list; `evaluate_sequence` will receive a non‑negative, sum‑1 vector.

```python
"""
Propose a non‑negative step‑function (list of heights) that minimises

    2 * n * max(conv(a, a)) / (sum(a)**2)

The algorithm works in three stages:

1.  A fast parametric sweep over several families (geometric, power‑law,
    geometric·power, symmetric geometric, plateau‑geometric,
    double‑exponential) for a few lengths.  Every candidate is normalised
    to a probability vector and evaluated with an FFT‑based convolution.

2.  Smoothed‑max gradient descent (log‑sum‑exp approximation of the
    maximum) using exponentiated‑gradient updates and Euclidean projection
    onto the simplex.

3.  Linear‑programming refinement: for the current iterate `f` we solve

        max  1ᵀ g
        s.t. (f * g)_k ≤ M   (k = 0 … 2n‑2)
             g ≥ 0

    where M = max(f*f).  The solution `g` is normalised and mixed with
    `f` (convex combination).  A short gradient‑descent warm‑up follows.
    Several LP‑mix steps are performed while time permits.

All steps keep the sequence on the simplex, therefore the final value
passed to `evaluate_sequence` is directly comparable to the target bound.
"""

import time
import numpy as np
import scipy.sparse as sp
import scipy.optimize as opt

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution via FFT (full length)."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.irfft(fx * fy, n=N)[:L]
    return conv


def _evaluate_on_simplex(a: np.ndarray) -> float:
    """Objective 2·n·max(conv) for a vector already on the simplex."""
    conv = _conv_fft(a, a)
    return float(2.0 * len(a) * np.max(conv))


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = cssv[-1] / n
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Parametric families
# ----------------------------------------------------------------------


def _geom(n: int, r: float) -> np.ndarray:
    a = r ** np.arange(n, dtype=np.float64)
    a /= a.sum()
    return a


def _power(n: int, p: float) -> np.ndarray:
    idx = np.arange(1, n + 1, dtype=np.float64)
    a = 1.0 / (idx ** p)
    a /= a.sum()
    return a


def _geom_power(n: int, r: float, p: float) -> np.ndarray:
    idx = np.arange(1, n + 1, dtype=np.float64)
    a = (r ** (idx - 1)) / (idx ** p)
    a /= a.sum()
    return a


def _sym_geom(n: int, r: float) -> np.ndarray:
    a = r ** np.arange(n, dtype=np.float64) + r ** np.arange(n - 1, -1, -1, dtype=np.float64)
    a /= a.sum()
    return a


def _plateau_geom(n: int, plateau_len: int, r: float) -> np.ndarray:
    """A flat plateau of ones followed by a geometric tail."""
    if plateau_len >= n:
        a = np.ones(n, dtype=np.float64)
    else:
        tail_len = n - plateau_len
        tail = r ** np.arange(tail_len, dtype=np.float64)
        a = np.concatenate([np.ones(plateau_len, dtype=np.float64), tail])
    a /= a.sum()
    return a


def _double_exp(n: int, r1: float, r2: float, split: int) -> np.ndarray:
    """Two consecutive exponentials, split point `split`."""
    if split >= n:
        a = r1 ** np.arange(n, dtype=np.float64)
    else:
        part1 = r1 ** np.arange(split, dtype=np.float64)
        part2 = (r1 ** split) * (r2 ** np.arange(n - split, dtype=np.float64))
        a = np.concatenate([part1, part2])
    a /= a.sum()
    return a


# ----------------------------------------------------------------------
# Linear‑programming refinement utilities
# ----------------------------------------------------------------------


def _build_conv_matrix(f: np.ndarray) -> sp.csr_matrix:
    """
    Return the matrix A such that A @ g == conv(f, g) (full linear convolution).
    Shape of A is (2·len(f)-1, len(f)).
    Each diagonal d (0 ≤ d < n) is constant f[d].
    """
    n = f.shape[0]
    # every diagonal contains the same constant value f[d]
    data = [np.full(n, f[d], dtype=np.float64) for d in range(n)]
    offsets = np.arange(n)  # 0,1,…,n‑1
    A = sp.diags(data, offsets, shape=(2 * n - 1, n), format="csr")
    return A


def _lp_max_sum_under_bound(f: np.ndarray, bound: float) -> np.ndarray | None:
    """
    Solve   max 1ᵀ g   s.t. conv(f, g) ≤ bound, g ≥ 0.
    Returns the optimal g (not normalised) or None on failure.
    """
    n = f.shape[0]
    A = _build_conv_matrix(f)                       # (2n‑1) × n
    c = -np.ones(n, dtype=np.float64)               # maximise → minimise –sum(g)
    b = np.full(2 * n - 1, bound, dtype=np.float64)
    bounds = [(0, None)] * n

    # SciPy's HiGHS backend works efficiently with sparse A
    res = opt.linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                     method="highs", options={"presolve": True, "time_limit": 30})
    if not res.success:
        return None
    return res.x


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises ``evaluate_sequence``.
    The routine respects the supplied time budget and returns the best
    sequence (as a plain Python list) found so far.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 5.0   # small safety margin

    best_seq = None
    best_val = np.inf

    # ------------------------------------------------------------------
    # 1. PARAMETRIC SWEEP
    # ------------------------------------------------------------------
    lengths = [1000, 2000, 4000]               # reasonable trade‑off
    # geometric parameter r = 1 - c / n, c in [0.2, 5.0]
    c_vals = np.linspace(0.2, 5.0, 20)
    # power‑law exponent
    p_vals = np.linspace(0.0, 2.0, 16)
    # plateau length fractions
    plateau_fractions = [0.1, 0.3, 0.5, 0.7, 0.9]

    for n in lengths:
        # --- geometric ---
        for c in c_vals:
            r = 1.0 - c / n
            if r <= 0.0:
                continue
            a = _geom(n, r)
            val = _evaluate_on_simplex(a)
            if val < best_val:
                best_val, best_seq = val, a.copy()
                print(f"[sweep] geom n={n:4d} c={c:4.2f} → {val:.6f}")

        # --- power law ---
        for p in p_vals:
            a = _power(n, p)
            val = _evaluate_on_simplex(a)
            if val < best_val:
                best_val, best_seq = val, a.copy()
                print(f"[sweep] power n={n:4d} p={p:4.2f} → {val:.6f}")

        # --- geometric * power ---
        for c in c_vals:
            r = 1.0 - c / n
            if r <= 0.0:
                continue
            for p in p_vals:
                a = _geom_power(n, r, p)
                val = _evaluate_on_simplex(a)
                if val < best_val:
                    best_val, best_seq = val, a.copy()
                    print(f"[sweep] g×p n={n:4d} c={c:4.2f} p={p:4.2f} → {val:.6f}")

        # --- symmetric geometric ---
        for c in c_vals:
            r = 1.0 - c / n
            if r <= 0.0:
                continue
            a = _sym_geom(n, r)
            val = _evaluate_on_simplex(a)
            if val < best_val:
                best_val, best_seq = val, a.copy()
                print(f"[sweep] sym‑g n={n:4d} c={c:4.2f} → {val:.6f}")

        # --- plateau‑geometric ---
        for frac in plateau_fractions:
            k = int(frac * n)
            for c in c_vals:
                r = 1.0 - c / n
                if r <= 0.0:
                    continue
                a = _plateau_geom(n, k, r)
                val = _evaluate_on_simplex(a)
                if val < best_val:
                    best_val, best_seq = val, a.copy()
                    print(f"[sweep] plat‑g n={n:4d} k={k:4d} c={c:4.2f} → {val:.6f}")

        # --- double exponential ---
        split_fractions = [0.2, 0.5, 0.8]
        for split_frac in split_fractions:
            s = int(split_frac * n)
            for r1 in [0.96, 0.98, 0.99]:
                for r2 in [0.80, 0.90, 0.95]:
                    a = _double_exp(n, r1, r2, s)
                    val = _evaluate_on_simplex(a)
                    if val < best_val:
                        best_val, best_seq = val, a.copy()
                        print(f"[sweep] 2exp n={n:4d} s={s:4d} r1={r1:.2f} r2={r2:.2f} → {val:.6f}")

        if time.time() >= deadline:
            break

    # ------------------------------------------------------------------
    # 2. SMOOTHED‑MAX GRADIENT DESCENT REFINEMENT
    # ------------------------------------------------------------------
    if best_seq is None:                                 # should never happen
        n = 1000
        best_seq = np.ones(n, dtype=np.float64) / n
        best_val = _evaluate_on_simplex(best_seq)

    a = best_seq.copy()
    n = len(a)

    max_iters = 8000
    eta0 = 0.6                # initial learning rate
    beta0 = 4.0               # initial smooth‑max temperature
    beta_mul = 1.02

    for it in range(max_iters):
        if time.time() > deadline:
            break

        conv = _conv_fft(a, a)
        cur_max = np.max(conv)
        cur_val = 2.0 * n * cur_max
        if cur_val < best_val:
            best_val, best_seq = cur_val, a.copy()
            print(f"[gd]  iter {it:4d}  val={cur_val:.6f}")

        # smoothed max (log‑sum‑exp) weights
        beta = beta0 * (beta_mul ** it)
        shift = cur_max                       # stabilise exponentials
        w = np.exp(beta * (conv - shift))
        w_sum = w.sum()
        if w_sum == 0.0:
            continue
        w /= w_sum

        # gradient = 2 * (a_rev * w)   (only the central n entries are needed)
        grad_full = _conv_fft(a[::-1], w)
        grad = 2.0 * grad_full[n - 1:n - 1 + n]

        # exponentiated (multiplicative) update + projection onto simplex
        eta = eta0 / np.sqrt(it + 1.0)
        a = a * np.exp(-eta * grad)
        a = _project_simplex(a)

    # ------------------------------------------------------------------
    # 3. LINEAR‑PROGRAMMING REFINEMENT (active‑set step)
    # ------------------------------------------------------------------
    lp_iters = 6
    mix_weight = 0.5                # convex combination factor (1‑t)

    for lp_it in range(lp_iters):
        if time.time() > deadline:
            break

        # current bound M
        conv = _conv_fft(a, a)
        M = np.max(conv)

        # solve LP  max 1ᵀ g   s.t. (a * g) ≤ M , g ≥ 0
        g = _lp_max_sum_under_bound(a, M)
        if g is None:
            print("[lp]  LP failed – aborting LP phase")
            break

        sum_g = g.sum()
        if sum_g == 0.0:
            print("[lp]  Trivial solution – aborting LP phase")
            break

        g_norm = g / sum_g                # back to probability simplex

        # convex combination (keeps sum = 1)
        a = (1.0 - mix_weight) * a + mix_weight * g_norm

        # a short warm‑up of gradient descent after mixing
        warm_iters = 400
        for w_it in range(warm_iters):
            if time.time() > deadline:
                break
            conv = _conv_fft(a, a)
            cur_max = np.max(conv)
            cur_val = 2.0 * n * cur_max
            if cur_val < best_val:
                best_val, best_seq = cur_val, a.copy()
                print(f"[lp‑gd] lp {lp_it} warm {w_it}  val={cur_val:.6f}")

            beta = beta0 * (beta_mul ** (lp_it * warm_iters + w_it))
            shift = cur_max
            w = np.exp(beta * (conv - shift))
            w_sum = w.sum()
            if w_sum == 0.0:
                break
            w /= w_sum
            grad_full = _conv_fft(a[::-1], w)
            grad = 2.0 * grad_full[n - 1:n - 1 + n]
            eta = eta0 / np.sqrt(lp_it * warm_iters + w_it + 1.0)
            a = a * np.exp(-eta * grad)
            a = _project_simplex(a)

    # ------------------------------------------------------------------
    # 4. RANDOM LOCAL SEARCH (optional, cheap)
    # ------------------------------------------------------------------
    # A few perturbations followed by a short gradient run can escape
    # possible shallow local minima.
    perturb_trials = 12
    for trial in range(perturb_trials):
        if time.time() > deadline:
            break
        eps = 0.02
        a_pert = best_seq + eps * np.random.randn(n)
        a_pert = np.clip(a_pert, 0.0, None)
        if a_pert.sum() == 0.0:
            continue
        a_pert /= a_pert.sum()

        # short gradient descent from the perturbed start
        a_loc = a_pert.copy()
        for it in range(300):
            if time.time() > deadline:
                break
            conv = _conv_fft(a_loc, a_loc)
            cur_max = np.max(conv)
            cur_val = 2.0 * n * cur_max
            if cur_val < best_val:
                best_val, best_seq = cur_val, a_loc.copy()
                print(f"[rand] trial {trial} iter {it}  val={cur_val:.6f}")

            beta = beta0 * (beta_mul ** (it))
            shift = cur_max
            w = np.exp(beta * (conv - shift))
            w_sum = w.sum()
            if w_sum == 0.0:
                break
            w /= w_sum
            grad_full = _conv_fft(a_loc[::-1], w)
            grad = 2.0 * grad_full[n - 1:n - 1 + n]
            eta = 0.5 / np.sqrt(it + 1.0)
            a_loc = a_loc * np.exp(-eta * grad)
            a_loc = _project_simplex(a_loc)

    # ------------------------------------------------------------------
    # 5. Return the best solution found
    # ------------------------------------------------------------------
    # Convert to a plain Python list (evaluate_sequence will apply its own
    # clipping and normalisation, but we already stay on the simplex).
    return best_seq.tolist()
```
