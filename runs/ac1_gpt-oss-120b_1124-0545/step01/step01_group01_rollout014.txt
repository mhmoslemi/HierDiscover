Propose a step‑function height sequence that minimizes

    E(a) = 2 * n * max(conv(a, a)) / (sum(a)**2)

with a_i ≥ 0.  The search is performed in three stages:

1.  Random exponential families (a_i ∝ exp(-λ·i) and variants) give quick
    good candidates.
2.  A smoothed–max gradient descent refines the best candidate.

    weighted sum of the gradients of the individual convolution entries.
    The descent steps are projected onto the ℓ₁‑simplex (fixed ℓ₁‑norm
    √(2·n)).
3.  Inside each refinement run a small fraction of the genuine sub‑gradient
    of the current maximal convolution entry is mixed in, helping to
    flatten the whole convolution profile.

The algorithm respects the 1000 s time budget, prints progress and
returns the best sequence found as a plain Python list.

import random

# Simplex projection (Wang & Carreira‑Perpiñán, 2013)
def _simplex_projection(v: np.ndarray, s: float) -> np.ndarray:
    """Project v onto the simplex { w ≥ 0 , sum(w)=s }."""
    n = v.size
    if s < 0:
        raise ValueError("Target sum must be non‑negative")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, s / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w
