Algorithm
---------
1. Initialise the sequence with the normalised Catalan coefficients
   (the discrete analogue of (1‑x)^‑½).  This gives a good start
   with a score ≈ π/2.

   the infinity‑norm of the self‑convolution:
        F(a) = log‑sum‑exp( α·(a*a) ) / α

   The gradient of this surrogate is a weighted sum of the gradients of
   the individual convolution entries; the weights are a soft‑max over
   the current convolution values.  When ``α`` is small the optimiser
   smooths the whole profile, later it concentrates on the maximal
   entry, effectively mimicking a sub‑gradient step for the true max.

   After every Adam step we project back onto the feasible set:
   non‑negative entries and ℓ₁‑norm equal to 1.

   Keep the best sequence seen so far.

4. After the gradient phase launch a few short random‑restart runs
   (Dirichlet‑initialised) to escape possible local minima.

5. Finish with a lightweight simulated‑annealing perturbation stage

is exhausted.  All heavy linear‑algebra operations use FFTs, so the
method scales to a few thousand coefficients inside the time limit.
"""

import numpy as np
import time

# Helper functions (must be top‑level – no closures)
# ----------------------------------------------------------------------


def compute_catalan_sequence(n: int) -> np.ndarray:
    """
    Return the first *n* Catalan‑type coefficients

        c_i = (2i choose i) / 4**i   ,   i = 0 … n‑1

    and normalise them so that they sum to one.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    a /= a.sum()
    return a


def random_perturb(a: np.ndarray, eps: float) -> np.ndarray:
    """
    Transfer a fraction ``eps`` of the mass from a random index i
    to a different random index j (i ≠ j) and re‑normalise.
    """
    n = a.shape[0]
    i, j = np.random.randint(0, n, size=2)
    if i == j:
        return a
    delta = eps * a[i]
    if delta <= 0.0:
        return a
    a2 = a.copy()
    a2[i] -= delta
    a2[j] += delta
    a2 /= a2.sum()
    return a2
