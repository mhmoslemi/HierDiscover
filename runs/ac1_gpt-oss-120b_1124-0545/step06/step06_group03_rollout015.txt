"""
propose_candidate – simple “power‑law” step functions

The evaluation function is scale‑invariant:
    E(a) = 2·n·max(conv(a,a)) / (∑a)² .
If we normalise ∑a = 1 the objective reduces to
    J(a) = 2·n·max(conv(a,a)) .

For a monotone increasing power law

        a_i ∝ (i+1)ᴾ      (i = 0 … n‑1)

the central convolution value (index n‑1) is

        C_center = (P+1)²·B(P+1,P+1) / n ,

where B is the Beta function.  The end value is
a_max² = ((P+1)/n)².
The maximum of the whole convolution is the larger of these two.
For a given length n the optimum exponent P is roughly ½·log₂n

The implementation below searches a small grid of lengths and exponents,

import time

from math import log2, sqrt

# ----------------------------------------------------------------------
# Helper: generate a power‑law (increasing) sequence and normalise it
# ----------------------------------------------------------------------
def _power_inc(n: int, p: float) -> np.ndarray:
    """
    Return a non‑negative sequence a_i = (i+1)^p,  i=0…n-1,
    normalised so that sum(a)=1.
    """
    i = np.arange(1, n + 1, dtype=np.float64)   # 1 … n
    a = i ** p
    s = a.sum()
    if s == 0.0:
        a = np.full(n, 1.0 / n, dtype=np.float64)
    else:
        a = a / s
    return a
