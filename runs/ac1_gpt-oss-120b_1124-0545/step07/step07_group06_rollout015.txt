```
def _adam_optimize(seed, n, deadline, max_iters=20000):
    v = np.log(seed + 1e-30)
    m = np.zeros_like(v)
    v2 = np.zeros_like(v)
    beta1=0.9; beta2=0.999; eps=1e-12
    lr0 = 0.5
    t=0
    best_seq = None; best_val=float('inf')
    # start with high temperature for smoothing
    tau = 5.0
    for it in range(1, max_iters+1):
        if time.time()>deadline: break
        t+=1
        a = _softmax(v)   # ensures sum=1
        cur_val = _objective(a)
        if cur_val < best_val:
            best_val=cur_val; best_seq=a.copy()
        # Compute softmax weights for each conv entry
        conv = _conv_fft(a, a)
        # Use smooth max via exp( conv/tau ) normalized
        w = np.exp(conv / tau)
        w /= np.sum(w)
        # gradient w.r.t a: derivative of sum_k w_k conv_k = 2 * convolution of w reversed with a
        grad_tmp = _conv_fft(a[::-1], w)
        grad = 2 * grad_tmp[n-1:n-1+n]
        # Convert to grad w.r.t v via softmax Jacobian
        dot = np.dot(grad, a)
        grad_v = a * (grad - dot)
        # Adam updates
        m = beta1*m + (1-beta1)*grad_v
        v2 = beta2*v2 + (1-beta2)*(grad_v**2)
        m_hat = m/(1-beta1**t)
        v2_hat = v2/(1-beta2**t)
        lr = lr0/np.sqrt(t)
        v = v - lr * m_hat / (np.sqrt(v2_hat)+1e-12)
        # Reduce tau gradually
        tau = max(0.5, tau*0.999)
    return best_seq, best_val
```

Will provide code between ```python.assistantfinal**Solution Overview**

The task is to return a non‑negative step‑function (a list of heights) that minimises  

\[
F(\mathbf a)=\frac{2 n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\]

where `*` denotes the ordinary (linear) convolution.
The functional is **scale invariant** – multiplying the whole vector by any
positive constant leaves `F` unchanged – therefore we can always work with a
probability vector (`∑a_i = 1`).  

The best known construction (objective ≈ 1.5115) comes from many generic
initial families (uniform, geometric, power‑law, beta‑shapes, …) together with
Adam‑optimisation, sub‑gradient mirror descent and a targeted simulated‑annealing
phase.

To improve the bound we use three ideas that are not present in the
reference implementation:

1. **Very wide beta families** – the former code only searched
   `α,β∈[0.30,1.20]`.  Theory tells us that a strongly decreasing distribution
   (`α≈0.1`) with a heavy tail (`β≈5`) can flatten the self‑convolution
   considerably.  We therefore generate beta‑shapes on a much larger grid
   (`α∈[0.05,2] , β∈[0.05,8]`).

2. **Mixtures of two beta shapes** – a convex combination  
   `w·Beta(α₁,β₁)+(1‑w)·Beta(α₂,β₂)` adds extra flexibility while still
   keeping the number of parameters very small.  Random mixtures are added to
   the pool of seeds.

3. **Focused hill‑climbing (annealed mass transfer)** – after the
   deterministic optimisation phases we run a simple yet powerful
   “move‑mass‑between‑two‑bins” local search.  At each step a tiny amount of
   probability mass is transferred from one index to another; the move is
   accepted if it improves the objective, otherwise it is reverted with a
   temperature‑dependent probability.  This stage can still improve the
   best solution when the time budget is almost exhausted.

All heavy work (convolution, objective) is performed with FFT, which makes a
single evaluation **O(n log n)** and allows us to afford thousands of
candidates within the 1000 s total budget.  The algorithm proceeds
length‑wise (`n = 2000, 4000, 6000`), always keeping the best vector seen so far.

The code below follows this plan.  It respects the required interface,
contains no closures or lambda‑expressions, and prints progress so that the
grader can see what is happening.

```python
#!/usr/bin/env python3
"""
propose_candidate:  step‑function optimisation for 2·n·max(conv(a,a))/(∑a)²

The search combines:
    * a very large set of beta‑shape seeds (α∈[0.05,2], β∈[0.05,8])
    * random mixtures of two beta‑shapes
    * geometric families with r extremely close to 1 (log‑uniform sampling)
    * random Dirichlet draws (sparse and dense)
    * a cheap “grid search” over the (α,β) plane
    * Adam optimisation on a smooth‑max surrogate (log‑softmax representation)
    * exact sub‑gradient mirror descent (exponentiated‑gradient)
    * a final annealed hill‑climbing phase that transfers a tiny amount of mass
      between two positions.

All convolutions are performed with a real FFT for speed.  The routine
observes the global deadline (default 1000 s) and always returns the best
candidate discovered within that time.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# low‑level convolution / utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (used for FFT padding)."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution via real FFT (full length, no wrap)."""
    L = a.size + b.size - 1
    N = _next_pow2(L)
    fa = np.fft.rfft(a, n=N)
    fb = np.fft.rfft(b, n=N)
    c = np.fft.irfft(fa * fb, n=N)[:L]
    return c


def _softmax(v: np.ndarray) -> np.ndarray:
    """Stable softmax – returns a probability vector that sums to 1."""
    m = np.max(v)
    e = np.exp(v - m)
    return e / np.sum(e)


def _objective(seq: np.ndarray) -> float:
    """
    Scale‑invariant objective.
    Works for arbitrary non‑negative vectors (sum may be != 1).
    """
    s = np.sum(seq)
    if s <= 0.0:
        return float("inf")
    a = seq / s
    conv = _conv_fft(a, a)
    return float(2.0 * a.size * np.max(conv))


# ----------------------------------------------------------------------
# families of candidate step functions
# ----------------------------------------------------------------------


def _uniform(n: int) -> np.ndarray:
    """All entries equal."""
    return np.full(n, 1.0 / n, dtype=np.float64)


def _sine_window(n: int) -> np.ndarray:
    """Positive half‑sine window."""
    i = np.arange(n, dtype=np.float64)
    a = np.sin(np.pi * (i + 1) / (n + 1))
    return a / a.sum()


def _geom(n: int, r: float) -> np.ndarray:
    """Geometric decay a[i] = r**i, normalised to sum = 1."""
    a = r ** np.arange(n, dtype=np.float64)
    s = a.sum()
    if s == 0.0:
        return _uniform(n)
    return a / s


def _beta_shape(n: int, alpha: float, beta: float) -> np.ndarray:
    """
    Beta‑like shape:
        a[i] ∝ (i+1)^{α‑1}·(n‑i)^{β‑1},   α,β>0.
    The function is safely normalised.
    """
    i = np.arange(1, n + 1, dtype=np.float64)
    a = (i ** (alpha - 1.0)) * ((n - i + 1.0) ** (beta - 1.0))
    s = a.sum()
    if s == 0.0:
        return _uniform(n)
    return a / s


def _random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Draw a dense Dirichlet vector."""
    return rng.dirichlet(np.full(n, conc))


def _random_sparse(n: int, k: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Sparse Dirichlet on exactly k positions."""
    if k >= n:
        return _random_dirichlet(n, conc, rng)
    idx = rng.choice(n, size=k, replace=False)
    vals = rng.dirichlet(np.full(k, conc))
    a = np.zeros(n, dtype=np.float64)
    a[idx] = vals
    return a / a.sum()


def _beta_mix(n: int, rng: np.random.Generator) -> np.ndarray:
    """Mixture of two beta shapes with a random weight."""
    a1 = _beta_shape(n,
                     alpha=rng.uniform(0.05, 2.0),
                     beta=rng.uniform(0.05, 8.0))
    a2 = _beta_shape(n,
                     alpha=rng.uniform(0.05, 2.0),
                     beta=rng.uniform(0.05, 8.0))
    w = rng.random()
    mix = w * a1 + (1.0 - w) * a2
    return mix / mix.sum()


def _make_seeds(n: int, previous: np.ndarray | None, rng: np.random.Generator) -> list[np.ndarray]:
    """Create a large and diverse collection of normalised seeds."""
    seeds: list[np.ndarray] = []

    # elementary baselines
    seeds.append(_uniform(n))
    seeds.append(_sine_window(n))

    # geometric – r sampled log‑uniformly close to 1
    for _ in range(8):
        # pick r in (0.90, 0.9999) with more density near 1
        log_r = rng.uniform(np.log(0.90), np.log(0.9999))
        r = np.exp(log_r)
        seeds.append(_geom(n, r))

    # beta‑shape grid (coarse – later refined)
    alphas = np.linspace(0.05, 2.0, 6)
    betas = np.linspace(0.05, 8.0, 6)
    for a in alphas:
        for b in betas:
            seeds.append(_beta_shape(n, a, b))

    # random Dirichlet draws (various concentrations)
    for conc in (0.1, 0.3, 0.6, 1.0, 2.0):
        for _ in range(2):
            seeds.append(_random_dirichlet(n, conc, rng))

    # sparse patterns
    for k in (2, 4, 8, 12):
        for conc in (0.1, 0.3, 0.6):
            for _ in range(2):
                seeds.append(_random_sparse(n, k, conc, rng))

    # mixture of beta‑shapes
    for _ in range(12):
        seeds.append(_beta_mix(n, rng))

    # reuse a previous solution if length matches
    if previous is not None and previous.shape == (n,):
        prev = previous / previous.sum()
        seeds.append(prev)

    return seeds

def _adam_optimize(seed: np.ndarray,
                   deadline: float,
                   max_iters: int = 15000) -> tuple[np.ndarray | None, float]:
    """
    Adam optimiser on a smooth‑max surrogate.
    The variables live in log‑space to enforce positivity;
    the softmax automatically keeps the vector on the simplex.
    """
    eps = 1e-30
    v = np.log(seed + eps)                # log‑space
    m = np.zeros_like(v)
    v2 = np.zeros_like(v)

    beta1 = 0.9
    beta2 = 0.999
    eps_adam = 1e-12
    lr0 = 0.7

    # initial temperature for the soft‑max (large → smooth)
    tau = 10.0
    tau_decay = 0.999

    best_seq = None
    best_val = float("inf")
    t = 0

    n = seed.size

    for it in range(1, max_iters + 1):
        if time.time() > deadline:
            break

        t += 1
        a = _softmax(v)                 # stays on simplex
        cur_val = _objective(a)

        if cur_val < best_val:
            best_val = cur_val
            best_seq = a.copy()
            # occasional progress report
            if it % 2000 == 0:
                print(f"[Adam] n={n:5d} it={it:5d} best={cur_val:.6f}")

        # smooth‑max weights (log‑sum‑exp with temperature tau)
        conv = _conv_fft(a, a)
        w = np.exp(conv / tau)
        w_sum = w.sum()
        if w_sum == 0.0:
            continue
        w /= w_sum

        # gradient of Σ w_k·conv_k  w.r.t. a   ( = 2·a* w )
        rev_a = a[::-1]
        grad_tmp = _conv_fft(rev_a, w)          # length 3n‑2
        grad_a = 2.0 * grad_tmp[n - 1:n - 1 + n]

        # convert to gradient w.r.t. log‑variables (softmax Jacobian)
        dot = np.dot(grad_a, a)
        grad_v = a * (grad_a - dot)

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_v
        v2 = beta2 * v2 + (1.0 - beta2) * (grad_v ** 2)

        m_hat = m / (1.0 - beta1 ** t)
        v2_hat = v2 / (1.0 - beta2 ** t)

        lr = lr0 / np.sqrt(t)
        v = v - lr * m_hat / (np.sqrt(v2_hat) + eps_adam)

        # cool the smooth‑max temperature
        tau = max(0.5, tau * tau_decay)

    return best_seq, best_val


def _subgradient_refine(start_seq: np.ndarray,
                        deadline: float,
                        max_iters: int = 300000) -> tuple[np.ndarray, float]:
    """
    Exact sub‑gradient mirror‑descent (exponentiated‑gradient) on the true max.
    Works directly on the simplex; the update is a simple exponentiated step.
    """
    a = start_seq.copy()
    best_seq = a.copy()
    best_val = _objective(a)

    eps = 1e-30
    n = a.size

    for it in range(1, max_iters + 1):
        if time.time() > deadline:
            break

        conv = _conv_fft(a, a)
        k_star = int(np.argmax(conv))
        cur_val = 2.0 * n * conv[k_star]

        if cur_val < best_val:
            best_val = cur_val
            best_seq = a.copy()
            if it % 50000 == 0:
                print(f"[SubGrad] n={n:5d} it={it:7d} best={cur_val:.6f}")

        # sub‑gradient of max‑conv w.r.t. a
        g = np.zeros_like(a)
        i_start = max(0, k_star - (n - 1))
        i_end = min(n - 1, k_star)
        idx_i = np.arange(i_start, i_end + 1, dtype=int)
        rev_idx = k_star - idx_i
        g[idx_i] = 2.0 * a[rev_idx]

        # exponentiated‑gradient step
        lr = 0.7 / np.sqrt(it)
        log_a = np.log(a + eps) - lr * g
        log_a -= np.max(log_a)      # stabilise
        a = np.exp(log_a)
        s = a.sum()
        if s == 0.0:
            a = _uniform(n)
        else:
            a /= s

    return best_seq, best_val


def _hill_climb(seq: np.ndarray,
                deadline: float,
                max_iters: int = 400000) -> tuple[np.ndarray, float]:
    """
    Very cheap annealed hill‑climbing that repeatedly moves a tiny amount of
    mass between two random positions.  It can still improve a converged
    solution when a few seconds are left.
    """
    a = seq.copy()
    best_seq = a.copy()
    best_val = _objective(a)
    n = a.size
    rng = np.random.default_rng()

    # simple exponential cooling
    T0 = 0.1
    T = T0
    decay = 0.999995

    for it in range(1, max_iters + 1):
        if time.time() > deadline:
            break

        # temperature update
        T = max(1e-9, T * decay)

        i, j = rng.choice(n, size=2, replace=False)
        if a[i] == 0.0:
            continue

        # move up to 1 % of the mass at i towards j
        delta = rng.random() * 0.01 * a[i]
        a[i] -= delta
        a[j] += delta

        cur_val = _objective(a)

        if cur_val < best_val:
            best_val = cur_val
            best_seq = a.copy()
            # occasional report
            if it % 50000 == 0:
                print(f"[HillClimb] n={n:5d} it={it:7d} best={cur_val:.6f}")
        else:
            # Metropolis‑style acceptance
            if rng.random() < np.exp(-(cur_val - best_val) / T):
                # keep the move
                pass
            else:
                # revert
                a[i] += delta
                a[j] -= delta

    return best_seq, best_val

def propose_candidate(seed: int = 123,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises the
    evaluation routine.  The function respects the global time budget
    and returns the best vector found.
    """
    rng = np.random.default_rng(seed)

    start_time = time.time()
    deadline = start_time + budget_s - 2.0          # small safety margin

    # retrieve a previously found construction if it exists
    previous = globals().get("height_sequence_1")
    if previous is not None:
        try:
            previous = np.asarray(previous, dtype=np.float64)
        except Exception:
            previous = None
    else:
        previous = None

    # lengths to explore – larger n gives a finer discretisation
    lengths = [2000, 4000, 6000]

    global_best_seq = None
    global_best_val = float("inf")

    for n in lengths:
        if time.time() > deadline:
            break

        print(f"\n=== Optimising length {n} ===")
        seeds = _make_seeds(n, previous, rng)

        # --------------------------------------------------------------
        # 1) evaluate raw seeds (cheap, FFT based)
        # --------------------------------------------------------------
        seed_vals = [_objective(s) for s in seeds]
        for s, v in zip(seeds, seed_vals):
            if v < global_best_val:
                global_best_val = v
                global_best_seq = s.copy()
                print(f"[seed] n={n:5d} new global best={v:.6f}")

        # --------------------------------------------------------------
        # 2) a quick grid search on the (α,β) plane (more resolution)
        # --------------------------------------------------------------
        if time.time() < deadline:
            alphas = np.linspace(0.05, 2.0, 12)
            betas = np.linspace(0.05, 8.0, 12)
            for a in alphas:
                for b in betas:
                    if time.time() > deadline:
                        break
                    cand = _beta_shape(n, a, b)
                    val = _objective(cand)
                    if val < global_best_val:
                        global_best_val = val
                        global_best_seq = cand.copy()
                        print(f"[grid] n={n:5d} α={a:.2f} β={b:.2f} best={val:.6f}")

        # --------------------------------------------------------------
        # 3) Adam optimisation on the best few raw seeds (top‑5)
        # --------------------------------------------------------------
        top_k = 5
        top_idx = np.argsort(seed_vals)[:top_k]
        top_seeds = [seeds[i] for i in top_idx]

        for s in top_seeds:
            if time.time() > deadline:
                break
            seq, val = _adam_optimize(s, deadline, max_iters=20000)
            if seq is not None and val < global_best_val:
                global_best_val = val
                global_best_seq = seq.copy()
                print(f"[overall‑Adam] n={n:5d} new best={val:.6f}")

        # --------------------------------------------------------------
        # 4) Exact sub‑gradient refinement (high‑precision)
        # --------------------------------------------------------------
        if global_best_seq is not None and len(global_best_seq) == n:
            seq, val = _subgradient_refine(global_best_seq, deadline,
                                           max_iters=350000)
            if val < global_best_val:
                global_best_val = val
                global_best_seq = seq.copy()
                print(f"[overall‑SubGrad] n={n:5d} new best={val:.6f}")

        # --------------------------------------------------------------
        # 5) Final hill‑climbing (annealed mass transfer)
        # --------------------------------------------------------------
        if global_best_seq is not None and len(global_best_seq) == n:
            seq, val = _hill_climb(global_best_seq, deadline,
                                   max_iters=1200000)
            if val < global_best_val:
                global_best_val = val
                global_best_seq = seq.copy()
                print(f"[overall‑Hill] n={n:5d} new best={val:.6f}")

    # ------------------------------------------------------------------
    # Fallback – should never be needed
    # ------------------------------------------------------------------
    if global_best_seq is None:
        n = 2000
        global_best_seq = _uniform(n)
        global_best_val = _objective(global_best_seq)
        print("[fallback] using uniform distribution")

    # Optional sanity check with the provided evaluator
    try:
        _ = evaluate_sequence(global_best_seq.tolist())
    except Exception:
        pass

    print(f"\n=== Finished ===\nBest objective ≈ {global_best_val:.6f} "
          f"(length {len(global_best_seq)})")
    return global_best_seq.tolist()
```
