    E(a) = 2 * n * max(conv(a,a)) / (sum(a)**2)

The temperature‑like parameter β is increased from a small value to a

After every update the vector is projected back onto the simplex.
Occasional tiny random perturbations help escaping shallow local minima.
The routine respects a supplied time budget (≈1000 s) and returns the

import random
import numpy as np

# ----------------------------------------------------------------------
def _simplex_projection(v: np.ndarray, s: float) -> np.ndarray:
    """
    Project a vector `v` onto the simplex {x >= 0, sum(x)=s}.
    Implementation of the algorithm by Wang & Carreira‑Perpiñán (2013).
    """
    if s < 0:
        raise ValueError("Target sum must be non‑negative")
    n = v.size
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # fallback – should happen only when s == 0
        return np.full_like(v, s / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w
