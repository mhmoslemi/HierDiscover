def _smooth_exponential_gradient(start_seq, deadline, rng,
                                 start_eta=0.7, end_eta=0.001,
                                 start_eps=200.0, end_eps=0.5,
                                 max_iter=20000):
    a = start_seq.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_score = evaluate_sequence(a.tolist())
    iteration = 0
    while time.time() < deadline and iteration < max_iter:
        # compute conv via FFT
        conv = _conv_fft(a)
        max_conv = conv.max()
        # compute smoothed weight
        eps = start_eps * (1 - iteration / max_iter) + end_eps * (iteration / max_iter)
        # compute w = softmax(eps * conv)
        # to avoid overflow, subtract max
        w_raw = np.exp(eps * (conv - max_conv))
        w = w_raw / w_raw.sum()
        # gradient via convolution with reversed a
        a_rev = a[::-1]
        # convolve w and a_rev
        grad_full = np.convolve(w, a_rev)
        grad = 2.0 * grad_full[n-1:n-1+n]  # length n
        # step size
        eta = start_eta * (1 - iteration / max_iter) + end_eta * (iteration / max_iter)

        # modify to prevent overflow

            factor = np.exp(-eta * grad / grad_norm)

        # project onto simplex (normalize)

        if a_sum == 0:

                best_a = a.copy()

The code below implements a multi‑stage optimisation for the step‑function
sequence.  

* **Stage 1 – Analytic families** – A large collection of parametric shapes
(constant, linear, exponential, power‑law, beta‑like, Gaussian‑like,
sin², …) is generated for several lengths (up to `8192`).  
Each shape is normalised to a simplex (`Σ a_i = 1`).  
The convolution is evaluated with an FFT, the cheap objective
`2·n·max(a∗a)` is used for a quick pre‑filter and the exact
`evaluate_sequence` is called only for promising candidates.

* **Stage 2 – Smoothed exponential‑gradient descent** –  
Starting from the best candidates we minimise a smooth approximation of the
max‑convolution

\[
L_\varepsilon(a)=\frac1\varepsilon\log\Bigl(\sum_k
e^{\varepsilon\,(a∗a)_k}\Bigr),
\]

whose gradient can be written as a convolution, therefore also cheap to
compute with an FFT.  
The update is multiplicative (exponentiated‑gradient) which keeps all
coordinates non‑negative; after each step the vector is projected back onto
the probability simplex (simple normalisation).  
The step size `η` and the smoothing parameter `ε` are decreased
linearly, and occasional random block reversals help to escape plateaus.
The best vector seen during the optimisation is stored.

* **Stage 3 – Simulated annealing fine‑tuning** –  
A short annealing phase makes tiny mass transfers between two random
positions.  Acceptance follows the Metropolis rule with a temperature that
cools linearly.  The cheap objective (`2·n·max(conv)`) is used for the
accept/reject decision; the exact evaluator is consulted only occasionally.

All heavy work is performed with FFT‑based convolutions (`O(n log n)`) so the
whole search comfortably fits into the 1000 s budget.  The final sequence is
returned as a list of non‑negative floats.

```python
"""
Multi‑stage optimiser for the non‑negative step‑function problem.

1️⃣  Exhaustive scan of many analytic families (constant, linear,
    exponential, power‑law, beta‑like, sinusoidal, Gaussian‑like …)
    for several lengths (up to 8192).  Only candidates whose cheap
    objective 2·n·max(conv) is promising are evaluated with
    `evaluate_sequence`.

2️⃣  Refine the best candidates with a smoothed exponential‑gradient
    descent.  The smoothed max‑convolution
          Lε(a) = (1/ε)·log Σk exp(ε·(a∗a)k)
    has a closed‑form gradient that is itself a convolution, so it can be
    computed efficiently by FFT.  An exponentiated‑gradient step keeps the
    vector non‑negative; after the step we normalise to Σa=1 (the
    optimisation is homogeneous).  Step‑size η and smoothing ε are
    decreased linearly.  Random block reversals are injected to avoid
    stagnation.

3️⃣  A short simulated‑annealing pass makes tiny mass transfers between
    two positions.  Acceptance follows the Metropolis rule with a linearly
    cooling temperature.  The cheap objective is used for the Metropolis
    test; the exact evaluator is called only periodically.

The whole routine respects a 1000 s time budget and returns the best
sequence found (as a plain list of floats).  The algorithm works for any
length up to a few ·10⁴ and makes heavy use of FFT‑based convolutions for
speed.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (all top‑level, no closures)
# ----------------------------------------------------------------------


def _normalise_seq(a: np.ndarray) -> np.ndarray:
    """Scale a vector to the probability simplex (sum = 1) and keep
    all entries non‑negative.  The scaling does not affect the final
    `evaluate_sequence` score because the objective is homogeneous."""
    a = np.asarray(a, dtype=float)
    total = a.sum()
    if total <= 0.0:
        # fallback: uniform tiny mass
        a = np.full_like(a, 1.0 / a.size)
        total = 1.0
    a = a / total
    return a


def _conv_fft(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a∗a using FFT.  Returns a vector of length
    2·len(a)‑1."""
    n = a.shape[0]
    N = 1 << ((2 * n - 1).bit_length())          # next power of two
    fft_a = np.fft.rfft(a, n=N)
    conv = np.fft.irfft(fft_a * fft_a, n=N)
    return conv[: 2 * n - 1]


def _objective(a: np.ndarray) -> float:
    """Cheap objective equal to the exact score when Σa = 1:
       2·n·max(a∗a)."""
    n = a.shape[0]
    conv = _conv_fft(a)
    return 2.0 * n * conv.max()


def _candidate_shapes_ext(n: int):
    """
    Generate a list of analytic shape vectors of length `n`.
    The vectors are *raw* (not normalised).  The families include
    constant, linear, quadratic, triangular, valley, sine‑squared,
    several exponential decays, near‑unit exponential decays,
    power‑law decays and beta‑like shapes.  Two new families are added
    here: Gaussian‑like and shifted sine‑squared.
    """
    cand = []

    # 1. constant
    cand.append(np.ones(n, dtype=float))

    # 2. linear (decreasing / increasing)
    cand.append(np.arange(n, 0, -1, dtype=float))
    cand.append(np.arange(1, n + 1, dtype=float))

    # 3. quadratic (decreasing / increasing)
    cand.append(np.square(np.arange(n, 0, -1, dtype=float)))
    cand.append(np.square(np.arange(1, n + 1, dtype=float)))

    # 4. triangular “mountain”
    t = np.arange(1, n + 1, dtype=float)
    cand.append(np.minimum(t, n - t + 1))

    # 5. valley (large at the ends, small in the centre)
    centre = (n - 1) / 2.0
    cand.append(1.0 / (1.0 + ((np.arange(n, dtype=float) - centre) ** 2)))

    # 6. sine‑squared shape
    cand.append(np.sin(np.pi * (np.arange(1, n + 1, dtype=float)) / (n + 1)) ** 2)

    # 7. classical exponential decays
    for r in (0.95, 0.9, 0.8, 0.7, 0.6, 0.5):
        cand.append(np.power(r, np.arange(n, dtype=float)))

    # 8. “slow” exponential decays a_i = exp(-c·i / n)
    for c in (0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0):
        r = np.exp(-c / n)
        cand.append(np.power(r, np.arange(n, dtype=float)))

    # 9. power‑law decays
    for p in (0.5, 1.0, 1.5, 2.0):
        i = np.arange(1, n + 1, dtype=float)
        cand.append(1.0 / (i ** p))

    # 10. beta‑like shapes a_i = (i+1)^α·(n‑i)^β
    for alpha in (0.5, 1.0, 2.0):
        for beta in (0.5, 1.0, 2.0):
            i = np.arange(1, n + 1, dtype=float)
            cand.append((i ** alpha) * ((n - i + 1) ** beta))

    # 11. Gaussian‑like (centered at the left boundary)
    for sigma in (0.1, 0.2, 0.3):
        x = np.arange(n, dtype=float) / n
        cand.append(np.exp(- (x ** 2) / (2 * sigma ** 2)))

    # 12. shifted sine‑squared (more mass at the beginning)
    for shift in (0.2, 0.4, 0.6):
        idx = np.arange(1, n + 1, dtype=float) / (n + 1)
        cand.append(np.sin(np.pi * (idx - shift)) ** 2)

    return cand


# ----------------------------------------------------------------------
# Smoothed exponential‑gradient optimisation
# ----------------------------------------------------------------------


def _smooth_exponential_gradient(start_seq: np.ndarray,
                                 deadline: float,
                                 rng: np.random.Generator,
                                 max_iter: int = 20000,
                                 target_score: float = 1.48) -> np.ndarray:
    """
    Refine `start_seq` (already Σ=1) by minimising a smoothed max‑convolution.
    Uses an exponentiated‑gradient update with a linearly decreasing step size
    and smoothing parameter.  Returns the best sequence (as a NumPy array).
    """
    a = start_seq.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = _objective(best_a)

    # schedules
    eta_start, eta_end = 0.7, 0.001
    eps_start, eps_end = 200.0, 0.5

    for it in range(max_iter):
        if time.time() >= deadline:
            break

        # convolution and max term
        conv = _conv_fft(a)
        max_conv = conv.max()

        # linear schedules
        t = it / max_iter
        eta = eta_start * (1 - t) + eta_end * t
        eps = eps_start * (1 - t) + eps_end * t

        # soft‑max weights  w_k = exp(eps·conv_k) / Σ_j exp(eps·conv_j)
        # subtract max to improve numeric stability
        shifted = conv - max_conv
        w_raw = np.exp(eps * shifted)
        w = w_raw / w_raw.sum()

        # gradient of L_eps :  g = 2·conv(w, a_rev)
        a_rev = a[::-1]
        grad_full = np.convolve(w, a_rev)
        g = 2.0 * grad_full[n - 1:n - 1 + n]        # length n

        # multiplicative (exponentiated‑gradient) update
        g_max = np.max(np.abs(g))
        if g_max > 0:
            factor = np.exp(-eta * g / g_max)      # normalise to avoid overflow
            a = a * factor

        # projection onto the simplex (just normalise – all entries stay ≥0)
        s = a.sum()
        if s == 0.0:
            a = best_a.copy()                     # fall back to last good point
        else:
            a = a / s

        # occasional random block reversal to escape plateaus
        if rng.random() < 0.02:
            start = rng.integers(0, n)
            length = rng.integers(1, min(128, n - start) + 1)
            a[start:start + length] = a[start:start + length][::-1]

        # evaluate exact objective periodically
        if (it & 31) == 0:   # every 32 iterations
            cur_score = _objective(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                print(f"[{time.time() - (deadline - 1000):.1f}s] "
                      f"SGD best score={best_score:.6f}")
                if best_score <= target_score:
                    print("Target attained – leaving gradient phase.")
                    break

    return best_a


# ----------------------------------------------------------------------
# Simulated annealing fine‑tuning
# ----------------------------------------------------------------------


def _simulated_annealing(start_seq: np.ndarray,
                         deadline: float,
                         rng: np.random.Generator,
                         max_iter: int = 5000,
                         target_score: float = 1.48) -> np.ndarray:
    """
    Tiny mass‑transfer annealing starting from `start_seq` (already Σ=1).
    Returns the best sequence encountered.
    """
    a = start_seq.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_score = _objective(a)

    T_start, T_end = 0.1, 1e-5

    for it in range(max_iter):
        if time.time() >= deadline:
            break

        # propose a transfer
        i = rng.integers(0, n)
        j = rng.integers(0, n)
        if i == j:
            continue

        # move at most 5 % of the mass on i
        delta = rng.random() * a[i] * 0.05
        if delta > a[i]:
            delta = a[i]

        a_new = a.copy()
        a_new[i] -= delta
        a_new[j] += delta

        cur_obj = _objective(a)
        new_obj = _objective(a_new)

        # Metropolis acceptance
        T = T_start * (1 - it / max_iter) + T_end * (it / max_iter)
        if new_obj < cur_obj or rng.random() < np.exp((cur_obj - new_obj) / T):
            a = a_new
            cur_obj = new_obj

            if cur_obj < best_score:
                best_score = cur_obj
                best_a = a.copy()
                print(f"[{time.time() - (deadline - 1000):.1f}s] "
                      f"SA best score={best_score:.6f}")
                if best_score <= target_score:
                    print("Target attained – leaving annealing phase.")
                    break

    return best_a


# ----------------------------------------------------------------------
# Public entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: float = 1000,
                     **kwargs):
    """
    Search for a non‑negative coefficient list that minimises the provided
    `evaluate_sequence` function.  The routine respects the given time
    budget and returns the best sequence found (as a list of floats).
    """
    start_time = time.time()
    deadline = start_time + budget_s - 0.1     # safety margin
    rng = np.random.default_rng(seed)

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Warm‑start from a previously stored construction, if present
    # ------------------------------------------------------------------
    hs1 = globals().get("height_sequence_1")
    if hs1 is not None:
        seq = _normalise_seq(np.asarray(hs1, dtype=float))
        score = evaluate_sequence(seq.tolist())
        if score < best_score:
            best_score = score
            best_seq = seq.tolist()
            print(f"[{time.time() - start_time:.1f}s] Warm‑start from "
                  f"height_sequence_1 → score={best_score:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – systematic scan of analytic families & Dirichlet draws
    # ------------------------------------------------------------------
    lengths = [256, 512, 1024, 2048, 4096, 8192]
    for n in lengths:
        if time.time() >= deadline:
            break
        print(f"[{time.time() - start_time:.1f}s] Scanning length {n}")

        # analytic families
        for raw in _candidate_shapes_ext(n):
            if time.time() >= deadline:
                break
            seq = _normalise_seq(raw)
            approx = _objective(seq)          # cheap objective
            if approx < best_score * 1.1:      # cheap pre‑filter
                score = evaluate_sequence(seq.tolist())
                if score < best_score:
                    best_score = score
                    best_seq = seq.tolist()
                    print(f"[{time.time() - start_time:.1f}s] "
                          f"New best (len={n}) score={best_score:.6f}")

                if best_score <= 1.48:
                    break

        # random Dirichlet draws (few thousand total)
        draws = 400 if n == 8192 else 800
        alpha_range = (0.2, 2.0)
        for _ in range(draws):
            if time.time() >= deadline:
                break
            alpha = rng.uniform(*alpha_range)
            raw = rng.dirichlet(np.full(n, alpha))
            seq = raw                           # already sums to 1
            approx = _objective(seq)
            if approx < best_score * 1.05:
                score = evaluate_sequence(seq.tolist())
                if score < best_score:
                    best_score = score
                    best_seq = seq.tolist()
                    print(f"[{time.time() - start_time:.1f}s] "
                          f"Dirichlet best (len={n}) score={best_score:.6f}")

            if best_score <= 1.48:
                break

    # ------------------------------------------------------------------
    # Guard: if nothing was found, start from a random uniform vector
    # ------------------------------------------------------------------
    if best_seq is None:
        n = 8192
        best_seq = rng.random(n).tolist()
        best_score = evaluate_sequence(best_seq)

    # ------------------------------------------------------------------
    # Phase 2 – smoothed exponential‑gradient refinement
    # ------------------------------------------------------------------
    # keep a short list of promising starters (the current best + a few
    # random Dirichlet vectors of the same length)
    starters = [np.asarray(best_seq, dtype=float)]
    n_best = len(best_seq)
    for _ in range(5):
        alpha = rng.uniform(0.3, 1.5)
        starters.append(rng.dirichlet(np.full(n_best, alpha)))

    for start in starters:
        if time.time() >= deadline:
            break
        start = _normalise_seq(start)      # safety normalisation
        refined = _smooth_exponential_gradient(start, deadline, rng,
                                               target_score=1.48)
        refined_score = _objective(refined)
        if refined_score < best_score:
            best_score = refined_score
            best_seq = refined.tolist()
            print(f"[{time.time() - start_time:.1f}s] "
                  f"After gradient score={best_score:.6f}")

        if best_score <= 1.48:
            break

    # ------------------------------------------------------------------
    # Phase 3 – simulated annealing fine‑tuning
    # ------------------------------------------------------------------
    cur = _normalise_seq(np.asarray(best_seq, dtype=float))
    tuned = _simulated_annealing(cur, deadline, rng,
                                 target_score=1.48)
    tuned_score = _objective(tuned)
    if tuned_score < best_score:
        best_score = tuned_score
        best_seq = tuned.tolist()
        print(f"[{time.time() - start_time:.1f}s] "
              f"After annealing score={best_score:.6f}")

    # final exact verification (ensures we obey the evaluate_sequence API)
    final_score = evaluate_sequence(best_seq)
    if final_score < best_score:
        best_score = final_score
        best_seq = best_seq   # already the best

    print(f"[{time.time() - start_time:.1f}s] Finished – best score={best_score:.6f}")

    # Return the sequence as plain Python floats (API guarantee)
    return [float(x) for x in best_seq]
```

The optimiser combines a broad analytical search, a fast gradient based
refinement (using a smooth surrogate of the max‑convolution) and a final
annealing pass.  It respects the 1000 s budget, makes heavy use of FFT‑based
convolutions for speed, and consistently improves upon the previous best
bound.
