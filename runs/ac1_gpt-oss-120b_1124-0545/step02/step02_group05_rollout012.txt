Propose a candidate step‑function sequence.

Algorithm (LP‑guided rebalancing)

* Initialise a feasible non‑negative vector `a` of length `n`
  (takes the existing construction `height_sequence_1` if present,
  otherwise a uniform vector).  The ℓ₁‑norm is fixed to
  S = sqrt(2·n) because the evaluation function is scale‑invariant,
  and with this normalisation the objective reduces to `max(conv(a,a))`.

* In each iteration
    – compute the current maximal self‑convolution `M`.
    – build a small “active” set of the `k_active` largest
      convolution entries (these are the constraints that are tight
      and therefore most relevant).
    – form the linear constraints   A·g ≤ M   that constrain a new
      vector `g` (g ≥ 0) so that its convolution with the current `a`
      never exceeds the present maximum.
    – solve the linear program
          maximise   Σ g_j
          subject to A·g ≤ M ,  g ≥ 0
      using SciPy’s high‑performance `linprog` (HiGHS).  The LP finds
      an extreme point that pushes as much mass as possible into the
      “holes’’ of the current convolution profile.
    – rescale `g` to satisfy the ℓ₁‑norm constraint
          g ← g * (S / Σ g).
    – if the rescaled `g` already improves the objective
            max(conv(g,g)) < M
      replace `a` by `g`.  Otherwise try a convex combination
            a' = (1‑t)·a + t·g   with several trial step‑sizes `t`.
      Accept the first `t` that yields a strict improvement.
    – keep track of the best vector seen so far.
    – every few hundred iterations perform a random perturbation
      (mix the best vector with a fresh exponential sample) to
      escape possible plateaus.

* The loop runs until the 1000 s time budget (minus a small safety
  margin) expires.  The best sequence discovered is returned as a
  plain Python list, ready to be passed to `evaluate_sequence`.

The method does not rely on gradient information; it works directly
with linear programming on the most binding convolution constraints.
Empirically this produces a rapid decrease of the maximum

def _simplex_projection(v: np.ndarray, s: float) -> np.ndarray:
    """Project a vector onto the simplex {w ≥ 0, Σ w = s}."""
    if s < 0:
        raise ValueError("Target sum must be non‑negative")
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, s / n)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def _max_convolution(a: np.ndarray) -> float:
    """Return max of the full self‑convolution of a."""
    return np.max(np.convolve(a, a))


def _build_active_matrix(a: np.ndarray, idx_rows: np.ndarray) -> np.ndarray:
    """
    Construct the matrix A (shape |idx_rows| × n) such that
        (A @ g)[r] = sum_i a_i * g_{k_r - i}
    for each selected convolution index k_r in idx_rows.
    """
    n = a.size
    m = idx_rows.size
    A = np.zeros((m, n), dtype=float)
    for r, k in enumerate(idx_rows):
        # indices j for which 0 ≤ k - j < n  ⇔  j ∈ [max(0,k-n+1) , min(k,n-1)]
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        js = np.arange(j_start, j_end + 1, dtype=int)
        A[r, js] = a[k - js]
    return A
