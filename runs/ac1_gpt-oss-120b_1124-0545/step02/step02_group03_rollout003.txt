assistantfinal**Solution Explanation**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a_i\ge 0,
\]

where `a*a` is the full linear convolution of `a` with itself.
The value is invariant under scaling, therefore we keep the vector on the
probability simplex (`∑a_i = 1`).  
`F(a)=2·n·max(conv)` because after normalisation `∑a_i = 1`.

The previous implementation used a sub‑gradient that only looks at the
indices that are *exactly* maximal.  When the convolution has a flat
plateau the gradient becomes zero and the search stalls.  
The new algorithm lifts this issue by **smoothing the max operator** with a
log‑sum‑exp.  The smoothed objective

\[
G_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_k e^{\beta\, (a*a)_k}\Bigr)
\]

has a well‑behaved gradient for any `β>0`.  
When `β→∞`, `G_β` converges to the original max, so we increase `β`
gradually (annealing).

The gradient of `G_β` is a weighted combination of all convolution
entries:

\[
\nabla G_\beta(a)=2\;a_{\text{rev}} * w,
\qquad 
w_k=\frac{e^{\beta (a*a)_k}}{\sum_j e^{\beta (a*a)_j}} .
\]

`*` denotes linear convolution, `a_rev` is `a` reversed.
The factor **2** comes from the two symmetric contributions in a
self‑convolution.

Because the feasible set is the simplex we use an **exponentiated‑gradient**
(step of the form `a_i ← a_i·exp(-η∇_i)`) which stays in the interior of
the simplex, followed by normalisation.  This is more natural than a
simple Euclidean projection and gives a larger effective step size.

To keep exploration we occasionally perform a cheap random *mass‑transfer*
move (move a tiny amount of probability mass from one index to another)
and we restart from a fresh random point when the search has not improved
for a while.

All operations are performed with FFT‑based convolutions (`O(n log n)`);
with `n=6000` the whole loop fits comfortably into the 1000 s budget.

--------------------------------------------------------------------

```python
"""
Probabilistic exponentiated‑gradient search with a smoothed max‑operator.

- The objective 2·n·max(conv) is scale‑invariant → we keep the vector on the
  simplex (∑a = 1, a ≥ 0).
- A log‑sum‑exp with an annealed temperature β approximates the max
  and provides a dense gradient even on plateaus.
- Gradient of the smooth objective is obtained by a convolution of the
  reversed current vector with the soft‑max weights.
- An exponentiated‑gradient update respects the simplex geometry.
- Random “mass‑transfer’’ moves and time‑based restarts avoid stagnation.
- The algorithm works for any length n (default 6000) and
  returns the best sequence found within the time budget.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper routines (top level, no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_fft(u: np.ndarray, v: np.ndarray, size: int) -> np.ndarray:
    """
    Linear convolution using FFT.  ``size`` must be a power of two
    and ≥ len(u)+len(v)-1.
    Returns the full convolution truncated to the mathematically correct length.
    """
    fu = np.fft.rfft(u, n=size)
    fv = np.fft.rfft(v, n=size)
    w = np.fft.irfft(fu * fv, n=size)
    return w[: len(u) + len(v) - 1]


def _full_convolution(a: np.ndarray, size: int) -> np.ndarray:
    """Convenient wrapper for a*a."""
    return _conv_fft(a, a, size)


def _random_transfer(a: np.ndarray, scale: float) -> np.ndarray:
    """
    Move a random fraction of mass from one index to another.
    ``scale`` controls the maximal transferred proportion of the source entry.
    """
    n = a.shape[0]
    i, j = np.random.randint(n, size=2)
    while i == j:
        j = np.random.randint(n)
    max_transfer = a[i]
    if max_transfer == 0.0:
        return a
    delta = scale * max_transfer * np.random.rand()
    a_new = a.copy()
    a_new[i] -= delta
    a_new[j] += delta
    # renormalise (the sum is unchanged up to rounding)
    s = a_new.sum()
    if s > 0.0:
        a_new /= s
    else:
        a_new = np.random.rand(n)
        a_new /= a_new.sum()
    return a_new


def _initial_distribution(n: int) -> np.ndarray:
    """
    Initialise a probability vector of length ``n``.
    If a global variable ``height_sequence_1`` exists we upsample it,
    otherwise we start from a random Dirichlet point.
    """
    seq0 = globals().get("height_sequence_1", None)
    if isinstance(seq0, (list, tuple, np.ndarray)):
        seq0 = np.asarray(seq0, dtype=float)
        if seq0.size != n:
            # linear interpolation to the required length
            x_old = np.linspace(0.0, 1.0, seq0.size, endpoint=False)
            x_new = np.linspace(0.0, 1.0, n, endpoint=False)
            a = np.interp(x_new, x_old, seq0)
        else:
            a = seq0.copy()
        a = np.clip(a, 0.0, None)
        total = a.sum()
        if total > 0.0:
            a /= total
        else:
            a = np.random.rand(n)
            a /= a.sum()
        return a
    # fallback: uniform Dirichlet draw
    a = np.random.rand(n)
    a /= a.sum()
    return a


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Search for a low‑value step‑function within ``budget_s`` seconds.

    The algorithm:
        * keeps the candidate on the probability simplex,
        * minimises a smoothed version of the max‑autocorrelation via
          exponentiated‑gradient updates,
        * slowly increases the smoothing parameter β (annealing),
        * injects occasional random mass‑transfer moves,
        * restarts when progress stalls.

    The best sequence found is returned as a plain ``list[float]``.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 0.5          # tiny safety margin

    # --------------------------------------------------------------
    # problem size
    # --------------------------------------------------------------
    n = int(kwargs.get("n", 6000))

    # --------------------------------------------------------------
    # initialise a probability vector
    # --------------------------------------------------------------
    a = _initial_distribution(n)

    # --------------------------------------------------------------
    # pre‑compute FFT lengths (powers of two) – they stay constant
    # --------------------------------------------------------------
    size_conv = _next_pow2(2 * n - 1)       # for a * a
    size_grad = _next_pow2(3 * n - 2)       # for a_rev * weight vector

    # --------------------------------------------------------------
    # bookkeeping
    # --------------------------------------------------------------
    # initial objective (sum a = 1 ⇒ denominator = 1)
    conv = _full_convolution(a, size_conv)
    max_b = conv.max()
    best_score = 2.0 * n * max_b
    best_seq = a.copy()
    print(f"[init] n={n}, initial score={best_score:.6f}")

    # algorithmic hyper‑parameters
    eta0 = 0.12                # base learning rate for exponentiated update
    beta = 0.6                 # initial temperature for the soft‑max
    beta_inc = 0.0015          # how fast β grows (annealing)
    beta_max = 12.0            # stop growing after this point
    rand_prob = 0.015          # probability of a random mass‑transfer move
    rand_scale = 0.06          # relative size of the random transfer
    stagnation_time = 35.0     # seconds without improvement → restart
    last_improve = start
    it = 0

    # --------------------------------------------------------------
    # main optimisation loop
    # --------------------------------------------------------------
    while time.time() < deadline:
        # ----- 1. current convolution and score -----
        conv = _full_convolution(a, size_conv)
        max_b = conv.max()
        cur_score = 2.0 * n * max_b

        # ----- 2. keep the best -----
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_seq = a.copy()
            last_improve = time.time()
            elapsed = last_improve - start
            print(f"[{it:7d}] new best = {best_score:.6f}  time={elapsed:.1f}s")

        # ----- 3. decide whether to explore randomly -----
        if np.random.rand() < rand_prob:
            a = _random_transfer(a, rand_scale)
        else:
            # ----- 4. smooth‑max weights -----
            # stability trick: subtract the maximum before exponentiation
            conv_shift = conv - conv.max()
            exp_vals = np.exp(beta * conv_shift)
            w = exp_vals / exp_vals.sum()          # shape (2n‑1,)

            # ----- 5. gradient of the smoothed objective -----
            a_rev = a[::-1]
            grad_full = _conv_fft(a_rev, w, size_grad)   # length 3n‑2
            # central n entries correspond to the partial derivatives
            grad = 2.0 * grad_full[n - 1 : n - 1 + n]

            # ----- 6. exponentiated‑gradient update -----
            # step size decays like 1/√t to guarantee convergence
            eta = eta0 / np.sqrt(it + 1.0)
            # move in the negative gradient direction
            mult = np.exp(-eta * grad)
            # avoid under‑flow – enforce a tiny lower bound
            a = a * mult
            a = np.maximum(a, 1e-15)
            a /= a.sum()        # projection onto the simplex

        # ----- 7. anneal the temperature -----
        if beta < beta_max:
            beta = min(beta_max, beta + beta_inc)

        # ----- 8. occasional restart if we are stuck -----
        if (time.time() - last_improve) > stagnation_time:
            a = np.random.rand(n)
            a /= a.sum()
            last_improve = time.time()
            print(f"[{it:7d}] restart due to stagnation (β={beta:.2f})")

        it += 1

    # --------------------------------------------------------------
    # final reporting
    # --------------------------------------------------------------
    total = time.time() - start
    print(f"[done] iterations={it}, best score={best_score:.6f}, time={total:.1f}s")
    # Return the best sequence as a plain list of Python floats.
    # (evaluate_sequence will perform its own clipping, so we keep numbers modest.)
    return best_seq.tolist()
```
