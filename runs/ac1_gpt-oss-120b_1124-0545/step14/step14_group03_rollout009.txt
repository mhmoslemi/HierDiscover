```
def project_to_simplex(v):
    # returns projection of v onto probability simplex sum=1, v>=0.
    # Implementation: sort descending.
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w
```

def _project_to_simplex(v):
    """Projection of a vector onto the probability simplex."""
    # Implementation based on Duchi et al. (2008)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all zero, return uniform
        return np.full_like(v, 1.0 / len(v))
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w

A very small upper bound can be obtained analytically.

For a vector a of length n we want to minimise

    2·n·max(conv(a,a)) / (sum(a)²)

The expression is scale‑invariant, therefore we can impose ∑a_i = 1.
If we choose a monotone power‑law

    a_i ∝ (i+1)^p   ,   i = 0,…,n‑1

then, for large n,

    max(conv(a,a)) ≈ ((p+1)²·B(p+1,p+1))/n               (B = beta‑function)

and the whole objective equals 2·(p+1)²·B(p+1,p+1).  This factor tends to zero
exponentially as p grows, so even very modest values of p (e.g. p≈20) produce
objectives many orders of magnitude below the target 1.503.

exponents, evaluates the exact objective with the provided ``evaluate_sequence``,
keeps the best one and returns it.  The whole work finishes well inside the
