Random sparse mask search for low max‑autocorrelation step functions.

The code samples many binary supports (sets of indices) of size `m`,
assigns equal weight on the chosen indices and keeps the best sequence.
The surrogate objective 2·n·max(conv) / (sum²) is evaluated cheaply via
FFT‑based convolution on the binary mask (the weight factor 1/m² is applied
analytically).  When a promising support is found we optionally polish the
weights by a short exponentiated‑gradient descent on the exact objective.
The whole procedure respects the 1000 s budget and stores the best vector

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())

def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full linear convolution via real FFT (complexity O(n log n))."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.irfft(fx * fy, n=N)[:L]
    return conv

def _surrogate_from_mask(mask: np.ndarray, m: int, n: int) -> float:
    """
    Return the surrogate value 2·n·max(conv) for a uniform distribution on `mask`.

    `mask` is a binary (0/1) vector of length `n`, `m` = mask.sum().
    The true convolution of the probability vector `p = mask / m` equals
    conv_counts / m² where conv_counts = mask * mask (linear convolution).
    """
    conv_counts = _conv_fft(mask.astype(np.float64), mask.astype(np.float64))
    max_cnt = float(np.max(conv_counts))
    return 2.0 * n * max_cnt / (m * m)

def _objective_full(seq: np.ndarray) -> float:
    """Exact objective 2·n·max(conv) for a full (already normalised) vector."""
    n = len(seq)
    conv = _conv_fft(seq, seq)
    return float(2.0 * n * np.max(conv))

def _exp_gradient_refine(seq: np.ndarray, deadline: float) -> np.ndarray:
    """
    A very short exponentiated‑gradient polish on the exact objective.
    The routine stops when the deadline is reached or after a small
    number of iterations (≈5 000).  It keeps the vector on the simplex.
    """
    n = len(seq)
    a = seq.copy()
    a = a / a.sum()
    log_a = np.log(a + 1e-30)

    it = 0
    while True:
        if time.time() > deadline:
            break
        if it >= 5000:
            break
        it += 1

        conv = _conv_fft(a, a)
        max_idx = int(np.argmax(conv))

        g = np.zeros_like(a)
        i_start = max(0, max_idx - (n - 1))
        i_end = min(n - 1, max_idx)
        idx_i = np.arange(i_start, i_end + 1, dtype=int)
        rev_idx = max_idx - idx_i
        g[idx_i] = 2.0 * a[rev_idx]

        eta = 0.5 / math.sqrt(it)
        log_a -= eta * g
        a = np.exp(log_a)
        a = a / a.sum()
    return a

            best_val = val

    # ------------------------------------------------------------------
    iteration = 0

    target_surrogate = 1.503 * (1.0)  # the objective itself (already 2·n·max)

        # an objective below the target.
        # The heuristic draws m uniformly in [600, 2000].
        m = int(rng.integers(600, 2001))

        idx = rng.choice(n, size=m, replace=False)

        mask[idx] = 1

            seq = mask.astype(np.float64) / m

            best_val = surrogate

Random‑sparse‑mask optimisation for the max‑autoconvolution objective.

The programme repeatedly draws a random set of indices (a “support”),
places equal probability mass on those indices and keeps the best
candidate seen so far.  The surrogate objective  

    2·n·max(conv(a,a)) / (sum(a)²)

is evaluated extremely cheaply for a uniform distribution on a support
because

    conv(a,a) = conv(mask,mask) / |mask|²

where *mask* is the binary indicator of the support.  The convolution
itself is performed with a real FFT (O(n log n)).  Occasionally the same
support is re‑weighted with a Dirichlet draw, which can give a modest
extra improvement.  When a promising vector is found we finish with a
very short exponentiated‑gradient polish that works on the exact
objective.

The whole search respects the 1000 s budget, stores the best sequence in

    fy = np.fft.rfft(y, n=N)

    The probability vector is p = mask / m (∑p = 1).  Its convolution
    satisfies conv(p,p) = conv(mask,mask) / m², so the objective
