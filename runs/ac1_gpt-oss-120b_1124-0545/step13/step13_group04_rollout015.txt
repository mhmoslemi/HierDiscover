Propose a step‑function (non‑negative list) that minimizes

    2·n·max(conv(a,a)) / (sum(a)²)

The objective is scale‑invariant, i.e. it depends only on the
ℓ₁‑normalised vector p = a / sum(a).  Hence we minimise the
ℓ₁‑simplex problem

    f(p) = 2·n·max(p∗p) .

The algorithm is deliberately simple and fast:

1.  Initialise `p` from the previously found solution (global
    variable ``height_sequence_1``) if it exists, otherwise from a
    random sparse support with equal weights.
2.  Run a long **projected sub‑gradient descent** on the exact
    non‑smooth objective.  In each iteration we
        • compute the full linear convolution via a real FFT,
        • locate the index k where the convolution attains its maximum,
        • form the sub‑gradient `g_i = 2·p_{k‑i}` (zero outside the valid
          range),
        • take a diminishing step `p ← p – η_k·g` and project back onto the
          probability simplex using the Euclidean projection.
    The step size follows η_k = η₀ / sqrt(k) (η₀≈0.05).  This schedule
    yields many tiny updates that slowly flatten the peak.
3.  Every ~10 000 iterations a tiny Gaussian perturbation is added
    (amplitude 1e‑6) to help escape shallow plateaus.
4.  The best vector seen during the whole run (lowest surrogate value)
    is finally evaluated with the official ``evaluate_sequence`` call and
    stored in ``height_sequence_1`` for possible reuse.

All heavy work is done with FFT‑based convolutions (O(n log n)) and the
projection onto the simplex (O(n log n)).  The routine respects the
user‑supplied time budget (default 1000 s) and guarantees a single call
to ``evaluate_sequence`` at the end.
"""

import time
import math
import numpy as np

# ------------------------------------------------------------
# Low‑level utilities (FFT convolution, simplex projection, etc.)
# ------------------------------------------------------------

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Full linear convolution using a real FFT (O(n log n)).
    Returns an array of length len(x)+len(y)-1.
    """
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.ifft(fx * fy, n=N).real[:L]
    return conv


def _proj_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    (∑v = 1, v ≥ 0).  Implements the O(n) algorithm of
    Wang & Carreira‑Perpiñán (2013).
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # All entries equal – the projection is the uniform vector.
        return np.full_like(v, 1.0 / n)
    rho = ind[cond].max()
    theta = cssv[cond].max() / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _surrogate(p: np.ndarray, n: int) -> float:
    """
    Fast surrogate 2·n·max(conv(p,p)) for an ℓ₁‑normalised vector.
    Used only for cheap comparisons; the final value is obtained
    from ``evaluate_sequence``.
    """
    conv = _conv_fft(p, p)
    return float(2.0 * n * np.max(conv))
