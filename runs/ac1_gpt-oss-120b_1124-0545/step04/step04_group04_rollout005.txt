The goal is to return a non‑negative vector `a` that minimises  

```python
E(a) = 2·n·max(conv(a,a)) / (sum(a)**2)
```

with `conv(a,a) = np.convolve(a,a)`.  
The problem is non‑convex, the objective is scale‑invariant and the only
constraints are non‑negativity (the evaluator also clips values to the
interval `[0,1000]`).  

The programme below combines three ideas that together beat the previous
run:

1. **Broad random exploration** – a cheap Dirichlet‑sampling phase gives
   a good starting point quickly.
2. **Smoothed‑max Adam optimisation** – we optimise a *soft* version of the
   max‑operator (log‑sum‑exp) on the simplex via a soft‑max
   parametrisation.  The temperature (`β`) is annealed from a large value
   (very smooth) down to a hard max.  Adam with a decaying learning‑rate
   updates the log‑parameters.  The gradient of the (smoothed) objective is
   obtained analytically using FFTs; this is the same gradient that the
   previous code used but with a more aggressive schedule and an
   automatic restart when progress stalls.
3. **Local hill‑climbing** – after the Adam phase we perform inexpensive
   pairwise mass‑transfer moves (`δ` from index *i* to *j*) and keep any
   improvement.  Because the objective is cheap to evaluate with the
   pre‑compiled `evaluate_sequence`, this stage can perform many tiny
   refinements.

The whole search respects the 1000 s budget, uses at most two CPU cores
(the code is pure NumPy) and prints periodic progress reports.

```python
"""Propose a step‑function (non‑negative vector) that minimises the
objective used by ``evaluate_sequence``.

The algorithm consists of:
  1. A quick random Dirichlet sampling phase.
  2. Several independent Adam‑optimisation runs that minimise a
     temperature‑annealed soft‑max of the convolution.
  3. A cheap hill‑climbing post‑processing that swaps tiny amounts of
     mass between two positions.

All helper functions are top‑level; there are no closures or lambda
expressions.  The routine respects the 1000 s time budget and returns the
best sequence found.
"""

import time
import math
import numpy as np

# -------------------------------------------------------------
# Helper utilities – all top‑level, no closures
# -------------------------------------------------------------

def softmax(v: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max mapping ℝⁿ → simplex."""
    v_max = np.max(v)
    e = np.exp(v - v_max)
    return e / e.sum()


def _next_pow2(x: int) -> int:
    """Small helper – smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_fft(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Linear convolution a*a using FFT of length ``fft_len``."""
    fa = np.fft.fft(a, fft_len)
    conv = np.real(np.fft.ifft(fa * fa))[: 2 * len(a) - 1]
    return conv


def _gradient_softmax(a: np.ndarray,
                      w: np.ndarray,
                      fft_len: int,
                      n: int) -> np.ndarray:
    """
    Gradient of 2·n·⟨w, a*a⟩ w.r.t. the *probability* vector a.

    Parameters
    ----------
    a : np.ndarray, shape (n,)
        Current probability vector (∑a = 1, a ≥ 0).
    w : np.ndarray, shape (2·n-1,)
        Weight vector – either a soft‑max over the convolution or a hard mask.
    fft_len : int
        Length of the FFT (≥ 3·n‑2) used for the linear convolutions.
    n : int
        Length of the underlying sequence.

    Returns
    -------
    g : np.ndarray, shape (n,)
        Gradient of the smoothed objective w.r.t. a.
    """
    # FFT of the weight vector
    fw = np.fft.fft(w, fft_len)

    # a's FFT (already computed in the caller, but recompute for clarity)
    fa = np.fft.fft(a, fft_len)

    # (w * a) – linear convolution, first n entries
    conv_wa = np.real(np.fft.ifft(fw * fa))[: 3 * n - 2]
    g2 = conv_wa[:n]

    # w ⋆ a  – linear cross‑correlation, first n entries
    # cross‑correlation = ifft(conj(fw) * fa)
    corr_full = np.real(np.fft.ifft(np.conj(fw) * fa))[: 3 * n - 2]
    g1 = corr_full[:n]

    # Gradient of 2·n·⟨w, a*a⟩
    return 2.0 * n * (g1 + g2)


def _adam_optimize(a_init: np.ndarray,
                   n: int,
                   time_budget: float,
                   rng: np.random.Generator,
                   verbose: bool = True) -> tuple[np.ndarray, float]:
    """
    Adam optimisation of a single start vector ``a_init`` for at most
    ``time_budget`` seconds.  Returns the best vector found and the exact
    (scale‑invariant) score ``2·n·max(conv)`` (i.e. the value that
    ``evaluate_sequence`` would return for a vector normalised to sum = 1).

    The optimiser works on the log‑parameters ``v = log(a)`` and uses a
    temperature‑annealed soft‑max to obtain a smooth surrogate of the
    max‑operator.
    """
    # ---------- initialisation ----------
    v = np.log(a_init + 1e-12)          # log‑simplex parameters
    beta_start, beta_end = 1e3, 5e3    # temperatures (soft → hard)
    lr_start, lr_end = 0.4, 0.002      # learning‑rate schedule
    beta1, beta2, eps = 0.9, 0.999, 1e-8

    m = np.zeros_like(v)
    v_hat = np.zeros_like(v)

    fft_len = _next_pow2(3 * n - 2)

    # bookkeeping
    start = time.time()
    deadline = start + time_budget - 0.05   # tiny safety margin
    best_a = a_init.copy()
    cur_conv = _conv_fft(best_a, fft_len)
    best_score = 2.0 * n * cur_conv.max()
    last_improve = start
    it = 0
    mask_phase_start = 0.70        # switch to hard mask after 70 % of time

    # ---------- main loop ----------
    while time.time() < deadline:
        elapsed = time.time() - start
        p = min(1.0, elapsed / (time_budget - 5.0))   # normalised progress

        # temperature and learning‑rate schedules
        beta = beta_start * (1.0 - p) + beta_end * p
        lr = lr_start * (1.0 - p) + lr_end * p

        # ---- current probabilities (simplex) ----
        a = softmax(v)                     # Σa = 1, a_i ≥ 0

        # ---- convolution a*a --------------------
        conv = _conv_fft(a, fft_len)       # length 2·n‑1

        # ---- weight vector w (smooth max) ------
        if p < mask_phase_start:
            # smooth soft‑max (log‑sum‑exp) over the convolution entries
            z = beta * conv
            z_max = np.max(z)
            w = np.exp(z - z_max)
            w_sum = w.sum()
            w = w / w_sum
        else:
            # hard mask on the true maximum (sub‑gradient of max)
            max_val = conv.max()
            eps_mask = max_val * 1e-12 + 1e-14
            mask = (conv >= max_val - eps_mask).astype(float)
            mask_sum = mask.sum()
            if mask_sum == 0.0:            # safety fallback
                mask = np.zeros_like(conv)
                mask[np.argmax(conv)] = 1.0
                mask_sum = 1.0
            w = mask / mask_sum

        # ---- gradient wrt a (via FFT) ----------
        g = _gradient_softmax(a, w, fft_len, n)

        # ---- chain rule for the log‑softmax parametrisation ----
        #   ∂E/∂v = a ∘ (g - ⟨a,g⟩)
        ag = np.dot(a, g)
        grad_v = a * (g - ag)

        # ---- Adam update ----
        it += 1
        m = beta1 * m + (1.0 - beta1) * grad_v
        v_hat = beta2 * v_hat + (1.0 - beta2) * (grad_v ** 2)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat_corr = v_hat / (1.0 - beta2 ** it)

        v = v - lr * m_hat / (np.sqrt(v_hat_corr) + eps)

        # ---- exact score & bookkeeping ----------
        cur_score = 2.0 * n * conv.max()
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
            last_improve = time.time()
            if verbose and (it % 2000 == 0):
                print(
                    f"[Adam {it:07d}] new best = {best_score:.6f} "
                    f"(t={elapsed:.1f}s, β={beta:.1f})"
                )

        # ---- restart if stagnated for >15 s ----
        if time.time() - last_improve > 15.0:
            # jitter log‑parameters around the current best point
            jitter = rng.normal(scale=0.01, size=n)
            v = np.log(best_a + 1e-12) + jitter
            m.fill(0.0)
            v_hat.fill(0.0)
            last_improve = time.time()
            if verbose:
                print(f"[Adam {it:07d}] restart (no improve for 15 s)")

    return best_a, best_score


def _local_hill_climb(a: np.ndarray,
                      n: int,
                      time_budget: float,
                      rng: np.random.Generator,
                      verbose: bool = True) -> tuple[np.ndarray, float]:
    """
    Very cheap hill‑climbing: repeatedly move a tiny amount of mass
    between two random coordinates and keep the move if it improves the
    true objective (the one computed by ``evaluate_sequence``).

    Returns the (potentially) improved vector and its true score.
    """
    start = time.time()
    deadline = start + time_budget
    best_a = a.copy()
    best_score = evaluate_sequence(best_a.tolist())

    # typical step size – decreasing with the remaining time
    while time.time() < deadline:
        # pick two distinct indices
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue

        # magnitude of the transfer – a few per‑cent of the source weight
        delta = min(1e-3, best_a[i])
        if delta <= 0.0:
            continue

        cand = best_a.copy()
        cand[i] -= delta
        cand[j] += delta

        # evaluate – the provided function already performs all clipping
        score = evaluate_sequence(cand.tolist())
        if score < best_score - 1e-12:
            best_a = cand
            best_score = score
            if verbose:
                now = time.time() - start
                print(
                    f"[Hill‑climb] improved to {best_score:.6f} "
                    f"(t={now:.1f}s, moved {delta:.5f} from {i}→{j})"
                )
    return best_a, best_score

# Main entry point required by the evaluation harness
# -------------------------------------------------------------

def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function (a probability vector)
    that minimises ``evaluate_sequence``.  The routine respects the
    total time budget (default 1000 s) and returns the best sequence it
    found as a plain ``list[float]``.
    """
    rng_global = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + max(0.0, budget_s - 0.5)   # safety margin

    n = int(kwargs.get("n", 2000))

    # ------------------------------------------------------------------
    # 1) Quick random Dirichlet sampling
    # ------------------------------------------------------------------
    best_a = None
    best_score = float("inf")
    # allocate at most 10 % of the whole budget to the random phase
    random_budget = 0.10 * (deadline - start_time)
    while time.time() < start_time + random_budget:
        # Dirichlet with concentration 0.5 gives diverse, sparse starts
        a = rng_global.dirichlet(np.full(n, 0.5))
        score = evaluate_sequence(a.tolist())
        if score < best_score:
            best_score = score
            best_a = a
            print(f"[Random] new best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2) Adam optimisation – several independent starts
    # ------------------------------------------------------------------
    attempts = 6
    for attempt in range(attempts):
        time_left = deadline - time.time()
        if time_left < 15.0:               # not enough time for another run
            break

        # Allocate a fraction of the remaining budget to this attempt
        remaining = attempts - attempt
        alloc = time_left * 0.85 / remaining

        if attempt == 0 and "height_sequence_1" in globals():
            a0 = np.array(globals()["height_sequence_1"], dtype=float)
            if a0.size != n:
                if a0.size > n:
                    a0 = a0[:n]
                else:
                    a0 = np.pad(a0, (0, n - a0.size))
            a0 = np.maximum(a0, 0.0)
            a0 = a0 / a0.sum()
        else:
            # start from the current global best (jittered) or a fresh Dirichlet
            if best_a is not None:
                a0 = best_a + 0.005 * rng_global.normal(size=n)
                a0 = np.clip(a0, 0.0, None)
                a0 = a0 / a0.sum()
            else:
                a0 = rng_global.dirichlet(np.full(n, 0.5))

        a_opt, score_opt = _adam_optimize(
            a_init=a0,
            n=n,
            time_budget=alloc,
            rng=np.random.default_rng(seed + attempt + 12345),
            verbose=False,
        )

        # Convert the raw Adam score (2·n·max) to the true evaluation score
        true_score = evaluate_sequence(a_opt.tolist())
        if true_score < best_score:
            best_score = true_score
            best_a = a_opt.copy()
            elapsed = time.time() - start_time
            print(
                f"[Attempt {attempt}] new global best = {best_score:.6f} "
                f"(elapsed {elapsed:.1f}s)"
            )

    # ------------------------------------------------------------------
    # 3) Final cheap hill‑climbing on the best candidate
    # ------------------------------------------------------------------
    time_left = deadline - time.time()
    if time_left > 5.0 and best_a is not None:
        a_hc, hc_score = _local_hill_climb(
            best_a,
            n,
            time_budget=time_left,
            rng=rng_global,
            verbose=False,
        )
        if hc_score < best_score:
            best_score = hc_score
            best_a = a_hc
            print(f"[Hill‑climb] final best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4) Fallback – uniform vector if nothing was ever found
    # ------------------------------------------------------------------
    if best_a is None:
        best_a = np.full(n, 1.0 / n)

    # Ensure non‑negativity (safety) and return as plain Python list
    best_a = np.maximum(best_a, 0.0)
    total_time = time.time() - start_time
    print(f"[done] best score = {best_score:.6f}, total time = {total_time:.1f}s")
    return best_a.tolist()
```
