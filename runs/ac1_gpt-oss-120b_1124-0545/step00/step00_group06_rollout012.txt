def project_simplex(v):
    # As per standard algorithm.
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.where(u - cssv / (np.arange(len(v)) + 1) > 0)[0][-1]

propose_candidate – Random binary mask search

The evaluation function is
    score = 2 * n * max(conv(a, a)) / (sum(a) ** 2)

Because the score is homogeneous, any scaling of the vector does not change the
result – we may always work with a vector whose entries sum to 1.

Idea
----
Take a long step‑function (n ≈ 2‑3 000) and make it a *binary* mask:
a_i is either 0 or 1/k, where k is the number of non‑zero entries.
If the non‑zeros are placed at random with density ≈ 0.5, the convolution
behaviour is that each sum index receives roughly k²/(2 n) ordered pairs.
Since each pair contributes (1/k)², the expected maximal convolution value is
≈ 1/(2 n), i.e. the score is close to 1 (far below the current 2.0 bound).

The search therefore consists of:
* draw many random masks of length n (n is random in a reasonable range);
* keep the mask with the lowest score;
* occasionally try a cheap local move (swap a zero with a one) to improve it.

The algorithm runs until the allotted time (≈ 1000 s) expires and returns the
best sequence found.  It never produces negative numbers (the mask is
non‑negative) and respects all validation checks of `evaluate_sequence`.

        # ------------------------------------------------------------------
        # Create a random binary mask and turn it into a probability vector.
        # The mask must contain at least one 1.
        # ------------------------------------------------------------------
        mask = np.random.rand(n) < p
        k = mask.sum()
        if k == 0:
            continue
        a = mask.astype(float) / float(k)          # each non‑zero = 1/k, sum(a) == 1

        # ------------------------------------------------------------------
        # Evaluate and keep the best candidate.
        # ------------------------------------------------------------------
        score = evaluate_sequence(a.tolist())
        if score < best_score:
            best_score = float(score)
            best_seq = a.copy()
            print(f"[update] new best = {best_score:.6f} | n={n} p={p:.3f} k={k}")

        # ------------------------------------------------------------------
        # Occasionally try a tiny local optimisation: swap a 1 ↔ 0 while
        # preserving the number of non‑zeros (so the weight stays 1/k).
        # This can occasionally drop a stray peak.
        # ------------------------------------------------------------------
        if np.random.rand() < 0.03:                # low‑frequency local move
            nz_idx = np.where(best_seq > 0)[0]
            z_idx = np.where(best_seq == 0)[0]
            if nz_idx.size and z_idx.size:
                i = np.random.choice(nz_idx)
                j = np.random.choice(z_idx)
                # perform the swap (keep weight = 1/k)
                trial = best_seq.copy()
                trial[i] = 0.0
                trial[j] = 1.0 / float(k)
                trial_score = evaluate_sequence(trial.tolist())
                if trial_score < best_score:
                    best_score = float(trial_score)
                    best_seq = trial
                    print(f"[swap] improvement via swap -> {best_score:.6f}")

    # ------------------------------------------------------------------
    # Return the best sequence found (as a plain Python list).
    # ------------------------------------------------------------------
    print(f"[final] best score = {best_score:.6f} with length = {len(best_seq)}")
    return best_seq.tolist()
