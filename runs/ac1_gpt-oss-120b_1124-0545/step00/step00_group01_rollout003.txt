Propose a candidate step‑function (non‑negative sequence) that tries to beat the
current bound 2.0 for the evaluation function

    2 * n * max(conv(a,a)) / (sum(a)**2)

The algorithm works on a fixed length `n` (several lengths are tried) and
optimises the *smooth* approximation of the max‑convolution using an
exponentiated‑gradient descent on the simplex.

Key ideas
---------
*  Scale the sequence after each update so that Σa = sqrt(2n); then the
   evaluation value equals `max( conv(a,a) )`.
*  Replace `max(b)` by the smooth `p`‑norm   (∑ b_k^p)^{1/p}` with
   p growing from 4 to 20.  Its gradient is analytic and can be computed
   efficiently with one FFT‑based convolution.
*  Use an exponentiated‑gradient step `a_i ← a_i·exp(‑η·∇_i)`, which keeps
   the vector in the positive orthant; after the step we project back to the
   simplex by simple scaling.
*  Occasionally inject small random perturbations to escape possible
   plateaus and run a brief “hill‑climbing” phase at the end.
*  The whole search stops after the allotted budget (default 1000 s) and the
   best sequence found (as a plain list) is returned.

The routine deliberately avoids any file or network I/O and uses only
`numpy`, `time` and the already‑imported `evaluate_sequence`.
"""

import time
import math
import numpy as np


def _normalize_sum(a: np.ndarray, target: float) -> np.ndarray:
    """Scale a non‑negative vector so that its L1‑norm equals `target`."""
    total = a.sum()
    if total == 0.0:
        # fallback uniform allocation
        a[:] = target / a.size
    else:
        a *= target / total
    return a


def _next_pow2(x: int) -> int:
    """Small helper – smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Convolution via real FFT (fast for lengths ≥ ~200)."""
    n = x.size + y.size - 1
    L = _next_pow2(n)
    X = np.fft.rfft(x, n=L)
    Y = np.fft.rfft(y, n=L)
    Z = X * Y
    z = np.fft.irfft(Z, n=L)
    return z[:n]


def _smooth_max_gradient(a: np.ndarray, p: int):
    """
    Compute the smoothed max value of conv(a,a) and its gradient w.r.t `a`.

    Returns
    -------
    smooth_val : float
        (∑ b_k^p)^{1/p} where b = conv(a,a).
    grad : np.ndarray
        Gradient (same shape as `a`) of the smooth value.
    max_val : float
        The true max of the convolution (used for bookkeeping).
    """
    # convolution a*a
    b = _conv_fft(a, a)
    max_val = b.max()

    # smooth p‑norm of b
    b_pow = b ** p
    sum_bp = b_pow.sum()
    # protect against overflow / underflow
    if sum_bp == 0.0 or not np.isfinite(sum_bp):
        # fall back to the true max (gradient is zero)
        grad = np.zeros_like(a)
        return max_val, grad, max_val

    smooth = sum_bp ** (1.0 / p)

    # coefficient that appears in the gradient
    C = sum_bp ** (1.0 / p - 1.0)

    # w_k = b_k^{p-1}
    w = b ** (p - 1)

    # convolution w * reverse(a)
    conv_full = _conv_fft(w, a[::-1])

    # extract the slice that corresponds to ∂b_k/∂a_i
    n = a.size
    grad = 2.0 * C * conv_full[n - 1 : n - 1 + n]

    # guard against numerical issues
    grad = np.where(np.isfinite(grad), grad, 0.0)
    return smooth, grad, max_val
