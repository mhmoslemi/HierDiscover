def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Generates a simple polynomial step function f_i = (i/(n-1))^p scaled to max 1000.
    Using exponent p>=2 gives evaluation < 2, with p=2 ~0.6, p=3 ~0.23.
    Returns the generated sequence.
    """
    import numpy as np, time, math

    # Choose length based on existing sequence if available
    n = None
    if 'height_sequence_1' in globals():
        try:
            n = len(height_sequence_1)
        except Exception:
            n = None
    if n is None:
        n = 2000  # fallback length

    # Exponent p (integer >=2). We choose 3 to get good margin.
    p = 3

    # Generate values in [0,1000]
    # Use i from 0..n-1
    i = np.arange(n, dtype=np.float64)
    # Avoid division by zero for n=1; but n>1.
    norm = (i / (n - 1)) ** p
    seq = norm * 1000.0

    # Convert to Python list
    best_sequence = seq.tolist()

    # Optionally compute evaluation for logging
    try:
        score = evaluate_sequence(best_sequence)
        print(f"Generated polynomial sequence (p={p}, n={n}) => score {score}")
    except Exception as e:
        print("Evaluation failed:", e)

    return best_sequence

"""
Polynomial step function generator.

We construct a deterministic non‑negative sequence 
    a_i = 1000 * (i/(n-1))**p ,  i = 0,…,n‑1
where n is the length of the known best sequence (or a fallback size)

The convolution (f*f) at its largest index k = n‑1 equals 
∑_{i=0}^{n-1} a_i * a_{n-1-i} = 1000**2 * (p!²/(2p+1)!) * (n‑1)^{2p+1} / (n‑1)^{2p} ,
which after the scale‑invariant evaluation (2·n·max_b / (∑a)²) reduces to the
closed form  

    E(p) = 2 * (p!² / (2p+1)!) * (p+1)² .

For p = 2 we obtain E = 0.6, for p = 3 we obtain E ≈ 0.229, etc.  
Thus even the simple cubic shape (p = 3) easily beats the target bound
1.503, and the evaluation is independent of the length n (once n is

The function below builds the cubic sequence, clips automatically to the

once for logging, and returns the list.

    Produce a deterministic polynomial step function that achieves a very low
    evaluate_sequence score.
