propose_candidate – simple provably optimal construction.

The evaluation function is
    score = 2 * n * max(conv(sequence, sequence)) / (sum(sequence) ** 2)

Because the convolution is non‑negative and
    max(conv) ≥ conv_0 = Σ a_i²,
Cauchy–Schwarz gives  Σ a_i² ≥ (Σ a_i)² / n.
Hence for any non‑negative sequence of length n

    score = 2 * n * max(conv) / (Σ a_i)² ≥ 2 * n * (Σ a_i)² / (n * (Σ a_i)²) = 2.

Equality holds exactly when **all** entries are equal (the uniform step
function).  Therefore the uniform sequence is the global optimum and any
more elaborate search cannot beat a score lower than 2.

The function below therefore returns a uniform list of the same length as
the existing `height_sequence_1` (if available) or a default length of
1000.  A tiny optional local‑search loop is kept for completeness, but it
cannot improve the score beyond the optimum.

    """Create a uniform sequence of the given length."""
