sqrt(2·n)) equals the maximal entry of the convolution a*a.  To lower the
score we therefore minimise the peak of the convolution.  The algorithm
optimises the squared L2‑distance of the convolution to the constant
value C = sum(a)^2 / (2·n‑1) (the average of the convolution).  When the
convolution becomes flat its maximal entry approaches C, whose theoretical
limit is 1.  The optimisation proceeds by:

1. Choose a moderate length n (100‒400) – large enough for a good bound,
   small enough for fast iterations.
2. Initialise a random non‑negative vector and project it onto the simplex
   of total mass sqrt(2·n).
3. Repeatedly:
   * Compute the convolution c = a*a.
   * Compute the residual r = c – C.
   * The gradient of ½‖r‖₂² w.r.t. a is 4·(r * a_rev)[n‑1:n‑1+n],
     where a_rev = a[::-1] and * denotes the linear convolution.
   * Perform a back‑tracking line‑search on step size η and project the
     tentative point back onto the simplex (non‑negativity + fixed sum).
   * Accept the step only if the maximal convolution value decreases.
   * Occasionally inject a small random perturbation to escape plateaus.
4. Keep the best sequence encountered (according to ``evaluate_sequence``)
   and return it when the time budget expires.

The procedure is repeated from several random restarts (including the
previous best construction ``height_sequence_1`` if it is available) and
the overall best sequence is returned.  It runs completely within the
allowed 1000‑second budget and uses only NumPy; no file or network I/O
is performed.
"""

import numpy as np
import time
import math

# ----------------------------------------------------------------------
# Helper: projection of a vector onto the probability simplex with given
# total mass ``z`` (z > 0).  The result is non‑negative and sums to ``z``.
def _project_to_simplex(v, z=1.0):
    """Project onto the simplex {x >= 0, sum(x) = z}."""
    if z <= 0:
        raise ValueError("Simplex target must be positive")
    v = np.asarray(v, dtype=float)
    # shift to make the problem sum(x) = z
    u = np.sort(v)[::-1]
    css = np.cumsum(u) - z
    rho = np.where(u - css / (np.arange(1, len(v) + 1)) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = css[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
def propose_candidate(seed=42, budget_s=990, **kwargs):
    """
    Search for a step‑function (non‑negative heights) with a low evaluation
    score.  The algorithm uses projected gradient descent on the squared
    deviation of the auto‑convolution from a constant target, repeatedly
    from several random restarts (including the previous best construction
    if it exists).  The best sequence found before the time budget expires
    is returned.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s   # safety margin already applied

    # ------------------------------------------------------------------
    # configuration
    n_candidates = [150, 200, 250, 300]          # lengths to try
    max_iters_per_restart = 5000                # safety bound
    target_score = 2.0                          # current best known bound
    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # main loop over several restarts (including the previous solution)
    restart = 0
    while time.time() < deadline:
        # pick a length n (cycles through list, then random)
        if restart < len(n_candidates):
            n = n_candidates[restart]
        else:
            n = np.random.randint(120, 350)

        # total mass that corresponds to the usual normalisation:
        # sum(a) = sqrt(2 * n)  =>  evaluation == max(conv)
        target_sum = math.sqrt(2.0 * n)

        # initialise a sequence -------------------------------------------------
        if restart == 0 and 'height_sequence_1' in globals():
            # first restart: use the previously discovered construction,
            # trimmed or padded to length n
            base = np.array(height_sequence_1, dtype=float)
            if len(base) > n:
                a = base[:n]
            else:
                a = np.concatenate([base, np.zeros(n - len(base))])
        else:
            # random Dirichlet initialisation
            a = np.random.rand(n)
            a = a / np.sum(a) * target_sum

        # keep the best sequence seen inside this restart
        local_best_seq = a.copy()
        local_best_score = float("inf")

        # constant target for the convolution (its average)
        C_const = target_sum ** 2 / (2 * n - 1)   # = average of a*a

        # ------------------------------------------------------------------
        # iterative optimisation
        it = 0
        while time.time() < deadline and it < max_iters_per_restart:
            it += 1

            # current convolution and its supremum
            conv = np.convolve(a, a)
            cur_max = conv.max()
            cur_score = float(cur_max)   # because sum(a)=target_sum gives eval=cur_max

            # store globally best
            if cur_score < best_score:
                best_score = cur_score
                best_seq = a.copy()
                # useful progress output
                print(f"[{time.time():.1f}] New global best: {best_score:.6f} "
                      f"(n={n}, iter={it}, restart={restart})")

            # store locally best as well (for occasional re‑initialisation)
            if cur_score < local_best_score:
                local_best_score = cur_score
                local_best_seq = a.copy()

            # stop early if we have reached the target bound
            if best_score <= 1.503:
                break

            # ---------- gradient of ½‖conv‑C‖² ----------
            residual = conv - C_const
            a_rev = a[::-1]
            # convolution of residual with reversed a gives the needed sums
            grad_full = np.convolve(residual, a_rev)
            # take the segment that corresponds to gradient entries
            grad = 4.0 * grad_full[n - 1 : n - 1 + n]

            # if gradient is (almost) zero we are at a flat solution
            grad_norm = np.linalg.norm(grad)
            if grad_norm < 1e-12:
                break

            # ---------- back‑tracking line search ----------
            # initial step proportional to the surplus over the target
            surplus = cur_max - C_const
            eta = 0.5 * surplus / (grad_norm + 1e-12)   # heuristic
            # make sure eta is not ridiculously large
            eta = min(eta, target_sum)  

            improved = False
            for _ in range(12):
                a_candidate = a - eta * grad
                # enforce non‑negativity and the sum constraint
                a_candidate = np.maximum(a_candidate, 0.0)
                a_candidate = _project_to_simplex(a_candidate, target_sum)

                # evaluate the candidate
                conv_cand = np.convolve(a_candidate, a_candidate)
                max_cand = conv_cand.max()
                if max_cand < cur_max - 1e-12:
                    a = a_candidate
                    improved = True
                    break
                eta *= 0.5  # shrink step

            if not improved:
                # small random perturbation to escape a possible flat plateau
                a += 0.01 * np.random.randn(n)
                a = np.maximum(a, 0.0)
                a = _project_to_simplex(a, target_sum)

        # end of one restart
        restart += 1
        # optional early exit if we already hit the target
        if best_score <= 1.503:
            break

    # ----------------------------------------------------------------------
    # Return the best sequence found (as a plain Python list)
    if best_seq is None:
        # fallback: a simple uniform sequence (never happens in practice)
        n = 200
        best_seq = np.full(n, math.sqrt(2.0 * n) / n)
    # Ensure we obey the limits imposed by evaluate_sequence
    best_seq = [float(max(0.0, min(1000.0, x))) for x in best_seq]
    return best_seq
