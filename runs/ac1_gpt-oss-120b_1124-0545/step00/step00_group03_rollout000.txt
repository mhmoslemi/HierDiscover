The evaluation metric is

    2 * n * max(conv(f, f)) / (sum(f))**2

For a non‑negative vector `f` the convolution at offset zero equals
∑ f_i², which is always at least (∑ f_i)² / n by Cauchy–Schwarz.
Consequently the metric is bounded below by 2, with equality **iff**
all entries are identical.  Hence the provably optimal sequence is a
uniform (constant) one.

This function therefore builds a constant sequence of the same length as
