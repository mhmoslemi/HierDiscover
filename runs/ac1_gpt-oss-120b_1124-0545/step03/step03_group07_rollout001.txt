"""
propose_candidate

A two‑phase optimizer for the evaluation function
    2·n·max(a∗a) / (∑a)² .

Phase 1 – mirror (exponentiated) descent on a smooth approximation of the
max‑convolution.  The smooth max is the log‑sum‑exp of the convolution
entries with a temperature α that is increased from a small to a large
value, so that early iterations move the mass away from many large
convolution entries while later iterations focus on the true maximum.
Each iteration updates the coefficients by a multiplicative step
a_i ← a_i·exp(−η·g_i) where g is the gradient of the smooth max.
A projection onto the ℓ₁‑simplex (∑a = √(2·n), a_i ≥ 0) is performed
by simple renormalisation.

Phase 2 – classic simulated annealing starting from the best vector
found in Phase 1.  Random transfers of a small fraction of the mass are
proposed; downhill moves are always accepted, uphill moves are accepted
with probability exp(−Δ/T) where T is exponentially cooled.
Both phases respect the global time budget (≈ 1000 s) and keep the
overall best sequence seen.

The optimizer uses only NumPy and the provided `evaluate_sequence`
function; no file‑system or network access is performed.
"""

import time
import math
import random
import numpy as np

# ----------------------------------------------------------------------
def _max_convolution(a: np.ndarray, fft_len: int) -> tuple[float, int]:
    """
    Return (max_convolution_value, argmax_index) for the self‑convolution
    ``a*a`` using an FFT of length ``fft_len`` (must be a power of two ≥ 2·n‑1).
    """
    fa = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fa * fa, n=fft_len)[: 2 * a.size - 1]
    idx = int(np.argmax(conv))
    val = float(conv[idx])
    return val, idx

    and returns the best sequence found as a plain Python list.

    else:

    n = max(base.size, 3000)                     # 3000 is a safe default
    if base.size < n:

    else:

    # the final score, but keeps the objective exactly equal to max(conv)).
    target_sum = math.sqrt(2.0 * n)
    a = a / a.sum() * target_sum

    # ------------------------------------------------------------------
    # Pre‑compute FFT lengths.
    #   * For the self‑convolution we need length ≥ 2·n‑1.

**Explanation of the improvements**

* **Smoothed‑max gradient** – By replacing the hard max with a log‑sum‑exp we obtain a differentiable objective that simultaneously reduces all large convolution entries, not only the single active one used in the plain sub‑gradient method.  
* **Exponentiated (mirror) updates** – Multiplicative updates keep the variables non‑negative by construction and work naturally with the ℓ₁‑simplex projection (simple renormalisation).  
* **Adaptive schedules** – Both the smoothing parameter α and the step‑size η are increased/decreased linearly with the iteration count, allowing a coarse global movement early on and a fine local refinement later.  
* **Hybridisation with SA** – After the mirror‑descent phase we run a standard simulated‑annealing refinement (as in the reference code) but start from a much higher‑quality point, leading to a lower final bound.  
* **Stagnation handling** – Random restarts and occasional tiny perturbations prevent the search from getting trapped in poor local minima.

The algorithm respects the 1000‑second budget, makes extensive use of fast FFT‑based convolutions, and is fully self‑contained (no file or network I/O). It should beat the previous best bound of 1.520888 and aim for the target 1.503.
