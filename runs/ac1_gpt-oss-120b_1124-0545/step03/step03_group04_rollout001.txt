The goal is to minimise  

\[
F(a)=\frac{2\,n\,\max (a*a)}{\bigl(\sum a_i\bigr)^2}
\]

for a non‑negative step‑function \(a\) (here we keep the normalisation
\(\sum a_i = 1\) – then \(F(a)=2n\max(a*a)\)).  
The function is highly non‑smooth because of the `max`.  
The previous implementation used a smoothed soft‑max and a plain projected
gradient descent with a learning‑rate that decayed to zero very fast,
which caused early stagnation.

**Key ideas**

1. **Simplex parametrisation** – we write
   \[
   a_i=\frac{e^{x_i}}{\sum_j e^{x_j}}\;(x\in\mathbb R^n)
   \]
   so the positivity and the sum‑constraint are satisfied automatically.
2. **Soft‑max surrogate for the maximum** – for a temperature
   \(\varepsilon\) we minimise  

   \[
   \phi_\varepsilon(x)=\varepsilon\,
   \log\Bigl(\sum_{k}e^{\frac{(a*a)_k}{\varepsilon}}\Bigr)
   \]

   whose gradient is a smooth weighted sum of the usual
   \(\nabla (a*a)_k\).  The weight vector is the soft‑max of the
   convolution entries.  By slowly decreasing \(\varepsilon\) we
   approach the true maximum.
3. **Natural‑gradient (exponentiated gradient)** – the gradient in the
   `x`‑space is  

   \[
   \nabla_x \phi = a\odot\bigl(\,\nabla_a\phi -
   \langle a,\nabla_a\phi\rangle\bigr).
   \]

   Updating `x` with this gradient automatically stays on the simplex.
4. **Adam optimiser** – an adaptive step‑size (Adam) is used on the
   `x`‑variables.  Unlike the previous code the learning‑rate does **not**
   collapse to zero, allowing continued progress throughout the whole
   time budget.
5. **Time‑controlled loop** – the algorithm runs until the allotted
   time (default 1000 s) is exhausted, keeping the best sequence seen.
6. **Final local refinement** – after the Adam phase a cheap
   random‑swap hill‑climber is applied for the last few seconds to
   squeeze out any remaining improvement.

All heavy work (convolutions) is performed with an FFT‑based routine,
so each iteration costs only \(O(n\log n)\) with \(n\approx 5000\).

The code below follows this plan, complies with the required interface
and contains only top‑level definitions (no closures).  It should be
able to push the bound below the target 1.503.

        • build a soft‑max over the convolution entries with a slowly
          decreasing temperature ε (≈σ·max_conv)
        • obtain the smoothed gradient w.r.t. a (v + a) and pull it back
          to the x‑space via the KL‑natural gradient
        • update x with Adam (adaptive moments) – no manual learning‑rate decay
        • keep the best sequence seen so far
  4. In the last few seconds perform a cheap random‑swap hill‑climber to
     polish the result.
The routine respects a 1000 s budget, prints progress and finally returns
the best list of floats.
"""

import time
import math
import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    size = x.size + y.size - 1
    N = 1 << ((size - 1).bit_length())       # next power of two
    X = np.fft.rfft(x, n=N)
    Y = np.fft.rfft(y, n=N)
    Z = X * Y
    conv = np.fft.irfft(Z, n=N)[:size]
    return conv


def _softmax(v: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (returns a probability vector)."""
    vmax = np.max(v)
    e = np.exp(v - vmax)
    s = e.sum()
    if s == 0.0:
        # fallback to uniform distribution
        return np.full_like(v, 1.0 / v.shape[0])
    return e / s


def _softmax_x(x: np.ndarray) -> np.ndarray:
    """Soft‑max of the raw parameters x (produces a vector that sums to 1)."""
    # subtract max to avoid overflow
    x_shift = x - np.max(x)
    e = np.exp(x_shift)
    s = e.sum()
    if s == 0.0:
        return np.full_like(x, 1.0 / x.shape[0])
    return e / s


def _initial_sequence(n: int) -> np.ndarray:
    """
    Return a normalised power‑law start a_i ∝ (i+1)^(-0.5).
    Guarantees a_i ≥ 0 and sum(a)=1.
    """
    idx = np.arange(1, n + 1, dtype=float)
    a = idx ** (-0.5)
    a_sum = a.sum()
    if a_sum == 0.0:
        a[:] = 1.0 / n
    else:
        a /= a_sum
    return a


# ----------------------------------------------------------------------
# Adam optimiser (plain implementation, no closures)
# ----------------------------------------------------------------------


class _AdamState:
    """Container for Adam moment estimates."""
    def __init__(self, dim: int, beta1: float = 0.9, beta2: float = 0.999):
        self.m = np.zeros(dim, dtype=np.float64)
        self.v = np.zeros(dim, dtype=np.float64)
        self.t = 0
        self.beta1 = beta1
        self.beta2 = beta2

    def update(self, grad: np.ndarray, lr: float, eps: float = 1e-8) -> np.ndarray:
        """Perform one Adam step and return the new parameters."""
        self.t += 1
        self.m = self.beta1 * self.m + (1.0 - self.beta1) * grad
        self.v = self.beta2 * self.v + (1.0 - self.beta2) * (grad * grad)

        m_hat = self.m / (1.0 - self.beta1 ** self.t)
        v_hat = self.v / (1.0 - self.beta2 ** self.t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        return step


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> List[float]:
    """
    Search for a step‑function (non‑negative sequence) minimising
    ``evaluate_sequence``.  The routine respects a time budget
    (default 1000 s) and returns the best sequence discovered.
    """
    # ------------------------------------------------------------------
    # 0. Global preparation
    # ------------------------------------------------------------------
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0               # keep a margin

    # ------------------------------------------------------------------
    # 1. Initialise the probability vector a (sum = 1)
    # ------------------------------------------------------------------
    try:
        # ``height_sequence_1`` may be provided by the harness
        init = np.array(height_sequence_1, dtype=np.float64)   # type: ignore[name-defined]
        n = init.size
        a = np.maximum(init, 0.0)
        total = a.sum()
        if total > 0.0:
            a /= total
        else:
            raise ValueError
    except Exception:
        # fallback: power‑law with exponent 0.5, length 5000
        n = 5000
        a = _initial_sequence(n)

    # Ensure strict positivity for the log‑parameterisation
    eps_init = 1e-12
    a = np.maximum(a, eps_init)
    a /= a.sum()

    # ------------------------------------------------------------------
    # 2. Parameterisation a = softmax(x)  (x ∈ ℝⁿ)
    # ------------------------------------------------------------------
    x = np.log(a)                     # a_i = exp(x_i) / Σexp(x)
    # Adam state
    adam = _AdamState(dim=n, beta1=0.9, beta2=0.999)

    # Temperature schedule for the soft‑max over the convolution
    sigma_start = 0.5
    sigma_end = 0.02

    # Adam learning‑rate (fixed; Adam handles decay automatically)
    lr_adam = 0.02

    # ------------------------------------------------------------------
    # 3. Main optimisation loop (soft‑max surrogate + Adam)
    # ------------------------------------------------------------------
    best_a = a.copy()
    conv = _conv_fft(a, a)
    best_score = 2.0 * n * conv.max()
    best_iter = 0

    iteration = 0
    print(f"[init] n={n}, start_score={best_score:.6f}")

    while time.time() < deadline:
        iteration += 1

        # ---- a from current x (soft‑max) ----
        a = _softmax_x(x)

        # ---- self‑convolution and raw maximum ----
        conv = _conv_fft(a, a)
        max_conv = conv.max()
        cur_score = 2.0 * n * max_conv

        # keep the best exact score
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            best_iter = iteration
            print(f"[improve] iter={iteration}, score={best_score:.6f}")

        # ---- temperature (σ) decreasing linearly in log‑space ----
        elapsed = time.time() - start_time
        frac = min(elapsed / (budget_s - 5.0), 1.0)
        sigma = sigma_start * ((sigma_end / sigma_start) ** frac)

        eps_temp = max(sigma * max_conv, 1e-12)

        # ---- soft‑max weights over the convolution entries ----
        # (use a safe clipping to avoid overflow)
        expo = conv / eps_temp
        expo = np.clip(expo, a_min=None, a_max=50.0)     #  e⁵⁰ ≈ 5·10²¹  – safe
        w = np.exp(expo)
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # ---- compute v = Σ_i w_{i+j} a_i  (via convolution) ----
        w_rev = w[::-1]                                   # reversed weight vector
        v_full = _conv_fft(a, w_rev)                      # length = 3n‑2
        idx = (2 * n - 2) - np.arange(n)                  # slice giving v_j
        v = v_full[idx]

        # ---- gradient of the smoothed objective w.r.t. a ----
        # (the derivative of eps*log Σ e^{conv/eps} )
        grad_a = v + a

        # ---- pull‑back to x‑space (natural gradient on simplex) ----
        dot = np.dot(a, grad_a)
        grad_x = a * (grad_a - dot)

        # ---- Adam update on x ----
        step = adam.update(grad_x, lr=lr_adam)
        x -= step

        # ---- keep numbers in a reasonable range (soft‑max invariance) ----
        # Subtract the max to avoid overflow/underflow in exp().
        x -= np.max(x)

        # (optional) occasional random jitter to escape plateaus
        if iteration % 5000 == 0:
            jitter = np.random.randn(n) * 1e-4
            x += jitter

    print(f"[phase‑1 done] best_score={best_score:.6f} after {iteration} iters "
          f"(last improvement at iter {best_iter})")

    # ------------------------------------------------------------------
    # 4. Final local refinement (random mass swaps)
    # ------------------------------------------------------------------
    # Use the remaining time (≈5 s) for a cheap hill‑climber.
    refinement_deadline = start_time + budget_s - 0.5
    cur_a = best_a.copy()
    cur_score = best_score

    while time.time() < refinement_deadline:
        # pick two distinct indices
        i, j = np.random.choice(n, 2, replace=False)
        # move a small random fraction of mass from i to j
        delta = min(cur_a[i] * 0.3, cur_a[i] * np.random.rand() * 0.1)
        if delta <= 0.0:
            continue
        cur_a[i] -= delta
        cur_a[j] += delta

        # evaluate
        conv = _conv_fft(cur_a, cur_a)
        new_score = 2.0 * n * conv.max()
        if new_score < cur_score:
            cur_score = new_score
            if new_score < best_score:
                best_score = new_score
                best_a = cur_a.copy()
                print(f"[refine] score={best_score:.6f}")

    print(f"[final] best_score={best_score:.6f}, total_iterations={iteration}")

    # Return a plain Python list – evaluate_sequence will post‑process it.
    return best_a.tolist()
