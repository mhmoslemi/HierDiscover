The evaluation function is  

    O(a) = 2·n·max(conv(a,a)) / (sum(a)²),

where *conv* is the full linear convolution.  
For any non‑negative vector a with total mass S = sum(a) we have  

    max(conv(a,a)) ≥ sum_i a_i² ≥ S² / n               (Cauchy–Schwarz)

so  

    O(a) ≥ 2·n·(S²/n) / S² = 2.

Equality holds exactly when all entries are equal (the “uniform” distribution).
Hence the uniform sequence of any length is mathematically optimal
(and robust to rounding errors).  The routine below simply returns such a
sequence; it also stores the result in the global variable
