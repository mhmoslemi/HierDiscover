assistantfinal**Solution Overview**

The program searches for a non‑negative step function `a = (a₀,…,aₙ₋₁)` that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `*` denotes the linear (full) convolution.  
Because the score is invariant under a global scaling we can restrict the
search to probability vectors (`∑a_i = 1`).  Then  

\[
\text{score}=2\,n\;\max_k (a*a)_k .
\]

The optimisation problem is non‑convex, but its structure admits fast
first‑order methods:

*   **Mirror‑descent (exponentiated‑gradient)** on the exact max‑convolution.
    The iterate lives in the log‑softmax space, guaranteeing feasibility
    (`a_i≥0`, `∑a_i=1`).  
    The sub‑gradient of the active convolution entry `k` is  
    \[
    g_i =\begin{cases}
          2\,a_{k-i} &\text{if }0\le i\le n-1,\;0\le k-i\le n-1\\[2pt]
          0          &\text{otherwise}.
          \end{cases}
    \]

*   **Smooth‑max L‑BFGS‑B** – a continuation method that replaces the hard max
    by a log‑sum‑exp with an increasing temperature `β`.  The objective
    becomes smooth and L‑BFGS‑B converges quickly.  The gradient is obtained
    analytically (see the code).

*   **Global random restarts** – a pool of cheap initialisations
    (uniform, Dirichlet draws with many concentrations, monotone ramps,
    tiny perturbations of the current best).  
    Each seed is polished by the mirror‑descent optimiser; the best result
    is kept.

The whole search respects the 1000 s time budget, aborting cleanly when the
deadline is reached.  The final sequence is stored in the global variable
`height_sequence_1` and also returned as a plain Python list.

```python
"""
Propose a step‑function that improves the current best bound.
Algorithm
---------

1. Gather a diverse seed pool (uniform, previous best, monotone ramps,
   Dirichlet draws, tiny perturbations).

2. For every seed run a long mirror‑descent (exponentiated‑gradient)
   optimisation on the exact max‑convolution objective.
   The iterates stay on the probability simplex via the soft‑max
   re‑parameterisation.

3. Keep the best sequence seen so far.

4. Refine the best sequence with a continuation L‑BFGS‑B optimiser that
   minimises a smoothed version of the max (log‑sum‑exp with an
   annealing schedule for the smoothing parameter β).

5. Evaluate the final candidate with the provided ``evaluate_sequence``.
   Store it in the global variable ``height_sequence_1`` and return it.

All stages stop as soon as the global deadline (1000 s – small safety margin)
is reached.
"""

import time
import math
import numpy as np

# optional SciPy for the final L‑BFGS‑B pass
try:
    import scipy.optimize as _opt
except Exception:   # pragma: no cover
    _opt = None


# ----------------------------------------------------------------------
# Numerical utilities
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution via real FFT (O(n log n))."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    c = np.fft.irfft(fx * fy, n=N)[:L]
    return c


def _softmax(v: np.ndarray) -> np.ndarray:
    """Numerically stable softmax – yields a probability vector."""
    m = np.max(v)
    e = np.exp(v - m)
    s = e.sum()
    if s == 0.0:
        return np.full_like(v, 1.0 / len(v))
    return e / s


# ----------------------------------------------------------------------
# Objective (exact for ℓ₁‑normalised vectors)
# ----------------------------------------------------------------------
def _objective_surrogate(a: np.ndarray) -> float:
    """2·n·max(conv(a,a)), assuming ∑a = 1."""
    n = a.shape[0]
    conv = _conv_fft(a, a)
    return float(2.0 * n * np.max(conv))


# ----------------------------------------------------------------------
# Seed generators (all return ℓ₁‑normalised vectors)
# ----------------------------------------------------------------------
def _uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)


def _random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Draw from Dirichlet(conc,…,conc) and normalise (already normalised)."""
    return rng.dirichlet(np.full(n, conc)).astype(np.float64)


def _perturb(a: np.ndarray, rng: np.random.Generator, sigma: float = 0.002) -> np.ndarray:
    """Add Gaussian noise, clip to ≥0 and renormalise."""
    noisy = a + sigma * rng.normal(size=a.shape)
    noisy = np.maximum(noisy, 0.0)
    s = noisy.sum()
    if s <= 0.0:
        return a.copy()
    return noisy / s


def _monotone_ramp(n: int, increasing: bool = True) -> np.ndarray:
    """Linear ramp, normalised."""
    if increasing:
        w = np.arange(1, n + 1, dtype=np.float64)
    else:
        w = np.arange(n, 0, -1, dtype=np.float64)
    return w / w.sum()


# ----------------------------------------------------------------------
# Mirror‑descent (exponentiated‑gradient) optimiser on the true max
# ----------------------------------------------------------------------
def _exp_gradient_opt(start_seq: np.ndarray,
                     deadline: float,
                     max_iters: int = 2_000_000,
                     eta0: float = 8.0) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent on the exact max‑convolution objective.
    Operates in the log‑softmax space; the returned pair is (best_seq, best_val).
    """
    n = start_seq.shape[0]
    a = start_seq.copy()
    log_a = np.log(a + 1e-30)                     # keep away from log(0)
    best_seq = a.copy()
    best_val = _objective_surrogate(a)

    for it in range(1, max_iters + 1):
        # time check
        if time.time() > deadline:
            break

        conv = _conv_fft(a, a)
        k = int(np.argmax(conv))                 # active index (hard max)

        # sub‑gradient of the active entry
        g = np.zeros_like(a)
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        idx = np.arange(i_start, i_end + 1, dtype=int)
        rev = k - idx
        g[idx] = 2.0 * a[rev]

        # step‑size schedule η_t = η₀ / √t
        eta = eta0 / math.sqrt(it)
        log_a = log_a - eta * g
        a = _softmax(log_a)

        cur_val = _objective_surrogate(a)
        if cur_val < best_val:
            best_val = cur_val
            best_seq = a.copy()

        # occasional tiny random jitter to avoid stagnation
        if it % 20000 == 0:
            jitter = np.log(np.maximum(a, 1e-12)) + 1e-5 * np.random.randn(n)
            log_a = jitter
            a = _softmax(log_a)

    return best_seq, best_val


# ----------------------------------------------------------------------
# Continuation L‑BFGS optimiser (smooth max via log‑sum‑exp)
# ----------------------------------------------------------------------
def _lbfgs_smooth_optimize(start_vec: np.ndarray,
                           deadline: float,
                           beta_schedule=None,
                           max_iter_per_beta: int = 8000) -> np.ndarray:
    """
    L‑BFGS‑B optimisation of a smooth approximation of the max‑convolution.
    The variables are the log‑softmax parameters.
    """
    if _opt is None:
        # SciPy missing – fall back to the input unchanged.
        return start_vec

    if beta_schedule is None:
        beta_schedule = [1.0, 5.0, 20.0, 80.0, 200.0, 500.0, 1000.0,
                         2000.0, 5000.0, 20000.0, 50000.0, 100000.0,
                         200000.0, 500000.0, 1000000.0]

    n = start_vec.shape[0]
    v = np.log(start_vec + 1e-30)     # initialise log‑softmax variables

    for beta in beta_schedule:
        if time.time() > deadline:
            break
        beta_f = float(beta)

        def fun(v_local):
            a = _softmax(v_local)
            conv = _conv_fft(a, a)
            m = np.max(conv)
            # smooth max via log‑sum‑exp
            exp_beta = np.exp(beta_f * (conv - m))
            sum_exp = exp_beta.sum()
            obj = 2.0 * n * (m + np.log(sum_exp) / beta_f)

            # gradient w.r.t a (derivative of smooth max)
            w = exp_beta / sum_exp                       # weights
            rev_a = a[::-1]
            full = _conv_fft(rev_a, w)                  # length 3n‑2
            grad_a = 2.0 * full[n - 1:n - 1 + n]

            # chain rule through softmax
            dot = np.dot(grad_a, a)
            grad_v = a * (grad_a - dot)
            return obj, grad_v

        def callback(_):
            # abort if out of time
            if time.time() > deadline:
                raise KeyboardInterrupt()

        try:
            res = _opt.minimize(fun=fun,
                                x0=v,
                                method='L-BFGS-B',
                                jac=True,
                                callback=callback,
                                options={'maxiter': max_iter_per_beta,
                                         'disp': False,
                                         'ftol': 1e-12})
            v = res.x
        except KeyboardInterrupt:
            break
        except Exception as e:  # pragma: no cover
            print(f"[L‑BFGS] exception {e} at β={beta_f}")
            break

    return _softmax(v)

    if best_seq is not None and time.time() < deadline:
        print("\n--- L‑BFGS refinement (smooth max) ---")
        sub_deadline = deadline - 2.0                # a tiny safety margin
        seq_lbfgs = _lbfgs_smooth_optimize(best_seq,
                                           sub_deadline,
                                           beta_schedule=[1.0, 5.0, 20.0, 80.0,
                                                          200.0, 500.0, 1000.0,
                                                          2000.0, 5000.0,
                                                          20000.0, 50000.0,
                                                          100000.0, 200000.0,
                                                          500000.0, 1000000.0],
                                           max_iter_per_beta=10000)
        val_lbfgs = _objective_surrogate(seq_lbfgs)
        print(f"[L‑BFGS] surrogate = {val_lbfgs:.6f}")
        if val_lbfgs < best_val:
            best_val = val_lbfgs
            best_seq = seq_lbfgs.copy()
            print(f"  >>> Updated global best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # 3️⃣  Final evaluation with the official checker
    # ------------------------------------------------------------------
    true_val = None
    try:
        true_val = evaluate_sequence(best_seq.tolist())
        print(f"\n=== Finished ===\nSurrogate ≈ {best_val:.6f}, evaluate_sequence = {true_val:.6f}")
    except Exception as exc:  # pragma: no cover
        print("Warning: evaluate_sequence raised an exception:", exc)

    # store for the next invocation
    globals()["height_sequence_1"] = best_seq.tolist()
    return best_seq.tolist()
```
