```python
    L = len(x) + len(y) - 1
```

The optimiser builds a diverse pool of analytic “seed” step‑functions (uniform,
triangular, power‑law / arcsine, Beta‑densities and Dirichlet draws).  
All seeds are normalised to a probability vector, their surrogate objective  

```
F(a) = 2·n·max(conv(a,a))                (   ∑a = 1   )
```

is evaluated cheaply with an FFT based convolution and the best few seeds are
kept.

A cheap *mixing* step explores convex combinations of the top seeds – the
objective is linear in the mixing coefficients, so a simple grid search over
λ∈[0,1] already discovers better shapes that are not contained in the original
family.

Starting from the best mixed candidate we run two refinement phases:

1. **Adam on a smooth‐max surrogate** – a log‑sum‑exp approximation of the
   max‑convolution, with a schedule of smoothness parameters.  This gives a
   quick first improvement while staying in the simplex.

2. **Exponentiated‑gradient (mirror descent) on the true max** – we use a
   sub‑gradient that averages the gradients of all *active* convolution indices
   (those within a tiny tolerance of the current maximum).  The update is performed
   in the log‑space (`a = softmax(log_a)`) which automatically respects the
   simplex constraints.

Finally a short **simulated‑annealing walk** makes stochastic “polish” moves.

The whole search respects the 1000 s budget, stores the best sequence in the
global variable `height_sequence_1` and returns it as a plain list of floats.

```python
"""
Search for a non‑negative step function that minimises ``evaluate_sequence``.

The optimiser consists of the following stages (all respect a total 1000 s budget)

0️⃣  Build a large pool of analytic seeds (uniform, triangular, power‑law /
    arcsine, Beta‑densities, Dirichlet draws).  Very fine sweeps over the
    arcsine exponent *p* and over a few (α,β) pairs are performed.

1️⃣  Evaluate every seed with the cheap surrogate 2·n·max(conv(a,a)) and keep
    the best few (default 10).

2️⃣  **Mixing** – try convex combinations λ·a_i+(1‑λ)·a_j of the top seeds,
    λ ∈ {0,0.05,…,1}.  The best mixture is taken as the new global best.

3️⃣  **Adam smoothing** – minimise a log‑sum‑exp smooth approximation of the
    max‑convolution, gradually increasing the smoothness parameter β.
    The update is done in the log‑simplex (mirror) space.

4️⃣  **Exact exponentiated‑gradient polishing** – sub‑gradient descent on the
    true max‑convolution.  All indices whose convolution value is within a tiny
    tolerance of the maximum form the active set; their gradients are averaged
    to obtain a robust direction.

5️⃣  **Final annealing walk** – cheap stochastic moves (transfer a small
    fraction of mass i→j) with a linear cooling schedule, accepting moves
    according to the Metropolis rule.

The best sequence found is stored globally as ``height_sequence_1``
and returned as ``list[float]``.
"""

import time

# Low‑level utilities

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full linear convolution using real FFT (O(N log N))."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.irfft(fx * fy, n=N)[:L]
    return conv


def _softmax(v: np.ndarray) -> np.ndarray:
    """Softmax that returns a probability vector (numerically stable)."""
    m = np.max(v)
    e = np.exp(v - m)
    s = e.sum()
    if s == 0.0:
        return np.full_like(v, 1.0 / v.size)
    return e / s


def _objective_surrogate(seq: np.ndarray) -> float:
    """
    Exact surrogate used throughout the optimiser.
    The input is assumed to sum to 1.
    """
    n = len(seq)
    conv = _conv_fft(seq, seq)
    return float(2.0 * n * np.max(conv))

# Analytic seed families
# ----------------------------------------------------------------------


def _uniform(n: int) -> np.ndarray:
    """Uniform distribution on n points."""
    return np.full(n, 1.0 / n, dtype=np.float64)


def _triangular(n: int) -> np.ndarray:
    """Symmetric triangular shape (peak in the middle)."""
    half = n // 2
    if n % 2 == 0:
        left = np.arange(1, half + 1, dtype=np.float64)
        right = left[::-1]
    else:
        left = np.arange(1, half + 2, dtype=np.float64)
        right = left[:-1][::-1]
    a = np.concatenate([left, right])
    a /= a.sum()
    return a


def _power_arcsine(n: int, p: float) -> np.ndarray:
    """
    Generalised arcsine family:
        a_i ∝ ((i+½)(n‑½‑i))^{-p}
    p = 0.5 gives the classic arcsine density.
    """
    i = np.arange(n, dtype=np.float64)
    denom = (i + 0.5) * (n - 0.5 - i)
    a = np.power(denom + 1e-12, -p)
    a /= a.sum()
    return a


def _beta_asymmetric(n: int, alpha: float, beta: float) -> np.ndarray:
    """
    Discrete Beta(α,β) density on {0,…,n‑1}.
    """
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    eps = 1e-12
    a = np.power(x + eps, alpha - 1.0) * np.power(1.0 - x + eps, beta - 1.0)
    a /= a.sum()
    return a


def _random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Dirichlet draw with constant concentration parameter."""
    return rng.dirichlet(np.full(n, conc)).astype(np.float64)

def _adam_smoothing(start_seq: np.ndarray, deadline: float) -> tuple[np.ndarray, float]:
    """
    Adam on the smooth (log‑sum‑exp) surrogate.
    """
    n = len(start_seq)
    logit = np.log(start_seq + 1e-30)               # initialise logits
    m = np.zeros_like(logit)
    v = np.zeros_like(logit)

    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    it = 0

    # smooth‑max schedule (geometric growth)
    beta_schedule = [
        1.0, 5.0, 20.0, 80.0,
        200.0, 500.0, 1_000.0,
        2_000.0, 5_000.0,
        20_000.0, 50_000.0,
        100_000.0, 200_000.0, 500_000.0,
        1_000_000.0, 2_000_000.0, 5_000_000.0,
        10_000_000.0, 20_000_000.0,
    ]

    best_seq = start_seq.copy()
    best_val = _objective_surrogate(best_seq)

    for beta in beta_schedule:
        if time.time() > deadline:
            break
        max_iter_beta = 4000
        for _ in range(max_iter_beta):
            if time.time() > deadline:
                break

            a = _softmax(logit)                  # point on the simplex
            conv = _conv_fft(a, a)
            max_c = np.max(conv)

            # smooth‑max (log‑sum‑exp) weighting
            exp_beta = np.exp(beta * (conv - max_c))
            w = exp_beta / exp_beta.sum()

            # gradient of Σ w·conv w.r.t. a
            rev_a = a[::-1]
            full = _conv_fft(rev_a, w)           # length = n + (2n‑1) – 1
            grad_weighted = 2.0 * full[n - 1:n - 1 + n]
            grad_a = grad_weighted * (2.0 * n)    # outer factor 2·n

            # convert to gradient in log‑space (mirror)
            dot = np.dot(grad_a, a)
            grad_log = a * (grad_a - dot)

            # Adam update
            it += 1
            m = beta1 * m + (1.0 - beta1) * grad_log
            v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)

            m_hat = m / (1.0 - beta1 ** it)
            v_hat = v / (1.0 - beta2 ** it)

            lr = 0.12
            logit = logit - lr * m_hat / (np.sqrt(v_hat) + eps)

            # periodic exact evaluation
            if it % 500 == 0:
                cur_val = _objective_surrogate(a)
                if cur_val < best_val:
                    best_val = cur_val
                    best_seq = a.copy()

    final_a = _softmax(logit)
    final_val = _objective_surrogate(final_a)
    if final_val < best_val:
        best_seq, best_val = final_a, final_val

    return best_seq, best_val


def _exp_multi_gradient_opt(start_seq: np.ndarray,
                            deadline: float,
                            eta0: float = 5.0,
                            max_iters: int = 2_000_000,
                            tol: float = 1e-12) -> tuple[np.ndarray, float]:
    """
    Exponentiated‑gradient (mirror descent) on the **exact** max‑convolution.
    The sub‑gradient averages over all *active* indices (those whose value is
    within ``tol`` of the current maximum).
    """
    n = len(start_seq)
    a = start_seq.copy()
    log_a = np.log(a + 1e-30)

    best_seq = a.copy()
    best_val = _objective_surrogate(a)

    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1
        conv = _conv_fft(a, a)
        max_c = np.max(conv)

        # active set (indices with value close to the max)
        active_mask = (conv >= max_c - tol).astype(np.float64)
        if active_mask.sum() == 0:
            active_mask = np.array([1.0], dtype=np.float64)   # fallback
        w = active_mask / active_mask.sum()

        rev_a = a[::-1]
        full = _conv_fft(rev_a, w)          # length = n + (2n‑1) – 1
        grad = 2.0 * full[n - 1:n - 1 + n]   # sub‑gradient of max(conv)

        eta = eta0 / math.sqrt(it)
        log_a = log_a - eta * grad
        a = _softmax(log_a)

        if it % 3000 == 0:
            cur_val = _objective_surrogate(a)
            if cur_val < best_val:
                best_val = cur_val
                best_seq = a.copy()

    final_val = _objective_surrogate(a)
    if final_val < best_val:
        best_seq, best_val = a, final_val

    return best_seq, best_val


def _anneal_opt(start_seq: np.ndarray,
                deadline: float,
                init_temp: float = 0.02,
                final_temp: float = 1e-7,
                sigma: float = 0.015) -> tuple[np.ndarray, float]:
    """
    Tiny simulated‑annealing walk on the simplex.
    A random fraction of mass is transferred from i → j.
    """
    n = len(start_seq)
    a = start_seq.copy()
    cur_val = _objective_surrogate(a)
    best_seq = a.copy()
    best_val = cur_val
    rng = np.random.default_rng()

    start_time = time.time()
    while time.time() < deadline:
        elapsed = time.time() - start_time
        total = deadline - start_time
        temp = init_temp * (1.0 - elapsed / total)
        temp = max(final_temp, temp)

        i, j = rng.integers(0, n, size=2)
        if i == j or a[i] <= 0.0:
            continue
        delta = sigma * a[i] * rng.random()
        if delta <= 0.0:
            continue
        new_a = a.copy()
        new_a[i] -= delta
        new_a[j] += delta
        if new_a[i] < 0.0:
            continue
        new_val = _objective_surrogate(new_a)
        accept = False
        if new_val < cur_val:
            accept = True
        else:
            prob = math.exp(-(new_val - cur_val) / temp)
            if rng.random() < prob:
                accept = True
        if accept:
            a = new_a
            cur_val = new_val
            if cur_val < best_val:
                best_val = cur_val
                best_seq = a.copy()

    return best_seq, best_val

        remaining = deadline - time.time()
        adam_deadline = time.time() + 0.10 * remaining   # ≈ 10 % of the rest
        print("\n--- Adam smoothing (smooth max) ---")
        seq_adam, val_adam = _adam_smoothing(best_seq, adam_deadline)
        print(f"[Adam] surrogate = {val_adam:.6f}")
        if val_adam < best_val:
            best_seq, best_val = seq_adam, val_adam
            print("   >>> Updated global best after Adam")

    # ------------------------------------------------------------------
    # 4️⃣ Exact exponentiated‑gradient polishing (multi‑active set)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        eg_deadline = deadline - 4.0                     # keep seconds for final walk
        print("\n--- Exponentiated‑gradient polishing (exact max) ---")
        seq_eg, val_eg = _exp_multi_gradient_opt(best_seq, eg_deadline,
                                                 eta0=5.0,
                                                 max_iters=2_000_000)
        print(f"[EG] surrogate = {val_eg:.6f}")
        if val_eg < best_val:
            best_seq, best_val = seq_eg, val_eg
            print("   >>> Updated global best after EG")

    # ------------------------------------------------------------------
    # 5️⃣ Final tiny annealing walk
    # ------------------------------------------------------------------
    if time.time() < deadline:
        print("\n--- Final annealing walk ---")
        seq_loc, val_loc = _anneal_opt(best_seq, deadline,
                                       init_temp=0.02,
                                       final_temp=1e-7,
                                       sigma=0.015)
        print(f"[Anneal] surrogate = {val_loc:.6f}")
        if val_loc < best_val:
            best_seq, best_val = seq_loc, val_loc
            print("   >>> Updated global best after annealing")

    # ------------------------------------------------------------------
    # 6️⃣ Official evaluation with the supplied ``evaluate_sequence``
    # ------------------------------------------------------------------
    true_val = None
    try:
        true_val = evaluate_sequence(best_seq.tolist())
        print(f"\n=== Finished ===\nSurrogate ≈ {best_val:.6f}, "
              f"evaluate_sequence = {true_val:.6f}")
    except Exception as exc:  # pragma: no cover
        print("Warning: evaluate_sequence raised an exception:", exc)

    # Store for next invocation
    globals()["height_sequence_1"] = best_seq.tolist()
    return best_seq.tolist()
```
