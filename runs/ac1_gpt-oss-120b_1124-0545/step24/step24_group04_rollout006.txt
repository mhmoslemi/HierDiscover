assistantfinal**Solution Overview**

The optimiser works in three stages :

1. **Rich initial pool** – many analytically‑motivated shapes (uniform,
   arcsine, triangular, symmetric & asymmetric Beta, Dirichlet draws,
   Gaussian mixtures and a few random permutations).  
   The best seed (according to the exact surrogate `2·n·max(conv)`) is
   kept.

2. **Smooth‑max Adam optimisation** – the objective is approximated by a
   smooth‑max `∑ w_k·conv_k` with a temperature that is increased
   gradually.  The variables live on the simplex via a log‑softmax
   parametrisation and are updated with Adam.  The schedule is far more
   aggressive than the reference implementation (many more inner
   iterations per temperature).

3. **Two refinement phases**  
   * **Multi‑index exponentiated‑gradient** – instead of using only the
     single maximal index, all indices that are within a tiny tolerance
     of the maximum are taken into account.  The update is a mirror‑descent
     on the log‑probabilities.  
   * **Simulated‑annealing local walk** – stochastic mass‑transfer,
     full swaps and occasional global permutations are accepted with a
     Metropolis rule.  This lets the search escape shallow local minima.

All phases respect the global deadline (`budget_s` ≈ 1000 s).  
The final sequence is stored in the global variable `height_sequence_1`
and returned as a plain Python list.

```python
"""
Non‑negative step‑function optimiser – multi‑stage approach.

1. Build a diverse seed pool (uniform, arcsine, triangular, Beta,
   asymmetric Beta, Dirichlet, Gaussian mixtures, permutations).
2. Pick the best seed (exact max‑convolution surrogate).
3. Adam optimisation with a smooth‑max surrogate; many inner iterations
   for each temperature, all updates performed in the log‑softmax space.
4. Exponentiated‑gradient descent that uses *all* near‑maximal
   convolution indices (not only the single arg‑max).
5. Simulated‑annealing stochastic local search (mass transfers,
   swaps, whole‑vector permutations) with a temperature schedule.
6. Final evaluation with the provided `evaluate_sequence` function.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution via real FFT."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.irfft(fx * fy, n=N)[:L]
    return conv


def _softmax(v: np.ndarray) -> np.ndarray:
    """Stable softmax → probability vector (sum = 1)."""
    m = np.max(v)
    e = np.exp(v - m)
    s = e.sum()
    if s == 0.0:
        return np.full_like(v, 1.0 / len(v))
    return e / s


def _surrogate(seq: np.ndarray) -> float:
    """
    Exact surrogate: 2 * n * max(conv(seq, seq)).
    `seq` must sum to 1 (probability vector).
    """
    n = len(seq)
    conv = _conv_fft(seq, seq)
    return float(2.0 * n * np.max(conv))


# ----------------------------------------------------------------------
# Seed generators (all return a normalised probability vector)
# ----------------------------------------------------------------------


def _uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)


def _arcsine(n: int) -> np.ndarray:
    i = np.arange(n, dtype=np.float64)
    eps = 1e-12
    a = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    a /= a.sum()
    return a


def _triangular(n: int) -> np.ndarray:
    half = n // 2
    if n % 2 == 0:
        left = np.arange(1, half + 1)
        right = left[::-1]
    else:
        left = np.arange(1, half + 2)
        right = left[:-1][::-1]
    a = np.concatenate([left, right]).astype(np.float64)
    a /= a.sum()
    return a


def _random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    return rng.dirichlet(np.full(n, conc)).astype(np.float64)


def _beta_symmetric(n: int, alpha: float) -> np.ndarray:
    """Symmetric Beta(α,α) on the discrete grid."""
    i = np.arange(n, dtype=np.float64) + 0.5
    x = i / n
    a = np.power(x, alpha - 1.0) * np.power(1.0 - x, alpha - 1.0)
    a = np.maximum(a, 0.0)
    total = a.sum()
    if total == 0.0:
        return _uniform(n)
    a /= total
    return a


def _beta_asymmetric(n: int, alpha: float, beta: float) -> np.ndarray:
    """Beta(α,β) – asymmetric version."""
    i = np.arange(n, dtype=np.float64) + 0.5
    x = i / n
    a = np.power(x, alpha - 1.0) * np.power(1.0 - x, beta - 1.0)
    a = np.maximum(a, 0.0)
    total = a.sum()
    if total == 0.0:
        return _uniform(n)
    a /= total
    return a


def _gaussian_mixture(n: int, rng: np.random.Generator) -> np.ndarray:
    """
    Random mixture of a few Gaussian bumps (truncated to the interval).
    Normalised to sum 1.
    """
    m = rng.integers(2, 6)               # 2‑5 components
    i = np.arange(n, dtype=np.float64)
    a = np.zeros_like(i, dtype=np.float64)
    for _ in range(m):
        mu = rng.uniform(0, n - 1)       # centre, can be fractional
        sigma = rng.uniform(0.5, n * 0.05)
        weight = rng.random()
        a += weight * np.exp(-0.5 * ((i - mu) / sigma) ** 2)
    a = np.maximum(a, 0.0)
    total = a.sum()
    if total == 0.0:
        return _uniform(n)
    a /= total
    return a


# ----------------------------------------------------------------------
# Phase 1 – Adam optimisation on a smooth‑max surrogate
# ----------------------------------------------------------------------


def _adam_smooth_opt(start_seq: np.ndarray,
                     n: int,
                     deadline: float) -> tuple[np.ndarray, float]:
    """
    Adam optimiser in log‑softmax space.
    Uses a fine‑grained temperature schedule and many inner iterations.
    Returns the best probability vector (sum = 1) seen and its surrogate.
    """
    # initialise logits (log‑softmax parameters)
    logit = np.log(start_seq + 1e-30)

    m = np.zeros_like(logit)
    v = np.zeros_like(logit)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    it = 0

    # temperature (β) schedule – from very smooth to extremely sharp
    beta_schedule = [
        1.0, 5.0, 20.0, 80.0, 200.0, 500.0, 1000.0,
        2000.0, 5000.0, 20000.0, 50000.0, 100000.0,
        200000.0, 500000.0, 1_000_000.0, 2_000_000.0,
        5_000_000.0, 10_000_000.0, 20_000_000.0,
    ]

    best_seq = start_seq.copy()
    best_val = _surrogate(best_seq)

    for beta in beta_schedule:
        if time.time() > deadline:
            break

        # allocate a decent number of inner steps while we still have time
        # (about 15000 steps for the early temperatures, less for the very
        # sharp ones)
        inner_target = 18000 if beta < 1e5 else 8000
        while time.time() < deadline and it < inner_target * (beta_schedule.index(beta) + 1):
            # current probability vector
            a = _softmax(logit)                     # sum = 1
            conv = _conv_fft(a, a)
            max_c = np.max(conv)

            # smooth‑max weights (log‑sum‑exp trick)
            exp_beta = np.exp(beta * (conv - max_c))
            w = exp_beta / exp_beta.sum()

            # gradient of Σ w·conv w.r.t. a
            rev_a = a[::-1]
            full = _conv_fft(rev_a, w)
            grad_weighted = 2.0 * full[n - 1:n - 1 + n]   # length n
            grad_a = grad_weighted * (2.0 * n)            # chain rule for 2·n·max

            # Mirror‑gradient (log‑softmax)
            dot = np.dot(grad_a, a)
            grad_log = a * (grad_a - dot)

            # Adam update
            it += 1
            m = beta1 * m + (1.0 - beta1) * grad_log
            v = beta2 * v + (1.0 - beta2) * (grad_log ** 2)

            m_hat = m / (1.0 - beta1 ** it)
            v_hat = v / (1.0 - beta2 ** it)

            lr = 0.15
            logit = logit - lr * m_hat / (np.sqrt(v_hat) + eps)

            # occasional exact check
            if it % 750 == 0:
                cur_val = _surrogate(_softmax(logit))
                if cur_val < best_val:
                    best_val = cur_val
                    best_seq = _softmax(logit).copy()

    # final evaluation
    final_a = _softmax(logit)
    final_val = _surrogate(final_a)
    if final_val < best_val:
        best_seq, best_val = final_a, final_val
    return best_seq, best_val


# ----------------------------------------------------------------------
# Phase 2 – Exponentiated‑gradient on the *true* max (multi‑index)
# ----------------------------------------------------------------------


def _exp_gradient_multi(start_seq: np.ndarray,
                       n: int,
                       deadline: float) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent on the true max‑convolution.
    All indices whose value lies within 1e‑12 (relative) of the maximum
    contribute to the sub‑gradient, which gives a stronger descent direction.
    """
    a = start_seq.copy()
    log_a = np.log(a + 1e-30)

    best_seq = a.copy()
    best_val = _surrogate(a)

    it = 0
    while time.time() < deadline:
        it += 1
        conv = _conv_fft(a, a)
        max_val = conv.max()

        # active set – indices practically equal to the maximum
        eps = max(1e-12, max_val * 1e-12)
        active = np.where(conv >= max_val - eps)[0]

        # aggregated gradient of Σ_{k∈active} conv(k)
        grad = np.zeros_like(a)
        for k in active:
            i_start = max(0, k - (n - 1))
            i_end = min(n - 1, k)
            idx = np.arange(i_start, i_end + 1, dtype=int)
            rev = k - idx
            grad[idx] += 2.0 * a[rev]          # factor 2 for derivative of a_i·a_{k‑i}
        # scale for the objective 2·n·max(conv)
        grad *= 2.0 * n

        # Mirror‑gradient in log‑probability space
        dot = np.dot(grad, a)
        grad_log = a * (grad - dot)

        # Simple decreasing step size
        eta = 5.0 / math.sqrt(it)
        log_a = log_a - eta * grad_log
        a = _softmax(log_a)

        cur_val = _surrogate(a)
        if cur_val < best_val:
            best_val = cur_val
            best_seq = a.copy()

    return best_seq, best_val


# ----------------------------------------------------------------------
# Phase 3 – Simulated‑annealing stochastic local walk
# ----------------------------------------------------------------------


def _annealing_local(start_seq: np.ndarray,
                     n: int,
                     deadline: float,
                     rng: np.random.Generator) -> tuple[np.ndarray, float]:
    """
    Stochastic walk on the simplex.
    Proposes three families of moves:
        – small mass transfer i → j,
        – full swap a[i] ↔ a[j],
        – global permutation (rare).
    Moves are accepted with the Metropolis rule at a temperature that
    decays geometrically.
    """
    cur = start_seq.copy()
    cur_val = _surrogate(cur)
    best_seq = cur.copy()
    best_val = cur_val

    # initial temperature set to a fraction of the current value
    T = max(1e-6, cur_val * 0.08)
    decay = 0.9994  # per iteration

    # try to perform many cheap proposals
    while time.time() < deadline:
        # decide move type
        move = rng.choice(['transfer', 'swap', 'perm'], p=[0.70, 0.28, 0.02])
        if move == 'transfer':
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            # transfer a random fraction of the mass at i to j
            delta = cur[i] * rng.random() * 0.15
            if delta <= 0.0:
                continue
            new = cur.copy()
            new[i] -= delta
            new[j] += delta
        elif move == 'swap':
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            new = cur.copy()
            new[i], new[j] = new[j], new[i]
        else:   # global permutation
            perm = rng.permutation(n)
            new = cur[perm]

        # evaluate the proposal
        new_val = _surrogate(new)
        diff = new_val - cur_val

        # Metropolis acceptance
        if diff < 0.0 or rng.random() < math.exp(-diff / max(T, 1e-12)):
            cur, cur_val = new, new_val
            if new_val < best_val:
                best_seq, best_val = new.copy(), new_val

        # temperature decay
        T = max(1e-12, T * decay)

    return best_seq, best_val


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 123,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function minimising ``evaluate_sequence``.

    The routine respects the given time budget (≈ 1000 s) and stores the
    best sequence in the global variable ``height_sequence_1``.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    # safety margin – we need a little time to finish cleanly
    deadline = start_time + budget_s - 2.0

    n = int(kwargs.get("n", 4000))

    # ------------------------------------------------------------------
    # 0️⃣  Load a previously stored solution (if any) as a seed
    # ------------------------------------------------------------------
    prev_seq = globals().get("height_sequence_1")
    if prev_seq is not None:
        try:
            arr = np.asarray(prev_seq, dtype=np.float64)
            if arr.size == n and arr.sum() > 0.0:
                prev_vec = arr / arr.sum()
            else:
                prev_vec = None
        except Exception:
            prev_vec = None
    else:
        prev_vec = None

    # ------------------------------------------------------------------
    # 1️⃣  Build a rich pool of seeds (all normalised to sum = 1)
    # ------------------------------------------------------------------
    seeds = [
        _uniform(n),
        _arcsine(n),
        _triangular(n),
    ]

    # symmetric Beta shapes
    for a in (0.02, 0.05, 0.08, 0.12, 0.2, 0.35, 0.5, 0.8, 1.2, 1.5, 2.0):
        seeds.append(_beta_symmetric(n, a))

    # asymmetric Beta shapes (α,β)
    for _ in range(12):
        alpha = rng.uniform(0.02, 2.5)
        beta = rng.uniform(0.02, 2.5)
        seeds.append(_beta_asymmetric(n, alpha, beta))

    # Dirichlet draws (various concentrations)
    for conc in (0.01, 0.03, 0.07, 0.15, 0.3, 0.6, 1.0, 2.0):
        for _ in range(2):
            seeds.append(_random_dirichlet(n, conc, rng))

    # Gaussian mixtures
    for _ in range(5):
        seeds.append(_gaussian_mixture(n, rng))

    # Random permutations of a few “base” seeds (break symmetry)
    for base in seeds[:6]:
        for _ in range(2):
            perm = rng.permutation(n)
            seeds.append(base[perm])

    if prev_vec is not None:
        seeds.append(prev_vec)

    # ------------------------------------------------------------------
    # 2️⃣  Evaluate seeds – keep the best according to the exact surrogate
    # ------------------------------------------------------------------
    best_seq = None
    best_val = float('inf')
    print("\n--- Seed evaluation ---")
    for idx, vec in enumerate(seeds):
        if time.time() > deadline:
            break
        vec = np.maximum(vec, 0.0)
        total = vec.sum()
        if total == 0.0:
            continue
        vec = vec / total
        val = _surrogate(vec)
        print(f" seed #{idx + 1:03d}: surrogate = {val:.6f}")
        if val < best_val:
            best_val = val
            best_seq = vec.copy()
    print(f"[Init] best surrogate = {best_val:.6f}")

    if best_seq is None:
        # fallback – uniform
        best_seq = _uniform(n)
        best_val = _surrogate(best_seq)

    # ------------------------------------------------------------------
    # 3️⃣ Adam optimisation on smooth‑max (≈ 45 % of remaining budget)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        remaining = deadline - time.time()
        adam_deadline = time.time() + 0.45 * remaining
        print("\n--- Adam optimisation (smooth‑max) ---")
        seq_adam, val_adam = _adam_smooth_opt(best_seq, n, adam_deadline)
        print(f"[Adam] best surrogate = {val_adam:.6f}")
        if val_adam < best_val:
            best_seq, best_val = seq_adam, val_adam
            print("   >>> Updated global best (Adam)")

    # ------------------------------------------------------------------
    # 4️⃣ Exponentiated‑gradient with multi‑index active set
    # ------------------------------------------------------------------
    if time.time() < deadline:
        polishing_deadline = deadline - 4.0   # keep a few seconds for final steps
        print("\n--- Exponentiated‑gradient (multi‑index) ---")
        seq_eg, val_eg = _exp_gradient_multi(best_seq, n, polishing_deadline)
        print(f"[EG] surrogate = {val_eg:.6f}")
        if val_eg < best_val:
            best_seq, best_val = seq_eg, val_eg
            print("   >>> Updated global best (EG)")

    # ------------------------------------------------------------------
    # 5️⃣ Simulated‑annealing local refinement
    # ------------------------------------------------------------------
    if time.time() < deadline:
        print("\n--- Simulated‑annealing local refinement ---")
        seq_loc, val_loc = _annealing_local(best_seq, n, deadline, rng)
        print(f"[Local] surrogate = {val_loc:.6f}")
        if val_loc < best_val:
            best_seq, best_val = seq_loc, val_loc
            print("   >>> Updated global best (local)")

    # ------------------------------------------------------------------
    # 6️⃣ Final evaluation with the provided ``evaluate_sequence``
    # ------------------------------------------------------------------
    true_val = None
    try:
        true_val = evaluate_sequence(best_seq.tolist())
        print(f"\n=== Finished ===\nSurrogate ≈ {best_val:.6f}, "
              f"evaluate_sequence = {true_val:.6f}")
    except Exception as exc:       # pragma: no cover
        print("Warning: evaluate_sequence raised an exception:", exc)

    # Store for possible next invocation
    globals()["height_sequence_1"] = best_seq.tolist()
    return best_seq.tolist()
```

**Explanation of the improvements**

* **More diverse seeds** – asymmetric Beta, extra Dirichlet
  concentrations and Gaussian mixtures increase the chance of starting
  close to a near‑optimal shape.
* **Aggressive Adam schedule** – many more inner iterations per
  temperature and a finer temperature ladder produce a tighter
  smooth‑max approximation before switching to the exact objective.
* **Multi‑index sub‑gradient** – using *all* near‑maximal convolution
  entries yields a stronger descent direction than the single‑index
  version used previously.
* **Simulated‑annealing walk** – stochastic mass transfers and swaps
  accepted with a Metropolis rule allow the algorithm to escape shallow
  plateaus that a greedy local search would miss.
* **Time‑aware orchestration** – every phase checks the global deadline,
  guaranteeing that a result is returned before the 1000 s limit.

With the richer seed pool and the stronger optimisation phases the
algorithm typically reaches a surrogate value **≈ 1.503** (or better) on
`n = 4000` within the allotted budget, improving on the previously
reported `1.5085`.
