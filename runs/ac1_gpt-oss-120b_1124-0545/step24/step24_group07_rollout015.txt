assistantfinal**Solution Overview**

The goal is to minimise  

```
evaluate_sequence(a) = 2·n·max(conv(a,a)) / (sum(a)²)          (n = len(a))
```  

The ratio is scale‑invariant, therefore we may (and do) normalise every candidate
to `sum(a)=1`.  
After normalisation the problem reduces to **minimising the peak of the
self‑convolution** `max(conv(a,a))`.

The new optimiser comprises three phases

| Phase | Idea | Why it helps |
|------|------|--------------|
| **1️⃣ Seed generation** | A very diverse pool: uniform, triangular, many Beta‑ and power‑law families, random Dirichlet draws and random *convex* mixtures of these bases. | A good seed is crucial – the objective is highly non‑convex, so starting from many different points increases the chance of finding a deep basin. |
| **2️⃣ Exact mirror‑descent (exponentiated‑gradient) runs** | For each of the best seeds we run a fast exponentiated‑gradient optimiser on the *true* max‑convolution (the same gradient that the original code used) but with many short restarts and an aggressive step‑size schedule (`η₀=10`). | The gradient points directly to the active convolution index, so a few hundred k updates are enough to move far away from the seed while never leaving the simplex. Multiple independent runs explore many basins. |
| **3️⃣ Fine polishing** | A final simulated‑annealing walk with a slowly cooling temperature and a larger perturbation (`σ=0.02`). | Accepts occasional worsening moves, letting the optimiser escape shallow minima that the deterministic mirror‑descent may miss. |

All heavy work uses the cheap surrogate  

```
S(a) = 2·n·max(conv(a,a))       (a is already normalised)
```  

which is exactly the value returned by `evaluate_sequence` for a normalised
sequence.  The final candidate is finally fed to the *real* `evaluate_sequence`
to obtain the official score.

The whole routine respects the 1000 s wall‑clock budget, logs progress and
stores the best sequence in the global variable `height_sequence_1` for the next
invocation.



```python
"""Improved optimiser for the step‑function attack.

The optimiser works in three stages:

1️⃣  Build a huge, diverse seed pool (uniform, triangular, many Beta /
    power‑law families, Dirichlet draws and random convex mixtures).

2️⃣  Run several independent exponentiated‑gradient (mirror‑descent) optimisations
    on the *exact* max‑convolution starting from the best seeds.  The step‑size
    schedule η₀/√t (η₀=10) is aggressive, allowing rapid escape from bad basins.

3️⃣  Finish with a cheap simulated‑annealing walk on the simplex to polish the
    result.

All intermediate evaluations use the cheap surrogate
    2·n·max(conv(a,a))
which, for a normalised sequence (∑a=1), equals the value returned by
``evaluate_sequence``.  The best sequence found is stored globally as
``height_sequence_1`` and returned as a plain ``list[float]``.
"""

import time
import math
import numpy as np
from scipy.optimize import minimize  # only needed for the optional L‑BFGS fine‑tune

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full linear convolution using a real FFT (O(N log N))."""
    L = len(x) + len(y) - 1
    N = _next_pow2(L)
    fx = np.fft.rfft(x, n=N)
    fy = np.fft.rfft(y, n=N)
    conv = np.fft.irfft(fx * fy, n=N)[:L]
    return conv


def _softmax(v: np.ndarray) -> np.ndarray:
    """Numerically stable softmax (mirrored simplex)."""
    m = np.max(v)
    e = np.exp(v - m)
    s = e.sum()
    if s == 0.0:
        return np.full_like(v, 1.0 / v.size)
    return e / s


def _objective_surrogate(seq: np.ndarray) -> float:
    """
    Exact surrogate: 2·n·max(conv(seq, seq)).
    The input is assumed to sum to 1.
    """
    n = len(seq)
    conv = _conv_fft(seq, seq)
    return float(2.0 * n * np.max(conv))


# ----------------------------------------------------------------------
# Analytic seed families
# ----------------------------------------------------------------------


def _uniform(n: int) -> np.ndarray:
    return np.full(n, 1.0 / n, dtype=np.float64)


def _triangular(n: int) -> np.ndarray:
    half = n // 2
    if n % 2 == 0:
        left = np.arange(1, half + 1)
        right = left[::-1]
    else:
        left = np.arange(1, half + 2)
        right = left[:-1][::-1]
    a = np.concatenate([left, right]).astype(np.float64)
    a = a / a.sum()
    return a


def _power_arcsine(n: int, p: float) -> np.ndarray:
    """Generalised arcsine family: a_i ∝ ((i+½)(n‑½‑i))^{-p}."""
    i = np.arange(n, dtype=np.float64)
    denom = (i + 0.5) * (n - 0.5 - i)
    a = np.power(denom + 1e-12, -p)
    a = a / a.sum()
    return a


def _power_general(n: int, p: float, off: float) -> np.ndarray:
    """Power‑law with a tunable offset: a_i ∝ ((i+off)(n‑off‑i))^{-p}."""
    i = np.arange(n, dtype=np.float64)
    denom = (i + off) * (n - off - i)
    a = np.power(denom + 1e-12, -p)
    a = a / a.sum()
    return a


def _beta_asymmetric(n: int, alpha: float, beta: float) -> np.ndarray:
    """Discrete Beta(α,β) density on {0,…,n‑1}."""
    x = (np.arange(n, dtype=np.float64) + 0.5) / n
    eps = 1e-12
    a = np.power(x + eps, alpha - 1.0) * np.power(1.0 - x + eps, beta - 1.0)
    a = a / a.sum()
    return a


def _random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    return rng.dirichlet(np.full(n, conc)).astype(np.float64)


def _random_mix(seeds: list[np.ndarray], rng: np.random.Generator) -> np.ndarray:
    """Random convex combination of a few base seeds."""
    k = rng.integers(2, min(5, len(seeds)) + 1)          # number of components
    idx = rng.choice(len(seeds), size=k, replace=False)
    weights = rng.random(k)
    weights /= weights.sum()
    mix = np.zeros_like(seeds[0])
    for w, i in zip(weights, idx):
        mix += w * seeds[i]
    # avoid exact zeros that could later cause numerical issues
    mix = np.maximum(mix, 1e-30)
    mix /= mix.sum()
    return mix


# ----------------------------------------------------------------------
# Optimisation primitives
# ----------------------------------------------------------------------


def _exp_gradient_opt(start_seq: np.ndarray,
                     deadline: float,
                     eta0: float = 10.0,
                     max_iters: int = 5_000_000) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent (exponentiated‑gradient) on the exact max‑convolution.
    Operates in log‑softmax (probability) space, guaranteeing a≥0 and sum=1.
    """
    n = len(start_seq)
    a = start_seq.copy()
    log_a = np.log(a + 1e-30)

    best_seq = a.copy()
    best_val = _objective_surrogate(a)

    it = 0
    while time.time() < deadline and it < max_iters:
        it += 1
        conv = _conv_fft(a, a)
        k = int(np.argmax(conv))

        # sub‑gradient for the active index k (double count for i≠j)
        g = np.zeros_like(a)
        i_start = max(0, k - (n - 1))
        i_end = min(n - 1, k)
        idx_i = np.arange(i_start, i_end + 1, dtype=int)
        rev_idx = k - idx_i
        g[idx_i] = 2.0 * a[rev_idx]                 # 2·a_{k‑i}

        eta = eta0 / math.sqrt(it)
        log_a = log_a - eta * g
        a = _softmax(log_a)

        if it % 4000 == 0:
            cur_val = _objective_surrogate(a)
            if cur_val < best_val:
                best_val = cur_val
                best_seq = a.copy()

    final_val = _objective_surrogate(a)
    if final_val < best_val:
        best_seq, best_val = a, final_val

    return best_seq, best_val


def _anneal_opt(start_seq: np.ndarray,
                deadline: float,
                init_temp: float = 0.05,
                final_temp: float = 1e-8,
                sigma: float = 0.02) -> tuple[np.ndarray, float]:
    """
    Tiny simulated‑annealing walk on the simplex.
    Moves transfer a random fraction of mass from i → j.
    """
    n = len(start_seq)
    a = start_seq.copy()
    cur_val = _objective_surrogate(a)
    best_seq = a.copy()
    best_val = cur_val
    rng = np.random.default_rng()

    start_time = time.time()
    while time.time() < deadline:
        elapsed = time.time() - start_time
        total = deadline - start_time
        temp = init_temp * (1.0 - elapsed / total)
        temp = max(final_temp, temp)

        i, j = rng.integers(0, n, size=2)
        if i == j or a[i] <= 0.0:
            continue
        delta = sigma * a[i] * rng.random()
        if delta <= 0.0:
            continue
        new_a = a.copy()
        new_a[i] -= delta
        new_a[j] += delta
        if new_a[i] < 0.0:
            continue
        new_val = _objective_surrogate(new_a)

        accept = False
        if new_val < cur_val:
            accept = True
        else:
            prob = math.exp(-(new_val - cur_val) / temp)
            if rng.random() < prob:
                accept = True
        if accept:
            a = new_a
            cur_val = new_val
            if cur_val < best_val:
                best_val = cur_val
                best_seq = a.copy()

    return best_seq, best_val


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 123,
                     budget_s: int = 1000,
                     n: int = 4000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises ``evaluate_sequence``.
    The best sequence found within the allotted budget is stored globally as
    ``height_sequence_1`` and returned as a plain list of floats.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 2.0          # a tiny safety margin

    # --------------------------------------------------------------
    # Try to reuse a sequence from a previous run
    # --------------------------------------------------------------
    prev = globals().get("height_sequence_1")
    prev_vec = None
    if isinstance(prev, (list, tuple, np.ndarray)):
        try:
            arr = np.asarray(prev, dtype=np.float64)
            if arr.size == n and arr.sum() > 0.0:
                prev_vec = arr / arr.sum()
        except Exception:
            pass

    # --------------------------------------------------------------
    # 0️⃣  Assemble a huge and diverse seed pool
    # --------------------------------------------------------------
    seeds = [_uniform(n), _triangular(n)]

    # arcsine‑like power families (p around the known optimum)
    for p in np.arange(0.40, 0.61, 0.025):
        seeds.append(_power_arcsine(n, float(p)))

    # more flexible power‑law with an offset
    for off in (0.1, 0.5, 1.0):
        for p in (0.45, 0.5, 0.55, 0.6):
            seeds.append(_power_general(n, float(p), float(off)))

    # asymmetric Beta families – a fairly dense grid
    alphas = [0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.0, 1.5, 2.0]
    betas = [0.05, 0.1, 0.2, 0.3, 0.5, 0.8, 1.0, 1.5, 2.0, 3.0, 5.0]
    for a in alphas:
        for b in betas:
            seeds.append(_beta_asymmetric(n, float(a), float(b)))

    # Dirichlet draws with several concentration parameters
    for conc in (0.001, 0.005, 0.01, 0.05, 0.1, 0.2, 0.5):
        for _ in range(2):
            seeds.append(_random_dirichlet(n, conc, rng))

    # a few random convex mixtures of the already generated bases
    for _ in range(30):
        seeds.append(_random_mix(seeds, rng))

    if prev_vec is not None:
        seeds.append(prev_vec)

    # --------------------------------------------------------------
    # 1️⃣  Quick surrogate evaluation of every seed
    # --------------------------------------------------------------
    seed_infos = []
    print("\n--- Seed pool evaluation (surrogate) ---")
    for idx, vec in enumerate(seeds):
        if time.time() > deadline:
            break
        vec = np.maximum(vec, 0.0)
        if vec.sum() == 0.0:
            continue
        vec = vec / vec.sum()
        val = _objective_surrogate(vec)
        seed_infos.append((val, vec))
        if (idx + 1) % 50 == 0 or idx == len(seeds) - 1:
            print(f"  evaluated {idx + 1}/{len(seeds)} seeds – best so far {min(v for v, _ in seed_infos):.6f}")

    if not seed_infos:
        raise RuntimeError("No valid seeds generated before deadline.")

    seed_infos.sort(key=lambda x: x[0])
    top_k = min(12, len(seed_infos))
    top_seeds = [vec for _, vec in seed_infos[:top_k]]
    best_seq = top_seeds[0].copy()
    best_val = _objective_surrogate(best_seq)
    print(f"[Init] best surrogate = {best_val:.6f}")

    # --------------------------------------------------------------
    # 2️⃣  Multiple short exponentiated‑gradient runs (exact max)
    # --------------------------------------------------------------
    if time.time() < deadline:
        eg_deadline = deadline - 5.0         # reserve a few seconds for polishing
        print("\n--- Exponentiated‑gradient runs (exact max) ---")
        for run_id, seed_vec in enumerate(top_seeds, start=1):
            if time.time() >= eg_deadline:
                break
            # give each run roughly the same slice of remaining time
            remaining = eg_deadline - time.time()
            per_run_deadline = time.time() + remaining / (len(top_seeds) - run_id + 1)
            seq_eg, val_eg = _exp_gradient_opt(seed_vec, per_run_deadline,
                                               eta0=10.0,
                                               max_iters=2_000_000)
            print(f"   run #{run_id:02d}: surrogate = {val_eg:.6f}")
            if val_eg < best_val:
                best_seq, best_val = seq_eg.copy(), val_eg
                print("      >>> New global best after EG run")

    # --------------------------------------------------------------
    # 3️⃣  Final annealing walk (polish)
    # --------------------------------------------------------------
    if time.time() < deadline:
        print("\n--- Final annealing polish ---")
        seq_loc, val_loc = _anneal_opt(best_seq, deadline,
                                       init_temp=0.05,
                                       final_temp=1e-8,
                                       sigma=0.02)
        print(f"[Anneal] surrogate = {val_loc:.6f}")
        if val_loc < best_val:
            best_seq, best_val = seq_loc.copy(), val_loc
            print("      >>> Updated global best after annealing")

    # --------------------------------------------------------------
    # 4️⃣  Official evaluation with the supplied ``evaluate_sequence``
    # --------------------------------------------------------------
    true_val = None
    try:
        true_val = evaluate_sequence(best_seq.tolist())
        print(f"\n=== Finished ===\nSurrogate ≈ {best_val:.6f}, "
              f"evaluate_sequence = {true_val:.6f}")
    except Exception as exc:                 # pragma: no cover
        print("Warning: evaluate_sequence raised an exception:", exc)

    # Store for the next invocation
    globals()["height_sequence_1"] = best_seq.tolist()
    return best_seq.tolist()
```
