Hybrid search for a low‑autocorrelation step function.

The evaluator computes
    score = 2 * n * max( a * a ) / (sum(a)**2)          (n = len(a))

For a probability vector (sum == 1) this reduces to   score = 2·n·max(conv).

Uniform weights give a score of exactly 2, therefore any improvement
must find a non‑trivial probability distribution with a smaller
convolution peak.  The routine below explores the feasible simplex
with three complementary stochastic optimisation phases:

1.  **Exponentiated‑gradient (EG) descent** – a smooth‑max surrogate of
    the peak is optimised using a temperature schedule.  The EG
    update keeps the iterate on the probability simplex without an
    explicit projection.

2.  **Simulated‑annealing (SA) jumps** – occasional random mass
    transfers between coordinates are accepted with a Metropolis
    criterion.  This helps to escape shallow basins that the EG phase
    can get stuck in.

3.  **Projected sub‑gradient refinement** – after the two phases a
    cheap deterministic sweep with the exact sub‑gradient of the
    true max‑convolution is performed, projecting each trial back onto
    the simplex.

The algorithm runs as many outer cycles as the 1000 s budget allows,
always keeping the best vector seen so far.  The final call to
`evaluate_sequence` is made once at the end (the only unavoidable call
to the provided black‑box).  The implementation uses only NumPy and
SciPy (for the FFT based convolutions) and respects the one‑CPU limit.

# Helper utilities (all top‑level, no closures)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two >= x."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """
    Full linear convolution of a real vector with itself using FFT.
    Length = 2*len(x)-1.
    """
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = rfft(x, size)
    conv = irfft(fx * fx, size)[:out_len]
    return conv


def _cross_corr(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Cross‑correlation of w with a (both real, 1‑D).
    Result has length len(a) and corresponds to
        (w ⋆ a)[i] = Σ_k w_k · a_{k-i}
    """
    n = a.shape[0]
    a_rev = a[::-1]
    out_len = w.shape[0] + n - 1          # = (2n‑1) + n‑1 = 3n‑2
    size = _next_pow2(out_len)
    fw = rfft(w, size)
    fa = rfft(a_rev, size)
    conv = irfft(fw * fa, size)[:out_len]
    start = n - 1
    return conv[start:start + n]


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex {x ≥ 0, Σx = 1}."""
    if v.ndim != 1:
        raise ValueError("v must be 1‑D")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    rho = np.where(u - cssv / ind > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _objective(a: np.ndarray, n: int) -> float:
    """Exact objective used by the optimiser (sum(a) is assumed to be 1)."""
    conv = _full_convolution(a)
    return 2.0 * n * conv.max()


def _smooth_max_weights(conv: np.ndarray, lam: float) -> np.ndarray:
    """Return a probability vector over the convolution entries that
    approximates the max, controlled by temperature λ."""
    cmax = conv.max()
    if lam > 5e3:                              # switch to exact max
        w = np.zeros_like(conv)
        w[np.argmax(conv)] = 1.0
    else:
        # soft‑max on (conv - cmax) to improve numerical stability
        exp_vals = np.exp(lam * (conv - cmax))
        w = exp_vals / exp_vals.sum()
    return w
