The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max\limits_{k}(a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where \((a*a)\) is the full linear convolution of the vector `a` with itself.
Because the denominator scales quadratically with the sum of the coefficients,
`F(a)` depends only on the *shape* of the vector (`a` can be normalised to
\(\sum a_i = 1\)).  
Consequently the cheap proxy used during the search is  

\[
\tilde F(a)=2\,n\;\max_k (a*a)[k]\;,
\]

exactly the value returned by ``evaluate_sequence`` after the clipping steps.

The previous implementation used a simple sub‑gradient / mirror‑descent loop.
To go further we replace the plain sub‑gradient by a **smooth approximation of
the maximum** (log‑sum‑exp) and optimise that surrogate with an Adam‑style
exponential‑gradient update.  
The smoothing parameter \(\alpha\) is increased during the run so that the
algorithm first follows a benign landscape (small \(\alpha\)) and later focuses
on the true maximum (large \(\alpha\)).

A short random‑support warm‑start (identical to the one in the reference code)
gives a good starting point; the optimiser then refines the solution.
Occasional Gaussian jitter prevents the iterate from stagnating.

The whole search respects the 1000 s budget and finally returns the best
sequence found.

```python
"""
Propose a step‑function (non‑negative sequence) that minimises
``evaluate_sequence``.

Algorithm
---------

1️⃣ Warm‑start  
   *If a previous solution (`height_sequence_1`) exists it is interpolated to the
   current length (`n = 8000`).  Otherwise a uniform distribution is used.*

2️⃣ Random‑support exploration (cheap stage) – many candidates with a random
   mask are generated, normalised to sum = 1 and evaluated by the cheap proxy
   ``2*n*max(conv(a,a))``.  The best candidate of this phase becomes the start
   of the refinement.

3️⃣ Smoothed‑maximum optimisation  
   * a smooth approximation of the max‑operator is used  
     \(\displaystyle  \operatorname{LSE}_\alpha(c)=\frac{\log\sum_k
        e^{\alpha c_k}}{\alpha}\) with a gradually increasing \(\alpha\);
   * the gradient of the surrogate is
     \(\displaystyle \nabla\operatorname{LSE}_\alpha(c)=
        \frac{\sum_k e^{\alpha c_k}\,\nabla c_k}{\sum_k e^{\alpha c_k}}\) .
     \(\nabla c_k\) is obtained efficiently by a single convolution.
   * An Adam‑style exponential‑gradient update keeps the iterate on the
     probability simplex (multiply by ``exp(-step*grad)`` and renormalise).

   *Step size* decays linearly from ~0.4 to ~5·10⁻⁵.  The smoothing factor
   ``alpha`` starts at 1.0 and is multiplied by ``1.02`` each iteration
   (capped at 200).

4️⃣ Periodic jitter (probability 0.001) adds a tiny Gaussian noise,
   re‑normalises the vector and resets the momentum – this helps to escape
   plateaux.

The routine stops a few tenths of a second before the deadline, evaluates the
best candidate with the official ``evaluate_sequence`` function and returns it.

The method is fully deterministic apart from the initial random seeds and
fits easily into the 1000 s time limit.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution utilities (FFT‑based, full linear convolution)
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """
    Returns the full linear convolution of ``x`` with itself.
    Length = 2*len(x) - 1.
    The routine uses an FFT of the next power‑of‑two for speed.
    """
    n = x.shape[0]
    size = 1 << (2 * n - 2).bit_length()          # next power of two ≥ 2n‑1
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[: 2 * n - 1]
    return conv


def _objective(a: np.ndarray) -> float:
    """
    Cheap proxy used during the search.
    Assumes ``a`` is already normalised (sum == 1).
    Returns 2 * n * max(conv(a,a)).
    """
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())


# ----------------------------------------------------------------------
# Smoothed‑maximum gradient (log‑sum‑exp)
# ----------------------------------------------------------------------


def _smooth_gradient(a: np.ndarray, alpha: float) -> np.ndarray:
    """
    Compute the gradient of
        g(a) = 2*n*log‑sum‑exp(alpha * conv(a,a)) / alpha
    with respect to ``a`` (a is a probability vector, sum == 1).

    The gradient of conv(a,a) w.r.t. a is
        ∂c_k/∂a_i = a_{k-i} + a_{k-i}   (i ≠ k-i)
                    a_i                (i = k-i)
    which can be expressed compactly as 2 * correlate(w, a)
    where w_k = exp(alpha * c_k).  The implementation uses a single
    convolution (FFT / np.convolve) and returns the full gradient.
    """
    n = a.shape[0]

    # full convolution of a with itself
    c = _full_convolution(a)                     # length 2n‑1

    # weights for the log‑sum‑exp
    # clipping protects against overflow when alpha is large
    w = np.exp(np.clip(alpha * c, -700, 700))

    # normalisation factor (the denominator of the gradient)
    w_sum = w.sum()
    if w_sum == 0.0:
        w_sum = 1.0

    # correlate(w, a) = Σ_k w_k * a_{k-i}
    a_rev = a[::-1]
    tmp = np.convolve(w, a_rev, mode='full')    # length 3n‑2
    # extract the segment that corresponds to i = 0 … n‑1
    corr = tmp[n - 1 : n - 1 + n]                # shape (n,)

    # gradient of the smooth objective (without the outer factor 2*n)
    grad = (2.0 * corr) / w_sum                  # shape (n,)

    # finally multiply by 2*n (the outer factor of the original objective)
    grad *= 2.0 * n

    return grad

        # Adam‑style moment updates
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        m_hat = m / (1.0 - beta1 ** (it + 1))
        v_hat = v / (1.0 - beta2 ** (it + 1))

        # Linear step‑size decay
        progress = (time.time() - start) / (deadline - start)
        step = step_start * (1.0 - progress) + step_end

        # Exponentiated (multiplicative) update – guarantees positivity
        log_factor = -step * (m_hat / (np.sqrt(v_hat) + eps))
        log_factor = np.clip(log_factor, -40.0, 40.0)   # avoid overflow
        a = a * np.exp(log_factor)
        s = a.sum()
        if s == 0.0 or not np.isfinite(s):
            a = np.full(n, 1.0 / n, dtype=np.float64)
        else:
            a = a / s

        # Increase smoothing gradually
        if alpha < alpha_max:
            alpha = min(alpha * alpha_factor, alpha_max)

        # Occasional jitter to break plateaux or after many non‑improvements
        if rng.random() < 0.001 or no_improve >= max_no_improve:
            jitter = rng.normal(scale=0.001, size=n)
            a = np.maximum(a + jitter, 0.0)
            a = a / a.sum()
            m.fill(0.0)
            v.fill(0.0)
            no_improve = 0
            alpha = 1.0       # reset smoothing after a big jump
            print(f"[jitter] iter {it} – reset momentum & smoothing")

        it += 1

    # ------------------------------------------------------------------
    # 3️⃣ Final secure evaluation
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"[final] evaluate_sequence returned {final_score:.6f}")
    except Exception as exc:   # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_seq.tolist()
```
