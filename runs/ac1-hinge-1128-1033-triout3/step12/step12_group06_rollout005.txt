The evaluation function  

```
score = 2·n·max(conv(a,a)) / (sum(a))²
```

is *scale‑invariant*: multiplying a by any constant does not change the
score.  
Consequently we may normalise every candidate sequence to `sum(a)=1`
and simply minimise  

```
F(a) = 2·n·max(conv(a,a))            (1)
```

where `conv` is the full linear convolution.

For a monotone power‑law  

```
a_i ∝ (i+1)^p ,   i = 0 … n‑1                     (2)
```

the convolution coefficient at lag `k = n‑1` (the centre) is  

```
C(p) = Σ_{i=1}^{n} i^p (n+1-i)^p  ≈  n^{2p+1}·B(p+1,p+1)     (3)
```

with `B` the Beta‑function.
After normalising the vector to `sum = 1` the factor `n^{2p+1}` is cancelled
and the asymptotic value of (1) becomes

```
F(p) = 2·(p+1)²·B(p+1,p+1) .                         (4)
```

`F(p)` decreases quickly, reaches ∼0.01 for `p≈5–6` and never exceeds `2`.
Hence a simple power‑law family already contains sequences far better than
the previously reported 1.508.

The optimiser below

* scans a fine grid of exponents `p`,
* evaluates (1) using an FFT‑based convolution,
* keeps the best candidate,
* performs a tiny random refinement around the best exponent,
* finally returns the best sequence (already normalised, therefore ready
  for `evaluate_sequence`).

The whole search finishes well within the 1000 s budget.

```python
"""
Propose a step‑function (non‑negative sequence) that minimises
evaluate_sequence.  The search uses the monotone power‑law family
a_i ∝ (i+1)^p, scans a fine grid of exponents, refines the best
exponent locally and returns the best normalised sequence found.
All numbers are non‑negative and the sum of the returned sequence is 1,
so evaluate_sequence works directly on the result.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution helpers (exact, FFT based)
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Linear convolution of a real vector with itself (full length)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    # pick next power of two for efficient FFT
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _objective(a: np.ndarray) -> float:
    """Exact objective 2·n·max(conv(a,a)) for a sequence with sum(a)=1."""
    n = a.shape[0]
    conv = _full_convolution(a)
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
# Candidate families
# ----------------------------------------------------------------------


def _power_shape(p: float, n: int) -> np.ndarray | None:
    """
    Return a normalised vector a_i ∝ (i+1)^p  (i = 0 … n‑1).
    The vector is guaranteed to sum to 1 and to contain only non‑negative
    numbers.
    """
    if p <= 0:
        return None
    i = np.arange(1, n + 1, dtype=np.float64)   # 1 … n
    a = np.power(i, p)
    total = a.sum()
    if total <= 0.0:
        return None
    a /= total
    return a


# ----------------------------------------------------------------------
# Main entry point required by the competition framework
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a low‑score step function.

    Algorithm
    ----------
    1.  Choose a problem size `n` (8000 is a good trade‑off).
    2.  Scan exponents `p` in a dense grid, evaluate the exact objective,
        keep the best shape.
    3.  Perform a small random refinement around the best exponent.
    4.  Return the best normalised sequence found before the time budget
        expires.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 0.5   # spare half a second for the final call

    # length of the step function – large enough to be expressive but cheap
    n = 8000

    best_seq: np.ndarray | None = None
    best_val = np.inf

    def _try_candidate(seq: np.ndarray, src: str):
        """Update the current best sequence if `seq` improves the objective."""
        nonlocal best_seq, best_val
        val = _objective(seq)
        if val < best_val:
            best_val = val
            best_seq = seq.copy()
            print(f"[search] new best {val:.6f} from {src}")

    # ------------------------------------------------------------------
    # 0️⃣  Try to reuse the previous solution if it exists.
    # ------------------------------------------------------------------
    try:
        # `height_sequence_1` may be defined by the outer framework
        old = np.asarray(height_sequence_1, dtype=np.float64)  # type: ignore[name-defined]
        # interpolate to current length
        old_x = np.linspace(0.0, 1.0, old.shape[0])
        new_x = np.linspace(0.0, 1.0, n)
        interpolated = np.interp(new_x, old_x, old)
        interpolated = np.maximum(interpolated, 0.0)
        interpolated /= interpolated.sum()
        _try_candidate(interpolated, "interpolated previous")
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1️⃣  Exhaustive grid search over exponents
    # ------------------------------------------------------------------
    # a dense grid around the theoretically good region (0.5 … 10)
    grid = np.linspace(0.5, 10.0, 100)
    for p in grid:
        cand = _power_shape(p, n)
        if cand is not None:
            _try_candidate(cand, f"p={p:.2f}")
        if time.time() >= deadline - 200.0:
            break

    # ------------------------------------------------------------------
    # 2️⃣  Random local search around the best exponent found so far
    # ------------------------------------------------------------------
    if best_seq is not None:
        # approximate exponent behind the current best by a simple heuristic:
        # use the ratio of the first two entries (a_1 / a_0) ≈ ((2)/(1))^p
        # => p ≈ log(a_1/a_0) / log(2)
        try:
            a0, a1 = best_seq[0], best_seq[1]
            approx_p = np.log(a1 / a0) / np.log(2.0) if a0 > 0 else 2.0
        except Exception:
            approx_p = 5.0
    else:
        approx_p = 5.0

    rng = np.random.default_rng()
    for _ in range(3000):
        # perturb on a log‑scale, centred around the current estimate
        p = rng.normal(loc=approx_p, scale=1.5)
        if p <= 0.0:
            continue
        cand = _power_shape(p, n)
        if cand is not None:
            _try_candidate(cand, f"rand p={p:.2f}")
        if time.time() >= deadline - 50.0:
            break

    # ------------------------------------------------------------------
    # 3️⃣  Final safety net – if nothing was found, fall back to uniform.
    # ------------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)
        best_val = _objective(best_seq)

    # ------------------------------------------------------------------
    # 4️⃣  Logging of the final score (optional, does not affect the answer)
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"[final] evaluate_sequence score = {final_score:.6f}")
    except Exception as exc:  # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    # return a plain Python list as required by the framework
    return best_seq.tolist()
```
