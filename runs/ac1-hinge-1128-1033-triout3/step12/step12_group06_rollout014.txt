For a shape a_i ∝ (i+1)^p the dominant term of the objective is

    2·(p+1)²·B(p+1,p+1)          (central autocorrelation)

where B is the Beta function.  This expression falls rapidly with p
until the edge term 2·(p+1)²/n (coming from a_max²) becomes dominant.
For n≈8000 the optimal exponent lies around p≈6, giving a score
≈1.2 × 10⁻² – far below the target 1.503.

The routine:
    • scans a coarse grid of exponents,

The whole search respects the 1000 s time budget.

import time

# ----------------------------------------------------------------------
# Convolution utilities (FFT based, linear full convolution)
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Linear full convolution x*x using zero‑padded FFT."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _objective(a: np.ndarray) -> float:
    """
    Exact objective 2·n·max(conv(a,a)) assuming Σa = 1.
    The vector a is already normalised to sum‑to‑one.
    """
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())

    total = a.sum()
    if total == 0.0 or not np.isfinite(total):

    a /= total
    return a
