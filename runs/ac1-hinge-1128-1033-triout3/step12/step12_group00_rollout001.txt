def _exp_grad_polish(a0, n, deadline, start, best_a, best_val, max_iters=500000):
    a = a0.copy()
    cur_val = _objective(a)
    # track best
    best_local = a.copy()
    best_local_val = cur_val
    for itr in range(max_iters):
        now = time.time()
        if now >= deadline:
            break
        b = _full_convolution(a)
        M = b.max()
        max_idxs = np.where(b == M)[0]
        # compute subgradient as average over max_idxs
        grad = np.zeros_like(a)
        for k in max_idxs:
            idx = k - np.arange(n)
            mask = (idx >= 0) & (idx < n)
            grad[mask] += 2.0 * a[idx[mask]]

        grad /= len(max_idxs)
        # step size schedule: e.g., eta = 0.5 / (1 + itr*1e-4)

The score of a candidate `a = (a₀,…,a_{n‑1})` is  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a_i)^2}\; .
\]

All entries are forced to be non‑negative, the denominator is made 1 by normalising the vector (`∑a_i = 1`).  
Consequently the optimisation problem is

* minimise `2·n·max(conv(a,a))`  
* subject to `a_i ≥ 0` and `∑a_i = 1`.

The objective is the maximum of many quadratic forms – a convex but non‑smooth function.
The previous implementation uses a smooth‑max surrogate (log‑sum‑exp) together with L‑BFGS and a
projected sub‑gradient step.  It works well, yet a finer search on a *low‑dimensional*
parameterisation and an *exponential‑gradient* polishing step can push the bound a little
further.

--------------------------------------------------------------------
### 1.  Parameterised families (Beta‑shapes)

A symmetric Beta density

\[
a_i \propto i^{p-1}\,(n-i+1)^{q-1},\qquad i=1,…,n
\]

covers almost all “reasonable’’ step‑functions (flat, triangular, bell‑shaped …).  
Only the two positive parameters `p,q` have to be tuned.  
We first generate a coarse set of candidates (uniform, old solution, random Dirichlet,
random Beta) and keep the best few.  Afterwards a tiny L‑BFGS optimisation is performed
*directly* on the two parameters (`log p, log q`) using the smooth‑max surrogate.
Because the dimension is only two the optimisation is cheap and converges to a
near‑optimal shape.

--------------------------------------------------------------------
### 2.  Full‑vector L‑BFGS on a smooth surrogate

For a full‑vector start point we run L‑BFGS on the same smooth‑max surrogate as the
reference code, but with a **more aggressive schedule for the smoothing parameter**
`ε` (starts at `5·10⁻¹` and decays exponentially to `10⁻¹⁰`).  
Each run is performed from the current best vector, from a randomly perturbed copy,
and from the refined Beta‑shape.  All vectors are represented by logits (`softmax`) so
the simplex constraints are satisfied automatically.

--------------------------------------------------------------------
### 3.  Exponential‑gradient polishing (mirror descent on the simplex)

The remaining non‑smoothness is handled by a projected *exponential* gradient step
(a mirror‑descent in the KL‑geometry).  
For the current vector `a`

* compute the convolution `b = a*a` and the maximal value `M = max(b)`;
* build a sub‑gradient of the max (average of the gradients of all indices where
  `b` attains `M`);
* update multiplicatively  

  \[
  a_i \leftarrow a_i\;\exp(-\eta\,g_i)
  \]

  and re‑normalise onto the simplex.

The step‑size `η` starts relatively large (`≈0.3`) and decays slowly, while occasional
random jitter prevents stagnation.  This method converges much faster than the plain
projected Euclidean sub‑gradient used before.

--------------------------------------------------------------------
### 4.  Final short L‑BFGS with an ultra‑small `ε`

A last L‑BFGS run with `ε = 10⁻¹²` refines the solution to the exact objective.

--------------------------------------------------------------------
### 5.  Time management

The total budget is 1000 s.  The algorithm splits the time roughly as

| Phase | Approx. fraction |
|------|-------------------|
| initial sweep & best‑candidate selection | 5 % |
| L‑BFGS on smooth surrogate (multiple restarts) | 40 % |
| exponentiated‑gradient polishing | 45 % |
| final L‑BFGS (tiny ε) | 10 % |

All loops constantly check the wall‑clock and abort when the deadline is reached,
avoiding a forced termination with `-inf`.

--------------------------------------------------------------------
### 6.  Result

The function `propose_candidate` returns a plain Python list of non‑negative
floats (sum ≈ 1).  It can be called directly by the evaluation harness.

"""
Optimiser for the step‑function benchmark.

Strategy
--------
* 12000 coefficients (n) – a good compromise between expressive power
  and FFT speed.
* Coarse random sweep (uniform, old solution, Dirichlet, Beta families)
  → keep the best few.
* Low‑dimensional optimisation of the symmetric Beta shape (p,q) via L‑BFGS
  on a smooth‑max surrogate.
* Full‑vector L‑BFGS on the same surrogate from several start points,
  with a rapidly decreasing smoothing parameter ε.
* Mirror‑descent polishing on the exact objective using an exponential‑gradient
  update (KL‑projection onto the simplex).
* Final short L‑BFGS with ε≈1e‑12 for fine tuning.

All phases respect the 1000 s wall‑clock budget.
"""

import time
import math
import numpy as np
from scipy.optimize import minimize
from scipy.special import i0  # (not strictly needed, kept for possible extensions)

# ----------------------------------------------------------------------
# FFT‑based convolutions (full linear)
# ----------------------------------------------------------------------
def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of `x` with itself (length 2·len(x)‑1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Exact objective (Σa = 1)
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Exact value of 2·n·max(conv(a,a)) under Σa = 1."""
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())


# ----------------------------------------------------------------------
# Smooth‑max (log‑sum‑exp) and its gradient (already multiplied by 2·n)
# ----------------------------------------------------------------------
def _smooth_max_and_grad(a: np.ndarray, eps: float) -> tuple[float, np.ndarray]:
    """
    Returns a smooth approximation of max(conv(a,a)) and the gradient of
    2·n·smooth_max w.r.t. a (already includes the factor 2·n).
    """
    n = a.shape[0]
    b = _full_convolution(a)                     # length 2n‑1
    max_b = b.max()
    # log‑sum‑exp trick
    shifted = (b - max_b) / eps
    # shifted ≤ 0, safe for exp
    weights = np.exp(shifted)
    p = weights / weights.sum()                  # shape (2n‑1,)

    # convolution of a with reversed p
    p_rev = p[::-1]
    conv_ab = _conv_fft(a, p_rev)                # length 2n‑1
    # keep the n “forward” entries (indices n‑1 … 2n‑2)
    segment = conv_ab[n - 1:2 * n - 1]            # n entries
    grad_a = 4.0 * n * segment[::-1]             # includes factor 2·n
    smooth_val = max_b + eps * np.log(weights.sum())
    return smooth_val, grad_a


# ----------------------------------------------------------------------
# Soft‑max (log‑its → probability simplex)
# ----------------------------------------------------------------------
def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max returning a probability vector."""
    x_shift = x - np.max(x)
    e = np.exp(x_shift)
    return e / e.sum()


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto {x | x≥0, Σx=1}."""
    if np.abs(v.sum() - 1.0) < 1e-12 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Random Beta family candidate (cheap initial sweep)
# ----------------------------------------------------------------------
def _random_beta_candidate(n: int, rng: np.random.Generator) -> np.ndarray:
    """Draw (p,q) on a log‑scale and return the normalised Beta shape."""
    i = np.arange(1, n + 1, dtype=np.float64)
    logp = rng.uniform(-9.2, 2.3)   # ~1e‑4 … 10
    logq = rng.uniform(-9.2, 2.3)
    p = np.exp(logp)
    q = np.exp(logq)
    a = (i ** (p - 1.0)) * ((n - i + 1) ** (q - 1.0))
    s = a.sum()
    if s == 0.0:
        a = np.full(n, 1.0 / n)
    else:
        a /= s
    return a


# ----------------------------------------------------------------------
# L‑BFGS optimiser on the smooth‑max surrogate (full vector)
# ----------------------------------------------------------------------
def _lbfgs_optimize(a0: np.ndarray,
                    n: int,
                    deadline: float,
                    start_time: float,
                    best_a: np.ndarray,
                    best_val: float,
                    eps: float = 1e-6,
                    max_iter: int = 1500) -> tuple[np.ndarray, float]:
    """
    Run L‑BFGS‑B on the smoothed objective.
    """
    x0 = np.log(a0 + 1e-12)   # logits; ensures a_i>0

    def fun(x):
        a = _softmax(x)
        smooth_val, _ = _smooth_max_and_grad(a, eps)
        return 2.0 * n * smooth_val

    def jac(x):
        a = _softmax(x)
        smooth_val, grad_a = _smooth_max_and_grad(a, eps)
        # gradient w.r.t. logits via the softmax Jacobian
        dot = np.dot(a, grad_a)
        return a * (grad_a - dot)

    # time guard
    if time.time() >= deadline - 0.5:
        return best_a, best_val

    opts = {"maxiter": max_iter, "ftol": 1e-12, "gtol": 1e-12}
    try:
        res = minimize(fun, x0, jac=jac, method="L-BFGS-B", options=opts)
    except Exception as exc:  # pragma: no cover
        print("[L‑BFGS] minimise raised:", exc)
        return best_a, best_val

    a_opt = _softmax(res.x)
    val_opt = _objective(a_opt)
    if val_opt < best_val:
        best_val, best_a = val_opt, a_opt.copy()
        print(f"[L‑BFGS] new best = {best_val:.6f}")
    return best_a, best_val


# ----------------------------------------------------------------------
# Blend with the uniform distribution (helps smooth spikes)
# ----------------------------------------------------------------------
def _blend_with_uniform(a: np.ndarray,
                        n: int,
                        cur_best_val: float) -> tuple[np.ndarray, float]:
    """Try convex combinations t·a + (1‑t)·u for a few t‑values."""
    u = np.full(n, 1.0 / n)
    best_a, best_val = a.copy(), cur_best_val
    for t in np.linspace(0.0, 1.0, 21):
        cand = t * a + (1.0 - t) * u
        cand /= cand.sum()
        val = _objective(cand)
        if val < best_val:
            best_val, best_a = val, cand.copy()
    return best_a, best_val


# ----------------------------------------------------------------------
# Exponential‑gradient polishing on the exact objective
# ----------------------------------------------------------------------
def _exp_gradient_polish(a0: np.ndarray,
                         n: int,
                         deadline: float,
                         start_time: float,
                         best_a: np.ndarray,
                         best_val: float,
                         rng: np.random.Generator,
                         max_iters: int = 300_000) -> tuple[np.ndarray, float]:
    """
    Mirror‑descent (exponential update) on the true objective.
    """
    a = a0.copy()
    cur_val = _objective(a)
    best_local_a, best_local_val = a.copy(), cur_val

    for it in range(max_iters):
        now = time.time()
        if now >= deadline:
            break

        b = _full_convolution(a)
        M = b.max()
        max_idxs = np.where(b == M)[0]

        # sub‑gradient: average of the gradients of all maximal entries
        grad = np.zeros_like(a)
        for k in max_idxs:
            idx = k - np.arange(n)
            mask = (idx >= 0) & (idx < n)
            grad[mask] += 2.0 * a[idx[mask]]
        grad /= len(max_idxs)

        # step‑size schedule – aggressive early, vanishing later
        progress = (now - start_time) / (deadline - start_time)
        eta = 0.35 * (1.0 - progress) + 1e-4 * progress

        # multiplicative (exponential) update + projection onto simplex
        a = a * np.exp(-eta * grad)
        a = _project_simplex(a)

        new_val = _objective(a)
        if new_val < best_local_val - 1e-12:
            best_local_val, best_local_a = new_val, a.copy()
            print(f"[ExpG] itr {it:06d} new best = {best_local_val:.6f}")

        # occasional random jitter to escape plateaus
        if it % 5000 == 0 and rng.random() < 0.07:
            a = np.maximum(a + rng.normal(scale=0.010, size=n), 0.0)
            a = _project_simplex(a)

    if best_local_val < best_val:
        best_val, best_a = best_local_val, best_local_a.copy()
        print(f"[ExpG] updated global best = {best_val:.6f}")

    return best_a, best_val


# ----------------------------------------------------------------------
# Optimise the two‑parameter Beta family (p,q) with L‑BFGS on the smooth surrogate
# ----------------------------------------------------------------------
def _optimize_beta_params(n: int,
                          init_logp: float,
                          init_logq: float,
                          deadline: float,
                          start_time: float,
                          eps: float = 1e-6,
                          max_iter: int = 800) -> tuple[np.ndarray, float]:
    """
    Optimise log‑parameters (log p, log q) of the discrete Beta shape.
    Returns the normalised vector and its exact objective.
    """
    def beta_vec(logpq):
        logp, logq = logpq
        p = math.exp(logp)
        q = math.exp(logq)
        i = np.arange(1, n + 1, dtype=np.float64)
        # compute in log‑space to avoid overflow for tiny p,q
        log_a = (p - 1.0) * np.log(i) + (q - 1.0) * np.log(n - i + 1)
        log_a -= np.max(log_a)
        a = np.exp(log_a)
        a_sum = a.sum()
        if a_sum == 0.0:
            a = np.full(n, 1.0 / n)
        else:
            a /= a_sum
        return a

    def fun(logpq):
        a = beta_vec(logpq)
        smooth_val, _ = _smooth_max_and_grad(a, eps)
        return 2.0 * n * smooth_val

    def jac(logpq):
        a = beta_vec(logpq)
        smooth_val, grad_a = _smooth_max_and_grad(a, eps)

        # ∂a/∂logp = a * (log(i) - E[log(i)]), similarly for q
        i = np.arange(1, n + 1, dtype=np.float64)
        log_i = np.log(i)
        log_ni = np.log(n - i + 1)

        avg_log_i = np.dot(a, log_i)
        avg_log_ni = np.dot(a, log_ni)

        da_dlogp = a * (log_i - avg_log_i)
        da_dlogq = a * (log_ni - avg_log_ni)

        # chain rule: ∂f/∂logp = grad_a·da/dlogp , etc.
        grad_logp = np.dot(grad_a, da_dlogp)
        grad_logq = np.dot(grad_a, da_dlogq)
        return np.array([grad_logp, grad_logq])

    x0 = np.array([init_logp, init_logq])
    if time.time() >= deadline - 0.5:
        # Time exhausted – fall back to the unoptimised Beta shape
        a = beta_vec(x0)
        return a, _objective(a)

    opts = {"maxiter": max_iter, "ftol": 1e-12, "gtol": 1e-12}
    try:
        res = minimize(fun, x0, jac=jac, method="L-BFGS-B", bounds=[(None, None), (None, None)], options=opts)
    except Exception as exc:  # pragma: no cover
        print("[Beta‑opt] minimise raised:", exc)
        a = beta_vec(x0)
        return a, _objective(a)

    a_opt = beta_vec(res.x)
    return a_opt, _objective(a_opt)

        log_a = (p - 1.0) * np.log(i) + (q - 1.0) * np.log(n - i + 1)
        a = np.exp(log_a - np.max(log_a))
        a /= a.sum()
        candidates.append((_objective(a), a))

    # keep the best few for the next phase
    candidates.sort(key=lambda t: t[0])
    top_k = min(10, len(candidates))
    best_val, best_a = candidates[0][0], candidates[0][1].copy()
    print(f"[Init] best after sweep: value={best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase A – L‑BFGS on smooth‑max (multiple restarts)
    # ------------------------------------------------------------------
    phase_a_deadline = start_time + 0.40 * budget_s
    eps_start = 5e-1
    eps_end = 1e-10

    while time.time() < phase_a_deadline and time.time() < deadline:
        prog = (time.time() - start_time) / (phase_a_deadline - start_time)
        eps = eps_start * (eps_end / eps_start) ** prog

        for idx in range(top_k):
            if time.time() >= phase_a_deadline:
                break
            start_vec = candidates[idx][1]

            # L‑BFGS from the pure candidate
            best_a, best_val = _lbfgs_optimize(start_vec, n, deadline,
                                                start_time, best_a, best_val,
                                                eps=eps, max_iter=1200)

            # a few jittered restarts
            if rng.random() < 0.25:
                jitter = start_vec + rng.normal(scale=0.015, size=n)
                jitter = np.maximum(jitter, 0.0)
                jitter /= jitter.sum()
                best_a, best_val = _lbfgs_optimize(jitter, n, deadline,
                                                    start_time, best_a, best_val,
                                                    eps=eps, max_iter=800)

            # blend with uniform after each successful improvement
            best_a, best_val = _blend_with_uniform(best_a, n, best_val)

    # ------------------------------------------------------------------
    # Phase B – Low‑dimensional Beta parameter optimisation
    # ------------------------------------------------------------------
    beta_phase_deadline = start_time + 0.55 * budget_s
    if time.time() < beta_phase_deadline:
        # use the best candidate as a warm‑start for (log p,log q)
        init_logp = np.log(2.0)   # reasonable starting point
        init_logq = np.log(2.0)
        a_beta, val_beta = _optimize_beta_params(
            n, init_logp, init_logq, beta_phase_deadline, start_time,
            eps=5e-2, max_iter=600)
        if val_beta < best_val:
            best_a, best_val = a_beta, val_beta
            print(f"[Beta‑opt] improved to {best_val:.6f}")

        # try a few random starts for (p,q)
        for _ in range(6):
            if time.time() >= beta_phase_deadline:
                break
            logp0 = rng.uniform(-4.0, 2.0)
            logq0 = rng.uniform(-4.0, 2.0)
            a_tmp, val_tmp = _optimize_beta_params(
                n, logp0, logq0, beta_phase_deadline, start_time,
                eps=5e-2, max_iter=500)
            if val_tmp < best_val:
                best_a, best_val = a_tmp, val_tmp
                print(f"[Beta‑opt] random start improved to {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase C – Exponential‑gradient polishing on the exact objective
    # ------------------------------------------------------------------
    phase_c_deadline = start_time + 0.90 * budget_s
    best_a, best_val = _exp_gradient_polish(best_a, n,
                                            deadline=phase_c_deadline,
                                            start_time=start_time,
                                            best_a=best_a,
                                            best_val=best_val,
                                            rng=rng,
                                            max_iters=250_000)
    best_a, best_val = _blend_with_uniform(best_a, n, best_val)

    # ------------------------------------------------------------------
    # Phase D – Final short L‑BFGS with ultra‑small ε
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = _lbfgs_optimize(best_a, n, deadline,
                                            start_time, best_a, best_val,
                                            eps=1e-12, max_iter=800)

    # ------------------------------------------------------------------
    # Final secure evaluation
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[Final] reported score = {final_score:.6f}")
    except Exception as exc:   # pragma: no cover
        print("[Final] evaluate_sequence raised:", exc)

    # Return a plain list of floats
    return best_a.tolist()
