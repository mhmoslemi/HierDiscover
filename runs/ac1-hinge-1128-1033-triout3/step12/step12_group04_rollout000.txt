assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0,
\]

where `(a*a)` is the linear self‑convolution of the step‑function `a`.  
Because the objective is invariant under a global scaling of `a`, we may fix  

\[
\sum_i a_i = 1 .
\]

The problem is then  

\[
\min_{a\ge 0,\;\sum a_i=1}\; \max_k (a*a)_k .
\]

The “max’’ makes the objective non‑smooth.  
Instead of the plain sub‑gradient method used previously we introduce a **smooth
approximation of the maximum** by a soft‑max (log‑sum‑exp) with a temperature
parameter α.  For a given `a`

```
c = a * a                         # full convolution (length 2·n‑1)
w_i = exp( α·(c_i - max(c)) )     # soft‑max weights, Σ w_i = 1
```

The smoothed objective is `Σ w_i·c_i`; its gradient is a weighted sum of the
individual gradients of the convolution entries.  Using the identity  

\[
∂(a*a)_k/∂a_i = 2·a_{k-i},
\]

the gradient can be written as a **cross‑correlation** of `a` and the weight
vector `w`.  All convolutions are performed with FFTs, giving an `O(n log n)`
per iteration cost.

To stay on the simplex we employ a **multiplicative (exponentiated‑gradient)
update**, which automatically preserves non‑negativity, followed by a simple
renormalisation.  The temperature α is increased slowly (so the optimisation
starts with a very smooth objective and ends close to the true max), while the
step size η is exponentially decayed.  If the search stalls we inject a tiny
Gaussian jitter and keep the best sequence seen so far.

After the main search we perform a short **sub‑gradient refinement** (the same
as in the reference code) on the best candidate, using any remaining time.
Finally we call the provided `evaluate_sequence` once and return the best
sequence.

The whole routine respects the 1000 s budget, never uses closures, and only
relies on `numpy` (plus standard library modules).

"""
Exponentiated‑gradient optimiser with soft‑max smoothing for the L∞
self‑convolution problem.

*   Uses a smoothed max (log‑sum‑exp) with a temperature α that grows
    during the run.
*   Gradient of the smoothed objective is computed via a single FFT‑based
    correlation.
*   Updates are multiplicative (a_i ← a_i·exp(-η·g_i)) followed by
    renormalisation onto the probability simplex.
*   Periodic Gaussian jitter helps escaping plateaus.
*   A brief sub‑gradient refinement is performed on the best candidate
    before the final call to ``evaluate_sequence``.
"""

import time
import numpy as np


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x (used for FFT padding)."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """
    Linear convolution of a real vector with itself.
    Length of the result is 2·len(x)‑1.
    """
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    # Implementation of Algorithm 1 from
    #   Duchi et al., “Efficient Projections onto the L1‑Ball for
    #   Learning in High Dimensions”, ICML 2008.
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = ind[cond][-1]
        theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def fast_objective(a: np.ndarray, n: int) -> float:
    """Fast evaluation of 2·n·max(a*a) (sum(a) is assumed to be 1)."""
    conv = _full_convolution(a)
    return 2.0 * n * conv.max()
