Propose a non‑negative step function that (empirically) improves the bound

    O = 2·n·max(conv(a,a)) / (sum(a))² .

The algorithm follows three phases:

1. **Diverse start points** – reuse the previous best (if available),
   several smooth Beta shapes and a handful of Dirichlet draws.
2. **Soft‑max Adam optimisation** – the vector is optimised in the log‑domain
   using an Adam update.  The “soft‑max’’ temperature α grows from ≈1 to a few
   thousand, turning the smooth approximation of the max into the true max.
3. **Heavy‑weight entropy‑mirror polishing** – after the Adam phase the best
   candidate is refined by many steps of exponentiated‑gradient (mirror) descent
   on the exact max entry of the self‑convolution.  The step‑size η decays
   linearly, and a jitter is injected whenever progress stalls.

The routine respects a 1000 s budget, prints progress and finally returns the
best sequence it found.  All values are forced to be non‑negative; the final
score is obtained with the provided ``evaluate_sequence`` function.

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based full convolution (linear, not circular)
# ----------------------------------------------------------------------
def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Linear convolution of a vector with itself (full length 2·len(x)-1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _full_convolution_two(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution of two different vectors (full length n+m‑1)."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Entropy‑mirror descent on the exact max entry of the self‑convolution
# ----------------------------------------------------------------------
def _max_refine(a: np.ndarray,
                steps: int = 20000,
                eta_start: float = 0.8,
                eta_end: float = 0.05) -> np.ndarray:
    """Exponentiated‑gradient (mirror) descent on the true max entry."""
    n = a.shape[0]
    a = a.copy()
    for t in range(steps):
        conv = _full_convolution(a)
        k = int(conv.argmax())                     # index of current max
        # sub‑gradient of max entry w.r.t a
        g = np.zeros_like(a)

        lo = max(0, k - (n - 1))
        hi = min(k, n - 1)
        if lo <= hi:
            idx = np.arange(lo, hi + 1, dtype=int)
            g[idx] = 2.0 * a[k - idx]

        # linear decay of step size
        eta = eta_start * (1.0 - t / steps) + eta_end * (t / steps)
        a = a * np.exp(-eta * g)

        # normalise to keep the vector a probability distribution
        s = a.sum()
        if s > 0.0:
            a /= s
        else:
            a.fill(1.0 / n)

    return a
