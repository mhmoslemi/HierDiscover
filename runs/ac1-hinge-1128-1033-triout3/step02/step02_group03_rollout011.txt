Propose a step‑function (non‑negative heights) that minimises

        M = 2·n·max(conv(a, a)) / (sum(a)**2)

Algorithm
---------

* **Parameterisation** – a is stored as a probability vector `p` (sum(p)=1)
  and is obtained from an unconstrained log‑it vector `logits` via a
  soft‑max.  This automatically respects the non‑negativity and the simplex
  constraints.

* **Phase 1 – Smoothed Adam on the simplex**  
  We minimise a smooth approximation of `max(conv)` using the
  log‑sum‑exp (soft‑max) with a temperature `alpha`.  The temperature is
  increased slowly (`alpha *= 1.01`) so the problem gradually turns from a
  smooth to the true max‑objective.  An Adam optimiser on the logits
  (with bias‑correction) provides an adaptive step‑size and momentum.
  Periodic Gaussian jitter on the logits helps escaping shallow plateaus.
  The best exact score seen so far is stored.

* **Phase 2 – Exact sub‑gradient with exponentiated updates**  
  Starting from the best distribution found in Phase 1 we switch to the
  true non‑smooth objective.  For the current active convolution index
  `k_max` we compute the sub‑gradient `∇max(conv)` analytically and apply a
  multiplicative (mirror‑descent) update `p ← p·exp(−η∇)`.  The step‑size
  `η` decays slowly; occasional jitter on `p` is added.

* **Final random sampling** – any remaining time is spent drawing cheap
  Dirichlet‑like random points that might improve the record.

* **Result** – the best probability vector is returned as a plain list;
  `evaluate_sequence` will clip it to `[0,1000]` and compute the score.

The whole routine respects the 1000 s budget, uses only NumPy and the

        sub_it += 1

        conv = np.convolve(p, p)
        k_max = int(np.argmax(conv))

        # ---- sub‑gradient of the true max (only the active index) ----
        grad = np.zeros_like(p)
        i_start = max(0, k_max - (n - 1))
        i_end = min(k_max, n - 1)
        if i_start <= i_end:
            idx_range = np.arange(i_start, i_end + 1)
            grad[i_start:i_end + 1] = 2.0 * p[k_max - idx_range]

        # ---- exponentiated (mirror‑descent) update ----
        p = p * np.exp(-eta * grad)
        s = p.sum()
        if s == 0.0:
            p = np.full(n, 1.0 / n)
        else:
            p = p / s

        # occasional jitter to avoid tiny cycles
        if sub_it % 750 == 0:
            p = p * np.exp(rng.normal(scale=0.001, size=n))
            p = p / p.sum()

        # decay learning‑rate
        eta *= eta_decay

        # evaluate exact score
        cur_score = 2.0 * n * np.max(np.convolve(p, p))
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_seq = p.copy()
            no_improve_2 = 0
            total_iters = it + sub_it
            print(f"[Phase 2] iter {total_iters:6d} – new best M={best_score:.6f}")
        else:
            no_improve_2 += 1

        if best_score <= 1.503:
            break

        # restart if no improvement for a long while
        if no_improve_2 >= 3000 and best_seq is not None:
            p = best_seq + rng.normal(scale=0.003, size=n)
            p = np.clip(p, 0.0, None)
            p = p / p.sum()
            no_improve_2 = 0

    # ----------------------------------------------------------------------
    # 7. Final cheap random sampling with any remaining time
    # ----------------------------------------------------------------------
    while time.time() < deadline:
        trial = rng.random(n)
        trial = trial / trial.sum()
        cur_score = 2.0 * n * np.max(np.convolve(trial, trial))
        if cur_score < best_score:
            best_score = cur_score
            best_seq = trial.copy()
            print(f"[Random] new best M={best_score:.6f}")
        # stop the tiny loop if we are very close to the deadline
        if time.time() + 0.01 > deadline:
            break

    # ----------------------------------------------------------------------
    # 8. Return the best sequence (plain Python list)
    # ----------------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)

    result = np.clip(best_seq, 0.0, 1000.0).tolist()
    print(f"Best M achieved: {best_score:.6f}")
    return result
