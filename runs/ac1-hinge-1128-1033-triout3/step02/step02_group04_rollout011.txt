assistantfinal**Solution Overview**

The score of a sequence `a` (after the internal clamping of `evaluate_sequence`) is  

\[
\text{score}(a)=\frac{2n\;\max\limits_{k}(a*a)_k}{(\sum_i a_i)^2},
\qquad (a*a)_k=\sum_i a_i\,a_{k-i}.
\]

All admissible sequences can be rescaled to have unit sum, therefore we
optimise

\[
\min_{a\ge 0,\; \sum a =1}
\; 2n\; \max_k (a*a)_k .
\]

The problem is non‑convex.  Two complementary ideas work well in practice:

1. **Smoothed‑max gradient descent (Adam)** – a fast first‑order method
   that drives the maximum of the self‑convolution down.
2. **Linear‑programming lift** – after a few gradient steps we solve the
   LP  

   \[
   \max_{b\ge 0}\; \mathbf 1^\top b
   \quad\text{s.t.}\quad a * b \le M\mathbf 1,
   \]

   where `M` is the current maximal convolution value.
   The LP produces a new distribution `b` that spreads the mass as much
   as possible without increasing the peak.  Mixing `b` into the current
   iterate strictly improves the objective.

The driver runs the Adam optimiser, periodically calls the LP step and
finishes with a short pairwise‑swap local search.  Multiple restarts
are performed while the time budget allows; the best sequence seen so
far is returned.

The implementation uses only `numpy` and `scipy.optimize.linprog`
(the latter is available in the execution environment).  All
operations stay inside the 1000 s budget, and every intermediate vector
is projected onto the probability simplex to keep the constraints
`a_i ≥ 0, Σ a_i = 1`.

"""
Propose a low‑objective step‑function.

The algorithm consists of three phases:

1. Adam optimisation on a smooth log‑sum‑exp approximation of the
   max of the self‑convolution (keeps iterates on the simplex).
2. A few linear‑programming lifts:
      maximise   Σ b_j   subject to   a * b ≤ M   and   b ≥ 0
   (M is the current max‑convolution).  The LP spreads the mass as far
   as possible without increasing the peak.  The solution is mixed into
   the current iterate.
3. Final pairwise‑swap hill‑climbing.

All phases respect the time budget (default 1000 s).  The best sequence
found is returned as a plain list of floats; it will be clipped to
[0, 1000] by `evaluate_sequence`.
"""

import time
import numpy as np
from scipy.optimize import linprog


# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex.
# ----------------------------------------------------------------------
def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project v onto {x | x_i ≥ 0, Σ x_i = 1}."""
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    rho = np.where(u - cssv / ind > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Convolution utilities (FFT based, length suitable for all needed ops)
# ----------------------------------------------------------------------
def _fft_len(n: int) -> int:
    """Next power‑of‑two that can hold a convolution of length 3·n‑2."""
    return 1 << ((3 * n - 2).bit_length())


def _self_convolution(p: np.ndarray, m_fft: int) -> np.ndarray:
    """Return the linear self‑convolution p∗p (length 2·n‑1)."""
    p_fft = np.fft.rfft(p, n=m_fft)
    conv = np.fft.irfft(p_fft * p_fft, n=m_fft)[: 2 * len(p) - 1]
    return conv


def _convolution_matrix(p: np.ndarray) -> np.ndarray:
    """
    Build the matrix A such that  (p * b)[ℓ] = (A @ b)[ℓ].
    A has shape (2·n‑1, n) and contains the appropriate shifted copies
    of p.  Used only inside the LP step (few calls, O(n²) is fine).
    """
    n = len(p)
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=float)
    # column i contributes p[ℓ‑i] for ℓ ∈ [i , i+n‑1]
    for i in range(n):
        A[i : i + n, i] = p[: rows - i]
    return A

    p = best_p.copy()
    cur_score, _, _ = current_state(p)
    swap_trials = 5000
    for _ in range(swap_trials):
        if time.time() >= deadline:
            break
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue
        eps = 1e-5 * rng.random()    # very small mass transfer
        if p[i] <= eps:
            continue
        new_p = p.copy()
        new_p[i] -= eps
        new_p[j] += eps
        new_score, _, _ = current_state(new_p)
        if new_score < cur_score:
            p = new_p
            cur_score = new_score
            if cur_score < best_score:
                best_score = cur_score
                best_p = p.copy()
                print(f"[Swap] improved to {best_score:.6f}")

    print(f"[Done] final best score {best_score:.6f}")
    # Clip to the range enforced by evaluate_sequence and return as list
    return np.clip(best_p, 0.0, 1000.0).tolist()
