propose_candidate
-----------------

Search algorithm for the step‑function optimisation problem.

The objective is
    O(a) = 2·n·max_k (a * a)[k] / (sum a)^2,
with a_i ≥ 0.  Because the objective is homogeneous we fix
    sum a_i = 1  (simplex) and minimise 2·n·max_k (a*a)[k].

The code uses an exponentiated‑gradient ( mirror‑descent on the simplex )
with the exact sub‑gradient of the *max* of the self‑convolution.
The sub‑gradient is obtained from the active set of indices where the
convolution attains its maximum; a correlation computed by FFT gives the
gradient in O(n log n) time.

To avoid getting trapped in local minima the method performs
periodic Gaussian jitter, aggressive restarts when progress stalls,
and a final cheap local “pairwise move” refinement.
The routine works with the provided global variable `height_sequence_1`
as a warm start, otherwise it creates a random initial distribution.
All operations stay on the probability simplex, so the returned list can be
directly fed to `evaluate_sequence`.

The whole search respects the given time budget (default 1000 s) and
prints intermediate scores for monitoring.

import numpy as np
import time
from typing import List

# ----------------------------------------------------------------------
# Helper: FFT based convolution utilities (same size for all calls)
# ----------------------------------------------------------------------
def _conv_self(p: np.ndarray, m_fft: int) -> np.ndarray:
    """Return the full self‑convolution of p (length 2·n‑1)."""
    p_fft = np.fft.rfft(p, n=m_fft)
    conv = np.fft.irfft(p_fft * p_fft, n=m_fft)[: 2 * len(p) - 1]
    return conv


def _gradient_from_active(p: np.ndarray, active_mask: np.ndarray,
                          m_fft: int) -> np.ndarray:
    """
    Compute the sub‑gradient of max_k (p*p)[k] w.r.t. p.
    active_mask is a binary array of length 2·n‑1 marking the
    positions where the convolution equals its maximum.
    """
    n = len(p)

    # weight each active index equally (any convex combination works)
    w = active_mask.astype(float)
    if w.sum() == 0:
        # should never happen – fall back to a single maximum index
        w[np.argmax(_conv_self(p, m_fft))] = 1.0
    else:
        w /= w.sum()

    # correlation p * w_rev  (size 3·n‑2)
    p_fft = np.fft.rfft(p, n=m_fft)
    w_rev = w[::-1]
    w_rev_fft = np.fft.rfft(w_rev, n=m_fft)
    corr_full = np.fft.irfft(p_fft * w_rev_fft, n=m_fft)[: 3 * n - 2]

    # map correlation to gradient (see derivation in analysis)
    idx = 2 * n - 2 - np.arange(n)          # 0 … n‑1
    grad = 2.0 * corr_full[idx]
    return grad
