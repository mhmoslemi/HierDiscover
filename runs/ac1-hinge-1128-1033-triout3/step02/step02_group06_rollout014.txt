Iterative linear‑programming refinement of the classical central‑binomial
(step‑function) construction.

The central‑binomial coefficients
    b_k = C(2k, k) / 4**k
have a self‑convolution that is identically 1, giving the analytic bound
π/2 ≈ 1.570796 for the evaluation function.
The LP‑based update (inspired by the method from the statement) tries to
increase the ℓ₁‑norm of a new vector `g` while keeping the mixed
convolution `f * g` below the current maximum `M = max(f*f)`.  After a
convex combination `f ← (1–t)·f + t·g` the maximum of `f*f` cannot grow,
and in practice it decreases, producing a better score.

The routine builds a convolution matrix `A` (size (2n‑1)×n) such that
`A @ g = f * g`.  A linear program

    maximise   1·g                (i.e. maximise sum(g))

        # recurrence  b_{k} = b_{k-1} * (2k-1) / (2k)
        cur = cur * (2 * k - 1) / (2 * k)
        b[k] = cur
    return b

            # ---------------------- build sparse convolution matrix ----------------------
            # A[k, i] = f[k-i]  if 0 ≤ k-i < n, else 0.
            rows = np.repeat(np.arange(n), n)          # column index i repeated n times
            cols = np.tile(np.arange(n), n)            # row offset j repeated for each i
            data = np.take(f, cols)                    # f_j for each (i,j)
            row_idx = rows + cols                      # k = i + j
            A = sp.csr_matrix((data, (row_idx, cols)), shape=(2 * n - 1, n))

            # --------------------------- linear program ---------------------------------
            c = -np.ones(n)                             # minimise -sum(g)  → maximise sum(g)
            b_ub = np.full(2 * n - 1, M)               # each (f*g)_k ≤ M
            bounds = [(0, None)] * n

            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                          method='highs', options={'presolve': True})

            if not res.success:
                print(f"[lp] iteration {it}: linprog failed – {res.message}")
                break

            g0 = res.x
            sum_g0 = np.sum(g0)

            # The LP guarantees sum_g0 ≥ target_sum (otherwise the current f would not be optimal)
            if sum_g0 <= 0:
                print("[lp] zero sum obtained – aborting LP stage")
                break

            # Rescale to keep the prescribed normalisation
            g = g0 * (target_sum / sum_g0)

            # Convex combination update
            f_new = (1 - t) * f + t * g
            f_new = np.clip(f_new, 0.0, 1000.0)   # respect evaluator's clipping

            # Evaluate
            cur_score = _score(f_new)
            print(f"[lp] it={it:02d}  M={M:.6f}  sum_g0={sum_g0:.6f}  score={cur_score:.9f}")

            if cur_score < best_score:
                best_score = cur_score
                best_seq = f_new.copy()
                print(f"[improve] new best {best_score:.9f} at iteration {it}")

            # Termination test – if improvement is tiny, stop early
            if abs(cur_score - best_score) < 1e-7:
                break

            f = f_new

    # ------------------------------------------------------------------
    # Phase 3 – tiny stochastic hill‑climb (quick, cheap, always safe)
    # ------------------------------------------------------------------
    cur_seq = best_seq.copy()
    cur_score = best_score
    sigma = 0.03                # relative perturbation magnitude
    no_improve = 0
    max_no_improve = 2000

    while time.time() < deadline and no_improve < max_no_improve:
        idx = np.random.randint(n)
        old = cur_seq[idx]
        # Gaussian perturbation proportional to current magnitude
        delta = np.random.randn() * sigma * max(old, 1e-12)
        new_val = max(0.0, old + delta)

        cand = cur_seq.copy()
        cand[idx] = new_val

        cand_score = _score(cand)
        if cand_score < cur_score:
            cur_seq, cur_score = cand, cand_score
            no_improve = 0
            if cand_score < best_score:
                best_score = cand_score
                best_seq = cand.copy()
                print(f"[hill] improve to {best_score:.9f} (idx={idx})")
        else:
            no_improve += 1

    # final safety conversion – plain Python floats, non‑negative
    best_seq = [float(max(0.0, x)) for x in best_seq]
    print(f"[final] best score = {best_score:.9f}, length = {len(best_seq)}")
    return best_seq
