propose_candidate
-----------------

Search for a step‑function (list of non‑negative heights) whose
evaluation score 

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

is as small as possible.

The algorithm starts from the analytically optimal “constant‑convolution”
coefficients a_k = C(2k, k) / 4**k (the binomial‑coefficient sequence).
These coefficients give a max‑convolution of exactly 1 on the first n
indices and a score that converges to π/2 ≈ 1.570796 from above.

From that seed we perform a simple stochastic local search (random
perturbations with greedy acceptance) under the given time budget.
Any improvement over the seed is kept.  The search works directly with
the provided ``evaluate_sequence`` function, so the true (exact) score
is used for acceptance.  The routine respects the 1000 s wall‑clock
limit and returns the best sequence it has found.

The search is deliberately lightweight (no external solvers) but
typically discovers modest improvements for moderate lengths while never
exceeding the time budget.

import random
import numpy as np

def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Return a list of non‑negative step heights that (hopefully) improves
    on the constant‑convolution construction.

    Parameters
    ----------
    seed : int, optional
        Random seed for reproducibility.
    budget_s : int, optional
        Wall‑clock budget in seconds.
    **kwargs : dict

    """

    # ------------------------------------------------------------------

        score = evaluate_sequence(coeffs.tolist())
