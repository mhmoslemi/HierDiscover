Propose a step‑function (non‑negative vector) that minimises
`evaluate_sequence`.  The algorithm works in three stages

1. **Broad exploration** – generate a few hundred diverse candidates
   (uniform, analytic “sqrt” series, power‑law, exponential and random
   Dirichlet draws) and keep the best one seen so far.

2. **Smoothed‑gradient optimisation** – keep the current best vector,
   represent it by log‑coordinates (soft‑max), and minimise a
   smooth approximation of the max‑convolution using Adam.  The smooth
   max is realised by a log‑sum‑exp with a temperature that grows from
   a few to a large value, turning the problem from a smooth one into
   the original max‑convolution objective.

3. **Fine‑grained simulated annealing** – starting from the gradient
   result, repeatedly move a random amount of mass from one index to
   another.  Moves are accepted with a Metropolis rule using a linearly
   decreasing temperature.  The best vector ever observed (according to
   the fast FFT‑based score) is finally checked with the official
   `evaluate_sequence` and returned.

All heavy work (convolution, gradients) uses FFTs (O(n log n)).
Only when a new global best is discovered is the slow
`evaluate_sequence` called.  The routine respects the supplied
`budget_s` time limit and works on a single CPU.
"""

import math
import numpy as np

# ----------------------------------------------------------------------
# Helper: fast evaluation (identical to evaluate_sequence but without
# clipping and sum‑checks).  Returns the exact value of the objective
# for a vector that already sums to 1 and stays inside the clipping
# range.
# ----------------------------------------------------------------------
def _fast_score(a: np.ndarray, fft_len: int) -> float:
    """2·n·max(a∗a) using an FFT of length fft_len."""
    n = a.shape[0]
    fa = np.fft.rfft(a, fft_len)
    conv = np.fft.irfft(fa * fa, fft_len)[: 2 * n - 1]
    return 2.0 * n * conv.max()


# ----------------------------------------------------------------------
# Analytic start – coefficients of (1‑x)^(-1/2) (the classic “sqrt”
# series) normalised to sum to 1.
# ----------------------------------------------------------------------
def _sqrt_series(n: int) -> np.ndarray:
    w = np.empty(n, dtype=np.float64)
    w[0] = 1.0
    for k in range(1, n):
        w[k] = w[k - 1] * (2.0 * (k - 1) + 1.0) / (2.0 * k)
    w /= w.sum()
    return w


# ----------------------------------------------------------------------
# Candidate generators for the exploratory phase.
# ----------------------------------------------------------------------
def _candidate_power_law(n: int, p: float) -> np.ndarray:
    """a_i ∝ (i+1)^{-p}."""
    idx = np.arange(1, n + 1, dtype=np.float64)
    a = idx ** (-p)
    a /= a.sum()
    return a


def _candidate_exponential(n: int, lam: float) -> np.ndarray:
    """a_i ∝ exp(-lam * i)."""
    idx = np.arange(n, dtype=np.float64)
    a = np.exp(-lam * idx)
    a /= a.sum()
    return a


def _candidate_mix(a: np.ndarray, b: np.ndarray, t: float) -> np.ndarray:
    """Convex combination (1‑t)·a + t·b, renormalised."""
    mix = (1.0 - t) * a + t * b
    mix /= mix.sum()
    return mix
