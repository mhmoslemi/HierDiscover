Implementation details for projection onto simplex:

def project_simplex(v):
    # ensure v non-negative and sum 1
    # Using algorithm from https://doi.org/10.1007/s10107-004-0559-0
    # Input v (numpy array). Output with sum 1, nonneg.
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w

"""
Propose a candidate sequence for the evaluation function.

Algorithm
---------
We treat the normalized sequence as a probability distribution (sum = 1).
The objective to minimise is 2*n*max(conv(a,a))/sum(a)^2, which is
scale‑invariant.  Hence we minimise ``max(conv(a,a))`` under the simplex
constraint a_i ≥ 0, Σ a_i = 1.

We use a smooth approximation of the max‑operator:
    L(a) = (1/β)·log( Σ_k exp( β·c_k ) ),   where c = a*a (auto‑convolution)
For large β this is close to max(c).  Its gradient is
    ∂L/∂a_i = 2·Σ_k w_k·a_{k-i},
with w_k = exp(β·c_k) / Σ_j exp(β·c_j).  The gradient can be obtained
by a single FFT‑based convolution.

At each iteration we:
1. compute the auto‑convolution c,
2. build the weight vector w (exponential emphasis of large entries),
3. obtain the gradient via FFT,
4. take a small step opposite to the gradient,
5. project the result back onto the probability simplex.

The learning rate decays slowly; occasional random perturbations are
added to escape possible stagnation.  The best sequence encountered is
returned.

The method works directly with the provided ``evaluate_sequence`` and
needs no external files or network access.
"""

import numpy as np
import time
from scipy import optimize  # only to keep the import present; not used here

def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of a vector onto the probability simplex."""
    # Based on the algorithm by Duchi et al. (2008)
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    # Find the last index where the condition holds
    rho = np.where(u - cssv / ind > 0)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w
