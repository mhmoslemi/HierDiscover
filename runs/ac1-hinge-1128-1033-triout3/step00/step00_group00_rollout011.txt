We treat the step heights as a probability vector `a` (all entries non‑negative and sum = 1).  
For a fixed length `n` the evaluation reduces to  

```
E(a) = 2·n·max( conv(a,a) )
```

because the denominator `sum(a)^2` equals 1.  
The goal is to make the self‑convolution as flat as possible – i.e. to lower its
maximum value.

The algorithm is a *simulated‑annealing* search that works directly on the
vector `a`:

1. **Initialisation** – start from a smooth “edge heavy’’ shape  
   `a_i ∝ 1‑sin(π·i/(n‑1))` and normalise it.
2. **Move generation** – two kinds of moves are used  
   *random move*: pick two distinct indices `i, j` and transfer a random
   amount `δ` from `i` to `j`;  
   *targeted move*: locate the index `k` where the current convolution is
   maximal, pick the pair `(i, j=k‑i)` that contributes most to this peak
   and move a fraction of `a_i` away from it.
3. **Fast update** – when performing a move we update the convolution
   `c = conv(a,a)` in *O(n)* time instead of recomputing it from scratch.
   The update formulas follow from the bilinear definition of the
   convolution.
4. **Acceptance** – a move that lowers `E` is always accepted.
   Worse moves are accepted with probability `exp(-(E_new‑E)/T)`,
   where the temperature `T` decreases linearly from `0.1` to `1e‑4`.
5. **Best‑ever tracking** – the best vector seen so far (`best_a`,
   `best_E`) is stored and returned at the end.

The whole search runs for the allotted time (≈ 1000 s) and finally returns
the best sequence found.  All numbers are non‑negative, the sum is well
above the 0.01 safety limit, and each entry stays far below the 1000 cap,
so `evaluate_sequence` will accept the result.

```python
"""
Simulated‑annealing search for a step function with a flat self‑convolution.
The objective is  2·n·max(conv(a,a))  (a is normalised to sum = 1).
Fast O(n) updates of the convolution are used, and moves are either random
or targeted at the current maximal convolution entry.
"""

import numpy as np
import time
import math

# ----------------------------------------------------------------------
# Helper: fast convolution update when moving a mass δ from index i to j
# ----------------------------------------------------------------------
def apply_move(a: np.ndarray, conv: np.ndarray, i: int, j: int, delta: float):
    """
    Return new (a, conv) after moving `delta` from a[i] to a[j].
    a – 1‑D array of length n, sum(a) = 1
    conv – convolution a*a (length 2n‑1)
    i, j – distinct indices, 0 ≤ i,j < n
    delta – 0 < delta ≤ a[i]
    """
    n = a.shape[0]
    a_i = a[i]
    a_j = a[j]

    di = -delta            # change at i
    dj = +delta            # change at j

    # new vector (exact, sum stays 1)
    a_new = a.copy()
    a_new[i] = a_i - delta
    a_new[j] = a_j + delta

    # fast convolution update
    conv_new = conv.copy()

    # indices other than i and j
    idx = np.arange(n)
    mask = (idx != i) & (idx != j)
    q = idx[mask]                # all other positions
    a_q = a[q]

    # contributions of the changed entries to all sums
    conv_new[i + q] += 2.0 * di * a_q    # (i, q) and (q, i)
    conv_new[j + q] += 2.0 * dj * a_q    # (j, q) and (q, j)

    # self‑pair contributions (i,i) and (j,j)
    conv_new[2 * i] += 2.0 * di * a_i + di * di
    conv_new[2 * j] += 2.0 * dj * a_j + dj * dj

    # cross term (i,j) and (j,i)
    cross = i + j
    conv_new[cross] += 2.0 * (a_i * dj + a_j * di + di * dj)

    return a_new, conv_new


# ----------------------------------------------------------------------
# Helper: produce a targeted move focusing on the current maximum of conv
# ----------------------------------------------------------------------
def targeted_move(a: np.ndarray, conv: np.ndarray):
    """
    Choose indices (i, j) that are most responsible for the current
    maximal convolution entry and a random destination j'.
    Returns (src, dst).
    """
    n = a.shape[0]
    k = int(np.argmax(conv))                     # position of the current peak

    # feasible i so that both i and k-i lie inside the vector
    i_min = max(0, k - (n - 1))
    i_max = min(n - 1, k)
    i_candidates = np.arange(i_min, i_max + 1, dtype=int)
    j_candidates = k - i_candidates

    # contribution of each unordered pair to the peak
    contrib = a[i_candidates] * a[j_candidates]
    # pick the pair with the largest product
    src = int(i_candidates[np.argmax(contrib)])

    # pick a random destination different from src
    dst = np.random.randint(n - 1)
    if dst >= src:
        dst += 1
    return src, dst

    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 2.0   # keep a small safety margin

    # ------------------------------------------------------------------
    # Choose the length n.
```
