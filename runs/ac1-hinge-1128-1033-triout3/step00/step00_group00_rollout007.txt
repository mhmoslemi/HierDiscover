def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Search for a step sequence minimizing the evaluation function.
    The algorithm explores a family of distributions p_i ∝ ((i+ε)*(L-i+ε))^α,
    which approximate the arcsine distribution whose self-convolution is nearly uniform.
    A grid search over the exponent α and the smoothing ε (and optionally the

    The best sequence found before the deadline is returned.
    """
    import numpy as np, time
    import math

    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 5

    best_score = float('inf')
    best_seq = None
    best_params = None

    # define candidate lengths
    lengths = [500, 800, 1000, 1200, 1500, 1742, 2000, 2500]  # choose a few

    # initial coarse grid
    alphas = np.linspace(-1.2, -0.1, 12)  # negative exponents
    epsilons = np.linspace(0.01, 2.0, 20)

    for n in lengths:
        L = n - 1
        indices = np.arange(n, dtype=np.float64)
        # Precompute part depending only on n
        for alpha in alphas:
            # compute base factor for each epsilon inside epsilon loop
            # we need (i+eps)*(L-i+eps)
            for eps in epsilons:
                # compute weights
                w = ( (indices + eps) * (L - indices + eps) ) ** alpha
                # possibly some w become infinite if (i+eps)*(L-i+eps) == 0, but eps>0 ensures >0.

                sum_w = w.sum()
                if sum_w == 0 or not np.isfinite(sum_w):
                    continue
                p = w / sum_w
                # Compute convolution using FFT
                m = 2 * n - 1
                # zero-pad and compute FFT
                fft_len = 1 << (m-1).bit_length()  # next power of two
                # but using np.fft.rfft may be efficient; we can just use np.fft.fft with size m
                # compute conv
                F = np.fft.fft(p, fft_len)
                conv = np.real(np.fft.ifft(F * F))[:m]
                max_conv = conv.max()
                score = 2.0 * n * max_conv   # since sum(p)=1
                if score < best_score:
                    best_score = score
                    best_seq = p.copy()
                    best_params = (n, alpha, eps)
                # Check time
                if time.time() > deadline:
                    break
            if time.time() > deadline:
                break
        if time.time() > deadline:
            break

    # Now local random search around best parameters, if any time left.

    if best_params is not None:

The objective that `evaluate_sequence` implements can be written in a
scale‑invariant way.  
For a non‑negative vector `a` of length `n`

```
S = sum(a)                     # total height
c = a * a  (linear convolution)   # length 2n‑1
M = max(c)                         # largest convolution entry
score = 2·n·M / S²
```

If we replace `a` by `λ·a` then `S` becomes `λ·S` and `M` becomes `λ²·M`,
so the factor `λ` cancels – the score depends only on the *shape* of the
distribution `a / S`.  Thus the problem is

```
choose a probability distribution p = (p0,…,pn‑1)   (pi ≥ 0, Σpi = 1)
so that   max(p * p)   is as small as possible.
```

`p * p` is the distribution of the sum of two independent draws from `p`.
The ideal would be a perfectly uniform sum‑distribution, which would give
`score = 2·n·1/(2n‑1) ≈ 1`.  A classic construction that makes the sum
distribution almost flat is the **arcsine distribution**

```
pdf(x) = 1 / (π·√(x·(L‑x))) ,   0 ≤ x ≤ L,
```

because the convolution of this continuous law is close to uniform.
A discrete analogue is

```
pi(α,ε) ∝ ((i+ε)·(L‑i+ε))^α ,           L = n‑1 ,  i = 0,…,n‑1
```

* `α < 0` pushes mass towards the ends (U‑shape);
* `ε > 0` regularises the singularities at the borders;
* the normalising constant is chosen so that Σpi = 1.

For `α = –½` and a small `ε` we obtain the discrete arcsine law.
Different pairs `(α,ε)` give slightly different shapes, therefore we
search the two‑dimensional parameter space for the combination that
minimises the score.

The algorithm consists of two phases  

1. **Coarse grid search** – a small set of lengths (`n`), exponents
   (`α`) and smoothing parameters (`ε`) is tested.  The best triple
   `(n,α,ε)` is remembered.
2. **Stochastic refinement** – starting from the best triple we perform
   a simple hill‑climbing: random perturbations of the three parameters
   are generated, the corresponding score is evaluated (using an FFT for
   fast convolution) and the best improvement is kept.  This continues
   until the time budget (≈ 1000 s) is exhausted.
