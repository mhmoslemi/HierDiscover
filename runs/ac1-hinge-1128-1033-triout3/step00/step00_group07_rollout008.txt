The scoring function is  

```python
score = 2 * n * max(conv(a,a)) / (sum(a)**2)
```  

where `conv(a,a)` is the linear (not circular) convolution of the non‑negative
vector `a`.  The score is **to be minimised** – the current best value is `2.0`
(and the (theoretical) optimum is exactly `2.0`).  Nevertheless the framework
expects a search routine that tries to *improve* the best known vector
(`height_sequence_1`).  The implementation below performs a multi‑start
random search combined with the linear‑programming direction used in the
reference code and a simple simulated‑annealing hill‑climber.  All
techniques are wrapped in pure functions (no closures, no lambdas) so that
the judge can import them directly.

The algorithm works as follows:

1. **Initialisation** – several random vectors of different lengths are
   generated (including the supplied `height_sequence_1`).  Their scores are
   evaluated and the best `population_size` vectors are kept.
2. **LP‑driven improvement** – for each vector in the elite set we call the
   LP routine `lp_step`.  The LP maximises the total mass while keeping
   `conv(f,g)` below the current maximal convolution `M`.  Mixing the old
   vector with the LP solution (with a tunable mixing factor `t`) usually
   reduces the maximal convolution and therefore the score.
3. **Local random perturbations** – after a successful LP step we apply a
   small random perturbation to escape shallow plateaus.  The perturbation
   size decays with the annealing temperature.
4. **Selection** – after each iteration the global best vector (lowest
   score) is stored.  The elite set is refreshed with the best candidates
   observed so far.
5. **Time budget** – the loop runs until the user‑provided time budget is
   exhausted (a safety margin of 5 s is kept).

The code uses only `numpy` and `scipy.optimize.linprog` (the same LP solver
as the reference implementation) and prints occasional progress messages,
so the user can see the current best score.

"""
Multi‑start optimisation for the step‑function evaluation problem.

The function `propose_candidate` searches for a non‑negative sequence that
minimises

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

where `conv` is the linear convolution.  The algorithm combines
* random initialisation,
* a linear‑programming direction (maximise the total mass while preserving
  the maximal convolution),
* simple simulated‑annealing perturbations,
* and elitist selection.

All helper functions are top‑level (no closures) and respect the 1000 s
runtime limit imposed by the evaluation harness.
"""

import time
import random
import numpy as np
from scipy import optimize

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def evaluate(seq):
    """
    Wrapper around the provided `evaluate_sequence` that guarantees a float
    and catches any unexpected exception.
    """
    try:
        return float(evaluate_sequence(seq))
    except Exception:           # pragma: no cover – defensive programming
        return float("inf")


def conv_max(seq):
    """
    Return the maximal entry of the linear convolution of `seq` with itself.
    The sequence is first converted to a NumPy array for speed.
    """
    arr = np.asarray(seq, dtype=float)
    conv = np.convolve(arr, arr)
    return float(conv.max())


def normalize_sum(seq, target_sum):
    """
    Scale `seq` so that its ℓ¹‑norm equals `target_sum`.  The function works
    in‑place on a list and returns the scaled list (also as a Python list).
    """
    s = float(sum(seq))
    if s == 0:
        return seq
    factor = target_sum / s
    return [float(x * factor) for x in seq]


def lp_step(f_seq, t=0.01):
    """
    Perform one LP‑driven improvement step.

    Parameters
    ----------
    f_seq : list[float]
        Current sequence (non‑negative).
    t : float
        Mixing factor; the next sequence is (1‑t)·f + t·g where `g` is the
        LP solution normalised to the same ℓ¹‑norm as `f`.

    Returns
    -------
    new_seq : list[float] | None
        The improved sequence, or `None` if the LP was infeasible.
    """
    n = len(f_seq)
    # Normalise to the SOTA convention (ℓ¹‑norm = sqrt(2n) )
    sqrt2n = np.sqrt(2.0 * n)
    f_norm = normalize_sum(f_seq, sqrt2n)

    # Current maximal convolution (the RHS of the LP)
    M = conv_max(f_norm)

    # --- Build LP ------------------------------------------------------
    # maximise   sum(b)  == minimise  -sum(b)
    c = -np.ones(n)

    # Upper‑bound constraints:   (f * b)[k] <= M   for k = 0 … 2n‑2
    a_ub = []
    b_ub = []

    for k in range(2 * n - 1):
        row = np.zeros(n)
        for i in range(n):
            j = k - i
            if 0 <= j < n:
                row[j] = f_norm[i]
        a_ub.append(row)
        b_ub.append(M)

    # Non‑negativity constraints  -b <= 0
    a_ub.extend(-np.eye(n))
    b_ub.extend([0.0] * n)

    a_ub = np.asarray(a_ub, dtype=float)
    b_ub = np.asarray(b_ub, dtype=float)

    # Solve the LP (time‑limited)
    res = optimize.linprog(
        c,
        A_ub=a_ub,
        b_ub=b_ub,
        bounds=(0, None),
        method='highs',
        options={'presolve': True, 'time_limit': 5.0},
    )
    if not res.success:
        return None

    g = np.maximum(res.x, 0.0)               # numerical safety
    # Normalise g back to the original ℓ¹‑norm of f (not to sqrt(2n))
    g_norm = normalize_sum(g.tolist(), sum(f_seq))

    # Mix the two sequences
    new_seq = [(1.0 - t) * f + t * g for f, g in zip(f_seq, g_norm)]
    return new_seq


def random_sequence(length, low=0.0, high=1.0):
    """
    Generate a random non‑negative sequence of the given length.
    Values are clipped to the interval [0, 1000] to respect the limits of
    `evaluate_sequence`.
    """
    seq = [random.random() * (high - low) + low for _ in range(length)]
    # Clip to the allowed range.
    return [max(0.0, min(1000.0, x)) for x in seq]


def perturb(seq, magnitude=0.1):
    """
    Apply a small random perturbation to a random subset of entries.
    The magnitude is a relative factor (percentage of the current value)
    and decays with the annealing temperature.
    """
    n = len(seq)
    # Number of indices to touch – roughly 5 % of the vector.
    k = max(1, n // 20)
    idxs = random.sample(range(n), k)
    new_seq = seq[:]
    for i in idxs:
        delta = (random.random() * 2.0 - 1.0) * magnitude * (seq[i] + 1e-9)
        new_seq[i] = max(0.0, min(1000.0, new_seq[i] + delta))
    return new_seq


def elite_selection(population, scores, elite_size):
    """
    Return the `elite_size` best members of `population` according to `scores`.
    """
    paired = list(zip(scores, population))
    paired.sort(key=lambda x: x[0])               # minimise the score
    elite = [p[1] for p in paired[:elite_size]]
    elite_scores = [p[0] for p in paired[:elite_size]]
    return elite, elite_scores

def propose_candidate(seed=42, budget_s=1000, **kwargs):
    """
    Search for a step‑function that minimises the evaluation metric.

    The function runs for at most ``budget_s`` seconds (a small safety margin
    of a few seconds is kept for returning the result) and returns a list of
    non‑negative floats.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int | float
        Total time budget in seconds.
    **kwargs
        Ignored – kept for compatibility with the original interface.

    Returns
    -------
    best_seq : list[float]
        The best sequence found within the time limit.
    """
    random.seed(seed)
    np.random.seed(seed)

    # ------------------------------------------------------------------
    # 1. Build an initial population (including the supplied SOTA sequence)
    # ------------------------------------------------------------------
    deadline = time.time() + budget_s - 5.0   # safety margin
    population = []
    scores = []

    # Use the known sequence if available
    try:
        base = list(height_sequence_1)     # noqa: F821 – defined by the judge
        population.append(base)
        scores.append(evaluate(base))
        print(f"[init] height_sequence_1 score = {scores[-1]:.6f}")
    except Exception:
        pass

    # Random initial candidates of varying length
    for _ in range(8):
        length = random.randint(200, 1500)
        seq = random_sequence(length, low=0.0, high=5.0)
        population.append(seq)
        scores.append(evaluate(seq))

    # Keep the top few as the elite set
    elite_size = 4
    elite, elite_scores = elite_selection(population, scores, elite_size)

    best_seq = elite[0]
    best_score = elite_scores[0]
    print(f"[start] best initial score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2. Main optimisation loop
    # ------------------------------------------------------------------
    iteration = 0
    temperature = 1.0          # goes down to 0.01 – controls perturb size

    while time.time() < deadline:
        iteration += 1
        # Reduce temperature slowly (simulated annealing schedule)
        temperature = max(0.01, temperature * 0.9995)

        new_population = []
        new_scores = []

        # ----------------------------------------------------------------
        # (a) LP‑driven step for each elite member
        # ----------------------------------------------------------------
        for seq in elite:
            t = 0.02 + 0.08 * random.random()   # random mixing factor
            candidate = lp_step(seq, t=t)
            if candidate is None:                # LP failed – fall back
                candidate = perturb(seq, magnitude=temperature * 0.5)
            else:
                # Occasionally apply a tiny perturbation to avoid stagnation
                if random.random() < 0.2:
                    candidate = perturb(candidate, magnitude=temperature * 0.2)

            score = evaluate(candidate)
            new_population.append(candidate)
            new_scores.append(score)

            # Track global best
            if score < best_score:
                best_score = score
                best_seq = candidate[:]
                print(f"[iter {iteration}] new best = {best_score:.6f}")

        # ----------------------------------------------------------------
        # (b) Small random newcomers to diversify the search
        # ----------------------------------------------------------------
        for _ in range(2):
            length = random.randint(150, 1800)
            seq = random_sequence(length, low=0.0, high=2.0)
            score = evaluate(seq)
            new_population.append(seq)
            new_scores.append(score)
            if score < best_score:
                best_score = score
                best_seq = seq[:]
                print(f"[iter {iteration}] new random best = {best_score:.6f}")

        # ----------------------------------------------------------------
        # (c) Form the next elite set
        # ----------------------------------------------------------------
        combined_pop = elite + new_population
        combined_scores = elite_scores + new_scores
        elite, elite_scores = elite_selection(combined_pop, combined_scores, elite_size)

        # Occasionally print a short status line
        if iteration % 30 == 0:
            print(f"[status] iter {iteration:4d} – best score {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Return the best sequence found
    # ------------------------------------------------------------------
    print(f"[done] iterations = {iteration}, best score = {best_score:.6f}")
    return best_seq
