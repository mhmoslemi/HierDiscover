The evaluation function  

\[
E(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale‑invariant* – multiplying the whole sequence by a constant does not change the
value.  Moreover for any non‑negative sequence the Cauchy–Schwarz inequality gives  

\[
\max_k (a*a)_k \;\ge\; (a*a)_0 = \sum_i a_i^2\;\ge\; \frac{(\sum_i a_i)^2}{n}\;,
\]

hence  

\[
E(a)\;\ge\; \frac{2n\;\frac{(\sum a_i)^2}{n}}{(\sum a_i)^2}=2 .
\]

Thus **2 is a theoretical lower bound** of the objective; it cannot be beaten.
A constant (uniform) sequence attains this bound, because for a uniform vector all
inequalities above are equalities.

Consequently the best possible construction is simply a uniform step‑function.
The `propose_candidate` implementation below returns such a sequence (using the
same length as the previously found best construction, if it exists).  The function
contains a tiny amount of bookkeeping and prints a short progress line – this
conforms to the required interface while guaranteeing the optimal value.
