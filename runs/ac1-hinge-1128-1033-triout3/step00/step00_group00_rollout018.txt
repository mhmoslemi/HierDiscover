assistantfinal**Solution Overview**

The evaluation function is  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_{i=0}^{n-1}a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

`n` is the length of the array, `(a*a)_k` is the ordinary discrete convolution.  
`F` is invariant under a global scaling of the vector, therefore only the *shape*
of the sequence matters.

The convolution at index `k` is  

\[
c_k=\sum_{i+j=k} a_i a_j .
\]

For a *flat* convolution we want every `c_k` to be as close as possible to the
average value  

\[
\frac{\sum_k c_k}{2n-1}= \frac{(\sum_i a_i)^2}{2n-1}.
\]

If the large entries of the vector never meet each other in a sum `i+j`
(their pair‑wise sums are all different) the only large contributions to a
convolution entry come from a **single** ordered pair, i.e. at most `2·a_i·a_j`.
Such a set of indices is known as a **Sidon (B₂) set**.

The construction below uses

* a Sidon set `S` of size `m≈√n`.  
  For `n≈1742` a greedy algorithm yields `m≈41`.
* weight `1` on the indices in `S` (the “heavy’’ positions).
* a tiny background value `ε` on all other indices.
  The background increases the total `ℓ₁`‑norm (the denominator of `F`) but its
  contribution to any convolution entry is bounded by `n·ε²`.  
  Choosing  

\[
\varepsilon = \frac{\sqrt{2}}{2\sqrt n}
\]

guarantees `n·ε² ≤ ½`, i.e. the background never dominates the heavy‑heavy
contribution (`2`).

With this choice  

\[
\sum_i a_i = m + (n-m)\varepsilon \;\approx\; 70\!-\!80,
\qquad
\max_k (a*a)_k \approx 2,
\]
and consequently  

\[
F(a) \approx \frac{4n}{\bigl(m+(n-m)\varepsilon\bigr)^2}\; <\; 1.5 .
\]

The algorithm builds the Sidon set, constructs the vector, and performs a
tiny hill‑climbing phase (swapping a heavy and a light position) that can only
improve the score further while staying well within the time limit.

import math
import random
import time
import numpy as np

# -------------------------------------------------------------
# Helper: greedy construction of a Sidon (B2) set
# -------------------------------------------------------------
def greedy_sidon_set(max_index: int, target_size: int) -> list[int]:
    """
    Return a Sidon set S ⊂ {0,…,max_index} with at most target_size elements.
    The construction is greedy: the smallest possible numbers are taken first,
    which keeps all pairwise sums small.
    """
    S = []
    sums = set()                     # all i+j with i<=j, i,j∈S
    for x in range(max_index + 1):
        # test whether adding x would duplicate a sum
        conflict = False
        for y in S:
            if x + y in sums:
                conflict = True
                break
        if conflict:
            continue
        if x + x in sums:            # i=j case must also be unique
            continue
        # x is admissible – add it and its new sums
        for y in S:
            sums.add(x + y)
        sums.add(x + x)
        S.append(x)
        if len(S) >= target_size:
            break
    return S


# -------------------------------------------------------------
# Optional tiny hill‑climbing improvement
# -------------------------------------------------------------
def improve_sequence(seq: list[float], eps: float,
                     time_budget: float = 5.0) -> list[float]:
    """
    Simple hill‑climbing: repeatedly swap a heavy (value=1) and a light
    (value=eps) position.  Keep the best sequence seen.
    """
    n = len(seq)
    start = time.time()
    best_seq = seq[:]
    best_score = evaluate_sequence(best_seq)

    heavy = [i for i, v in enumerate(best_seq) if v > eps * 1.5]

    while time.time() - start < time_budget:
        if not heavy:
            break
        i = random.choice(heavy)                 # heavy index
        j = random.randrange(n)                  # random partner
        if j in heavy:
            continue                              # we need a light position
        # swap the values (1 ↔ eps)
        cand = best_seq[:]
        cand[i], cand[j] = cand[j], cand[i]

        try:
            sc = evaluate_sequence(cand)
        except Exception:
            continue
        if sc < best_score:
            best_score = sc
            best_seq = cand
            # update heavy list
            heavy.remove(i)
            heavy.append(j)
    return best_seq

    # -----------------------------------------------------------------
