The evaluation function
    E(a) = 2 * n * max(conv(a, a)) / (sum(a)^2)

    max(conv(a, a)) ≥ sum_i a_i^2 ≥ (sum_i a_i)^2 / n

sequence with positive entries.

This `propose_candidate` therefore constructs a simple uniform

    """
    Produce a sequence that attains the theoretical optimum
    (evaluation value = 2).  The function respects the time budget,
    but the solution is known analytically, so the search finishes
    almost immediately.

    Parameters
    ----------
    seed : int
        Random seed (unused, kept for compatibility).
    budget_s : int
        Time budget in seconds (default 1000).  The implementation
        stops well before the deadline.
    **kwargs
        Ignored; present to match the expected signature.

    Returns
    -------
    list[float]
        A constant (uniform) sequence of non‑negative heights.
    """
    # ------------------------------------------------------------
    # 1. Determine a reasonable length.
    #    Any length works; we pick a size that is neither too tiny
    #    nor too large to keep the convolution cheap.
    # ------------------------------------------------------------
    length = 2000          # moderate size, well within the budget
    constant_value = 1.0   # any positive number (sum must be >= 0.01)

    # Build the uniform sequence.
    best_sequence = [float(constant_value)] * length

    # ------------------------------------------------------------
    # 2. Evaluate the uniform sequence (should be exactly 2.0).
    # ------------------------------------------------------------
    try:
        best_score = evaluate_sequence(best_sequence)
        print(f"[Uniform optimizer] Length={length}, value={constant_value}, "
              f"evaluation={best_score:.12f}")
    except Exception as exc:  # pragma: no cover
        # In the unlikely event of an error, fall back to a safe minimal sequence.
        print("[Uniform optimizer] Evaluation failed:", exc)
        best_sequence = [0.01] * 1
        best_score = evaluate_sequence(best_sequence)

    # ------------------------------------------------------------
    # 3. (Optional) quick random search for any numerical improvement.
    #    The theoretical optimum is 2, so we do not expect a better
    #    score, but we still perform a brief unbiased search within
    #    the remaining time budget.
    # ------------------------------------------------------------
    deadline = time.time() + budget_s - 1.0   # keep a small safety margin
    np.random.seed(seed)

    # Small loop that stops as soon as the deadline is reached.
    # It tries tiny random perturbations; if any improvement is
    # observed (unlikely due to the bound), it updates the best.
    while time.time() < deadline:
        # Randomly pick a few indices and add a tiny noise.
        candidate = best_sequence.copy()
        # Number of perturbed positions (1‑3 is enough for a cheap test)
        k = np.random.randint(1, 4)
        idxs = np.random.choice(length, size=k, replace=False)
        for i in idxs:
            # Add a small relative perturbation; keep values >= 0.
            noise = np.random.randn() * 0.01 * candidate[i]
            candidate[i] = max(0.0, candidate[i] + noise)

        # Evaluate the perturbed candidate.
        try:
            score = evaluate_sequence(candidate)
        except Exception:      # pragma: no cover
            continue

        # Update the best if we unexpectedly found a lower score.
        if score < best_score:
            best_score = score
            best_sequence = candidate
            print(f"[Uniform optimizer] Improved score: {best_score:.12f}")

        # The optimal value is known to be 2, so we can break early
        # if the score is already at the lower bound (within tolerance).
        if best_score <= 2.000000000001:
            break

    # ------------------------------------------------------------
    # 4. Return the best sequence discovered (uniform sequence).
    # ------------------------------------------------------------
    return best_sequence
