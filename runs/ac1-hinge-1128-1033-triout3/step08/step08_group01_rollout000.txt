The objective  

\[
J(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2},
\qquad a_i\ge 0 ,
\]

depends only on the shape of the vector, not on an overall scale.  
We therefore always keep the vector **normalised to sum = 1** and the
objective reduces to  

\[
J(a)=2\,n\;\max_k (a*a)_k .
\]

The code below follows a *global‑then‑local* strategy.

1. **Global search** – a cheap differential‑evolution (DE) on a
   low‑dimensional *block‑wise* representation.  
   The vector is split into `B` blocks, each block is uniform and
   described by a single mass `p_j`.  `p` lives on the probability
   simplex, so a standard DE (mutation + crossover + simplex projection)
   can explore many very different shapes quickly.

2. **Local refinement** – three complementary descent phases, exactly as
   in the reference implementation, but with slightly different
   schedules and a few extra restarts:
   * **Adam** on a smooth log‑sum‑exp approximation of the maximum
     convolution entry.
   * **Targeted hill‑climbing** that moves a small amount of mass from
     indices that contribute the most to the current peak toward indices
     that contribute little.
   * **Projected sub‑gradient descent** on the true non‑smooth objective.

3. **Final polishing** – a tiny mixture with the uniform distribution
   (often reduces the peak a little more).

All phases respect the overall time budget (`budget_s`).  
The code is written with only NumPy‑based operations, no closures, no
lambdas, and conforms to the required `propose_candidate` signature.

```python
"""
Propose a step‑function (non‑negative vector) of length n that minimises

    2·n·max(conv(a,a)) / (sum(a)^2)

The algorithm consists of

* a fast global differential‑evolution (DE) on a block‑wise uniform
  parametrisation (few dozen variables);
* three local refinement phases (Adam, targeted hill‑climbing,
  projected sub‑gradient descent) using the exact objective;
* a final tiny mixture with the uniform vector.

All phases run within the supplied time budget and the best vector seen
is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution helpers ----------------------------------------------------
# ----------------------------------------------------------------------
def _next_pow2(v: int) -> int:
    """Next power of two greater or equal to v."""
    return 1 << (v - 1).bit_length()


def _full_convolution(a: np.ndarray) -> np.ndarray:
    """
    Full linear convolution a * a (length 2·len(a)‑1) using FFT.
    """
    n = a.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[:out_len]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Full convolution of two real vectors using FFT.
    """
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Simple projection onto the probability simplex -------------------------
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the simplex { w ≥ 0, Σ w = 1 }.
    """
    if np.sum(v) == 1.0 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.where(u - cssv / (np.arange(len(v)) + 1) > 0)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Exact objective (assumes Σ a = 1) --------------------------------------
# ----------------------------------------------------------------------
def _objective_value(a: np.ndarray) -> float:
    """
    Compute 2·n·max(conv(a,a)) for a vector normalised to sum = 1.
    """
    n = a.shape[0]
    return float(2.0 * n * _full_convolution(a).max())


# ----------------------------------------------------------------------
# Global DE on a block‑wise uniform representation -----------------------
# ----------------------------------------------------------------------
def _de_optimize(n: int,
                 B: int,
                 deadline: float,
                 rng: np.random.Generator,
                 init_pop: np.ndarray = None) -> tuple[np.ndarray, float]:
    """
    Differential evolution on the B‑dimensional block‑mass vector `p`
    (p lies on the simplex).  Returns the best `p` and its objective.
    """
    # block lengths – first `rem` blocks get one extra element
    L = n // B
    rem = n - L * B
    block_lengths = np.full(B, L, dtype=int)
    block_lengths[:rem] += 1

    def _build_a(p: np.ndarray) -> np.ndarray:
        """Expand block masses `p` to a full length‑n vector."""
        parts = [
            np.full(block_lengths[i], p[i] / block_lengths[i], dtype=np.float64)
            for i in range(B)
        ]
        return np.concatenate(parts)

    def _obj(p: np.ndarray) -> float:
        a = _build_a(p)
        return _objective_value(a)

    pop_size = max(20, 2 * B)          # modest population
    if init_pop is None:
        pop = rng.dirichlet(np.ones(B), size=pop_size)
    else:
        # seed the population with the supplied candidate
        pop = np.vstack([init_pop] + [rng.dirichlet(np.ones(B)) for _ in range(pop_size - 1)])
    pop_obj = np.array([_obj(ind) for ind in pop])
    best_idx = np.argmin(pop_obj)
    best_p = pop[best_idx].copy()
    best_val = pop_obj[best_idx]

    F = 0.8                # differential weight
    CR = 0.7               # crossover probability
    max_gen = 2000        # safety upper bound (will stop earlier by time)

    for gen in range(max_gen):
        for i in range(pop_size):
            # mutation: a + F*(b - c) with distinct indices
            idxs = list(range(pop_size))
            idxs.remove(i)
            a, b, c = rng.choice(idxs, size=3, replace=False)
            mutant = pop[a] + F * (pop[b] - pop[c])
            mutant = np.maximum(mutant, 0.0)
            mutant = _project_simplex(mutant)

            # crossover
            cross_mask = rng.random(B) < CR
            if not np.any(cross_mask):
                cross_mask[rng.integers(B)] = True
            trial = np.where(cross_mask, mutant, pop[i])
            trial = _project_simplex(trial)

            trial_val = _obj(trial)
            if trial_val < pop_obj[i]:
                pop[i] = trial
                pop_obj[i] = trial_val
                if trial_val < best_val:
                    best_val = trial_val
                    best_p = trial.copy()
        # time check – leave a small margin for the next phases
        if time.time() > deadline * 0.95:
            break
    return best_p, best_val


# ----------------------------------------------------------------------
# Phase A – Adam on a smooth approximation of max(conv) -----------------
# ----------------------------------------------------------------------
def _adam_phase(a0: np.ndarray,
                start: float,
                deadline: float,
                best_a: np.ndarray,
                best_val: float,
                target_val: float = 1.503) -> tuple[np.ndarray, float]:
    """
    Projected Adam on the log‑sum‑exp smooth version of the objective.
    a0 must already be on the simplex.
    """
    n = a0.shape[0]
    w = np.log(a0 + 1e-12)          # logits → simplex via soft‑max

    beta1, beta2 = 0.90, 0.999
    lr_start, lr_end = 0.15, 0.003
    eps_start, eps_end = 1e-1, 1e-12

    m = np.zeros_like(w)
    v = np.zeros_like(w)
    t = 0
    no_improve = 0
    IMPROVE_LIMIT = 30000

    it = 0
    while time.time() < deadline:
        # get a point on the simplex
        w_shift = w - np.max(w)
        a = np.exp(w_shift)
        a /= np.sum(a)

        cur_val = _objective_value(a)

        if cur_val < best_val - 1e-12:
            best_val, best_a = cur_val, a.copy()
            no_improve = 0
            print(f"[Adam {it:6d}] new best = {best_val:.6f}")
            if best_val <= target_val:
                break
        else:
            no_improve += 1

        # schedule for learning rate and epsilon
        progress = (time.time() - start) / (deadline - start)
        eps = eps_start * (eps_end / eps_start) ** progress
        lr = lr_start * (lr_end / lr_start) ** progress

        # smooth max via log‑sum‑exp
        b_full = _full_convolution(a)
        max_b = b_full.max()
        shifted = (b_full - max_b) / eps
        weights = np.exp(shifted)
        p = weights / weights.sum()                     # soft‑max over positions

        # gradient of smooth objective w.r.t. a:
        #   ∂/∂a  2·n·∑_k p_k (a*a)_k = 4·n·conv(a, p_rev)
        p_rev = p[::-1]
        conv_ab = _conv_fft(a, p_rev)                   # length 3·n‑2
        segment = conv_ab[n - 1: 2 * n - 1]
        grad_a = 4.0 * n * segment[::-1]

        # chain rule through the soft‑max (log‑softmax) parametrisation
        dot = np.dot(grad_a, a)
        grad_w = a * (grad_a - dot)

        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad_w
        v = beta2 * v + (1.0 - beta2) * (grad_w * grad_w)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        w -= lr * m_hat / (np.sqrt(v_hat) + 1e-8)

        # occasional jitter to escape plateaus
        if np.random.rand() < 0.006:
            w += np.random.normal(scale=0.008, size=n)

        # restart if stuck
        if no_improve > IMPROVE_LIMIT:
            print(f"[Adam {it:6d}] restart (idle {no_improve})")
            w = np.random.randn(n) * 0.3
            m.fill(0.0)
            v.fill(0.0)
            t = 0
            no_improve = 0

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase B – Targeted hill‑climbing on the exact objective ---------------
# ----------------------------------------------------------------------
def _hillclimb_targeted(a_start: np.ndarray,
                        start: float,
                        deadline: float,
                        best_a: np.ndarray,
                        best_val: float,
                        target_val: float = 1.503) -> np.ndarray:
    """
    Move a small fraction of mass from indices that heavily contribute to
    the current maximal convolution entry to indices that contribute little.
    """
    n = a_start.shape[0]
    a = a_start.copy()
    b = _full_convolution(a)
    cur_val = 2.0 * n * b.max()

    max_frac_start, max_frac_end = 0.5, 0.001
    IMPROVE_LIMIT = 250_000
    no_improve = 0
    it = 0
    rng = np.random.default_rng()

    while time.time() < deadline:
        progress = (time.time() - start) / (deadline - start)
        max_frac = max_frac_start * (1.0 - progress) + max_frac_end * progress

        k_max = int(np.argmax(b))

        # contribution of each index to the maximal entry
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        contrib = np.zeros_like(a)
        contrib[mask] = a[mask] * a[idx[mask]]
        total_contrib = contrib.sum()

        # source index – proportional to contribution
        if total_contrib > 0:
            probs = contrib / total_contrib
            i = rng.choice(n, p=probs)
        else:
            i = int(np.argmax(a))

        if a[i] <= 1e-15:
            continue

        # target index – preferably one that does not affect the max entry
        if rng.random() < 0.38:
            rev_idx = k_max - np.arange(n)
            rev_mask = (rev_idx >= 0) & (rev_idx < n)
            rev_contrib = np.zeros(n)
            rev_contrib[rev_mask] = a[rev_idx[rev_mask]]
            w = 1.0 / (rev_contrib + 1e-12)
            w[i] = 0.0
            if w.sum() > 0:
                probs_j = w / w.sum()
                j = rng.choice(n, p=probs_j)
            else:
                j = (i + rng.integers(1, n)) % n
        else:
            j = (i + rng.integers(1, n)) % n

        delta = a[i] * rng.random() * max_frac
        if delta <= 0.0:
            continue

        # incremental update of the convolution (O(n))
        b_new = b.copy()
        # add delta * a to the slice j..j+n-1
        b_new[j:j + n] += 2.0 * delta * a
        # remove delta * a from the slice i..i+n-1
        b_new[i:i + n] -= 2.0 * delta * a
        # adjust the pure‑quadratic terms
        b_new[2 * j] += delta * delta
        b_new[2 * i] += delta * delta
        b_new[i + j] -= 2.0 * delta * delta

        new_val = 2.0 * n * b_new.max()

        if new_val < cur_val - 1e-15:
            a[i] -= delta
            a[j] += delta
            b = b_new
            cur_val = new_val
            no_improve = 0
            if new_val < best_val - 1e-12:
                best_val, best_a = new_val, a.copy()
                print(f"[Hill {it:6d}] new best = {best_val:.6f}")
                if best_val <= target_val:
                    break
        else:
            no_improve += 1

        if no_improve > IMPROVE_LIMIT:
            # perturb around the current best to escape stagnation
            a = best_a.copy()
            noise = rng.normal(scale=0.013, size=n)
            a = np.maximum(a + noise, 0.0)
            a /= a.sum()
            b = _full_convolution(a)
            cur_val = 2.0 * n * b.max()
            no_improve = 0
            print(f"[Hill {it:6d}] perturbing after stagnation")

        it += 1

    return best_a


# ----------------------------------------------------------------------
# Phase C – Exact sub‑gradient descent -----------------------------------
# ----------------------------------------------------------------------
def _subgradient_phase(a0: np.ndarray,
                       start: float,
                       deadline: float,
                       best_a: np.ndarray,
                       best_val: float,
                       target_val: float = 1.503) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent on 2·n·max(conv(a,a)).
    """
    n = a0.shape[0]
    a = a0.copy()
    best_local_a = a.copy()
    best_local_val = best_val

    eta0 = 0.5 / n
    eta = eta0
    decay = 0.9994
    it = 0
    no_improve = 0
    IMPROVE_LIMIT = 200_000
    rng = np.random.default_rng()

    while time.time() < deadline:
        b = _full_convolution(a)
        cur_val = 2.0 * n * b.max()
        if cur_val < best_local_val - 1e-12:
            best_local_val, best_local_a = cur_val, a.copy()
            no_improve = 0
            print(f"[SGD {it:6d}] new best = {best_local_val:.6f}")
            if best_local_val <= target_val:
                break
        else:
            no_improve += 1

        k_max = int(np.argmax(b))

        # sub‑gradient of the maximal entry
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        grad = np.zeros_like(a)
        grad[mask] = 2.0 * a[idx[mask]]

        # step & projection onto the simplex
        v = a - eta * grad
        a = _project_simplex(v)

        # decay step size
        eta *= decay

        if no_improve > IMPROVE_LIMIT:
            # slight shake and reset step size
            noise = rng.normal(scale=0.009, size=n)
            a = np.maximum(best_local_a + noise, 0.0)
            a /= a.sum()
            eta = eta0
            no_improve = 0
            print(f"[SGD {it:6d}] perturbing after stagnation")

        it += 1

    return best_local_a, best_local_val


# ----------------------------------------------------------------------
# Small post‑processing: mixing with uniform -----------------------------
# ----------------------------------------------------------------------
def _mix_with_uniform(a: np.ndarray) -> tuple[np.ndarray, float]:
    """Try a few convex mixtures (1‑α)·a + α·uniform and keep the best."""
    n = a.shape[0]
    best_a, best_val = a, _objective_value(a)
    uniform = np.full(n, 1.0 / n)
    for alpha in (0.001, 0.003, 0.005, 0.010, 0.020):
        cand = (1.0 - alpha) * a + alpha * uniform
        cand /= cand.sum()
        val = _objective_value(cand)
        if val < best_val:
            best_val, best_a = val, cand
    return best_a, best_val

# Main entry point ------------------------------------------------------
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Optimise a non‑negative step‑function within the given time budget.
    Returns a list of floats that minimises `evaluate_sequence`.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a tiny safety margin for the final wrapper call
    deadline = start_time + budget_s - 0.5

    # ------------------------------------------------------------------
    # Problem size – a few ten‑thousands entries give a good trade‑off.
    # ------------------------------------------------------------------
    n = 12000                # length of the final vector
    B = 60                   # number of blocks for the DE stage

    # ------------------------------------------------------------------
    # Try to keep a previously discovered solution as a fallback.
    # ------------------------------------------------------------------
    try:
        old = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        old_x = np.linspace(0.0, 1.0, old.shape[0])
        new_x = np.linspace(0.0, 1.0, n)
        a0 = np.interp(new_x, old_x, old)
        a0 = np.maximum(a0, 0.0)
        a0 /= a0.sum()
    except Exception:
        # simple uniform start if nothing else is available
        a0 = np.full(n, 1.0 / n)

    best_a = a0.copy()
    best_val = _objective_value(best_a)
    print(f"[Init] objective = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 0 – global differential‑evolution on a block‑wise model.
    # ------------------------------------------------------------------
    phase0_deadline = start_time + 0.18 * (deadline - start_time)
    rng = np.random.default_rng(seed + 7)
    # initialise DE with the current best vector projected onto the block space
    L = n // B
    rem = n - L * B
    block_lengths = np.full(B, L, dtype=int)
    block_lengths[:rem] += 1
    # compute masses of best_a per block
    start = 0
    init_p = np.empty(B, dtype=np.float64)
    for i in range(B):
        length = block_lengths[i]
        init_p[i] = best_a[start:start + length].sum()
        start += length
    init_p = _project_simplex(init_p)

    best_p, best_p_val = _de_optimize(
        n=n,
        B=B,
        deadline=phase0_deadline,
        rng=rng,
        init_pop=init_p,
    )
    # expand the best block vector to the full representation
    a_de = np.empty(0, dtype=np.float64)
    for i, length in enumerate(block_lengths):
        a_de = np.concatenate([a_de,
                               np.full(length, best_p[i] / length, dtype=np.float64)])
    # sanity – enforce exact normalisation
    a_de /= a_de.sum()
    de_val = _objective_value(a_de)
    print(f"[DE] best block obj = {best_p_val:.6f}  full‑vector obj = {de_val:.6f}")

    if de_val < best_val:
        best_a, best_val = a_de, de_val
        print("[Update] adopted DE solution")

    # ------------------------------------------------------------------
    # Phase A – Adam optimisation (smooth max)
    # ------------------------------------------------------------------
    phase_a_deadline = start_time + 0.35 * (deadline - start_time)
    best_a, best_val = _adam_phase(
        a0=best_a,
        start=start_time,
        deadline=phase_a_deadline,
        best_a=best_a,
        best_val=best_val,
        target_val=1.503,
    )
    print(f"[After Adam] best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase B – targeted hill‑climbing on the exact objective
    # ------------------------------------------------------------------
    phase_b_deadline = start_time + 0.80 * (deadline - start_time)
    best_a = _hillclimb_targeted(
        a_start=best_a,
        start=phase_a_deadline,
        deadline=phase_b_deadline,
        best_a=best_a,
        best_val=best_val,
        target_val=1.503,
    )
    best_val = _objective_value(best_a)
    print(f"[After Hill] best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase C – exact sub‑gradient descent
    # ------------------------------------------------------------------
    phase_c_deadline = deadline
    best_a, best_val = _subgradient_phase(
        a0=best_a,
        start=phase_b_deadline,
        deadline=phase_c_deadline,
        best_a=best_a,
        best_val=best_val,
        target_val=1.503,
    )
    print(f"[After SGD] best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final polishing – tiny uniform mixing
    # ------------------------------------------------------------------
    best_a, best_val = _mix_with_uniform(best_a)
    print(f"[Final mix] best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final evaluation with the provided secure wrapper.
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] reported evaluation = {final_score:.6f}")
    except Exception as exc:                     # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    # Return a plain Python list as required by the harness.
    return best_a.tolist()
```
