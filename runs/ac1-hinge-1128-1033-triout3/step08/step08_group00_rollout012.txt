A three‑stage optimiser for the step‑function problem.

Stage 0 – cheap initialisation (beta‑family sweep, Dirichlet draws,
optionally interpolating the previously best solution).

Stage 1 – LP‑driven Frank‑Wolfe steps.
   For the current candidate f (∑f = √(2·n)) we compute M = max(f∗f).
   We then solve the linear programme
        maximise   Σx
        subject to f∗x ≤ M   (element‑wise)
                    0 ≤ x ≤ √(2·n).
   The solution x is rescaled to the same ℓ₁‑norm as f, yielding g.
   A Frank‑Wolfe step f ← (1‑t)·f + t·g (t = 2/(k+2)) is taken.
   Repeating this reduces the maximal auto‑convolution M.

Stage 2 – a brief simulated‑annealing hill‑climb that moves a small
   amount of mass from indices that heavily contribute to the current
   maximal convolution entry to indices that contribute little.

                total_allowed = deadline - start
                T = max(1e-8, (remaining / total_allowed) * 0.02)
                if np.random.rand() < np.exp(-(new_M - cur_M_val) / T):
                    accept = True

            if accept:
                cur, cur_M_val = new_cur, new_M
                no_improve = 0
                if cur_M_val < best_M - 1e-12:
                    # keep the globally best candidate
                    nonlocal_best_a = cur.copy()         # type: ignore[misc]
                    nonlocal_best_M = cur_M_val          # type: ignore[misc]
                    # (we will compare after the function returns)
            else:
                no_improve += 1
                if no_improve > IMP_LIMIT:
                    # escape a plateau with a random perturbation
                    cur = a.copy()
                    cur += np.random.normal(scale=0.02, size=n)
                    cur = np.maximum(cur, 0.0)
                    cur = _norm(cur)
                    cur_M_val = _full_convolution(cur).max()
                    no_improve = 0
        return cur, cur_M_val

    hill_a, hill_M = _hillclimb(best_a, best_M)
    if hill_M < best_M:
        best_a, best_M = hill_a, hill_M
        print("[Hill] improved M =", best_M)

    # --------------------------------------------------------------
    # Final evaluation using the provided secure wrapper.
    # --------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print("[final] reported score =", final_score)
    except Exception as exc:               # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_a.tolist()
