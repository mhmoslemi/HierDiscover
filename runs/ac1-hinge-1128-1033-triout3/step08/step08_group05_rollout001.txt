assistantfinal**Solution Overview**

The algorithm searches the simplex \(\{a\in\mathbb R_{\ge0}^n\mid\sum a_i=1\}\) for a distribution whose self‑convolution has a small maximum.
The objective of `evaluate_sequence` (after fixing the scale) is  

\[
\text{score}(a)=2\,n\;\max_k (a*a)_k .
\]

Hence we have to minimise the peak of the convolution.
The search consists of four blocks that complement each other:

| Block | Idea |
|------|------|
| **0 – initialisation** | Load the previously found sequence if it exists, otherwise start from several diverse candidates (uniform, Dirichlet, sinusoid, …). |
| **1 – smooth surrogate optimisation** | Optimise a *log‑sum‑exp* smoothed version of the max‑convolution with L‑BFGS. The smoothing parameter ε is decreased logarithmically; the variables are soft‑max logits so the simplex constraint is always satisfied. |
| **2 – exact mirror‑descent** | Use the exact sub‑gradient of the (unsmoothed) peak. The update is an exponentiated‑gradient step, which stays on the simplex automatically. A moderate step‑size schedule together with occasional symmetrisation gives fast convergence. |
| **3 – aggressive mass‑transfer hill‑climb** | Repeatedly identify the pair \((i,j)\) that contributes the most to the current peak and move a tiny fraction of mass from the larger contributor to a location with very small probability.  Simulated‑annealing acceptance allows occasional uphill moves, helping to escape plateaus. |
| **4 – cheap polishing** | Very cheap random swaps / small transfers that accept *only* improvements – final fine‑tuning. |
| **final check** | The best vector found is fed to the official `evaluate_sequence` for safety. |

All stages respect a global time budget (default 1000 s).  The code contains no closures, no file I/O, and only uses `numpy`, `scipy` and the provided `evaluate_sequence`.

```python
"""
Propose a non‑negative step‑function (list of heights) that minimises
evaluate_sequence.  The search uses

  0. several diverse initial vectors,
  1. an L‑BFGS optimisation of a log‑sum‑exp smooth surrogate of the
     max‑convolution,
  2. an exact mirror‑descent (exponentiated‑gradient) on the true
     max‑convolution,
  3. a targeted pairwise mass‑transfer hill‑climber with simulated
     annealing,
  4. a final cheap stochastic polish.

All phases stop automatically when the 1000 s budget (minus a small
safety margin) is exhausted.  The best vector obtained is finally
checked with the official evaluate_sequence and returned as a plain
Python list.
"""

import time
import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp

# ----------------------------------------------------------------------
# Global placeholders for the smooth surrogate (updated before each L‑BFGS call)
# ----------------------------------------------------------------------
_GLOBAL_EPS = None   # smoothing parameter ε
_GLOBAL_N = None     # problem size n


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (used for FFT padding)."""
    return 1 << (x - 1).bit_length()


def _full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using an FFT of power‑of‑2 size."""
    n = a.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    np.maximum(conv, 0.0, out=conv)   # remove tiny negatives caused by round‑off
    return conv


def _smooth_obj_and_grad(w: np.ndarray) -> tuple[float, np.ndarray]:
    """
    Smoothed surrogate L_ε(w) and its gradient.
    Variables are logits w → soft‑max probabilities a_i.
    L_ε = 2·n·max(conv) + 2·n·ε·log Σ_k exp((conv_k‑max)/ε)
    """
    eps = _GLOBAL_EPS
    n = _GLOBAL_N

    # soft‑max to obtain a (always on the simplex)
    w_shift = w - np.max(w)
    a = np.exp(w_shift)
    a /= a.sum()

    # convolution and the (hard) maximum
    conv = _full_convolution(a)
    max_c = conv.max()

    # smooth max (log‑sum‑exp)
    shifted = (conv - max_c) / eps
    log_sum = logsumexp(shifted)
    obj = 2.0 * n * max_c + 2.0 * n * eps * log_sum

    # gradient wrt a
    # p_k = exp((conv_k-max)/ε) / Σ exp(...)
    weights = np.exp(shifted)
    p = weights / weights.sum()                     # distribution over lag indices

    # derivative of max‑smoothed term w.r.t. a:
    #   ∂conv_k/∂a_i = a_{k-i} (if k-i in range), otherwise 0.
    #   Hence grad_a = 4·n * (p *reversed* a) convolution
    p_rev = p[::-1]
    size = _next_pow2(a.shape[0] + p_rev.shape[0] - 1)
    fa = np.fft.rfft(a, size)
    fp = np.fft.rfft(p_rev, size)
    conv_ap = np.fft.irfft(fa * fp, size)[: a.shape[0] + p_rev.shape[0] - 1]
    seg = conv_ap[n - 1: 2 * n - 1]                # aligns with ∂conv/∂a_i
    grad_a = 4.0 * n * seg[::-1]                  # reverse to get proper order

    # chain rule through the soft‑max
    dot = np.dot(grad_a, a)
    grad_w = a * (grad_a - dot)

    return float(obj), grad_w


def _smooth_obj_and_grad_wrapper(w: np.ndarray) -> tuple[float, np.ndarray]:
    """Wrapper required by scipy.minimize."""
    return _smooth_obj_and_grad(w)


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex.
    Implements the O(n) algorithm of Wang & Carreira‑Perpiñán (2013).
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def _fast_evaluate(a: np.ndarray) -> float:
    """
    Fast version of evaluate_sequence for vectors that already satisfy
    Σa_i = 1 and a_i ≥ 0.
    """
    n = a.shape[0]
    conv = _full_convolution(a)
    return float(2.0 * n * conv.max())   # denominator = 1²


def _anti_symmetric_reorder(a: np.ndarray) -> np.ndarray:
    """
    Put the largest values on the left, the smallest on the right.
    This often flattens the self‑convolution peak.
    """
    n = a.shape[0]
    s = np.sort(a)                      # ascending
    out = np.empty_like(a)
    half = n // 2
    for i in range(half):
        out[i] = s[n - 1 - i]           # big → left side
        out[n - 1 - i] = s[i]           # small → right side
    if n % 2:
        out[half] = s[half]
    return out


def _symmetrize(a: np.ndarray) -> np.ndarray:
    """Replace a by (a + a[::-1]) / 2 and renormalise."""
    b = (a + a[::-1]) * 0.5
    s = b.sum()
    if s > 0:
        b /= s
    return b


def _refine_hill_climb(a: np.ndarray, cur_val: float,
                       deadline: float) -> tuple[np.ndarray, float]:
    """
    Very cheap hill‑climber that only accepts *strict* improvements.
    Random swaps (20 %) and mass transfers (80 %).  The vector stays on the simplex.
    """
    rng = np.random.default_rng()
    n = a.shape[0]
    best_a = a.copy()
    best_val = cur_val

    while time.time() < deadline:
        if rng.random() < 0.2:   # pure swap
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            cand = best_a.copy()
            cand[i], cand[j] = cand[j], cand[i]
        else:                    # mass transfer
            i, j = rng.integers(0, n, size=2)
            if i == j or best_a[i] <= 1e-15:
                continue
            delta = best_a[i] * 0.04 * rng.random()
            cand = best_a.copy()
            cand[i] -= delta
            cand[j] += delta

        # projection (simple because only positivity and sum matter)
        np.maximum(cand, 0.0, out=cand)
        s = cand.sum()
        if s < 1e-12:
            continue
        cand /= s

        val = _fast_evaluate(cand)
        if val < best_val - 1e-12:
            best_a = cand
            best_val = val
            # optional: print progress (kept light to avoid clutter)
            # print(f"[polish] new best = {best_val:.6f}")

    return best_a, best_val

                best_a = cur_a.copy()
                print(f"[pairhill] improved to {best_val:.6f}")

        T = max(T * cooling, 1e-6)

    # ------------------------------------------------------------------
    # 4 – final cheap stochastic polish
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = _refine_hill_climb(best_a, best_val, deadline)

    # ------------------------------------------------------------------
    # Final safety check with the official evaluator
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] evaluate_sequence reports {final_score:.6f}")
    except Exception as exc:               # pragma: no cover
        print("[final] evaluate_sequence raised an exception:", exc)

    return best_a.tolist()
```
