assistantfinal**Solution Overview**

The program searches for a non‑negative step‑function (a probability vector `a`) that minimises  

```
evaluate_sequence(a) = 2·n·max(conv(a,a)) / (sum(a)²)
```

For the optimisation we keep the vector normalised (`sum(a)=1`).  
The goal is therefore to reduce `max(conv(a,a))`.

The approach combines three complementary phases and repeats them several times
until the time budget expires:

1. **Initialisation** – several diverse starting points are generated  
   (interpolation of the previous best solution, a “U‑shaped’’ Beta family,
   sparse Dirichlet draws).

2. **Adam optimisation** – minimises a *smooth* upper‑bound on the true
   objective plus a variance penalty on the convolution.  
   The loss is  

   ```
   L(a) = 2·n·smooth_max(conv(a,a)) + λ·Var(conv(a,a))
   ```

   `λ` is large at the beginning (strong flattening) and is linearly
   annealed to 0.  The simplex constraint Σa=1 is enforced via a
   log‑softmax parametrisation (Adam works on the logits).

3. **Hill‑climbing (simulated annealing)** – a fast O(n) local search that
   repeatedly transfers a small amount of mass from an index that contributes
   heavily to the current maximal convolution entry to an index that contributes
   little.  Both the transfer fraction and the temperature are annealed to 0.

4. **Exact sub‑gradient polishing** – a few projected‑sub‑gradient steps on the
   *true* maximum (not a smooth approximation) to shave off the last bits.

All phases are run in **multiple independent cycles** (different random seeds,
different initialisations).  The best vector found over all cycles is returned.
The code respects the 1000 s budget (a 0.5 s safety margin for the final call
to `evaluate_sequence`).  

The implementation uses only `numpy` and pure‑Python; all helper functions are
defined at the top level as required.

```python
"""
Optimise a non‑negative step function under the 1000 s budget.
The algorithm repeatedly performs:

  • a diverse initialisation,
  • Adam optimisation on a smooth max + variance loss,
  • simulated‑annealing hill‑climbing,
  • a few projected sub‑gradient steps on the true max.

Multiple independent cycles are executed until time runs out,
keeping the best vector (minimum evaluate_sequence value) seen.
"""
import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution helpers (FFT based, full linear convolution)
# ----------------------------------------------------------------------
def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of `x` with itself (length 2·len(x)‑1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Exact objective (assumes Σa = 1)
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Exact value of 2·n·max(conv(a,a)) under Σa = 1."""
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())


# ----------------------------------------------------------------------
# Smooth‑max and its gradient (includes the factor 2·n)
# ----------------------------------------------------------------------
def _smooth_max_and_grad(a: np.ndarray, eps: float) -> tuple[float, np.ndarray]:
    """
    Smooth approximation of max(conv(a,a)) and gradient of
    2·n·smooth_max with respect to `a`.
    """
    n = a.shape[0]
    b = _full_convolution(a)   # length 2n‑1
    max_b = b.max()
    # log‑sum‑exp trick
    shifted = (b - max_b) / eps
    w = np.exp(shifted)
    p = w / w.sum()                     # soft‑max weights, shape (2n‑1,)

    # convolution of a with reversed soft‑max weights
    conv_ap = _conv_fft(a, p[::-1])     # length 2n‑1
    # the part that corresponds to shift by 0…n‑1
    segment = conv_ap[n - 1:2 * n - 1]
    grad = 4.0 * n * segment[::-1]      # factor 2·n already included
    smooth_val = max_b + eps * np.log(w.sum())
    return smooth_val, grad


# ----------------------------------------------------------------------
# Variance of the convolution and its gradient
# ----------------------------------------------------------------------
def _var_and_grad(a: np.ndarray) -> tuple[float, np.ndarray]:
    """
    Returns   var(b) = mean((b‑avg)²)   and   ∂var/∂a  (no extra scaling).
    Here b = a*a and avg = 1/(2n‑1) because Σb = (Σa)² = 1.
    """
    n = a.shape[0]
    b = _full_convolution(a)
    m = 2 * n - 1
    avg = 1.0 / m
    v = b - avg
    var = np.mean(v * v)

    # gradient: (4/m) * cross‑correlation of a with v
    conv = _conv_fft(a, v[::-1])
    segment = conv[n - 1:2 * n - 1]
    grad = (4.0 / m) * segment[::-1]
    return var, grad


# ----------------------------------------------------------------------
# Projection onto the probability simplex (Σx = 1, x ≥ 0)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """ Euclidean projection of v onto the simplex Σx=1, x≥0. """
    if np.sum(v) == 1.0 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Adam optimiser on the simplex (smooth max + variance penalty)
# ----------------------------------------------------------------------
def _adam_optimize(
    a0: np.ndarray,
    n: int,
    start_time: float,
    deadline: float,
    best_a: np.ndarray,
    best_val: float,
    target_val: float = 1.503,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser that minimises
        L(a) = 2·n·smooth_max(a) + λ·Var(conv(a,a)),
    where λ is linearly annealed from λ_start to 0.
    Simplex constraint Σa=1 is enforced via logits (soft‑max).
    """
    w = np.log(a0 + 1e-12)               # logits
    beta1, beta2 = 0.90, 0.999
    lr_start, lr_end = 0.25, 0.001
    eps_start, eps_end = 0.8, 1e-8

    lam_start = 15.0 * n                  # stronger variance penalty
    lam_end = 0.0

    m = np.zeros_like(w)
    v = np.zeros_like(w)
    t = 0
    idle = 0
    MAX_IDLE = 25000

    while True:
        now = time.time()
        if now >= deadline:
            break

        # ----- obtain current a from logits (soft‑max) -----
        w_shift = w - np.max(w)
        a = np.exp(w_shift)
        a /= a.sum()

        cur_val = _objective(a)
        if cur_val < best_val:
            best_val, best_a = cur_val, a.copy()
            idle = 0
            print(f"[Adam] new best = {best_val:.6f}")
            if best_val <= target_val:
                break
        else:
            idle += 1

        # ----- schedules -----
        progress = (now - start_time) / (deadline - start_time)
        eps = eps_start * (eps_end / eps_start) ** progress
        lr = lr_start * (lr_end / lr_start) ** progress
        lam = lam_start * (1.0 - progress) + lam_end * progress

        # ----- smooth‑max and variance -----
        smooth_val, grad_smooth = _smooth_max_and_grad(a, eps)
        var_val, grad_var = _var_and_grad(a)

        # total gradient of the loss (we minimise it)
        grad_a = grad_smooth + lam * grad_var

        # chain rule through soft‑max
        dot = np.dot(grad_a, a)
        grad_w = a * (grad_a - dot)

        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * grad_w
        v = beta2 * v + (1.0 - beta2) * (grad_w * grad_w)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        w -= lr * m_hat / (np.sqrt(v_hat) + 1e-8)

        # occasional stochastic perturbation (helps escape plateaus)
        if np.random.rand() < 0.010:
            w += np.random.normal(scale=0.015, size=n)

        # restart if we have been idle for too long
        if idle > MAX_IDLE:
            print("[Adam] restart after idle")
            w = np.random.randn(n) * 0.15
            m.fill(0.0)
            v.fill(0.0)
            t = 0
            idle = 0

    return best_a, best_val


# ----------------------------------------------------------------------
# Simulated‑annealing hill‑climbing (fast O(n) local updates)
# ----------------------------------------------------------------------
def _hillclimb_anneal(
    a0: np.ndarray,
    n: int,
    start_time: float,
    deadline: float,
    best_a: np.ndarray,
    best_val: float,
    target_val: float = 1.503,
) -> tuple[np.ndarray, float]:
    """
    Local search that moves a small amount of mass from an index that
    contributes heavily to the current maximal convolution entry to an index
    that contributes little.
    """
    a = a0.copy()
    b = _full_convolution(a)
    cur_val = 2.0 * n * b.max()
    eps = 1e-12

    # schedules
    max_frac_start, max_frac_end = 0.55, 0.001
    temp_start, temp_end = 0.02, 1e-7
    no_improve = 0
    IMPROVE_LIMIT = 120_000

    while True:
        now = time.time()
        if now >= deadline:
            break

        progress = (now - start_time) / (deadline - start_time)
        max_frac = max_frac_start * (1.0 - progress) + max_frac_end * progress
        T = temp_start * (temp_end / temp_start) ** progress

        # current maximal convolution entry
        k_max = int(np.argmax(b))

        # contribution of each index to that entry
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        contrib = np.zeros_like(a)
        contrib[mask] = a[mask] * a[idx[mask]]
        tot_contrib = contrib.sum()

        # source index – probabilistic, weighted by contribution
        if tot_contrib > 0:
            src_probs = contrib / tot_contrib
            i = np.random.choice(n, p=src_probs)
        else:
            i = int(np.argmax(a))

        if a[i] <= eps:
            continue

        # target index – prefers indices with low contribution
        tgt_w = np.zeros_like(a)
        tgt_w[mask] = 1.0 / (contrib[mask] + eps)
        tgt_w[i] = 0.0
        wsum = tgt_w.sum()
        if wsum > 0:
            j = np.random.choice(n, p=tgt_w / wsum)
        else:
            # uniform fallback
            j = np.random.randint(n - 1)
            if j >= i:
                j += 1

        # amount of mass to move
        delta = a[i] * np.random.rand() * max_frac
        if delta <= 0.0:
            continue

        # incremental update of the convolution (O(n))
        b_new = b.copy()
        b_new[j:j + n] += 2.0 * delta * a
        b_new[i:i + n] -= 2.0 * delta * a
        b_new[2 * j] += delta * delta
        b_new[2 * i] += delta * delta
        b_new[i + j] -= 2.0 * delta * delta

        new_max = b_new.max()
        new_val = 2.0 * n * new_max

        # Metropolis acceptance
        accept = False
        if new_val < cur_val - 1e-15:
            accept = True
        elif T > 0:
            prob = np.exp(-(new_val - cur_val) / T)
            if np.random.rand() < prob:
                accept = True

        if accept:
            a[i] -= delta
            a[j] += delta
            b = b_new
            cur_val = new_val
            no_improve = 0
            if new_val < best_val - 1e-12:
                best_val, best_a = new_val, a.copy()
                print(f"[Hill] new best = {best_val:.6f}")
                if best_val <= target_val:
                    break
        else:
            no_improve += 1

        if no_improve > IMPROVE_LIMIT:
            # perturbation to escape a plateau
            a = best_a.copy()
            noise = np.random.normal(scale=0.025, size=n)
            a = np.maximum(a + noise, 0.0)
            a /= a.sum()
            b = _full_convolution(a)
            cur_val = 2.0 * n * b.max()
            no_improve = 0
            print("[Hill] stagnation – random perturbation")

    return best_a, best_val


# ----------------------------------------------------------------------
# Exact sub‑gradient polishing (uses the true max, not a smooth proxy)
# ----------------------------------------------------------------------
def _subgradient_polish(
    a0: np.ndarray,
    n: int,
    start_time: float,
    deadline: float,
    best_a: np.ndarray,
    best_val: float,
    target_val: float = 1.503,
) -> tuple[np.ndarray, float]:
    """
    Few projected sub‑gradient steps on the true max(conv(a,a)).
    Very small step sizes are used; the procedure is quick and helps shave
    off the last fractional improvements.
    """
    a = a0.copy()
    step = 0.02  # initial step – will be decayed
    while True:
        now = time.time()
        if now >= deadline:
            break
        b = _full_convolution(a)
        k = int(np.argmax(b))          # index of the current maximum
        # gradient of max conv w.r.t. a: g_j = 2 * a_{k-j} (if index valid)
        g = np.zeros_like(a)
        idx = k - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        g[mask] = 2.0 * a[idx[mask]]
        a -= step * g
        a = _project_simplex(a)
        cur_val = 2.0 * n * b.max()
        if cur_val < best_val - 1e-12:
            best_val, best_a = cur_val, a.copy()
            print(f"[SubGrad] new best = {best_val:.6f}")
            if best_val <= target_val:
                break
        # geometric decay of step size
        step *= 0.995
        if step < 1e-5:
            break
    return best_a, best_val


# ----------------------------------------------------------------------
# Parametric Beta family sweep (quick cheap initial candidates)
# ----------------------------------------------------------------------
def _beta_family_best(n: int) -> tuple[np.ndarray, float]:
    """Search a two‑parameter Beta family a_i ∝ i^{p‑1}(n‑i+1)^{q‑1}."""
    best_a = None
    best_val = np.inf
    p_vals = np.concatenate([np.linspace(0.1, 1.0, 9),
                             np.geomspace(1.0, 6.0, 7)[1:]])
    q_vals = p_vals.copy()
    i = np.arange(1, n + 1, dtype=np.float64)

    for p in p_vals:
        for q in q_vals:
            a = (i ** (p - 1.0)) * ((n - i + 1) ** (q - 1.0))
            s = a.sum()
            if s == 0.0:
                continue
            a /= s
            val = _objective(a)
            if val < best_val:
                best_val, best_a = val, a.copy()
    return best_a, best_val


# ----------------------------------------------------------------------
# Main entry point required by the evaluation framework
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Optimise a non‑negative step‑function under the 1000 s budget.
    Returns a plain Python list (sum will be 1 after normalisation).
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5          # safety margin for final call

    # problem size – 8000 offers a good trade‑off between expressivity and speed
    n = 8000

    best_a = None
    best_val = np.inf

    # ------------------------------------------------------------------
    # 1️⃣  Initialise from a previously best construction if available
    # ------------------------------------------------------------------
    try:
        old = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        old_len = old.shape[0]
        new_x = np.linspace(0.0, 1.0, n)
        old_x = np.linspace(0.0, 1.0, old_len)
        a0 = np.interp(new_x, old_x, old)
        a0 = np.maximum(a0, 0.0)
        a0 /= a0.sum()
        val = _objective(a0)
        best_a, best_val = a0.copy(), val
        print(f"[Init] interpolated previous solution, value={best_val:.6f}")
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 2️⃣  Cheap exploratory candidates (Beta sweep + few Dirichlet draws)
    # ------------------------------------------------------------------
    try:
        beta_a, beta_val = _beta_family_best(n)
        if beta_val < best_val:
            best_a, best_val = beta_a, beta_val
            print(f"[Init] beta‑family sweep improved value={best_val:.6f}")
    except Exception as exc:
        print("[Init] beta family failed:", exc)

    for _ in range(4):
        # Dirichlet draws with concentration 0.5 produce a somewhat sparse start
        rand_a = np.random.dirichlet(np.full(n, 0.5))
        val = _objective(rand_a)
        if val < best_val:
            best_a, best_val = rand_a, val
            print(f"[Init] random Dirichlet improved value={best_val:.6f}")

    # ------------------------------------------------------------------
    # Main optimisation loop – run independent cycles until time is gone
    # ------------------------------------------------------------------
    cycle = 0
    while True:
        now = time.time()
        remaining = deadline - now
        if remaining < 30.0:                # keep a slack for the final evaluation
            break

        cycle += 1
        print(f"\n--- Cycle {cycle} (remaining {remaining:.1f}s) ---")

        # ---------- pick a fresh start ----------
        # Mix the current best with noise to diversify the start
        noise = np.random.normal(scale=0.03, size=n)
        start_a = best_a * 0.7 + np.maximum(noise, 0.0)
        start_a = np.maximum(start_a, 0.0)
        start_a /= start_a.sum()

        # ---------- allocate time for the three phases ----------
        # 30 % Adam, 55 % hill‑climb, 10 % sub‑gradient, 5 % spare
        t_adam = now + 0.30 * remaining
        t_hill = t_adam + 0.55 * remaining
        t_sub  = t_hill + 0.10 * remaining

        # ---------- Adam ----------
        best_a, best_val = _adam_optimize(
            a0=start_a,
            n=n,
            start_time=now,
            deadline=t_adam,
            best_a=best_a,
            best_val=best_val,
            target_val=1.503,
        )

        # ---------- Hill‑climbing ----------
        best_a, best_val = _hillclimb_anneal(
            a0=best_a,
            n=n,
            start_time=t_adam,
            deadline=t_hill,
            best_a=best_a,
            best_val=best_val,
            target_val=1.503,
        )

        # ---------- Sub‑gradient polishing ----------
        best_a, best_val = _subgradient_polish(
            a0=best_a,
            n=n,
            start_time=t_hill,
            deadline=t_sub,
            best_a=best_a,
            best_val=best_val,
            target_val=1.503,
        )

        print(f"[Cycle {cycle}] best value so far = {best_val:.6f}")

        # Early exit if we have already reached the target bound
        if best_val <= 1.503:
            print("[Info] target achieved – exiting early")
            break

    # ------------------------------------------------------------------
    # Final evaluation (uses the provided secure wrapper)
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] reported score = {final_score:.6f}")
    except Exception as exc:               # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_a.tolist()
```
