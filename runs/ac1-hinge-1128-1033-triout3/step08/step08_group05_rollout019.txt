Propose a non‑negative step function (list of heights) that lowers the

Algorithm
---------
The search consists of three long‑running stages plus a final polish.

1️⃣  **Adam optimisation of a smooth surrogate** – we minimise
    the log‑sum‑exp approximation of the max‑convolution
    (the same surrogate used in the reference code) but with the
    Adam optimiser instead of L‑BFGS.  A schedule of smoothing
    parameters ε from 1e‑1 down to 1e‑16 is used; for each ε we run
    a few thousand Adam steps.  The decision variables are the
    unconstrained soft‑max parameters `w`, i.e. `a_i = exp(w_i)/∑exp(w)`.

2️⃣  **Exact mirror‑descent on the true max‑convolution** – after the
    surrogate pass we perform many exponential mirror‑descent updates
    using the exact sub‑gradient of `max(a*a)`.  The step‑size decays
    very slowly, allowing the iterates to wander around the best point
    found in stage 1.

3️⃣  **Long simulated‑annealing hill‑climber** – a cheap but very
    thorough stochastic optimiser that repeatedly moves a small
    fraction of mass from a “heavy” index to a “light” one, accepts
    uphill moves with a temperature that is slowly cooled, and also
    tries random swaps.  This stage is responsible for the final
    few‑hundredths of improvement.

4️⃣  **Final polishing** – a tiny random‑swap hill‑climber that only
    accepts strict improvements (as in the reference code).

All stages respect a global deadline (≈ 1000 s) and keep the best
sequence seen so far.  At the end we call the official
`evaluate_sequence` once for a safety check and return the list of
heights.

The implementation is deliberately self‑contained, uses only NumPy,
SciPy and the standard library, and avoids any filesystem or network I/O.

import numpy as np
from scipy.fft import rfft, irfft
from scipy.special import logsumexp

# Helper functions – all top‑level, no closures
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x (used for zero‑padding FFT)."""
    return 1 << (x - 1).bit_length()


def _full_convolution(a: np.ndarray) -> np.ndarray:
    """
    Linear convolution a*a (full length 2·len(a)‑1) using an FFT of power‑of‑2 size.
    The result is clipped to non‑negative values to avoid tiny negatives from
    round‑off errors.
    """
    n = a.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fa = rfft(a, size)
    conv = irfft(fa * fa, size)[:out_len]
    np.maximum(conv, 0.0, out=conv)
    return conv


def _softmax(w: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max that returns a probability vector."""
    w_shift = w - np.max(w)
    exp_w = np.exp(w_shift)
    return exp_w / exp_w.sum()


def _smooth_obj_and_grad(w: np.ndarray, eps: float, n: int) -> tuple[float, np.ndarray]:
    """
    Smoothed surrogate for 2·n·max(a*a) and its gradient w.r.t. the
    soft‑max parameters w.

    The surrogate is::
        L = 2·n·M + 2·n·ε·log Σ_k exp((c_k‑M)/ε)
    where M = max(c) and c = a*a (full convolution).

    Returns
    -------
    L : float
        The objective value.
    grad_w : np.ndarray
        Gradient w.r.t. w (same shape as w).
    """
    # soft‑max → a
    a = _softmax(w)                               # a_i ≥ 0, Σ a_i = 1

    # convolution
    conv = _full_convolution(a)                   # length 2·n‑1
    M = conv.max()

    # smooth max term
    shifted = (conv - M) / eps
    log_sum = logsumexp(shifted)
    L = 2.0 * n * M + 2.0 * n * eps * log_sum

    # gradient wrt a
    # weights for the log‑sum‑exp term
    wts = np.exp(shifted)
    p = wts / wts.sum()                           # distribution over lag indices

    # derivative of Σ p_k·conv_k w.r.t. a is 2·a ⊛ p_rev
    p_rev = p[::-1]
    size = _next_pow2(len(a) + len(p_rev) - 1)
    fa = rfft(a, size)
    fp = rfft(p_rev, size)
    conv_ap = irfft(fa * fp, size)[: len(a) + len(p_rev) - 1]

    # the part that aligns with a (indices n‑1 … 2·n‑2)
    seg = conv_ap[n - 1: 2 * n - 1]               # length n
    grad_a = 2.0 * n * seg[::-1]                  # reverse back to a‑order

    # chain rule through soft‑max
    dot = np.dot(grad_a, a)
    grad_w = a * (grad_a - dot)

    return L, grad_w


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex.
    Implementation of the algorithm by Wang & Carreira‑Perpiñán (2013).
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w


def _fast_evaluate(a: np.ndarray) -> float:
    """
    Fast version of ``evaluate_sequence`` for vectors that already sum to 1.
    Returns   2·n·max(conv) .
    """
    n = a.shape[0]
    conv = _full_convolution(a)
    max_b = conv.max()
    return 2.0 * n * max_b
