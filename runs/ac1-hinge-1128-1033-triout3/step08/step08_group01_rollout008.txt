The goal is to find a non‑negative vector `a` (∑a = 1) that minimises  

```
F(a) = 2·n·max(conv(a,a))
```

where `conv` is the linear convolution of `a` with itself.  
The value `F(a)` is exactly what `evaluate_sequence` returns (after the
internal normalisation checks).

The optimisation consists of three stages that respect the time budget:

1. **Diverse initialisation** – a sweep over several parametric families
   (uniform, exponential, triangular, power‑law and an *arcsine* shape)
   together with a few random Dirichlet draws.  
   The best of those candidates is kept.

2. **Smooth gradient descent** – the max‑convolution is approximated by a
   temperature‑controlled soft‑max (log‑sum‑exp).  
   Using the analytic gradient  

   ```
   ∂/∂a  2·n·∑_k p_k (a⋆a)_k = 4·n·conv(a , p_rev)
   ```

   (with `p` the soft‑max weights) we perform a projected gradient step
   on the probability simplex.  The learning‑rate and temperature decrease
   steadily, driving the optimisation towards the true max.

3. **Targeted hill‑climbing** – the exact objective is now cheap to evaluate.
   At each iteration the index `k_max` that yields the current maximal
   convolution entry is identified.  
   A source index `i` is chosen proportionally to its contribution to that
   entry, a destination index `j` is chosen where the contribution is small,
   and a small amount of mass `δ` is moved from `i` to `j`.  
   The convolution update is performed in *O(n)* using an incremental
   formula, and the move is accepted only if the true objective decreases.

Finally a tiny mixture with the uniform distribution is tried – this often
lowers the peak a little more.

All phases stop automatically when the allocated part of the 1000 s budget
is exhausted, guaranteeing that a valid vector is always returned.

The implementation uses only `numpy`; FFT‑based convolutions keep the per‑iteration
cost low even for vectors of length 10 000.

```python
"""
Optimise a step‑function (non‑negative vector, Σ = 1) to minimise
    2·n·max(conv(a,a))

Algorithm
---------
1.  Generate a diverse set of initial candidates (uniform, exponential,
    triangular, power‑law, arcsine, random Dirichlet) and keep the best.

2.  Smooth gradient descent on the log‑sum‑exp approximation of the max:
        • temperature τ → 0   (soft‑max over convolution entries)
        • learning‑rate decays
        • each step: a ← proj_simplex( a – η·grad ),   grad = 4·n·conv(a,p_rev)

3.  Exact hill‑climbing on the true objective:
        • locate the maximal convolution index k_max
        • pick a source i with probability proportional to its contribution
          a_i·a_{k_max‑i}
        • pick a destination j where the contribution is small
        • move a small amount δ from i to j and accept if the objective improves

4.  Mix a tiny amount of uniform mass (α ∈ {0.001,…,0.02}) and keep the best.

The whole procedure respects the given time budget (default 1000 s) and
returns a list of floats ready for `evaluate_sequence`.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution helpers (FFT based, linear convolution)
# ----------------------------------------------------------------------
def _full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution of `a` with itself (length 2·len(a)‑1)."""
    n = a.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()        # next power of two
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Exact objective (assumes Σa = 1)
# ----------------------------------------------------------------------
def _objective_val(a: np.ndarray) -> float:
    """Return 2·n·max(conv(a,a)) for a probability vector `a`."""
    n = a.shape[0]
    return float(2.0 * n * _full_convolution(a).max())


# ----------------------------------------------------------------------
# Simple Euclidean projection onto the probability simplex
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Project v onto {w ≥ 0, Σ w = 1}."""
    if np.abs(v.sum() - 1.0) < 1e-12 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.where(u - cssv / (np.arange(len(v)) + 1) > 0)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Parametric families for initialisation (uniform, exponential, …)
# ----------------------------------------------------------------------
def _initial_candidate(n: int):
    """Return a promising probability vector and its objective."""
    best_a = np.full(n, 1.0 / n)
    best_val = _objective_val(best_a)

    def _try(vec):
        nonlocal best_a, best_val
        a = np.asarray(vec, dtype=np.float64)
        if a.ndim != 1 or a.shape[0] != n:
            return
        if np.any(a < 0):
            return
        s = a.sum()
        if s <= 0:
            return
        a = a / s
        val = _objective_val(a)
        if val < best_val:
            best_val, best_a = val, a.copy()

    # uniform
    _try(np.ones(n))

    # exponential (left‑hand side)
    for r in (0.9999, 0.9997, 0.9995, 0.999, 0.998):
        a = r ** np.arange(n, dtype=float)
        _try(a)

    # symmetric exponential (U‑shaped)
    for r in (0.9999, 0.9997, 0.9995, 0.999):
        i = np.arange(n, dtype=float)
        a = r ** i + r ** (n - 1 - i)
        _try(a)

    # power‑law symmetric
    for p in (0.5, 1.0, 1.5, 2.0):
        i = np.arange(1, n + 1, dtype=float)
        a = i ** (-p) + (n - i + 1) ** (-p)
        _try(a)

    # half‑wave sine (zero at ends, peak in centre)
    a = np.sin(np.pi * (np.arange(1, n + 1) / (n + 1)))
    _try(a)

    # triangular (peak in centre, zero at ends)
    i = np.arange(n, dtype=float)
    a = np.minimum(i, n - 1 - i)
    _try(a)

    # arcsine‑type shape  a_i ∝ 1/√( (i+0.5)*(n‑0.5‑i) )
    i = np.arange(n, dtype=float)
    a = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i))
    _try(a)

    # random Dirichlet draws – a few quick samples
    rng = np.random.default_rng(12345)
    for _ in range(15):
        a = rng.dirichlet(np.ones(n))
        _try(a)

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 1 – smooth (log‑sum‑exp) gradient descent on the max‑convolution
# ----------------------------------------------------------------------
def _smooth_gradient_descent(a0: np.ndarray,
                             start: float,
                             deadline: float,
                             best_a: np.ndarray,
                             best_val: float) -> tuple[np.ndarray, float]:
    """
    Projected gradient descent on
        2·n·log‑sum‑exp((a*a)/τ)   (τ → 0)
    The update rule uses the closed‑form gradient 4·n·conv(a, p_rev)
    where p is the soft‑max over convolution entries.
    """
    n = a0.shape[0]
    a = a0.copy()

    # schedules
    lr_start, lr_end = 0.7, 0.02
    tau_start, tau_end = 0.2, 1e-8
    eps = 1e-12   # to avoid division by zero

    it = 0
    while time.time() < deadline:
        progress = (time.time() - start) / (deadline - start)
        lr = lr_start * (lr_end / lr_start) ** progress
        tau = tau_start * (tau_end / tau_start) ** progress

        # current objective (exact)
        cur_val = _objective_val(a)
        if cur_val < best_val - 1e-12:
            best_val, best_a = cur_val, a.copy()
            print(f"[Smooth {it:6d}] new best = {best_val:.6f}")

        # convolution and smooth max weights
        b = _full_convolution(a)                # length 2·n‑1
        max_b = b.max()
        shifted = (b - max_b) / (tau + eps)     # ≤ 0
        # stable soft‑max
        exp_shift = np.exp(shifted - np.max(shifted))
        p = exp_shift / exp_shift.sum()

        # gradient of smoothed objective
        conv_ab = _conv_fft(a, p[::-1])        # length 3·n‑2
        grad = 4.0 * n * conv_ab[n - 1:2 * n - 1]  # segment of length n

        # gradient step and projection onto simplex
        a = a - lr * grad
        a = _project_simplex(a)

        # small jitter occasionally to escape plateaus
        if np.random.rand() < 0.004:
            a = _project_simplex(a + np.random.normal(scale=0.003, size=n))

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 2 – targeted hill‑climbing on the exact max‑convolution
# ----------------------------------------------------------------------
def _hillclimb_targeted(a_start: np.ndarray,
                        start: float,
                        deadline: float,
                        best_a: np.ndarray,
                        best_val: float) -> tuple[np.ndarray, float]:
    """
    Exact hill‑climbing:
        – locate the index k where (a*a)_k is maximal,
        – move a small fraction of mass from a contributing index i
          to a weakly‑contributing index j,
        – accept the move only if the true objective improves.
    """
    a = a_start.copy()
    n = a.shape[0]
    b = _full_convolution(a)
    cur_val = 2.0 * n * b.max()

    # fraction of mass that may be moved (annealed)
    frac_start, frac_end = 0.30, 0.001
    IMPROVE_LIMIT = 250_000
    no_improve = 0
    it = 0

    while time.time() < deadline:
        progress = (time.time() - start) / (deadline - start)
        max_frac = frac_start * (1.0 - progress) + frac_end * progress

        k_max = int(np.argmax(b))

        # contributions of each index to the maximal entry
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        contrib = np.zeros_like(a)
        contrib[mask] = a[mask] * a[idx[mask]]
        total_contrib = contrib.sum()

        # choose source index (weighted by contribution)
        if total_contrib > 0:
            probs_i = contrib / total_contrib
            i = np.random.choice(n, p=probs_i)
        else:
            i = int(np.argmax(a))

        # choose destination index – prefer indices with little impact
        # on the maximal entry (inverse of the reversed contribution)
        rev_idx = k_max - np.arange(n)
        rev_mask = (rev_idx >= 0) & (rev_idx < n)
        rev_contrib = np.zeros(n)
        rev_contrib[rev_mask] = a[rev_idx[rev_mask]]
        w = 1.0 / (rev_contrib + 1e-12)
        w[i] = 0.0                               # never move back to i
        if w.sum() > 0:
            probs_j = w / w.sum()
            j = np.random.choice(n, p=probs_j)
        else:
            # fallback – any different index
            j = (i + np.random.randint(1, n)) % n

        # amount of mass to move
        delta = a[i] * np.random.rand() * max_frac
        if delta <= 1e-15:
            continue

        # incremental convolution update (O(n))
        b_new = b.copy()
        # add contribution from new mass at j
        b_new[j:j + n] += 2.0 * delta * a
        # remove contribution from removed mass at i
        b_new[i:i + n] -= 2.0 * delta * a
        # self‑terms at positions 2·i, 2·j, i+j
        b_new[2 * j] += delta * delta
        b_new[2 * i] += delta * delta
        b_new[i + j] -= 2.0 * delta * delta

        new_val = 2.0 * n * b_new.max()

        if new_val < cur_val - 1e-15:
            # accept move
            a[i] -= delta
            a[j] += delta
            b = b_new
            cur_val = new_val
            no_improve = 0
            if new_val < best_val - 1e-12:
                best_val, best_a = new_val, a.copy()
                print(f"[Hill   {it:6d}] new best = {best_val:.6f}")
        else:
            no_improve += 1

        if no_improve > IMPROVE_LIMIT:
            # perturb from the current best to escape stagnation
            a = best_a.copy()
            a += np.random.normal(scale=0.008, size=n)
            a = _project_simplex(a)
            b = _full_convolution(a)
            cur_val = 2.0 * n * b.max()
            no_improve = 0
            print(f"[Hill   {it:6d}] perturbing after stagnation")

        it += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 3 – final tiny uniform mixing
# ----------------------------------------------------------------------
def _mix_with_uniform(a: np.ndarray, n: int) -> tuple[np.ndarray, float]:
    """Try a few convex combinations (1‑α)·a + α·uniform."""
    best_a, best_val = a, _objective_val(a)
    uniform = np.full(n, 1.0 / n)
    for alpha in (0.001, 0.003, 0.006, 0.010, 0.015, 0.020):
        cand = (1.0 - alpha) * a + alpha * uniform
        cand = _project_simplex(cand)
        val = _objective_val(cand)
        if val < best_val:
            best_val, best_a = val, cand
    return best_a, best_val
```
