assistantfinal**Solution Overview**

The objective  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}
\]

is invariant under scaling of the vector `a`.  
We therefore optimise a **probability vector** (sum = 1) and later let the
scaling happen automatically.

* **Symmetry** – the optimal step function is expected to be symmetric.
  We represent a length `n` vector by a half‑vector `x` of length `m=n/2`
  (for even `n`).  
  `a = [x, x[::-1]]` .  
  This reduces the number of optimisation variables by a factor two.

* **Parametrisation** – we enforce non‑negativity by a soft‑max
  (`x = softmax(w)`).  The optimisation variables are the unconstrained
  real vector `w`.

* **Smooth surrogate** – the non‑smooth `max` is replaced by a
  log‑sum‑exp (LSE) with a temperature `ε`:

\[
\operatorname{LSE}_ε(b)=ε\log\Bigl(\sum_i e^{b_i/ε}\Bigr)
\]

  As `ε → 0` the LSE converges to `max(b)`.  
  For a fixed `ε` the surrogate is smooth and we can write an exact
  gradient.

* **Gradient** – using the convolution theorem the gradient of the
  surrogate with respect to `w` can be expressed by three FFT‑based
  convolutions only ( `O(n log n)` ).

* **Continuation + L‑BFGS‑B** – we start with a large temperature
  (`ε=0.1`) and successively halve it down to `1e‑4`.  
  For every temperature we run a short L‑BFGS‑B optimisation (max
  120 iterations).  The result of one stage is the start point of the
  next, which yields a continuation method that tracks the true optimum.

* **Multiple restarts** – several random starts (plus an optional start
  from the previous best solution) are performed until the time budget
  is exhausted.  The best candidate found so far is kept.

* **Final polishing** – a tiny amount of uniform mass (`α∈[10⁻³,2·10⁻²]`)
  is mixed into the best vector; this often reduces the peak of the
  convolution a little more.

All heavy lifting (convolution, gradient, L‑BFGS) is done with NumPy
and SciPy, which comfortably fits into the 1000 s budget even for
`n = 8000`.

```python
"""Step‑function optimisation for the evaluation function.

The algorithm:
1.  Represent a symmetric step function a of length n by a half‑vector x
    (soft‑max of an unconstrained vector w).
2.  minimise a smooth log‑sum‑exp surrogate of 2·n·max(a*a) with L‑BFGS‑B
    for a decreasing sequence of temperatures ε.
3.  Perform several random restarts (and optionally a deterministic start
    from the previous best solution) within the time budget.
4.  After optimisation, try a few tiny mixtures with the uniform vector
    to lower the peak further.
5.  Return the best vector found (the scaling does not affect the score).

The code is self‑contained; only `numpy`, `scipy.optimize` and
`scipy.special` are required.
"""

import time
import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp

# ----------------------------------------------------------------------
# Global variables (filled by propose_candidate before optimisation)
# ----------------------------------------------------------------------
CURRENT_N = None          # full length of the step function (even)
CURRENT_M = None          # half‑length (n // 2)
CURRENT_EPS = None        # temperature for the smooth max
EVEN = True               # we use an even length only

# ----------------------------------------------------------------------
# Convolution helpers (FFT, linear convolution)
# ----------------------------------------------------------------------
def _full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a * a (length 2·len(a)-1)."""
    n = a.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()        # next power of two
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using FFT."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Soft‑max and construction of the full symmetric vector
# ----------------------------------------------------------------------
def _softmax(w: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max."""
    w_shift = w - np.max(w)
    e = np.exp(w_shift)
    return e / np.sum(e)


def _construct_a(w: np.ndarray) -> np.ndarray:
    """
    From a parameter vector w (length m) build the full symmetric step
    function a (length CURRENT_N).  No explicit normalisation is performed;
    scaling does not affect the objective.
    """
    x = _softmax(w)                     # x ≥ 0, Σx = 1
    if EVEN:
        # a = [x, x[::-1]]
        a = np.concatenate([x, x[::-1]])
    else:
        # odd length – centre element appears only once
        a = np.concatenate([x, x[-2::-1]])
    return a


# ----------------------------------------------------------------------
# Smooth objective and its gradient (w.r.t. the unconstrained parameters w)
# ----------------------------------------------------------------------
def _objective_and_grad(w: np.ndarray):
    """
    Returns (value, grad) of the smooth surrogate
        2·n·ε·logsumexp( (a*a)/ε )
    where a = _construct_a(w).
    The gradient is derived analytically and uses only FFTs.
    """
    # unpack global parameters
    n = CURRENT_N
    m = CURRENT_M
    eps = CURRENT_EPS

    # a = R·softmax(w)
    x = _softmax(w)
    if EVEN:
        a = np.concatenate([x, x[::-1]])
    else:
        a = np.concatenate([x, x[-2::-1]])

    # ----- smooth max (log‑sum‑exp) -----
    b = _full_convolution(a)                 # length 2·n‑1
    smooth_max = eps * logsumexp(b / eps)    # ε·log∑exp(b/ε)
    value = 2.0 * n * smooth_max

    # ----- gradient -----
    # soft‑max over convolution entries
    max_b = b.max()
    shifted = (b - max_b) / eps
    weights = np.exp(shifted)
    p = weights / weights.sum()               # shape (2·n‑1,)

    # convolution of a with reversed p
    p_rev = p[::-1]
    conv_ab = _conv_fft(a, p_rev)            # length 3·n‑2
    # central part corresponds to ∂/∂a of the smooth max
    segment = conv_ab[n - 1: 2 * n - 1]       # length n
    grad_a = 4.0 * n * segment[::-1]          # ∂F/∂a

    # map gradient from a back to the half‑vector x
    if EVEN:
        left = grad_a[:m]
        right = grad_a[-m:][::-1]
        grad_x = left + right
    else:
        left = grad_a[:m - 1]
        right = grad_a[-(m - 1):][::-1]
        grad_x = np.empty(m)
        grad_x[:m - 1] = left + right
        grad_x[m - 1] = grad_a[m - 1]

    # chain rule through the soft‑max (log‑soft‑max)
    dot = np.dot(grad_x, x)
    grad_w = x * (grad_x - dot)

    return value, grad_w


# ----------------------------------------------------------------------
# Quick hill‑climbing refinement (optional, cheap)
# ----------------------------------------------------------------------
def _hillclimb(a: np.ndarray, deadline: float, best_val: float):
    """Small stochastic hill‑climbing that moves a little mass around."""
    n = a.shape[0]
    cur_a = a.copy()
    cur_val = best_val
    rng = np.random.default_rng()

    # pre‑compute a factor that appears in the denominator (constant)
    while time.time() < deadline:
        # pick source proportional to its contribution to the current maximum
        conv = _full_convolution(cur_a)
        kmax = int(np.argmax(conv))

        idx = kmax - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        contrib = np.zeros_like(cur_a)
        contrib[mask] = cur_a[mask] * cur_a[idx[mask]]
        total = contrib.sum()
        if total > 0:
            probs = contrib / total
            i = rng.choice(n, p=probs)
        else:
            i = np.argmax(cur_a)

        # choose a target far from the max‑contributing region
        j = rng.integers(0, n)
        if j == i:
            j = (i + 1) % n

        # move a tiny fraction of mass
        delta = cur_a[i] * rng.random() * 0.001
        if delta <= 0:
            continue

        cur_a[i] -= delta
        cur_a[j] += delta

        # evaluate
        new_val = evaluate_sequence(cur_a.tolist())
        if new_val < cur_val:
            cur_val = new_val
            best_val = new_val
        else:
            # revert
            cur_a[i] += delta
            cur_a[j] -= delta

    return cur_a, best_val


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Optimise a non‑negative step function under the given time budget.
    Returns a list of floats; its score is obtained by `evaluate_sequence`.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5          # safety margin

    # problem size – 8000 entries give a good trade‑off
    global CURRENT_N, CURRENT_M, EVEN
    CURRENT_N = 8000
    EVEN = True
    CURRENT_M = CURRENT_N // 2

    # ------------------------------------------------------------------
    # Helper for a single L‑BFGS run over a temperature schedule
    # ------------------------------------------------------------------
    def _run_schedule(w0, eps_schedule, max_iter):
        w = w0.copy()
        for eps in eps_schedule:
            # set the globals used by the objective
            global CURRENT_EPS
            CURRENT_EPS = eps

            # L‑BFGS‑B on the smooth surrogate
            res = minimize(_objective_and_grad,
                           w,
                           method='L-BFGS-B',
                           jac=True,
                           options={'maxiter': max_iter,
                                    'ftol': 1e-14,
                                    'disp': False})
            w = res.x
        return w

    # ------------------------------------------------------------------
    # Initial starting points (deterministic + random)
    # ------------------------------------------------------------------
    start_vectors = []

    # deterministic start from the previous best construction, if available
    try:
        old = np.asarray(height_sequence_1, dtype=float)     # type: ignore[name-defined]
        old_x = np.linspace(0.0, 1.0, old.shape[0])
        new_x = np.linspace(0.0, 1.0, CURRENT_N)
        old_interp = np.interp(new_x, old_x, old)
        # symmetrise and take the first half
        sym = 0.5 * (old_interp + old_interp[::-1])
        x0 = sym[:CURRENT_M]
        w0 = np.log(x0 + 1e-12)
        start_vectors.append(w0)
    except Exception:
        pass

    # a pure uniform start
    start_vectors.append(np.zeros(CURRENT_M))

    # a few random starts
    rng = np.random.default_rng(seed + 123)
    for _ in range(4):
        start_vectors.append(rng.normal(scale=0.5, size=CURRENT_M))

    # ------------------------------------------------------------------
    # Parameters for the continuation schedule
    # ------------------------------------------------------------------
    eps_schedule = [0.1, 0.05, 0.02, 0.01, 0.005,
                    0.002, 0.001, 5e-4, 2e-4, 1e-4]
    max_iter_per_stage = 120

    best_val = np.inf
    best_a = None

    # ------------------------------------------------------------------
    # Main optimisation loop (many restarts until time runs out)
    # ------------------------------------------------------------------
    restart_id = 0
    while time.time() < deadline - 5.0:          # keep 5 s for final polishing
        w0 = start_vectors[restart_id % len(start_vectors)].copy()
        restart_id += 1

        # run the continuation L‑BFGS schedule
        w_opt = _run_schedule(w0, eps_schedule, max_iter_per_stage)

        # build the full vector and evaluate it
        a_candidate = _construct_a(w_opt)
        try:
            val = evaluate_sequence(a_candidate.tolist())
        except Exception:
            val = np.inf

        if val < best_val:
            best_val = val
            best_a = a_candidate.copy()
            print(f"[Restart {restart_id:3d}] new best = {best_val:.6f}")

        # optional cheap hill‑climb if we still have a few seconds left
        if time.time() < deadline - 2.0 and best_a is not None:
            a_refined, refined_val = _hillclimb(best_a, deadline, best_val)
            if refined_val < best_val:
                best_val, best_a = refined_val, a_refined.copy()
                print(f"[HillClimb] improved to {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final polishing – mix a tiny amount of uniform mass
    # ------------------------------------------------------------------
    if best_a is None:
        # fallback – uniform vector
        best_a = np.full(CURRENT_N, 1.0 / CURRENT_N)

    uniform = np.full(CURRENT_N, 1.0 / CURRENT_N)
    for alpha in (0.001, 0.003, 0.005, 0.010, 0.020):
        cand = (1.0 - alpha) * best_a + alpha * uniform
        try:

        except Exception:

            print(f"[Mix] alpha={alpha:.3f} gives {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final evaluation (just for the log)
    # ------------------------------------------------------------------
    try:

        print(f"[final] reported best score = {final_score:.6f}")
    except Exception as exc:               # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_a.tolist()
```
