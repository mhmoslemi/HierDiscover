analysisThe problem: we need to write a propose_candidate function that searches for a sequence that minimizes the evaluation function evaluate_sequence(seq). The evaluation function does the following:

- Input is a list.
- It validates types, ensures non-negative, clamps values between 0 and 1000.
- Computes n = len(sequence).
- Computes b_sequence = np.convolve(sequence, sequence).
- max_b = max(b_sequence).
- sum_a = sum(sequence).
- If sum_a < 0.01, return inf.
- Returns float(2 * n * max_b / (sum_a**2))

Thus our objective is to minimize 2 * n * max_b / (sum_a**2). Since n and sum_a are variables. We want to find a non-negative sequence a_i (i=0..n-1) that maximizes sum_a per max_b, as we want denominator bigger, numerator small.

We could scale any sequence arbitrarily: scaling a_i by factor α scales sum_a linearly (sum_a → α* sum_a), and max_b scales quadratically (max_convolution = α^2 * max_b_original). Then the overall objective 2 n * α^2 max_b_original / (α^2 sum_a_original^2) = 2 n * max_b_original / (sum_a_original^2). So scaling cancels; the objective is homogeneous of degree 0 (scale invariant). Therefore we can restrict sum_a = 1 (or any constant). Indeed the evaluate_sequence will clamp negative and big values but not rescale; you can set sum a = 1 or any positive, but the objective depends only on the shape of distribution.

Thus objective reduces to: For n, minimize 2 n * max(conv) where conv = a * a (full linear convolution). Since sum a = 1, we have to consider probability vectors on n.

Thus the problem is akin to minimizing the maximal autocorrelation value of a probability distribution over a finite interval. Equivalent to constructing a sequence to spread autocorrelation mass thin.

"""
Propose a step‑function (non‑negative vector) that minimizes

    2 * n * max_k (a * a)[k]

where * is the full linear convolution.  The routine works in three phases:

1.  A deterministic sweep over several parametric families (inverse‑distance,
    inverse‑product‑distance, exponential and a two‑exponential mixture) for a
    range of lengths.  The best vector from this sweep seeds the search.

2.  A fast stochastic refinement that stays on the probability simplex.  The
    update uses an exponentiated‑gradient (mirror‑descent) step driven by the
    sub‑gradient of the maximal convolution entry, combined with a simple
    simulated‑annealing acceptance rule, occasional random mass‑transfer moves
    and a reheating mechanism to escape stagnation.

3.  The best vector found is returned as a plain Python list.  All heavy work
    respects the provided time budget (default 1000 s).

The algorithm improves upon the previous implementation by using a mirror‑
descent step (which respects the simplex geometry) and a smoother annealing
schedule, while still performing the exhaustive parametric sweep that gave the
initial good candidates.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Projects a vector onto the probability simplex { w >= 0 , sum(w) = 1 }.
    Implements the O(n log n) algorithm of Wang & Carreira‑Perpiñán.
    """
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = u - (cssv - 1) / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = (cssv[rho] - 1) / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def full_convolution_fft(a: np.ndarray) -> np.ndarray:
    """
    Full linear convolution a * a using a real FFT.
    Returns an array of length 2*len(a)-1.
    """
    n = a.shape[0]
    size = 2 * n
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)
    return conv[: 2 * n - 1]


def compute_subgradient(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of max_k (a*a)[k] w.r.t. a.
    Only indices where the convolution attains (or almost attains) its maximum
    are taken into account.
    """
    max_val = conv.max()
    eps = max_val * 1e-12 + 1e-15
    max_idx = np.where(conv >= max_val - eps)[0]
    n = a.shape[0]
    grad = np.zeros_like(a)
    for k in max_idx:
        start_i = max(0, k - (n - 1))
        end_i = min(n - 1, k)
        i_vals = np.arange(start_i, end_i + 1, dtype=np.int64)
        j_vals = k - i_vals
        grad[i_vals] += 2.0 * a[j_vals]
    return grad


def u_min_distribution(n: int, p: float) -> np.ndarray:
    """
    Symmetric “U‑shape’’ based on distance to the nearest edge:
        a[i] = (min(i, n‑1‑i) + 1)^{-p}
    Normalised to sum = 1.
    """
    d = np.arange(n, dtype=np.float64)
    d = np.minimum(d, n - 1 - d)
    a = (d + 1) ** (-p) + 1e-14
    a /= a.sum()
    return a


def u_prod_distribution(n: int, p: float) -> np.ndarray:
    """
    Symmetric “U‑shape’’ based on the product of distances to both edges:
        a[i] = ((i+1)*(n‑i))^{-p}
    Normalised to sum = 1.
    """
    i = np.arange(n, dtype=np.float64)
    prod = (i + 1) * (n - i)
    a = prod ** (-p) + 1e-14
    a /= a.sum()
    return a


def exp_distribution(n: int, lam: float) -> np.ndarray:
    """
    Symmetric exponential decay from the edges:
        a[i] = exp(-lam*i) + exp(-lam*(n‑1‑i))
    Normalised to sum = 1.
    """
    i = np.arange(n, dtype=np.float64)
    a = np.exp(-lam * i) + np.exp(-lam * (n - 1 - i))
    a = np.maximum(a, 1e-14)
    a /= a.sum()
    return a


def double_exp_distribution(n: int, lam1: float, lam2: float) -> np.ndarray:
    """
    A mixture of two exponentials, symmetric with respect to the centre.
    """
    i = np.arange(n, dtype=np.float64)
    a = (np.exp(-lam1 * i) + np.exp(-lam2 * i) +
         np.exp(-lam1 * (n - 1 - i)) + np.exp(-lam2 * (n - 1 - i)))
    a = np.maximum(a, 1e-14)
    a /= a.sum()
    return a


def score_from_vector(a: np.ndarray) -> float:
    """
    Exact value returned by ``evaluate_sequence`` for a vector that already
    satisfies sum(a) == 1 (the denominator becomes 1).
    """
    n = a.shape[0]
    conv = full_convolution_fft(a)
    return float(2.0 * n * conv.max())

# Main search routine
# ----------------------------------------------------------------------

    function.  The function respects the given CPU‑time budget and returns a
    plain Python list (the external driver will rescale as required).
    """

    best_seq = None
    best_score = np.inf

    # 1. Deterministic sweep over parametric families
    # ------------------------------------------------------------------
    lengths = [2000, 4000, 6000, 8000, 12000, 16000, 20000]
    exponents = np.arange(0.1, 6.01, 0.1)
    lam_vals = np.logspace(-4, -0.5, num=30)   # exponential decay parameters

    print("=== Deterministic sweep start ===")
    for n in lengths:
        if time.time() > deadline:
            break

        # 1a – inverse‑distance (U‑min)
        for p in exponents:
            a = u_min_distribution(n, p)
            sc = score_from_vector(a)
            if sc < best_score:
                best_score = sc
                best_seq = a.copy()
                print(f" new best (U‑min)  n={n:5d} p={p:4.2f}  score={sc:.6f}")

        # 1b – inverse‑product‑distance (U‑prod)
        for p in exponents:
            a = u_prod_distribution(n, p)
            sc = score_from_vector(a)
            if sc < best_score:
