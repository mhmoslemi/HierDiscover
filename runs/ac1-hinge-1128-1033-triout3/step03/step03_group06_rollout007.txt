assistantfinal**Solution Overview**

The evaluation function can be written as  

\[
\text{score}(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the score is *scale invariant* we may normalise the vector to a
probability distribution (`∑a_i = 1`).  
Then  

\[
\text{score}(a)=2\,n\;\max_k (a*a)_k .
\]

The task is therefore to **minimise the maximal entry of the
self‑convolution** of a probability vector.

The algorithm below combines three ideas that improve on the previously
submitted code:

1. **Exact sub‑gradient of the max‑convolution** –  
   the gradient of `max_k (a*a)_k` at a point `a` is obtained from the
   active indices `k` where the maximum is attained.  
   With an FFT this sub‑gradient is computed in `O(n log n)`.

2. **Mirror‑descent on the simplex** –  
   we keep the positivity constraint by a multiplicative update  
   `a ← a·exp(‑η·∇)`, followed by renormalisation onto the simplex.
   The step size `η` follows a decreasing schedule
   `η_t = η₀/√t` and is adapted greedily (increase on success,
   decrease on failure).

3. **Multi‑scale search + simple parametric families** –  
   before the gradient phase we scan a few families of analytically
   tractable shapes (U‑shaped power laws, symmetric exponentials,
   edge‑uniform blocks) for several lengths.  
   The best shape found becomes the seed for the mirror‑descent.
   Afterwards we increase the length (`n≈ 8k → 20k → 40k`) and continue
   optimisation, always propagating the current best vector.

The whole routine respects the 1000 s wall‑time limit, prints progress
information and finally returns the best sequence found.

```python
"""
Propose a non‑negative step sequence that minimises the evaluation metric.

Algorithm
---------
1.  Optionally initialise from the externally provided `height_sequence_1`.
2.  For a set of lengths (8000, 12000, 20000, 40000) do:
      a)  Scan a few parametric families (U‑shape, exponential, edge‑block)
          and keep the vector with the smallest *approximate* score
          (2·n·max(conv) with a cheap FFT).
      b)  Run a mirror‑descent optimiser that works with the **exact**
          sub‑gradient of the max‑convolution.
          * a ← a·exp(‑η·grad)   (η decreasing as 1/√t, greedy adaptation)
          * a is projected back to the probability simplex.
          * Every iteration evaluates the true maximum of the convolution
            (still O(n log n) via FFT) and updates the global best.
          * Occasionally a tiny random jitter is added to escape flat
            regions.
3.  After the time budget the best vector is evaluated with the official
    `evaluate_sequence` and returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top‑level, no closures)
# ----------------------------------------------------------------------


def max_conv_fft(a: np.ndarray) -> float:
    """
    Max entry of the (full) self‑convolution a*a using an FFT.
    a must be a 1‑D non‑negative array; its sum is *not* required to be 1.
    """
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)[: 2 * n - 1]
    return float(conv.max())


def full_conv_fft(a: np.ndarray, size: int) -> np.ndarray:
    """
    Full self‑convolution a*a (length 2·n‑1) using a supplied FFT size.
    Returned array is real.
    """
    A = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(A * A, n=size)[: 2 * a.shape[0] - 1]
    return conv


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection onto the simplex {x | x_i ≥ 0, Σ x_i = 1}.
    O(n log n) implementation (Wang & Carreira‑Perpiñán 2013).
    """
    if v.ndim != 1:
        raise ValueError("project_to_simplex expects a 1‑D array")
    n = v.size
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries become equal
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def resample_distribution(old: np.ndarray, new_n: int) -> np.ndarray:
    """
    Linear interpolation of a probability vector `old` (sum = 1) to length
    `new_n`; the result is re‑normalised.
    """
    old_n = old.shape[0]
    if old_n == new_n:
        return old.copy()
    x_old = np.linspace(0.0, 1.0, old_n)
    x_new = np.linspace(0.0, 1.0, new_n)
    new = np.interp(x_new, x_old, old)
    new += 1e-14                     # avoid exact zeros
    new /= new.sum()
    return new


# ----------------------------------------------------------------------
# Parametric families – cheap source of good initial vectors
# ----------------------------------------------------------------------


def u_shaped_distribution(n: int, p: float) -> np.ndarray:
    """Symmetric power‑law “U‑shape” (larger values at the two ends)."""
    d = np.arange(n)
    d = np.minimum(d, n - 1 - d)          # distance to nearest edge
    a = (d + 1) ** (-p) + 1e-14
    a /= a.sum()
    return a


def exponential_distribution(n: int, lam: float) -> np.ndarray:
    """Symmetric exponential decay from the edges towards the centre."""
    i = np.arange(n, dtype=float)
    a = np.exp(-lam * i) + np.exp(-lam * (n - 1 - i))
    a += 1e-14
    a /= a.sum()
    return a


def edge_block_distribution(n: int, m: int) -> np.ndarray:
    """
    Uniform mass on the first `m` and the last `m` entries,
    zero elsewhere (symmetric “block” shape).
    """
    if m * 2 > n:
        m = n // 2
    a = np.zeros(n, dtype=float)
    a[:m] = 1.0
    a[-m:] = 1.0
    a /= a.sum()
    return a


# ----------------------------------------------------------------------
# Exact sub‑gradient of max‑convolution
# ----------------------------------------------------------------------


def maxconv_and_subgradient(a: np.ndarray, size: int):
    """
    Returns (max_val, gradient) where
        max_val = max_k (a*a)_k
        gradient  = d/d a  max_k (a*a)_k   (sub‑gradient)
    The gradient is computed by convolution of the active‑mask with the
    reversed vector (see analysis). The gradient has the same length as `a`.
    """
    n = a.shape[0]
    # ----- convolution a*a ------------------------------------------------
    A = np.fft.rfft(a, n=size)
    conv_full = np.fft.irfft(A * A, n=size)[: 2 * n - 1]
    max_val = conv_full.max()

    # ----- active mask (average over all maximising positions) ----------
    # tolerance guards against floating‑point ties
    eps = max_val * 1e-12 + 1e-20
    mask = (conv_full >= max_val - eps).astype(np.float64)
    mask_sum = mask.sum()
    if mask_sum > 1.0:
        mask /= mask_sum          # average the contribution

    # ----- gradient = 2 * (mask * a_rev) evaluated at indices n‑1 … 2n‑2 --
    a_rev = a[::-1]
    A_rev = np.fft.rfft(a_rev, n=size)
    W = np.fft.rfft(mask, n=size)
    conv_mask = np.fft.irfft(W * A_rev, n=size)[: 3 * n - 2]
    grad = 2.0 * conv_mask[(n - 1):(n - 1 + n)]
    return max_val, grad

                global_best_score = cur_score
                global_best_seq = a.copy()
                print(f"Iter {iteration:5d} – new global best: {cur_score:.6f}")

                if global_best_score < 1.503:
                    print("Target reached – exiting early.")
                    break

            # ----- mirror‑descent step ---------------------------------
            step = eta / np.sqrt(iteration)          # decreasing schedule
            exp_arg = -step * grad
            exp_arg = np.clip(exp_arg, -50.0, 50.0)   # avoid overflow
            a_candidate = a * np.exp(exp_arg)
            s = a_candidate.sum()
            if s > 0:
                a_candidate /= s
            else:
                a_candidate = a.copy()               # safety fallback

            # ----- evaluate candidate (exact max) -----------------------
            max_val_cand = max_conv_fft(a_candidate)
            cand_score = 2.0 * n * max_val_cand

            # ----- acceptance rule (greedy) ---------------------------
            if cand_score < cur_score:
                a = a_candidate
                eta = min(eta * 1.03, eta_max)      # become a bit bolder
            else:
                eta = max(eta * 0.90, eta_min)      # shrink step

            # ----- occasional random jitter to escape plateaus ---------
            if iteration % 2000 == 0:
                jitter = 1e-3 * np.random.randn(n)
                a = np.maximum(a + jitter, 0.0)
                a /= a.sum()
                print(f"Iter {iteration:5d}: jitter added, score≈{cur_score:.6f}")

        # after this length keep the last a as seed for the next one
        best_seq = a.copy()

        # early stop if we already beat the target
        if global_best_score < 1.503:
            break

    # ------------------------------------------------------------
    # 5.  Final official evaluation & return
    # ------------------------------------------------------------
    try:
        exact_score = evaluate_sequence(global_best_seq.tolist())   # noqa: F821
        print(f"\nExact evaluation by evaluate_sequence: {exact_score:.6f}")
    except Exception as exc:
        print(f"Could not call evaluate_sequence: {exc}")
        exact_score = global_best_score

    print("\n=== Search finished ===")
    print(f"Best score (approx.) : {global_best_score:.6f}")
    print(f"Best length          : {global_best_seq.shape[0]}")
    return global_best_seq.tolist()
```
