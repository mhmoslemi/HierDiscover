The evaluator is scale‑invariant, therefore we can restrict ourselves to
probability vectors `a` (non‑negative, sum = 1).  
The objective  

```
E(a) = 2·n·max_k (a*a)[k]
```

is the product of the length `n` and the largest entry of the
autoconvolution of `a`.  The global optimum is attained for a symmetric
distribution; we therefore keep the vector symmetric during the search.

The algorithm consists of three stages

1. **Initialisation** – use the best known construction (`height_sequence_1`);
   if it is unavailable, fall back to a fast deterministic sweep over
   a few U‑shaped families.
2. **Smoothed max‑gradient descent** –  
   *Parameterisation* : `a = softmax(x)`.  This automatically satisfies the
   simplex constraints.  
   *Smooth approximation of the max* :

   \[
   F(a) = \frac{1}{\alpha}\log\!\Bigl(\sum_{k} e^{\alpha (a*a)[k]}\Bigr)
   \]

   For large `α` the function approaches `max_k (a*a)[k]`.  
   Its gradient w.r.t. `a` is a weighted sum of the individual convolution
   gradients; the weights are the normalized exponentials of the
   convolution entries.  All required convolutions are performed by real FFTs,
   giving an **O(n log n)** per‑iteration cost.
3. **Adam optimisation on the unconstrained variables `x`** – the
   gradient w.r.t. `x` follows from the Jacobian of the soft‑max:
   `∂F/∂x_i = a_i (∂F/∂a_i – Σ_j a_j ∂F/∂a_j)`.  
   A small amount of noise is injected when the search stagnates
   (re‑heat), and `α` is slowly increased so that the optimisation first
   follows a smooth landscape and then focuses on the true maximum.

The routine respects the 1000 s budget, prints progress, and finally
returns the best vector found as a plain Python list.  The code uses only
NumPy and the standard library.  

```python
"""
propose_candidate – stochastic optimisation for the convolution max problem.

We minimises   2 * n * max_k (a * a)[k]   over non‑negative vectors a
with sum(a) = 1.  The algorithm works in three phases:

1) initialise from the supplied `height_sequence_1`; otherwise fall back to
   a fast deterministic sweep over a few parametric families.
2) optimise a smooth surrogate of the max using Adam on the soft‑max
   parametrisation a = softmax(x).  All convolutions are performed by
   real FFTs (O(n log n)).
3) re‑heat (add small noise) when stagnation is detected.

The function respects a 1000 s time budget and returns the best sequence
as a plain Python list.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Return the smallest power of two >= x."""
    return 1 << (x - 1).bit_length()


def full_convolution_fft(a: np.ndarray, size: int = None) -> np.ndarray:
    """
    Full linear convolution a * a using a real FFT.
    Returns an array of length 2*len(a)-1.
    """
    n = a.shape[0]
    if size is None:
        size = next_pow2(2 * n)
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)
    return conv[: 2 * n - 1]


def u_min_distribution(n: int, p: float) -> np.ndarray:
    """Symmetric U‑shape based on the distance to the nearest edge."""
    d = np.arange(n)
    d = np.minimum(d, n - 1 - d)
    a = (d + 1) ** (-p) + 1e-14
    a /= a.sum()
    return a


def u_prod_distribution(n: int, p: float) -> np.ndarray:
    """Symmetric U‑shape based on the product of distances to both edges."""
    i = np.arange(n, dtype=np.float64)
    prod = (i + 1) * (n - i)
    a = prod ** (-p) + 1e-14
    a /= a.sum()
    return a


def exp_distribution(n: int, lam: float) -> np.ndarray:
    """Symmetric exponential decay from the edges."""
    i = np.arange(n, dtype=np.float64)
    a = np.exp(-lam * i) + np.exp(-lam * (n - 1 - i))
    a = np.maximum(a, 1e-14)
    a /= a.sum()
    return a


def score_from_vector(a: np.ndarray) -> float:
    """
    Exact value that evaluate_sequence would return for a vector already
    normalised to sum(a) == 1.
    """
    n = a.shape[0]
    conv = full_convolution_fft(a)
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for the best non‑negative height sequence within the given
    time budget (seconds).  Returns the sequence as a plain Python list.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 4.0  # safety margin

    # --------------------------------------------------------------
    # 1. Initialise – try to use the known construction
    # --------------------------------------------------------------
    try:
        init = np.array(height_sequence_1, dtype=float)
        init = np.maximum(init, 0.0)
        s = init.sum()
        if s == 0.0:
            raise ValueError
        init /= s
        print(f"Initialised from global height_sequence_1 (len={len(init)})")
    except Exception:
        # Fallback: deterministic sweep over a few parametric families
        print("Fallback deterministic sweep for initial vector")
        best_vec = None
        best_sc = np.inf
        lengths = [2000, 4000, 8000, 12000]
        exps = np.arange(0.2, 5.01, 0.2)
        lam_vals = np.logspace(-4, -0.4, 20)
        for n in lengths:
            if time.time() > deadline:
                break
            for p in exps:
                a = u_min_distribution(n, p)
                sc = score_from_vector(a)
                if sc < best_sc:
                    best_sc = sc
                    best_vec = a.copy()
                a = u_prod_distribution(n, p)
                sc = score_from_vector(a)
                if sc < best_sc:
                    best_sc = sc
                    best_vec = a.copy()
            for lam in lam_vals:
                a = exp_distribution(n, lam)
                sc = score_from_vector(a)
                if sc < best_sc:
                    best_sc = sc
                    best_vec = a.copy()
        if best_vec is None:
            # final safety net
            n = 5000
            best_vec = np.random.rand(n)
            best_vec /= best_vec.sum()
            best_sc = score_from_vector(best_vec)
        init = best_vec
        print(f"Chosen deterministic seed: len={len(init)}  score={best_sc:.6f}")

    # --------------------------------------------------------------
    # 2. Prepare optimisation variables
    # --------------------------------------------------------------
    a = init.astype(np.float64)
    n = a.shape[0]

    # Ensure symmetry – many optimal solutions are symmetric
    a = (a + a[::-1]) / 2.0
    a /= a.sum()

    # Soft‑max parametrisation: x such that a = softmax(x)
    eps = 1e-12
    x = np.log(a + eps)

    # Adam hyper‑parameters
    beta1, beta2 = 0.9, 0.999
    lr0 = 0.05
    eps_adam = 1e-8
    m = np.zeros_like(x)
    v = np.zeros_like(x)

    # Smoothing (soft‑max) parameter for the max
    alpha = 5.0                 # start low, increase gradually
    alpha_target = 200.0
    alpha_inc = (alpha_target - alpha) / 250000.0   # approx 250k iters

    # Pre‑computed FFT size (must accommodate both conv and correlation)
    size_fft = next_pow2(3 * n)

    # --------------------------------------------------------------
    # 3. Optimisation loop (Adam on x)
    # --------------------------------------------------------------
    best_a = a.copy()
    best_score = score_from_vector(best_a)
    best_iter = 0
    last_improve = 0
    iteration = 0
    stagnation_patience = 5000

    print("\n=== Adam optimisation start ===")
    while time.time() < deadline:
        iteration += 1

        # ----- a from current x (soft‑max) -----
        mx = np.max(x)
        exp_x = np.exp(x - mx)                     # stabilise
        a = exp_x / exp_x.sum()

        # enforce symmetry at every step
        a = (a + a[::-1]) / 2.0
        a /= a.sum()

        # ----- FFT of a -----
        Fa = np.fft.rfft(a, n=size_fft)

        # ----- convolution a*a (full) -----
        conv = np.fft.irfft(Fa * Fa, n=size_fft)[: 2 * n - 1]

        # ----- exact score (occasionally) -----
        if iteration % 25 == 0:
            cur_score = float(2.0 * n * conv.max())
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                best_iter = iteration
                last_improve = iteration
                print(f"Iter {iteration:7d}: new best score = {best_score:.6f}")

        # ----- smooth approximation of the max -----
        max_c = conv.max()
        # scale to avoid overflow: subtract max before exponentiation
        scaled = conv - max_c
        # use current alpha (large alpha -> sharper approximation)
        weights = np.exp(alpha * scaled)
        w_sum = weights.sum()
        if w_sum == 0 or np.isnan(w_sum):
            # fallback: concentrate all weight on the maximal entries
            weights = np.zeros_like(conv)
            weights[np.isclose(conv, max_c, atol=1e-12)] = 1.0
            w_sum = weights.sum()
        weights /= w_sum

        # ----- gradient w.r.t. a (linear combination of individual gradients) -----
        Fw = np.fft.rfft(weights, n=size_fft)
        # correlation via conj(Fa)
        corr_full = np.fft.irfft(Fw * np.conj(Fa), n=size_fft)
        grad_a = 2.0 * corr_full[:n]               # gradient of smoothed max

        # ----- gradient w.r.t. x (soft‑max Jacobian) -----
        dot = np.dot(a, grad_a)
        grad_x = a * (grad_a - dot)

        # ----- Adam update on x -----
        m = beta1 * m + (1.0 - beta1) * grad_x
        v = beta2 * v + (1.0 - beta2) * (grad_x ** 2)
        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)
        step = lr0 * m_hat / (np.sqrt(v_hat) + eps_adam)
        x -= step

        # ----- increase smoothing parameter slowly -----
        if alpha < alpha_target:
            alpha = min(alpha_target, alpha + alpha_inc)

        # ----- stagnation handling (re‑heat) -----
        if iteration - last_improve > stagnation_patience:
            # inject tiny random perturbation and reset Adam moments
            perturb = np.random.randn(n) * 1e-4
            x += perturb
            m.fill(0.0)
            v.fill(0.0)
            last_improve = iteration
            print(f"Iter {iteration:7d}: re‑heat (stagnation)")

    # --------------------------------------------------------------
    # 4. Return best found sequence
    # --------------------------------------------------------------
    print("\n=== Search finished ===")
    print(f"Best score {best_score:.6f} found at iteration {best_iter}, length {len(best_a)}")
    return best_a.tolist()
```
