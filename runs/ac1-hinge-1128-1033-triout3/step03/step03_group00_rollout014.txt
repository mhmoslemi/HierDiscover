"""
Propose a step‑function (vector of non‑negative heights) that minimises
``evaluate_sequence``.

Algorithm
---------

We start from the best known construction (`height_sequence_1`) if it is
available, otherwise from the uniform distribution on a length‑4000
simplex.  The objective for a vector `a` with Σa=1 is simply

    F(a) = 2·n·max(conv(a,a))

so we have to reduce the maximal value of the self‑convolution.
The optimisation is a stochastic hill‑climbing / simulated‑annealing
procedure that repeatedly transfers a small amount of mass from a
position that contributes heavily to the current maximum convolution
peak to a position that does not participate in that peak.

The convolution update after moving a quantity `δ` from index `i` to
index `j` can be performed in O(1) time:

    let d_i = –δ, d_j = +δ.
    conv_new = conv_old + Δ   where

        Δ[2i]   = –2·δ·a_i + δ²
        Δ[2j]   =  2·δ·a_j + δ²
        Δ[i+j]  =  2·δ·(a_i – a_j – δ)

All other entries stay unchanged.  After the update we recompute the
global maximum of the convolution (a cheap `np.max` over 2·n‑1 elements)
and accept the move if it improves the objective; otherwise a
Metropolis acceptance step with a slowly cooling temperature is used.

Periodic full recomputation of the convolution corrects accumulated
round‑off error.  Random perturbations and occasional restarts prevent
the search from getting stuck.  The best vector seen is reported at the
end and evaluated with the provided ``evaluate_sequence`` for safety.
"""

import time
import math
import numpy as np

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Return a list of non‑negative heights that (hopefully) improves on
    the current best bound.  The routine runs for at most ``budget_s``
    seconds and prints intermediate progress.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # safety margin

    # --------------------------------------------------------------
    # Problem size – the previous best used n = 4000, keep the same.
    # --------------------------------------------------------------
    n = 4000

    # --------------------------------------------------------------
    # Initialise from the previous construction if available.
    # --------------------------------------------------------------
    try:
        # height_sequence_1 is provided by the environment
        a = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        # Interpolate to the required length
        old_x = np.linspace(0.0, 1.0, a.shape[0])
        new_x = np.linspace(0.0, 1.0, n)
        a = np.interp(new_x, old_x, a)
    except Exception:
        # uniform distribution on the simplex
        a = np.full(n, 1.0 / n)

    # enforce feasibility
    a = np.maximum(a, 0.0)
    a = a / a.sum()      # Σ a_i = 1

    # full convolution of a with itself (used for the objective)
    conv = np.convolve(a, a)               # length 2·n‑1
    cur_val = 2.0 * n * conv.max()
    best_a = a.copy()
    best_val = cur_val

    # bookkeeping
    iteration = 0
    no_improve = 0
    IMP_LIMIT = 20000         # after many idle steps we jitter the current point
    RECOMPUTE_EVERY = 20000   # full recomputation interval to avoid drift

    print(f"[init] n={n}, initial value = {cur_val:.6f}")

    # --------------------------------------------------------------
    # Main stochastic hill‑climbing loop
    # --------------------------------------------------------------
    while True:
        now = time.time()

            break

        # ----------------------------------------------------------

        # ----------------------------------------------------------

        # temperature for Metropolis acceptance (tiny, but enough to escape plateaus)
        temperature = 5e-4 * (1.0 - progress) + 1e-6
        # maximal relative transfer from a source index (starts large, ends ~0.01)
        step_coeff = 0.5 * (1.0 - progress) + 0.01 * progress
