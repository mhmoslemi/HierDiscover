The objective of `evaluate_sequence` (with a fixed sum) is  
\[
\min_{a_i\ge 0,\;\sum a_i = 1}\;2\,n\;\max_k (a*a)_k .
\]
`a*a` is the linear convolution of `a` with itself.  
The average value of the convolution is `1/(2n‑1)`, therefore the optimum
cannot be smaller than `2n/(2n‑1)≈1`.  A good‐quality solution is obtained by
*flattening* the convolution – i.e. reducing the largest diagonal sum of the
outer product `a·aᵀ`.

The algorithm below consists of two phases:

* **Phase 1 – smoothed max (Adam)** – exactly the method that produced the
  previous best result, but with a more aggressive learning‑rate schedule.
  It quickly finds a decent region of the simplex.

* **Phase 2 – sub‑gradient / exponentiated‑gradient** – once the sequence is
  close to a flat convolution we switch to a *hard* max.  
  The sub‑gradient of the maximum diagonal is
  \[
  g_i = 2\sum_{k:\;(a*a)_k = M} a_{k-i},
  \qquad
  M = \max_k (a*a)_k ,
  \]
  which is computed by a single FFT‑based convolution.  
  An exponentiated‑gradient step
  \[
  a_i \leftarrow a_i\exp(-\eta_t g_i),\qquad a\leftarrow a/\sum a
  \]
  keeps the iterate inside the probability simplex and moves probability mass
  away from the entries that contribute most to the current peak.  
  The step size `η_t` decays as `η₀/√t`.  Random restarts are performed if
  no improvement has been seen for a long time.

Both phases keep the best exact evaluation (using `evaluate_sequence`) and
return it when the time budget expires.

The implementation uses only NumPy (FFT for O(n log n) convolutions) and
conforms to the required API.

# FFT‑based convolution utilities (real data)

def _full_convolution(x: np.ndarray) -> np.ndarray:
    """
    Full linear convolution of a real vector with itself.
    Returns an array of length 2*len(x)-1.
    """
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    # eliminate tiny negative round‑off (should not affect correctness)
    np.maximum(conv, 0, out=conv)
    return conv


def _conv_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Full convolution of two real vectors using a real FFT."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = 1 << (out_len - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    np.maximum(conv, 0, out=conv)
    return conv
