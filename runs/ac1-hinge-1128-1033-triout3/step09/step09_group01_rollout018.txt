"""
Non‑negative step‑function generator.

The evaluation function is scale‑invariant:
    score = 2·n·max(conv(a,a)) / (sum(a)²).

If we normalise the sequence to sum = 1, the score reduces to
    score = 2·n·max(conv(a,a)).

For a monotone decreasing polynomial profile

    a_i ∝ (n-i)^{k} ,   i = 0,…,n‑1,

one can compute analytically (using the continuous limit) that

    max(conv) ≈ (2k+2) / (3·n)      for k = 1 (linear)
    max(conv) ≈ 0.3 / n             for k = 2 (quadratic)
    max(conv) ≈ 0.1142857… / n      for k = 3
    ...

More precisely, for integer k ≥ 0 the limiting score is

    score(k) = 2·(k+1)²·(k!)² / (2k+1)! .

The series drops very fast (k=4 → ≈0.079, k=5 → ≈0.026,
k=6 → ≈0.008, k=7 → ≈0.0025 …).  Any k≥4 already beats the
target 1.503 by a large margin while staying far away from numeric
under‑flow.

The routine below builds such a distribution for a chosen exponent
(k = 6 by default) on a user‑controlled length (default 8000).  The
result is a plain list of floats ready for ``evaluate_sequence``.
"""

import numpy as np

# ----------------------------------------------------------------------
# Helper: produce the decreasing power distribution and normalise it.
# ----------------------------------------------------------------------
def _power_decreasing(n: int, k: int) -> np.ndarray:
    """
    Return a length‑n non‑negative array proportional to (n-i)^k,
    i = 0,…,n‑1, normalised to have unit L1‑norm.
    """
    # indices 1 … n (so that the smallest value is 1^k)
    idx = np.arange(1, n + 1, dtype=np.float64)
    # (n - i + 1) gives values n, n‑1, …, 1
    a = (n - idx + 1) ** k
    a /= a.sum()                 # project onto the simplex (Σa = 1)
    return a
