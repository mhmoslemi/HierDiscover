assistantfinal**Solution Overview**

The evaluation metric is  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a` is a non‑negative step function.  
Because the metric is invariant under a global scaling of `a` (the numerator
and denominator both grow quadratically), we may restrict ourselves to
probability vectors (`∑a_i = 1`).  The problem then becomes

```
minimise   max_k  (a*a)_k       subject to   a_i ≥ 0 ,  ∑ a_i = 1 .
```

`max_k (a*a)_k` is the ℓ∞‑norm of the self‑convolution.
Its lower bound is the average value of the convolution,
\(1/(2n-1)\), so the optimal objective is close to 1.  The current state‑of‑the‑art
achieves ≈ 1.510 and we aim for a better value.

The new search routine combines three ideas:

1. **Smooth approximation of the maximum** –  
   For a smoothing parameter β we use  
   \[
   w_k =\exp\!\bigl(\beta\,(c_k-\max c)\bigr),\qquad
   S(a)=\sum_k w_k\,c_k .
   \]
   As β → ∞, S(a) → max c.  The gradient of S w.r.t. a is available in closed
   form and can be computed by a single FFT‑based convolution.

2. **Adam on the soft‑max (log‑it) parametrisation** –  
   We represent a probability vector as `a = softmax(x)`.  
   Updating the unconstrained logits `x` with the Adam optimiser gives fast,
   well‑behaved optimisation on the simplex without explicit projections.

3. **Late‑stage stochastic hill‑climbing** –  
   After the smooth‑gradient phase we perform a cheap local search that
   transfers a small amount of mass between two coordinates (or swaps them)
   and accepts only strict improvements.  Occasionally a small amount of
   Gaussian noise is added to escape plateaus.

All heavy linear‑time operations are performed with FFTs, so even with
`n = 8000` the inner loop runs comfortably within the 1000 s budget.
The algorithm also tries a random restart (perturbation) if no improvement
has been seen for a while.

The code follows the required interface: a top‑level `propose_candidate`
function that returns a list of non‑negative floats.

```python
"""
Propose a non‑negative step function that minimises `evaluate_sequence`.

Algorithm
---------

* Work with a probability vector (∑a_i = 1) – scaling does not affect the
  objective, therefore we can safely stay on the simplex.
* Use a soft‑max parametrisation a = softmax(x).  The unconstrained logits x
  are optimised with the Adam optimiser.
* Approximate max(a*a) by a smooth weighted sum:
        w_k = exp(β·(c_k – max(c)))      (β grows from 0.5 to 2000)
        S(a) = Σ_k w_k·c_k                (c = a*a)
  The gradient of S w.r.t. a is
        g_a = 2·(a * w_rev)               (linear convolution, computed by FFT)
  The gradient w.r.t. the logits follows from the soft‑max Jacobian.
* Adam updates are applied to the logits; after each 200 iterations the true
  `evaluate_sequence` value is queried and the best vector is stored.
* If the optimiser stalls for >15 k iterations we add a small Gaussian
  perturbation to the logits.
* Finally a short stochastic hill‑climbing phase (mass transfers and swaps)
  refines the best vector found.

The routine respects the 1000 s time budget, prints intermediate scores,
and returns the best sequence as a plain list of floats.
"""

import time

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (used for zero‑padding in FFT)."""
    return 1 << (x - 1).bit_length()


def _full_convolution_fft(a: np.ndarray) -> np.ndarray:
    """
    Linear self‑convolution a * a (length 2·len(a)‑1) using FFT.
    The result is fully non‑negative (tiny negatives are clipped to 0).
    """
    n = a.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    np.maximum(conv, 0.0, out=conv)  # numerical safety
    return conv


def _gradient_weighted_fft(a: np.ndarray, w_rev: np.ndarray) -> np.ndarray:
    """
    Gradient of Σ_k w_k·(a*a)_k w.r.t. a.
    Returned vector has length len(a) and equals 2·(a * w_rev) restricted
    to the positions that contribute to the linear convolution.
    """
    n = a.shape[0]
    conv_len = n + w_rev.shape[0] - 1          # = 3n‑2 because |w_rev| = 2n‑1
    size = _next_pow2(conv_len)
    fa = np.fft.rfft(a, size)
    fw = np.fft.rfft(w_rev, size)
    conv = np.fft.irfft(fa * fw, size)[:conv_len]
    start = w_rev.shape[0] - 1                 # = 2n‑2
    segment = conv[start:start + n]            # extract the needed slice
    return 2.0 * segment


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max returning a probability vector."""
    mx = np.max(x)
    e = np.exp(x - mx)
    s = np.sum(e)
    if s == 0:
        # should never happen, but fall back to uniform
        return np.full_like(x, 1.0 / x.shape[0])
    return e / s


def _anti_symmetric_reorder(a: np.ndarray) -> np.ndarray:
    """
    Pair the largest values with the smallest ones (left‑right anti‑symmetric).
    This heuristic is occasionally useful as a post‑processing step.
    """
    n = a.shape[0]
    s = np.sort(a)               # ascending
    b = np.empty_like(a)
    half = n // 2
    for i in range(half):
        b[i] = s[-1 - i]        # biggest → left side
        b[-1 - i] = s[i]        # smallest → right side
    if n % 2:
        b[half] = s[half]
    return b

    # and speed of the FFT‑based inner loop.
    # ------------------------------------------------------------------
    n = 8000

    # ------------------------------------------------------------------
    # Initialise either from the historic construction or from a random Dirichlet.
    # ------------------------------------------------------------------
    try:
        # height_sequence_1 may be defined in the surrounding environment
        a0 = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        if a0.shape[0] != n:
            # Linear interpolation to the target length
            old_x = np.linspace(0.0, 1.0, a0.shape[0])
            new_x = np.linspace(0.0, 1.0, n)
            a0 = np.interp(new_x, old_x, a0)
        a0 = np.maximum(a0, 0.0)
        s0 = a0.sum()
        a0 = a0 / s0 if s0 > 0 else np.full(n, 1.0 / n)
    except Exception:
        # Random exponential draws → Dirichlet(1,…,1)
        a0 = rng.exponential(scale=1.0, size=n)
        a0 = a0 / a0.sum()

    # Logits for the soft‑max parametrisation
    x = np.log(a0 + 1e-15)

    # Best solution found so far (store as a probability vector)
    best_a = a0.copy()
    best_val = evaluate_sequence(best_a.tolist())
    print(f"[init] n={n}, evaluation = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Adam optimiser state
    # ------------------------------------------------------------------
    m = np.zeros_like(x)
    v = np.zeros_like(x)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr = 0.15                     # learning rate for the logits

    # Smoothing schedule for the soft‑max approximation of the maximum
    beta_start = 0.5
    beta_end = 2000.0
    beta_ramp_iters = 50000       # linear increase of β

    it = 0
    max_iter = 150_000
    last_improve = 0

    # ------------------------------------------------------------------
    # Phase 1 – smoothed Adam optimisation on the simplex
    # ------------------------------------------------------------------
    while time.time() < deadline - 20 and it < max_iter:
        # Current probability vector
        a = _softmax(x)

        # Self‑convolution (full length 2n‑1)
        conv = _full_convolution_fft(a)

        # Smooth approximation of the max
        maxc = conv.max()
        beta = beta_start + (beta_end - beta_start) * min(1.0, it / beta_ramp_iters)
        w = np.exp(beta * (conv - maxc))          # w[max] = 1, others ≤ 1

        # Gradient of the smoothed objective w.r.t. a
        g_a = _gradient_weighted_fft(a, w[::-1])

        # Convert to gradient w.r.t. logits (soft‑max Jacobian)
        dot = np.dot(g_a, a)
        g_x = a * (g_a - dot)

        # Adam update of the logits
        m = beta1 * m + (1.0 - beta1) * g_x
        v = beta2 * v + (1.0 - beta2) * (g_x * g_x)
        m_hat = m / (1.0 - beta1 ** (it + 1))
        v_hat = v / (1.0 - beta2 ** (it + 1))
        x -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # ------------------------------------------------------------------
        # Periodic full evaluation (costly) – keep the best seen so far
        # ------------------------------------------------------------------
        if it % 200 == 0:
            cur_val = evaluate_sequence(a.tolist())
            if cur_val < best_val - 1e-12:
                best_val = cur_val
                best_a = a.copy()
                last_improve = it
                print(f"[adam iter {it:6d}] new best = {best_val:.6f}")

                # Occasionally try the anti‑symmetric reorder heuristic
                if it % 2000 == 0:
                    a_ord = _anti_symmetric_reorder(a)
                    val_ord = evaluate_sequence(a_ord.tolist())
                    if val_ord < best_val - 1e-12:
                        best_val = val_ord
                        best_a = a_ord.copy()
                        x = np.log(a_ord + 1e-15)   # continue optimisation from here
                        print(f"[reorder {it}] improved to {best_val:.6f}")

        # ------------------------------------------------------------------
        # Stagnation handling – add a bit of random noise to the logits
        # ------------------------------------------------------------------
        if (it - last_improve) > 15000:
            noise = rng.normal(scale=0.05, size=n)
            x += noise
            last_improve = it
            print(f"[perturb] at iteration {it}")

        it += 1

    # ------------------------------------------------------------------
    # Phase 2 – simple stochastic hill‑climbing refinement
    # ------------------------------------------------------------------
    cur_a = best_a.copy()
    cur_val = best_val

    while time.time() < deadline:
        # Choose move type: 30 % swap, 70 % tiny mass transfer
        if rng.random() < 0.30:
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            new_a = cur_a.copy()
            new_a[i], new_a[j] = new_a[j], new_a[i]
        else:
            i, j = rng.integers(0, n, size=2)
            if i == j or cur_a[i] <= 1e-15:
                continue
            # Transfer a small fraction of mass from i to j
            delta = cur_a[i] * 0.08 * rng.random()
            new_a = cur_a.copy()
            new_a[i] -= delta
            new_a[j] += delta

        # Re‑project onto the simplex (numerical safety)
        new_a = np.maximum(new_a, 0.0)
        s = new_a.sum()
        if s < 1e-12:
            continue
        new_a /= s

        val = evaluate_sequence(new_a.tolist())
        if val < cur_val - 1e-12:
            cur_a = new_a
            cur_val = val
            best_a = new_a.copy()
            best_val = val
            print(f"[refine] new best = {cur_val:.6f}")

    # ------------------------------------------------------------------
    # Final evaluation & return
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_a.tolist())
    print(f"[final] best evaluation reported by evaluate_sequence = {final_score:.6f}")
    return best_a.tolist()
```

The function complies with all requirements:

* No filesystem or network access.
* Only top‑level functions are used (no closures, no lambdas).
* The heavy linear algebra (convolutions, gradients) is performed with FFTs.
* Intermediate progress is printed, and the best sequence found within the
  1000 s budget is returned.
