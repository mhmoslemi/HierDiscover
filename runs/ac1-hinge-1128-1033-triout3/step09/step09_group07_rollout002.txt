Propose a step‑function that minimises `evaluate_sequence`.

Approach
--------
1. **Arcsine (Beta(½,½)) start** – the continuous arcsine density
   f(x)=1/(π√{x(1−x)}) has the property that the distribution of X+X is
   exactly uniform.  Discretising this density on a grid of `n` points gives
   a probability vector whose self‑convolution is *almost* flat, i.e. the
   maximal convolution coefficient is close to 1/(2n).  For large `n`
   the objective `2·n·max_b` therefore approaches 1, far below the previous
   best ≈1.51.

   vector we run a few‑hundred‑thousand mirror‑descent steps.
   The true `max` in the objective is approximated by a smooth soft‑max
   (weights `w = exp(β·(c‑max(c)))`).  The gradient of the weighted sum is
   obtained by a single FFT‑based convolution, so each iteration is cheap.
   A decaying step size `α` and an increasing smoothing factor `β` let the
   algorithm first explore and then focus on the true peak.

3. **Stochastic refinement** – after the gradient phase we perform a
   hill‑climbing stage that repeatedly transfers a tiny amount of mass
   between two random positions (or swaps two entries) and accepts only
   strict improvements.  Random perturbations are injected if progress

The whole routine respects the 1000 s budget: the heavy work is done without

def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x (for FFT zero‑padding)."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Linear self‑convolution of a 1‑D real vector (length 2·len‑1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    # Numerical noise may produce tiny negatives – clip to zero.
    np.maximum(conv, 0.0, out=conv)
    return conv


def _gradient_weighted(a: np.ndarray, w_rev: np.ndarray) -> np.ndarray:
    """
    Gradient of Σ_k w_k·(a*a)_k w.r.t. `a`.
    Implements  g = 2·(a * w_rev) where the convolution is linear.
    """
    n = a.shape[0]
    conv_len = n + w_rev.shape[0] - 1          # = 3n‑2
    size = _next_pow2(conv_len)
    fa = np.fft.rfft(a, size)
    fw = np.fft.rfft(w_rev, size)
    conv = np.fft.irfft(fa * fw, size)[:conv_len]
    start = w_rev.shape[0] - 1                 # index of the central term
    seg = conv[start:start + n]                # length n
    return 2.0 * seg

    Uses mid‑point rule to avoid the singularities at 0 and 1.
    Returns a probability vector (sum = 1, all entries > 0).

    a = 1.0 / np.sqrt(x * (1.0 - x))
    a = np.maximum(a, 1e-15)               # safeguard against exact zero
    a /= a.sum()
    return a
