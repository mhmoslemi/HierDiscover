   variable `height_sequence_1` is available it is interpolated to the
   working size, otherwise a uniform start is used.

2. **Linear‑programming mixing loop**  
   Repeatedly solve the LP  

        maximise   Σ g_i
        subject to  (a * g)_k ≤ M   (k = 0 … 2n‑2)
                    g_i ≥ 0

   where `M = max(a*a)`.  The LP is linear because `a` is fixed,
   therefore the convolution constraints are linear in `g`.  The
   solution `g` is rescaled to a probability vector `ĝ = g / Σg`.  A
   convex combination `a ← (1‑t)·a + t·ĝ` (with a small, slowly
   adapting step‑size `t`) is performed.  This is exactly the
   “alternating LP” method described in the problem statement and
   provably never increases the current maximum convolution value.
   The loop stops when the time budget is exhausted or when progress
   stalls.

3. **Projected sub‑gradient polishing**  
   Starting from the best vector found, perform classic sub‑gradient
   descent on the exact objective `2·n·max(conv(a,a))` while keeping
   the iterate on the probability simplex.

4. **Uniform mixing (optional fine tuning)**  
   Test a few tiny convex combinations with the uniform distribution
   – this can occasionally lower the peak further.

5. Return the best sequence (as a plain list of non‑negative floats).
   The sequence is already normalised (sum = 1), which is safe for
   `evaluate_sequence` because the evaluation function is scale‑invariant
   (apart from the clamping that never triggers for our tiny values).

The whole procedure respects the 1000 s limit and prints intermediate
progress, allowing the harness to see how the bound improves.
"""

import time
import numpy as np
from scipy import optimize, linalg

# ----------------------------------------------------------------------
# Utility functions
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if np.abs(v.sum() - 1.0) < 1e-12 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.where(u - cssv / (np.arange(len(v)) + 1) > 0)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _objective(a: np.ndarray) -> float:
    """Exact objective used by `evaluate_sequence` for a unit‑sum vector."""
    n = a.shape[0]
    max_b = np.convolve(a, a).max()
    return float(2.0 * n * max_b)   # sum(a) == 1 → denominator = 1


def _build_conv_matrix(f: np.ndarray) -> np.ndarray:
    """Full linear convolution matrix of a fixed vector f (len = n)."""
    n = f.shape[0]
    # Toeplitz matrix with first column = [f, 0, …, 0]  (length 2n‑1)
    # and first row = [f[0], 0, …, 0] (length n)
    col = np.concatenate([f, np.zeros(n - 1)])
    row = np.concatenate([f[:1], np.zeros(n - 1)])
    return linalg.toeplitz(col, row)   # shape (2n‑1, n)


def _solve_lp(f: np.ndarray, M: float) -> tuple[np.ndarray, float]:
    """
    Solve
        maximise   Σ g_i
        subject to  (f * g)_k ≤ M   (k = 0 … 2n‑2)
                    g_i ≥ 0
    Returns the optimal vector g and its sum Σg.
    """
    n = f.shape[0]
    A = _build_conv_matrix(f)                     # (2n‑1, n)
    b = np.full(2 * n - 1, M + 1e-12)             # small tolerance
    c = -np.ones(n)                               # linprog minimises → maximise Σg
    bounds = [(0, None)] * n
    res = optimize.linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                           method='highs')
    if not res.success:
        raise RuntimeError("LP failed: " + res.message)
    g = res.x
    return g, g.sum()


def _subgradient_descent(a0: np.ndarray, deadline: float) -> tuple[np.ndarray, float]:
    """Projected sub‑gradient descent on the exact max‑convolution objective."""
    a = a0.copy()
    n = a.shape[0]
    best_a, best_val = a.copy(), _objective(a)

    eta0 = 0.5 / n          # initial step size (≈ half the average entry)
    eta = eta0
    decay = 0.9995
    it = 0

    while time.time() < deadline:
        conv = np.convolve(a, a)
        cur_val = 2.0 * n * conv.max()
        if cur_val < best_val - 1e-14:
            best_a, best_val = a.copy(), cur_val
            # print improvement inside main loop if desired
        # sub‑gradient of the maximal entry
        k = int(np.argmax(conv))
        idx = k - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        grad = np.zeros(n)
        grad[mask] = 2.0 * a[idx[mask]]
        # gradient step & projection
        a = _project_simplex(a - eta * grad)
        eta *= decay
        it += 1

    return best_a, best_val


def _mix_with_uniform(a: np.ndarray) -> tuple[np.ndarray, float]:
    """Try a few tiny convex combinations with the uniform vector."""
    n = a.shape[0]
    best_a, best_val = a, _objective(a)
    uniform = np.full(n, 1.0 / n)
    for alpha in (0.001, 0.003, 0.005, 0.010, 0.020):
        cand = (1.0 - alpha) * a + alpha * uniform
        cand /= cand.sum()
        val = _objective(cand)
        if val < best_val:
            best_a, best_val = cand, val
    return best_a, best_val


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """
    Return a non‑negative step‑function (as a list of floats) that
    minimises `evaluate_sequence`.  The algorithm follows the plan
    described in the module docstring and respects the given time budget.
    """
    np.random.seed(seed)
    rng = np.random.default_rng(seed)

    start_time = time.time()
    # keep a tiny safety buffer for the final evaluate_sequence call
    deadline = start_time + budget_s - 0.5

    # ------------------------------------------------------------------
    # Choose a working size – 2500 gives a good trade‑off between speed
    # and expressive power.
    # ------------------------------------------------------------------
    n = 2500

    # ------------------------------------------------------------------
    # Initialise a probability vector.
    # Prefer the previously discovered construction if it exists.
    # ------------------------------------------------------------------
    try:
        old_seq = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        x_old = np.linspace(0.0, 1.0, old_seq.size)
        x_new = np.linspace(0.0, 1.0, n)
        a = np.interp(x_new, x_old, old_seq)
        a = np.maximum(a, 0.0)
        if a.sum() == 0:
            a = np.ones(n) / n
        else:
            a /= a.sum()
    except Exception:
        a = np.ones(n) / n

    best_a, best_val = a.copy(), _objective(a)
    print(f"[init] objective = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 1 – alternating LP mixing (≈ 60 % of the budget)
    # ------------------------------------------------------------------
    phase1_end = start_time + 0.6 * (deadline - start_time)
    t_mix = 0.20            # initial mixing weight
    iteration = 0
    while time.time() < phase1_end:
        conv = np.convolve(best_a, best_a)
        M = conv.max()
        try:
            g, sum_g = _solve_lp(best_a, M)
        except Exception as exc:
            print("[LP] failed:", exc)
            break
        if sum_g <= 1e-12:
            print("[LP] trivial solution, aborting LP phase")
            break
        g_norm = g / sum_g               # rescale to a probability vector
        # convex combination
        a_new = (1.0 - t_mix) * best_a + t_mix * g_norm
        a_new = np.maximum(a_new, 0.0)
        a_new /= a_new.sum()
        val_new = _objective(a_new)
        if val_new < best_val - 1e-12:
            best_a, best_val = a_new, val_new
            print(f"[LP {iteration:04d}] new best = {best_val:.6f}")
            # if we are making progress, allow a slightly larger step
            t_mix = min(0.5, t_mix * 1.05)
        else:
            # no improvement → shrink the mixing weight
            t_mix = max(0.02, t_mix * 0.90)
        best_a = a_new
        iteration += 1

    # ------------------------------------------------------------------
    # Phase 2 – projected sub‑gradient descent (remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = _subgradient_descent(best_a, deadline)
        print(f"[SGD] after polishing objective = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – tiny uniform mixing (optional fine‑tuning)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = _mix_with_uniform(best_a)
        print(f"[mix] after uniform mixing objective = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final evaluation (the harness will also call evaluate_sequence)
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] reported evaluation = {final_score:.6f}")
    except Exception as exc:                     # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_a.tolist()
