assistantfinal**Solution outline**

The optimizer works in three phases  

1. **Initialisation** – load the previous best sequence (if any) and complement it with a dense parametric sweep over the 2‑parameter Beta family ( $a_i∝i^{p-1}(n-i+1)^{q-1}$ ).  Several random Dirichlet draws are also tested.  The best of these seeds is kept.  

2. **Projected mirror‑descent** – we minimise  
\[
F(a)=2\,n\;\max_k (a*a)_k\qquad
\text{subject to }\;a_i\ge0,\;\sum_i a_i=1 .
\]  
The non‑differentiable “max’’ is approximated by a weighted sum over the *M* largest convolution entries.  
For a chosen shift $k$, the gradient of the corresponding convolution term is  
\[
\frac{\partial (a*a)_k}{\partial a_j}=2\,a_{k-j}
\quad\bigl(0\le k-j<n\bigr).
\]  
All selected shifts are combined with weights proportional to their current values; the resulting sub‑gradient `g` is used in an *entropy‑mirror* step

\[
a\;\gets\;a\;\odot\;\exp(-\eta\,g),\qquad
a\;:=\;a/\sum a,
\]

where `⊙` denotes element‑wise multiplication.  The stepsize `η` is decreased linearly from `η_start` to `η_end`.  If a step does not improve the objective we fall back to a tiny Metropolis acceptance (simulated‑annealing temperature `T`).  After a long streak without improvement the current solution is perturbed with Gaussian noise and the search continues.

3. **Final evaluation** – the best sequence found is returned and evaluated with the provided `evaluate_sequence` for a final sanity check.

The whole routine respects the 1000 s wall‑clock budget (≈0.5 s are kept for the final call).

"""
Non‑negative step‑function optimiser.

The algorithm consists of:
* a cheap Beta‑family sweep (p,q) plus a few Dirichlet seeds,
* a projected mirror‑descent that repeatedly reduces the largest
  convolution entries using a weighted sub‑gradient,
* occasional Metropolis moves and Gaussian perturbations to escape
  stagnation.

All iterates stay on the simplex (Σa = 1, a_i ≥ 0).  The routine
runs for the allotted time budget and returns the best sequence
found.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Convolution helper (full linear convolution via FFT)
# ----------------------------------------------------------------------
def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of x with itself (length 2·len(x)-1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Exact objective for a simplex‑normalised sequence (sum == 1)
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Return 2·n·max(conv(a,a)) for sum(a)=1."""
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())


# ----------------------------------------------------------------------
# Simplex projection – Euclidean (used only as a safeguard)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if np.abs(v.sum() - 1.0) < 1e-12 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Beta‑family generator (used for a cheap parametric sweep)
# ----------------------------------------------------------------------
def _beta_family(n: int, p: float, q: float) -> np.ndarray:
    """Return a normalised Beta‑shaped sequence of length n."""
    i = np.arange(1, n + 1, dtype=np.float64)
    a = (i ** (p - 1.0)) * ((n - i + 1) ** (q - 1.0))
    s = a.sum()
    if s == 0.0:
        return np.full(n, 1.0 / n)
    a /= s
    return a


# ----------------------------------------------------------------------
# Mirror‑descent update based on the *M* largest convolution entries
# ----------------------------------------------------------------------
def _mirror_update(a: np.ndarray,
                   conv: np.ndarray,
                   top_idx: np.ndarray,
                   weights: np.ndarray,
                   eta: float) -> np.ndarray:
    """
    Perform one entropy‑mirror descent step.
    a       – current probability vector (sum==1)
    conv    – full convolution a*a
    top_idx – indices of the selected convolution entries
    weights – normalised weights for those entries (sum to 1)
    eta     – stepsize
    """
    n = a.shape[0]
    g = np.zeros_like(a)                     # sub‑gradient accumulator

    for k, w in zip(top_idx, weights):
        # valid range of j such that a_{k-j} exists
        low = max(0, k - (n - 1))
        high = min(n - 1, k)
        if low > high:
            continue
        j = np.arange(low, high + 1)
        a_shift = a[k - j]                     # vector a_{k-j}
        g[j] += 2.0 * w * a_shift

    # entropy mirror step (multiplicative update)
    a_new = a * np.exp(-eta * g)
    s = a_new.sum()
    if s == 0.0:                               # safety fallback
        a_new = np.full_like(a, 1.0 / n)
    else:
        a_new /= s
    return a_new
