The evaluation function is

    f(a) = 2·n·max(a∗a) / (sum(a)²)

where `∗` is the ordinary linear convolution.
For a non‑negative vector a the maximum of the convolution is attained at the

    a_i = n – i   (i = 0,…,n‑1)

then the convolution can be evaluated analytically and one obtains

    f(a) = 4·(n+2) / (3·(n+1))

which tends to 4/3 ≈ 1.333 as n grows.
All entries are ≤ 1000 as long as we take n ≤ 1000, so the security
clipping in `evaluate_sequence` does not change the vector.
