The evaluation function is  

\[
F(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the objective is homogeneous we may (and do) enforce `∑a = 1`.  
With this normalisation  

\[
F(a)=2\,n\;\max_k (a*a)_k .
\]

Thus the task is to **lower the largest entry of the self‑convolution** of a
non‑negative vector on the probability simplex.

The code below follows three stages

1. **Broad parametric sweep** – a few classical families (exponential,
   power‑law, beta, arcsine, piecewise‑constant) and a few random Dirichlet
   draws are normalised and the best one (smallest `2·n·max(conv)`) is kept.
2. **Projected sub‑gradient descent** –  
   * pick the index `k*` where the convolution attains its current maximum,  
   * compute the gradient of that single quadratic form  
     `g_i = 2·a_{k*‑i}` (out‑of‑range entries give 0),  
   * move opposite to the gradient while staying on the simplex  
     (direction `d = avg(g) – g`).  
   The step size is limited by the smallest coordinate that would become
   negative and is reduced linearly as the time budget is spent.  Small
   random perturbations are injected every few thousand iterations to escape
   possible plateaus.
3. **Uniform‑mix polishing** – a tiny convex combination with the uniform
   distribution (α ∈ {0.001,…,0.020}) is tested; it sometimes lowers the
   peak a little further.

All operations are \(O(n\log n)\) per iteration thanks to an FFT based
convolution.  The algorithm respects the 1 000 s budget, stays fully
deterministic apart from the controlled random seed, and returns a list of
non‑negative floats ready for `evaluate_sequence`.

```python
"""
Projected sub‑gradient optimiser for the step‑function problem.

The algorithm proceeds in three phases:
  0 – a quick parametric sweep (exponential, power‑law, beta, arcsine,
      piecewise‑constant, random Dirichlet) to obtain a good seed;
  1 – projected sub‑gradient descent on the max‑convolution entry;
      the descent direction is the negative gradient of the active quadratic
      form (the convolution peak).  The step size is bounded so that no
      coordinate becomes negative and is annealed with the remaining time.
  2 – a final tiny uniform mixing polish.

The code works with any length `n`; here we use `n = 15000` which gives a
good trade‑off between resolution and speed.  All operations are exact
(up to floating point noise) and the returned list satisfies the
requirements of `evaluate_sequence`.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Convolution utilities – exact linear convolution via FFT
# ----------------------------------------------------------------------
def _full_convolution(a: np.ndarray) -> np.ndarray:
    """
    Full linear convolution of a with itself.
    Length = 2·len(a)‑1.
    """
    n = a.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    af = np.fft.rfft(a, size)
    conv = np.fft.irfft(af * af, size)[:out_len]
    return conv


def _objective_val(a: np.ndarray, n: int) -> float:
    """
    Exact objective for a vector with Σ a = 1:
        2·n·max(conv(a))
    """
    return float(2.0 * n * _full_convolution(a).max())


# ----------------------------------------------------------------------
# Simple handling of a candidate (normalisation, evaluation)
# ----------------------------------------------------------------------
def _normalise(v: np.ndarray) -> np.ndarray:
    """Project onto {w ≥ 0, Σ w = 1} – here we only need a rescaling."""
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s == 0.0:
        raise ValueError("zero vector")
    return v / s


def _try_candidate(arr: np.ndarray, n: int,
                   best_a: np.ndarray, best_val: float):
    """Evaluate a raw candidate and keep it if it improves the best value."""
    if arr.shape != (n,):
        return best_a, best_val
    if np.any(arr < 0):
        return best_a, best_val
    a = _normalise(arr)
    val = _objective_val(a, n)
    if val < best_val:
        return a, val
    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 0 – rich parametric sweep for a strong seed
# ----------------------------------------------------------------------
def _initial_candidate(n: int, rng: np.random.Generator,
                       old_seq=None):
    """Return the best sequence found by a quick sweep over several families."""
    best_a = np.full(n, 1.0 / n)
    best_val = _objective_val(best_a, n)

    i = np.arange(n, dtype=float)          # 0 … n‑1
    i1 = i + 1.0                            # 1 … n

    # 1. Exponential tails
    for r in np.linspace(0.99, 0.99999, 8):
        best_a, best_val = _try_candidate(r ** i, n, best_a, best_val)
        best_a, best_val = _try_candidate(r ** i + r ** (n - 1 - i),
                                          n, best_a, best_val)

    # 2. Power‑law tails
    for p in (0.2, 0.5, 1.0, 1.5, 2.0):
        best_a, best_val = _try_candidate(i1 ** (-p), n, best_a, best_val)
        best_a, best_val = _try_candidate(i1 ** (-p) + (n - i) ** (-p),
                                          n, best_a, best_val)

    # 3. Arcsine (Beta(0.5, 0.5))
    arcs = 1.0 / np.sqrt((i + 0.5) * (n - i - 0.5))
    best_a, best_val = _try_candidate(arcs, n, best_a, best_val)

    # 4. Piecewise “high‑at‑edges” (U‑shaped)
    for k_frac in (0.008, 0.015, 0.025):
        k = max(1, int(round(k_frac * n)))
        if 2 * k >= n:
            continue
        for high_frac in (0.15, 0.25, 0.35):
            total = 2.0 * k * high_frac
            if total >= 1.0:
                continue
            low = (1.0 - total) / (n - 2 * k)
            a = np.full(n, low)
            a[:k] = high_frac
            a[-k:] = high_frac
            best_a, best_val = _try_candidate(a, n, best_a, best_val)

    # 5. Random Dirichlet draws
    for _ in range(30):
        best_a, best_val = _try_candidate(rng.dirichlet(np.ones(n)),
                                          n, best_a, best_val)

    # 6. Interpolate old solution, if it exists
    if old_seq is not None:
        try:
            old = np.asarray(old_seq, dtype=float)
            old_x = np.linspace(0.0, 1.0, old.shape[0])
            new_x = np.linspace(0.0, 1.0, n)
            a_interp = np.interp(new_x, old_x, old)
            a_interp = np.maximum(a_interp, 0.0)
            a_interp = a_interp / a_interp.sum()
            best_a, best_val = _try_candidate(a_interp,
                                              n, best_a, best_val)
        except Exception:
            pass

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 1 – projected sub‑gradient descent on the active peak
# ----------------------------------------------------------------------
def _subgradient_descent(a: np.ndarray, n: int,
                         start: float, deadline: float,
                         best_a: np.ndarray, best_val: float) -> tuple[np.ndarray, float]:
    """
    Minimise 2·n·max(conv(a)) using a sub‑gradient step that targets the
    current active convolution index.
    """
    rng = np.random.default_rng(12345)
    iteration = 0

    while time.time() < deadline:
        # Full convolution and current objective
        b = _full_convolution(a)
        cur_max = b.max()
        cur_val = 2.0 * n * cur_max

        # Keep global best
        if cur_val < best_val - 1e-12:
            best_val = cur_val
            best_a = a.copy()
            print(f"[GD {iteration:07d}] new best = {best_val:.6f}")

        # Index where the peak occurs
        k_max = int(np.argmax(b))

        # Gradient of the active quadratic form: g_i = 2·a_{k_max‑i}
        rev = k_max - np.arange(n)
        mask = (rev >= 0) & (rev < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[rev[mask]]

        # Descent direction on the simplex (sum(d)=0)
        avg_g = g.mean()
        d = avg_g - g                     # = -(g - avg_g)

        # If all components of d are non‑negative we cannot move further
        if not np.any(d < -1e-15):
            break

        # Largest feasible step before any coordinate would become negative
        neg = d < 0
        alpha_max = np.min(-a[neg] / d[neg])

        # Annealing factor – from 0.5 down to 0.02 over the time budget
        progress = (time.time() - start) / (deadline - start)
        factor = 0.5 * (1.0 - progress) + 0.02 * progress
        alpha = factor * alpha_max

        # Update and re‑normalise (round‑off may drift the sum)
        a = a + alpha * d
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s == 0.0:                       # safety fallback
            a = best_a.copy()
        else:
            a = a / s

        # Occasional tiny random jitter to escape shallow traps
        if iteration % 3000 == 0 and iteration > 0:
            noise = rng.normal(scale=0.001, size=n)
            a = np.maximum(a + noise, 0.0)
            a = a / a.sum()

        iteration += 1

    return best_a, best_val


# ----------------------------------------------------------------------
# Phase 2 – final tiny mixing with the uniform distribution
# ----------------------------------------------------------------------
def _uniform_mix_polish(a: np.ndarray, n: int) -> tuple[np.ndarray, float]:
    """Convex combination with a very small share of the uniform vector."""
    best_a = a.copy()
    best_val = _objective_val(best_a, n)
    uniform = np.full(n, 1.0 / n)
    for alpha in (0.001, 0.003, 0.005, 0.010, 0.020):
        cand = (1.0 - alpha) * best_a + alpha * uniform
        cand = cand / cand.sum()
        val = _objective_val(cand, n)
        if val < best_val:
            best_val, best_a = val, cand.copy()
            print(f"[Mix] new best after alpha={alpha:.3f}: {best_val:.6f}")
    return best_a, best_val


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Return a non‑negative step‑function (list of floats) that minimises
    `evaluate_sequence`.  The routine follows the three‑phase strategy
    described in the module docstring.
    """
    np.random.seed(seed)
    rng = np.random.default_rng(seed)

    start_time = time.time()
    deadline = start_time + budget_s - 0.5          # safety margin

    # Problem size – a few‑ten thousand points give a good trade‑off.
    n = 15000

    # --------------------------------------------------------------
    # Phase 0 – generate a good seed
    # --------------------------------------------------------------
    print("[Init] starting parametric sweep")
    # If a previous solution is available in the global namespace, reuse it.
    old_seq = globals().get("height_sequence_1", None)
    best_a, best_val = _initial_candidate(n, rng, old_seq)
    print(f"[Init] best after sweep = {best_val:.6f}")

    # --------------------------------------------------------------
    # Phase 1 – projected sub‑gradient descent
    # --------------------------------------------------------------
    best_a, best_val = _subgradient_descent(
        best_a, n,
        start=start_time,
        deadline=deadline,
        best_a=best_a,
        best_val=best_val,
    )
    print(f"[GD] best = {best_val:.6f}")

    # --------------------------------------------------------------
    # Phase 2 – tiny uniform mixing polish
    # --------------------------------------------------------------
    best_a, best_val = _uniform_mix_polish(best_a, n)
    print(f"[Final] best after mixing = {best_val:.6f}")

    # --------------------------------------------------------------
    # Final sanity check using the provided wrapper (only for logging)
    # --------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] evaluate_sequence reported = {final_score:.6f}")
    except Exception as exc:          # pragma: no cover
        print("[final] evaluate_sequence raised an exception:", exc)

    # Return a plain Python list – the harness expects that.
    return best_a.tolist()
```
