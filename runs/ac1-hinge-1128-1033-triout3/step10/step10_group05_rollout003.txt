The goal is to minimize  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\]

where `a` is a non‑negative vector (the step‑function heights) and
`(a*a)[k]` is the self‑convolution.
The factor `2 n` is fixed for a given length `n`, therefore the
interesting part is the *shape* of the probability vector
\(p_i=a_i/\sum_j a_j\).

The program below works in four phases:

1. **Exploration of simple parametric families** –  
   a short grid search over families that are known to concentrate mass
   at the ends (powers of \(x(1-x)\) and inverse‑power of the index).
   Each candidate is normalised to a probability vector and its exact
   objective value is evaluated with an FFT based convolution.

2. **Deterministic greedy refinement** –  
   repeatedly moves a small amount of mass from the index that contributes
   most to the current maximal convolution entry to an index with the
   smallest contribution.  The amount moved is computed analytically so
   that the maximal entry would fall to the second‑largest entry (with a
   safety factor).  The move is kept only if the objective really improves.

3. **Projected sub‑gradient descent (polishing)** –  
   uses the exact sub‑gradient of the current maximal entry,
   takes a decreasing step and projects back onto the simplex.
   A few hundred iterations are enough to remove the tiny remaining
   irregularities.

4. **Uniform mixing** –  
   finally the best vector is mixed with a tiny amount of the uniform
   distribution; this often smooths isolated spikes and yields a
   marginal improvement.

All phases respect the global time budget (`budget_s`).  
The implementation is completely self‑contained, uses only `numpy`
(and the already imported `evaluate_sequence`) and complies with the
requirement that every helper function is defined at the top level.

```python
"""
A lightweight multi‑phase optimizer for the self‑convolution
min‑max problem.

The algorithm:
  1. Scan a few 1‑parameter families (edge‑heavy, index‑heavy) on a
     modest size (n≈5000) and keep the best shape.
  2. Deterministic greedy refinement: analytically move mass from the
     most harmful source index to the least harmful target index.
  3. Projected sub‑gradient descent on the exact max‑convolution entry.
  4. Tiny uniform mixing.

All steps stop as soon as the overall time budget (default 1000 s)
is exhausted.  The returned list of non‑negative floats can be fed to
`evaluate_sequence`.
"""

from __future__ import annotations

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Convolution utilities (FFT based, exact up to floating point noise)
# ----------------------------------------------------------------------
def full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a (length = 2·len(a)–1) using FFT."""
    n = a.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Objective evaluation (exact, no security checks)
# ----------------------------------------------------------------------
def objective_value(a: np.ndarray) -> float:
    """Exact value of 2·n·max(conv(a,a)) / (sum(a)**2).  a must be non‑negative."""
    s = a.sum()
    if s <= 0.0:
        return float("inf")
    n = a.shape[0]
    b = full_convolution(a)
    return float(2.0 * n * b.max() / (s * s))


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex
# ----------------------------------------------------------------------
def project_simplex(v: np.ndarray) -> np.ndarray:
    """Projects v onto {x ≥ 0, sum(x)=1}."""
    if np.all(v >= 0) and abs(v.sum() - 1.0) < 1e-12:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.where(u - cssv / (np.arange(len(v)) + 1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Deterministic greedy refinement (phase D)
# ----------------------------------------------------------------------
def deterministic_refine(a: np.ndarray,
                         deadline: float,
                         best_val: float) -> tuple[np.ndarray, float]:
    """Move mass from the index that harms the maximal convolution entry
    to the index that helps the most.  Stops when no improvement is possible
    or the time limit is hit."""
    n = a.shape[0]
    a = a.copy()
    b = full_convolution(a)
    cur_val = 2.0 * n * b.max()

    while time.time() < deadline:
        k_max = int(np.argmax(b))

        # contribution of each i to entry k_max
        idx = np.arange(n)
        mask = (k_max - idx >= 0) & (k_max - idx < n)
        contrib = np.zeros(n, dtype=a.dtype)
        contrib[mask] = a[idx[mask]] * a[k_max - idx[mask]]

        i = int(np.argmax(contrib))
        if a[i] <= 0.0:
            break

        # pick a target index with (currently) smallest a
        j = int(np.argsort(a)[0])               # smallest a
        if j == i:
            # choose the second smallest if we hit the same index
            j = int(np.argsort(a)[1])
        # contributions of i and j to the maximal entry
        a_ki = a[k_max - i] if 0 <= k_max - i < n else 0.0
        a_kj = a[k_max - j] if 0 <= k_max - j < n else 0.0
        if a_ki <= a_kj + 1e-12:
            # moving from i cannot lower the maximal entry
            break

        # second‑largest convolution entry (excluding k_max)
        b_tmp = b.copy()
        b_tmp[k_max] = -np.inf
        second_max = b_tmp.max()
        if second_max == -np.inf:
            second_max = 0.0

        # analytical delta that would bring b[k_max] down to second_max
        denom = 2.0 * (a_ki - a_kj) + 1e-12
        delta_needed = (b[k_max] - second_max) / denom
        delta = min(delta_needed * 0.9, a[i])   # 0.9 = safety factor
        if delta <= 1e-14:
            break

        # incremental update of the convolution (exact)
        b_old = b.copy()
        b[j:j + n] += 2.0 * delta * a
        b[i:i + n] -= 2.0 * delta * a
        L = b.shape[0]
        two_j = 2 * j
        two_i = 2 * i
        ij = i + j
        if two_j < L:
            b[two_j] += delta * delta
        if two_i < L:
            b[two_i] += delta * delta
        if ij < L:
            b[ij] -= 2.0 * delta * delta

        a[i] -= delta
        a[j] += delta

        new_val = 2.0 * n * b.max()
        if new_val < cur_val - 1e-14:
            cur_val = new_val
            if new_val < best_val:
                best_val = new_val
                print(f"[refine] new global best = {best_val:.6f}")
        else:
            # revert – move not beneficial
            b = b_old
            a[i] += delta
            a[j] -= delta
            break

    return a, best_val


# ----------------------------------------------------------------------
# Projected sub‑gradient descent (phase C)
# ----------------------------------------------------------------------
def subgradient_descent(a: np.ndarray,
                        deadline: float,
                        best_val: float,
                        max_iter: int = 2000) -> tuple[np.ndarray, float]:
    """Exact sub‑gradient descent on the true max‑convolution objective."""
    n = a.shape[0]
    a = a.copy()
    eta0 = 0.5 / n           # initial step size (≈ half average entry)
    eta = eta0
    decay = 0.9995

    it = 0
    while time.time() < deadline and it < max_iter:
        b = full_convolution(a)
        cur_val = 2.0 * n * b.max()
        if cur_val < best_val - 1e-14:
            best_val = cur_val
            print(f"[sgd] new global best = {best_val:.6f}")

        k_max = int(np.argmax(b))

        # sub‑gradient of the maximal entry
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        grad = np.zeros_like(a)
        grad[mask] = 2.0 * a[idx[mask]]

        # gradient step + projection onto simplex
        v = a - eta * grad
        a = project_simplex(v)

        eta *= decay
        it += 1

    return a, best_val


# ----------------------------------------------------------------------
# Tiny uniform mixing (post‑processing)
# ----------------------------------------------------------------------
def mix_with_uniform(a: np.ndarray,
                     deadline: float,
                     best_val: float) -> tuple[np.ndarray, float]:
    """Convex combination with a tiny amount of uniform mass."""
    n = a.shape[0]
    uniform = np.full(n, 1.0 / n)

    for alpha in (0.001, 0.003, 0.005, 0.010, 0.020):
        if time.time() >= deadline:
            break
        cand = (1.0 - alpha) * a + alpha * uniform
        cand /= cand.sum()
        val = objective_value(cand)
        if val < best_val:
            best_val = val
            a = cand
            print(f"[mix] new global best = {best_val:.6f}")

    return a, best_val

    except Exception:
        # No previous solution – start from uniform
        best_a = np.full(n, 1.0 / n)
        best_val = objective_value(best_a)
        print(f"[init] start from uniform, value = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase A – sweep simple parametric families
    # ------------------------------------------------------------------
    x = (np.arange(n) + 0.5) / n                # centre of each bin
    eps = 1e-12

    # a small helper for evaluating a raw (non‑normalised) candidate
    def evaluate_candidate(raw: np.ndarray, label: str) -> None:
        nonlocal best_a, best_val
        if time.time() >= deadline:
            return
        a = np.maximum(raw, 0.0)
        s = a.sum()
        if s <= 0.0:
            return
        a /= s
        val = objective_value(a)
        if val < best_val - 1e-14:
            best_val = val
            best_a = a
            print(f"[grid {label:>12}] new best = {best_val:.6f}")

    # ----- hand‑crafted families -------------------------------------------------
    evaluate_candidate(np.ones(n), "uniform")
    evaluate_candidate(np.sin(np.pi * (np.arange(1, n + 1) / (n + 1))), "sin")
    evaluate_candidate(1.0 / np.sqrt(np.clip(x * (1.0 - x), eps, None)), "arcsine")

    # ----- exponential–type (U‑shaped) -----------------------------------------
    for r in (0.9999, 0.9995, 0.998, 0.996, 0.995):
        idx = np.arange(n, dtype=float)
        a_exp = r ** idx + r ** (n - 1 - idx)
        evaluate_candidate(a_exp, f"exp_{r:.4f}")

    # ----- parametric families --------------------------------------------------
    # (x·(1‑x))^{‑β}
    for beta in np.arange(0.10, 3.01, 0.10):
        a = (x * (1.0 - x) + eps) ** (-beta)
        evaluate_candidate(a, f"beta_{beta:4.2f}")

    # inverse‑power of the index (symmetrised)
    idx_one = np.arange(1, n + 1, dtype=float)
    for beta in np.arange(0.20, 3.01, 0.20):
        a = (idx_one ** (-beta) + (n - idx_one + 1) ** (-beta))
        evaluate_candidate(a, f"idxbeta_{beta:4.2f}")

    # ----- random Dirichlet draws (few) ----------------------------------------
    for _ in range(6):
        a_rand = rng.dirichlet(np.ones(n))
        evaluate_candidate(a_rand, "dirichlet")

    # ------------------------------------------------------------------
    # Phase D – deterministic greedy refinement (exact moves)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = deterministic_refine(best_a, deadline, best_val)

    # ------------------------------------------------------------------
    # Phase C – projected sub‑gradient polishing
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = subgradient_descent(best_a, deadline, best_val)

    # ------------------------------------------------------------------
    # Phase E – tiny uniform mixing
    # ------------------------------------------------------------------
    if time.time() < deadline:
        best_a, best_val = mix_with_uniform(best_a, deadline, best_val)

    # ------------------------------------------------------------------
    # Final call to the provided evaluator (for the harness)
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] best evaluation reported = {final_score:.6f}")
    except Exception as exc:   # pragma: no cover
        print("[final] evaluate_sequence raised an exception:", exc)

    return best_a.tolist()
```
