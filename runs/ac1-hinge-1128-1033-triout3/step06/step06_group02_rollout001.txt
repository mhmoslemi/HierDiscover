propose_candidate
-----------------

Search for a non‑negative step‑function (list of heights) that minimizes
the provided ``evaluate_sequence`` objective.

The algorithm works in three stages within the 1000 s budget:

1. **Initialization** – start from the best known construction
   (`height_sequence_1` if it exists) or from a random Dirichlet vector.
   The vector is projected onto the probability simplex (sum = 1).

2. **Mirror‑descent refinement** – repeatedly:
   * compute the full self‑convolution,
   * locate the lag `k*` attaining the maximal value,
   * set the gradient `g_i = a_{k*‑i}` (zero outside the valid range),
   * update multiplicatively `a_i ← a_i·exp(−α·g_i)` (α decays as 1/√t),
   * re‑project onto the simplex.
   The step size is small, the update is inexpensive (O(n log n) via FFT)
   and quickly reduces the peak of the convolution.
   Periodically we apply the “anti‑symmetric reorder’’ heuristic and,
   if no improvement is seen for a while, we inject a tiny random jitter
   to escape plateaus.

3. **Simulated‑annealing hill climbing** – after the gradient phase we
   perform a stochastic local search:
   * randomly transfer a small fraction of mass from one index to another,
   * occasionally swap two entries,
   * accept a move if it lowers the objective, otherwise accept with a
     probability `exp(−Δ/T)` where the temperature `T` decays exponentially.
   The objective is evaluated cheaply as `2·n·max(conv)` because the sum of
   the vector is kept equal to 1 (exactly the same value that
   ``evaluate_sequence`` would return).

During the whole run the best sequence found so far is stored.
A final call to ``evaluate_sequence`` verifies the score before returning.
The implementation uses only NumPy and the standard library, runs

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Return the smallest power of two >= x (used for FFT padding)."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """
    Full linear convolution of a real vector with itself.
    Length of the result is 2·len(x)‑1.
    """
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    # Remove tiny negative rounding artefacts
    np.maximum(conv, 0.0, out=conv)
    return conv


def _anti_symmetric_reorder(a: np.ndarray) -> np.ndarray:
    """
    Pair large values with small ones (left/right) – a cheap heuristic that
    frequently reduces the self‑convolution peak.
    """
    n = a.shape[0]
    sorted_vals = np.sort(a)               # ascending
    new_a = np.empty_like(a)

    half = n // 2
    for i in range(half):
        new_a[i] = sorted_vals[n - 1 - i]          # large → left side
        new_a[n - 1 - i] = sorted_vals[i]          # small → right side

    if n % 2:
        new_a[half] = sorted_vals[half]
    return new_a
