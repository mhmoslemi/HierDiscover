analysisThe problem is a competition which asks to generate a non-negative sequence (list of floats) that minimizes the function evaluate_sequence(seq) = 2 * n * max(conv(seq, seq)) / (sum(seq)**2). The function also clamps values to [0,1000] and enforces non-negative and sum>0.

The sequence length n can be chosen arbitrarily (the evaluate_sequence takes any length). The expression: if we scale the sequence by constant factor c, sum scales linearly, max(conv) scales as c^2 (since convolution of scaled sequence multiplies the product). So evaluate_sequence is scale-invariant: numerator ~ c^2 * max(conv(original)), denominator (sum(c*a))^2 = c^2 * (sum(a))^2, so dependence cancels. So we can view the objective as 2 * n * max(conv(a, a)) / (sum(a)^2). If we normalise sum(a)=1 (or any, but the function is invariant), then objective reduces to 2 * n * max(conv(a, a)). So we want to minimize max(conv(a,a))/n? Actually score = 2 * n * max(conv(a,a)) with sum=1. So the goal: minimize max(conv) among probability vectors a (non-negative sum 1) multiplied by n (i.e., scaling by length). If we change n, we can affect the objective: the factor of n appears directly, so increasing n tends to increase score linearly, unless max(conv) goes down inversely. The objective depends on both n and a.

Essentially we want to find a probability vector for given n that minimizes the maximum element of its self-convolution.

The self-convolution (a*a) length = 2n-1, with indexes k from 0 to 2n-2 (zero-indexed). max(conv) is the max of sum_{i+j=k} a_i a_j, which is like the "auto-correlation" of a: c_k = \sum_i a_i a_{k-i} for k from 0 to 2n-2, with a_i = 0 outside [0,n-1].

Goal: find sequence a_i≥0 with sum=1 to minimize max_k c_k.

This is akin to designing a weight distribution to minimize the largest auto-correlation (peak). Known to have connections to "spectral flatness", "low autocorrelation sequences". But here we have nonnegative real-valued isn't required to be binary.

"""
Search for a non‑negative step‑function that minimizes

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The algorithm uses a large degree of freedom (n≈8000) and a
mass‑transfer simulated‑annealing scheme with an *exact* update of the
full convolution.  At each step we move a small amount of probability
mass from a source index (chosen proportionally to its contribution to
the current maximal convolution entry) to a random destination index.
The convolution is updated with O(n) slice operations, so a very large
number of moves can be performed in the allotted time.  The best
sequence encountered is returned.

The code is pure NumPy; no external solvers are required and it runs
well within a 1000 s budget.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Full linear convolution via real FFT (used only occasionally for
# re‑synchronisation).
# ----------------------------------------------------------------------
def _full_convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Return the full linear convolution a * b using a real FFT."""
    size = a.shape[0] + b.shape[0] - 1
    nfft = 1 << (size - 1).bit_length()
    Fa = np.fft.rfft(a, n=nfft)
    Fb = np.fft.rfft(b, n=nfft)
    Fc = Fa * Fb
    conv = np.fft.irfft(Fc, n=nfft)[:size]
    return conv


# ----------------------------------------------------------------------
# Main entry point required by the grader.
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Return a sequence of non‑negative heights that (approximately) minimises
    the evaluation function.  The routine respects a `budget_s` second
    time limit, performs an intensive simulated‑annealing search with
    exact convolution updates, and prints progress information.
    """
    start_time = time.time()
    deadline = start_time + budget_s - 5.0          # safety margin
    rng = np.random.default_rng(seed)

    # ------------------------------------------------------------------
    # Problem size – a larger n gives more freedom while still fitting
    # comfortably in RAM.
    # ------------------------------------------------------------------
    n = 8000

    # ------------------------------------------------------------------
    # Warm start: use a previously found sequence if available,
    # otherwise build a random mixture of classic shapes.
    # ------------------------------------------------------------------
    a = None
    if 'height_sequence_1' in globals():
        try:
            base = np.asarray(height_sequence_1, dtype=np.float64)
            if base.shape[0] >= n:
                a = base[:n].copy()
            else:
                a = np.pad(base, (0, n - base.shape[0]), constant_values=0.0)
        except Exception:
            a = None

    if a is None:
        x = np.arange(n, dtype=np.float64)

        shapes = []

        # exponential tails
        for _ in range(2):
            lam = rng.uniform(5e-4, 2e-2)
            shapes.append(np.exp(-lam * x))

        # power‑law decays
        for _ in range(2):
            p = rng.uniform(0.3, 2.0)
            shapes.append((x + 1) ** (-p))

        # half‑sine (positive)
        shapes.append(np.sin(np.pi * (x + 0.5) / n))

        # centred Gaussian
        sigma = rng.uniform(n / 8.0, n / 2.0)
        shapes.append(np.exp(-0.5 * ((x - (n - 1) / 2.0) / sigma) ** 2))

        # simple triangle
        shapes.append(np.minimum(x, n - 1 - x) + 1.0)

        # random convex combination
        w = rng.random(len(shapes))
        w /= w.sum()
        a = sum(wi * sh for wi, sh in zip(w, shapes))

    # ------------------------------------------------------------------
    # Normalise to the probability simplex.
    # ------------------------------------------------------------------
    a = np.maximum(0.0, a)
    s = a.sum()
    if s == 0.0:
        a = np.full(n, 1.0 / n)
    else:
        a /= s

    # ------------------------------------------------------------------
    # Initial convolution, score and bookkeeping.
    # ------------------------------------------------------------------
    conv = _full_convolution_fft(a, a)          # length 2*n‑1
    cur_max = conv.max()
    cur_score = 2.0 * n * cur_max                # sum(a)=1 ⇒ scale‑invariant
    best_val = cur_score
    best_seq = a.copy()
    print(f"[init] n={n} score={cur_score:.12f}")

    # ------------------------------------------------------------------
    # Simulated‑annealing loop with exact O(n) convolution updates.
    # ------------------------------------------------------------------
    total_time = deadline - start_time
    it = 0
    stagn = 0                                    # iterations without improvement
    max_transfer_const = 0.02                     # absolute upper bound on a single move

    while time.time() < deadline:
        it += 1
        # linear cooling based on remaining time
        remaining = deadline - time.time()
        T = max(1e-7, (cur_score * 0.2) * (remaining / total_time))

        # --------------------------------------------------------------
        # Choose a source index weighted by its contribution to the
        # current maximal convolution entry (this is a sub‑gradient step).
        # --------------------------------------------------------------
        kmax = int(conv.argmax())                # index of the current max
        idx = np.arange(n)
        jdx = kmax - idx
        mask = (jdx >= 0) & (jdx < n)
        if mask.any():
            contrib = np.zeros(n, dtype=np.float64)
            contrib[mask] = a[idx[mask]] * a[jdx[mask]]
            total_contrib = contrib.sum()
            if total_contrib > 0:
                probs = contrib / total_contrib
                i = rng.choice(n, p=probs)
            else:
                i = rng.integers(0, n)
        else:
            i = rng.integers(0, n)

        if a[i] <= 0.0:
            continue                                 # unlikely but safe

        # random destination, distinct from source
        j = rng.integers(0, n - 1)
        if j >= i:
            j += 1

        # amount to transfer: a small fraction of the source mass
        max_transfer = min(a[i], max_transfer_const)
        if max_transfer <= 0.0:
            continue
        delta = rng.random() * max_transfer
        if delta <= 0.0:
            continue

        # --------------------------------------------------------------
        # Compute the candidate convolution by an exact slice update.
        # --------------------------------------------------------------
        conv_candidate = conv.copy()
        # shift contributions of the moved mass
        conv_candidate[i:i + n] -= 2.0 * delta * a
        conv_candidate[j:j + n] += 2.0 * delta * a
        # quadratic correction (tiny but keeps the update exact)
        conv_candidate[2 * i] += delta * delta
        conv_candidate[2 * j] += delta * delta
        conv_candidate[i + j] -= 2.0 * delta * delta

        new_max = conv_candidate.max()
        new_score = 2.0 * n * new_max

        # --------------------------------------------------------------
        # Metropolis acceptance test.
        # --------------------------------------------------------------
        if new_score < cur_score or rng.random() < math.exp(-(new_score - cur_score) / T):
            # accept move
            a[i] -= delta
            a[j] += delta
            conv = conv_candidate
            cur_max = new_max
            cur_score = new_score
            stagn = 0

            if new_score < best_val - 1e-12:
                best_val = new_score
                best_seq = a.copy()
                print(f"[SA iter {it:6d}] new_best={best_val:.12f}  T={T:.2e}")

        else:
            stagn += 1

        # --------------------------------------------------------------
        # Periodic full recomputation (removes accumulated rounding error)
        # and occasional random jitter to escape possible plateaux.
        # --------------------------------------------------------------
        if it % 5000 == 0:
            conv = _full_convolution_fft(a, a)
            cur_max = conv.max()
            cur_score = 2.0 * n * cur_max

        if stagn > 200_000:
            # a gentle global perturbation
            jitter = rng.normal(scale=0.001, size=n)
            a = a + jitter
            a = np.maximum(a, 0.0)
            a /= a.sum()
            conv = _full_convolution_fft(a, a)
            cur_max = conv.max()
            cur_score = 2.0 * n * cur_max
            stagn = 0
            print(f"[SA jitter] iter {it}")

    # ------------------------------------------------------------------
    # Return the best sequence in the format required by `evaluate_sequence`.
    # ------------------------------------------------------------------
    final_seq = [float(max(0.0, min(1000.0, x))) for x in best_seq.tolist()]

    # optional logging of the official score
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"[result] final_score={final_score:.12f}, length={len(final_seq)}")
    except Exception:
        print("[result] evaluate_sequence not available")

    return final_seq
