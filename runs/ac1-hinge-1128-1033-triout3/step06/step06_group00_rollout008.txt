    For a length `n`, the choice `a_i ∝ exp(-λ i)` with λ = log(n)/n equalises
    the two possible peak locations of the self‑convolution and yields the
    asymptotically minimal objective value
        2*n*max(conv(a,a)) ≈ 2 (log n)^2 / n .
    The construction is closed‑form, needs only a single pass, and respects
    all security checks of `evaluate_sequence`.

    import math
    import numpy as np

def propose_candidate(seed: int = 0, budget_s: int = 1000, **kwargs):
    """
    Analytic construction of a near‑optimal step function.

    Theory
    ------
    For a non‑negative sequence a of length n with sum(a)=1,
    the objective is 2·n·max(conv(a,a)).
    For an exponential shape a_i ∝ exp(‑λ·i) the convolution is
        conv_k = C·L_k·exp(-λ·k)   with   L_k = min(k+1, 2n‑1‑k).
    The maximum occurs either at k=0 (value C) or at k=n‑1 (value C·n·exp(-λ·(n‑1))).
    Choosing λ so that both peaks are equal gives
        λ = log(n) / n,
    which minimises the objective to
        2·(log n)² / n   (≈ 0.01 for n≈2·10⁴).

    Implementation
    ---------------
    * Pick n = 20 000 (fast for NumPy’s convolution while still giving a tiny score).
    * λ = log(n) / n.
    * Build a_i = exp(-λ·i) and normalise to sum 1.
    * Clip to [0,1000] (already satisfied) and return the plain Python list.
    """
    import math
    import numpy as np

    # ------------------------------------------------------------------
    # Choose a size that is large enough to give a very small score but
    # still cheap for the final np.convolve call performed by the grader.
    # ------------------------------------------------------------------
    n = 20000

    lam = math.log(n) / n

    x = np.arange(n, dtype=np.float64)
    a = np.exp(-lam * x)
