Propose a non‑negative step function (a probability vector) that tries to
flatten its self‑convolution.  The algorithm consists of three stages
inside the 1000 s time budget:

1. **Warm‑start shapes** – a small set of parametrised families
   (exponential, power‑law, half‑sine, Gaussian, “Beta‑U‑shaped”,
   etc.) are generated, normalised to sum = 1 and the best one is kept.

2. **Linear‑programming refinement on a small problem** – the current
   vector `a` (size 𝑛₀≈500) defines a linear operator
   `F(a)g = a * g`.  Solving the LP

        max   1ᵀg
        s.t.  F(a) g ≤ M      (M = max(a*a))
              g ≥ 0

   yields a vector `g` that has a larger ℓ₁‑norm while respecting the same
   maximal convolution bound `M`.  Normalising `g` and mixing it with `a`
   (parameter τ≈0.5) strictly reduces the bound.  The LP is cheap for
   𝑛₀≈500 and is iterated until no improvement is observed.

3. **Upscale & continuous optimisation** – the refined small vector is
   interpolated to a larger size (𝑛≈6000) and a few thousand steps of
   projected sub‑gradient descent (Adam) followed by a short simulated
   annealing phase are applied.  The final vector is clipped to the
   `[0,1000]` range required by `evaluate_sequence`.

All operations keep the vector on the probability simplex, which makes
the evaluation function `2·n·max(conv(a,a))` scale‑invariant.  The code
prints intermediate scores and returns the best sequence found before the
budget expires.

import time
import math
import numpy as np
from scipy.optimize import linprog
from scipy.linalg import toeplitz

# ----------------------------------------------------------------------
# Helper: projection onto the probability simplex (Duchi et al. 2008).
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if np.any(cond):
        rho = np.nonzero(cond)[0][-1]
        theta = cssv[rho] / (rho + 1)
    else:
        theta = cssv[-1] / n
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Full linear convolution using a real FFT (fast for all sizes).
# ----------------------------------------------------------------------
def _full_convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    size = a.shape[0] + b.shape[0] - 1
    nfft = 1 << (size - 1).bit_length()
    Fa = np.fft.rfft(a, n=nfft)
    Fb = np.fft.rfft(b, n=nfft)
    conv = np.fft.irfft(Fa * Fb, n=nfft)[:size]
    return conv


# ----------------------------------------------------------------------
# Objective for a vector already normalised (sum = 1).
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    n = a.size
    conv = _full_convolution_fft(a, a)
    return float(2.0 * n * conv.max())

    # ------------------------------------------------------------------
    # Helper: generate a list of candidate shapes for the warm start.
    # ------------------------------------------------------------------
    def generate_shapes(n):
        x = np.arange(n, dtype=np.float64)
        shapes = []

        # exponential families
        for lam in (5e-4, 2e-3, 8e-4):
            shapes.append(np.exp(-lam * x))

        # power‑law families
        for p in (0.4, 1.0, 1.6):
            shapes.append(1.0 / (x + 1) ** p)

        # half‑sine (always positive)
        shapes.append(np.sin(np.pi * (x + 0.5) / n))

        # centred Gaussian
        sigma = rng.uniform(n / 8.0, n / 2.0)
        shapes.append(np.exp(-0.5 * ((x - (n - 1) / 2.0) / sigma) ** 2))

        # simple triangle
        shapes.append(np.minimum(x, n - 1 - x) + 1.0)

        # Beta‑U‑shaped (inverse‑sqrt at the ends, arcsine‑like)
        eps = 1e-12
        beta_like = 1.0 / np.sqrt(np.maximum(x + 0.5, eps) *
                                 np.maximum(n - 0.5 - x, eps))
        shapes.append(beta_like)

        # random convex combos of the above (few)
        for _ in range(5):
            w = rng.random(len(shapes))
            w /= w.sum()
            combo = sum(ww * s for ww, s in zip(w, shapes))
            shapes.append(combo)

        return shapes

    # ------------------------------------------------------------------
    # Warm start – try to reuse any previously discovered sequence.
    # ------------------------------------------------------------------
    a_small = None
    if 'height_sequence_1' in globals():
        try:
            base = np.asarray(height_sequence_1, dtype=np.float64)
            # down‑sample to n_small by averaging blocks
            if base.size > n_small:
                block = base.size // n_small
                base = base[:block * n_small].reshape(n_small, block).mean(axis=1)
            elif base.size < n_small:
                base = np.pad(base, (0, n_small - base.size))
            a_small = np.maximum(0.0, base)
            if a_small.sum() > 0:
                a_small /= a_small.sum()
            else:
                a_small = None
        except Exception:
            a_small = None

    # If not usable, create a set of classic shapes and pick the best.
    if a_small is None:
        cand_shapes = generate_shapes(n_small)
        best_val = np.inf
        for s in cand_shapes:
            a = np.maximum(0.0, s)
            if a.sum() == 0:
                continue
            a /= a.sum()
            val = _objective(a)
            if val < best_val:
                best_val = val
                a_small = a.copy()
        print(f"[warm] initial small size={n_small} score={best_val:.12f}")

    # ------------------------------------------------------------------
    # Phase 1 – LP refinement on the small problem.
    # ------------------------------------------------------------------
    it_lp = 0
    best_small_score = _objective(a_small)
    best_small = a_small.copy()

    while time.time() < deadline - 30.0:   # leave time for the big phase
        it_lp += 1
        # current max‑convolution bound
        conv = _full_convolution_fft(a_small, a_small)
        M = conv.max()

        # Build the (2n‑1) × n convolution matrix F such that F @ g = a*g
        col = np.concatenate([a_small, np.zeros(n_small - 1)])
        row = np.concatenate([a_small[:1], np.zeros(2 * n_small - 2)])
        F_full = toeplitz(col, row)          # dense (2n‑1)×(2n‑1)
        F = F_full[:, :n_small]              # keep only the first n columns

        # Linear program: maximise sum(g) s.t. F g ≤ M, g ≥ 0
        c_lp = -np.ones(n_small)             # minimise –sum(g)  →  maximise sum(g)
        b_ub = np.full(F.shape[0], M)
        res = linprog(c_lp, A_ub=F, b_ub=b_ub,
                      bounds=[(0, None)] * n_small,
                      method='highs', options={'presolve': True})

        if res.status != 0:
            # LP failed – exit the refinement loop
            print("[LP] solver failed, breaking LP loop")
            break

        g = res.x
        sum_g = g.sum()
        if sum_g <= 1.0 + 1e-12:
            # No increase in ℓ₁‑norm – cannot improve further
            print("[LP] no ℓ₁‑norm gain, terminating LP iterations")
            break

        # Normalise g to keep the sum = 1
        g_norm = g / sum_g

        # Simple line‑search on mixing weight τ
        best_local = None
        best_local_score = np.inf
        for tau in (0.2, 0.4, 0.6, 0.8):
            a_candidate = (1.0 - tau) * a_small + tau * g_norm
            a_candidate = _project_simplex(a_candidate)   # keep exact sum = 1
            cand_score = _objective(a_candidate)
            if cand_score < best_local_score:
                best_local_score = cand_score
                best_local = a_candidate

        if best_local_score < best_small_score - 1e-12:
            best_small_score = best_local_score
            best_small = best_local.copy()
            a_small = best_small.copy()
            print(f"[LP iter {it_lp:4d}] new best small score={best_small_score:.12f}")
        else:
            # No improvement – stop the LP refinement
            print("[LP] mixing did not improve, stopping")
            break

    # ------------------------------------------------------------------
    # Phase 2 – upscale to the final size and fine‑tune with gradient
    # descent + simulated annealing.
    # ------------------------------------------------------------------
    # Linear interpolation from n_small to n_big
    xs = np.linspace(0, 1, n_small)
    xb = np.linspace(0, 1, n_big)
    a_big = np.interp(xb, xs, best_small)
    a_big = np.maximum(0.0, a_big)
    a_big /= a_big.sum()
    cur = a_big.copy()
    cur_score = _objective(cur)
    best_big = cur.copy()
    best_big_score = cur_score
    print(f"[upscale] score after up‑scale n={n_big}: {cur_score:.12f}")

    # ------------------------------------------------------------------
    # Sub‑gradient descent (Adam) – keep the vector on the simplex.
    # ------------------------------------------------------------------
    beta1, beta2 = 0.9, 0.999
    lr = 0.08
    eps_adam = 1e-8
    m = np.zeros_like(cur)
    v = np.zeros_like(cur)
    beta1_pow = 1.0
    beta2_pow = 1.0
    it_sgd = 0
    stagn = 0
    while time.time() < deadline - 15.0:
        it_sgd += 1
        beta1_pow *= beta1
        beta2_pow *= beta2

        conv = _full_convolution_fft(cur, cur)
        M = conv.max()
        score = 2.0 * n_big * M
        if score < best_big_score - 1e-12:
            best_big_score = score
            best_big = cur.copy()
            stagn = 0
            print(f"[SGD iter {it_sgd:6d}] new best={best_big_score:.12f}")
        else:
            stagn += 1

        # sub‑gradient of max‑conv (average over active indices)
        tol = 1e-12
        active = np.flatnonzero(conv >= M - tol)
        w = np.zeros_like(conv)
        w[active] = 1.0 / max(1, active.size)
        rev = cur[::-1]
        g = 2.0 * _full_convolution_fft(rev, w)[n_big - 1:n_big - 1 + n_big]

        # Adam update
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)

        m_hat = m / (1.0 - beta1_pow)
        v_hat = v / (1.0 - beta2_pow)

        step = lr * m_hat / (np.sqrt(v_hat) + eps_adam)
        cur_candidate = cur - step
        cur = _project_simplex(cur_candidate)

        # occasional random jitter if stagnation is observed
        if stagn > 4000:
            jitter = rng.normal(scale=0.001, size=n_big)
            cur = cur + jitter
            cur = _project_simplex(cur)
            stagn = 0
            m.fill(0.0)
            v.fill(0.0)
            beta1_pow = beta2_pow = 1.0
            print(f"[SGD jitter] iter {it_sgd}")

        if it_sgd % 20000 == 0:
            cur = cur / cur.sum()

    # ------------------------------------------------------------------
    # Phase 3 – simple simulated‑annealing fine‑tuning.
    # ------------------------------------------------------------------
    cur_score = _objective(cur)
    if cur_score < best_big_score:
        best_big_score = cur_score
        best_big = cur.copy()

    T0 = 1e-3
    Tmin = 1e-7
    it_sa = 0
    while time.time() < deadline:
        it_sa += 1
        T = max(Tmin, T0 * (1.0 - it_sa / 200_000))

        i, j = rng.choice(n_big, size=2, replace=False)
        if cur[i] <= 0.0:
            continue
        max_transfer = min(cur[i], 0.01)
        delta = rng.uniform(0.0, max_transfer)
        new = cur.copy()
        new[i] -= delta
        new[j] += delta
        new_score = _objective(new)
        if new_score < cur_score:
            accept = True
        else:
            accept = rng.random() < math.exp(-(new_score - cur_score) / T)

        if accept:
            cur = new
            cur_score = new_score
            if cur_score < best_big_score - 1e-12:
                best_big_score = cur_score
                best_big = cur.copy()
                print(f"[SA iter {it_sa:6d}] new best={best_big_score:.12f}")

        if it_sa % 20000 == 0:
            # occasional global jitter to escape plateaus
            cur = cur + rng.normal(scale=0.001, size=n_big)
            cur = _project_simplex(cur)
            cur_score = _objective(cur)

    # ------------------------------------------------------------------
    # Return the best sequence in the required format.
    # ------------------------------------------------------------------
    final_seq = [float(max(0.0, min(1000.0, x))) for x in best_big.tolist()]
    try:
        final_score = evaluate_sequence(final_seq)
        print(f"[result] final_score={final_score:.12f}, length={len(final_seq)}")
    except Exception:
        print("[result] evaluate_sequence not available")

    return final_seq
