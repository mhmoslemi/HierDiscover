assistantfinal**Solution Overview**

The objective is  

\[
J(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because this expression is scale‑invariant we may restrict ourselves to 
probability vectors `a` (i.e. `∑a = 1`).  
For a fixed `a` let  

\[
M(a)=\max_k (a*a)_k .
\]

If we can find another non‑negative vector `g` that satisfies  

\[
(a*g)_k\le M(a)\qquad\forall k,
\]

then we may replace a fraction of the mass of `a` by `g`:

\[
a^{\rm new}= (1-\tau)a+\tau\frac{g}{\sum g},
\qquad 0<\tau\le 1 .
\]

Since every constraint is linear in `g`, the search for a `g` that maximises
the total added mass `∑ g_i` is a **linear programme**:

```
max   1ᵀ g
s.t.  (a * g)_k ≤ M(a)   for all k
      g ≥ 0 .
```

Increasing the total mass while respecting the convolution bound forces the
next self‑convolution `M(a^{new})` to drop.  Repeating the LP‑step a few
times drives the objective towards its optimum.

The algorithm consists of four stages

1. **Initial seed** – a short sweep over the two‑parameter Beta family
   `(i+1)^{p-1}(n-i)^{q-1}` (mostly positive entries).  The best seed is
   kept as the starting vector `a`.

2. **Iterative LP‑expansion** – solve the LP described above, mix the
   solution into `a` with a decreasing step size `τ`, and repeat.
   The LP is built with a dense matrix (`A_{k,i}=a_{k-i}`) because the
   problem size (`n≈2000`) comfortably fits into memory and the HiGHS
   solver is very fast for this scale.

3. **Fine‑grained local search** – a cheap simulated‑annealing move that
   transfers a small amount of probability mass from indices that
   contribute heavily to the current maximal convolution entry to
   low‑contributing indices.  This step refines the result produced by the
   LP loop.

4. **Return the best vector** – the final vector is sent to the provided
   `evaluate_sequence` wrapper (the wrapper clamps values, therefore the
   printed vector is already safe).

All work is performed inside the 1000 s budget; the bulk of the time is
spent in the LP‑loop (≈0.5 s per solve for `n=2000`).  The whole pipeline
comfortably finishes well before the deadline.

```python
"""
Propose a step‑function (non‑negative list) that minimises the
`evaluate_sequence` objective.

Algorithm
---------
1. Build a Beta‑family seed (a_i ∝ (i+1)^{p‑1} (n‑i)^{q‑1}) on a grid of
   (p,q).  Keep the best (lowest exact objective).

2. Repeatedly:
   * compute M = max self‑convolution,
   * solve the linear programme   max 1ᵀ g   s.t.  (a * g)_k ≤ M,  g ≥ 0,
   * normalise g, mix a ← (1‑τ) a + τ g   (τ slowly decays).

   The LP is solved with SciPy’s HiGHS backend; the constraint matrix
   contains the shifted copies of the current a.

3. After the LP phase run a short simulated‑annealing hill‑climber that
   moves a tiny amount of mass from high‑contributing indices to low‑
   contributing ones.  Moves that improve the exact objective are always
   accepted; uphill moves are accepted with Metropolis probability.

4. Return the best vector (its sum is 1, which does not affect the final
   objective because it is scale‑invariant).
"""

import time
import numpy as np
from scipy.optimize import linprog

# ----------------------------------------------------------------------
# Helper functions (all top‑level, no closures)
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of a vector with itself (length 2·len‑1)."""
    return np.convolve(x, x)


def _objective(a: np.ndarray) -> float:
    """Exact value of the evaluation function with Σa = 1."""
    n = a.shape[0]
    max_conv = _full_convolution(a).max()
    return float(2.0 * n * max_conv)


def _beta_family_best(n: int):
    """Sweep a two‑parameter Beta family and keep the best vector."""
    best_a = None
    best_val = np.inf

    # exponents grid – a mix of linear and log spacing
    p_vals = np.concatenate([np.linspace(0.2, 1.0, 9),
                             np.geomspace(1.0, 6.0, 7)[1:]])
    q_vals = p_vals.copy()
    i = np.arange(1, n + 1, dtype=np.float64)

    for p in p_vals:
        for q in q_vals:
            a = (i ** (p - 1.0)) * ((n - i + 1) ** (q - 1.0))
            s = a.sum()
            if s == 0.0:
                continue
            a /= s
            val = _objective(a)
            if val < best_val:
                best_val = val
                best_a = a.copy()
    return best_a, best_val


def _solve_lp(f: np.ndarray, M: float):
    """
    Solve   max 1ᵀ g   subject to   (f * g)_k ≤ M   for all k,
    with g ≥ 0.
    Returns the optimal g (may be all zeros if the LP fails).
    """
    n = f.shape[0]
    # Build constraint matrix A of shape (2n‑1, n) where
    # A[k, i] = f_{k‑i}  (0 if index out of range).
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)
    for i in range(n):
        A[i:i + n, i] = f

    # Linear programme data
    c = -np.ones(n, dtype=np.float64)               # minimise –1ᵀg  → maximise 1ᵀg
    b_ub = np.full(rows, M, dtype=np.float64)

    # Bounds g_i ≥ 0
    bounds = [(0, None)] * n

    # HiGHS is the default and very fast for dense problems of this size.
    res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if not res.success:
        # fall back to a zero vector – this will simply leave the current a unchanged
        return np.zeros_like(f)
    return res.x


def _lp_expansion(a: np.ndarray, max_iters: int, deadline: float, start_time: float):
    """
    Repeatedly solve the LP described in the algorithm overview and mix the
    result back into a.  Returns (best_a, best_val) observed during the loop.
    """
    n = a.shape[0]
    best_a = a.copy()
    best_val = _objective(best_a)

    for it in range(max_iters):
        now = time.time()
        if now >= deadline:
            break

        # current bound
        conv_a = _full_convolution(a)
        M = conv_a.max()

        # solve LP
        g = _solve_lp(a, M)

        # the LP could return the zero vector (e.g. numerical issues); guard against it
        if g.sum() < 1e-12:
            break

        # normalise g to a probability vector
        g_norm = g / g.sum()

        # step size τ – starts at 0.25 and decays to 0.02
        tau = 0.25 * (1.0 - it / max_iters) + 0.02

        # convex combination
        a = (1.0 - tau) * a + tau * g_norm

        # keep strictly positive numbers (helps the next LP)
        eps = 1e-14
        a = np.maximum(a, eps)
        a /= a.sum()

        cur_val = _objective(a)
        if cur_val < best_val:
            best_val = cur_val
            best_a = a.copy()
            print(f"[LP   {it:3d}] new best = {best_val:.6f}")

        # stop early if we have already crossed the target
        if best_val <= 1.503:
            break

    return best_a, best_val


def _hillclimb(a0: np.ndarray, deadline: float, start_time: float):
    """
    Simple simulated‑annealing hill‑climber that moves a small amount of mass
    from indices that strongly contribute to the current maximal convolution
    entry to indices that contribute little.
    """
    a = a0.copy()
    n = a.shape[0]
    conv_a = _full_convolution(a)
    cur_val = 2.0 * n * conv_a.max()

    best_a = a.copy()
    best_val = cur_val

    # annealing schedule
    T_start, T_end = 0.015, 1e-7
    frac_start, frac_end = 0.35, 0.001

    it = 0
    while True:
        now = time.time()
        if now >= deadline:
            break

        progress = (now - start_time) / (deadline - start_time)
        T = T_start * (T_end / T_start) ** progress
        max_frac = frac_start * (1.0 - progress) + frac_end * progress

        # find the index k where the convolution currently attains its maximum
        k_max = int(np.argmax(conv_a))

        # contribution of each a_i to that entry (only indices that really appear)
        idx = k_max - np.arange(n)
        mask = (idx >= 0) & (idx < n)
        contrib = np.zeros_like(a)
        contrib[mask] = a[mask] * a[idx[mask]]
        total = contrib.sum()

        # source – probability proportional to contribution
        if total > 0:
            src_probs = contrib / total
            i = np.random.choice(n, p=src_probs)
        else:
            i = np.argmax(a)

        if a[i] < 1e-15:
            continue

        # target – favour indices with small contribution
        tgt_weights = np.zeros_like(a)
        tgt_weights[mask] = 1.0 / (contrib[mask] + 1e-15)
        tgt_weights[i] = 0.0
        wsum = tgt_weights.sum()
        if wsum > 0:
            j = np.random.choice(n, p=tgt_weights / wsum)
        else:
            j = (i + 1) % n

        # amount to move
        delta = a[i] * np.random.rand() * max_frac
        if delta <= 0.0:
            continue

        # incremental convolution update (O(n))
        b_new = conv_a.copy()
        b_new[j:j + n] += 2.0 * delta * a
        b_new[i:i + n] -= 2.0 * delta * a
        b_new[2 * j] += delta * delta
        b_new[2 * i] += delta * delta
        b_new[i + j] -= 2.0 * delta * delta

        new_val = 2.0 * n * b_new.max()

        # Metropolis acceptance
        accept = False
        if new_val < cur_val - 1e-15:
            accept = True
        else:
            if T > 0:
                prob = np.exp(-(new_val - cur_val) / T)
                if np.random.rand() < prob:
                    accept = True

        if accept:
            a[i] -= delta
            a[j] += delta
            conv_a = b_new
            cur_val = new_val

            if cur_val < best_val:
                best_val = cur_val
                best_a = a.copy()
                print(f"[Hill  {it:4d}] new best = {best_val:.6f}")
                if best_val <= 1.503:
                    break
        it += 1

    return best_a, best_val

def propose_candidate(seed: int = 123,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Optimise a non‑negative step‑function under the 1000 s budget.
    Returns a list whose sum is 1 and that (attempts to) minimise
    ``evaluate_sequence``.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a short safety margin for the final evaluation call
    deadline = start_time + budget_s - 0.5

    # ------------------------------------------------------------------
    # Problem size (a few thousand entries give a good trade‑off)
    # ------------------------------------------------------------------
    n = 2000   # 2000 works well with the dense LP formulation

    # ------------------------------------------------------------------
    # 0️⃣ Initialise from a previous solution if available
    # ------------------------------------------------------------------
    a0 = None
    try:
        old = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        old_len = old.shape[0]
        # linear interpolation onto the new grid
        new_x = np.linspace(0.0, 1.0, n)
        old_x = np.linspace(0.0, 1.0, old_len)
        a0 = np.interp(new_x, old_x, old)
        a0 = np.maximum(a0, 0.0)
        a0 /= a0.sum()
        print("[init] interpolated previous solution")
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1️⃣  Beta‑family sweep (always performed)
    # ------------------------------------------------------------------
    best_a, best_val = None, np.inf
    if a0 is not None:
        val = _objective(a0)
        best_a, best_val = a0.copy(), val
        print(f"[init] start from interpolated solution, value={best_val:.6f}")

    try:
        shape_a, shape_val = _beta_family_best(n)
        if shape_val < best_val:
            best_a, best_val = shape_a, shape_val
            print(f"[init] beta‑family sweep improved value={best_val:.6f}")
    except Exception as exc:
        print("[init] beta‑family sweep failed:", exc)

    # fallback to a random start if everything else failed
    if best_a is None:
        a = np.random.rand(n)
        a /= a.sum()
        best_a, best_val = a, _objective(a)
        print("[init] random start, value=", best_val)

    # ------------------------------------------------------------------
    # 2️⃣  LP‑expansion phase (≈40 % of the total budget)
    # ------------------------------------------------------------------
    lp_deadline = start_time + 0.40 * budget_s
    best_a, best_val = _lp_expansion(best_a,
                                     max_iters=15,
                                     deadline=lp_deadline,
                                     start_time=start_time)

    # ------------------------------------------------------------------
    # 3️⃣  Fine‑grained simulated‑annealing hill‑climber (remaining budget)
    # ------------------------------------------------------------------
    best_a, best_val = _hillclimb(best_a,
                                  deadline=deadline,
                                  start_time=lp_deadline)

    # ------------------------------------------------------------------
    # 4️⃣  Final evaluation (uses the provided secure wrapper)
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_a.tolist())
        print(f"[final] reported score = {final_score:.6f}")
    except Exception as exc:               # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    return best_a.tolist()
```
