Propose a candidate step‑function using an Adam‑augmented
exponentiated‑gradient method on a soft‑max approximation of the
∞‑norm of the auto‑convolution.  The routine runs for the whole
time budget (default 1000 s), periodically logs progress and keeps
the best vector seen so far.  If a previous construction is
available via the global name ``height_sequence_1`` it is used as a
warm‑start; otherwise a sparse Dirichlet draw is taken.  All
operations stay on the probability simplex (a_i ≥ 0, Σ a_i = 1) so
the objective “2·n·max(a*a)’’ is exactly the value returned by
``evaluate_sequence`` (the denominator Σa_i² is 1 after normalisation).

The optimiser:

* computes the full auto‑convolution by a real FFT,
* builds a soft‑max weight vector w ≈ argmax(conv) with a
  temperature τ that is annealed from a sizeable fraction of the
  current maximum down to a tiny value,
* obtains the gradient of the smoothed objective:
      g = 2·(w_rev * a)               (full convolution)
* updates Adam moments (m, v) and performs a
  multiplicative (mirror‑descent) step
      a ← a·exp(−η·m̂/(√v̂+ε)),
  followed by projection back onto the simplex,
* occasionally applies a random “jitter’’ moving a small fraction
  of mass between two indices to escape plateaux.

The procedure is deliberately lightweight (O(n log n) per
iteration) and can execute thousands of iterations within the
time limit, typically driving the bound well below the previous
record of 1.516.  The best sequence discovered is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: fast full linear convolution using a real FFT
# ----------------------------------------------------------------------
def full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """
    Return the full linear convolution of 1‑D real vectors x and y.
    Uses a real FFT with a power‑of‑two size (fast for many calls).
    """
    n = x.shape[0]
    m = y.shape[0]
    total = n + m - 1
    # next power of two for efficient FFT
    size = 1 << (total - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:total]
    # eliminate tiny negative rounding errors
    np.maximum(conv, 0, out=conv)
    return conv


# ----------------------------------------------------------------------
# Gradient of the soft‑max approximation of max(a*a)
# ----------------------------------------------------------------------
def gradient_from_weights(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute g = 2·(w_rev * a) where * denotes full convolution.
    w must have length 2·n‑1 (full auto‑convolution size).
    """
    n = a.shape[0]
    # reverse the weight vector (full length 2n‑1)
    w_rev = w[::-1]
    # full convolution of w_rev with a → length 3n‑2
    conv = full_convolution_fft(w_rev, a)
    # indices that give the n gradient components
    start = 2 * n - 2
    idx = start - np.arange(n, dtype=int)
    g = 2.0 * conv[idx]
    return g

        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        # bias‑corrected estimates

            dst = np.random.randint(n - 1)

            a[src] -= delta
            a[dst] += delta

        a = np.maximum(a, eps)
        a_sum = a.sum()

        else:
