"""
Hill‑climbing on the simplex to flatten the self‑convolution.

The code keeps an exact convolution (full length 2n‑1) and performs
small “mass‑transfer” moves:
    a_i ← a_i – δ ,   a_j ← a_j + δ      (δ > 0, i ≠ j)

The convolution can be updated in O(n) using the formula
    (a+δ(e_j‑e_i))*(a+δ(e_j‑e_i))
   = a*a + 2δ( a shifted by j – a shifted by i )
     + δ²(δ_{2j} – 2δ_{i+j} + δ_{2i}).

A greedy choice of the source index i is the one that contributes most
to the current peak of the convolution (the product a_i·a_{k*‑i} where
k* = argmax (a*a)).  This reduces the peak directly.  A simple
annealing schedule controls the size of δ and occasional random “jitter”
steps help to escape plateaus.

The algorithm works on the probability simplex (∑a_i = 1, a_i ≥ 0) –
the evaluation function is invariant to scaling, so we keep the sum = 1.
The routine runs until the allotted time expires and returns the best
sequence discovered.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: fast full convolution using real FFT (for occasional re‑sync)
# ----------------------------------------------------------------------
def _full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Return the linear convolution x*y (length len(x)+len(y)-1) using FFT."""
    n = x.shape[0]
    m = y.shape[0]
    total = n + m - 1
    size = 1 << (total - 1).bit_length()        # next power of two
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:total]
    # tiny negative values can appear because of round‑off
    np.maximum(conv, 0, out=conv)
    return conv
