assistantfinal**Solution Overview**

The evaluation function

```
score = 2·n·max(conv_self(a)) / (sum(a)²)
```

is homogeneous of degree 0, therefore we can restrict ourselves to vectors `a`
with `sum(a)=1`.  For a fixed length `n` the problem is to minimise the
maximum entry of the self‑convolution `c = a∗a`.  The maximum is always
attained at a certain lag `k`; the gradient of that entry can be written
in closed form, which allows cheap sub‑gradient steps after the candidate has
been found.

The search proceeds in three phases

1. **Parametric sweep** –  a two‑parameter family  

   $$a_i(α,ε) \;\propto\;
   \bigl(i+½+ε\bigr)^{-α}\,
   \bigl(n-½-i+ε\bigr)^{-α}, \qquad i=0,\dots,n-1,$$

   (a symmetric, edge‑heavy shape that contains the classic arcsine
   distribution for `α=0.5 , ε=0`).  
   A coarse grid (`α∈[0.2,1.0]`, `ε∈[0,20]`) is examined, then a finer
   local grid around the best parameters.

2. **Simplex projection sub‑gradient descent** – starting from the best
   vector found in (1) we run a short projected sub‑gradient optimisation
   on the exact maximal convolution entry.  The projection onto the
   probability simplex guarantees feasibility (non‑negative, unit sum).

3. **Tiny random‑swap hill‑climber** – a final polishing phase that swaps
   tiny amounts of mass between two positions if the move improves the
   exact objective.

All steps use FFT‑based convolution (`O(n log n)`) and respect the
1000 s budget.  The algorithm is deterministic apart from the optional
random restarts, which are seeded for reproducibility.

The function `propose_candidate` implements the whole pipeline and returns
the best sequence found (clipped to the `[0, 1000]` range required by
`evaluate_sequence`).

The algorithm consists of three stages:

1. Coarse + fine grid search over a 2‑parameter symmetric family
   a_i(α,ε) ∝ ((i+½+ε)*(n‑½‑i+ε))^(‑α), normalised to sum = 1.
2. Projected sub‑gradient descent on the exact maximal convolution entry.
3. Tiny random‑swap hill‑climber for final polishing.

All vectors are kept on the probability simplex, guaranteeing feasibility
for `evaluate_sequence`.  The search stops after the supplied time budget
(≈ 1000 s) and returns the best sequence encountered.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: projection onto the probability simplex {x ≥ 0, Σx = 1}
# ----------------------------------------------------------------------
def _simplex_projection(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the simplex."""
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    rho = np.where(u - cssv / ind > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
# Convolution utilities (FFT based, returns the *full* convolution)
# ----------------------------------------------------------------------
def _conv_self(p: np.ndarray, fft_len: int) -> np.ndarray:
    """Full self‑convolution of p using FFT of length `fft_len`."""
    p_fft = np.fft.rfft(p, n=fft_len)
    conv = np.fft.irfft(p_fft * p_fft, n=fft_len)[: 2 * p.size - 1]
    return conv


def _objective(p: np.ndarray, n: int, fft_len: int) -> float:
    """Exact objective 2·n·max(conv_self(p)).  Assumes sum(p)=1."""
    conv = _conv_self(p, fft_len)
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
# Sub‑gradient of the maximal convolution entry (exact version)
# ----------------------------------------------------------------------
def _subgradient(p: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Gradient of max(conv) w.r.t. p.
    `conv` must be the full self‑convolution of `p`.
    """
    n = p.size
    max_val = conv.max()
    # tolerance to collect a small active set
    tol = 1e-12
    active = np.where(conv >= max_val - tol)[0]

    g = np.zeros_like(p)
    for idx in active:
        if idx < n:                      # 0 ≤ idx ≤ n‑1
            # contribution from lag = idx
            g[: idx + 1] += 2.0 * p[idx::-1]
        else:                             # n ≤ idx ≤ 2n‑2
            start = idx - n + 1
            # reversed slice of the tail part
            g[start:] += 2.0 * p[n - 1 : start - 1 : -1]
    g /= float(active.size)
    return g


# ----------------------------------------------------------------------
# Main entry point required by the evaluation framework
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> list[float]:
    """Return a non‑negative sequence that (hopefully) improves the bound."""
    rng = np.random.default_rng(seed)

    # --------------------------------------------------------------
    # Problem size (use historic sequence length if available)
    # --------------------------------------------------------------
    try:
        base_seq = np.array(height_sequence_1, dtype=float)  # type: ignore[name-defined]
        n = len(base_seq)
    except Exception:
        n = 1153

    # FFT length – next power of two that covers a full convolution
    fft_len = 1 << ((2 * n - 2).bit_length())

    # --------------------------------------------------------------
    # Helper that evaluates a candidate (sum(p) is kept = 1)
    # --------------------------------------------------------------
    def eval_p(p: np.ndarray) -> float:
        return _objective(p, n, fft_len)

    # --------------------------------------------------------------
    # 1) PARAMETRIC SWEEP (coarse → fine)
    # --------------------------------------------------------------
    i = np.arange(n, dtype=float)

    best_score = float("inf")
    best_p = None
    best_alpha = None
    best_eps = None

    deadline = time.time() + budget_s - 0.5   # 0.5 s safety margin

    # ---------- coarse grid ----------
    alphas = np.linspace(0.20, 1.00, 81)      # step = 0.01
    epsilons = np.linspace(0.0, 20.0, 41)    # step = 0.5

    for alpha in alphas:
        if time.time() >= deadline:
            break
        # pre‑compute the symmetric product term (independent of eps)
        base_prod = (i + 0.5) * (n - 0.5 - i)
        for eps in epsilons:
            if time.time() >= deadline:
                break
            # (i+½+ε)*(n‑½‑i+ε)
            prod = (i + 0.5 + eps) * (n - 0.5 - i + eps)
            w = prod ** (-alpha)
            if w.sum() == 0:
                continue
            p = w / w.sum()
            score = eval_p(p)
            if score < best_score:
                best_score = score
                best_p = p.copy()
                best_alpha = alpha
                best_eps = eps
                print(f"[Coarse] new best {best_score:.6f}  α={alpha:.3f}  ε={eps:.3f}")

    # ---------- fine grid around the best coarse point ----------
    if best_alpha is not None:
        fine_alphas = np.linspace(max(0.01, best_alpha - 0.02),
                                 best_alpha + 0.02, 41)  # step ≈0.001
        fine_eps = np.linspace(max(0.0, best_eps - 2.0),
                               best_eps + 2.0, 41)      # step ≈0.1
        for alpha in fine_alphas:
            if time.time() >= deadline:
                break
            for eps in fine_eps:
                if time.time() >= deadline:
                    break
                prod = (i + 0.5 + eps) * (n - 0.5 - i + eps)
                w = prod ** (-alpha)
                if w.sum() == 0:
                    continue
                p = w / w.sum()
                score = eval_p(p)
                if score < best_score:
                    best_score = score
                    best_p = p.copy()
                    best_alpha = alpha
                    best_eps = eps
                    print(f"[Fine]   new best {best_score:.6f}  α={alpha:.4f}  ε={eps:.3f}")

    # --------------------------------------------------------------
    # 2) PROJECTED SUB‑GRADIENT DESCENT (exact max)
    # --------------------------------------------------------------
    if best_p is not None:
        p = best_p.copy()
        step = 0.3
        decay = 0.9997
        min_step = 1e-8
        for it in range(30_000):
            if time.time() >= deadline:
                break
            conv = _conv_self(p, fft_len)
            cur_score = 2.0 * n * conv.max()
            if cur_score < best_score - 1e-12:
                best_score = cur_score
                best_p = p.copy()
                print(f"[Subgrad] iter {it:5d} → new best {best_score:.6f}")
                if best_score <= 1.503:
                    break
            # compute sub‑gradient of the current maximal entry
            g = _subgradient(p, conv)
            p = p - step * g
            p = _simplex_projection(p)
            step = max(step * decay, min_step)

    # --------------------------------------------------------------
    # 3) TINY RANDOM‑SWAP HILL‑CLIMBER (polishing)
    # --------------------------------------------------------------
    if best_p is None:
        # fallback – uniform distribution
        best_p = np.full(n, 1.0 / n)

    p_swap = best_p.copy()
    cur_score = eval_p(p_swap)

    for it in range(60_000):
        if time.time() >= deadline:
            break
        i1, i2 = rng.integers(0, n, size=2)
        if i1 == i2:
            continue
        # move a small random amount from i1 to i2
        eps_move = 0.001 * rng.random()
        if p_swap[i1] <= eps_move:
            continue
        new_p = p_swap.copy()
        new_p[i1] -= eps_move
        new_p[i2] += eps_move
        new_score = eval_p(new_p)
        if new_score < cur_score - 1e-15:
            p_swap = new_p
            cur_score = new_score
            if cur_score < best_score:
                best_score = cur_score
                best_p = p_swap.copy()
                print(f"[Swap]   iter {it:5d} → new best {best_score:.6f}")
                if best_score <= 1.503:
                    break

    # ------------------------------------------------------------------
    # Return the best vector (clipped to the limits enforced by
    # `evaluate_sequence`).  The function must return a plain Python list.
    # ------------------------------------------------------------------
    print(f"\n*** Final best score (internal objective) = {best_score:.6f}")
    return np.clip(best_p, 0.0, 1000.0).tolist()
