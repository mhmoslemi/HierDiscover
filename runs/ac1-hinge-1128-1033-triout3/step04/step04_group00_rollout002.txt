The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2}
\]

for a non‑negative sequence `a`.  
Because `F` is homogeneous we can fix the normalisation  
\(\sum_i a_i = 1\) and minimise simply the maximal self‑convolution
value.  

The algorithm below is a *projected Adam* optimiser on a smooth
approximation of the `max` (soft‑max).  
Key ideas

* **Soft‑max smoothing** – the vector `w` is a soft‑max of the
  convolution entries, controlled by a temperature `ε`.  When `ε→0`,
  `w` concentrates on the maximal entries, turning the smooth objective
  into the true `max`.
* **Adam on the simplex** – we use an exponentiated‑gradient (mirror‑descent)
  update which automatically stays non‑negative, then renormalise to the
  simplex.  Adam’s per‑coordinate adaptive learning rates accelerate
  convergence.
* **Symmetrisation** – the optimal solution is symmetric (the problem
  itself is), so after each update we replace `a` by `(a + a[::-1])/2`.
* **Multiple restarts & perturbations** – if no improvement is seen for
  a while we add a small multiplicative random perturbation to escape
  plateaus.
* **Final polishing** – a short sub‑gradient loop on the true maximal
  convolution entry removes the last bits of error.

The whole routine respects the 1000 s wall‑time limit, works for any
length `n` (default 5000, or the length of a previously found solution
if `height_sequence_1` exists) and returns the best sequence discovered.

def _full_convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution a * b (full length) via real FFT."""
    size = a.shape[0] + b.shape[0] - 1
    nfft = 1 << (size - 1).bit_length()          # next power of two
    Fa = np.fft.rfft(a, n=nfft)
    Fb = np.fft.rfft(b, n=nfft)
    Fc = Fa * Fb
    conv = np.fft.irfft(Fc, n=nfft)[:size]
    return conv

            best_seq = a.copy()
            stagn = 0
            print(f"[iter {t:6d}] new best = {best_val:.12f}")
        else:
            stagn += 1

        # ----- temperature schedule ------------------------------------
        if eps is None:
            eps = max(max_conv * 0.5, 1e-12)
        else:
            eps = max(eps * eps_decay, max_conv * 1e-5, 1e-12)

        # ----- soft‑max weights (focus on large convolution entries) ---
        w = np.exp((conv - max_conv) / eps)          # ≤ 1, max = 1
        w_sum = w.sum()
        if w_sum > 0 and np.isfinite(w_sum):
            w /= w_sum
        else:                                          # fallback uniform
            w.fill(1.0 / w.size)

        # ----- gradient of the weighted sum (cross‑correlation) -------
        rev_a = a[::-1]
        conv_rev = _full_convolution_fft(rev_a, w)   # length 3n‑2
        g = 2.0 * conv_rev[n - 1 : n - 1 + n]        # slice to length n

        # ----- Adam moments --------------------------------------------
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * (g * g)

        # bias‑corrected estimates
        mb = m / (1.0 - beta1 ** t)
        vb = v / (1.0 - beta2 ** t)

        # ----- exponentiated‑gradient (mirror descent) step ------------
        step = alpha * mb / (np.sqrt(vb) + 1e-8)
        step = np.clip(step, 0.0, max_step)          # avoid overflow

        # update in log‑space to keep positivity automatically
        log_a = np.log(a + 1e-30) - step
        a = np.exp(log_a)

        # ----- re‑normalise and enforce symmetry -----------------------
        a = np.maximum(a, 1e-30)                     # avoid exact zero
        a = a / a.sum()
        a = (a + a[::-1]) / 2.0
        a = a / a.sum()

        # ----- learning‑rate decay ------------------------------------
        alpha = max(alpha_min, alpha * alpha_decay)

        # ----- occasional perturbation to escape plateaus ------------
        if stagn > 8000:
            # multiplicative Gaussian noise (log‑space)
            noise = rng.normal(scale=0.02, size=n)
            a = a * np.exp(noise)
            a = a / a.sum()
            a = (a + a[::-1]) / 2.0
            a = a / a.sum()
            stagn = 0
            alpha = max(alpha_min, alpha * 2.0)
            print(f"[perturb] iteration {t}")

        # ----- safety re‑normalisation every few thousand steps --------
        if t % 5000 == 0:
            a = a / a.sum()

    # ------------------------------------------------------------------
    # Polishing phase – sub‑gradient descent on the true max entry
    # ------------------------------------------------------------------
    a = best_seq.copy()
    for _ in range(3000):
        conv = _full_convolution_fft(a, a)
        mx = conv.max()
        # pick the first index attaining the maximum
        idx = int(np.argmax(conv))

        # gradient of the single maximal entry (sub‑gradient)
        lo = max(0, idx - (n - 1))
        hi = min(n - 1, idx)
        i_range = np.arange(lo, hi + 1, dtype=np.int64)
        j = idx - i_range
        g = np.zeros_like(a)
        g[i_range] = 2.0 * a[j]

        # tiny step + projection onto the simplex
        a = a - 5e-6 * g
        a = np.maximum(a, 0.0)
        a = a / a.sum()
        a = (a + a[::-1]) / 2.0
        a = a / a.sum()

    # ------------------------------------------------------------------
    # Final evaluation & return
    # ------------------------------------------------------------------
    final_seq = [float(max(0.0, min(1000.0, x))) for x in a.tolist()]
    final_score = evaluate_sequence(final_seq)

    # In the unlikely event polishing worsened the score, fall back
    if final_score > best_val:
        final_seq = [float(max(0.0, min(1000.0, x))) for x in best_seq.tolist()]
        final_score = best_val

    print(f"[result] final_score={final_score:.12f}, length={len(final_seq)}")
    return final_seq
