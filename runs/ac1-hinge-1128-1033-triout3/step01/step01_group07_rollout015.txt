The task is to find a non‑negative step function `a = (a0,…,a_{n‑1})` that minimises  

\[
L(a)=\frac{2n\;\max (a*a)}{(\sum a)^2}\ .
\]

`evaluate_sequence` computes exactly this value (after clipping the
coefficients to the interval `[0,1000]`).  
The best construction so far uses a *core* with the optimal
\(a_i\propto 1/\sqrt{i+1}\) and a constant *tail* with a tiny height.
The resulting score is `1.574058`.  
Below we improve the construction using the *linear‑programming* idea
described in the statement:

* for a given sequence `f` with   \(M = \|f*f\|_\infty\) we maximise  
  \(\sum_j b_j\) under the *linear* constraints `f*b ≤ M` (`b≥0`).  
  The optimum is obtained by a simple forward‑substitution (greedy) that
  fills the convolution constraints one by one.

* the maximiser `g` may violate the self‑convolution bound
  (`g*g ≤ M`).  We therefore blend the old sequence `f` with the new
  one `g` (convex combination).  By binary‑searching the mixing weight `t`
  we guarantee that the new sequence never exceeds the previous
  maximum `M`.  Consequently the denominator grows while the numerator
  stays the same, strictly decreasing the evaluation score.

The algorithm repeats this improvement step until either the time budget
is exhausted or the score stops decreasing.

All heavy work is done with NumPy and FFT‑based convolutions, the whole
search fits comfortably into the 1000 s budget.

    maximise   Σ b_j   subject to   b_j ≥ 0   and   (f * b)_k ≤ M  ∀k,

where `f` is the current sequence and `M = max(f*f)`.  
The optimal `b` is obtained by a greedy forward substitution (the
constraints are triangular).  Afterwards `b` is blended with `f` using
the largest possible convex mixing factor `t` that keeps the self‑
convolution ≤ M.  This strictly increases the ℓ¹‑norm while never
increasing the maximum convolution, therefore the evaluation score
monotonically decreases.

The algorithm starts from the best known construction (``height_sequence_1``)
or from a fresh inverse‑square‑root core + tiny tail, and repeats the
improvement step until the time budget (≈ 1000 s) is exhausted.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions
# ----------------------------------------------------------------------


def _conv_max(seq: np.ndarray) -> float:
    """
    Maximum value of the linear convolution of ``seq`` with itself.
    Uses an FFT of power‑of‑two size for speed.
    """
    n = seq.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(seq, n=size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return float(conv.max())


def _score(seq: np.ndarray) -> float:
    """
    Exact evaluation of the objective for a given sequence.
    Equivalent to evaluate_sequence but much faster (no clipping etc.).
    """
    total = float(seq.sum())
    if total < 0.01:
        return np.inf
    max_conv = _conv_max(seq)
    return 2.0 * len(seq) * max_conv / (total * total)


def _greedy_g(f: np.ndarray, M: float) -> np.ndarray:
    """
    Solve   max Σ g_j   subject to   g ≥ 0  and  f * g ≤ M
    (linear constraints only).  The solution is obtained by a forward
    substitution: for each shift `j` we add as much as possible to `g[j]`
    while keeping the convolution at `j` ≤ M.
    """
    n = f.shape[0]
    # first element of f must be positive – for all our constructions it is.
    f0 = f[0]
    if f0 <= 0:
        # fallback – use the first positive entry
        idx = int(np.flatnonzero(f > 0)[0])
        f0 = f[idx]
        # shift not needed for our uses because we always have f[0] > 0
    g = np.zeros_like(f)
    conv = np.zeros(2 * n, dtype=np.float64)          # holds f * g so far

    for j in range(n):
        slack = M - conv[j]                           # how much we can still add at shift j
        if slack <= 0.0:
            continue
        # the contribution of g[j] to conv[j] is f[0] * g[j]
        gj = slack / f0
        g[j] = gj
        # update all future convolution entries (vectorised)
        conv[j : j + n] += f * gj
    return g


def _max_self_conv(x: np.ndarray) -> float:
    """Maximum of the self‑convolution of `x` (used for scaling)."""
    return _conv_max(x)


def _blend_with_bound(f: np.ndarray, g: np.ndarray, M: float) -> tuple[np.ndarray, float]:
    """
    Find the largest mixing factor `t`∈[0,1] such that
        h = (1‑t) * f + t * g
    satisfies max(h*h) ≤ M.
    Returns the new sequence `h` and the used `t`.
    """
    lo, hi = 0.0, 1.0
    best_t = 0.0
    # binary search – 30 iterations give sub‑micro precision, more than enough
    for _ in range(30):
        mid = (lo + hi) * 0.5
        h = (1.0 - mid) * f + mid * g
        m = _conv_max(h)
        if m <= M * (1.0 + 1e-12):          # allow tiny numerical overshoot
            best_t = mid
            lo = mid
        else:
            hi = mid
        if hi - lo < 1e-7:
            break
    h = (1.0 - best_t) * f + best_t * g
    return h, best_t


# ----------------------------------------------------------------------
# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a step function with a smaller evaluation value.
    The routine works in three stages:

    1. initialise a good starting sequence (either the known best or a
       fresh inverse‑sqrt core + tiny tail);
    2. repeatedly:
          * compute M = max(f*f);
          * obtain the LP‑maximiser g (greedy forward substitution);
          * optionally enlarge g a little (target a 2 % higher ℓ¹‑norm);
          * blend f with g while keeping max convolution ≤ M;
          * keep the best sequence seen so far;
    3. return the best sequence as a plain Python list.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5           # safety margin

    # --------------------------------------------------------------
    # 1) Starting point
    # --------------------------------------------------------------
    if "height_sequence_1" in globals() and isinstance(globals()["height_sequence_1"], list):
        f = np.array(globals()["height_sequence_1"], dtype=np.float64)
        print(f"[init] using provided height_sequence_1 (length={len(f)})")
    else:
        # simple inverse‑sqrt core + negligible tail
        n = 8000
        core_len = max(2, int(0.2 * n))
        core = 1.0 / np.sqrt(np.arange(1, core_len + 1, dtype=np.float64))
        tail = np.full(n - core_len, 1e-5, dtype=np.float64)
        f = np.concatenate([core, tail])
        print(f"[init] generated fresh sequence (n={n})")

    n = f.shape[0]
    best_seq = f.copy()
    best_val = _score(best_seq)
    print(f"[init] initial score: {best_val:.6f}")

    # --------------------------------------------------------------
    # 2) Iterative improvement
    # --------------------------------------------------------------
    iteration = 0
    while time.time() < deadline:
        iteration += 1
        M = _conv_max(f)                     # current max convolution
        # solve the linear programme (greedy)
        g0 = _greedy_g(f, M)

        sum_f = float(f.sum())
        sum_g0 = float(g0.sum())

        # if the LP solution does not increase the ℓ¹‑norm we stop
        if sum_g0 <= sum_f * 1.001:
            print("[stop] LP does not increase ℓ¹‑norm any more")
            break

        # we would like to grow the norm by a modest amount (≈2 %)
        target_sum = sum_f * 1.02
        scaling = target_sum / sum_g0
        # avoid huge scaling steps that would make blending impossible
        scaling = min(scaling, 5.0)
        g = g0 * scaling

        # blend f with g while keeping the max convolution ≤ M
        f_new, t_used = _blend_with_bound(f, g, M)

        if t_used == 0.0:
            print("[stop] blending could not improve the bound")
            break

        new_val = _score(f_new)
        if new_val < best_val:
            best_val = new_val
            best_seq = f_new.copy()
            print(f"[iter {iteration:03d}] improved score to {best_val:.6f} (t={t_used:.4f})")
        else:
            # even if the score did not improve we keep the updated `f`
            # to give the next iteration a chance to move further.
            print(f"[iter {iteration:03d}] no score improvement (t={t_used:.4f})")

        f = f_new

        # safety break – if the improvement per iteration becomes tiny we stop
        if iteration >= 200:   # more than enough for the time budget
            break

    # --------------------------------------------------------------
    # 3) Return best sequence found
    # --------------------------------------------------------------
    print(f"final best score: {best_val:.6f}")
    # Clip to the domain required by evaluate_sequence (non‑negative, ≤1000)
    best_seq = np.clip(best_seq, 0.0, 1000.0)
    return best_seq.tolist()
