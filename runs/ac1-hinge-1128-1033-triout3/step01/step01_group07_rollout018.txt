assistantfinal**Solution Overview**

The evaluation function is homogeneous: scaling all coefficients does not change the score.  
Hence we can fix the shape of the sequence and only worry about its *relative* values.  

For a sequence that follows a power‑law  

```
a[i] = (i + β)⁻ᵖ ,   i = 0 … n‑1            (β > 0 , 0 < p < 1)
```

the self‑convolution is almost constant, which is the reason the classical
`1/√i`‑shape (`p = 0.5`) gives a score close to the theoretical bound π/2 ≈ 1.571.  
Small variations of the exponent `p` and the offset `β` change the discrete
convolution only a little, but they are enough to push the maximum a little
below the value obtained by the pure `1/√i` construction.

The algorithm consists of three phases

1. **Coarse grid search** – explore `p ∈ [0.45, 0.55]` and `β ∈ [10⁻², 10²]`
   on a modest grid, evaluate each candidate with a fast FFT‑based convolution,
   keep the best one.

2. **Local refinement** – starting from the best grid point, perform a simple
   hill‑climbing / simulated‑annealing style search on the two parameters
   (`p` and `β`).  Only the two‑parameter family is explored, which keeps the
   run‑time well below the 1000 s budget while still allowing the score to
   improve noticeably.

3. **Fallback** – if for any reason no candidate is found, return a uniform
   sequence (score = 2), which is always accepted by the evaluator.

All helper functions are top‑level and contain no closures, obey the
restriction on imports, and print progress information.  The final sequence
is returned as a plain Python list, ready for `evaluate_sequence`.

```python
"""
propose_candidate
=================

Search for a non‑negative step function that minimises

    L = 2·n·max(conv(a,a)) / (sum(a))²

The search is restricted to sequences of the form

    a[i] = (i + beta) ** (-p)    ,   i = 0 .. n‑1 , beta > 0 , 0 < p < 1

and performs a coarse grid search followed by a small hill‑climbing
refinement on the two parameters (p, beta).  The convolution is evaluated by
FFT for speed.  The returned list satisfies all checks performed by
`evaluate_sequence`.
"""

import time
import numpy as np

def _conv_max(seq: np.ndarray) -> float:
    """Maximum of the linear convolution of ``seq`` with itself (FFT version)."""
    n = seq.shape[0]
    # next power‑of‑two size for the FFT
    size = 1 << ((2 * n - 1).bit_length())
    # forward transform
    fa = np.fft.rfft(seq, n=size)
    # element‑wise product = convolution in frequency domain
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return float(conv.max())


def _score(seq: np.ndarray) -> float:
    """Exact evaluation of the objective for a given sequence."""
    total = float(seq.sum())
    if total < 0.01:                     # guard for the evaluator
        return np.inf
    max_conv = _conv_max(seq)
    n = seq.shape[0]
    return 2.0 * n * max_conv / (total * total)


def propose_candidate(seed: int = 42, budget_s: int = 1000) -> list[float]:
    """
    Return a sequence that (hopefully) beats the previous best score.

    The algorithm works within the time budget ``budget_s`` (seconds).
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.2  # a tiny safety margin

    # length of the candidate – use the existing construction when available
    n = len(globals().get("height_sequence_1", []))
    if n == 0:
        n = 8000                         # default length if nothing is present

    best_seq = None
    best_val = np.inf
    best_p = best_beta = None

    # ------------------------------------------------------------
    # 1) Coarse grid search over the two parameters (p, beta)
    # ------------------------------------------------------------
    # exponent grid (around the known optimal 0.5)
    p_grid = np.linspace(0.45, 0.55, 21)          # step = 0.005
    # offset grid – logarithmic because the scale matters a lot
    beta_grid = np.logspace(-2, 2, 60)           # 10⁻² … 10²

    print("[grid] start coarse search (n = {})".format(n))

    for p in p_grid:
        if time.time() > deadline:
            break
        # pre‑compute the powers only once per p
        i = np.arange(n, dtype=np.float64)
        for beta in beta_grid:
            # sequence a[i] = (i + beta) ^ -p
            seq = (i + beta) ** (-p)
            val = _score(seq)
            if val < best_val:
                best_val = val
                best_seq = seq.copy()
                best_p, best_beta = p, beta
                print("[grid] new best: {:.6f} (p={:.5f}, β={:.5f})".format(
                    best_val, best_p, best_beta))
            if time.time() > deadline:
                break

    # ------------------------------------------------------------
    # 2) Local refinement around the best grid point
    # ------------------------------------------------------------
    if best_seq is None:
        # fallback – uniform sequence (score == 2)
        best_seq = np.full(n, 1.0 / n, dtype=np.float64)
        best_val = _score(best_seq)
        best_p = 0.5
        best_beta = 1.0
        print("[fallback] using uniform sequence, val = {:.6f}".format(best_val))

    # hill‑climbing on (p, beta) with a decreasing step size
    cur_p, cur_beta = best_p, best_beta
    cur_seq = best_seq
    cur_val = best_val
    start = time.time()
    # initial step sizes (relative)
    step_p = 0.02
    step_beta = 0.20

    print("[refine] start local optimisation (p={:.5f}, β={:.5f})".format(
        cur_p, cur_beta))

    while time.time() < deadline:
        # propose a new (p, beta) by a small random perturbation
        p_new = cur_p * (1.0 + np.random.randn() * step_p)
        beta_new = cur_beta * (1.0 + np.random.randn() * step_beta)

        # keep parameters inside sensible bounds
        if not (0.3 < p_new < 0.8) or beta_new <= 0.0:
            continue

        # build the candidate sequence
        seq_new = (np.arange(n, dtype=np.float64) + beta_new) ** (-p_new)

        val_new = _score(seq_new)

        # accept if strictly better – simple greedy hill climbing
        if val_new < cur_val:
            cur_p, cur_beta = p_new, beta_new
            cur_seq, cur_val = seq_new, val_new
            if val_new < best_val:
                best_val, best_seq = val_new, seq_new.copy()
                best_p, best_beta = p_new, beta_new
                print("[refine] improved to {:.6f} (p={:.5f}, β={:.5f})".format(
                    best_val, best_p, best_beta))

        # gradually shrink the step sizes (simulated annealing style)
        elapsed = time.time() - start
        decay = max(0.0, 1.0 - elapsed / (budget_s * 0.9))
        step_p = 0.02 * decay
        step_beta = 0.20 * decay
        # if steps become too small we stop the refinement loop
        if step_p < 1e-5 and step_beta < 1e-3:
            break

    print("[final] best value found: {:.6f} (p={:.5f}, β={:.5f})".format(
        best_val, best_p, best_beta))

    # Return a plain Python list as required by the evaluation harness.
    return best_seq.tolist()
```
