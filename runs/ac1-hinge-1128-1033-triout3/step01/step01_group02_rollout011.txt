"""
propose_candidate
-----------------

A deterministic improvement over the plain Catalan (central‑binomial) construction.
The idea is the “LP‑descent” described in the statement:

* Start from the Catalan distribution (which gives the asymptotic bound π/2 ≈1.57).
* For the current distribution f (∑f = 1) compute M = max(f*f).
* Solve the linear program  
        maximise   Σ g_i
        subject to (f·g)_k ≤ M   for every convolution index k,
                    g_i ≥ 0.
  Because the constraints are linear in g (f is fixed) this LP is cheap for
  a few hundred variables.
* Normalise g to a probability vector and move a fraction t towards it:
        f ← (1-t)·f + t·ĝ .
  The new f always has the same L¹‑norm (=1) but its self‑convolution
  peak is (typically) smaller.  Repeating the LP‑step shrinks the peak
  until the evaluation score 2·n·max(f*f) stops improving.

The routine runs a simple adaptive scheme:
    – a moderate size (n≈600) keeps the LP tiny,
    – the step size t is increased when a move succeeds and decreased
      otherwise,
    – occasional tiny random perturbations are tried to escape plateaus.

The whole search respects the 1000 s budget, prints progress and finally
returns the best sequence found (as a plain Python list).  The returned
vector is already normalised (∑a_i = 1) and consists of non‑negative
entries only, so `evaluate_sequence` can be called directly.
"""

    M = conv_f.max()               # maximal self‑convolution value
    best_score = 2.0 * n * M
    best_f = f.copy()
    print(f"[init] n={n}, max_conv={M:.9e}, score={best_score:.6f}")

    # --------------------------------------------------------------
    # 2) Iterative LP‑based refinement.
    # --------------------------------------------------------------
    deadline = time.time() + budget_s - 5.0      # keep a safety margin
    t = 0.5                                      # initial mixing factor

    iteration = 0
    while time.time() < deadline:
        iteration += 1

        # Build the (2n‑1)×n constraint matrix A   (A·g ≤ M).
        # Row k of A contains the shifted version of f that multiplies g in (f·g)_k.
        A = np.zeros((2 * n - 1, n), dtype=float)
        for j in range(n):
            A[j:j + n, j] = f

        # Linear program: maximise Σ g_i  subject to A·g ≤ M , g ≥ 0.
        g_var = cp.Variable(n, nonneg=True)
        constraints = [A @ g_var <= M + 1e-14]   # tiny slack for numerical safety
        prob = cp.Problem(cp.Maximize(cp.sum(g_var)), constraints)

        try:
            prob.solve(solver=cp.ECOS, warm_start=True, max_iters=2000, verbose=False)
        except Exception as exc:
            print(f"[lp] solve failed on iter {iteration}: {exc}")
            break

        if g_var.value is None:
            print(f"[lp] no solution on iter {iteration}")
            break

        g = np.asarray(g_var.value).flatten()
        sum_g = g.sum()
        if sum_g <= 0.0:
            print(f"[lp] sum(g) non‑positive on iter {iteration}")
            break

        # Normalise g to a probability vector.
        g_hat = g / sum_g

        # Convex combination with the current distribution.
        f_new = (1.0 - t) * f + t * g_hat
        f_new /= f_new.sum()           # re‑normalise (numerical safety)

        # Evaluate the new peak.
        conv_new = np.convolve(f_new, f_new)
        M_new = conv_new.max()
        score_new = 2.0 * n * M_new

        # Accept the step if we have a genuine improvement.
        if score_new < best_score - 1e-12:
            best_score = score_new
            best_f = f_new.copy()
            f = f_new
            M = M_new
            # increase step size modestly – we are moving in a promising direction
            t = min(0.9, t * 1.07)
            print(f"[iter {iteration:04d}] improved score={best_score:.6f}, max={M:.9e}, t={t:.3f}")
        else:
            # no improvement – shrink the step size and keep the old f
            t = max(0.1, t * 0.85)

        # ----------------------------------------------------------
        # Occasional tiny random tweak (helps to escape tiny plateaus)
        # ----------------------------------------------------------
        if np.random.rand() < 0.04:
            idx = np.random.randint(n)
            delta = (np.random.rand() - 0.5) * 0.02   # tiny perturbation
            f_tmp = best_f.copy()
            f_tmp[idx] = max(0.0, f_tmp[idx] + delta)
            f_tmp = np.clip(f_tmp, 0.0, None)
            f_tmp /= f_tmp.sum()
            conv_tmp = np.convolve(f_tmp, f_tmp)
            M_tmp = conv_tmp.max()
            score_tmp = 2.0 * n * M_tmp
            if score_tmp < best_score:
                best_score = score_tmp
                best_f = f_tmp.copy()
                f = f_tmp
                M = M_tmp
                print(f"[rand] random tweak improved score={best_score:.6f}")

    # --------------------------------------------------------------
    # Return the best sequence found (plain Python list).
    # --------------------------------------------------------------
    print(f"[final] best score={best_score:.6f} after {iteration} iterations")
    return best_f.tolist()
