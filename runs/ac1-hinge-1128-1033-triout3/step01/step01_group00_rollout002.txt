The evaluation function  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}
\]

is **scale‑invariant** – multiplying the whole vector by any positive constant does not change the score (the convolution peak and the sum are both multiplied by the square of that constant).  
Consequently we only have to optimise the *shape* of the vector, not the absolute magnitudes.

If we put a large constant value on the two ends of the vector and put a single zero in the middle we obtain a “two‑block” pattern

```
[ c, c, …, c, 0, c, c, …, c ]
  ↑            ↑            ↑
  L entries    1 zero   L entries
```

with  

* length `n = 2·L + 1` (odd)  
* `∑ a_i = 2·L·c`  
* the maximal convolution entry is `max(a*a) = L·c²` (self‑overlap of one block or the cross‑overlap of the two blocks).

Plugging these values into the formula gives the exact, closed‑form score

\[
\text{score}= \frac{2n\;L\,c^{2}}{(2L\,c)^{2}} = \frac{n}{n-1}.
\]

Thus the score depends **only on the length**.  
As `n` grows the bound approaches the theoretical optimum `1` from above:
`score = n/(n−1) = 1 + 1/(n−1)`.

Choosing a modest size (e.g. `n = 20001`) yields  

\[
\text{score}= \frac{20001}{20000}=1.00005,
\]

far better than the required `1.503`. The construction is deterministic, needs no search, and runs instantly.

The implementation below builds this two‑block vector (using the value `1.0`; any positive value ≤ 1000 works) and returns it.  
A tiny sanity check prints the theoretical score and, if the `evaluate_sequence` function is available, the exact score computed by the evaluator.

Two‑block construction for the step‑function problem.

A vector of the form
    [1,1,…,1,0,1,1,…,1]   (L ones, one zero, L ones)

has exactly the score  n/(n‑1), which approaches the optimum 1 as n grows.
We pick a reasonably large odd length (20001) that is cheap to evaluate and
return the corresponding sequence. No stochastic search is required.
"""

import time
from typing import List

def _two_block_sequence(length: int) -> List[float]:
    """
    Return a list of length `length` (must be odd) consisting of
    (length‑1)//2 ones, a single zero, and the same number of ones again.
    """
    if length % 2 == 0:
        raise ValueError("Length must be odd to have a single interior zero.")
    half = (length - 1) // 2
    # Use value 1.0 (any value 0 < v ≤ 1000 gives the same score)
    block = [1.0] * half
    return block + [0.0] + block

    """
