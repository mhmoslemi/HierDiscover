assistantfinal**Solution Overview**

The evaluation function is  

\[
E(a)=\frac{2\,n\;\max_k (a*a)[k]}{(\sum_i a_i)^2},
\qquad a_i\ge 0,
\]

and it is *scale invariant* – only the *shape* of the vector matters.  
Our goal is therefore to find a probability distribution (sum = 1) on a
discrete line whose self‑convolution is as flat as possible.

**Key ideas**

1. **Parametric families** – two simple families that generate “U‑shaped’’
   distributions are examined  
   * `u_min` :  \(a_i\propto\bigl(\min(i,n-1-i)+1\bigr)^{-p}\)  
   * `u_prod`:  \(a_i\propto\bigl((i+1)(n-i)\bigr)^{-p}\)  

   For many lengths `n` and many exponents `p` we evaluate the exact
   score and keep the best seed.

2. **Fast convolution** – convolution and its maximum are computed with a
   single FFT (`np.fft.rfft`), which works in \(O(n\log n)\) and is fast
   even for tens of thousands of entries.

3. **Projected (sub‑)gradient descent** – with the current vector `a`
   we compute the set of indices where the convolution attains its
   maximum.  
   The sub‑gradient of the max‑entry is  

   \[
   g_i = 2\!\!\sum_{k\in K_{\max}} a_{k-i},
   \]

   where the sum runs over the (few) maximal indices `K_max`.  
   A step `a←a−α g` is taken and the result is projected back onto the
   probability simplex by the O(n log n) algorithm of Wang &
   Carreira‑Perpiñán.

4. **Exploration moves** – with probability `0.5` a random *mass transfer*
   between two positions is tried (moving up to 50 % of the source mass).
   This gives the algorithm the ability to jump out of plateaus.

5. **Simulated‑annealing acceptance** – worsening moves are accepted with
   probability `exp((E_cur−E_new)/T)`.  Temperature `T` and the step size
   `α` are multiplied by a factor `0.9999` each iteration.

6. **Time budget handling** – the whole procedure stops a few seconds
   before the 1000 s limit and returns the best vector seen so far.

The whole optimiser fits into a single function `propose_candidate`
as required.

```python
"""
Propose a low‑score step‑function.

The algorithm works in three phases:

1.  Exhaustive search over two parametric “U‑shaped’’ families
    (min‑distance and product‑distance) for several lengths and
    power‑law exponents.  The best seed is remembered.

2.  Projected.sub‑gradient descent on the simplex, driven by the
    sub‑gradient of the maximal convolution entry.  The step size
    decays with a simulated‑annealing schedule.

3.  Random mass‑transfer moves (occasionally accepted) to escape
    local minima.

All convolutions are evaluated with a single FFT, which makes the
inner loop fast enough to explore many millions of candidates in the
1000 s budget.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Project a vector onto the probability simplex {w >= 0, sum(w) = 1}.
    Implementation of the O(n log n) algorithm by Wang & Carreira‑Perpiñán.
    """
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = u - (cssv - 1) / np.arange(1, n + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = (cssv[rho] - 1) / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def u_min_distribution(n: int, p: float) -> np.ndarray:
    """
    Symmetric “U‑shape’’ based on distance to the nearest edge:
        a[i] = (min(i, n-1-i) + 1)^{-p}
    The vector is normalised to sum = 1.
    """
    d = np.arange(n)
    d = np.minimum(d, n - 1 - d)          # distance to nearest edge
    a = (d + 1) ** (-p) + 1e-14           # tiny epsilon avoids exact zeros
    a /= a.sum()
    return a


def u_prod_distribution(n: int, p: float) -> np.ndarray:
    """
    Symmetric “U‑shape’’ based on the product of distances to both edges:
        a[i] = ((i+1)*(n-i))^{-p}
    Normalised to sum = 1.
    """
    i = np.arange(n)
    prod = (i + 1) * (n - i)
    a = prod.astype(np.float64) ** (-p) + 1e-14
    a /= a.sum()
    return a


def full_convolution_fft(a: np.ndarray) -> np.ndarray:
    """
    Compute the full (linear) convolution of a with itself using FFT.
    Returns a vector of length 2*len(a)-1.
    """
    n = a.shape[0]
    # zero‑pad to 2*n for a clean circular convolution that covers the linear one
    size = 2 * n
    fa = np.fft.rfft(a, n=size)
    conv = np.fft.irfft(fa * fa, n=size)
    return conv[: 2 * n - 1]


def max_convolution(a: np.ndarray) -> float:
    """
    Return max_k (a * a)[k] for a non‑negative vector a with sum == 1.
    Uses the FFT based convolution.
    """
    conv = full_convolution_fft(a)
    return float(conv.max())


def score_from_vector(a: np.ndarray) -> float:
    """
    Exact value returned by evaluate_sequence for a vector already
    normalised to sum == 1.
    """
    n = len(a)
    max_c = max_convolution(a)
    return 2.0 * n * max_c


# ----------------------------------------------------------------------
# Main proposal routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function that minimises
    `evaluate_sequence`.  The routine respects the given time budget and
    returns the best sequence (list of floats) it discovered.
    """
    np.random.seed(seed)
    # leave a small safety margin for the host runner
    deadline = time.time() + budget_s - 5.0

    # --------------------------------------------------------------
    # 1.  Exhaustive search over simple parametric families
    # --------------------------------------------------------------
    best_seq = None
    best_score = np.inf

    lengths = [2000, 4000, 8000, 12000, 16000, 20000]
    # exponents from 0.1 to 3.0 (step 0.1) – fine enough for a quick sweep
    exponents = np.arange(0.1, 3.01, 0.1)

    print("=== Deterministic U‑shape sweep ===")
    for n in lengths:
        if time.time() > deadline:
            break
        for p in exponents:
            # ----- family 1 : min‑distance -----
            a1 = u_min_distribution(n, p)
            sc1 = score_from_vector(a1)
            if sc1 < best_score:
                best_score = sc1
                best_seq = a1.copy()
                print(f" new best (min)  n={n:5d} p={p:4.2f}  score={sc1:.6f}")

            # ----- family 2 : product‑distance -----
            a2 = u_prod_distribution(n, p)
            sc2 = score_from_vector(a2)
            if sc2 < best_score:
                best_score = sc2
                best_seq = a2.copy()
                print(f" new best (prod) n={n:5d} p={p:4.2f}  score={sc2:.6f}")

        # occasional time‑check
        if time.time() > deadline:
            break

    # --------------------------------------------------------------
    # 2.  Include the previously supplied construction if it exists
    # --------------------------------------------------------------
    try:
        external = np.array(height_sequence_1, dtype=float)
        if external.size > 0:
            external = np.maximum(external, 0.0)
            if external.sum() > 0:
                external /= external.sum()
                sc_ext = score_from_vector(external)
                if sc_ext < best_score:
                    best_score = sc_ext
                    best_seq = external.copy()
                    print(f" using external height_sequence_1  score={sc_ext:.6f}")
    except NameError:
        pass

    # --------------------------------------------------------------
    # 3.  Fallback (should never be needed)
    # --------------------------------------------------------------
    if best_seq is None:
        n = 5000
        best_seq = np.random.rand(n)
        best_seq /= best_seq.sum()
        best_score = score_from_vector(best_seq)
        print(f" fallback random seed  n={n}  score={best_score:.6f}")

    # --------------------------------------------------------------
    # 4.  Stochastic refinement (projected sub‑gradient + random moves)
    # --------------------------------------------------------------
    current = best_seq.copy()
    current_score = best_score

    n = len(current)

    temperature = 1.0               # SA temperature
    cooling_rate = 0.9999           # slower cooling → more exploration
    step_size = 0.2                 # initial gradient step
    step_decay = cooling_rate

    iteration = 0
    last_improve_iter = 0

    print("\n=== Starting stochastic refinement ===")
    while time.time() < deadline:
        iteration += 1

        # ----------------------------------------------------------
        # 4a – pick a move type
        # ----------------------------------------------------------
        if np.random.rand() < 0.5:
            # ----- random mass transfer -----
            i, j = np.random.choice(n, 2, replace=False)
            if current[i] == 0.0:
                continue
            # move at most 50 % of the source mass
            delta = current[i] * np.random.rand() * 0.5
            cand = current.copy()
            cand[i] -= delta
            cand[j] += delta
            # sum stays 1 → no projection needed
        else:
            # ----- projected sub‑gradient step -----
            conv = full_convolution_fft(current)
            max_val = conv.max()
            # indices that are (numerically) maximal
            eps = max_val * 1e-12 + 1e-15
            max_idx = np.where(conv >= max_val - eps)[0]

            grad = np.zeros_like(current)
            # accumulate the sub‑gradient from all maximal indices
            for k in max_idx:
                start_i = max(0, k - (n - 1))
                end_i = min(n - 1, k)
                i_vals = np.arange(start_i, end_i + 1)
                j_vals = k - i_vals
                grad[i_vals] += 2.0 * current[j_vals]

            cand = current - step_size * grad
            cand = np.maximum(cand, 0.0)
            cand = simplex_projection(cand)

        # ----------------------------------------------------------
        # 4b – evaluate candidate (cheap internal score)
        # ----------------------------------------------------------
        cand_score = score_from_vector(cand)

        # ----------------------------------------------------------
        # 4c – Simulated‑annealing acceptance
        # ----------------------------------------------------------
        accept = False
        if cand_score < current_score:
            accept = True
        else:
            prob = np.exp((current_score - cand_score) / max(temperature, 1e-12))
            if np.random.rand() < prob:
                accept = True

        if accept:
            current = cand
            current_score = cand_score
            # update global best
            if cand_score < best_score:
                best_score = cand_score
                best_seq = cand.copy()
                last_improve_iter = iteration
                print(f"Iter {iteration:7d}: new best score = {best_score:.6f}")

        # ----------------------------------------------------------
        # 4d – anneal
        # ----------------------------------------------------------
        temperature *= cooling_rate
        step_size *= step_decay

        # ----------------------------------------------------------
        # 4e – stagnation handling (re‑heat occasionally)
        # ----------------------------------------------------------
        if iteration - last_improve_iter > 20000:
            # after many non‑improving steps, re‑inject a tiny random bump
            bump = np.random.rand(n) * 1e-4
            current = current + bump
            current = simplex_projection(current)
            current_score = score_from_vector(current)
            last_improve_iter = iteration
            temperature = 1.0   # give the search a fresh push

    # --------------------------------------------------------------
    # 5.  Return the best sequence found
    # --------------------------------------------------------------
    print("\n=== Search finished ===")
    print(f"Best score found: {best_score:.6f}   (length {len(best_seq)})")
    # The external evaluator will clip and normalise again,
    # so we just return the raw vector.
    return best_seq.tolist()
```
