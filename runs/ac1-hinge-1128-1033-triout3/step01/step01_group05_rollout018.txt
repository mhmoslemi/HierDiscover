------------------

Searches a non‑negative step‑function that minimizes

    2 * n * max(conv(a, a)) / (sum(a) ** 2)

The construction is analytic:

* The “constant‑convolution’’ sequence (central binomial coefficients)
  `b_k = C(2k,k)/4**k` satisfies   (b*b)_k = 1 for all k≥0.
* Take a prefix of length `N` of this sequence – interior part.
* Add a long tail of identical small entries `ε`.  
  Let the tail length be `M` and `ε` be chosen so that the
  largest convolution value never exceeds 1:

        ε * Σ_{i<N} b_i  +  ε² (M‑N)  =  1               (1)

   tail‑tail contributions).  For a given interior length `N` we

def generate_binomial_prefix(max_n: int):
    """
    Central binomial coefficients b_k = C(2k,k)/4**k  for 0 <= k < max_n.
    Recurrence:  b_{k+1} = b_k * (2k+1) / (2(k+1)).

    coeffs[0] = cur
    for k in range(1, max_n):
        cur = cur * (2 * k - 1) / (2 * k)
        coeffs[k] = cur
    return coeffs

                print(
                    f"[improve] N={N:4d} M={M:5d} eps={eps:.6g} "
                    f"score={sc:.6f}"
                )

        # also evaluate the extreme case B = B_max (full tail)
        # (the loop above may have missed the last point because of step)
        if B_max % step != 0 and time.time() < deadline:
            B = B_max
            disc = A * A + 4.0 * B
            eps = (np.sqrt(disc) - A) / (2.0 * B)
            eps = min(eps, 1.0 / A * 0.9999)
            M = N + B
            seq = binom.tolist() + [float(eps)] * M
            try:
                sc = evaluate_sequence(seq)
            except Exception:
                sc = float('inf')
            if sc < best_score:
                best_score = sc
                best_seq = seq
                print(
                    f"[improve] N={N:4d} M={M:5d} eps={eps:.6g} "
                    f"score={sc:.6f}"
                )

    # ------------------------------------------------------------------
    # Fallback – if something went wrong we return the classic binomial
    # prefix (length 3000) which already beats the 2.0 baseline.
    # ------------------------------------------------------------------
    if best_seq is None:
        fallback_len = 3000
        coeffs = generate_binomial_prefix(fallback_len)
        best_seq = coeffs.tolist()
        print("[fallback] using plain binomial prefix, length =", fallback_len)

    # Final sanitisation – enforce the evaluator's clamping rules
    best_seq = [
        float(max(0.0, min(1000.0, x))) for x in best_seq
    ]

    return best_seq
