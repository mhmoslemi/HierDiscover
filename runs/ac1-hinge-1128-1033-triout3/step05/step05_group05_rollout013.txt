Simulated‑annealing + targeted mass‑transfer search for a step‑function
that minimises `evaluate_sequence`.

The algorithm works as follows:

1. **Initialisation** – start from the known construction `height_sequence_1`
   (if it exists) or from a random point on the probability simplex.
   The vector is kept normalised (∑a = 1) because the objective is
   scale‑invariant.

2. **Main loop (simulated annealing)**  
   * Compute the full autocorrelation `b = a*a` (FFT based).  
   * Identify the index `k` where `b` attains its maximum.  
   * For this `k` compute the contribution of each coordinate
     `c_i = a_i * a_{k-i}` (zero when the partner index is out of range).
   * Choose a *source* index `i` with a large contribution (`c_i`), and a
     *target* index `j` whose partner `a_{k-j}` is small – this movement
     reduces the peak of the convolution as much as possible.
   * Transfer a small amount `δ` from `i` to `j`.  The effect on the full
     convolution can be updated in `O(n)` time using the bilinearity of the
     convolution (no full FFT is needed for every trial move).
   * Accept the move if it strictly improves the true objective
     `2·n·max(b)`.  Otherwise accept it with probability
     `exp((old‑new)/T)`, where the temperature `T` decays linearly from a
     modest start value to almost zero.  This occasional uphill move
     helps to escape local minima that trapped the previous greedy
     hill‑climber.

3. **Stagnation handling** – after a long stretch without improvement the
   current solution is discarded and a fresh random simplex point is
   generated (a short “restart”).  The best solution seen so far is kept
   throughout.

4. **Final polishing** – once the time budget is exhausted the best
   sequence is evaluated with the provided `evaluate_sequence` wrapper and
   returned.

The code is fully self‑contained, uses only NumPy and the standard library,
and respects the 1000 s time limit.

import time
import numpy as np

# ----------------------------------------------------------------------
# Convolution utilities (FFT based, length 2·n‑1)
# ----------------------------------------------------------------------
def full_convolution(x: np.ndarray) -> np.ndarray:
    """Return the full autocorrelation `x * x` (length 2·len(x)‑1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Simplex helper – Euclidean projection onto {x ≥ 0, Σx = 1}
# ----------------------------------------------------------------------
def project_simplex(v: np.ndarray) -> np.ndarray:
    """Project vector v onto the probability simplex."""
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full(n, 1.0 / n, dtype=np.float64)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = v - theta
    w[w < 0] = 0.0
    if w.sum() > 0:
        w /= w.sum()
    else:
        w = np.full(n, 1.0 / n, dtype=np.float64)
    return w


# ----------------------------------------------------------------------
# Random point on the simplex (exponential / Dirichlet(1) distribution)
# ----------------------------------------------------------------------
def random_simplex(n: int) -> np.ndarray:
    """Generate a random probability vector of length n."""
    v = np.random.exponential(scale=1.0, size=n)
    return v / v.sum()


# ----------------------------------------------------------------------
# Incremental update of the full convolution when mass δ moves
# from index i to index j (i ≠ j).  The update is O(n).
# ----------------------------------------------------------------------
def updated_convolution(b: np.ndarray, a: np.ndarray,
                        i: int, j: int, delta: float) -> np.ndarray:
    """Return a fresh copy of b after moving `delta` from i to j."""
    n = a.shape[0]
    b_new = b.copy()
    # cross‑terms (2·δ·a) added to the j‑shift block, subtracted from i‑shift block
    b_new[j:j + n] += 2.0 * delta * a
    b_new[i:i + n] -= 2.0 * delta * a
    # pure δ² terms
    b_new[2 * j] += delta * delta
    b_new[2 * i] += delta * delta
    b_new[i + j] -= 2.0 * delta * delta
    # Numerical safeguard – the convolution should never become negative
    # (the true mathematical value is non‑negative).
    np.maximum(b_new, 0.0, out=b_new)
    return b_new


# ----------------------------------------------------------------------
# Helper: contributions to a particular lag k (used for guided moves)
# ----------------------------------------------------------------------
def contributions_at_k(a: np.ndarray, k: int) -> np.ndarray:
    """
    Return an array `c` where c[i] = a[i] * a[k-i] if the second index
    lies in range, otherwise 0.  This is exactly the contribution of
    coordinate i to the convolution entry b[k].
    """
    n = a.shape[0]
    idx = np.arange(n)
    opp = k - idx
    valid = (opp >= 0) & (opp < n)
    c = np.zeros_like(a)
    c[valid] = a[valid] * a[opp[valid]]
    return c
