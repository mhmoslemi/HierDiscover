Propose a step‑function sequence that minimizes `evaluate_sequence`.

Algorithm
---------
1. Initialise the coefficients `a` on the probability simplex
   (sum = 1).  Use the previously discovered best construction
   (`height_sequence_1`) if it exists, otherwise start from a uniform
   distribution of length `n≈1800`.

2. Keep the exact linear convolution `conv = a * a` (length `2n‑1`).
   The evaluation for a normalised vector is `2*n*max(conv)`.

3. Repeatedly perform *mass‑transfer* moves:
      a[i_src]   ← a[i_src]   – δ
      a[i_dst]   ← a[i_dst]   + δ
   where `i_src` is the index that contributes most to the current
   convolution peak (`max(conv)`) and `i_dst` is the index whose
   contribution to that peak is minimal (often zero).  The move size
   `δ` is a fraction of `a[i_src]` that shrinks linearly during the run.

   The convolution is updated incrementally in `O(n)` using the exact
   formula for a rank‑1 update, avoiding a full FFT each step.

4. Acceptance:
   * downhill moves are always accepted;
   * uphill moves are accepted with probability `exp(-(Δ)/T)`,
     where the temperature `T` ramps down from `0.02*obj` to `0.0001*obj`.

5. Occasionally (probability `jitter_prob`) perform a larger random
   transfer (“jitter”) and accept it under the same Metropolis rule.
   This helps the search escape plateaus.

6. Every `recompute_interval` iterations recompute the convolution
   from scratch with an FFT to eliminate numerical drift.

7. If no improvement has been seen for a long period,
   add a tiny random perturbation to all coefficients,
   renormalise, and recompute the convolution.

The loop runs until the allocated time budget (default 1000 s) is exhausted.
The best sequence found is returned as a plain list of floats.

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: full linear convolution via real FFT (used for occasional recompute)
# ----------------------------------------------------------------------
def _full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution `x*y` (length len(x)+len(y)-1) using real FFT."""
    n = x.shape[0]
    m = y.shape[0]
    total = n + m - 1
    size = 1 << (total - 1).bit_length()        # next power of two
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:total]
    # eliminate tiny negative artefacts
    np.maximum(conv, 0, out=conv)
    return conv
