Propose a candidate step‑function sequence that minimises
evaluate_sequence(...).

Algorithm
---------
* Work on the probability simplex (∑a_i = 1, a_i ≥ 0).  Scaling does not
  affect the objective, so we keep the sum fixed throughout.
* Keep the exact self‑convolution `conv = a * a` (full length 2n‑1) and
  update it *incrementally* after each mass‑transfer move.
* In every iteration we:
    1. locate the current peak `k* = argmax(conv)`;
    2. pick the pair (i_src, partner) that contributes the most to this
       peak (maximises a_i·a_{k*-i});
    3. choose a destination index `j_dst` whose partner value
       `a_{k*-j}` is minimal – this gives the largest linear reduction
       of the peak;
    4. compute the *largest* feasible mass `δ` that can be moved from
       `i_src` to `j_dst` without creating a new, higher peak.
       The bound is derived from the linearised effect on every entry of
       the convolution; a safe quadratic correction is applied later.
    5. apply the move (updating `a` and `conv`) and keep the best vector
       seen so far.
* To avoid getting stuck in plateaus a small probability of a random
  “jitter’’ move is added, and the convolution is fully recomputed
  periodically to clear accumulated floating‑point drift.
* The routine runs for at most `budget_s` seconds and returns the best
  sequence discovered.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: exact linear convolution via real FFT (used for occasional full sync)
# ----------------------------------------------------------------------
def _full_convolution_fft(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    n = x.shape[0]
    m = y.shape[0]
    total = n + m - 1
    size = 1 << (total - 1).bit_length()
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:total]
    np.maximum(conv, 0, out=conv)
    return conv


# ----------------------------------------------------------------------
# Helper: projection of a vector onto the probability simplex (∑=1, ≥0)
# ----------------------------------------------------------------------
def _project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the simplex {x≥0, sum x = 1}."""
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(n) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # numerical safety – fall back to uniform
        return np.full(n, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w

    recompute_interval = 5000     # full FFT recompute to remove drift
    iteration = 0

    eps = 1e-14

    while True:
        now = time.time()
        if now >= deadline:

        iteration += 1

        # ----------------------------------------------------------
        # Locate the current peak of the convolution
        # ----------------------------------------------------------
        k_star = int(conv.argmax())
        cur_max = conv[k_star]

        # ----------------------------------------------------------

        # ----------------------------------------------------------

        i_end = min(n - 1, k_star)

        conv[j_dst:j_dst + n] += 2.0 * delta * a_old
        # quadratic part (only three positions are affected)

        conv[2 * j_dst] += delta2

            conv[j_dst:j_dst + n] -= 2.0 * delta * a_old
            conv[2 * i_src] -= delta2

            conv[i_src + j_dst] += 2.0 * delta2
