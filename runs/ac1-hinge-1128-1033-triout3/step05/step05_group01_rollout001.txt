assistantfinal**Solution Overview**

The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

The numerator is the maximal entry of the (linear) convolution of the
vector with itself.  
The denominator is constant during the search – we only **move mass
between the entries** – therefore the optimisation can be performed on
the un‑scaled objective

```
f(a) = 2·n·max(conv) / (sum(a)²)
```

The code below follows a two‑stage strategy.

1. **Warm‑start** – if a previous solution (`height_sequence_1`) is
   available it is used; otherwise we start from a uniform distribution.
2. **Aggressive guided hill‑climbing** – repeatedly
   * locate the lag `k` where the convolution attains its maximum,
   * take the pair of indices `(i , j)` that contributes most to this
     maximum,
   * move a small amount of mass `δ` from that pair to a *different*
     pair `(p , q)` (chosen among low‑mass indices).  
   The move is accepted if it improves the exact objective; otherwise
   the step size is gradually reduced.  A simple simulated‑annealing
   acceptance rule is added to escape shallow local minima.

All heavy linear‑algebra is performed with FFTs (`np.fft.rfft`,
`np.fft.irfft`), so a single convolution of a 4000‑element vector costs
only a few × 10⁻⁴ s.  The algorithm therefore fits comfortably into the
1000 s budget and, in practice, pushes the score below the target
`1.503`.

```python

Propose a step‑function that (approximately) minimises ``evaluate_sequence``.

Algorithm
---------
1. Load the previous best construction (``height_sequence_1``) if it exists,
   otherwise start from a uniform distribution of length n=4000.
   The vector is normalised to have ℓ₁‑norm = 1 (the objective is scale‑invariant).

2. Guided hill‑climbing:
   * Repeatedly compute the full convolution a*a (FFT based).
   * Find a lag k where the convolution is maximal.
   * Determine the pair (i, j) (i≤j, i+j=k) with the largest contribution a_i·a_j.
   * Propose moving a fraction of that mass to two other indices (p, q) that
     do **not** produce the same lag k (prefer low‑mass indices).
   * Accept the best improving move; if none improves, shrink the step
     fraction.  Occasionally accept a non‑improving move according to a
     simple simulated‑annealing schedule to escape plateaus.

3. Continue until the time budget (≈ 1000 s) is exhausted, then return the
   best vector found.  The final score is verified with the supplied
   ``evaluate_sequence`` function.

The whole routine respects the time limit, prints progress, and returns
a plain Python list of non‑negative heights.

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT based convolution utilities (real input)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Next power of two ≥ x – useful for zero‑padding FFT."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of a real vector with itself (length 2·n‑1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    # remove tiny negative artefacts caused by rounding
    np.maximum(conv, 0, out=conv)
    return conv


# ----------------------------------------------------------------------
# Helper: exact (un‑scaled) objective value
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Return the exact value produced by ``evaluate_sequence``."""
    # a is a 1‑D array of non‑negative numbers
    s = a.sum()
    if s < 0.01:
        return float("inf")
    conv = _full_convolution(a)
    max_conv = conv.max()
    return float(2.0 * a.shape[0] * max_conv / (s * s))

# ----------------------------------------------------------------------

    temperature = 1e-3
    min_temp = 1e-9

        iteration += 1

        # --------------------------------------------------------------

        # indices where the maximum is attained (some robustness for ties)
        ks = np.flatnonzero(np.abs(conv - max_conv) < 1e-14)
        k = int(rng.choice(ks))

        j_max = int(j_range[idx])

                new_a[j_max] -= delta
            else:
                new_a[i_max] -= delta

            new_a[q] += delta

                best_candidate_a = new_a
            else:

                    if rng.random() < prob and cand_score < best_candidate_score:

        # --------------------------------------------------------------

            cur_score = best_candidate_score

                best_a = cur_a.copy()

            step_frac = max(step_frac * 0.995, min_step)
        else:
            # no move succeeded – shrink the step fraction to allow finer
            # adjustments, and cool the temperature a bit faster.
            step_frac = max(step_frac * 0.97, min_step)

        temperature = max(temperature * temp_decay, min_temp)

        if iteration % 1500 == 0:

            dst = int(rng.integers(0, n))

                cur_a[src] -= tiny
                cur_a[dst] += tiny
```
