    The function f_i = 2*(n-1-i)/(n*(n-1)) for i=0,...,n-1.

    of the self‑convolution, yielding an evaluation score of 4/3

    # 8000 matches the previous experiments and keeps runtime low.

    if n < 2:

    # Create decreasing arithmetic sequence: n-1, n-2, ..., 0.
    # Scale so that the sum equals 1.
    a = np.arange(n, dtype=np.float64)[::-1]  # values n-1 down to 0
    # Convert to float and apply scaling factor.
    scale = 2.0 / (n * (n - 1))
    a = a * scale

    # Ensure non‑negativity (the last element is exactly zero) and sum to 1.
    a[-1] = max(a[-1], 0.0)

    total = a.sum()

    return a.tolist()
