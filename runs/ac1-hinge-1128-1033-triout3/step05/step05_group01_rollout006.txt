"""
Generate a decreasing power‑law step function.

The objective evaluate_sequence(sequence) is scale‑invariant:
only the shape of the distribution matters.  For a sequence of length n
with entries

    a_i ∝ (n – i)^p   (i = 0,…,n‑1),

the full convolution attains its maximum at lag n‑1 and
asymptotically

    max(conv) ≈ ((p+1)^2·(p!)^2) / ((2p+1)!·n).

Hence the evaluation score

    2·n·max(conv) / (∑a_i)^2 = 2·((p+1)^2·(p!)^2) / (2p+1)!

which shrinks rapidly with the exponent p.  Already p=5 gives a score
≈0.03, far below the target 1.5.

The routine below tries a short grid of exponents (p=1…10) for a modest
length (default 4000 or the length of an existing height_sequence_1),

call and returns it.  The whole process finishes well within the 1000 s

"""

    Return a non‑negative vector a of length n with
        a_i ∝ (n - i)^p,
    normalised so that sum(a) == 1.
    """

    vals = (n - idx) ** p
    total = vals.sum()
    if total == 0.0:                     # pathological fallback
        return np.full(n, 1.0 / n, dtype=np.float64)
    return vals / total
