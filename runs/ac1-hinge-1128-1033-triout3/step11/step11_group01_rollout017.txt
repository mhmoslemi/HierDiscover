We minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)_k}{\left(\sum_i a_i\right)^2}
\]

where `a` is a non‑negative step‑function (list of heights) and `*` denotes the full linear convolution.  
Because the objective is *scale‑invariant* we may enforce \(\sum a_i = 1\) and simply minimise the
maximum entry of the convolution.

The algorithm works in two phases:

1. **Flat‑convolution phase** – we minimise the variance of the convolution
   (i.e. minimise \(\sum_k (a*a)_k^2\)).  
   The gradient of this term is   \(g_{\text{flat}} = 4\,\text{cross‑corr}(a*a,\,a)\).

2. **Maximum‑phase** – we focus on the true objective.  
   We approximate the non‑differentiable `max` by a soft‑max:
   \[
   w_k = \frac{\exp\bigl(\lambda\,(c_k-c_{\max})\bigr)}{\sum_j
   \exp\bigl(\lambda\,(c_j-c_{\max})\bigr)} ,
   \qquad
   g_{\max}=2\,\text{cross‑corr}(w,\,a)
   \]
   with a temperature \(\lambda\) that grows from a small value to a large one.

Both gradients are blended linearly with the progress of the optimisation,
so the early iterations flatten the whole convolution and the later iterations
sharpen the reduction of the true maximum.

The optimisation variable is the log‑probability vector `z` (soft‑max
guarantees non‑negativity and unit sum).  Adam is used to update `z`
and occasional Gaussian noise is added to escape plateaux.
The best sequence seen so far is stored and finally evaluated with
`evaluate_sequence`.

The whole search respects the 1000 s budget and returns the best
sequence discovered.

Non‑negative step‑function optimiser (flat‑then‑max gradient descent).

The algorithm works with a probability vector a ( Σ a = 1 ) represented by
log‑parameters z (soft‑max).  It first flattens the convolution by
minimising the sum of squares of the convolution entries, then
focuses on the true max‑objective using a soft‑max approximation.
Adam updates on the logits are used; occasional Gaussian noise helps
escape stagnation.  The routine respects the 1000 s budget and finally

# ----------------------------------------------------------------------
# Helper: next power of two – used for FFT sizes
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


# ----------------------------------------------------------------------
# Full linear convolution a*a (real FFT, length 2·n‑1)
# ----------------------------------------------------------------------
def _full_convolution(a: np.ndarray) -> np.ndarray:
    """Return full convolution of a with itself."""
    n = a.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Cross‑correlation needed for gradients:
#   g_i = Σ_k w_k * a_{k-i}
# obtained as a slice of the convolution of w with reversed a.
# ----------------------------------------------------------------------
def _cross_corr(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Compute g_i = Σ_k w_k * a_{k-i} for i=0..len(a)-1.
    Uses FFT; returns a real vector of length len(a).
    """
    n = a.shape[0]
    a_rev = a[::-1]
    out_len = len(w) + n - 1          # = (2n‑1) + n‑1 = 3n‑2
    size = _next_pow2(out_len)
    fw = np.fft.rfft(w, size)
    fa = np.fft.rfft(a_rev, size)
    conv = np.fft.irfft(fw * fa, size)[:out_len]
    start = n - 1                     # indices n‑1 … n‑1+n‑1
    return conv[start:start + n]


# ----------------------------------------------------------------------
# Project a vector onto the probability simplex {x ≥ 0, Σ x = 1}
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the simplex."""
    if np.all(v <= 0):
        # all non‑positive -> return uniform distribution
        return np.full_like(v, 1.0 / v.size)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w
