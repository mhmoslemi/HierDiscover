assistantfinal**Solution Overview**

The evaluation function is  

\[
F(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where \((a*a)_k\) is the full linear convolution of the non‑negative vector
\(a\) with itself.  
The function is *scale‑invariant*: multiplying every entry of `a` by a constant
does not change `F`.  Therefore we can restrict the search to the simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

The problem is non‑convex because of the `max` operator.  
We use a **smooth approximation** of the maximum

\[
\phi_\beta(a)=\frac{1}{\beta}\log\Bigl(\sum_k e^{\beta\,(a*a)_k}\Bigr)
\]

and minimise the smooth objective with projected (simplex) gradient descent.
The gradient of \(\phi_\beta\) can be written in closed form and is evaluated
with a few FFTs ( \(O(n\log n)\) ).  

To obtain a better solution we:

1. **Try many diverse initial points** – uniform, interpolated previous best,
   Beta‑shaped families, truncated exponentials and Dirichlet draws.
2. **Run many independent optimisation runs**.  
   Each run uses a different start and a *fast* Adam‑style update with a
   projection onto the simplex after every step.
3. **Increase the smoothing parameter quickly** (`β ← min(β_max,β·β_mul)`);
   after a few hundred iterations `β` reaches `β_max = 200` and the optimiser
   works on the true `max` (no smoothing).
4. **Add occasional jitter** to escape shallow plateaus.
5. **Keep the best sequence ever seen** and finally evaluate it with the
   supplied `evaluate_sequence`.

The code respects the 1000 s time limit, only uses the allowed libraries and
exposes a single `propose_candidate` function.

"""
Propose a step‑function (list of non‑negative heights) that minimises
``evaluate_sequence``.

The algorithm
--------------
* Normalise all candidates to the probability simplex (Σa = 1, a≥0).
* Generate a diverse set of starting vectors:
  – interpolated previous solution (if any)
  – uniform distribution
  – truncated exponential families
  – Beta‑shaped families (a_i ∝ i^{p‑1}(n‑i+1)^{q‑1})
  – Dirichlet draws with several concentration parameters.
* Keep the best start (lowest exact objective).
* Run many *restarts* of projected Adam‑style gradient descent on the
  **smoothed maximum**  

      φ_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)

  The gradient is computed analytically via FFTs.
* β (smoothing) starts small (0.1) and is multiplied by 1.02 each step,
  quickly reaching β_max = 200, i.e. the original non‑smoothed problem.
* After each gradient step the iterate is projected onto the simplex.
* Small random jitter is added occasionally to jump out of flat regions.
* The best sequence seen during the whole search is finally passed to
  ``evaluate_sequence`` and returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of `x` with itself (length 2·len(x)-1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex Σx=1, x≥0."""
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def _beta_shape(p: float, q: float, n: int) -> np.ndarray | None:
    """
    Return a normalised Beta‑shaped vector:
        a_i ∝ i^{p-1}·(n‑i+1)^{q-1},   i = 1,…,n .
    Returns None if the parameters give an all‑zero vector.
    """
    i = np.arange(1, n + 1, dtype=np.float64)
    a = (i ** (p - 1.0)) * ((n - i + 1) ** (q - 1.0))
    total = a.sum()
    if total <= 0.0:
        return None
    a /= total
    return a


def _gradient_smooth(a: np.ndarray, beta: float) -> tuple[np.ndarray, float]:
    """
    Gradient of the smoothed max‑convolution

        φ_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)

    Returns (grad, max_conv) where `grad` has the same shape as `a`
    and `max_conv` = max_k (a*a)_k (the exact max, useful for the true objective).
    """
    n = a.shape[0]

    # ----- 1. full convolution a⋆a (length 2n‑1) -----
    out_len = 2 * n - 1
    size_conv = 1 << (out_len - 1).bit_length()
    fa = np.fft.rfft(a, size_conv)
    conv = np.fft.irfft(fa * fa, size_conv)[:out_len]        # (a⋆a)

    max_conv = conv.max()

    # ----- 2. soft‑max weights w_i -----
    exp_arg = beta * (conv - max_conv)          # ≤ 0, avoids overflow
    w = np.exp(exp_arg)
    w_sum = w.sum()
    w_norm = w / w_sum                           # Σ_i w_i = 1

    # ----- 3. gradient = 2·(a ⋆_cross w_norm) -----
    # cross‑correlation (a ⋆ w_norm)[j] = Σ_k a_k·w_norm_{k+j}
    rev_w = w_norm[::-1]                         # reverse for convolution
    out_len_corr = n + out_len - 1               # = 3n‑2
    size_corr = 1 << (out_len_corr - 1).bit_length()
    Fa = np.fft.rfft(a, size_corr)
    Fw = np.fft.rfft(rev_w, size_corr)
    corr_full = np.fft.irfft(Fa * Fw, size_corr)[:out_len_corr]

    offset = out_len - 1                         # position of lag 0
    idx = offset - np.arange(n)                  # indices for j = 0…n‑1
    grad = 2.0 * corr_full[idx]

    return grad, max_conv

    except Exception as exc:   # pragma: no cover

    return best_seq.tolist()
