The goal is to minimise  

\[
E(a)=\frac{2\,n\;\max (a\ast a)}{(\sum_i a_i)^2},
\]

where `a` is a non‑negative step‑function (a vector) and `*` is the linear convolution.
The objective is scale‑invariant, therefore we restrict the search to the probability
simplex `∑a_i = 1 , a_i ≥ 0`.  
If the convolution were perfectly flat, all its entries would be `1/(2n‑1)`,
giving a theoretical lower bound `E≈1`.  Uniform vectors have a triangular
convolution and reach `E=2`.  By breaking the symmetry of the uniform vector we can
flatten the convolution and push the value below `2`.

The programme below follows a **pure smoothed gradient descent**:

1. **Initialisation** – start from an almost‑uniform vector with a tiny random
   perturbation (to break symmetry).
2. **Smoothed objective** – replace `max` by a log‑sum‑exp with temperature `β`.  
   For a given `β` the gradient is a weighted cross‑correlation that can be
   computed with three FFTs.
3. **Projected Adam updates** – an Adam‑style adaptive step is taken,
   followed by Euclidean projection onto the simplex.
4. **β‑schedule** – `β` is increased multiplicatively (from `5` up to `300`),
   so the optimisation first sees a smoothed landscape and finally focusses on
   the true maximum.
5. **Time‑budget handling** – the loop runs until the supplied budget (`budget_s`)
   is exhausted (leaving a small safety margin).  The best vector found so far is
   returned and finally evaluated with the supplied `evaluate_sequence`.

The algorithm spends almost the whole budget on the gradient loop (no costly
grid searches), allowing many thousands of iterations and typically achieving
values considerably below the previous `1.508…` result.

```python
"""
propose_candidate – minimise evaluate_sequence() by smoothed gradient descent.

The routine works on the probability simplex (∑a_i = 1, a_i ≥ 0) and repeatedly
optimises the smooth approximation

    φ_β(a) = (1/β)·log Σ_k exp(β·(a⋆a)_k)

whose gradient is a weighted cross‑correlation.  An Adam‑style adaptive step is
taken and the iterate is projected back onto the simplex.  The temperature β
is increased slowly (5 → 300) so that the optimisation finishes on the true
max‑convolution objective.  The best vector found before the time budget
expires is returned and finally evaluated with `evaluate_sequence`.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution x⋆x (length 2·len(x)‑1) via FFT."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()          # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _objective(a: np.ndarray) -> float:
    """Exact objective 2·n·max(a⋆a) for a vector with Σa = 1."""
    n = a.shape[0]
    b = _full_convolution(a)
    return float(2.0 * n * b.max())


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex Σx=1, x≥0."""
    if np.all(v >= 0) and np.isclose(v.sum(), 1.0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # numerical safety – fall back to uniform distribution
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def _gradient_smooth(a: np.ndarray, beta: float):
    """
    Gradient of the smoothed objective φ_β and the exact maximal convolution.

    Returns
        grad   – Euclidean gradient (same shape as a)
        max_b  – max(a⋆a) (needed for the exact objective)
    """
    n = a.shape[0]

    # ---- 1️⃣ full convolution a⋆a ------------------------------------
    out_len = 2 * n - 1
    size_conv = 1 << (out_len - 1).bit_length()
    fa = np.fft.rfft(a, size_conv)
    conv = np.fft.irfft(fa * fa, size_conv)[:out_len]        # (a⋆a)

    max_b = conv.max()

    # ---- 2️⃣ soft‑max weights ----------------------------------------
    # shift by max to avoid overflow
    exp_arg = beta * (conv - max_b)          # ≤ 0
    w = np.exp(exp_arg)
    w_norm = w / w.sum()                     # Σ w_i = 1

    # ---- 3️⃣ gradient = 2·(a ⋆_cross w_norm) -------------------------
    rev_w = w_norm[::-1]                     # reverse for convolution
    out_len_corr = n + out_len - 1            # = 3n‑2
    size_corr = 1 << (out_len_corr - 1).bit_length()
    Fa = np.fft.rfft(a, size_corr)
    Fw = np.fft.rfft(rev_w, size_corr)
    corr_full = np.fft.irfft(Fa * Fw, size_corr)[:out_len_corr]

    offset = out_len - 1                     # position of lag‑0
    idx = offset - np.arange(n)              # indices for j = 0…n‑1
    grad = 2.0 * corr_full[idx]

    return grad, max_b


# ----------------------------------------------------------------------
# Main entry point
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a non‑negative step function that minimises ``evaluate_sequence``.
    Returns the best sequence discovered before the time budget expires.
    """
    np.random.seed(seed)
    start_time = time.time()
    # reserve a little margin for the final call to evaluate_sequence
    deadline = start_time + budget_s - 0.5

    # --------------------------------------------------------------
    # 1️⃣ problem size – larger n gives a lower theoretical bound
    # --------------------------------------------------------------
    n = 12000                # feel free to adjust; fits easily into the budget

    # --------------------------------------------------------------
    # 2️⃣ initialise from (almost) uniform distribution
    # --------------------------------------------------------------
    a = np.full(n, 1.0 / n)
    # tiny random perturbation to break symmetry
    a += np.random.normal(scale=0.001 / n, size=n)
    a = np.maximum(a, 0.0)
    a = _project_simplex(a)

    # Keep the best solution seen so far
    conv_now = _full_convolution(a)
    best_val = 2.0 * n * conv_now.max()
    best_seq = a.copy()
    print(f"[init] objective = {best_val:.6f}")

    # --------------------------------------------------------------
    # 3️⃣ optimisation hyper‑parameters
    # --------------------------------------------------------------
    beta = 5.0                      # start of smoothing
    beta_max = 300.0
    beta_mul = 1.0015               # multiplicative increase per iteration

    step0 = 1.0                     # base step size for Adam (scaled by 1/√t)
    iteration = 0

    # Adam moment estimates
    m = np.zeros_like(a)
    v = np.zeros_like(a)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12

    # --------------------------------------------------------------
    # 4️⃣ main optimisation loop (runs until the time budget expires)
    # --------------------------------------------------------------
    while time.time() < deadline:
        iteration += 1
        step = step0 / np.sqrt(iteration)

        # gradient of the smoothed objective and exact max‑convolution
        grad, cur_max = _gradient_smooth(a, beta)
        cur_obj = 2.0 * n * cur_max

        # keep the best point ever seen
        if cur_obj < best_val:
            best_val = cur_obj
            best_seq = a.copy()
            print(f"[iter {iteration}] new best = {best_val:.6f} (β={beta:.2f})")
            # optional early stop – can be removed if more time is desired
            if best_val <= 1.40:
                break

        # ---- Adam update -------------------------------------------------
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** iteration)
        v_hat = v / (1.0 - beta2 ** iteration)

        # adaptive step (per‑coordinate)
        update = step * m_hat / (np.sqrt(v_hat) + eps)
        a = a - update

        # projection back onto the simplex (ensures non‑negativity and Σa=1)
        a = _project_simplex(a)

        # occasional tiny random jitter to escape plateaus
        if np.random.rand() < 0.001:
            a += np.random.normal(scale=1e-4, size=n)
            a = np.maximum(a, 0.0)
            a = _project_simplex(a)

        # increase smoothing parameter slowly
        beta = min(beta_max, beta * beta_mul)

        # occasional status report (does not affect performance much)
        if iteration % 2000 == 0:
            print(f"[status] iter={iteration}, best={best_val:.6f}, cur={cur_obj:.6f}, β={beta:.2f}")

    # --------------------------------------------------------------
    # 5️⃣ final secure evaluation
    # --------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"[final] reported score = {final_score:.6f}")
    except Exception as exc:   # pragma: no cover
        print("[final] evaluate_sequence raised:", exc)

    # Return the best sequence as a plain Python list
    return best_seq.tolist()
```
