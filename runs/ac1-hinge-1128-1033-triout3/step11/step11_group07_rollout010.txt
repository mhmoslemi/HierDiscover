Now produce final answer with code block.assistantfinal**Solution Overview**

The program searches for a non‑negative *step function* `a = (a₀,…,aₙ₋₁)` that minimises  

```
evaluate_sequence(a) = 2·n·max(conv(a,a)) / (∑a)² .
```

The objective is scale‑invariant, therefore we keep the vector normalised
(`∑a = 1`).  
The maximum of `conv(a,a)` is attained either at the centre of the
convolution (dot‑product of `a` with its reverse) or at the very ends
(`a₀²`, `aₙ₋₁²`).  A classical family that can control both effects is the
*Beta‑shape*

```
a_i ∝ i^{p−1}·(n−i+1)^{q−1} ,   i = 1…n ,   p>0 , q>0 .
```

When `p≈q` we obtain a symmetric (almost uniform) vector, and when
`p≠q` the distribution is skewed – the large values appear at one end,
the small values at the other, reducing the centre overlap while keeping
the end‑values moderate.

The optimiser has three phases

1. **Coarse grid search** over `p` and `q` on a logarithmic grid.
   For each pair we build the Beta vector, evaluate the exact objective
   (`conv` via FFT) and keep the best candidate.

2. **Local refinement** – random log‑normal perturbations of the best
   `(p,q)` pair (≈ 5000 trials) to explore the neighbourhood more
   precisely.

3. **Exact sub‑gradient polishing** – projected sub‑gradient descent on
   the true (non‑smooth) objective, starting from the best vector found
   so far.  The step‑size decays linearly; each iteration projects the
   iterate onto the probability simplex.

The whole procedure respects the 1000 s time limit, prints intermediate
progress, and finally returns the best vector as a plain list of floats.
The code contains only top‑level functions, no closures or lambdas,
and works with only `numpy` and the standard library.

```python
"""
Beta‑shape optimiser for the step‑function attack.

* Phase 1 – exhaustive log‑grid over the Beta exponents (p,q)
* Phase 2 – random log‑normal refinement around the best pair
* Phase 3 – exact projected sub‑gradient polishing on the true max‑norm

All heavy work is done with FFT‑based convolutions; the algorithm
stops automatically before the 1000‑second deadline.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Convolution helpers (FFT, full linear convolution)
# ----------------------------------------------------------------------
def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Full linear convolution of `x` with itself (length 2·len(x)-1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = 1 << (out_len - 1).bit_length()   # next power of two
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Exact objective (assumes Σa = 1)
# ----------------------------------------------------------------------
def _objective(a: np.ndarray) -> float:
    """Exact value of evaluate_sequence for a normalised vector."""
    n = a.shape[0]
    s = a.sum()
    if s < 1e-12:
        return np.inf
    b = _full_convolution(a)
    return float(2.0 * n * b.max() / (s * s))


# ----------------------------------------------------------------------
# Simple Euclidean projection onto the probability simplex Σx = 1, x ≥ 0
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Projection of v onto the simplex."""
    if np.abs(v.sum() - 1.0) < 1e-12 and np.all(v >= 0):
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(len(v)) + 1
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Exact sub‑gradient polishing (max‑convolution)
# ----------------------------------------------------------------------
def _subgradient_polish(a0: np.ndarray,
                        deadline: float,
                        start_time: float,
                        best_a: np.ndarray,
                        best_val: float,
                        max_iters: int = 200_000) -> tuple[np.ndarray, float]:
    """Projected sub‑gradient descent on the true objective."""
    a = a0.copy()
    cur_val = _objective(a)

    n = a.shape[0]

    for it in range(max_iters):
        now = time.time()
        if now >= deadline:
            break

        b = _full_convolution(a)
        max_b = b.max()
        k_maxes = np.where(b == max_b)[0]

        # sub‑gradient (sum of contributions from all maximal indices)
        grad = np.zeros_like(a)
        for k in k_maxes:
            idx = k - np.arange(n)               # potential partner indices
            mask = (idx >= 0) & (idx < n)
            grad[mask] += 2.0 * a[idx[mask]]      # 2·a_j for each pair (i,j)

        # linear decay of the step size
        progress = (now - start_time) / (deadline - start_time)
        step = 0.30 * (1.0 - progress) + 1e-5 * progress

        a_new = a - step * grad
        a_new = _project_simplex(a_new)

        new_val = _objective(a_new)
        if new_val < cur_val - 1e-12:
            a = a_new
            cur_val = new_val
            if new_val < best_val:
                best_val = new_val
                best_a = a.copy()
                print(f"[Polish] new best = {best_val:.6f}")

        # occasional tiny jitter to escape plateaus
        if it % 500 == 0 and np.random.rand() < 0.03:
            a = np.maximum(a + np.random.normal(scale=0.02, size=n), 0.0)
            a = _project_simplex(a)

    return best_a, best_val


# ----------------------------------------------------------------------
# Beta‑shape generator (log‑stable)
# ----------------------------------------------------------------------
def _beta_shape(p: float, q: float, n: int,
                log_i: np.ndarray,
                log_rev: np.ndarray) -> np.ndarray:
    """
    Return the normalised Beta‑shaped vector:
        a_i ∝ i^{p−1} (n−i+1)^{q−1} .
    The logarithms of i and (n−i+1) are supplied to avoid repeated work.
    """
    # compute log‑amplitudes, shift by the max to keep numbers in range
    log_a = (p - 1.0) * log_i + (q - 1.0) * log_rev
    log_a -= np.max(log_a)
    a = np.exp(log_a)
    s = a.sum()
    if s == 0.0:
        a = np.full(n, 1.0 / n)
    else:
        a /= s
    return a

        p_new = best_p * 10 ** rng.uniform(-0.2, 0.2)
        q_new = best_q * 10 ** rng.uniform(-0.2, 0.2)
        if p_new <= 0 or q_new <= 0 or p_new + q_new <= 1.0:
            continue
        cand = _beta_shape(p_new, q_new, n, log_i, log_rev)
        val = _objective(cand)
        if val < best_val:
            best_val, best_a = val, cand.copy()
            best_p, best_q = p_new, q_new
            print(f"[Refine] new best = {best_val:.6f} (p={p_new:.4g}, q={q_new:.4g})")

    # ------------------------------------------------------------------
    # Phase 3 – exact sub‑gradient polishing (remaining time)
    # ------------------------------------------------------------------
    if time.time() < deadline:
        print("[Phase 3] sub‑gradient polishing")
        best_a, best_val = _subgradient_polish(
            best_a,
            deadline=deadline,
            start_time=start_time,
            best_a=best_a,
            best_val=best_val,
            max_iters=300_000,
        )
        print(f"[Phase 3] polishing finished, best = {best_val:.6f}")

    # ------------------------------------------------------------------
    # Final secure evaluation (for the competition harness)
    # ------------------------------------------------------------------
    try:
        reported = evaluate_sequence(best_a.tolist())
        print(f"[Final] evaluate_sequence reports = {reported:.6f}")
    except Exception as exc:   # pragma: no cover
        print("[Final] evaluate_sequence raised:", exc)

    return best_a.tolist()
```
