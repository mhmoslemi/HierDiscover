Propose a candidate step‑function that minimises
    evaluate_sequence(seq) = 2·n·max(conv(seq,seq)) / (sum(seq))²

Algorithm
---------

1.  Initialise a probability vector `a` (sum = 1).  If a previous
    solution `height_sequence_1` exists it is interpolated to the
    chosen length `n`; otherwise a uniform start is used.

2.  Optimise `a` with a **smoothed Adam** loop (the same idea as the
    reference code) but on a larger problem size (`n≈12000`).  The
    Adam updates are performed on the logits `z = log a` so positivity
    is automatic.  A soft‑max with a temperature `α` smooths the
    `max(conv)`; `α` is annealed from ~1 to >300.

3.  Every few thousand Adam steps (or after a long stagnation) a
    cheap *analytic* improvement is applied:

        * Solve the dual of the linear program
          `max sum(g)  s.t. conv(a,g) ≤ max(conv(a,a))`.
          The dual admits a simple closed form:
          `g ∝ 1/a` after a scaling that guarantees the convolution
          bound.  This pushes mass from large entries of `a` to the
          small ones and typically reduces the peak of the
          autocorrelation.

        * The new `g` is mixed with the current `a` (`a ← (1‑t)a + t g`,
          `t≈0.15`) and the Adam state is re‑initialised.

4.  A reset (small random jitter of the logits) is performed if the
    optimisation stalls for many iterations.

5.  After the time budget expires a short **entropy‑mirror‑descent**
    polishing phase (exact max‑entry gradient) is run on the best
    vector found.

The whole routine respects the 1000 s wall‑time limit, prints
progress information and finally returns the best sequence as a list
of floats.  All numbers are non‑negative (the wrapper will clamp
negative entries anyway).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based full convolutions (linear, not circular)
# ----------------------------------------------------------------------
def _next_pow2(x: int) -> int:
    """Return the next power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _full_convolution(x: np.ndarray) -> np.ndarray:
    """Linear convolution of a vector with itself (length 2·len(x)-1)."""
    n = x.shape[0]
    out_len = 2 * n - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    conv = np.fft.irfft(fx * fx, size)[:out_len]
    return conv


def _full_convolution_two(x: np.ndarray, y: np.ndarray) -> np.ndarray:
    """Linear convolution of two possibly different vectors."""
    n, m = x.shape[0], y.shape[0]
    out_len = n + m - 1
    size = _next_pow2(out_len)
    fx = np.fft.rfft(x, size)
    fy = np.fft.rfft(y, size)
    conv = np.fft.irfft(fx * fy, size)[:out_len]
    return conv


# ----------------------------------------------------------------------
# Entropy‑mirror‑descent polishing (exact max entry of the convolution)
# ----------------------------------------------------------------------
def _max_refine(a: np.ndarray, steps: int = 1500, eta_start: float = 0.45) -> np.ndarray:
    """Mirror‑descent on the exact max‑entry of a*a."""
    n = a.shape[0]
    a = a.copy()
    for t in range(steps):
        conv = _full_convolution(a)
        k = int(conv.argmax())
        # sub‑gradient of the max entry w.r.t. a
        g = np.zeros_like(a)
        lo = max(0, k - (n - 1))
        hi = min(k, n - 1)
        if lo <= hi:
            idx = np.arange(lo, hi + 1, dtype=int)
            g[idx] = 2.0 * a[k - idx]
        # decreasing step size
        eta = eta_start * (1.0 - t / steps)
        a = a * np.exp(-eta * g)
        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a /= s
    return a
