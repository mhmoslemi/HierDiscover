"""
Propose a better step function sequence.

Algorithm outline
-----------------
1. **Initialize** a non‑negative sequence of length ``n`` (default 800) and
   normalise it so the sum equals 1 (the objective is scale invariant).

2. **Iterative improvement** until the time budget expires.
   * **Gradient‑like sub‑gradient step** – the current maximal convolution entry
     occurs at index ``k_max``.  The sub‑gradient of this max w.r.t. the
     coefficients is ``g_i = 2 * a_{k_max-i}`` (zero if the index is out of
     range).  We move a little in the opposite direction, clip to non‑negative,
     then re‑normalise.  This reduces the maximal autocorrelation while keeping
     the ℓ¹‑norm fixed.
   * **Occasional linear‑programming boost** – every ``LP_EVERY`` iterations we
     solve the LP

       maximise   Σ b_i
       subject to (a * b)_k ≤ M   for all k
                  b_i ≥ 0

     where ``M`` is the current maximal convolution value.
     The LP finds a direction ``b`` that can increase the total sum without
     increasing the bound ``M``.  We then mix the current sequence with ``b``
     using a back‑tracking line‑search on the mixing weight ``t`` to obtain a
     strict improvement.

   * **Random perturbations** – if neither the gradient step nor the LP step
     improves the score we occasionally add small Gaussian noise to escape
     possible stagnation.

3. Keep the best sequence seen so far and return it when the time limit is
   reached.

The method combines cheap sub‑gradient updates with the powerful LP‑based
“mass‑redistribution” step used in the reference implementation, but adds a
dynamic step‑size line search and a simple simulated‑annealing acceptance rule
to explore the non‑convex landscape more aggressively.
"""

import time
import numpy as np
from scipy.optimize import linprog

# ----------------------------------------------------------------------
# Helper: solve the LP  maximise Σ b_i   s.t.   (a * b)_k ≤ M , b ≥ 0
# ----------------------------------------------------------------------
def solve_convolution_lp(a_seq, bound_M):
    """
    Returns a non‑negative vector `b` with maximal ℓ¹‑norm such that the
    discrete convolution a_seq * b never exceeds `bound_M`.
    If the LP fails, ``None`` is returned.
    """
    n = len(a_seq)
    # Build the convolution constraints: for each possible sum index k
    #   Σ_i a_i * b_{k-i} ≤ bound_M
    A = np.zeros((2 * n - 1, n), dtype=np.float64)
    for k in range(2 * n - 1):
        low = max(0, k - (n - 1))
        high = min(n - 1, k)
        # i runs over the part of a that participates
        for i in range(low, high + 1):
            j = k - i
            A[k, j] = a_seq[i]

    b = np.full(2 * n - 1, bound_M, dtype=np.float64)
    c = -np.ones(n)                     # maximise Σ b_i  ⇔ minimise -Σ b_i
    bounds = [(0, None)] * n            # b_i ≥ 0

    # Use the high‑performance 'highs' solver (default in recent SciPy)
    res = linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                  method='highs', options={'presolve': True})
    if res.success:
        return res.x
    return None
