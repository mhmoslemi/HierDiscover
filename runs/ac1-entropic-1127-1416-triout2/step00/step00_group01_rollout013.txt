Search for a step function with low evaluation by using a power‑law shape.

We generate sequences a_i = (i+offset)^{-p} for several exponents p ≈ 0.55‑0.65
and a few integer offsets.  The evaluation function is scale‑invariant, therefore
the raw values can be used directly – the only freedom is the relative shape of
the sequence.  Theory shows that for p∈[0.5,0.65] the maximal convolution value
is attained in the middle of the array and the ratio 2·n·max(conv)/(sum a)^2
has a closed form 2·B(1‑p,1‑p)·(1‑p)^2, which is < 1.5 around p≈0.58.  The code
materialises this idea, evaluates a handful of candidates with the provided
`evaluate_sequence` and returns the best one found before the time budget
expires.
"""

import time
import numpy as np
# evaluate_sequence is assumed to be already imported in the environment.

def _make_power_law(n: int, p: float, offset: float = 0.0) -> list[float]:
    """Generate a non‑negative sequence a_i = (i+offset)^{-p}, i=1..n.

    The exponent p > 0 determines how fast the values decay.
    A small offset moves the singularity away from the first element and
    slightly flattens the shape.
    """
    # Using Python list comprehension is faster than np.power for the short loops.
    return [(i + offset) ** (-p) for i in range(1, n + 1)]

        a_i = (i+offset)^{-p}

    evaluation function is called; the best sequence found before the time
    limit is returned.

    Parameters
    ----------
    seed : int, optional
        Seed for NumPy's RNG – currently unused but kept for compatibility.
    budget_s : int, optional
        Approximate time budget in seconds (default 1000).

    Returns

    list[float]
        The best sequence discovered.
    """

    # Basic settings

    start_time = time.time()
