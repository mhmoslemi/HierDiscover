"""
Simple analytic construction for the auto‑convolution minimisation problem.

The evaluation function is scale‑invariant, therefore we can treat the step
heights as a probability distribution.  For a monotone decreasing density
f(x) = (p+1)*(1-x)^p on the interval [0,1] the L∞‑norm of the

    2·(p+1)²·B(p+1,p+1) = 2·(p+1)²·(p!·p!)/(2p+1)!

    a_i = C·(n‑i)ᵖ ,   i = 0 … n‑1

The function below builds the sequence using p=5 (any p≥2 works, larger p

"""

import time
