"""
Linear‑step construction.

The evaluation function is
    f(a) = 2·n·max(a∗a) / (sum(a))²

For a monotone linear profile a_i = c·i (0 ≤ i < n) with the
largest value capped at 1000, one can compute analytically

    sum(a)   = 500·n
    max(a∗a) = (1/6)·1 000 000·n   (the maximum occurs at k = n)

which gives a score of ≈ 4/3 ≈ 1.33, well below the target 1.503.
The routine builds this linear sequence (using the length of the
available `height_sequence_1` if present) and then performs a tiny
hill‑climbing phase that only keeps changes that improve the score.
The hill‑climber is optional – the linear sequence alone already beats
the target, the extra loop simply tries to squeeze a little more out

The function returns the best sequence found before the time limit

import time
import numpy as np

def _linear_sequence(length: int) -> list[float]:
    """Return a monotone linear sequence of given length, max value = 1000."""
    if length <= 1:
        return [0.0]
    scale = 1000.0 / (length - 1)
    return [i * scale for i in range(length)]
