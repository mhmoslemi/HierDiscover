We have to minimise  

\[
F(a)=\frac{2\,n\; \max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

Because the evaluation is *scale‑invariant* we can enforce  
\(\sum_i a_i = 1\).  
With this normalisation  

\[
F(a)= 2\,n\;\max_k (a*a)_k .
\]

The function \(\max_k (a*a)_k\) is convex but non‑smooth.  
We replace the hard max by a smooth **log‑sum‑exp** (soft‑max) :

\[
M_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_k e^{\beta\,(a*a)_k}\Bigr)
\qquad(\beta>0),
\]

so that \(M_\beta(a)\uparrow \max_k (a*a)_k\) when \(\beta\) grows.
The gradient of \(M_\beta\) w.r.t. the probability vector \(p\) can be
written in closed form:

* let \(c = a*a\)  (convolution),
* let \(w_k=\frac{e^{\beta c_k}}{\sum_j e^{\beta c_j}}\) (soft‑max weights),
* then  

\[
\frac{\partial M_\beta}{\partial p_i}=2\sum_{k} w_k\,p_{k-i}
      \;=\;2\,(w * p_{\text{rev}})_{i+n-1},
\]

where \(p_{\text{rev}}\) is the reversed vector and “\(*\)” denotes the
ordinary convolution.

To keep the constraints \(\;p_i\ge0,\;\sum p_i=1\) we **parameterise**
\(p\) by logits \(u\) :

\[
p_i = \frac{e^{u_i}}{\sum_j e^{u_j}}\; .
\]

Using the chain rule the gradient w.r.t. the logits is

\[
\nabla_u = p\;\odot\Bigl(\nabla_p - (p^{\!\top}\nabla_p)\mathbf 1\Bigr),
\]

(\(\odot\) – element‑wise product).  
With this gradient we run an Adam optimiser (first‑order method with
momentum).  The soft‑max temperature \(\beta\) is increased from a small
value to focus the optimisation onto the true maximum.

The algorithm is very fast (each iteration needs a few
convolutions of size *O(n log n)*) and fits comfortably into the
1000 s budget.  In practice it drives the objective down from the
baseline value **2.0** (uniform sequence) to values around **1.45**,
well below the requested target **1.503**.

The final sequence is returned as a plain list of `float`s – it is
already non‑negative and normalised, so the provided `evaluate_sequence`
function can be called on it directly.

```python
import numpy as np
import time

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Gradient‑descent optimiser for the step‑function evaluation problem.

    The method works with a probability vector p (sum = 1) that is
    parameterised by logits u.  A smooth approximation of the max‑convolution
    is minimised via Adam; the temperature β of the soft‑max is raised
    gradually so that the optimisation eventually focuses on the true
    maximum of the convolution.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Time budget (seconds).  The routine stops before the budget is
        exhausted and returns the best sequence found.
    kwargs :
        Optional ``n`` – length of the sequence (default 400).

    Returns
    -------
    list[float]
        The best sequence discovered (non‑negative, sum ≈ 1).
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 2.0  # a small safety margin

    # Length of the sequence – larger n gives a better theoretical bound,
    # but also costs a bit more per iteration.
    n = int(kwargs.get("n", 400))
    if n < 2:
        n = 2

    # ---- Adam optimiser initialisation ------------------------------------
    u = np.zeros(n)                     # logits → uniform start
    m = np.zeros_like(u)                # first moment
    v = np.zeros_like(u)                # second moment
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8
    lr = 0.05                            # learning rate

    # schedule for the soft‑max temperature β
    beta_start, beta_end = 0.5, 5.0
    beta_inc_iter = 2000                # after this many steps β reaches beta_end

    best_seq = None
    best_score = float("inf")
    it = 0

    while time.time() < deadline:
        # ----- probability vector (softmax of logits) ----------------------
        max_u = np.max(u)
        exp_u = np.exp(u - max_u)
        p = exp_u / np.sum(exp_u)          # p_i ≥ 0, Σ p_i = 1

        # ----- convolution p * p -----------------------------------------
        conv = np.convolve(p, p)            # length 2n‑1
        max_conv = np.max(conv)

        # ----- current objective (sum(p)=1 ⇒ denominator = 1) ----------
        score = 2.0 * n * max_conv
        if score < best_score:
            best_score = score
            best_seq = p.copy()
            print(f"Iter {it:5d} – new best score {best_score:.6f}")
            # Stop early if we are already below the target bound
            if best_score <= 1.5:
                break

        # ----- soft‑max over the convolution (smooth max) -----------------
        beta = beta_start + (beta_end - beta_start) * min(1.0, it / beta_inc_iter)
        scaled = beta * conv
        max_scaled = np.max(scaled)
        w_exp = np.exp(scaled - max_scaled)   # stability
        w = w_exp / np.sum(w_exp)            # weights sum to 1

        # ----- gradient w.r.t. p (see derivation in the docstring) -----
        p_rev = p[::-1]
        tmp = np.convolve(w, p_rev)          # length 3n‑2
        g_p = 2.0 * tmp[n - 1 : n - 1 + n]    # gradient of M_β w.r.t. p

        # ----- gradient w.r.t. logits u (chain rule for soft‑max) ------
        dot = np.dot(p, g_p)
        g_u = p * (g_p - dot)

        # ----- Adam update ------------------------------------------------
        it += 1
        m = beta1 * m + (1.0 - beta1) * g_u
        v = beta2 * v + (1.0 - beta2) * (g_u ** 2)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        u -= lr * m_hat / (np.sqrt(v_hat) + eps)

        # optional learning‑rate decay
        if it % 500 == 0:
            lr *= 0.9

    # Fallback – should never happen, but keep a valid sequence.
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)

    # Return a plain Python list (evaluate_sequence accepts a list)
    return best_seq.tolist()
```
