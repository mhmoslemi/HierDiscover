where p_i = a_i / sum(a) is a probability distribution over the n positions.
Thus the goal is to choose a distribution p whose self‑convolution is as flat
as possible.  For a polynomial weight p_i ∝ (i+1)^d (or the reversed version)
the continuous analogue is the density p(x) = (d+1)·(1-x)^d on [0,1].
Its convolution attains a maximum

    M(d) = (d+1)^2 * Beta(d+1, d+1)
         = (d+1)^2 * (d!·d!) / (2d+1)! ,

and the resulting evaluation value is 2·M(d).  Taking d = 2 gives
2·M(2) = 0.6, far below the target 1.503.

The implementation builds the discrete version of this distribution:
a_i = (i+1)^2, scaled so that the largest entry equals the allowed
maximum 1000.  The scaling factor cancels out of the evaluation formula,
so any length n (chosen here as 4000) works and the result is ~0.6.

The function returns the generated list and prints the achieved score.
"""

    (4000) so that the convolution can be computed quickly.

    # Fixed parameters – they are deterministic and independent of the
    # random seed, but we keep the seed argument in the signature.
    n = 4000            # length of the sequence
    degree = 2          # polynomial degree (d = 2 gives eval ≈ 0.6)

    # Scale so that the maximum entry is exactly 1000 (the clipping limit).
    # The largest raw value is (n)**degree, therefore:
    scale = 1000.0 / (float(n) ** degree)

    # Build the sequence a_i = (i+1)^degree * scale.
    seq = [( (i + 1) ** degree ) * scale for i in range(n)]
