Uniform step function search.

The evaluation metric is  

    E(a) = 2·n·max(conv(a,a)) / (sum(a))²,

where `conv` denotes the discrete (zero‑padded) convolution.
For any non‑negative sequence the inequality  

    max(conv(a,a)) ≥ sum(a_i²) ≥ (sum(a))² / n

holds, giving the universal lower bound `E(a) ≥ 2`.  
Uniform sequences (all entries equal) attain this bound with equality,
so they are provably optimal for the given metric.

The `propose_candidate` function therefore returns a uniform sequence.
A tiny random search is performed in the remaining time as a sanity check;
if a (unlikely) better sequence is found it is kept, otherwise the
uniform construction is returned.
"""

def _uniform_sequence(length: int, value: float) -> list[float]:
    """
    Create a uniform sequence of the given length and constant value.
    All entries are converted to float so they satisfy the validator.
    """
    return [float(value)] * length

        best_score = float("inf")

    # -----------------------------------------------------------------
    # 2.  Random exploration (very cheap – only a few hundred trials)
    # -----------------------------------------------------------------
    while time.time() < deadline:
        # random length between 50 and 5000 (inclusive)
        n = np.random.randint(50, 5001)

        # generate a random vector in [0, 1000] – the validator will clip
        # anyway, but staying inside the bounds prevents unnecessary work.
        seq = (np.random.rand(n) * 1000.0).tolist()

        # Evaluate; ignore sequences that raise (should not happen).
        try:
            score = evaluate_sequence(seq)   # type: ignore[name-defined]
        except Exception:    # pragma: no cover
            continue

        # We are minimizing the metric; keep the best.
        if score < best_score:
            best_score = score
            best_seq = seq

            # The theoretical optimum is 2.0; if we ever see something
            # noticeably below that we stop early – this is unlikely.
            if best_score < 1.9:
                break

    # -----------------------------------------------------------------
    # 3.  Return the best sequence discovered.
    # -----------------------------------------------------------------
    print(f"Best score found: {best_score:.6f} (length {len(best_seq)})")
    return best_seq
