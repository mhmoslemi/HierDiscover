The evaluation function  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is *scale invariant*: multiplying a vector `a` by a constant does not change the score.
Hence we may fix the 𝓁₁‑norm of the vector (`∑a_i = 1`) and only minimise the
maximum entry of its *self‑convolution*.

A classical construction uses the coefficients of the generating function  

\[
(1-z)^{-1/2}= \sum_{i\ge0}\frac{\binom{2i}{i}}{4^i}\;z^{i},
\]

because  

\[
\bigl((1-z)^{-1/2}\bigr)^2 = (1-z)^{-1}= \sum_{k\ge0}z^{k},
\]

so for the infinite sequence  

\[
c_i=\frac{\binom{2i}{i}}{4^i}\qquad(i\ge0)
\]

the convolution `c*c` is **exactly constant** (`=1`).  
After normalising `c` to a probability vector the score is

\[
E = \frac{2n}{\bigl(\sum_i c_i\bigr)^2}\;=\;\frac{\pi}{2}\approx1.571 .
\]

The bound we aim at (≈ 1.503) is strictly better, therefore we need a
distribution whose self‑convolution is *almost* constant but with a
slightly smaller peak.  

The program below starts from the optimal “square‑root’’ distribution,
then repeatedly performs a **smooth‑max gradient descent**:

* a soft‑max weight `w` concentrates on the largest convolution entries,
  providing a differentiable surrogate for the max;
* the gradient of the weighted sum `∑ w_k (a*a)_k` w.r.t. `a` is computed
  via a single convolution;
* a multiplicative (exponentiated‑gradient) update keeps the vector
  non‑negative; after each update we project back onto the simplex
  (`∑a_i = 1`);
* the temperature `τ` of the soft‑max is slowly increased so that the
  optimisation focuses more on the true maximum;
* occasional random jitter and (very rare) random restarts avoid stagnation.

The method runs inside the allocated 1000 s, keeps the best sequence found,
and returns it as a plain Python list.

#!/usr/bin/env python3
"""
Propose a step‑function sequence that minimises `evaluate_sequence`.

The algorithm:
  1. Initialise with the coefficients of (1‑z)^(-1/2) (the optimal
     “square‑root’’ distribution).  After normalisation the score is ≈π/2.
  2. Repeatedly minimise a smooth approximation of the max‑convolution
     using exponentiated‑gradient descent.
     * soft‑max weight w_k = exp( τ·(b_k – max(b)) )   (τ grows slowly)
     * gradient  g_i = 2·∑_j a_j·w_{i+j}
       computed efficiently with a single convolution.
     * update a_i ← a_i·exp( –η·g_i ) and renormalise to ∑a_i = 1.
  3. Keep the best sequence seen; add occasional random jitter or a full
     random restart when progress stalls.
The whole search respects the 1000 s budget and returns the best
coefficients found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (all top‑level – required by the platform)
# ----------------------------------------------------------------------


def sqrt_distribution(n: int) -> np.ndarray:
    """Return the normalised coefficients of (1‑z)^(-1/2) up to length n.

    c_0 = 1,  c_{i+1}=c_i·(2i+1)/(2i+2).
    The vector is normalised so that its sum equals 1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        # recurrence  c_{i} = c_{i-1}·(2i‑1)/(2i)
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    a /= a.sum()
    return a


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Project a non‑negative vector onto the probability simplex (sum = 1)."""
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s <= 0.0:
        v[:] = 1.0 / v.size
    else:
        v /= s
    return v


def smooth_max_gradient(a: np.ndarray, tau: float):
    """
    Compute the gradient of  g(a)=∑_k w_k·(a*a)_k  where
    w_k = softmax_τ( (a*a)_k ) .
    Returns (gradient, current max of a*a, full convolution).
    """
    # self‑convolution
    b = np.convolve(a, a)                     # length 2n‑1
    max_b = b.max()

    # soft‑max weights, numerically stable
    w = np.exp(tau * (b - max_b))
    w_sum = w.sum()
    if w_sum == 0.0:
        w = np.full_like(w, 1.0 / w.size)
    else:
        w /= w_sum

    # gradient = 2·∑_j a_j·w_{i+j}
    # Compute via one convolution with the reversed weight vector.
    w_rev = w[::-1]
    conv_rev = np.convolve(a, w_rev)                     # length 3n‑2
    L = b.size
    grad = 2.0 * conv_rev[(L - 1) - np.arange(a.size)]
    return grad, max_b, b

# Main entry point required by the platform
# ----------------------------------------------------------------------
