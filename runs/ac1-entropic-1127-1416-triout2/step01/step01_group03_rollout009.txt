assistantfinal**Solution Explanation**

The score returned by `evaluate_sequence` is  

\[
\text{score}= \frac{2\,n\,\max (a*a)}{(\sum a)^2},
\qquad a\in \mathbb R_{\ge 0}^n .
\]

The expression is *scale‑invariant*: multiplying the whole vector by a constant
c does not change the score.  
Therefore we may **fix the ℓ₁‑norm to 1** (`∑a = 1`).  
With this normalisation  

\[
\text{score}= 2n\;\max (a*a).
\]

Hence the whole problem reduces to **making the maximal entry of the
self‑convolution as small as possible** while keeping the entries non‑negative
and summing to one.

--------------------------------------------------------------------

### 1.  Smooth surrogate of the max‑function  

The true objective `max(b)` (with `b = a*a`) is not differentiable.
We minimise instead the *ℓₚ‑norm* of `b`

\[
F_p(a)=\bigl(\sum_k b_k^{p}\bigr)^{1/p},
\qquad p\ge 2 .
\]

For `p → ∞` the ℓₚ‑norm converges to `max(b)`.  
The gradient of the un‑rooted quantity  

\[
G_p(a)=\sum_k b_k^{p}
\]

is very easy to compute:

* `b = a * a` (self‑convolution)  
* `w_k = b_k^{p-1}` (the weight of each entry)  
* `∂G_p/∂a_i = 2p \sum_j a_j w_{i+j}`  

The last summation is a convolution again, so the whole gradient can be
evaluated with two FFT‑convolutions (`O(n log n)`).  

--------------------------------------------------------------------

### 2.  Mirror / exponentiated gradient update  

All entries must stay non‑negative.  
A mirror‑step on the probability simplex is obtained by the
*exponentiated* update  

\[
a_i^{\text{new}} = a_i\; \exp\!\bigl(-\eta\,\frac{g_i}{\|g\|_\infty}\bigr),
\]

followed by a projection onto the simplex (simple normalisation).  
The division by the maximal absolute gradient makes the step size
independent of the scaling of `g`.

--------------------------------------------------------------------

### 3.  Homotopy on `p` and adaptive step size  

*Start* with a small exponent (`p = 2`) – the landscape is smooth and the
method moves quickly.  
Every few hundred iterations `p` is multiplied by `1.02` (up to a safe
maximum, e.g. `30`).  
In parallel the learning rate `η` is slowly decayed (`η ← η·0.995`).

If the current best score does not improve for a while we inject a tiny
random jitter; after a longer stagnation we **restart** from a fresh random
simplex point (the best sequence found so far is kept).

--------------------------------------------------------------------

### 4.  Whole search strategy  

* one outer loop runs until the time budget is exhausted,
* each outer iteration is a *restart* (random simplex start or the classic
  `(1‑z)^{-1/2}` distribution),
* inside a restart we perform the exponentiated‑gradient steps described
  above,
* the best sequence over **all** restarts is returned.

All heavy work (convolutions, gradients, max‑convolution) uses FFTs,
so even for `n ≈ 2500` millions of iterations easily fit into the 1000 s
budget.

--------------------------------------------------------------------

### 5.  Correctness & Compliance  

* All helper functions are top level – no closures.  
* No file or network I/O.  
* The returned object is a plain Python list of non‑negative floats.  
* The code respects the 1000 s limit using a deadline (`time.time`).  
* `evaluate_sequence` is only called when a *real* score is needed (once per
  improvement) – the program works even if it is unavailable.

--------------------------------------------------------------------

### 6.  Expected performance  

The algorithm is a genuine improvement over the previous soft‑max
exponentiated‑gradient method:

* a tighter surrogate (`ℓₚ` rather than soft‑max) focuses the search on the
  true maximal convolution entries,
* homotopy on `p` gives a smooth start and a sharp final refinement,
* adaptive learning‑rate and occasional restarts avoid being trapped in
  poor local minima.

#!/usr/bin/env python3
"""
Mirror‑gradient optimisation of a step‑function.

The algorithm works with the scale‑invariant formulation
    score = 2·n·max(a*a)  (∑a = 1).

A smooth ℓₚ‑norm surrogate of the max‑operator is minimised.
The gradient is obtained by two FFT‑convolutions, an exponentiated‑gradient
(update on the probability simplex) is applied, and the exponent `p`
is increased slowly (homotopy).  Random restarts and jitter avoid
stagnation.  The best sequence found before the time budget expires is
returned as a plain list.
"""

from __future__ import annotations

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities – all top‑level as required by the platform
# ----------------------------------------------------------------------


def sqrt_distribution(n: int) -> np.ndarray:
    """
    Coefficients of (1‑z)^(-1/2) up to length n, normalised to sum = 1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        # recurrence c_i = c_{i‑1}·(2i‑1)/(2i)
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    a /= a.sum()
    return a


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Project a non‑negative vector onto the probability simplex (sum = 1).
    """
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s <= 0.0:
        # fallback to uniform distribution
        v[:] = 1.0 / v.size
    else:
        v /= s
    return v


def next_pow2(x: int) -> int:
    """Small utility returning the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def fft_convolve(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Real convolution using FFT.  Returns a vector of length len(a)+len(b)-1.
    """
    n = next_pow2(len(a) + len(b) - 1)
    fa = np.fft.rfft(a, n=n)
    fb = np.fft.rfft(b, n=n)
    fc = fa * fb
    c = np.fft.irfft(fc, n=n)
    return c[: len(a) + len(b) - 1]


def max_convolution(a: np.ndarray) -> float:
    """
    Return max(a*a) using an FFT convolution (fast, O(n log n)).
    """
    b = fft_convolve(a, a)
    return float(b.max())


def grad_lp_convolution(a: np.ndarray, p: float) -> tuple[np.ndarray, float]:
    """
    Gradient of G_p(a) = Σ (a*a)_k^p   (the un‑rooted ℓₚ‑norm).
    Returns (gradient, max_b) where max_b = max(a*a).
    """
    # self‑convolution
    b = fft_convolve(a, a)                     # length 2n‑1
    max_b = float(b.max())

    # weights w_k = b_k^{p‑1}  (add a tiny epsilon for numerical stability)
    eps = 1e-12
    w = np.exp((p - 1.0) * np.log(np.maximum(b, eps)))

    # gradient = 2·p·∑_j a_j·w_{i+j}
    # compute via convolution with reversed weight vector
    w_rev = w[::-1]
    conv = fft_convolve(a, w_rev)              # length 3n‑2
    L = b.size                                 # = 2n‑1
    grad = 2.0 * p * conv[L - 1 - np.arange(a.size)]

    return grad, max_b

    exponentiated‑gradient on the simplex is used.  The function respects the
    given time budget and returns the best sequence found.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # small safety margin

    # ------------------------------------------------------------------
    # Choose a problem size.
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:

    # ------------------------------------------------------------------
    # Containers for the overall best solution.
    # ------------------------------------------------------------------
    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Restart loop – we keep trying new initialisations until time runs out.
    # ------------------------------------------------------------------
    restart_counter = 0
    while time.time() < deadline:
        restart_counter += 1
        # ----- initial point ------------------------------------------------
        if restart_counter == 1 and 'height_sequence_1' in globals():
            # use the previously discovered sequence (if any) as a warm start
            a = np.array(height_sequence_1, dtype=np.float64)
            a = project_to_simplex(a)
        elif restart_counter == 2:

            a = sqrt_distribution(n).copy()
        else:
            # later restarts – random simplex point
            a = np.random.rand(n)
            a = project_to_simplex(a)

        # ----- parameters for this run ------------------------------------
        p = 2.0                 # start exponent
        p_max = 30.0
        eta = 0.5               # base learning rate
        min_eta = 0.01
        stagnation = 0

        # ------------------------------------------------------------------
        while time.time() < deadline:

            # --------------------------------------------------------------

                stagnation = 0

            else:
                stagnation += 1

            a = a_new

            # ------------------------------------------------------------------
            # Adaptive schedule
            # ------------------------------------------------------------------
            # increase the ℓₚ exponent slowly (homotopy)
            if iteration % 250 == 0 and p < p_max:
                p = min(p_max, p * 1.02)

            # decay learning rate a little
            if iteration % 500 == 0 and eta > min_eta:
                eta *= 0.995

            # small jitter after a while without improvement
            if stagnation > 800:

                a = project_to_simplex(a + jitter)
                eta = max(min_eta, eta * 0.85)
                stagnation = 0
                print(f"[restart {restart_counter:02d} iter {iteration:06d}] "
                      f"jitter added, eta={eta:.4f}, p={p:.2f}")

            # give up this restart if it stalls for too long
            if stagnation > 5000:
                break

        # ------------------------------------------------------------------
        # End of a restart – continue with a fresh start if time permits
        # ------------------------------------------------------------------
        print(f"[restart {restart_counter}] finished after {iteration} iterations, "
              f"best so far = {best_score:.6f}")

    # ----------------------------------------------------------------------
    # Return the best sequence discovered (as a plain Python list)
    # ----------------------------------------------------------------------
    if best_seq is None:
        # fallback – a uniform distribution (never happens in practice)
        best_seq = np.full(n, 1.0 / n)
        best_score = 2.0 * n * max_convolution(best_seq)

    print(f"[done] overall best score = {best_score:.6f} "
          f"(length={len(best_seq)})")
    return best_seq.tolist()
