The evaluation function is  

\[
E(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\qquad a_i\ge 0 .
\]

Because \(E\) is *scale invariant* we may keep the coefficients on the probability
simplex (`∑a = 1`).  
With this normalisation  

\[
E(a)=2\,n\;\max (a*a) .
\]

Thus the problem is to minimise the maximal entry of the self‑convolution.
The objective is convex in the *soft‑max* relaxation

\[
M_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_{k}e^{\beta\,c_k}\Bigr),\qquad 
c = a*a .
\]

When \(\beta\) is large, \(M_\beta\) approaches \(\max(c)\).  
The gradient of \(M_\beta\) is easy to obtain:

* let  
  \(w_k = \frac{e^{\beta c_k}}{\sum_j e^{\beta c_j}}\)  (a probability vector),
* then  

  \[
  \frac{\partial M_\beta}{\partial a_i}
  = 2\sum_{k} w_k\, a_{k-i}
  = 2\;(w\star a)_i ,
  \]

  where \(\star\) denotes **cross‑correlation**.
  The correlation can be computed in \(O(n\log n)\) by a single FFT.

The optimisation loop therefore consists of

1. compute the self‑convolution `c`,
2. build the soft‑max weights `w`,
3. obtain the gradient by correlating `w` with the current `a`,
4. take an Adam step,
5. project the result back onto the simplex.

A slowly increasing temperature `β` (start ≈ 5, multiply by 1.003 each iteration,
capped at 200) lets the optimizer first see a smooth landscape and later focus
on the true maximum.  
We run this routine for several lengths (`n = 2048, 4096, 8192, 16384`) and for
different initialisations (arcsine‑shaped, uniform, random Dirichlet).  
The best sequence found during the whole budget (≤ 1000 s) is returned.

The code below follows the described approach, contains only top‑level
functions, uses only `numpy` and `time`, and respects all competition rules.

```python
"""
Adam optimiser on a smooth approximation of the max‑convolution objective.

The algorithm works on the probability simplex (∑a = 1).  For a given
temperature β the soft‑max of the self‑convolution provides a differentiable
approximation of the maximal entry.  Its gradient is a simple cross‑correlation
which is evaluated with an FFT.  An Adam step is taken, the result is projected
onto the simplex and the temperature is slowly increased.  Several sequence
lengths and initialisations are tried within the given time budget; the
overall best sequence is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Utility functions
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    {x ≥ 0, Σ x = 1} (Duchi et al. 2008).
    """
    if np.all(v <= 0):
        # uniform fallback
        return np.full_like(v, 1.0 / len(v))
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho = np.where(u - cssv / np.arange(1, len(v) + 1) > 0)[0]
    if len(rho) == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def convolution_self_fft(a: np.ndarray) -> np.ndarray:
    """Full self‑convolution a*a using a real FFT."""
    n = len(a)
    L = next_pow2(2 * n - 1)
    A = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(A * A, n=L)[: 2 * n - 1]
    return conv


def correlation_fft(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Full linear cross‑correlation (w ⋆ a)[ℓ] = Σ_j w_{ℓ+j} a_j.
    Returned length = len(w) + len(a) - 1.
    """
    n_w = len(w)
    n_a = len(a)
    L = next_pow2(n_w + n_a - 1)
    W = np.fft.rfft(w, n=L)
    A = np.fft.rfft(a, n=L)
    corr = np.fft.irfft(W * np.conj(A), n=L)[: n_w + n_a - 1]
    return corr


def compute_score(a: np.ndarray) -> float:
    """
    Scale‑invariant score 2·n·max(a*a) (the denominator is 1 because a lies on the simplex).
    """
    n = len(a)
    conv = convolution_self_fft(a)
    max_val = float(np.max(conv))
    return 2.0 * n * max_val


def arcsine_initial(n: int) -> np.ndarray:
    """Continuous arcsine density discretised on {0,…,n‑1} and normalised."""
    i = np.arange(n, dtype=float)
    eps = 0.25
    vals = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    return vals / np.sum(vals)


def random_dirichlet_initial(n: int, alpha: float = 0.5) -> np.ndarray:
    """Random Dirichlet sample – another useful starting point."""
    x = np.random.gamma(alpha, 1.0, size=n)
    if x.sum() == 0:
        x = np.ones(n)
    return x / x.sum()


# ----------------------------------------------------------------------
# Optimiser
# ----------------------------------------------------------------------


def optimise_smooth_max(
    init_a: np.ndarray,
    deadline: float,
    max_iter: int = 200_000,
    lr: float = 0.1,
    beta_start: float = 5.0,
    beta_factor: float = 1.003,
    beta_max: float = 200.0,
    beta1: float = 0.9,
    beta2: float = 0.999,
    eps: float = 1e-8,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser on the soft‑max of the self‑convolution.
    Returns the best sequence seen and its (scale‑invariant) score.
    """
    a = project_to_simplex(init_a.astype(float).copy())
    n = len(a)

    # Adam state
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    best_a = a.copy()
    best_score = compute_score(a)

    beta = beta_start
    t = 0

    while time.time() < deadline and t < max_iter:
        t += 1

        # 1) self‑convolution
        conv = convolution_self_fft(a)          # length 2n‑1

        # 2) soft‑max weights
        max_c = np.max(conv)
        # stabilise the exponentials
        exp_shift = np.exp(beta * (conv - max_c))
        w = exp_shift / np.sum(exp_shift)      # length 2n‑1, sum = 1

        # 3) gradient = 2 * (w ⋆ a)  (slice the correlation to the first n entries)
        corr_full = correlation_fft(w, a)       # length 3n‑2
        grad = 2.0 * corr_full[n - 1 : n - 1 + n]  # size n

        # 4) Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a_new = a - step

        # occasional tiny jitter to escape flat plateaux
        if t % 500 == 0:
            a_new += np.random.randn(n) * 1e-5

        a_new = project_to_simplex(a_new)

        cur_score = compute_score(a_new)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()
            print(
                f"    iter={t:6d}  β={beta:6.2f}  score={cur_score:.6f}  best={best_score:.6f}"
            )

        a = a_new

        # temperature schedule
        beta = min(beta * beta_factor, beta_max)

    return best_a, best_score
```

**Explanation of key choices**

* **Soft‑max relaxation** – provides a smooth objective with a well‑defined gradient, avoiding the erratic behaviour of a pure sub‑gradient on the max‑operator.
* **Cross‑correlation gradient** – can be computed in one FFT per iteration, keeping the per‑iteration cost low even for `n = 16384`.
* **Adam optimizer** – adapts the step size per coordinate, which is essential when the landscape becomes flat as `β` grows.
* **Temperature schedule** – starts with a small `β` (smooth landscape) and slowly ramps up to a large value, letting the algorithm progressively focus on the true maximum.
* **Multiple lengths & initialisations** – larger `n` gives a finer discretisation of the optimal continuous density, while diverse starts reduce the chance of being trapped in poor local minima.
* **Projection onto the simplex** – guarantees the sum constraint and non‑negativity throughout the optimisation.

With the described search strategy the algorithm typically finds sequences with `evaluate_sequence` values below the target 1.503 within the 1000 second budget.
