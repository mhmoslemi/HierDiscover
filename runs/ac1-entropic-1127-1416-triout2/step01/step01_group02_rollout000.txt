The evaluation function  

\[
E(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}
\]

is *scale‑invariant*: multiplying the whole vector by a constant does **not**
change the value.  Hence we can normalise the sequence to have a unit
\(L_1\)‑norm (`sum = 1`) and the problem reduces to **minimising the
maximum entry of the auto‑convolution**.

The well‑known “binomial” construction (central binomial coefficients)
gives a constant convolution value `≈ 1` and a score of `π/2 ≈ 1.571`.
To beat this bound we need a shape whose convolution is *slightly flatter*,
i.e. whose largest entry is a little below 1 while the total mass stays
the same.

The code below

1. builds the binomial sequence,
2. normalises it to sum = 1,
3. repeatedly performs a **projected gradient step** that reduces the
   contribution of the current maximal convolution entry,
4. interleaves tiny random mass‑transfer perturbations (simulated‑annealing
   style) to escape flat plateaus,
5. keeps the best vector found during the whole 1000 s budget.

All operations respect the required non‑negativity and the
`evaluate_sequence` security checks.  The algorithm is entirely
self‑contained, uses only `numpy`, and prints progress information.

```python
"""
propose_candidate
-----------------
Gradient‑descent / simulated‑annealing search for a non‑negative step‑height
sequence that minimises

    2 * n * max(a * a) / (sum(a) ** 2)

where *a* is the height vector and `*` denotes linear convolution.
The method starts from the classical central‑binomial (C(2k,k)/4**k)
construction, normalises the vector to unit L1‑norm (the objective is
scale‑invariant), and iteratively reduces the maximal convolution entry.
A projected gradient step (zero‑sum direction, projection onto the simplex)
moves mass away from the positions that contribute most to the current
maximum; occasional random pair‑wise transfers add stochasticity and help
escape local minima.  The best sequence seen within the allotted time is
returned as a plain Python list.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
def binomial_sequence(length: int) -> np.ndarray:
    """
    Return the first *length* central‑binomial coefficients
    c_k = C(2k, k) / 4**k, k = 0 … length‑1.
    They satisfy   c_0 = 1,
    c_{k+1} = c_k * ((2k+1)(2k+2)) / (4 (k+1)^2).
    """
    seq = np.empty(length, dtype=np.float64)
    seq[0] = 1.0
    for k in range(1, length):
        seq[k] = seq[k - 1] * ((2 * k - 1) * (2 * k)) / (4.0 * k * k)
    return seq


# ----------------------------------------------------------------------
def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a non‑negative vector onto the probability simplex
    (non‑negative, sum = 1).  Simple clipping + renormalisation works because
    after clipping we still have a strictly positive sum (unless the vector is
    all zeros, which we handle separately).
    """
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s == 0.0:
        # fallback to a uniform distribution
        return np.full_like(v, 1.0 / len(v))
    return v / s


# ----------------------------------------------------------------------
def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> list[float]:
    """
    Search for a step‑function height sequence that (heuristically) minimises
    the provided evaluate_sequence function.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Time budget in seconds; the function returns as soon as the budget
        is exhausted (or a little before to be safe).

    Returns
    -------
    list[float]
        The best sequence found within the time limit.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.1   # safety margin

    # ------------------------------------------------------------------
    # Length of the sequence – use the length of the supplied construction if
    # it exists, otherwise fall back to a generous default.
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 8000   # a larger length gives more degrees of freedom

    # ------------------------------------------------------------------
    # Initialise from the optimal (continuous) binomial coefficients.
    a = binomial_sequence(n).astype(np.float64)
    a = a / a.sum()          # normalise to unit L1‑norm (scale invariance)

    # Compute the initial score (will be ~π/2).
    b = np.convolve(a, a)
    cur_max = b.max()
    cur_score = 2.0 * n * cur_max / (a.sum() ** 2)   # sum(a) == 1 -> 2*n*max
    best_seq = a.copy()
    best_score = cur_score

    print(f"[init] length={n}, initial score={best_score:.9f}")

    # ------------------------------------------------------------------
    # Parameters for the gradient descent / simulated annealing loop.
    step_size = 0.12               # initial step for the projected gradient
    step_decay = 0.9997            # exponential decay of the step
    min_step = 1e-5                # never go below this
    iter_cnt = 0
    last_improve = time.time()

    # Main optimisation loop
    while time.time() < deadline:
        # --------------------------------------------------------------
        # 1.  Compute convolution and locate the (set of) maximal entries.
        b = np.convolve(a, a)
        max_val = b.max()
        cur_score = 2.0 * n * max_val   # sum(a) == 1

        # keep the best ever seen
        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[improve] iter={iter_cnt}, score={best_score:.9f}, "
                  f"time={time.time() - (deadline - budget_s):.2f}s")
            last_improve = time.time()

        # --------------------------------------------------------------
        # 2.  Gradient of the maximal convolution entry.
        #    We collect all indices where b is (numerically) maximal.
        tol = max_val - 1e-14          # tiny absolute tolerance
        max_indices = np.flatnonzero(b >= tol)

        #   g_i = Σ_{k∈max} a_{k-i}  (only the part that changes when a_i varies)
        g = np.zeros_like(a)
        for k in max_indices:
            lo = max(0, k - (n - 1))
            hi = min(n - 1, k)
            idx = np.arange(lo, hi + 1)
            g[idx] += a[k - idx]       # a_{k-i}

        #   Zero‑sum direction: d = -g + (sum(g)/n) * 1
        sum_g = g.sum()
        d = -g + (sum_g / n)

        # --------------------------------------------------------------
        # 3.  Projected gradient step (maintain non‑negativity, keep sum=1).
        a_candidate = a + step_size * d
        a_candidate = np.maximum(a_candidate, 0.0)
        a_candidate = project_to_simplex(a_candidate)

        # --------------------------------------------------------------
        # 4.  Occasionally inject a tiny random mass‑transfer (simulated‑annealing).
        if np.random.rand() < 0.001:          # ~once per 1000 iterations
            i, j = np.random.randint(0, n, size=2)
            if i != j and a_candidate[i] > 0.0:
                # move a small fraction from i to j
                amount = 0.02 * np.random.rand() * a_candidate[i]
                a_candidate[i] -= amount
                a_candidate[j] += amount
                a_candidate = project_to_simplex(a_candidate)

        # --------------------------------------------------------------
        # 5.  Accept the candidate (always) because the projection already
        #     guarantees a valid point; we keep the old point only if we want
        #     a Metropolis criterion – here we accept unconditionally to stay
        #     simple (the gradient points downhill in most cases).
        a = a_candidate

        # --------------------------------------------------------------
        # 6.  Decay the step size, but never let it vanish completely.
        step_size = max(min_step, step_size * step_decay)

        iter_cnt += 1

    # ------------------------------------------------------------------
    print(f"[final] best score={best_score:.9f}, iterations={iter_cnt}")
    # The evaluation function clips values to [0,1000] anyway; our numbers are
    # far smaller, so the returned list is safe.
    return best_seq.tolist()
```
