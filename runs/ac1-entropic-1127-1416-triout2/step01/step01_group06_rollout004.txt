Iterative LP‑based refinement for the step‑function problem.

The algorithm follows the scheme described in the statement:

1. Fix a length `n` and a target `ℓ = sqrt(2n)`.  All iterates are
   renormalised to have ℓ as ℓ₁‑sum (the evaluation function then returns
   the maximal auto‑convolution value, i.e. the objective itself).

2. Given the current vector `f` we compute its largest convolution value
   `M = max(f * f)`.  We then maximise `∑ g_i` under the linear constraints
   `f * g ≤ M` (convolution is linear in `g`).  The linear programme is
   solved with `scipy.optimize.linprog` (HDHS solver).

3. The optimal `g` is rescaled to the prescribed sum `ℓ` and mixed with
   `f` (`f ← (1‑t) f + t g`).  Because `g` respects the bound `M`,
   the mixed sequence has a strictly smaller maximal auto‑convolution.
   Repeating the step drives the objective down.

The routine stops when the time budget is exhausted or when no further
improvement is observed for a few iterations.  The best sequence encountered
is returned.
"""

def _make_initial_sequence(n, seed=0):
    """Create a smooth, strictly positive decreasing start vector."""
    rng = np.random.RandomState(seed)
    # Exponential decay with a random rate
    rate = rng.uniform(0.001, 0.02)
    a = np.exp(-rate * np.arange(n, dtype=float))
    # add a tiny constant to avoid exact zeros (important for the LP)
    a += 1e-12
    return a


def _max_convolution(x):
    """Return max of the full convolution of x with itself."""
    return np.max(np.convolve(x, x))


def _build_constraint_matrix(f):
    """
    Build the matrix A (shape (2n‑1, n)) such that A @ g = f * g (full convolution).
    Each row corresponds to one lag k and contains the coefficients f_i that
    multiply g_{k‑i} (zero outside the index range).
    """
    n = f.size
    rows = 2 * n - 1
    A = np.zeros((rows, n), dtype=np.float64)

    # column i contributes to rows i .. i+n‑1 with coefficient f_i
    for i, fi in enumerate(f):
        A[i:i + n, i] = fi
    return A

                for i in idxs:
                    factor = 1.0 + random.gauss(0.0, 0.08)
                    cand[i] = max(0.0, cand[i] * factor)
                mx = cand.max()
                if mx > 0:
                    cand = cand / mx
                cand = cand.tolist()
                sc = _score(cand)
                if sc < best_score:
                    best_score, best_seq = sc, cand
                    print(f"Hill‑climb improvement → {best_score:.6f}")
                continue

            n = int(random.choice(lengths))
            family = random.choice(['exp', 'pow', 'lin', 'mix', 'log', 'randdec'])

            if family == 'exp':
                log_a = random.uniform(-4, math.log10(5))
                alpha = 10 ** log_a
                cand = np.exp(-alpha * np.arange(n, dtype=float))
            elif family == 'pow':
                p = random.uniform(0.0, 3.0)
                idx = np.arange(1, n + 1, dtype=float)
                cand = idx ** (-p)
            elif family == 'lin':
                beta = random.uniform(0.0, 2.0 / n)
                cand = np.maximum(0.0, 1.0 - beta * np.arange(n, dtype=float))
            elif family == 'mix':
                log_a = random.uniform(-4, math.log10(5))
                alpha = 10 ** log_a
                eps = random.uniform(0.0, 0.5)
                cand = np.exp(-alpha * np.arange(n, dtype=float)) + eps
            elif family == 'log':
                steep = random.uniform(0.01, n / 2.0)
                i = np.arange(n, dtype=float)
                mid = n / 2.0
                cand = 1.0 / (1.0 + np.exp((i - mid) / steep))
            else:  # randdec
                arr = np.random.rand(n)
                arr.sort()
                cand = arr[::-1]

            # normalise max to 1 (scale‑invariant)
            mx = np.max(cand)
            if mx > 0:
                cand = cand / mx
            sc = _score(cand.tolist())
            if sc < best_score:
                best_score, best_seq = sc, cand.tolist()
                print(f"New best ({family}) n={n} → {best_score:.6f}")

        if best_seq is None:
            best_seq = [1.0] * 500
            best_score = _score(best_seq)

    # ------------------------------------------------------------------
    # Final report
    # ------------------------------------------------------------------
    print(f"Finished search – best score {best_score:.6f} (len={len(best_seq)})")
    # Ensure the returned list is plain Python floats
    return [float(x) for x in best_seq]
