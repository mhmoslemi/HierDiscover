Projection onto simplex:

```
def project_simplex(v):
    # v: numpy array
    # returns projection onto {x >=0, sum=1}
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n+1)
    cond = u - cssv / ind > 0
    rho = ind[cond].max()
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0)
    return w
```

assistantfinal**Solution Overview**

The task is to minimise  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\left(\sum_i a_i\right)^2},
\qquad a_i\ge 0 .
\]

Because the objective is *scale‑invariant* we may normalise the vector to
\(\sum_i a_i=1\).  Then  
\(E(a)=2\,n\;\max_k (a*a)_k\) and the problem becomes

* minimise the maximum entry of the self‑convolution of a non‑negative
  vector on the simplex.

The classic construction \(a_k=\binom{2k}{k}/4^k\) makes the first `n`
convolution entries equal to a constant, giving the limit \(E=\pi/2\approx
1.571\).  The exact optimum is known to be smaller (≈ 1.503).  
We therefore search for a better shape using a *smooth approximation of the
max* and projected gradient descent on the simplex.

--------------------------------------------------------------------
Key ideas
--------------------------------------------------------------------
1. **Smooth max** – replace `max(conv)` by the log‑sum‑exp
   \[
   \Phi_\alpha(\mathbf{c})=\frac{1}{\alpha}\log\Bigl(\sum_k e^{\alpha
   c_k}\Bigr) .
   \]
   For large `α` this converges to the true max, but for moderate `α`
   it is differentiable.

2. **Gradient** – using the chain rule
   \[
   \frac{\partial \Phi_\alpha}{\partial a_i}=2\sum_k w_k\,a_{k-i},
   \qquad
   w_k=\frac{e^{\alpha c_k}}{\sum_j e^{\alpha c_j}} .
   \]
   The sum is a *cross‑correlation* of `a` and the weight vector `w`.
   Both the convolution `c = a*a` and the correlation are computed with
   FFTs, i.e. in `O(n log n)` time.

3. **Projection onto the simplex** – after a gradient step we project
   back onto \(\{a\ge0,\;\sum a=1\}\) using the standard `O(n)` algorithm.

4. **Annealing of `α`** – we start with `α≈0` (almost uniform weights)
   and increase it slowly up to a few thousand.  This lets the optimizer
   first smooth‑out the whole convolution and later focus on the true
   maximum.

5. **Momentum & occasional jitter** – a classic Nesterov‑style momentum
   accelerates convergence; tiny random perturbations break possible
   stagnation.

The whole optimisation runs inside the given time budget (default 1000 s)
and keeps the best vector seen.  Finally the vector is returned as a
plain Python list – ready for `evaluate_sequence`.

--------------------------------------------------------------------
```python
"""
Smooth‑max gradient descent on the simplex to minimise the
self‑convolution maximum (the evaluation function).

The algorithm:
    * initialise with the classic constant‑convolution coefficients,
      normalised to sum = 1.
    * repeatedly
        – compute the convolution a*a (FFT)
        – build a soft‑max weight vector w over the convolution entries
        – obtain the gradient of the smooth max (correlation a⋆w)
        – take a projected gradient step with a decaying step size
          and a momentum term
        – slowly increase the soft‑max temperature α (annealing)
    * keep the best vector (lowest 2·n·maxconv) and return it.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _constant_conv_base(n: int) -> np.ndarray:
    """First n terms of a_k = C(2k,k) / 4**k (central binomial / 4^k)."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for k in range(1, n):
        # recurrence a_k = a_{k-1} * (1 - 1/(2k))
        a[k] = a[k - 1] * (1.0 - 1.0 / (2.0 * k))
    return a


def _next_pow_two(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _project_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex
    {x | x_i ≥ 0, sum_i x_i = 1}.
    """
    n = v.shape[0]
    u = np.sort(v)[::-1]          # sort descending
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are zero – return the uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond].max()
    theta = cssv[cond].max() / rho
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function (list of heights) that
    minimises `evaluate_sequence`.  The routine is bounded by `budget_s`
    seconds and returns the best sequence found.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # safety margin

    # ------------------------------------------------------------------
    # Choose the length of the sequence.
    # ------------------------------------------------------------------
    if "height_sequence_1" in globals() and isinstance(
        height_sequence_1, (list, tuple, np.ndarray)
    ):
        n = len(height_sequence_1)
    else:
        n = 2000                     # a safe default, fast enough for many iterations

    # ------------------------------------------------------------------
    # Initial vector – classic constant‑convolution coefficients.
    # ------------------------------------------------------------------
    base = _constant_conv_base(n).astype(np.float64)
    a = base / base.sum()           # normalise to L1 = 1

    # keep the best solution seen so far
    conv_full = np.convolve(a, a)
    best_score = 2.0 * n * conv_full.max()
    best_seq = a.copy()
    print(f"Initial length {n}, initial score {best_score:.6f}")

    # ------------------------------------------------------------------
    # Parameters for the optimisation
    # ------------------------------------------------------------------
    it = 0
    step0 = 0.5                     # initial step size (will decay)
    beta = 0.9                      # momentum coefficient
    momentum = np.zeros_like(a)

    alpha = 0.0                     # smooth‑max temperature
    alpha_max = 5000.0              # final temperature (≈ max‑like)
    alpha_inc = 0.5                 # increase per iteration (linear schedule)

    # FFT length (next power of two covering a*a)
    conv_len = 2 * n - 1
    fft_len = _next_pow_two(conv_len)

    # ------------------------------------------------------------------
    # Main optimisation loop
    # ------------------------------------------------------------------
    while time.time() < deadline:
        # --------------------------------------------------------------
        # 1) convolution a * a (FFT)
        # --------------------------------------------------------------
        A = np.fft.rfft(a, fft_len)
        conv = np.fft.irfft(A * A, fft_len)[:conv_len]

        # --------------------------------------------------------------
        # 2) soft‑max weights over the convolution entries
        # --------------------------------------------------------------
        #   w_k = exp(α·c_k) / Σ exp(α·c_j)
        scaled = conv * alpha
        max_scaled = scaled.max()
        # subtraction prevents overflow
        exp_scaled = np.exp(scaled - max_scaled)
        w = exp_scaled / exp_scaled.sum()

        # --------------------------------------------------------------
        # 3) gradient of the smoothed max (cross‑correlation a ⋆ w)
        # --------------------------------------------------------------
        a_rev = a[::-1]                         # reversed a
        W = np.fft.rfft(w, fft_len)
        A_rev = np.fft.rfft(a_rev, fft_len)
        corr = np.fft.irfft(W * A_rev, fft_len)  # length fft_len
        grad = 2.0 * corr[n - 1 : n - 1 + n]      # slice the needed part

        # --------------------------------------------------------------
        # 4) momentum update and projected gradient step
        # --------------------------------------------------------------
        momentum = beta * momentum + (1.0 - beta) * grad
        step = step0 / np.sqrt(it + 1.0)          # classic 1/√t decay
        a_new = a - step * momentum

        # projection onto the simplex (non‑negative, sum = 1)
        a = _project_simplex(a_new)

        # --------------------------------------------------------------
        # 5) occasional tiny random jitter to escape plateaus
        # --------------------------------------------------------------
        if it % 5000 == 0 and it > 0:
            jitter = np.random.randn(n) * 1e-6
            a = _project_simplex(a + jitter)

        # --------------------------------------------------------------
        # 6) evaluate current objective (exact max, not the smooth version)
        # --------------------------------------------------------------
        conv_full = np.convolve(a, a)
        cur_max = conv_full.max()
        cur_score = 2.0 * n * cur_max

        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            print(
                f"Iter {it:8d}: improved score {best_score:.6f} "
                f"(maxconv={cur_max:.8f}, α={alpha:.1f})"
            )

        # --------------------------------------------------------------
        # 7) anneal α (increase the temperature)
        # --------------------------------------------------------------
        if alpha < alpha_max:
            alpha = min(alpha_max, alpha + alpha_inc)

        it += 1

    # ------------------------------------------------------------------
    # Final sanity check using the provided evaluate_sequence
    # ------------------------------------------------------------------
    try:
        final_score = evaluate_sequence(best_seq.tolist())
        print(f"Final reported score by evaluate_sequence: {final_score:.6f}")
    except Exception:
        final_score = best_score
    print(f"Search finished after {it} iterations, best score {best_score:.6f}")

    return best_seq.tolist()
```
