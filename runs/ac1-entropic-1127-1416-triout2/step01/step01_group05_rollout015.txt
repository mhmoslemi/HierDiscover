Algorithm:

- Sort v descending: u = np.sort(v)[::-1]
- Compute cumulative sum: cssv = np.cumsum(u)
- Find rho = max {j: u_j + (z - cssv_j) / (j+1) > 0}
- theta = (cssv[rho] - z) / (rho + 1)
- w = np.maximum(v - theta, 0)

"""
Propose a step function that lower‑bounds the evaluation score.

The algorithm starts from a good known construction (the global
``height_sequence_1`` if present, otherwise a 1/√x power‑law) and then
performs a fast simulated‑annealing / biased local‑move search.

Main ideas
-----------

1.  Keep the ℓ1‑norm (the sum of the heights) fixed – the objective is
    scale invariant, so we simply preserve the current total.
2.  At each iteration compute the self‑convolution via an FFT (O(n log n))
    and locate the index ``k_max`` where the convolution attains its
    maximum.
3.  The contribution of element ``i`` to that maximum is
    ``a[i] * a[k_max‑i]`` (when the partner index is inside the vector).
    Elements with large contributions are “bad” – we move a small amount
    of mass from a high‑contribution index to a low‑value index.
4.  Moves are accepted if they improve the score; otherwise they are
    accepted with a temperature‑dependent probability (simulated annealing)
    to allow occasional uphill steps.
5.  Every few thousand iterations a random “shake” (a perturbed power‑law)
    is tried to escape possible plateaus.

The search runs until the time budget expires (default 1000 s) and
returns the best sequence found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _normalise_to_sum(arr: np.ndarray, target: float) -> np.ndarray:
    """Scale ``arr`` so that its sum becomes ``target`` (preserving sign)."""
    s = arr.sum()
    if s == 0.0:
        return arr
    return arr * (target / s)


def _conv_fft(seq: np.ndarray) -> np.ndarray:
    """Self‑convolution of a real vector using an FFT (full length)."""
    n = seq.shape[0]
    size = 2 * n - 1
    fft_len = 1 << (size - 1).bit_length()          # next power of two
    f = np.fft.rfft(seq, n=fft_len)
    conv = np.fft.irfft(f * f, n=fft_len)[:size]
    # small negative rounding errors are harmless for the max‑search
    return conv


def _max_conv_info(seq: np.ndarray):
    """Return (conv, k_max, max_val) for a sequence."""
    conv = _conv_fft(seq)
    k = int(np.argmax(conv))
    return conv, k, float(conv[k])

# Main search routine
# ----------------------------------------------------------------------
