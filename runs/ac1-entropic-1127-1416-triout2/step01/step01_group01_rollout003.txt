The score of a step‑function `a = (a₀,…,a_{n‑1})` is  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2}.
\]

If we normalise the vector so that `sum(a)=1` the denominator disappears and the
score reduces to  

\[
\text{score}(a)=2\,n\;\max_k (a*a)_k .
\]

Thus we have to **flatten the self‑convolution** of a non‑negative
vector with unit sum.  

The algorithm below consists of two phases

1. **Random sparse‑support exploration** –  
   Choose a random set `S ⊂ {0,…,n‑1}` of size `m` and put the same
   weight `1/m` on the selected positions.  
   For a sparse support the number of ordered pairs `(i,j)∈S×S`
   that produce a given sum `k` is close to its mean
   `m²/(2n‑1)`, i.e. almost uniform.  
   A moderate support size (`m ≈ 600 … 1200` for `n≈5·10³`) gives scores
   well below the target `1.503`.

2. **Projected sub‑gradient refinement** –  
   Starting from the best random candidate we repeatedly
   * compute the index `k⁎` where the convolution attains its maximum,
   * build the sub‑gradient of that maximum entry,
   * take a step in the opposite direction,
   * project back onto the simplex `{a_i ≥ 0 , Σ a_i = 1}`.

   The projection is the Euclidean projection onto the probability simplex
   (Duchi *et al.* 2008) and guarantees feasibility after every step.

Both phases are cheap: a convolution is performed with an FFT
(`O(n log n)`) and the whole search finishes well inside the 1000 s budget.

"""Search for a step function with a small self‑convolution peak.

The routine combines a random sparse‑support search (uniform heights on a
randomly chosen subset of indices) with a projected sub‑gradient descent
that minimises 2·n·max(conv) under the simplex constraint.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top‑level – no closures)
# ----------------------------------------------------------------------


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
        { w | w_i ≥ 0 , Σ w_i = 1 }.

    Implementation follows Duchi, Shalev‑Shwartz, Singer & Chandra (2008).
    """
    n = v.shape[0]
    if n == 0:
        return v
    # sort v in decreasing order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    # find the last index where the condition holds
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are non‑positive → return uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1               # zero‑based index
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def objective_on_simplex(a: np.ndarray, n: int) -> float:
    """
    Return 2·n·max(a*a) for a vector `a` with Σ a = 1.
    The convolution is computed with an FFT (real‑valued) for speed.
    """
    # real FFT of length 2*n-1
    fft = np.fft.rfft(a, n=2 * n - 1)
    conv = np.fft.irfft(fft * fft, n=2 * n - 1)
    max_b = conv.max()
    return 2.0 * n * max_b


def subgradient_of_max_conv(a: np.ndarray, n: int, k_max: int) -> np.ndarray:
    """
    Sub‑gradient of the entry `conv[k_max] = max_i (a*a)[i]` with respect to `a`.
    For each index `i` that participates in the sum `i + j = k_max` we have
    ∂conv[k_max]/∂a_i = 2 * a_j.
    """
    g = np.zeros_like(a)
    low = max(0, k_max - n + 1)
    high = min(n - 1, k_max)
    idx = np.arange(low, high + 1)
    partner = k_max - idx
    # each ordered pair contributes, hence factor 2
    g[idx] = 2.0 * a[partner]
    return g

# Main search routine
# ----------------------------------------------------------------------

    """
    Find a sequence of non‑negative heights (list of floats) that minimises
    ``evaluate_sequence``.  The algorithm works in two stages:
    1. Random sparse support vectors with equal heights on the chosen indices.
    2. A short projected sub‑gradient descent starting from the best random
       candidate.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : int
        Time budget in seconds (the function will stop a few seconds before
        the limit to avoid a forced termination).

    Returns
    -------
    list[float]
        The best sequence discovered, normalised to sum ≈ 1.
    """
    np.random.seed(seed)
    # ------------------------------------------------------------------
    # 0. Time handling
    # ------------------------------------------------------------------
    safety = 5.0                      # seconds reserved for returning the result
    deadline = time.time() + budget_s - safety

    # ------------------------------------------------------------------
    # 1. Problem size
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)   # type: ignore[name-defined]
    except Exception:
        n = 5146                       # fallback from the prompt

    # ------------------------------------------------------------------

    # ------------------------------------------------------------------
    a_ramp = np.arange(n, 0, -1, dtype=float)          # n, n‑1, …, 1
    a_ramp = 2.0 * a_ramp / (n * (n + 1))              # Σ a = 1
    best_a = a_ramp.copy()
    best_score = objective_on_simplex(best_a, n)
    print(f"[init] linear ramp score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Random sparse‑support search
    # ------------------------------------------------------------------
    # Choose a sensible interval for the support size m.
    # Empirically m ≈ 0.05·n … 0.30·n works well for n≈5k.
    m_low = max(200, n // 20)          # at least 200 or 5 % of n

    if m_low > m_high:                 # extremely small n – fallback
        m_low = max(2, n // 10)
        m_high = n

    rand_iter = 0

    while time.time() < deadline and rand_iter < 20000:

    a = best_a.copy()

        step = 0.5 / math.sqrt(sg_iter + 1)

            best_a = a.copy()
            print(f"[sg {sg_iter:5d}] improved = {best_score:.6f}")

        sg_iter += 1

    print(f"[sg] finished after {sg_iter} iterations, final best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Return the best sequence as a plain Python list
    # ------------------------------------------------------------------
    # ``evaluate_sequence`` will later clamp values to [0,1000] – our values are
    # already in that interval (they are ≤ 1).
    return [float(v) for v in best_a.tolist()]
