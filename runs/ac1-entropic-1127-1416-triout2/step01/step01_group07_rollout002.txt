assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max_k (a*a)[k]}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge0 .
\]

The objective is *scale‑invariant*: multiplying the whole vector by a constant does not change the value.  
Hence we can enforce the normalisation  

\[
\sum_i a_i = S:=\sqrt{2n},
\]

and then simply try to make the *maximum* entry of the self‑convolution as small as possible.

The previous code used a sub‑gradient on the exact maximum.  
Here we improve the optimisation in three ways

| improvement | why it helps |
|-------------|--------------|
| **Soft‑max re‑parameterisation** `a = S·softmax(w)`  | guarantees non‑negativity and the sum‑constraint *exactly* – no separate projection step is needed. |
| **Smoothed max (log‑sum‑exp)** with an annealing parameter `β` | turns the max‑functional into a smooth objective, allowing true gradients (instead of sub‑gradients) and much more stable optimisation. |
| **Adam optimiser** on the logits `w` | adaptive step sizes per coordinate → faster convergence and easier escape from plateaus. |

The algorithm proceeds as follows:

1. **Initialisation** – try to use the best sequence found so far (`height_sequence_1`), otherwise fall back to a geometric seed. Convert the seed to logits `w = log(a+ε)`.
2. **Iterative optimisation** (until the time budget expires)  

   * compute `a = S·softmax(w)`  
   * obtain the convolution `c = a * a` by FFT ( O(n log n) )  
   * form the smoothed max distribution `p_i = exp(β c_i) / Σ exp(β c)`  
   * gradient w.r.t. `a` : `∇_a F_s = 2 · corr(p, a)` (valid‑mode correlation)  
   * chain‑rule to get the gradient w.r.t. `w` : `∇_w F_s = a · (∇_a F_s – avg)` where `avg = (a·∇_a F_s)/S`  
   * Adam update of `w`  
   * slowly increase `β` (annealing) so that the optimisation starts smooth and ends with an accurate approximation of the true max.
3. Every few iterations we evaluate the *exact* score  
   \[
   \text{score}= \frac{2\,n\;\max(c)}{(\sum a)^2}
   \]  
   and keep the best sequence seen so far.
4. Return the best sequence (as a plain list) when the time limit is reached.

The method works for any `n`; we use `n = 5000` (still fast, but gives the optimiser more freedom than the previous `n = 3000`).  
All operations are vectorised, the FFT length is the next power‑of‑two, and the code never writes to the file‑system.

```python
"""
Propose a candidate step‑function that minimises

    2·n·max(a*a) / (sum(a)**2)

using a soft‑max re‑parameterisation, a smoothed max (log‑sum‑exp) and
the Adam optimiser.  The algorithm respects the non‑negativity and
normalisation constraints by construction, runs under the supplied time
budget and returns the best sequence found.
"""

import time
import numpy as np

# --------------------------------------------------------------------------- #
# Helper: soft‑max that also returns the normalised vector a = S·softmax(w)
def softmax_scaled(w: np.ndarray, scale: float) -> np.ndarray:
    """Return scale * softmax(w) with numerically stable exponentiation."""
    w_shift = w - np.max(w)          # stability
    e = np.exp(w_shift)
    return scale * (e / e.sum())

# --------------------------------------------------------------------------- #
def propose_candidate(seed: int = 42, budget_s: float = 1000, **kwargs):
    """
    Search for a low‑score non‑negative step function.

    Parameters
    ----------
    seed : int
        Random seed for reproducibility.
    budget_s : float
        Time budget in seconds.

    Returns
    -------
    list[float]
        The best sequence discovered within the time limit.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 0.1          # safety margin

    # --------------------------------------------------------------- #
    # 1. Problem size
    n = 5000                                   # longer than the previous run
    S = np.sqrt(2.0 * n)                       # exact normalisation

    # --------------------------------------------------------------- #
    # 2. Initialise logits w -------------------------------------------------
    # Try to reuse the best known construction (global variable)
    init_a = None
    seq1 = globals().get("height_sequence_1")
    if seq1 is not None:
        a1 = np.asarray(seq1, dtype=float)
        if a1.size < n:
            a1 = np.concatenate([a1, np.zeros(n - a1.size)])
        elif a1.size > n:
            a1 = a1[:n]
        a1 = np.clip(a1, 0.0, 1000.0)
        if a1.sum() == 0.0:
            a1 = np.full(n, S / n)
        else:
            a1 = a1 * (S / a1.sum())
        init_a = a1

    if init_a is None:
        # geometric seed a_i = C * r**i  (r very close to 1)
        r = 0.9995
        r_n = r ** n
        denom = 1.0 - r_n
        C = S * (1.0 - r) / denom
        init_a = C * (r ** np.arange(n))

    eps = 1e-12
    w = np.log(init_a + eps)          # logits – softmax will recover init_a

    # --------------------------------------------------------------- #
    # 3. Optimisation hyper‑parameters
    beta = 1.0                         # start of the log‑sum‑exp smoothing
    beta_max = 20.0
    beta_inc = (beta_max - beta) / 3000.0   # linear schedule

    lr = 0.1                           # base learning rate for Adam
    beta1, beta2 = 0.9, 0.999
    eps_adam = 1e-8

    m = np.zeros_like(w)
    v = np.zeros_like(w)

    # FFT length (next power of two ≥ 2*n‑1)
    fft_len = 1 << ((2 * n - 1).bit_length())

    best_a = None
    best_score = float("inf")
    it = 0

    # --------------------------------------------------------------- #
    while time.time() < deadline:
        # ---- a = softmax(w) -------------------------------------------------
        a = softmax_scaled(w, S)            # a_i ≥ 0, Σ a_i = S up to rounding

        # ---- convolution a*a (FFT) -----------------------------------------
        F = np.fft.rfft(a, n=fft_len)
        conv = np.fft.irfft(F * F, n=fft_len)[: 2 * n - 1]

        # ---- smoothed max ---------------------------------------------------
        # p_i ∝ exp(β·conv_i)
        beta_conv = beta * conv
        max_bc = np.max(beta_conv)
        exp_bc = np.exp(beta_conv - max_bc)          # safe exp
        p = exp_bc / exp_bc.sum()                    # probability on conv entries

        # ---- gradient w.r.t. a (valid‑mode correlation) --------------------
        #   ∇_a = 2 * corr(p, a)   → length n
        grad_a = 2.0 * np.correlate(p, a, mode='valid')

        # ---- chain rule to obtain ∇_w ---------------------------------------
        avg = np.dot(a, grad_a) / S                  # (a·∇_a)/S
        grad_w = a * (grad_a - avg)                  # shape (n,)

        # ---- Adam update ----------------------------------------------------
        it += 1
        m = beta1 * m + (1.0 - beta1) * grad_w
        v = beta2 * v + (1.0 - beta2) * (grad_w ** 2)
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)
        w -= lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        # ---- occasional random jitter (helps escape tiny plateaus) ---------
        if np.random.rand() < 0.01:
            w += np.random.randn(n) * 0.01

        # ---- anneal β -------------------------------------------------------
        beta = min(beta + beta_inc, beta_max)

        # ---- evaluate the exact objective every ~50 iterations -------------
        if it % 50 == 0:
            # exact max of the convolution (no extra cost – we already have conv)
            max_val = conv.max()
            sum_a = a.sum()                    # should be ≈ S
            score = 2.0 * n * max_val / (sum_a ** 2)

            if score < best_score:
                best_score = score
                best_a = a.copy()
                elapsed = time.time() - start
                print(f"[{elapsed:6.1f}s] iter {it:6d} → new best {best_score:.6f}")

        # ---- stop a tad early if we are about to exceed the deadline ----------
        if time.time() > deadline - 0.5:
            break

    # ------------------------------------------------------------------- #
    # If we never stored a best candidate (unlikely) fall back to last a
    if best_a is None:
        best_a = softmax_scaled(w, S)
        # final exact score (using the provided evaluator to be safe)
        best_score = evaluate_sequence(best_a.tolist())
    else:
        # final sanity check with the official evaluator (it will clamp anyway)
        best_score = evaluate_sequence(best_a.tolist())

    print(f"Search finished. Best score found: {best_score:.6f}")
    return best_a.tolist()
```
