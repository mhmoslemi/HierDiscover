assistantfinal**Solution Explanation**

The score returned by `evaluate_sequence` is  

\[
S(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 .
\]

The denominator is *scale‑invariant*: multiplying the whole vector by any
positive factor does **not** change the score.  
Therefore we may (and do) enforce the probability‑simplex constraint  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

With this normalisation  

\[
S(a)= 2\,n\; \max_k (a*a)_k,
\]

so minimising the score is equivalent to flattening the auto‑convolution
\(b_k=(a*a)_k\) as much as possible.

--------------------------------------------------------------------
### Optimisation strategy
* **Parameterisation** – we keep the vector `a` directly and, after each
  update, renormalise it onto the simplex (`a /= a.sum()`).
* **Smooth approximation of the max** –  
  the non‑smooth term `max(b)` is replaced by a soft‑max  

  \[
  w_k = \frac{\exp\!\bigl(\tau\,(b_k-\max b)\bigr)}{\sum_j\exp\!\bigl(\tau\,(b_j-\max b)\bigr)},
  \qquad
  g_i = 2\sum_j a_j\,w_{i+j}.
  \]

  For small \(\tau\) the soft‑max is wide (exploration), for large
  \(\tau\) it concentrates on the true maximiser (exploitation).
* **FFT based convolutions** – both the auto‑convolution `b` and the
  gradient `g` are computed with `np.fft.rfft`/`irfft`.  This makes a
  single iteration essentially \(O(n\log n)\) even for several‑thousand
  entries.
* **Momentum‑accelerated exponentiated gradient** –  
  The simple update  

  \[
  a_i \leftarrow a_i\exp(-\eta\,g_i)
  \]

  guarantees non‑negativity.  Adding a momentum term  

  \[
  m \leftarrow \beta m+(1-\beta)g,\qquad
  a_i \leftarrow a_i\exp(-\eta\,m_i)
  \]

  (followed by renormalisation) gives the same robustness as Adam/Nesterov
  while still staying on the simplex.
* **Adaptive schedules**  
  * `τ` grows linearly from **0.5** up to **30** – we start with a smooth
    landscape and finish with a tight approximation of the true max.
  * The learning‑rate `η` decays very slowly (never below **0.01**) and is
    bumped back after a stagnation event.
* **Stagnation handling** – if the best score has not improved for a
  while we inject a small multiplicative jitter (Gaussian noise in the
  log‑domain) and, after a longer stall, perform a full random restart.
* **Time‑aware loop** – the routine stops well before the 1000 s budget
  and returns the best sequence ever seen.

--------------------------------------------------------------------
### Why this should beat the previous run
* **Momentum** prevents the destructive “step‑size‑to‑zero” behaviour that
  caused `eta` to collapse to `0` in the original code.
* **FFT** makes it cheap to increase the length of the vector (more
  degrees of freedom → lower possible `max(b)`) without sacrificing
  iteration speed.
* **Two‑phase temperature schedule** explores the landscape early and
  focuses on the true maximum later, a pattern that is known to improve
  soft‑max optimisation.
* **Jitter & restarts** keep the search from being trapped in a local
  basin.

All of these changes are implemented in the `propose_candidate` function
below and respect the 1000 s time limit.

  * FFT based convolutions for speed

  * adaptive τ, learning‑rate η and occasional jitter / restarts
"""

def sqrt_distribution(n: int) -> np.ndarray:

    divided by its sum so that Σ a_i = 1.
    """
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
    a /= a.sum()
    return a


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Project a non‑negative vector onto the probability simplex (sum=1)."""
    v = np.maximum(v, 0.0)
    s = v.sum()
    if s == 0.0:
        v[:] = 1.0 / v.size
    else:
        v /= s
    return v


def smooth_max_gradient_fft(a: np.ndarray, tau: float):
    """
    Compute the gradient of the soft‑max surrogate of max(a*a).

    Returns
        grad  – ∂/∂a  Σ_k w_k·(a*a)_k   (shape = a.shape)
        max_b – the exact maximum of the convolution b = a*a
        b     – the full convolution (for diagnostic use)
    """
    n = a.shape[0]
    Lb = 2 * n - 1                     # length of a*a

    # ---- a*a via FFT -------------------------------------------------
    A = np.fft.rfft(a, Lb)
    b = np.fft.irfft(A * A, n=Lb)      # real convolution, length Lb
    max_b = b.max()

    # ---- soft‑max weights --------------------------------------------
    w = np.exp(tau * (b - max_b))
    w_sum = w.sum()
    if w_sum == 0.0:
        w.fill(1.0 / w.size)
    else:
        w /= w_sum

    # ---- gradient = 2·a ⋆ w_rev --------------------------------------
    w_rev = w[::-1]                    # reverse for proper indexing
    Lg = n + Lb - 1                     # length of a ⋆ w_rev = 3n‑2
    A_big = np.fft.rfft(a, Lg)
    W_big = np.fft.rfft(w_rev, Lg)
    conv_rev = np.fft.irfft(A_big * W_big, n=Lg)

    # indices that correspond to the gradient (see original non‑FFT version)
    idx = (Lb - 1) - np.arange(n)       # decreasing slice
    grad = 2.0 * conv_rev[idx]

    return grad, max_b, b

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function with a low `evaluate_sequence`
    score.  The routine respects the time budget, keeps the best vector it
    ever saw and returns it as a plain Python list.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5          # safety margin

    # --------------------------------------------------------------
    # 1. Choose length and initial vector
    # --------------------------------------------------------------
    try:
        # If the previous best construction is available, reuse its length.
        n = len(height_sequence_1)                    # type: ignore[name-defined]
        init = np.array(height_sequence_1, dtype=np.float64)
        if init.sum() == 0.0:
            a = sqrt_distribution(n)
        else:
            a = init / init.sum()
    except Exception:
        # Fallback length – long enough to give extra degrees of freedom.
        n = 2500
        a = sqrt_distribution(n)

    a = project_to_simplex(a)

    # --------------------------------------------------------------
    # 2. Track the best solution so far
    # --------------------------------------------------------------
    best_seq = a.copy()
    best_score = evaluate_sequence(best_seq.tolist())
    print(f"[init] n={n}, score={best_score:.6f}")

    # --------------------------------------------------------------
    # 3. Hyper‑parameters
    # --------------------------------------------------------------
    eta = 0.30                 # base learning rate (never drops below 0.01)
    eta_min = 0.01
    eta_decay = 0.9999        # very slow decay
    beta = 0.9                # momentum coefficient
    momentum = np.zeros_like(a)

    tau = 0.5                 # start temperature
    tau_increment = 0.001     # linear schedule
    tau_max = 30.0

    iteration = 0
    stagnant = 0               # number of iterations without improvement

    # --------------------------------------------------------------
    # 4. Main optimisation loop
    # --------------------------------------------------------------
    while time.time() < deadline:
        # --- gradient of the smooth surrogate ---
        grad, max_b, _ = smooth_max_gradient_fft(a, tau)

        # --- momentum update (exponential moving average) ---
        momentum = beta * momentum + (1.0 - beta) * grad

        # --- multiplicative (exponentiated) update ---
        # Clip the momentum before exponentiation to avoid overflow.
        m_clip = np.clip(momentum, -20.0, 20.0)
        a = a * np.exp(-eta * m_clip)

        # --- enforce positivity & simplex constraint ---
        a = np.maximum(a, 1e-30)          # avoid exact zeros
        a = a / a.sum()

        # --- evaluate ------------------------------------------------
        cur_score = evaluate_sequence(a.tolist())

        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_seq = a.copy()
            stagnant = 0
            print(f"[{iteration:05d}] improved score={best_score:.6f}, "
                  f"max_b={max_b:.8e}, τ={tau:.3f}, η={eta:.4f}")
        else:
            stagnant += 1

        # --- schedule ------------------------------------------------
        tau = min(tau + tau_increment, tau_max)
        eta = max(eta * eta_decay, eta_min)

        # --- stagnation handling ------------------------------------
        if stagnant >= 2000:
            # Small multiplicative jitter (log‑domain Gaussian noise)
            sigma = 0.02
            jitter = np.exp(sigma * np.random.randn(n))
            a = a * jitter
            a = a / a.sum()
            momentum.fill(0.0)          # reset momentum after jitter
            stagnant = 0
            # give the learning rate a tiny boost to escape flat regions
            eta = max(eta, 0.05)
            print(f"[{iteration:05d}] jitter applied, η={eta:.4f}, τ={tau:.3f}")

        if stagnant >= 10000:
            # Full restart – fresh sqrt‑distribution.
            a = sqrt_distribution(n)
            momentum.fill(0.0)
            tau = 0.5
            eta = 0.30
            stagnant = 0
            print(f"[{iteration:05d}] full restart")

        iteration += 1

    # --------------------------------------------------------------
    # 5. Return the best sequence found
    # --------------------------------------------------------------
    print(f"[done] best score = {best_score:.6f} after {iteration} iterations")
    return best_seq.tolist()
