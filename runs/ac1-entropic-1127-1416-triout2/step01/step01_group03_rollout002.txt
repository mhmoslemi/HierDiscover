The evaluation function is  

\[
E(a)=\frac{2\,n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\]

where \((a*a)_k\) is the discrete convolution of the non‑negative sequence
\(a\) with itself.  
For a **scale‑invariant** objective we may multiply every entry of the
sequence by a constant without changing the score – the clipping at
\(0\le a_i\le1000\) is never activated if we start with values \(\le1\).

For a power‑law shape  

\[
a_i = (i+1)^{-\;p} \qquad (p\in(0,1)),
\]

asymptotic analysis gives  

\[
\sum_{i=0}^{n-1} a_i \sim \frac{n^{1-p}}{1-p},
\qquad
\max_k (a*a)_k \sim B(1-p,1-p)\; n^{1-2p},
\]

with \(B\) the beta‑function. Hence for large \(n\)

\[
E(a) \longrightarrow
2\,\bigl(1-p\bigr)^2\,
\frac{\Gamma(1-p)^2}{\Gamma(2(1-p))},
\tag{1}
\]

a constant that **decreases when \(p\) approaches 1**.  
For the classical square‑root distribution (\(p=\frac12\)) (1) gives 
\(\frac\pi2\approx1.5708\).  Already at \(p=0.9\) the bound is about
\(0.39\), far below the required 1.503.

The algorithm therefore:

1. Chooses a length \(n\) (the length of the previously found
   construction if it exists, otherwise 2000).
2. Scans a small set of exponents \(p\in[0.55,0.99]\) (step 0.01),
   builds the corresponding power‑law sequence, evaluates it and
   keeps the best one.
3. Returns the best sequence as a plain Python list.

The search touches only a few dozen candidates, each requiring a single
\(O(n^2)\) convolution, which is negligible compared with the 1000 s
budget.

#!/usr/bin/env python3
"""
Propose a step‑function sequence that minimises `evaluate_sequence`.

Algorithm
---------
* Use a power‑law shape a_i = (i+1)^{-p} (p∈(0,1)).
* For a given length n the evaluation score depends only on the exponent
  p (the score is scale‑invariant).  Equation (1) shows that larger p
  (i.e. faster decay) yields a smaller bound.
* Scan a short list of exponents, evaluate each candidate with the
  provided `evaluate_sequence`, and keep the best.
* Return the best sequence as a plain Python list.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (top level – required by the platform)
# ----------------------------------------------------------------------


def power_law_sequence(n: int, p: float) -> np.ndarray:
    """
    Return a non‑negative power‑law sequence a_i = (i+1)^{-p} of length n.
    The values are ≤1, therefore never clipped by the evaluation routine.
    """
    idx = np.arange(1, n + 1, dtype=np.float64)
    return np.power(idx, -p)


def evaluate(seq):
    """
    Wrapper around the external `evaluate_sequence` that catches unexpected
    errors and returns +inf on failure.
    """
    try:
        return evaluate_sequence(seq)   # pylint: disable=undefined-variable
    except Exception:                 # pragma: no cover
        return float("inf")


# ----------------------------------------------------------------------
# Main entry point required by the platform
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a low‑score step‑function using a simple power‑law family.
    The function respects the time budget and returns the best sequence
    found before the deadline.
    """
    np.random.seed(seed)
    deadline = time.time() + budget_s - 0.5   # safety margin

    # ------------------------------------------------------------------
    # Choose the length of the sequence.
    # Prefer the length of a previously discovered construction if it
    # exists; otherwise fall back to a moderate size (2000).
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 2000

    print(f"[info] Using sequence length n={n}")

    # ------------------------------------------------------------------
    # Scan a small grid of exponents p.  The score is scale‑invariant,
    # therefore we can use the raw (i+1)^{-p} values.
    # ------------------------------------------------------------------
    best_score = float("inf")
    best_seq = None
    best_p = None

    # Exponents to test – dense enough for this simple search.
    # The algorithm stops as soon as the time budget expires.
    for p in np.arange(0.55, 0.991, 0.01):
        if time.time() >= deadline:
            break

        a = power_law_sequence(n, p)
        # Convert to plain Python list for the evaluator.
        cur_score = evaluate(a.tolist())

        if cur_score < best_score:
            best_score = cur_score
            best_seq = a.copy()
            best_p = p
            print(f"[update] p={p:.3f} → score={cur_score:.6f}")

    # ------------------------------------------------------------------
    # If, for any reason, the grid produced no valid candidate,
    # fall back to the square‑root distribution used previously.
    # ------------------------------------------------------------------
    if best_seq is None:
        print("[fallback] no candidate found, using sqrt distribution")
        # Re‑use the helper from the previous state‑of‑the‑art code.
        def sqrt_distribution(m: int) -> np.ndarray:
            a = np.empty(m, dtype=np.float64)
            a[0] = 1.0
            for i in range(1, m):
                a[i] = a[i - 1] * (2 * i - 1) / (2 * i)
            a /= a.sum()
            return a
        best_seq = sqrt_distribution(n)

    # ------------------------------------------------------------------
    # Final report
    # ------------------------------------------------------------------
    print(f"[done] best exponent p={best_p:.3f}, best score={best_score:.6f}")
    # Return a plain list as required by the evaluation harness.
    return best_seq.tolist()
