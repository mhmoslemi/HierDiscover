assistantfinal**Solution Overview**

The evaluator penalises the *maximum* entry of the a‑periodic self‑convolution of a non‑negative vector, normalised only by its sum.  
If the vector is normalised to a probability distribution (`∑aᵢ = 1`) the score becomes  

```
score(a) = 2·n·max_k (a * a)_k
```

Hence the optimisation problem is:

*find a non‑negative vector on the simplex that makes the peak of its auto‑convolution as small as possible.*

The programme below follows a **multi‑stage deterministic + stochastic pipeline** that works well for large `n` (up to 32768) inside the 1000 s budget.

1. **Length selection** – the larger the length the lower the theoretical lower bound (≈ 1); we use `n = 32768` when time permits.
2. **Fast analytic seeds** – families (`symmetric_product`, `left_heavy_power`, `exponential_decay`) and Dirichlet draws are evaluated quickly and the best seed is stored.
3. **Smoothed max‑convolution (log‑sum‑exp) optimisation** – the non‑smooth `max` is replaced by  

   ```
   f_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)
   ```

   The gradient is exact and cheap (two FFT‑based convolutions).  
   Adam with an exponentially increasing β (5 → 5·10⁴) drives the surrogate very close to the true max.  
   Several restarts from random sparse vectors keep the search diverse.
4. **High‑β refinement** – a second Adam run with an even larger β (2·10⁴ → 1·10⁵) finalises the surrogate to the true max.
5. **Entropy‑mirror sub‑gradient descent** – true‑max sub‑gradients are used (`g_i = 2·a_{k−i}` where `k` is the active shift) with a diminishing step `η_t = 0.9/√t`. This reduces the remaining gap.
6. **Symmetrisation** – the optimal solution is almost always symmetric; we therefore average the vector with its reverse and re‑project onto the simplex.
7. **Tiny simulated‑annealing hill‑climb** – a light SA loop (≈ 1 M proposals) escapes shallow local minima.
8. **Best‑ever bookkeeping** – every time a lower score is found it is printed and stored; the final vector is returned as a plain Python list.

All heavy linear algebra is performed with NumPy’s FFT (real‑valued, `rfft`/`irfft`) which is O(n log n) and fast even for `n = 32768`.  
The implementation avoids any hidden state (no closures, no file I/O) and respects the 1‑CPU limit.

```python
"""
Propose a step‑function sequence that minimises the evaluation score.

The algorithm:
  1. Choose a large length n (up to 32768) depending on the time budget.
  2. Initialise a pool of analytic and random distributions; keep the best.
  3. Optimise the smooth log‑sum‑exp surrogate of the max‑convolution
     with Adam (β is annealed from 5 to 5·10⁴).  Several restarts are run.
  4. Refine the best candidate with a high‑β Adam run (β up to 1·10⁵).
  5. Perform entropy‑mirror sub‑gradient descent on the true max‑objective.
  6. Symmetrise the vector (a ← (a + a[::-1])/2) and re‑project onto the simplex.
  7. Finish with a tiny simulated‑annealing hill‑climb.
  8. Return the best vector found (plain Python list).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic linear‑algebra utilities
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full aperiodic convolution using real FFT."""
    m = a.size + b.size - 1
    nfft = next_pow2(m)
    A = np.fft.rfft(a, n=nfft)
    B = np.fft.rfft(b, n=nfft)
    C = A * B
    conv = np.fft.irfft(C, n=nfft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """Exact score for a probability vector (sum(a) == 1)."""
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return float(2.0 * n * conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    n = v.shape[0]
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / n)

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def softmax(z: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max."""
    z_max = np.max(z)
    e = np.exp(z - z_max)
    return e / e.sum()


# ----------------------------------------------------------------------
# Analytic families (fast deterministic seeds)
# ----------------------------------------------------------------------


def symmetric_product_family(n: int, alpha: float) -> np.ndarray:
    """a_i ∝ [(i+½)(n‑½‑i)]^(‑α) , symmetric, sum = 1."""
    i = np.arange(n, dtype=np.float64)
    logprod = np.log(i + 0.5) + np.log(n - 0.5 - i)
    w = np.exp(-alpha * logprod)
    w[np.isinf(w)] = np.finfo(np.float64).max
    a = w / w.sum()
    return a


def left_heavy_power_family(n: int, beta: float) -> np.ndarray:
    """a_i ∝ (i+½)^(‑β) , monotone decreasing, sum = 1."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-beta * np.log(i + 0.5))
    a = w / w.sum()
    return a


def exponential_decay_family(n: int, gamma: float) -> np.ndarray:
    """a_i ∝ exp(-γ·i) , monotone decreasing, sum = 1."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-gamma * i)
    a = w / w.sum()
    return a


# ----------------------------------------------------------------------
# Random initialisers
# ----------------------------------------------------------------------


def random_dirichlet_start(n: int, conc: float) -> np.ndarray:
    """Symmetric Dirichlet draw with concentration α = conc."""
    vec = np.random.gamma(conc, 1.0, size=n)
    return vec / vec.sum()


def random_sparse_start(n: int, sparsity: float = 0.05) -> np.ndarray:
    """Very sparse uniform vector (≈ sparsity % non‑zeros)."""
    k = max(2, int(round(sparsity * n)))
    idx = np.random.choice(n, size=k, replace=False)
    a = np.zeros(n, dtype=np.float64)
    a[idx] = 1.0 / k
    return project_to_simplex(a)


# ----------------------------------------------------------------------
# Smoothed optimisation (log‑sum‑exp surrogate) via Adam
# ----------------------------------------------------------------------


def adam_smooth_optimize(
    start_a: np.ndarray,
    deadline: float,
    max_iters: int = 300_000,
    beta_start: float = 5.0,
    beta_end: float = 50_000.0,
    lr: float = 0.018,
) -> tuple[np.ndarray, float]:
    """
    Minimise the smoothed surrogate
          f_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)

    using Adam on the soft‑max parametrisation a = softmax(z).
    β is increased exponentially from beta_start to beta_end.
    """
    eps = 1e-12
    # initialise Adam on log‑softmax for numerical stability
    z = np.log(start_a + eps)
    m = np.zeros_like(z)
    v = np.zeros_like(z)

    beta1, beta2 = 0.9, 0.999
    eps_adam = 1e-12

    best_a = softmax(z)
    best_score = compute_score(best_a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # ---- β schedule (exponential) ----
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        # ---- current a (softmax) ----
        a = softmax(z)

        # ---- smoothed weights w_k ∝ exp(β·conv_k) ----
        conv = convolution_fft(a, a)          # length 2n‑1
        maxc = conv.max()
        exp_w = np.exp(beta * (conv - maxc))   # stabilised
        w = exp_w / exp_w.sum()                # soft‑max over shifts

        # ---- gradient of f_β w.r.t. a ----
        a_rev = a[::-1]
        # convolution of reversed a with w gives the required gradient window
        conv_rev = convolution_fft(a_rev, w)   # length 3n‑2
        n = a.shape[0]
        grad_a = 2.0 * conv_rev[n - 1 : n - 1 + n]

        # ---- back‑prop through soft‑max ----
        dot_ag = np.dot(a, grad_a)
        grad_z = a * grad_a - dot_ag * a

        # ---- Adam update ----
        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z ** 2)
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)
        z -= lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        # ---- occasional exact evaluation ----
        if it % 400 == 0:
            a_tmp = softmax(z)
            sc = compute_score(a_tmp)
            if sc < best_score:
                best_score = sc
                best_a = a_tmp.copy()
                print(f"[{time.time():.1f}]   Adam iter {it:7d} – new best = {best_score:.6f}")

    # final check
    a_fin = softmax(z)
    sc_fin = compute_score(a_fin)
    if sc_fin < best_score:
        best_score = sc_fin
        best_a = a_fin.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Entropy‑mirror sub‑gradient descent on the exact max‑objective
# ----------------------------------------------------------------------


def mirror_subgrad_optimize(
    start_a: np.ndarray,
    deadline: float,
    step0: float = 0.9,
    check_interval: int = 2000,
) -> tuple[np.ndarray, float]:
    """
    Mirror (multiplicative) sub‑gradient descent for the true max‑convolution.
    Step size η_t = step0 / sqrt(t).
    """
    n = start_a.shape[0]
    a = start_a.astype(np.float64).copy()
    best_a = a.copy()
    best_score = compute_score(a)

    t = 0
    while time.time() < deadline:
        t += 1
        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))                     # active shift index

        # sub‑gradient for the active shift
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        eta = step0 / np.sqrt(t)
        a = a * np.exp(-eta * g)                     # multiplicative update
        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / s                                   # renormalise

        if t % check_interval == 0:
            sc = compute_score(a)
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
                print(f"[{time.time():.1f}]   Mirror step {t:7d} – new best = {best_score:.6f}")

    sc = compute_score(a)
    if sc < best_score:
        best_score = sc
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Tiny simulated‑annealing hill‑climb (final polishing)
# ----------------------------------------------------------------------


def hill_climb_sa(
    start_a: np.ndarray,
    deadline: float,
    max_steps: int = 1_500_000,
    init_temp_factor: float = 1e-4,
) -> tuple[np.ndarray, float]:
    """
    Very low‑temperature SA on the simplex.
    At each step either swaps two entries or transfers a small fraction of mass.
    """
    n = start_a.size
    cur_a = start_a.copy()
    cur_score = compute_score(cur_a)

    best_a = cur_a.copy()
    best_score = cur_score

    T0 = best_score * init_temp_factor
    T = T0
    step_scale = 0.12

    for step in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        cand = cur_a.copy()
        if np.random.rand() < 0.5:                       # swap two positions
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:                                            # move a fraction of mass
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = step_scale * cur_a[i]
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0.0:
                    cand[i] = 0.0

        cand = project_to_simplex(cand)
        cand_score = compute_score(cand)
        delta = cand_score - cur_score

        # Metropolis criterion
        if delta < 0.0 or np.random.rand() < np.exp(-delta / (T + 1e-18)):
            cur_a = cand
            cur_score = cand_score
            if cur_score < best_score:
                best_score = cur_score
                best_a = cur_a.copy()
                step_scale = min(step_scale * 1.07, 0.5)
        else:
            step_scale *= 0.97

        # linear cooling
        T = T0 * (1.0 - step / max_steps)

    return best_a, best_score


# ----------------------------------------------------------------------
# Main driver required by the harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **_) -> list[float]:
    """
    Search for a non‑negative step‑function that minimises
    `evaluate_sequence`.  The routine respects the given time budget
    (≈ 1000 s) and returns a plain Python list.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a tiny safety margin for the outer harness
    deadline = start_time + budget_s - 2.0

    # ------------------------------------------------------------------
    # Choose a length – larger n gives a lower theoretical bound.
    # ------------------------------------------------------------------
    if budget_s >= 800:
        n = 32768
    elif budget_s >= 600:
        n = 16384
    else:
        n = 8192
    print(f"[{time.time():.1f}] Using length n = {n}")

    # ------------------------------------------------------------------
    # Global best bookkeeping
    # ------------------------------------------------------------------
    best_seq = None
    best_score = float("inf")

    def maybe_update(vec: np.ndarray, tag: str = ""):
        """Update the global best if `vec` improves the score."""
        nonlocal best_seq, best_score
        sc = compute_score(vec)
        if sc < best_score:
            best_score = sc
            best_seq = vec.tolist()
            print(f"[{time.time():.1f}] new best {tag:<14} = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 0. Optional fallback to a previously provided construction
    # ------------------------------------------------------------------
    try:
        fb_vec = [float(x) for x in height_sequence_1]   # type: ignore
        fb_sc = evaluate_sequence(fb_vec)
        print(f"[{time.time():.1f}] fallback score = {fb_sc:.6f}")
        if fb_sc < best_score:
            best_score = fb_sc
            best_seq = fb_vec
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1. Cheap analytic families + Dirichlet draws
    # ------------------------------------------------------------------
    uniform = np.full(n, 1.0 / n)
    maybe_update(uniform, "uniform")

    # symmetric product family
    for alpha in np.linspace(0.0, 6.0, 41):
        if time.time() >= deadline - 40.0:
            break
        vec = symmetric_product_family(n, alpha)
        maybe_update(vec, f"sym‑α={alpha:.2f}")

    # left‑heavy power law
    for beta in np.linspace(0.0, 6.0, 41):
        if time.time() >= deadline - 40.0:
            break
        vec = left_heavy_power_family(n, beta)
        maybe_update(vec, f"pow‑β={beta:.2f}")

    # exponential decay family
    for gamma in np.linspace(0.0, 8.0, 51):
        if time.time() >= deadline - 40.0:
            break
        vec = exponential_decay_family(n, gamma)
        maybe_update(vec, f"exp‑γ={gamma:.2f}")

    # Dirichlet draws with a wide range of concentration parameters
    conc_vals = np.logspace(-2, 1, 25)          # 0.01 … 10
    for conc in conc_vals:
        for _ in range(3):
            if time.time() >= deadline - 40.0:
                break
            vec = random_dirichlet_start(n, conc)
            maybe_update(vec, f"dir‑α={conc:.3f}")

    # ------------------------------------------------------------------
    # 2. Smoothed Adam optimisation – many restarts while time permits
    # ------------------------------------------------------------------
    while time.time() < deadline - 260.0:
        # random sparse start gives a good diversity
        start_vec = random_sparse_start(n, sparsity=np.random.uniform(0.02, 0.08))
        a_opt, sc_opt = adam_smooth_optimize(
            start_vec,
            deadline - 210.0,
            max_iters=250_000,
            beta_start=5.0,
            beta_end=20_000.0,
            lr=0.018,
        )
        if sc_opt < best_score:
            best_score = sc_opt
            best_seq = a_opt.tolist()
            print(f"[{time.time():.1f}]   after Adam‑smooth (restart) best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. High‑β refinement (almost the true max)
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 120.0:
        print(f"[{time.time():.1f}] high‑β refinement stage")
        a_ref, sc_ref = adam_smooth_optimize(
            np.array(best_seq, dtype=np.float64),
            deadline - 90.0,
            max_iters=120_000,
            beta_start=20_000.0,
            beta_end=100_000.0,
            lr=0.010,
        )
        if sc_ref < best_score:
            best_score = sc_ref
            best_seq = a_ref.tolist()
            print(f"[{time.time():.1f}] after high‑β Adam best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4. Mirror sub‑gradient descent on the exact max objective
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 70.0:
        print(f"[{time.time():.1f}] starting mirror sub‑gradient descent")
        a_sub, sc_sub = mirror_subgrad_optimize(
            np.array(best_seq, dtype=np.float64),
            deadline - 20.0,
            step0=1.0,
        )
        if sc_sub < best_score:
            best_score = sc_sub
            best_seq = a_sub.tolist()
            print(f"[{time.time():.1f}] after mirror sub‑grad best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Symmetrisation (important for the optimal shape)
    # ------------------------------------------------------------------
    if best_seq is not None:
        a_arr = np.array(best_seq, dtype=np.float64)
        a_sym = (a_arr + a_arr[::-1]) * 0.5
        a_sym = project_to_simplex(a_sym)
        maybe_update(a_sym, "symmetrised")

    # ------------------------------------------------------------------
    # 6. Final tiny simulated‑annealing hill‑climb
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 5.0:
        print(f"[{time.time():.1f}] final hill‑climb (SA)")
        a_final, sc_final = hill_climb_sa(
            np.array(best_seq, dtype=np.float64),
            deadline,
            max_steps=1_200_000,
        )
        if sc_final < best_score:
            best_score = sc_final
            best_seq = a_final.tolist()
            print(f"[{time.time():.1f}] hill‑climb improved best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Safeguard – fallback to a modest uniform vector if nothing succeeded
    # ------------------------------------------------------------------
    if best_seq is None:
        n_small = 256
        best_seq = [1.0 / n_small] * n_small
        best_score = evaluate_sequence(best_seq)

    # ------------------------------------------------------------------
    # Final official evaluation (the outer harness will also call evaluate_sequence)
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\n[{time.time():.1f}] finished search – final reported score = {final_score:.6f}")

    return best_seq
```
