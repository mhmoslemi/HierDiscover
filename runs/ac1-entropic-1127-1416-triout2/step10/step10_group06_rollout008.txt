assistantfinal**Solution Overview**

The program searches for a non‑negative step‑function `a = (a₀,…,a_{n‑1})` that minimises  

```
E(a) = 2·n·max_k (a * a)_k / (∑ a_j)²        (exactly the value returned by evaluate_sequence)
```

The optimisation is carried out in three stages

1. **Exploratory families** – a large collection of analytic shapes (triangular,
   cosine, Gaussian, super‑Gaussian, power‑law, exponential, β‑distribution …) is
   scanned on a grid of parameters, together with many random Dirichlet starts.
   The best vector (always kept on the probability simplex) is stored as `best_a`.

2. **Smooth surrogate optimisation** – the non‑smooth `max` is approximated by a
   log‑sum‑exp:

   ```
   f_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)
   ```

   The surrogate is smooth and its gradient is available in closed form.
   Using SciPy’s L‑BFGS‑B we minimise `f_β` for a schedule of increasing
   β = {200, 800, 2000, 5000, 10000, 20000}.  
   The optimisation works on the log‑soft‑max parameters `z` (so that `a = softmax(z)`
   automatically satisfies the simplex constraints).

3. **Fine‑grained local search** – an exponentiated mirror‑subgradient descent
   directly minimises the true objective `2·n·max(a*a)`.  Afterwards a tiny
   simulated‑annealing hill‑climb is performed to escape any remaining shallow
   minima.

All stages respect the global time budget (default 1000 s).  The final vector is
returned as a plain Python list of floats; `evaluate_sequence` will be called by
the outer harness to obtain the official score.

```python
"""
Propose a step‑function (non‑negative sequence) minimising `evaluate_sequence`.

Algorithm
---------
0.  Choose a length `n` (2048 for a fast run, 4096 when enough time is left).
1.  Scan a wide variety of analytic families (triangular, cosine‑bell,
    Gaussian, super‑Gaussian, power‑law, exponential, β‑distribution) together
    with many random Dirichlet vectors – keep the best (vectors are kept on the
    probability simplex, i.e. ∑a = 1).
2.  Refine the current best with a smooth log‑sum‑exp surrogate
    `f_β(a) = (1/β)·log∑exp(β·(a*a)_k)`.  The surrogate is minimised by
    L‑BFGS‑B on the log‑soft‑max parameters `z` for an increasing schedule of
    β = 200, 800, 2000, 5000, 10000, 20000.
3.  Use exponentiated mirror sub‑gradient descent on the exact objective
    `2·n·max(a*a)` (projected onto the simplex each iteration).
4.  A final tiny simulated‑annealing hill‑climb fine‑tunes the result.
5.  Return the best vector found as a list of floats.

All steps stop before the global deadline (default 1000 s).  The code is
self‑contained, uses only NumPy and SciPy (if available) and prints progress
information.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Optional SciPy import (for L‑BFGS‑B)
# ----------------------------------------------------------------------
try:
    import scipy.optimize as _opt
    _HAS_SCIPY = True
except Exception:  # pragma: no cover
    _HAS_SCIPY = False

# ----------------------------------------------------------------------
# FFT utilities (linear convolution via real FFT)
# ----------------------------------------------------------------------
def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution a*b using real FFT (returns full length)."""
    m = a.size + b.size - 1
    nfft = next_pow2(m)
    A = np.fft.rfft(a, n=nfft)
    B = np.fft.rfft(b, n=nfft)
    C = A * B
    conv = np.fft.irfft(C, n=nfft)[:m]
    return conv


# ----------------------------------------------------------------------
# Objective helper (scale invariant, works for any non‑negative vector)
# ----------------------------------------------------------------------
def evaluate_vec(v: np.ndarray) -> float:
    """Exact value of evaluate_sequence for a vector v (no clipping)."""
    s = v.sum()
    if s < 1e-12:
        return float("inf")
    conv = convolution_fft(v, v)
    return float(2.0 * v.size * conv.max() / (s * s))


# ----------------------------------------------------------------------
# Simplex utilities
# ----------------------------------------------------------------------
def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection onto the probability simplex (∑=1, v≥0)."""
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def softmax(z: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max (maps ℝⁿ → simplex)."""
    z_max = np.max(z)
    e = np.exp(z - z_max)
    return e / e.sum()


# ----------------------------------------------------------------------
# Analytic families (all return a probability vector, i.e. sum = 1)
# ----------------------------------------------------------------------
def symmetric_product_family(n: int, alpha: float) -> np.ndarray:
    """U‑shaped: a_i ∝ [(i+½)(n‑½‑i)]^(‑α)."""
    i = np.arange(n, dtype=np.float64)
    logprod = np.log(i + 0.5) + np.log(n - 0.5 - i)
    w = np.exp(-alpha * logprod)
    w[np.isinf(w)] = np.finfo(np.float64).max
    a = w / w.sum()
    return a


def left_heavy_power_family(n: int, beta: float) -> np.ndarray:
    """Monotone decreasing power law: a_i ∝ (i+½)^(‑β)."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-beta * np.log(i + 0.5))
    a = w / w.sum()
    return a


def exponential_decay_family(n: int, gamma: float) -> np.ndarray:
    """Simple exponential decay: a_i ∝ exp(‑γ·i)."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-gamma * i)
    a = w / w.sum()
    return a


def beta_distribution_family(n: int, alpha: float) -> np.ndarray:
    """Symmetric beta‑shape: a_i ∝ (i/(n‑1))^α·(1‑i/(n‑1))^α."""
    i = np.arange(n, dtype=np.float64)
    t = i / (n - 1)
    eps = 1e-12
    w = (t + eps) ** alpha * (1 - t + eps) ** alpha
    a = w / w.sum()
    return a


def triangular_family(n: int, p: float = 1.0) -> np.ndarray:
    """Triangular (mountain) shape, optional exponent p."""
    i = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    base = 1.0 - np.abs(i - centre) * 2.0 / (n - 1)
    w = np.maximum(base, 0.0) ** p
    a = w / w.sum()
    return a


def cosine_bell_family(n: int, p: float = 1.0) -> np.ndarray:
    """Hann / cosine‑bell: w = (1 - cos(2π·i/(n‑1))) / 2, raised to p."""
    i = np.arange(n, dtype=np.float64)
    w = 0.5 * (1.0 - np.cos(2.0 * np.pi * i / (n - 1)))
    w = w ** p
    a = w / w.sum()
    return a


def gaussian_family(n: int, sigma_factor: float) -> np.ndarray:
    """Discrete Gaussian centred at the middle, σ = sigma_factor·n."""
    i = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    sigma = sigma_factor * n
    w = np.exp(-0.5 * ((i - centre) / sigma) ** 2)
    a = w / w.sum()
    return a


def supergaussian_family(n: int, p: float, sigma_factor: float) -> np.ndarray:
    """Super‑Gaussian (exp( -|x|^p )) centred at the middle."""
    i = np.arange(n, dtype=np.float64)
    centre = (n - 1) / 2.0
    sigma = sigma_factor * n
    w = np.exp(- ((np.abs(i - centre) / sigma) ** p))
    a = w / w.sum()
    return a


# ----------------------------------------------------------------------
# Random initialisers
# ----------------------------------------------------------------------
def random_dirichlet_start(n: int, concentration: float) -> np.ndarray:
    """Draw a Dirichlet vector with given concentration (≥0)."""
    if concentration <= 0:
        # pure uniform fallback
        return np.full(n, 1.0 / n)
    draws = np.random.gamma(concentration, 1.0, size=n)
    a = draws / draws.sum()
    return a


def random_sparse_start(n: int) -> np.ndarray:
    """Sparse vector (~5 % non‑zeros)."""
    sparsity = np.random.uniform(0.03, 0.07)
    k = max(2, int(round(sparsity * n)))
    idx = np.random.choice(n, size=k, replace=False)
    a = np.zeros(n, dtype=np.float64)
    a[idx] = 1.0 / k
    return project_to_simplex(a)


def random_monotone_start(n: int) -> np.ndarray:
    """Random decreasing vector (sorted power‑transformed uniform)."""
    r = np.random.rand(n) ** np.random.uniform(0.5, 5.0)
    r.sort()
    a = r[::-1]               # decreasing
    a = a / a.sum()
    return a


# ----------------------------------------------------------------------
# Smooth surrogate optimisation (L‑BFGS‑B on log‑sum‑exp)
# ----------------------------------------------------------------------
def _smooth_obj_and_grad(z: np.ndarray, beta: float, n: int):
    """
    Returns (f, grad) where
        f   = (1/β)·log Σ_k exp[β·(a*a)_k]
        grad = ∂f/∂z   (z are the log‑soft‑max parameters)
    """
    a = softmax(z)                     # a lives on the simplex
    conv = convolution_fft(a, a)       # length 2n‑1

    # stable log‑sum‑exp
    cmax = conv.max()
    exp_terms = np.exp(beta * (conv - cmax))
    sum_exp = exp_terms.sum()
    f = (np.log(sum_exp) + beta * cmax) / beta

    # gradient w.r.t. a (derivative of the soft‑max surrogate)
    w = exp_terms / sum_exp            # same shape as conv
    # d/da (conv_k) = 2· Σ_j a_j  if j contributes to k ; can be computed via convolution
    a_rev = a[::-1]
    conv_rev = convolution_fft(a_rev, w)   # length 3n‑2
    grad_a = 2.0 * conv_rev[n - 1 : 2 * n - 1]

    # chain rule through soft‑max
    dot = np.dot(a, grad_a)
    grad_z = a * (grad_a - dot)
    return float(f), grad_z.astype(np.float64)


def l_bfgs_refine(start_a: np.ndarray, deadline: float,
                  beta_list=(200.0, 800.0, 2000.0, 5000.0, 10000.0, 20000.0),
                  max_iter_per_beta=800) -> tuple[np.ndarray, float]:
    """
    Refine `start_a` with L‑BFGS‑B on the smooth surrogate.
    Returns the best vector (still on the simplex) and its exact score.
    """
    if not _HAS_SCIPY:
        # SciPy missing – fall back to the unmodified start
        return start_a, evaluate_vec(start_a)

    best_a = start_a.copy()
    best_score = evaluate_vec(best_a)

    eps = 1e-12
    z = np.log(best_a + eps)   # initialise log‑soft‑max parameters

    for beta in beta_list:
        if time.time() >= deadline - 4.0:
            break

        # adapt number of iterations to the remaining budget
        remaining = deadline - time.time()
        max_iter = min(max_iter_per_beta, int(remaining * 8))  # ~8 L‑BFGS iters / sec

        def func(z_vec):
            f, g = _smooth_obj_and_grad(z_vec, beta, best_a.shape[0])
            return f, g

        try:
            opt_res = _opt.fmin_l_bfgs_b(
                func,
                z,
                maxiter=max_iter,
                disp=False,
                factr=1e7,
                pgtol=1e-12,
            )
        except Exception as exc:  # pragma: no cover
            print(f"[{time.time():.1f}] L‑BFGS failed at β={beta}: {exc}")
            continue

        z = opt_res[0]
        a_opt = softmax(z)
        sc_opt = evaluate_vec(a_opt)
        if sc_opt < best_score:
            best_score = sc_opt
            best_a = a_opt.copy()
            print(f"[{time.time():.1f}] L‑BFGS β={beta:.0f} improved score = {best_score:.6f}")

    return best_a, best_score


# ----------------------------------------------------------------------
# Mirror (exponentiated) sub‑gradient descent on the true max‑objective
# ----------------------------------------------------------------------
def mirror_subgrad_optimize(start_a: np.ndarray, deadline: float,
                           step0: float = 0.8,
                           check_interval: int = 1500) -> tuple[np.ndarray, float]:
    """
    Exponentiated sub‑gradient descent on `F(a) = 2·n·max(a*a)`,
    staying on the simplex via multiplicative updates and renormalisation.
    """
    n = start_a.shape[0]
    a = start_a.astype(np.float64).copy()
    best_a = a.copy()
    best_score = evaluate_vec(a)

    t = 0
    while time.time() < deadline:
        t += 1
        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))

        # sub‑gradient of the active entry (see original code)
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        eta = step0 / math.sqrt(t)
        a = a * np.exp(-eta * g)          # multiplicative update
        a_sum = a.sum()
        if a_sum == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / a_sum

        if t % check_interval == 0:
            sc = evaluate_vec(a)
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
                print(f"[{time.time():.1f}] mirror sub‑grad iter {t} best = {best_score:.6f}")

    # final check
    sc = evaluate_vec(a)
    if sc < best_score:
        best_score = sc
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Tiny simulated‑annealing hill‑climb (local fine‑tuning)
# ----------------------------------------------------------------------
def hill_climb_sa(start_a: np.ndarray, deadline: float,
                  max_steps: int = 1_200_000,
                  init_temp_factor: float = 1e-4) -> tuple[np.ndarray, float]:
    """
    Very low‑temperature random walk on the simplex.
    50 % swaps, otherwise a small mass transfer between two indices.
    """
    n = start_a.size
    cur_a = start_a.copy()
    cur_score = evaluate_vec(cur_a)

    best_a = cur_a.copy()
    best_score = cur_score

    T0 = best_score * init_temp_factor
    T = T0
    step_scale = 0.12

    for step in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        cand = cur_a.copy()
        if np.random.rand() < 0.5:          # swap two entries
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:                               # mass transfer
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = step_scale * cur_a[i]
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0.0:
                    cand[i] = 0.0

        cand = cand / cand.sum()
        cand_score = evaluate_vec(cand)
        delta = cand_score - cur_score

        if delta < 0.0 or np.random.rand() < np.exp(-delta / (T + 1e-18)):
            cur_a = cand
            cur_score = cand_score
            if cur_score < best_score:
                best_score = cur_score
                best_a = cur_a.copy()
                step_scale = min(step_scale * 1.07, 0.5)
        else:
            step_scale *= 0.97

        T = T0 * (1.0 - step / max_steps)

    return best_a, best_score


# ----------------------------------------------------------------------
# High‑level driver
# ----------------------------------------------------------------------
def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Main entry point – searches for a non‑negative step‑function with minimal
    `evaluate_sequence` score and returns it as a plain Python list of floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    # safety margin for the outer harness
    deadline = start_time + budget_s - 2.0

    # ------------------------------------------------------------------
    # Choose a reasonable length (larger n gives smoother shapes, but
    # also more expensive convolution).  We use 2048 for a fast baseline,
    # 4096 when the budget is generous.
    # ------------------------------------------------------------------
    if budget_s >= 800:
        n = 4096
    else:
        n = 2048
    print(f"[{time.time():.1f}] Using length n = {n}")

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 0. Optional fallback to a known construction (if the global variable
    #    `height_sequence_1` exists).
    # ------------------------------------------------------------------
    try:
        fb_vec = [float(x) for x in height_sequence_1]   # type: ignore
        fb_score = evaluate_sequence(fb_vec)
        print(f"[{time.time():.1f}] fallback score = {fb_score:.6f}")
        if fb_score < best_score:
            best_score = fb_score
            best_seq = fb_vec
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1. Scan analytic families (dense parameter grids)
    # ------------------------------------------------------------------
    # Helper to evaluate a vector and possibly update the best solution
    def try_vector(vec: np.ndarray, tag: str):
        nonlocal best_seq, best_score
        sc = evaluate_vec(vec)
        if sc < best_score:
            best_score = sc
            best_seq = vec.tolist()
            print(f"[{time.time():.1f}] new best ({tag}) = {best_score:.6f}")

    # --- symmetric product (U‑shaped) ------------------------------------
    for alpha in np.linspace(0.0, 10.0, 121):
        if time.time() >= deadline - 30.0:
            break
        try_vector(symmetric_product_family(n, alpha), f"sym‑α={alpha:.2f}")

    # --- left‑heavy power law -------------------------------------------
    for beta in np.linspace(0.0, 10.0, 121):
        if time.time() >= deadline - 30.0:
            break
        try_vector(left_heavy_power_family(n, beta), f"left‑β={beta:.2f}")

    # --- exponential decay -----------------------------------------------
    for gamma in np.linspace(0.0, 9.0, 101):
        if time.time() >= deadline - 30.0:
            break
        try_vector(exponential_decay_family(n, gamma), f"exp‑γ={gamma:.2f}")

    # --- beta distribution ------------------------------------------------
    for alpha in np.linspace(0.0, 12.0, 121):
        if time.time() >= deadline - 30.0:
            break
        try_vector(beta_distribution_family(n, alpha), f"beta‑α={alpha:.2f}")

    # --- triangular (mountain) -------------------------------------------
    for p in np.linspace(0.1, 5.0, 81):
        if time.time() >= deadline - 30.0:
            break
        try_vector(triangular_family(n, p), f"tri‑p={p:.2f}")

    # --- cosine‑bell (Hann) ---------------------------------------------
    for p in np.linspace(0.1, 5.0, 81):
        if time.time() >= deadline - 30.0:
            break
        try_vector(cosine_bell_family(n, p), f"cos‑p={p:.2f}")

    # --- Gaussian --------------------------------------------------------
    for sigma_factor in np.linspace(0.02, 0.25, 45):
        if time.time() >= deadline - 30.0:
            break
        try_vector(gaussian_family(n, sigma_factor), f"gauss‑σ={sigma_factor:.3f}")

    # --- Super‑Gaussian ---------------------------------------------------
    for p in [2, 4, 6, 8]:
        for sigma_factor in np.linspace(0.02, 0.2, 30):
            if time.time() >= deadline - 30.0:
                break
            try_vector(supergaussian_family(n, p, sigma_factor),
                       f"sg‑p{p}_σ={sigma_factor:.3f}")

    # --- Random Dirichlet starts -----------------------------------------
    for _ in range(200):
        if time.time() >= deadline - 30.0:
            break
        concentration = np.random.uniform(0.05, 5.0)
        vec = random_dirichlet_start(n, concentration)
        try_vector(vec, f"rand‑dir‑c={concentration:.2f}")

    # ------------------------------------------------------------------
    # 2. Refine the best candidate with the smooth log‑sum‑exp surrogate
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 150.0:
        print(f"[{time.time():.1f}] Starting L‑BFGS refinement")
        a_start = np.array(best_seq, dtype=np.float64)
        a_refined, sc_refined = l_bfgs_refine(
            a_start,
            deadline - 100.0,
            beta_list=(200.0, 800.0, 2000.0, 5000.0, 10000.0, 20000.0),
            max_iter_per_beta=800,
        )
        if sc_refined < best_score:
            best_score = sc_refined
            best_seq = a_refined.tolist()
            print(f"[{time.time():.1f}] after L‑BFGS best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Mirror sub‑gradient descent on the exact objective
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 80.0:
        print(f"[{time.time():.1f}] Starting mirror sub‑gradient descent")
        a_sub, sc_sub = mirror_subgrad_optimize(
            np.array(best_seq, dtype=np.float64),
            deadline - 30.0,
            step0=0.5,           # a slightly smaller initial step size for finer tuning
        )
        if sc_sub < best_score:
            best_score = sc_sub
            best_seq = a_sub.tolist()
            print(f"[{time.time():.1f}] after mirror sub‑grad best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4. Symmetrisation (many optimal solutions are symmetric)
    # ------------------------------------------------------------------
    if best_seq is not None:
        a_arr = np.array(best_seq, dtype=np.float64)
        a_sym = (a_arr + a_arr[::-1]) * 0.5
        a_sym = project_to_simplex(a_sym)
        sc_sym = evaluate_vec(a_sym)
        if sc_sym < best_score:
            best_score = sc_sym
            best_seq = a_sym.tolist()
            print(f"[{time.time():.1f}] symmetrisation improved best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Final tiny simulated‑annealing hill‑climb
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 5.0:
        print(f"[{time.time():.1f}] Final hill‑climb (SA)")
        a_final, sc_final = hill_climb_sa(
            np.array(best_seq, dtype=np.float64),
            deadline,
            max_steps=1_500_000,
        )
        if sc_final < best_score:
            best_score = sc_final
            best_seq = a_final.tolist()
            print(f"[{time.time():.1f}] hill‑climb improved best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # Safeguard – if nothing succeeded, fall back to a modest uniform vector
    # ------------------------------------------------------------------
    if best_seq is None:
        n_small = 256
        best_seq = [1.0 / n_small] * n_small
        best_score = evaluate_sequence(best_seq)

    # ------------------------------------------------------------------
    # Final official evaluation (the harness will also call evaluate_sequence)
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\n[{time.time():.1f}] finished search – final reported score = {final_score:.6f}")

    return best_seq
```
