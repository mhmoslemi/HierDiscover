The function `propose_candidate` builds a non‑negative step‑function (a vector `a`) that minimises  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}\;,
\]

i.e. it minimises the maximal value of the auto‑convolution under the
constraint \(\sum a_i=\sqrt{2n}\) (the `evaluate_sequence` routine enforces
the same scaling).

The search consists of three phases

1. **Seeding** – a large collection of simple families (geometric,
   power‑law, mixed exponentials, random Dirichlet vectors, the provided
   `height_sequence_1` if any). Every seed is projected onto the simplex
   \(\{x\ge 0,\;\sum x=\sqrt{2n}\}\) and scored with a fast FFT based
   routine. The best seed becomes the starting point.

2. **Projected Adam optimisation** – we minimise the non‑smooth objective
   with a sub‑gradient of the max‑functional.  
   * The convolution and its maximal entry are obtained by a single FFT.  
   * The active set consists of all indices whose convolution value is
     within a relative tolerance (`1e‑4`) of the current maximum.  
   * For each active index we add the contribution \(2a_j\) to the gradient,
     exactly as in the previous implementation.  
   * Adam’s adaptive moments (`m`, `v`) are used to obtain a direction,
     then the tentative point is projected back onto the simplex.
   * A small amount of Gaussian jitter is injected from time to time,
     and after a long plateaux the optimiser is re‑initialised from the
     current best solution plus a larger jitter (helps to escape local
     minima).

3. **Linear‑programming polishing** – after the Adam phase we solve a
   small LP (the same one used in the reference code) a few times to
   tighten the bound.

All operations respect the security checks of `evaluate_sequence`.  
The whole search stops after the allotted time (≈ 1000 s) and returns the
best sequence discovered.

"""
search for a low‑score step‑function.

The algorithm proceeds in three stages:

1) **Seeding** – many parametric families (geometric, power‑law,
   double‑exponential, random Dirichlet) are projected onto the
   ℓ₁‑simplex (sum = sqrt(2 n)) and the best is kept.

2) **Projected Adam optimisation** – we minimise the maximal
   auto‑convolution using a sub‑gradient of the max‑functional.
   An Adam‑style adaptive step is taken, the result is projected onto
   the simplex, occasional jitter and restart are applied.

3) **LP polishing** – a handful of linear‑programming updates (the same
   LP as in the reference solution) are performed to further lower the
   bound.

The routine respects the 1000 s budget and returns the best sequence
found.
"""

import time
import numpy as np

# --------------------------------------------------------------------------- #
# Simplex projection (Duchi et al. 2008)
def projection_simplex(v: np.ndarray, s: float) -> np.ndarray:
    """Project vector v onto the simplex {x ≥ 0, Σx = s}."""
    if s < 0:
        raise ValueError("simplex sum must be non‑negative")
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - s
    rho_arr = np.where(u - cssv / (np.arange(n) + 1.0) > 0)[0]
    if rho_arr.size == 0:
        return np.zeros_like(v)
    rho = rho_arr[-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# --------------------------------------------------------------------------- #
def _fast_score(seq: np.ndarray, fft_len: int) -> float:
    """Fast evaluation of the objective (without the security checks)."""
    n = seq.size
    F = np.fft.rfft(seq, n=fft_len)
    conv = np.fft.irfft(F * F, n=fft_len)[: 2 * n - 1]
    max_conv = conv.max()
    s = seq.sum()
    # denominator = s**2 ; we keep s = sqrt(2n) in the optimisation,
    # but we compute the exact expression for completeness.
    return float(2.0 * n * max_conv / (s * s))


# --------------------------------------------------------------------------- #
def _build_toeplitz_matrix(f: np.ndarray):
    """Return a sparse matrix A (shape (2n‑1, n)) such that A·g = f * g."""
    n = f.shape[0]
    rows = np.empty(n * n, dtype=np.int32)
    cols = np.empty(n * n, dtype=np.int32)
    data = np.empty(n * n, dtype=np.float64)

    ptr = 0
    for i in range(n):
        rows[ptr: ptr + n] = np.arange(i, i + n)          # rows i … i+n‑1
        cols[ptr: ptr + n] = i
        data[ptr: ptr + n] = f
        ptr += n

    from scipy.sparse import csr_matrix
    return csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))

def propose_candidate(seed: int = 42, budget_s: float = 1000, **kwargs):
    """
    Search for a non‑negative step‑function that minimises
    ``evaluate_sequence``.  The function respects a ~1000 s budget and
    returns the best sequence found as a plain Python list.
    """
    np.random.seed(seed)
    start = time.time()
    deadline = start + budget_s - 0.2      # safety margin for the final return

    # ------------------------------------------------------------------- #
    # Problem size – a few thousand entries give a reasonable trade‑off.
    n = 2500
    target_sum = np.sqrt(2.0 * n)          # we keep the ℓ₁‑norm fixed

    # pre‑compute FFT length (next power of two >= 2·n‑1)
    fft_len = 1 << ((2 * n - 1).bit_length())

    # ------------------------------------------------------------------- #
    # 1. Build a diverse set of seeds.
    seeds = []

    # ---- geometric families ------------------------------------------------
    # a_i = C * r^i  (r in (0,1))
    lambdas = np.logspace(-5, -1, 40)
    for lam in lambdas:
        r = 1.0 - lam
        r_n = r ** n
        denom = 1.0 - r_n
        if denom <= 0.0:
            continue
        C = target_sum * lam / denom
        a = C * (r ** np.arange(n))
        seeds.append(a)

    # ---- power‑law families ------------------------------------------------
    for p in np.linspace(0.3, 0.95, 30):
        base = 1.0 / np.power(np.arange(1, n + 1, dtype=np.float64), p)
        C = target_sum / base.sum()
        a = C * base
        seeds.append(a)

    # ---- double‑exponential mixtures --------------------------------------
    # a_i = C1 * r1^i + C2 * r2^i
    for r1 in [0.999, 0.995, 0.99]:
        for r2 in [0.9, 0.85, 0.8]:
            C1 = target_sum * 0.6 / (1.0 - r1 ** n)
            C2 = target_sum * 0.4 / (1.0 - r2 ** n)
            a = C1 * (r1 ** np.arange(n)) + C2 * (r2 ** np.arange(n))
            seeds.append(a)

    # ---- plateau + exponential decay --------------------------------------
    for k_frac in np.linspace(0.1, 0.6, 6):
        k = int(k_frac * n)
        plateau_val = target_sum * 0.5 / k if k > 0 else 0.0
        r = 0.96
        tail_len = n - k
        if tail_len > 0:
            C_tail = target_sum * 0.5 / (1.0 - r ** tail_len)
            tail = C_tail * (r ** np.arange(tail_len))
            a = np.concatenate([np.full(k, plateau_val), tail])
        else:
            a = np.full(n, plateau_val)
        seeds.append(a)

    # ---- random Dirichlet samples -----------------------------------------
    for _ in range(30):
        # gamma(1) gives exponential distribution; normalise to target_sum
        a = np.random.gamma(shape=1.0, scale=1.0, size=n)
        a = a / a.sum() * target_sum
        seeds.append(a)

    # ---- uniform fallback --------------------------------------------------
    seeds.append(np.full(n, target_sum / n))

    # ---- possibly use the global reference sequence -----------------------
    try:
        if isinstance(height_sequence_1, (list, tuple, np.ndarray)):
            hs = np.asarray(height_sequence_1, dtype=np.float64)
            if hs.shape[0] == n:
                hs = np.clip(hs, 0.0, 1000.0)
                hs = hs * (target_sum / hs.sum())
                seeds.append(hs)
    except Exception:
        pass

    # ------------------------------------------------------------------- #
    # 2. Scan seeds, keep the best (projected onto the simplex).
    best_seq = None
    best_score = float("inf")
    for idx, cand in enumerate(seeds):
        if time.time() >= deadline:
            break
        cand = projection_simplex(cand, target_sum)
        sc = _fast_score(cand, fft_len)
        if sc < best_score:
            best_score, best_seq = sc, cand.copy()
            print(f"[{time.time() - start:6.1f}s] seed {idx:03d} → score {sc:.6f}")

    # ------------------------------------------------------------------- #
    # 3. Projected Adam optimisation (sub‑gradient of the max‑functional).
    curr = best_seq.copy()
    best = curr.copy()
    best_score = _fast_score(best, fft_len)

    # Adam parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    m = np.zeros_like(curr)
    v = np.zeros_like(curr)
    t_adam = 0

    # base step size – a few percent of the average entry
    step_base = 0.05 * target_sum / n
    step_max = step_base * 30.0

    # progress counters
    it = 0
    no_improve = 0
    rel_tol = 1e-4       # tolerance for the active set (relative)

    while time.time() < deadline:
        # ----- convolution & current score ---------------------------------
        F = np.fft.rfft(curr, n=fft_len)
        conv = np.fft.irfft(F * F, n=fft_len)[: 2 * n - 1]
        max_val = conv.max()
        score = float(2.0 * n * max_val / (curr.sum() ** 2))

        # ----- keep global best --------------------------------------------
        if score < best_score - 1e-12:
            best_score, best = score, curr.copy()
            no_improve = 0
            # tighten step size a little when we make progress
            step_base = max(step_base * 0.95, 1e-9)
            print(f"[{time.time() - start:6.1f}s] iter {it:7d} → new best {score:.6f}")
        else:
            no_improve += 1

        # ----- sub‑gradient of the max ------------------------------------
        tol_abs = max_val * rel_tol
        active_idx = np.where(conv >= max_val - tol_abs)[0]

        grad = np.zeros_like(curr)
        idx_arr = np.arange(n)
        for k in active_idx:
            j = k - idx_arr
            mask = (j >= 0) & (j < n)
            grad[mask] += 2.0 * curr[j[mask]]

        # ----- Adam update -------------------------------------------------
        t_adam += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** t_adam)
        v_hat = v / (1.0 - beta2 ** t_adam)

        step_vec = -step_base * m_hat / (np.sqrt(v_hat) + eps)

        # clip the step length to avoid too large jumps
        step_norm = np.linalg.norm(step_vec)
        if step_norm > step_max:
            step_vec = step_vec * (step_max / step_norm)

        tentative = curr + step_vec
        tentative = np.clip(tentative, 0.0, 1000.0)
        curr = projection_simplex(tentative, target_sum)

        # ----- occasional jitter (helps to escape plateaus) --------------
        if np.random.rand() < 0.012:
            jitter = (np.random.randn(n) *
                      step_base * 5.0 / np.sqrt(n))
            curr = projection_simplex(
                np.clip(curr + jitter, 0.0, 1000.0), target_sum)

        # ----- restart after a long stagnation ---------------------------
        if no_improve > 8000:
            jitter = np.random.randn(n) * step_base * 20.0
            curr = projection_simplex(
                np.clip(best + jitter, 0.0, 1000.0), target_sum)
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            no_improve = 0
            print(f"[{time.time() - start:6.1f}s] restart after {it} iters")

        it += 1

    # ------------------------------------------------------------------- #
    # 4. Linear‑programming polishing (if SciPy is available).
    try:
        from scipy.optimize import linprog
        from scipy.sparse import csr_matrix
    except Exception:
        linprog = None

    if linprog is not None and time.time() < deadline - 5.0:
        f = best.copy()
        for lp_iter in range(20):
            if time.time() >= deadline - 5.0:
                break

            # current maximal convolution value (M)
            F = np.fft.rfft(f, n=fft_len)
            conv_f = np.fft.irfft(F * F, n=fft_len)[: 2 * n - 1]
            M = conv_f.max()

            # Toeplitz matrix for constraints (f * g)_k ≤ M
            A = _build_toeplitz_matrix(f)   # shape (2n‑1, n)
            b = np.full(2 * n - 1, M)

            # maximise Σ g_i  → minimise -Σ g_i
            res = linprog(
                c=-np.ones(n),
                A_ub=A,
                b_ub=b,
                bounds=[(0, None)] * n,
                method='highs',
                options={'presolve': True, 'time_limit': 30}
            )
            if not res.success or res.x is None:
                break

            g = res.x
            sum_g = g.sum()
            if sum_g < 1e-12:
                break

            # rescale to target ℓ₁‑norm and mix
            g = g * (target_sum / sum_g)
            t_mix = 0.15
            f_new = (1.0 - t_mix) * f + t_mix * g
            f_new = projection_simplex(f_new, target_sum)

            # evaluate new bound
            Fnew = np.fft.rfft(f_new, n=fft_len)

            Mnew = conv_new.max()
            score_new = float(2.0 * n * Mnew / (f_new.sum() ** 2))

            if score_new < best_score - 1e-9:
                best_score, best = score_new, f_new.copy()
                print(f"[{time.time() - start:6.1f}s] LP‑iter {lp_iter} → best {score_new:.6f}")

            if Mnew <= M * 0.999:
                f = f_new
            else:

    final_score = evaluate_sequence(best.tolist())
    print(f"Search finished. Final score reported by evaluate_sequence: {final_score:.6f}")

    return best.tolist()
