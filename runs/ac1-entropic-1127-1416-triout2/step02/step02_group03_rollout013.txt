It builds on the previous approach but adds a few new ideas:

* **Broader random search** – a 5‑parameter family (adds an exponential decay term) is explored quickly.
* **Weighted sub‑gradient step** – instead of using only the exact maximisers of the convolution, all indices whose value is within a (decreasing) tolerance of the maximum are taken into account.  This yields a smoother descent direction.
* **FFT‑based gradient** – the sub‑gradient for a whole mask of active indices can be computed with a single convolution, keeping the per‑iteration cost low.
* **Adaptive step size & tolerance** – the step size follows the classic `1/√t` schedule, while the tolerance starts relatively large (5 % of the current maximum) and shrinks over time.
* **Periodic jitter** – small random perturbations help escape flat regions.
* **Larger problem size** – the algorithm works with 12 000 coefficients (still cheap thanks to FFT) which gives a finer discretisation and usually a lower bound.

```python
"""
Propose a step‑function (non‑negative sequence) that minimises

    2 * n * max(conv(a,a)) / (sum(a)**2)

The algorithm consists of:

1.  A fast random sweep over a 5‑parameter family
    a_i = (i+1+α)^(-p) * (1 + β*i/(n-1)) * exp(-γ*i)
    (α≥0, 0.30≤p≤0.70, –0.9≤β≤2.5, 0≤γ≤5·10⁻⁴).

2.  A projected sub‑gradient descent that uses a *mask* of all
    convolution entries whose value lies within a tolerance of the
    current maximum.  The sub‑gradient for the whole mask is obtained
    by a single FFT‑based convolution, which makes the iteration cheap.

3.  Adaptive step size (η = η₀/√t), a tolerance that shrinks
    geometrically, and occasional tiny random jitter.

The best sequence observed during the whole run is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities (all top‑level, no closures)
# ----------------------------------------------------------------------


def _project_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of a vector onto the simplex
        { w | w_i ≥ 0, Σ w_i = target_sum } .
    Implements the algorithm of Duchi et al. (2008).
    """
    if target_sum < 0:
        raise ValueError("target_sum must be non‑negative")
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.zeros_like(v)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _full_convolution_fft(x: np.ndarray, y: np.ndarray = None) -> np.ndarray:
    """
    Compute the full (linear) convolution of one or two real vectors
    using a real FFT.
    If ``y`` is omitted, the convolution of ``x`` with itself is returned.
    """
    if y is None:
        y = x
    n = len(x)
    m = len(y)
    size = 1 << ((n + m - 1).bit_length())  # next power of two
    fx = np.fft.rfft(x, n=size)
    fy = np.fft.rfft(y, n=size)
    conv = np.fft.irfft(fx * fy, n=size)[: n + m - 1]
    return conv


def _max_conv(a: np.ndarray) -> float:
    """Maximum entry of a*a (full convolution)."""
    return _full_convolution_fft(a).max()


def _make_candidate(
    n: int,
    p: float,
    offset: float,
    beta: float,
    gamma: float,
) -> np.ndarray:
    """
    Build a raw (un‑normalised) sequence

        a_i = (i+1+offset)^(-p) *
              (1 + beta * i/(n-1)) *
              exp(-gamma * i)

    Clip negatives, then project onto the simplex
    Σ a_i = sqrt(2·n).
    """
    idx = np.arange(n, dtype=float)          # i = 0 … n‑1
    base = np.power(idx + 1.0 + offset, -p)
    tilt = 1.0 + beta * idx / (n - 1)
    decay = np.exp(-gamma * idx)
    raw = base * tilt * decay
    raw = np.maximum(raw, 0.0)
    target = math.sqrt(2.0 * n)
    return _project_simplex(raw, target)


def _subgradient_step_nearmax(
    a: np.ndarray,
    conv_full: np.ndarray,
    max_val: float,
    tol: float,
    step: float,
    target_sum: float,
) -> np.ndarray:
    """
    Perform one sub‑gradient step where the gradient is accumulated
    over *all* indices whose convolution value is within ``tol`` of
    the current maximum.

    The gradient for a mask of active indices can be written as

        g = 2 * (a_rev  *  mask)[offset : offset+n]

    where ``a_rev`` is ``a`` reversed and ``mask`` is a binary vector
    (1 = active, 0 = inactive).  The convolution is evaluated with a
    single FFT.
    """
    n = len(a)
    a_rev = a[::-1]

    # binary mask of active convolution entries
    mask = (conv_full >= max_val - tol).astype(float)

    # convolution a_rev * mask
    conv_rev = _full_convolution_fft(a_rev, mask)   # length = 3n‑2
    offset = n - 1
    g = 2.0 * conv_rev[offset : offset + n]

    cand = a - step * g
    cand = _project_simplex(cand, target_sum)
    return cand


# ----------------------------------------------------------------------
# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 123, budget_s: int = 1000, **kwargs):
    """
    Search for a sequence of non‑negative heights that minimizes

        2 * n * max(conv(a, a)) / (sum(a) ** 2)

    The routine respects the 1000 s time limit and returns the best
    sequence found.  It combines a random parametric sweep with a
    masked sub‑gradient descent that uses FFT‑based gradients.
    """
    np.random.seed(seed)
    # Leave a small safety margin for the harness.
    deadline = time.time() + budget_s - 2.0

    # ------------------------------------------------------------------
    # 0. Problem size – 12 000 works well with a 2¹⁵‑point FFT.
    # ------------------------------------------------------------------
    n = 12000
    target_sum = math.sqrt(2.0 * n)

    # ------------------------------------------------------------------
    # 1. Warm start – use the previously discovered sequence if it
    #    matches the chosen length, otherwise fall back to a simple
    #    power‑law candidate.
    # ------------------------------------------------------------------
    best_seq = None
    hs = globals().get("height_sequence_1")
    if isinstance(hs, list) and len(hs) == n:
        best_seq = np.array(hs, dtype=float)
        best_seq = _project_simplex(best_seq, target_sum)
    else:
        # power‑law start (p≈0.5, zero offset, no tilt/decay)
        best_seq = _make_candidate(n, p=0.5, offset=0.0, beta=0.0, gamma=0.0)

    # ------------------------------------------------------------------
    # 2. Coarse random exploration of the 5‑parameter family.
    #    Roughly 20 % of the time budget is spent here.
    # ------------------------------------------------------------------
    best_score = _max_conv(best_seq)          # because Σa = √(2n) ⇒ score = max conv
    print(f"[init] n={n:5d}  score={best_score:.6f}")

    sweep_deadline = time.time() + 0.20 * (deadline - time.time())
    while time.time() < sweep_deadline:
        p = np.random.uniform(0.30, 0.70)
        off = np.random.uniform(0.0, 12.0)
        beta = np.random.uniform(-0.9, 2.5)
        gamma = np.random.uniform(0.0, 5e-4)          # gentle exponential tail
        cand = _make_candidate(n, p, off, beta, gamma)
        cand_score = _max_conv(cand)
        if cand_score < best_score:
            best_score = cand_score
            best_seq = cand
            print(f"[sweep] new best {best_score:.6f}  p={p:.3f} α={off:.3f} β={beta:.3f} γ={gamma:.6f}")
            if best_score < 1.503:
                break

    # ------------------------------------------------------------------
    # 3. Masked projected sub‑gradient descent.
    # ------------------------------------------------------------------
    curr = best_seq.copy()
    step0 = 1.5                     # initial step size
    iteration = 0
    tol_factor = 0.05               # start with 5 % of the current max
    min_tol = 1e-8

    while time.time() < deadline:
        iteration += 1

        # Full convolution a*a
        conv_full = _full_convolution_fft(curr)
        M = conv_full.max()

        # Record best solution seen so far.
        if M < best_score:
            best_score = M
            best_seq = curr.copy()
            print(f"[sgd] iter {iteration:6d}  new best {best_score:.6f}")

            if best_score < 1.503:
                break

        # --- adaptive tolerance -------------------------------------------------
        # tolerance shrinks geometrically every few thousand iterations.
        if iteration % 4000 == 0:
            tol_factor = max(tol_factor * 0.85, 0.001)   # never go below 0.1 %
        tol = max(min_tol, M * tol_factor)

        # --- step size (1/√t) ---------------------------------------------------
        step = step0 / math.sqrt(iteration)

        # --- one masked sub‑gradient step --------------------------------------
        cand = _subgradient_step_nearmax(
            curr, conv_full, M, tol, step, target_sum
        )

        # occasional jitter to avoid stagnation
        if iteration % 250 == 0 and np.random.rand() < 0.25:
            jitter = (np.random.rand(n) - 0.5) * 0.02 * cand
            cand = cand + jitter
            cand = _project_simplex(cand, target_sum)

        curr = cand

    # ------------------------------------------------------------------
    # 4. Final report
    # ------------------------------------------------------------------
    print(f"Finished after {iteration} iterations – best score {best_score:.6f}")
    return best_seq.tolist()
```
