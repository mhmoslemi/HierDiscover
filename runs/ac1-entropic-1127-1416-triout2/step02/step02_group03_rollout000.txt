The goal is to minimise  

\[
\text{score}(a)=\frac{2n\;\max (a*a)}{(\sum a)^2},
\qquad a_i\ge 0 ,
\]

where `a*a` is the discrete self‑convolution.
If we keep the sum fixed to  

\[
\sum a_i = \sqrt{2n},
\]

the denominator is constant and the score equals the maximal
convolution value.  

The previous code used a sub‑gradient method on the *exact* max.
Here we replace the non‑smooth max by a **smooth soft‑max**
(“log‑sum‑exp”) and apply an Adam optimiser with projection onto the
simplex.  
The temperature of the soft‑max (`α`) is increased slowly, so early
iterations see a very smooth landscape (easy to escape plateaus) and
later iterations focus on the true maximum.

The algorithm consists of:

1. **Initialisation** – use the previously discovered `height_sequence_1`
   (if available) or a simple power‑law, projected onto the simplex.
2. **Main loop** – until the time budget expires  
   * compute the full convolution (`c = a*a`);
   * form soft‑max weights `w_k ∝ exp(α·c_k)`;
   * obtain the gradient of the soft‑max:
     \[
     \nabla = 2\;(w * a^{\text{rev}})_{[n-1:n-1+n]},
     \]
     where `*` is the full convolution and `a^{rev}` the reversed vector;
   * Adam update (`a ← a − η·∇`);
   * project back onto the simplex (`a_i ≥ 0, Σa_i = √{2n}`);
   * increase `α` a little and occasionally add a tiny random jitter.
3. **Best‑so‑far tracking** – the exact max‑convolution value is
   evaluated every iteration; the best sequence is kept and returned
   at the end.

All heavy operations are performed with real FFTs, so each iteration
costs `O(n log n)`.  With `n = 7000` a few‑hundred thousand
iterations comfortably fit into the 1000 s budget.

```python
"""
Propose a step‑function (non‑negative heights) with a very low evaluation
value using a smooth‑max (log‑sum‑exp) surrogate and Adam optimisation.
The algorithm keeps the sum fixed to sqrt(2·n) (the denominator of the
score is then constant) and projects after each update onto the simplex.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def _project_simplex(v: np.ndarray, target_sum: float) -> np.ndarray:
    """
    Euclidean projection of a vector onto the simplex
        { w | w_i ≥ 0, Σ w_i = target_sum }.
    Implements the algorithm of Duchi et al. (2008).
    """
    if target_sum < 0:
        raise ValueError("target_sum must be non‑negative")
    u = np.sort(v)[::-1]                     # sort descending
    cssv = np.cumsum(u) - target_sum
    ind = np.arange(1, len(v) + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        return np.zeros_like(v)
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def _next_pow_two(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _full_convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Full linear convolution a*b using a real FFT.
    Returns an array of length len(a)+len(b)-1.
    """
    n = len(a) + len(b) - 1
    size = _next_pow_two(n)
    fa = np.fft.rfft(a, n=size)
    fb = np.fft.rfft(b, n=size)
    conv = np.fft.irfft(fa * fb, n=size)[:n]
    return conv


def _max_conv(a: np.ndarray) -> float:
    """Maximum entry of the self‑convolution a*a."""
    return _full_convolution_fft(a, a).max()


def _make_power_law(n: int, p: float = 0.5, offset: float = 0.0) -> np.ndarray:
    """
    Generate a simple power‑law sequence a_i ∝ (i+1+offset)^{-p}
    and project it onto the simplex Σa = √(2·n).
    """
    idx = np.arange(n, dtype=float)
    raw = np.power(idx + 1.0 + offset, -p)
    target = np.sqrt(2.0 * n)
    return _project_simplex(raw, target)


# ----------------------------------------------------------------------
# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 123, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative sequence that minimises
        2 * n * max(conv(a,a)) / (sum(a)**2)

    The routine respects a 1000 s time limit and returns the best
    sequence found (as a plain Python list).
    """
    np.random.seed(seed)
    stop_time = time.time() + budget_s - 2.0          # safety margin

    # ------------------------------------------------------------------
    # 0. Choose the sequence length.
    # ------------------------------------------------------------------
    n = 7000                                          # comfortable for the budget
    target_sum = np.sqrt(2.0 * n)

    # ------------------------------------------------------------------
    # 1. Initialise a starting point.
    # ------------------------------------------------------------------
    start_seq = None
    # Use the previously discovered construction if it matches the length.
    global height_sequence_1
    try:
        hs = globals().get("height_sequence_1")
        if isinstance(hs, list) and len(hs) == n:
            start_seq = np.array(hs, dtype=float)
            start_seq = _project_simplex(start_seq, target_sum)
    except Exception:
        start_seq = None

    if start_seq is None:
        # Simple power‑law start.
        start_seq = _make_power_law(n, p=0.5, offset=0.0)

    # ------------------------------------------------------------------
    # 2. Adam optimiser state.
    # ------------------------------------------------------------------
    a = start_seq.copy()
    m = np.zeros_like(a)               # first moment
    v = np.zeros_like(a)               # second moment
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    lr = 0.08                          # base learning rate
    t = 0                               # iteration counter

    # Soft‑max temperature (α). Start low, increase slowly.
    alpha = 5.0
    alpha_max = 150.0
    alpha_inc_factor = 1.005           # multiplicative increase per iteration

    best_seq = a.copy()
    best_score = _max_conv(a)          # because Σa = √(2n) ⇒ score = max conv
    print(f"[init] n={n} target_sum={target_sum:.4f} score={best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Main optimisation loop.
    # ------------------------------------------------------------------
    while time.time() < stop_time:
        t += 1

        # ----- convolution and exact max (for tracking) -----
        conv_full = _full_convolution_fft(a, a)          # length 2n‑1
        M = conv_full.max()
        if M < best_score:
            best_score = M
            best_seq = a.copy()
            print(f"[iter {t:6d}] new best score {best_score:.6f}")
            if best_score < 1.503:                      # target reached
                break

        # ----- soft‑max weights -----
        # w_k ∝ exp(α·c_k)  (shifted by the max to avoid overflow)
        shifted = conv_full - M
        w = np.exp(alpha * shifted)
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.size)
        else:
            w /= w_sum

        # ----- gradient of the smooth max -----
        a_rev = a[::-1]
        # full convolution w * a_rev  → length 3n‑2
        conv_w_rev = _full_convolution_fft(w, a_rev)
        grad = 2.0 * conv_w_rev[n - 1 : n - 1 + n]        # slice of length n

        # ----- Adam update -----
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)
        a = a - step

        # ----- projection onto the simplex (non‑negativity & fixed sum) -----
        a = _project_simplex(a, target_sum)

        # ----- temperature schedule -----
        if alpha < alpha_max:
            alpha = min(alpha_max, alpha * alpha_inc_factor)

        # ----- occasional random jitter to avoid stagnation -----
        if t % 200 == 0 and np.random.rand() < 0.15:
            jitter = (np.random.rand(n) - 0.5) * 0.02 * a   # up to ±1 % of each entry
            a = a + jitter
            a = _project_simplex(a, target_sum)

    # ------------------------------------------------------------------
    # 4. Return the best sequence observed.
    # ------------------------------------------------------------------
    print(f"Finished after {t} iterations – best score {best_score:.6f}")
    return best_seq.tolist()
```
