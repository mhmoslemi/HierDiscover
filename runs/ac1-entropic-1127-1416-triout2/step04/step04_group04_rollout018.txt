The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max\bigl((a*a)\bigr)}{(\sum_i a_i)^2},
\]

for a non‑negative vector `a`.  
The score is invariant under scaling, therefore we can work on the
probability simplex (`∑a_i = 1`).  
`max(a*a)` is the maximum entry of the linear convolution of `a` with
itself, a non‑smooth function.  

The previous implementation used a sub‑gradient (exponentiated‑gradient) on
the true objective.  Here we improve the search in three ways:

1. **Smooth approximation of the max** – we replace the hard max by a
   temperature‑controlled *log‑sum‑exp* (soft‑max).  For a temperature
   β the smooth objective  

   \[
   f_β(a)=\frac{1}{β}\log\!\Bigl(\sum_k e^{β\, (a*a)_k}\Bigr)
   \]

   is a differentiable upper‑bound of `max(a*a)`.  As β grows the bound
   tightens.

2. **Soft‑max parametrisation** – the vector `a` is written as a soft‑max
   of free parameters `w` (`a_i = e^{w_i}/∑_j e^{w_j}`), guaranteeing
   non‑negativity and the simplex constraint without any projection.

3. **Adam optimisation on the smooth problem** – we run a few thousand
   Adam steps for each random restart, gradually increasing β so that the
   optimisation moves from a smooth landscape to the true objective.
   The gradient of the smooth objective w.r.t. `w` can be expressed
   analytically using one FFT‑based convolution, giving a fast per‑step
   cost *O(n log n)*.

The algorithm performs many short random restarts (Dirichlet draws) and
keeps the best vector seen (according to the official `evaluate_sequence`
function).  A final polish with a longer Adam run is executed on the
global best if time permits.

The implementation respects the 1000 s budget, prints progress, and
always returns a feasible list of non‑negative floats.

```python
"""
search_step_function.py

A fast ADAM optimiser that minimises the official objective by
optimising a smooth log‑sum‑exp approximation of the convolution
maximum.  The parameters are the logits of a soft‑max, guaranteeing a
non‑negative vector on the probability simplex.  Multiple random restarts
are performed; the best sequence found (according to evaluate_sequence)
is returned.
"""

import time
import numpy as np
from typing import List, Tuple

# ----------------------------------------------------------------------
# Low‑level numeric utilities (FFT‑based convolution)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Linear convolution of two real vectors using real FFT.
    Results are truncated to the true linear convolution length.
    """
    m = len(a) + len(b) - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def gradient_from_weights(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of  Σ_k w_k·(a*a)_k   with respect to a.
    Implements g_j = 2· Σ_m a_m·w_{m+j}.
    Computed via a single FFT‑based convolution.
    """
    w_rev = w[::-1]                     # reverse order of the weight vector
    conv = convolution_fft(a, w_rev)    # length = len(a)+len(w_rev)-1 = 3·n‑2
    idx = 2 * len(a) - 2                # position of the centre of the full convolution
    grads = 2.0 * conv[idx - np.arange(len(a))]
    return grads


# ----------------------------------------------------------------------
# Simple families – useful for a quick deterministic fallback
# ----------------------------------------------------------------------


def uniform_shape(n: int) -> np.ndarray:
    """Uniform probability vector (∑ a_i = 1)."""
    return np.full(n, 1.0 / n)


def arcsine_initial(n: int) -> np.ndarray:
    """
    Discrete arcsine‑like shape:
        a_i ∝ 1 / sqrt((i+½)(n‑½‑i) + ε)
    The small ε avoids division by zero.
    """
    i = np.arange(n, dtype=float)
    eps = 0.25
    vals = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    vals /= vals.sum()
    return vals


# ----------------------------------------------------------------------
# Optimisation of the smooth surrogate
# ----------------------------------------------------------------------


def _softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable soft‑max."""
    m = np.max(x)
    e = np.exp(x - m)
    return e / e.sum()


def smooth_max_optimize(
    a0: np.ndarray,
    deadline: float,
    *,
    max_iter: int = 4000,
    beta_start: float = 0.5,
    beta_end: float = 20.0,
    lr: float = 0.12,
) -> Tuple[np.ndarray, float]:
    """
    Adam optimisation of the smoothed objective
        f_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)

    a is kept on the simplex via a soft‑max parametrisation.
    Returns the best vector (according to the official evaluate_sequence)
    encountered during the run and its score.
    """
    n = len(a0)
    # Initialise logits (log‑soft‑max variables)
    w = np.log(a0 + 1e-12)

    # Adam state
    m1 = np.zeros_like(w)
    m2 = np.zeros_like(w)
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8

    # Temperature schedule (geometric growth)
    if max_iter > 1:
        beta_factor = (beta_end / max(beta_start, 1e-12)) ** (1.0 / (max_iter - 1))
    else:
        beta_factor = 1.0
    beta = beta_start

    # Keep the best vector seen (according to the true objective)
    best_a = a0.copy()
    best_val = float("inf")

    for it in range(1, max_iter + 1):
        # ----- time guard -------------------------------------------------
        if time.time() >= deadline:
            break

        # ----- a = softmax(w) (ensures ∑a=1, a≥0) -----------------------
        a = _softmax(w)

        # ----- convolution a*a -------------------------------------------
        conv = convolution_fft(a, a)                     # length 2n‑1

        # ----- smooth‑max weights (soft‑max over the convolution entries) --
        # Use the current temperature β.
        max_c = np.max(conv)
        exp_c = np.exp(beta * (conv - max_c))
        W = exp_c / np.sum(exp_c)                        # shape (2n‑1,)

        # ----- gradient w.r.t. a (of Σ_k W_k·(a*a)_k ) -------------------
        g_a = gradient_from_weights(a, W)                # shape (n,)

        # ----- chain rule: ∂f/∂w = a * (g_a – (a·g_a)) --------------------
        dot = np.dot(g_a, a)
        g_w = a * (g_a - dot)

        # ----- Adam update ------------------------------------------------
        m1 = beta1 * m1 + (1.0 - beta1) * g_w
        m2 = beta2 * m2 + (1.0 - beta2) * (g_w * g_w)
        m1_hat = m1 / (1.0 - beta1 ** it)
        m2_hat = m2 / (1.0 - beta2 ** it)
        w -= lr * m1_hat / (np.sqrt(m2_hat) + eps)

        # ----- increase temperature (tighten the bound) -------------------
        beta = min(beta_end, beta * beta_factor)

        # ----- occasional evaluation with the real objective ----------------
        if it % 200 == 0 or it == max_iter:
            cur_val = evaluate_sequence(a.tolist())
            if cur_val < best_val:
                best_val = cur_val
                best_a = a.copy()
                print(f"    iter={it:5d}  β={beta:.2f}  score={cur_val:.6f}")

    return best_a, best_val


# ----------------------------------------------------------------------
# Main entry point required by the competition harness
# ----------------------------------------------------------------------


def propose_candidate(
    seed: int = 42,
    budget_s: int = 1000,
    **kwargs,
) -> List[float]:
    """
    Search for a non‑negative step‑function that minimises
        2·n·max(conv(a,a)) / (sum(a)²)

    The routine:
      * tries a small deterministic fallback (uniform / arcsine),
      * performs many short Adam runs on a smooth surrogate of the max,
        each starting from a random Dirichlet draw,
      * keeps the best vector seen (according to the official evaluation),
      * optionally applies a longer final polishing run,
      * always returns a feasible list of floats.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    # keep a tiny safety margin to avoid hard timeout
    deadline = start_time + budget_s - 2.0

    best_seq: List[float] = []
    best_val: float = float("inf")

    # ------------------------------------------------------------------
    # 0.  deterministic fallback (uniform & arcsine)
    # ------------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]  # type: ignore
        val = evaluate_sequence(fallback)
        print(f"[fallback] score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, fallback
    except NameError:
        pass

    # ------------------------------------------------------------------
    # 1.  random restarts on a chosen length
    # ------------------------------------------------------------------
    # 2048 gives a good balance between expressive power and speed.
    n = 2048
    print(f"\n=== Optimising length n = {n} ===")
    restarts = 30

    for r in range(restarts):
        if time.time() >= deadline - 5.0:
            break

        # initialise a random point on the simplex (Dirichlet / exponential)
        a0 = rng.exponential(1.0, size=n)
        a0 = a0 / a0.sum()

        # occasionally blend with a simple deterministic shape to diversify
        if r % 7 == 0:
            a0 = (a0 + arcsine_initial(n)) / 2.0
            a0 = a0 / a0.sum()

        # Decide a modest iteration budget based on the remaining time.
        # Roughly 1500 it/s for n≈2000 on a typical CPU.
        remaining = max(0.0, deadline - time.time())
        max_iter = int(min(5000, max(500, remaining * 1500.0)))

        refined, _ = smooth_max_optimize(
            a0,
            deadline,
            max_iter=max_iter,
            beta_start=0.5,
            beta_end=25.0,
            lr=0.12,
        )

        # final official evaluation
        val = evaluate_sequence(refined.tolist())
        print(f"[restart {r+1:2d}/{restarts}] evaluated score = {val:.6f}")

        if val < best_val:
            best_val, best_seq = val, refined.tolist()
            print(f" *** New global best: {best_val:.6f} ***")

    # ------------------------------------------------------------------
    # 2.  Final polishing of the global best (if time permits)
    # ------------------------------------------------------------------
    if best_seq and time.time() < deadline - 5.0:
        print("\n--- Final polishing of the best sequence ---")
        a_best = np.array(best_seq, dtype=float)
        remaining = max(0.0, deadline - time.time())
        max_iter = int(min(20000, max(2000, remaining * 1500.0)))

        polished, _ = smooth_max_optimize(
            a_best,
            deadline,
            max_iter=max_iter,
            beta_start=5.0,
            beta_end=40.0,
            lr=0.08,
        )
        val = evaluate_sequence(polished.tolist())
        print(f"Polished score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, polished.tolist()
            print("*** Updated global best after polishing ***")

    # ------------------------------------------------------------------
    # 3.  Guard – always return a feasible sequence.
    # ------------------------------------------------------------------
    if not best_seq:
        # fallback to a safe uniform vector
        best_seq = uniform_shape(256).tolist()
        best_val = evaluate_sequence(best_seq)

    print(f"\nSearch finished. Best score = {best_val:.6f}")
    return best_seq
```
