def compute_conv(a):
    n = len(a)
    L = 1 << ((2*n-1).bit_length()) # next power of two
    fft_a = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fft_a * fft_a, n=L)[:2*n-1]
    return conv

The goal is to minimise  

```
2·n·max( a*a )      with   a_i ≥ 0 ,   Σ a_i = 1
```

where `a*a` denotes the linear (zero‑padded) self‑convolution of the
height vector `a`.  
`evaluate_sequence` is scale‑invariant, therefore we keep the vector on the
probability simplex (`Σa=1`).  

The new optimiser follows **deterministic annealing**:

1. **Smooth max** – replace the non‑differentiable `max` by a
   temperature‑controlled soft‑maximum  

   ```
   Sτ(a) = τ·log Σ_k exp( (a*a)_k / τ )
   ```

   For large τ the objective is almost quadratic, for τ→0 it converges to
   the true max.

2. **Exact gradient** – the gradient of `Sτ` is obtained analytically:

   * let `c = a*a`                (FFT for speed)  
   * let `w_k = exp((c_k‑maxc)/τ) / Σ exp((c‑maxc)/τ)` (soft‑max weights)  
   * `∇Sτ = 2· ( w  ★  a )`               (★ = cross‑correlation)

   The correlation is computed with one extra FFT.

3. **Adam on the simplex** – a standard Adam update is applied to the
   weight vector and then projected back onto the simplex (Duchi et al.
   2008).  Adam automatically adapts learning rates per coordinate,
   which is far more robust than a plain sub‑gradient step.

4. **Temperature schedule** – τ is decreased geometrically
   (`τ←τ·decay`) so that the optimisation starts in a smooth landscape and
   slowly focuses on the true `max`.  When τ becomes tiny the update
   coincides with a sub‑gradient step on the original objective.

5. **Best‑ever bookkeeping** – every few hundred iterations the exact
   (non‑smooth) score `2·n·max(a*a)` is evaluated; the best vector found
   so far is kept.

The whole routine runs for the allotted time (default 1000 s) and finally
returns the best probability vector discovered.  All operations are
implemented with NumPy/FFT, therefore each iteration is `O(n log n)` and
comfortably fits into the time budget even for `n≈5000`.

"""
deterministic‑annealing optimiser for ``evaluate_sequence``

The algorithm works on the probability simplex (Σa=1, a_i≥0) and
minimises the infinity‑norm of the self‑convolution.
A temperature‑controlled soft‑max is used to obtain a smooth loss;
its exact gradient is computed by FFT‑based correlation.
Adam updates with a projection onto the simplex drive the search.
The temperature is reduced geometrically, turning the smooth problem
into the original max‑convolution problem.
The best vector found within the time budget is returned.
"""

import time
import math
import numpy as np

# --------------------------------------------------------------
# Helper utilities – all top‑level, no closures
# --------------------------------------------------------------


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex.
    Implements the algorithm of Duchi et al. (ICML 2008).
    """
    n = v.shape[0]
    # sort descending
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # numerical safety – return uniform
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / rho
    w = np.maximum(v - theta, 0.0)
    return w


def compute_full_convolution(a: np.ndarray, L: int) -> np.ndarray:
    """
    Linear (zero‑padded) self‑convolution a*a using FFT.
    Returns the first (2·len(a)‑1) entries.
    """
    n = a.shape[0]
    fa = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fa * fa, n=L)[: 2 * n - 1]
    return conv


def smooth_max_gradient(a: np.ndarray,
                        conv: np.ndarray,
                        tau: float,
                        L: int) -> np.ndarray:
    """
    Exact gradient of the smooth maximum   τ·log Σ exp(conv/τ)
    with respect to the probability vector a.
    """
    # soft‑max weights (numerically stable)
    maxc = conv.max()
    exp_term = np.exp((conv - maxc) / tau)
    w = exp_term / exp_term.sum()          # shape (2n‑1,)

    # cross‑correlation w ★ a  ==  (w reversed) * a  (convolution)
    w_rev = w[::-1]

    fa = np.fft.rfft(a, n=L)
    fw = np.fft.rfft(w_rev, n=L)
    corr_full = np.fft.irfft(fa * fw, n=L)
    # length = n + (2n‑1) – 1 = 3n‑2 ; we need entries offset‑i
    offset = len(w) - 1                     # = 2n‑2
    grad = 2.0 * corr_full[offset - np.arange(a.shape[0])]
    return grad


def exact_score(a: np.ndarray, L: int) -> float:
    """
    Returns the true evaluation value 2·n·max(a*a)
    (no scaling – the sum of a is assumed to be 1).
    """
    conv = compute_full_convolution(a, L)
    return 2.0 * a.shape[0] * conv.max()
