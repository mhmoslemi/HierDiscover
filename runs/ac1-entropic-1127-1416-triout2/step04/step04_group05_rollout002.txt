def propose_candidate(seed=0, budget_s=1000):
    np.random.seed(seed)
    # Initialize n: maybe 5000 or use existing.
    try: n = len(height_sequence_1); a = np.array(height_sequence_1) / sum(height_sequence_1)
    except: n=5146; a = np.ones(n)/n
    # Setup schedule:
    t0 = time.time()
    deadline = t0 + budget_s - 0.5

    # compute initial conv, score.
    best_score = compute_score(a) # current true objective
    best_a = a.copy()

    # Choose schedule for beta (softmax temperature)
    beta = 0.1  # start low (smooth)
    beta_max = 1000.0  # large enough to approximate max
    beta_factor = 1.2  # multiplicative increase per outer loop

    while time.time() < deadline:
        # inner gradient descent for current beta
        # determine number of iterations based on remaining time
        inner_iters = 1000
        for it in range(inner_iters):
            if time.time() >= deadline: break
            # compute conv
            fft_a = np.fft.rfft(a, n=2*n-1)
            conv = np.fft.irfft(fft_a * fft_a, n=2*n-1)
            # compute smooth loss L = (1/beta) * logsumexp(beta * conv)
            # but for numeric stability: use max of conv
            maxc = conv.max()
            # compute scaled weights w = exp(beta * (conv - maxc))
            w = np.exp(beta * (conv - maxc))
            w_sum = w.sum()
            w /= w_sum  # softmax
            # gradient: 2 * (w convolve a_rev)[offset]
            a_rev = a[::-1]
            # convolution via FFT
            L = 1
            # Find appropriate FFT length: next_pow2
            m = 2*n-1 + n - 1
            L = 1 << (m-1).bit_length()
            # compute conv of w and a_rev:
            fft_w = np.fft.rfft(w, n=L)
            fft_ar = np.fft.rfft(a_rev, n=L)
            grad = 2.0 * np.fft.irfft(fft_w * fft_ar, n=L)  # length L
            # extract relevant part
            # grad_full length L, want indices n-1 : n-1 + n
            grad = grad[n-1:n-1+n]
            # exponentiated update
            step = 0.5 / np.sqrt(it+1)  # decreasing step
            a = a * np.exp(-step * grad)
            # renorm
            a_sum = a.sum()
            if a_sum == 0 or not np.isfinite(a_sum):
                a = np.ones_like(a)/len(a)
            else:
                a = np.maximum(a, 1e-15)
                a /= a.sum()
        # after inner loop evaluate true objective
        cur_score = compute_score(a)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"beta {beta:.3e} improvement: best_score {best_score:.6f}")
        # increase beta
        beta = min(beta * beta_factor, beta_max)
        # If beta reached max and improvement stalls, break or random restart
        # optional random restart if stuck
        if beta >= beta_max and best_score - cur_score < 1e-6:
            # random restart
            a = np.random.dirichlet(np.ones(n))
            beta = 0.1
            print("Random restart")
    # final best a: scale to sum=1 (already)
    return [float(v) for v in best_a.tolist()]

assistantfinal**Solution Overview**  

The evaluation function  

\[
E(a)=\frac{2\,n\;\max\_{k}(a\ast a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is scale‑invariant, therefore we may restrict the search to **probability vectors**
\(\sum_i a_i = 1,\; a_i\ge 0\).  
For a probability vector `a` the objective simplifies to  

\[
F(a)=2\,n\;\max_k (a\ast a)_k .
\]

The exact maximum is a non‑smooth function, which makes plain sub‑gradient
methods (the code you posted) get stuck in local plateaus.
The new algorithm follows three ideas:

1. **Smooth surrogate** – replace `max` by a temperature‑controlled soft‑max  

   \[
   L_\beta(a)=\frac1\beta\log\!\Bigl(\sum_k e^{\beta\,(a\ast a)_k}\Bigr) .
   \]

   When \(\beta\) is small the loss is almost the average of the convolution,
   when \(\beta\to\infty\) it converges to the true `max`.  
   By *deterministic annealing* (gradually increasing `β`) we can follow a
   smooth path to a good local minimum.

2. **Exact gradient of the surrogate** – for the soft‑max the gradient is

   \[
   \frac{\partial L_\beta}{\partial a_i}
   = 2\sum_k w_k\,a_{k-i},\qquad
   w_k=\frac{e^{\beta\,(a\ast a)_k}}{\sum_j e^{\beta\,(a\ast a)_j}} .
   \]

   Both the convolution and the weighted convolution needed for the gradient
   are computed with a single FFT of length  
   \(L\ge 3n-2\) ( `np.fft.rfft` / `irfft` ), i.e.  \(O(n\log n)\) per iteration.

3. **Mirror‑descent on the simplex** – we keep the variables non‑negative and
   automatically on the simplex by an *exponentiated‑gradient* (multiplicative)
   update  

   \[
   a_i \leftarrow a_i\; \exp\!\bigl(-\eta\,\partial_i L_\beta\bigr),
   \qquad a\leftarrow a/\sum a .
   \]

   The step‑size \(\eta\) decays like \(1/\sqrt{t}\).

The algorithm proceeds as follows  

* **(a) Fast parametric warm‑start** – a short sweep over the
  two‑parameter Beta‑family  
  \(B(\alpha,\beta)\) (U‑shaped, uniform, bell‑shaped).  
  The best Beta‑vector becomes the initial point for the annealing phase.

* **(b) Deterministic‑annealing mirror‑descent** – start with a small
  temperature (`β≈0.5`), perform several thousand mirror‑descent steps,
  then increase `β` geometrically (`β←β·1.3`) until a large value
  (`β≈2000`).  The current best point (according to the *true* objective
  `2·n·max(conv)`) is stored.

* **(c) Optional diversification** – if the score does not improve for a
  while we mix the current best point with a fresh Dirichlet draw and reset
  `β`.  This keeps the search from being trapped forever.

All work is performed inside the time budget (≤ 1000 s).  
The function returns the best probability vector found; the evaluator will
scale it automatically, so the returned sequence is ready to be passed to
`evaluate_sequence`.

"""
Propose a step‑height sequence that minimises ``evaluate_sequence``.

Algorithm
---------
1.  Warm‑start: sweep a two‑parameter Beta‑family (α,β) and keep the best
    discretised density (already a probability vector).

2.  Deterministic annealing: minimise the smooth surrogate
        L_β(a) = (1/β)·log∑_k exp(β·(a*a)_k)
    using exponentiated‑gradient (mirror‑descent) on the probability simplex.
    β is increased geometrically (β←1.3·β) – this drives the surrogate gradually
    to the true max‑convolution objective.

3.  Gradient of L_β is
        ∂L/∂a_i = 2·(w ∗ a_rev)[i+n‑1]      with   w_k ∝ exp(β·(a*a)_k) .
    Both convolutions are performed with a single FFT of length ≥ 3·n‑2.

4.  Occasionally (if no improvement) restart from a mixture of the current
    best point and a random Dirichlet sample.

The function respects the 1000 s limit, prints progress and finally returns
the best probability vector (non‑negative, sum = 1) discovered.

def _next_pow2(x: int) -> int:
    """Small helper: smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def _proj_to_simplex_exp(v: np.ndarray) -> np.ndarray:
    """
    Exponentiated‑gradient style projection onto the probability simplex:
    keep entries positive and renormalise.
    """
    v = np.maximum(v, 1e-15)
    s = v.sum()
    if s == 0.0 or not np.isfinite(s):
        return np.ones_like(v) / v.size
    return v / s


def _conv_self(a: np.ndarray, fft_len: int) -> np.ndarray:
    """Return the linear convolution a*a (length 2·n‑1) using FFT of length fft_len."""
    fft_a = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fft_a * fft_a, n=2 * a.size - 1)
    return conv


def _gradient_softmax_conv(a: np.ndarray, beta: float, fft_len: int,
                          conv: np.ndarray) -> np.ndarray:
    """
    Gradient of the soft‑max surrogate L_β at point a.
    conv must be the self‑convolution of a (length 2·n‑1).
    """
    # soft‑max weights
    maxc = conv.max()
    w = np.exp(beta * (conv - maxc))
    w_sum = w.sum()
    if w_sum == 0 or not np.isfinite(w_sum):
        w = np.ones_like(w) / w.size
    else:
        w /= w_sum

    # gradient = 2·(w ∗ a_rev)[i+n‑1]
    a_rev = a[::-1]
    fft_w = np.fft.rfft(w, n=fft_len)
    fft_ar = np.fft.rfft(a_rev, n=fft_len)
    grad_full = np.fft.irfft(fft_w * fft_ar, n=fft_len)
    n = a.size
    grad = grad_full[n - 1:n - 1 + n]       # slice the needed n entries
    grad *= 2.0
    return grad


def _beta_sequence(alpha: float, beta: float, n: int) -> np.ndarray:
    """
    Discretised Beta(α,β) density on n points, normalised to sum = 1.
    """
    x = (np.arange(n) + 0.5) / n
    # compute in log‑space to avoid overflow for extreme parameters
    logw = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    logw = np.clip(logw, -700.0, 700.0)   # stay in double range
    w = np.exp(logw)
    if not np.isfinite(w.sum()) or w.sum() == 0.0:
        w = np.ones_like(w)
    w /= w.sum()
    return w


def _true_score(a: np.ndarray) -> float:

    Exact value of ``evaluate_sequence`` for a probability vector.
    Returns 2·n·max(conv) where conv = a * a.
    """
    n = a.shape[0]
    # convolution length = 2·n‑1, FFT length can be any ≥ this
    fft_len = _next_pow2(2 * n - 1)
    conv = _conv_self(a, fft_len)
    return 2.0 * n * conv.max()

                cur_score = _true_score(a)
                if cur_score < best_score:
                    best_score = cur_score
                    best_a = a.copy()
                    last_improve = it
                    print(f"Iter {it:6d} (β={beta_temp:.1f}) new best {best_score:.6f}")

            it += 1

        # ----- increase temperature (make the surrogate sharper) -----
        beta_temp = min(beta_temp * beta_factor, beta_max)
        print(f"Temperature increased → β = {beta_temp:.2f}")

        # ----- optional diversification if we have stalled for a while -----
        if it - last_improve > 60000 and time.time() < deadline:
            # mix the best found point with a fresh Dirichlet sample
            mix = np.random.dirichlet(np.ones(n))
            a = 0.5 * best_a + 0.5 * mix
            a = _proj_to_simplex_exp(a)
            beta_temp = 0.5
            last_improve = it
            print("Diversification restart performed")

    # --------------------------------------------------------------
    # 3 – Return the best sequence (still a probability vector)
    # --------------------------------------------------------------
    best_a = best_a / best_a.sum()
    print(f"Finished – best score found = {best_score:.6f}")
    return [float(v) for v in best_a.tolist()]
