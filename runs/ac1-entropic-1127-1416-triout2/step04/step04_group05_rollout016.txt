assistantfinal**Solution Overview**

The score of a non‑negative sequence `a` (with `sum(a)=1`) is  

```
score(a) = 2·n·max( a ＊ a )
```

where `＊` denotes the *linear* convolution.  
`max(a＊a)` is the only term that matters – the sum is fixed – therefore we try to make the
self‑convolution as flat as possible.  
The optimum would be a perfectly flat convolution (`max = 1/(2n‑1)`) giving a theoretical
lower bound `score≈1`.  The previous implementation (hard sub‑gradient + simulated annealing)
stops at about `1.515`.  

The new method uses three ideas:

1. **Soft‑max smoothing of the `max` operator** –  
   instead of the exact sub‑gradient of `max(conv)` we minimise  

   ```
   Fβ(a) = (1/β)·log Σ_k exp( β·conv_k )
   ```

   For small `β` the objective is smooth, for large `β` it becomes the true
   `max`.  The gradient of `Fβ` can be written in closed form and is obtained
   by a single convolution.

2. **Exponentiated‑gradient (mirror‑descent) on the probability simplex** –  
   the update `a ← a·exp(‑η·∇Fβ)` automatically respects `a_i≥0`.  After the
   multiplicative step we renormalise the vector, i.e. stay on the simplex.

3. **Continuation in β** – we start with a small smoothing factor (`β≈0.5`) and
   double it every *B* iterations (up to `β≈128`).  This lets the optimiser
   first move quickly in a smooth landscape and then focus on the true
   `max`‑constraint.

When the time budget is almost exhausted a short **simulated‑annealing**
phase makes small pairwise mass transfers to fine‑tune the result.

The complete algorithm runs completely on the simplex, never produces illegal
values and returns the best sequence seen during the run.

```python
"""
propose_candidate – minimise evaluate_sequence

The algorithm consists of three phases

1.  Soft‑max (β‑continuation) exponentiated‑gradient descent on the simplex.
    For the current vector a we compute the full self‑convolution
    conv = a * a, build a soft‑max weighting
        p_k ∝ exp( β·(conv_k – max(conv)) ),
    obtain the gradient
        ∇Fβ = 2·( a ＊ p )   (first n entries only)
    and perform a mirror‑descent step
        a ← a·exp(‑η·∇Fβ) ,   a ← a / sum(a).

    β is increased geometrically (0.5, 1, 2, 4, …) so that the optimisation
    first moves in a smooth landscape and later concentrates on the true
    max‑constraint.

2.  Random restarts – every few hundred thousand iterations a fresh Dirichlet
    sample is tried; if it improves the best score it replaces the current
    point.

3.  Guided simulated‑annealing – starting from the best point found in phase 1,
    a small amount of probability mass is transferred from a “high‑gradient”
    index to a “low‑gradient” index.  Moves that improve the score are always
    accepted; worsening moves are accepted with Metropolis probability with a
    slowly decreasing temperature.

All operations stay on the probability simplex, therefore the sequence is
always valid for ``evaluate_sequence``.  The routine stops after the allotted
budget (default 1000 s) and returns the best sequence discovered.
"""

import time
import math
import numpy as np

# Helper routines – all top‑level, no closures
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Small utility returning the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def compute_full_conv(a: np.ndarray) -> np.ndarray:
    """
    Linear convolution a * a (full length 2·len(a)-1) using FFT.
    """
    n = a.shape[0]
    L = _next_pow2(2 * n - 1)
    fft = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fft * fft, n=L)[: 2 * n - 1]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact value of ``evaluate_sequence`` for a vector whose sum is 1.
    Returns 2·n·max(conv) where conv = a * a (linear convolution).
    """
    n = a.shape[0]
    conv = compute_full_conv(a)
    return 2.0 * n * conv.max()


def subgradient_of_max_conv(a: np.ndarray, conv: np.ndarray) -> np.ndarray:
    """
    Sub‑gradient of max(conv) at a (average over all active indices).
    Identical to the routine used by the previous solution – kept for the
    final simulated‑annealing phase.
    """
    n = a.shape[0]
    max_b = conv.max()
    eps = max_b * 1e-6
    active = np.where(conv >= max_b - eps)[0]

    if active.size == 0:
        return 2.0 * a

    grad = np.zeros_like(a)
    for k in active:
        low = max(0, k - n + 1)
        high = min(n - 1, k)
        idx = np.arange(low, high + 1, dtype=int)
        partner = k - idx
        grad[idx] += 2.0 * a[partner]
    grad /= float(active.size)
    return grad


def exponential_update(a: np.ndarray, grad: np.ndarray, step: float) -> np.ndarray:
    """
    Mirror‑descent (exponentiated‑gradient) update on the simplex.
    a is multiplied element‑wise by exp(‑step·grad) and then normalised.
    A tiny lower‑bound prevents under‑flow.
    """
    factor = np.exp(-step * grad)
    # Clip multiplicative factors to a safe interval
    factor = np.clip(factor, 1e-30, 1e30)
    a_new = a * factor
    a_new = np.clip(a_new, 1e-30, None)   # stay strictly positive
    a_new /= a_new.sum()
    return a_new


def _softmax_weights(conv: np.ndarray, beta: float) -> np.ndarray:
    """
    Return a probability vector p proportional to exp(β·conv).
    The subtraction of max(conv) guarantees numerical stability.
    """
    max_c = conv.max()
    scaled = beta * (conv - max_c)
    # Clip the exponent to avoid overflow (np.exp can handle up to ~709 safely)
    scaled = np.clip(scaled, -700.0, 700.0)
    w = np.exp(scaled)
    return w / w.sum()


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000) -> list[float]:
    """
    Search for a non‑negative step‑height sequence that minimises
    ``evaluate_sequence``.  The routine runs for at most ``budget_s`` seconds
    and returns the best sequence discovered.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5   # safety margin for the final return

    # ------------------------------------------------------------------
    # 1 – problem size & initial point
    # ------------------------------------------------------------------
    try:
        # use the supplied construction if it exists
        init = np.array(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        n = min(2000, init.shape[0])          # keep the dimension moderate for speed
        if n < init.shape[0]:
            init = init[:n]
        print(f"Using existing height_sequence_1 (truncated) length {n}.")
    except NameError:
        # fallback – uniform start
        n = 2048
        init = np.ones(n, dtype=float)
        print(f"No previous sequence – starting with uniform vector, length {n}.")

    # normalise to a probability vector (sum == 1)
    a = init.astype(float)
    a = np.clip(a, 1e-12, None)       # avoid exact zeros for the first soft‑max
    a /= a.sum()

    best_a = a.copy()
    best_score = compute_score(best_a)
    print(f"Initial score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2 – Soft‑max continuation + exponentiated‑gradient descent
    # ------------------------------------------------------------------
    iteration = 0
    beta = 0.5               # start with a very smooth approximation
    beta_max = 128.0
    beta_growth_iter = 50000     # double β after this many iterations
    step0 = 0.5

    while time.time() < deadline - 5.0:     # reserve a few seconds for phase 3
        conv = compute_full_conv(a)
        cur_score = 2.0 * n * conv.max()

        # keep the best point seen so far
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            print(f"Iter {iteration:7d}: new best {best_score:.6f} (β={beta:.1f})")

        # ----- soft‑max gradient -------------------------------------------------
        p = _softmax_weights(conv, beta)               # length 2·n‑1, sums to 1
        grad = 2.0 * np.convolve(a, p)[:n]            # first n entries = ∇Fβ

        # ----- step‑size schedule -----------------------------------------------
        step = step0 / math.sqrt(iteration + 1.0) / max(beta, 1.0)

        # ----- mirror‑descent update ---------------------------------------------
        a = exponential_update(a, grad, step)

        iteration += 1

        # ----- increase β after a fixed number of iterations --------------------
        if iteration % beta_growth_iter == 0 and beta < beta_max:
            beta = min(beta_max, beta * 2.0)
            print(f"Iteration {iteration}: raising β to {beta}")

        # ----- occasional random restart (exploration) ---------------------------
        if iteration % 250000 == 0:
            cand = np.random.dirichlet(np.ones(n))
            cand_score = compute_score(cand)
            if cand_score < best_score:
                best_score = cand_score
                best_a = cand.copy()
                a = cand.copy()
                print(f"Random restart gave new best {best_score:.6f}")
            else:
                # accept with a tiny probability to keep diversity
                if np.random.rand() < 0.1:
                    a = cand.copy()
                    print("Random restart accepted (no improvement)")

    # ------------------------------------------------------------------
    # 3 – Guided simulated‑annealing fine‑tuning (short phase)
    # ------------------------------------------------------------------
    # start from the best point found so far
    cur_a = best_a.copy()
    cur_score = compute_score(cur_a)

    # temperature is a modest fraction of the current score
    T = cur_score * 0.05
    it_sa = 0

    while time.time() < deadline:
        # recompute convolution and a sub‑gradient of the true max
        conv = compute_full_conv(cur_a)
        grad = subgradient_of_max_conv(cur_a, conv)

        # source biased towards large gradient (large contribution to the peak)
        src_probs = grad / grad.sum()
        src = np.random.choice(n, p=src_probs)

        # target biased towards small gradient
        inv = 1.0 / (grad + 1e-12)
        tgt_probs = inv / inv.sum()
        tgt = np.random.choice(n, p=tgt_probs)

        if src == tgt or cur_a[src] <= 0.0:
            it_sa += 1
            continue

        # transfer a random fraction of the source mass
        delta = cur_a[src] * np.random.rand() * 0.1   # at most 10 % of source
        cand = cur_a.copy()
        cand[src] -= delta
        cand[tgt] += delta
        cand = np.clip(cand, 0.0, None)
        cand /= cand.sum()

        cand_score = compute_score(cand)

        # Metropolis acceptance
        if cand_score < cur_score:
            accept = True
        else:
            prob = math.exp(-(cand_score - cur_score) / max(T, 1e-12))
            accept = np.random.rand() < prob

        if accept:
            cur_a = cand
            cur_score = cand_score
            if cand_score < best_score:
                best_score = cand_score
                best_a = cand.copy()
                print(f"SA iter {it_sa:7d}: new best {best_score:.6f}")

        # geometric cooling
        T *= 0.99995
        it_sa += 1

    # ------------------------------------------------------------------
    # 4 – Return the best sequence (still normalised to sum == 1)
    # ------------------------------------------------------------------
    best_a = best_a / best_a.sum()
    print(f"Finished. Best score = {best_score:.6f}")
    return [float(v) for v in best_a.tolist()]
```

The routine follows the plan described above, stays well within the
