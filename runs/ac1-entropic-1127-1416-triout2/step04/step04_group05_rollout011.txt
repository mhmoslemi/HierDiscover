assistantfinal**Solution Overview**

The evaluation function is scale‑invariant, therefore the search can be performed on the
probability simplex  

```
a_i ≥ 0 ,  Σ a_i = 1 .
```

For a fixed vector `a`

```
c = a * a            # linear convolution (size 2·n‑1)
score = 2·n·max(c)   # the value returned by evaluate_sequence
```

`max(c)` is the quantity we have to minimise.  
Instead of working with the non‑smooth `max` we minimise a smooth
upper‑bound

```
F_λ(a) = (1/λ)·log Σ_k exp( λ·c_k )
```

`F_λ → max(c)` when λ → ∞.  
For a given λ the gradient of `F_λ` is

```
∇F_λ(a) = Σ_k  w_k · ∇c_k ,   w_k = exp(λ·c_k) / Σ_j exp(λ·c_j) .
```

`∇c_k` is known analytically:

```
∂c_k / ∂a_i = 2·a_{k-i}          (indices outside [0,n‑1] are ignored)
```

All convolutions are performed with FFTs, so each iteration costs only
`O(n log n)`.

The optimisation proceeds as follows:

1. **Initial point** – the previously found sequence `height_sequence_1`
   (if present) is normalised to a probability vector, otherwise a uniform
   vector is used.
2. **Adam‑style projected gradient descent** on `F_λ`.  
   * λ is increased continuously from a small value (`λ_start`) to a large
     one (`λ_end`) – the algorithm first smoothes the objective and later
     focuses on the true maximum.  
   * After every gradient step the iterate is projected back onto the simplex
     with the standard Euclidean projection.
   * The best ever iterate (according to the exact score) is stored.
3. **Escaping stagnation** – if no improvement is seen for many
   iterations a small random perturbation is added to the current point.
4. The loop runs until the time budget (≤ 1000 s) is exhausted and the
   best vector found is returned.

The method stays completely on the simplex, therefore the evaluation
function never rejects a candidate.  It differs from the previous
exponentiated‑gradient / simulated‑annealing approach by using a *smooth*
approximation of the max‑norm and a well‑tuned Adam optimiser, which
typically yields a lower final bound.

```python
"""
Propose a step‑height sequence that minimises ``evaluate_sequence``.

The algorithm works on the probability simplex (∑a_i = 1, a_i ≥ 0).
It minimises a smooth upper‑bound of the ∞‑norm of the self‑convolution
by using an Adam optimiser with a simplex projection.  The smoothing
parameter λ is increased from a small to a large value, so the optimiser
first reduces the average convolution height and later concentrates on
the true maximum.  The best vector seen during the run is returned.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper functions (all top level, no closures)
# ----------------------------------------------------------------------


def project_onto_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
       { x | x_i ≥ 0 , Σ x_i = 1 }.
    Implementation follows the algorithm of Duchi et al. (2008).
    """
    if v.ndim != 1:
        raise ValueError("project_onto_simplex works on 1‑D arrays")
    n = v.shape[0]
    # sort v in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    # Find the rho index
    rho_arr = u - (cssv - 1) / (np.arange(1, n + 1))
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        # all entries are zero or negative -> return uniform point
        theta = 0.0
    else:
        rho = rho[-1]
        theta = (cssv[rho] - 1) / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def compute_exact_score(a: np.ndarray) -> float:
    """
    Exact value of ``evaluate_sequence`` for a vector whose sum equals 1.
    Returns 2·n·max(conv) where conv = a * a (linear convolution).
    """
    n = a.shape[0]
    L = 2 * n - 1
    fft_a = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fft_a * fft_a, n=L)
    return 2.0 * n * conv.max()


def softmax_weights(conv: np.ndarray, lam: float) -> np.ndarray:
    """
    Compute soft‑max weights w_k = exp(lam·conv_k) / Σ exp(lam·conv_k)
    in a numerically stable way.
    """
    if lam == 0.0:
        # uniform weights – avoid exp(0) overflow issues
        return np.full_like(conv, 1.0 / conv.size)
    scaled = lam * conv
    # subtract the maximum for stability
    max_s = scaled.max()
    exp_scaled = np.exp(scaled - max_s)
    w = exp_scaled / exp_scaled.sum()
    return w


def gradient_of_softmax_obj(a: np.ndarray, w: np.ndarray, L_fft: int) -> np.ndarray:
    """
    Gradient of the smooth objective F_λ(a) = (1/λ)·log Σ exp(λ·c_k)
    where w_k are the soft‑max probabilities.
    The formula reduces to a weighted sum of the gradients of individual
    convolution entries.
    """
    n = a.shape[0]
    # reverse the weight vector (required for the convolution formula)
    w_rev = w[::-1]

    # FFT of a (already zero‑padded to length L_fft)
    fft_a = np.fft.rfft(a, n=L_fft)

    # FFT of the reversed weight vector
    fft_w = np.fft.rfft(w_rev, n=L_fft)

    # Convolution a * w_rev (full length L_fft)
    conv2_full = np.fft.irfft(fft_a * fft_w, n=L_fft)

    # Extract the slice that corresponds to Σ_k w_k ∇c_k
    # (see derivation in the analysis)
    grad = 2.0 * conv2_full[n - 1 : 2 * n - 1][::-1]
    return grad


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000) -> list[float]:
    """
    Search for a non‑negative height sequence that minimises
    ``evaluate_sequence``.  The algorithm runs for at most ``budget_s``
    seconds and returns the best sequence discovered.
    """
    np.random.seed(seed)
    start_time = time.time()
    # safety margin – stop a little before the hard deadline
    deadline = start_time + budget_s - 0.2

    # --------------------------------------------------------------
    # 1 – problem size & initial point
    # --------------------------------------------------------------
    try:
        init = np.array(height_sequence_1, dtype=float)  # type: ignore[name-defined]
        n = init.shape[0]
        print(f"Using existing height_sequence_1 of length {n}.")
    except NameError:
        n = 5146
        init = np.ones(n, dtype=float) / n
        print(f"No existing sequence – using uniform start, length {n}.")

    a = init / init.sum()                     # ensure exact simplex point

    # best solution seen so far
    best_a = a.copy()
    best_score = compute_exact_score(best_a)
    print(f"Initial exact score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 2 – optimisation parameters
    # --------------------------------------------------------------
    # Adam parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-12
    alpha = 0.05          # base learning rate

    # moment estimates
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    # soft‑max (smoothing) schedule
    lam_start = 5.0
    lam_end = 5000.0

    # length for the FFTs (next power of two ≥ 3·n‑2)
    L_fft = 1 << ((3 * n - 2).bit_length())

    # counters for stagnation handling
    it = 0
    no_improve = 0
    RESTART_AFTER = 20000          # iterations without improvement

    # --------------------------------------------------------------
    # 3 – main optimisation loop
    # --------------------------------------------------------------
    while time.time() < deadline:
        # ---------- compute convolution and exact score ----------
        fft_a = np.fft.rfft(a, n=L_fft)
        conv_full = np.fft.irfft(fft_a * fft_a, n=L_fft)
        conv = conv_full[: 2 * n - 1]               # linear convolution a*a
        cur_score = 2.0 * n * conv.max()

        # store best solution
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            no_improve = 0
            if it % 5000 == 0:
                print(f"Iter {it:6d}: new best exact score = {best_score:.6f}")
        else:
            no_improve += 1

        # ---------- soft‑max weight (smooth approximation of max) ----------
        elapsed = time.time() - start_time
        fraction = min(1.0, elapsed / (budget_s - 0.2))
        lam = lam_start * (lam_end / lam_start) ** fraction

        w = softmax_weights(conv, lam)

        # ---------- gradient of the smooth objective ----------
        grad = gradient_of_softmax_obj(a, w, L_fft)

        # ---------- Adam update ----------
        it += 1
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = alpha / (np.sqrt(v_hat) + eps)
        a_new = a - step * m_hat

        # ---------- projection onto the simplex ----------
        a = project_onto_simplex(a_new)

        # ---------- occasional random perturbation to escape plateaus ----------
        if no_improve >= RESTART_AFTER:
            # add a small Gaussian noise, keep feasibility
            noise = 0.01 * np.random.randn(n)
            a = a + noise
            a = np.clip(a, 0.0, None)
            a = a / a.sum()
            # reset moments to avoid stale information
            m.fill(0.0)
            v.fill(0.0)
            no_improve = 0
            print(f"Iter {it:6d}: perturbation restart applied")

    # --------------------------------------------------------------
    # 4 – finish & return
    # --------------------------------------------------------------
    # ensure the returned vector sums exactly to 1 (tiny numeric drift possible)
    best_a = best_a / best_a.sum()
    final_score = compute_exact_score(best_a)
    print(f"Finished after {it} iterations – best exact score = {final_score:.6f}")
    return [float(x) for x in best_a.tolist()]
```
