The sequence a_i = 2·(i+1) / (n·(n+1)) (i = 0 … n‑1) satisfies
∑ a_i = 1 and yields a closed‑form expression for the maximal
convolution value

    max(conv(a,a)) = 2·(n+2) / (3·n·(n+1))

Hence

    evaluate_sequence(a) = 2·n·max(conv)/1²
                         = 4·(n+2) / (3·(n+1)) → 4/3 ≈ 1.333…

For n = 2048 the score is ≈ 1.334, well below the target 1.503.
The function below builds this vector and returns it.
"""

    length would work – the formula above gives the same asymptotic
    bound.
    """
    # The problem is scale‑invariant, so we simply enforce ∑a_i = 1.
    # A linear increase from left to right (triangular shape) minimises
    # the peak of the additive self‑convolution.
    n = 2048                       # length of the sequence
    idx = np.arange(1, n + 1, dtype=float)   # i+1 for i = 0 … n‑1
    seq = 2.0 * idx / (n * (n + 1))          # a_i = 2·(i+1) / (n·(n+1))

    # Convert to plain Python list for the harness.
    seq_list = seq.tolist()

        print("[triangular] evaluation failed:", exc)
