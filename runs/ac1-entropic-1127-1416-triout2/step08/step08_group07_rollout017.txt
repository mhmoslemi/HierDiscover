the convolution max is attained at the full‑overlap shift (k = n‑1) and,
after a common scaling, the objective becomes

    f = 2·(p+1)²·Beta(p+1, p+1)                     (1)

where Beta is the Euler beta‑function.  Equation (1) shows that the score
decreases rapidly with the exponent p (p=1 → 4/3, p=2 → 0.6, p=3 → 0.228…,
p=4 → 0.079…, p=5 → 0.0259, …).  Because the evaluation normalises out any
overall scaling, we can safely scale the vector so that its largest entry
is ≤ 1000 (the clipping limit of ``evaluate_sequence``).  This yields a
valid candidate whose score is essentially given by (1), i.e. far below
the target 1.503.

The implementation tries a few small integer exponents (p = 1 … 6) on a
moderately large length (n = 8192) and keeps the best one according to
the cheap surrogate ``fast_score`` (which is identical to the official
score when no clipping occurs).  The whole routine finishes in well
under the 1000 s budget.
"""

import time
import numpy as np
from typing import List

# --------------------------------------------------------------
# Helper: linear convolution via FFT (full mode)
# --------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution using a real FFT (O(N log N))."""
    m = a.size + b.size - 1
    n_fft = _next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    return np.fft.irfft(C, n=n_fft)[:m]


def fast_score(a: np.ndarray) -> float:
    """
    Exact objective for a non‑negative vector a (no clipping performed).
    Returns 2·n·max(conv(a,a)) / (sum(a)²).
    """
    n = a.shape[0]
    s = a.sum()
    if s <= 1e-12:
        return float("inf")
    conv = convolution_fft(a, a)
    return 2.0 * n * np.max(conv) / (s * s)


# --------------------------------------------------------------
# Main entry point required by the harness
# --------------------------------------------------------------
def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs) -> List[float]:
    """
    Return a step‑function (list of non‑negative floats) with a
    very low ``evaluate_sequence`` score.

    The construction uses a simple power‑law shape a_i ∝ (n‑i)^p.
    Several exponents are tried and the one with the smallest
    surrogate score is returned.
    """
    # The budget is not needed – the algorithm runs in a few seconds.
    _ = seed, budget_s, kwargs  # unused, kept for the required signature

    # Length of the sequence – larger gives a finer discretisation.
    n = 8192

    # Exponents to try – p = 1 gives the linear shape (score ≈ 1.33),
    # larger p rapidly improve the bound.
    exponents = [1, 2, 3, 4, 5, 6]

    best_vec: np.ndarray = None
    best_val: float = float("inf")

    # Descending integer powers (n, n‑1, …, 1)ᵖ
    base = np.arange(n, 0, -1, dtype=float)  # n, n‑1, …, 1

    for p in exponents:
        # raw values (still huge, possibly > 1e300 for very large p,
        # but within double‑precision for the chosen range)
        raw = base ** p

        # Scale the vector so that the maximum entry is just below
        # the clipping limit (1000).  Scaling does NOT affect the
        # objective because ``evaluate_sequence`` is homogeneous.
        scale = 999.0 / raw[0]          # raw[0] = n**p
        vec = raw * scale

        # Compute the exact surrogate (identical to the official score,
        # because we stay below the clipping bound).
        val = fast_score(vec)

        # Keep the best exponent.
        if val < best_val:
            best_val = val
            best_vec = vec

    # Safety fallback – this should never happen.
    if best_vec is None:
        best_vec = np.full(n, 1.0 / n)

    # Convert to a plain Python list as required by the harness.
    return best_vec.tolist()
