The score to minimise is  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

We restrict ourselves to the simplex \(\sum a_i=1\); then the score equals  

\[
\text{score}=2n\;\max(a*a).
\]

The optimisation problem is **convex in the objective** (a maximum of linear
functions) but **non‑convex because the constraints are quadratic**
(\(a*a\) contains products \(a_i a_j\)).
A practical approach is a combination of

* a very cheap *coarse* grid‑search that creates many plausible start
  shapes,
* **projected sub‑gradient descent** on the exact max‑convolution,
* an **exponentiated‑gradient (mirror‑descent) polish**, and
* a cheap **stochastic hill‑climber**.

To increase the chance of escaping local minima we run the whole
refinement pipeline on several independent seeds (different lengths,
different shape families and a few random Dirichlet draws).  
The total wall‑clock time is kept under the 1000 s budget by cutting each
stage short when the deadline is near.

All heavy linear algebra uses an FFT‑based convolution, which is
\(O(n\log n)\) and fast enough for the required iteration counts.

The code below follows exactly this plan and returns the best
non‑negative sequence it found.

```python
"""
Propose a step‑function sequence with a low official score.

Algorithm
---------

1. **Coarse seeding** – generate many candidate shapes:
   * uniform,
   * arcsine,
   * generalized arcsine `a_i ∝ ((i+½)(n‑½‑i)+ε)^‑p` with a dense grid of p,
   * mixtures of arcsine and uniform,
   * random Dirichlet draws (using the arcsine parameters as a guide).

   Lengths in {1024, 2048, 4096, 8192} are tried.
   The 4 best candidates (according to the fast surrogate
   `2·n·max(conv(a,a))`) are kept.

2. **Refinement of every seed** (time‑aware):
   * **Projected sub‑gradient descent** on the exact max‑convolution.
     The step size is `η = η₀ / sqrt(t)` and each step is
     back‑tracked until the surrogate does not increase.
   * **Exponentiated‑gradient polish** – mirror‑descent w.r.t. KL
     (still on the simplex) for a few more passes.
   * **Local random hill climbing** – repeatedly move a tiny amount of
     mass from one coordinate to another, accepting improving moves.

   The best refined sequence over all seeds is kept.

3. **Official evaluation** – the final candidate is fed to
   `evaluate_sequence`.  If, for any reason, the routine fails, a safe
   uniform fallback is returned.

All steps respect the global 1000 s wall‑clock limit.
"""

import time
import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Low‑level utilities
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Linear convolution via real FFT.
    Returns a vector of length len(a)+len(b)-1.
    """
    m = a.size + b.size - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of v onto the probability simplex {x ≥ 0, Σx = 1}.
    Implements the algorithm of Duchi et al. (2008).
    """
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.size)

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, v.size + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def compute_score(a: np.ndarray) -> float:
    """
    Fast surrogate of the official score.
    The vector a is assumed to be on the simplex (Σa = 1);
    the surrogate is 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(np.max(conv))

def arcsine_initial(n: int) -> np.ndarray:
    """Discrete arcsine density, normalised to sum = 1."""
    i = np.arange(n, dtype=float)
    eps = 0.25
    vals = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    return vals / vals.sum()


def generate_power_shape(n: int, p: float, eps: float = 1e-12) -> np.ndarray:
    """
    Generalised arcsine shape:
    a_i ∝ ((i+½)*(n‑½‑i) + ε)^{-p}.
    """
    i = np.arange(n, dtype=float)
    denom = ((i + 0.5) * (n - 0.5 - i) + eps) ** p
    vals = 1.0 / denom
    total = vals.sum()
    if total <= 0.0 or not np.isfinite(total):
        return np.full(n, 1.0 / n)
    return vals / total


def generate_mixture_shape(n: int, weight_arc: float) -> np.ndarray:
    """Mixture weight_arc·arcsine + (1‑weight_arc)·uniform."""
    arc = arcsine_initial(n)
    uni = np.full(n, 1.0 / n)
    mix = weight_arc * arc + (1.0 - weight_arc) * uni
    return mix / mix.sum()

def subgradient_adaptive(
    a_init: np.ndarray,
    deadline: float,
    max_iter: int = 150_000,
    eta0: float = 0.14,
) -> np.ndarray:
    """
    Projected sub‑gradient descent with simple back‑tracking.
    Works on the exact max‑convolution.
    """
    a = project_to_simplex(a_init.copy())
    n = a.size
    L = 2 * n - 1

    cur_score = compute_score(a)
    best_a = a.copy()
    best_score = cur_score

    # step schedule – start large, shrink ~1/√t
    for it in range(1, max_iter + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        max_val = float(np.max(conv))
        # tolerance to collect *all* (almost) maximal indices
        tol = max_val * 1e-12 + 1e-14
        mask = (np.abs(conv - max_val) <= tol).astype(float)

        # sub‑gradient: 2·conv(a, mask_rev)
        subgrad = 2.0 * convolution_fft(a, mask[::-1])[L - 1 - np.arange(n)]

        # basic step size
        eta = eta0 / np.sqrt(it)

        # back‑track until an improvement is seen (or eta becomes tiny)
        while eta > 1e-12:
            a_candidate = a - eta * subgrad
            a_candidate = project_to_simplex(a_candidate)
            cand_score = compute_score(a_candidate)
            if cand_score <= cur_score:
                a = a_candidate
                cur_score = cand_score
                if cur_score < best_score:
                    best_score = cur_score
                    best_a = a.copy()
                break
            eta *= 0.5

    return best_a


def eg_polish(
    a_init: np.ndarray,
    deadline: float,
    max_iter: int = 120_000,
    eta0: float = 0.25,
) -> np.ndarray:
    """
    Exponentiated‑gradient (mirror descent w.r.t. KL) polish.
    """
    a = a_init.copy()
    n = a.size
    L = 2 * n - 1

    for it in range(1, max_iter + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        max_val = float(np.max(conv))
        tol = max_val * 1e-12 + 1e-14
        mask = (np.abs(conv - max_val) <= tol).astype(float)

        subgrad = 2.0 * convolution_fft(a, mask[::-1])[L - 1 - np.arange(n)]

        eta = eta0 / (np.sqrt(it) + 1.0)
        a = a * np.exp(-eta * subgrad)

        total = a.sum()
        if total == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a /= total

    return a


def local_random_search(
    a_init: np.ndarray,
    deadline: float,
    max_trials: int = 30_000,
    step_scale: float = 0.001,
    rng: np.random.Generator = np.random.default_rng(),
) -> np.ndarray:
    """
    Very cheap stochastic hill climbing.
    Moves a tiny amount of mass from one index to another
    and accepts only improving moves (according to the surrogate).
    """
    a_cur = a_init.copy()
    score_cur = compute_score(a_cur)
    n = a_cur.size

    while time.time() < deadline - 0.2 and max_trials > 0:
        i, j = rng.integers(0, n, size=2)
        if i == j:
            continue
        eps = step_scale * a_cur[i]
        if eps <= 0.0:
            continue
        a_new = a_cur.copy()
        a_new[i] -= eps
        a_new[j] += eps
        if a_new[i] < 0.0:
            continue
        s_new = compute_score(a_new)
        if s_new < score_cur:
            a_cur = a_new
            score_cur = s_new
        max_trials -= 1

    return a_cur

        if remaining > 15.0:
            eg_deadline = time.time() + min(remaining * 0.4, 180.0)
            a_ref = eg_polish(a_ref, eg_deadline, max_iter=120_000, eta0=0.25)
            s_ref = compute_score(a_ref)
            print(f"  After EG polish surrogate = {s_ref:.6f}")

        # Local random search
        remaining = deadline - time.time()
        if remaining > 5.0:
            lr_deadline = time.time() + remaining - 0.5
            a_ref = local_random_search(a_ref, lr_deadline, max_trials=30_000,
                                        step_scale=0.001, rng=rng)
            s_ref = compute_score(a_ref)
            print(f"  After local search surrogate = {s_ref:.6f}")

        # Keep the best overall
        if s_ref < best_surrogate:
            best_surrogate = s_ref
            best_seq = a_ref.tolist()
            print(f"  *** New best surrogate overall: {s_ref:.6f}")

    # ------------------------------------------------------------------
    # Official evaluation of the best candidate
    # ------------------------------------------------------------------
    try:
        final_val = evaluate_sequence(best_seq)
        print(f"\nOfficial final score = {final_val:.6f}")
        if final_val < best_official:
            best_official = final_val
    except Exception as e:
        print(f"Official evaluation failed: {e}")
        final_val = float("inf")

    # ------------------------------------------------------------------
    # Guard – guarantee a non‑empty return
    # ------------------------------------------------------------------
    if not best_seq:
        fallback_n = 1024
        best_seq = [1.0 / fallback_n] * fallback_n
        final_val = evaluate_sequence(best_seq)
        print(f"Fallback to uniform length {fallback_n}, score = {final_val:.6f}")

    print(f"\nSearch finished. Best official score = {best_official:.6f}")
    return best_seq
```
