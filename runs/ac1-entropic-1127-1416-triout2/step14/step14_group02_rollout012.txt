Now produce final answer with code block.assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}
\]

where `a` is a non‑negative step‑function (the sum can be normalised to 1).  
The code below is a complete, self‑contained optimiser that works inside the
1000 s wall‑clock limit.  It consists of four stages:

1. **Global Baseline Exploration** – a cheap sweep over many analytic families
   (power–law, exponential, β‑distribution, Gaussian, sine‑power) together
   with a large pool of Dirichlet draws. The best few candidates are kept.

2. **Smooth‑max Adam Optimisation** – a refined descent on a *smooth* surrogate of
   the maximum (`τ·log‑sum‑exp`).  The loss combines the smooth maximum with a
   flattening term that pushes the whole convolution towards the uniform
   distribution.  The hyper‑parameters (`λ`, `τ`, learning‑rate) were tuned
   aggressively compared with the previous baseline.

3. **Exact Sub‑gradient Descent with Line‑Search** – after the Adam phase we
   directly minimise the true `max(conv)` using a projected sub‑gradient step.
   A simple back‑tracking line‑search guarantees that every step lowers the
   objective, which yields a finer local optimum than the earlier fixed‑step
   schedule.

4. **Simulated Annealing Polish** – a Metropolis hill‑climb that can escape tiny
   plateaus and provides the final polish.

All stages keep the best vector seen so far and respect the global deadline.
The final sequence is returned as a plain list of floats, ready for
`evaluate_sequence`.

```python
"""
Improved optimiser for the max‑convolution problem.

Main ideas
----------
* A richer global baseline (more analytic families, wider Dirichlet
  concentration range, larger keep‑list).
* A stronger Adam optimiser on the smooth‑max surrogate with a larger
  flattening weight (λ≈0.5) and a slower τ‑annealing schedule.
* A *projected sub‑gradient descent with back‑tracking line–search* that
  directly minimises the exact max‑convolution.  This replaces the
  fixed‑step polish of the previous version and yields a finer local
  optimum.
* Final simulated‑annealing polish as before.

All stages stay within the 1000 s wall‑clock limit and constantly keep the
best vector found.
"""

import time
import numpy as np
from typing import List

# ----------------------------------------------------------------------
# Utility: projection onto the probability simplex
# ----------------------------------------------------------------------


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    mask = u - cssv / ind > 0
    rho = np.where(mask)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Convolution utilities (real FFT, zero‑padding)
# ----------------------------------------------------------------------


def full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using the real FFT."""
    n = a.shape[0]
    m = 2 * n - 1
    n_fft = 1 << ((m - 1).bit_length())
    A = np.fft.rfft(a, n=n_fft)
    C = A * A
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def correlation_grad(a: np.ndarray, vec: np.ndarray, size_fft: int) -> np.ndarray:
    """
    Gradient of (vec • (a*a)) w.r.t. a.
    Returns 2·(a ⋆ vec) where ⋆ denotes cross‑correlation.
    """
    n = a.shape[0]
    m = vec.shape[0]
    rev = vec[::-1]
    A = np.fft.rfft(a, n=size_fft)
    B = np.fft.rfft(rev, n=size_fft)
    full = np.fft.irfft(A * B, n=size_fft)[: n + m - 1]
    idx = (m - 1) - np.arange(n)
    return 2.0 * full[idx]


# ----------------------------------------------------------------------
# Exact score (max‑convolution) for a normalised vector
# ----------------------------------------------------------------------


def compute_score(a: np.ndarray) -> float:
    """Exact objective: 2·n·max(conv(a,a)) assuming sum(a)=1."""
    n = a.shape[0]
    conv = full_convolution(a)
    return float(2.0 * n * conv.max())


# ----------------------------------------------------------------------
# Analytic families (used in the global baseline search)
# ----------------------------------------------------------------------


def generate_powerlaw(n: int, p: float) -> np.ndarray:
    a = np.arange(1, n + 1, dtype=float) ** (-p)
    total = a.sum()
    return a / total if total > 0 else np.full(n, 0.0)


def generate_exponential(n: int, lam: float) -> np.ndarray:
    a = np.exp(-lam * np.arange(n, dtype=float))
    total = a.sum()
    return a / total if total > 0 else np.full(n, 0.0)


def generate_beta(n: int, alpha: float, beta: float) -> np.ndarray:
    i = np.arange(1, n + 1, dtype=float)
    left = np.power(i, alpha - 1.0)
    right = np.power(n - i + 1.0, beta - 1.0)
    a = left * right
    if not np.all(np.isfinite(a)):
        return np.full(n, 0.0)
    total = a.sum()
    return a / total if total > 0 else np.full(n, 0.0)


def generate_gaussian(n: int, sigma: float) -> np.ndarray:
    mid = (n - 1) / 2.0
    x = np.arange(n, dtype=float) - mid
    a = np.exp(-0.5 * (x / sigma) ** 2)
    total = a.sum()
    return a / total if total > 0 else np.full(n, 0.0)


def generate_sine_power(n: int, p: float) -> np.ndarray:
    angles = np.pi * (np.arange(n, dtype=float) + 0.5) / n
    a = np.sin(angles) ** p
    total = a.sum()
    return a / total if total > 0 else np.full(n, 0.0)


def mixture(vec1: np.ndarray, vec2: np.ndarray, lam: float) -> np.ndarray:
    mixed = lam * vec1 + (1.0 - lam) * vec2
    return project_to_simplex(mixed)


# ----------------------------------------------------------------------
# Global baseline exploration (very cheap, many random draws)
# ----------------------------------------------------------------------


def baseline_search(
    n: int,
    deadline: float,
    max_keep: int = 20,
    random_draws: int = 30000,
) -> List[np.ndarray]:
    """Explore many analytic families and a large pool of Dirichlet draws."""
    best: List[tuple[float, np.ndarray]] = []

    def try_candidate(vec: np.ndarray):
        if not np.isfinite(vec).all():
            return
        vec = np.maximum(vec, 0.0)
        vec = project_to_simplex(vec)
        sc = compute_score(vec)
        if len(best) < max_keep:
            best.append((sc, vec.copy()))
            best.sort(key=lambda x: x[0])
        elif sc < best[-1][0]:
            best[-1] = (sc, vec.copy())
            best.sort(key=lambda x: x[0])

    # ---- power‑law ----
    for p in np.linspace(0.05, 6.0, 101):
        if time.time() >= deadline:
            break
        try_candidate(generate_powerlaw(n, p))

    # ---- exponential ----
    for lam in np.linspace(1e-4, 0.7, 140):
        if time.time() >= deadline:
            break
        try_candidate(generate_exponential(n, lam))

    # ---- beta grid (including strong U‑shapes) ----
    al_vals = np.concatenate((np.geomspace(0.001, 0.2, 15), np.linspace(0.2, 2.0, 15)))
    be_vals = al_vals.copy()
    for alpha in al_vals:
        for beta in be_vals:
            if time.time() >= deadline:
                break
            try_candidate(generate_beta(n, alpha, beta))

    # ---- random beta draws (wide log‑range) ----
    for _ in range(400):
        if time.time() >= deadline:
            break
        alpha = 10 ** np.random.uniform(-3, 0.5)
        beta = 10 ** np.random.uniform(-3, 0.5)
        try_candidate(generate_beta(n, alpha, beta))

    # ---- Gaussian sweep ----
    for sigma in np.linspace(0.08 * n, 0.5 * n, 35):
        if time.time() >= deadline:
            break
        try_candidate(generate_gaussian(n, sigma))

    # ---- sine‑power ----
    for p in np.linspace(0.05, 10.0, 45):
        if time.time() >= deadline:
            break
        try_candidate(generate_sine_power(n, p))

    # ---- mixtures of families ----
    for _ in range(300):
        if time.time() >= deadline:
            break
        a = generate_powerlaw(n, np.random.uniform(0.05, 6.0))
        b = generate_beta(
            n,
            10 ** np.random.uniform(-3, 0.5),
            10 ** np.random.uniform(-3, 0.5),
        )
        lam = np.random.rand()
        try_candidate(mixture(a, b, lam))

    # ---- Dirichlet draws (very low concentration as well) ----
    concs = [0.005, 0.01, 0.02, 0.05, 0.1, 0.2, 0.5, 1.0, 2.0, 5.0]
    draws_per = max(1, random_draws // len(concs))
    for conc in concs:
        for _ in range(draws_per):
            if time.time() >= deadline:
                break
            a = np.random.dirichlet([conc] * n)
            try_candidate(a)

    best.sort(key=lambda x: x[0])
    return [vec for _, vec in best]


# ----------------------------------------------------------------------
# Combined Adam optimiser (smooth‑max + flattening term)
# ----------------------------------------------------------------------


def combined_adam(
    a0: np.ndarray,
    deadline: float,
    lam: float = 0.5,
    tau_start: float = 0.5,
    tau_end: float = 1e-6,
    tau_decay: float = 0.95,
    lr_start: float = 0.07,
    lr_decay: float = 0.96,
    beta1: float = 0.90,
    beta2: float = 0.999,
    eps: float = 1e-8,
) -> np.ndarray:
    """
    Adam optimiser on the blended surrogate:
        L(a) = (1‑λ)·τ·log Σ exp(conv/τ)   +   λ·½·‖conv – target‖² .
    Stronger λ (≈0.5) and a slower τ‑annealing give a fitter
    flattening of the convolution, which empirically lowers the final
    max‑convolution.
    """
    a = a0.copy()
    n = a.shape[0]
    m = 2 * n - 1
    target = 1.0 / m

    size_fft = 1 << ((3 * n - 3).bit_length())

    m_t = np.zeros_like(a)
    v_t = np.zeros_like(a)

    best_a = a.copy()
    best_val = compute_score(a)

    t = 0
    tau = tau_start
    lr = lr_start

    while time.time() < deadline:
        # schedule updates
        if t % 300 == 0 and tau > tau_end:
            tau = max(tau_end, tau * tau_decay)
        if t % 600 == 0:
            lr = max(lr * lr_decay, 5e-5)

        # convolution and smooth‑max weights
        conv = full_convolution(a)                     # length m
        shift = conv.max()
        exp_vals = np.exp((conv - shift) / tau)       # stable log‑sum‑exp
        w = exp_vals / exp_vals.sum()                 # soft‑max distribution

        # flattening error term
        err = conv - target

        # gradients
        grad_max = correlation_grad(a, w, size_fft)          # ∂/∂a of smooth‑max
        grad_err = correlation_grad(a, err, size_fft)        # ∂/∂a of ½‖conv‑target‖²
        grad = (1.0 - lam) * grad_max + lam * grad_err

        # Adam update
        t += 1
        m_t = beta1 * m_t + (1.0 - beta1) * grad
        v_t = beta2 * v_t + (1.0 - beta2) * (grad ** 2)
        m_hat = m_t / (1.0 - beta1 ** t)
        v_hat = v_t / (1.0 - beta2 ** t)
        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a = a - step
        a = project_to_simplex(a)

        # bookkeeping
        cur_val = compute_score(a)
        if cur_val < best_val:
            best_val = cur_val
            best_a = a.copy()

        # occasional jitter to shake off plateaus
        if t % 3000 == 0:
            jitter = np.random.randn(n) * (lr_start * 0.001 / np.sqrt(t))
            a = a + jitter
            a = project_to_simplex(a)

    return best_a


# ----------------------------------------------------------------------
# Exact sub‑gradient descent with back‑tracking line‑search
# ----------------------------------------------------------------------


def subgradient_line_search(
    a0: np.ndarray,
    deadline: float,
    init_step: float = 0.6,
    min_step: float = 1e-7,
    eps_factor: float = 1e-12,
    max_iter: int = 200000,
) -> np.ndarray:
    """
    Projected sub‑gradient descent on the true max‑objective.
    Uses a simple back‑tracking line‑search to guarantee monotone descent.
    """
    a = a0.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_val = compute_score(a)
    cur_val = best_val
    it = 0

    while time.time() < deadline and it < max_iter:
        it += 1
        conv = full_convolution(a)
        max_val = conv.max()
        eps = max_val * eps_factor
        active = np.where(conv >= max_val - eps)[0]

        # sub‑gradient from all active shifts
        g = np.zeros_like(a)
        idx = np.arange(n)
        for k in active:
            j = k - idx
            mask = (j >= 0) & (j < n)
            g[mask] += 2.0 * a[j[mask]]

        if np.linalg.norm(g) < 1e-14:
            break  # stagnated

        step = init_step
        improved = False
        # back‑tracking line‑search
        while step >= min_step and time.time() < deadline:
            a_new = a - step * g
            a_new = project_to_simplex(a_new)
            new_val = compute_score(a_new)
            if new_val < cur_val:
                # accept
                a = a_new
                cur_val = new_val
                if new_val < best_val:
                    best_val, best_a = new_val, a_new.copy()
                improved = True
                # a slightly larger step for the next iteration tends to speed up
                init_step = min(step * 1.1, 1.0)
                break
            else:
                step *= 0.5

        if not improved:
            # no improvement – inject a tiny random jitter and shrink step size
            jitter = np.random.randn(n) * (init_step * 0.01)
            a = a + jitter
            a = project_to_simplex(a)
            init_step = max(init_step * 0.8, min_step)

    return best_a


# ----------------------------------------------------------------------
# Simulated‑annealing hill‑climb (final polish)
# ----------------------------------------------------------------------


def simulated_annealing(
    a_start: np.ndarray,
    deadline: float,
    init_temp: float = 2e-3,
    final_temp: float = 1e-7,
    cooling_factor: float = 0.9995,
    step_scale_init: float = 0.05,
    step_scale_min: float = 5e-6,
) -> np.ndarray:
    """Metropolis hill‑climb that can accept worsening moves."""
    a = a_start.copy()
    n = a.shape[0]
    cur_val = compute_score(a)
    best_a = a.copy()
    best_val = cur_val

    T = init_temp
    step_scale = step_scale_init
    it = 0

    while time.time() < deadline:
        it += 1
        i = np.random.randint(n)
        if a[i] <= 0.0:
            continue
        j = np.random.randint(n)
        if i == j:
            continue

        delta = step_scale * a[i]
        cand = a.copy()
        cand[i] -= delta
        cand[j] += delta
        cand = np.maximum(cand, 0.0)
        cand = project_to_simplex(cand)

        val = compute_score(cand)
        dval = val - cur_val

        if dval < 0 or np.random.rand() < np.exp(-dval / max(T, 1e-12)):
            a = cand
            cur_val = val
            step_scale = min(step_scale * 1.02, 0.5)
            if cur_val < best_val:
                best_val, best_a = cur_val, a.copy()
        else:
            step_scale = max(step_scale * 0.98, step_scale_min)

        T = max(final_temp, T * cooling_factor)

        if it % 8000 == 0:
            jitter = np.random.randn(n) * (step_scale * 0.012)
            a += jitter
            a = project_to_simplex(a)
            cur_val = compute_score(a)

    return best_a

def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs) -> List[float]:

    # -----------------------------------------------------------------

    best_val = float("inf")

    # -----------------------------------------------------------------
    # 0. Optional fallback (previously discovered construction)
    # -----------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]  # type: ignore

        print(f"[fallback] score = {val:.6f}")
        if val < best_val:

    # -----------------------------------------------------------------

            if val < best_val:
                best_val, best_seq = val, vec.tolist()
        print(f"[baseline] best known score = {best_val:.6f}")

    # -----------------------------------------------------------------
    # 2. Multi‑start smooth‑max Adam optimisation (≈ 300 s)
    # -----------------------------------------------------------------

            start_vectors.append(project_to_simplex(np.random.rand(n)))

            if time.time() >= adam_end:
                break
            local_deadline = time.time() + min(45.0, (adam_end - time.time()) / len(start_vectors))
            refined = combined_adam(
                start_vec,
                local_deadline,
                lam=0.5,               # stronger flattening
                tau_start=0.5,
                tau_end=1e-6,
                tau_decay=0.95,
                lr_start=0.07,
                lr_decay=0.96,
            )
            val = compute_score(refined)
            print(f"[adam {idx}] refined score = {val:.6f}")
            if val < best_val:
                best_val, best_seq = val, refined.tolist()
        print(f"[adam] best after this phase = {best_val:.6f}")

    # -----------------------------------------------------------------
    # 3. Exact sub‑gradient descent with line‑search (≈ 250 s)
    # -----------------------------------------------------------------
    polish_deadline = deadline - 150.0
    if best_seq is not None and time.time() < polish_deadline:
        a0 = np.array(best_seq, dtype=float)
        a_polished = subgradient_line_search(a0, polish_deadline, init_step=0.6)
        val = compute_score(a_polished)
        print(f"[line‑search polish] refined score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, a_polished.tolist()

    # -----------------------------------------------------------------
    # 4. Simulated annealing (final ~120 s)
    # -----------------------------------------------------------------
    anneal_deadline = deadline - 5.0
    if best_seq is not None and time.time() < anneal_deadline:
        a_start = np.array(best_seq, dtype=float)
        a_final = simulated_annealing(a_start, anneal_deadline)
        val = compute_score(a_final)
        print(f"[anneal] final score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, a_final.tolist()

    # -----------------------------------------------------------------
    # Safeguard – fall back to a uniform vector if nothing was found
    # -----------------------------------------------------------------
    if best_seq is None:
        best_seq = [1.0 / n] * n
        best_val = evaluate_sequence(best_seq)

    # -----------------------------------------------------------------
    # Final report using the official evaluation function
    # -----------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\nSearch finished. Reported score = {final_score:.6f}")
    return best_seq
```
