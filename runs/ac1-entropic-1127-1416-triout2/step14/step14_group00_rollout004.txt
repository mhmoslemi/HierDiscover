assistantfinal**Solution Overview**

The goal is to minimise  

\[
F(a)=\frac{2n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the linear (full) convolution of the non‑negative vector `a`.
Because the objective is homogeneous we may restrict ourselves to probability
vectors (`∑a = 1`).  Then  

\[
F(a)=2n\;\max (a*a),
\]

so we only have to make the self‑convolution as flat as possible.

The code below implements a three‑stage search:

1. **Initial shape** – the discrete *arcsine* distribution (`β(½,½)`) is a
   theoretically good starting point.  It is generated for a relatively large
   size (`n = 4096`) so that the discrete approximation is very close to the
   continuous optimum.

2. **Smoothed maximum descent** – the non‑smooth `max` is replaced by a
   temperature‑controlled log‑sum‑exp:

   \[
   \phi_T(a)=T\log\Bigl(\sum_i e^{(a*a)_i/T}\Bigr)
   \]

   Its gradient is an inexpensive **cross‑correlation** between the current
   vector `a` and the normalised weights  
   \(
   w_i=\frac{e^{(a*a)_i/T}}{\sum_j e^{(a*a)_j/T}}.
   \)
   Using FFTs we compute both the convolution (for the objective) and the
   correlation (for the gradient) in *O(n log n)* time.  After each gradient
   step we project back onto the probability simplex with the Euclidean
   projection of Duchi et al.

   The temperature is slowly reduced (`geometric decay`) and the step size
   follows a `1/√t` schedule.  Occasional small random jitter prevents the
   iterate from getting trapped on a flat plateau.

3. **Fine polishing** – a cheap sub‑gradient descent (the same routine that
   performed well in the previous attempt) is run for the remaining budget
   to squeeze out the last tiny improvement.

All work is bounded by the supplied wall‑clock budget (default 1000 s).  The
best sequence found is returned as a plain Python list; the official
`evaluate_sequence` function is called once at the very end only.

```python
"""
Step‑function optimisation for ``evaluate_sequence``.

1.  Initialise with the discrete arcsine distribution (β(½,½)).
2.  minimise a smoothed version of the max‑convolution using
    projected gradient descent with a log‑sum‑exp temperature schedule.
    The gradient is obtained by a fast FFT‑based cross‑correlation.
3.  Final cheap sub‑gradient polishing (as in the prior baseline).

The algorithm works on the probability simplex (∑a = 1) and respects the
non‑negativity requirement.  It runs until the supplied time budget (≈1000 s)
is exhausted and returns the best vector found.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex (∑=1, v≥0)."""
    if np.all(v <= 0):
        # all non‑positive → uniform distribution
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, len(v) + 1)
    mask = u - cssv / ind > 0
    if not np.any(mask):
        return np.full_like(v, 1.0 / v.shape[0])
    rho = np.where(mask)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def full_convolution(a: np.ndarray) -> np.ndarray:
    """Full linear convolution a*a using a real FFT (fast for large n)."""
    n = a.shape[0]
    m = 2 * n - 1
    n_fft = 1 << ((m - 1).bit_length())          # next power of two ≥ m
    A = np.fft.rfft(a, n=n_fft)
    C = A * A
    return np.fft.irfft(C, n=n_fft)[:m]


def compute_score(a: np.ndarray) -> float:
    """
    Exact objective 2·n·max(conv(a,a)) for vectors normalised to sum = 1.
    """
    n = a.shape[0]
    conv = full_convolution(a)
    return float(2.0 * n * conv.max())


def generate_arcsine(n: int) -> np.ndarray:
    """
    Discrete arcsine (Beta(½,½)) distribution.
    a_i ∝ 1 / √((i+½)*(n‑½‑i)),   i = 0 … n‑1,
    normalised to sum = 1.
    """
    i = np.arange(n, dtype=float) + 0.5
    denom = np.sqrt(i * (n - 0.5 - i))
    a = 1.0 / denom
    a /= a.sum()
    return a


def correlation_gradient(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Gradient of  Σ_i w_i·(a*a)_i  with respect to a.
    The formula is   g = 2·corr(a, w)   where   corr(a,w)[k] = Σ_j a_j·w_{j+k}.
    Computed via FFT (linear, not circular, correlation).
    """
    n = a.shape[0]
    m = w.shape[0]                     # = 2n‑1
    size = 1 << ((n + m - 2).bit_length())   # ≥ n+m‑1
    FA = np.fft.rfft(a, n=size)
    FW = np.fft.rfft(w, n=size)
    # linear correlation = ifft(FA * conj(FW))
    corr = np.fft.irfft(FA * np.conj(FW), n=size)
    # first n entries correspond to lags k = 0 … n‑1
    return 2.0 * corr[:n]


# ----------------------------------------------------------------------
# Smoothed‑max gradient descent
# ----------------------------------------------------------------------


def smoothed_max_descent(
    a0: np.ndarray,
    deadline: float,
    init_temp: float = 0.12,
    min_temp: float = 1e-6,
    temp_decay: float = 0.9995,
    step0: float = 0.30,
) -> np.ndarray:
    """
    Projected gradient descent on the log‑sum‑exp smoothed maximum.
    Returns the best vector seen (according to the exact objective).
    """
    a = a0.copy()
    best_a = a.copy()
    best_val = compute_score(a)

    it = 0
    temp = init_temp

    while time.time() < deadline:
        it += 1
        # ---- convolution and temperature update ----
        conv = full_convolution(a)
        max_conv = conv.max()
        temp = max(min_temp, temp * temp_decay)

        # ---- weights for the smoothed max (log‑sum‑exp) ----
        # subtract max_conv for numerical stability
        w = np.exp((conv - max_conv) / temp)
        w /= w.sum()                       # normalise → probabilities

        # ---- gradient of the smoothed objective ----
        grad = correlation_gradient(a, w)

        # ---- projected gradient step ----
        step = step0 / np.sqrt(it)
        a -= step * grad
        a = project_to_simplex(a)

        # ---- keep the best exact solution ----
        cur_val = compute_score(a)
        if cur_val < best_val:
            best_val, best_a = cur_val, a.copy()

        # ---- occasional jitter to escape plateaus ----
        if it % 4000 == 0:
            jitter = np.random.randn(a.shape[0]) * (step0 * 0.004 / np.sqrt(it))
            a += jitter
            a = project_to_simplex(a)

    print(f"[descent] finished after {it} iterations – best score = {best_val:.6f}")
    return best_a


# ----------------------------------------------------------------------
# Sub‑gradient polishing (identical to the earlier baseline)
# ----------------------------------------------------------------------


def subgradient_polish(a0: np.ndarray, deadline: float,
                       step0: float = 0.30) -> np.ndarray:
    """Projected sub‑gradient descent on the true max‑convolution objective."""
    a = a0.copy()
    n = a.shape[0]
    best_a = a.copy()
    best_val = compute_score(a)

    t = 0
    while time.time() < deadline:
        t += 1
        conv = full_convolution(a)
        max_val = conv.max()
        eps = max_val * 1e-9
        active = np.where(conv >= max_val - eps)[0]

        # gradient of max(conv) = sum of gradients of the active entries
        g = np.zeros_like(a)
        idx = np.arange(n)
        for k in active:
            j = k - idx
            mask = (j >= 0) & (j < n)
            g[mask] += 2.0 * a[j[mask]]

        step = step0 / np.sqrt(t)
        a -= step * g
        a = project_to_simplex(a)

        cur_val = compute_score(a)
        if cur_val < best_val:
            best_val, best_a = cur_val, a.copy()

        if t % 2000 == 0:
            jitter = np.random.randn(n) * (step0 * 0.005 / np.sqrt(t))
            a += jitter
            a = project_to_simplex(a)

    print(f"[polish] completed – refined score = {best_val:.6f}")
    return best_a


# ----------------------------------------------------------------------
# Main entry point required by the harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative coefficient sequence that minimises
    ``evaluate_sequence``.  The implementation uses a large arcsine start,
    a smoothed‑max gradient descent, and a final sub‑gradient polish.
    Returns a plain list of floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 5.0          # short safety margin

    # -----------------------------------------------------------------
    # 0. Optional fallback (previous best sequence, if available)
    # -----------------------------------------------------------------
    best_seq = None
    best_score = float("inf")
    try:
        fallback = [float(x) for x in height_sequence_1]   # type: ignore
        val = evaluate_sequence(fallback)
        print(f"[fallback] score = {val:.6f}")
        if val < best_score:
            best_score, best_seq = val, np.array(fallback, dtype=float)
    except Exception:
        pass

    # -----------------------------------------------------------------
    # 1. Choose problem size (larger n helps the discrete approximation)
    # -----------------------------------------------------------------
    n = 4096          # 2‑times the previous size – still very fast FFTs

    # -----------------------------------------------------------------
    # 2. Deterministic strong start: arcsine distribution
    # -----------------------------------------------------------------
    a = generate_arcsine(n)
    sc = compute_score(a)
    print(f"[arcsine] initial score = {sc:.6f}")
    if sc < best_score:
        best_score, best_seq = sc, a.copy()

    # -----------------------------------------------------------------
    # 3. Small random perturbations of the arcsine start (5 attempts)
    # -----------------------------------------------------------------
    for rep in range(5):
        if time.time() >= deadline:
            break
        pert = a + 0.02 * np.random.randn(n) * a   # relative jitter
        pert = np.maximum(pert, 0.0)
        pert = pert / pert.sum()
        sc = compute_score(pert)
        if sc < best_score:
            best_score, best_seq = sc, pert.copy()
    print(f"[perturb] best score after jitter = {best_score:.6f}")

    # -----------------------------------------------------------------
    # 4. Smoothed‑max gradient descent (main workhorse)
    # -----------------------------------------------------------------
    if time.time() < deadline:
        descent_deadline = deadline - 5.0           # keep a few seconds for polish
        print("[descent] start")
        a_descent = smoothed_max_descent(
            a0=best_seq.copy(),
            deadline=descent_deadline,
            init_temp=0.12,
            min_temp=1e-6,
            temp_decay=0.9997,
            step0=0.35,
        )
        sc = compute_score(a_descent)
        print(f"[descent] best refined score = {sc:.6f}")
        if sc < best_score:
            best_score, best_seq = sc, a_descent.copy()

    # -----------------------------------------------------------------
    # 5. Sub‑gradient polishing (fine tuning)
    # -----------------------------------------------------------------
    if time.time() < deadline:
        polish_deadline = deadline - 2.0
        print("[polish] start")
        a_polished = subgradient_polish(best_seq.copy(), polish_deadline)
        sc = compute_score(a_polished)
        print(f"[polish] final polished score = {sc:.6f}")
        if sc < best_score:
            best_score, best_seq = sc, a_polished.copy()

    # -----------------------------------------------------------------
    # 6. Safeguard – return uniform vector if nothing succeeded
    # -----------------------------------------------------------------
    if best_seq is None:
        best_seq = np.full(n, 1.0 / n)
        best_score = compute_score(best_seq)

    # -----------------------------------------------------------------
    # 7. Official evaluation (the harness will use this value)
    # -----------------------------------------------------------------
    final_score = evaluate_sequence(best_seq.tolist())
    print(f"\nSearch finished. Reported score = {final_score:.6f}")

    # Return a plain Python list as required by the harness
    return best_seq.tolist()
```
