assistantfinal**Solution Overview**

The objective is scale‑invariant, therefore we may restrict ourselves to vectors whose entries sum to 1.  
The score then simplifies to  

```
score = 2·n·max(conv(a,a))
```

where `conv(a,a)` is the *full* linear convolution of `a` with itself.  
The search consists of four independent stages that together respect the 1000 s wall‑clock limit.

1. **Parametric families** – random vectors are drawn from a handful of analytically simple families
   (Beta‑distribution, Gaussian, exponential, cosine‑taper and sparse Dirichlet).  
   Each candidate is evaluated exactly (FFT based) and the best one is kept.

2. **Flattening (L₂) Adam optimisation** – starting from the best parametric vector we minimise the
   squared deviation of the convolution from its mean (i.e. we make the convolution as flat as
   possible).  This surrogate is differentiable; the gradient is obtained by a single extra FFT.
   Adam‑style momentum and Euclidean projection onto the probability simplex keep the iterates
   feasible.

3. **Sharp max‑surrogate optimisation** – a smooth log‑sum‑exp approximation of the `max`
   (temperature `β` annealed up to 5000) is minimised with Adam and a simplex projection.
   The exact `max` is monitored periodically and the best exact score is recorded.

4. **Projected sub‑gradient + simulated‑annealing polishing** – a classic sub‑gradient method on the
   true max‑objective followed by a stochastic hill‑climb that accepts occasional worsening moves
   (temperature decreasing to zero).  Both steps respect the simplex constraint.

If time permits the current best vector is *upsampled* (each entry split into two halves) and the
refinement steps are repeated on the longer vector – the finer resolution sometimes yields a
slightly lower peak.

All heavy work is done with FFT‑based convolutions (`O(n log n)`) and the code continuously
checks the remaining budget, returning the best vector found before the deadline.

```python
"""Advanced search for a low‑peak autocorrelation step function.

The algorithm combines:
  – random sampling from several parametric families (Beta, Gaussian,
    exponential, cosine‑taper, sparse Dirichlet);
  – an Adam optimiser that flattens the self‑convolution (L2 objective);
  – Adam on a smooth log‑sum‑exp approximation of the max‑convolution;
  – projected sub‑gradient descent on the exact max‑objective;
  – simulated‑annealing hill‑climbing.

All iterates are kept on the probability simplex (non‑negative, unit sum)
so that the scale‑invariant `evaluate_sequence` can be called directly.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic linear‑algebra utilities
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Full linear convolution using real FFT.
    Length of result = len(a) + len(b) - 1.
    """
    m = a.shape[0] + b.shape[0] - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact `evaluate_sequence` score under the constraint ∑a_i = 1.
    Returns 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
    {x | x_i ≥ 0, Σ x_i = 1}.
    """
    v = np.asarray(v, dtype=float)
    n = v.shape[0]

    # fast path for all‑zero vector
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / n)

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    # numerical safety – renormalise if tiny drift occurred
    w_sum = w.sum()
    if w_sum == 0:
        return np.full_like(v, 1.0 / n)
    return w / w_sum


# ----------------------------------------------------------------------
# Random start generators (different shapes)
# ----------------------------------------------------------------------


def random_start_dense(n: int) -> np.ndarray:
    """Uniform Dirichlet‑(1) start."""
    a = np.random.rand(n)
    a /= a.sum()
    return a


def random_start_sparse(n: int) -> np.ndarray:
    """Place mass on about √n positions."""
    k = max(2, int(np.sqrt(n)))
    idx = np.random.choice(n, size=k, replace=False)
    a = np.zeros(n, dtype=float)
    a[idx] = 1.0 / k
    return project_to_simplex(a)


def random_start_gaussian(n: int) -> np.ndarray:
    """Smooth bell‑shaped start (σ≈n/8)."""
    x = np.arange(n)
    sigma = n / 8.0
    a = np.exp(-0.5 * ((x - n / 2) / sigma) ** 2)
    a /= a.sum()
    return a


def random_start(n: int) -> np.ndarray:
    """Pick one of the three generators at random."""
    r = np.random.rand()
    if r < 0.4:
        return random_start_dense(n)
    elif r < 0.7:
        return random_start_sparse(n)
    else:
        return random_start_gaussian(n)


# ----------------------------------------------------------------------
# Parametric families (used in the coarse stage)
# ----------------------------------------------------------------------


def generate_beta(alpha: float, beta: float, n: int) -> np.ndarray:
    """Beta(α,β) density on a regular grid, rescaled to sum = 1."""
    x = (np.arange(n) + 0.5) / n          # centre of each bin in (0,1)
    # compute in log‑space to avoid overflow for α<1 or β<1
    log_a = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    a = np.exp(log_a)
    a_sum = a.sum()
    if a_sum == 0:
        # extreme parameters → fall back to uniform
        a = np.ones(n, dtype=float) / n
    else:
        a /= a_sum
    return a


def generate_gaussian(sigma: float, n: int) -> np.ndarray:
    """Centered Gaussian (σ > 0) on a grid of length n."""
    x = np.arange(n)
    a = np.exp(-0.5 * ((x - n / 2) / sigma) ** 2)
    a_sum = a.sum()
    if a_sum == 0:
        a = np.ones(n, dtype=float) / n
    else:
        a /= a_sum
    return a


def generate_exponential(lam: float, n: int) -> np.ndarray:
    """Symmetric exponential decay from the centre."""
    x = np.arange(n)
    a = np.exp(-lam * np.abs(x - (n - 1) / 2.0))
    a_sum = a.sum()
    if a_sum == 0:
        a = np.ones(n, dtype=float) / n
    else:
        a /= a_sum
    return a


def generate_cosine(width: float, n: int) -> np.ndarray:
    """Raised cosine on an interval of given half‑width (width ≥ 1)."""
    x = np.arange(n)
    center = (n - 1) / 2.0
    arg = np.pi * (x - center) / width
    a = np.cos(arg)
    a[a < 0] = 0.0
    a_sum = a.sum()
    if a_sum == 0:
        a = np.ones(n, dtype=float) / n
    else:
        a /= a_sum
    return a


# ----------------------------------------------------------------------
# 1. Flatten‑convolution Adam optimiser (L2 surrogate)
# ----------------------------------------------------------------------


def flatten_adam_optimize(
    start_a: np.ndarray,
    time_deadline: float,
    max_iters: int = 300_000,
    step0: float = 0.8,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser that minimises  Σ (conv – mean)².
    The gradient is obtained analytically via a second convolution.
    Returns the best exact (max‑convolution) score observed.
    """
    a = start_a.astype(float).copy()
    n = a.shape[0]

    m = np.zeros_like(a)
    v = np.zeros_like(a)

    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8

    best_a = a.copy()
    best_score = compute_score(a)

    for it in range(1, max_iters + 1):
        if time.time() >= time_deadline:
            break

        conv = convolution_fft(a, a)
        avg = conv.mean()
        # weight vector for the L2 loss (∂L/∂conv)
        w = 2.0 * (conv - avg)

        # gradient of Σ w_k * conv_k  w.r.t. a  = 2 * (a_rev * w)[center‑slice]
        a_rev = a[::-1]
        conv_rev = convolution_fft(a_rev, w)
        grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad * grad)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        step = step0 / np.sqrt(it)
        a_new = a - step * m_hat / (np.sqrt(v_hat) + eps)
        a_new = project_to_simplex(a_new)

        a = a_new

        # record best exact score every few hundred steps
        if it % 400 == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()

    # final check
    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# 2. Smooth log‑sum‑exp Adam optimiser (soft‑max surrogate)
# ----------------------------------------------------------------------


def smooth_gradient_optimize_enhanced(
    start_a: np.ndarray,
    time_deadline: float,
    max_iters: int = 300_000,
    beta_start: float = 5.0,
    beta_end: float = 5000.0,
    step0: float = 1.0,
    adam_beta1: float = 0.9,
    adam_beta2: float = 0.999,
    adam_eps: float = 1e-8,
) -> tuple[np.ndarray, float]:
    """
    Adam on the log‑sum‑exp surrogate of max(conv(a,a)).
    Temperature β is geometrically annealed from β_start to β_end.
    Returns the best exact score seen.
    """
    a = start_a.astype(float).copy()
    n = a.shape[0]

    m = np.zeros_like(a)
    v = np.zeros_like(a)

    best_a = a.copy()
    best_score = compute_score(a)

    for it in range(1, max_iters + 1):
        if time.time() >= time_deadline:
            break

        # anneal β
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        conv = convolution_fft(a, a)          # length 2n‑1
        maxc = conv.max()
        # stable soft‑max weights
        w = np.exp(beta * (conv - maxc))
        w_sum = w.sum()
        if w_sum == 0.0:
            w = np.full_like(w, 1.0 / w.shape[0])
        else:
            w /= w_sum

        # gradient of the smoothed objective
        a_rev = a[::-1]
        conv_rev = convolution_fft(a_rev, w)
        grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

        # Adam update
        m = adam_beta1 * m + (1.0 - adam_beta1) * grad
        v = adam_beta2 * v + (1.0 - adam_beta2) * (grad * grad)

        m_hat = m / (1.0 - adam_beta1 ** it)
        v_hat = v / (1.0 - adam_beta2 ** it)

        step = step0 / np.sqrt(it)
        a_new = a - step * m_hat / (np.sqrt(v_hat) + adam_eps)

        a = project_to_simplex(a_new)

        # occasional exact evaluation
        if it % 500 == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# 3. Projected sub‑gradient descent on the true max‑objective
# ----------------------------------------------------------------------


def subgrad_optimize(
    init_a: np.ndarray,
    time_deadline: float,
    max_iter: int = 500_000,
    step0: float = 0.04,
) -> tuple[np.ndarray, float]:
    """
    Classic sub‑gradient method for 2·n·max(conv(a,a)).
    The sub‑gradient comes from the index attaining the maximal convolution entry.
    """
    a = init_a.astype(float).copy()
    best_a = a.copy()
    best_score = compute_score(a)
    n = a.shape[0]

    for t in range(1, max_iter + 1):
        if time.time() >= time_deadline:
            break

        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))                 # offset with maximal entry

        # build sub‑gradient (see analysis)
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        step = step0 / np.sqrt(t)
        a_new = a - step * g
        a_new = project_to_simplex(a_new)

        cur_score = compute_score(a_new)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()

        a = a_new

        # tiny jitter every few thousand iterations to escape possible stalls
        if t % 2000 == 0:
            jitter = np.random.randn(n) * (step0 * 0.003 / np.sqrt(t))
            a += jitter
            a = project_to_simplex(a)

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# 4. Stochastic hill‑climb with simulated‑annealing acceptance
# ----------------------------------------------------------------------


def hill_climb_anneal(
    seq,
    time_deadline,
    max_steps: int = None,
) -> tuple[list[float], float]:
    """
    Random local moves (swap or small mass transfer) with a temperature schedule.
    Improving moves are always accepted; worsening moves are accepted with probability
    exp(−Δ/T).  The temperature decays linearly to a tiny floor.
    """
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(best_a)

    cur_a = a.copy()
    cur_score = best_score

    start = time.time()
    steps = 0
    # initial temperature based on current score
    T0 = best_score * 0.02
    Tmin = best_score * 1e-6

    while (max_steps is None or steps < max_steps) and time.time() < time_deadline:
        elapsed = time.time() - start
        total = time_deadline - start
        T = max(Tmin, T0 * (1.0 - elapsed / total))

        cand = cur_a.copy()
        if np.random.rand() < 0.5:
            # swap two positions
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:
            # transfer a small fraction from i to j
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = 0.05 * cand[i]           # move 5 % of source mass
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0.0:
                    cand[i] = 0.0

        cand = project_to_simplex(cand)
        cand_score = compute_score(cand)

        # acceptance test
        if cand_score < cur_score or np.random.rand() < np.exp(-(cand_score - cur_score) / max(T, 1e-12)):
            cur_a = cand
            cur_score = cand_score
            if cand_score < best_score:
                best_score = cand_score
                best_a = cand.copy()

        steps += 1

    return best_a.tolist(), best_score


# ----------------------------------------------------------------------
# 5. Upsampling helper (splits each mass into two halves)
# ----------------------------------------------------------------------


def upsample_sequence(seq: list[float]) -> np.ndarray:
    """
    Double the length by replacing each entry a_i with two adjacent entries a_i/2.
    The total mass is unchanged; a final projection onto the simplex guards against
    numerical drift.
    """
    a = np.array(seq, dtype=float)
    up = np.empty(2 * a.shape[0], dtype=float)
    up[0::2] = a * 0.5
    up[1::2] = a * 0.5
    up = project_to_simplex(up)
    return up

# Main entry point required by the harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step‑function (list of floats) that minimises
    `evaluate_sequence`.  The routine respects a 1000 s wall‑clock budget and
    returns the best vector found.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a tiny safety margin for the harness after return
    deadline = start_time + budget_s - 2.0

    best_seq = None
    best_val = float("inf")
    n = 2048  # primary resolution

    # ------------------------------------------------------------------
    # 0. Optional fallback from a previously discovered construction
    # ------------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]   # type: ignore
        fallback_val = evaluate_sequence(fallback)
        print(f"Fallback score = {fallback_val:.6f}")
        if fallback_val < best_val:
            best_val = fallback_val
            best_seq = fallback
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1. Coarse parametric search (≈12 % of the budget)
    # ------------------------------------------------------------------
    param_deadline = start_time + 0.12 * budget_s
    families = ["beta", "gauss", "exp", "cos", "dense", "sparse"]
    print("=== Parametric search phase ===")
    while time.time() < param_deadline:
        choice = np.random.choice(families)
        if choice == "beta":
            # α,β drawn log‑uniform in [0.2,5]
            log_a = np.random.uniform(np.log10(0.2), np.log10(5.0))
            log_b = np.random.uniform(np.log10(0.2), np.log10(5.0))
            alpha = 10 ** log_a
            beta = 10 ** log_b
            a = generate_beta(alpha, beta, n)
        elif choice == "gauss":
            sigma = np.random.uniform(n / 32.0, n / 2.0)
            a = generate_gaussian(sigma, n)
        elif choice == "exp":
            lam = np.random.uniform(0.001, 0.02)   # gentle decay
            a = generate_exponential(lam, n)
        elif choice == "cos":
            width = np.random.uniform(n / 8.0, n * 1.5)
            a = generate_cosine(width, n)
        elif choice == "dense":
            a = random_start_dense(n)
        else:  # sparse
            a = random_start_sparse(n)

        scr = compute_score(a)
        if scr < best_val:
            best_val = scr
            best_seq = a.tolist()
            print(f"New best from parametric stage: {best_val:.6f}")

    # ------------------------------------------------------------------
    # 2. L2‑flattening Adam optimisation (if time permits)
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 250.0:
        print("\n=== Flatten‑convolution Adam optimisation ===")
        a0 = np.array(best_seq, dtype=float)
        a_opt, score_opt = flatten_adam_optimize(
            a0,
            time_deadline=deadline - 200.0,
            max_iters=300_000,
            step0=0.8,
        )
        if score_opt < best_val:
            best_val = score_opt
            best_seq = a_opt.tolist()
            print(f"Flatten‑Adam improvement: {best_val:.6f}")

    # ------------------------------------------------------------------
    # 3. Smooth max‑surrogate Adam optimisation (enhanced)
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 150.0:
        print("\n=== Smooth max‑surrogate Adam optimisation ===")
        a0 = np.array(best_seq, dtype=float)
        a_opt, score_opt = smooth_gradient_optimize_enhanced(
            a0,
            time_deadline=deadline - 120.0,
            max_iters=300_000,
            beta_start=5.0,
            beta_end=5000.0,
            step0=1.0,
        )
        if score_opt < best_val:
            best_val = score_opt
            best_seq = a_opt.tolist()
            print(f"Smooth‑max Adam improvement: {best_val:.6f}")

    # ------------------------------------------------------------------
    # 4. Sub‑gradient refinement
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 100.0:
        print("\n=== Sub‑gradient refinement ===")
        a_opt, score_opt = subgrad_optimize(
            np.array(best_seq, dtype=float),
            time_deadline=deadline - 80.0,
            max_iter=400_000,
            step0=0.04,
        )
        if score_opt < best_val:
            best_val = score_opt
            best_seq = a_opt.tolist()
            print(f"Sub‑gradient improvement: {best_val:.6f}")

    # ------------------------------------------------------------------
    # 5. Optional up‑sampling and extra polishing (if budget remains)
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 30.0:
        # try a single up‑sampling step followed by a quick hill‑climb
        print("\n=== Upsampling + final hill‑climb ===")
        up_seq = upsample_sequence(best_seq)                # length → 2·n
        # short polish on the longer vector
        polished_seq, polished_score = hill_climb_anneal(
            up_seq.tolist(),
            time_deadline=deadline - 5.0,
            max_steps=None,
        )
        if polished_score < best_val:
            best_val = polished_score
            best_seq = polished_seq
            print(f"Upsample+hill‑climb improvement: {best_val:.6f}")

    # ------------------------------------------------------------------
    # 6. Fallback to a uniform vector (should never be needed)
    # ------------------------------------------------------------------
    if best_seq is None:
        print("\nFallback – uniform vector")
        n_fallback = 256
        best_seq = [1.0 / n_fallback] * n_fallback
        best_val = evaluate_sequence(best_seq)

    # ------------------------------------------------------------------
    # 7. Final official evaluation (the harness will call it again,
    #    but we log it here for debugging)
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\nFinished search. Final reported score = {final_score:.6f}")

    # Return a plain Python list – the harness expects this.
    return best_seq
```
