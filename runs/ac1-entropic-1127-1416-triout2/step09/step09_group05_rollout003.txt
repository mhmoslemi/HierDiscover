assistantfinal**Solution Overview**

The program searches for a non‑negative step‐function (a list of heights) that minimises  

\[
\text{score}= 
\frac{2n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad (a*a)_k=\sum_i a_i\,a_{k-i}.
\]

Because the score is homogeneous of degree 0 it is enough to keep the
vector normalised to sum = 1; the objective then reduces to  

\[
\text{score}=2n\;\max_k (a*a)_k .
\]

The code follows three stages

1. **Exploratory scan** – a fine grid over three one‑parameter families  
   (exponential, power‑law and a combined exponential·power law) is
   evaluated with the exact objective.  The best few candidates are kept.

2. **Stochastic optimisation** – the best candidate is refined with a
   *smooth‑max* approximation.  The smooth max is  

   \[
   f_\beta(a)=\frac1\beta\log\Bigl(\sum_k e^{\beta\,(a*a)_k}\Bigr)
   \]

   whose gradient can be computed analytically.  An exponentiated‑gradient
   (KL‑mirror) update is performed with an annealed temperature
   \( \beta\) (from 0.5 up to 5000) and a step‑size that decays like
   \( \eta_t\propto 1/\sqrt t\).  Several independent random restarts
   (Dirichlet initialisations) are executed; the best result is retained.

3. **Polishing** – a short greedy hill‑climb (mass swaps / transfers) is
   run on the current best vector to squeeze out the last bits of improvement.

All work respects the 1000 s wall‑clock limit; intermediate scores are printed
for monitoring.

```python
"""
Propose a step‑function that minimises `evaluate_sequence`.

Algorithm
---------
1. Choose a length `n` that fits the remaining time budget.
2. Scan three simple families (exponential, power‑law, combined
   exponential·power‑law).  Keep the best few vectors.
3. From the best vector run several random‑restart exponentiated‑gradient
   optimisations of a smooth log‑sum‑exp approximation of the max‑convolution.
   The temperature β is annealed (0.5 → 5000) and the step size decays as 1/√t.
4. The best result from the restarts is further refined with a longer
   optimisation run.
5. Finish with a greedy hill‑climb that moves a small packet of mass between
   two positions or swaps two entries, accepting only improving moves.
6. Return the best sequence (a plain Python list of floats).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic utilities
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full aperiodic convolution using real FFT."""
    m = a.size + b.size - 1
    nfft = next_pow2(m)
    A = np.fft.rfft(a, n=nfft)
    B = np.fft.rfft(b, n=nfft)
    C = A * B
    return np.fft.irfft(C, n=nfft)[:m]


def compute_score(a: np.ndarray) -> float:
    """
    Exact objective for a vector normalised to sum = 1:
        score = 2·n·max(conv)
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
# Parameterised families
# ----------------------------------------------------------------------


def exponential_shape(n: int, lam: float) -> np.ndarray:
    """a_i ∝ exp(-lam·i), normalised to sum = 1."""
    i = np.arange(n, dtype=float)
    w = np.exp(-lam * i) if lam > 0.0 else np.ones_like(i)
    return w / w.sum()


def power_shape(n: int, p: float) -> np.ndarray:
    """a_i ∝ (i+1)^(-p), normalised to sum = 1."""
    i = np.arange(1, n + 1, dtype=float)
    w = i ** (-p) if p > 0.0 else np.ones_like(i)
    return w / w.sum()


def combined_shape(n: int, lam: float, p: float) -> np.ndarray:
    """a_i ∝ exp(-lam·i)·(i+1)^(-p), normalised to sum = 1."""
    i = np.arange(n, dtype=float)
    # avoid overflow / underflow
    w = np.exp(-lam * i) * (i + 1.0) ** (-p)
    # numerically clean – drop NaNs / infinities
    w = np.where(np.isfinite(w), w, 0.0)
    s = w.sum()
    if s == 0.0:
        # fallback to uniform
        return np.full(n, 1.0 / n)
    return w / s


# ----------------------------------------------------------------------
# Scanning of simple families
# ----------------------------------------------------------------------


def scan_families(n: int, deadline: float, keep_top: int = 10):
    """
    Scan exponential, power‑law and combined families.
    Returns a list of the best `keep_top` vectors (sorted by score).
    """
    candidates = []   # list of (score, vector)

    def maybe_add(vec):
        sc = compute_score(vec)
        candidates.append((sc, vec))
        candidates.sort(key=lambda x: x[0])
        if len(candidates) > keep_top:
            candidates.pop()   # keep only the best keep_top

    # exponential λ grid
    lam_grid = np.concatenate((np.array([0.0]), np.logspace(-5, -2, 200)))
    for lam in lam_grid:
        if time.time() >= deadline:
            break
        a = exponential_shape(n, lam)
        maybe_add(a)

    # power‑law p grid
    p_grid = np.linspace(0.0, 6.0, 200)
    for p in p_grid:
        if time.time() >= deadline:
            break
        a = power_shape(n, p)
        maybe_add(a)

    # combined (lam, p) grid – coarser but explores interactions
    lam_grid2 = np.logspace(-5, -2, 30)   # 30 values
    p_grid2 = np.linspace(0.0, 6.0, 30)   # 30 values
    for lam in lam_grid2:
        for p in p_grid2:
            if time.time() >= deadline:
                break
            a = combined_shape(n, lam, p)
            maybe_add(a)

    # return only the vectors (sorted best first)
    return [vec for _, vec in candidates]


# ----------------------------------------------------------------------
# Smooth‑max exponentiated‑gradient optimisation
# ----------------------------------------------------------------------


def exp_smooth_optimize(
    start_a: np.ndarray,
    deadline: float,
    max_iters: int = 300_000,
    beta_start: float = 0.5,
    beta_end: float = 5000.0,
    eta0: float = 0.6,
    eps: float = 1e-14,
) -> tuple[np.ndarray, float]:
    """
    Minimise a log‑sum‑exp approximation of the max‑convolution.
    Uses a KL‑mirror (exponentiated‑gradient) update.
    """
    a = np.maximum(start_a.astype(float), eps)
    a /= a.sum()
    n = a.shape[0]

    best_a = a.copy()
    best_sc = compute_score(a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # anneal temperature β
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        # smoothed weights (log‑sum‑exp)
        conv = convolution_fft(a, a)
        maxc = conv.max()
        expw = np.exp(beta * (conv - maxc))      # stabilised
        w = expw / expw.sum()

        # gradient of the smooth objective
        a_rev = a[::-1]
        conv_rev = convolution_fft(a_rev, w)
        grad = 2.0 * conv_rev[n - 1 : n - 1 + n]

        # step size (decays as 1/√t)
        eta = eta0 / np.sqrt(it)

        # KL‑mirror update + projection to simplex
        a = np.maximum(a * np.exp(-eta * grad), eps)
        s = a.sum()
        if s == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a /= s

        # occasional exact evaluation
        if it % 200 == 0:
            sc = compute_score(a)
            if sc < best_sc:
                best_sc = sc
                best_a = a.copy()

    # final check
    sc = compute_score(a)
    if sc < best_sc:
        best_sc = sc
        best_a = a.copy()
    return best_a, best_sc


# ----------------------------------------------------------------------
# Greedy hill‑climb polishing
# ----------------------------------------------------------------------


def hill_climb(
    start_seq: np.ndarray,
    deadline: float,
    max_steps: int = 500_000,
) -> tuple[np.ndarray, float]:
    """
    Simple stochastic hill‑climb:
        – with prob 0.5 swap two entries,
        – otherwise transfer a fraction of mass from one index to another.
    Only improving moves are kept.
    """
    a = start_seq.copy()
    n = a.size
    best_a = a.copy()
    best_sc = compute_score(best_a)

    step_scale = 0.12
    steps = 0
    while steps < max_steps and time.time() < deadline:
        cand = best_a.copy()
        if np.random.rand() < 0.5:
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = step_scale * best_a[i]
                cand[i] -= delta
                cand[j] += delta
        cand = project_to_simplex(cand)
        sc = compute_score(cand)

        if sc < best_sc:
            best_sc = sc
            best_a = cand
            step_scale = min(step_scale * 1.07, 0.5)
        else:
            step_scale *= 0.97

        steps += 1

    return best_a, best_sc


# ----------------------------------------------------------------------
# Main entry point expected by the harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative sequence that minimises `evaluate_sequence`.
    The routine
        * scans three analytic families,
        * performs several random‑restart smooth‑max optimisations,
        * finishes with a short hill‑climb,
    while respecting the 1000 s wall‑clock limit.
    """
    np.random.seed(seed)
    start_time = time.time()
    # a small safety margin before the hard timeout
    deadline = start_time + budget_s - 2.0

    # ------------------------------------------------------------------
    # Choose a working length
    # ------------------------------------------------------------------
    remaining = deadline - start_time
    if remaining > 800:
        n = 8192
    elif remaining > 500:
        n = 4096
    else:
        n = 2048
    print(f"[{time.time():.1f}] chosen length = {n}")

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # Optional fallback from a previously found construction
    # ------------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]  # type: ignore
        fb = evaluate_sequence(fallback)
        print(f"[{time.time():.1f}] fallback score = {fb:.6f}")
        if fb < best_score:
            best_score = fb
            best_seq = fallback
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1. Scan analytic families (exponential, power‑law, combined)
    # ------------------------------------------------------------------
    scan_deadline = deadline - 180.0
    family_vectors = scan_families(n, scan_deadline, keep_top=10)
    for vec in family_vectors:
        sc = compute_score(vec)
        if sc < best_score:
            best_score = sc
            best_seq = vec.tolist()
    if best_seq is not None:
        print(f"[{time.time():.1f}] best after family scan = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2. Random‑restart smooth‑max optimisation
    # ------------------------------------------------------------------
    # Allocate time for a few independent runs
    while time.time() < deadline - 140.0:
        # random Dirichlet start
        rnd = np.random.rand(n)
        start_a = rnd / rnd.sum()
        # a few short runs first (to explore)
        opt_deadline = min(deadline - 120.0, time.time() + 30.0)
        a_opt, sc_opt = exp_smooth_optimize(
            start_a,
            opt_deadline,
            max_iters=180_000,
            beta_start=0.5,
            beta_end=2000.0,
            eta0=0.6,
        )
        if sc_opt < best_score:
            best_score = sc_opt
            best_seq = a_opt.tolist()
            print(f"[{time.time():.1f}] new best after random‑restart = {best_score:.6f}")

        # stop early if we have hardly any time left
        if time.time() > deadline - 130.0:
            break

    # ------------------------------------------------------------------
    # 3. Long refinement on the current best vector
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 70.0:
        print(f"[{time.time():.1f}] long refinement started")
        a_ref, sc_ref = exp_smooth_optimize(
            np.array(best_seq, dtype=float),
            deadline - 60.0,
            max_iters=500_000,
            beta_start=0.5,
            beta_end=5000.0,
            eta0=0.6,
        )
        if sc_ref < best_score:
            best_score = sc_ref
            best_seq = a_ref.tolist()
            print(f"[{time.time():.1f}] after long refinement best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4. Final hill‑climb polishing
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 5.0:
        print(f"[{time.time():.1f}] final hill‑climb")
        a_final, sc_final = hill_climb(
            np.array(best_seq, dtype=float),
            deadline,
            max_steps=700_000,
        )
        if sc_final < best_score:
            best_score = sc_final
            best_seq = a_final.tolist()
            print(f"[{time.time():.1f}] hill‑climb improved best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Safeguard – fall back to a tiny uniform vector if nothing was found
    # ------------------------------------------------------------------
    if best_seq is None:
        n_small = 256
        best_seq = [1.0 / n_small] * n_small
        best_score = evaluate_sequence(best_seq)

    # ------------------------------------------------------------------
    # Final official evaluation (the harness will also call it)
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\n[{time.time():.1f}] finished search – final reported score = {final_score:.6f}")

    # The harness expects a plain Python list of floats.
    return best_seq
```
