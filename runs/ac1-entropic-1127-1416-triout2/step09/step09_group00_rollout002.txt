   n = len(f)
   if M is None:
       conv_f = np.convolve(f, f)
       M = conv_f.max()
   Build matrix A (2n-1 x n). We'll use sparse.

assistantfinal**Solution Overview**

The evaluation function is  

\[
J(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2},
\qquad a_i\ge 0\; .
\]

Because the numerator and the denominator are both quadratic in the
scale of *a*, the objective is **scale‑invariant** – we can restrict the
search to the probability simplex  

\[
\sum_i a_i = 1,\qquad a_i\ge 0 .
\]

For a fixed vector \(f\) define  

\[
M(f)=\max (f*f) .
\]

If we can find another non‑negative vector \(b\) with a larger
\(\ell_1\)‑norm while still satisfying

\[
(f*b)_k\le M(f)\qquad\forall k,
\]

then after normalising \(b\) to unit sum we obtain a new candidate
\(g\).  The convex combination  

\[
f^{\text{new}}=(1-t)f+t\,g ,\qquad 0<t\le 1,
\]

has the same total mass as \(f\) and a *strictly* smaller peak
convolution.  This is exactly the linear‑programming step described in
the original paper.

The algorithm below consists of three phases  

1. **Initialisation** – take the best known construction (the global
   variable `height_sequence_1`), otherwise fall back to a quick
   analytic scan over a few parameterised families.
2. **LP‑refinement** – repeatedly solve the linear programme

   \[
   \begin{aligned}
   \max\;&\mathbf 1^\top b\\
   \text{s.t. }&A_f\,b\le M(f)\mathbf 1,\;b\ge 0,
   \end{aligned}
   \]

   where the matrix \(A_f\) encodes the aperiodic convolution
   \( (f*b)_k = \sum_j f_{k-j}\,b_j\).
   The solution is mixed with the current iterate.
3. **Polishing** – a short projected sub‑gradient descent (the cheap
   routine already used in the reference code) fine‑tunes the final
   vector.

All work respects the global time budget (default 1000 s).  The code
uses only `numpy` and `scipy.optimize.linprog` (the HiGHS solver), which
handles the dense linear programme efficiently for the chosen size
\(n=2048\).

```python
"""
Iterative LP‑refinement of a non‑negative step function.

The algorithm:
  1. Start from the best known construction (fallback: quick analytic scan).
  2. While time permits:
        • compute M = max(f*f)
        • build the convolution matrix A_f  (A_f b = f*b)
        • solve   max 1ᵀb  s.t. A_f b ≤ M, b ≥ 0   (LP)
        • normalise b → g, mix g into f with step size t.
  3. Finish with a few thousand cheap sub‑gradient steps.
The returned list is a probability vector (sum = 1).  The evaluation
function is scale‑invariant, so the objective value is 2·n·max(conv).
"""

import time
import numpy as np
from scipy.optimize import linprog

# ----------------------------------------------------------------------
# Helper utilities (FFT based convolution, simplex projection)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Full aperiodic convolution using real FFT.
    Returns length len(a)+len(b)-1 array.
    """
    m = a.size + b.size - 1
    nfft = next_pow2(m)
    A = np.fft.rfft(a, n=nfft)
    B = np.fft.rfft(b, n=nfft)
    C = A * B
    conv = np.fft.irfft(C, n=nfft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact objective for a probability vector (∑a = 1):
        J(a) = 2·n·max(a*a)
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex.
    """
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
# Analytic families (used only for a cheap fallback initialisation)
# ----------------------------------------------------------------------


def symmetric_product_family(n: int, alpha: float) -> np.ndarray:
    """a_i ∝ [(i+½)(n‑½‑i)]^{‑α}, symmetric and normalised."""
    i = np.arange(n, dtype=np.float64)
    logprod = np.log(i + 0.5) + np.log(n - 0.5 - i)
    w = np.exp(-alpha * logprod)
    a = w / w.sum()
    return a


def left_heavy_power_family(n: int, beta: float) -> np.ndarray:
    """a_i ∝ (i+½)^{‑β}, monotone decreasing, normalised."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-beta * np.log(i + 0.5))
    a = w / w.sum()
    return a


def exp_u_family(n: int, gamma: float) -> np.ndarray:
    """U‑shape: a_i ∝ exp(-γ·min(i, n‑1‑i)), normalised."""
    i = np.arange(n, dtype=np.float64)
    dist = np.minimum(i, n - 1 - i)
    w = np.exp(-gamma * dist)
    a = w / w.sum()
    return a


# ----------------------------------------------------------------------
# Linear‑programming refinement (core of the new algorithm)
# ----------------------------------------------------------------------


def build_conv_matrix(f: np.ndarray) -> np.ndarray:
    """
    Build the dense matrix A such that A @ b = f * b (full convolution).
    For n = len(f) the matrix has shape (2*n-1, n).
    """
    n = f.shape[0]
    rows = 2 * n - 1
    A = np.empty((rows, n), dtype=np.float64)
    # each column i receives the whole vector f shifted by i rows
    for i in range(n):
        A[i:i + n, i] = f
    return A


def lp_step(f: np.ndarray, mix: float = 0.5) -> np.ndarray:
    """
    Perform one LP refinement step.
        * maximise sum(b)   subject to   (f*b)_k ≤ M(f)   and   b≥0
    Returns the convex combination (1‑mix)·f + mix·g,
    where g is the normalised solution of the LP.
    """
    n = f.shape[0]
    conv_f = convolution_fft(f, f)
    M = conv_f.max()

    # Build convolution matrix A_f
    A = build_conv_matrix(f)                     # shape (2n‑1, n)
    b_ub = np.full(A.shape[0], M, dtype=np.float64)

    # Linear programme: maximise 1ᵀb  →  minimise -1ᵀb
    c = -np.ones(n, dtype=np.float64)
    bounds = [(0.0, None)] * n

    # HiGHS is fast and handles dense problems well
    res = linprog(
        c,
        A_ub=A,
        b_ub=b_ub,
        bounds=bounds,
        method="highs",
        options={"presolve": True, "time_limit": 30},
    )

    if not res.success:
        # If LP fails we simply keep the current f.
        return f

    b = np.maximum(res.x, 0.0)          # clip tiny negatives caused by numerical noise
    sum_b = b.sum()
    if sum_b <= 1e-12:
        return f

    # Normalise to the simplex
    g = b / sum_b

    # Convex combination (mix ∈ (0,1])
    f_new = (1.0 - mix) * f + mix * g
    # Numerical drift may break exact sum‑to‑1; re‑project
    f_new = project_to_simplex(f_new)
    return f_new


# ----------------------------------------------------------------------
# Very cheap projected sub‑gradient descent (final polishing)
# ----------------------------------------------------------------------


def subgrad_optimize(start_a: np.ndarray,
                     deadline: float,
                     max_iters: int = 200_000,
                     step0: float = 0.07) -> np.ndarray:
    """
    Projected sub‑gradient descent on  J(a)=2·n·max(a*a)
    with diminishing step size  step0 / sqrt(t).
    """
    n = start_a.shape[0]
    a = start_a.astype(np.float64).copy()
    best = a.copy()
    best_score = compute_score(a)

    for t in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))

        # gradient of the active entry (ordered pairs)
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        step = step0 / np.sqrt(t)
        a = project_to_simplex(a - step * g)

        if t % 2000 == 0:
            sc = compute_score(a)
            if sc < best_score:
                best_score = sc
                best = a.copy()
                print(f"[{time.time():.1f}] sub‑grad improved to {best_score:.6f}")

    # final check
    if compute_score(a) < best_score:
        best = a.copy()
    return best


# ----------------------------------------------------------------------
# High‑level driver required by the evaluation harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Search for a step‑function that minimises the evaluation metric.
    The routine respects the global time budget and returns a plain
    Python list of floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin for the harness
    deadline = start_time + budget_s - 2.0

    best_vec = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 0.  Fallback construction (global variable, if present)
    # ------------------------------------------------------------------
    try:
        fb = globals()["height_sequence_1"]               # may be a list/array
        fb_vec = [float(x) for x in fb]
        sc = evaluate_sequence(fb_vec)
        print(f"[{time.time():.1f}] fallback score = {sc:.6f}")
        if sc < best_score:
            best_score = sc
            best_vec = fb_vec
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1.  Cheap analytic scan (only if we have no fallback)
    # ------------------------------------------------------------------
    if best_vec is None:
        n = 2048
        best_local = None
        best_local_score = float("inf")
        # Scan a few alphas for the symmetric product family
        for alpha in np.linspace(0.0, 8.0, 33):
            if time.time() >= deadline - 30.0:
                break
            cand = symmetric_product_family(n, alpha)
            sc = compute_score(cand)
            if sc < best_local_score:
                best_local_score = sc
                best_local = cand
        # Scan a few betas for the left‑heavy power law
        for beta in np.linspace(0.0, 8.0, 33):
            if time.time() >= deadline - 30.0:
                break
            cand = left_heavy_power_family(n, beta)
            sc = compute_score(cand)
            if sc < best_local_score:
                best_local_score = sc
                best_local = cand
        # Scan a few gammas for the exponential U‑shape
        for gamma in np.linspace(0.0, 4.0, 21):
            if time.time() >= deadline - 30.0:
                break
            cand = exp_u_family(n, gamma)
            sc = compute_score(cand)
            if sc < best_local_score:
                best_local_score = sc
                best_local = cand

        if best_local is not None:
            best_vec = best_local.tolist()
            best_score = compute_score(np.array(best_vec))
            print(f"[{time.time():.1f}] analytic start score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 2.  Main LP‑refinement loop
    # ------------------------------------------------------------------
    if best_vec is not None:
        f = np.array(best_vec, dtype=np.float64)
        f = project_to_simplex(f)               # ensure exact sum = 1
        best_score = compute_score(f)
        print(f"[{time.time():.1f}] start LP loop – score = {best_score:.6f}")

        iteration = 0
        mix = 0.5                                # initial mixing weight
        while time.time() < deadline - 30.0 and iteration < 12:
            iteration += 1
            f_prev = f.copy()
            f = lp_step(f, mix=mix)

            new_score = compute_score(f)
            print(f"[{time.time():.1f}] LP iter {iteration:02d} → score {new_score:.6f}")

            if new_score < best_score - 1e-8:
                best_score = new_score
                best_vec = f.tolist()
                # slowly shrink the mixing factor to stabilise later iterations
                mix = max(0.15, mix * 0.85)
            else:
                # no progress – stop early
                print("[{:.1f}] LP stopped – no improvement".format(time.time()))
                break

    # ------------------------------------------------------------------
    # 3.  Final cheap sub‑gradient polishing (if time permits)
    # ------------------------------------------------------------------
    if best_vec is not None and time.time() < deadline - 5.0:
        a_start = np.array(best_vec, dtype=np.float64)
        a_refined = subgrad_optimize(
            a_start,
            deadline - 2.0,
            max_iters=200_000,
            step0=0.06,
        )
        refined_score = compute_score(a_refined)
        if refined_score < best_score:
            best_score = refined_score
            best_vec = a_refined.tolist()
            print(f"[{time.time():.1f}] post‑subgrad improved to {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4.  Final safety net (unlikely to be used)
    # ------------------------------------------------------------------
    if best_vec is None:
        n_small = 256
        best_vec = [1.0 / n_small] * n_small
        best_score = evaluate_sequence(best_vec)

    # ------------------------------------------------------------------
    # 5.  Report final result
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_vec)
    print(f"\n[{time.time():.1f}] finished – final reported score = {final_score:.6f}")

    return best_vec
```
