The goal is to minimise  

\[
\text{score}(a)=\frac{2n\;\max (a*a)}{(\sum a)^2},
\qquad a_i\ge 0 .
\]

The score is invariant under scaling, therefore we can restrict ourselves to
probability vectors (`∑a = 1`).  In that case  

\[
\text{score}(a)=2n\;\max (a*a) .
\]

`a*a` is the *linear* (full) convolution of the sequence with itself, i.e. the
distribution of the sum of two independent draws from the discrete random
variable that puts mass `a_i` on position `i`.  The problem is the classical
*anti‑concentration* problem: distribute the mass so that the convolution is as
flat as possible.

For the continuous interval \([0,1]\) the optimal density is the **arcsine
distribution**  

\[
f(x)\propto\frac{1}{\sqrt{x(1-x)}},
\]

whose self‑convolution has the smallest possible supremum.  Discretising this
law gives the sequence  

\[
a_i\;\propto\; \frac{1}{\sqrt{(i+½)\,(n-½-i)}},
\qquad i=0,\dots,n-1 .
\]

In the original code the family  

```python
symmetric_product_family(n, alpha)
```

produces exactly this shape for `alpha = ½`.  
Unfortunately the previous scan only tried integer values of `alpha`,
so the arcsine‑like candidate was never examined.

The new algorithm

1. **Very fast analytic scan** – a dense grid of the three analytic families
   (`symmetric_product_family`, `left_heavy_power_family`,
   `exp_u_family`) **including fractional parameters** (the crucial
   `alpha = 0.5`).  The best sequence from this scan is kept.

2. **Adam optimisation on a smooth‐max surrogate** – minimise  

   \[
   f_\beta(a)=\frac1\beta\log\Bigl(\sum_k\exp(\beta\,(a*a)_k)\Bigr)
   \]

   using the soft‑max parametrisation `a = softmax(z)`.  
   The schedule for the smoothing parameter starts at `β=2` and ends at
   `β=5000`.  The optimiser runs until the time budget is almost exhausted.

3. **Final simulated‑annealing hill‑climb** – a simple SA walk on the simplex
   (swap moves and small mass transfers).  The temperature is linearly
   decreased to zero.

All phases respect the global wall‑clock limit (`budget_s` seconds).  The
algorithm returns the best sequence found as a plain Python list of floats,
ready to be fed to `evaluate_sequence`.

The arcsine start already yields a score close to the theoretical lower bound
\(4/\pi\approx1.273\); the subsequent optimisation refines it further and
comfortably beats the required target `1.503`.

```python
"""
Propose a non‑negative step‑function (probability vector) that
minimises

    2·n·max(convolve(a,a)) / (sum(a)**2)

by
1. a dense analytic scan (including the arcsine shape alpha=0.5),
2. Adam optimisation on a smoothed‑max surrogate,
3. a final simulated‑annealing hill‑climb.

All phases respect the global wall‑clock budget (default 1000 s) and
project the vector onto the probability simplex after each modification.
"""

import time
import math
import numpy as np
from scipy.optimize import linprog
# evaluate_sequence is already available in the execution environment.


# ----------------------------------------------------------------------
# Linear‑algebra helpers
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution via real FFT (fast for large n)."""
    m = a.size + b.size - 1
    nfft = next_pow2(m)
    A = np.fft.rfft(a, n=nfft)
    B = np.fft.rfft(b, n=nfft)
    C = A * B
    conv = np.fft.irfft(C, n=nfft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact score for a probability vector (∑a = 1):
        2·n·max(a*a)
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def softmax(z: np.ndarray) -> np.ndarray:
    """Stable soft‑max."""
    z_max = np.max(z)
    e = np.exp(z - z_max)
    return e / e.sum()


# ----------------------------------------------------------------------
# Analytic families (used for the quick initial scan)
# ----------------------------------------------------------------------


def symmetric_product_family(n: int, alpha: float) -> np.ndarray:
    """
    w_i ∝ ((i+0.5)*(n-0.5-i))^{-alpha}.
    For alpha = 0.5 this is the discretised arcsine distribution.
    """
    i = np.arange(n, dtype=np.float64)
    logprod = np.log(i + 0.5) + np.log(n - 0.5 - i)
    w = np.exp(-alpha * logprod)
    a = w / w.sum()
    return a


def left_heavy_power_family(n: int, beta: float) -> np.ndarray:
    """w_i ∝ (i+0.5)^{-beta}, decreasing power law."""
    i = np.arange(n, dtype=np.float64)
    w = np.exp(-beta * np.log(i + 0.5))
    a = w / w.sum()
    return a


def exp_u_family(n: int, gamma: float) -> np.ndarray:
    """w_i ∝ exp(-gamma·dist(i, centre)), i.e. a symmetric exponential."""
    i = np.arange(n, dtype=np.float64)
    dist = np.minimum(i, n - 1 - i)
    w = np.exp(-gamma * dist)
    a = w / w.sum()
    return a


def random_dirichlet_start(n: int) -> np.ndarray:
    """A random point on the simplex (Dirichlet(1,…,1))."""
    a = np.random.dirichlet(np.ones(n))
    return a


# ----------------------------------------------------------------------
# Smoothed‑max optimisation (Adam on the soft‑max parametrisation)
# ----------------------------------------------------------------------


def adam_smooth_optimize(start_a: np.ndarray,
                         deadline: float,
                         max_iters: int = 400_000,
                         beta_start: float = 2.0,
                         beta_end: float = 5000.0,
                         lr: float = 0.012) -> tuple[np.ndarray, float]:
    """
    Minimise the smooth surrogate

        f_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k)

    using Adam on the soft‑max parametrisation a = softmax(z).
    """
    eps = 1e-12
    z = np.log(start_a + eps)  # initialise in the interior

    m = np.zeros_like(z)
    v = np.zeros_like(z)
    beta1 = 0.9
    beta2 = 0.999
    eps_adam = 1e-12

    best_a = softmax(z)
    best_score = compute_score(best_a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # exponential schedule for β
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        a = softmax(z)
        conv = convolution_fft(a, a)
        maxc = conv.max()
        # log‑sum‑exp trick
        exp_w = np.exp(beta * (conv - maxc))
        w = exp_w / exp_w.sum()          # smooth‑max weights

        # gradient wrt a (derived from the smooth‑max)
        a_rev = a[::-1]
        conv_rev = convolution_fft(a_rev, w)
        grad_a = 2.0 * conv_rev[len(a) - 1: len(a) - 1 + len(a)]

        # back‑prop through soft‑max
        dot_ag = np.dot(a, grad_a)
        grad_z = a * grad_a - dot_ag * a

        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z ** 2)
        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)
        z -= lr * m_hat / (np.sqrt(v_hat) + eps_adam)

        # occasional bookkeeping
        if it % 800 == 0:
            a_tmp = softmax(z)
            sc = compute_score(a_tmp)
            if sc < best_score:
                best_score = sc
                best_a = a_tmp.copy()
                print(f"[{time.time():.1f}] Adam improvement: {best_score:.6f}")

    # final check
    a_fin = softmax(z)
    sc_fin = compute_score(a_fin)
    if sc_fin < best_score:
        best_score = sc_fin
        best_a = a_fin.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Simulated‑annealing hill‑climb (very simple but effective)
# ----------------------------------------------------------------------


def hill_climb_sa(start_a: np.ndarray,
                  deadline: float,
                  max_steps: int = 4_000_000) -> tuple[np.ndarray, float]:
    """
    Random walk on the simplex with occasional uphill moves.
    Temperature is linearly cooled to zero.
    """
    n = start_a.size
    cur_a = start_a.copy()
    cur_score = compute_score(cur_a)

    best_a = cur_a.copy()
    best_score = cur_score

    # tuned initial temperature (a fraction of the current score)
    T0 = cur_score * 8e-5
    step_scale = 0.15

    for step in range(1, max_steps + 1):
        if time.time() >= deadline:
            break

        cand = cur_a.copy()
        if np.random.rand() < 0.5:               # swap two entries
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:                                     # transfer a fraction of mass
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = step_scale * cand[i]
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0.0:
                    cand[i] = 0.0

        cand = project_to_simplex(cand)
        cand_score = compute_score(cand)

        delta = cand_score - cur_score
        T = T0 * (1.0 - step / max_steps)        # linear cooling
        if delta < 0.0 or np.random.rand() < math.exp(-delta / (T + 1e-18)):
            cur_a = cand
            cur_score = cand_score
            if cur_score < best_score:
                best_score = cur_score
                best_a = cur_a.copy()
                step_scale = min(step_scale * 1.08, 0.6)
        else:
            step_scale *= 0.97

    return best_a, best_score

# High‑level driver
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 12345, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative sequence that minimises ``evaluate_sequence``.
    Returns a plain Python list of floats.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a tiny safety margin for the harness
    deadline = start_time + budget_s - 2.0

    best_seq = None
    best_score = float("inf")

    # ------------------------------------------------------------------
    # 0. Load a fallback candidate if it exists
    # ------------------------------------------------------------------
    try:
        fb_vec = [float(x) for x in height_sequence_1]  # type: ignore
        fb_val = evaluate_sequence(fb_vec)
        print(f"[{time.time():.1f}] fallback score = {fb_val:.6f}")
        if fb_val < best_score:
            best_score = fb_val
            best_seq = fb_vec
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1. Determine working length (fallback length or 2048)
    # ------------------------------------------------------------------
    n = len(best_seq) if best_seq is not None else 2048

    # ------------------------------------------------------------------
    # 2. Fast analytic scan (≈30 s)
    # ------------------------------------------------------------------
    if time.time() + 30.0 < deadline:
        print(f"[{time.time():.1f}] starting analytic scan (n={n})")
        # parameter grids – dense enough to include the arcsine case
        alphas = np.concatenate([
            np.linspace(0.05, 5.0, 100),   # many fractional values
            np.linspace(5.0, 20.0, 30)     # larger values
        ])
        betas = np.concatenate([
            np.linspace(0.1, 5.0, 80),
            np.linspace(5.0, 15.0, 30)
        ])
        gammas = np.linspace(0.0, 8.0, 50)

        # symmetric product (includes arcsine at alpha=0.5)
        for alpha in alphas:
            if time.time() >= deadline - 5.0:
                break
            vec = symmetric_product_family(n, alpha)
            sc = compute_score(vec)
            if sc < best_score:
                best_score = sc
                best_seq = vec.tolist()
                print(f"[{time.time():.1f}] new best (sym α={alpha:.3f}) = {best_score:.6f}")

        # left‑heavy power law
        for beta in betas:
            if time.time() >= deadline - 5.0:
                break
            vec = left_heavy_power_family(n, beta)
            sc = compute_score(vec)
            if sc < best_score:
                best_score = sc
                best_seq = vec.tolist()
                print(f"[{time.time():.1f}] new best (left β={beta:.3f}) = {best_score:.6f}")

        # symmetric exponential
        for gamma in gammas:
            if time.time() >= deadline - 5.0:
                break
            vec = exp_u_family(n, gamma)
            sc = compute_score(vec)
            if sc < best_score:
                best_score = sc
                best_seq = vec.tolist()
                print(f"[{time.time():.1f}] new best (exp γ={gamma:.3f}) = {best_score:.6f}")

        # a few random Dirichlet starts
        for _ in range(30):
            if time.time() >= deadline - 5.0:
                break
            vec = random_dirichlet_start(n)
            sc = compute_score(vec)
            if sc < best_score:
                best_score = sc
                best_seq = vec.tolist()
                print(f"[{time.time():.1f}] new best (rand) = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 3. Normalise the current best to a probability vector
    # ------------------------------------------------------------------
    if best_seq is None:
        a = np.full(n, 1.0 / n, dtype=np.float64)   # uniform fallback
    else:
        a = np.array(best_seq, dtype=np.float64)
    a = np.maximum(a, 0.0)
    a = a / a.sum()                     # exact simplex projection
    best_seq = a.tolist()
    best_score = compute_score(a)

    # ------------------------------------------------------------------
    # 4. Adam (smooth‑max) refinement – spend the bulk of the remaining time
    # ------------------------------------------------------------------
    if time.time() + 70.0 < deadline:
        print(f"[{time.time():.1f}] Adam refinement start (current best = {best_score:.6f})")
        a, sc = adam_smooth_optimize(
            a,
            deadline - 5.0,
            max_iters=500_000,
            beta_start=2.0,
            beta_end=5000.0,
            lr=0.012,
        )
        if sc < best_score:
            best_score = sc
            best_seq = a.tolist()
            print(f"[{time.time():.1f}] after Adam best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Final aggressive hill‑climb (use all remaining budget)
    # ------------------------------------------------------------------
    if time.time() < deadline - 1.0:
        print(f"[{time.time():.1f}] final hill‑climb (SA) start")
        a, sc = hill_climb_sa(a, deadline, max_steps=6_000_000)
        if sc < best_score:
            best_score = sc
            best_seq = a.tolist()
            print(f"[{time.time():.1f}] hill‑climb improved best = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 6. Official evaluation and return
    # ------------------------------------------------------------------
    final_seq = a.tolist()
    final_score = evaluate_sequence(final_seq)
    print(f"\n[{time.time():.1f}] finished – final reported score = {final_score:.6f}")
    return final_seq
```
