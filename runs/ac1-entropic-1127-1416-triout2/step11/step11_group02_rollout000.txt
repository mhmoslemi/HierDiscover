The score returned by `evaluate_sequence` is  

\[
\text{score}(a)=\frac{2\,n\;\max_k (a*a)_k}{(\sum_i a_i)^2},
\qquad a_i\ge 0 .
\]

Because the denominator is homogeneous we may **force** the vector to be a
probability distribution (`∑a_i = 1`).  
For a fixed vector `a` the convolution `c = a*a` is linear in `a`,
but the “max‑over‑coordinates’’ part is non‑smooth.  
A common trick is to replace the max by a **smooth log‑sum‑exp**
approximation

\[
f_\lambda(a)=\frac1\lambda\log\Bigl(\sum_k e^{\lambda\,c_k}\Bigr),
\qquad \lambda>0,
\]

which converges to `max(c)` when `λ→∞`.  
For a given `λ` the gradient can be written very compactly:

\[
\nabla f_\lambda(a)=
2\;w *_{\text{corr}} a ,
\qquad
w_k=\frac{e^{\lambda c_k}}{\sum_j e^{\lambda c_j}},
\]

i.e. two times the **cross‑correlation** of the weight vector `w` with the
current step‑function `a`.  
Both the convolution `c = a*a` and the correlation can be evaluated
with a single FFT of length `≈3·n`, so each iteration costs only
`O(n log n)` (≈ 1 ms for `n = 2048`).

The optimiser therefore works as follows

1. **Quick global sweep** (power‑law, geometric families) – gives a decent
   starting point.
2. **Projected gradient descent on `f_λ`** – λ is increased slowly
   (`λ = 5 → 200`) so the algorithm first follows a smooth landscape
   and later focuses on the true maximum.
   After every gradient step the iterate is projected onto the probability
   simplex (`project_to_simplex`).
3. **Final local polish** – a cheap stochastic hill‑climb, exactly as in the
   reference implementation, to extract any remaining tiny improvement.

All phases respect the total wall‑clock budget (default 1000 s).  
The code below implements the whole pipeline and returns the best
sequence it found.

```python
"""
Step‑function optimiser for `evaluate_sequence`.

Approach
--------
*   Normalise the coefficients to a probability vector (∑a = 1).
*   Initialise with a cheap parametric sweep (power‑law / geometric families).
*   Refine by projected gradient descent on a smooth approximation of the
    max‑convolution:   f_λ(a) = (1/λ)·log Σ exp(λ·(a*a)).
    The gradient is 2·corr(w, a) where w is the soft‑max of the current
    convolution.  FFTs give the gradient in O(n log n) time.
*   λ is increased from a small value (≈5) to a larger one (≈200) so the
    optimisation first follows a smooth surface and finally concentrates
    on the true max.
*   After the gradient phase a short stochastic hill‑climb (mass‑transfer)
    is applied for extra polishing.

The whole search respects a 1000 s wall‑clock limit and returns a plain
Python list of non‑negative floats.
"""

def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex.
    Result is non‑negative and sums to 1.
    """
    if np.all(v <= 0):
        # All non‑positive → project to the uniform distribution.
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    mask = u - cssv / ind > 0
    rho = np.where(mask)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


def next_pow2(x: int) -> int:
    """Small helper – next power of two ≥ x."""
    return 1 << ((x - 1).bit_length())


def full_convolution(a: np.ndarray) -> np.ndarray:
    """
    Linear (full) convolution a*a using a real FFT.
    Length of the result is 2·len(a)‑1.
    """
    n = a.shape[0]
    m = 2 * n - 1
    L = next_pow2(m)
    A = np.fft.rfft(a, n=L)
    C = A * A
    conv = np.fft.irfft(C, n=L)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact objective for a normalised vector (∑a == 1):
        2·n·max(conv(a,a))
    """
    n = a.shape[0]
    conv = full_convolution(a)
    return float(2.0 * n * conv.max())

# Phase 2 – smooth‑max gradient descent (FFT based)

def correlation_w_a(w: np.ndarray, a: np.ndarray) -> np.ndarray:
    """
    Compute the cross‑correlation needed for the gradient:
        g_i = 2·∑_j w_{i+j}·a_j ,  i = 0..n‑1
    Both arguments are real, `w` length = 2·n‑1, `a` length = n.
    Returned `g` has length n.
    """
    n = a.shape[0]
    m = w.shape[0]            # = 2·n‑1
    L = next_pow2(n + m - 1)   # length for linear correlation (no wrap‑around)

    # FFTs (real‑to‑complex) ------------------------------------------------
    W = np.fft.rfft(w, n=L)
    A = np.fft.rfft(a, n=L)

    # Linear correlation via inverse FFT of product W·conj(A)
    corr_full = np.fft.irfft(W * np.conj(A), n=L)[: n + m - 1]

    # Valid part starts at offset (n‑1)
    start = n - 1
    g = 2.0 * corr_full[start:start + n]
    return g


def smooth_max_descent(
    a0: np.ndarray,
    deadline: float,
    lambda_start: float = 5.0,
    lambda_end: float = 200.0,
    step0: float = 0.25,
) -> np.ndarray:
    """
    Projected gradient descent on the smooth approximation of the max‑convolution.
    The schedule slowly raises `λ` so the optimisation first moves on a
    smooth surface and later concentrates on the true max.
    """
    a = a0.copy()
    n = a.shape[0]

    best_a = a.copy()
    best_M = full_convolution(a).max()

    it = 0
    λ = lambda_start
    λ_inc_factor = (lambda_end / lambda_start) ** (1.0 / 5000)  # ≈ 5000 steps

    # Pre‑allocate arrays to avoid repeated allocations (tiny optimisation)
    while time.time() < deadline:
        it += 1

        # 1️⃣ convolution a*a
        conv = full_convolution(a)

        # 2️⃣ soft‑max weights (stable formulation)
        M = conv.max()
        exp_shift = np.exp(λ * (conv - M))          # subtract max to avoid overflow
        w = exp_shift / exp_shift.sum()

        # 3️⃣ gradient = 2·corr(w, a)
        g = correlation_w_a(w, a)

        # 4️⃣ step size (inverse‑sqrt schedule)
        step = step0 / math.sqrt(it)

        # 5️⃣ take a gradient step and project back onto the simplex
        a_new = a - step * g
        a_new = project_to_simplex(a_new)

        # 6️⃣ evaluate new maximum convolution
        conv_new = full_convolution(a_new)
        M_new = conv_new.max()

        # 7️⃣ keep the best vector seen so far
        if M_new < best_M:
            best_M = M_new
            best_a = a_new.copy()

        # 8️⃣ simple early‑stopping heuristic: if no improvement for many
        #    iterations we may lower the step size more aggressively.
        if it % 2000 == 0:
            if best_M / M < 0.9999:   # some improvement observed
                pass
            else:
                step0 *= 0.5           # become more careful

        # 9️⃣ increase λ slowly (log‑linear schedule)
        λ = min(lambda_end, λ * λ_inc_factor)

        a = a_new

        # occasional progress report (does not affect timing much)
        if it % 500 == 0:
            print(
                f"[smooth‑GD] it={it:5d} λ={λ:6.2f} best_M={best_M:.6e}"
            )

    return best_a

def hill_climb(a_start: np.ndarray, deadline: float, max_iter: int = 1_000_000) -> np.ndarray:
    """Tiny stochastic moves with greedy acceptance."""
    a = a_start.copy()
    best_a = a.copy()
    best_M = full_convolution(a).max()
    n = a.shape[0]
    step_scale = 0.05
    it = 0
    no_improve = 0

    while time.time() < deadline and it < max_iter:
        i, j = np.random.randint(n, size=2)
        if i == j:
            continue

        delta = step_scale * a[i]
        cand = a.copy()
        cand[i] -= delta
        cand[j] += delta
        cand = np.maximum(cand, 0.0)
        cand = project_to_simplex(cand)

        M_cand = full_convolution(cand).max()
        if M_cand < best_M:
            best_M = M_cand
            best_a = cand.copy()
            a = cand
            step_scale = min(step_scale * 1.07, 0.5)
            no_improve = 0
        else:
            step_scale *= 0.985
            no_improve += 1

        it += 1
        if no_improve > 100_000:
            # re‑jitter the current point to escape a plateau
            jitter = np.random.randn(n) * 0.001
            a = best_a + jitter
            a = project_to_simplex(a)
            no_improve = 0

    return best_a

            print(f"[global sweep] best score = {val:.6f}")
            if val < best_val:
                best_val, best_seq = val, a0.tolist()

    # -----------------------------------------------------------------
    # 2. Smooth‑max projected gradient descent (Phase 2)
    # -----------------------------------------------------------------
    gd_deadline = deadline - 150.0
    if best_seq is not None and time.time() < gd_deadline:
        a_start = np.array(best_seq, dtype=float)
        a_refined = smooth_max_descent(
            a_start,
            gd_deadline,
            lambda_start=5.0,
            lambda_end=200.0,
            step0=0.25,
        )
        val = compute_score(a_refined)
        print(f"[smooth‑GD] refined score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, a_refined.tolist()

    # -----------------------------------------------------------------
    # 3. Final stochastic hill‑climb (Phase 3)
    # -----------------------------------------------------------------
    hill_deadline = deadline - 5.0
    if best_seq is not None and time.time() < hill_deadline:
        a_start = np.array(best_seq, dtype=float)
        a_final = hill_climb(a_start, hill_deadline)
        val = compute_score(a_final)
        print(f"[hill‑climb] final score = {val:.6f}")
        if val < best_val:
            best_val, best_seq = val, a_final.tolist()

    # -----------------------------------------------------------------
    # 4. Fallback to uniform if everything failed
    # -----------------------------------------------------------------
    if best_seq is None:
        best_seq = [1.0 / n] * n
        best_val = evaluate_sequence(best_seq)

    # -----------------------------------------------------------------
    # 5. Final report using the official evaluator
    # -----------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\nSearch finished. Reported score = {final_score:.6f}")
    return best_seq
```

**Explanation of the new components**

* **Smooth‑max gradient descent** – replaces the non‑smooth `max` by a
  differentiable log‑sum‑exp with a controllable temperature `λ`.  
  The gradient is obtained analytically and computed via a single FFT‑based
  cross‑correlation, giving an iteration time of a few milliseconds.

* **λ‑schedule** – starts with a small value (`λ≈5`) where the objective is
  very smooth, allowing large‑scale rearrangements of the mass.  λ is
  multiplied by a tiny factor each iteration until it reaches `≈200`,
  at which point the approximation is already very close to the true max.

* **Projection** – after every gradient step the iterate is projected back
  onto the probability simplex, guaranteeing feasibility (`a_i ≥ 0`,
  `∑a_i = 1`).

* **Hybrid pipeline** – the global sweep provides a solid initial point,
  the gradient phase performs the heavy lifting, and the last hill‑climb
  extracts any remaining marginal gain.

The algorithm respects the 1000 s wall‑clock limit, prints intermediate
progress, and returns the best coefficient list it discovered.
