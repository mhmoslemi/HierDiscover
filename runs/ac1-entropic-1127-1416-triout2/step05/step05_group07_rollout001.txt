assistantfinal**Solution Overview**

The evaluation function  

\[
F(a)=\frac{2\,n\;\max\limits_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is homogeneous, therefore we can restrict the search to probability
vectors (`a_i ≥ 0`, `∑ a_i = 1`).  
The problem becomes  

\[
\min_{a\in\Delta_n}\; \max_k (a*a)_k .
\]

The convolution is the inverse FFT of the squared Fourier transform.
If the maximum were smooth we could use a gradient‑based optimiser.
We therefore **smooth the max** with a log‑sum‑exp (soft‑max) :

\[
M_\beta(a)=\frac{1}{\beta}\log\!\sum_k e^{\beta\,(a*a)_k},
\qquad 
\lim_{\beta\to\infty}M_\beta(a)=\max_k (a*a)_k .
\]

`M_\beta` is differentiable for any `β>0`.  Its gradient can be written
in closed form using a single extra convolution:

* let `c = a*a` (full linear convolution, length `2n‑1`);
* `w_k = e^{\beta c_k}/\sum_j e^{\beta c_j}` (soft‑max weights);
* the gradient with respect to `a` is  

\[
\nabla_a M_\beta = 2\;(a \star w)
\]

where `⋆` denotes the **cross‑correlation**.
The cross‑correlation can be computed as a convolution of `a` with the
reversed weight vector `w[::-1]`.

To keep the simplex constraints we **parameterise** a by a soft‑max of an
unconstrained vector `x` :

\[
a_i = \frac{e^{x_i}}{\sum_j e^{x_j}} .
\]

With the Jacobian of the soft‑max (`J = diag(a) – a aᵀ`) we obtain the
gradient w.r.t. `x` :

\[
\nabla_x = a\;\bigl(\nabla_a - (a^\top\nabla_a)\mathbf 1\bigr).
\]

Thus we have a fully‑differentiable objective `Φ_β(x)=2 n·M_β(a(x))`
and its gradient, ready for a quasi‑Newton method.

**Algorithm**

1. **Initial shapes** – discrete arcsine, up‑sampled best from the previous
   run, a few random Dirichlet draws.
2. **Continuation on β** – start with a small smoothing (`β=5`) and
   gradually increase (`β = 5, 15, 40, 100`).  
   Each stage refines the current `x` with `L‑BFGS‑B`.
3. **Length hierarchy** – solve the problem for `n=2048`,
   then up‑sample the obtained vector to `4096`, `8192`, …
   (linear interpolation followed by re‑normalisation).  
   The up‑sampled vector is used as warm‑start for the next length.
4. **Budget awareness** – the whole procedure monitors the wall‑clock
   and stops well before the 1000 s limit.
5. **Evaluation** – the cheap surrogate `compute_score` is used for every
   intermediate candidate; the official `evaluate_sequence` is called only
   for the current best vectors.
6. **Final polishing** – a last `L‑BFGS‑B` run with a high `β` on the
   best vector found.

The method works entirely on the simplex, needs only FFT‑based
convolutions ( O(n log n) ) and, thanks to the smooth approximation,
creates a landscape that `L‑BFGS‑B` can navigate more efficiently than
the pure sub‑gradient routine used previously.

```python
"""
Hybrid smoothing + L‑BFGS optimisation for the max‑self‑convolution problem.

We minimise a smoothed version of  max_k (a*a)_k  on the probability simplex.
The optimisation variable is the unconstrained vector x; a = softmax(x).
A continuation on the smoothing parameter β (log‑sum‑exp) is used:
β = 5 → 15 → 40 → 100.  Each stage is solved with SciPy's L‑BFGS‑B.
The solution is progressively up‑sampled to larger lengths (2048, 4096,
8192 …) while keeping the wall‑clock budget (≈ 1000 s) in mind.
Only the cheap surrogate score is used during the search; the expensive
evaluate_sequence() is called for the current best candidates.
"""

import time
import math
from typing import List, Tuple

import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp


# ----------------------------------------------------------------------
# FFT based convolution utilities (real FFT for speed)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Full linear convolution using a real FFT.
    Returns an array of length len(a)+len(b)-1.
    """
    m = len(a) + len(b) - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


# ----------------------------------------------------------------------
# Simple surrogate score (identical to evaluate_sequence up to the constant factor 2n)
# ----------------------------------------------------------------------


def compute_score(a: np.ndarray) -> float:
    """Fast surrogate: 2·n·max(a*a) for a normalised probability vector."""
    n = len(a)
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


# ----------------------------------------------------------------------
# Helper for probability vectors
# ----------------------------------------------------------------------


def softmax(x: np.ndarray) -> np.ndarray:
    """Numerically stable softmax."""
    x_max = np.max(x)
    e = np.exp(x - x_max)
    return e / e.sum()


def arcsine_initial(n: int) -> np.ndarray:
    """Discrete arcsine density a_i ∝ 1/√((i+½)(n‑½‑i))."""
    i = np.arange(n, dtype=float)
    eps = 0.25
    vals = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    return vals / vals.sum()


def random_dirichlet(n: int, conc: float, rng: np.random.Generator) -> np.ndarray:
    """Draw from a Dirichlet‑like distribution with concentration `conc`."""
    if conc <= 0:
        # heavy‑tailed, near‑sparse draws
        samp = rng.exponential(1.0, size=n) ** (1.0 / max(0.1, -conc))
    else:
        samp = rng.gamma(conc, 1.0, size=n)
    samp += 1e-12
    return samp / samp.sum()


def upsample(prev: np.ndarray, new_n: int) -> np.ndarray:
    """Linear interpolation from len(prev) → new_n, followed by re‑normalisation."""
    x_old = np.linspace(0.0, 1.0, len(prev))
    x_new = np.linspace(0.0, 1.0, new_n)
    interp = np.interp(x_new, x_old, prev)
    total = interp.sum()
    if total == 0.0:
        return np.full(new_n, 1.0 / new_n)
    return interp / total


# ----------------------------------------------------------------------
# Smoothed objective and gradient (β is the smoothing parameter)
# ----------------------------------------------------------------------


def obj_and_grad(x: np.ndarray, beta: float) -> Tuple[float, np.ndarray]:
    """
    Returns (objective, gradient) for the smoothed max‑self‑convolution.

    The optimisation variable is the unconstrained vector `x`.
    a = softmax(x) lives on the simplex.
    The objective is  Φ_β(x) = 2·n·M_β(a)  with
        M_β(a) = (1/β)·log Σ_k exp(β·(a*a)_k).

    Gradient is derived analytically (see the paper notes above).
    """
    # a lives on the simplex
    a = softmax(x)
    n = a.shape[0]

    # full convolution of a with itself
    conv = convolution_fft(a, a)                # length 2n‑1

    # smooth maximum via log‑sum‑exp
    scaled = beta * conv
    logZ = logsumexp(scaled)                    # scalar
    smooth_max = logZ / beta

    # soft‑max weights (sum to 1)
    w = np.exp(scaled - logZ)                   # shape (2n‑1,)

    # gradient w.r.t. a : 2 * (a ⋆ w)
    # cross‑correlation a ⋆ w = Σ_i a_i w_{i+j}
    # can be obtained by convolving a with reversed w
    w_rev = w[::-1]
    corr_full = convolution_fft(a, w_rev)      # length 3n‑2
    # index of the central element of w (2n‑2)
    centre = len(w) - 1                         # = 2n‑2
    grad_a = 2.0 * corr_full[centre - np.arange(n)]

    # chain rule through softmax: J = diag(a) – a aᵀ
    dot_ag = np.dot(a, grad_a)                  # scalar
    grad_x = a * (grad_a - dot_ag)              # shape (n,)

    # scale by the constant 2·n (the same factor used in evaluate_sequence)
    obj = 2.0 * n * smooth_max
    grad_x *= 2.0 * n

    return obj, grad_x

# Optimisation driver for a single length and a list of starting points
# ----------------------------------------------------------------------


def optimise_length(
    n: int,
    start_vectors: List[np.ndarray],
    deadline: float,
    beta_schedule: List[float],
    max_iter_per_stage: int = 800,
) -> Tuple[np.ndarray, float]:
    """
    Optimises a probability vector of size `n` using the continuation on β.
    All starts are given as probability vectors (already normalised).

    Returns the best internal vector (sum = 1) and its surrogate score.
    """
    best_a = None
    best_score = float("inf")

    # L‑BFGS options – we keep a modest maxiter for each stage
    opts = {"maxiter": max_iter_per_stage, "disp": False}

    for start_id, a0 in enumerate(start_vectors):
        if time.time() >= deadline - 5.0:
            break

        x_cur = x0.copy()
        for beta in beta_schedule:
            if time.time() >= deadline - 5.0:

                fun=obj_and_grad,
                x0=x_cur,
                args=(beta,),

                jac=True,

            x_cur = res.x

    # Safety fallback – if nothing succeeded, return a uniform vector
    if best_a is None:
        best_a = np.full(n, 1.0 / n)

    # ------------------------------------------------------------------
    # 0.  Optional fallback from a previously discovered construction.
    # ------------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]   # type: ignore
        val = evaluate_sequence(fallback)
        print(f"Fallback (height_sequence_1) score = {val:.6f}")
        if val < best_val:
            best_val = val
            best_seq = fallback
            best_internal = np.array(fallback, dtype=float)
            best_internal /= best_internal.sum()
    except Exception:
        pass

    # ------------------------------------------------------------------
    # 1.  Length hierarchy – start modest, enlarge progressively.
    # ------------------------------------------------------------------
    lengths = [2048, 4096, 8192]   # can be trimmed automatically by the timer
    beta_schedule = [5.0, 15.0, 40.0, 100.0]

    for n in lengths:
        if time.time() >= deadline - 7.0:
            break
        print(f"\n=== Optimising length n = {n} ===")

        # ------------------------------------------------------------------
        # 1a.  Build a set of start points for this length.
        # ------------------------------------------------------------------
        starts: List[np.ndarray] = []

        # warm‑start from the current global best (upsampled)
        if best_internal is not None:
            up = upsample(best_internal, n)
            starts.append(up)

        # classic arcsine – always a solid baseline
        starts.append(arcsine_initial(n))

        # a couple of random Dirichlet draws for diversity
        for conc in (0.5, 1.0, 2.0):
            draws = random_dirichlet(n, conc, rng)
            starts.append(draws)

        # ------------------------------------------------------------------
        # 1b.  Optimise each start (L‑BFGS‑B + β continuation)
        # ------------------------------------------------------------------
        a_opt, surrogate_score = optimise_length(
            n=n,
            start_vectors=starts,
            deadline=deadline,
            beta_schedule=beta_schedule,
            max_iter_per_stage=500,   # ~500 L‑BFGS iterations per β stage
        )

        # ------------------------------------------------------------------
        # 1c.  Evaluate the candidate with the official (expensive) evaluator.
        # ------------------------------------------------------------------
        if time.time() < deadline - 5.0:
            val = evaluate_sequence(a_opt.tolist())
            print(f"    evaluated official score = {val:.6f}")

            if val < best_val:
                best_val = val
                best_seq = a_opt.tolist()
                best_internal = a_opt.copy()
                print(f"    *** New global best: {best_val:.6f} (n={n}) ***")

    # ------------------------------------------------------------------
    # 2.  Final polishing on the overall best (if time permits).
    # ------------------------------------------------------------------
    if best_internal is not None and time.time() < deadline - 5.0:
        print("\nFinal polishing of the global best")
        # use a finer β schedule with more L‑BFGS iterations
        fine_beta_schedule = [100.0, 200.0, 400.0]
        polish_a, _ = optimise_length(
            n=len(best_internal),
            start_vectors=[best_internal],
            deadline=deadline,
            beta_schedule=fine_beta_schedule,
            max_iter_per_stage=800,
        )
        final_val = evaluate_sequence(polish_a.tolist())
        print(f"Final polished score = {final_val:.6f}")
        if final_val < best_val:
            best_val = final_val
            best_seq = polish_a.tolist()
            print("*** Updated global best after final polish ***")

    # ------------------------------------------------------------------
    # 3.  Guard – always return a feasible sequence.
    # ------------------------------------------------------------------
    if not best_seq:
        best_seq = [1.0] * 256
        best_val = evaluate_sequence(best_seq)

    print(f"\nSearch finished. Best reported score = {best_val:.6f}")
    return best_seq
```
