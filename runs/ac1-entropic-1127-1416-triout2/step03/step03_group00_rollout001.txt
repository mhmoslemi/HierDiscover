The evaluation function is homogeneous, therefore we can restrict the search to probability vectors  
(`a_i ≥ 0 , Σ a_i = 1`).  For such a vector

```
evaluate_sequence(a) = 2·n·max(conv(a,a))
```

where `conv(a,a)` is the linear convolution of `a` with itself.  
The problem is to minimise the maximal entry of this convolution.

The algorithm consists of three phases:

1. **Initialisation** – use the previously‑found sequence if it exists,
   otherwise start from a symmetric Beta distribution.

2. **Smoothed‑max Adam optimisation** –  
   * Replace the non‑smooth `max` by a differentiable soft‑max  
     `Sα(x)= (1/α)·log Σ exp(α·x_i)`.  
   * The gradient of `Sα` w.r.t. `a` can be written as a convolution
     of the weighting vector `w` (the soft‑max probabilities) with the
     reversed current iterate.  Both convolutions are evaluated with FFT
     in `O(n log n)`.  
   * Adam (projected onto the probability simplex) performs fast,
     adaptive steps.  The smoothing parameter `α` is increased
     gradually so the optimisation first follows a smooth landscape
     and later focuses on the true maximum.

3. **Fine‑grained simulated annealing** – after the Adam phase we
   apply a simple mass‑transfer Metropolis walk (preserving the sum)
   to escape possible local minima and to polish the solution.

All work is limited to the supplied time budget (`budget_s`).  The best
vector seen so far is returned.

```python
"""
Propose a step‑function height sequence that minimises `evaluate_sequence`.

Algorithm
---------
1. Initialise from the existing global `height_sequence_1` (if present) or
   from a centred Beta distribution; normalise to a probability vector.
2. Run a projected Adam optimiser that minimises a *smoothed* version of
   `max(conv(a,a))`.  The smoothing parameter α grows from 5 to 200,
   turning the objective gradually into the true max.  Gradients are
   obtained by a second FFT‑based convolution.
3. Finish with a simulated‑annealing mass‑transfer walk to fine‑tune the
   result.
4. Return the best sequence (still normalised to sum = 1).

The code stays entirely on the CPU, uses only NumPy and the already
imported `evaluate_sequence`, and respects the 1000 s time limit.
"""

import time
import math
import numpy as np

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    { w | w_i ≥ 0 , Σ w_i = 1 }.
    Implements the O(n) algorithm of Duchi et al. (2008).
    """
    v = np.asarray(v, dtype=float)
    n = v.shape[0]

    # Sort v in decreasing order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0

    if not np.any(cond):
        # All entries are non‑positive → uniform distribution
        return np.full_like(v, 1.0 / n)

    rho = ind[cond][-1] - 1          # zero‑based index of last positive entry
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def compute_score(a: np.ndarray) -> float:
    """
    Exact value of `evaluate_sequence` for a probability vector `a`
    (Σ a = 1).  Returns 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    fft = np.fft.rfft(a, n=2 * n - 1)
    conv = np.fft.irfft(fft * fft, n=2 * n - 1)
    return float(2.0 * n * conv.max())


def beta_sequence(alpha: float, beta: float, n: int) -> np.ndarray:
    """
    Discretised Beta(α,β) density on `n` equally spaced mid‑points,
    normalised to sum 1.
    """
    x = (np.arange(n, dtype=float) + 0.5) / n
    # work in log‑space to avoid overflow at the ends
    logw = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    logw = np.clip(logw, -700.0, 700.0)          # safety cap
    w = np.exp(logw)
    if not np.isfinite(w.sum()) or w.sum() == 0.0:
        w = np.ones_like(w)
    return w / w.sum()


# ----------------------------------------------------------------------
# Main optimisation routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000) -> list[float]:
    """
    Search for a non‑negative height sequence that minimises
    `evaluate_sequence`.  The routine respects the given time budget,
    returns the best sequence found (normalised to sum = 1) and prints
    progress information.
    """
    np.random.seed(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 0.5       # small safety margin

    # --------------------------------------------------------------
    # 1. Starting point
    # --------------------------------------------------------------
    try:
        # use the previously discovered construction if available
        init = np.array(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        n = init.shape[0]
        print(f"Using existing height_sequence_1 of length {n}.")
    except NameError:
        # fallback: centred Beta shape, power‑of‑two length for fast FFTs
        n = 8192
        init = beta_sequence(2.5, 2.5, n)
        print(f"No existing sequence – using a Beta start, length {n}.")

    # Normalise to a probability vector (Σ = 1)
    a = init / init.sum()

    best_a = a.copy()
    best_score = compute_score(best_a)
    print(f"Initial score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 2. Smoothed‑max Adam optimisation on the simplex
    # --------------------------------------------------------------
    # Adam parameters
    beta1, beta2 = 0.9, 0.999
    eps = 1e-12
    m = np.zeros(n)
    v = np.zeros(n)
    lr = 0.20                     # base learning rate
    t = 0                         # iteration counter

    # smoothing schedule  α ∈ [α_start , α_end]
    alpha_start = 5.0
    alpha_end = 200.0
    # we reserve ~40 s for the final SA phase
    max_adam_time = deadline - 40.0

    while time.time() < max_adam_time:
        t += 1

        # ----- convolution a * a (linear, length 2n‑1) -----
        fft_a = np.fft.rfft(a, n=2 * n - 1)
        conv = np.fft.irfft(fft_a * fft_a, n=2 * n - 1)

        max_conv = conv.max()
        cur_score = 2.0 * n * max_conv

        # ----- update best observed -----
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            if t % 2000 == 0:
                print(f"Adam iter {t:6d}: new best {best_score:.6f}")

        # ----- soft‑max weighting -----
        # linear increase of α, saturating at alpha_end after ~5·10⁴ iters
        alpha = alpha_start + (alpha_end - alpha_start) * min(1.0, t / 50000.0)

        # stabilise the exponent by subtracting the maximum
        exp_arg = alpha * (conv - max_conv)
        w = np.exp(exp_arg)
        w_sum = w.sum()
        if w_sum == 0.0:                         # numerical safeguard
            w = np.full_like(w, 1.0 / w.shape[0])
        else:
            w /= w_sum

        # ----- gradient of the smoothed objective -----
        #   g = 2 * (w  ⋆  rev(a))   (⋆ = linear convolution)
        rev_a = a[::-1]

        fft_w = np.fft.rfft(w, n=M)
        fft_rev = np.fft.rfft(rev_a, n=M)
        conv_full = np.fft.irfft(fft_w * fft_rev, n=M)
        grad = 2.0 * conv_full[n - 1 : n - 1 + n]   # slice of length n

        # ----- Adam update (projected) -----
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        step = lr * m_hat / (np.sqrt(v_hat) + eps)

        a = simplex_projection(a - step)

        # optional learning‑rate decay
        if t % 5000 == 0:
            lr *= 0.9

    print(f"Adam phase finished after {t} iterations; best score {best_score:.6f}")

    # --------------------------------------------------------------
    # 3. Simulated‑annealing refinement (mass‑transfer moves)
    # --------------------------------------------------------------
    cur_a = best_a.copy()
    cur_score = best_score

    # temperature schedule – start fairly high, exponential cooling
    T_start = cur_score * 0.02
    T_end = cur_score * 1e-5
    it_sa = 0

    while time.time() < deadline:
        # exponential cooling
        T = max(T_end, T_start * (0.9995 ** it_sa))

        # ----- propose a move that conserves the total mass -----
        src = np.random.choice(n, p=cur_a)           # source biased by current mass
        tgt = np.random.randint(n - 1)
        if tgt >= src:
            tgt += 1

        if cur_a[src] <= 0.0:
            continue

        delta = cur_a[src] * np.random.rand()        # random fraction of the source mass
        cand = cur_a.copy()
        cand[src] -= delta
        cand[tgt] += delta

        # evaluate candidate (exact score, cheap because we already have a fast helper)
        cand_score = compute_score(cand)

        # Metropolis acceptance
        if cand_score < cur_score:
            accept = True
        else:
            accept_prob = math.exp(-(cand_score - cur_score) / max(T, 1e-12))
            accept = np.random.rand() < accept_prob

        if accept:
            cur_a = cand
            cur_score = cand_score
            if cand_score < best_score:
                best_score = cand_score
                best_a = cand.copy()
                print(f"SA iter {it_sa:7d}: new best {best_score:.6f}")

        # occasional large diversification step (restart from a fresh Beta draw)
        if it_sa % 20000 == 0 and it_sa > 0:
            tmp = beta_sequence(
                np.random.uniform(0.5, 5.0), np.random.uniform(0.5, 5.0), n
            )
            cur_a = tmp
            cur_score = compute_score(cur_a)

        it_sa += 1

    print(f"Simulated‑annealing finished after {it_sa} iterations; final best score = {best_score:.6f}")

    # --------------------------------------------------------------
    # 4. Return the best solution (still on the simplex)
    # --------------------------------------------------------------
    best_a = best_a / best_a.sum()
    return [float(v) for v in best_a.tolist()]
```
