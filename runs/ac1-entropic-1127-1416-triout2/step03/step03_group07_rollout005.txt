-----------------

Search for a non‑negative step‑function (probability vector) that minimises

    2·n·max(convolve(a, a)) / (sum(a)²)

The objective is homogeneous, therefore we keep sum(a)=1 and minimise
`2·n·max(conv)`.  

Algorithm
---------
* Choose a problem size `n` (use the historic length if available, otherwise
  a few thousand).
* Initialise `a` from a Dirichlet distribution (concentration 0.5 gives a

* Optimise `a` with a **smooth‑max** surrogate:
    •  `w_k = exp(α·(conv_k‑max(conv)))`  (soft‑max weights, α grows from 1 to 100)
    •  `∇ = 2·correlate(w, a)`  gives the gradient of the smooth max.
* Apply the **Adam** adaptive‑step rule to the gradient and project the
  resulting vector back onto the probability simplex.
* Occasionally inject a tiny Gaussian jitter to escape plateaus.
* Keep the globally best sequence seen; stop early if the target 1.503 is

The optimiser is a blend of mirror‑descent (simplex projection) and

import time
import numpy as np

# ----------------------------------------------------------------------
# Helper: Euclidean projection onto the probability simplex.
# ----------------------------------------------------------------------
def _project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Project a vector onto {x >= 0, sum(x)=1}."""
    n = v.shape[0]
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are equal -> return uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1  # zero‑based index of the last positive theta
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w
