The evaluation function is  

\[
E(a)=\frac{2n\;\max_k (a*a)_k}{\bigl(\sum_i a_i\bigr)^2},
\qquad a_i\ge 0 ,
\]

where \((a*a)_k=\sum_i a_i\,a_{k-i}\) is the auto‑convolution of the
non‑negative vector `a`.  
Because the denominator is homogeneous of degree 2, scaling `a`
does not change the score – we may (and will) keep the vector normalised
to a probability simplex \(\sum_i a_i = 1\).

The task is therefore to **minimise the maximal convolution entry**.
The function \(\max_k c_k\) is non‑smooth, which makes a plain
sub‑gradient method slow.  
Instead we optimise the smooth surrogate

\[
F_\alpha(a)=\frac{1}{\alpha}\log\!\Bigl(\sum_k
  \exp\bigl(\alpha\,c_k\bigr)\Bigr) ,
\qquad
c_k = (a*a)_k .
\]

For small \(\alpha\) the surrogate is a very smooth average of the
convolution entries; as \(\alpha\) grows it approaches the true maximum.
The gradient of \(F_\alpha\) can be written in closed form:

\[
\frac{\partial F_\alpha}{\partial a_j}
   = 2\;\sum_{k} w_k\,a_{k-j},
\qquad
w_k = \frac{\exp(\alpha c_k)}{\sum_\ell \exp(\alpha c_\ell)} .
\]

The term on the right‑hand side is a **correlation** of the current
vector `a` with the weight vector `w`.  Correlation (and also the
convolution needed for the objective) can be computed in
\(O(n\log n)\) time by FFTs.

The optimisation proceeds in three stages

1. **Seed generation** – a handful of deterministic and random vectors
   (uniform, ramps, exponentials, polynomial shapes, Beta‑distributions,
   Dirichlet samples).  
   The best seed (including the optional global variable
   `height_sequence_1`) becomes the starting point.

2. **Annealing gradient descent** – we minimise the smooth surrogate.
   * Initialise \(\alpha=0.1\) and increase it geometrically
     (`α ← α·α_factor`) until a large value (≈ 5000) is reached.
   * At iteration `t`  
        * compute the auto‑convolution `c` by a single FFT,
        * build the soft‑max weights `w`,
        * obtain the gradient `g = 2·correlation(a,w)` via another FFT,
        * take a step `a ← a – η_t·g` with a step size decaying as
          `η_t = η0 / sqrt(t+1) / (‖g‖+ε)`,
        * project back onto the simplex (`simplex_projection`).
   * If no improvement has been seen for a long time we add a small
     Gaussian perturbation to escape plateaus.

3. **Fine‑grained sub‑gradient polishing** – once \(\alpha\) is very large
   the weights `w` concentrate on the truly maximal convolution entries,
   i.e. we are effectively using the classic sub‑gradient method.
   A few thousand extra iterations are performed to clean up any tiny
   remaining peaks.

During the whole run the exact score `2·n·max(c)` is monitored and the
best vector found so far is stored.  The algorithm respects the
`budget_s` time limit (default 1000 s) and returns the best sequence as a
plain Python list.

The whole implementation uses only `numpy` and `time`; all helper
functions are top‑level as required.

"""
Annealing soft‑max gradient descent for minimising
max(a * a) on the probability simplex.

The algorithm
* builds a diverse set of seeds (uniform, ramps, exponentials,
  polynomial shapes, Beta‑distributions, Dirichlet samples and,
  if present, the global variable `height_sequence_1`);
* starts from the best seed;
* iteratively minimises the smooth surrogate
      Fα(a) = (1/α)·log Σ exp(α·(a*a)_k)
  using projected gradient descent;
  the temperature α is increased gradually (annealing), turning the
  surrogate into the true max;
* when progress stalls a small Gaussian perturbation is added;
* finally a short sub‑gradient phase (large α) polishes the solution.
All operations are performed with FFTs (O(n log n)) and the iterates
are kept on the simplex via Euclidean projection.

# Simplex projection (Euclidean, Duchi et al. 2008)
# ----------------------------------------------------------------------


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """Project vector v onto the probability simplex {x_i≥0, Σx_i=1}."""
    v = np.asarray(v, dtype=np.float64)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries non‑positive → uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Objective helpers (same as evaluate_sequence for sum‑normalised vectors)
# ----------------------------------------------------------------------


def compute_objective(a: np.ndarray) -> float:
    """Return 2·n·max(a*a) assuming Σ a_i = 1."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())          # power of two ≥ 2n‑1
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return 2.0 * n * conv.max()


def auto_convolution(a: np.ndarray) -> np.ndarray:
    """Linear auto‑convolution a*a (length 2·n‑1) using FFT."""
    n = a.shape[0]
    size = 1 << ((2 * n - 1).bit_length())
    fa = np.fft.rfft(a, size)
    conv = np.fft.irfft(fa * fa, n=size)[: 2 * n - 1]
    return conv


def correlation_with_weights(a: np.ndarray, w: np.ndarray) -> np.ndarray:
    """
    Compute g_j = 2 * Σ_i a_i * w_{i+j}   (j = 0…n‑1)
    where w has length 2·n‑1.  Implemented via FFT correlation.
    """
    n = a.shape[0]
    m = 2 * n - 1
    size = 1 << ((3 * n - 2).bit_length())       # ≥ 3n‑2 for linear correlation
    fa = np.fft.rfft(a, size)
    fw = np.fft.rfft(w, size)
    corr = np.fft.irfft(fa * np.conj(fw), n=size)
    start = m - 1                       # index of lag 0
    g = 2.0 * corr[start : start + n]   # g has length n
    return g


# ----------------------------------------------------------------------
# Seed families
# ----------------------------------------------------------------------


def beta_sequence(alpha: float, beta: float, n: int) -> np.ndarray:
    """Discretised Beta(α,β) density on the mid‑points, normalised to sum 1."""
    x = (np.arange(n, dtype=float) + 0.5) / n
    logw = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    logw = np.clip(logw, -700.0, 700.0)          # avoid overflow
    w = np.exp(logw)
    if not np.isfinite(w).all() or w.sum() == 0.0:
        w = np.ones_like(w)
    w /= w.sum()
    return w


def exponential_shape(lam: float, n: int) -> np.ndarray:
    """a_i ∝ exp(-lam·i), normalised to sum 1."""
    i = np.arange(n, dtype=float)
    w = np.exp(-lam * i)
    w /= w.sum()
    return w


def polynomial_shape(p: float, n: int) -> np.ndarray:
    """a_i ∝ 1 - (i/(n‑1))**p, clipped to ≥0 and normalised."""
    i = np.arange(n, dtype=float)
    frac = i / (n - 1)
    w = 1.0 - np.power(frac, p)
    w = np.clip(w, 0.0, None)
    w /= w.sum()
    return w


# ----------------------------------------------------------------------
# Main search routine
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 0, budget_s: int = 1000) -> list[float]:
    """
    Return a list of non‑negative heights that (approximately) minimises
    evaluate_sequence().  The routine runs for at most `budget_s` seconds
    and respects all constraints of the challenge.
    """
    np.random.seed(seed)
    start = time.time()
    # a small safety margin for the outer runner
    deadline = start + budget_s - 5.0

    # ------------------------------------------------------------------
    # 1. Problem size
    # ------------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except NameError:
        n = 5146                            # fallback from the prompt

    # ------------------------------------------------------------------
    # 2. Helpers to keep the best candidates
    # ------------------------------------------------------------------
    best_seq = None
    best_score = np.inf
    TOP_K = 5
    top = []                               # list of (score, seq)

    def consider(candidate: np.ndarray) -> None:
        """Evaluate *candidate* (already normalised) and update global best."""
        nonlocal best_seq, best_score, top
        sc = compute_objective(candidate)
        if sc < best_score:
            best_score = sc
            best_seq = candidate.copy()
            print(f"[seed] new global best {sc:.6f}")
        # maintain a small top‑K list
        if len(top) < TOP_K:
            top.append((sc, candidate.copy()))
            top.sort(key=lambda x: x[0])
        else:
            if sc < top[-1][0]:
                top[-1] = (sc, candidate.copy())
                top.sort(key=lambda x: x[0])

    # ------------------------------------------------------------------
    # 3. Deterministic and random seeds
    # ------------------------------------------------------------------
    # ramp (decreasing)
    ramp = np.arange(n, 0, -1, dtype=float)
    ramp = 2.0 * ramp / (n * (n + 1))
    ramp /= ramp.sum()
    consider(ramp)

    # uniform
    uniform = np.full(n, 1.0 / n)
    consider(uniform)

    # exponential family
    for lam in np.linspace(0.001, 5.0, 12):
        consider(exponential_shape(lam, n))

    # polynomial family
    for p in [0.5, 1.0, 1.5, 2.0, 3.0]:
        consider(polynomial_shape(p, n))

    # coarse Beta grid
    alphas = np.linspace(0.2, 5.0, 10)
    betas = np.linspace(0.2, 5.0, 10)
    for a in alphas:
        for b in betas:
            if time.time() >= deadline:
                break
            consider(beta_sequence(a, b, n))
        if time.time() >= deadline:
            break

    # random Dirichlet‑like samples
    for _ in range(150):
        if time.time() >= deadline:
            break
        conc = np.random.uniform(0.1, 3.0, size=n)
        vec = np.random.gamma(conc, 1.0)
        vec /= vec.sum()
        consider(vec)

        # random Beta shape
        a = np.random.uniform(0.05, 5.0)
        b = np.random.uniform(0.05, 5.0)
        consider(beta_sequence(a, b, n))

    # ------------------------------------------------------------------
    # 4. Optional start from the provided global variable
    # ------------------------------------------------------------------
    try:
        glob = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        if glob.size == n:
            glob = np.maximum(glob, 0.0)
            glob /= glob.sum()
            consider(glob)
    except NameError:
        pass

    # ------------------------------------------------------------------
    # 5. Start the annealing gradient descent
    # ------------------------------------------------------------------
    # use the best seed discovered above
    a = best_seq.copy()
    # hyper‑parameters
    eta0 = 1.0                # base step‑size factor
    alpha = 0.1               # initial temperature
    alpha_factor = 1.001      # geometric increase per iteration
    alpha_max = 5000.0
    stagnation = 0
    iteration = 0
    max_iter = 800000        # hard cap (will be cut by the deadline)

    while time.time() < deadline and iteration < max_iter:
        # -------- compute auto‑convolution and current score ----------
        conv = auto_convolution(a)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[iter {iteration:6d}] new best {best_score:.6f}")
            stagnation = 0
        else:
            stagnation += 1

        # -------- soft‑max weights (smooth approximation of max) ------
        if alpha < 1e-8:          # guard against zero
            alpha = 1e-8
        shift = cur_max                     # stability trick
        exp_arg = alpha * (conv - shift)
        # clip exponent to avoid overflow (numpy will handle very large positives)
        exp_arg = np.clip(exp_arg, -700, 700)
        w_raw = np.exp(exp_arg)
        w = w_raw / w_raw.sum()

        # -------- gradient of the surrogate ----------------------------
        g = correlation_with_weights(a, w)

        # -------- step size (adaptive) --------------------------------
        norm_g = np.linalg.norm(g) + 1e-16
        step = eta0 / (np.sqrt(iteration + 1) * norm_g)

        # -------- gradient step + simplex projection --------------------
        a_next = a - step * g
        a_next = simplex_projection(a_next)

        a = a_next
        iteration += 1

        # -------- temperature schedule ---------------------------------
        if alpha < alpha_max:
            alpha *= alpha_factor

        # -------- occasional perturbation to escape plateaus ----------
        if stagnation >= 20000:
            sigma = max(0.01, 0.5 / np.sqrt(iteration + 1))
            noise = sigma * np.random.randn(n) * a
            a = a + noise
            a = np.clip(a, 0.0, None)
            a /= a.sum()
            stagnation = 0
            print(f"[iter {iteration:6d}] perturbation applied, score {cur_score:.6f}")

        # -------- early exit if target already reached ---------------
        if best_score <= 1.503:
            print(f"[iter {iteration:6d}] target reached ({best_score:.6f})")
            break

    # ------------------------------------------------------------------
    # 6. Final short sub‑gradient polishing (large α)
    # ------------------------------------------------------------------
    # run a few thousand iterations with a huge α to behave like a pure
    # max‑subgradient method.
    alpha = 1e6
    for _ in range(3000):
        if time.time() >= deadline:
            break
        conv = auto_convolution(a)
        cur_max = conv.max()
        cur_score = 2.0 * n * cur_max
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_seq = a.copy()
            print(f"[polish] new best {best_score:.6f}")

        # active set (indices attaining the maximal value up to a tiny tol)
        eps = cur_max * 1e-8
        active = np.where(conv >= cur_max - eps)[0]
        if active.size == 0:
            active = np.array([conv.argmax()], dtype=int)

        # sub‑gradient (average over active indices)
        g = np.zeros_like(a)
        for k in active:
            low = max(0, k - n + 1)
            high = min(n - 1, k)
            idx = np.arange(low, high + 1, dtype=int)
            partner = k - idx
            g[idx] += a[partner]
        g *= 2.0 / active.size

        step = eta0 / np.sqrt(iteration + 1)
        a = simplex_projection(a - step * g)
        iteration += 1

    # ------------------------------------------------------------------
    # 7. Return the best sequence discovered
    # ------------------------------------------------------------------
    print(f"Finished after {iteration} iterations, best score = {best_score:.6f}")
    return [float(v) for v in best_seq.tolist()]
