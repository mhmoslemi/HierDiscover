assistantfinal**Solution Overview**

The evaluation function  

\[
F(a)=\frac{2\,n\;\max\limits_{k}(a*a)_k}{\bigl(\sum_i a_i\bigr)^2}
\]

is scale‑invariant, therefore we may restrict the search to the simplex  

\[
\Delta=\Bigl\{a\in\mathbb R_{\ge0}^n\;\Big|\;\sum_i a_i = 1\Bigr\}.
\]

For a fixed `a` the a‑periodic convolution `c = a*a` can be obtained with one FFT.
The non‑smooth term `max(c)` is replaced during the first phase by the
smooth approximation  

\[
M_\alpha(a)=\frac{1}{\alpha}\log\Bigl(\sum_k e^{\alpha\,c_k}\Bigr)
\]

(the **log‑sum‑exp**).  Its gradient is the weighted sum of the
gradients of the individual convolution entries:

\[
\nabla M_\alpha(a)=\sum_k p_k \,\nabla c_k,\qquad
p_k =\frac{e^{\alpha c_k}}{\sum_j e^{\alpha c_j}} .
\]

For a convolution entry  

\[
c_k = \sum_i a_i a_{k-i},
\qquad
\frac{\partial c_k}{\partial a_j}=2\,a_{k-j}
\]

(the derivative is zero when the index is out of range).  
Collecting the weighted sums gives a **correlation** that can be
computed with a single FFT as well:

```
grad = 4·n·corr(w , a)      with   w = softmax(α·c)
```

where `corr` denotes the a‑periodic correlation of `w` and `a`.

The algorithm works in two stages

1. **Smooth optimisation** – gradient descent on the simplex with
   an annealing schedule for `α` (starting small, growing to several
   thousands).  The simplex constraint is enforced by the classic
   Euclidean projection onto the simplex.

2. **Fine‑tuning** – a short Adam optimisation that works directly on
   the non‑smooth objective (`max(c)`).  The Adam code is identical
   to the one that produced the previous best bound; here it is used
   only for a few seconds to polish the result obtained by the smooth
   phase.

Both stages are executed repeatedly with different random
initialisations (uniform, Dirichlet, geometric, or the previous best
solution).  The whole search respects the 1000 s budget and always
returns a feasible sequence.

```python
"""
A two‑stage optimiser for the step‑function bound

    2·n·max(conv(a,a)) / (sum(a)**2)

Stage 1 – smooth optimisation using a log‑sum‑exp surrogate and
          gradient descent on the simplex (FFT‑based convolution &
          correlation).  The temperature α is slowly increased so
          that the surrogate approaches the true max.

Stage 2 – a short Adam run (sub‑gradient of the true max) polishing
          the best vector found in stage 1.

Multiple random restarts are performed until the time budget expires.
All helper functions are top‑level, there are no closures and the
returned list contains only non‑negative floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Simplex projection (Wang & Carreira‑Perpiñán 2013)
# ----------------------------------------------------------------------
def _project_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto the probability simplex."""
    if v.ndim != 1:
        raise ValueError("v must be a 1‑D array")
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries are zero – return uniform vector
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / float(rho)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Convolution / correlation utilities (FFT based)
# ----------------------------------------------------------------------
def _full_conv(a: np.ndarray, L: int) -> np.ndarray:
    """Aperiodic self‑convolution of a, length 2·n‑1, using FFT length L."""
    fft_a = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fft_a * fft_a, n=L)
    return conv[: 2 * a.shape[0] - 1]


def _corr_w_a(w: np.ndarray, a: np.ndarray, L: int) -> np.ndarray:
    """
    Correlation of w (length 2·n‑1) with a (length n).
    Returns the segment of length n that corresponds to shifts k=0…n‑1.
    """
    fft_w = np.fft.rfft(w, n=L)
    fft_a = np.fft.rfft(a, n=L)
    corr = np.fft.irfft(fft_a * np.conj(fft_w), n=L)
    n = a.shape[0]
    return corr[n - 1 : n - 1 + n]


# ----------------------------------------------------------------------
# Stage 1 – smooth optimisation (log‑sum‑exp surrogate)
# ----------------------------------------------------------------------
def _smooth_optimize(
    init_a: np.ndarray, deadline: float, rng: np.random.Generator
) -> tuple[np.ndarray, float]:
    """
    Gradient descent on the simplex minimizing
        2·n·M_α(a)   with   M_α = (1/α)·log Σ exp(α·conv)
    α is increased during the run (annealing).  Returns the best vector
    found and its exact (non‑smooth) score.
    """
    a = init_a.copy()
    n = a.shape[0]
    L = 1 << ((2 * n - 2).bit_length())        # next power of two
    best_a = a.copy()
    # exact score of the current vector (sum = 1)
    conv = _full_conv(a, L)
    best_score = 2.0 * n * conv.max()

    # annealing parameters
    alpha = 0.5                      # start very smooth
    alpha_mul = 1.15                 # multiplicative increase every few iters
    inc_every = 300                 # iterations between α updates
    it = 0
    stagn = 0
    while time.time() < deadline:
        it += 1

        # ----- convolution -------------------------------------------------
        conv = _full_conv(a, L)                # length 2·n‑1
        # ----- soft‑max weights -------------------------------------------
        scaled = alpha * conv
        max_scaled = scaled.max()
        exp_scaled = np.exp(scaled - max_scaled)   # safe soft‑max
        w = exp_scaled / exp_scaled.sum()          # Σ w = 1

        # ----- gradient (4·n·correlation) ---------------------------------
        corr = _corr_w_a(w, a, L)               # length n
        grad = 4.0 * n * corr

        # ----- step size (simple diminishing schedule) --------------------
        lr = 0.7 / (1.0 + it * 0.001)           # a few tenths at start
        a -= lr * grad

        # ----- simplex projection -----------------------------------------
        a = _project_simplex(a)

        # ----- exact objective (no smoothing) ----------------------------
        conv = _full_conv(a, L)
        score = 2.0 * n * conv.max()

        if score < best_score - 1e-12:
            best_score = score
            best_a = a.copy()
            stagn = 0
            print(f"Smooth  iter {it:6d}: best = {best_score:.6f}")
        else:
            stagn += 1

        # ----- occasional random jitter to escape plateaus ---------------
        if stagn > 4000:
            a += 1e-3 * rng.standard_normal(n)
            a = _project_simplex(a)
            stagn = 0

        # ----- anneal α ---------------------------------------------------
        if it % inc_every == 0:
            alpha = min(alpha * alpha_mul, 2000.0)

    return best_a, best_score


# ----------------------------------------------------------------------
# Stage 2 – Adam optimiser on the true max‑convolution (sub‑gradient)
# ----------------------------------------------------------------------
def _maxconv_and_subgrad(a: np.ndarray, fft_len: int):
    """Return (max_conv, sub‑gradient) for the aperiodic self‑convolution."""
    fft = np.fft.rfft(a, n=fft_len)
    conv = np.fft.irfft(fft * fft, n=fft_len)[: 2 * a.shape[0] - 1]

    max_val = conv.max()
    tol = max_val * 1e-12 + 1e-14
    active = np.where(conv >= max_val - tol)[0]

    grad = np.zeros_like(a)
    n = a.shape[0]
    for k in active:
        low = max(0, k - n + 1)
        high = min(n - 1, k)
        idx = np.arange(low, high + 1, dtype=int)
        grad[idx] += 2.0 * a[k - idx]

    if active.size > 1:
        grad /= float(active.size)

    return max_val, grad


def _adam_optimize(
    init_a: np.ndarray, deadline: float, restart_id: int, target: float = 1.503
) -> tuple[np.ndarray, float]:
    """
    Adam optimisation on the logits of a soft‑max representation.
    Returns the best (a, score) seen before the deadline.
    """
    n = init_a.shape[0]
    fft_len = 1 << ((2 * n - 2).bit_length())

    # logits (log‑softmax) – small epsilon prevents log(0)
    eps_init = 1e-12
    b = np.log(init_a + eps_init)

    m = np.zeros_like(b)
    v = np.zeros_like(b)
    beta1, beta2 = 0.9, 0.999
    eps = 1e-8

    # initial evaluation
    a0 = np.exp(b - b.max())
    a0 = a0 / a0.sum()
    max_val, _ = _maxconv_and_subgrad(a0, fft_len)
    best_score = 2.0 * n * max_val
    best_a = a0.copy()
    stagn = 0
    it = 0

    while time.time() < deadline:
        it += 1

        # probabilities from logits
        b_max = np.max(b)
        a = np.exp(b - b_max)
        a /= a.sum()

        # convolution & sub‑gradient of the max entry
        max_val, grad_a = _maxconv_and_subgrad(a, fft_len)
        cur_score = 2.0 * n * max_val

        # keep global best
        if cur_score < best_score:
            best_score = cur_score
            best_a = a.copy()
            stagn = 0
            print(
                f"Adam {restart_id:02d} iter {it:6d}: best = {best_score:.6f}"
            )
        else:
            stagn += 1

        # early stop
        if best_score < target:
            break
        if stagn > 8000:
            b += 0.01 * np.random.randn(n)   # log‑space jitter
            stagn = 0

        # Adam update (gradient of original objective)
        grad_obj = 2.0 * n * grad_a
        avg = np.dot(a, grad_obj)
        grad_b = a * (grad_obj - avg)

        m = beta1 * m + (1.0 - beta1) * grad_b
        v = beta2 * v + (1.0 - beta2) * (grad_b ** 2)

        m_hat = m / (1.0 - beta1 ** it)
        v_hat = v / (1.0 - beta2 ** it)

        lr = 0.4 / np.sqrt(it)
        b -= lr * m_hat / (np.sqrt(v_hat) + eps)

    return best_a, best_score


# ----------------------------------------------------------------------
# Main entry point required by the evaluation harness
# ----------------------------------------------------------------------
def propose_candidate(budget_s: int = 1000) -> list:
    """
    Search for a low‑score step‑function sequence within the given time
    budget (seconds).  The routine mixes a smooth gradient descent phase
    with a short Adam polishing phase and returns the best sequence it
    discovers as a plain ``list`` of floats.
    """
    rng = np.random.default_rng(12345)          # reproducible randomness
    deadline = time.time() + budget_s - 1.5     # small safety margin

    # ------------------------------------------------------------------
    # Problem size – reuse the previous best if available
    # ------------------------------------------------------------------
    try:
        previous = np.asarray(height_sequence_1, dtype=float)   # type: ignore[name-defined]
        n = previous.shape[0]
    except Exception:
        previous = None
        n = 5146                                 # default length from earlier runs

    # ------------------------------------------------------------------
    # Global bookkeeping
    # ------------------------------------------------------------------
    best_overall_a = None
    best_overall_score = float("inf")
    restart_id = 0
    strategies = ["prev", "uniform", "random_dirichlet", "geometric"]

    # ------------------------------------------------------------------
    # Main loop – several restarts until time runs out
    # ------------------------------------------------------------------
    while time.time() < deadline - 5.0:
        kind = strategies[restart_id % len(strategies)]

        # ---- generate feasible start point ---------------------------------
        if kind == "prev" and previous is not None:
            a0 = previous.copy()
            if a0.shape[0] != n:
                # pad / truncate to required length
                if a0.shape[0] > n:
                    a0 = a0[:n]
                else:
                    a0 = np.concatenate([a0, np.zeros(n - a0.shape[0])])
            a0 = np.maximum(a0, 0.0)
            s = a0.sum()
            a0 = a0 / s if s > 0 else np.full(n, 1.0 / n)
        elif kind == "uniform":
            a0 = np.full(n, 1.0 / n)
        elif kind == "random_dirichlet":
            # sparse Dirichlet (α=0.5)
            sample = rng.gamma(0.5, 1.0, size=n)
            a0 = sample / sample.sum()
        elif kind == "geometric":
            r = 0.98 + 0.02 * rng.random()
            left = r ** np.arange(n)
            right = r ** np.arange(n - 1, -1, -1)
            a0 = left + right
            a0 = a0 / a0.sum()
        else:
            a0 = np.full(n, 1.0 / n)

        # ---- allocate a slice of the remaining budget for this restart -----
        remaining = deadline - time.time()
        slice_deadline = time.time() + min(30.0, 0.45 * remaining)

        # ---- Stage 1: smooth optimisation ---------------------------------
        a_smooth, score_smooth = _smooth_optimize(a0, slice_deadline, rng)

        # ---- Stage 2: tiny Adam polishing (if time permits) -------------
        if time.time() < deadline - 4.0:
            a_fine, score_fine = _adam_optimize(
                a_smooth, deadline, restart_id, target=1.503
            )
        else:
            a_fine, score_fine = a_smooth, score_smooth

        # ---- update global best -------------------------------------------
        if score_fine < best_overall_score:
            best_overall_score = score_fine
            best_overall_a = a_fine.copy()
            print(
                f"Global best after restart {restart_id:02d}: {best_overall_score:.6f}"
            )

        # early exit if we already beat the target
        if best_overall_score < 1.503:
            print(
                f"Target reached (score={best_overall_score:.6f}) after {restart_id+1} restarts."
            )
            break

        restart_id += 1

    # ------------------------------------------------------------------
    # Fallback – guarantee a valid return value
    # ------------------------------------------------------------------
    if best_overall_a is None:
        best_overall_a = np.full(n, 1.0 / n)

    # Return a plain Python list (the evaluator expects this)
    return [float(v) for v in best_overall_a.tolist()]
```
