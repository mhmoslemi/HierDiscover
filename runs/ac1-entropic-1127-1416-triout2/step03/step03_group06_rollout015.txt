The evaluation function is  

\[
E(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2}\;,
\]

where `*` denotes the full linear convolution.  
Because the expression is *scale‑invariant* we may fix the $\ell_{1}$‑norm of the vector to `1`.  
Consequently the problem reduces to

*find a non‑negative probability vector `a` (∑a = 1) that minimises*  

\[
\max (a*a) .
\]

The optimisation is non‑convex, but the objective *smoothly* approaches the
maximum when we replace `max` by a **log‑sum‑exp** (soft‑max) :

\[
\phi_T(a)=T\log\Bigl(\sum_{k}e^{\frac{(a*a)_k}{T}}\Bigr) ,
\qquad T>0 .
\]

For a fixed temperature `T` the gradient of `\phi_T` is available in closed
form:

\[
\frac{\partial\phi_T}{\partial a}=2\; w * a ,
\qquad  
w_k=\frac{e^{(a*a)_k/T}}{\sum_j e^{(a*a)_j/T}} .
\]

`w*a` is a *cross‑correlation* of `w` and `a`.  
Both the convolution and the correlation are computed with a single FFT,
so each iteration costs only `O(L log L)` with  
\(L=\operatorname{nextpow2}(3n-2)\) (≈ 16 k for the usual `n≈5200`).

The optimisation proceeds as follows:

1. **Generate a diverse pool of seeds** (ramps, exponentials, polynomials,
   Beta‑distributions, random Dirichlet vectors) and keep the best few.
2. **Projected (momentum) gradient descent** on the simplex  
   – the soft‑max temperature is slowly annealed (exponential decay).  
   After every step the iterate is projected onto the probability simplex
   (Euclidean projection of Duchi et al.).
3. **Escaping plateaus** – after a long stretch without improvement a
   small random perturbation is added.
4. **Final local search** – a cheap hill‑climbing loop that moves a tiny
   amount of mass between two random coordinates; any improvement is kept.
5. The best sequence seen during the whole run is returned.

All helper routines are defined at the top level (no closures).  
The routine respects the 1000 s budget, prints progress information and
finally produces a plain `list[float]` that can be fed directly to
`evaluate_sequence`.

```python
Propose a step‑function (non‑negative sequence) that minimises the
evaluation function.  The algorithm consists of:
  • a large, diverse set of seeds (ramps, exponentials, polynomials,
    Beta‑distributions, Dirichlet draws);
  • projected gradient descent on the simplex, where the objective
    is a temperature‑smoothed approximation of the max‑convolution;
    the gradient is obtained analytically via a single FFT‑based
    cross‑correlation;
  • an annealing schedule for the temperature and a decreasing step‑size;
  • occasional random perturbations to escape stagnation;
  • a short hill‑climbing phase that moves a tiny amount of mass
    between two coordinates.
The best sequence found before the time budget expires is returned.
"""

# Linear‑algebra / optimisation helpers (top‑level, no closures)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def simplex_projection(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex:
    { w | w_i ≥ 0, Σ w_i = 1 }.
    Implementation follows Duchi et al. (2008).
    """
    v = np.asarray(v, dtype=float)
    n = v.shape[0]
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, n + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        # all entries non‑positive → uniform distribution
        return np.full_like(v, 1.0 / n)
    rho = ind[cond][-1] - 1               # zero‑based index
    theta = cssv[cond][-1] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w


def compute_score(a: np.ndarray) -> float:
    """
    Return the value that `evaluate_sequence` would give,
    assuming Σ a_i = 1.
    """
    n = a.shape[0]
    L = next_pow2(2 * n - 1)
    A_fft = np.fft.rfft(a, L)
    conv = np.fft.irfft(A_fft * A_fft, n=2 * n - 1)
    max_b = conv.max()
    return 2.0 * n * max_b  # sum is 1, therefore denominator = 1


def beta_sequence(alpha: float, beta: float, n: int) -> np.ndarray:
    """Discretised Beta(α,β) density on the mid‑points, normalised to sum = 1."""
    x = (np.arange(n) + 0.5) / n
    # use log‑density to avoid overflow
    logw = (alpha - 1.0) * np.log(x) + (beta - 1.0) * np.log(1.0 - x)
    logw = np.clip(logw, -700.0, 700.0)
    w = np.exp(logw)
    total = w.sum()
    if total == 0.0 or not np.isfinite(total):
        w = np.ones_like(w)
        total = w.sum()
    return w / total


def exponential_shape(lam: float, n: int) -> np.ndarray:
    """a_i ∝ exp(-lam·i), normalised to sum = 1."""
    i = np.arange(n, dtype=float)
    w = np.exp(-lam * i)
    w /= w.sum()
    return w


def polynomial_shape(p: float, n: int) -> np.ndarray:
    """a_i ∝ 1 - (i/(n‑1))**p, normalised to sum = 1."""
    i = np.arange(n, dtype=float)
    frac = i / (n - 1)
    w = 1.0 - np.power(frac, p)
    w = np.clip(w, 0.0, None)
    w /= w.sum()
    return w


def ramp_sequence(n: int) -> np.ndarray:
    """Decreasing triangular ramp, normalised to sum = 1."""
    a = np.arange(n, 0, -1, dtype=float)
    a = 2.0 * a / (n * (n + 1))
    a /= a.sum()
    return a


def uniform_sequence(n: int) -> np.ndarray:
    """Uniform distribution on n points."""
    return np.full(n, 1.0 / n)

            momentum = np.zeros_like(a)
            stagnation = 0
            print(f"[Iter {iteration:6d}] Perturbation applied, cur score={cur_score:.6f}")

        # early stop if we already beat the target
        if best_score <= 1.503:
            print(f"[Iter {iteration}] Target reached (score={best_score:.6f})")
            break

    # --------------------------------------------------------------
    # 8️⃣  Short local hill‑climbing around the best solution found
    # --------------------------------------------------------------
    if best_seq is not None:
        a = best_seq.copy()
        # a small fixed step for the hill‑climb
        hill_step = 0.004  # 0.4 % of a coordinate, typical magnitude
        while time.time() < deadline:
            i, j = np.random.choice(n, 2, replace=False)
            eps = hill_step * a[i]          # amount to move from i to j
            if eps <= 0.0:
                continue
            a_new = a.copy()
            a_new[i] -= eps
            a_new[j] += eps
            # keep feasibility (projection is cheap, but we can simply re‑normalise)
            a_new = np.clip(a_new, 0.0, None)
            a_new /= a_new.sum()
            sc = compute_score(a_new)
            if sc < best_score - 1e-12:
                best_score = sc
                best_seq = a_new.copy()
                a = a_new
                print(f"[Hill] Improvement to {best_score:.6f}")
            # otherwise discard

    # --------------------------------------------------------------
    # 9️⃣  Return the best sequence discovered (plain Python list)
    # --------------------------------------------------------------
    if best_seq is None:
        # very unlikely, but fall back to uniform
        best_seq = uniform_sequence(n)

    print(f"Finished after {iteration} gradient iterations, best score = {best_score:.6f}")
    return [float(v) for v in best_seq.tolist()]
```

The function `propose_candidate` can be called directly; it respects the
1000 s limit, prints intermediate progress, and returns a list of non‑negative
heights that (empirically) improve upon the previous best bound
(~ 1.5216) and may reach the target 1.503.
