assistantfinal**Solution Overview**

The goal is to produce a non‑negative step function (a probability vector) that minimises  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum_i a_i)^2}\;,
\]

where `a*a` is the linear convolution of the vector with itself.
Because the objective is *scale‑invariant* we may restrict ourselves to vectors that sum to 1; then  

\[
F(a)=2\,n\;\max (a*a) .
\]

The problem is a convex optimisation on the probability simplex:
* the objective is the pointwise maximum of a family of convex quadratic forms,
* the feasible set (non‑negative entries, unit sum) is a simplex.

The algorithm follows three stages that fit comfortably into the 1000 s time budget:

1. **Smooth max‑approximation with Adam** –  
   minimise a differentiable surrogate  
   \[
   \phi_\beta(a)=\frac{1}{\beta}\log\!\Bigl(\sum_k e^{\beta (a*a)_k}\Bigr)
   \]
   whose gradient can be written in closed form using a single extra convolution.
   An *annealing schedule* raises the smoothing parameter β from a small value
   (≈ 5) to a large value (≈ 500) so the surrogate gradually becomes the true max.
   Adam‑style momentum with a decreasing step‑size is used; after each update the
   vector is projected back onto the probability simplex.

2. **Exact sub‑gradient polishing** –  
   When β is large the surrogate gradient is already a valid sub‑gradient of the
   true objective.  A short Adam run with β fixed at the final value refines the
   solution.

3. **Stochastic hill‑climb** –  
   Small random mass‑transfer moves (or swaps) are accepted only if they improve
   the exact score.  This removes the last few rounding artefacts.

The method works for any length `n`.  Larger `n` gives a tighter lower bound
(`2 n/(2 n‑1) → 1`), so we pick the longest length that still leaves enough time for
the optimisation (8192 when the budget is tight, 16384 when we have > 800 s).

All heavy work is performed with FFT‑based convolutions (`O(n log n)`) and the
implementation respects the 1000 s wall‑clock limit.

```python
"""
Convex optimisation of a non‑negative step function.

*   Uses a smoothed log‑sum‑exp approximation of the max‑convolution.
*   Adam optimiser with an annealing schedule for the smoothing parameter β.
*   Final polishing with a sub‑gradient run (β fixed at its final value).
*   Very cheap stochastic hill‑climb to escape the last plateaus.
*   Length adapts to the remaining time (8192 or 16384 entries).
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# Basic utilities (top‑level, no closures)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full linear convolution via real FFT."""
    m = a.shape[0] + b.shape[0] - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Exact objective for a vector that already sums to 1.
    Returns 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    (non‑negative entries that sum to 1).
    """
    if np.all(v <= 0):
        # uniform fallback – the only feasible point when all entries are ≤0
        return np.full_like(v, 1.0 / v.shape[0])

    # standard O(n) algorithm
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
# Smooth (log‑sum‑exp) optimisation
# ----------------------------------------------------------------------


def smooth_max_optimize(
    a0: np.ndarray,
    deadline: float,
    max_iters: int = 5_000_000,
    beta_start: float = 5.0,
    beta_end: float = 500.0,
    step0: float = 0.9,
    adam_beta1: float = 0.9,
    adam_beta2: float = 0.999,
    adam_eps: float = 1e-8,
) -> tuple[np.ndarray, float]:
    """
    Adam optimiser for the smoothed max‑convolution objective.
    Returns the best vector encountered (projected onto the simplex) and its exact score.
    """
    a = a0.astype(float).copy()
    n = a.shape[0]
    m1 = np.zeros_like(a)  # first moment
    v1 = np.zeros_like(a)  # second moment

    best_a = a.copy()
    best_score = compute_score(a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # --------- anneal β -------------------------------------------------
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        # --------- convolution & smoothed weights ---------------------------
        conv = convolution_fft(a, a)               # length 2n‑1
        maxc = conv.max()
        # keep numbers ≤0 to avoid overflow; subtract maxc first
        exp_w = np.exp(beta * (conv - maxc))
        w = exp_w / exp_w.sum()                    # soft‑max weights, sum‑to‑1

        # --------- gradient of the smooth objective -------------------------
        # grad = 2 * (a_rev * w)   (cross‑correlation)
        a_rev = a[::-1]
        conv_rev = convolution_fft(a_rev, w)       # length 3n‑2
        grad = 2.0 * conv_rev[n - 1 : n - 1 + n]    # slice of length n

        # --------- Adam update -----------------------------------------------
        m1 = adam_beta1 * m1 + (1.0 - adam_beta1) * grad
        v1 = adam_beta2 * v1 + (1.0 - adam_beta2) * (grad * grad)
        m_hat = m1 / (1.0 - adam_beta1 ** it)
        v_hat = v1 / (1.0 - adam_beta2 ** it)

        step = step0 / np.sqrt(it)
        a_new = a - step * m_hat / (np.sqrt(v_hat) + adam_eps)

        # --------- project back onto the simplex -------------------------------
        a = project_to_simplex(a_new)

        # --------- keep exact best --------------------------------------------
        if (it % 1000) == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                print(f"Iter {it:>7d} – exact score improved to {best_score:.6f}")

    # final check
    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Sub‑gradient polish (β fixed at its final value)
# ----------------------------------------------------------------------


def subgradient_optimize(
    a0: np.ndarray,
    deadline: float,
    beta: float = 500.0,
    max_iters: int = 1_000_000,
    step0: float = 0.07,
) -> tuple[np.ndarray, float]:
    """
    Projected sub‑gradient descent on the exact (non‑smoothed) objective.
    Uses Adam‑style momentum to keep the steps stable.
    """
    a = a0.astype(float).copy()
    n = a.shape[0]

    m1 = np.zeros_like(a)
    v1 = np.zeros_like(a)

    best_a = a.copy()
    best_score = compute_score(a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))

        # sub‑gradient of the maximal entry
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        step = step0 / np.sqrt(it)
        a_new = a - step * g

        a_new = project_to_simplex(a_new)

        cur_score = compute_score(a_new)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()
            print(f"Sub‑grad iter {it:>7d} – improved score {best_score:.6f}")

        # Adam‑style momentum (helps with noisy sub‑gradients)
        m1 = 0.9 * m1 + 0.1 * g
        v1 = 0.999 * v1 + 0.001 * (g * g)
        a = a_new

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ----------------------------------------------------------------------
# Tiny stochastic hill‑climb (final polishing)
# ----------------------------------------------------------------------


def hill_climb(
    seq,
    deadline,
    max_steps: int = 500_000,
) -> tuple[list[float], float]:
    """
    Random mass‑transfer / swap moves on the simplex.
    Only moves that improve the *exact* score are kept.
    """
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(best_a)

    # initial move magnitude (fraction of the source entry)
    step_scale = 0.10

    while max_steps > 0 and time.time() < deadline:
        cand = best_a.copy()
        if np.random.rand() < 0.5:
            # simple swap
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:
            # transfer a fraction from i to j
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = step_scale * best_a[i]
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0.0:
                    cand[i] = 0.0

        cand = project_to_simplex(cand)
        cur_score = compute_score(cand)

        if cur_score < best_score:
            best_score = cur_score
            best_a = cand
            step_scale = min(step_scale * 1.07, 0.5)        # become bolder
        else:
            step_scale *= 0.96                               # become more cautious

        max_steps -= 1

    return best_a.tolist(), best_score

    a0 += 5e-4 * np.random.rand(n)          # break perfect symmetry a little
    a0 = np.maximum(a0, 0.0)
    a0 /= a0.sum()                           # unit sum → probability simplex

    # ------------------------------------------------------------------
    # 3. Smooth optimisation (large fraction of the budget)
    # ------------------------------------------------------------------
    smooth_deadline = deadline - (budget_s * 0.07)   # keep ~7 % for polishing
    best_a, best_score = smooth_max_optimize(
        a0,
        smooth_deadline,
        max_iters=10_000_000,          # very generous – will be cut by time
        beta_start=5.0,
        beta_end=500.0,
        step0=0.9,
    )
    print(f"After smooth stage best score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 4. Sub‑gradient polish (β fixed at its final value)
    # ------------------------------------------------------------------
    if time.time() < deadline - 5.0:
        subgrad_deadline = deadline - 3.0
        best_a, best_score = subgradient_optimize(
            best_a,
            subgrad_deadline,
            beta=500.0,
            max_iters=2_000_000,
            step0=0.07,
        )
        print(f"After sub‑gradient polish best score = {best_score:.6f}")

    # ------------------------------------------------------------------
    # 5. Final stochastic hill‑climb
    # ------------------------------------------------------------------
    if time.time() < deadline - 1.0:
        final_deadline = deadline
        best_seq, best_score = hill_climb(best_a.tolist(), final_deadline, max_steps=600_000)
        print(f"Hill‑climb final best score = {best_score:.6f}")
    else:
        best_seq = best_a.tolist()

    # ------------------------------------------------------------------
    # 6. Final official evaluation (the harness will call evaluate_sequence)
    # ------------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\nFinished search – final reported score = {final_score:.6f}")
    return best_seq
```
