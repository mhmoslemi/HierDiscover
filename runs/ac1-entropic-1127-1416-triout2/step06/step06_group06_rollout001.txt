assistantfinal**Solution Overview**

This implementation searches for a non‑negative step‑function (a probability vector) that minimizes  

\[
\text{score}(a)=\frac{2\,n\;\max\bigl(a*a\bigr)}{\bigl(\sum a\bigr)^{2}}
\]

where `*` denotes the linear convolution.  
The score is *scale‑invariant*, therefore we restrict the search to the probability simplex
\(\{a\mid a_i\ge 0,\;\sum_i a_i = 1\}\) and minimise the simpler quantity  

\[
F(a)=2\,n\;\max\bigl(a*a\bigr)\; .
\]

The optimiser consists of three complementary phases that run inside the
1000 s budget:

1. **Random‑restart smoothed exponentiated‑gradient descent** –  
   a soft‑max surrogate of the maximum convolution is minimised.
   The surrogate becomes sharper (λ grows from ≈0.5 to 80) so the algorithm
   focuses on the truly worst shift.  The update is multiplicative,
   followed by Euclidean projection onto the simplex.

2. **Simulated‑annealing perturbations** –  
   starting from the best vector found so far, random Gaussian perturbations
   are proposed, accepted with a Metropolis rule, and the temperature is
   cooled linearly.  This phase helps to escape local minima that the
   gradient method cannot leave.

3. **Fine‑grained hill‑climbing** –  
   deterministic mass‑transfer moves (move a fraction of the mass from one
   index to another) are performed until the time limit.  The step size
   is adapted to the observed success rate.

All three phases share fast FFT‑based convolution and an Euclidean
projection onto the simplex.  The code prints occasional progress messages
and finally returns the best sequence (list of `float`s) found before the
deadline.

```python
"""
Hybrid optimiser for the step‑function attack.

The objective is   score(a) = 2·n·max(conv(a,a)) / (sum(a))**2 .
Because the score is invariant under scaling we work on the probability
simplex (sum(a)=1, a_i≥0) and minimise 2·n·max(conv(a,a)).

Three phases are carried out within the time budget:

1️⃣ Random‑restart smoothed exponentiated‑gradient descent.
   A soft‑max over the convolution entries provides a smooth surrogate.
   λ (softness) is increased from ≈0.5 to 80, making the surrogate focus
   on the true worst shift.  Updates are multiplicative and projected onto
   the simplex.

2️⃣ Simulated‑annealing perturbations starting from the best vector.
   Gaussian noise is added, the candidate is projected back onto the simplex
   and accepted according to a decreasing temperature schedule.

3️⃣ Fine‑grained hill‑climbing (mass‑transfer moves) for polishing.

The programme respects the 1000 s budget, prints intermediate scores and
returns the best list of floats.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based convolution utilities (real FFT, linear convolution)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Linear convolution a*b using a real FFT.
    Result length is len(a)+len(b)-1.
    """
    m = a.shape[0] + b.shape[0] - 1
    n_fft = _next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


# ----------------------------------------------------------------------
# Objective and projection
# ----------------------------------------------------------------------


def compute_score(a: np.ndarray) -> float:
    """
    Fast evaluation of the objective for a probability vector a.
    Returns 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(np.max(conv))


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x | x_i ≥ 0, Σx_i = 1}.
    """
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# 1️⃣ Smoothed exponentiated‑gradient descent
# ----------------------------------------------------------------------


def smooth_exp_optimize(
    init_a: np.ndarray,
    deadline: float,
    eta0: float = 0.8,
    lam_start: float = 0.5,
    lam_end: float = 80.0,
    eval_interval: int = 300,
) -> tuple[np.ndarray, float]:
    """
    Multiplicative (exponentiated) gradient descent on the soft‑max
    surrogate of   max_k (a*a)[k] .
    Returns the best vector seen and its true score.
    """
    a = init_a.astype(float).copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(a)

    it = 0
    while time.time() < deadline:
        it += 1

        # full convolution a*a (length 2n‑1)
        conv = convolution_fft(a, a)
        M = np.max(conv)

        # linearly increase λ, never exceeding lam_end
        lam = lam_start + (lam_end - lam_start) * min(1.0, it / 2_500_000)

        # soft‑max weights (stable)
        exp_vals = np.exp(lam * (conv - M))
        w = exp_vals / np.sum(exp_vals)  # sums to 1, length 2n‑1

        # gradient = 2 * (rev(a) * w) restricted to the central n entries
        a_rev = a[::-1]
        g_full = convolution_fft(a_rev, w)          # length 3n‑2
        g = 2.0 * g_full[n - 1 : n - 1 + n]

        # step size (decreasing like 1/√t)
        eta = eta0 / np.sqrt(it)

        # multiplicative update, guard against overflow
        step = -eta * g
        step = np.clip(step, -50.0, 50.0)
        a = a * np.exp(step)

        # project back onto the simplex
        a = project_to_simplex(a)

        # occasional evaluation of the true (non‑smoothed) objective
        if it % eval_interval == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()
                print(
                    f"[{time.time():.1f}]  iter {it:,}  new best (grad) {best_score:.6f}"
                )

    # final check
    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()

    return best_a, best_score

def simulated_annealing(
    init_a: np.ndarray,
    deadline: float,
    max_steps: int = 400_000,
    init_temp: float = 0.12,
    final_temp: float = 0.002,
) -> tuple[np.ndarray, float]:
    """
    Simple Metropolis simulated annealing on the true objective.
    Gaussian perturbations are projected onto the simplex.
    """
    a = init_a.copy()
    cur_score = compute_score(a)

    best_a = a.copy()
    best_score = cur_score

    n = a.shape[0]
    it = 0

    while time.time() < deadline and it < max_steps:
        it += 1
        # linear temperature schedule
        T = init_temp + (final_temp - init_temp) * (it / max_steps)

        # propose a noisy candidate
        eps = 0.03  # standard deviation of the Gaussian noise
        cand = a + eps * np.random.randn(n)
        cand = np.maximum(cand, 0.0)
        cand = project_to_simplex(cand)

        cand_score = compute_score(cand)

        # accept if better, otherwise with Metropolis probability
        if cand_score < cur_score or np.random.rand() < np.exp((cur_score - cand_score) / max(T, 1e-12)):
            a = cand
            cur_score = cand_score
            if cand_score < best_score:
                best_score = cand_score
                best_a = cand.copy()
                print(f"[{time.time():.1f}]  SA step {it:,}  new best {best_score:.6f}")

        if it % 20_000 == 0:
            # occasional progress report
            print(f"[{time.time():.1f}]  SA step {it:,}  current {cur_score:.6f}")

    return best_a, best_score

# ----------------------------------------------------------------------


def hill_climb(
    start_seq,
    deadline,
    max_steps: int = 800_000,
) -> tuple[list, float]:
    """
    Deterministic hill‑climbing that moves a fraction of mass from one
    coordinate to another.  The transfer fraction adapts to recent success.
    """
    a = np.array(start_seq, dtype=float)
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(best_a)

    # adaptive step size (fraction of the source mass)
    step_scale = 0.12

    steps = 0
    while steps < max_steps and time.time() < deadline:
        i, j = np.random.randint(n, size=2)
        if i == j:
            continue

        # propose moving a fraction of the mass at i towards j
        cand = best_a.copy()
        delta = step_scale * cand[i]
        if delta <= 0.0:
            continue
        cand[i] -= delta
        cand[j] += delta

        # enforce non‑negativity and renormalise
        cand = np.maximum(cand, 0.0)
        cand = project_to_simplex(cand)

        cur_score = compute_score(cand)

        if cur_score < best_score:
            best_score = cur_score
            best_a = cand
            step_scale = min(step_scale * 1.08, 0.45)  # increase on success
        else:
            step_scale *= 0.97                         # decrease on failure

        steps += 1

        if steps % 100_000 == 0:
            print(f"[{time.time():.1f}]  hill‑climb step {steps:,}  best {best_score:.6f}")

    return best_a.tolist(), best_score

            np.array(best_seq, dtype=float),
            deadline=sa_deadline,
            max_steps=350_000,
            init_temp=0.12,
            final_temp=0.002,
        )
        if sa_val < best_val:
            best_val = sa_val
            best_seq = sa_best.tolist()
            print(f"SA improved best to {best_val:.6f}")

    # ------------------------------------------------------------------
    # Phase 3 – fine hill‑climbing polishing.
    # ------------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 3.0:
        print("\nFinal hill‑climb polishing")
        hc_seq, hc_val = hill_climb(
            best_seq,
            deadline=deadline,
            max_steps=800_000,
        )
        if hc_val < best_val:
            best_val = hc_val
            best_seq = hc_seq
            print(f"Hill‑climb improved best to {best_val:.6f}")

    # ------------------------------------------------------------------
    # Fallback in the unlikely event that nothing was produced.
    # ------------------------------------------------------------------
    if best_seq is None:
        best_seq = [1.0 / n] * n
        best_val = evaluate_sequence(best_seq)

    final_score = evaluate_sequence(best_seq)
    print(f"\nSearch finished. Final reported score = {final_score:.6f}")

    return best_seq
```
