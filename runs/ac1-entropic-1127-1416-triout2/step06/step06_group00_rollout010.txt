assistantfinal**Solution Overview**

The goal is to find a non‑negative step‑function `a = (a₀,…,aₙ₋₁)` that minimises  

\[
F(a)=\frac{2\,n\;\max (a*a)}{(\sum a_i)^2},
\]

where `*` is the ordinary convolution.  
The value is invariant under scaling, therefore we keep the vector on the
probability simplex (`∑a_i = 1`).  

The search consists of three independent stages:

1. **Multiple random restarts + smoothed gradient descent** –  
   a log‑sum‑exp smoothing of the `max` is minimised.  
   The smoothing parameter β is annealed from a modest value to a very large
   one (β≈200).  A Nesterov‑style momentum term is added to the updates and
   after each step the vector is projected back onto the simplex.

2. **Projected sub‑gradient descent on the true objective** –  
   the exact maximal convolution index is identified and a sub‑gradient
   (the usual `2·a`‑shift) is applied.  The step size follows the classic
   `αₜ = α₀ / √t` schedule.  This stage cleans up the remaining
   non‑smooth parts of the landscape.

3. **Simulated‑annealing hill‑climb** –  
   a stochastic local search that moves a small fraction of mass from one
   position to another (or swaps two positions).  Worse moves are accepted
   with a temperature‑dependent probability, which allows the algorithm to
   escape shallow local minima.  After each move the vector is projected
   onto the simplex.

All three stages respect the global wall‑clock limit (≈ 1000 s).  The
best sequence seen during the whole run is finally evaluated with the
provided `evaluate_sequence` and returned.

The implementation uses only `numpy` and the standard library – no
external LP solver is required, but the code can be extended easily if a
solver is available.

```python
"""
Propose a step‑function with a very low evaluation score.

The search consists of three stages:

1.  Many random restarts followed by a smoothed log‑sum‑exp gradient
    descent (β is annealed up to ≈200).  A Nesterov momentum term is used
    and each iterate is projected onto the probability simplex.

2.  Projected sub‑gradient descent on the exact max‑objective
    (step size αₜ = α₀/√t).

3.  Simulated‑annealing hill‑climb that moves a small fraction of mass
    between two indices (or swaps two entries).  Worse moves are accepted
    with a temperature‑dependent probability; the temperature decays
    slowly.  The vector is always kept on the simplex.

The routine adapts the sequence length to the available budget
(2048 / 4096 / 8192) and stops well before the 1000 s deadline, returning
the best sequence found.
"""

import time
import numpy as np

# ------------------------------------------------------------
# Helper utilities
# ------------------------------------------------------------

def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Full convolution a ⊛ b using a real FFT."""
    m = a.shape[0] + b.shape[0] - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """
    Fast replica of `evaluate_sequence` when the vector sums to 1.
    Returns 2·n·max(a⊛a).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(conv.max())


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x ≥ 0, Σx = 1}.
    """
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    if not np.any(cond):
        theta = 0.0
    else:
        rho = np.where(cond)[0][-1]
        theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ------------------------------------------------------------
# 1. Smoothed log‑sum‑exp gradient descent (with momentum)
# ------------------------------------------------------------

def smooth_gradient_optimize(start_a: np.ndarray,
                             deadline: float,
                             max_iters: int = 200_000,
                             beta_start: float = 5.0,
                             beta_end: float = 200.0,
                             step0: float = 0.7,
                             momentum: float = 0.9) -> tuple[np.ndarray, float]:
    """
    Minimise a smoothed surrogate of the max‑convolution.
    Uses Nesterov‑style momentum and anneals the smoothing parameter β.
    """
    a = start_a.astype(float).copy()
    n = a.shape[0]
    best_a = a.copy()
    best_score = compute_score(a)

    # momentum buffers
    vel = np.zeros_like(a)

    for it in range(1, max_iters + 1):
        if time.time() >= deadline:
            break

        # anneal β (geometric schedule)
        t = it / max_iters
        beta = beta_start * (beta_end / beta_start) ** t

        # smooth max via log‑sum‑exp
        conv = convolution_fft(a, a)                # length 2n‑1
        maxc = conv.max()
        exp_weights = np.exp(beta * (conv - maxc))   # stability trick
        w = exp_weights / exp_weights.sum()          # probabilities, length 2n‑1

        # gradient = 2·conv( a_rev , w )
        a_rev = a[::-1]
        grad_full = convolution_fft(a_rev, w)      # length 3n‑2
        grad = 2.0 * grad_full[n - 1:n - 1 + n]    # slice of length n

        # step size decreasing like 1/√t
        step = step0 / np.sqrt(it)

        # Nesterov momentum update
        vel = momentum * vel - step * grad
        a_new = a + vel
        a_new = project_to_simplex(a_new)

        a = a_new

        # occasional exact evaluation
        if it % 250 == 0:
            cur_score = compute_score(a)
            if cur_score < best_score:
                best_score = cur_score
                best_a = a.copy()

    # final evaluation
    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ------------------------------------------------------------
# 2. Projected sub‑gradient descent on the true max‑objective
# ------------------------------------------------------------

def subgrad_optimize(start_a: np.ndarray,
                     deadline: float,
                     max_iter: int = 150_000,
                     step0: float = 0.07) -> tuple[np.ndarray, float]:
    """
    Classic projected sub‑gradient descent on    2·n·max(conv(a,a)).
    """
    a = start_a.astype(float).copy()
    best_a = a.copy()
    best_score = compute_score(a)
    n = a.shape[0]

    for t in range(1, max_iter + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        k = int(np.argmax(conv))          # index of maximal entry

        # sub‑gradient for the max entry (2·a shifted)
        idx = np.arange(n)
        j = k - idx
        mask = (j >= 0) & (j < n)
        g = np.zeros_like(a)
        g[mask] = 2.0 * a[j[mask]]

        step = step0 / np.sqrt(t)
        a_new = a - step * g
        a_new = project_to_simplex(a_new)

        cur_score = compute_score(a_new)
        if cur_score < best_score:
            best_score = cur_score
            best_a = a_new.copy()

        a = a_new

        # tiny random jitter every few thousand steps (helps escape plateaus)
        if t % 2000 == 0:
            a += np.random.randn(n) * (step0 * 0.004 / np.sqrt(t))
            a = project_to_simplex(a)

    final_score = compute_score(a)
    if final_score < best_score:
        best_score = final_score
        best_a = a.copy()
    return best_a, best_score


# ------------------------------------------------------------
# 3. Simulated‑annealing hill‑climb
# ------------------------------------------------------------

def hill_climb_sa(seq,
                  deadline,
                  max_steps: int = 400_000) -> tuple[list[float], float]:
    """
    Stochastic hill‑climb with occasional uphill moves (simulated annealing).
    The vector is always projected onto the simplex.
    """
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(best_a)

    cur_a = a.copy()
    cur_score = best_score

    # temperature schedule (starts relatively high, decays slowly)
    temp = 0.015 * best_score          # proportional to the objective magnitude
    temp_decay = 0.999985

    # typical fraction of mass moved in each proposal
    move_frac = 0.08

    step = 0
    while step < max_steps and time.time() < deadline:
        step += 1

        cand = cur_a.copy()
        if np.random.rand() < 0.5:
            # transfer a small fraction from i to j
            i, j = np.random.randint(n, size=2)
            if i != j:
                delta = move_frac * cur_a[i]
                cand[i] -= delta
                cand[j] += delta
                if cand[i] < 0:
                    cand[i] = 0.0
        else:
            # simple swap of two entries
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]

        cand = project_to_simplex(cand)
        cand_score = compute_score(cand)

        # accept if better, otherwise accept with prob. exp(-Δ/Temp)
        if cand_score < cur_score:
            cur_a, cur_score = cand, cand_score
        else:
            if np.random.rand() < np.exp(-(cand_score - cur_score) / max(temp, 1e-12)):
                cur_a, cur_score = cand, cand_score

        # keep track of the overall best
        if cand_score < best_score:
            best_score = cand_score
            best_a = cand.copy()
            # when we improve, increase move size a bit
            move_frac = min(move_frac * 1.04, 0.30)

        # slowly cool down
        temp *= temp_decay

        # occasional diagnostics
        if step % 20000 == 0:
            print(f"SA step {step:,d} – best score {best_score:.6f}")

    return best_a.tolist(), best_score
```
