```
    n = len(a)
```

The goal is to minimise  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a)^2},
\]

where `a*a` is the ordinary (linear) convolution of `a` with itself.  
The ratio is invariant under scaling, therefore we restrict all candidates to the
probability simplex  

\[
\Delta_n=\left\{a\in\mathbb R_{\ge0}^n\;\Big|\;\sum_{i}a_i=1\right\}
\]

and minimise the simpler objective  

\[
\phi(a)=2\,n\;\max_k (a*a)_k .
\]

The function \(\phi\) is convex in the *max* but the dependence on `a` is
quadratic.  A successful strategy is to smooth the max with a soft‑max,
run a fast exponentiated‑gradient descent, and finish with a **hard‑max**
(sub‑gradient) refinement followed by a short stochastic hill‑climber.
The algorithm below

* uses several random restarts (Dirichlet draws with random concentration),
* runs a **soft‑max** optimiser with a large temperature schedule
  (`λ` grows up to 300),  
* switches to a **hard‑max** optimiser that follows the true sub‑gradient,
* finally applies a **mass‑transfer hill‑climber**,
* keeps the best candidate seen so far.

All heavy work (convolutions) is performed with an FFT‑based routine, which
makes the inner loop cheap enough to fit many thousands of iterations into the
1000 s budget.

The code follows the required interface – the only public symbol is
`propose_candidate`.  It returns a list of non‑negative floats ready to be
passed to the supplied `evaluate_sequence`.  The implementation prints a few
progress messages so the user can see how the bound improves over time.

```python
"""
Hybrid optimiser for the step‑function attack.

The algorithm works on the probability simplex (∑a = 1, a_i ≥ 0) and
minimises  f(a) = 2·n·max(conv(a,a)) .

Three phases are performed for each random restart:

  1️⃣  Smoothed exponentiated‑gradient descent – a soft‑max over all
      convolution entries gives a smooth surrogate.
      The temperature λ is increased from 1 up to 300, the step‑size
      η decays as η₀/√t, and the update is multiplicative
      (a ← a·exp(−η·g)) with a Euclidean projection onto the simplex.

  2️⃣  Hard‑max sub‑gradient descent – after the soft phase the exact
      worst shift is used (one‑hot weight) and a classic projected
      gradient step is applied (additive update).  This removes the
      remaining slack of the soft approximation.

  3️⃣  Fine‑grained hill‑climbing – stochastic transfers of a fraction
      of the mass between two positions are accepted whenever they
      improve the true (non‑smoothed) objective.

Multiple restarts are interleaved until the time budget (≈1000 s) is
exhausted.  The best sequence encountered is returned.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT‑based linear convolution (real FFT, fast for the sizes we use)
# ----------------------------------------------------------------------


def _next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Linear convolution a*b using a real FFT.
    Result length = len(a) + len(b) - 1.
    """
    m = a.shape[0] + b.shape[0] - 1
    n_fft = _next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


# ----------------------------------------------------------------------
# Simple utilities
# ----------------------------------------------------------------------


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto the probability simplex
    {x | x_i ≥ 0, Σx_i = 1}.
    """
    if np.all(v <= 0):
        # All non‑positive ⇒ uniform point
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_score(a: np.ndarray) -> float:
    """
    Fast replica of `evaluate_sequence` for Σa = 1.
    Returns 2·n·max(conv(a,a)).
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(np.max(conv))


# ----------------------------------------------------------------------
# 1️⃣ Smoothed exponentiated‑gradient descent
# ----------------------------------------------------------------------


def smooth_exp_optimize(
    init_a: np.ndarray,
    deadline: float,
    eta0: float = 0.8,
    lam_start: float = 1.0,
    lam_end: float = 300.0,
    eval_interval: int = 250,
) -> tuple[np.ndarray, float]:
    """
    Multiplicative (exponentiated) gradient descent on the smooth surrogate

        F(a) = log‑sum‑exp( λ·conv(a,a) )

    The gradient of the surrogate is

        g = 2·(a_rev * w),

    where w is the soft‑max over the convolution entries.
    """
    a = init_a.astype(float).copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(a)

    it = 0
    while True:
        if time.time() >= deadline:
            break
        it += 1

        # full convolution a*a (length 2n‑1)
        conv = convolution_fft(a, a)

        # current temperature λ (linear schedule)
        lam = lam_start + (lam_end - lam_start) * min(1.0, it / 2_000_000)

        # soft‑max weights (stable version)
        max_c = np.max(conv)
        exp_vals = np.exp(lam * (conv - max_c))
        w = exp_vals / np.sum(exp_vals)

        # gradient = 2·(a_rev * w)   (central n entries only)
        a_rev = a[::-1]
        g_full = convolution_fft(a_rev, w)          # length 3n‑2
        g = 2.0 * g_full[n - 1 : n - 1 + n]

        # step size (decreasing)
        eta = eta0 / np.sqrt(it)

        # multiplicative update, clipped for numeric safety
        step = -eta * g
        step = np.clip(step, -50, 50)
        a = a * np.exp(step)

        # back onto the simplex
        a = project_to_simplex(a)

        # occasional true‑objective evaluation
        if it % eval_interval == 0:
            cur = compute_score(a)
            if cur < best_score:
                best_score = cur
                best_a = a.copy()
                print(f"[{time.time():.1f}]  iter {it:,}  new best {best_score:.6f}")

    # final check
    cur = compute_score(a)
    if cur < best_score:
        best_score = cur
        best_a = a.copy()

    return best_a, best_score


# ----------------------------------------------------------------------
# 2️⃣ Hard‑max (exact sub‑gradient) descent
# ----------------------------------------------------------------------


def hard_subgrad_optimize(
    init_a: np.ndarray,
    deadline: float,
    eta0: float = 0.5,
    eval_interval: int = 200,
) -> tuple[np.ndarray, float]:
    """
    Projected gradient descent using the exact sub‑gradient of
    max(conv(a,a)).  The gradient for the active shift k* is

        g_i = 2·a_{k*‑i}   (with the obvious index bounds).

    The update is additive on the simplex (a ← a − η·g, then projection).
    """
    a = init_a.astype(float).copy()
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(a)

    it = 0
    while True:
        if time.time() >= deadline:
            break
        it += 1

        conv = convolution_fft(a, a)
        k_max = int(np.argmax(conv))

        # one‑hot weight for the active shift
        w = np.zeros_like(conv)
        w[k_max] = 1.0

        a_rev = a[::-1]
        g_full = convolution_fft(a_rev, w)
        g = 2.0 * g_full[n - 1 : n - 1 + n]

        # step size (decreasing)
        eta = eta0 / np.sqrt(it)

        a = a - eta * g
        a = np.maximum(a, 0.0)          # keep non‑negative before projection
        a = project_to_simplex(a)

        if it % eval_interval == 0:
            cur = compute_score(a)
            if cur < best_score:
                best_score = cur
                best_a = a.copy()
                print(f"[{time.time():.1f}]  hard‑subgrad iter {it:,}  best {best_score:.6f}")

    cur = compute_score(a)
    if cur < best_score:
        best_score = cur
        best_a = a.copy()

    return best_a, best_score


# ----------------------------------------------------------------------
# 3️⃣ Fine‑grained hill‑climber
# ----------------------------------------------------------------------


def hill_climb(seq, deadline, max_steps: int = 800_000):
    """
    Stochastic hill‑climber that transfers a fraction of mass from one index
    to another.  The step size adapts to the recent success rate.
    """
    a = np.array(seq, dtype=float)
    n = a.shape[0]

    best_a = a.copy()
    best_score = compute_score(best_a)

    step_scale = 0.15          # start with 15 % of the source mass
    succ = 0
    trials = 0

    while trials < max_steps and time.time() < deadline:
        i, j = np.random.randint(n, size=2)
        if i == j:
            continue

        delta = step_scale * best_a[i]
        if delta <= 0:
            continue

        cand = best_a.copy()
        cand[i] -= delta
        cand[j] += delta

        cand = np.maximum(cand, 0.0)
        cand = project_to_simplex(cand)

        cur = compute_score(cand)

        if cur < best_score:
            best_score = cur
            best_a = cand
            step_scale = min(step_scale * 1.07, 0.5)
            succ += 1
        else:
            step_scale *= 0.98
        trials += 1

        # adapt step_scale every 2000 attempts
        if trials % 2000 == 0 and trials > 0:
            if succ / 2000 < 0.05:   # too few successes → shrink more aggressively
                step_scale = max(step_scale * 0.9, 0.02)
            succ = 0

    return best_a.tolist(), best_score

def propose_candidate(seed: int = 2024, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative sequence that minimises `evaluate_sequence`.
    The search consists of many random restarts, a smoothed exponentiated
    gradient phase, a hard‑max sub‑gradient refinement and a short
    hill‑climbing polishing phase.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin for the harness
    deadline = start_time + budget_s - 1.0

    # --------------------------------------------------------------
    # Length of the vector – use the fallback length if it exists,
    # otherwise 2048 (a good compromise between quality and speed)
    # --------------------------------------------------------------
    try:
        n = len(height_sequence_1)          # type: ignore[name-defined]
    except Exception:
        n = 2048

    best_seq = None
    best_val = float("inf")

    # --------------------------------------------------------------
    # If a fallback sequence is available, evaluate it first
    # --------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]  # type: ignore[name-defined]
        fallback_val = evaluate_sequence(fallback)
        print(f"Fallback score = {fallback_val:.6f}")
        if fallback_val < best_val:
            best_val = fallback_val
            best_seq = fallback
    except Exception:
        pass

    # --------------------------------------------------------------
    # Main optimisation loop – keep trying new starts until time runs out
    # --------------------------------------------------------------
    restart_counter = 0
    # we keep roughly 15 s for the final polishing step
    while time.time() < deadline - 15.0:
        restart_counter += 1

        # Dirichlet start – random concentration to vary sparsity
        alpha = np.random.uniform(0.1, 5.0)
        a0 = np.random.dirichlet(np.full(n, alpha))

        # allocate a slice of the remaining budget for this restart
        now = time.time()
        remaining = deadline - now
        # reserve 5 s for the final hill‑climb, the rest for this restart
        sub_deadline = now + max(5.0, remaining * 0.7)

        print(f"[{now:.1f}] Restart {restart_counter}, α={alpha:.2f}")

        # ---- phase 1: smooth exponentiated gradient descent ----
        refined_a, refined_score = smooth_exp_optimize(
            a0,
            deadline=sub_deadline,
            eta0=0.85,
            lam_start=1.0,
            lam_end=300.0,
            eval_interval=300,
        )
        if refined_score < best_val:
            best_val = refined_score
            best_seq = refined_a.tolist()
            print(f"   → new global best after smooth‑opt {best_val:.6f}")

        # ---- phase 2: hard‑max sub‑gradient refinement ----
        # give it a modest slice of the remaining time (if any)
        if time.time() < deadline - 8.0:
            sub_deadline2 = time.time() + min(8.0, (deadline - time.time()) * 0.5)
            refined_a, refined_score = hard_subgrad_optimize(
                refined_a,
                deadline=sub_deadline2,
                eta0=0.6,
                eval_interval=200,
            )
            if refined_score < best_val:
                best_val = refined_score
                best_seq = refined_a.tolist()
                print(f"   → new global best after hard‑subgrad {best_val:.6f}")

    # --------------------------------------------------------------
    # Final hill‑climb polishing (uses the exact objective)
    # --------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 2.0:
        print("\nFinal hill‑climb polishing")
        polished_seq, polished_val = hill_climb(
            best_seq,
            deadline=deadline,
            max_steps=600_000,
        )
        if polished_val < best_val:
            best_val = polished_val
            best_seq = polished_seq
            print(f"Hill‑climb improved best to {best_val:.6f}")

    # --------------------------------------------------------------
    # Safeguard – should never happen, but return a uniform vector if it does
    # --------------------------------------------------------------
    if best_seq is None:
        best_seq = [1.0 / n] * n
        best_val = evaluate_sequence(best_seq)

    final_score = evaluate_sequence(best_seq)
    print(f"\nSearch finished. Final reported score = {final_score:.6f}")

    return best_seq
```
