assistantfinal**Solution Overview**

The score to minimise is  

\[
\text{score}(a)=\frac{2\,n\;\max (a*a)}{(\sum a_i)^2},
\qquad a\in\mathbb R_{\ge0}^n .
\]

Because the expression is **scale‑invariant**, we may restrict ourselves to the
probability simplex \(\sum a_i=1\).  
For a vector on the simplex the score simplifies to  

\[
\text{score}(a)=2\,n\;\max\bigl(a*a\bigr) .
\]

Hence the optimisation problem is *“make the self‑convolution as flat as
possible”*.

The algorithm below follows three stages

1. **Many random restarts** – each restart starts from a Dirichlet draw.
2. **Smooth optimisation** – we minimise a soft‑max approximation of the
   \(\ell_\infty\)‑norm of the convolution.  
   The gradient of the smooth objective is obtained analytically and the
   parameters are updated with the Adam optimiser; the temperature
   \(\beta\) of the soft‑max is increased linearly up to a large value
   (`beta_max=200`) so that the approximation becomes very sharp.
3. **Targeted max‑gradient descent** – after the soft‑max phase we focus on the
   *real* maximum entry of the convolution and perform a few projected
   gradient steps that directly reduce this entry.
4. **Final stochastic hill‑climbing** – short random walk (swaps,
   mass transfers) to polish the best vector.

All operations are performed on the simplex (projection with the
Euclidean method) and the fast FFT‑based convolution is used for the score.
The whole search respects the 1000 s budget.

```python
"""
Improved search for a low‑score non‑negative step function.

The algorithm consists of
1️⃣   several random Dirichlet restarts,
2️⃣   a smooth soft‑max optimisation of  max(a*a)  using Adam and a high
     soft‑max temperature (β up to 200),
3️⃣   a few projected gradient steps that directly attack the true
     maximum entry of the convolution,
4️⃣   a final stochastic hill‑climber (swap / mass‑transfer moves).

All computations respect the simplex constraint (Σa_i = 1) and the
time‑budget of 1000 s.
"""

import time
import numpy as np

# ----------------------------------------------------------------------
# FFT utilities (linear convolution, real‑valued)
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Return the smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """
    Linear convolution using an (real) FFT.
    Length of the result is len(a)+len(b)-1.
    """
    m = a.size + b.size - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


# ----------------------------------------------------------------------
# Euclidean projection onto the probability simplex
# ----------------------------------------------------------------------


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """
    Euclidean projection of a vector onto
    {x | x_i ≥ 0 , Σ x_i = 1 }.
    """
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.shape[0])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    ind = np.arange(1, v.shape[0] + 1)
    cond = u - cssv / ind > 0
    rho = np.where(cond)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


# ----------------------------------------------------------------------
# Exact objective when Σa_i = 1
# ----------------------------------------------------------------------


def fast_score(a: np.ndarray) -> float:
    """
    Return 2·n·max(a*a) for a probability vector a.
    This equals the value returned by `evaluate_sequence`.
    """
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(np.max(conv))


# ----------------------------------------------------------------------
# Soft‑max (smooth) optimisation with Adam
# ----------------------------------------------------------------------


def smooth_optimize_adam(
    a: np.ndarray,
    deadline: float,
    iters: int = 120_000,
    beta0: float = 0.5,
    beta_max: float = 200.0,
    eta0: float = 0.4,
    report_every: int = 10_000,
) -> tuple[np.ndarray, float]:
    """
    minimise the soft‑max  f_β(a) = (2·n/β)·log Σ_k exp(β·(a*a)[k])
    using Adam and an increasing temperature β.
    Returns the best vector seen and its exact score.
    """
    n = a.shape[0]
    L = next_pow2(3 * n - 2)          # size needed for all FFTs
    eps = 1e-12

    # Adam parameters
    beta1 = 0.9
    beta2 = 0.999
    m = np.zeros_like(a)
    v = np.zeros_like(a)

    best_a = a.copy()
    best_val = fast_score(best_a)

    for t in range(1, iters + 1):
        if time.time() >= deadline - 1.0:
            break

        # ----- convolution a*a (full length) -----
        A = np.fft.rfft(a, n=L)
        conv_full = np.fft.irfft(A * A, n=L)
        conv = conv_full[: 2 * n - 1]            # length 2n‑1
        max_c = np.max(conv)

        # ----- soft‑max weights w -----
        beta = min(beta_max, beta0 + (beta_max - beta0) * (t / iters))
        # stabilized exponentials
        exp_terms = np.exp(beta * (conv - max_c))
        w = exp_terms / np.sum(exp_terms)        # shape (2n‑1,)

        # ----- gradient = 2·(w ⋆ a_rev) -----
        a_rev = a[::-1]
        A_rev = np.fft.rfft(a_rev, n=L)
        W = np.fft.rfft(w, n=L)
        grad_full = np.fft.irfft(A_rev * W, n=L)
        grad = 2.0 * grad_full[n - 1 : n - 1 + n]  # slice of length n

        # ----- Adam update -----
        m = beta1 * m + (1.0 - beta1) * grad
        v = beta2 * v + (1.0 - beta2) * (grad ** 2)

        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        # step size decays like 1/√t (standard for Adam)
        step = eta0 / np.sqrt(t + 1.0)

        a = a - step * m_hat / (np.sqrt(v_hat) + eps)
        a = project_to_simplex(a)

        # ----- occasional reporting -----
        if t % report_every == 0:
            cur_val = fast_score(a)
            if cur_val < best_val:
                best_val = cur_val
                best_a = a.copy()
                print(f"  iter {t:8d} – new best (soft) score {cur_val:.6f}")

    # final check
    final_val = fast_score(a)
    if final_val < best_val:
        best_val = final_val
        best_a = a.copy()
    return best_a, best_val


# ----------------------------------------------------------------------
# Targeted max‑gradient descent (uses the true max entry)
# ----------------------------------------------------------------------


def max_gradient_descent(
    a: np.ndarray,
    deadline: float,
    max_steps: int = 15_000,
    step0: float = 0.12,
    decay: float = 0.97,
) -> tuple[np.ndarray, float]:
    """
    Perform a few projected gradient steps that directly minimise the
    current maximal entry of a*a.  The gradient for a given k is simply a
    shifted reverse of a.  The update is a = a - η·grad, followed by a
    simplex projection.
    """
    n = a.shape[0]
    best_a = a.copy()
    best_val = fast_score(best_a)

    step = step0
    for it in range(max_steps):
        if time.time() >= deadline - 0.5:
            break

        conv = convolution_fft(a, a)
        k_max = int(np.argmax(conv))

        # gradient for the one‑hot weight at k_max:
        # grad_i = 2 * a_rev[i + (n-1 - k_max)]  (zero outside the range)
        shift = n - 1 - k_max
        if shift >= 0:
            grad = np.concatenate([a[::-1][shift:], np.zeros(shift)])
        else:
            grad = np.concatenate([np.zeros(-shift), a[::-1][: n + shift]])
        grad = 2.0 * grad

        a = a - step * grad
        a = project_to_simplex(a)

        cur_val = fast_score(a)
        if cur_val < best_val:
            best_val = cur_val
            best_a = a.copy()
            # when we improve we can be a bit more aggressive
            step = min(step0, step / decay)
        else:
            step *= decay

    return best_a, best_val


# ----------------------------------------------------------------------
# Simple stochastic hill‑climber (swap / mass‑transfer moves)
# ----------------------------------------------------------------------


def hill_climb(
    seq,
    deadline,
    max_steps: int = 250_000,
) -> tuple[list[float], float]:
    """
    Stochastic hill‑climber that tries swaps and fractional mass‑transfers.
    Uses the exact score for acceptance.
    """
    a = np.array(seq, dtype=float)
    n = a.size

    best_a = a.copy()
    best_score = fast_score(best_a)

    scale = 0.1  # typical fraction of mass moved in a transfer

    while max_steps > 0 and time.time() < deadline:
        cand = best_a.copy()

        if np.random.rand() < 0.5:
            # swap two indices
            i, j = np.random.randint(n, size=2)
            cand[i], cand[j] = cand[j], cand[i]
        else:
            # transfer a fraction from i to j
            i, j = np.random.randint(n, size=2)
            if i != j and cand[i] > 0.0:
                delta = scale * cand[i]
                cand[i] -= delta
                cand[j] += delta

        cand = project_to_simplex(cand)
        cur_score = fast_score(cand)

        if cur_score < best_score:
            best_score = cur_score
            best_a = cand
            scale = min(scale * 1.07, 0.5)      # success → larger steps
        else:
            scale *= 0.96                     # failure → smaller steps

        max_steps -= 1

    return best_a.tolist(), best_score

def propose_candidate(seed: int = 42, budget_s: int = 1000, **kwargs):
    """
    Search for a non‑negative step function with a low score.
    The routine respects the 1000 s time‑budget, tries a few random
    Dirichlet restarts, refines them with a smooth Adam optimiser,
    applies a short targeted max‑gradient phase and finishes with a
    stochastic hill‑climber.
    """
    np.random.seed(seed)
    start_time = time.time()
    # keep a small safety margin for the harness
    deadline = start_time + budget_s - 2.0

    best_seq = None
    best_val = float("inf")

    # --------------------------------------------------------------
    # 0️⃣  Fallback (if a pre‑computed sequence is provided)
    # --------------------------------------------------------------
    try:
        fallback = [float(x) for x in height_sequence_1]  # type: ignore
        fb_val = evaluate_sequence(fallback)
        print(f"Fallback score = {fb_val:.6f}")
        if fb_val < best_val:
            best_val = fb_val
            best_seq = fallback
    except Exception:
        pass

    # --------------------------------------------------------------
    # 1️⃣  Choose a length – 2048 is a good compromise between quality
    #     and speed; we switch to 1024 if we are already very tight on time.
    # --------------------------------------------------------------
    n = 2048
    if time.time() + 8 > deadline:
        n = 1024
    print(f"Using sequence length n = {n}")

    # --------------------------------------------------------------
    # 2️⃣  Random restarts with smooth Adam optimisation
    # --------------------------------------------------------------
    # decide on the number of restarts from remaining time
    remaining = deadline - time.time()
    # each restart with smooth optimisation takes roughly 0.8·remaining / 6 secs
    # (empirically).  We cap the restarts at 5.
    num_restarts = min(5, max(1, int(remaining // 180.0)))
    iters_per_restart = 120_000

    for r in range(num_restarts):
        if time.time() >= deadline - 30.0:
            break

        # Dirichlet start – random concentration encourages both dense and
        # sparse initialise‑d vectors
        alpha = np.random.uniform(0.2, 2.5)
        a0 = np.random.gamma(alpha, 1.0, size=n)
        a0 = a0 / a0.sum()                     # projection onto the simplex

        init_score = fast_score(a0)
        if init_score < best_val:
            best_val = init_score
            best_seq = a0.tolist()
            print(f"Restart {r}: initial score = {init_score:.6f}")

        # ----- smooth optimisation (Adam + soft‑max) -----
        refined_a, refined_score = smooth_optimize_adam(
            a0,
            deadline - 12.0,
            iters=iters_per_restart,
            beta0=0.5,
            beta_max=200.0,
            eta0=0.35,
            report_every=15_000,
        )
        if refined_score < best_val:
            best_val = refined_score
            best_seq = refined_a.tolist()
            print(f"Restart {r}: after smooth optimisation best = {refined_score:.6f}")

        # ----- a few max‑gradient steps to attack the true max -----
        max_opt_a, max_opt_score = max_gradient_descent(
            refined_a,
            deadline - 8.0,
            max_steps=12_000,
            step0=0.12,
            decay=0.95,
        )
        if max_opt_score < best_val:
            best_val = max_opt_score
            best_seq = max_opt_a.tolist()
            print(f"Restart {r}: after max‑gradient best = {max_opt_score:.6f}")

    # --------------------------------------------------------------
    # 3️⃣  Final hill‑climb polishing (uses the exact objective)
    # --------------------------------------------------------------
    if best_seq is not None and time.time() < deadline - 5.0:
        print("\nApplying final hill‑climb polishing")
        polished_seq, polished_val = hill_climb(
            best_seq, deadline, max_steps=250_000
        )
        if polished_val < best_val:
            best_val = polished_val
            best_seq = polished_seq
            print(f"Hill‑climb improved best to {best_val:.6f}")

    # --------------------------------------------------------------
    # 4️⃣  Safeguard – tiny uniform vector if everything failed
    # --------------------------------------------------------------
    if best_seq is None:
        n_small = 256
        best_seq = [1.0 / n_small] * n_small
        best_val = evaluate_sequence(best_seq)

    # --------------------------------------------------------------
    # Report final score and return the sequence
    # --------------------------------------------------------------
    final_score = evaluate_sequence(best_seq)
    print(f"\nSearch finished. Final reported score = {final_score:.6f}")
    return best_seq
```
