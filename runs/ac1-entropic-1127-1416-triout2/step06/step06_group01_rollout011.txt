The score returned by `evaluate_sequence` (after the automatic scaling) is  

\[
\text{score}=2\,n\;\max_k (a*a)[k] ,
\qquad\text{with }\;a_i\ge 0,\;\sum_i a_i =1 .
\]

Hence the problem is **to minimise the maximum entry of the self‑convolution** of a
probability vector.  
The algorithm below follows a three‑stage strategy that is different from the
previous “Adam → sub‑gradient → EG” pipeline.

1. **Linear‑programming step** –  
   For a current vector `f` we compute  
   \[
   M = \max_k (f*f)[k].
   \]
   Keeping `M` fixed we solve the LP  

   \[
   \max_{g\ge 0}\;\;\mathbf 1^\top g \quad\text{s.t.}\quad
   (f*g)_k\le M\;(k=0,\dots,2n-2).
   \]

   The matrix of the linear constraints is a (rectangular) Toeplitz matrix,
   i.e. the linear‑convolution operator `f * g`.  
   The optimal `g` has a **larger total mass** than `f` while still respecting the
   same worst‑case convolution value `M`.  After normalising `g` to a probability
   vector we move from `f` towards `g`.  A short line‑search guarantees that the
   new vector really decreases `M`.  Repeating this LP‑+‑line‑search loop drives
   the maximal convolution value down and makes the autocorrelation increasingly flat.

2. **Exact polishing** –  
   After a few LP iterations the vector is already close to optimal.  A modest
   number of projected sub‑gradient steps (the same routine used before) removes
   the remaining excess in the ‑∞‑norm.  Finally a short exponentiated‑gradient
   (mirror‑descent) pass gives a clean final point.

3. **Multiple lengths & final choice** –  
   The whole pipeline is executed for two lengths (1024 and 2048).  The
   surrogate score `2·n·max(conv)` is used to pick the best candidate, which is
   then evaluated with the official `evaluate_sequence`.  The best official
   result is returned.

All stages respect a global 1000 s budget and use only NumPy & SciPy
(allowed by the rules).  The code contains no closures, no filesystem access,
and prints progress information.

```python
"""
Propose a step‑function sequence with a low evaluate_sequence score.

Algorithm
---------
1. Start from an arcsine‑distributed probability vector (sum = 1).
2. Iteratively improve it by solving a linear programme:
      maximise   Σ g_i
      subject to  (f * g)_k ≤ M   for every shift k,
                  g_i ≥ 0,
   where M = max(f*f).  The LP is built with a Toeplitz convolution matrix.
3. After each LP solve, normalise g to a probability vector and perform a
   back‑tracking line‑search on the segment (1‑t)·f + t·g, keeping the smallest
   t that strictly reduces the maximal convolution value.
4. When the LP improvement stalls (or time runs out) run a short projected
   sub‑gradient descent on the exact max‑convolution, followed by a few
   exponentiated‑gradient iterations.
5. Do the whole procedure for n = 1024 and n = 2048, keep the best official
   result and return it.

The method directly reduces the L∞‑norm of the auto‑correlation, which is the
quantity appearing in the official objective, and therefore achieves a lower
upper bound than the previous purely gradient‑based approach.
"""

import time
import numpy as np
from scipy.linalg import toeplitz
from scipy.optimize import linprog
from typing import List, Tuple

# ----------------------------------------------------------------------
# Basic convolution utilities
# ----------------------------------------------------------------------


def next_pow2(x: int) -> int:
    """Smallest power of two ≥ x."""
    return 1 << (x - 1).bit_length()


def convolution_fft(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Linear convolution via real FFT (length = len(a)+len(b)-1)."""
    m = len(a) + len(b) - 1
    n_fft = next_pow2(m)
    A = np.fft.rfft(a, n=n_fft)
    B = np.fft.rfft(b, n=n_fft)
    C = A * B
    conv = np.fft.irfft(C, n=n_fft)[:m]
    return conv


def compute_score(a: np.ndarray) -> float:
    """Fast surrogate: 2·n·max(conv(a,a))  (assumes Σa = 1)."""
    n = a.shape[0]
    conv = convolution_fft(a, a)
    return 2.0 * n * float(np.max(conv))


# ----------------------------------------------------------------------
# Simplex projection (used by later polishing steps)
# ----------------------------------------------------------------------


def project_to_simplex(v: np.ndarray) -> np.ndarray:
    """Euclidean projection of v onto {x ≥ 0, Σx = 1} (Duchi et al.)."""
    if np.all(v <= 0):
        return np.full_like(v, 1.0 / v.size)

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1.0
    rho_arr = u - cssv / np.arange(1, v.size + 1)
    rho = np.where(rho_arr > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = cssv[rho] / (rho + 1.0)
    w = np.maximum(v - theta, 0.0)
    return w


# ----------------------------------------------------------------------
# Starting shapes
# ----------------------------------------------------------------------


def arcsine_initial(n: int) -> np.ndarray:
    """
    Classic arcsine (Beta(½,½)) shape:
        a_i ∝ 1 / sqrt( (i+½)*(n‑½‑i) )
    Normalised to sum = 1.
    """
    i = np.arange(n, dtype=float)
    eps = 0.25
    vals = 1.0 / np.sqrt((i + 0.5) * (n - 0.5 - i) + eps)
    return vals / vals.sum()


# ----------------------------------------------------------------------
# Linear‑programming helpers
# ----------------------------------------------------------------------


def build_conv_matrix(a: np.ndarray) -> np.ndarray:
    """
    Return the (2n‑1)×n matrix A such that A @ g = np.convolve(a, g, mode='full').
    The matrix has a Toeplitz (constant‑diagonal) structure.
    """
    n = a.shape[0]
    first_col = np.concatenate([a, np.zeros(n - 1)])
    first_row = np.concatenate([a[:1], np.zeros(2 * n - 2)])
    A = toeplitz(first_col, first_row)[:, :n]   # shape (2n‑1, n)
    return A


def solve_lp_for_g(a: np.ndarray, M: float) -> np.ndarray | None:
    """
    Solve   maximise Σ g_i   s.t.  (a * g)_k ≤ M  (all k),  g ≥ 0.
    Returns the optimal g (not normalised) or None on failure.
    """
    n = a.shape[0]
    A = build_conv_matrix(a)                     # (2n‑1) × n
    b = np.full(2 * n - 1, M, dtype=np.float64)  # upper bound for each shift
    c = -np.ones(n, dtype=np.float64)            # minimise –Σg_i  → maximise Σg_i
    bounds = [(0, None)] * n

    # Use the high‑performance HiGHS interior‑point solver
    res = linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                  method='highs', options={'presolve': True})
    if not res.success:
        return None
    g = res.x
    if np.sum(g) <= 0:
        return None
    return g


def line_search_step(f: np.ndarray,
                     g: np.ndarray,
                     M_old: float,
                     max_iters: int = 20,
                     tol: float = 1e-8) -> Tuple[np.ndarray, float, float]:
    """
    Short back‑tracking line‑search on the segment (1‑t)·f + t·g.
    Returns (new_f, new_M, t_used) where new_M < M_old,
    or (f, M_old, 0.0) if no improvement is possible.
    """
    lo, hi = 0.0, 1.0
    best_f, best_M = f, M_old
    for _ in range(max_iters):
        t = (lo + hi) / 2.0
        cand = (1.0 - t) * f + t * g
        M_cand = float(np.max(convolution_fft(cand, cand)))
        if M_cand < M_old:
            # improvement – try a larger step
            hi = t
            best_f, best_M = cand, M_cand
        else:
            lo = t
        if hi - lo < tol:
            break
    # If the best_t is essentially zero, signal no progress
    if hi < 1e-6:
        return f, M_old, 0.0
    return best_f, best_M, hi


# ----------------------------------------------------------------------
# Exact polishing (sub‑gradient + exponentiated‑gradient)
# ----------------------------------------------------------------------


def subgradient_descent_exact(initial_a: np.ndarray,
                              deadline: float,
                              max_iter: int = 80_000,
                              step0: float = 0.05) -> np.ndarray:
    """
    Projected sub‑gradient descent on the exact objective max(conv(a,a)).
    Stops when the deadline is reached.
    """
    a = project_to_simplex(initial_a.copy())
    n = len(a)
    L = 2 * n - 1

    for it in range(1, max_iter + 1):
        if time.time() >= deadline:
            break
        conv = convolution_fft(a, a)
        max_val = float(np.max(conv))
        # mask of entries attaining (or almost attaining) the maximum
        tol = max_val * 1e-12 + 1e-14
        mask = (np.abs(conv - max_val) <= tol).astype(float)

        # sub‑gradient = 2 * (mask reversed) * a  (via convolution)
        mask_rev = mask[::-1]
        conv_rev = convolution_fft(a, mask_rev)
        subgrad = 2.0 * conv_rev[L - 1 - np.arange(n)]

        eta = step0 / np.sqrt(it)
        a = a - eta * subgrad
        a = project_to_simplex(a)

    return a


def eg_refine(a: np.ndarray,
              deadline: float,
              max_iter: int = 100_000,
              eta0: float = 0.3) -> np.ndarray:
    """
    Exponentiated‑gradient (mirror‑descent) polishing.
    """
    a = a.copy()
    n = len(a)
    L = 2 * n - 1

    for it in range(1, max_iter + 1):
        if time.time() >= deadline:
            break

        conv = convolution_fft(a, a)
        max_val = float(np.max(conv))
        tol = max_val * 1e-12 + 1e-14
        mask = (np.abs(conv - max_val) <= tol).astype(float)

        mask_rev = mask[::-1]
        conv_rev = convolution_fft(a, mask_rev)
        subgrad = 2.0 * conv_rev[L - 1 - np.arange(n)]

        eta = eta0 / (np.sqrt(it) + 1.0)
        a = a * np.exp(-eta * subgrad)

        tot = a.sum()
        if tot == 0.0:
            a = np.full_like(a, 1.0 / n)
        else:
            a = a / tot

    return a


# ----------------------------------------------------------------------
# Main entry point required by the competition harness
# ----------------------------------------------------------------------


def propose_candidate(seed: int = 42,
                     budget_s: int = 1000,
                     **kwargs) -> List[float]:
    """
    Search for a non‑negative step sequence with a low evaluate_sequence value.
    The routine runs the LP‑based improvement, followed by a short exact
    polishing phase, for two different lengths (1024 and 2048).  The best
    official result found before the deadline is returned.
    """
    rng = np.random.default_rng(seed)
    start_time = time.time()
    deadline = start_time + budget_s - 1.0      # safety margin

    best_seq: List[float] = []
    best_val: float = float("inf")

    # ------------------------------------------------------------------
    # Helper to run the whole pipeline for a given length
    # ------------------------------------------------------------------
    def optimise_length(n: int) -> Tuple[np.ndarray, float]:
        """Return (vector, surrogate_score) after LP‑+‑polish for length n."""
        # --- 0. initial shape -------------------------------------------------
        f = arcsine_initial(n)    # already Σ = 1

        # --- 1. LP improvement loop -------------------------------------------
        for iter_lp in range(1, 21):
            if time.time() >= deadline - 2.0:
                break
            # current worst‑case convolution value
            conv_ff = convolution_fft(f, f)
            M = float(np.max(conv_ff))

            # solve LP: maximise Σ g_i  s.t. (f * g)_k ≤ M
            g_raw = solve_lp_for_g(f, M)
            if g_raw is None:
                # LP failed – abort this length
                break

            # normalise g to a probability vector
            g = g_raw / np.sum(g_raw)

            # line search on the segment f → g
            f_new, M_new, t_used = line_search_step(f, g, M)
            if t_used == 0.0:
                # no improvement – stop LP iterations
                break

            f = f_new
            # occasional progress report
            if iter_lp % 5 == 0:
                print(f"    n={n}   LP it={iter_lp:02d}   M={M_new:.6e}   step={t_used:.4f}")

        surrogate = compute_score(f)
        print(f"\n*** Length {n}: LP phase finished, surrogate={surrogate:.6f}")

        # --- 2. Exact polishing (sub‑gradient + EG) --------------------------
        remaining = deadline - time.time()
        if remaining < 2.0:
            return f, surrogate

        # sub‑gradient descent – allocate most of the remaining budget
        max_iter_sub = int(min(120_000, remaining * 30))
        f_ref = subgradient_descent_exact(f, deadline,
                                          max_iter=max_iter_sub,
                                          step0=0.10)

        # exponentiated‑gradient polishing (if time permits)
        if time.time() < deadline - 1.0:
            remaining2 = deadline - time.time()
            max_iter_eg = int(min(120_000, remaining2 * 30))
            f_ref = eg_refine(f_ref, deadline,
                              max_iter=max_iter_eg,
                              eta0=0.20)

        # final surrogate after polishing
        final_surrogate = compute_score(f_ref)
        print(f"    Length {n}: final surrogate after polish = {final_surrogate:.6f}")
        return f_ref, final_surrogate

    # ------------------------------------------------------------------
    # Run the optimisation for the selected lengths
    # ------------------------------------------------------------------
    lengths = [1024, 2048]
    candidates: List[Tuple[float, np.ndarray]] = []   # (surrogate, vector)

    for n in lengths:
        if time.time() >= deadline - 5.0:
            break
        print(f"\n=== Optimising length {n} ===")
        vec, sur = optimise_length(n)
        candidates.append((sur, vec))

    # ------------------------------------------------------------------
    # Pick the best candidate according to the fast surrogate,
    # evaluate it with the official function, and keep the best official score.
    # ------------------------------------------------------------------
    candidates.sort(key=lambda x: x[0])
    for surrogate, vec in candidates:
        if time.time() >= deadline - 2.0:
            break
        try:
            val = evaluate_sequence(vec.tolist())
            print(f"Official evaluation (len={len(vec)}): {val:.6f}")
            if val < best_val:
                best_val = val
                best_seq = vec.tolist()
                print("*** New global best! ***")
        except Exception as e:
            print(f"Evaluation failed: {e}")

    # ------------------------------------------------------------------
    # Fallback: uniform vector (guarantees a finite score)
    # ------------------------------------------------------------------
    if not best_seq:
        n_fallback = 1024
        best_seq = [1.0 / n_fallback] * n_fallback
        best_val = evaluate_sequence(best_seq)
        print(f"Fallback uniform sequence, official score = {best_val:.6f}")

    print(f"\nSearch finished. Best official score = {best_val:.6f}")
    return best_seq
```
